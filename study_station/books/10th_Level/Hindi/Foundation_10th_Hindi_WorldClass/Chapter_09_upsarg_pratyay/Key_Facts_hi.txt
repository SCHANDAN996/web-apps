उपसर्ग और प्रत्यय — 25 संशोधन बिंदु

1. **उपसर्ग की परिभाषा** — मूल शब्द के **आरंभ** में जुड़कर उसका अर्थ बदलने या विशेष बनाने वाले अव्यय को उपसर्ग कहते हैं।  
   उदाहरण: "अनु" + "करण" = "अनुकरण"।

2. **प्रत्यय की परिभाषा** — मूल शब्द के **अंत** में जुड़कर नया शब्द बनाने या काल/लिंग/वचन बदलने वाले अव्यय को प्रत्यय कहते हैं।  
   उदाहरण: "पढ़" + "ना" = "पढ़ना"।

3. **उपसर्ग मूल शब्द से स्वतंत्र नहीं होता** — यह हमेशा मूल शब्द के साथ जुड़ा रहता है; अलग से प्रयोग नहीं होता।

4. **प्रत्यय भी स्वतंत्र नहीं होता** — यह मूल शब्द के पीछे जुड़कर ही अर्थ पूरा करता है।

5. **उपसर्ग अर्थ-परिवर्तक होता है** — जैसे "सु" (अच्छा) + "कर्म" = "सुकर्म" (अच्छा काम), "दु" (बुरा) + "कर्म" = "दुकर्म" (बुरा काम)।

6. **प्रत्यय शब्द-भेद बदल सकता है** — क्रिया से विशेषण/संज्ञा: "कृ" + "त" = "कृत" (विशेषण), "पढ़" + "आई" = "पढ़ाई" (संज्ञा)।

7. **मुख्य उपसर्ग (हिंदी व्याकरणानुसार)** — अनु, अभि, अव, आ, उप, नि, निस्, परा, प्रति, प्र, वि, सम्, सु, दु, अ, कु।

8. **मुख्य प्रत्यय (कृदंत/तद्धित)** — क्त, क्तवतु, शतृ, शानच्, तव्य, अनीय, यत् (कृदंत); त, तृ, इनि, ईयस्, इष्ठ, तम, त्व, ता, मत्, वत् (तद्धित)।

9. **उपसर्ग 'प्र' का अर्थ** — आगे, बहुत, आरंभ।  
   उदाहरण: "प्र" + "काश" = "प्रकाश" (आगे चमकना), "प्र" + "थम" = "प्रथम" (सबसे आगे)।

10. **उपसर्ग 'वि' का अर्थ** — विशेष, विपरीत, अलग।  
    उदाहरण: "वि" + "भाग" = "विभाग" (विशेष भाग), "वि" + "परीत" = "विपरीत" (उल्टा)।

11. **उपसर्ग 'अनु' का अर्थ** — पीछे, अनुसार।  
    उदाहरण: "अनु" + "करण" = "अनुकरण" (पीछे करना/नकल)।

12. **उपसर्ग 'उप' का अर्थ** — निकट, नीचे, सहायक।  
    उदाहरण: "उप" + "वन" = "उपवन" (निकट का वन), "उप" + "चार" = "उपचार" (सहायक चिकित्सा)।

13. **उपसर्ग 'नि/निस्' का अर्थ** — निश्चय, बाहर, बिना।  
    उदाहरण: "नि" + "श्चय" = "निश्चय" (दृढ़ निश्चय), "निस्" + "सहाय" = "निस्सहाय" (बिना सहायता)।

14. **उपसर्ग 'सु/दु' का अर्थ** — सु = अच्छा/सुगम, दु = बुरा/कठिन।  
    उदाहरण: "सु" + "ंदर" = "सुंदर", "दु" + "घटना" = "दुर्घटना"।

15. **प्रत्यय 'ता/त्व' (तद्धित)** — संज्ञा/विशेषण से भाववाचक संज्ञा बनाता है।  
    उदाहरण: "सुंदर" + "ता" = "सुंदरता", "बुद्धिमान" + "ता" = "बुद्धिमत्ता"।

16. **प्रत्यय 'इक/ईय' (तद्धित)** — संज्ञा से विशेषण बनाता है।  
    उदाहरण: "देश" + "इक" = "देशिक", "देश" + "ईय" = "देशीय"।

17. **प्रत्यय 'क' (कर्तृ, कृदंत)** — क्रिया से कर्ता बोधक संज्ञा बनाता है।  
    उदाहरण: "लिख" + "क" = "लेखक", "गाय" + "क" = "गायक"।

18. **प्रत्यय 'नीय/तव्य' (कृदंत)** — कर्तव्य/योग्यता बोधक विशेषण बनाता है।  
    उदाहरण: "कृ" + "अनीय" = "करणीय", "पठ्" + "नीय" = "पाठनीय"।

19. **उपसर्ग जोड़ते समय वर्ण-संधि** — कई बार उपसर्ग का अंतिम वर्ण मूल शब्द के प्रथम वर्ण से मिलकर बदल जाता है।  
    उदाहरण: "सम्" + "कार" = "संकार" (म् → ं), "नि:" + "शुल्क" = "निःशुल्क" (ः)।

20. **प्रत्यय जोड़ते समय मूल शब्द में परिवर्तन** — कभी मूल शब्द का अंतिम स्वर/व्यंजन बदलता या लुप्त होता है।  
    उदाहरण: "हस" + "न" = "हँसना" (स् → ँस अनुनासिक), "पा" + "ना" = "पाना" (आ → ा)।

21. **उपसर्ग 'अ/अन्' (नकारात्मक)** — विशेषण/संज्ञा के आगे लगकर विपरीत अर्थ देता है।  
    उदाहरण: "अ" + "सत्य" = "असत्य", "अन्" + "एक" = "अनेक"।

22. **उपसर्ग 'प्रति' का अर्थ** — प्रति, उत्तर, प्रतिबिंब।  
    उदाहरण: "प्रति" + "दिन" = "प्रतिदिन", "प्रति" + "क्षा" = "प्रतीक्षा"।

23. **उपसर्ग 'परा' का अर्थ** — परे, दूर, पूर्ण।  
    उदाहरण: "परा" + "जय" = "पराजय", "परा" + "विद्या" = "पराविद्या"।

24. **एक शब्द में एक से अधिक उपसर्ग/प्रत्यय संभव** —  
    उदाहरण: "प्रति" + "कूल" = "प्रतिकूल" (एक उपसर्ग), "कृ" + "त" + "वत्" = "कृतवत्" (दो कृदन्त प्रत्यय)।

25. **परीक्षा में पहचानने का सूत्र** — शब्द के **आरंभ** में जुड़ा अव्यय **उपसर्ग**, **अंत** में जुड़ा अव्यय **प्रत्यय**। मूल शब्द अलग करके देखें: अर्थ बदलता है तो उपसर्ग, शब्द-भेद/काल बदलता है तो प्रत्यय।
