1. Which of the following words is spelled correctly in Hindi?
(a) विद्यालय् (b) विधालय (c) विद्द्यालय (d) विद्यालय
Answer: (d)
Solution: The trap is option (b) "विधालय" which misses the 'य' after 'द', and option (c) "विद्द्यालय" which incorrectly doubles the 'द'. The correct spelling uses 'द्' + 'य' = 'दय' without doubling, so the answer is विद्यालय.
Source: NCERT Class 6 Hindi Vasant

2. Identify the correctly spelled word for "teacher" in Hindi.
(a) अध्यापकः (b) अध्यापक (c) अध्यापकक (d) अध्यापक्
Answer: (b)
Solution: Option (d) adds an unnecessary halant at the end, option (c) doubles the final consonant, and option (a) adds a visarga which is not used in this noun form. The standard spelling is अध्यापक, so the answer is अध्यापक.
Source: NCERT Class 6 Hindi Vasant

Answer: (d)
Solution: The trap is option (b) "आकांश" which incorrectly uses anusvār before 'श' (a sibilant) where 'श' itself represents the sound; option (c) misses the 'श' sound entirely. The correct spelling uses 'श' directly without anusvār, so the answer is आकाश.

21. In the following sentence, identify the part with a spelling error: "बच्चे स्कूल जाते हैं।" Parts: P="बच्चे", Q="स्कूल", R="जाते", S="हैं"
(a) No error (b) Part Q (c) Part R (d) Part P
Answer: (a)
Solution: The trap is expecting an error in "स्कूल" (often misspelled as "स्कुल" with short 'उ') or "हैं" (often written as "है" missing candrabindu). But all parts are correctly spelled: "बच्चे" (double च् + ए), "स्कूल" (long ऊ), "जाते" (ज + आ + त + ए), "हैं" (ह + ैं with candrabindu). So the answer is No error.
Source: PYQ-style

22. Which part contains a spelling mistake in: "मैँ कल दिल्ली जाऊँगा।" Parts: P="मैँ", Q="कल", R="दिल्ली", S="जाऊँगा"
(a) Part Q (b) Part S (c) Part R (d) Part P
Answer: (d)
Solution: The trap is Part P "मैँ" — the candrabindu (ँ) is incorrectly placed on 'मै' (which already has a vowel matrā). The correct form is "मैं" (चंद्रबिंदु on 'म' with no matrā) or "मैँ" is sometimes seen but standard is "मैं". Part R "दिल्ली" correctly uses double 'ल्' + 'ी'. Part S "जाऊँगा" correctly uses anusvār before 'ग'. So the error is in Part P.
Source: PYQ-style
