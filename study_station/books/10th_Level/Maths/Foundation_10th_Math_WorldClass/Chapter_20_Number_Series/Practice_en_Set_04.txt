Practice Set 4 — Number Series (Questions 76–100: All Medium)

76. Find the next term in the series: 6, 9, 14, 23, 38, ?
(a) 61 (b) 63 (c) 65 (d) 67
Answer: (a)
Solution: The differences are +3, +5, +9, +15, and these differences rise by 2, 4, 6, so the next rise is 8, giving a difference of 23. The trap is stopping at the first level of differences and guessing 63. So the answer is 61.
Source: PYQ-style

77. What comes next: 1, 5, 14, 30, 55, ?
(a) 80 (b) 91 (c) 85 (d) 95
Answer: (b)
Solution: The differences are +4, +9, +16, +25, i.e. the squares 2², 3², 4², 5², so the next difference is 6² = 36. The trap is treating the differences as random and adding 30 to get 85. So the answer is 91.
Source: NCERT Class 8 Mathematics

78. Complete the series: 3, 7, 19, 55, ?
(a) 155 (b) 163 (c) 167 (d) 171
Answer: (b)
Solution: Each term is the previous term multiplied by 3 minus 2: 3×3−2=7, 7×3−2=19, 19×3−2=55. The trap is using ×3−10, which gives 155. So the answer is 163.
Source: PYQ-style

79. Find the next term: 2, 5, 17, 71, ?
(a) 359 (b) 355 (c) 347 (d) 351
Answer: (a)
Solution: The operations are ×2+1, ×3+2, ×4+3, so next is ×5+4: 71×5+4=359. The trap is applying ×5+0 and getting 355. So the answer is 359.
Source: PYQ-style

80. Find the missing term: 4, 9, 25, 49, ?
(a) 64 (b) 81 (c) 100 (d) 121
Answer: (d)
Solution: These are squares of consecutive primes: 2²=4, 3²=9, 5²=25, 7²=49, so next is 11². The trap is taking squares of odd numbers and picking 81 (9²). So the answer is 121.
Source: NCERT Class 8 Mathematics

81. Find the next term: 8, 10, 18, 44, ?
(a) 108 (b) 140 (c) 124 (d) 156
Answer: (c)
Solution: The differences are +2, +8, +26, and the gaps between differences are +6, +18, which triple, so the next gap is +54, giving a difference of 80. The trap is doubling the last difference (26×2=52) and getting 96, which is not listed, pushing guessers to 108. So the answer is 124.
Source: PYQ-style

82. Complete the series: 11, 20, 38, 74, ?
(a) 148 (b) 150 (c) 146 (d) 142
Answer: (c)
Solution: Each term is the previous term multiplied by 2 minus 2: 11×2−2=20, 20×2−2=38, 38×2−2=74. The trap is using ×2 exactly and getting 148. So the answer is 146.
Source: PYQ-style

83. Find the next term: 5, 8, 17, 44, ?
(a) 116 (b) 128 (c) 137 (d) 125
Answer: (d)
Solution: Each term is the previous term multiplied by 3 minus 7: 5×3−7=8, 8×3−7=17, 17×3−7=44. The trap is computing 44×3=132 and subtracting 4 by mistake to get 128. So the answer is 125.
Source: PYQ-style

85. Find the next term: 0, 2, 6, 12, 20, ?
(a) 28 (b) 26 (c) 30 (d) 32
Answer: (c)
Solution: The terms follow n²−n (1²−1=0, 2²−2=2, …, 5²−5=20), so next is 6²−6. Equivalently the differences grow by 2: +2, +4, +6, +8, then +10. The trap is adding 8 again to get 28. So the answer is 30.
Source: NCERT Class 8 Mathematics

86. Complete the series: 3, 5, 9, 17, 33, ?
(a) 65 (b) 61 (c) 63 (d) 67
Answer: (a)
Solution: Each term is the previous term multiplied by 2 minus 1: 3×2−1=5, 5×2−1=9, …, 33×2−1=65. The trap is doubling and adding nothing, which gives 66, nudging guessers to 67. So the answer is 65.
Source: PYQ-style

88. What comes after 7, 14, 28, 56, ?
(a) 84 (b) 98 (c) 112 (d) 120

89. Find the next term: 1, 3, 10, 41, ?
(a) 196 (b) 186 (c) 216 (d) 206
Answer: (d)
Solution: The multipliers rise by one each step with +1 added: 1×2+1=3, 3×3+1=10, 10×4+1=41, so next is 41×5+1. The trap is using ×5−9 and landing on 196. So the answer is 206.
Source: PYQ-style

90. Complete the series: 100, 81, 64, 49, ?
(a) 40 (b) 36 (c) 42 (d) 34
Answer: (b)
Solution: These are descending squares: 10², 9², 8², 7², so next is 6². The trap is subtracting the last difference 15 again to get 34. So the answer is 36.

98. Find the next number: 3, 5, 8, 13, 21, ?
(a) 32 (b) 35 (c) 33 (d) 34
Answer: (d)
Solution: This is a Fibonacci-type series where each term is the sum of the previous two: 13+21=34. The trap is treating the differences as +2, +3, +5, +8 and adding 11 to get 32. So the answer is 34.
Source: NCERT Class 10 Mathematics

99. Complete the series: 2, 9, 28, 65, 126, ?
(a) 217 (b) 215 (c) 218 (d) 216
Answer: (a)
Solution: The terms are n³+1: 1³+1=2, 2³+1=9, …, 5³+1=126, so next is 6³+1. The trap is writing just the cube 216 and forgetting the +1. So the answer is 217.
Source: NCERT Class 8 Mathematics

100. Find the next term: 3, 11, 27, 59, ?
(a) 123 (b) 121 (c) 119 (d) 117
Answer: (a)
Solution: The differences are +8, +16, +32, doubling each time, so the next difference is +64. The trap is using ×2+5 on 59 and getting 123 by luck but misreading it as 121 through an arithmetic slip. So the answer is 123.
Source: PYQ-style
