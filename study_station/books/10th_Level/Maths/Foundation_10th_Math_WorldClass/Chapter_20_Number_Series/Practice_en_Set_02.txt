Set 2: Number Series MCQs (Foundation Level) — Questions 26–50 (All Medium)

26. What comes next in the series: 7, 11, 19, 35, 67, ?
(a) 135 (b) 125 (c) 128 (d) 131
Answer: (d)
Solution: The differences are +4, +8, +16, +32, doubling each time, so the next difference is +64. The trap is 128, which comes from repeating +32 or a doubling slip; 67 + 64 = 131, so the answer is 131.
Source: PYQ-style

27. Find the missing term: 3, 10, 29, 66, 127, ?
(a) 218 (b) 196 (c) 206 (d) 222
Answer: (a)
Solution: Each term is n³ + 2: 1³+2=3, 2³+2=10, 3³+2=29, 4³+2=66, 5³+2=127, so the next is 6³+2. The trap is 222, which comes from miscomputing 6³ as 220; 6³ = 216 and 216 + 2 = 218, so the answer is 218.
Source: NCERT Class 8 Mathematics

29. Complete the series: 2, 4, 10, 28, ?
(a) 78 (b) 82 (c) 84 (d) 72
Answer: (b)
Solution: The rule is ×3 − 2: 2×3−2=4, 4×3−2=10, 10×3−2=28. The trap is 84, which is just 28×3 without subtracting 2; 28×3−2 = 82, so the answer is 82.
Source: PYQ-style
