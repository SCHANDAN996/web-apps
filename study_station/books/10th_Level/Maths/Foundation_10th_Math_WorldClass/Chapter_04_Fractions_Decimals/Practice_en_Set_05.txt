Set 5: Fractions & Decimals MCQs (Hard / Advanced Operations)
Questions 101–125: Hard

101. Simplify the continued fraction: 1 + 1 / [ 1 + 1 / ( 1 + 1/3 ) ]
(a) 11/7 (b) 8/5 (c) 10/7 (d) 7/4
Answer: (a) 11/7
Solution: Evaluate bottom-up: 1 + 1/3 = 4/3. 1/(4/3) = 3/4. Next: 1 + 3/4 = 7/4. 1/(7/4) = 4/7. Finally: 1 + 4/7 = 11/7.
Source: SSC CGL Pattern

102. If 2 = x + 1 / [ 1 + 1 / ( 3 + 1/4 ) ], find the value of x.
(a) 18/17 (b) 21/17 (c) 1 (d) 24/17
Answer: (b) 21/17
Solution: Bottom-up: 3 + 1/4 = 13/4. 1/(13/4) = 4/13. 1 + 4/13 = 17/13. 1/(17/13) = 13/17. Then 2 = x + 13/17 ⇒ x = 2 – 13/17 = 21/17.
Source: SSC CGL Pattern

103. Evaluate: 1 / [ 3 + 1 / ( 2 + 1 / ( 1/2 ) ) ]
(a) 3/13 (b) 1/4 (c) 4/13 (d) 5/13
Answer: (c) 4/13
Solution: 1 / (1/2) = 2. Inside bracket: 2 + 2 = 4. Then 1/4. Next: 3 + 1/4 = 13/4. Finally: 1 / (13/4) = 4/13.
Source: Banking Exam Pattern

104. Which of the following fractions has a terminating decimal expansion?
(a) 7/12 (b) 13/24 (c) 11/30 (d) 21/250
Answer: (d) 21/250
Solution: A fraction in simplest form has a terminating decimal if and only if the prime factorization of its denominator contains only 2s and 5s. 250 = 2 × 5³, so 21/250 terminates (0.084).
Source: NCERT Class 10

105. Find the value of: (0.1³ + 0.02³) / (0.2³ + 0.04³)
(a) 0.125 (b) 0.25 (c) 0.5 (d) 0.0625
Answer: (a) 0.125
Solution: Factor out 2³ = 8 from the denominator: (0.2³ + 0.04³) = 2³ × (0.1³ + 0.02³). The ratio is 1/8 = 0.125.
Source: SSC CGL Pattern

106. Simplify the telescoping series: 1/(1×2) + 1/(2×3) + 1/(3×4) + ... + 1/(9×10)
(a) 1 (b) 9/10 (c) 4/5 (d) 10/11
Answer: (b) 9/10
Solution: Each term 1/(n(n+1)) = 1/n – 1/(n+1). Sum = (1 – 1/2) + (1/2 – 1/3) + ... + (1/9 – 1/10) = 1 – 1/10 = 9/10.
Source: Railway (RRB NTPC) Pattern

107. Find the sum: 1/(2×3) + 1/(3×4) + 1/(4×5) + 1/(5×6)
(a) 1/6 (b) 1/4 (c) 1/3 (d) 5/12
Answer: (c) 1/3
Solution: Using partial fractions: (1/2 – 1/3) + (1/3 – 1/4) + (1/4 – 1/5) + (1/5 – 1/6) = 1/2 – 1/6 = 3/6 – 1/6 = 2/6 = 1/3.
Source: NCERT Class 7

108. Evaluate: (3.75² – 2.25²) / (3.75 – 2.25)
(a) 5.5 (b) 5.0 (c) 7.0 (d) 6.0
Answer: (d) 6.0
Solution: Using identity (a² – b²) / (a – b) = a + b. Here a = 3.75 and b = 2.25, so sum = 3.75 + 2.25 = 6.0.
Source: SSC CHSL Pattern

109. Evaluate: 1 / [ 1 + 1 / ( 2 + 1/3 ) ]
(a) 7/10 (b) 10/7 (c) 3/7 (d) 4/7
Answer: (a) 7/10
Solution: Bottom-up: 2 + 1/3 = 7/3. 1/(7/3) = 3/7. Next: 1 + 3/7 = 10/7. Finally: 1/(10/7) = 7/10.
Source: Banking (IBPS) Pattern

110. Find the value of: (999 995/999) × 999
(a) 995 (b) 998996 (c) 999995 (d) 998001
Answer: (b) 998996
Solution: Psychological Trap: Treating the mixed fraction as multiplication and cancelling 999 to get 995 is incorrect. A mixed fraction means addition: 999 995/999 = 999 + 995/999. Multiplying by 999: (999 × 999) + 995 = (1000 – 1) × 999 + 995 = 999,000 – 999 + 995 = 999,000 – 4 = 998,996.
Source: SSC CGL Pattern

111. Find the sum: 1/(1×3) + 1/(3×5) + 1/(5×7) + 1/(7×9)
(a) 2/9 (b) 3/8 (c) 4/9 (d) 5/9
Answer: (c) 4/9
Solution: Difference between factors is 2: (1/2) × (1/1 – 1/9) = (1/2) × (8/9) = 4/9.
Source: SSC CGL Pattern

112. If a/b = 4/3, find the value of (3a + 2b) / (3a – 2b).
(a) 2 (b) 5 (c) 4 (d) 3
Answer: (d) 3
Solution: Substitute a = 4 and b = 3: (3×4 + 2×3) / (3×4 – 2×3) = (12 + 6) / (12 – 6) = 18 / 6 = 3.
Source: SSC MTS Pattern

113. Evaluate: (0.96³ – 0.04³) / (0.96² + 0.96 × 0.04 + 0.04²)
(a) 0.92 (b) 1.00 (c) 0.96 (d) 0.90
Answer: (a) 0.92
Solution: Using identity (a³ – b³) / (a² + ab + b²) = a – b. Here 0.96 – 0.04 = 0.92.
Source: SSC CGL Pattern

114. Simplify: 5 / [ 1 + 1 / ( 3 – 1/2 ) ]
(a) 3 1/7 (b) 3 4/7 (c) 4 (d) 2 6/7
Answer: (b) 3 4/7
Solution: 3 – 1/2 = 5/2. 1/(5/2) = 2/5. 1 + 2/5 = 7/5. Finally: 5 ÷ (7/5) = 5 × 5/7 = 25/7 = 3 4/7.
Source: Railway (RRB NTPC) Pattern

115. Which of the following fractions has a non-terminating repeating decimal expansion?
(a) 3/8 (b) 7/20 (c) 2/15 (d) 9/40
Answer: (c) 2/15
Solution: Denominator 15 = 3 × 5 has a prime factor 3 (other than 2 and 5), which produces a non-terminating repeating decimal (0.1333...).
Source: NCERT Class 10

116. Find the sum: 999 1/7 + 999 2/7 + 999 3/7 + 999 4/7 + 999 5/7 + 999 6/7
(a) 5994 (b) 6000 (c) 5991 (d) 5997
Answer: (d) 5997
Solution: Group integer and fraction parts: (999 × 6) + (1 + 2 + 3 + 4 + 5 + 6)/7 = 5994 + 21/7 = 5994 + 3 = 5997.
Source: SSC CGL Pattern

117. If x = 1 + 1 / [ 1 + 1 / ( 1 + 1/2 ) ], find the value of 2x + 7/4.
(a) 4.95 (b) 4.50 (c) 5.25 (d) 3.75
Answer: (a) 4.95
Solution: Continued fraction: 1 + 1/2 = 3/2 ⇒ 2/3. 1 + 2/3 = 5/3 ⇒ 3/5. x = 1 + 3/5 = 8/5. Expression: 2(8/5) + 7/4 = 16/5 + 7/4 = (64 + 35)/20 = 99/20 = 4.95.
Source: SSC CGL Pattern

118. Find the sum: 1/(3×5) + 1/(5×7) + 1/(7×9) + 1/(9×11)
(a) 2/33 (b) 4/33 (c) 8/33 (d) 1/11
Answer: (b) 4/33
Solution: Using formula (1/difference) × (1/first – 1/last): (1/2) × (1/3 – 1/11) = (1/2) × (8/33) = 4/33.
Source: Banking Exam Pattern

119. Calculate: 1.7 × 1.7 + 0.3 × 0.3 – 2 × 1.7 × 0.3
(a) 1.44 (b) 1.69 (c) 1.96 (d) 2.25
Answer: (c) 1.96
Solution: Using identity a² + b² – 2ab = (a – b)². Here (1.7 – 0.3)² = 1.4² = 1.96.
Source: SSC CHSL Pattern

120. If 1 / [ a + 1 / ( b + 1/c ) ] = 9/26, where a, b, c are positive integers, find the value of a + b + c.
(a) 9 (b) 10 (c) 12 (d) 11
Answer: (d) 11
Solution: Psychological Trap: Inverting fractions prematurely. Take reciprocal: 26/9 = 2 + 8/9, so a = 2. Next reciprocal: 9/8 = 1 + 1/8, so b = 1 and c = 8. Sum: a + b + c = 2 + 1 + 8 = 11.
Source: SSC CGL Pattern

121. Simplify the product: (1 – 1/2)(1 – 1/3)(1 – 1/4)...(1 – 1/10)
(a) 1/10 (b) 1/5 (c) 1/20 (d) 9/10
Answer: (a) 1/10
Solution: Simplify brackets: (1/2) × (2/3) × (3/4) × ... × (9/10). All intermediate numerators and denominators cancel out, leaving 1/10.
Source: SSC MTS Pattern

122. Simplify the product: (1 + 1/2)(1 + 1/3)(1 + 1/4)...(1 + 1/10)
(a) 5 (b) 11/2 (c) 6 (d) 13/2
Answer: (b) 11/2
Solution: Simplify brackets: (3/2) × (4/3) × (5/4) × ... × (11/10). Intermediate terms cancel out, leaving 11/2 = 5.5.
Source: SSC CGL Pattern

123. Evaluate: (0.3375 ÷ 0.045) × 0.2
(a) 1.2 (b) 1.8 (c) 1.5 (d) 2.0
Answer: (c) 1.5
Solution: Division: 0.3375 ÷ 0.045 = 337.5 ÷ 45 = 7.5. Multiplication: 7.5 × 0.2 = 1.5.
Source: Banking Exam Pattern

124. Find the sum of the series: 1/(1×4) + 1/(4×7) + 1/(7×10) + 1/(10×13) + 1/(13×16)
(a) 3/16 (b) 1/4 (c) 7/16 (d) 5/16
Answer: (d) 5/16
Solution: Common difference = 3: (1/3) × (1/1 – 1/16) = (1/3) × (15/16) = 5/16.
Source: Railway (RRB NTPC) Pattern

125. If a/b = 2/3 and b/c = 4/5, find the value of (a + b) / (b + c).
(a) 10/27 (b) 20/27 (c) 15/28 (d) 8/15
Answer: (b) 20/27
Solution: Compound ratio: a : b = 8 : 12 and b : c = 12 : 15, so a : b : c = 8 : 12 : 15. Then (a + b)/(b + c) = (8 + 12)/(12 + 15) = 20/27.
Source: SSC CHSL Pattern
