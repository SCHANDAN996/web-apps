सेट 5: भिन्न और दशमलव बहुविकल्पीय प्रश्न (कठिन / उन्नत संक्रियाएँ)
प्रश्न 101–125: कठिन

101. वितत भिन्न को सरल कीजिए: 1 + 1 / [ 1 + 1 / ( 1 + 1/3 ) ]
(a) 11/7 (b) 8/5 (c) 10/7 (d) 7/4
उत्तर: (a) 11/7
हल: नीचे से ऊपर हल करें: 1 + 1/3 = 4/3। 1/(4/3) = 3/4। 1 + 3/4 = 7/4। 1/(7/4) = 4/7। अंत में: 1 + 4/7 = 11/7।
स्रोत: SSC CGL Pattern

102. यदि 2 = x + 1 / [ 1 + 1 / ( 3 + 1/4 ) ] है, तो x का मान ज्ञात कीजिए।
(a) 18/17 (b) 21/17 (c) 1 (d) 24/17
उत्तर: (b) 21/17
हल: नीचे से हल करें: 3 + 1/4 = 13/4 ⇒ 4/13। 1 + 4/13 = 17/13 ⇒ 13/17। अतः x = 2 – 13/17 = 21/17।
स्रोत: SSC CGL Pattern

103. मान ज्ञात कीजिए: 1 / [ 3 + 1 / ( 2 + 1 / ( 1/2 ) ) ]
(a) 3/13 (b) 1/4 (c) 4/13 (d) 5/13
उत्तर: (c) 4/13
हल: 1 / (1/2) = 2। 2 + 2 = 4। फिर 3 + 1/4 = 13/4। अंत में: 1 / (13/4) = 4/13।
स्रोत: Banking Exam Pattern

104. निम्नलिखित में से किस भिन्न का दशमलव प्रसार सांत (terminating) है?
(a) 7/12 (b) 13/24 (c) 11/30 (d) 21/250
उत्तर: (d) 21/250
हल: सांत दशमलव के लिए सरलतम भिन्न के हर के अभाज्य गुणनखंड केवल 2 और 5 होने चाहिए। 250 = 2 × 5³, अतः 21/250 सांत है (0.084)।
स्रोत: NCERT Class 10

105. मान ज्ञात कीजिए: (0.1³ + 0.02³) / (0.2³ + 0.04³)
(a) 0.125 (b) 0.25 (c) 0.5 (d) 0.0625
उत्तर: (a) 0.125
हल: हर में से 2³ = 8 उभयनिष्ठ लें: अनुपात 1/8 = 0.125 प्राप्त होता है।
स्रोत: SSC CGL Pattern

106. श्रेणी का योग ज्ञात कीजिए: 1/(1×2) + 1/(2×3) + 1/(3×4) + ... + 1/(9×10)
(a) 1 (b) 9/10 (c) 4/5 (d) 10/11
उत्तर: (b) 9/10
हल: प्रत्येक पद 1/n – 1/(n+1) होता है। पदों के कटने पर: 1 – 1/10 = 9/10।
स्रोत: Railway (RRB NTPC) Pattern

107. योग ज्ञात कीजिए: 1/(2×3) + 1/(3×4) + 1/(4×5) + 1/(5×6)
(a) 1/6 (b) 1/4 (c) 1/3 (d) 5/12
उत्तर: (c) 1/3
हल: आंशिक भिन्न विधि: 1/2 – 1/6 = 2/6 = 1/3।
स्रोत: NCERT Class 7

108. मान ज्ञात कीजिए: (3.75² – 2.25²) / (3.75 – 2.25)
(a) 5.5 (b) 5.0 (c) 7.0 (d) 6.0
उत्तर: (d) 6.0
हल: सर्वसमिका (a² – b²) / (a – b) = a + b से: 3.75 + 2.25 = 6.0।
स्रोत: SSC CHSL Pattern

109. मान ज्ञात कीजिए: 1 / [ 1 + 1 / ( 2 + 1/3 ) ]
(a) 7/10 (b) 10/7 (c) 3/7 (d) 4/7
उत्तर: (a) 7/10
हल: नीचे से हल करें: 2 + 1/3 = 7/3 ⇒ 3/7। 1 + 3/7 = 10/7। अंत में 1/(10/7) = 7/10।
स्रोत: Banking (IBPS) Pattern

110. मान ज्ञात कीजिए: (999 995/999) × 999
(a) 995 (b) 998996 (c) 999995 (d) 998001
उत्तर: (b) 998996
हल: मनोवैज्ञानिक जाल: 999 को काटकर केवल 995 उत्तर देना गलत है। मिश्रित भिन्न का अर्थ जोड़ है: 999 + 995/999। 999 से गुणा करने पर: 999 × 999 + 995 = 999000 – 999 + 995 = 998,996।
स्रोत: SSC CGL Pattern

111. योग ज्ञात कीजिए: 1/(1×3) + 1/(3×5) + 1/(5×7) + 1/(7×9)
(a) 2/9 (b) 3/8 (c) 4/9 (d) 5/9
उत्तर: (c) 4/9
हल: गुणनखंडों का अंतर 2 है: 1/2 × (1/1 – 1/9) = 1/2 × 8/9 = 4/9।
स्रोत: SSC CGL Pattern

112. यदि a/b = 4/3 है, तो (3a + 2b) / (3a – 2b) का मान क्या होगा?
(a) 2 (b) 5 (c) 4 (d) 3
उत्तर: (d) 3
हल: a = 4 तथा b = 3 रखने पर: (12 + 6) / (12 – 6) = 18 / 6 = 3।
स्रोत: SSC MTS Pattern

113. मान ज्ञात कीजिए: (0.96³ – 0.04³) / (0.96² + 0.96 × 0.04 + 0.04²)
(a) 0.92 (b) 1.00 (c) 0.96 (d) 0.90
उत्तर: (a) 0.92
हल: सर्वसमिका (a³ – b³) / (a² + ab + b²) = a – b से: 0.96 – 0.04 = 0.92।
स्रोत: SSC CGL Pattern

114. सरल कीजिए: 5 / [ 1 + 1 / ( 3 – 1/2 ) ]
(a) 3 1/7 (b) 3 4/7 (c) 4 (d) 2 6/7
उत्तर: (b) 3 4/7
हल: 3 – 1/2 = 5/2 ⇒ 2/5। 1 + 2/5 = 7/5। अतः 5 × 5/7 = 25/7 = 3 4/7।
स्रोत: Railway (RRB NTPC) Pattern

115. निम्नलिखित में से किस भिन्न का दशमलव प्रसार असांत आवर्ती है?
(a) 3/8 (b) 7/20 (c) 2/15 (d) 9/40
उत्तर: (c) 2/15
हल: हर 15 = 3 × 5 में अभाज्य गुणनखंड 3 है (2 और 5 के अतिरिक्त), अतः इसका प्रसार असांत आवर्ती है (0.133...)।
स्रोत: NCERT Class 10

116. योग ज्ञात कीजिए: 999 1/7 + 999 2/7 + 999 3/7 + 999 4/7 + 999 5/7 + 999 6/7
(a) 5994 (b) 6000 (c) 5991 (d) 5997
उत्तर: (d) 5997
हल: पूर्णांक व भिन्न अलग करें: (999 × 6) + 21/7 = 5994 + 3 = 5997।
स्रोत: SSC CGL Pattern

117. यदि x = 1 + 1 / [ 1 + 1 / ( 1 + 1/2 ) ] है, तो 2x + 7/4 का मान ज्ञात कीजिए।
(a) 4.95 (b) 4.50 (c) 5.25 (d) 3.75
उत्तर: (a) 4.95
हल: x = 8/5। व्यंजक: 2(8/5) + 7/4 = 16/5 + 7/4 = 99/20 = 4.95।
स्रोत: SSC CGL Pattern

118. योग ज्ञात कीजिए: 1/(3×5) + 1/(5×7) + 1/(7×9) + 1/(9×11)
(a) 2/33 (b) 4/33 (c) 8/33 (d) 1/11
उत्तर: (b) 4/33
हल: सूत्र 1/d × (1/प्रथम – 1/अंतिम): 1/2 × (1/3 – 1/11) = 4/33।
स्रोत: Banking Exam Pattern

119. मान ज्ञात कीजिए: 1.7 × 1.7 + 0.3 × 0.3 – 2 × 1.7 × 0.3
(a) 1.44 (b) 1.69 (c) 1.96 (d) 2.25
उत्तर: (c) 1.96
हल: सर्वसमिका a² + b² – 2ab = (a – b)² से: (1.7 – 0.3)² = 1.4² = 1.96।
स्रोत: SSC CHSL Pattern

120. यदि 1 / [ a + 1 / ( b + 1/c ) ] = 9/26 है, जहाँ a, b, c धनात्मक पूर्णांक हैं, तो a + b + c का मान क्या होगा?
(a) 9 (b) 10 (c) 12 (d) 11
उत्तर: (d) 11
हल: मनोवैज्ञानिक जाल: व्युत्क्रम की सही शृंखला न बनाने पर त्रुटि होती है। 26/9 = 2 + 8/9 ⇒ a = 2। फिर 9/8 = 1 + 1/8 ⇒ b = 1, c = 8। योग = 2 + 1 + 8 = 11।
स्रोत: SSC CGL Pattern

121. गुणनफल को सरल कीजिए: (1 – 1/2)(1 – 1/3)(1 – 1/4)...(1 – 1/10)
(a) 1/10 (b) 1/5 (c) 1/20 (d) 9/10
उत्तर: (a) 1/10
हल: कोष्ठकों को हल करें: (1/2) × (2/3) × ... × (9/10)। मध्य पद कट जाते हैं, शेष बचता है: 1/10।
स्रोत: SSC MTS Pattern

122. गुणनफल को सरल कीजिए: (1 + 1/2)(1 + 1/3)(1 + 1/4)...(1 + 1/10)
(a) 5 (b) 11/2 (c) 6 (d) 13/2
उत्तर: (b) 11/2
हल: कोष्ठक हल करें: (3/2) × (4/3) × ... × (11/10)। मध्य पद कटने पर: 11/2 = 5.5।
स्रोत: SSC CGL Pattern

123. मान ज्ञात कीजिए: (0.3375 ÷ 0.045) × 0.2
(a) 1.2 (b) 1.8 (c) 1.5 (d) 2.0
उत्तर: (c) 1.5
हल: भाग: 0.3375 ÷ 0.045 = 7.5। गुणा: 7.5 × 0.2 = 1.5।
स्रोत: Banking Exam Pattern

124. श्रेणी का योग ज्ञात कीजिए: 1/(1×4) + 1/(4×7) + 1/(7×10) + 1/(10×13) + 1/(13×16)
(a) 3/16 (b) 1/4 (c) 7/16 (d) 5/16
उत्तर: (d) 5/16
हल: अंतर 3 है: 1/3 × (1/1 – 1/16) = 1/3 × 15/16 = 5/16।
स्रोत: Railway (RRB NTPC) Pattern

125. यदि a/b = 2/3 और b/c = 4/5 है, तो (a + b) / (b + c) का मान क्या होगा?
(a) 10/27 (b) 20/27 (c) 15/28 (d) 8/15
उत्तर: (b) 20/27
हल: संयुक्त अनुपात: a : b : c = 8 : 12 : 15। अतः (a + b)/(b + c) = 20/27।
स्रोत: SSC CHSL Pattern
