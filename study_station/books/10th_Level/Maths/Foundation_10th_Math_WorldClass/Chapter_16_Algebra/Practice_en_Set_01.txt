Set 1: Algebra MCQs — Questions 1–20: Easy | Questions 21–25: Medium

1. Solve: 3x + 7 = 22
(a) 5 (b) 3 (c) 7 (d) 15
Answer: (a)
Solution: The trap is dividing 22 by 3 directly without subtracting 7 first, which tempts toward 7. Here 3x = 22 – 7 = 15, so x = 15/3, and the answer is 5.
Source: NCERT Class 8 Mathematics

2. What is the value of (a + b)² when a = 2, b = 3?
(a) 13 (b) 10 (c) 25 (d) 36
Answer: (c)
Solution: The trap is computing a² + b² = 4 + 9 = 13 and forgetting the middle term 2ab. Since (2 + 3)² = 5², the answer is 25.
Source: NCERT Class 8 Mathematics

3. Which of the following is an equation?
(a) 5x + 3 (b) 5x (c) 5x + 3 = 18 (d) 3x – 7
Answer: (c)
Solution: The trap is picking any expression containing a variable, but an expression alone is not an equation. An equation must contain an equality sign, so the answer is 5x + 3 = 18.
Source: NCERT Class 8 Mathematics

4. If 2y – 5 = 11, then y = ?
(a) 6 (b) 8 (c) 16 (d) 3
Answer: (b)
Solution: The trap is stopping at 2y = 16 and choosing 16 without dividing by 2. Since 2y = 11 + 5 = 16 gives y = 8, the answer is 8.
Source: NCERT Class 8 Mathematics

5. Expand (x + 4)(x + 6).
(a) x² + 24x + 10 (b) x² + 10x + 24 (c) x² + 10x + 10 (d) x² + 4x + 6
Answer: (b)
Solution: The trap is swapping the coefficient of x with the constant term, giving x² + 24x + 10. Using (x + a)(x + b) = x² + (a + b)x + ab, we get x² + 10x + 24, so the answer is x² + 10x + 24.
Source: NCERT Class 8 Mathematics

6. Use identity: 105² – 95² = ?
(a) 2000 (b) 1000 (c) 200 (d) 20000
Answer: (a)
Solution: The trap is multiplying only (105 – 95) = 10 by 100 or misplacing a zero. Using a² – b² = (a – b)(a + b) = 10 × 200, the answer is 2000.
Source: NCERT Class 8 Mathematics

7. If x = 3, then 2x² – 5x + 1 = ?
(a) 10 (b) 4 (c) 18 (d) 28
Answer: (b)
Solution: The trap is computing 2x² = 18 and stopping, or adding all terms as positive. Here 2(9) – 5(3) + 1 = 18 – 15 + 1, so the answer is 4.
Source: NCERT Class 9 Mathematics

8. What is the coefficient of y in the expression 7x + 3y – 5?
(a) 7 (b) –5 (c) 3 (d) 0
Answer: (c)
Solution: The trap is picking 7, which is the coefficient of x, not y. The term containing y is 3y, so the answer is 3.
Source: NCERT Class 8 Mathematics

9. "Three times a number increased by 5 gives 20." The number is:
(a) 10 (b) 6 (c) 15 (d) 5
Answer: (d)
Solution: The trap is solving 3x = 20 + 5 by moving 5 with the wrong sign, giving x near 8, or dividing 20 by 3. Correctly, 3x + 5 = 20 gives 3x = 15, so the answer is 5.
Source: NCERT Class 8 Mathematics

10. Simplify using distributive law: 99 × 8.
(a) 782 (b) 792 (c) 812 (d) 802
Answer: (b)
Solution: The trap is computing (100 – 1) × 8 as 800 + 8 or making an arithmetic slip to 782. Since 99 × 8 = 800 – 8, the answer is 792.
Source: NCERT Class 8 Mathematics

11. Solve: (x/4) – 3 = 2
(a) 10 (b) 5 (c) 20 (d) 8
Answer: (c)
Solution: The trap is stopping at x/4 = 5 and choosing 5 without multiplying by 4. Since x/4 = 2 + 3 = 5 gives x = 20, the answer is 20.
Source: NCERT Class 8 Mathematics

12. The sum of two consecutive numbers is 25. The smaller number is:
(a) 12 (b) 11 (c) 13 (d) 10
Answer: (a)
Solution: The trap is answering 13, which is the larger number, not the smaller one asked for. With x + (x + 1) = 25, we get 2x = 24, so the answer is 12.
Source: NCERT Class 8 Mathematics

13. If a = 5, b = –3, evaluate a² – b².
(a) 16 (b) 34 (c) 22 (d) 4
Answer: (a)
Solution: The trap is treating b² as –9 instead of (–3)² = 9 and getting 25 + 9 = 34. Since a² – b² = 25 – 9, the answer is 16.
Source: NCERT Class 8 Mathematics

14. Which of the following is a linear equation in one variable?
(a) x² + 1 = 0 (b) 2x + 3y = 7 (c) x + y + z = 0 (d) 3x – 5 = 0
Answer: (d)
Solution: The trap is choosing x² + 1 = 0, which has one variable but power 2, so it is not linear. A linear equation in one variable has a single variable with highest power 1, so the answer is 3x – 5 = 0.
Source: NCERT Class 8 Mathematics

15. Solve for y: 5y + 9 = 34
(a) 5 (b) 7 (c) 9 (d) 25
Answer: (a)
Solution: The trap is stopping at 5y = 25 and choosing 25 without dividing by 5. Since 5y = 34 – 9 = 25 gives y = 5, the answer is 5.
Source: NCERT Class 8 Mathematics

16. Expand (a – 4)².
(a) a² + 8a + 16 (b) a² – 4a + 16 (c) a² – 8a + 16 (d) a² – 16
Answer: (c)
Solution: The trap is writing a² – 16, which wrongly drops the middle term as if it were a difference of squares. Using (a – b)² = a² – 2ab + b², we get a² – 8a + 16, so the answer is a² – 8a + 16.
Source: NCERT Class 8 Mathematics

17. What is the value of (a + b)(a – b) if a = 10, b = 6?
(a) 160 (b) 16 (c) 4 (d) 64
Answer: (d)
Solution: The trap is computing only a² = 100 or only (a – b) = 4. Since (10 + 6)(10 – 6) = 16 × 4, the answer is 64.
Source: NCERT Class 8 Mathematics

18. If 2(x + 3) = 18, find x.
(a) 12 (b) 6 (c) 9 (d) 3
Answer: (b)
Solution: The trap is dividing 18 by 2 to get 9 and forgetting to subtract 3. Since 2x + 6 = 18 gives 2x = 12, the answer is 6.
Source: NCERT Class 8 Mathematics

19. Which identity is used to factor 49x² – 36?
(a) (a + b)² (b) (x + a)(x + b) (c) (a – b)² (d) a² – b²
Answer: (d)
Solution: The trap is choosing a perfect-square identity, but there is no middle term here. Since 49x² – 36 = (7x)² – 6² = (7x – 6)(7x + 6), the answer is a² – b².
Source: NCERT Class 8 Mathematics

20. Find the value of 2x + 3y when x = 1, y = 2.
(a) 5 (b) 7 (c) 8 (d) 10
Answer: (c)
Solution: The trap is adding 2 + 3 + 1 + 2 = 8 incorrectly as 2 + 3 = 5 and stopping. Here 2(1) + 3(2) = 2 + 6, so the answer is 8.
Source: NCERT Class 9 Mathematics

21. If 5x + 3y = 55 and 3x + 5y = 49, then x + y = ?
(a) 8 (b) 10 (c) 12 (d) 13
Answer: (d)
Solution: The trap is solving for x and y separately and making an arithmetic slip, when adding the equations is faster. Adding gives 8x + 8y = 104, so 8(x + y) = 104 and the answer is 13.
Source: PYQ-style

22. If a + b = 7 and a – b = 3, find a² + b².
(a) 29 (b) 40 (c) 20 (d) 58
Answer: (a)
Solution: The trap is computing (a + b)² + (a – b)² = 58 and forgetting to divide by 2. Since 2(a² + b²) = 49 + 9 = 58, the answer is 29.
Source: NCERT Class 9 Mathematics

23. If x = √3 + √2, find x + 1/x.
(a) 2√2 (b) √3 – √2 (c) 2 (d) 2√3
Answer: (d)
Solution: The trap is rationalising incorrectly and getting 2√2 by keeping the wrong surd. Since 1/x = √3 – √2, we get x + 1/x = (√3 + √2) + (√3 – √2), so the answer is 2√3.
Source: PYQ-style

24. The denominator of a fraction is 1 more than twice the numerator. If the sum of numerator and denominator is 16, find the fraction.
(a) 5/11 (b) 6/7 (c) 7/15 (d) 5/6
Answer: (a)
Solution: The trap is taking the denominator as twice the numerator without the extra 1, which leads to a wrong pair. With numerator x, denominator 2x + 1, and x + 2x + 1 = 16 giving x = 5, the answer is 5/11.
Source: NCERT Class 8 Mathematics

25. If a + b + c = 0, then a³ + b³ + c³ equals:
(a) 0 (b) 3abc (c) abc (d) 1
Answer: (b)
Solution: The trap is assuming the sum of cubes is also 0 just because the sum of the numbers is 0. The standard identity states that when a + b + c = 0, the answer is 3abc.
Source: NCERT Class 9 Mathematics
