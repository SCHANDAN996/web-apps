Set 3: Algebra MCQs — Questions 51–75 (All Medium)

51. If x + 1/x = 6, find x² + 1/x².
(a) 32 (b) 36 (c) 38 (d) 34
Answer: (d)
Solution: Squaring both sides gives x² + 1/x² + 2 = 36, so x² + 1/x² = 34. The trap is option 36, which comes from forgetting to subtract the 2 that appears on squaring. Hence the answer is 34.
Source: NCERT Class 9 Mathematics

52. The sum of two numbers is 20 and their product is 96. The numbers are:
(a) 10, 10 (b) 6, 16 (c) 8, 12 (d) 9, 11
Answer: (c)
Solution: The numbers are roots of t² – 20t + 96 = 0, which factors as (t – 8)(t – 12) = 0. Option 6, 16 is tempting because 6 × 16 = 96, but 6 + 16 = 22, not 20. So the numbers are 8 and 12.
Source: NCERT Class 10 Mathematics

53. Solve for x and y: 4x + 3y = 25 and 5x – 2y = 14.
(a) x = 3, y = 4 (b) x = 5, y = 2 (c) x = 4, y = 3 (d) x = 2, y = 5
Answer: (c)
Solution: Multiply the first equation by 2 and the second by 3, then add: 8x + 6y = 50 and 15x – 6y = 42 give 23x = 92, so x = 4; substituting back, 16 + 3y = 25 gives y = 3. Option x = 3, y = 4 merely swaps the values and fails the first equation. So the answer is x = 4, y = 3.
Source: NCERT Class 10 Mathematics

54. If a² + b² = 29 and ab = 10, find a – b.
(a) ±5 (b) ±7 (c) ±9 (d) ±3
Answer: (d)
Solution: (a – b)² = a² + b² – 2ab = 29 – 20 = 9, so a – b = ±3. The trap is option ±7, which comes from wrongly using (a – b)² = a² + b² + 2ab = 49. So the answer is ±3.
Source: NCERT Class 9 Mathematics

55. If x – 1/x = 2, then x³ – 1/x³ equals:
(a) 8 (b) 14 (c) 6 (d) 10
Answer: (b)
Solution: Cubing, (x – 1/x)³ = x³ – 1/x³ – 3(x – 1/x), so 8 = x³ – 1/x³ – 6, giving x³ – 1/x³ = 14. Option 8 is the trap for those who just cube 2 and forget the correction term. So the answer is 14.
Source: NCERT Class 9 Mathematics

56. Find the value of (2.3)² – (1.7)².
(a) 2.4 (b) 0.6 (c) 2.0 (d) 4.0
Answer: (a)
Solution: Using a² – b² = (a – b)(a + b) = 0.6 × 4.0 = 2.4. Option 0.6 is the trap — it is only the factor (a – b), not the full product. So the answer is 2.4.
Source: NCERT Class 8 Mathematics

57. The numerator of a fraction is 3 less than the denominator. If 2 is added to both, the fraction becomes 2/3. The fraction is:
(a) 4/7 (b) 5/8 (c) 3/6 (d) 7/10
Answer: (a)
Solution: Let the denominator be x, so the numerator is x – 3. Then (x – 1)/(x + 2) = 2/3 gives 3x – 3 = 2x + 4, so x = 7 and the numerator is 4. Option 3/6 is tempting as it equals 1/2 superficially, but adding 2 to both terms gives 5/8, not 2/3. So the fraction is 4/7.
Source: NCERT Class 10 Mathematics

58. If 5x + 4y = 18 and 4x + 5y = 18, then x + y = ?
(a) 5 (b) 2 (c) 3 (d) 4
Answer: (d)
Solution: Adding the two equations gives 9x + 9y = 36, so x + y = 4. Solving fully gives x = y = 2, and option 2 is the trap for those who stop at x = 2 instead of finding the sum. So the answer is 4.
Source: PYQ-style

59. If (a + b)² = 100 and ab = 20, find a² + b².
(a) 80 (b) 60 (c) 40 (d) 90
Answer: (b)
Solution: (a + b)² = a² + b² + 2ab, so 100 = a² + b² + 40, giving a² + b² = 60. Option 80 is the trap for subtracting only one ab instead of 2ab. So the answer is 60.
Source: NCERT Class 9 Mathematics

60. Solve: (2x – 1)/5 = (3x + 2)/7.
(a) 17 (b) –17 (c) –1 (d) 1
Answer: (b)
Solution: Cross-multiplying, 7(2x – 1) = 5(3x + 2), so 14x – 7 = 15x + 10, giving –x = 17 and x = –17. Option 17 is the trap from dropping the negative sign when transposing. So the answer is –17.
Source: NCERT Class 8 Mathematics

61. The product of two consecutive even numbers is 168. The smaller number is:
(a) 14 (b) 10 (c) 12 (d) 16
Answer: (c)
Solution: Let the numbers be n and n + 2; then n(n + 2) = 168, so n² + 2n – 168 = 0, giving (n – 12)(n + 14) = 0 and n = 12. Option 14 is the trap — it is the larger number, not the smaller. So the smaller number is 12.
Source: NCERT Class 10 Mathematics

62. If √x + 1/√x = 3, find x + 1/x.
(a) 9 (b) 7 (c) 5 (d) 11
Answer: (b)
Solution: Squaring both sides, x + 1/x + 2 = 9, so x + 1/x = 7. Option 9 is the trap for those who forget to subtract the 2 obtained on squaring. So the answer is 7.
Source: NCERT Class 9 Mathematics

63. Five years ago, a man's age was 7 times his son's age. Five years from now, his age will be 3 times his son's age. The son's present age is:
(a) 12 years (b) 8 years (c) 10 years (d) 15 years
Answer: (c)
Solution: Let the son's present age be x and the man's be y. Then y – 5 = 7(x – 5) and y + 5 = 3(x + 5); substituting y = 7x – 30 into the second gives 7x – 25 = 3x + 15, so x = 10. Option 15 is the trap from mixing up "5 years ago" with "5 years hence" in one equation. So the son's present age is 10 years.
Source: NCERT Class 10 Mathematics

64. The solution of 2x + 3y = 0 and 3x – 4y = –17 is:
(a) x = 3, y = –2 (b) x = 3, y = 2 (c) x = –3, y = –2 (d) x = –3, y = 2
Answer: (d)
Solution: Multiply the first equation by 4 and the second by 3, then add: 8x + 12y = 0 and 9x – 12y = –51 give 17x = –51, so x = –3; then –6 + 3y = 0 gives y = 2. Option x = 3, y = –2 is the trap from sign errors in elimination. So the answer is x = –3, y = 2.
Source: NCERT Class 10 Mathematics

65. If x + 1/x = 3, then x³ + 1/x³ equals:
(a) 18 (b) 27 (c) 9 (d) 24
Answer: (a)
Solution: Cubing, (x + 1/x)³ = x³ + 1/x³ + 3(x + 1/x), so 27 = x³ + 1/x³ + 9, giving x³ + 1/x³ = 18. Option 27 is the trap for those who just cube 3 and ignore the 3(x + 1/x) term. So the answer is 18.
Source: NCERT Class 9 Mathematics

66. Two numbers are in the ratio 3 : 4. If 8 is added to each, the ratio becomes 4 : 5. The numbers are:
(a) 24, 32 (b) 15, 20 (c) 12, 16 (d) 18, 24
Answer: (a)
Solution: Let the numbers be 3x and 4x. Then (3x + 8)/(4x + 8) = 4/5 gives 15x + 40 = 16x + 32, so x = 8 and the numbers are 24 and 32. Option 12, 16 is tempting as it is in ratio 3 : 4, but adding 8 gives 20 : 24 = 5 : 6, not 4 : 5. So the numbers are 24 and 32.
Source: NCERT Class 10 Mathematics

67. If a = √7 + √6, then a + 1/a is:
(a) 2√6 (b) √7 – √6 (c) 2√7 (d) 2√7 – √6
Answer: (c)
Solution: Rationalising, 1/a = 1/(√7 + √6) = √7 – √6, since (√7)² – (√6)² = 1. Then a + 1/a = (√7 + √6) + (√7 – √6) = 2√7. Option 2√6 is the trap for those who cancel the wrong surd. So the answer is 2√7.
Source: PYQ-style

68. The sum of the digits of a two-digit number is 11. If the digits are reversed, the new number exceeds the original by 27. The original number is:
(a) 56 (b) 74 (c) 47 (d) 65
Answer: (c)
Solution: Let the number be 10a + b with a + b = 11. Reversing gives 10b + a, and (10b + a) – (10a + b) = 27 gives b – a = 3; solving, b = 7 and a = 4. Option 74 is the trap — it is the reversed number, not the original. So the original number is 47.
Source: NCERT Class 10 Mathematics

69. If x² + 1/x² = 27, find x – 1/x.
(a) ±3 (b) ±√29 (c) ±√23 (d) ±5
Answer: (d)
Solution: (x – 1/x)² = x² + 1/x² – 2 = 27 – 2 = 25, so x – 1/x = ±5. Option ±√29 is the trap from adding 2 instead of subtracting it. So the answer is ±5.
Source: NCERT Class 9 Mathematics

70. A fraction becomes 1/3 when 1 is subtracted from its numerator, and it becomes 1/4 when 8 is added to its denominator. The fraction is:
(a) 5/12 (b) 3/10 (c) 4/9 (d) 6/15
Answer: (a)
Solution: Let the fraction be x/y. Then (x – 1)/y = 1/3 gives y = 3x – 3, and x/(y + 8) = 1/4 gives 4x = y + 8; substituting, 4x = 3x + 5, so x = 5 and y = 12. Option 6/15 is the trap because it reduces to 2/5 and looks plausible, but it fails both conditions. So the fraction is 5/12.
Source: NCERT Class 10 Mathematics

71. If 2x + 3y = 7 and 3x + 2y = 8, then x – y = ?
(a) 1 (b) 0 (c) –1 (d) 2
Answer: (a)
Solution: Subtracting the first equation from the second gives x – y = 1 directly. Option –1 is the trap for subtracting in the wrong order. So the answer is 1.
Source: PYQ-style

72. The value of (2.8)² – (1.2)² is:
(a) 6.4 (b) 5.6 (c) 4.0 (d) 1.6
Answer: (a)
Solution: Using a² – b² = (a – b)(a + b) = 1.6 × 4.0 = 6.4. Option 1.6 is the trap — it is only the factor (a – b), not the product. So the answer is 6.4.
Source: NCERT Class 8 Mathematics

73. If x + y = 12 and xy = 32, find x² + y².
(a) 112 (b) 48 (c) 144 (d) 80
Answer: (d)
Solution: x² + y² = (x + y)² – 2xy = 144 – 64 = 80. Option 112 is the trap for subtracting only one xy instead of 2xy. So the answer is 80.
Source: NCERT Class 9 Mathematics

74. A student got twice as many sums wrong as he got right. If he attempted 48 sums in all, how many did he get right?
(a) 24 (b) 16 (c) 12 (d) 32
Answer: (b)
Solution: Let the right sums be x, so the wrong ones are 2x; then 3x = 48 gives x = 16. Option 32 is the trap — it is the number of wrong sums, not the right ones. So the answer is 16.
Source: NCERT Class 8 Mathematics

75. If a + b + c = 0, then the value of a³ + b³ + c³ is:
(a) 0 (b) 3abc (c) 1 (d) abc
Answer: (b)
Solution: The identity a³ + b³ + c³ – 3abc = (a + b + c)(a² + b² + c² – ab – bc – ca) becomes 0 when a + b + c = 0, so a³ + b³ + c³ = 3abc. Option 0 is the trap for assuming the cubes also cancel like the terms themselves. So the answer is 3abc.
Source: NCERT Class 9 Mathematics
