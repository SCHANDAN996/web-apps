26. If x + 1/x = 4, then x² + 1/x² is equal to:
(a) 16 (b) 12 (c) 14 (d) 18
Answer: (c)
Solution: Squaring both sides, (x + 1/x)² = 16, so x² + 2 + 1/x² = 16. The trap is option 16, which is just the square of 4 without subtracting 2. Hence x² + 1/x² = 14, so the answer is 14.
Source: NCERT Class 9 Mathematics

27. If a + b = 8 and ab = 15, find a² + b².
(a) 64 (b) 49 (c) 34 (d) 44
Answer: (c)
Solution: (a + b)² = a² + b² + 2ab gives 64 = a² + b² + 30. The trap is option 64, which ignores the 2ab term. So a² + b² = 64 − 30 = 34, and the answer is 34.
Source: NCERT Class 9 Mathematics

28. If 2x + 3y = 13 and 5x − 4y = −2, find the value of x.
(a) 2 (b) 1 (c) 4 (d) 3
Answer: (a)
Solution: Multiply the first equation by 4 and the second by 3, then add: 8x + 12y = 52 and 15x − 12y = −6 give 23x = 46. The trap is solving for y first and misreading it as x. So x = 2, and the answer is 2.
Source: NCERT Class 10 Mathematics

29. Solve for x: (x + 3)/2 + (x − 1)/3 = 7.
(a) 7 (b) 5 (c) 4 (d) 6
Answer: (a)
Solution: Multiplying throughout by 6: 3(x + 3) + 2(x − 1) = 42, so 5x + 7 = 42 and 5x = 35. The trap is forgetting to multiply the right side 7 by 6, which gives a wrong small value. So x = 7, and the answer is 7.
Source: NCERT Class 8 Mathematics

30. A number consists of two digits whose sum is 9. If 27 is added to the number, its digits are reversed. Find the number.
(a) 45 (b) 63 (c) 36 (d) 54
Answer: (c)
Solution: Let the number be 10x + y with x + y = 9. Then 10x + y + 27 = 10y + x gives y − x = 3, so y = 6 and x = 3. The trap is option 63, the reversed number obtained after adding 27. The original number is 36, so the answer is 36.
Source: NCERT Class 10 Mathematics

31. If a − b = 4 and ab = 45, find a² + b².
(a) 106 (b) 56 (c) 61 (d) 41
Answer: (a)
Solution: (a − b)² = a² − 2ab + b² gives 16 = a² + b² − 90. The trap is subtracting 90 instead of adding it, which gives a negative or small value. So a² + b² = 16 + 90 = 106, and the answer is 106.
Source: NCERT Class 9 Mathematics

32. If x = √5 + 2, find x − 1/x.
(a) 4 (b) 2√5 (c) √5 (d) 2
Answer: (a)
Solution: Rationalising, 1/x = (√5 − 2)/(5 − 4) = √5 − 2. Then x − 1/x = (√5 + 2) − (√5 − 2) = 4. The trap is option 2√5, which comes from adding instead of subtracting. So the answer is 4.
Source: NCERT Class 9 Mathematics

33. If 3x − 4y = 10 and xy = −2, find 9x² + 16y².
(a) 100 (b) 52 (c) 68 (d) 148
Answer: (b)
Solution: (3x − 4y)² = 9x² + 16y² − 24xy = 100, so 9x² + 16y² = 100 + 24(−2) = 52. The trap is option 148, obtained by adding 48 instead of subtracting because the sign of xy is missed. So the answer is 52.
Source: PYQ-style

34. The sum of the numerator and denominator of a fraction is 12. If the denominator is increased by 3, the fraction becomes 1/2. Find the fraction.
(a) 7/5 (b) 4/8 (c) 3/9 (d) 5/7
Answer: (d)
Solution: Let the fraction be x/y with x + y = 12 and 2x = y + 3. Solving gives x = 5, y = 7. The trap is option 7/5, which swaps numerator and denominator. The fraction is 5/7, so the answer is 5/7.
Source: NCERT Class 10 Mathematics

35. If (3x + 2y) : (3x − 2y) = 5 : 2, then x : y is:
(a) 14 : 9 (b) 6 : 7 (c) 7 : 6 (d) 9 : 14
Answer: (a)
Solution: Cross-multiplying, 2(3x + 2y) = 5(3x − 2y), so 6x + 4y = 15x − 10y, giving 14y = 9x. The trap is option 9 : 14, which inverts the ratio while transposing. Hence x : y = 14 : 9, so the answer is 14 : 9.
Source: PYQ-style

36. If x² + y² = 29 and xy = 10, find x + y.
(a) 7 (b) ±7 (c) ±5 (d) 5
Answer: (b)
Solution: (x + y)² = x² + y² + 2xy = 29 + 20 = 49, so x + y = ±7. The trap is option 7, which forgets the negative root that also satisfies the given conditions. So the answer is ±7.
Source: NCERT Class 9 Mathematics

37. If a/3 = b/4 = c/7, then (a + b + c)/c equals:
(a) 7/2 (b) 14 (c) 2 (d) 3/7
Answer: (c)
Solution: Let a = 3k, b = 4k, c = 7k. Then (a + b + c)/c = 14k/7k = 2. The trap is option 14, which is only the numerator's coefficient before dividing by c. So the answer is 2.
Source: NCERT Class 10 Mathematics

38. Solve: (x + 1)/(x − 1) = 5/3.
(a) 2 (b) 3 (c) 4 (d) 5
Answer: (c)
Solution: Cross-multiplying, 3(x + 1) = 5(x − 1), so 3x + 3 = 5x − 5 and 2x = 8. The trap is a sign error giving 2x = −2. So x = 4, and the answer is 4.
Source: NCERT Class 8 Mathematics

39. The solution of the equations x + 2y = 8 and 2x + y = 7 is:
(a) x = 3, y = 2 (b) x = 4, y = 2 (c) x = 1, y = 3.5 (d) x = 2, y = 3
Answer: (d)
Solution: Doubling the first equation gives 2x + 4y = 16; subtracting the second gives 3y = 9, so y = 3 and x = 2. The trap is option x = 3, y = 2, which interchanges the values. So the answer is x = 2, y = 3.
Source: NCERT Class 10 Mathematics

40. A man is 5 times as old as his son. After 10 years, he will be three times as old as his son. Find the son's present age.
(a) 5 years (b) 10 years (c) 15 years (d) 20 years
Answer: (b)
Solution: Let the son's age be x, so the man is 5x. Then 5x + 10 = 3(x + 10), giving 2x = 20. The trap is writing 5x + 10 = 3x + 10, forgetting the son also ages 10 years. So x = 10, and the answer is 10 years.
Source: NCERT Class 10 Mathematics

41. If a + b + c = 9 and ab + bc + ca = 26, find a² + b² + c².
(a) 35 (b) 29 (c) 23 (d) 55
Answer: (b)
Solution: (a + b + c)² = a² + b² + c² + 2(ab + bc + ca), so 81 = a² + b² + c² + 52. The trap is subtracting 26 instead of 52, giving 55. So a² + b² + c² = 29, and the answer is 29.
Source: NCERT Class 9 Mathematics

42. If x − 1/x = 3, find x⁴ + 1/x⁴.
(a) 97 (b) 81 (c) 47 (d) 119
Answer: (d)
Solution: Squaring once: x² + 1/x² = 9 + 2 = 11. Squaring again: x⁴ + 1/x⁴ = 121 − 2 = 119. The trap is option 97, from wrongly using 9² + 16 or mis-squaring. So the answer is 119.
Source: NCERT Class 9 Mathematics

43. The cost of 4 pens and 3 pencils is ₹26, while 6 pens and 5 pencils cost ₹40. Find the cost of one pen.
(a) ₹4 (b) ₹5 (c) ₹3 (d) ₹6
Answer: (b)
Solution: From 4p + 3q = 26 and 6p + 5q = 40, multiply the first by 5 and the second by 3: 20p + 15q = 130 and 18p + 15q = 120, so 2p = 10. The trap is option ₹3, which is the pencil's cost (q = 2 gives 4p = 20; actually q = 2, and misreading gives confusion). So p = 5, and the answer is ₹5.
Source: NCERT Class 10 Mathematics

44. If (a + b) : (b + c) : (c + a) = 6 : 7 : 8 and a + b + c = 21, find a.
(a) 8 (b) 6 (c) 7 (d) 5
Answer: (c)
Solution: Let a + b = 6k, b + c = 7k, c + a = 8k. Adding, 2(a + b + c) = 21k, so 42 = 21k and k = 2. Then a = (a + b + c) − (b + c) = 21 − 14 = 7. The trap is option 5, which is b, not a. So the answer is 7.
Source: PYQ-style

45. If x + 1/x = √5, then x² + 1/x² equals:
(a) 5 (b) √5 (c) 2 (d) 3
Answer: (d)
Solution: Squaring, x² + 1/x² + 2 = 5, so x² + 1/x² = 3. The trap is option 5, which is just the square of √5 without subtracting 2. So the answer is 3.

46. Simplify: (7.5² − 2.5²)/(7.5 − 2.5).
(a) 10 (b) 5 (c) 7.5 (d) 2.5
Answer: (a)
Solution: Using a² − b² = (a − b)(a + b), the (a − b) cancels, leaving a + b = 7.5 + 2.5 = 10. The trap is option 5, which is the denominator value a − b. So the answer is 10.
Source: NCERT Class 8 Mathematics

47. For what value of k does the system 3x + ky = 15 and 6x + 10y = 30 have infinitely many solutions?
(a) 5 (b) 3 (c) 10 (d) 6
Answer: (a)
Solution: For infinitely many solutions, 3/6 = k/10 = 15/30 = 1/2, so k/10 = 1/2 and k = 5. The trap is option 10, taken directly from the second equation's coefficient without applying the ratio condition. So the answer is 5.
Source: NCERT Class 10 Mathematics

48. The sum of two numbers is 15 and the sum of their reciprocals is 3/10. Find the numbers.
(a) 6 and 9 (b) 7 and 8 (c) 4 and 11 (d) 5 and 10
Answer: (d)
Solution: (x + y)/(xy) = 3/10 gives 15/(xy) = 3/10, so xy = 50. The numbers are roots of t² − 15t + 50 = 0, i.e. (t − 5)(t − 10) = 0. The trap is option 6 and 9, whose product is 54, not 50. So the numbers are 5 and 10, and the answer is 5 and 10.
Source: NCERT Class 10 Mathematics

49. If x = 2 + √3, find x² + 1/x².
(a) 7 (b) 14 (c) 4 (d) 16
Answer: (b)
Solution: 1/x = (2 − √3)/(4 − 3) = 2 − √3, so x + 1/x = 4. Squaring, x² + 1/x² = 16 − 2 = 14. The trap is option 16, which forgets to subtract 2 after squaring. So the answer is 14.
Source: PYQ-style

50. A boat goes 30 km upstream and 44 km downstream in 10 hours. In 13 hours it goes 40 km upstream and 55 km downstream. The speed of the boat in still water (in km/h) is:
(a) 10 (b) 6 (c) 12 (d) 8
Answer: (d)
Solution: Let 1/(x − y) = a and 1/(x + y) = b. Then 30a + 44b = 10 and 40a + 55b = 13; solving gives b = 1/11 and a = 1/5, so x − y = 5 and x + y = 11, giving x = 8. The trap is option 6, which is 11 − 5, the difference rather than the average. So the answer is 8 km/h.
Source: PYQ-style
