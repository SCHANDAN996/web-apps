126. If a + b + c = 0, then the value of (a+b)(b+c)(c+a)/abc is:
(a) 1 (b) 0 (c) –1 (d) 3
Answer: (c)
Solution: Since a+b+c = 0, we get a+b = –c, b+c = –a, c+a = –b, so the product is (–c)(–a)(–b) = –abc. The trap is ignoring one minus sign and getting +1, so the answer is –1.
Source: PYQ-style

127. Solve: 4ˣ – 3·2ˣ + 2 = 0.
(a) x = 1 only (b) x = 0, 1 (c) x = 0 only (d) x = 2
Answer: (b)
Solution: Put y = 2ˣ, giving y² – 3y + 2 = 0, so y = 1 or y = 2, hence x = 0 or x = 1. The trap is stopping after finding one root, so the answer is x = 0, 1.
Source: NCERT Class 10 Mathematics

128. If x = √2 + 1, find the value of (x – 1/x)⁴.
(a) 4 (b) 64 (c) 16 (d) 256
Answer: (c)
Solution: 1/x = 1/(√2+1) = √2 – 1, so x – 1/x = (√2+1) – (√2–1) = 2, and 2⁴ = 16. The trap is computing x + 1/x = 2√2 instead, so the answer is 16.
Source: PYQ-style

129. If x² + 1/x² = 7, find x³ + 1/x³.
(a) 14 (b) 18 (c) 28 (d) 21
Answer: (b)
Solution: (x + 1/x)² = 7 + 2 = 9, so x + 1/x = 3; then x³ + 1/x³ = 3³ – 3·3 = 27 – 9 = 18. The trap is cubing 7 directly or forgetting to subtract 3(x+1/x), so the answer is 18.
Source: NCERT Class 9 Mathematics

130. The difference of two numbers is 4 and the difference of their cubes is 316. Find the sum of their squares.
(a) 62 (b) 64 (c) 58 (d) 50
Answer: (c)
Solution: a³ – b³ = (a–b)(a²+ab+b²) gives a²+ab+b² = 79, and (a–b)² = 16 gives 3ab = 63, so ab = 21 and a²+b² = 79 – 21 = 58. The trap is reporting a²+ab+b² = 79 instead of a²+b², so the answer is 58.
Source: NCERT Class 9 Mathematics

131. If (a+b)/c = (b+c)/a = (c+a)/b = k, then the possible value(s) of k is/are:
(a) 2 or –1 (b) –1 only (c) 2 only (d) 1 only
Answer: (a)
Solution: If a+b+c ≠ 0, adding numerators and denominators gives k = 2; if a+b+c = 0, then a+b = –c and k = –1. The trap is assuming only the first case, so the answer is 2 or –1.
Source: PYQ-style

132. If x + y + z = 0, then the value of x²/yz + y²/zx + z²/xy is:
(a) 0 (b) 3 (c) –3 (d) 1
Answer: (b)
Solution: The expression equals (x³+y³+z³)/xyz, and since x+y+z = 0 we have x³+y³+z³ = 3xyz, giving 3. The trap is thinking the sum is 0 like x+y+z, so the answer is 3.
Source: NCERT Class 9 Mathematics

133. The value of (1 + 1/2)(1 + 1/3)(1 + 1/4)…(1 + 1/100) is:
(a) 101/100 (b) 50 (c) 101/50 (d) 101/2
Answer: (d)
Solution: The product is (3/2)(4/3)(5/4)…(101/100); all middle terms cancel, leaving 101/2. The trap is cancelling the 2 as well and getting 101, so the answer is 101/2.
Source: NCERT Class 10 Mathematics

134. If 2x + 3y = 78 and 3x + 2y = 72, then the value of xy is:
(a) 200 (b) 210 (c) 196 (d) 216
Answer: (d)
Solution: Adding gives x+y = 30; subtracting gives y–x = 6, so x = 12, y = 18 and xy = 216. The trap is swapping x and y and misreading the product, so the answer is 216.
Source: NCERT Class 10 Mathematics

135. If x² – 3x + 1 = 0, find x⁵ + 1/x⁵.
(a) 126 (b) 132 (c) 123 (d) 119
Answer: (c)
Solution: Dividing by x gives x + 1/x = 3; then x²+1/x² = 7 and x³+1/x³ = 18, so x⁵+1/x⁵ = 7×18 – 3 = 123. The trap is forgetting to subtract x+1/x = 3 from 126, so the answer is 123.
Source: PYQ-style

136. Solve for real x: √(x+3) + √(x–2) = 5.
(a) 6 (b) 7 (c) 8 (d) 5
Answer: (a)
Solution: Squaring twice gives √(x²+x–6) = 12–x, then x²+x–6 = 144–24x+x², so 25x = 150 and x = 6; checking, √9+√4 = 5. The trap is skipping the verification and accepting an extraneous root, so the answer is 6.
Source: PYQ-style

137. If x + 1/x = –1, then x¹² + 1/x¹² equals:
(a) 2 (b) 1 (c) –2 (d) –1
Answer: (a)
Solution: x + 1/x = –1 gives x²+x+1 = 0, so x³ = 1 and x¹² = (x³)⁴ = 1, hence x¹² + 1/x¹² = 2. The trap is assuming x¹² = –1 from the negative sign, so the answer is 2.
Source: NCERT Class 9 Mathematics

138. If a² + b² = 117 and ab = 54, find a + b given a, b are positive.
(a) 15 (b) 13 (c) 17 (d) 9
Answer: (a)
Solution: (a+b)² = a²+b²+2ab = 117+108 = 225, so a+b = 15. The trap is using (a+b)² = a²+b² and getting √117, so the answer is 15.
Source: NCERT Class 9 Mathematics

139. The sum of the roots of the equation (x–1)(x–2)(x–3) = 24 is:
(a) 5 (b) –5 (c) –6 (d) 6
Answer: (d)
Solution: Expanding gives x³ – 6x² + 11x – 30 = 0, and the sum of roots is –(–6) = 6. The trap is thinking the roots are still 1, 2, 3 after moving 24, so the answer is 6.
Source: NCERT Class 10 Mathematics

140. If a/2 = b/3 = c/4 and a + 2b + 3c = 40, then a is:
(a) 2 (b) 4 (c) 8 (d) 6
Answer: (b)
Solution: Let a = 2k, b = 3k, c = 4k; then 2k+6k+12k = 20k = 40, so k = 2 and a = 4. The trap is reporting k = 2 as the value of a, so the answer is 4.
Source: NCERT Class 10 Mathematics

141. Three consecutive terms of a geometric progression have sum 21 and product 216. The largest term is:
(a) 18 (b) 12 (c) 9 (d) 6
Answer: (b)
Solution: Let the terms be a/r, a, ar; the product gives a³ = 216, so a = 6, and the sum gives 2r²–5r+2 = 0, so r = 2 or 1/2, making the terms 3, 6, 12. The trap is reporting the middle term 6, so the answer is 12.
Source: NCERT Class 10 Mathematics

142. If √x + y = 7 and x + √y = 11, find x and y (positive integers).
(a) x=9, y=4 (b) x=4, y=9 (c) x=16, y=1 (d) x=1, y=16
Answer: (a)
Solution: Try √x = 3: then y = 7–3 = 4 and x + √y = 9+2 = 11, which fits. The trap is swapping the values of x and y, so the answer is x = 9, y = 4.
Source: PYQ-style

143. Solve: 2ˣ⁺² + 2ˣ⁻¹ = 9.
(a) x = 0 (b) x = 2 (c) x = –1 (d) x = 1
Answer: (d)
Solution: 2ˣ⁺² + 2ˣ⁻¹ = 2ˣ⁻¹(2³+1) = 9·2ˣ⁻¹ = 9, so 2ˣ⁻¹ = 1 and x = 1. The trap is adding exponents wrongly to get 2²ˣ⁺¹, so the answer is x = 1.
Source: NCERT Class 10 Mathematics

144. If (a+b) : (b+c) : (c+a) = 3 : 4 : 5 and a+b+c = 24, find c.
(a) 8 (b) 12 (c) 16 (d) 10
Answer: (b)
Solution: Let a+b = 3k, b+c = 4k, c+a = 5k; adding gives 2(a+b+c) = 12k = 48, so k = 4, and c = (a+b+c) – (a+b) = 24 – 12 = 12. The trap is taking c = 5k = 20 by mismatching the ratio, so the answer is 12.
Source: PYQ-style

145. If x + 1/x = 2, then x¹⁰⁰ + 1/x¹⁰⁰ equals:
(a) 2¹⁰⁰ (b) 1 (c) 2 (d) 0
Answer: (c)
Solution: x + 1/x = 2 gives (x–1)² = 0, so x = 1 and x¹⁰⁰ + 1/x¹⁰⁰ = 2. The trap is raising 2 to the power 100, so the answer is 2.
Source: NCERT Class 9 Mathematics

146. The product (1 – 1/2²)(1 – 1/3²)…(1 – 1/100²) equals:
(a) 101/200 (b) 99/200 (c) 101/100 (d) 99/100
Answer: (a)
Solution: Each factor is (n–1)(n+1)/n², and the product telescopes to (1/2)(101/100) = 101/200. The trap is cancelling only one side and getting 101/100, so the answer is 101/200.
Source: PYQ-style

147. If a+b+c = 5, ab+bc+ca = 3, abc = –1, find a³+b³+c³.
(a) 75 (b) 80 (c) 85 (d) 77
Answer: (d)
Solution: a²+b²+c² = 25–6 = 19, and a³+b³+c³ – 3abc = 5(19–3) = 80, so a³+b³+c³ = 80 + 3(–1) = 77. The trap is adding 3 instead of subtracting because of abc = –1, giving 83, so the answer is 77.
Source: PYQ-style

148. If the roots of x³ + ax² + bx + c = 0 are 1, 2, 3, then a+b+c is:
(a) 11 (b) 1 (c) –1 (d) –6
Answer: (c)
Solution: a = –(1+2+3) = –6, b = 2+6+3 = 11, c = –6, so a+b+c = –6+11–6 = –1. The trap is dropping the minus signs in Vieta's formulas and getting 11, so the answer is –1.
Source: NCERT Class 10 Mathematics

149. If x = 2 + √3, find the value of x² – 4x + 1.
(a) 1 (b) 2 (c) 4 (d) 0
Answer: (d)
Solution: x – 2 = √3, so (x–2)² = 3, i.e. x² – 4x + 4 = 3, hence x² – 4x + 1 = 0. The trap is substituting and making an arithmetic slip with the surd terms, so the answer is 0.
Source: PYQ-style

150. Solve for real x, y with x > y: 2ˣ + 2ʸ = 20 and x + y = 5.
(a) x = 4, y = 1 (b) x = 2, y = 3 (c) x = 3, y = 2 (d) no solution
Answer: (a)
Solution: With y = 5–x and t = 2ˣ, we get t + 32/t = 20, so t²–20t+32 = 0, giving t = 16 or t = 4, i.e. x = 4 or x = 2; the condition x > y selects x = 4, y = 1. The trap is ignoring the x > y condition and picking x = 2, y = 3, so the answer is x = 4, y = 1.
Source: PYQ-style
