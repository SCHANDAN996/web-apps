Set 5: Algebra MCQs (Medium Q101–120, Hard Q121–125)

101. Solve the system: 2x + 3y = 13 and 5x – 4y = –2.
(a) x = 3, y = 2 (b) x = 4, y = 1 (c) x = 1, y = 4 (d) x = 2, y = 3
Answer: (d)
Solution: The trap is swapping x and y after elimination, which gives the reversed pair. Multiply the first equation by 4 and the second by 3, then add: 8x + 12y = 52 and 15x – 12y = –6 give 23x = 46, so x = 2, and substituting back gives y = 3, so the answer is x = 2, y = 3.
Source: NCERT Class 10 Mathematics

102. If a + b = 8 and a² + b² = 40, find the value of ab.
(a) 12 (b) 14 (c) 16 (d) 10
Answer: (a)
Solution: The trap is assuming ab = a² + b² – (a + b) = 32 or halving 40 to get 20. Use (a + b)² = a² + b² + 2ab: 64 = 40 + 2ab, so 2ab = 24 and the answer is 12.
Source: NCERT Class 9 Mathematics

103. The sum of the ages of a father and his son is 45 years. Five years ago, the product of their ages was 124. Find the son's present age.
(a) 8 years (b) 10 years (c) 12 years (d) 9 years
Answer: (d)
Solution: The trap is accepting the second root 36 of the quadratic, which would make the son older than the father. With f + s = 45 and (f – 5)(s – 5) = 124, substituting f = 45 – s gives s² – 45s + 324 = 0, i.e. (s – 9)(s – 36) = 0; the valid younger age is 9, so the answer is 9 years.
Source: NCERT Class 10 Mathematics

104. If x + 1/x = 5, then x³ + 1/x³ equals:
(a) 110 (b) 115 (c) 120 (d) 125
Answer: (a)
Solution: The trap is cubing 5 directly and answering 125, forgetting the correction term. Since (x + 1/x)³ = x³ + 1/x³ + 3(x + 1/x), we get 125 = x³ + 1/x³ + 15, so the answer is 110.
Source: NCERT Class 9 Mathematics

105. The solution of the equations 3x – 2y = 4 and x + y = 3 is:
(a) x = 2, y = 1 (b) x = 1, y = 2 (c) x = 3, y = 0 (d) x = 0, y = 3
Answer: (a)
Solution: The trap is picking x = 1, y = 2, which satisfies x + y = 3 but fails 3x – 2y = 4. From the second equation x = 3 – y; substituting in the first gives 9 – 5y = 4, so y = 1 and x = 2, so the answer is x = 2, y = 1.
Source: NCERT Class 10 Mathematics

106. If a/3 = b/4 = c/5, then (a + b + c)/c equals:
(a) 4 (b) 5/12 (c) 3 (d) 12/5
Answer: (d)
Solution: The trap is inverting the ratio and answering 5/12. Put a = 3k, b = 4k, c = 5k; then (a + b + c)/c = 12k/5k, so the answer is 12/5.
Source: PYQ-style

107. A number is 56 greater than the average of its one-third, one-fourth and one-twelfth parts. Find the number.
(a) 84 (b) 96 (c) 72 (d) 108
Answer: (c)
Solution: The trap is averaging the fractions 1/3, 1/4, 1/12 instead of the parts of x. The average of the parts is (x/3 + x/4 + x/12)/3 = (8x/12)/3 = 2x/9, so x – 2x/9 = 56 gives 7x/9 = 56, and the answer is 72.
Source: PYQ-style

108. If (a + b) : (b + c) : (c + a) = 5 : 7 : 6 and a + b + c = 18, find the value of a.
(a) 2 (b) 3 (c) 4 (d) 5
Answer: (c)
Solution: The trap is taking a = k = 2 directly instead of solving for a. Adding the three sums: 2(a + b + c) = 18k, so 36 = 18k and k = 2; then a + b = 10, b + c = 14, c + a = 12, and a = (10 + 12 – 14)/2, so the answer is 4.
Source: PYQ-style

109. A fraction simplifies to 3/5. If 5 is added to both the numerator and the denominator, it becomes 2/3. The denominator of the original fraction is:
(a) 25 (b) 30 (c) 20 (d) 15
Answer: (a)
Solution: The trap is reporting the numerator 15 instead of the denominator. Let the fraction be 3x/5x; then (3x + 5)/(5x + 5) = 2/3 gives 9x + 15 = 10x + 10, so x = 5 and the denominator 5x is 25, so the answer is 25.
Source: NCERT Class 10 Mathematics

110. If x – 1/x = √6, find x² + 1/x².
(a) 6 (b) 8 (c) 10 (d) 4
Answer: (b)
Solution: The trap is subtracting 2 instead of adding, giving 4, because the identity for the minus case is x² + 1/x² = (x – 1/x)² + 2. Squaring gives x² + 1/x² – 2 = 6, so the answer is 8.
Source: NCERT Class 9 Mathematics

111. Solve: (x + 2)/(x – 1) = 3/2.
(a) –7 (b) 7 (c) 5 (d) –5
Answer: (b)
Solution: The trap is a sign slip in cross-multiplication, writing 2x + 4 = 3x + 3 and getting x = 1 or a negative value. Correctly, 2(x + 2) = 3(x – 1) gives 2x + 4 = 3x – 3, so the answer is 7.
Source: NCERT Class 8 Mathematics

112. The sum of two numbers is 25 and their difference is 5. The product of the numbers is:
(a) 120 (b) 150 (c) 100 (d) 75
Answer: (b)
Solution: The trap is computing 25 × 5 = 125-style shortcuts or taking the numbers as 20 and 5. Adding the equations gives 2x = 30, so x = 15 and y = 10, and the product is 150, so the answer is 150.
Source: NCERT Class 9 Mathematics

113. If a + b + c = 10 and ab + bc + ca = 31, find a² + b² + c².
(a) 42 (b) 100 (c) 69 (d) 38
Answer: (d)
Solution: The trap is subtracting 31 only once, giving 69, instead of subtracting 2(ab + bc + ca). Since (a + b + c)² = a² + b² + c² + 2(ab + bc + ca), we get 100 = a² + b² + c² + 62, so the answer is 38.
Source: NCERT Class 9 Mathematics

114. A boat takes 1.5 hours to go 15 km downstream and 3 hours to return the same distance upstream. The speed of the stream (in km/h) is:
(a) 2 (b) 3 (c) 1.5 (d) 2.5
Answer: (d)
Solution: The trap is halving the downstream speed or averaging 10 and 5 to get 7.5, which is the boat's speed in still water, not the stream's. Downstream speed = 15/1.5 = 10 km/h and upstream = 15/3 = 5 km/h, so stream speed = (10 – 5)/2, and the answer is 2.5 km/h.
Source: NCERT Class 10 Mathematics

115. If x + y = 9 and xy = 18, find the value of (x – y)².
(a) 81 (b) 9 (c) 36 (d) 45
Answer: (b)
Solution: The trap is using (x + y)² – 2xy = 81 – 36 = 45, which gives x² + y², not (x – y)². Since (x – y)² = (x + y)² – 4xy = 81 – 72, the answer is 9.
Source: NCERT Class 9 Mathematics

116. In a two-digit number, the tens digit is twice the units digit. The number exceeds the number formed by reversing the digits by 18. The original number is:
(a) 84 (b) 63 (c) 42 (d) 21
Answer: (c)
Solution: The trap is picking 84 or 63, where the tens digit is twice the units digit but the difference with the reverse is 36 or 27, not 18. With units digit u, the number is 21u and its reverse is 12u, so 9u = 18 gives u = 2, and the answer is 42.
Source: NCERT Class 10 Mathematics

117. If (a + b) : (a – b) = 7 : 3, then (a² + b²) : (a² – b²) is:
(a) 29 : 21 (b) 20 : 29 (c) 29 : 20 (d) 21 : 29
Answer: (a)
Solution: The trap is computing a² – b² as 25 – 5 = 20 by mis-squaring b = 2k. By componendo-dividendo, a/b = (7 + 3)/(7 – 3) = 5/2; taking a = 5k, b = 2k gives a² + b² = 29k² and a² – b² = 21k², so the answer is 29 : 21.
Source: PYQ-style

118. Solve: 0.4x + 0.3y = 1.7 and 0.7x – 0.2y = 0.8.
(a) x = 3, y = 2 (b) x = 2, y = 3 (c) x = 1, y = 5 (d) x = 5, y = 1
Answer: (b)
Solution: The trap is a decimal slip; multiplying both equations by 10 first avoids it. Then 4x + 3y = 17 and 7x – 2y = 8; doubling the first and tripling the second and adding gives 29x = 58, so x = 2 and y = 3, so the answer is x = 2, y = 3.
Source: NCERT Class 10 Mathematics

119. A fraction becomes 1/2 when 1 is added to the numerator, and becomes 1/3 when 1 is subtracted from the denominator. The fraction is:
(a) 1/3 (b) 2/5 (c) 1/4 (d) 3/8
Answer: (c)
Solution: The trap is mixing up which condition applies to the numerator and which to the denominator. From (x + 1)/y = 1/2 we get y = 2x + 2, and from x/(y – 1) = 1/3 we get 3x = y – 1; substituting gives x = 1, y = 4, so the answer is 1/4.
Source: NCERT Class 10 Mathematics

120. If 5^(x + 3) = 25^(x – 1), find x.
(a) 3 (b) 5 (c) 7 (d) 4
Answer: (b)
Solution: The trap is equating x + 3 = x – 1 or treating 25 as 5 × 5 in the exponent incorrectly. Write 25^(x – 1) = 5^(2x – 2); equating exponents gives x + 3 = 2x – 2, so the answer is 5.
Source: PYQ-style

121. If a + b = 1 and ab = –6, then the value of a³ + b³ is:
(a) 19 (b) 37 (c) –17 (d) –19
Answer: (a)
Solution: The trap is dropping the minus sign of ab and computing 1 – 18 = –17. Since a³ + b³ = (a + b)³ – 3ab(a + b) = 1 – 3(–6)(1) = 1 + 18, the answer is 19.
Source: NCERT Class 9 Mathematics

122. If x + 1/x = 3, find the value of x⁵ + 1/x⁵.
(a) 123 (b) 126 (c) 129 (d) 132
Answer: (a)
Solution: The trap is stopping at the product 7 × 18 = 126, forgetting that the product also contains x + 1/x. Here x² + 1/x² = 7 and x³ + 1/x³ = 18; their product equals x⁵ + 1/x⁵ + (x + 1/x), so x⁵ + 1/x⁵ = 126 – 3, and the answer is 123.
Source: PYQ-style

123. If a, b, c are real numbers such that a² + b² + c² = 2(a – b – c) – 3, then the value of a + b + c is:
(a) 1 (b) 3 (c) –3 (d) –1
Answer: (d)
Solution: The trap is a sign error in completing the square for b and c, which leads to a + b + c = 3. Rearranging gives (a – 1)² + (b + 1)² + (c + 1)² = 0, so a = 1, b = –1, c = –1, and the answer is –1.
Source: PYQ-style

124. The number of real solutions of the equation (x² + 5x + 6)(x² – 7x + 12) = 0 is:
(a) 2 (b) 3 (c) 4 (d) 1
Answer: (c)
Solution: The trap is assuming the two quadratics share a root and counting only 2 or 3 solutions. Factorising gives (x + 2)(x + 3)(x – 3)(x – 4) = 0 with roots –2, –3, 3, 4, all real and distinct, so the answer is 4.
Source: NCERT Class 10 Mathematics

125. If x + y + z = 0, then (x² + y² + z²)/(xy + yz + zx) is equal to:
(a) –1 (b) 2 (c) –2 (d) 1
Answer: (c)
Solution: The trap is dropping the minus sign and answering 2. From (x + y + z)² = 0 we get x² + y² + z² = –2(xy + yz + zx), so the ratio is –2 (with denominator non-zero), and the answer is –2.
Source: PYQ-style
