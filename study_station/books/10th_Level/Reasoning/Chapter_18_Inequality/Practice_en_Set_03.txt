51. In a certain code: 'A @ B' means A ≤ B, 'A # B' means A ≥ B, 'A $ B' means A < B, 'A % B' means A > B, 'A * B' means A = B. Statements: X # Y, Y @ Z, Z $ A, A % B. Conclusions: I. X % A  II. X * A
(a) Neither I nor II follows (b) Only II follows (c) Either I or II follows (d) Only I follows
Answer: (a)
Solution: Decoded: X ≥ Y, Y ≤ Z, Z < A, A > B. Between X and A the signs reverse at Y (≥ then ≤), so no definite relation exists; the tempting Either-Or fails because the two conclusions do not exhaust the possibilities here. So the answer is Neither I nor II follows.

52. Statements: A > B = C ≥ D < E; F ≤ D > G. Conclusions: I. A > F  II. B > G
(a) Only I follows (b) Neither I nor II follows (c) Only II follows (d) Both follow
Answer: (d)
Solution: From A > B = C ≥ D ≥ F we get A > F, and from B = C ≥ D > G we get B > G; both are definite. The trap is to reject conclusion I because F is linked through D, but the chain is unbroken. So the answer is Both follow.

53. In a certain code: 'A α B' means A > B, 'A β B' means A < B, 'A γ B' means A = B, 'A δ B' means A ≥ B, 'A ε B' means A ≤ B. Statements: P α Q, Q β R, R γ S, S ε T. Conclusions: I. P β T  II. P α T
(a) Only II follows (b) Neither I nor II follows (c) Either I or II follows (d) Only I follows
Answer: (b)
Solution: Decoded: P > Q < R = S ≤ T. The link between P and T breaks at Q due to opposite signs, so all of P > T, P < T and P = T are possible; since equality is missing from the conclusions, they are not a complementary pair. So the answer is Neither I nor II follows.

54. Which of the following expressions will make 'M ≤ N' definitely true?
(a) M > O ≥ N (b) M ≥ O < N (c) M = O > N (d) M < O ≤ N
Answer: (d)
Solution: In M < O ≤ N we get M < N, which always satisfies M ≤ N. The other expressions either give M ≥ N or leave the relation undecided, so they cannot guarantee M ≤ N. So the answer is M < O ≤ N.

Solution: M ≥ N > O forces M > O, so conclusion I is definite and II is false. The trap is reading M ≥ N > O as merely M ≥ O and picking Either-Or, but the strict '>' in the chain makes M = O impossible. So the answer is Only I follows.

60. Which set of symbols should replace the blanks in the expression 'A _ B _ C _ D' so that both 'A ≥ C' and 'B > D' definitely hold?
(a) =, ≥, < (b) >, ≥, = (c) ≥, >, = (d) ≥, =, ≥
Answer: (c)
Solution: With ≥, >, = the expression is A ≥ B > C = D: A ≥ B > C gives A > C (hence A ≥ C), and B > C = D gives B > D. The set >, ≥, = is the trap — it gives B ≥ C = D, i.e. only B ≥ D, not the strict B > D. So the answer is ≥, >, =.
