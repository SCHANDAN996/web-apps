101. Statements: A > B ≥ C = D ≤ E < F
Conclusions: I. A > D  II. B < F  III. C < F
(a) Only I follows (b) All follow (c) I and II follow (d) I and III follow
Answer: (d)
Solution: The tempting trap is II: B ≥ C = D ≤ E < F reverses direction at D, so no definite relation exists between B and F. But A > B ≥ C = D gives A > D, and C = D ≤ E < F gives C < F, so the answer is that I and III follow.

102. In a certain code: 'A @ B' means A ≤ B, 'A # B' means A ≥ B, 'A $ B' means A < B, 'A % B' means A > B, 'A * B' means A = B

Conclusions: I. P % S  II. P * S
(a) Only II follows (b) Only I follows (c) Neither I nor II follows (d) Either I or II follows

Solution: Decoded: P ≤ Q > R = S, and the signs reverse at Q, so no definite relation exists between P and S. The trap is choosing 'either-or', but > and = are not complementary because < is missing, so the answer is that neither follows.

Solution: With >, =, ≤ we get A > B = C ≤ D, so A > C holds and B = C ≤ D gives B ≤ D. The trap is the first set, where A > B < C breaks the chain between A and C, so the answer is >, =, ≤.
