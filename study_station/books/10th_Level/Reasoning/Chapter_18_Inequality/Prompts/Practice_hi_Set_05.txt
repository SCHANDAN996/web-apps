प्रश्न 101. कथन:
A > B ≥ C = D ≤ E < F
निष्कर्ष:
I. A > D
II. B < F
III. C ≥ E
(a) केवल I अनुसरण करता है
(b) I और II अनुसरण करते हैं
(c) केवल III अनुसरण करता है
(d) कोई अनुसरण नहीं करता

उत्तर: (a) केवल I अनुसरण करता है
हल:
I: A > B ≥ C = D ⇒ A > D (सत्य)।
II: B ≥ C = D ≤ E < F, चिह्न टूटते हैं; B और F का निश्चित संबंध नहीं।
III: C = D ≤ E ⇒ C ≤ E, अतः C ≥ E निश्चित नहीं।
स्रोत: IBPS Clerk 2021

प्रश्न 103. कथन:

निष्कर्ष:
I. M % R
II. O $ S
III. N % Q
(a) केवल III अनुसरण करता है
(b) I और II अनुसरण करते हैं
(c) केवल II अनुसरण करता है
(d) कोई अनुसरण नहीं करता

उत्तर: (d) कोई अनुसरण नहीं करता
हल:
डिकोड: M > N < O ≥ P = Q < R ≤ S।
I: M < R? M > N < O ≥ P = Q < R, कोई निश्चितता नहीं।
II: O > S? O ≥ P = Q < R ≤ S, कोई निश्चितता नहीं।
III: N < Q? N < O ≥ P = Q, कोई निश्चितता नहीं।
प्रत्येक निष्कर्ष में जंजीर टूटती है।

प्रश्न 124. (कठिन) कथन:
A ≥ B = C < D ≤ E; F = E > G; H ≤ G
निष्कर्ष:
I. A < E
II. A = E
III. B < F
IV. H < E
(a) केवल III और IV अनुसरण करते हैं
(b) I, III और IV अनुसरण करते हैं
(c) III, IV और या तो I या II अनुसरण करते हैं
(d) सभी अनुसरण करते हैं

उत्तर: (c) III, IV और या तो I या II अनुसरण करते हैं
हल:
A ≥ B = C < D ≤ E से A और E के बीच A < E, A = E, A > E तीनों संभव; अतः I और II पूरक युग्म हैं (या तो I या II अनुसरण करता है)।
III: B = C < D ≤ E = F ⇒ B < F (सत्य)।
IV: H ≤ G < E ⇒ H < E (सत्य)।
अतः III, IV और या तो I या II अनुसरण करते हैं।
जाल: अनेक निष्कर्षों के बीच एक पूरक युग्म को पहचानना।
स्रोत: SSC CGL 2022

प्रश्न 125. (कठिन) एक निश्चित कोड में:
‘A α B’ ⇒ A > B
‘A β B’ ⇒ A < B
‘A γ B’ ⇒ A = B
‘A δ B’ ⇒ A ≥ B
‘A ε B’ ⇒ A ≤ B
कथन:
M δ N
N α O
O γ P
P β Q
Q δ R
R ε S
निष्कर्ष:
I. M α Q
II. O β R
III. N γ P
IV. M δ S
(a) केवल I और IV अनुसरण करते हैं
(b) केवल II अनुसरण करता है
(c) I, II और IV अनुसरण करते हैं
(d) कोई अनुसरण नहीं करता

उत्तर: (d) कोई अनुसरण नहीं करता
हल:
डिकोड: M ≥ N > O = P < Q ≥ R ≤ S।
I: M > Q? M ≥ N > O = P < Q, टूटता है।
II: O < R? O = P < Q ≥ R, टूटता है।
III: N = P? N > O = P, असत्य।
IV: M ≥ S? M ≥ N > O = P < Q ≥ R ≤ S, टूटता है।
सभी निष्कर्षों में जंजीर टूटती है; अतः कोई अनुसरण नहीं करता।
स्रोत: IBPS PO 2021
