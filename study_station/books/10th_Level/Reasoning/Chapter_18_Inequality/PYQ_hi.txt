PYQ विश्लेषण: असमानता (SSC, बैंकिंग, रेलवे — पिछले 10 वर्ष)

असमानता से हर परीक्षा में 2–5 प्रश्न आते हैं (बैंकिंग में आम)। जाल दिशा बदलना और ≥/≤ की बराबरी है।

प्रश्न 1. यदि A > B > C, तो कौन-सा सही है?
(a) A > C (b) C > A (c) A = C (d) नहीं कह सकते
उत्तर: (a) A > C
हल: समान दिशा जुड़ती है: A > B > C से A > C।
स्रोत: बैंक PO

प्रश्न 2. यदि A > B < C, तो A और C में क्या संबंध है?
(a) A > C (b) A < C (c) A = C (d) नहीं कह सकते
उत्तर: (d) नहीं कह सकते
हल: दिशा बदल गई (> फिर <), अतः कोई निश्चित संबंध नहीं।
स्रोत: SSC CGL

प्रश्न 3. यदि A > B = C, तो कौन-सा सही है?
(a) A > C (b) A < C (c) A = C (d) नहीं कह सकते
उत्तर: (a) A > C
हल: बराबर बीच में: A > B = C से A > C।
स्रोत: SSC MTS

प्रश्न 4. यदि A < B < C, तो सबसे छोटा कौन है?
(a) A (b) B (c) C (d) नहीं कह सकते
उत्तर: (a) A
हल: A < B < C, अतः A सबसे छोटा।
स्रोत: SSC CHSL

प्रश्न 5. 'A ≥ B' का अर्थ क्या है?
(a) A, B से बड़ा (b) A, B से बड़ा या बराबर (c) A, B से छोटा (d) A, B के बराबर
उत्तर: (b) A, B से बड़ा या बराबर
हल: ≥ का अर्थ बड़ा या बराबर।
स्रोत: NCERT रीज़निंग

प्रश्न 6. यदि P > Q > R > S, तो क्या P > S?
(a) सही (b) ग़लत (c) नहीं कह सकते (d) P = S
उत्तर: (a) सही
हल: पूरी शृंखला समान दिशा में: P > S।
स्रोत: बैंक क्लर्क

प्रश्न 7. यदि A = B > C, तो कौन-सा सही है?
(a) A > C (b) A < C (c) A = C (d) नहीं कह सकते
उत्तर: (a) A > C
हल: A = B और B > C, अतः A > C।
स्रोत: RRB NTPC

प्रश्न 8. यदि A < B और B < C, तो कौन-सा सही है?
(a) A < C (b) A > C (c) A = C (d) नहीं कह सकते
उत्तर: (a) A < C
हल: समान दिशा: A < B < C से A < C।
स्रोत: SSC CGL

प्रश्न 9. यदि A ≥ B और B > C, तो कौन-सा सही है?
(a) A > C (b) A < C (c) A = C (d) नहीं कह सकते
उत्तर: (a) A > C
हल: A ≥ B का अर्थ A > B या A = B; दोनों में A > C।
स्रोत: बैंक PO

प्रश्न 10. यदि A > B और B = C, तो क्या A > C?
(a) सही (b) ग़लत (c) नहीं कह सकते (d) A = C
उत्तर: (a) सही
हल: B = C और A > B, अतः A > C।
स्रोत: SSC MTS
