PYQ Analysis: Inequality (SSC, Banking, Railway — last 10 years)

Inequality gives 2–5 questions per exam (common in banking). The trap is a direction change and the ≥/≤ equality part.

Q1. If A > B > C, then which is true?
(a) A > C (b) C > A (c) A = C (d) Can't say
Answer: (a) A > C
Solution: Same direction joins: A > B > C gives A > C.
Source: Bank PO

Q2. If A > B < C, what is the relation between A and C?
(a) A > C (b) A < C (c) A = C (d) Can't say
Answer: (d) Can't say
Solution: The direction changes (> then <), so no definite relation.
Source: SSC CGL

Q3. If A > B = C, then which is true?
(a) A > C (b) A < C (c) A = C (d) Can't say
Answer: (a) A > C
Solution: Equality in between: A > B = C gives A > C.
Source: SSC MTS

Q4. If A < B < C, which is the smallest?
(a) A (b) B (c) C (d) Can't say
Answer: (a) A
Solution: A < B < C, so A is the smallest.
Source: SSC CHSL

Q5. What does 'A ≥ B' mean?
(a) A greater than B (b) A greater than or equal to B (c) A less than B (d) A equal to B
Answer: (b) A greater than or equal to B
Solution: ≥ means greater than or equal.
Source: NCERT Reasoning

Q6. If P > Q > R > S, is P > S?
(a) True (b) False (c) Can't say (d) P = S
Answer: (a) True
Solution: Same direction throughout: P > S.
Source: Bank Clerk

Q7. If A = B > C, then which is true?
(a) A > C (b) A < C (c) A = C (d) Can't say
Answer: (a) A > C
Solution: A = B and B > C, so A > C.
Source: RRB NTPC

Q8. If A < B and B < C, then which is true?
(a) A < C (b) A > C (c) A = C (d) Can't say
Answer: (a) A < C
Solution: Same direction: A < B < C gives A < C.
Source: SSC CGL

Q9. If A ≥ B and B > C, then which is true?
(a) A > C (b) A < C (c) A = C (d) Can't say
Answer: (a) A > C
Solution: A ≥ B means A > B or A = B; either way A > C.
Source: Bank PO

Q10. If A > B and B = C, is A > C?
(a) True (b) False (c) Can't say (d) A = C
Answer: (a) True
Solution: B = C and A > B, so A > C.
Source: SSC MTS
