📊 PYQ Analysis: Inequality (Reasoning)

1. How Exams Ask Questions from This Chapter

Inequality is a regular feature of the reasoning section in banking exams (IBPS PO/Clerk, SBI PO, RRB PO/Clerk) and appears occasionally in SSC CGL Tier-1 and RRB NTPC. In bank prelims it usually comes as a small set of 3–5 quick questions; in SSC/Railway exams it appears as 1–2 standalone questions. Difficulty is mostly easy to moderate — these are scoring questions meant to be solved fast.

Examiners test this chapter in four recurring forms:

- **Direct Inequality**: Statements like A > B ≥ C = D < E are given, followed by two conclusions. You must decide which conclusion(s) definitely follow.
- **Coded Inequality**: Symbols like @, #, $, %, © are defined as <, >, ≤, ≥, =. You decode first, then solve like direct inequality.
- **Either-Or Cases**: Two conclusions are complementary (e.g., A > B and A ≤ B) and neither is individually definite — then "either I or II follows."
- **Missing Symbol / Equation Completion**: You must pick the option whose symbols make two given relations definitely true.

2. Sub-Topics That Repeat Most Often

- Direct inequality with 2 conclusions — the most frequent form.
- Coded inequality — common in bank prelims.
- Either-or conclusion pairs — used to trap students who don't check the three conditions (complementary pair, same elements, neither individually true).
- Missing-symbol questions — less frequent but time-consuming.

3. Examiner Traps (Psychological Patterns)

- **"≥ includes =" illusion**: From A > B ≥ C, A > C is definite, but the examiner offers "A = C" as a conclusion to tempt you.
- **Partial chain illusion**: Two relations sharing one variable but pointing in opposite directions (e.g., N > O and P ≤ O) give no definite relation between N and P — yet options pretend they do.
- **Missing link fabrication**: Two variables that are never connected by the chain are given a conclusion anyway; students invent a relation.
- **Opposite arrow blind spot**: A second chain written with reversed symbols (V < R > K ≥ F > O) reverses direction; students miss the reversal.
- **Either-or mirage**: Two conclusions look complementary, but if one is definitely true, either-or cannot apply.
- **Decoding overwhelm**: In coded inequality, students skip decoding and guess.
- **Trial-and-error time sink**: Missing-symbol questions tempt you to test every option and overspend time.

4. High-Yield PYQ-Style Questions with Solutions & Traps

Q1. (PYQ-style, bank prelims pattern)

Statements: A > B ≥ C = D < E. Conclusions: I. A > C, II. A = C.

Solution: From A > B ≥ C, A > C is definite. Conclusion I is true, II is false. Answer: Only I follows.

🧠 Trap: "Double possibility confusion" — A > B ≥ C makes A > C definite, yet the examiner offers A = C, tempting you because ≥ includes =.

Q2. (PYQ-style)

Statements: M ≥ N > O; P ≤ O. Conclusions: I. M > O, II. N > P.

Solution: M ≥ N > O gives M > O (True). N > O and O ≥ P give N > P (True). Answer: Both follow.

🧠 Trap: "Partial chain illusion" — Students see P ≤ O and N > O and assume no relation between N and P. But since O ≥ P and N > O, N > P is definite. Always check whether the shared variable connects the chain in one direction.

Q3. (PYQ-style, SSC CGL pattern)

Statements: P < Q < R; A = B > C > D; R = I < M < N < A. Conclusions: I. R < A, II. I < B.

Solution: Combine: P < Q < R = I < M < N < A = B. R < A (True), I < B (True). Answer: Both follow.

🧠 Trap: "Complex chain management" — Multiple chains joined by equalities require careful combination; missing one link breaks the conclusion.

Q4. (PYQ-style)

Statements: G < D ≤ T < Y = O; V < R > K ≥ F > O. Conclusions: I. D < R, II. Y ≥ K.

Solution: D ≤ T < Y = O < F ≤ K < R, so D < R is definite (True). Y = O < F ≤ K gives Y < K, so Y ≥ K is false. Answer: Only I follows.

🧠 Trap: "Opposite arrow blind spot" — The second chain uses > which reverses direction; students miss the reversal.

Q5. (PYQ-style)

Statements: S > N ≥ W = J ≤ T; Y ≥ U > N ≥ P. Conclusions: I. P ≤ S, II. T > Y.

Solution: S > N ≥ P ⇒ S > P, so P ≤ S is true. There is no chain connecting T and Y, so II is false. Answer: Only I follows.

🧠 Trap: "Missing link assumption" — T and Y are not connected; students fabricate a relation.

Q6. (PYQ-style, coded inequality)

In the following question, the symbols @, #, $, % and © are used with the following meanings:
M @ N ⇒ M ≤ N; M # N ⇒ M ≥ N; M $ N ⇒ M < N; M © N ⇒ M > N; M % N ⇒ M = N.

Statements: P © Q; N # O. Conclusions: I. P © O, II. P @ O.

Solution: Decoding gives P > Q and N ≥ O. There is no statement linking P (or Q) with N or O, so no relation between P and O exists. Answer: Neither I nor II follows.

🧠 Trap: "Decoding overwhelm" — Five symbols must be decoded first; students skip decoding and guess. Also note the two statements share no variable — that itself is the signal that no conclusion can follow.

Q7. (PYQ-style)

Statements: A < B = C ≤ D; C > E ≥ F; F > G < H. Conclusions: I. A < D, II. G < B.

Solution: A < B = C ≤ D ⇒ A < D (True). B = C > E ≥ F > G ⇒ B > G, i.e., G < B (True). Answer: Both follow.

🧠 Trap: "Chain splitting error" — Students fail to split the combined chain into two valid sub-chains.

Q8. (PYQ-style)

Statements: I > J ≥ K < L; M > N > L; O = P > M. Conclusions: I. K < O, II. M > K.

Solution: K < L < N < M < P = O ⇒ K < O (True). M > N > L > K ⇒ M > K (True). Answer: Both follow.

🧠 Trap: "Multiple intermediate variables" — The chain has many variables; students lose track and skip the question unnecessarily.

Q9. (PYQ-style, missing symbol)

Which symbols should be placed in the blanks in P _ R _ D _ U _ E (in the same order) so that 'U ≤ P' and 'P ≥ D' definitely hold?
(a) ≥, =, ≥, <  (b) >, ≥, =, <  (c) ≥, >, ≥, ≤  (d) =, =, <, <

Solution: Option (a) gives P ≥ R = D ≥ U < E. Then P ≥ D (True) and P ≥ U, i.e., U ≤ P (True). Other options break at least one required relation. Answer: (a).

🧠 Trap: "Trial-and-error time sink" — Testing every option can consume far too long. Check the required relations (P ≥ D and U ≤ P) against each option's first three symbols only; skip the question if not solved within about 45 seconds.

Q10. (PYQ-style)

Statements: P ≤ Q < R > K; R < S > T; T < U < V. Conclusions: I. P < S, II. P ≥ S.

Solution: P ≤ Q < R < S ⇒ P < S. So I is true and II is false. Answer: Only I follows.

🧠 Trap: "Either-or mirage" — I and II look complementary, but because I is definitely true, either-or cannot apply. Students waste time checking either-or conditions.

5. Time Management — 15/45-Second Rule

- **15-second rule (coded inequality)**: If decoding the symbols (as in Q6) takes more than about 15 seconds, mark the question for review and move on to avoid early time loss.
- **45-second rule (missing symbol)**: If trial-and-error on a missing-symbol question (as in Q9) extends beyond about 45 seconds, skip it. Such questions can consume disproportionate time relative to their 1-mark value.
