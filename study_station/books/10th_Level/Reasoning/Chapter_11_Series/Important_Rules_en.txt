Key Rules/Approaches
Rule Name	Description	Example
30‑Second Scan Rule	Ask three questions: Direction (up/down/mixed), Speed (slow/fast/explosive), Gaps (constant/changing).	7,14,28,56 → fast up → likely ×2.
Difference Ladder	Find differences between terms. If not constant, find second difference to uncover hidden AP.	4,9,16,25 → diff +5,+7,+9 → second diff +2 → next diff +11 → 36.
Multiplication/Division Check	Rapid growth means ×; rapid decay means ÷. Look for mixed patterns like ×2+1.	3,7,15,31 → ×2+1.
Square/Cube Memory	Memorise squares (1‑25) and cubes (1‑15). Series often hides n²±a or n³±a.	2,5,10,17 → 1²+1, 2²+1, 3²+1, 4²+1.
Letter → Number Conversion	Treat letter series as number series: A=1, B=2, …, Z=26. Find pattern, then convert back.	B(2), E(5), H(8), K(11) → +3 → N(14).
Opposite Letter Pair Sum	Each opposite pair sums to 27 (A+Z=27, B+Y=27). Useful for forward‑backward series.	AZ, BY, CX, DW → first +1, second −1 → EV.
Alternate Series (Twin Rope)	Separate odd‑position and even‑position terms into two independent series and solve each.	3,10,5,20,7,30 → odd: 3,5,7 (+2); even: 10,20,30 (+10) → next 9.
Wrong Term Detection	Find rule that fits all terms except one; that one is wrong. Verify rule on at least 3 correct terms.	5,10,17,26,36,50 (n²+1) → 36 should be 37.
Pattern Validation Rule	Never finalise the answer until the discovered pattern works for every given term without exception.	Even if two patterns give same missing term, check all terms.
Time Management
Rule	Time Limit	Action
15‑Second Decision Rule	15 seconds	If no clear pattern (direction, differences, operation) emerges in 15 seconds, mark the question for review and skip immediately.
45‑Second Maximum Rule	45 seconds	If you’re still working on a series after 45 seconds, stop. Even if close, the cost of time outweighs the mark. Move on and revisit only if time permits.
Scan‑and‑Go Strategy	First 10 sec	Quickly classify series type (additive, multiplicative, square, alternate) to decide whether it’s worth attempting.
Logical/Mathematical Formulas
Formula	Application
Opposite Letter Position	Reverse position = 27 – Forward position (A=1,…Z=26). e.g., Z=26, reverse of Z=1.
Letter‑to‑Number Mapping	A=1, B=2, C=3, …, Z=26. Used to convert any letter series into a numeric series.
General Series Representation	No single formula; patterns are built using +, –, ×, ÷, squares, cubes, and combinations. The “Difference Ladder” method is the closest to a formal approach.
