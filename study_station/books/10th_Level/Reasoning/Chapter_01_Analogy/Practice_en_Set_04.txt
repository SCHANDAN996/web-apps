76. Knife : Cut :: Axe : ?
(a) Sharp (b) Chop (c) Tool (d) Wood
Answer: (b)
Solution: A knife is a tool whose specific action is cutting; an axe is a tool whose specific action is chopping. The trap is "Wood", which is the object the axe works on, not the action — the relationship is tool to action. So the answer is Chop.
Source: PYQ-style

77. 7 : 42 :: 8 : ?
(a) 54 (b) 64 (c) 72 (d) 56
Answer: (d)
Solution: The pattern is n × (n − 1): 7 × 6 = 42, so 8 × 7 = 56. The trap is 64, which is simply 8² and tempts students who assume a square pattern. So the answer is 56.
Source: PYQ-style

78. ABC : DEF :: GHI : ?
(a) HIJ (b) KLM (c) IJK (d) JKL
Answer: (d)
Solution: Each letter moves forward by 3: A→D, B→E, C→F. Applying the same shift, G→J, H→K, I→L. The trap is KLM, which comes from shifting only the first letter by 4. So the answer is JKL.

85. D : H :: M : ?
(a) Q (b) P (c) R (d) O
Answer: (a)
Solution: D is the 4th letter and H is the 8th, a shift of +4. M is the 13th letter, so M + 4 = Q (17th). The trap is P, which results from adding only 3. So the answer is Q.

86. 25 : 125 :: 64 : ?
(a) 512 (b) 256 (c) 320 (d) 384
Answer: (a)
Solution: 25 = 5² and 125 = 5³, so the pattern is square to cube of the same root. 64 = 8², and 8³ = 512. The trap is 320, which is 64 × 5, a multiplication guess. So the answer is 512.
