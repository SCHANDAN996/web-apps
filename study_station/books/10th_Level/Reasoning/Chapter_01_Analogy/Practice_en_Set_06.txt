126. Architect : Blueprint :: Composer : ?
(a) Orchestra (b) Symphony (c) Concert (d) Score
Answer: (d)
Solution: An architect uses a blueprint as the detailed written plan for construction; similarly, a composer uses a score as the detailed written plan for a musical performance. The trap is "Symphony", which is the finished work, not the plan, so the answer is Score.

127. 4 : 68 :: 5 : ?
(a) 125 (b) 130 (c) 120 (d) 135
Answer: (b)
Solution: The pattern is n³ + n: 4³ + 4 = 64 + 4 = 68. The trap is 125, which is only 5³ and ignores the addition of n. Applying the rule, 5³ + 5 = 125 + 5 = 130, so the answer is 130.

128. ABCD : ZYXW :: MNOP : ?
(a) NMLK (b) MNOP (c) KLMN (d) LKMN
Answer: (a)
Solution: Each letter is replaced by its opposite-position letter in the alphabet: A→Z, B→Y, C→X, D→W, with the order preserved. The trap is KLMN, which wrongly reverses the order after substitution. Applying the same rule, M→N, N→M, O→L, P→K, so the answer is NMLK.

Solution: The pattern is factorial: 3! = 6 and 4! = 24. The trap is 125, which is 5³ and uses the wrong operation. Applying the rule, 5! = 5 × 4 × 3 × 2 × 1 = 120, so the answer is 120.
