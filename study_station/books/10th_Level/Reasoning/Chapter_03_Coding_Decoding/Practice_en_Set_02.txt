26. If 'GOLD' is coded as 'HPME' and 'IRON' is coded as 'JSPO', then 'SILVER' is coded as
(a) TJMWFS (b) TJMWFT (c) TJMVFS (d) TJNXFS
Answer: (a)
Solution: Each letter is shifted forward by 1 position: S→T, I→J, L→M, V→W, E→F, R→S. Option TJMWFT is the trap for those who slip on the last letter, so the answer is TJMWFS.

28. If 'BALL' = 27 and 'CALL' = 28, then 'WALL' =
(a) 50 (b) 49 (c) 48 (d) 47
Answer: (c)
Solution: The code is the sum of alphabetical positions: BALL = 2+1+12+12 = 27 and CALL = 3+1+12+12 = 28. So WALL = 23+1+12+12 = 48; option 47 is the trap for those who take W as 22, so the answer is 48.

29. In a certain code language, 'kitab padhna' is written as 'pa sa', 'padhna achha' is written as 'sa ta' and 'achhi kitab' is written as 'ta ma'. What is the code for 'achha'?
(a) pa (b) ta (c) ma (d) sa
Answer: (b)
Solution: 'padhna' is common to the first two phrases, so 'padhna' = 'sa'; 'kitab' = 'pa'. Comparing the second and third phrases, 'achha/achhi' = 'ta'. Option 'sa' is the trap as it belongs to 'padhna', so the answer is ta.
Source: PYQ-style

(a) ma (b) ta (c) ka (d) na
Answer: (c)
Solution: 'green' = 'ma' (common to phrases 1 and 2), 'leaf' = 'na' (common to 2 and 3), 'is' = 'ta' (common to 1 and 3), leaving 'fresh' = 'ka'. Option 'na' tempts those who stop at 'leaf', so the answer is ka.
