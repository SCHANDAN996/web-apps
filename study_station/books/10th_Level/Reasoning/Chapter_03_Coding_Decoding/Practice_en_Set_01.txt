1. If 'CAT' is coded as 'DBU', what is the code for 'DOG'?
(a) EPI (b) FPH (c) EQH (d) EPH
Answer: (d)
Solution: Each letter is shifted forward by 1 position: D→E, O→P, G→H. The trap option FPH comes from shifting the first letter by 2, so the answer is EPH.
Source: PYQ-style

2. If 'PEN' is coded as 'QFO', what is the code for 'INK'?

Answer: (b)
Solution: Each letter moves +1: I→J, N→O, K→L. JOM is tempting if you shift the last letter by 2, but the correct code is JOL.

3. If 'A' = 1, 'B' = 2, …, 'Z' = 26, then how is 'BAT' coded?

15. If 'MALE' = 31 and 'FEMALE' = 42, then what is the value of 'MALES'?

Solution: The value is the sum of letter positions: M+A+L+E = 13+1+12+5 = 31, and MALES adds S = 19, giving 50. Forgetting to add S fully gives 49, so the answer is 50.
