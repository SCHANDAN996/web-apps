101. If 'MARCH' is coded as 'OCTEJ' and 'APRIL' is coded as 'CRTKN', then 'JUNE' is coded as
(a) LWPG (b) LWPF (c) LVPG (d) KWPG
Answer: (a)
Solution: Each letter is shifted +2 in the alphabet: J→L, U→W, N→P, E→G. Option LWPF tempts those who shift the last letter by only +1, so the answer is LWPG.

115. In a code language, 'ta pa ma' means 'birds fly high', 'ma na ka' means 'high in sky', and 'pa ra na' means 'fly in air'. What is the code for 'sky'?
(a) ka (b) na (c) ma (d) ra
Answer: (a)
Solution: Comparing the first two messages, 'high' is common, so 'high' = ma; comparing the last two, 'in' is common, so 'in' = na. The only word left in 'high in sky' is 'sky', so the answer is ka.

125. In a code language, 'ne la ta' means 'see you there', 'la pa sa' means 'you are good', and 'ta ra pa' means 'good there here'. What is the code for 'see here'?
(a) ne pa (b) la ra (c) ta ra (d) ne ra
Answer: (d)
Solution: Comparing the first two messages, 'you' = la; comparing the first and third, 'there' = ta; so 'see' = ne. Comparing the last two messages, 'good' = pa, so 'here' = ra. Option ne pa wrongly pairs 'see' with 'good', so the answer is ne ra.
Source: PYQ-style
