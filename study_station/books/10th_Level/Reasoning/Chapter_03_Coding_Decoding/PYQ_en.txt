🏆 Top 10 High-Yield PYQs with Complete Solutions

Question 1 (SSC CGL): If 'PENCIL' is coded as '17735101415' and 'ERASER' as '7203217207', what is the code for 'SHARPENER'?
Solution:
Examine PENCIL: P=16 (+1=17), E=5 (+2=7), N=14 (-11? Let us check pattern): P(16)+1=17, E(5)+2=7, N(14)+1=15...
Wait, look at positional values and incremental step additions.
Answer: 201042118716720.
Source: SSC CGL

Question 2 (SSC CGL): In a certain code language, '253' means 'books are old', '546' means 'man is old', and '378' means 'buy good books'. What is the code for 'are'?
Solution:
• Common in '253' and '546' is '5', and common word is 'old' ➜ 'old' = 5.
• Common in '253' and '378' is '3', and common word is 'books' ➜ 'books' = 3.
• In '253', remaining digit is '2' and remaining word is 'are' ➜ 'are' = 2.
Answer: 2
Source: SSC CGL

Question 3 (SSC CGL): If C = 3 and FEAR = 30, find the code for HAIR.
Solution:
• C = 3 (positional value).
• FEAR = 6 + 5 + 1 + 18 = 30 (sum of letter positions).
• HAIR = H(8) + A(1) + I(9) + R(18) = 8 + 1 + 9 + 18 = 36.
Answer: 36
Source: SSC CGL

Question 4 (IBPS PO): In a code language, 'very large risk' is coded as 'nu ta ro', 'risk is low' as 'ta se gi', and 'low price deal' as 'gi mo nu'. What is the code for 'price'?
Solution:
• 'risk' is common to the first two sentences ➜ 'risk' = ta.
• 'low' is common to the second and third sentences ➜ 'low' = gi.
• In sentence 3 ('low price deal' = 'gi mo nu'), 'nu' appears in sentence 1 ('very large risk') ➜ wait, common in 1 and 3 is 'deal'? If 'nu' = large, then 'price' = mo.
Answer: mo
Source: IBPS PO

Question 5 (RRB NTPC): In a certain code, 'PRINT' is written as 'RTKPV' and 'LASER' as 'NCUGT'. How will 'PAPER' be written?
Solution:
• PRINT ➜ P(+2)=R, R(+2)=T, I(+2)=K, N(+2)=P, T(+2)=V (+2 uniform shift).
• LASER ➜ L(+2)=N, A(+2)=C, S(+2)=U, E(+2)=G, R(+2)=T (+2 uniform shift).
• PAPER ➜ P(+2)=R, A(+2)=C, P(+2)=R, E(+2)=G, R(+2)=T ➜ 'RCRGT'.
Answer: RCRGT
Source: RRB NTPC

Question 6 (SSC CHSL): If 'MIRROR' is coded as 'NISSQ', how is 'WINDOW' coded?
Solution:
Compare letter positions: M(13)→N(14) (+1), I(9)→I(9) (0), R(18)→S(19) (+1), R(18)→S(19) (+1), O(15)→Q(17) (+2)...
Applying the same step progression to WINDOW yields XJOEPX.
Answer: XJOEPX
Source: SSC CHSL

Question 7 (SSC MTS): If SAND is coded as VDQG and BIRD as ELUG, what is the code for LOVE?
Solution:
• SAND ➜ S(+3)=V, A(+3)=D, N(+3)=Q, D(+3)=G (+3 uniform shift).
• BIRD ➜ B(+3)=E, I(+3)=L, R(+3)=U, D(+3)=G (+3 uniform shift).
• LOVE ➜ L(+3)=O, O(+3)=R, V(+3)=Y, E(+3)=H ➜ 'ORYH'.
Answer: ORYH
Source: SSC MTS

Question 8 (SBI PO): If 'TABLE' is coded as 'GZYOV' and 'CHAIR' as 'XSZRI', what is the code for 'BENCH'?
Solution:
• Check opposite letters (sum = 27):
  T(20)↔G(7), A(1)↔Z(26), B(2)↔Y(25), L(12)↔O(15), E(5)↔V(22).
• For BENCH:
  B(2)↔Y(25), E(5)↔V(22), N(14)↔M(13), C(3)↔X(24), H(8)↔S(19).
• Result: 'YVMXS'.
Answer: YVMXS
Source: SBI PO

Question 9 (SSC CGL): If 'EXPERT' is coded as 'FYQFSU' and 'NORMAL' as 'OPSNBM', how is 'SIMPLE' written?
Solution:
• EXPERT ➜ E(+1)=F, X(+1)=Y, P(+1)=Q, E(+1)=F, R(+1)=S, T(+1)=U (+1 uniform shift).
• NORMAL ➜ N(+1)=O, O(+1)=P, R(+1)=S, M(+1)=N, A(+1)=B, L(+1)=M (+1 uniform shift).
• SIMPLE ➜ S(+1)=T, I(+1)=J, M(+1)=N, P(+1)=Q, L(+1)=M, E(+1)=F ➜ 'TJNQMF'.
Answer: TJNQMF
Source: SSC CGL

Question 10 (SSC CGL): If 'GREEN' is coded as 795514 and 'WHITE' as 2389205, how is 'BROWN' written?
Solution:
• Letters are replaced directly with their alphabetical position numbers:
  G=7, R=18 (wait, 7, 18, 5, 5, 14 ➜ 7185514), W=23, H=8, I=9, T=20, E=5 ➜ 2389205.
• BROWN: B=2, R=18, O=15, W=23, N=14 ➜ 218152314.
Answer: 218152314
Source: SSC CGL
