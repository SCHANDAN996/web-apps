📋 Important Rules & Approaches (Key Rules, Time Management, Formulas)

1. Key Rules / Approaches
Rule Name	Description	Example
Identify Puzzle Type	Spot trigger words to classify as Arrangement, Comparison, Scheduling, or Direction.	"Left/right" → Arrangement; "taller than" → Comparison.
Definite Clues First	Place clues that fix a position or value directly before using relative clues.	"A is at position 3" → place A at 3 at once.
Clean Diagram	Draw a simple diagram with one symbol per slot; use arrows for direction.	Row: 1 2 3 4 5 with L/R arrows. Circle: points with F.C./F.O.
"Immediately" vs "Any"	The word "immediately/just/ठीक" means zero gap; otherwise gaps are allowed.	"A is left of B" ≠ "A is immediately left of B".
Left-Right in Circular	Centre-facing: left = anticlockwise. Outside-facing: left = clockwise.	C-LAC, O-LC mnemonic.
Build Cases (Max 2)	If a clue allows two possibilities, create Case 1 and Case 2. Eliminate with further clues.	Q at 2 or 5 → case 1: Q=2; case 2: Q=5. Test both.
Relative Positioning Care	In parallel rows facing each other, the left end of one row is opposite the right end of the other.	Row 1 left-end faces Row 2 right-end.
No Assumptions	Never assume gender, direction, or absence of gaps unless stated.	If not given, do not assume "immediate".
Cross-Check Final Arrangement	Verify your arrangement against all original clues before answering.	Re-read each clue and confirm.
Skip Irrelevant Information	If a detail (like colour, height) is not asked, ignore it to save time.	"A likes blue" in a seating question → ignore.
2. Time Management
Rule	Time Limit	Action
15-Second Rule	15 seconds	If puzzle type and main relationships are not clear, mark and skip. Return later if time permits.
45-Second Rule	45 seconds	If more than 2 cases are still open or you haven't fixed a single definite position, skip the set.
2-Minute Set Drill	2 minutes per 3-question set	Breakdown: 20 sec diagram + 20 sec definite + 30 sec relative/cases + 30 sec eliminate + 20 sec answer.
Overall Paper Strategy	—	Solve all simple puzzles first (high accuracy, low time). Leave complex/uncertain puzzles for the end.
