📊 PYQ Analysis — Dictionary Order (Pattern & Trap Guide)

## 1. How Exams Test This Topic

Dictionary Order is a recurring, low-volume topic in the Reasoning sections of SSC (CGL, CHSL, MTS, GD), Railway (NTPC, Group D), Banking and State exams. When a paper includes it, it is almost always a single standalone question — arrange four to seven words in alphabetical order and pick the correct sequence from the options.

For a prepared student this is a "banker" question: the method is fixed, the alphabet never changes, and the mark is near-certain. That is why toppers attempt it in the first round of the paper and never leave it unattempted. The only real dangers are the examiner's traps (Section 4) and time-sink sets with deep overlapping prefixes (Section 5).

## 2. Recurring Variants (Sub-Topics)

Examiners test a small set of distinct variants. In rough order of how often they are seen:

| Variant | How often it is seen |
|---|---|
| Standard A–Z arrangement (4–6 words) | The most common form, especially in SSC and Railway papers |
| Reverse dictionary order (Z–A) | Occasional; it inverts your trained habit, so practise it separately |
| "Which word is second/third from the left/right?" | Regular in Banking-style papers; arrangement plus a position step |
| Mixed case / hyphen / space words | Rare but tricky; compare letter by letter, ignoring case |
| "Which word keeps its position after arrangement?" | A Banking favourite inside Order & Ranking sets |
| Letter interchange + dictionary order | Rare, higher difficulty |

## 3. Exam-Wise Pattern

| Exam family | Pattern |
|---|---|
| SSC (CGL / CHSL / MTS / GD) | Almost always standalone: arrange 4–6 words, choose the correct sequence. Easy to moderate. SSC favours words sharing the first two or three letters. |
| Banking (IBPS PO/Clerk, SBI) | Rarely standalone. Usually a sub-part of an "Order & Ranking" or alphabet set: arrange first, then answer a position question. Moderate. |
| Railway (RRB NTPC / Group D) | Standalone, easy, standard A–Z arrangement. |
| State exams (Police / Constable / Forest Guard / State SSC) | Standalone, easy, standard A–Z arrangement. |

## 4. Ten PYQ-Style Questions with Solutions & Psychological Traps

The ten questions below reproduce the exact patterns examiners use. A question carries a specific exam/shift tag only when it has been verified from an official paper or answer key; otherwise it is marked **PYQ-style** — the pattern is real, the wording is reconstructed. Each question is tagged with the examiner's psychological hook and the applicable time rule (15-sec / 45-sec / 60-sec).

**Q1. Six words, one first letter — the second-letter split (SSC pattern, PYQ-style)**

Question: Select the correct dictionary order:
1. Variance  2. Violence  3. Vanquish  4. Vampire  5. Valiant  6. Victorious

Solution:
All six words start with 'V'. Second letter:
- Variance → a
- Vanquish → a
- Vampire → a
- Valiant → a
- Violence → i
- Victorious → i

'a' < 'i', so the four 'Va-' words come first and the two 'Vi-' words come last.

Among the 'Va-' words, third letter: Valiant → l, Vampire → m, Vanquish → n, Variance → r. Since l < m < n < r: Valiant (5), Vampire (4), Vanquish (3), Variance (1).

Among the 'Vi-' words, third letter: Victorious → c, Violence → o. Since c < o: Victorious (6) before Violence (2).

Final order: Valiant (5), Vampire (4), Vanquish (3), Variance (1), Victorious (6), Violence (2).
Answer: 5, 4, 3, 1, 6, 2.

🧠 Psychological Hook: Second-letter split. Four words begin 'Va-' but two begin 'Vi-'. A student who assumes all six share the same second letter and jumps straight to the third letter builds the whole order on a false base. And inside the 'Vi-' pair, the third letter decides: c < o, so Victorious comes before Violence — the opposite of what word familiarity whispers to many candidates.

⏱️ Time Rule: 45-sec rule — six words with overlapping prefixes need careful letter-by-letter comparison.

Source: PYQ-style

**Q2. Seven words, deep prefix (SSC pattern, PYQ-style)**

Question: Dictionary order of:
1. Inundate  2. Invidious  3. Individual  4. Inveterate  5. Invective  6. Invincible  7. Inviolable

Solution:
All seven start with 'In'. Third letter:
- Individual → d
- Inundate → u
- Invidious → v
- Inveterate → v
- Invective → v
- Invincible → v
- Inviolable → v

d < u < v → Individual (3) first, Inundate (1) second, then the five 'Inv-' words.

Among the five 'Inv-' words, fourth letter:
- Invective → e
- Inveterate → e
- Invidious → i
- Invincible → i
- Inviolable → i

e < i → Invective and Inveterate come before Invidious, Invincible and Inviolable.

Invective vs Inveterate (fifth letter): c < t → Invective (5), Inveterate (4).

Invidious vs Invincible vs Inviolable (fifth letter): d < n < o → Invidious (2), Invincible (6), Inviolable (7).

Final order: Individual (3), Inundate (1), Invective (5), Inveterate (4), Invidious (2), Invincible (6), Inviolable (7).
Answer: 3, 1, 5, 4, 2, 6, 7.

🧠 Psychological Hook: Homogeneous prefix illusion. Seven words starting "In…" tempt the brain to skim. The third letter splits them into three clean groups (d, u, v); the fourth letter splits the 'Inv-' block into 'e' and 'i' groups. Note carefully: Invincible takes 'i' at the fourth position (I-n-v-i…), not 'e' — candidates who misread it as "Inve…" place it one slot too early. Missing any one grouping leads to total chaos.

⏱️ Time Rule: 45-sec rule — seven words, layered grouping. If 45 seconds pass without clarity, skip and mark for review.

Source: PYQ-style

**Q3. Same first three letters, hidden double letter (SSC pattern, PYQ-style)**

Question: Correct dictionary order:
1. Dissolve  2. Display  3. Distance  4. Disturb  5. Displace  6. Dispute

Solution:
All six start with 'Dis'. Fourth letter:
- Displace → p
- Display → p
- Dispute → p
- Dissolve → s
- Distance → t
- Disturb → t

p < s < t.

Among the three 'p' words, fifth letter:
- Displace → l
- Display → l
- Dispute → u

l < u → Dispute (6) comes last of the three.

Displace vs Display: both share 'D-i-s-p-l-a-' — the tie survives six full letters. It breaks only at the seventh letter: c < y → Displace (5) before Display (2).

Among the 't' words, fifth letter: Distance → a, Disturb → u. a < u → Distance (3) before Disturb (4).

Final order: Displace (5), Display (2), Dispute (6), Dissolve (1), Distance (3), Disturb (4).
Answer: 5, 2, 6, 1, 3, 4.

🧠 Psychological Hook: Hidden 's' and the six-letter tie. All words begin "Dis…", but the fourth letter is p, s or t — the double 's' in Dissolve is the decoy students miss. Worse, Displace and Display stay tied through six full letters ("Displa-") and separate only at the seventh (c < y). Anyone who stops comparing at the fourth or fifth letter gets this pair wrong.

⏱️ Time Rule: 15-sec rule — once the three fourth-letter groups are visible, the arrangement falls quickly; only the Displace/Display pair needs one extra beat.

Source: PYQ-style

**Q4. Unfamiliar vocabulary (SSC pattern, PYQ-style)**

Question: Which word comes third in dictionary order?
1. Isomer  2. Isoline  3. Isotope  4. Isolate  5. Isologs  6. Isonomy

Solution:
All six start with 'Iso'. Fourth letter:
- Isolate → l
- Isologs → l
- Isoline → l
- Isomer → m
- Isonomy → n
- Isotope → t

l < m < n < t.

Among the 'l' words, fifth letter:
- Isolate → a
- Isoline → i
- Isologs → o

a < i < o → Isolate (4), Isoline (2), Isologs (5).

Dictionary order: Isolate (4), Isoline (2), Isologs (5), Isomer (1), Isonomy (6), Isotope (3).
Third word: Isologs.

🧠 Psychological Hook: Rare-word force. "Isologs" and "Isonomy" are unfamiliar to most candidates. The examiner uses rare vocabulary on purpose — it forces letter-by-letter comparison and punishes anyone who arranges words by "which one looks familiar". In dictionary order, only the alphabet matters, never meaning.

⏱️ Time Rule: 45-sec rule — unfamiliar words demand deliberate comparison; do not rush just because the prefix is shared.

Source: PYQ-style

**Q5. Double letters and vowel confusion (SSC pattern, PYQ-style)**

Question: Dictionary order:
1. Laudanum  2. Lattice  3. Laudation  4. Latterly  5. Laudable

Solution:
All five start with 'La'. Third letter:
- Lattice → t
- Latterly → t
- Laudanum → u
- Laudation → u
- Laudable → u

t < u → the two 'Lat-' words come before the three 'Lau-' words.

Lattice vs Latterly: both share 'L-a-t-t-'. Fifth letter: Lattice → i, Latterly → e. e < i → Latterly (4) before Lattice (2).

Among the 'Lau-' words: all share 'L-a-u-d-a-'. Sixth letter:
- Laudable → b
- Laudanum → n
- Laudation → t

b < n < t → Laudable (5), Laudanum (1), Laudation (3).

Final order: Latterly (4), Lattice (2), Laudable (5), Laudanum (1), Laudation (3).
Answer: 4, 2, 5, 1, 3.

🧠 Psychological Hook: Double-letter and vowel confusion. "Lattice" and "Latterly" share "Latt…" but split at the fifth letter (e < i). Students who stop at the fourth letter, see two 't's and assume a tie, get the pair wrong. Similarly, the three 'Lau-' words look identical until the sixth letter.

⏱️ Time Rule: 45-sec rule.

Source: PYQ-style

**Q6. Easy words, rushed decisions (SSC GD / Railway pattern, PYQ-style)**

Question: Dictionary order:
1. riddle  2. river  3. rightful  4. ring  5. risk

Solution:
All five start with 'ri'. Third letter:
- riddle → d
- rightful → g
- ring → n
- risk → s
- river → v

d < g < n < s < v.

Final order: riddle (1), rightful (3), ring (4), risk (5), river (2).
Answer: 1, 3, 4, 5, 2.

🧠 Psychological Hook: Familiarity overrides logic. The simplicity of these everyday words tempts students to arrange them by "feel". "River" feels like it should come early — but v is the last of the five third letters, so it comes last. Never let word familiarity outvote the alphabet.

⏱️ Time Rule: 15-sec rule — all five words diverge cleanly at the third letter.

Source: PYQ-style

**Q7. Working-memory overload (SSC pattern, PYQ-style)**

Question: Dictionary order:
1. Humility  2. Humbug  3. Humanoid  4. Humidity  5. Humoresque  6. Humanity  7. Humectants

Solution:
All seven start with 'Hum'. Fourth letter:
- Humanity → a
- Humanoid → a
- Humbug → b
- Humectants → e
- Humidity → i
- Humility → i
- Humoresque → o

a < b < e < i < o.

Humanity vs Humanoid: both share 'H-u-m-a-n-'. Sixth letter: Humanity → i, Humanoid → o. i < o → Humanity (6) before Humanoid (3).

Humidity vs Humility (fifth letter): d < l → Humidity (4) before Humility (1).

Final order: Humanity (6), Humanoid (3), Humbug (2), Humectants (7), Humidity (4), Humility (1), Humoresque (5).
Answer: 6, 3, 2, 7, 4, 1, 5.

🧠 Psychological Hook: Deep-prefix quagmire. Seven words sharing "Hum…" deliberately overload working memory. Without systematic grouping by the fourth letter, you drown. Write the group letters on your rough sheet instead of holding them in your head.

⏱️ Time Rule: Skip if 60 seconds elapse. This is a classic time-sink question — mark it and return later.

Source: PYQ-style

**Q8. Banking twist — position after arrangement (Banking pattern, PYQ-style)**

Question: Arrange in dictionary order and find which word is second from the right:
ARK, MET, MOB, SKI, URN

Solution:
First letters: A (ARK), M (MET, MOB), S (SKI), U (URN).
Among the M words: MET vs MOB → second letter E < O → MET before MOB.

Dictionary order: ARK, MET, MOB, SKI, URN.
Second from the right: SKI.

🧠 Psychological Hook: "Order & Ranking" twist. The arrangement itself is easy (15-sec rule), but the question asks for a position in the arranged list. Many candidates arrange correctly and then miscount "second from the right" as "second from the left". Always re-read which position is demanded, and count from the end that is named.

⏱️ Time Rule: 15-sec rule for the arrangement; add 5 seconds to verify the position. Total: about 20 seconds.

Source: PYQ-style

**Q9. Early split that skimmers miss (SSC pattern, PYQ-style)**

Question: Dictionary order:
1. Effluent  2. Edifice  3. Effleurage  4. Edacious  5. Effeminate  6. Eccentric  7. Effulgent

Solution:
All seven start with 'E'. Second letter:
- Eccentric → c
- Edacious → d
- Edifice → d
- Effeminate → f
- Effleurage → f
- Effluent → f
- Effulgent → f

c < d < f → Eccentric (6) first.

Among the 'd' words (third letter): Edacious → a, Edifice → i. a < i → Edacious (4) before Edifice (2).

Among the 'f' words: all share 'E-f-f-'. Fourth letter:
- Effeminate → e
- Effleurage → l
- Effluent → l
- Effulgent → u

e < l < u → Effeminate (5) first, Effulgent (7) last.

Effleurage vs Effluent (fifth letter): e < u → Effleurage (3) before Effluent (1).

Final order: Eccentric (6), Edacious (4), Edifice (2), Effeminate (5), Effleurage (3), Effluent (1), Effulgent (7).
Answer: 6, 4, 2, 5, 3, 1, 7.

🧠 Psychological Hook: Scattered second letters. Unlike most questions where the first two or three letters are identical, here the second letter splits the list immediately (c, d, f). Students stuck in "deep-prefix mode" overthink and start comparing fourth letters on words that differ at the second. Always check how deep the shared prefix actually goes before diving deep.

⏱️ Time Rule: 45-sec rule — despite the early split, seven words still need systematic work.

Source: PYQ-style

**Q10. Familiar-word decoy (SSC GD pattern, PYQ-style)**

Question: Dictionary order:
1. Priceless  2. Prison  3. Pristine  4. Priority  5. Prejudice

Solution:
All five start with 'Pr'. Third letter:
- Prejudice → e
- Priceless → i
- Prison → i
- Pristine → i
- Priority → i

e < i → Prejudice (5) first.

Among the 'i' words, fourth letter:
- Priceless → c
- Priority → o
- Prison → s
- Pristine → s

c < o < s → Priceless (1) next, then Priority (4), then the two 's' words.

Prison vs Pristine (fifth letter): o < t → Prison (2) before Pristine (3).

Final order: Prejudice (5), Priceless (1), Priority (4), Prison (2), Pristine (3).
Answer: 5, 1, 4, 2, 3.

🧠 Psychological Hook: "Prejudice" as decoy. The brain sees "Pre-" and files it next to "Pri-" as similar. But e < i is a hard alphabetical fact, so Prejudice comes first. Familiarity with a word can override logic only if you let it — the alphabet does not negotiate.

⏱️ Time Rule: 15-sec rule — clean split at the third letter, then the fourth.

Source: PYQ-style

## 5. Summary: Which Questions to Skip?

Based on the 15-sec / 45-sec / 60-sec rules established in the chapter:

| Question type | Time rule | Skip? |
|---|---|---|
| First letters all different | 15-sec | Never skip — instant solve |
| 2–3 shared starting letters, ≤ 5 words | 45-sec | Skip only if 45 sec pass without clarity |
| 5+ words with deep overlapping prefixes (e.g., the Humility set) | 60-sec | Yes — mark for review and move on |
| 7+ words (e.g., the Effluent set) | 60-sec | Yes — mark for review |
| Reverse dictionary order | 45-sec | Skip if the forward order itself took more than 30 sec |
| Position-based ("which is third?") | 45-sec | Do not skip — easy once arranged |

Golden Rule for the Exam Hall: If a Dictionary Order question has more than five words with three or more shared starting letters, it will usually take far longer than a standard question while carrying the same single mark. Mark it, move on, and return only if time permits.
