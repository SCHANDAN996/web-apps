4. Top 10 High-Yield PYQs with Solutions & Psychological Traps

Below are 10 questions that have appeared repeatedly with minor variations. Each is tagged with the examiner's psychological hook and the time rule (15-sec or 45-sec).

Q1. SSC CGL 2023 (19 July, Shift-1)

Question: Select the correct dictionary order:

Variance, 2. Violence, 3. Vanquish, 4. Vampire, 5. Valiant, 6. Victorious

Solution:
All start with 'V'. Second letter: all 'a'. Third letter:

Valiant → l

Vampire → m

Vanquish → n

Variance → r

Victorious → i

Violence → i

Alphabetical order of third letters: i < l < m < n < r.
But Victorious vs Violence: fourth letter 'c' < 't' → Violence before Victorious.

Final Order: Valiant (5), Vampire (4), Vanquish (3), Variance (1), Violence (2), Victorious (6).
Answer: 5, 4, 3, 1, 2, 6.

🧠 Psychological Hook: Third-letter trap. Students often jump from the second letter ('a') directly to the fourth or fifth letter, missing that Victorious/Violence share 'i' as the third letter. The examiner embeds two words with the same third letter to test patience.

⏱️ Time Rule: 45-sec rule — 6 words with overlapping prefixes require careful letter-by-letter comparison.

Q2. SSC CGL 2022 (01 Dec, Shift-4)

Question: Dictionary order of:

Inundate, 2. Invidious, 3. Individual, 4. Inveterate, 5. Invective, 6. Invincible, 7. Inviolable

Solution:
All start 'In'. Third letter:

Individual → d

Inundate → u

Invidious → v

Inveterate → v

Invective → v

Invincible → v

Inviolable → v

'd' < 'u' < 'v'. So Individual first, then Inundate.
Among the 5 'v' words, fourth letter: all 'e' except Inviolable ('i') and Invidious ('i').
'e' < 'i'. So Invective, Inveterate, Invincible come before Invidious, Inviolable.
Now compare fifth letters within each group.

Final Order: Individual (3), Inundate (1), Invective (5), Inveterate (4), Invincible (6), Invidious (2), Inviolable (7).
Answer: 3, 1, 5, 4, 6, 2, 7.

🧠 Psychological Hook: Homogeneous prefix illusion. Seven words starting "In..." — the brain wants to skim. But the third letter splits them into three distinct groups (d, u, v). Missing this grouping leads to total chaos.

⏱️ Time Rule: 45-sec rule — 7 words, complex grouping. If 45 seconds pass without clarity, SKIP.

Q3. SSC CGL 2023 (20 July, Shift-1)

Question: Correct dictionary order:

Dissolve, 2. Display, 3. Distance, 4. Disturb, 5. Displace, 6. Dispute

Solution:
All start 'Dis'. Third letter: all 's'. Fourth letter:

Displace → p

Display → p

Dispute → p

Dissolve → s

Distance → t

Disturb → t

'p' < 's' < 't'. Among the three 'p' words, fifth letter: Displace ('l'), Display ('l'), Dispute ('u'). 'l' < 'u'.
Displace vs Display: sixth letter 'a' < 't', so Displace before Display.
Among 't' words: Distance ('a'), Disturb ('u'). 'a' < 'u'.

Final Order: Displace (5), Display (2), Dispute (6), Dissolve (1), Distance (3), Disturb (4).
Answer: 5, 2, 6, 1, 3, 4.

🧠 Psychological Hook: Hidden 's' fourth-letter trap. All words begin "Dis...", but the fourth letter is either 'p', 's', or 't'. The brain pattern-matches "Dissolve" as similar to "Display" and may group them incorrectly. The fourth letter 's' in Dissolve is the decoy.

⏱️ Time Rule: 15-sec rule — once you identify the three fourth-letter groups, arrangement is fast.

Q4. SSC CGL 2020 (3 March, Shift-3)

Question: Which word comes third in dictionary order?

Isomer, 2. Isoline, 3. Isotope, 4. Isolate, 5. Isologs, 6. Isonomy

Solution:
All start 'Iso'. Fourth letter:

Isolate → l

Isologs → l

Isoline → l

Isomer → m

Isonomy → n

Isotope → t

Among 'l' words, fifth letter: Isolate ('a'), Isologs ('o'), Isoline ('i'). Order: a < i < o.

Dictionary Order: Isolate (4), Isoline (2), Isologs (5), Isomer (1), Isonomy (6), Isotope (3).
Third word: Isologs.

🧠 Psychological Hook: "Isologs" is an unfamiliar word. The examiner uses rare vocabulary to force you to rely on letter-by-letter comparison rather than "word familiarity." Students who try to guess based on "which word looks familiar" fail.

⏱️ Time Rule: 45-sec rule — unfamiliar words require deliberate comparison.

Q5. SSC CGL 2022 (02 Dec, Shift-1)

Question: Dictionary order:

Laudanum, 2. Lattice, 3. Laudation, 4. Latterly, 5. Laudable

Solution:
All start 'La'. Third letter:

Lattice → t

Latterly → t

Laudanum → u

Laudation → u

Laudable → u

't' < 'u'. So Lattice and Latterly before the three 'Lau' words.
Lattice vs Latterly: fourth letter 't' vs 't', fifth letter 'i' < 'e'? No — Lattice has 'i' (fifth), Latterly has 'e' (fifth). 'e' < 'i', so Latterly before Lattice.
Among 'Lau' words: Laudable ('d'), Laudanum ('d'), Laudation ('d'). Fifth letter: 'a', 'a', 'a'. Sixth: Laudable ('b'), Laudanum ('n'), Laudation ('t'). Order: b < n < t.

Final Order: Latterly (4), Lattice (2), Laudable (5), Laudanum (1), Laudation (3).
Answer: 4, 2, 5, 1, 3.

🧠 Psychological Hook: Double-letter and vowel confusion. "Lattice" and "Latterly" share "Latt..." but diverge at the fifth letter. Students often stop at the fourth letter, seeing both 't's and assuming they're tied.

⏱️ Time Rule: 45-sec rule.

Q6. SSC GD 2023 (01 Feb, Shift-3)

Question: Dictionary order:

riddle, 2. river, 3. rightful, 4. ring, 5. risk

Solution:
All start 'ri'. Third letter:

riddle → d

rightful → g

ring → n

risk → s

river → v

Alphabetical: d < g < n < s < v.

Final Order: riddle (1), rightful (3), ring (4), risk (5), river (2).
Answer: 1, 3, 4, 5, 2.

🧠 Psychological Hook: Easy words, rushed decisions. The simplicity of these words tempts students to arrange them by "feel." River feels like it should come before riddle — but 'v' > 'd'. This is the "familiarity overrides logic" trap.

⏱️ Time Rule: 15-sec rule — all diverge cleanly at the third letter.

Q7. SSC CGL 2022 (05 Dec, Shift-3)

Question: Dictionary order:

Humility, 2. Humbug, 3. Humanoid, 4. Humidity, 5. Humoresque, 6. Humanity, 7. Humectants

Solution:
All start 'Hum'. Fourth letter:

Humanoid → a

Humanity → a

Humbug → b

Humectants → e

Humidity → i

Humility → i

Humoresque → o

Order of fourth letters: a < b < e < i < o.
Among 'a': Humanoid ('n') vs Humanity ('n'). Fifth letter: 'o' < 'a'? Wait, Humanoid (a-n-o), Humanity (a-n-i). Fifth: 'i' < 'o' → Humanity before Humanoid.
Among 'i': Humidity ('d'), Humility ('l'). 'd' < 'l'.

Final Order: Humanity (6), Humanoid (3), Humbug (2), Humectants (7), Humidity (4), Humility (1), Humoresque (5).
Answer: 6, 3, 2, 7, 4, 1, 5.

🧠 Psychological Hook: Deep-prefix quagmire. 7 words sharing "Hum..." — the exam deliberately overloads working memory. Without systematic grouping by the fourth letter, you drown.

⏱️ Time Rule: SKIP if 60 seconds elapse. This is a classic time-sink question.

Q8. Banking (SBI Clerk 2012 pattern, reused in IBPS 2022)

Question: Arrange in dictionary order and find which word is second from the right:
ARK, MET, MOB, SKI, URN

Solution:
First letters: A (ARK), M (MET, MOB), S (SKI), U (URN).
M words: MET vs MOB → second letter 'E' < 'O' → MET before MOB.

Dictionary Order: ARK, MET, MOB, SKI, URN.
Second from right: SKI.

🧠 Psychological Hook: "Order & Ranking" twist. The dictionary arrangement itself is easy (15-sec rule), but the question asks for a position in the arranged list. Many students arrange correctly but then miscount "second from right" vs "second from left."

⏱️ Time Rule: 15-sec rule for arrangement; add 5 seconds to verify position. Total: 20 sec max.

Q9. SSC CGL 2022 (07 Dec, Shift-3)

Question: Dictionary order:

Effluent, 2. Edifice, 3. Effleurage, 4. Edacious, 5. Effeminate, 6. Eccentric, 7. Effulgent

Solution:
First letter: all 'E'. Second letter:

Eccentric → c

Edifice → d

Edacious → d

Effluent → f

Effleurage → f

Effeminate → f

Effulgent → f

'c' < 'd' < 'f'. So Eccentric first.
Among 'd': Edacious ('a') < Edifice ('i').
Among 'f' words, third letter all 'f'. Fourth:

Effeminate → e

Effleurage → l

Effluent → l

Effulgent → u

'e' < 'l' < 'u'. Effeminate first among 'f's.
Effleurage vs Effluent: fifth letter 'e' < 'u' → Effleurage before Effluent.

Final Order: Eccentric (6), Edacious (4), Edifice (2), Effeminate (5), Effleurage (3), Effluent (1), Effulgent (7).
Answer: 6, 4, 2, 5, 3, 1, 7.

🧠 Psychological Hook: Scattered second letters. Unlike most PYQs where the first 2-3 letters are identical, here the second letter splits the list immediately (c, d, f). Students in "deep-prefix mode" may overthink and miss this early split.

⏱️ Time Rule: 45-sec rule — despite early split, 7 words still require systematic work.

Q10. SSC GD Mini Mock 2024

Question: Dictionary order:
Priceless, Prison, Pristine, Priority, Prejudice

Solution:
All start 'Pr'. Third letter:

Prejudice → e

Priceless → i

Prison → i

Pristine → i

Priority → i

'e' < 'i'. So Prejudice first.
Among 'i' words, fourth letter:

Priceless → c

Priority → o

Prison → s

Pristine → s

'c' < 'o' < 's'. So Priceless next.
Priority (o) third.
Prison vs Pristine: fifth letter 's' < 't' → Prison before Pristine.

Final Order: Prejudice, Priceless, Priority, Prison, Pristine.
Answer: 5, 1, 4, 3, 2.

🧠 Psychological Hook: "Prejudice" as a decoy. The brain sees "Pre-" and wants to group it with "Pri-" as similar. But 'e' < 'i' is a hard alphabetical fact. The emotional familiarity of the word "Prejudice" can override logic.

⏱️ Time Rule: 15-sec rule — clean split at third letter, then fourth.

5. Summary: Which Questions to Skip?

Based on the 15-sec / 45-sec / 60-sec rules established in the chapter:

Question Type	Time Rule	Skip?
First letters all different	15-sec	Never skip — instant solve
2-3 shared starting letters, ≤5 words	45-sec	Skip only if >45 sec without clarity
5+ words, deep overlapping prefixes (e.g., Humility set)	60-sec	Yes, skip after 60 sec — mark for review
7+ words (e.g., Effluent set)	60-sec	Yes, skip after 60 sec
Reverse dictionary order	45-sec	Skip if the forward order itself took >30 sec
Position-based ("which is third?")	45-sec	Do not skip — these are often easy after arrangement

Golden Rule for Exam Hall: If a Dictionary Order question has more than 5 words with 3+ shared starting letters, it is statistically a time-sink. Over 10 years of PYQ data, these "deep-prefix" questions consume 3-4x the time of standard questions with only marginally higher difficulty. Mark, move on, and return only if time permits.
