## भाग 1: म्नेमोनिक ट्रिक्स (याद रखने की कुंजियाँ)

┌─────────────────────────────────────────────┐
│ ट्रिक 1: "CIDE = मारना"                     │
│ Latin जड़ 'cide' = मारना (kill)             │
│ • Homicide = मनुष्य (homo) की हत्या         │
│ • Suicide = स्वयं (sui) की हत्या             │
│ • Fratricide = भाई (frater) की हत्या        │
│ • Regicide = राजा (rex) की हत्या            │
│ याद करें: "सीडी (cide) पर हत्या की फिल्म"   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 2: "PHILE = प्रेम, PHOBE = डर"        │
│ • Bibliophile = किताबों (biblio) से प्रेम    │
│ • Anglophile = इंग्लैंड से प्रेम             │
│ • Hydrophobia = पानी (hydro) का डर          │
│ • Claustrophobia = बंद जगह का डर            │
│ याद करें: "फ़िल्म (phile) देखने वाला =      │
│ प्रेमी; फोबिया (phobe) = डर"                │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 3: "CRACY = शासन"                     │
│ Greek जड़ 'kratos' = शासन/शक्ति             │
│ • Democracy = जनता (demos) का शासन          │
│ • Autocracy = स्वयं (auto) का शासन = तानाशाही│
│ • Bureaucracy = नौकरशाहों का शासन           │
│ • Theocracy = धर्मगुरुओं (theo) का शासन     │
│ याद करें: "क्रेसी (cracy) = कुर्सी पर कौन?" │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 4: "OMNI = सब"                        │
│ • Omnipotent = सर्वशक्तिमान (potent=शक्ति)  │
│ • Omniscient = सर्वज्ञ (scient=ज्ञान)        │
│ • Omnipresent = सर्वव्यापी (present=उपस्थित)│
│ • Omnivorous = सर्वभक्षी (vore=खाना)        │
│ याद करें: "ओम (OM) भगवान का — भगवान सब हैं" │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 5: "VORE = खाना"                      │
│ • Carnivorous = मांस (carni) खाने वाला      │
│ • Herbivorous = घास (herb) खाने वाला        │
│ • Omnivorous = सब खाने वाला                 │
│ • Insectivorous = कीड़े खाने वाला           │
│ याद करें: "वोर (vore) = भोर में खाना"       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 6: "LOGY = विद्या/अध्ययन"             │
│ • Biology = जीव (bio) का अध्ययन             │
│ • Zoology = जंतुओं (zoo) का अध्ययन          │
│ • Geology = पृथ्वी (geo) का अध्ययन          │
│ • Etymology = शब्दों के मूल का अध्ययन       │
│ याद करें: "लॉजी (logy) = लॉजिक से पढ़ाई"    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 7: "MANIA = पागलपन/सनक"               │
│ • Kleptomania = चोरी (klepto) की सनक        │
│ • Pyromania = आग (pyro) लगाने की सनक        │
│ • Megalomania = बड़ेपन (megalo) की सनक      │
│ याद करें: "मेनिया (mania) = मन में सनक"     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 8: "GRAPH = लिखना"                    │
│ • Biography = जीवन (bio) का लिखा वर्णन      │
│ • Autobiography = स्वयं (auto) लिखी जीवनी   │
│ • Calligraphy = सुंदर (kalli) लेखन          │
│ • Telegraph = दूर (tele) से लिखना           │
│ याद करें: "ग्राफ (graph) = ग्रंथ"           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 9: "AMBUL = चलना"                     │
│ • Ambulance = चलता-फिरता अस्पताल            │
│ • Somnambulist = नींद (somnus) में चलने वाला│
│ • Perambulator = बच्चों की गाड़ी (घुमाने    │
│   वाली)                                     │
│ याद करें: "एम्बुलेंस = चलने वाला अस्पताल"   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 10: "MORT = मृत्यु"                   │
│ • Mortal = नश्वर (जो मर सके)                │
│ • Immortal = अमर                            │
│ • Mortuary = शव-गृह                         │
│ • Post-mortem = मृत्यु के बाद (post) की जाँच│
│ याद करें: "मोर्ट (mort) = मौत"              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 11: "AUDI = सुनना"                    │
│ • Audible = जिसे सुना जा सके                │
│ • Audience = सुनने वाले (श्रोता)            │
│ • Auditorium = सुनने की जगह                 │
│ • Inaudible = जिसे सुना न जा सके            │
│ याद करें: "ऑडियो (audio) = सुनाई देने वाला" │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 12: "GAMY = विवाह"                    │
│ • Monogamy = एक (mono) विवाह                │
│ • Bigamy = दो (bi) विवाह                    │
│ • Polygamy = अनेक (poly) विवाह              │
│ याद करें: "गेमी (gamy) = शादी का खेल —      │
│ कितने खिलाड़ी?"                             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 13: "ANTE = पहले, POST = बाद"         │
│ • Antecedent = पूर्ववर्ती                   │
│ • Postpone = बाद (post) में टालना           │
│ • Antenatal = जन्म से पहले का               │
│ • Posthumous = मृत्यु के बाद का             │
│ याद करें: "ANTE = अंते नहीं, पहले!          │
│ POST = पोस्टमैन बाद में आता है"             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐

│ • Soliloquy = स्वगत कथन (अकेले बोलना)       │
│ • Eloquent = वाक्पटु (प्रभावशाली वक्ता)     │
│ याद करें: "लोक (loqu) बोलते हैं"            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐

│ • Pessimist = निराशावादी (पेसी = बुरा)      │

│ याद करें: "IN = अंदर मुड़ा, EX = बाहर निकला"│
└─────────────────────────────────────────────┘

## भाग 2: स्किप रणनीति (कब प्रश्न छोड़ें)

🚫 **स्किप नियम 1 — अनजानी जड़ (root) वाला शब्द:**
अगर शब्द की जड़ (root) बिल्कुल अनजानी है और चारों विकल्प एक-जैसे दिखते हैं (जैसे Ephemeral, Evanescent, Transient, Perennial), तो अंदाज़ा न लगाएँ — पहले बाकी प्रश्न करें, अंत में समय बचे तो वापस आएँ। नेगेटिव मार्किंग में अंधा अंदाज़ा घाटा कराता है।

🚫 **स्किप नियम 2 — "लगभग-सही" विकल्पों का जाल:**
जब दो विकल्प लगभग एक ही अर्थ के हों (जैसे "जो पढ़ा न जा सके" — Illegible बनाम Inedible), तो जल्दबाज़ी में टिक न करें। 10 सेकंड रुककर जड़ सोचें: legible = leg (पढ़ना), edible = eat (खाना)। फिर भी शक हो तो छोड़ दें।

🚫 **स्किप नियम 3 — लंबा वर्णन वाला प्रश्न:**
अगर प्रश्न में 2-3 पंक्तियों का वर्णन है और आपको पहली पंक्ति में ही उत्तर का जड़-संकेत न मिले, तो उसे अंत के लिए चिह्नित करें। पहले सीधे तथ्यात्मक प्रश्न (15-सेकंड वाले) निपटाएँ — इससे समय और आत्मविश्वास दोनों बचते हैं।

✅ **सुनहरा सुझाव:** एक शब्द प्रतिस्थापन के अधिकतर प्रश्न कुछ ही बार-बार पूछी जाने वाली जड़ों (roots) से बनते हैं। ऊपर की 15 ट्रिक्स की जड़ें रट लें — अधिकतर प्रश्न 15 सेकंड में हल होंगे और स्किप करने की ज़रूरत ही नहीं पड़ेगी।
