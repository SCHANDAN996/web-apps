# 🪄 Short Tricks + Skip Strategy — Direct & Indirect Speech

---

## Trick 1 — The "S-P-O-R-T" Reporting Verb Check

```
┌─────────────────────────────────────────────┐
│  S-P-O-R-T                                  │
│  S → Said (no object)                       │
│  P → Proposed / Suggested (for offers)      │
│  O → Ordered (imperative, negative = not to)│
│  R → Requested (please / kindly)            │
│  T → Told (MUST have an object: told me)    │
└─────────────────────────────────────────────┘
```
**Memory hook:** *"SAID walks alone, TOLD holds a hand."* If "told" has no object after it, the option is wrong — eliminate it in 5 seconds.

---

## Trick 2 — The "Back-Step Ladder" for Tenses

```
┌─────────────────────────────────────────────┐
│  Every tense takes ONE STEP BACK:           │
│  is/am/are   → was/were                     │
│  has/have    → had                          │
│  will/shall  → would/should                 │
│  can/may     → could/might                  │
│  V2 (past)   → had + V3                     │
│  ⚠ Past Perfect & would/could/might/ought   │
│    → NO CHANGE (already at the bottom!)     │
└─────────────────────────────────────────────┘
```
**Memory hook:** *"One step down the ladder — but the bottom rung never moves."*

---

## Trick 3 — "N-T-H" Time Word Swap

```
┌─────────────────────────────────────────────┐
│  N → Now becomes Then                       │
│  T → Today/This becomes That day/That       │
│  H → Here becomes There                     │
│  Bonus: ago → before, tomorrow → next day,  │
│  yesterday → previous day                   │
└─────────────────────────────────────────────┘
```
**Memory hook:** *"Near words run FAR away in indirect speech."* (this→that, here→there, now→then)

---

## Trick 4 — The "P-Q-I-E" Sentence-Type Formula

```
┌─────────────────────────────────────────────┐
│  P → Positive/Statement : said/told + that  │
│  Q → Question : asked + if/whether (Yes-No) │
│                 asked + Wh-word (Wh-Q)      │
│  I → Imperative : ordered/requested + to    │
│  E → Exclamation : exclaimed + that (with   │
│      joy/sorrow/surprise)                   │
└─────────────────────────────────────────────┘
```
**Memory hook:** First identify the sentence TYPE, then apply its connector. 80% of options die at the connector stage itself.

---

## Trick 5 — Question Mark Killer

```
┌─────────────────────────────────────────────┐
│  In indirect speech, a reported question    │
│  becomes a STATEMENT:                       │
│  ✗ He asked me where was I going.           │
│  ✓ He asked me where I was going.           │
│  Rule: Subject BEFORE Verb + NO "?" mark    │
└─────────────────────────────────────────────┘
```
**Memory hook:** *"Reported questions lose their question mark AND their inversion."*

## Trick 6 — "Please = Requested, Sir = Respectfully"

```
┌─────────────────────────────────────────────┐
│  Please / Kindly  → requested               │
│  Do it! (command) → ordered / commanded     │
│  Don't...         → forbade / ordered not to│
│  Let us...        → suggested / proposed    │
│  Let me...        → requested to be allowed │
└─────────────────────────────────────────────┘
```

---

## Trick 7 — The "Universal Truth Freeze"

```
┌─────────────────────────────────────────────┐
│  Universal truths, proverbs, habits:        │
│  TENSE DOES NOT CHANGE!                     │
│  He said, "The sun rises in the east."      │
│  → He said that the sun rises in the east.  │
│  (NOT "rose" — the sun didn't retire!)      │
└─────────────────────────────────────────────┘
```

---

## Trick 8 — Pronoun "S-O-N" Rule

```
┌─────────────────────────────────────────────┐
│  S → Subject  : 1st person (I/we) follows   │
│      the SUBJECT of reporting verb          │
│  O → Object   : 2nd person (you) follows    │
│      the OBJECT of reporting verb           │
│  N → No change: 3rd person (he/she/they)    │
│      stays as it is                         │
└─────────────────────────────────────────────┘
```
**Memory hook:** *"SON — the eldest rule of narration."*
Example: He said to me, "I will help you." → He told me that **he** (S→he) would help **me** (O→me).

## Trick 9 — Exclamation Converter

```
┌─────────────────────────────────────────────┐
│  What a / How + adjective  →  very/great +  │
│  adjective (as a statement)                 │
│  "What a beautiful flower!"                 │
│  → exclaimed that it was a very beautiful   │
│    flower.                                  │
│  Hurrah! → with joy | Alas! → with sorrow   │
└─────────────────────────────────────────────┘
```

---

## Trick 10 — "Said + Object = Told" Instant Fix

```
┌─────────────────────────────────────────────┐
│  said to + object  →  told + object         │
│  (drop the "to"!)                           │
│  He said to me → He told me                 │
│  said (no object) → stays "said"            │
└─────────────────────────────────────────────┘
```

---

## Trick 11 — Option Elimination Order (30-second filter)

```
┌─────────────────────────────────────────────┐
│  Check options in THIS order:               │
│  1. Reporting verb correct? (told/asked)    │
│  2. Connector correct? (that/if/Wh/to)      │
│  3. Tense stepped back?                     │
│  4. Pronoun (SON) correct?                  │
│  5. Time words changed? (now→then)          │
│  Most MCQs collapse by step 2 or 3.         │
└─────────────────────────────────────────────┘
```

---

## Trick 12 — "Must" Memory

```
┌─────────────────────────────────────────────┐
│  must → usually stays "must" or becomes     │
│  "had to" (obligation).                     │
│  shall (1st person, suggestion) → should/   │
│  would; in offers "Shall I...?" → offered   │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy

**Skip Tip 1 — The 3-Layer Question:** If a question mixes a question + imperative + exclamation in one long sentence (rare, hard level), and you cannot parse it in 45 seconds, mark it and move on. One tough narration question costs the same 1 mark as an easy one — never trade 3 easy questions for 1 hard one.

**Skip Tip 2 — Two Options Both "Look Right":** When two options differ only in tense (e.g., "had gone" vs "went"), re-read the reporting verb. If it is past tense, pick the back-stepped one. If still unsure after 45 seconds, choose the option with the correct **connector** (that/if) — connectors are tested more often than fine tense shades — and move on.

**Skip Tip 3 — Negative Imperative Confusion:** If "forbade" appears in options, remember *forbade* already carries a negative meaning — "forbade me to go" is correct, "forbade me not to go" is a double-negative trap. If you spot this trap, answer in 15 seconds; if the sentence is longer and confusing, skip and return after finishing the section.
