# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — वाक्य सुधार (सरल)

## 🎯 15 म्नेमोनिक ट्रिक्स (बॉक्स में)

```
┌─────────────────────────────────────────────────┐
│ ट्रिक 1: "SV जोड़ी" — Subject-Verb हमेशा जोड़ी   │
│ बीच में कितना भी लंबा वाक्यांश आए, क्रिया        │
│ कर्ता से ही मिलेगी।                              │
│ ✗ The quality of apples were good.               │
│ ✓ The quality of apples was good.                │
│ याद रखें: "बीच का माल फेक, जोड़ी देख!"          │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 2: "EACH-EVERY-ONE = एक"                   │
│ Each, Every, Everyone, Everybody, Someone,       │
│ Nobody → हमेशा एकवचन क्रिया (is/was/has)।        │
│ ✓ Each of the boys has a pen.                    │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 3: "NEITHER-NOR नज़दीकी नियम"              │
│ Neither...nor / Either...or / Not only...but also│
│ में क्रिया नज़दीक वाले कर्ता के अनुसार।          │
│ ✓ Neither the teacher nor the students were late.│
│ याद: "क्रिया पड़ोसी की सुनती है!"               │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 4: "SINCE = बिंदु, FOR = दूरी"             │
│ Since + समय का बिंदु (Monday, 2010, 5 baje)      │
│ For + समय की अवधि (two years, long time)         │
│ ✓ I have lived here since 2015 / for ten years.  │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 5: "DID के बाद V1"                         │
│ did/didn't के बाद क्रिया का पहला रूप ही आएगा।    │
│ ✗ He did not went.  ✓ He did not go.             │
│ याद: "did ने सारा past खा लिया!"                │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 6: "MUCH-भारी, MANY-गिनती"                 │
│ Much → अगणनीय (water, money, time)               │
│ Many → गणनीय (books, boys, days)                 │
│ याद: "Much मटका (पानी), Many मेज़ (किताबें)!"    │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 7: "LESS-FEWER जुड़वाँ"                    │
│ Less → अगणनीय, Fewer → गणनीय                     │
│ ✓ Less water, fewer bottles.                     │
│ याद: "Fewer में 'few' = गिन सकते हो!"            │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 8: "ELDER-OLDER भाई-बहन"                   │
│ Elder → परिवार में (than नहीं लगता)              │
│ Older → सामान्य तुलना (than लगता है)             │
│ ✓ He is my elder brother. / He is older than me. │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 9: "SUPERIOR जूनियर गैंग — NO THAN"        │
│ Superior, inferior, senior, junior, prefer →     │
│ इनके साथ 'to' लगता है, 'than' नहीं।              │
│ ✓ He is senior to me.                            │
│ याद: "ये 5 than से नफ़रत करते हैं!"             │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 10: "UNLESS = IF NOT"                      │
│ Unless के साथ not नहीं लगता (पहले से नकारात्मक)। │
│ ✗ Unless you do not work hard...                 │
│ ✓ Unless you work hard, you will fail.           │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 11: "NO SOONER-THAN जोड़ी"                 │
│ No sooner → than | Hardly/Scarcely → when        │
│ ✓ No sooner did he come than it rained.          │
│ ✓ Hardly had he come when it rained.             │
│ याद: "No sooner की शादी than से!"               │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 12: "ONE OF THE + बहुवचन + एकवचन क्रिया"   │
│ ✓ One of the boys has done it.                   │
│ याद: "भीड़ बहुत, हीरो एक!"                      │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 13: "NEWS-PHYSICS नकली बहुवचन"             │
│ News, Physics, Mathematics, Politics, Measles →  │
│ दिखते बहुवचन, होते एकवचन।                        │
│ ✓ The news is good.                              │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 14: "IT IS TIME + Past"                    │
│ It is time / It is high time के बाद past tense।  │
│ ✓ It is high time you went home.                 │
│ याद: "देर हो गई = कहानी past में!"              │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ ट्रिक 15: "हिंदी-अंग्रेज़ी पुल (Bridge Trick)"    │
│ हिंदी में "तुम क्या कर रहे हो?" — क्रिया बाद में। │
│ अंग्रेज़ी प्रश्न में helping verb पहले:           │
│ ✗ What you are doing?                            │
│ ✓ What are you doing?                            │
│ याद: "प्रश्न में is/are/do आगे भागते हैं!"      │
└─────────────────────────────────────────────────┘
```

## ⏭️ स्किप रणनीति (कब प्रश्न छोड़ें)

**टिप 1 — दो विकल्प "लगभग एक जैसे" हों तो रुको, तीन बार संदेह हो तो छोड़ो।**
अगर 45 सेकंड में भी दो विकल्पों में फँसे हो (जैसे 'since' बनाम 'for' दोनों सही लग रहे हों), तो प्रश्न को mark करके आगे बढ़ो। अंत में ताज़े दिमाग़ से लौटो — जल्दबाज़ी में अंदाज़ा = निगेटिव मार्किंग का न्योता।

**टिप 2 — "No improvement" पर अंधा भरोसा मत करो।**
परीक्षक जानबूझकर पहले से सही वाक्य देता है ताकि तुम ज़बरदस्ती गलती ढूँढो (Over-thinking जाल)। लेकिन हर शक में 'No improvement' टिक करना भी गलत है। नियम: वाक्य को ज़ोर से (मन में) पढ़ो — अगर कोई नियम टूटता नहीं दिखा, तभी 'No improvement' चुनो, वरना प्रश्न छोड़ना बेहतर है।

**टिप 3 — लंबे वाक्य + अपरिचित शब्द = पहले skip, बाद में वापसी।**
जिस वाक्य में 3+ लाइनें हों और 2-3 कठिन शब्द हों, उसे पहले राउंड में छोड़ दो। पहले 15-सेकंड वाले तथ्यात्मक प्रश्न (SV agreement, since/for, much/many) निपटाओ — ये तय अंक हैं। कठिन प्रश्न अंत में, जब समय की स्पष्ट तस्वीर हो।

**याद रखें:** एक सही छोड़ा गया प्रश्न 0 देता है, एक गलत अंदाज़ा −0.25 (या परीक्षा-अनुसार) देता है। छोड़ना भी रणनीति है, हार नहीं।
