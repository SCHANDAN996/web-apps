# 🪄 Short Tricks + Skip Strategy — Articles

## Mnemonic Boxes

```
┌─────────────────────────────────────────────┐
│ TRICK 1: "A-E-I-O-U → AN"                   │
│ Vowel SOUND (not letter) takes AN.          │
│ an apple, an egg, an idea, an orange, an    │
│ umbrella — but a university ("yoo"),        │
│ a European, a one-rupee note ("won").       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 2: "HONEST H"                         │
│ Silent H → AN: an hour, an honest man,      │
│ an heir, an honour.                         │
│ Pronounced H → A: a hotel, a horse, a hut.  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 3: "FANBOYS of Abbreviations"         │
│ Letter-by-letter abbreviations starting     │
│ with a vowel SOUND take AN:                 │
│ an M.P., an S.P., an F.I.R., an L.L.B.,     │
│ an X-ray, an N.C.C. cadet.                  │
│ (Say the letter aloud: "em", "es", "ef"…)   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 4: "FIRST A, SECOND THE"              │
│ First mention → a/an; second mention → the. │
│ "I saw A dog. THE dog was black."           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 5: "THE = UNIQUE ONE"                 │
│ Only one exists → THE:                      │
│ the sun, the moon, the earth, the sky,      │
│ the equator, the internet.                  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 6: "SUPER THE"                        │
│ Superlatives & ordinals always take THE:    │
│ the best, the tallest, the first, the last. │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 7: "RMS-D" — THE with water bodies    │
│ R = Rivers (the Ganga)                      │
│ M = Mountain RANGES (the Himalayas)         │
│ S = Seas/Oceans (the Indian Ocean)          │
│ D = Deserts (the Thar)                      │
│ BUT single peaks/lakes: NO the —            │
│ Mount Everest, Lake Baikal.                 │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 8: "NO THE before NAM-P"              │
│ N = Names of people (✗ the Ram)             │
│ A = Abstract nouns (✗ the honesty is best)  │
│ M = Meals (✗ the lunch is ready)            │
│ P = Places: countries, cities, states       │
│     (✗ the India, ✗ the Delhi)              │
│ Exception countries: the USA, the UK,       │
│ the Republic of India (official names).     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 9: "PLAY THE FLUTE, PLAY CRICKET"     │
│ Musical instruments → THE: play the piano.  │
│ Games & sports → NO article: play cricket.  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 10: "THE + ADJECTIVE = PEOPLE"        │
│ the rich = rich people, the poor, the blind,│
│ the unemployed, the elderly.                │
│ (Always plural verb: The poor NEED help.)   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 11: "SAME THE"                        │
│ Fixed phrases keep THE: the same, the whole,│
│ the only, the very, the following.          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 12: "BY BUS, ON FOOT — NO THE"        │
│ Transport after BY → no article:            │
│ by bus, by train, by air, by car.           │
│ BUT: in THE bus, on THE train (with prep).  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 13: "FEW vs A FEW vs THE FEW"         │
│ few = almost none (negative)                │
│ a few = some (positive)                     │
│ the few = the small number that exists      │
│ Same family: little / a little / the little │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 14: "SCHOOL TRAP"                     │
│ Purpose = NO article: go to school (study), │
│ go to hospital (treatment), go to prison.   │
│ Building/visit = THE: I went to THE school  │
│ to meet the principal.                      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 15: "NEWSPAPERS & HOLY BOOKS = THE"   │
│ the Times of India, the Hindu,              │
│ the Ramayana, the Quran, the Gita.          │
└─────────────────────────────────────────────┘

## ⏭️ Skip Strategy

1. **Skip the "over-thinking" trap.** If two options both look right (e.g., "a European" vs "an European"), say the word aloud in your head. Sound decides in 5 seconds — don't burn 45 seconds re-reading the sentence. If the sound test doesn't resolve it instantly, mark and move on; return after finishing the section.

2. **Skip long-sentence panic.** In error-spotting, the article error is almost always within 3–4 words of a noun. Scan noun-by-noun instead of reading the whole sentence repeatedly. If no noun phrase looks wrong after one scan, the error is elsewhere — skip the article hunt.

3. **Skip zero-article doubt.** When a blank sits before a plural or uncountable noun used generally ("___ honesty is the best policy"), the answer is usually "no article." Don't waste time forcing a/an/the into it — if the noun is general and uncountable/plural, choose "no article" and move on in under 15 seconds.
