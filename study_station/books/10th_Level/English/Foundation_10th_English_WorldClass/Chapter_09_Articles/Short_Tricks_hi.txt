# 🪄 Short Tricks + Skip Strategy — लेख (Articles)

## भाग 1: म्नेमोनिक ट्रिक्स (याद रखने की चाबियाँ)

```
┌─────────────────────────────────────────────┐
│ ट्रिक 1: "AEIOU = AN"                        │
│ स्वर ध्वनि (a, e, i, o, u की आवाज़) से पहले  │
│ हमेशा AN। शब्द नहीं, ध्वनि देखो!            │
│ an apple, an hour (h मूक), an honest man    │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 2: "UNIVERSITY में U = यू (Y)"         │
│ u से शुरू पर आवाज़ 'यू' (y) हो तो A लगाओ:   │
│ a university, a union, a European, a one-   │
│ rupee note (one = वन = w की आवाज़)          │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 3: "पहली बार A/AN, दूसरी बार THE"     │
│ I saw a dog. The dog was black.             │
│ नई चीज़ = a/an, पुरानी (पहले बताई हुई) = the│
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 4: "SUPER में THE"                     │
│ Superlative (सबसे…) से पहले THE:            │
│ the best, the tallest, the most beautiful   │
│ Ordinal भी: the first, the second, the last │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 5: "दुनिया में एक = THE"               │
│ जो चीज़ संसार में एक ही है:                  │
│ the sun, the moon, the earth, the sky,      │
│ the equator, the internet                   │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 6: "नदी-सागर-पहाड़-शृंखला = THE"      │
│ the Ganga, the Indian Ocean, the Himalayas  │
│ पर एकल पर्वत/झील = NO article:              │
│ Mount Everest, Lake Baikal                  │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 7: "देशों में THE का सूत्र: RUK"      │
│ R = Republic (the Republic of India)        │
│ U = United/Union (the USA, the UK, the UAE) │
│ K = Kingdom (the United Kingdom)            │
│ बहुवचन देश भी: the Netherlands, the Philippines│
│ बाकी देश = NO article: India, Japan, France │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 8: "अखबार-ग्रंथ-इमारत = THE"          │
│ the Times of India, the Ramayana,           │
│ the Taj Mahal, the Red Fort                 │
│ (मशहूर इमारतें, पवित्र ग्रंथ, समाचार-पत्र)  │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 9: "भोजन-भाषा-खेल-बीमारी = खाली"      │
│ NO article:                                 │
│ I have breakfast at 8. (भोजन)               │
│ She speaks Hindi. (भाषा)                    │
│ We play cricket. (खेल)                      │
│ He has fever. (सामान्य बीमारी)              │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 10: "SCHOOL का दोहरा चेहरा"           │
│ उद्देश्य के लिए जाओ = NO article:           │
│ go to school (पढ़ने), go to hospital (इलाज),│
│ go to church (प्रार्थना), go to prison (सज़ा)│
│ सिर्फ़ जगह देखने जाओ = THE:                 │
│ I went to the school to meet the teacher.   │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 11: "Uncountable के साथ A/AN मना"     │
│ water, milk, advice, information, furniture,│
│ news, bread — इनसे पहले a/an कभी नहीं।     │
│ ✗ an advice  ✓ a piece of advice            │
│ ✗ an information ✓ some information         │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 12: "वाद्ययंत्र बजाओ = THE"           │
│ play + the + instrument:                    │
│ play the guitar, play the flute, play the tabla│
│ पर खेल में THE नहीं: play cricket ✓         │
│ याद करो: "संगीत में THE, खेल में FREE"      │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 13: "THE + विशेषण = पूरा वर्ग"        │
│ the rich (अमीर लोग), the poor (गरीब लोग),   │
│ the blind, the old, the unemployed          │
│ ये हमेशा बहुवचन: The rich are not always happy.│
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 14: "Same/Only/Whole = THE का परिवार" │
│ the same book, the only son, the whole day, │
│ the very man — इन शब्दों से पहले THE पक्का। │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 15: "जातिवाचक का प्रतिनिधि = THE"     │
│ एकल countable noun पूरी जाति दिखाए = THE:   │
│ The tiger is a wild animal.                 │
│ (= सारे बाघ) The cow is a useful animal.    │
└─────────────────────────────────────────────┘
```

## भाग 2: Skip Strategy (कब प्रश्न छोड़ें)

**⏭️ रणनीति 1: "ध्वनि बनाम अक्षर" का भ्रम दिखे तो रुको, घबराओ मत — पर 45 सेकंड से ज़्यादा नहीं।**
अगर विकल्पों में `a/an` दोनों हैं और शब्द `hour / honest / university / European / one-rupee` जैसा है, तो यह Fact-based प्रश्न है — ध्वनि बोलकर जाँचो और 15 सेकंड में उत्तर दो। पर अगर शब्द अपरिचित है (जैसे कोई विदेशी संक्षिप्ताक्षर — `an MLA / a MLA`?) तो अनुमान मत लगाओ; पहले चक्र में छोड़ दो, बाद में आओ। (याद रखो: MLA = "एम-एल-ए" — स्वर ध्वनि से शुरू, इसलिए *an MLA* सही है।)

**⏭️ रणनीति 2: दो THE वाले लंबे वाक्य में अटक जाओ तो Skip।**
जब वाक्य में 3–4 रिक्त स्थान हों (जैसे: "___ Ganga is ___ longest river of ___ India"), तो हर रिक्ति अलग नियम माँगती है। ऐसे प्रश्न Inference-based हैं — इन्हें 45 सेकंड दो। फिर भी दो रिक्तियों में संदेह रहे तो उसे अंतिम चक्र के लिए चिह्नित करो; जल्दबाज़ी में गलत करने से बेहतर है छोड़ना (negative marking वाली परीक्षा में)।

**⏭️ रणनीति 3: "Exception वाला प्रश्न" पहचानो और सोच-समझकर निर्णय लो।**
अगर विकल्प ऐसे दिखें कि दो नियम टकरा रहे हों (जैसे "Mount Everest" — पहाड़ है पर THE नहीं लगता; "the Himalayas" — शृंखला है इसलिए THE लगता है), तो यह परीक्षक का जानबूझकर बिछाया जाल है। नियम याद है तो 15 सेकंड में मारो; नियम आधा-अधूरा याद है तो तुक्का मत मारो — Skip करो, क्योंकि ऐसे प्रश्नों में "लगता है सही है" वाला विकल्प अक्सर गलत होता है।
