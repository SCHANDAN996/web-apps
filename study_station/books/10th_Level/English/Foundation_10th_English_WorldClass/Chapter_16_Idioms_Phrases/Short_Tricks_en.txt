# 🪄 Short Tricks + Skip Strategy — Idioms & Phrases

## Trick 1: The "Picture Story" Method

```
┌─────────────────────────────────────────────────────┐
│ Never memorise an idiom as words alone.             │
│ Convert it into a 5-second mental MOVIE.            │
│ "To let the cat out of the bag" → imagine a cat     │
│ jumping out of a bag at a surprise party = secret   │
│ revealed! The stranger the picture, the longer it   │
│ stays in memory.                                    │
└─────────────────────────────────────────────────────┘
```

## Trick 2: The "Dead Body" Trick (Literal vs Idiomatic)

```
┌─────────────────────────────────────────────────────┐
│ If taking the idiom LITERALLY creates an absurd or  │
│ impossible scene, it must have a hidden meaning.    │
│ "Kick the bucket" — nobody dies by kicking a bucket │
│ → it means TO DIE. Absurd literal image = idiom.    │
└─────────────────────────────────────────────────────┘
```

## Trick 3: Mnemonic — "BITE" for Animal Idioms

```
┌─────────────────────────────────────────────────────┐
│ B – Black sheep = the disgraceful one in a group    │
│ I – (a) wild goose chase = a useless search         │
│ T – To kill two birds with one stone = two jobs,    │
│     one action                                      │
│ E – Eager beaver = an over-enthusiastic worker      │
│ Remember: animals BITE, and so do these 4 idioms!   │
└─────────────────────────────────────────────────────┘
```

## Trick 4: Mnemonic — "HAND" for Body-Part Idioms

```
┌─────────────────────────────────────────────────────┐
│ H – Heart of gold = a very kind person              │
│ A – Apple of one's eye = most loved person          │
│ N – (by the) skin of one's teeth = narrowly escape  │
│ D – Down in the mouth = sad / depressed             │
│ Your HAND has 4 fingers → 4 body idioms!            │
└─────────────────────────────────────────────────────┘
```

## Trick 5: The Colour Code

```
┌─────────────────────────────────────────────────────┐
│ RED    = danger/anger  → "red tape" = official delay│
│ BLUE   = sadness/rare  → "once in a blue moon"      │
│ GREEN  = envy/new      → "green with envy"          │
│ BLACK  = bad/disgrace  → "black sheep"              │
│ WHITE  = peace/honest  → "white lie" = harmless lie │
│ Colour + emotion = instant meaning recall.          │
└─────────────────────────────────────────────────────┘
```

## Trick 6: The "Opposite Pair" Memory Hook

```
┌─────────────────────────────────────────────────────┐
│ Learn idioms in opposite pairs — one recalls the    │
│ other automatically:                                │
│ • "To burn the midnight oil" (study hard) ↔         │
│   "To take it easy" (relax)                         │
│ • "To hit the nail on the head" (exactly right) ↔   │
│   "To beat about the bush" (avoid the point)        │
│ • "At sixes and sevens" (confused) ↔                │
│   "In apple-pie order" (perfectly arranged)         │
└─────────────────────────────────────────────────────┘
```

## Trick 7: The "Exam Elimination" Trick

```
┌─────────────────────────────────────────────────────┐
│ In MCQs, the option giving the LITERAL meaning is   │
│ almost always the trap. Eliminate it first.         │
│ Q: "To break the ice" — option "to crush frozen     │
│ water" is the decoy. Correct: "to start a friendly  │
│ conversation". Literal = wrong, 9 times out of 10.  │
└─────────────────────────────────────────────────────┘
```

## Trick 8: Mnemonic — "RAIN" for Weather Idioms

```
┌─────────────────────────────────────────────────────┐
│ R – Right as rain = perfectly healthy               │
│ A – (save for a) rainy day = save for hard times    │
│ I – It never rains but it pours = troubles come     │
│     together                                        │
│ N – (come) rain or shine = whatever happens         │
│ Weather idioms? Just remember it might RAIN!        │
└─────────────────────────────────────────────────────┘
```

## Trick 9: The "One-Word Swap" Trick

```
┌─────────────────────────────────────────────────────┐
│ Many idioms = one simple English word. Learn the    │
│ swap for one-word-substitution questions too:       │
│ • "To bite the dust" = to FAIL / be defeated        │
│ • "To call it a day" = to STOP working              │
│ • "To cut corners" = to do something CHEAPLY/badly  │
│ • "To face the music" = to ACCEPT punishment        │
└─────────────────────────────────────────────────────┘
```

## Trick 10: The "Hindi Twin" Trick

```
┌─────────────────────────────────────────────────────┐
│ Many English idioms have a Hindi twin — link them:  │
│ • "To shed crocodile tears" = मगरमच्छ के आँसू       │
│ • "A bolt from the blue" = आसमान से बिजली गिरना     │
│ • "To add fuel to fire" = आग में घी डालना           │
│ • "Castles in the air" = हवाई किले बनाना            │
│ Same image, two languages — learn once, use twice!  │
└─────────────────────────────────────────────────────┘
```

## Trick 11: The "Preposition Lock" Trick

```
┌─────────────────────────────────────────────────────┐
│ In idioms, the small word is FIXED — changing it    │
│ kills the idiom. Examiner swaps it to trap you:     │
│ ✓ "in high spirits"  ✗ "with high spirits"          │
│ ✓ "at a stone's throw" ✗ "by a stone's throw"       │
│ ✓ "on the cards" (likely) ✗ "in the cards"          │
│ Memorise the idiom WITH its preposition as one unit.│
└─────────────────────────────────────────────────────┘
```

## Trick 12: The "3-Story-a-Day" Habit

```
┌─────────────────────────────────────────────────────┐
│ Learn only 3 idioms daily, but write one personal   │
│ sentence for each about YOUR life.                  │
│ "My friend is the apple of my mother's eye."        │
│ 3 × 30 days = 90 idioms — more than enough for      │
│ SSC/Railway/Bank exams. Self-made sentences stick   │
│ 5× longer than copied ones.                         │
└─────────────────────────────────────────────────────┘
```

## Trick 13: The "First-Letter Chain" for Confusing Pairs

```
┌─────────────────────────────────────────────────────┐
│ "To eat humble pie" = to apologise humbly           │
│ "To eat one's words" = to take back what you said   │
│ Chain: Humble pie → H for "Haath jodkar maafi";     │
│ Words → W for "Wapas lo apni baat".                 │
│ The first letter itself becomes the clue.           │
└─────────────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy (Exam Hall)

**Skip Tip 1 — The Unknown-Idiom Rule:**
If you have never seen the idiom before, do NOT spend 45 seconds decoding it word by word — idioms are not logical puzzles. Mark the option that is clearly NOT the literal meaning, flag the question, and move on. Return only if time remains.

**Skip Tip 2 — The 50-50 Rescue:**
When two options feel equally correct, check which one matches the idiom's emotional tone (positive/negative). E.g., "a feather in one's cap" is positive (an achievement) — eliminate any negative option instantly. If still stuck after 20 seconds, skip.

**Skip Tip 3 — Don't Overthink Familiar Idioms:**
If you know the idiom well, answer in 10–15 seconds and never change your answer on re-reading. Examiners plant "almost-right" options (e.g., "to work very hard" vs "to study late at night" for *burn the midnight oil*) — your first, trained instinct is usually correct. Over-thinking is the biggest trap in vocabulary questions.
