# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — काल (Tense)

---

## 🎯 15 म्नेमोनिक ट्रिक्स

### ट्रिक 1: "V1-V2-V3 का खेल"
```
┌─────────────────────────────────────────────┐
│ Present = V1 (go)                           │
│ Past = V2 (went)                            │
│ Perfect में = V3 (gone)                     │
│                                             │
│ याद रखो: "आज V1, कल V2, हो चुका V3"        │
└─────────────────────────────────────────────┘
```

### ट्रिक 2: "Since = बिंदु, For = रेखा"
```
┌─────────────────────────────────────────────┐
│ Since → समय का बिंदु (Point)                │
│   since Monday, since 2010, since 5 pm      │
│ For → समय की अवधि (Duration)                │
│   for two days, for five years              │
│                                             │
│ याद रखो: "Since सीधा बिंदु, For फैली रेखा"  │
└─────────────────────────────────────────────┘
```

### ट्रिक 3: "ING का जुगाड़"
```
┌─────────────────────────────────────────────┐
│ Continuous देखो → be + V-ing                │
│   is/am/are + ing → Present Continuous      │
│   was/were + ing → Past Continuous          │
│   will be + ing → Future Continuous         │
│                                             │
│ याद रखो: "ING दिखे, be साथ चले"             │
└─────────────────────────────────────────────┘
```

### ट्रिक 4: "Has-Have-Had = Perfect का परिवार"
```
┌─────────────────────────────────────────────┐
│ has/have + V3 → Present Perfect             │
│ had + V3 → Past Perfect                     │
│ will have + V3 → Future Perfect             │
│                                             │
│ याद रखो: "Perfect मतलब V3 पक्का"            │
└─────────────────────────────────────────────┘
```

### ट्रिक 5: "दो Past = Had पहले"
```
┌─────────────────────────────────────────────┐
│ एक वाक्य में दो Past क्रियाएँ हों तो:        │
│ पहले हुई क्रिया → Past Perfect (had + V3)   │
│ बाद वाली क्रिया → Simple Past (V2)          │
│                                             │
│ उदा: The train had left before I reached.   │
│ याद रखो: "पहले वाला Had, बाद वाला V2"       │
└─────────────────────────────────────────────┘
```

### ट्रिक 6: "Yesterday-Ago-Last = Simple Past"
```
┌─────────────────────────────────────────────┐
│ ये शब्द दिखें तो सीधे Simple Past (V2):     │
│ yesterday, ago, last night/week/year,       │
│ in 2010, the other day                      │
│                                             │
│ याद रखो: "YAL = Yesterday, Ago, Last → V2"  │
└─────────────────────────────────────────────┘
```

### ट्रिक 7: "Just-Already-Yet = Present Perfect"
```
┌─────────────────────────────────────────────┐
│ just, already, yet, recently, ever, never,  │
│ so far, lately दिखें → has/have + V3        │
│                                             │
│ याद रखो: "JAY-REN = Just Already Yet +      │
│ Recently Ever Never → Perfect"              │
└─────────────────────────────────────────────┘
```

### ट्रिक 8: "Universal Truth = हमेशा Present"
```
┌─────────────────────────────────────────────┐
│ सार्वभौमिक सत्य, वैज्ञानिक तथ्य, आदतें      │
│ → हमेशा Simple Present                      │
│   The sun rises in the east.                │
│   Water boils at 100°C.                     │
│                                             │
│ याद रखो: "सच कभी बूढ़ा नहीं होता — Present" │
└─────────────────────────────────────────────┘
```

### ट्रिक 9: "Tomorrow की तिकड़ी"
```
┌─────────────────────────────────────────────┐
│ tomorrow, next week, soon, shortly दिखें    │
│ → will/shall + V1                           │
│                                             │
│ याद रखो: "आने वाला कल = will + V1"          │
└─────────────────────────────────────────────┘
```

### ट्रिक 10: "While = Past Continuous का दोस्त"
```
┌─────────────────────────────────────────────┐
│ While + Past Continuous, Simple Past        │
│   While I was sleeping, the phone rang.     │
│                                             │
│ याद रखो: "While के साथ लंबी क्रिया ING में,  │
│ छोटी क्रिया V2 में"                          │
└─────────────────────────────────────────────┘
```

### ट्रिक 11: "By the time = Perfect का इशारा"
```
┌─────────────────────────────────────────────┐
│ by the time, by 2025, by tomorrow दिखें     │
│ → Perfect Tense                             │
│   By 2025, I will have completed my degree. │
│                                             │
│ याद रखो: "By मतलब समाप्ति = Perfect"        │
└─────────────────────────────────────────────┘
```

### ट्रिक 12: "No sooner...than / Hardly...when"
```
┌─────────────────────────────────────────────┐
│ No sooner had + Subject + V3 ... than       │
│ Hardly/Scarcely had + Subject + V3 ... when │
│                                             │
│ याद रखो: "No sooner का साथी than,           │
│ Hardly का साथी when"                         │
└─────────────────────────────────────────────┘
```

### ट्रिक 13: "Wish-If only = Past में सोचो"
```
┌─────────────────────────────────────────────┐
│ I wish / If only के बाद Past Tense          │
│ (वर्तमान की कल्पना के लिए भी!)              │
│   I wish I were a bird. (अभी की इच्छा)      │
│                                             │
│ याद रखो: "इच्छा कल्पना में, काल Past में"    │
└─────────────────────────────────────────────┘
```

### ट्रिक 14: "It is time + Past"
```
┌─────────────────────────────────────────────┐
│ It is time / It is high time के बाद V2      │
│   It is high time we left. (left = V2)      │
│                                             │
│ याद रखो: "Time आ गया तो V2 लगा दो"          │
└─────────────────────────────────────────────┘
```

### ट्रिक 15: "Perfect Continuous = Since/For + ING"
```
┌─────────────────────────────────────────────┐
│ since/for + समय + क्रिया जारी               │
│ → has/have been + V-ing                     │
│   She has been waiting since morning.       │
│                                             │
│ याद रखो: "Since/For + चल रहा काम =          │
│ been + ING"                                  │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

### टिप 1: दोहरे Perfect वाले लंबे वाक्य
अगर वाक्य में Past Perfect + Present Perfect दोनों के विकल्प मिलकर भ्रम पैदा कर रहे हों और समय-संकेतक (time marker) स्पष्ट न हो, तो पहले छोड़ें। अंत में लौटकर since/for/yesterday जैसे संकेतक खोजें — 90% मामलों में वही उत्तर तय करता है।

### टिप 2: Conditional-Mixed वाक्य (If clause)
अगर "If" वाला वाक्य mixed conditional (past condition + present result) पर आधारित लगे और आपको नियम याद न आए, तो 45 सेकंड से ज़्यादा न दें। ये प्रश्न foundation स्तर में कम आते हैं — पहले आसान प्रश्न निपटाएँ।

### टिप 3: बिना Time Marker वाला प्रश्न
जब वाक्य में कोई समय-संकेतक ही न हो और चारों विकल्प व्याकरणिक रूप से संभव लगें, तो अंदाज़ा न लगाएँ — छोड़ दें। ऐसे प्रश्नों में negative marking का जोखिम सबसे ज़्यादा होता है।
