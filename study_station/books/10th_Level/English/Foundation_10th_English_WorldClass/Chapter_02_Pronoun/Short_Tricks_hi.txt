# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — सर्वनाम (Pronoun)

## 🎯 12 म्नेमोनिक ट्रिक्स

```
┌─────────────────────────────────────────────┐
│ ट्रिक 1: "में-मुझे" का नियम (I vs Me)        │
│ "काम करे तो I, काम सहे तो Me"               │
│ कर्ता (काम करने वाला) → I, He, She, We, They│
│ कर्म (काम सहने वाला) → Me, Him, Her, Us, Them│
│ ✓ He and I went. (हम गए — कर्ता)            │
│ ✓ Between you and me. (हमारे बीच — कर्म)    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 2: "B-R-O" — Between का राज़           │
│ Between के बाद हमेशा Objective (कर्म) रूप!   │
│ Between you and ME (I नहीं!)                │
│ याद रखें: "बीच में मुझे" — me, him, her, us │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 3: "2-3-1 अच्छा, 1-2-3 बुरा"           │
│ अच्छे काम में क्रम: You(2) → He(3) → I(1)    │
│ ✓ You, he and I will win.                   │
│ बुरे काम/गलती में क्रम: I(1) → You(2) → He(3)│
│ ✓ I, you and he are guilty.                 │
│ याद रखें: "अच्छे में पीछे, बुरे में आगे"     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 4: "Each-Every-Either-Neither = E4"    │
│ E4 के साथ हमेशा Singular Verb + Singular     │
│ Pronoun (his/her, their नहीं!)              │
│ ✓ Each boy has done HIS work.               │
│ याद रखें: "E4 अकेला खिलाड़ी"                │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 5: "One का One"                        │
│ One से शुरू, तो One ही आगे — his/he नहीं!    │
│ ✓ One should do ONE'S duty.                 │
│ याद रखें: "वन-वन जोड़ी, हिज़ नहीं"           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 6: "Than-As के बाद I"                  │
│ तुलना में than/as के बाद Subjective रूप:     │
│ ✓ He is taller than I (am).                 │
│ (Me केवल तब जब अर्थ बदले: He loves her      │
│ more than me = मुझसे ज़्यादा उसे चाहता है)   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 7: "It का जादू"                        │
│ दूरी, मौसम, समय, पहचान → हमेशा IT            │
│ ✓ It is raining. ✓ It is 5 o'clock.        │
│ ✓ It is I who called. (पहचान बताना)         │
│ याद रखें: "मौसम-समय-दूरी, IT की पूरी"        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 8: "Who-Whom का Him-टेस्ट"             │
│ उत्तर Him/Me में आए → Whom                   │
│ उत्तर He/I में आए → Who                      │
│ Q: ___ did you meet? A: I met HIM → Whom    │
│ Q: ___ came? A: HE came → Who               │
│ याद रखें: "M से M — Whom-Him दोनों में M"    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 9: "Enjoy के बाद Self"                 │
│ Enjoy, Avail, Absent, Pride के बाद           │
│ Reflexive Pronoun ज़रूरी (object न हो तो):   │
│ ✓ He enjoyed HIMSELF.                       │
│ याद रखें: "मज़े करो, खुद को जोड़ो"           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 10: "Same के साथ That/As"              │
│ The same ___ that/as — who/which नहीं!       │
│ ✓ This is the same book that I lost.        │
│ याद रखें: "Same का साथी That"                │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 11: "None = Not One"                   │
│ None अकेला → Singular मानें (परीक्षा में):    │
│ ✓ None of the boys WAS present.             │
│ (None but + Singular → Singular verb)       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 12: "Relative से पहले Comma नहीं"      │
│ Who/Which/That से पहले preposition आए तो:    │
│ ✓ The man TO WHOM I spoke. (to who ✗)       │
│ That के साथ preposition पहले कभी नहीं:       │
│ ✓ The house that I live in. (in that ✗)     │
└─────────────────────────────────────────────┘
```

## ⏭️ स्किप रणनीति (कब प्रश्न छोड़ें)

**🚩 स्किप नियम 1 — "दोनों सही लगें तो रुको":**
I/Me या Who/Whom में दो विकल्प दोनों सही लग रहे हों और 30 सेकंड में ट्रिक (Him-टेस्ट / कर्ता-कर्म परीक्षण) से फैसला न हो, तो प्रश्न मार्क करके आगे बढ़ें। अंत में लौटकर वाक्य को ज़ोर से मन में बोलकर सुनें — कान अक्सर सही पकड़ लेते हैं।

**🚩 स्किप नियम 2 — "लंबा Intervening Phrase वाला प्रश्न":**
"Each of the boys, along with his friends and neighbours, ___ (has/have)..." जैसे प्रश्न में बीच का पूरा हिस्सा काटकर (strike-through) पढ़ें। असली subject "Each" है → has। अगर subject पहचानने में 20 सेकंड से ज़्यादा लगें, तो स्किप करें — यह परीक्षक का समय-खाने वाला जाल है।

**🚩 स्किप नियम 3 — "अपरिचित Formal Structure":**
"It is I who am responsible" जैसे formal/शुद्ध व्याकरणिक प्रश्न जो पहले कभी practice न किए हों — अंदाज़ा न लगाएँ। Negative marking में अनजान नियम पर टिक लगाना घाटे का सौदा है। पहले वे प्रश्न निपटाएँ जो ऊपर की 12 ट्रिक्स से सीधे हल हों (ये 15-सेकंड वाले हैं), फिर बचे समय में जटिल वालों पर लौटें।
