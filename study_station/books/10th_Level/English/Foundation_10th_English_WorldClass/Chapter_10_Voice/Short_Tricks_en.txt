# 🪄 Short Tricks + Skip Strategy — Active & Passive Voice

---

## Trick 1: The "BY Test" — Spot Passive in 2 Seconds

```
┌─────────────────────────────────────────────┐
│  If you can add "by someone" at the end     │
│  and the sentence still makes sense →       │
│  it is PASSIVE.                             │
│                                             │
│  "The cake was eaten (by someone)." ✔       │
│  "The cake ate." ✘ (no sense → Active)      │
└─────────────────────────────────────────────┘
```

---

## Trick 2: The Golden Formula — "BE + V3"

```
┌─────────────────────────────────────────────┐
│  Passive = Object + BE (is/am/are/was/were/ │
│  been/being) + V3 (Past Participle)         │
│                                             │
│  No V3 after BE → NOT passive.              │
│  "He is running" → Active (V-ing, not V3)   │
│  "He is praised" → Passive (V3) ✔           │
└─────────────────────────────────────────────┘
```

---

## Trick 3: Mnemonic — "SOB" for Conversion

```
┌─────────────────────────────────────────────┐
│  S → O → B                                  │
│  Subject becomes Object,                    │
│  Object becomes Subject,                    │
│  Verb becomes BE + V3.                      │
│                                             │
│  "Ram (S) eats (V) mangoes (O)."            │
│  → "Mangoes (S) are eaten (B) by Ram (O)."  │
└─────────────────────────────────────────────┘
```

---

## Trick 4: Tense-Helper Swap Table (Memorize Once, Score Forever)

```
┌─────────────────────────────────────────────┐
│  Present Simple   → is/am/are + V3          │
│  Past Simple      → was/were + V3           │
│  Future Simple    → will be + V3            │
│  Present Cont.    → is/am/are BEING + V3    │
│  Past Cont.       → was/were BEING + V3     │
│  Present Perfect  → has/have BEEN + V3      │
│  Past Perfect     → had BEEN + V3           │
│  Modals           → modal + BE + V3         │
│  Modal Perfect    → modal + have BEEN + V3  │
└─────────────────────────────────────────────┘
```

---

## Trick 5: Mnemonic — "Being is for -ing, Been is for -n (Perfect)"

```
┌─────────────────────────────────────────────┐
│  Continuous tense (-ing) → use BEING        │
│  Perfect tense (has/had) → use BEEN         │
│                                             │
│  "is being built" (continuous)              │
│  "has been built" (perfect)                 │
└─────────────────────────────────────────────┘
```

---

## Trick 6: The "Double Object" Rule — Start with Either

```
┌─────────────────────────────────────────────┐
│  "She gave ME a BOOK." (two objects)        │
│  Passive 1: I was given a book by her.      │
│  Passive 2: A book was given to me by her.  │
│  Both correct! Examiner tests the "to/for"  │
│  before the person in Passive 2.            │
└─────────────────────────────────────────────┘
```

---

## Trick 7: Preposition Stick Rule

```
┌─────────────────────────────────────────────┐
│  Verb + fixed preposition → preposition     │
│  STICKS to the verb in passive.             │
│                                             │
│  "They laughed at him."                     │
│  → "He was laughed AT by them." ✔           │
│  Never drop the "at"!                       │
└─────────────────────────────────────────────┘
```

---

## Trick 8: Imperative Sentences — "Let + be + V3"

```
┌─────────────────────────────────────────────┐
│  "Open the door."                           │
│  → "Let the door BE opened."                │
│  "Do not insult the poor."                  │
│  → "Let the poor not BE insulted."          │
│  Mnemonic: "Orders need LET-BE"             │
└─────────────────────────────────────────────┘
```

---

## Trick 9: Infinitive Passive — "to be + V3"

```
┌─────────────────────────────────────────────┐
│  "I want someone to help me."               │
│  → "I want to BE helped."                   │
│  Active "to + V1" → Passive "to be + V3"    │
└─────────────────────────────────────────────┘
```

---

## Trick 10: Drop the Doer — "Unknown Agent" Trick

```
┌─────────────────────────────────────────────┐
│  If the doer is unknown/obvious/unimportant │
│  (someone, people, they, police) → DROP     │
│  "by + agent" in passive.                   │
│                                             │
│  "Someone stole my bike."                   │
│  → "My bike was stolen." (no "by someone")  │
└─────────────────────────────────────────────┘
```

---

## Trick 11: "Quasi-Passive" Trap — Verbs That Never Take Passive

```
┌─────────────────────────────────────────────┐
│  Intransitive verbs (no object) = NO passive│
│  happen, occur, die, sleep, come, go, run   │
│                                             │
│  "The accident was happened." ✘ WRONG       │
│  "The accident happened." ✔                 │
│  Mnemonic: "No object, no passive."         │
└─────────────────────────────────────────────┘
```

---

## Trick 12: "It is said that…" — Reporting Verbs Trick

```
┌─────────────────────────────────────────────┐
│  "People say that he is honest."            │
│  → "It is said that he is honest."          │
│  → "He is said to be honest."               │
│  Both forms accepted — examiners love this! │
└─────────────────────────────────────────────┘
```

---

## Trick 13: "Get-Passive" Recognition

```
┌─────────────────────────────────────────────┐
│  "He got selected." = "He was selected."    │
│  GET + V3 is informal passive — recognize   │
│  it, but in formal conversion use BE + V3.  │
└─────────────────────────────────────────────┘
```

---

## Trick 14: 15-Second Elimination Scan

```
┌─────────────────────────────────────────────┐
│  In options, instantly REJECT any passive   │
│  that:                                      │
│  1. Lacks BE (is/was/been/being)            │
│  2. Uses V2 instead of V3 ("was wrote" ✘)   │
│  3. Changes the tense of the original       │
│  Usually 2 of 4 options die in this scan!   │
└─────────────────────────────────────────────┘
```

---

## Trick 15: Mnemonic — "W-W-B" for Past Passive

```
┌─────────────────────────────────────────────┐
│  Was / Were + V3 = past simple passive      │
│  "Was-Were-Been" — the three W-B brothers:  │
│  was/were (simple), being (continuous),     │
│  been (perfect). One family, three jobs.    │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy

**Tip 1 — Skip the double-object puzzle (45+ sec):** If a question gives a sentence with two objects AND asks which passive is correct with tricky "to/for" placement, and you haven't revised it — mark it, attempt the direct tense-conversion questions first, and return only if time remains.

**Tip 2 — Skip "sound-right" traps:** Options like "The letter has wrote by him" *feel* wrong instantly if you run the BE + V3 scan. Never spend more than 15 seconds here — if no option has correct BE + V3, re-read; don't over-think.

**Tip 3 — Skip rare-structure questions on first pass:** Questions on "It is said that…" or modal-perfect passive ("should have been done") are 45-second inference-type. If the structure looks unfamiliar, flag it and finish the easy 15-second fact-based conversions (simple present/past/future) first — they carry the same marks.
