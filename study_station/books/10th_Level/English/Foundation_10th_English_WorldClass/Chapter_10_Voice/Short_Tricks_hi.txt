# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — वाच्य (Voice)

---

## 🎯 15 म्नेमोनिक ट्रिक्स

---

**ट्रिक 1 — "B-V3" मंत्र (Passive की पहचान)**

```
┌─────────────────────────────────────────────┐
│  Passive = Be + V3                          │
│  "बी के साथ V3, समझो Passive तैयार"          │
│  is/am/are/was/were/been/being + V3         │
│  → यह जोड़ी दिखते ही Passive पक्का!          │
└─────────────────────────────────────────────┘
```
उदाहरण: The letter **was written** (was + V3) → Passive ✔

---

**ट्रिक 2 — "सोना-सुलाना" ट्रिक (Subject ↔ Object की अदला-बदली)**

```
┌─────────────────────────────────────────────┐
│  Active → Passive में:                       │
│  Object सो जाओ Subject की जगह,              │
│  Subject सो जाओ by के पीछे!                  │
│  "आगे वाला पीछे, पीछे वाला आगे"              │
└─────────────────────────────────────────────┘
```
Ram (S) eats a mango (O) → A **mango** is eaten **by Ram**.

---

**ट्रिक 3 — "Tense नहीं बदलता, सिर्फ़ रूप बदलता है"**

```
┌─────────────────────────────────────────────┐
│  Voice बदलो, Tense वही रहे!                  │
│  is eating → is being eaten (दोनों Present   │
│  Continuous — Tense समान, रूप अलग)           │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 4 — "BYE-3" ट्रिक (by + agent कब छोड़ें)**

```
┌─────────────────────────────────────────────┐
│  BYE कह दो "by + agent" को जब कर्ता हो:      │
│  B = Broad (सामान्य: people, someone)        │
│  Y = Yourself स्पष्ट (police, teacher)       │
│  E = Extra/अनावश्यक जानकारी                  │
│  → Someone stole my watch.                   │
│  → My watch was stolen. (by someone हटाओ!)   │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 5 — "मोदीजी की फैमिली" (Modals का Passive)**

```
┌─────────────────────────────────────────────┐
│  Modal + be + V3                             │
│  can/could/shall/should/will/would/          │
│  may/might/must + be + V3                    │
│  "मोदी (Modal) के बाद बी (be), फिर V3"       │
└─────────────────────────────────────────────┘
```
He can solve it → It can **be solved** (by him).

---

**ट्रिक 6 — "Double Object = दो रास्ते"**

```
┌─────────────────────────────────────────────┐
│  give/send/teach/show जैसी क्रिया के         │
│  दो Objects हों तो Passive भी दो बनते हैं!   │
│  She gave me a book.                         │
│  ① I was given a book. (person आगे)          │
│  ② A book was given to me. (thing आगे)       │
│  याद रखें: person आगे = बिना to;             │
│  thing आगे = to/for लगेगा!                   │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 7 — "Let का जादू"**

```
┌─────────────────────────────────────────────┐
│  Let + object + be + V3                      │
│  Open the door.                              │
│  → Let the door be opened.                   │
│  "Let लगाओ, be+V3 जोड़ो, Imperative Passive  │
│  तैयार!"                                     │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 8 — "It is said ट्रिक" (say/believe/know/report)**

```
┌─────────────────────────────────────────────┐
│  People say that he is honest.               │
│  ① It is said that he is honest.             │
│  ② He is said to be honest.                  │
│  "It से शुरू या Subject + to + V1"           │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 9 — "Preposition चिपकी रहती है"**

```
┌─────────────────────────────────────────────┐
│  look at, laugh at, listen to, look after    │
│  → Passive में preposition क्रिया के साथ ही!  │
│  She looks after the child.                  │
│  → The child is looked after (by her).       │
│  ❌ The child is looked. (गलत!)              │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 10 — "Quasi-Passive चेतावनी"**

```
┌─────────────────────────────────────────────┐
│  कुछ वाक्य दिखते Active, मतलब Passive:       │
│  • Honey tastes sweet.                       │
│  • The book sells well.                      │
│  • Rice sells cheap.                         │
│  इन्हें Passive में मत बदलो — ये पहले से     │
│  Passive-भाव वाले हैं!                       │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 11 — "Intransitive = No Passive"**

```
┌─────────────────────────────────────────────┐
│  जिस क्रिया का Object नहीं, उसका Passive     │
│  नहीं! (go, come, sleep, die, run, cry)      │
│  He sleeps. → ❌ Passive संभव नहीं           │
│  "Object नहीं तो Passive नहीं — सीधा SKIP!"  │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 12 — "has/have + been" यादगार जोड़ी**

```
┌─────────────────────────────────────────────┐
│  Present Perfect Passive:                    │
│  has/have + been + V3                        │
│  Past Perfect Passive: had + been + V3       │
│  "Perfect में been ज़रूरी —                   │
│  been भूले तो पूरा प्रश्न गया!"              │
└─────────────────────────────────────────────┘
```
He has written a letter → A letter has **been** written.

---

**ट्रिक 13 — "Continuous में being"**

```
┌─────────────────────────────────────────────┐
│  is/am/are + being + V3  (Present Cont.)     │
│  was/were + being + V3   (Past Cont.)        │
│  "Continuous की पहचान -ing,                  │
│  Passive की पहचान being!"                    │
└─────────────────────────────────────────────┘
```
She is cooking food → Food is **being** cooked.

---

**ट्रिक 14 — "Who/Whom परिवर्तन"**

```
┌─────────────────────────────────────────────┐
│  Who teaches you? (Active)                   │
│  → By whom are you taught?                   │
│  → Who are you taught by?                    │
│  "Who → By whom / Who...by"                  │
│  Whom से शुरू Active → Who से शुरू Passive   │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 15 — "Get-Passive झटपट पहचान"**

```
┌─────────────────────────────────────────────┐
│  get + V3 भी Passive होता है (informal):     │
│  He got selected. = He was selected.         │
│  परीक्षा में "got + V3" दिखे तो घबराएँ नहीं  │
│  — यह भी सही Passive है!                     │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**स्किप 1 — Quasi-Passive / Intransitive वाला प्रश्न**
विकल्पों में "Honey tastes sweet" या "He died" जैसे वाक्य दिखें और पूछा हो "किसका Passive संभव है?" — अगर 15 सेकंड में Object की पहचान न हो, तो **छोड़ दें**। यहाँ जल्दबाज़ी में गलती लगभग तय है। बाद में शांत दिमाग से Object खोजें।

**स्किप 2 — Double Passive / जटिल Reported वाक्य**
"People believe that he was killed..." जैसे दोहरे ढाँचे वाले प्रश्न में दो संभावित Passive बनते हैं। अगर दोनों विकल्पों में बारीक अंतर (to be / to have been) समझ न आए, तो **पहले छोड़ें**, अंत में "It is believed that..." वाला सुरक्षित रूप चुनकर आएँ।

**स्किप 3 — Imperative + Negative मिश्रित प्रश्न**
"Do not insult the poor" जैसे वाक्यों में "Let the poor not be insulted" बनाम "The poor should not be insulted" — दोनों लुभावने लगते हैं। यदि Let-नियम तुरंत याद न आए तो **मार्क करके आगे बढ़ें**; यह 45-सेकंड वाला तार्किक प्रश्न है, 15-सेकंड में दांव न लगाएँ।
