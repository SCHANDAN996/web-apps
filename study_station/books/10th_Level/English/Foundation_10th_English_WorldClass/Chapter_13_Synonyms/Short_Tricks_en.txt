# 🪄 Short Tricks + Skip Strategy — Synonyms

## Trick 1: The "Replace & Read" Test
```
┌─────────────────────────────────────────────┐
│ Don't just match meanings — REPLACE the     │
│ word in the sentence and READ it aloud.     │
│ If the sentence still sounds natural,       │
│ that's your synonym.                        │
│ "He was CANDID" → "He was HONEST" ✓         │
└─────────────────────────────────────────────┘
```

## Trick 2: The Root Decoder
```
┌─────────────────────────────────────────────┐
│ Unknown word? Break it into roots:          │
│ BENE = good  → benefit, benevolent          │
│ MAL  = bad   → malice, malfunction          │
│ CRED = believe → credible, incredible       │
│ DICT = speak → predict, dictate             │
│ PORT = carry → transport, export            │
│ Many tough exam words can be decoded with   │
│ a small set of common roots like these.     │
└─────────────────────────────────────────────┘
```

## Trick 3: The Positive–Negative Filter
```
┌─────────────────────────────────────────────┐
│ Feel the word's CHARGE first:               │
│ "Frugal" = positive/neutral → "thrifty" ✓   │
│                not "miserly" (negative) ✗   │
│ Eliminate options with the wrong charge     │
│ BEFORE checking exact meaning.              │
└─────────────────────────────────────────────┘
```

## Trick 4: Mnemonic — "ABANDON the BAND"
```
┌─────────────────────────────────────────────┐
│ ABANDON = leave, give up                    │
│ Trick: The BAND left (abandoned) the stage. │
│ Synonyms: forsake, desert, relinquish       │
└─────────────────────────────────────────────┘
```

## Trick 5: Mnemonic — "CANDID Camera"
```
┌─────────────────────────────────────────────┐
│ CANDID = frank, honest                      │
│ Trick: A candid camera catches the TRUTH.   │
│ Synonyms: frank, open, straightforward      │
└─────────────────────────────────────────────┘
```

## Trick 6: Mnemonic — "OBSOLETE = OLD-LETE"
```
┌─────────────────────────────────────────────┐
│ OBSOLETE = outdated, no longer used         │
│ Trick: "It's OLD, LET it go" → obsolete.    │
│ Synonyms: outdated, archaic, antiquated     │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TIMID = shy, fearful                        │
│ Trick: Timid Tim hides behind the door.     │
│ Synonyms: shy, nervous, apprehensive        │
└─────────────────────────────────────────────┘
```

## Trick 8: Mnemonic — "VIVID Video"
```
┌─────────────────────────────────────────────┐
│ VIVID = bright, clear, lively               │
│ Trick: A VIVID video = bright HD picture.   │
│ Synonyms: bright, graphic, striking         │
└─────────────────────────────────────────────┘
```

## Trick 9: Mnemonic — "ZENITH = Z-Top"
```
┌─────────────────────────────────────────────┐
│ ZENITH = highest point                      │
│ Trick: Z is the LAST/top letter → the peak. │
│ Synonyms: peak, summit, apex                │
│ (Opposite pair: NADIR = lowest point)       │
└─────────────────────────────────────────────┘
```

## Trick 10: Mnemonic — "EPHEMERAL = A Mere While"
```
┌─────────────────────────────────────────────┐
│ EPHEMERAL = short-lived                     │
│ Trick: "Eph-emeral" sounds like "a mere     │
│ while" — lasting only a mere while.         │
│ Synonyms: temporary, fleeting, transient    │
└─────────────────────────────────────────────┘
```

## Trick 11: The Degree Ladder
```
┌─────────────────────────────────────────────┐
│ Synonyms differ in INTENSITY. Pick the one  │
│ matching the sentence's strength:           │
│ happy → delighted → ecstatic                │
│ angry → furious → enraged                   │
│ big → large → enormous                      │
│ "Enraged" is NOT a synonym of "annoyed".    │
└─────────────────────────────────────────────┘
```

## Trick 12: The Word-Family Check
```
┌─────────────────────────────────────────────┐
│ Match the PART OF SPEECH:                   │
│ Word: "beautify" (verb)                     │
│ ✓ adorn (verb)  ✗ beautiful (adjective)     │
│ Examiners love mixing noun/verb/adjective   │
│ forms of the same root as traps.            │
└─────────────────────────────────────────────┘
```

## Trick 13: The Elimination Ladder (15-Second Routine)
```
┌─────────────────────────────────────────────┐
│ Step 1: Know the word? → answer directly.   │
│ Step 2: Don't know it? → root decode.       │
│ Step 3: Still stuck? → charge filter (+/−). │
│ Step 4: Eliminate 2 wrong → 50% guess.      │
│ Never leave blank if 2 options are out.     │
└─────────────────────────────────────────────┘
```

## Trick 14: The Confusable-Pairs Alarm
```
┌─────────────────────────────────────────────┐
│ Examiners recycle these look-alikes:        │
│ • Elicit (draw out) ≠ Illicit (illegal)     │
│ • Affect (usually a verb: to influence)     │
│   ≠ Effect (usually a noun: a result)       │
│ • Compliment (praise) ≠ Complement (complete)│
│ • Principal (chief) ≠ Principle (rule)      │
│ Learn the PAIR, not just the single word.   │
└─────────────────────────────────────────────┘
```

## Trick 15: The Context Anchor
```
┌─────────────────────────────────────────────┐
│ In sentence-based synonym questions, the    │
│ words AROUND the target word are clues:     │
│ "The ARID desert…" → dry, barren ✓          │
│ (desert = dry context)                      │
│ Read the full sentence, never the word alone│
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy

**Skip Tip 1 — The 20-Second Wall:**
If after 20 seconds you cannot eliminate even one option, mark the question and move on. Synonym questions are pure recall — staring longer will not "unlock" a word you don't know. Return only if time remains.

**Skip Tip 2 — Don't Overthink Known Words:**
If you instantly know the answer, mark it and go. Re-reading all four options on an easy word invites the "Sound-Right Trap" — a fancy unfamiliar option starts looking attractive. Your first recall is usually correct.

**Skip Tip 3 — Negative-Marking Maths:**
In exams with negative marking (e.g., −0.25), guess only when you can eliminate **at least two** options. A blind 4-way guess loses marks over time; a 2-way guess is statistically safer. When in doubt between "guess" and "skip" — count your eliminations first.
