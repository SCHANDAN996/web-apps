# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — क्रियाविशेषण (Adverb)

## 🎯 15 म्नेमोनिक ट्रिक्स

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 1: "कैसे-कब-कहाँ-कितना" = Adverb की पहचान        │
│ किसी भी शब्द से ये 4 सवाल पूछो —                        │
│ HOW? (कैसे) WHEN? (कब) WHERE? (कहाँ) HOW MUCH? (कितना) │
│ जो शब्द इनमें से किसी का जवाब दे, वही Adverb है।        │
│ जैसे: He runs FAST → कैसे दौड़ता है? तेज़ = Adverb     │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 2: "LY लगाओ, विशेषण बनाओ" — उल्टा याद रखो!        │
│ Adjective + ly = Adverb                                  │
│ quick → quickly, slow → slowly, happy → happily          │
│ ⚠️ लेकिन हर -ly वाला शब्द Adverb नहीं!                  │
│ friendly, costly, lonely, lovely = Adjective हैं!        │
│ याद करो: "FCLL — Friendly Costly Lonely Lovely"          │
│ ये चारों परीक्षक के पसंदीदा जाल हैं।                    │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 3: "FAST-HARD-LATE" — बदलते नहीं!                  │
│ कुछ शब्दों का Adjective और Adverb एक जैसा होता है:      │
│ fast → fast (❌ fastly नहीं होता)                        │
│ hard → hard (❌ hardly = मुश्किल से, अर्थ बदल जाता है)   │
│ late → late (❌ lately = हाल ही में, अर्थ अलग)           │
│ याद करो: "तेज़-मेहनती-देर वाला बदलता नहीं"              │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 4: "Hard vs Hardly" का जादू                        │
│ He works HARD = वह कड़ी मेहनत करता है                   │
│ He HARDLY works = वह मुश्किल से ही काम करता है           │
│ ट्रिक: "Hardly आया तो मेहनत गायब"                       │
│ इसी जोड़ी में: late/lately, near/nearly, free/freely    │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 5: "Enough की सीट" — आगे-पीछे का नियम             │
│ Adjective/Adverb + enough (पीछे): good enough, fast enough│
│ enough + Noun (आगे): enough money, enough time           │
│ याद करो: "NA के साथ enough पीछे, Noun के साथ आगे"       │
│ ❌ enough good  ✅ good enough                           │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 6: "Very-Much-Too" तीनों भाई                       │
│ VERY = बहुत (सकारात्मक): very good                       │
│ TOO = ज़रूरत से ज़्यादा (नकारात्मक): too hot to drink    │
│ MUCH = तुलना/भूतकाल के साथ: much better, much surprised  │
│ ट्रिक: "Very खुशी, Too परेशानी, Much तुलना"              │
│ ❌ too good (जब तक नकारात्मक अर्थ न हो)                  │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 7: "Only की कुर्सी बदली, अर्थ बदल गया"             │
│ Only he lent me ₹100 = केवल उसने दिए (कोई और नहीं)       │
│ He only lent me ₹100 = उधार दिए, गिफ्ट नहीं              │
│ He lent me only ₹100 = सिर्फ़ 100, ज़्यादा नहीं          │
│ नियम: Only उसी शब्द के ठीक पहले रखो जिसे सीमित करना है।  │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 8: "MPT क्रम" — कई Adverb एक साथ हों तो            │
│ क्रम: Manner → Place → Time (कैसे → कहाँ → कब)           │
│ She sang beautifully (M) in the hall (P) yesterday (T).  │
│ याद करो: "मैडम पहले ताली बजाएँ" = M-P-T                  │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 9: "Seldom, Rarely, Hardly, Scarcely = नकारात्मक"  │
│ इनके साथ not/never/doesn't दोबारा मत लगाओ!               │
│ ❌ He does not hardly work.                              │
│ ✅ He hardly works.                                      │
│ ट्रिक: "SRHS — एक ही नकारात्मक काफी है"                  │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 10: "Else + but" की जोड़ी                          │
│ ❌ He did nothing else than complain.                    │
│ ✅ He did nothing else but complain.                     │
│ याद करो: "Else का साथी but है, than नहीं"                │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 11: "So/Too + that" की जोड़ियाँ                    │
│ too ... to = इतना ... कि (नहीं सका): too weak to walk    │
│ so ... that = इतना ... कि: so weak that he fell          │
│ ट्रिक: "Too के साथ to, So के साथ that"                   │
│ ❌ too weak that...  ✅ too weak to...                   │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 12: "Fairly vs Rather" — अच्छा-बुरा बंटवारा        │
│ FAIRLY = सुखद चीज़ों के साथ: fairly good, fairly well    │
│ RATHER = दुखद/बुरी चीज़ों के साथ: rather bad, rather rude│
│ ट्रिक: "Fair = फेयर (अच्छा), Rather = रद्दी (बुरा)"      │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 13: "Ago vs Before" — समय का पेंच                  │
│ AGO = अभी से पीछे (Past Tense के साथ): two days ago      │
│ BEFORE = किसी और घटना से पहले: I had met him before.     │
│ ट्रिक: "Ago अकेला, Before रिश्तेदार"                     │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 14: "Adverb की जगह" — Frequency वाले बीच में       │
│ always, usually, often, never, seldom →                  │
│ मुख्य क्रिया से पहले: He always comes late.              │
│ is/am/are/was/were के बाद: He is always late.            │
│ ट्रिक: "क्रिया से पहले, 'होना' के बाद"                   │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 15: "No sooner...than / Hardly...when /            │
│ Scarcely...when" — तीनों की अपनी जोड़ी                   │
│ ❌ No sooner had he come when...                         │
│ ✅ No sooner had he come than...                         │
│ याद करो: "No sooner का than, बाकी दोनों का when"         │
└─────────────────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

```
┌─────────────────────────────────────────────────────────┐
│ स्किप टिप 1: "Only की जगह" वाला प्रश्न                   │
│ अगर वाक्य में only की position बदलकर अर्थ पूछा गया है    │
│ और सभी विकल्प लगभग एक जैसे दिख रहे हैं — पहली बारी में │
│ छोड़ दो। ये प्रश्न 45+ सेकंड खा जाते हैं और गलती की     │
│ संभावना सबसे ज़्यादा होती है। दूसरे राउंड में आराम से    │
│ हर विकल्प का अर्थ बदलकर देखो।                            │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ स्किप टिप 2: "दोनों सही लग रहे हैं" स्थिति               │
│ hardly/scarcely वाले प्रश्नों में अगर दो विकल्प          │
│ ग्रामर-दृष्टि से सही लगें (जैसे hardly...when और         │
│ scarcely...when दोनों), तो वाक्य का TENSE देखो —         │
│ Past Perfect + Simple Past की जोड़ी जाँचो। फिर भी शक हो  │
│ तो mark करके आगे बढ़ो, अटकना नहीं।                       │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ स्किप टिप 3: "Sound-Right जाल" में फँसो तो               │
│ fastly, hardly work करता है, enough good — ये सुनने में  │
│ सही लगते हैं। अगर कोई विकल्प "कान को सही" लगे लेकिन     │
│ नियम याद न आए, तो उसे तुरंत टिक मत करो — यही परीक्षक का │
│ जाल है। 15 सेकंड में नियम याद न आए तो स्किप करो,         │
│ अंत में "LY-नियम" और "Enough-नियम" लगाकर हल करो।         │
└─────────────────────────────────────────────────────────┘
```

## ⚡ अंतिम 30-सेकंड रिवीजन मंत्र

> **"LY लगाओ पर FCLL बचाओ, Hard-Hardly में अर्थ बदलाओ, Enough को NA के पीछे बिठाओ, SRHS के साथ not हटाओ, Only को सही कुर्सी पर पाओ, MPT क्रम अपनाओ — Adverb का प्रश्न पक्का बनाओ!"**
