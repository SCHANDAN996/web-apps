# 🪄 Short Tricks + Skip Strategy — Adverb

## Memory Boxes (Mnemonics)

┌─────────────────────────────────────────────┐
│ TRICK 1 — "HOW? WHEN? WHERE? HOW MUCH?"     │
│ An adverb answers one of these 4 questions  │
│ about the verb. Ask the question → find the │
│ adverb.                                     │
│ He ran quickly. (Ran HOW? → quickly)        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 2 — "MPT" Order of Adverbs            │
│ When many adverbs sit together:             │
│ Manner → Place → Time                       │
│ She sang beautifully (M) in the hall (P)    │
│ yesterday (T).                              │
│ Memory hook: "My Pet Tiger"                 │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 3 — "LY is NOT a Guarantee"           │
│ Friendly, lonely, costly, lively, orderly,  │
│ cowardly, scholarly = ADJECTIVES (not       │
│ adverbs) despite ending in -ly!             │
│ Hook: "Friendly Lonely Costly — LY liars!"  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 4 — "FAST-HARD-LATE-EARLY"            │
│ Same word = adjective AND adverb.           │
│ a fast train / he runs fast                 │
│ hard work / he works hard                   │
│ Never say "fastly" or "hardly" for these!   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 5 — "HARD vs HARDLY"                  │
│ hard = with effort | hardly = almost not    │
│ He works hard. (puts in effort)             │
│ He hardly works. (almost doesn't work)      │
│ Same pair: late/lately, near/nearly.        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 6 — "VERB ke baad, ADJECTIVE nahi"    │
│ Action verb + adverb; Linking verb +        │
│ adjective.                                  │
│ She sings sweetly. (action → adverb)        │
│ The song sounds sweet. (linking → adj)      │
│ Linking verbs: is/are/seem/look/feel/taste/ │
│ smell/sound/appear.                         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 7 — "Only = Chameleon"                │
│ "Only" changes meaning with position. Keep  │
│ it just before the word it modifies.        │
│ Only he lent me ₹100. (nobody else)         │
│ He lent me only ₹100. (not more)            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 8 — "Enough comes AFTER"              │
│ adjective/adverb + enough (enough AFTER).   │
│ He is tall enough. ✔                        │
│ He is enough tall. ✘                        │
│ But with a noun, enough comes BEFORE:       │
│ enough money, enough time ✔                 │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 9 — "Too = Trouble"                   │
│ "too" = more than needed (negative sense).  │
│ "very" = simply a high degree.              │
│ It is very hot. (fine)                      │
│ It is too hot to go out. (problem)          │
│ too…to = so…that…cannot                     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 10 — "Seldom, Never, Hardly = NO NOT" │
│ Negative adverbs already carry "not".       │
│ He seldom goes there. ✔                     │
│ He does not seldom go there. ✘              │
│ Double negative = double trouble!           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 11 — "Much-Very, Very-Much"           │
│ very + positive degree (very tall)          │
│ much + comparative degree (much taller)     │
│ very much + verb (I like it very much)      │
│ Hook: "Very Positive, Much Comparative"     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 12 — "Ago vs Before"                  │
│ ago = from NOW, with simple past.           │
│ before = from a past point, with past       │
│ perfect.                                    │
│ I met him two days ago.                     │
│ I had met him two days before.              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ TRICK 13 — "Adverb of Frequency = Mid Seat" │
│ always, usually, often, seldom, never sit   │
│ BEFORE the main verb, AFTER 'be' verb.      │
│ He always comes late.                       │
│ He is always late.                          │
└─────────────────────────────────────────────┘

## ⏭️ Skip Strategy

**Tip 1 — Skip the "position puzzle" on first pass.**
Questions asking "where should 'only/enough' be placed in this long sentence?" need careful re-reading of every option. If the sentence is 3+ lines, mark it and return after finishing the quick spot-the-error questions. These are 45-second questions, not 15-second ones.

**Tip 2 — Skip when two options both "sound right".**
If your ear cannot decide between "He works hard" and "He works hardly", do not guess by sound — recall the rule (Trick 5). If you cannot recall the rule in 10 seconds, skip and come back. Sound-based guessing is exactly the examiner's trap.

**Tip 3 — Never skip a "find the adverb" recall question.**
Direct questions like "Which word is an adverb?" or "Identify the type of adverb" are pure 15-second fact questions — attempt them first, bank the marks, and save your time for the tricky sentence-improvement ones.
