```
│  MNEMONIC: "BEST FRIENDS FIGHT"             │
```

## Trick 2: Negative Prefix = Instant Antonym

```
┌─────────────────────────────────────────────┐
│  MNEMONIC: "UN-IN-IM-DIS — the 4 Destroyers"│
│  UN-  : happy → unhappy                     │
│  IN-  : active → inactive                   │
│  IM-  : possible → impossible (before p/b/m)│
│  DIS- : honest → dishonest                  │
│  Rule: IM before lips-sounds (P, B, M) —    │
│  "IM kisses the lips!"                      │
└─────────────────────────────────────────────┘
```


## ⏭️ Skip Strategy — When to Move On

**Tip 1: The 15-Second Rule**
If you know the word's meaning instantly, answer in 15 seconds. Antonym questions are fact-based — you either know the word or you don't. Do NOT re-read the options 4 times; your first instinct on vocabulary is usually right.

**Tip 2: The "Unknown Word" Skip**
If the given word is completely unfamiliar AND you cannot break it into roots/prefixes, mark it and skip. Spending 90 seconds guessing one antonym costs you three easy questions elsewhere. Return only if time remains.

**Tip 3: The "Two Close Options" Trap Exit**
When two options both look like opposites (e.g., "cruel" vs "harsh" for *kind*), don't freeze. Pick the STRONGER opposite (cruel) — examiners prefer the clearest contrast — and move on within 45 seconds. Never leave it blank if there is no negative marking; never gamble blindly if there is.
