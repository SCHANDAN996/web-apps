# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — Preposition

## 🎯 12 म्नेमोनिक ट्रिक्स (बॉक्स में)

```
┌─────────────────────────────────────────────┐
│ ट्रिक 1: "समय में IN-ON-AT"                  │
│ बड़ा समय IN (in 2024, in July, in the       │
│ morning)                                     │
│ दिन/तारीख ON (on Monday, on 15 August)      │
│ ठीक समय AT (at 5 o'clock, at noon)          │
│ याद रखें: "I-O-A = बड़ा-दिन-घड़ी"            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 2: "स्थान का उल्टा क्रम"               │
│ बड़ी जगह IN (in India, in Delhi)            │
│ सतह पर ON (on the table, on the road)       │
│ ठीक बिंदु AT (at the station, at the door)  │
│ याद रखें: "देश IN, मेज़ ON, दरवाज़ा AT"        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 3: "SINCE = बिंदु, FOR = अवधि"         │
│ since + समय का बिंदु (since Monday, 2010)   │
│ for + समय की अवधि (for two years)           │
│ याद रखें: "SINCE शुरुआत, FOR फैलाव"          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 4: "BY = अंतिम तिथि, UNTIL = जारी"     │
│ by 5 pm = 5 बजे तक या उससे पहले (deadline)  │
│ until 5 pm = 5 बजे तक लगातार (continuity)   │
│ याद रखें: "BY बंद, UNTIL उड़ान"              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 5: "BETWEEN दो, AMONG झुंड"            │
│ between = दो के बीच (between Ram and Shyam) │
│ among = तीन या अधिक (among the students)    │
│ याद रखें: "BETWEEN = Bi (दो), AMONG = Army"  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 6: "BESIDE पास, BESIDES अतिरिक्त"      │
│ beside = के पास/बगल में (sit beside me)     │
│ besides = के अलावा (besides Hindi, English) │
│ याद रखें: "S लगा तो 'साथ में और'"            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 7: "IN = अंदर, INTO = अंदर की ओर"      │
│ in = पहले से अंदर (He is in the room)       │
│ into = गति के साथ अंदर                       │
│ (He went into the room)                     │
│ याद रखें: "INTO में TO = टहलते हुए अंदर"     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 8: "ABOVE-ON, BELOW-UNDER"             │
│ on = छूकर (book on the table)               │
│ above = बिना छुए ऊपर (fan above the head)   │
│ under = बिना छुए नीचे (cat under the table) │
│ below = स्तर में नीचे (below zero)          │
│ याद रखें: "ON छूता, ABOVE उड़ता"             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 9: "ACROSS पार, THROUGH भीतर से"       │
│ across = सतह के पार                          │
│ (swim across the river)                     │
│ through = भीतर से निकलना                     │
│ (through the tunnel)                        │
│ याद रखें: "ACROSS ऊपर-ऊपर, THROUGH घुसकर"    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 10: "क्रिया-Preposition जोड़े (Fixed)"  │
│ depend ON, believe IN, listen TO,           │
│ wait FOR, look AT, agree WITH,              │
│ consist OF, succeed IN, insist ON           │
│ याद रखें: "D-B-L-W-L-A-C-S-I"               │
│ = "Depend-Believe-Listen-Wait-Look-         │
│    Agree-Consist-Succeed-Insist"            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 11: "विशेषण-Preposition जोड़े"         │
│ afraid OF, angry WITH (व्यक्ति)/AT (चीज़),   │
│ good AT, interested IN, fond OF,            │
│ proud OF, different FROM, married TO        │
│ याद रखें: "डर OF, गुस्सा WITH, शादी TO"      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 12: "संग्या-Preposition जोड़े"         │
│ reason FOR, need OF, lack OF,               │
│ solution TO, key TO, answer TO,             │
│ interest IN, demand FOR                     │
│ याद रखें: "Solution-Key-Answer हमेशा TO"     │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy (कब प्रश्न छोड़ें)

**टिप 1 — अपरिचित Fixed Preposition जोड़ा:**
अगर प्रश्न में ऐसा verb/adjective + preposition जोड़ा आए जो आपने कभी नहीं पढ़ा (जैसे "abstain ___", "debar ___"), तो अंदाज़ा न लगाएँ। Negative marking में यह सबसे खतरनाक प्रश्न है — पहले छोड़ें, अंत में समय बचे तो "from" पर दांव लगाएँ (abstain from, debar from — अलगाव वाले शब्दों के साथ from अक्सर सही होता है)।

**टिप 2 — दो विकल्प लगभग एक जैसे लगें:**
अगर in/at या since/for में से दोनों सही लग रहे हों और 30 सेकंड में नियम याद न आए, तो प्रश्न को चिह्नित कर आगे बढ़ें। ऐसे प्रश्न "तार्किक" श्रेणी के हैं — इन्हें दूसरे दौर में 45 सेकंड दें, पहले दौर में नहीं।

**टिप 3 — लंबा वाक्य + खाली स्थान बीच में:**
जब वाक्य बहुत लंबा हो और blank के आसपास intervening phrase (जैसे "along with his friends") छिपा हो, तो जल्दबाज़ी में गलती निश्चित है। पहले आसान तथ्यात्मक प्रश्न (in/on/at, fixed pairs) निपटाएँ, फिर इन लंबे वाक्यों पर लौटें — blank के ठीक पहले और बाद के शब्द पढ़कर जोड़ा पहचानें।
