# 🪄 Short Tricks + Skip Strategy — Preposition

## Trick 1 — The "Mouse Box" Test
```
┌─────────────────────────────────────────────┐
│  Ask: "Can a mouse do this with a box?"     │
│  IN the box, ON the box, UNDER the box,     │
│  BEHIND the box, BETWEEN boxes, OVER it…    │
│  If yes → it's a PREPOSITION of place.      │
└─────────────────────────────────────────────┘
```
Any word that passes the mouse-box test shows position. Instant identification in "spot the preposition" questions.

## Trick 2 — "IN-ON-AT" Time Ladder
```
┌─────────────────────────────────────────────┐
│  BIG time → IN   (in 2024, in July, in      │
│                    the morning)             │
│  DAY      → ON   (on Monday, on 15 August)  │
│  EXACT    → AT   (at 5 pm, at noon, at      │
│                    night)                   │
│  Memory hook: "IN is INside a big period,   │
│  ON sits ON a day, AT points AT a clock."   │
└─────────────────────────────────────────────┘
```

## Trick 3 — "IN-ON-AT" Place Zoom
```
┌─────────────────────────────────────────────┐
│  Zoom OUT → IN  (in India, in Delhi)        │
│  Surface  → ON  (on the table, on the road) │
│  Zoom IN  → AT  (at the door, at the bus    │
│                   stop, at 10 MG Road)      │
│  Think of a camera: wide shot = IN,         │
│  surface shot = ON, close-up = AT.          │
└─────────────────────────────────────────────┘
```

## Trick 4 — "Arrive" Rule
```
┌─────────────────────────────────────────────┐
│  arrive IN + big place (country/city)       │
│  arrive AT + small point (station, airport) │
│  ❌ arrive to / reach to                    │
│  ✅ reach Delhi (NO preposition after       │
│     "reach"!)                               │
└─────────────────────────────────────────────┘
```

## Trick 5 — Verbs That HATE Prepositions
```
┌─────────────────────────────────────────────┐
│  Mnemonic: "RACE-DO"                        │
│  Reach, Accompany, Comprise, Enter,         │
│  Discuss, Order, Request                    │
│  ❌ entered into the room                   │
│  ✅ entered the room                        │
│  ❌ comprises of  ✅ comprises / consists of│
└─────────────────────────────────────────────┘
```

## Trick 6 — Verbs That NEED Fixed Prepositions
```
┌─────────────────────────────────────────────┐
│  "LILA-DIP"                                 │
│  Listen TO, Look AT, Apologise FOR,         │
│  Depend ON, Insist ON, Participate IN       │
│  ❌ discuss about  ✅ talk about            │
│  ❌ listen the song  ✅ listen to the song  │
└─────────────────────────────────────────────┘
```

## Trick 7 — Since vs For
```
┌─────────────────────────────────────────────┐
│  SINCE = Starting point (since Monday,      │
│          since 2010) — "S for Start"        │
│  FOR   = Full duration (for two years,      │
│          for a week) — "F for Full length"  │
└─────────────────────────────────────────────┘
```

## Trick 8 — Between vs Among
```
┌─────────────────────────────────────────────┐
│  BETWEEN = 2 (between Ram and Shyam)        │
│  AMONG   = 3+ (among the students)          │
│  Hook: "BETWEEN has TWO 'e's together —     │
│  think of a pair."                          │
└─────────────────────────────────────────────┘
```

## Trick 9 — Beside vs Besides
```
┌─────────────────────────────────────────────┐
│  BESIDE  = next to (Sit beside me.)         │
│  BESIDES = in addition to (Besides tea,     │
│            he drank coffee.)                │
│  Hook: extra "S" = Something extra.         │
└─────────────────────────────────────────────┘
```

## Trick 10 — By vs With (Agent vs Tool)
```
┌─────────────────────────────────────────────┐
│  BY   = the doer  (killed BY the hunter)    │
│  WITH = the tool  (killed WITH a knife)     │
│  Hook: "BY the Body, WITH the Weapon."      │
└─────────────────────────────────────────────┘
```

## Trick 11 — Adjective + Preposition Pairs
```
┌─────────────────────────────────────────────┐
│  "A-GIFT"                                   │
│  Afraid OF, Good AT, Interested IN,         │
│  Fond OF, Tired OF                          │
│  ❌ good in English  ✅ good at English     │
│  ❌ interested to    ✅ interested in       │
└─────────────────────────────────────────────┘
```

## Trick 12 — "Different FROM", Never "Different Than"
```
┌─────────────────────────────────────────────┐
│  In Indian exams, always choose:            │
│  ✅ different FROM                          │
│  ❌ different than / different to           │
│  Same family: similar TO, superior TO,      │
│  junior TO, prefer X TO Y.                  │
└─────────────────────────────────────────────┘
```

## Trick 13 — No Preposition After "Home / Here / There / Abroad"
```
┌─────────────────────────────────────────────┐
│  ❌ go to home   ✅ go home                 │
│  ❌ come to here ✅ come here               │
│  These words are adverbs of place —         │
│  they refuse "to".                          │
└─────────────────────────────────────────────┘
```

## Trick 14 — In Time vs On Time
```
┌─────────────────────────────────────────────┐
│  ON time = exactly at the scheduled moment  │
│  (The train arrived on time — 5:00 sharp.)  │
│  IN time = early enough, before deadline    │
│  (I reached in time to catch the train.)    │
└─────────────────────────────────────────────┘
```

## Trick 15 — Ending a Sentence With a Preposition Is OK
```
┌─────────────────────────────────────────────┐
│  ✅ "Who are you waiting for?"              │
│  ✅ "This is the house I live in."          │
│  Don't pick "error" just because a          │
│  preposition ends the sentence — examiners  │
│  love this trap!                            │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy

**Tip 1 — Skip "fixed pair" confusion in the first pass.**
If a question tests an idiom pair you have never seen (e.g., "abide ___", "hanker ___"), don't burn 45 seconds guessing. Mark it, finish the paper, return later. Fixed prepositions are pure memory — thinking longer never helps. (15-second fact question: answer instantly or skip.)

**Tip 2 — Eliminate the two "sound-right" options first.**
In error-spotting, examiners plant options that *sound* natural to Hindi speakers ("discuss about", "reach to", "comprise of"). If two options feel equally smooth, the trap is usually there — apply Trick 5 (RACE-DO) and eliminate. If you still can't decide in 45 seconds, skip and move on.

**Tip 3 — Never skip IN-ON-AT questions.**
Time/place preposition questions follow the Ladder and Zoom tricks (Tricks 2–3) and are the fastest marks in the paper — solvable in under 15 seconds. Attempt these first; save your skip budget for unfamiliar fixed pairs.
