# 🪄 शॉर्ट ट्रिक्स + Skip Strategy — वाक्य संरचना (Sentence Structure)

---

## 🎯 15 म्नेमोनिक ट्रिक्स

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 1: "SVA" — वाक्य की रीढ़                       │
│ Subject + Verb + Agreement                          │
│ हर वाक्य में पहले Subject खोजो, फिर Verb,           │
│ फिर जाँचो — दोनों मिल रहे हैं या नहीं।              │
│ याद रखो: "सब्जेक्ट बोले, वर्ब सुने"                 │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 2: "FANBOYS" — 7 जोड़ने वाले शब्द              │
│ For, And, Nor, But, Or, Yet, So                     │
│ इनसे जुड़े दो पूरे वाक्य = Compound Sentence        │
│ इनके पहले अल्पविराम (comma) लगता है।                │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 3: "AAAWWUBBIS" — Dependent Clause शुरुआती     │
│ After, Although, As, When, While, Until,            │
│ Because, Before, If, Since                          │
│ इनसे शुरू वाक्य = Complex Sentence,                 │
│ बीच में comma ज़रूरी: "Because it rained, we stayed."│
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 4: "बीच वाला भूल जाओ" — Intervening Phrase     │
│ "The box of chocolates IS mine."                    │
│ box और verb के बीच आया phrase नज़रअंदाज़ करो।        │
│ Subject = box (एकवचन), इसलिए IS, न कि are।          │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 5: "Each/Every = एक"                           │
│ Each, Every, Everyone, Everybody, Someone,          │
│ Nobody — सबके साथ एकवचन verb।                       │
│ "Each of the boys HAS a pen." (have नहीं)           │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 6: "Or/Nor = पड़ोसी नियम"                      │
│ Either...or / Neither...nor में verb                 │
│ पास वाले subject से मिलता है।                        │
│ "Neither the teacher nor the STUDENTS WERE late."   │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 7: "There = उल्टा वाक्य"                       │
│ There is/are से शुरू वाक्य में असली subject          │
│ verb के बाद आता है।                                  │
│ "There ARE three books on the table."               │
│ (books = बहुवचन, इसलिए are)                         │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 8: "प्रश्न में उलट-पुलट" — Inversion           │
│ सीधा: You are coming. → प्रश्न: Are you coming?     │
│ Helping verb हमेशा subject से पहले।                  │
│ ❌ "What you are doing?" ✅ "What are you doing?"   │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 9: "News है, पर एक" — भ्रामक एकवचन             │
│ News, Physics, Mathematics, Politics, Measles —     │
│ दिखते बहुवचन, हैं एकवचन।                            │
│ "The news IS good." (are नहीं)                      │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 10: "जोड़ी वाले = बहुवचन"                      │
│ Scissors, Trousers, Spectacles, Shoes (जोड़ी में)    │
│ — हमेशा बहुवचन verb।                                │
│ "My scissors ARE blunt."                            │
│ पर "A pair of scissors IS..." (pair = एकवचन!)       │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 11: "SVC जाँच" — 3 सेकंड में वाक्य पहचानो       │
│ Simple = 1 verb जोड़ा | Compound = FANBOYS           │
│ Complex = AAAWWUBBIS | Compound-Complex = दोनों      │
│ पहले verb गिनो, फिर जोड़ने वाला शब्द देखो।          │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 12: "Fragment = अधूरा खाना"                    │
│ जिस टुकड़े में subject या verb न हो, वो Fragment है।  │
│ "Running in the park." ❌ (कौन दौड़ रहा?)           │
│ "Ravi is running in the park." ✅                   │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 13: "Run-on = बिना ब्रेक की गाड़ी"             │
│ दो पूरे वाक्य बिना विराम-चिह्न के = Run-on।          │
│ इलाज: (1) Full stop (2) Semicolon                   │
│ (3) Comma + FANBOYS                                 │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 14: "Collective = टीम एक"                      │
│ Team, Army, Committee, Jury — एक इकाई की तरह        │
│ सोचें तो एकवचन verb।                                │
│ "The team IS playing well."                         │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 15: "Sound-Right जाल से बचो"                   │
│ कान से सही लगना = सही होना नहीं!                     │
│ "One of my friends IS..." (friends सुनकर are मत लगाओ)│
│ नियम याद करो, आवाज़ पर भरोसा मत करो।                │
└─────────────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**🚩 छोड़ो, अगर:**

1. **दो विकल्प लगभग एक जैसे लगें और 45 सेकंड में फैसला न हो** — जटिल error-spotting में अगर दो विकल्पों में अंतर समझ न आए, तो अंधा अनुमान मत लगाओ। पहले बाकी पेपर खत्म करो, अंत में लौटो।

2. **वाक्य बहुत लंबा हो और समय कम बचा हो** — 3-4 पंक्तियों वाले sentence-improvement प्रश्न में अगर पढ़ने में ही 30 सेकंड लग रहे हों, तो उसे अंत के लिए चिह्नित करो। पहले छोटे, तथ्यात्मक प्रश्न (verb form, एकवचन/बहुवचन) निपटाओ — वे 15 सेकंड में निश्चित अंक देते हैं।

3. **अपरिचित शब्दावली पर आधारित अनुमान प्रश्न** — अगर वाक्य का अर्थ ही समझ न आए (कठिन शब्दों के कारण) और context से भी सुराग न मिले, तो छोड़ दो।

**⚠️ Negative marking का ध्यान रखो:** हर परीक्षा में गलत उत्तर की कटौती अलग होती है — जैसे SSC CGL में −0.50 अंक, Railway परीक्षाओं में −1/3 अंक, कई Bank परीक्षाओं में −0.25 अंक। अपनी परीक्षा के notification में यह ज़रूर जाँच लो। सामान्य सिद्धांत यही है: **छोड़ा प्रश्न = 0 अंक, गलत प्रश्न = अंक कटेंगे।** इसलिए समझदारी छोड़ने में है, अंधे टुक्के में नहीं।
