# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति
## रिक्त स्थान भरें (सरल) — Fill in the Blanks (Basic)

## 🎯 15 म्नेमोनिक ट्रिक्स (याद रखने की चाबियाँ)

---

### ट्रिक 1: "सी-सी-सी" नियम (Subject-Verb Agreement)
```
┌─────────────────────────────────────────────┐
│  "कर्ता देखो, क्रिया जोड़ो — बीच का शब्द भूलो!"  │
│                                             │
│  The box of chocolates ___ on the table.    │
│  → कर्ता = box (एकवचन), chocolates नहीं!    │
│  → उत्तर: is ✓  (are ✗)                     │
└─────────────────────────────────────────────┘
```
**याद कैसे:** "बीच में of आए, पहले वाला भाई बड़ा कहलाए।"

---

### ट्रिक 2: "EACH-EVERY-NEITHER" = हमेशा एकवचन
```
┌─────────────────────────────────────────────┐
│  "ई-ई-एन-ई — सबके साथ IS/WAS/HAS"           │
│                                             │
│  Each / Every / Neither / Either / Everyone │
│  → इनके बाद क्रिया हमेशा एकवचन!             │
│  Each of the boys ___ present. → was ✓      │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 3: "साथी शब्दों का धोखा" (Intervening Phrase)
```
┌─────────────────────────────────────────────┐
│  with, along with, together with, as well as│
│  → ये "मेहमान" हैं, कर्ता नहीं!              │
│                                             │
│  Ram, along with his friends, ___ going.    │
│  → कर्ता = Ram → is ✓  (are ✗)              │
└─────────────────────────────────────────────┘
```
**याद कैसे:** "मेहमान घर बदलता नहीं — क्रिया असली मालिक के हिसाब से।"

---

### ट्रिक 4: "A/AN की आवाज़ ट्रिक"
```
┌─────────────────────────────────────────────┐
│  अक्षर नहीं, आवाज़ सुनो!                     │
│  • a university (यू- की आवाज़ = व्यंजन)       │
│  • an hour (h खामोश, अ- की आवाज़)            │
│  • an honest man ✓  |  a European ✓         │
└─────────────────────────────────────────────┘
```
**याद कैसे:** "कान से भरो, आँख से नहीं!"

---

### ट्रिक 5: "SINCE-FOR जोड़ी"
```
┌─────────────────────────────────────────────┐
│  SINCE = बिंदु (Point) → since Monday,      │
│          since 2010, since morning          │
│  FOR   = अवधि (Period) → for two days,      │
│          for five years                     │
│                                             │
│  याद: "Since-बिंदु, For-फैलाव"              │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 6: "IN-ON-AT सीढ़ी"
```
┌─────────────────────────────────────────────┐
│  AT  = सबसे छोटा (at 5 o'clock, at night)   │
│  ON  = दिन/तारीख (on Monday, on 15 August)  │
│  IN  = सबसे बड़ा (in 2024, in July,         │
│        in the morning)                      │
│                                             │
│  याद: "छोटा AT, मध्यम ON, बड़ा IN"          │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 7: "MUCH-MANY जोड़ी"
```
┌─────────────────────────────────────────────┐
│  MANY = गिन सकते हो → many books, many boys │
│  MUCH = गिन नहीं सकते → much water,         │
│         much money                          │
│                                             │
│  याद: "Many-मुट्ठी (गिनो), Much-मिट्टी      │
│  (गिन नहीं सकते)"                           │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 8: "FEW-LITTLE परिवार"
```
┌─────────────────────────────────────────────┐
│  FEW/A FEW     → गिनने वालों के लिए          │
│  LITTLE/A LITTLE → नापने वालों के लिए        │
│  'a' लगा = कुछ तो है (सकारात्मक)            │
│  बिना 'a' = लगभग नहीं (नकारात्मक)           │
│                                             │
│  There is ___ water. (लगभग नहीं) → little   │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 9: "2nd Form की दुकान" (Past Tense)
```
┌─────────────────────────────────────────────┐
│  वाक्य में ago, yesterday, last दिखे        │
│  → बिना सोचे Verb की 2nd Form!              │
│  He ___ there yesterday. → went ✓           │
│                                             │
│  याद: "ago दिखे, did मत लगाओ —               │
│  सीधे V2 उठाओ!"                             │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 10: "DID के बाद V1"
```
┌─────────────────────────────────────────────┐
│  did / did not के बाद हमेशा Verb की         │
│  1st Form — कभी 2nd नहीं!                   │
│  He did not ___ there. → go ✓ (went ✗)      │
│                                             │
│  याद: "DID ने सारा past खा लिया,             │
│  आगे वाली verb भूखी रह गई (V1)!"            │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 11: "Preposition के बाद -ING"
```
┌─────────────────────────────────────────────┐
│  of, in, on, at, for, with, by, without     │
│  के तुरंत बाद verb आए → -ing लगाओ           │
│  He is fond of ___. → reading ✓             │
│  He left without ___ anything. → saying ✓   │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 12: "TO के बाद V1 — पर 3 अपवाद!"
```
┌─────────────────────────────────────────────┐
│  सामान्य: to + V1 (to go, to eat)           │
│  अपवाद (to + V-ing):                        │
│  • look forward to meeting                  │
│  • be used to walking                       │
│  • object to paying                         │
│                                             │
│  याद: "Look-Used-Object — तीनों में          │
│  to के बाद ING!"                            │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 13: "Comparative की जोड़ी — THAN"
```
┌─────────────────────────────────────────────┐
│  -er / more दिखे → than ज़रूर आएगा          │
│  She is taller ___ me. → than ✓             │
│  ✗ taller from / taller then                │
│                                             │
│  याद: "than = तुलना, then = समय"            │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 14: "One of + बहुवचन + एकवचन क्रिया"
```
┌─────────────────────────────────────────────┐
│  One of the + बहुवचन संज्ञा + एकवचन क्रिया   │
│  One of the boys ___ absent. → was ✓        │
│  (boys देखकर were मत लगाओ!)                 │
│                                             │
│  याद: "One ही असली राजा, बाकी सब दरबारी!"   │
└─────────────────────────────────────────────┘
```

---

### ट्रिक 15: "No sooner / Hardly / Scarcely — तिकड़ी"
```
┌─────────────────────────────────────────────┐
│  No sooner ... THAN                         │
│  Hardly / Scarcely ... WHEN                 │
│  (तीनों में had + V3 आता है)                │
│  No sooner had he come ___ it rained.       │
│  → than ✓                                   │
│                                             │
│  याद: "No sooner का दोस्त THAN,              │
│  Hardly-Scarcely का WHEN"                   │
└─────────────────────────────────────────────┘
```

## ⏭️ स्किप रणनीति (कब प्रश्न छोड़ें)

### 🚫 स्किप नियम 1: "दो विकल्प, दोनों सही लगें"
अगर 45 सेकंड में भी दो विकल्पों में फँसे हो (जैसे *in* vs *at*, *few* vs *little*), तो प्रश्न **मार्क करके आगे बढ़ो**। अंत में लौटकर "कर्ता-क्रिया" या "गिनती" ट्रिक से तय करो। अंधा अनुमान = नकारात्मक अंकन का नुकसान।

### 🚫 स्किप नियम 2: "अनजानी मुहावरेदार जोड़ी (Idiom-based blank)"
अगर blank किसी ऐसे idiom/phrasal verb में है जिसे आपने कभी नहीं पढ़ा (जैसे *look ___ to*), तो तर्क लगाकर समय बर्बाद न करो — ये याद पर आधारित हैं, तर्क पर नहीं। **15 सेकंड में पहचानो, न आए तो छोड़ो।**

### 🚫 स्किप नियम 3: "लंबा वाक्य + टोन वाला blank"
जब वाक्य लंबा हो और उत्तर पूरे संदर्भ की भावना (सकारात्मक/नकारात्मक) पर निर्भर हो, तो पहले आसान तथ्यात्मक प्रश्न निपटाओ। ऐसे प्रश्न **दूसरे चक्र में** हल करो — जल्दबाज़ी में टोन उल्टा पढ़ने की गलती सबसे आम है।

## ⚡ अंतिम मंत्र

```
┌─────────────────────────────────────────────┐
│  1. पहले कर्ता खोजो → क्रिया मिलाओ           │
│  2. समय-संकेतक देखो (ago, since, for)       │
│  3. Preposition के बाद -ING                 │
│  4. 15 सेकंड = तथ्य, 45 सेकंड = तर्क        │
│  5. शक हो तो मार्क करो, अंधा अनुमान नहीं    │
└─────────────────────────────────────────────┘
```
