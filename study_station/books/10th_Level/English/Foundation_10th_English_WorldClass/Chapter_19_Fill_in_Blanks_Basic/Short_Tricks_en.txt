# 🪄 Short Tricks + Skip Strategy — Fill in the Blanks (Basic)

## Trick 1 — The "Read-Aloud Ear Test" 👂
```
┌─────────────────────────────────────────────┐
│  Before looking at options, read the        │
│  sentence silently with a BLANK sound       │
│  ("mmm"). Your ear often tells you the      │
│  answer before your brain does.             │
│  "She ___ to school daily" → your ear       │
│  already hears "goes".                      │
└─────────────────────────────────────────────┘
```

## Trick 2 — Mnemonic: **"S-V-A" (Subject–Verb Agreement)** 🔑
```
┌─────────────────────────────────────────────┐
│  "Find the SUBJECT, match the VERB,         │
│   get the ANSWER."                          │
│  Ignore everything between them!            │
│  "The box of chocolates (is/are) mine."     │
│  Subject = box → IS ✓                       │
└─────────────────────────────────────────────┘
```

## Trick 3 — Mnemonic: **"PAST pairs with PAST"** ⏳
```
┌─────────────────────────────────────────────┐
│  If the sentence has a past-time word       │
│  (yesterday, ago, last year, in 2010),      │
│  the verb MUST be past tense.               │
│  "He ___ here yesterday" → came ✓ (not come)│
└─────────────────────────────────────────────┘
```

## Trick 4 — Mnemonic: **"A before Consonant, AN before Vowel SOUND"** 🔤
```
┌─────────────────────────────────────────────┐
│  It's the SOUND, not the letter!            │
│  an hour (h silent), a university (yoo-),   │
│  an M.P. (em-), a one-rupee note (won-).    │
│  Trick: Say it aloud — ear beats eye.       │
└─────────────────────────────────────────────┘
```

## Trick 5 — Mnemonic: **"Since = Point, For = Period"** ⏰
```
┌─────────────────────────────────────────────┐
│  SINCE → a POINT in time (Monday, 2015,     │
│  childhood, 5 o'clock).                     │
│  FOR → a PERIOD of time (two years,         │
│  a long time, ages).                        │
│  Memory hook: "Since is a dot, For is a     │
│  line."                                     │
└─────────────────────────────────────────────┘
```

## Trick 6 — Mnemonic: **"IN-ON-AT ladder"** 🪜
```
┌─────────────────────────────────────────────┐
│  Time:  IN (month/year) → ON (day/date) →   │
│         AT (exact time)                     │
│  Place: IN (city/country) → ON (street/     │
│         surface) → AT (exact point)         │
│  Big → small, top → bottom of the ladder!   │
└─────────────────────────────────────────────┘
```

## Trick 7 — The "Elimination Ladder" 🪜
```
┌─────────────────────────────────────────────┐
│  Step 1: Cut options with wrong TENSE.      │
│  Step 2: Cut options with wrong NUMBER      │
│          (singular/plural).                 │
│  Step 3: Cut the option that doesn't        │
│          collocate (we "make a mistake",    │
│          never "do a mistake").             │
│  Usually only ONE option survives!          │
└─────────────────────────────────────────────┘
```

## Trick 8 — Mnemonic: **"MUCH-MANY, LITTLE-FEW"** ⚖️
```
┌─────────────────────────────────────────────┐
│  Countable? → MANY / FEW / A FEW            │
│  Uncountable? → MUCH / LITTLE / A LITTLE    │
│  Hook: "You can count FEW fingers,          │
│  but only a LITTLE water."                  │
└─────────────────────────────────────────────┘
```

## Trick 9 — Mnemonic: **"Neither-Nor, Either-Or — twins stay together"** 👯
```
┌─────────────────────────────────────────────┐
│  If you see EITHER in the sentence, the     │
│  blank almost always wants OR.              │
│  If you see NEITHER, it wants NOR.          │
│  Never mix the twins! (neither-or ✗)        │
└─────────────────────────────────────────────┘
```

## Trick 10 — The "Fixed Preposition Bank" 🏦
```
┌─────────────────────────────────────────────┐
│  Memorise these exam favourites as chunks:  │
│  afraid OF | good AT | interested IN |      │
│  depend ON | listen TO | married TO |       │
│  angry WITH (person) | different FROM |     │
│  consist OF | look AFTER | wait FOR         │
│  These are pure 15-second questions!        │
└─────────────────────────────────────────────┘
```

## Trick 11 — Mnemonic: **"One of the + PLURAL noun + SINGULAR verb"** 1️⃣
```
┌─────────────────────────────────────────────┐
│  "One of the boys (has/have) come."         │
│  Noun after "one of the" = plural (boys),   │
│  but the VERB = singular (has).             │
│  Hook: "Many boys, but only ONE came."      │
└─────────────────────────────────────────────┘
```

## Trick 12 — The "Signal Word Scanner" 🔍
```
┌─────────────────────────────────────────────┐
│  Circle signal words before answering:      │
│  • yesterday/ago → past tense               │
│  • since/for → perfect tense (has/have/had) │
│  • tomorrow/next → will + verb              │
│  • always/daily/every → simple present      │
│  The signal word IS the answer key!         │
└─────────────────────────────────────────────┘
```

## Trick 13 — Mnemonic: **"Sound-Right ≠ Right"** ⚠️
```
┌─────────────────────────────────────────────┐
│  If an option "sounds right" because you    │
│  say it in daily life, DOUBLE-CHECK it —    │
│  examiners plant spoken-English errors:     │
│  ✗ "He is more taller" → ✓ "He is taller"   │
│  ✗ "return back" → ✓ "return"               │
│  ✗ "discuss about" → ✓ "discuss"            │
└─────────────────────────────────────────────┘
```

## Trick 14 — The "Both-Blanks Cross-Check" (for double blanks) ✌️
```
┌─────────────────────────────────────────────┐
│  In two-blank questions, don't solve both   │
│  blanks. Solve the EASIER blank first —     │
│  it usually eliminates 2-3 options at once. │
│  Then check the second blank only in the    │
│  surviving options.                         │
└─────────────────────────────────────────────┘
```

## Trick 15 — Mnemonic: **"First Impression Rule"** 🎯
```
┌─────────────────────────────────────────────┐
│  In vocabulary blanks, your FIRST instinct  │
│  (from collocation/meaning) is right ~most  │
│  of the time. Change an answer ONLY if you  │
│  find a concrete grammar reason — never     │
│  because of doubt alone.                    │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy — When to Skip and Move On

**Skip Tip 1 — The 45-Second Wall 🧱**
If you have read the sentence twice, applied elimination, and still two options look equally correct — mark your best guess, flag the question, and MOVE ON. Fill-in-the-blanks questions are worth the same marks as easy ones; never trade 2 minutes of one hard blank for 3 easy questions left unattempted.

**Skip Tip 2 — Unknown Vocabulary = Strategic Skip 📕**
If the blank needs a word whose meaning you simply don't know (e.g., *ephemeral, candid, obsolete*) and no elimination is possible, don't burn time. Guess between the two most "neutral-sounding" options (examiners rarely make the answer an extreme word) and skip ahead. Build this word into your vocabulary list after the exam/mock.

**Skip Tip 3 — Double-Blank Traps: Solve or Skip in One Pass 🔀**
If NEITHER blank yields to your first elimination pass, skip immediately — double-blank questions are designed to eat time. Come back only if time remains. Remember: in SSC/Railway/Bank prelims, a skipped hard question costs 0, but a rushed negative-marked guess can cost 0.25–0.50 marks. Skip smart, score more.
