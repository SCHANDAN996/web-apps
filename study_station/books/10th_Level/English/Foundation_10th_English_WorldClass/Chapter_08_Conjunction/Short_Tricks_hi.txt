# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — संयोजक (Conjunction)

## 🎯 15 म्नेमोनिक ट्रिक्स

┌─────────────────────────────────────────────┐
│ ट्रिक 1: **FANBOYS** — 7 समन्वयी संयोजक      │
│ **F**or, **A**nd, **N**or, **B**ut, **O**r, │
│ **Y**et, **S**o                              │
│ याद करें: "फैनबॉयज़ दो समान वाक्य जोड़ते हैं" │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 2: **"No sooner… than"** — than ही आएगा│
│ ❌ No sooner did he come when…              │
│ ✅ No sooner did he come **than**…          │
│ याद करें: "Sooner के साथ than, कभी when नहीं"│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 3: **"Hardly/Scarcely… when"**         │
│ ❌ Hardly had I slept than…                 │
│ ✅ Hardly had I slept **when**…             │
│ याद करें: "Hardly-Scarcely की शादी when से"  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 4: **"Though… yet"** — but कभी नहीं    │
│ ❌ Though he is poor, **but** he is honest. │
│ ✅ Though he is poor, **yet** he is honest. │
│ याद करें: "Though के साथ but = दोहरा विरोध"  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 5: **"Because के साथ so मना"**         │
│ ❌ Because he was ill, **so** he stayed home│
│ ✅ Because he was ill, he stayed home.      │
│ याद करें: "एक वाक्य में एक ही कारण-शब्द"     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 6: **"Since के साथ therefore मना"**    │
│ ❌ Since he was tired, **therefore** he slept│
│ ✅ Since he was tired, he slept.            │
│ याद करें: "Since अकेला काफी है"              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 7: **"Unless = if… not"**              │
│ Unless you work hard, you will fail.        │
│ = If you do **not** work hard, you will fail│
│ ⚠️ Unless के साथ not दोबारा मत लगाओ!         │
│ ❌ Unless you do not work hard…             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 8: **"Until के साथ not मना"**          │
│ ❌ Until you do not call, I will wait.      │
│ ✅ Until you call, I will wait.             │
│ याद करें: "Until खुद नकारात्मक अर्थ रखता है" │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 9: **"Lest… should"**                  │
│ Walk fast **lest** you **should** miss train│
│ याद करें: "Lest के बाद should, not कभी नहीं" │
│ ❌ lest you should not miss…                │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 10: **जोड़ी-संयोजक (Correlative) पक्के │
│ करो:**                                       │
│ Either…or | Neither…nor | Not only…but also │
│ Both…and | Whether…or | Such…as             │
│ याद करें: "जोड़ी टूटी तो वाक्य गलत"          │
│ ❌ Neither Ram **or** Shyam → ✅ nor        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 11: **"Not only… but also" — समान रूप**│
│ ❌ He not only plays cricket but also       │
│    football.                                │
│ ✅ He plays not only cricket but also       │
│    football. (दोनों के बाद समान शब्द-वर्ग)   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 12: **"The reason… is that"**          │
│ ❌ The reason is **because** he was late.   │
│ ✅ The reason is **that** he was late.      │
│ याद करें: "Reason + because = दोहरा कारण"    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 13: **"As if / As though — अतीत का     │
│ रूप"**                                       │
│ He talks **as if** he **were** a king.      │
│ (वह राजा नहीं है — काल्पनिक, इसलिए were)     │
│ याद करें: "As if के बाद काल्पनिक = were/was- │
│ रूप का past"                                 │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 14: **"Scarcely/No sooner के बाद       │
│ inversion"**                                 │
│ ✅ No sooner **did** he arrive…             │
│ ✅ Hardly **had** she left…                 │
│ याद करें: "वाक्य की शुरुआत नकारात्मक संयोजक  │
│ से → helping verb पहले"                      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 15: **"Such…that vs So…that"**         │
│ **So** + adjective + that: He was **so**    │
│ tired **that** he slept.                    │
│ **Such** + noun + that: It was **such** a   │
│ hot day **that** we stayed in.              │
│ याद करें: "So-विशेषण, Such-संज्ञा"           │
└─────────────────────────────────────────────┘

## ⏭️ स्किप रणनीति (कब प्रश्न छोड़ें)

**💡 टिप 1 — दोहरा-निषेध पहचानो, फंसो मत:**
अगर विकल्पों में unless/until/lest के साथ not वाले वाक्य हैं और आपको नियम याद नहीं आ रहा, तो 15 सेकंड में "क्या संयोजक खुद नकारात्मक है?" यह जाँच कर उत्तर लगाओ। फिर भी संदेह हो तो प्रश्न **छोड़ दो** — अनुमान से negative marking का नुकसान ज़्यादा है।

**💡 टिप 2 — लंबे Error-spotting वाक्य में पहले संयोजक-जोड़ी खोजो:**
लंबा वाक्य देखते ही घबराओ मत। सीधे though/because/since/either/neither खोजो — गलती अक्सर इन्हीं जोड़ियों में होती है। 30 सेकंड में जोड़ी न मिले तो प्रश्न को **अंत के लिए चिह्नित** करके आगे बढ़ो।

**💡 टिप 3 — "Sound-right" जाल से बचो:**
जो विकल्प बोलने में सही लगे (जैसे "No sooner… when") वही अक्सर गलत होता है। अगर दो विकल्प लगभग एक जैसे लगें और नियम याद न आए, तो प्रश्न **skip** करो — यह परीक्षक का सबसे बड़ा जाल है, और अंदाज़े से खेलना यहाँ घातक है।
