# 🪄 Short Tricks + Skip Strategy — Conjunction

## 🎯 Master Mnemonics (Learn These First)

**📦 BOX 1 — FANBOYS (Coordinating Conjunctions)**
```
F — For      (reason)
A — And      (addition)
N — Nor      (negative alternative)
B — But      (contrast)
O — Or       (choice)
Y — Yet      (contrast, surprise)
S — So       (result)
```
*Trick:* "FANBOYS join equals" — word + word, phrase + phrase, clause + clause. If the two sides are not equal in rank, FANBOYS is wrong.

**📦 BOX 2 — "A BUS WAT" (Subordinating Conjunctions)**
```
A — After, Although, As
B — Because, Before
U — Until, Unless
S — Since, So that
W — When, While, Where
A — As if, As soon as
T — Though, Than, That
```
*Trick:* A subordinating conjunction makes one clause a "servant" (dependent). The servant clause alone cannot stand as a sentence.

**📦 BOX 3 — Correlative Pairs ("Married Couples")**
```
Either … or        Neither … nor
Not only … but also    Both … and
Whether … or       No sooner … than
Hardly/Scarcely … when    Rather … than
```
*Trick:* "Couples never change partners." ❌ Neither…or ✅ Neither…nor. ❌ No sooner…when ✅ No sooner…than.

**📦 BOX 4 — "UNLESS = IF…NOT"**
```
Unless you work hard, you will fail.
= If you do not work hard, you will fail.
```
*Trick:* Never write ❌ "Unless you do not work hard…" — unless already carries the negative. Double negative = double marks lost.

**📦 BOX 5 — "UNTIL vs UNLESS"**
```
UNTIL  → TIME (Wait until I come.)
UNLESS → CONDITION (Don't go unless I call.)
```
*Trick:* **T**ime = un**T**il. Condition = unless. Both start with "un" — check what follows: clock or condition?

**📦 BOX 6 — "BECAUSE–SO / ALTHOUGH–BUT: One Seat, One Person"**
```
❌ Because he was ill, so he stayed home.
✅ Because he was ill, he stayed home.
❌ Although he is rich, but he is not happy.
✅ Although he is rich, he is not happy.
```
*Trick:* Two conjunctions cannot share one sentence. "Because" and "so" fight for the same chair — keep only one. Same with "although" and "but".

**📦 BOX 7 — "No Sooner/Hardly/Scarcely = Inversion Alarm"**
```
No sooner had he entered than it rained.
Hardly had she slept when the phone rang.
Scarcely had we reached when the show began.
```
*Trick:* When these three open a sentence, the helping verb jumps before the subject (had he, had she, had we). Partner check: No sooner → **than**; Hardly/Scarcely → **when**.

**📦 BOX 8 — "Lest…Should"**
```
Walk fast lest you should miss the train.
```
*Trick:* After **lest**, always use **should** (or the base verb), and never use "not" — lest itself means "so that…not". ❌ lest you should not miss.

**📦 BOX 9 — "AS vs SINCE vs BECAUSE (Reason Strength)"**
```
BECAUSE → strong, direct reason (answers "why?")
SINCE   → reason already known/obvious
AS      → mild, casual reason
```
*Trick:* In error-spotting, "because" is almost never wrong for a direct reason. If the question asks "Why?", answer with "because".

**📦 BOX 10 — "SO THAT vs SO…THAT"**
```
SO THAT      → purpose (He saved money so that he could buy a cycle.)
SO + adj/adv + THAT → result (He was so tired that he slept at once.)
```
*Trick:* Purpose = so that (future plan). Result = so…that (already happened). Check: is there an adjective between "so" and "that"? Then it's result.

**📦 BOX 11 — "THAT vs WHICH vs WHO after Conjunctions"**
```
WHO  → persons
WHICH → things/animals
THAT  → both (after all, only, superlatives, something/anything)
```
*Trick:* After "all", "only", "everything", or a superlative (the best, the first), choose **that**, not which/who. ✅ All that glitters is not gold.

**📦 BOX 12 — "WHILE = Contrast or Time?"**
```
Time:     While I was reading, the lights went off.
Contrast: While Ram is lazy, Shyam is hardworking.
```
*Trick:* If "while" joins two opposite ideas, it means "whereas" — no comma confusion, no tense rule needed. Read the meaning, not the word.

**📦 BOX 13 — "Either…or / Neither…nor: Verb Loves the Nearest Subject"**
```
Neither the teacher nor the students were present.
Neither the students nor the teacher was present.
```
*Trick:* "Proximity Rule" — the verb agrees with the subject sitting closest to it. Look right before the verb, nowhere else.

**📦 BOX 14 — "AS IF / AS THOUGH = Unreal Past"**
```
He talks as if he were a king. (He is not.)
She behaved as though she had won. (She had not.)
```
*Trick:* After as if/as though, use past tense for present imagination (were, not was) and past perfect for past imagination. Reality check: if it's imaginary, shift one tense back.

**📦 BOX 15 — "BUT = ONLY (Hidden Meaning)"**
```
He is but a child. = He is only a child.
```
*Trick:* In old/formal exam sentences, "but" can mean "only". Don't mark it as an error — read the meaning first.

## ⏭️ Skip Strategy (When to Attempt, When to Skip)

**🚦 TIP 1 — The "Two-Clause Scan" (15-second rule)**
If the sentence has two clauses and a blank between them, it's a Fact-based question: identify the relationship (reason? contrast? result? choice?) and pick the conjunction. This takes 15 seconds — **always attempt**. Never skip a blank-fill conjunction question; the logic is visible on the surface.

**🚦 TIP 2 — Skip the "Sound-Right Trap" on First Pass**
If two options both "sound correct" (e.g., *since* vs *because*, *although* vs *though*), the question is testing a fine distinction — this is a 45-second question. Mark it, finish the easy ones, and return. Rule of thumb on return: for a direct "why" answer pick **because**; for an obvious known reason pick **since**.

**🚦 TIP 3 — Instant-Skip Signal: Long Sentence + Correlative Pair**
If a long error-spotting sentence contains *either/neither/not only/no sooner/hardly*, go straight to the pair-check (Box 3) and the verb-proximity check (Box 13). If both are correct, the error is elsewhere — don't re-read the whole sentence more than twice. If you can't spot it in 45 seconds, skip it; conjunction errors hide in the pair, not in the vocabulary.

**🚦 TIP 4 — Negative Marking Guard**
Never guess between "unless" and "until" without applying Box 5 (time vs condition). A blind guess here is the most common wrong answer in foundation exams — if you can't decide in one reading, leave it unattempted rather than lose 0.25–0.50 marks.
