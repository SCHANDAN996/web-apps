# 🪄 Short Tricks + Skip Strategy — Adjective

## Trick 1 — The "OSASCOMP" Order Box

```
┌─────────────────────────────────────────────┐
│  O-S-A-S-C-O-M-P  (Order of Adjectives)     │
│  Opinion – Size – Age – Shape – Colour –    │
│  Origin – Material – Purpose                │
│  "Our Silly Aunt Sings Cute Old Movie       │
│   Pictures"                                 │
│  ✅ a beautiful small old round red Indian  │
│     wooden writing table                    │
└─────────────────────────────────────────────┘
```
If two adjectives fight for position, ask: *Opinion first, Purpose last.*

## Trick 2 — The "No-Comparative Club"

```
┌─────────────────────────────────────────────┐
│  Words that NEVER take -er / more:          │
│  unique, perfect, universal, supreme,       │
│  complete, empty, full, round, extreme,     │
│  chief, absolute, eternal                   │
│  ❌ more unique  ✅ unique                  │
│  ❌ most perfect ✅ perfect                 │
└─────────────────────────────────────────────┘
```
Memory hook: **"U P U S C E F R E C A E"** — or just remember: *"Something either IS or ISN'T — no degrees."*

## Trick 3 — "Than" Test for Comparatives

```
┌─────────────────────────────────────────────┐
│  See "than"? → Use comparative (-er / more) │
│  See "the + of/in all"? → superlative       │
│  See "of the two"? → "the + comparative"    │
│  ✅ Ravi is the taller of the two brothers. │
└─────────────────────────────────────────────┘
```

## Trick 4 — Senior/Junior Take "to", Not "than"

```
┌─────────────────────────────────────────────┐
│  Latin comparatives + TO:                   │
│  senior, junior, superior, inferior,        │
│  prior, posterior, prefer                   │
│  ✅ He is senior to me. (❌ senior than me) │
│  Hook: "Latin lovers say TO, not THAN."     │
└─────────────────────────────────────────────┘
```

## Trick 5 — Adjective After "Sense Verbs"

```
┌─────────────────────────────────────────────┐
│  look, feel, smell, taste, sound, seem      │
│  → followed by ADJECTIVE, not adverb        │
│  ✅ The soup tastes good. (❌ well)         │
│  ✅ She looks happy.      (❌ happily)      │
│  Hook: "Senses describe, they don't act."   │
└─────────────────────────────────────────────┘
```

## Trick 6 — "The + Adjective = Whole Class"

```
┌─────────────────────────────────────────────┐
│  the rich = rich people (plural verb!)      │
│  the poor, the blind, the old, the young    │
│  ✅ The poor need our help. (❌ needs)      │
└─────────────────────────────────────────────┘
```

## Trick 7 — Little / A Little / The Little

```
┌─────────────────────────────────────────────┐
│  little     = almost none (negative)        │
│  a little   = some (positive)               │
│  the little = all that exists               │
│  Same family: few / a few / the few         │
│  Hook: "No 'a' = No hope."                  │
└─────────────────────────────────────────────┘
```

## Trick 8 — Countable vs Uncountable Switchboard

```
┌─────────────────────────────────────────────┐
│  COUNTABLE:  few, fewer, many, number       │
│  UNCOUNTABLE: little, less, much, quantity  │
│  ✅ fewer books   ✅ less water             │
│  ❌ less students  ❌ fewer milk            │
└─────────────────────────────────────────────┘
```

## Trick 9 — Double Comparative = Proportion

```
┌─────────────────────────────────────────────┐
│  "The + comparative … the + comparative"    │
│  ✅ The higher you go, the colder it gets.  │
│  ❌ The more higher… (never double!)        │
│  ❌ more better, more faster — always wrong │
└─────────────────────────────────────────────┘
```

## Trick 10 — -ed vs -ing Feelings

```
┌─────────────────────────────────────────────┐
│  -ed  = how YOU feel  (I am bored)          │
│  -ing = what CAUSES it (The film is boring) │
│  Hook: "ED = Experienced; ING = Instigator" │
└─────────────────────────────────────────────┘
```

## Trick 11 — Adjective After Indefinite Pronouns

```
┌─────────────────────────────────────────────┐
│  something, anything, nothing, someone…     │
│  → adjective comes AFTER                    │
│  ✅ something interesting (❌ interesting   │
│     something)                              │
└─────────────────────────────────────────────┘
```

## Trick 12 — "Enough" Sits After Adjectives

```
┌─────────────────────────────────────────────┐
│  enough + NOUN  → enough money              │
│  ADJECTIVE + enough → tall enough           │
│  ✅ He is strong enough to lift it.         │
└─────────────────────────────────────────────┘
```

## Trick 13 — One-Word Swap for Spot-the-Error

```
┌─────────────────────────────────────────────┐
│  If a sentence sounds odd, replace the      │
│  adjective with "good". If "good" fits,     │
│  you need an adjective; if "well" fits,     │
│  you need an adverb.                        │
│  "She sings ___" → well ✓ (adverb slot)     │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy

**Tip 1 — Skip the "Over-thinking" trap.** If a sentence like *"She is more unique than her sister"* appears, don't debate philosophy — "unique" has no degrees. Mark the error in 10 seconds and move on. Never spend 45 seconds re-reading a rule you already know.

**Tip 2 — Skip long intervening phrases.** In error-spotting, cross out everything between the noun and the adjective mentally: *"The quality of the apples **were** good"* → strip "of the apples" → "The quality was good." If stripping takes more than 20 seconds, flag the question and return later.

**Tip 3 — Skip unfamiliar vocabulary questions last.** If an adjective-order question has 4+ adjectives you've never seen, don't guess blindly — check only the first two positions (Opinion before Size solves 80% of cases). If that doesn't decide it, mark for review; a wild guess with negative marking costs more than a skip.
