## भाग 2: समय प्रबंधन (15/45 सेकंड नियम)

### ⏱️ 15 सेकंड वाले (तथ्यात्मक — तुरंत उत्तर)

| विषय | उदाहरण |
|---|---|
| दिवस/तिथियाँ | थलसेना दिवस, वायुसेना दिवस, नौसेना दिवस |
| स्थापना वर्ष | DRDO, BSF, NSG, ITBP |
| मुख्यालय | DRDO, सेना भवन, NDA, IMA |
| पुरस्कार क्रम | परमवीर > महावीर > वीर चक्र |
| मिसाइल का प्रकार | पृथ्वी (SSM), आकाश (SAM), ब्रह्मोस (क्रूज़) |
| पहले/सर्वोच्च व्यक्ति | पहले CDS, फील्ड मार्शल, मार्शल ऑफ एयर फोर्स |

### ⏱️ 45 सेकंड वाले (विश्लेषणात्मक — सोचकर उत्तर)

| विषय | उदाहरण |
|---|---|
| कथन-आधारित प्रश्न | "निम्न में से कौन-सा कथन सही है" (मिसाइल + देश + प्रकार का मिश्रण) |
| कालक्रम सजाना | युद्धों/परीक्षणों को सही क्रम में लगाना (1962, 1965, 1971, 1999) |
| जोड़ी मिलान | संगठन ↔ स्थापना वर्ष, मिसाइल ↔ प्रकार |
| नकारात्मक प्रश्न | "निम्न में से कौन CAPF नहीं है" — ध्यान से पढ़ें |
| मंत्रालय-विभाग संबंध | कौन-सा बल किस मंत्रालय के अधीन |

### 🎯 स्कोर मैक्सिमाइज़र विषय (इस अध्याय में)

| विषय | कारण |
|---|---|
| मिसाइलें (अग्नि, पृथ्वी, आकाश, ब्रह्मोस, नाग) | हर परीक्षा में लगभग निश्चित प्रश्न |
| वीरता पुरस्कारों का क्रम | 15 सेकंड में स्कोर, बार-बार पूछा जाता है |
| CAPF + स्थापना वर्ष | SSC/Railway का पसंदीदा क्षेत्र |
| तीनों सेनाओं के दिवस | एक लाइन में तैयार, निश्चित स्कोर |
| पहले व्यक्ति (CDS, सेनाध्यक्ष) | करंट + स्टैटिक दोनों से जुड़ा |

## भाग 3: आँकड़े एवं सूत्र

### 🔢 याद रखने योग्य संख्याएँ

| आँकड़ा | मान |
|---|---|
| भारतीय सेना की कमान | 7 (6 ऑपरेशनल + 1 ट्रेनिंग — ARTRAC, शिमला) |
| वायुसेना की कमान | 7 (5 ऑपरेशनल + 2 फंक्शनल) |
| नौसेना की कमान | 3 (पूर्वी — विशाखापत्तनम, पश्चिमी — मुंबई, दक्षिणी — कोच्चि) |
| CAPF की संख्या | 7 (BSF, CRPF, CISF, ITBP, SSB, असम राइफल्स, NSG) |
| फील्ड मार्शल | 2 (मानेकशॉ, करियप्पा) |
| मार्शल ऑफ द एयर फोर्स | 1 (अर्जन सिंह) |
| अग्नि-V की दूरी | 5,000 किमी से अधिक |
| ब्रह्मोस की गति | लगभग मैक 3 (सुपरसोनिक) |
| परमाणु परीक्षण वर्ष | 1974 (पोखरण-I), 1998 (पोखरण-II) |

### 🧮 क्रम-सूत्र (याद रखने का क्रम)

| श्रेणी | क्रम |
|---|---|
| युद्धकालीन वीरता पुरस्कार | परमवीर चक्र → महावीर चक्र → वीर चक्र |
| शांतिकालीन वीरता पुरस्कार | अशोक चक्र → कीर्ति चक्र → शौर्य चक्र |
| युद्ध कालक्रम | 1947-48 → 1962 → 1965 → 1971 → 1999 |
| अग्नि श्रृंखला (दूरी बढ़ते क्रम में) | अग्नि-I → II → III → IV → V |

> ⚠️ नोट: रक्षा बजट, आयात-निर्यात प्रतिशत, विश्व रैंकिंग जैसे हर साल बदलने वाले आँकड़े जानबूझकर नहीं दिए गए — परीक्षा में ऐसे प्रश्न आएँ तो वर्ष देखकर ही उत्तर दें।
