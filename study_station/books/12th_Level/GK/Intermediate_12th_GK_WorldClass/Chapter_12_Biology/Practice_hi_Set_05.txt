101. लार में मौजूद कौन-सा एंज़ाइम स्टार्च के पाचन की शुरुआत करता है?
(a) एमाइलेज़ (टायलिन) (b) पेप्सिन (c) लाइपेज़ (d) ट्रिप्सिन
उत्तर: (a)
हल: पेप्सिन लुभाने वाला विकल्प है, लेकिन यह आमाशय में प्रोटीन पर क्रिया करता है, स्टार्च पर नहीं। मुख में लार का एमाइलेज़ (टायलिन) स्टार्च को माल्टोज़ में बदलता है, इसलिए उत्तर एमाइलेज़ (टायलिन) है।

102. एक स्वस्थ वयस्क मनुष्य की सामान्य विश्राम अवस्था की हृदय गति लगभग कितनी होती है?

123. हृदय से होकर रक्त प्रवाह का सही क्रम निम्नलिखित में से कौन-सा है?
(a) बायाँ निलय → दायाँ निलय → फेफड़े → बायाँ आलिंद → दायाँ आलिंद → शरीर (b) बायाँ आलिंद → बायाँ निलय → शरीर → दायाँ आलिंद → दायाँ निलय → फेफड़े (c) दायाँ आलिंद → बायाँ आलिंद → दायाँ निलय → बायाँ निलय → शरीर (d) दायाँ आलिंद → दायाँ निलय → फेफड़े → बायाँ आलिंद → बायाँ निलय → शरीर

(a) मुख → ग्रासनली → छोटी आँत → आमाशय → बड़ी आँत → मलाशय (b) मुख → आमाशय → ग्रासनली → छोटी आँत → बड़ी आँत → मलाशय (c) मुख → ग्रासनली → आमाशय → छोटी आँत → बड़ी आँत → मलाशय (d) मुख → ग्रासनली → आमाशय → बड़ी आँत → छोटी आँत → मलाशय
