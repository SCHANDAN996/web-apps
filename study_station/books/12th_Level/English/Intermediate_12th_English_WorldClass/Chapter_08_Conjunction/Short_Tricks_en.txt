# 🪄 Short Tricks + Skip Strategy — Conjunction

## Memory Boxes (Mnemonics)

**Box 1 — FANBOYS (Coordinating Conjunctions)**
```
F — For
A — And
N — Nor
B — But
O — Or
Y — Yet
S — So
```
Trick: *"FANBOYS join equals — word to word, phrase to phrase, clause to clause."*
If the two sides are not grammatically equal, FANBOYS is the wrong choice.

**Box 2 — "No Sooner… THAN"**
```
No sooner had + Subject + V3 … THAN …
```
Trick: *"Sooner is jealous — it only pairs with THAN, never WHEN."*
❌ No sooner had he left **when**… ✅ No sooner had he left **than**…

**Box 3 — "Hardly / Scarcely… WHEN"**
```
Hardly/Scarcely had + Subject + V3 … WHEN …
```
Trick: *"Hardly and Scarcely are shy — they arrive WHEN, not THAN."*
Pair check: **No sooner → THAN | Hardly/Scarcely → WHEN**

**Box 4 — "Not only… But also"**
```
Not only + X + but also + Y   (X and Y must be parallel)
```
Trick: *"Whatever follows 'not only' must mirror what follows 'but also'."*
❌ He not only plays cricket but also football.
✅ He plays not only cricket but also football.

**Box 5 — "Either…Or / Neither…Nor — Verb loves the NEAR subject"**
```
Either the boys or the GIRL IS coming.
Neither the girl nor the BOYS ARE coming.
```
Trick: *"The verb flirts with the nearest subject."* (Proximity Rule)

**Box 6 — "Unless = If…not"**
```
Unless you work hard = If you do not work hard
```
Trick: *"Unless already carries a NOT inside — never add another not."*
❌ Unless you do not work hard… ✅ Unless you work hard…

**Box 7 — "Until vs Unless"**
```
Until  → TIME (Wait until I come.)
Unless → CONDITION (Don't go unless I come.)
```
Trick: *"Until = clock, Unless = condition."*

**Box 8 — "Since vs Because vs As"**
```
Since   → reason already known / obvious
Because → strong, direct reason (answers 'why?')
As      → mild, casual reason
```
Trick: *"BECAUSE is the strongest answer to WHY."*

**Box 9 — "Though/Although — never with BUT"**
```
Although he is rich, he is humble. ✅
Although he is rich, but he is humble. ❌
```
Trick: *"Although and But are enemies — only one can enter the sentence."*
(But 'yet' is allowed: Although…, yet…)

**Box 10 — "So…that / Such…that / Too…to"**
```
So + adjective + that      → He is so weak that he cannot walk.
Such + (a/an) + noun + that → It was such a hot day that we stayed in.
Too + adjective + to        → He is too weak to walk.
```
Trick: *"SO describes, SUCH names, TOO stops the action."*

**Box 11 — "Lest…should"**
```
Work hard lest you should fail.
```
Trick: *"After LEST, always SHOULD — and never a NOT."*
❌ lest you should not fail ✅ lest you should fail

**Box 12 — "As if / As though → Past tense for present imagination"**
```
He talks as if he WERE a king. (He is not.)
```
Trick: *"As if = imagination, so step one tense back."*

**Box 13 — "The reason… is THAT (not because)"**
```
The reason he failed is THAT he was lazy. ✅
The reason… is because… ❌
```
Trick: *"Reason + because = double reason = wrong."*

**Box 14 — "Both…And / Whether…Or — fixed pairs"**
```
both…and | either…or | neither…nor | not only…but also | whether…or
```
Trick: *"Correlatives are married couples — never mix the partners."*
❌ Neither…or ✅ Neither…nor

**Box 15 — "While vs Whereas vs During"**
```
While   → time / contrast (clause follows)
Whereas → sharp contrast only
During  → followed by a NOUN, never a clause
```
Trick: *"During takes a noun; While takes a sentence."*
❌ During he was sleeping ✅ During his sleep / While he was sleeping

## ⏭️ Skip Strategy

**Tip 1 — Skip the "double-negative trap" question only after a 10-second scan.**
If you see *unless / lest / hardly / scarcely* in the sentence, check instantly for an extra "not". This is a 15-second fact-based question — never skip it; it is free marks. Skip only if two options both look grammatically clean and the question is testing an idiom you have never seen — mark it, move on, return later.

**Tip 2 — Long sentence, short decision.**
In error-spotting questions with a long sentence, do not read the whole sentence repeatedly. Locate the conjunction first, then check only its pair (than/when/that/nor) and the parallelism around it. If the pair is correct and parallelism holds, the error is elsewhere — do not waste 45 seconds re-reading.

**Tip 3 — Skip "over-thinking" on Sound-Right traps.**
Phrases like *"No sooner…when"* or *"The reason is because"* sound correct because we hear them in daily speech. If your ear says "correct" but a rule says "wrong", trust the rule, answer in 15 seconds, and never leave such questions blank — they are the examiner's favourite but your easiest win.
