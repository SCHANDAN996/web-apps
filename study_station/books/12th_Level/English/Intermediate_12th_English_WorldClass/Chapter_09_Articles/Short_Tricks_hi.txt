🪄 Short Tricks + Skip Strategy — लेख (Articles)

═══════════════════════════════════
📦 म्नेमोनिक ट्रिक्स (बॉक्स में)
═══════════════════════════════════

┌─────────────────────────────────────┐
│ ट्रिक 1: "A-E-I-O-U = AN"           │
│ स्वर ध्वनि (sound) से शुरू होने    │
│ वाले शब्द से पहले AN। याद रखें —    │
│ ध्वनि देखें, अक्षर नहीं!            │
│ an hour, an honest man, an MBA      │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 2: "University = यू = A"      │
│ u से शुरू होकर भी 'यू' (yu) ध्वनि   │
│ हो तो A लगेगा:                      │
│ a university, a union, a European,  │
│ a one-rupee note (वन = व ध्वनि)     │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 3: "पहली बार A/AN, दूसरी बार  │
│ THE" — कहानी का नियम:               │
│ I saw a dog. The dog was black.     │
│ नया = a/an, पुराना/परिचित = the     │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 4: "THE = दोनों जानते हैं"    │
│ संभाषक और श्रोता दोनों जिस चीज़ को  │
│ जानते हों, उससे पहले THE:           │
│ Close the door. (कौन-सा दरवाज़ा     │
│ दोनों जानते हैं)                    │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 5: "सूरज-चाँद-पृथ्वी = THE"   │
│ ब्रह्मांड में एक ही हो → THE:       │
│ the sun, the moon, the earth,       │
│ the sky, the equator                │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 6: "Superlative + THE = जोड़ी"│
│ the best, the tallest, the most     │
│ beautiful — superlative के साथ      │
│ the अनिवार्य!                       │
│ Ordinal भी: the first, the second   │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 7: "नदी-पर्वत-समुद्र = THE,   │
│ चोटी-द्वीप = NO THE"                │
│ the Ganga, the Himalayas, the       │
│ Indian Ocean — लेकिन Mount Everest, │
│ Sri Lanka (बिना the)                │
│ समूह = the, इकलौता = no the         │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 8: "देश के नाम: अकेला = NO,   │
│ टोली = THE"                         │
│ India, Japan, France (बिना the)     │
│ the USA, the UK, the UAE,           │
│ the Netherlands, the Philippines    │
│ (गणतंत्र/संघ/बहुवचन = the)          │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 9: "भोजन-भाषा-खेल = NO THE"   │
│ I have lunch at 1.                  │
│ Hindi is easy. I play cricket.      │
│ (लेकिन: the Hindi language ✓)       │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 10: "THE + विशेषण = वर्ग"     │
│ the rich = अमीर लोग, the poor =     │
│ गरीब लोग, the blind, the elderly    │
│ (ये plural माने जाते हैं!)          │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 11: "Same, Only, Very = THE   │
│ का परिवार"                          │
│ the same book, the only solution,   │
│ the very man — इन शब्दों से पहले    │
│ the लगभग अनिवार्य                   │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 12: "School जाने का मतलब?"    │
│ पढ़ने जाना = go to school (no the)  │
│ मिलने जाना = go to the school       │
│ उद्देश्य-आधारित = no the;           │
│ इमारत-आधारित = the                  │
│ (school, hospital, church, prison,  │
│ bed — सब पर यही नियम)               │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 13: "पत्र = THE, पत्रिका = NO"│
│ the Times of India, the Hindu       │
│ (समाचार-पत्र = the)                 │
│ लेकिन: Time magazine, India Today   │
│ (पत्रिका/magazine = the नहीं)       │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 14: "Few vs A Few vs The Few" │
│ few = लगभग नहीं (नकारात्मक)         │
│ a few = कुछ (सकारात्मक)             │
│ the few = जो थे, वे सब              │
│ (little/a little/the little भी ऐसे) │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 15: "वाद्ययंत्र = THE,        │
│ खेल = NO"                           │
│ play the guitar, play the flute     │
│ लेकिन: play cricket, play chess     │
│ याद करें: "संगीत में THE, मैदान     │
│ में नहीं"                           │
└─────────────────────────────────────┘

⏭️ Skip Strategy — कब प्रश्न छोड़ें
═══════════════════════════════════

⏭️ टिप 1 — दोनों विकल्प सही लगें तो रुकें:
"a/an" में confusion हो और ध्वनि (sound) पहचानने में 30 सेकंड से ज़्यादा लग रहे हों (जैसे honest/hour/heir जैसे silent-h वाले tricky शब्द), तो प्रश्न mark करके आगे बढ़ें। अंत में शांत दिमाग से ध्वनि बोलकर जाँचें — जल्दबाज़ी में अक्षर देखकर गलती होती है।

⏭️ टिप 2 — लंबा वाक्य + खाली स्थान 3-4 जगह:
जिस प्रश्न में एक ही वाक्य में तीन blanks हों (a/the/zero article का मिश्रण), उसे पहले round में छोड़ दें। ये 'तार्किक' प्रश्न हैं — इन्हें 45 सेकंड का समय दूसरे round में दें, पहले 15-सेकंड वाले तथ्यात्मक प्रश्न (superlative + the, देश के नाम) निपटाएँ।

⏭️ टिप 3 — अपरिचित उदाहरण वाला नियम:
अगर विकल्पों में ऐसा शब्द/वाक्यांश हो जिसे आपने कभी नहीं पढ़ा (जैसे कोई idiom — "in the red", "at a loss"), तो अनुमान लगाने के बजाय छोड़ दें। Negative marking में अनजान idiom पर guess = घातक। जो नियम याद है उसी पर भरोसा करें, गढ़ा हुआ pattern न बनाएँ।

परीक्षा हॉल में Articles के अधिकांश प्रश्न इन्हीं 5 मुख्य नियमों से हल हो जाते हैं:
① ध्वनि देखो (a/an) ② दूसरी बार = the ③ एक ही है = the
④ Superlative/Ordinal = the ⑤ भोजन-भाषा-खेल-देश = no the
