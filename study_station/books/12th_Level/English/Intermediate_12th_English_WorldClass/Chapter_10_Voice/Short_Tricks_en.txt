# 🪄 Short Tricks + Skip Strategy — Active & Passive Voice

---

## Trick 1 — The "By-Whom?" Test (3 seconds)

```
┌─────────────────────────────────────────────┐
│  See a Passive sentence? Ask: "BY WHOM?"    │
│  The answer = the OBJECT of the Active.     │
│  "The letter was written BY RAM."           │
│  → Active: RAM wrote the letter.            │
└─────────────────────────────────────────────┘
```

## Trick 2 — The "V3 Detector"

```
┌─────────────────────────────────────────────┐
│  is/am/are/was/were/been/being + V3         │
│  = PASSIVE. 100% guaranteed.                │
│  No be-verb + V3? It is NOT passive.        │
│  ("He has gone" = Active, not Passive!)     │
└─────────────────────────────────────────────┘
```

## Trick 3 — Tense Swap Table (Memorize as a chant)

```
┌─────────────────────────────────────────────┐
│  Present Simple  → is/am/are + V3           │
│  Past Simple     → was/were + V3            │
│  Future Simple   → will be + V3             │
│  Present Cont.   → is/am/are BEING + V3     │
│  Past Cont.      → was/were BEING + V3      │
│  Perfect tenses  → has/have/had BEEN + V3   │
│  Chant: "Simple-BE, Continuous-BEING,       │
│          Perfect-BEEN"                      │
└─────────────────────────────────────────────┘
```

## Trick 4 — The "Double Object" Shortcut

```
┌─────────────────────────────────────────────┐
│  "He gave ME a BOOK." → Two passives:       │
│  ① I was given a book by him.  (person 1st) │
│  ② A book was given to me by him.           │
│  Exam favourite = ① (person as subject).    │
└─────────────────────────────────────────────┘
```

## Trick 5 — Modal Magic

```
┌─────────────────────────────────────────────┐
│  Modal + be + V3 — modal NEVER changes.     │
│  can/could/may/might/shall/should/          │
│  will/would/must/ought to → just add        │
│  "be + V3" after it.                        │
│  "She can solve it" → "It can be solved."   │
└─────────────────────────────────────────────┘
```

## Trick 6 — Imperative Sentences: "Let" Formula

```
┌─────────────────────────────────────────────┐
│  Order/Request → Let + object + be + V3     │
│  "Open the door." → "Let the door be        │
│  opened."                                     │
│  Negative: "Do not touch it." →             │
│  "Let it not be touched."                   │
└─────────────────────────────────────────────┘
```

## Trick 7 — "It is said that…" Pattern

```
┌─────────────────────────────────────────────┐
│  "People say that he is honest."            │
│  → It is said that he is honest.            │
│  → He is said to be honest.                 │
│  Verbs: say, believe, think, know, report,  │
│  suppose, expect.                           │
└─────────────────────────────────────────────┘
```

## Trick 8 — No-Passive Verbs (The "VIP List")

```
┌─────────────────────────────────────────────┐
│  Intransitive verbs NEVER take passive:     │
│  go, come, run, sleep, die, arrive, happen, │
│  occur, exist, rain, sit, stand, lie.       │
│  "The accident was happened" ❌             │
│  "The accident happened" ✔                  │
└─────────────────────────────────────────────┘
```

## Trick 9 — Preposition Glue

```
┌─────────────────────────────────────────────┐
│  Verb + preposition stays GLUED in passive: │
│  "They laughed at him."                     │
│  → "He was laughed AT by them." ✔           │
│  Never drop: at, for, to, with, of.         │
└─────────────────────────────────────────────┘
```

## Trick 10 — "By" is Not Always "By"

```
┌─────────────────────────────────────────────┐
│  known TO, surprised AT, amazed AT,         │
│  annoyed WITH, contained IN, cut WITH,      │
│  filled WITH, obliged TO.                   │
│  "I know him" → "He is known TO me." ✔      │
└─────────────────────────────────────────────┘
```

## Trick 11 — Quasi-Passive Trap

```
┌─────────────────────────────────────────────┐
│  "Rice sells cheap." / "The book reads      │
│  well." — Active form, Passive meaning.     │
│  Do NOT convert these. Examiner loves       │
│  offering "Rice is sold cheap" as bait.     │
└─────────────────────────────────────────────┘
```

## Trick 12 — Who Did It? Drop the Agent

```
┌─────────────────────────────────────────────┐
│  If the doer is obvious/unknown (someone,   │
│  people, they, police) → DROP "by…"         │
│  "Someone stole my watch."                  │
│  → "My watch was stolen." (NOT "by someone")│
└─────────────────────────────────────────────┘
```

## Trick 13 — Question Conversion in 2 Steps

```
┌─────────────────────────────────────────────┐
│  "Why did he beat you?"                     │
│  Step 1: Wh-word stays first → "Why…"       │
│  Step 2: Passive of the rest →              │
│  "Why were you beaten by him?"              │
│  Helping verb comes BEFORE the new subject. │
└─────────────────────────────────────────────┘
```

## Trick 14 — The 5-Second Elimination

```
┌─────────────────────────────────────────────┐
│  In options, instantly REJECT any passive   │
│  that:                                       │
│  ① changes the tense,                        │
│  ② drops "be/being/been",                    │
│  ③ uses V2 instead of V3,                    │
│  ④ adds "by" to an intransitive verb.        │
│  Usually 2 of 4 options die this way.        │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy

**Skip Tip 1 — The 20-Second Rule:** If after 20 seconds you cannot identify the tense of the original sentence, mark it and move on. Voice questions are pure formula — if the formula doesn't click fast, it won't click at all under pressure. Return in the review round.

**Skip Tip 2 — Skip "Double Passive" Monsters:** Sentences like "It is believed by them that the work has been done by him" with 4 similar-looking options are designed to eat 90 seconds. If two options differ only in "has been/had been", pick by matching the original tense — don't re-read the whole sentence.

**Skip Tip 3 — Never Skip These (Free Marks):** Modal + be + V3, imperative "Let…be" sentences, and simple present/past conversions are 10-second gifts. In any paper, attempt these first within the Voice block, then tackle continuous/perfect conversions.
