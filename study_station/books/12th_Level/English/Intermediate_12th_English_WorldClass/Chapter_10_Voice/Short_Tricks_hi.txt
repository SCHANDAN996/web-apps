# 🪄 शॉर्ट ट्रिक्स + Skip Strategy — वाच्य (Voice)

## 🎯 15 म्नेमोनिक ट्रिक्स

**ट्रिक 1 — "SOB" फॉर्मूला (Passive की रचना)**
```
┌─────────────────────────────────────────────┐
│ S → O → B : Subject-Object-BE               │
│ Active:  Ram (S) eats (V) mango (O)         │
│ Passive: Mango (O) + is + eaten (V3) + by Ram│
│ याद रखें: Object आगे आया, BE साथ लाया, V3 बनाया │
└─────────────────────────────────────────────┘
```

**ट्रिक 2 — "V3 ही पहचान"**
```
┌─────────────────────────────────────────────┐
│ Passive में मुख्य क्रिया हमेशा V3 (Past Participle)│
│ is/am/are/was/were/been/being + V3          │
│ V3 नहीं दिखे = Passive नहीं!                 │
└─────────────────────────────────────────────┘
```

**ट्रिक 3 — Tense-वार BE रूप ("IWAB" शृंखला)**
```
┌─────────────────────────────────────────────┐
│ Present Simple → is/am/are + V3             │
│ Past Simple    → was/were + V3              │
│ Future Simple  → will be + V3               │
│ Continuous     → is being / was being + V3  │
│ Perfect        → has been / had been + V3   │
│ याद: "Simple-BE, Continuous-BEING, Perfect-BEEN"│
└─────────────────────────────────────────────┘
```

**ट्रिक 4 — "No Passive Zone" (जहाँ Passive मना है)**
```
┌─────────────────────────────────────────────┐
│ Intransitive verbs (Object नहीं लेतीं) = No Passive│
│ go, come, sleep, die, arrive, happen, cry   │
│ ❌ "He was died" ✓ "He died"                │
└─────────────────────────────────────────────┘
```

**ट्रिक 5 — Modal का "MBV3" नियम**
```
┌─────────────────────────────────────────────┐
│ Modal (can/must/should/may) + be + V3       │
│ Active:  She can solve it.                  │
│ Passive: It can be solved (by her).         │
│ याद: Modal के बाद हमेशा "be" (कभी is/was नहीं)   │
└─────────────────────────────────────────────┘
```

**ट्रिक 6 — "By-हटाओ" ट्रिक (Agent कब छोड़ें)**
```
┌─────────────────────────────────────────────┐
│ by + someone/people/they/the police → हटा दो │
│ Someone stole my bike → My bike was stolen. │
│ कारण: Agent अज्ञात/अनावश्यक है              │
└─────────────────────────────────────────────┘
```

**ट्रिक 7 — Double Object का "PO नियम"**
```
┌─────────────────────────────────────────────┐
│ give/send/teach + दो Objects (Person + Thing)│
│ दोनों से Passive संभव, पर Person वाला ज़्यादा पूछा जाता│
│ He gave me a book → I was given a book.     │
│                 → A book was given to me.   │
└─────────────────────────────────────────────┘
```

**ट्रिक 8 — Preposition "चिपकी रहती है"**
```
┌─────────────────────────────────────────────┐
│ Phrasal verb की preposition कभी न छोड़ें     │
│ They laughed at him → He was laughed at.    │
│ ❌ He was laughed (at गायब = गलत)            │
└─────────────────────────────────────────────┘
```

**ट्रिक 9 — "Let" का Special Formula**
```
┌─────────────────────────────────────────────┐
│ Active:  Let him do the work.               │
│ Passive: Let the work be done (by him).     │
│ याद: Let + Object + be + V3                 │
└─────────────────────────────────────────────┘
```

**ट्रिक 10 — Imperative का "LBD" कोड**
```
┌─────────────────────────────────────────────┐
│ Order/Request → Let + Object + be + V3      │
│ Open the door → Let the door be opened.     │
│ LBD = Let-Be-Done                           │
└─────────────────────────────────────────────┘
```

**ट्रिक 11 — "It is said" पैटर्न (Reporting Verbs)**
```
┌─────────────────────────────────────────────┐
│ People say that he is honest.               │
│ → It is said that he is honest.             │
│ → He is said to be honest.                  │
│ दोनों रूप सही — परीक्षा में दोनों आते हैं!      │
└─────────────────────────────────────────────┘
```

**ट्रिक 12 — Question में "Wh-आगे" नियम**
```
┌─────────────────────────────────────────────┐
│ Active:  Why did he beat you?               │
│ Passive: Why were you beaten by him?        │
│ Wh-word अपनी जगह, बाकी Passive बाद में       │
└─────────────────────────────────────────────┘
```

**ट्रिक 13 — "Being vs Been" 10-सेकंड टेस्ट**
```
┌─────────────────────────────────────────────┐
│ Continuous दिखे (-ing) → being + V3         │
│ Perfect दिखे (has/had) → been + V3          │
│ The work is being done. (चल रहा है)          │
│ The work has been done. (हो चुका है)         │
└─────────────────────────────────────────────┘
```

**ट्रिक 14 — "Quasi-Passive" पहचान**
```
┌─────────────────────────────────────────────┐
│ कुछ वाक्य Passive दिखते हैं, Passive नहीं होते:  │
│ The shop opens at 9. / Rice sells cheap.    │
│ ये Active ही हैं — जबरन Passive मत बनाओ!      │
└─────────────────────────────────────────────┘
```

**ट्रिक 15 — "Infinitive Passive" ट्रिक**
```
┌─────────────────────────────────────────────┐
│ to + V1 → to be + V3                        │
│ I want someone to help me.                  │
│ → I want to be helped.                      │
│ याद: to दिखे तो "to be + V3" लगाओ            │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**1. दो विकल्प लगभग एक जैसे दिखें और Tense संदिग्ध हो**
अगर "has been done" और "had been done" में फँसे हों और वाक्य में समय-संकेत (yesterday, already, before) साफ़ न हो — 45 सेकंड से ज़्यादा न दें। पहले बाकी पेपर निपटाएँ, अंत में समय-संकेत ढूँढकर लौटें।

**2. Reporting Verb वाले लंबे वाक्य (It is said / He is said)**
दोनों रूप सही हो सकते हैं, इसलिए विकल्पों को ध्यान से पढ़ना ही पड़ता है। अगर पहली नज़र में दोनों पैटर्न विकल्पों में न दिखें, तो प्रश्न को mark करके आगे बढ़ें — जल्दबाज़ी में "to be" और "to have been" में गलती सबसे आम है।

**3. अपरिचित Phrasal Verb का Passive**
अगर verb की preposition ही याद न हो (जैसे "look into", "put off"), तो अनुमान लगाने के बजाय छोड़ दें — गलत preposition वाला विकल्प जानबूझकर रखा जाता है। Negative marking में यही समझदारी है।
