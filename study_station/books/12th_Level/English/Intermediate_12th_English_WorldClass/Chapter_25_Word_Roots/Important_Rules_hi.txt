# 📋 महत्वपूर्ण नियम एवं टिप्स — शब्द मूल (Roots) एवं रूपविज्ञान (Morphology)

---

## (क) 12 हाई-यील्ड नियम

| # | नियम | उदाहरण | परीक्षक का जाल |
|---|---|---|---|
| 1 | एक ही root से बने शब्दों का अर्थ root के अर्थ से जुड़ा होता है | **dict** = बोलना → dictate, predict, verdict, dictionary | "predict" को "लिखना" समझना — dict बोलना है, लिखना नहीं (लिखना = scrib/script) |
| 2 | **port** = ले जाना (carry) | transport (पार ले जाना), import (अंदर लाना), export (बाहर ले जाना), portable | "report" में port = carry ही है (सूचना वापस लाना: re + port) — अलग root मत समझो |
| 3 | **spect** = देखना | inspect (अंदर देखना), respect (फिर से देखना), spectator, prospect | "suspect" में spect छिपा है (नीचे से देखना = शक करना) |
| 4 | **ject** = फेंकना (throw) | reject (वापस फेंकना), inject (अंदर डालना), project (आगे फेंकना), eject | "object" = सामने फेंकी गई चीज़ → वस्तु/आपत्ति — दोनों अर्थ याद रखो |
| 5 | **cred** = विश्वास | credible (विश्वसनीय), incredible, credit, creed | "credulous" (भोला-भाला) ≠ "credible" (विश्वसनीय) — परीक्षक इन्हें बदलकर पूछता है |
| 6 | **bene/mal** = अच्छा/बुरा | benefit, benevolent / malnutrition, malicious, malfunction | "malevolent" (दुर्भावनापूर्ण) को "benevolent" से भ्रमित होना — एक अक्षर का खेल |
| 7 | **chron** = समय | chronology, chronic (पुरानी बीमारी), synchronize, anachronism | "chronic" का अर्थ "गंभीर" नहीं, "दीर्घकालिक" है |
| 8 | **bio** = जीवन, **geo** = पृथ्वी, **aqua** = जल | biology, biography / geography, geology / aquarium, aquatic | "biography" = जीवन + लेखन (graph = लिखना) — root जोड़कर अर्थ बनाओ |
| 9 | Prefix अर्थ बदलता है, suffix शब्द-वर्ग (part of speech) बदलता है | happy → un**happy** (अर्थ बदला); happy → happi**ness** (विशेषण → संज्ञा) | "-ful" और "-less" उल्टे हैं: careful ≠ careless |
| 10 | नकारात्मक prefixes: un-, in-/im-/il-/ir-, dis-, mis- | impossible (p से पहले im-), illegal (l से पहले il-), irregular (r से पहले ir-) | "inflammable" = ज्वलनशील (नकारात्मक नहीं!) — सबसे बड़ा जाल |
| 11 | **-phile** = प्रेमी, **-phobe** = डर/घृणा | bibliophile (पुस्तक-प्रेमी) / claustrophobe | "philanthropist" (मानव-प्रेमी) vs "misanthrope" (मानव-द्वेषी) — mis = घृणा |
| 12 | अज्ञात शब्द = prefix + root + suffix तोड़कर अर्थ निकालो | un + believ(e) + able = जिस पर विश्वास न किया जा सके | विकल्प में root का शाब्दिक अर्थ देकर भ्रमित करना (जैसे "transport" = "बंदरगाह") |

## (ख) समय प्रबंधन: 15/45 सेकंड नियम

**⏱️ 15 सेकंड — तथ्यात्मक (Fact-based) प्रश्न** — या तो root याद है या नहीं; सोचने से उत्तर नहीं बदलेगा:
- सीधा root-अर्थ मिलान: "'chron' का अर्थ क्या है?"
- एक शब्द का अर्थ root से: "'benevolent' का अर्थ?"
- Prefix/suffix पहचान: "'impossible' में prefix कौन-सा है?"
- One-word substitution जो root पर आधारित है: "पुस्तक-प्रेमी = ?"

**⏱️ 45 सेकंड — तार्किक (Inference-based) प्रश्न** — root को संदर्भ में लगाना पड़ता है:
- अज्ञात शब्द का अर्थ वाक्य के संदर्भ से निकालना (root + context clues)
- Odd one out: चार शब्दों में से एक जिसका root अलग है
- गद्यांश (RC) में दिए शब्द का अर्थ root से अनुमान लगाना
- शब्द-विन्यास (word formation) वाले प्रश्न जहाँ prefix + root + suffix तीनों तोड़ने पड़ें

**रणनीति:** पहले चक्कर में सारे 15-सेकंड वाले प्रश्न करो; 45-सेकंड वालों को दूसरे चक्कर में। जिस root पर 30 सेकंड में कोई संकेत न मिले, उसे अंधा अनुमान लगाने के बजाय छोड़ो (negative marking से बचो)।

## (ग) रूपात्मक सूत्र (Morphology Formulas)

**सूत्र 1: शब्द = Prefix + Root + Suffix**
> un + believe + able → unbelievable (जिस पर विश्वास न हो)

**सूत्र 2: Prefix अर्थ बदलता है (शब्द-वर्ग वही रहता है)**

| Prefix | अर्थ | उदाहरण |
|---|---|---|
| pre- | पहले | predict, preview |
| post- | बाद में | postpone, postmortem |
| re- | फिर से | rewrite, return |
| anti- | विरुद्ध | antibiotic, antisocial |
| inter- | बीच में | international, interrupt |
| sub- | नीचे | submarine, subway |
| trans- | पार | transport, translate |
| mis- | गलत | mislead, misunderstand |

**सूत्र 3: Suffix शब्द-वर्ग बदलता है**

| Suffix | बनाता है | उदाहरण |
|---|---|---|
| -tion/-sion | संज्ञा (क्रिया से) | act → action, decide → decision |
| -ness | संज्ञा (विशेषण से) | kind → kindness |
| -ful / -less | विशेषण | hopeful / hopeless |
| -ly | क्रिया-विशेषण | quick → quickly |
| -er/-or/-ist | कर्ता (संज्ञा) | teach → teacher, act → actor, art → artist |
| -able/-ible | विशेषण (योग्य) | readable, visible |

**सूत्र 4: Root-परिवार एक साथ याद करो**
> **spect** (देखना): in + spect = निरीक्षण | re + spect = सम्मान | pro + spect = संभावना | spect + ator = दर्शक | circum + spect = सावधान

**सूत्र 5: संयोजन नियम (in- का रूप बदलना)**
> in- + possible → **im**possible (p/b/m से पहले im-)
> in- + legal → **il**legal (l से पहले il-)
> in- + regular → **ir**regular (r से पहले ir-)

**सूत्र 6: अज्ञात शब्द का 3-कदम हल**
1. Prefix पहचानो → दिशा/नकारात्मकता पकड़ो
2. Root पहचानो → मूल अर्थ पकड़ो
3. Suffix पहचानो → शब्द-वर्ग पकड़ो → विकल्पों से मिलाओ
