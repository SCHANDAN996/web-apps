## ⚡ 3 सेकंड की रूट-पहचान विधि

1. **पहले उपसर्ग (Prefix) पकड़ो** — शब्द की शुरुआत देखो: un-, re-, dis-, pre-, anti- → दिशा/भाव मिल गया।
2. **फिर मूल (Root) पकड़ो** — बीच का हिस्सा: dict, port, spect → मूल अर्थ मिल गया।
3. **अंत में प्रत्यय (Suffix)** — -tion, -able, -ist → शब्द-भेद (noun/adjective) पता चल गया।

**उदाहरण:** Un-pre-dict-able → Un (नहीं) + pre (पहले) + dict (कहना) + able (योग्य) = "जिसे पहले से न कहा जा सके" ✅

## 🚫 Skip Strategy — कब प्रश्न छोड़ें

```
┌─────────────────────────────────────────────────┐
│ SKIP नियम 1: अनजाना रूट + अनजाने चारों विकल्प   │
│ अगर न रूट पहचाना, न कोई विकल्प जाना-पहचाना      │
│ लगा — तुक्का न मारें, छोड़ दें। Negative        │
│ marking में अनजान शब्द पर guess = घाटा।         │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ SKIP नियम 2: दो विकल्पों में 50-50 फँसे हों     │
│ रूट से अर्थ तक पहुँचे, पर दो विकल्प लगभग        │
│ समान अर्थ के हों (जैसे "घृणा" vs "तिरस्कार") —  │
│ 45 सेकंड से ज़्यादा न दें; mark करके आगे बढ़ें, │
│ अंत में समय बचे तो लौटें।                       │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│ SKIP नियम 3: लंबा गद्यांश-आधारित शब्दार्थ प्रश्न │
│ पैराग्राफ में underline शब्द का अर्थ पूछा हो    │
│ और पैराग्राफ भारी हो — पहले बाकी आसान प्रश्न   │
│ निपटाएँ; यह 'तार्किक' प्रश्न है, इसे 45 सेकंड   │
│ का पूरा समय अंत में दें।                        │
└─────────────────────────────────────────────────┘
```

## 🧠 अंतिम सूत्र

> **"Prefix बताए दिशा, Root बताए अर्थ, Suffix बताए जाति — तीनों मिलें तो शब्द हुआ साथी।"**

परीक्षा हॉल में अनजाना शब्द देखते ही घबराएँ नहीं — उसे तीन टुकड़ों में तोड़िए। अधिकांश अनजाने शब्द इसी एक तरीके से हल हो जाते हैं।
