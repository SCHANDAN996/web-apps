# 🪄 Short Tricks + Skip Strategy — Word Roots & Morphology

---

## Trick 1 — The "Word Surgery" Method

```
┌─────────────────────────────────────────────┐
│  Any long word = PREFIX + ROOT + SUFFIX     │
│  Cut it into 3 parts BEFORE guessing.       │
│  un + believe + able = "not able to be      │
│  believed" — meaning solved in 5 seconds!   │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│  BENE = good → benefit, benevolent,         │
│  beneficial, benediction                    │
│  MAL  = bad  → malicious, malnutrition,     │
│  malfunction, malady                        │
│  Memory hook: "BENE fits you, MAL harms     │
│  you." (BENE = Benefit, MAL = Malignant)    │
└─────────────────────────────────────────────┘
```

## Trick 3 — The Number Family (Never confuse again)

```
┌─────────────────────────────────────────────┐
│  UNI=1 (uniform), BI=2 (bicycle),           │
│  TRI=3 (triangle), QUAD=4 (quadrilateral),  │
│  PENT=5 (pentagon), DEC=10 (decade),        │
│  CENT=100 (century), MILLE/KILO=1000        │
│  (millennium, kilometer)                    │
│  Careful: MILLI- = 1/1000 (millimeter,      │
│  milligram) — the small one!                │
│  Hook: "Uni-Bi-Tri rode a Quad bike to the  │
│  Pentagon in December, a Century ago."      │
└─────────────────────────────────────────────┘
```

## Trick 13 — The Negative-Prefix Eliminator

```
┌─────────────────────────────────────────────┐
│  UN-, IN-/IM-/IL-/IR-, DIS-, MIS-, NON-,    │
│  ANTI- all flip meaning to negative.        │
│  In antonym questions, a word with a        │
│  negative prefix often pairs with its       │
│  positive root — check that option first.   │
│  e.g., happy ↔ unhappy, legal ↔ illegal     │
└─────────────────────────────────────────────┘
```


## ⏭️ Skip Strategy

**Skip Tip 1 — The Unknown-Root Skip:**
If you cannot identify even ONE familiar part (prefix, root, or suffix) in the word after 10 seconds, mark it and move on. Root-based questions are meant to be 15-second questions; a totally unfamiliar word will not become familiar by staring at it. Return only if time remains.

**Skip Tip 2 — The Two-Tempting-Options Skip:**
When two options both look correct (e.g., "fear of water" vs "fear of heights" for *hydrophobia*), do NOT gamble immediately. Check the root: *hydro* = water. If you still can't decide in 20 seconds, skip — a wrong answer costs negative marking, a skip costs nothing.

**Skip Tip 3 — The Over-Thinking Trap:**
Your first root-based instinct is usually right. If you broke the word down (e.g., *mal + nutrition* = bad nutrition) and got an answer, lock it in. Do not talk yourself out of it by imagining rare exceptions — examiners design distractors exactly for over-thinkers. Answer, mark, move.
