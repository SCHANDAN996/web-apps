# 🪄 Short Tricks + Skip Strategy — Direct & Indirect Speech

---

## Trick 1 — The "S-P-O-R-T" Rule for Reporting Verbs

```
┌─────────────────────────────────────────────┐
│  S — Said        → (no object) stays "said" │
│  P — Person told → "said to" becomes "told" │
│  O — Order       → imperative → ordered     │
│  R — Request     → imperative → requested   │
│  T — Truth       → universal truth: NO      │
│                    tense change!            │
└─────────────────────────────────────────────┘
```
**Memory hook:** *"SPORT players follow orders and never change the truth."*

---

## Trick 2 — The "Back-Shift Ladder" (Tense Change)

Every tense steps **one rung down** the ladder:

```
Present Simple      → Past Simple
Present Continuous  → Past Continuous
Present Perfect     → Past Perfect
Past Simple         → Past Perfect
Past Perfect        → Past Perfect (no further rung!)
will / shall        → would / should
can / may           → could / might
```

**Mnemonic:** *"When the reporter arrives late, every tense takes one step BACK."*

---

## Trick 3 — The "No-Change Trio" 🚫

```
┌─────────────────────────────────────────────┐
│  These NEVER change tense in Indirect:      │
│  1. Universal truths / proverbs             │
│     ("The sun rises in the east.")          │
│  2. Historical facts                        │
│     ("India got freedom in 1947.")          │
│  3. Past Perfect & Past Perfect Continuous  │
│     (already at the bottom of the ladder)   │
└─────────────────────────────────────────────┘
```
**Mnemonic:** *"Truth, History, and Perfect-Past are too stubborn to move."*

## Trick 4 — Pronoun Formula: **S-O-N**

```
┌─────────────────────────────────────────────┐
│  S — Subject: 1st person (I, we) changes    │
│      according to the SUBJECT of reporting  │
│      verb.                                  │
│  O — Object: 2nd person (you) changes       │
│      according to the OBJECT of reporting   │
│      verb.                                  │
│  N — No change: 3rd person (he, she, it,    │
│      they) stays the same.                  │
└─────────────────────────────────────────────┘
```
**Example:** He said to me, "I will help you."
→ He told me that **he** (S→subject 'he') would help **me** (O→object 'me').

**Mnemonic:** *"SON follows his parents — 1st follows Subject, 2nd follows Object, 3rd follows Nobody."*

## Trick 5 — Time & Place Words: "NOW-HERE Goes THERE-THEN"

| Direct | Indirect |
|---|---|
| now | then |
| here | there |
| this | that |
| these | those |
| today | that day |
| tonight | that night |
| yesterday | the previous day / the day before |
| tomorrow | the next day / the following day |
| ago | before |
| last night | the night before |
| next week | the following week |

**Mnemonic:** *"Near words become FAR words — the reporter stands at a distance, so 'this/here/now' all move away."*

## Trick 6 — Question Type Detector (30-second rule)

Look at the reported sentence's **first word**:

```
┌──────────────────────────────────────────────────┐
│  Starts with Wh-word (what, why, where...)?      │
│      → Keep the Wh-word, NO "if/whether"         │
│  Starts with helping verb (is, do, has, can...)? │
│      → Use "if" or "whether"                     │
│  Either way: question becomes a STATEMENT        │
│      (subject before verb, no question mark!)    │
└──────────────────────────────────────────────────┘
```
**Mnemonic:** *"Wh keeps its crown; Yes/No wears the IF cap."*

## Trick 7 — Imperative Sentence Shortcut

```
Order/Command  → ordered + to + V1   (negative: not to + V1)
Request        → requested + to + V1
Advice         → advised + to + V1
Forbidding     → forbade + to + V1
"Let us..."    → suggested / proposed + that...should
```

**Mnemonic:** *"Bosses ORDER, friends REQUEST, teachers ADVISE — all end in TO."*

---

## Trick 8 — Exclamatory Sentence Trick

```
"What a / How..."  → exclaimed with joy/sorrow/surprise
                     + that + (great/very replaces "what a/how")
"Hurrah!"          → exclaimed with joy
"Alas!"            → exclaimed with sorrow/grief
"Bravo!"           → exclaimed with appreciation
```

**Example:** He said, "What a beautiful day!"
→ He exclaimed with joy that it was a **very** beautiful day.

**Mnemonic:** *"Emotions get named, 'what a' becomes 'very'."*

---

## Trick 9 — The "Said-To Trap" Detector ⚠️

```
┌──────────────────────────────────────────────────┐
│  "said to + object"  → told + object (NO "to")   │
│  ✗ He told to me that...                         │
│  ✓ He told me that...                            │
│  ✗ He said me that...                            │
│  ✓ He said to me that... / He told me that...    │
└──────────────────────────────────────────────────┘
```
**Mnemonic:** *"TOLD is greedy — it grabs the object directly and kicks out the 'to'."*

---

## Trick 10 — "Must" Has Two Faces

```
must (duty/obligation)     → had to
must (deduction/certainty) → must (unchanged)
```

**Example:** "I must finish the work." → He said he **had to** finish the work.
"You must be tired." → He said I **must** be tired.

**Mnemonic:** *"Duty must travel; deduction must stay."*

---

## Trick 11 — Optative Sentences (Wishes & Prayers)

```
"May you succeed!"  → wished/prayed + that + subject + might
"Would that..."     → wished + that
```

**Example:** Mother said, "May God bless you!"
→ Mother **prayed that** God **might** bless me.

**Mnemonic:** *"MAY becomes MIGHT when wishes travel through time."*

---

## Trick 12 — The "That" Deletion Test

In options, if the sentence is a **statement**, "that" is optional — both "He said that he was ill" and "He said he was ill" are correct. But in **questions**, never insert "that" before if/whether or the Wh-word.

**Mnemonic:** *"Statements may carry THAT; questions never do."*

---

## Trick 13 — Reporting Verb in Present/Future = Freeze the Tense ❄️

```
┌──────────────────────────────────────────────────┐
│  He SAYS, "I am busy."    → He says that he IS   │
│                             busy. (NO change!)   │
│  He WILL SAY, "I am busy."→ He will say that he  │
│                             IS busy. (NO change!)│
│  Tense changes ONLY when reporting verb is PAST. │
└──────────────────────────────────────────────────┘
```
**Mnemonic:** *"Past reporter pulls tenses back; present/future reporter freezes them."*

## ⏭️ Skip Strategy — When to Skip & Return

**Tip 1 — Skip the "double-trap" question first.**
If a question mixes **two conversions at once** (e.g., an imperative inside a question, or pronoun + tense + time-word all changing), mark it and return after finishing the 15-second fact-based ones (simple tense back-shift, said→told). Multi-change questions eat 45+ seconds and are where silly slips happen.

**Tip 2 — Eliminate by the reporting verb alone.**
Before reading the full sentence, check the options' reporting verbs. If the Direct speech is a request and two options say "ordered," delete both instantly. Often **2 of 4 options die on the reporting verb**, and 1 more dies on tense — leaving the answer in under 20 seconds.

**Tip 3 — Never skip the "universal truth" question.**
It looks tricky but is a guaranteed 15-second gift: if the reported clause is a fact/proverb, the tense does **not** change. Examiners place it to scare you — collect the free mark and move on.
