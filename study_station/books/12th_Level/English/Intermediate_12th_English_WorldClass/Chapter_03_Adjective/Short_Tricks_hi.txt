# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — विशेषण (Adjective)

---

## 🎯 12 म्नेमोनिक ट्रिक्स (बॉक्स में)

---

**ट्रिक 1 — क्रम याद रखने का जादू: "OSASCOMP"**

```
┌─────────────────────────────────────────────┐
│  O — Opinion (राय)        → beautiful       │
│  S — Size (आकार)          → big             │
│  A — Age (उम्र)           → old             │
│  S — Shape (आकृति)        → round           │
│  C — Colour (रंग)         → red             │
│  O — Origin (मूल)         → Indian          │
│  M — Material (पदार्थ)    → wooden          │
│  P — Purpose (उद्देश्य)   → walking (stick) │
└─────────────────────────────────────────────┘
```
याद करें: **"ओसास-कॉम्प"** — एक काल्पनिक कंपनी का नाम।
✅ a beautiful big old round red Indian wooden walking stick
❌ a wooden red big beautiful stick

---

**ट्रिक 2 — Comparative में "than" अनिवार्य**

```
┌─────────────────────────────────────────────┐
│  जोड़ी याद रखो:                             │
│  "Comparative की शादी than से" 💍           │
│  taller THAN, better THAN, more honest THAN │
│  ❌ He is taller from me.                   │
│  ✅ He is taller than me.                   │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 3 — "Superior-Inferior" लैटिन परिवार — "to" लगता है, "than" नहीं**

```
┌─────────────────────────────────────────────┐
│  S-I-J-S-P (सिज़-प) परिवार:                 │
│  Superior, Inferior, Junior, Senior, Prefer │
│  → इनके साथ हमेशा "to"                      │
│  ✅ He is senior to me.                     │
│  ❌ He is senior than me.                   │
│  म्नेमोनिक: "लैटिन लोग than से नफरत करते हैं"│
└─────────────────────────────────────────────┘
```

---

**ट्रिक 4 — "The + Adjective = पूरी जाति"**

```
┌─────────────────────────────────────────────┐
│  the rich = अमीर लोग (वर्ग)                 │
│  the poor = गरीब लोग                        │
│  the blind = अंधे लोग                       │
│  ट्रिक: "The लगा तो Adjective बना Noun-समूह"│
│  ✅ The rich should help the poor.          │
└─────────────────────────────────────────────┘
```

**ट्रिक 5 — Double Comparative वर्जित**

```
┌─────────────────────────────────────────────┐
│  "एक ही शादी, दो बार नहीं!"                 │
│  ❌ more better, more taller, most best     │
│  ✅ better, taller, best                    │
│  -er/more में से एक ही चुनो।               │
└─────────────────────────────────────────────┘
```

**ट्रिक 6 — "No sooner... than" बनाम Comparative**

```
┌─────────────────────────────────────────────┐
│  No sooner के साथ than (than ही लगता है)    │
│  ✅ No sooner did he come than it rained.   │
│  याद रखो: "No sooner का दोस्त than"         │
└─────────────────────────────────────────────┘
```

**ट्रिक 7 — Little / A little / The little — "पानी का गिलास" ट्रिक**

```
┌─────────────────────────────────────────────┐
│  little     = लगभग नहीं (नकारात्मक) 😞      │
│  a little   = थोड़ा (पर्याप्त) 🙂           │
│  the little = जो थोड़ा है, सारा 💪          │
│  ✅ There is little water. (प्यासा रहोगे)   │
│  ✅ There is a little water. (पी लो)        │
│  ✅ He drank the little water he had.       │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 8 — Few / A few / The few — वही तिकड़ी, गिनती वालों के लिए**

```
┌─────────────────────────────────────────────┐
│  Countable → few/a few/the few              │
│  Uncountable → little/a little/the little   │
│  ट्रिक: "गिनो तो Few, नापो तो Little"       │
│  friends (गिन सकते हो) → few friends        │
│  milk (नापते हो) → little milk              │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 9 — "Much-Many" की जोड़ी**

```
┌─────────────────────────────────────────────┐
│  Many → गिनती (many books)                  │
│  Much → मात्रा (much water)                 │
│  ट्रिक: "Many में 'ny' = Number,            │
│          Much में 'ch' = चीज़ (मात्रा)"      │
└─────────────────────────────────────────────┘
```

**ट्रिक 10 — Adjective बनाम Adverb — "क्रिया के बाद सावधान"**

```
┌─────────────────────────────────────────────┐
│  Linking verbs (look, feel, smell, taste,   │
│  seem, sound) के बाद ADJECTIVE आता है:      │
│  ✅ The soup tastes good. (सूप कैसा है?)    │
│  ❌ The soup tastes well.                   │
│  लेकिन: ✅ She sings well. (गाना कैसे?)     │
│  ट्रिक: "इंद्रिय-क्रिया के बाद विशेषण"      │
└─────────────────────────────────────────────┘
```

**ट्रिक 11 — "One of the + Superlative + Plural Noun"**

```
┌─────────────────────────────────────────────┐
│  ✅ One of the best players                 │
│  ❌ One of the best player                  │
│  ट्रिक: "One of the के बाद भीड़ (plural)    │
│  चाहिए — एक, पर किसमें से? भीड़ में से!"    │
└─────────────────────────────────────────────┘
```

**ट्रिक 12 — "Enough" की जगह — पहले या बाद में?**

```
┌─────────────────────────────────────────────┐
│  Adjective/Adverb + enough (बाद में)        │
│  ✅ tall enough, fast enough                │
│  enough + Noun (पहले)                       │
│  ✅ enough money, enough time               │
│  ट्रिक: "Noun के आगे, बाकी सबके पीछे"       │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**स्किप नियम 1 — दो विकल्प "लगभग सही" लगें और नियम याद न आए**
जैसे "senior to" बनाम "senior than" — अगर S-I-J-S-P ट्रिक याद नहीं आ रहा, तो अंदाज़ा मत लगाओ। Negative marking वाली परीक्षा (SSC CGL) में ऐसे प्रश्न को अंत के लिए छोड़ो; पहले तथ्यात्मक प्रश्न (spelling, one-word) निपटाओ।

**स्किप नियम 2 — लंबा Error-Spotting वाक्य जिसमें 3+ clauses हों**
अगर वाक्य में intervening phrases (along with, as well as) और multiple adjectives घुसे हैं और 45 सेकंड में error न मिले, तो mark करके आगे बढ़ो। ऐसे प्रश्न "over-thinking" जाल में फँसाते हैं — जितना सोचोगे, उतना भ्रम बढ़ेगा।

**स्किप नियम 3 — Order of Adjectives वाला प्रश्न जिसमें 4+ विशेषण हों**
OSASCOMP याद हो तो 15 सेकंड में हल; न याद हो तो हर विकल्प को मुँह में घुमाने में 2 मिनट चले जाएँगे। बेहतर है छोड़ दो — याद करके दोबारा आओ। कभी भी "sound-right" (कान को सही लगना) पर भरोसा मत करो — परीक्षक यही जाल बिछाता है।
