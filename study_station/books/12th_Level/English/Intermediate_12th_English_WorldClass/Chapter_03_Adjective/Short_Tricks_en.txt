# 🪄 Short Tricks + Skip Strategy — Adjective

---

## 🧠 Memory Tricks & Mnemonics

**Trick 1 — Order of Adjectives: "OSASCOMP"**
```
┌─────────────────────────────────────────────┐
│  O – Opinion   (beautiful, ugly)            │
│  S – Size      (big, small)                 │
│  A – Age       (old, new)                   │
│  S – Shape     (round, square)              │
│  C – Colour    (red, black)                 │
│  O – Origin    (Indian, French)             │
│  M – Material  (wooden, gold)               │
│  P – Purpose   (walking stick, dining table)│
│                                             │
│  "Oh Sir, A Smart Cop Orders My Pizza"      │
└─────────────────────────────────────────────┘
```
✅ *a beautiful small old round Indian wooden table* — never *a wooden Indian old table*.

---

**Trick 2 — "The + Adjective = Whole Class"**
```
┌─────────────────────────────────────────────┐
│  the rich  = rich people (plural verb!)     │
│  the poor  = poor people                    │
│  the blind = blind people                   │
│  ✅ The rich are not always happy.          │
│  ❌ The rich is not always happy.           │
└─────────────────────────────────────────────┘
```

---

**Trick 3 — Comparative Twins: "Senior–Junior–Superior–Inferior–Prior–Prefer"**
```
┌─────────────────────────────────────────────┐
│  These Latin comparatives take TO, not THAN │
│  ✅ He is senior to me.                     │
│  ❌ He is senior than me.                   │
│  Mnemonic: "SJ SIPP loves TO, hates THAN"   │
└─────────────────────────────────────────────┘
```

---

**Trick 4 — "No Comparison" Adjectives**
```
┌─────────────────────────────────────────────┐
│  Unique, Perfect, Universal, Empty, Full,   │
│  Round, Square, Extreme, Chief, Complete    │
│  → No comparative/superlative degree!       │
│  ❌ most unique  ✅ unique                  │
│  ❌ more perfect ✅ perfect / nearly perfect│
│  Mnemonic: "UPE-FRES-CC are already at TOP" │
└─────────────────────────────────────────────┘
```

---

**Trick 5 — Little / A Little / The Little**
```
┌─────────────────────────────────────────────┐
│  little     = almost nothing (negative)     │
│  a little   = some (positive)               │
│  the little = all that is available         │
│  Same family: few / a few / the few         │
│  Mnemonic: "No A = NO hope; A = A bit;      │
│             THE = THE whole of it"          │
└─────────────────────────────────────────────┘
```

---

**Trick 6 — Elder vs Older**
```
┌─────────────────────────────────────────────┐
│  elder/eldest → only family members, NO than│
│  older/oldest → anyone/anything, takes than │
│  ✅ My elder brother is older than me.      │
│  Mnemonic: "Elder stays in the family       │
│  and refuses to go with THAN"               │
└─────────────────────────────────────────────┘
```

---

**Trick 7 — Later vs Latter**
```
┌─────────────────────────────────────────────┐
│  later  = time (opposite of earlier)        │
│  latter = order (second of two things)      │
│  Mnemonic: "Later has a T for Time;         │
│  Latter has double-T = Two things"          │
└─────────────────────────────────────────────┘
```

---

**Trick 8 — Adjective after Verbs of Sensation**
```
┌─────────────────────────────────────────────┐
│  look, feel, seem, smell, taste, sound      │
│  → take ADJECTIVE, not adverb               │
│  ✅ The soup tastes good.                   │
│  ❌ The soup tastes well.                   │
│  Mnemonic: "Senses describe, so they        │
│  take describing words"                     │
└─────────────────────────────────────────────┘
```

---

**Trick 9 — Farther vs Further**
```
┌─────────────────────────────────────────────┐
│  farther = physical distance                │
│  further = additional / more                │
│  ✅ Delhi is farther than Noida.            │
│  ✅ For further details, contact us.        │
│  Mnemonic: "FARther has FAR = distance"     │
└─────────────────────────────────────────────┘
```

---

**Trick 10 — Each vs Every**
```
┌─────────────────────────────────────────────┐
│  each  → two or more, one by one            │
│  every → three or more, as a group          │
│  ✅ Each of the two boys…                   │
│  ✅ Every student in the class…             │
│  Mnemonic: "Each = 2+; Every = 3+"          │
└─────────────────────────────────────────────┘
```

---

**Trick 11 — Adjectives used as Nouns stay Singular in Form**
```
┌─────────────────────────────────────────────┐
│  ❌ riches man   ✅ rich man                │
│  ❌ a 10-rupees note ✅ a 10-rupee note     │
│  Hyphenated numbers → singular noun!        │
│  a five-year-old boy, a two-day match       │
└─────────────────────────────────────────────┘
```

---

**Trick 12 — "One of the + Superlative + Plural Noun"**
```
┌─────────────────────────────────────────────┐
│  ✅ One of the best players                 │
│  ❌ One of the best player                  │
│  Mnemonic: "One out of MANY — so MANY       │
│  must be plural"                            │
└─────────────────────────────────────────────┘
```

---

**Trick 13 — Comparative for Two, Superlative for Three+**
```
┌─────────────────────────────────────────────┐
│  ✅ Ram is the taller of the two brothers.  │
│  ✅ Ram is the tallest of the three.        │
│  Trap: "of the two" → use comparative       │
│  with THE, not superlative!                 │
└─────────────────────────────────────────────┘
```

---

**Trick 14 — Enough's Position**
```
┌─────────────────────────────────────────────┐
│  enough + noun      → enough money          │
│  adjective + enough → good enough           │
│  Mnemonic: "Enough stands BEFORE things,    │
│  but AFTER qualities"                       │
└─────────────────────────────────────────────┘
```

---

**Trick 15 — Double Comparatives are Wrong**
```
┌─────────────────────────────────────────────┐
│  ❌ more better   ✅ better                 │
│  ❌ most fastest  ✅ fastest                │
│  Mnemonic: "One degree, one marker —        │
│  never two"                                 │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy (Exam Hall Tactics)

**Skip Tip 1 — The 15/45-Second Filter**
- **15-sec questions (attempt first):** direct rule recall — senior/junior + *to*, *the rich are*, elder/older, double comparative errors. If you spot the keyword (*senior, unique, one of the*), answer instantly.
- **45-sec questions (mark & return):** long sentences with multiple adjectives in a series (order of adjectives), or error-spotting where the adjective error hides inside an intervening phrase. Don't burn 2 minutes here in round one.

**Skip Tip 2 — When Two Options "Sound Right"**
If both options feel correct, apply the **rule test, not the ear test**: check degree (comparative/superlative), position (before/after noun), and article (*the* + adjective). Sound-based guessing fails exactly where the examiner sets the trap — skip the guess, verify the rule, or move on.

**Skip Tip 3 — Negative-Marking Discipline**
In exams with negative marking (SSC, Banking), skip any adjective question where you cannot eliminate at least **two** options. A blind 4-way guess costs more than it earns. Flag it, finish the section, and return only if time remains.
