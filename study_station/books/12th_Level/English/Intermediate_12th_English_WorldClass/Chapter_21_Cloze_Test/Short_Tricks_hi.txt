# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — क्लोज़ टेस्ट

## 📦 म्नेमोनिक ट्रिक्स (बॉक्स में)

┌─────────────────────────────────────────────┐
│ ट्रिक 1: "पहले पूरा, फिर खाली"              │
│ पैसेज को बिना विकल्प देखे एक बार पूरा पढ़ें।  │
│ कहानी का मूड (सकारात्मक/नकारात्मक) पकड़ें,    │
│ फिर ब्लैंक भरें। आधे प्रश्न मूड से ही हल।     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 2: "आगे-पीछे दो कदम"                  │
│ हर ब्लैंक से पहले और बाद की कम-से-कम दो      │
│ पंक्तियाँ ज़रूर पढ़ें। उत्तर अक्सर पड़ोसी      │
│ वाक्य में छिपा होता है।                       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 3: "FIT जाँच" — Grammar + Meaning + Tone│
│ हर विकल्प को तीन कसौटियों पर परखें:           │
│ F = Form (व्याकरणिक रूप सही?),               │
│ I = Idea (अर्थ बैठता है?),                  │
│ T = Tone (पैसेज के मूड से मेल?)              │
│ तीनों में फिट = उत्तर।                        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 4: "Preposition की जोड़ी"              │
│ क्रिया/विशेषण अपनी preposition साथ लाते हैं:  │
│ depend ON, afraid OF, good AT, consist OF,   │
│ insist ON, differ FROM, succeed IN।          │
│ ब्लैंक के बाद preposition दिखे तो जोड़ी याद   │
│ करो — उत्तर तुरंत मिलेगा।                    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 5: "Article का चश्मा"                  │
│ ब्लैंक के बाद स्वर-ध्वनि (vowel sound) = "an",│
│ व्यंजन-ध्वनि = "a"। ध्वनि देखें, अक्षर नहीं:  │
│ an hour, a university, an honest man।        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 6: "Connector का संकेत"                │
│ विरोध दिखे → but/however/although            │
│ कारण दिखे → because/since/as                 │
│ परिणाम दिखे → so/therefore/hence             │
│ जोड़ दिखे → and/moreover/also                │
│ पहले वाक्यों का रिश्ता पहचानो, फिर connector। │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 7: "Tense की माला"                     │
│ पैसेज जिस काल में शुरू हुआ, उसी में चलेगा।    │
│ कहानी past में है तो ब्लैंक में भी past form। │
│ "Yesterday, he ___ (go)" → went।             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 8: "Collocation चुंबक"                 │
│ अंग्रेज़ी में शब्द अपने पक्के साथी के साथ      │
│ चिपकते हैं: make a decision (do नहीं),        │
│ heavy rain (strong नहीं), fast car (quick     │
│ नहीं), do homework (make नहीं)।               │
│ अनजान जोड़ी सुनाई दे तो सचेत हो जाओ।          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 9: "Pronoun का पिछला पता"              │
│ it/they/he/she/this भरने से पहले पूछो —       │
│ "यह किसकी ओर इशारा कर रहा है?" पीछे जाकर     │
│ संज्ञा खोजो। एकवचन संज्ञा → it/he/she,        │
│ बहुवचन → they।                               │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 10: "Elimination की तलवार"             │
│ चार में से दो विकल्प लगभग हमेशा बेतुके होते   │
│ हैं — पहले उन्हें काटो। बचे दो में FIT जाँच   │
│ लगाओ। 50% संभावना से शुरुआत करना ही आधी      │
│ जीत है।                                       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 11: "शब्द-परिवार पहचानो"               │
│ ब्लैंक में noun चाहिए या adjective?           │
│ -tion/-ness/-ment = संज्ञा (noun)             │
│ -ful/-ous/-ive/-able = विशेषण (adjective)     │
│ -ly = क्रिया-विशेषण (adverb)                  │
│ प्रत्यय देखकर शब्द-वर्ग पहचानो, फिर चुनो।     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 12: "पहला-आखिरी वाक्य कम्पास"          │
│ पैसेज का पहला वाक्य विषय बताता है, आखिरी     │
│ वाक्य निष्कर्ष। दोनों पकड़ लो तो बीच के       │
│ ब्लैंक की दिशा अपने-आप साफ हो जाती है।        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 13: "अपना शब्द पहले सोचो"              │
│ विकल्प देखने से पहले ब्लैंक में अपना शब्द      │
│ मन में भरो। फिर विकल्पों में उसका समानार्थी   │
│ खोजो। इससे लुभावने गलत विकल्पों का जाल नहीं   │
│ फँसता।                                        │
└─────────────────────────────────────────────┘

## ⏭️ Skip Strategy (कब प्रश्न छोड़ें)

**स्किप 1 — "अटका हुआ ब्लैंक, आगे बढ़ो":**
कोई ब्लैंक 30 सेकंड में न सुलझे तो उसे छोड़कर आगे के ब्लैंक भरें। कई बार पैसेज के आगे के वाक्य पीछे के ब्लैंक का उत्तर खुद बता देते हैं। पूरा पैसेज भरने के बाद लौटकर आओ — अटका प्रश्न अक्सर आसान लगने लगता है।

**स्किप 2 — "दोनों सही लगें तो झगड़ा मत करो":**
दो विकल्पों में 45 सेकंड से ज़्यादा फँसे हो तो पहले वाला अनुमान (first instinct) लगाकर आगे बढ़ो। क्लोज़ टेस्ट में over-thinking से सही उत्तर बदलकर गलत करने की आदत सबसे घातक है। अंत में समय बचे तो ही दोबारा सोचो।

**स्किप 3 — "अनजान शब्द-जोड़ी पर दांव मत लगाओ":**
अगर ब्लैंक किसी ऐसे idiom या phrasal verb पर है जिसे आपने कभी नहीं पढ़ा (जैसे "to ___ the bucket" — kick), तो अंदाज़े में समय न गँवाओ। पहले बाकी ब्लैंक से अंक पक्के करो; ऐसे प्रश्न अंत में, केवल संदर्भ-सुराग मिले तो हल करो।
