# 🪄 Short Tricks + Skip Strategy — Cloze Test

## Trick 1: The "Read Twice, Fill Once" Rule

```
┌─────────────────────────────────────────────┐
│  PASS 1 → Read the whole passage WITHOUT    │
│  looking at options. Catch the TONE.        │
│  PASS 2 → Now fill blanks with options.     │
│  Never fill blank 1 before reading to the   │
│  end — the last line often decides the      │
│  first blank!                               │
└─────────────────────────────────────────────┘
```

## Trick 2: The "± Tone" Filter

Before touching options, mark the passage **+ (positive)** or **− (negative)**. Instantly delete options of the opposite tone.

> Passage: "Despite funding, the project ___ failed."
> Options: (a) surprisingly (b) expectedly (c) miraculously (d) fortunately
> Tone is negative + "despite" signals contrast → **(a) surprisingly**. Three options die in 5 seconds.

## Trick 3: Mnemonic — "P-C-G-V-C" (The 5-Blank Checklist)

```
┌─────────────────────────────────────────────┐
│  P → Preposition (fixed phrase?)            │
│  C → Collocation (which word "lives with"   │
│      this word? e.g., "make a decision")    │
│  G → Grammar (tense/agreement with subject) │
│  V → Vocabulary (exact shade of meaning)    │
│  C → Connector (however / therefore / and)  │
│  Ask these 5 questions for EVERY blank.     │
└─────────────────────────────────────────────┘
```

## Trick 4: The "Neighbourhood Watch" Trick

The answer to a blank is almost always hidden within **3 words before or after** it. Don't search the whole paragraph — search the neighbourhood.

> "He was ___ tired that he slept instantly." → "that" after the blank screams **so** (so…that pair).

## Trick 5: Mnemonic — "FANBOYS vs. STILL" for Connectors

```
┌─────────────────────────────────────────────┐
│  FANBOYS = the 7 coordinating conjunctions: │
│  For, And, Nor, But, Or, Yet, So            │
│  STILL = common contrast/result connectors: │
│  Since, Therefore, However, Instead,        │
│   Likewise, Although                        │
│  Step 1: Decide the RELATIONSHIP between    │
│  the two ideas — same direction, contrast,  │
│  or result.                                 │
│  Step 2: Pick the connector that matches    │
│  that relationship (and/but/so show         │
│  addition, contrast, result respectively).  │
└─────────────────────────────────────────────┘
```

## Trick 6: The "Delete-the-Phrase" Trick (Subject-Verb Trap)

When a long phrase sits between subject and verb, **mentally delete it**.

> "The quality of the products ___ poor." → Delete "of the products" → "The quality ___ poor" → **was** (not "were").

## Trick 7: Collocation Memory Hooks

```
┌─────────────────────────────────────────────┐
│  "MAKE money, DO business"                  │
│  "HEAVY rain, STRONG tea" (not strong rain) │
│  "TAKE a risk, PAY attention, CATCH a cold" │
│  Wrong collocation = wrong answer, even if  │
│  the meaning looks close.                   │
└─────────────────────────────────────────────┘
```

## Trick 8: The "Article Sound Test"

Blank before a noun? Say it aloud:
- Vowel **sound** → *an* (an hour, an MBA)
- Consonant **sound** → *a* (a university, a one-rupee note)
- Specific/second mention → *the*

## Trick 9: Mnemonic — "PREP-S" for Preposition Blanks

```
┌─────────────────────────────────────────────┐
│  P → Phrasal verb? (give UP, look AFTER)    │
│  R → Rule pair? (depend ON, insist ON)      │
│  E → Emotion word? (afraid OF, angry WITH)  │
│  P → Place/Time? (IN month, ON day, AT time)│
│  S → Sound it out — your ear often knows.   │
└─────────────────────────────────────────────┘
```

## Trick 10: The "Pronoun Mirror" Trick

A pronoun blank must **mirror** its noun in number and gender. Find the nearest noun it replaces:

> "The committee submitted ___ report." → committee (singular, acting as one body) → **its** (not "their").

## Trick 11: The "Tense Timeline" Trick

Find one time-clue word in the sentence and lock the tense:
- *yesterday / ago / last year* → past simple
- *since / for / already / yet* → perfect
- *tomorrow / next week* → future simple
- *by 2030 / by next year* → future perfect ("will have + V3")

## Trick 12: Mnemonic — "S-V-A-T" Order of Attack

```
┌─────────────────────────────────────────────┐
│  Solve blanks in this order, NOT 1→5:       │
│  S → Structure blanks first (grammar/tense) │
│  V → Vocabulary blanks second               │
│  A → Article/preposition blanks (fastest)   │
│  T → Tone/connector blanks LAST (need the   │
│      whole passage filled to judge flow)    │
└─────────────────────────────────────────────┘
```

## Trick 13: The "Two-Option Duel" Trick

Stuck between two options? Insert **each one** and read the full sentence aloud. The wrong one almost always breaks either grammar or logic. Never duel for more than 20 seconds — mark and move.

## Trick 14: The "Repeated Word" Signal

If a word (or its synonym) appears elsewhere in the passage, the blank often wants that **same word family**. Examiners love thematic consistency.

---

## ⏭️ Skip Strategy

**Skip Tip 1 — The 45-Second Ceiling:**
If a blank needs you to re-read the whole paragraph twice, skip it, fill the other four, and return. With 4 blanks done, the passage's meaning becomes clearer and the hard blank often solves itself in 10 seconds.

**Skip Tip 2 — Vocabulary You Don't Know = Don't Gamble Blindly:**
If all four options are unknown words, don't burn 60 seconds guessing. Eliminate by tone (Trick 2), pick the tone-matching option, mark for review, move on. One blank is worth the same as an easy one — never trade three easy marks for one hard guess.

**Skip Tip 3 — Connector Blanks Last:**
If blank 1 is a connector (however/therefore/moreover), skip it immediately. Connectors depend on the relationship between ideas — solve every other blank first, then the connector reveals itself.

*Review these tricks after 2 days: cover the boxes and recite P-C-G-V-C, FANBOYS vs. STILL, and S-V-A-T from memory.*
