# 🪄 Short Tricks + Skip Strategy — Noun

## Memory Boxes (Mnemonics)

```
┌─────────────────────────────────────────────┐
│ TRICK 1: "M-U-F-F-I-N" — Uncountable Nouns  │
│ M – Milk (all liquids)                      │
│ U – Utensils' contents (rice, sugar, flour) │
│ F – Furniture (and luggage, baggage)        │
│ F – Facts (information, news, knowledge)    │
│ I – Ideas (advice, work, homework)          │
│ N – Notes (money, cash)                     │
│ → Never add -s, never use a/an before them! │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 2: "Cattle Police People Poultry"     │
│ These 4 look SINGULAR but take PLURAL verb. │
│ ✗ The police is here.                       │
│ ✓ The police are here.                      │
│ Memory hook: "CPPP — Cops Patrol Public     │
│ Places" (always in groups, never alone!)    │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 3: "SCISSORS wear TROUSERS"           │
│ Tools with two legs/blades = always plural: │
│ scissors, trousers, spectacles, pliers,     │
│ tongs, binoculars, jeans, shorts.           │
│ Use "a pair of" to count them.              │
└─────────────────────────────────────────────────────────────┐
```

```
┌─────────────────────────────────────────────┐
│ TRICK 4: "NEWS is SINGULAR"                 │
│ Words ending in -s but SINGULAR:            │
│ News, Physics, Mathematics, Economics,      │
│ Politics, Measles, Mumps, Billiards, Ethics │
│ Hook: "The NEWS on Physics and Measles      │
│ IS boring."                                 │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 5: "F & FE → VES"                     │
│ knife→knives, wife→wives, leaf→leaves,      │
│ thief→thieves, wolf→wolves, life→lives      │
│ BUT exceptions: "CHIEFS on ROOFS carry      │
│ PROOFS and BELIEFS" (just add -s)           │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 6: "MAN-MAN, WOMAN-WOMAN"             │
│ Compounds with man/woman change BOTH parts: │
│ man-servant → men-servants                  │
│ woman-teacher → women-teachers              │
│ But: boy-friend → boy-friends (only last)   │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 7: "One of the + PLURAL noun"         │
│ ✗ One of the boy was absent.                │
│ ✓ One of the boys was absent.               │
│ Hook: "ONE out of MANY" — many = plural     │
│ noun, but ONE = singular verb!              │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 8: "A number ARE, The number IS"      │
│ A number of students were absent. (many)    │
│ The number of students is fifty. (figure)   │
│ Hook: A = Army (plural), The = Total        │
│ (singular)                                  │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 9: "Same Noun, Two Meanings"          │
│ Singular vs Plural change meaning:          │
│ air (हवा) → airs (घमंड)                     │
│ good (अच्छा) → goods (सामान)                │
│ iron (लोहा) → irons (हथकड़ी)                │
│ work (काम) → works (रचनाएँ/कारखाना)         │
│ Hook: "Plural = Personality change!"        │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 10: Apostrophe — "S-STOP"             │
│ Plural ending in -s → apostrophe AFTER s:   │
│ boys' school, girls' hostel                 │
│ Plural NOT ending in -s → 's:               │
│ men's room, children's park                 │
│ Hook: "S already there? STOP after it."     │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 11: "No 's with OF"                   │
│ For non-living things use OF, not 's:       │
│ ✗ the table's leg                           │
│ ✓ the leg of the table                      │
│ Hook: "Things don't OWN — they HAVE parts   │
│ OF them."                                   │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 12: "Hair vs Hairs"                   │
│ hair (all hair on head) = uncountable       │
│ hairs (counted strands) = countable         │
│ "Her hair is black." / "Two grey hairs!"    │
│ Same family: fruit/fruits, fish/fishes      │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 13: "Board of Directors" trick        │
│ Collective noun + united action → singular  │
│ Collective noun + divided members → plural  │
│ "The jury has given its verdict." (united)  │
│ "The jury are divided in opinion." (split)  │
│ Hook: "Together = ONE, Torn = MANY"         │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 14: Foreign Plurals — "UM→A, US→I,    │
│ IS→ES, ON→A"                                │
│ datum→data, medium→media (UM→A)             │
│ focus→foci, syllabus→syllabi (US→I)         │
│ crisis→crises, analysis→analyses (IS→ES)    │
│ criterion→criteria, phenomenon→phenomena    │
│ (ON→A)                                      │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ TRICK 15: "Mathematics of Money"            │
│ Amounts/distances/time as ONE unit →        │
│ singular verb:                              │
│ "Five hundred rupees is a big amount."      │
│ "Ten kilometres is a long walk."            │
│ Hook: "One PACKAGE = One VERB"              │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy (When to Skip & Return)

**Tip 1 — The "Double Trap" Skip:**
If a noun question has BOTH a tricky plural AND an apostrophe issue in the same sentence (e.g., "mens's footwear"), don't burn 60 seconds dissecting it. Mark it, solve the easy "uncountable noun" or "one of the + plural" questions first (these are 15-second fact-based questions), and return with a fresh eye. Double-trap questions are designed to eat your time.

**Tip 2 — The "Sound-Right" Skip:**
If an option "sounds correct" because you have heard it in spoken English (e.g., "The police is investigating"), that is exactly the trap. If you cannot recall the rule within 10 seconds, skip and return — guessing on sound-right questions has the highest error rate. Never let your ear override the rule book.

**Tip 3 — The "Foreign Plural" Skip:**
If a question tests rare Latin/Greek plurals you have not revised (e.g., "addendum," "stratum," "genus"), do not guess between two unfamiliar forms. Skip it, finish the set, and attempt it last with elimination: remove options that break the UM→A / US→I / IS→ES / ON→A patterns. One wrong guess costs more than one skipped question in negative-marking exams.
