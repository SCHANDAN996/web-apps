🪄 सर्वनाम (Pronoun) — शॉर्ट ट्रिक्स + स्किप रणनीति

## 🎯 15 म्नेमोनिक ट्रिक्स

┌─────────────────────────────────────────────┐
│ ट्रिक 1: "SAP" — Subject-Verb Agreement      │
│ Pronoun का verb उसके असली noun (antecedent)  │
│ से मिलाओ, बीच में आए phrase से नहीं।          │
│ "Each of the boys HAS (not have) a pen."     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 2: "123-231" नियम                       │
│ अच्छे काम के लिए क्रम: 2nd, 3rd, 1st (231)    │
│ बुरे काम/गलती के लिए: 1st, 2nd, 3rd (123)     │
│ ✔ You, he and I will go. (अच्छा काम)         │
│ ✔ I, you and he are guilty. (गलती स्वीकारना) │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 3: "Each/Every/Everyone = SINGULAR"     │
│ याद रखो: "E-वाले अकेले खिलाड़ी हैं"            │
│ Each, Every, Everyone, Everybody, Either,    │
│ Neither → हमेशा singular verb + his/his-her  │
│ ✔ Everyone has done his work.                │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 4: "Than/As के बाद Subject"             │
│ तुलना में than/as के बाद nominative (I, he,  │
│ we) आता है, objective (me, him, us) नहीं।    │
│ ✔ He is taller than I (am).                  │
│ ✘ He is taller than me. (परीक्षा में गलत)    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 5: "Let के बाद me"                      │
│ Let + objective case हमेशा।                   │
│ ✔ Let him and me go.                         │
│ ✘ Let him and I go.                          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 6: "It is I" नियम                       │
│ Verb 'to be' (is/am/was) के बाद nominative।  │
│ ✔ It is I who am responsible.                │
│ ✘ It is me. (formal परीक्षा में गलत)         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 7: "One → One's"                        │
│ One से शुरू, तो आगे भी one/one's/oneself।    │
│ ✔ One should do one's duty.                  │
│ ✘ One should do his duty.                    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 8: "Who vs Whom — Him टेस्ट"            │
│ उत्तर 'he' में आए → Who; 'him' में आए → Whom │
│ ___ did you meet? → I met him. → Whom ✔      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 9: "Between You and ME"                 │
│ Preposition (between, for, with, to) के बाद  │
│ objective case। "Between you and I" हमेशा    │
│ गलत है — परीक्षक का पसंदीदा जाल!             │
│ ✔ Between you and me, he is wrong.           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 10: "None = Singular (परीक्षा में)"     │
│ None of + plural noun → singular verb सुरक्षित│
│ ✔ None of the students was present.          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 11: "Enjoy + -self"                     │
│ Enjoy, avail, absent, pride, resign के बाद   │
│ reflexive pronoun (myself, himself) जब कोई   │
│ object न हो।                                  │
│ ✔ He enjoyed himself at the party.           │
│ ✘ He enjoyed at the party.                   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 12: "Same + that"                       │
│ Same के साथ relative pronoun 'that' (who/    │
│ which नहीं)।                                  │
│ ✔ This is the same book that I bought.       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 13: "Superlative + that"                │
│ Superlative degree के बाद 'that' ही आता है।  │
│ ✔ He is the best player that I know.         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 14: "Avoirdupois नहीं — AVAIL"          │
│ "Avail oneself of" सही; "avail of" अकेला गलत।│
│ ✔ He availed himself of the chance.          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 15: "Each other (2) vs One another (3+)"│
│ दो लोग → each other; तीन या अधिक → one       │
│ another।                                      │
│ ✔ Ram and Shyam love each other.             │
│ ✔ The four friends help one another.         │
└─────────────────────────────────────────────┘

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**1. दो विकल्प दोनों "सही लग रहे" हों (Sound-Right जाल):**
जैसे "than me" vs "than I" — दोनों कानों को सही लगते हैं। अगर 45 सेकंड में नियम याद न आए, तो प्रश्न मार्क करके आगे बढ़ें; अंत में "formal rule" वाला विकल्प (than I) चुनें। अंधा अनुमान न लगाएँ — नेगेटिव मार्किंग में −0.25 का नुकसान।

**2. Antecedent दूर छिपा हो (Intervening Phrase जाल):**
"The quality of the mangoes ___ (was/were) good" — जब subject और verb के बीच लंबा phrase हो और आप confuse हों, तो पहले phrase काटकर core subject पढ़ें। अगर फिर भी संदेह हो, तो skip करें — ऐसे प्रश्न में जल्दबाज़ी = गलती।

**3. Reflexive pronoun वाले लंबे वाक्य:**
"himself/themselves" वाले प्रश्न जहाँ verb की जानकारी (enjoy, avail, pride) याद न हो — वहाँ guess मत करें। पहले आसान 15-सेकंड वाले प्रश्न (case, number agreement) निपटाएँ, फिर समय बचे तो इन पर लौटें।

**सुनहरा नियम:** पहले सभी 'तथ्यात्मक' प्रश्न (15 सेकंड वाले) हल करें, फिर 'तार्किक' प्रश्नों (45 सेकंड) पर आएँ, और अंत में ही संदिग्ध प्रश्नों को छूएँ।
