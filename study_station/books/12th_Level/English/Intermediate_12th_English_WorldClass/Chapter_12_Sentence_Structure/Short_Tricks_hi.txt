# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — वाक्य संरचना (Sentence Structure)

## 🎯 म्नेमोनिक ट्रिक्स (याद रखने की चाबियाँ)

**ट्रिक 1 — "SVA" (Subject-Verb Agreement)**
```
┌─────────────────────────────────────┐
│  S → V → A : पहले कर्ता, फिर क्रिया, │
│  फिर बाकी सब। कर्ता ढूँढो, क्रिया     │
│  अपने-आप मिल जाएगी।                  │
└─────────────────────────────────────┘
```
जैसे: *The list of items **is** on the desk.* — कर्ता "list" है, "items" नहीं।

**ट्रिक 2 — "FANBOYS" (संयोजक / Conjunctions)**
```
┌─────────────────────────────────────┐
│ F-For, A-And, N-Nor, B-But,         │
│ O-Or, Y-Yet, S-So                   │
│ दो स्वतंत्र उपवाक्यों को जोड़ने वाले │
│ 7 जादुई शब्द!                        │
└─────────────────────────────────────┘
```

**ट्रिक 3 — "बीच का कचरा फेंको" (Intervening Phrase जाल)**
```
┌─────────────────────────────────────┐
│ कर्ता और क्रिया के बीच आया वाक्यांश  │
│ (of..., with..., along with...)      │
│ = कचरा। उसे काटो, फिर मेल जाँचो।    │
└─────────────────────────────────────┘
```
*The captain, along with his players, **is** here.* (players देखकर are मत लगाओ!)

**ट्रिक 4 — "Each-Every-Neither = हमेशा Singular"**
```
┌─────────────────────────────────────┐
│ Each, Every, Either, Neither,       │
│ Everyone, Someone → क्रिया Singular  │
│ याद रखो: "EEN-ES" — ईन में ऐस!      │
└─────────────────────────────────────┘
```
*Neither of the boys **is** guilty.*

**ट्रिक 5 — "Question में Inversion"**
```
┌─────────────────────────────────────┐
│ प्रश्न = Helping Verb पहले!          │
│ ❌ What you are doing?               │
│ ✅ What are you doing?               │
│ ट्रिक: "WH शब्द के बाद फौजी (verb)   │
│ सबसे आगे खड़ा होता है।"              │
└─────────────────────────────────────┘
```

**ट्रिक 6 — "There है तो पीछे देखो"**
```
┌─────────────────────────────────────┐
│ There is/are... में असली कर्ता       │
│ क्रिया के बाद आता है।                │
│ There **are** three books on the     │
│ table. (books = plural → are)        │
└─────────────────────────────────────┘
```

**ट्रिक 7 — "Collective Noun = एक टीम, एक क्रिया"**
```
┌─────────────────────────────────────┐
│ Team, Army, Committee, Jury →        │
│ एक इकाई की तरह सोचो → Singular verb │
│ (जब टीम टूटकर अलग-अलग काम करे,      │
│ तभी plural — परीक्षा में दुर्लभ!)    │
└─────────────────────────────────────┘
```
*The committee **has** taken its decision.*

**ट्रिक 8 — "Neither-Nor / Either-Or = पड़ोसी नियम"**
```
┌─────────────────────────────────────┐
│ क्रिया हमेशा नज़दीक वाले कर्ता से     │
│ मिलेगी (Proximity Rule)।             │
│ Neither the teacher nor the          │
│ students **are** here.               │
│ (students पास में → are)             │
└─────────────────────────────────────┘
```

**ट्रिक 9 — "Sound-Right जाल से बचो"**
```
┌─────────────────────────────────────┐
│ कान से सही लगना ≠ व्याकरण से सही।    │
│ "One of my friends **has** come"     │
│ (have नहीं — कर्ता One है!)          │
│ ट्रिक: "of + plural" देखो तो         │
│ असली कर्ता उसके पहले है।             │
└─────────────────────────────────────┘
```

**ट्रिक 10 — "Simple Sentence की पहचान: 1 कर्ता + 1 क्रिया"**
```
┌─────────────────────────────────────┐
│ Simple = 1 जोड़ा (SV)                │
│ Compound = 2 जोड़े + FANBOYS         │
│ Complex = 1 जोड़ा + because/when/    │
│ which वाला आश्रित उपवाक्य            │
│ ट्रिक: "1-2-1" फॉर्मूला              │
└─────────────────────────────────────┘
```

**ट्रिक 11 — "No sooner...than, Hardly...when"**
```
┌─────────────────────────────────────┐
│ जोड़ी पूरी होनी चाहिए:               │
│ No sooner → than (then नहीं!)        │
│ Hardly/Scarcely → when               │
│ और दोनों में Inversion:              │
│ No sooner **had he** reached...      │
└─────────────────────────────────────┘
```

**ट्रिक 12 — "It is I / It is me?"**
```
┌─────────────────────────────────────┐
│ 'To be' क्रिया के बाद Subject Case:  │
│ ✅ It is I. (परीक्षा में यही सही)    │
│ ❌ It is me. (बोलचाल ठीक, परीक्षा नहीं)│
└─────────────────────────────────────┘
```

**ट्रिक 13 — "A number of vs The number of"**
```
┌─────────────────────────────────────┐
│ A number of + plural verb (कई)       │
│ The number of + singular verb (संख्या)│
│ ✅ A number of students **were** absent.│
│ ✅ The number of students **is** fifty. │
└─────────────────────────────────────┘
```

**ट्रिक 14 — "News, Physics, Mathematics = Singular"**
```
┌─────────────────────────────────────┐
│ -s लगा है फिर भी Singular:           │
│ News, Physics, Economics, Measles    │
│ ट्रिक: "अखबार की News एक ही होती है!"│
└─────────────────────────────────────┘
```

**ट्रिक 15 — "Scissors, Trousers = Plural"**
```
┌─────────────────────────────────────┐
│ दो पैर/दो धार वाली चीज़ें = Plural:  │
│ Scissors, Trousers, Spectacles,      │
│ Pliers → are/were                    │
│ ट्रिक: "जोड़ी वाली चीज़, जोड़ी क्रिया"│
└─────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**स्किप नियम 1 — दो विकल्प लगभग एक जैसे दिखें और 45 सेकंड बीत जाएँ**
जब Error Spotting में दो विकल्पों में फँस जाओ और 45 सेकंड पार हो जाएँ, तो प्रश्न मार्क करके आगे बढ़ो। अंत में समय बचे तो लौटो — ताज़े दिमाग से जाल अक्सर तुरंत दिखता है। अनुमान लगाना हो तो "Intervening Phrase" वाले भाग को पहले संदिग्ध मानो।

**स्किप नियम 2 — लंबा Complex Sentence + Sentence Improvement**
अगर वाक्य 3-4 पंक्तियों का है और हर विकल्प भी लंबा है, तो पहले पूरे सेट के छोटे-छोटे प्रश्न (Fill in the blanks, Spelling) निपटाओ। लंबे प्रश्न समय-चोर होते हैं; उन्हें दूसरे चरण में उठाओ।

**स्किप नियम 3 — जिस नियम पर कभी अभ्यास न किया हो**
जैसे "Inversion after No sooner" या "Subjunctive (I wish I were...)" — अगर ये नियम तैयारी में नहीं पढ़े, तो अंधा अनुमान मत लगाओ (negative marking में -0.25/-0.50 का नुकसान)। ऐसे प्रश्न को छोड़ना ही सबसे स्मार्ट चाल है — बचे हुए अंक तैयार किए हुए नियमों से लाओ।
