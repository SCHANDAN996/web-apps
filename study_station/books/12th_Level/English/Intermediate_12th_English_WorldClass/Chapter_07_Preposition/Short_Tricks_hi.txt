# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — Preposition (संबंधसूचक)

---

## 🎯 15 म्नेमोनिक ट्रिक्स

---

**ट्रिक 1 — "IN-ON-AT की सीढ़ी" (समय)**

```
┌─────────────────────────────────────────────┐
│  बड़ा समय → IN   (in 2024, in July, in winter) │
│  मध्यम    → ON   (on Monday, on 15 August)     │
│  छोटा/बिंदु → AT  (at 5 pm, at noon, at night)  │
│                                             │
│  याद रखें: "इन-ऑन-ऐट = साल-दिन-घड़ी"          │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 2 — "IN-ON-AT की सीढ़ी" (स्थान)**

```
┌─────────────────────────────────────────────┐
│  बड़ी जगह  → IN  (in India, in Delhi, in room) │
│  सतह      → ON  (on the table, on the road)    │
│  बिंदु     → AT  (at the station, at the door)  │
│                                             │
│  याद रखें: "देश में, मेज़ पर, दरवाज़े पर(बिंदु)" │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 3 — "BY = आखिरी तारीख़, UNTIL = चलता रहा"**

```
┌─────────────────────────────────────────────┐
│  by 5 pm   = 5 बजे तक काम खत्म (deadline)     │
│  until 5 pm = 5 बजे तक काम चलता रहा (duration)│
│                                             │
│  याद रखें: "BY बंद करो, UNTIL उल्टा चलो"       │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 4 — "SINCE = बिंदु, FOR = फैलाव"**

```
┌─────────────────────────────────────────────┐
│  since Monday / since 2010  → शुरुआती बिंदु     │
│  for two days / for years   → समय की लंबाई      │
│                                             │
│  याद रखें: "SINCE सिग्नल (शुरुआत), FOR फासला"   │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 5 — "ARRIVE के साथ कभी TO नहीं"**

```
┌─────────────────────────────────────────────┐
│  arrive AT the station / arrive IN Delhi ✓     │
│  arrive TO the station ✗                      │
│                                             │
│  याद रखें: "Arrive आदमी है, TO से दूर रहता है"  │
│  (reach, enter, discuss, order — ये भी बिना    │
│   preposition के आते हैं!)                     │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 6 — "MARRY के साथ WITH नहीं"**

```
┌─────────────────────────────────────────────┐
│  She married him. ✓                           │
│  She married with him. ✗                      │
│  लेकिन: She got married TO him. ✓              │
│                                             │
│  याद रखें: "शादी सीधी, WITH बीच में नहीं"       │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 7 — "GOOD-BAD-ANGRY की टोली"**

```
┌─────────────────────────────────────────────┐
│  good AT, bad AT, clever AT     (कुशलता)       │
│  angry WITH (व्यक्ति), angry ABOUT (बात)        │
│  afraid OF, fond OF, proud OF   (भावना)        │
│                                             │
│  याद रखें: "हुनर AT, गुस्सा WITH, डर OF"        │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 8 — "LISTEN-LOOK-WAIT की TO-AT-FOR"**

```
┌─────────────────────────────────────────────┐
│  listen TO, look AT, wait FOR                 │
│                                             │
│  याद रखें: "सुनो TO, देखो AT, इंतज़ार FOR"      │
│  (तीनों क्रमशः T-A-F — "टाफ" याद रखें)          │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 9 — "DIFFERENT FROM, अमेरिका में THAN"**

```
┌─────────────────────────────────────────────┐
│  different FROM ✓ (मानक/ब्रिटिश)               │
│  different THAN (अमेरिकी — परीक्षा में गलत मानें)│
│                                             │
│  याद रखें: "भिन्नता FROM से"                   │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 10 — "BETWEEN दो, AMONG कई"**

```
┌─────────────────────────────────────────────┐
│  between Ram and Shyam (दो)                   │
│  among the students (तीन या अधिक)              │
│  ⚠️ between के साथ and, OR नहीं!               │
│                                             │
│  याद रखें: "BETWEEN = बी-ट्वीन (two),           │
│            AMONG = अ-मंग (मेले की भीड़)"        │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 11 — "BESIDE = बगल, BESIDES = अतिरिक्त"**

```
┌─────────────────────────────────────────────┐
│  beside me = मेरे बगल में                      │
│  besides me = मेरे अलावा                       │
│                                             │
│  याद रखें: "S लगा तो 'साथ-साथ अलावा'"           │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 12 — "IN TIME vs ON TIME"**

```
┌─────────────────────────────────────────────┐
│  on time = ठीक समय पर (नियत समय)               │
│  in time = समय रहते (किसी काम से पहले)          │
│                                             │
│  याद रखें: "ON = ठीक-ठाक, IN = इतनी जल्दी"      │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 13 — "ABOVE-OVER, BELOW-UNDER"**

```
┌─────────────────────────────────────────────┐
│  over = ऊपर + संपर्क/ढकना (bridge over river)  │
│  above = बस ऊपर (fan above my head)           │
│  under = नीचे + संपर्क (under the blanket)     │
│  below = बस नीचे (below the belt)              │
│                                             │
│  याद रखें: "OVER ढके, ABOVE अलग"               │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 14 — "वाहन का नियम: ON बड़ा, IN छोटा"**

```
┌─────────────────────────────────────────────┐
│  on a bus / train / plane / ship (बड़े, खुले)   │
│  in a car / taxi (छोटे, बंद)                   │
│  on foot, on horseback (हमेशा ON)              │
│                                             │
│  याद रखें: "बस-रेल ON, कार IN, पैदल भी ON"      │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 15 — "Preposition के बाद Verb की -ing"**

```
┌─────────────────────────────────────────────┐
│  He is fond of SWIMMING. ✓                    │
│  He is fond of SWIM. ✗                        │
│  insist on going, succeed in passing          │
│                                             │
│  याद रखें: "Preposition के पीछे -ing पीछे"      │
└─────────────────────────────────────────────┘
```

## ⏭️ स्किप रणनीति (कब प्रश्न छोड़ें)

**स्किप टिप 1 — दोनों विकल्प "सही लगने वाले" हों तो रुकें, न कि भागें।**
`in time` / `on time` या `beside` / `besides` जैसे जोड़े जहाँ दोनों विकल्प कान को सही लगें — वहाँ 10 सेकंड रुककर अर्थ पूछें: "बगल या अलावा? ठीक समय या समय रहते?" अर्थ मिलते ही उत्तर मिलेगा। ऐसे प्रश्न 45-सेकंड वाले हैं, स्किप नहीं।

**स्किप टिप 2 — अपरिचित fixed phrase दिखे तो अंदाज़ा न लगाएँ।**
अगर विकल्प में ऐसा phrase हो जिसे आपने कभी नहीं पढ़ा (जैसे *abide by*, *cope with*, *dispense with*) और नियम से हल न हो रहा हो, तो उसे अंतिम चरण के लिए छोड़ दें। Fixed prepositions याद पर चलते हैं, तर्क पर नहीं — गलत अंदाज़े से negative marking का जोखिम बढ़ता है।

**स्किप टिप 3 — लंबे वाक्य में पहले verb/adjective पकड़ें, वाक्य बाद में पढ़ें।**
लंबा वाक्य देखकर घबराकर स्किप न करें। रिक्त स्थान से ठीक पहले का शब्द (verb/adjective) खोजें — 80% प्रश्न उसी एक शब्द से हल हो जाते हैं (*depend ___ → on*, *accused ___ → of*)। बाकी वाक्य सिर्फ़ सजावट है।
