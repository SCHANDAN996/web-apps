# 🪄 Short Tricks + Skip Strategy — Sentence Improvement (Advanced)

---

## Trick 1: The "SVA Chop" (Subject-Verb Agreement)

```
┌─────────────────────────────────────────────┐
│  CHOP the middle!                           │
│  Cover everything between subject and verb  │
│  with your finger. Read what remains.       │
│  "The quality of apples IS good."           │
│  (Quality…is ✓ — "apples" was the trap!)    │
└─────────────────────────────────────────────┘
```
**Use when:** Long intervening phrases (of…, along with…, as well as…) sit between subject and verb.

---

## Trick 2: "FANBOYS = Comma, No FANBOYS = No Comma"

```
┌─────────────────────────────────────────────┐
│  FANBOYS: For, And, Nor, But, Or, Yet, So   │
│  Joining two full sentences? → comma before │
│  Joining two words only?    → no comma      │
└─────────────────────────────────────────────┘
```

---

## Trick 3: The "He/Him Swap" for Who vs. Whom

```
┌─────────────────────────────────────────────┐
│  Answer the question in your head:          │
│  HE answers it  → WHO                       │
│  HIM answers it → WHOM                      │
│  "___ did you invite?" → "I invited HIM"    │
│  → WHOM did you invite? ✓                   │
└─────────────────────────────────────────────┘
```

---

## Trick 4: "Neither-Nor = Near Rule"

```
┌─────────────────────────────────────────────┐
│  Verb agrees with the NEARER subject.       │
│  "Neither the teacher nor the STUDENTS      │
│   ARE here."  (students is near → are)      │
│  Same for: either…or, not only…but also     │
└─────────────────────────────────────────────┘
```

---

## Trick 5: "Since = Point, For = Period" (SPFP)

```
┌─────────────────────────────────────────────┐
│  S-P: Since → Point of time (Monday, 2010)  │
│  F-P: For   → Period of time (2 years)      │
│  Trap: "since two years" ❌ → "for two years"│
└─────────────────────────────────────────────┘
```

---

## Trick 6: The "Bare Infinitive Gang"

```
┌─────────────────────────────────────────────┐
│  After these, use V1 (no 'to'):             │
│  Make, Let, Bid, Help*, Watch, See, Hear,   │
│  Feel  → "He made me GO" (not 'to go')      │
│  *help can take both                        │
└─────────────────────────────────────────────┘
```

---

## Trick 7: "Had + V3? Then Past Perfect Partner"

```
┌─────────────────────────────────────────────┐
│  Two past actions → earlier one = had + V3  │
│  "When I reached, the train HAD LEFT."      │
│  Signal words: before, after, by the time,  │
│  no sooner…than, hardly/scarcely…when       │
└─────────────────────────────────────────────┘
```

---

## Trick 8: "No Sooner THAN, Hardly WHEN"

```
┌─────────────────────────────────────────────┐
│  No sooner … THAN  (never 'when'!)          │
│  Hardly/Scarcely … WHEN (never 'than'!)     │
│  Mnemonic: "Sooner marries THAN,            │
│  Hardly marries WHEN."                      │
└─────────────────────────────────────────────┘
```

---

## Trick 9: "One of the + Plural Noun + Singular Verb"

```
┌─────────────────────────────────────────────┐
│  "One of the BOYS HAS come."                │
│  Noun after 'one of the' = plural ✓         │
│  Verb = singular ✓                          │
│  Examiner flips one of the two — check both!│
└─────────────────────────────────────────────┘
```

---

## Trick 10: The "Sound-Right Alarm"

```
┌─────────────────────────────────────────────┐
│  If an option "sounds natural" because you  │
│  HEAR it daily — suspect it!                │
│  "return back", "repeat again", "enter into"│
│  "discuss about" → ALL WRONG (redundant)    │
│  Mnemonic: RRED — Remove REpeated Detail    │
└─────────────────────────────────────────────┘
```

---

## Trick 11: "Comparative = Than, Superior = To"

```
┌─────────────────────────────────────────────┐
│  Latin comparatives take TO, not THAN:      │
│  superior to, inferior to, senior to,       │
│  junior to, prefer…to, prior to             │
│  Mnemonic: "SIJ-PP → TO"                    │
│  (Superior, Inferior, Junior, Prefer, Prior)│
└─────────────────────────────────────────────┘
```

---

## Trick 12: The "3-Second Parallelism Check"

```
┌─────────────────────────────────────────────┐
│  In a list, all items must wear the SAME    │
│  grammatical dress:                         │
│  "She likes reading, swimming, and to dance"│
│  ❌ → "reading, swimming, and dancing" ✓    │
│  Signal words: and, or, but, not only…also  │
└─────────────────────────────────────────────┘
```

---

## Trick 13: "Unless = If…Not" (Negative Ban)

```
┌─────────────────────────────────────────────┐
│  'Unless' already carries a negative.       │
│  "Unless you do not work hard" ❌           │
│  "Unless you work hard" ✓                   │
│  Same ban: until, lest (lest…should)        │
└─────────────────────────────────────────────┘
```

---

## Trick 14: "Each/Every/Everyone = Singular Army"

```
┌─────────────────────────────────────────────┐
│  Each, Every, Everyone, Everybody, Someone, │
│  Nobody, Either, Neither → SINGULAR verb    │
│  "Each of the students HAS a book."         │
│  Mnemonic: "E-words walk ALONE."            │
└─────────────────────────────────────────────┘
```

---

## Trick 15: The "No Improvement" Confidence Test

```
┌─────────────────────────────────────────────┐
│  Pick "No improvement" ONLY if you can      │
│  state a rule the sentence already follows. │
│  If you just "feel" it's fine — recheck;    │
│  examiners hide errors in familiar-looking  │
│  sentences. "No improvement" is the correct │
│  answer in only a minority of questions —   │
│  treat it as the exception, not the default.│
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy

**1. The 20-Second Rule:** If after 20 seconds you cannot name the grammar rule being tested (agreement, tense, parallelism…), mark the question and move on. Sentence Improvement rewards rule-recognition, not long deliberation — your first rule-based instinct is usually right.

**2. Skip "Double-Doubt" Questions:** If two options both look grammatically possible and you cannot eliminate one by a *rule* (not by feel), skip and return at the end. Never guess between two options on "sound" — that is exactly the Sound-Right trap.

**3. Do the Easy Harvest First:** In a set, first solve all questions testing SVA, tense signals (since/for, yesterday), and fixed prepositions — these are 15-second fact-based questions. Leave long-sentence parallelism and subjunctive/inversion questions (45-second inference type) for the second pass. This banks sure marks before time pressure builds.
