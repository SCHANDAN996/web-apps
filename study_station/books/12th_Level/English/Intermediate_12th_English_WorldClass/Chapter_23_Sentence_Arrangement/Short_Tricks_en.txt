# 🪄 Short Tricks + Skip Strategy — Sentence Arrangement

---

## Trick 1: The "Opener Hunt" (Find Sentence 1 First)

```
┌─────────────────────────────────────────────┐
│  The opening sentence NEVER contains:       │
│  • Pronouns without antecedent (he, it,     │
│    this, these, such)                       │
│  • Connectors (but, however, therefore,     │
│    moreover, so, yet)                       │
│  • Articles pointing back (the + noun       │
│    already introduced)                      │
│  The opener usually has: a proper noun,     │
│  a definition, or a general statement.      │
└─────────────────────────────────────────────┘
```
**Example:** "He invented the telephone in 1876." ❌ can't open (who is "He"?). "Alexander Graham Bell was a Scottish-born scientist." ✅ perfect opener.

---

## Trick 2: The "Mandatory Pair" Chain

```
┌─────────────────────────────────────────────┐
│  Find TWO sentences that MUST stick together│
│  like glue. Common glue pairs:              │
│  • Noun → Pronoun   (Raman … He)            │
│  • General → Specific (a problem … For      │
│    example)                                 │
│  • Question → Answer                        │
│  • Cause → Effect (because … therefore)     │
│  Then check which option keeps that pair    │
│  intact. Often 2 of 4 options die instantly.│
└─────────────────────────────────────────────┘
```

---

## Trick 3: P-R-O-N-O-U-N Back-Check

**Mnemonic:** *"A pronoun is a shadow — it needs a body in front of it."*

Scan every pronoun (he, she, it, they, this, that, these, those, such). Ask: *Where is its noun?* The noun-sentence must come **before** the pronoun-sentence. This single check solves a large portion of Para-jumbles.

---

## Trick 4: The "T-I-M-E" Flow Test

```
┌─────────────────────────────────────────────┐
│  T — Topic sentence first (general idea)    │
│  I — Illustration / example next            │
│  M — More details / explanation             │
│  E — Ending: conclusion, result, or summary │
│  Words like "thus, hence, in conclusion,    │
│  as a result" = E (last or near-last).      │
└─────────────────────────────────────────────┘
```

---

## Trick 5: Article Logic — "A" before "The"

**Rule:** A noun introduced with **"a/an"** (first mention) comes **before** the same noun with **"the"** (second mention).

**Example:** "A man was walking on the road." → "The man suddenly stopped." ✅ Never the reverse.

---

## Trick 6: Connector Compass

| Connector | What it signals | Placement clue |
|---|---|---|
| However, But, Yet | Contrast | After the opposite idea |
| Therefore, Thus, Hence | Result | Near the end |
| Moreover, Also, Besides | Addition | After the point it extends |
| For example, For instance | Example | After a general claim |
| Firstly… Secondly… Finally | Sequence | Keep the chain in order |

---

## Trick 7: The "Option Elimination" Shortcut

```
┌─────────────────────────────────────────────┐
│  Don't arrange all 4-6 sentences blindly!   │
│  Step 1: Find the opener → kill options     │
│          that don't start with it.          │
│  Step 2: Find one glue pair → kill options  │
│          that break it.                     │
│  Step 3: Only 1 option usually survives.    │
│  Time saved: 30+ seconds per question.      │
└─────────────────────────────────────────────┘
```

---

## Trick 8: Chronology Clue — Dates & Time Words

If sentences contain years, ages, or sequence words (*first, then, later, finally, in 1947, after independence*), arrange them on a mental timeline. Chronology overrides everything else in narrative passages.

---

## Trick 9: The "Echo Word" Link

Two consecutive sentences often **echo** a word or its synonym:
- "…a new **policy** was announced." → "The **policy** aimed at…"
- "…**pollution** levels rose." → "This **contamination**…"

Spot the echo → lock the pair.

---

## Trick 10: "This/That/Such" = Pointing Finger

```
┌─────────────────────────────────────────────┐
│  "This theory", "Such behaviour",           │
│  "That decision" — these are POINTING       │
│  words. The thing they point at MUST be     │
│  in the immediately previous sentence.      │
│  No antecedent nearby = wrong arrangement.  │
└─────────────────────────────────────────────┘
```

---

## Trick 11: Opening & Closing in One Glance (PQRS type)

In SSC-style PQRS questions, sentence **P** (given first) and **S** (given last) are fixed. Read P's last line and S's first line — the correct middle order must **bridge** them smoothly. Test each option by reading P→(option start) and (option end)→S aloud in your head.

---

## Trick 12: The "Read-Back" 10-Second Check

After picking an answer, mentally read the full sequence once. If any sentence feels like a "speed bump" (sudden topic jump, orphan pronoun), re-check. **Never skip this on Hard questions** — it catches most trap answers.

---

## Trick 13: Mnemonic — "G-P-E-C" Paragraph Skeleton

```
┌─────────────────────────────────────────────┐
│  G — General statement (opener)             │
│  P — Particulars / details                  │
│  E — Example / evidence                     │
│  C — Conclusion                             │
│  "Great Paragraphs End Cleanly!"            │
└─────────────────────────────────────────────┘
```

---

## Trick 14: Two-Name Rule

If a person is introduced by **full name** ("Dr. A.P.J. Abdul Kalam") in one sentence and called **"Kalam"** or **"he"** in another, the full-name sentence comes **first**. Same for organisations: full form → abbreviation ("The World Health Organization" → "The WHO" → "It").

---

## ⏭️ Skip Strategy (Exam Hall)

**1. The 45-Second Gate:** If after 45 seconds you haven't found even the opener or one glue pair, **mark and skip**. Para-jumbles have diminishing returns — a stuck question can eat 3 minutes. Return only if time remains.

**2. Skip "All-Look-Alike" Options:** If all four options start with different sentences AND no pronoun/connector clue exists (rare, usually in Hard sets), the question is a time-trap. Attempt it last.

**3. Never Skip PQRS with Fixed Ends:** Questions where P and S are given are **always** solvable in under 45 seconds via the bridging trick (Trick 11). These are free marks — prioritise them over open 6-sentence jumbles.

**4. One-Read Rule:** Read the jumbled sentences only **twice** — once to spot clues, once to verify. A third read means you're guessing; mark your best elimination-based answer and move on.
