# 🪄 Short Tricks + Skip Strategy — Antonyms

## Mnemonic Boxes

```
┌─────────────────────────────────────────────────────────────┐
│ TRICK 1 — "OPPOSITE PAIRS NEVER TRAVEL ALONE"               │
│ Learn words in pairs, never alone:                          │
│ Ancient ↔ Modern | Expand ↔ Contract | Accept ↔ Reject      │
│ Brain stores pairs 2× faster than single words.             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 2 — "PREFIX = INSTANT ANTONYM"                        │
│ Negative prefixes flip meaning:                             │
│ UN- (happy→unhappy), IN-/IM- (possible→impossible),         │
│ DIS- (agree→disagree), MIS- (understand→misunderstand),     │
│ NON- (violence→non-violence), ANTI- (social→antisocial)     │
│ If the question word has a prefix, REMOVE it mentally       │
│ and think of the opposite of the root.                      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 3 — "SCALE METHOD" (for degree words)                 │
│ Place the word on a scale, then jump to the far end:        │
│ Freezing — Cold — Cool — Warm — Hot — Boiling               │
│ Antonym of LUKEWARM? → jump to extreme: BOILING / FREEZING  │
│ Antonym of SCARCE? → ABUNDANT (not just "enough")           │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 4 — "HINDI BRIDGE"                                    │
│ Translate the word to Hindi, then think of the Hindi        │
│ opposite, then translate back:                              │
│ GENEROUS → उदार → opposite: कंजूस → STINGY/MISERLY          │
│ HUMBLE → विनम्र → opposite: घमंडी → ARROGANT/PROUD          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 5 — "ROOT DECODER"                                    │
│ BENE = good → BENEVOLENT (kind) ↔ MALEVOLENT (MAL = bad)    │
│ PHIL = love → PHILANTHROPY ↔ MISANTHROPY (MIS = hate)       │
│ CRED = believe → CREDIBLE ↔ INCREDIBLE                      │
│ One root = 4-6 antonym pairs for free!                      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 6 — "ELIMINATE THE SYNONYM FIRST"                     │
│ In 4 options, usually 1-2 are SYNONYMS or near-synonyms     │
│ of the question word. Cross them out instantly.             │
│ Q: Antonym of CANDID                                        │
│ (a) frank ✗ (synonym!) (b) honest ✗ (synonym!)              │
│ (c) secretive ✓ (d) blunt ✗                                 │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 7 — "PART-OF-SPEECH LOCK"                             │
│ The antonym must match the word's part of speech.           │
│ BEAUTIFUL (adj) → UGLY (adj), NOT "ugliness" (noun)         │
│ EXPAND (verb) → CONTRACT (verb), NOT "contraction"          │
│ Wrong-POS options are examiner's favourite distractors.     │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 8 — "THE -ISM / -IST / -ITY FAMILY"                   │
│ Noun endings reveal the family; antonym keeps the family:   │
│ optimism ↔ pessimism | optimist ↔ pessimist                 │
│ humility ↔ pride | honesty ↔ dishonesty                     │
└─────────────────────────────────────────────────────────────┘

│ magnificent↔ordinary  narrow↔wide  obey↔disobey             │
│ permanent↔temporary  polite↔rude  profit↔loss               │

│ victory↔defeat  wisdom↔folly  zenith↔nadir                  │

┌─────────────────────────────────────────────────────────────┐
│ TRICK 10 — "CONTEXT CLUE RESCUE"                            │
│ If the word is unknown, look at the sentence (if given).    │
│ Words like BUT, HOWEVER, ALTHOUGH signal an opposite is     │
│ coming: "He was usually FRUGAL, but that day he spent       │
│ lavishly." → FRUGAL ↔ LAVISH/EXTRAVAGANT                    │

│ Don't confuse similar-sounding words:                       │
│ AFFECT (verb) vs EFFECT (noun)                              │
│ ACCEPT ↔ REJECT, but EXCEPT ≠ antonym of accept!            │

## ⏭️ Skip Strategy (Exam Hall)

**TIP 1 — The 15/45 Rule for Antonyms:**
- **15-second questions:** Direct word-pair antonyms (e.g., "Antonym of ANCIENT"). If you know the word, answer instantly. If you don't know the word at all, **SKIP immediately** — staring won't create vocabulary. Mark and move on.
- **45-second questions:** Antonyms in a sentence/context, or words with 4 close options. Use the Scale Method (Trick 3) and Eliminate-the-Synonym (Trick 6) before deciding.

**TIP 2 — The "Unknown Word" Skip Rule:**
If the question word is completely unfamiliar AND no prefix/root clue exists (Tricks 2 & 5 fail), skip it. A blind guess between 4 unknown options has only 25% success, but negative marking costs you more. Return only if time remains.

**TIP 3 — The "Two Options Left" Rule:**
If you can eliminate 2 options confidently (usually the synonyms), **never skip** — a 50-50 guess is statistically profitable even with negative marking. Guess between the remaining two using the Part-of-Speech Lock (Trick 7).

**TIP 4 — Don't Overthink Easy Words:**
If the word is common (HAPPY, BEGIN, VICTORY), the obvious opposite is usually correct. Overthinking ("maybe they want a trick answer?") wastes 30 seconds and often converts a right answer into a wrong one. Trust your first instinct on easy recall questions.
