# 🪄 शॉर्ट ट्रिक्स + Skip Strategy — विलोम (Antonyms)

## 🎯 म्नेमोनिक ट्रिक्स (याद रखने की चाबियाँ)

---

**ट्रिक 1 — "AB- मतलब दूर"**
```
AB = Away (दूर) → विपरीत अर्थ
Normal ↔ Abnormal (असामान्य)
```

**ट्रिक 2 — "DIS- मतलब नहीं"**
```
DIS = Not → शब्द उलट जाता है
Agree ↔ Disagree
Honest ↔ Dishonest
Appear ↔ Disappear
Use ↔ Disuse (उपयोग ↔ अनुपयोग)
```

**ट्रिक 3 — "UN- का उल्टा खेल"**
```
UN = Not
Able ↔ Unable | Known ↔ Unknown | Fair ↔ Unfair
```

**ट्रिक 4 — "IM/IN/IR — अंदर घुसकर उलटना"**
```
Possible ↔ IMpossible (p से पहले IM)
Active ↔ INactive
Regular ↔ IRregular (r से पहले IR)
💡 याद करें: "P के साथ IM, R के साथ IR, बाकी सब IN"
```

**ट्रिक 5 — "MAL = बुरा, BENE = अच्छा" (लैटिन जोड़ी)**
```
MAL (बुरा): Malice (द्वेष) ↔ BEN (अच्छा): Benevolence (परोपकार)
Malevolent ↔ Benevolent
💡 "माला (MAL) पहनने वाला बुरा, बेनी (BENE) अच्छा"
```

**ट्रिक 6 — "PHIL = प्यार, MIS = नफ़रत" (ग्रीक जोड़ी)**
```
Philanthropy (मानव-प्रेम) ↔ Misanthropy (मानव-द्वेष)
💡 "फिल्म (PHIL) सबको प्यारी, मिस (MIS) कॉल से नफ़रत"
```

**ट्रिक 7 — "ASCEND ऊपर, DESCEND नीचे"**
```
Ascend (चढ़ना) ↔ Descend (उतरना)
💡 "A = ऊपर की ओर तीर ↑, D = नीचे की ओर तीर ↓"
```

**ट्रिक 8 — "ANCIENT पुराना, MODERN नया"**
```
Ancient ↔ Modern | Antique ↔ New
💡 "दादी की ANCIENT घड़ी, मेरी MODERN घड़ी"
```

**ट्रिक 9 — "EXPAND फैलना, CONTRACT सिकुड़ना"**
```
Expand ↔ Contract | Extend ↔ Shorten
💡 "बैलून EXPAND होता है, ठंड में धातु CONTRACT"
```

**ट्रिक 10 — "OPTIMIST आशावादी, PESSIMIST निराशावादी"**
```
Optimistic ↔ Pessimistic
💡 "O = Open दिल (आशा), P = Problem देखने वाला (निराशा)"
```

**ट्रिक 11 — "GENEROUS दानी, STINGY कंजूस"**
```
Generous ↔ Stingy/Miserly
💡 "जनरल (GENEROUS) साहब उदार, स्टिंग (STINGY) करने वाला कंजूस"
```

**ट्रिक 12 — "TRANSPARENT पारदर्शी, OPAQUE अपारदर्शी"**
```
Transparent ↔ Opaque
💡 "शीशा Transparent, लकड़ी Opaque"
```

**ट्रिक 13 — "Genuine असली, Spurious नकली"**
```
Genuine ↔ Spurious/Fake
💡 "जीन (Genuine) असली ब्रांड की, SPURIOUS सड़क पर बिकने वाली"
```

**ट्रिक 14 — "Victory जीत, Defeat हार" (परीक्षा-हिट जोड़ियाँ)**
```
Victory ↔ Defeat | Success ↔ Failure
Accept ↔ Reject | Arrive ↔ Depart
💡 ये जोड़ियाँ परीक्षाओं में बार-बार घूमती हैं — रट लें!
```

**ट्रिक 15 — "Root से पहचानो"**
```
अनजाना शब्द आए तो root तोड़ो:
Benevolent = BENE (अच्छा) + VOL (इच्छा) → अच्छी इच्छा वाला
विलोम = Malevolent (बुरी इच्छा वाला) ✓
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**🚫 Skip नियम 1 — चारों विकल्प अनजाने हों**
अगर मुख्य शब्द और चारों विकल्प में से तीन अनजाने हैं, तो अंदाज़ा मत लगाओ। Negative marking में −0.25/−0.50 का नुकसान बिना सोचे टिक करने से बेहतर है। पहले root/प्रत्यय तोड़ने की कोशिश करो; 20 सेकंड में कुछ न बने तो **छोड़ दो**।

**🚫 Skip नियम 2 — "लगभग-सही" दो विकल्पों में फँसो**
जब दो विकल्प लगभग एक जैसे लगें (जैसे *Cruel* और *Brutal*), तो यह परीक्षक का जाल है। 30 सेकंड से ज़्यादा मत सोचो — पहले बाकी पेपर निपटाओ, अंत में लौटो। Over-thinking में सही उत्तर भी गलत हो जाता है।

**🚫 Skip नियम 3 — Synonym की जगह Antonym पढ़ लिया हो**
अगर प्रश्न पढ़ने में संदेह हो कि विलोम पूछा है या पर्यायवाची, तो प्रश्न दोबारा पढ़ो। जल्दबाज़ी में "NOT/OPPOSITE" छूट जाता है — यही सबसे बड़ा जाल है। संदेह रहे और समय कम हो, तो उस प्रश्न को अंत के लिए छोड़ दो।

---

## ⚡ परीक्षा हॉल का 3-स्टेप फॉर्मूला

```
1️⃣ शब्द पढ़ो → root/प्रत्यय तोड़ो (UN-, DIS-, MAL-…)
2️⃣ अपने शब्दों में विलोम सोचो → फिर विकल्पों में खोजो
3️⃣ दो विकल्प बचें → वाक्य में रखकर जाँचो, फिर टिक करो
```
