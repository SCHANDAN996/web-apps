# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — त्रुटि पहचान (उन्नत)

## म्नेमोनिक ट्रिक्स (याद रखने की चाबियाँ)

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 1: "S-V दूरी खतरनाक"                                │
│ कर्ता (Subject) और क्रिया (Verb) के बीच जितना लंबा वाक्यांश │
│ आए, क्रिया हमेशा असली कर्ता के अनुसार रहेगी।              │
│ "The quality of apples **is** good." (quality = असली कर्ता)│
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 2: "Each-Every-Everyone = एक ही राजा"              │
│ Each, Every, Everyone, Everybody, Someone, Nobody —      │
│ सब एकवचन क्रिया माँगते हैं।                               │
│ "Each of the boys **has** a pen."                        │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 3: "NEITHER-NOR = पास वाला बॉस"                    │
│ Neither...nor, Either...or, Not only...but also में      │
│ क्रिया **सबसे पास वाले कर्ता** के अनुसार आती है।          │
│ "Neither the teacher nor the students **were** present." │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 4: "News बीमारी खेल = Singular गैंग"               │
│ News, Physics, Mathematics, Measles, Billiards —         │
│ दिखने में बहुवचन, पर क्रिया एकवचन।                       │
│ "The news **is** shocking."                              │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 5: "Scissors की जोड़ी = Plural"                    │
│ Scissors, Trousers, Spectacles, Goggles, Pliers —        │
│ जोड़े वाली चीज़ें हमेशा बहुवचन क्रिया लेती हैं।           │
│ "My scissors **are** blunt."                             │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 6: "Since = Point, For = Period"                   │
│ Since → निश्चित समय-बिंदु (Monday, 2010, childhood)      │
│ For → अवधि (two years, a long time)                      │
│ "I have lived here **since** 2015 / **for** ten years."  │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 7: "Hardly-Scarcely के साथ WHEN, No sooner के साथ THAN"│
│ "Hardly had I reached **when** it rained."               │
│ "No sooner had I reached **than** it rained."            │
│ परीक्षक than/when की अदला-बदली करके जाल बिछाता है।       │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 8: "One of + बहुवचन संज्ञा + एकवचन क्रिया"          │
│ "One of the **boys** **has** won."                       │
│ संज्ञा बहुवचन, क्रिया एकवचन — दोनों याद रखो!             │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 9: "Superlative के बाद than नहीं, in/of"           │
│ "He is the best player **in** the team."                 │
│ Comparative (better) के साथ than, Superlative (best) के  │
│ साथ in/of — यही सबसे आम गलती है।                        │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 10: "Senior-Junior-Prefer = TO लगाओ, THAN भुलाओ"   │
│ Senior, junior, superior, inferior, prefer — इनके साथ    │
│ than नहीं, **to** आता है।                                │
│ "He is senior **to** me." / "I prefer tea **to** coffee."│
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 11: "Collective Noun = टीम एक, तो क्रिया एक"        │
│ Team, Committee, Army, Jury — एक इकाई की तरह सोचें तो    │
│ एकवचन क्रिया। सदस्य अलग-अलग काम करें तो बहुवचन।          │
│ "The jury **has** given its verdict."                    │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 12: "If I were — कल्पना में were ही"                │
│ काल्पनिक शर्त (Subjunctive) में I/He/She सबके साथ were।  │
│ "If I **were** a bird, I would fly."                     │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 13: "Many a = एकवचन का भेष"                        │
│ "Many a soldier **has** died for the country."           │
│ Many a + एकवचन संज्ञा + एकवचन क्रिया।                    │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 14: "Sound-Right जाल से सावधान"                     │
│ जो बोलने में सही लगे वही सबसे खतरनाक!                    │
│ "What you are doing?" ❌ → "What are you doing?" ✅      │
│ प्रश्नवाचक वाक्य में helping verb subject से पहले।       │
└─────────────────────────────────────────────────────────┘

## ⏭️ स्किप रणनीति (कब प्रश्न छोड़ें)

**1. दो बार पढ़ने पर भी त्रुटि न दिखे तो "No error" पर संदेह करो, पर अंदाज़ा न लगाओ।**
उन्नत स्तर पर "No error" विकल्प जानबूझकर रखा जाता है। अगर 45 सेकंड में कोई नियम टूटता न दिखे, तो प्रश्न को चिह्नित करके आगे बढ़ो — अंत में ताज़े दिमाग से लौटो। नेगेटिव मार्किंग में अनिश्चित उत्तर देने से बुरा है छोड़ना।

**2. लंबे वाक्य + Intervening Phrase वाले प्रश्न को अंत में लो।**
जहाँ कर्ता और क्रिया के बीच 8-10 शब्दों का वाक्यांश हो, वहाँ मानसिक गणना धीमी होती है। पहले छोटे तथ्यात्मक प्रश्न (preposition, article, tense) निपटाओ, फिर लंबे वाक्यों पर लौटो।

**3. दो विकल्पों में फँसने पर कॉइन-टॉस मत करो — नियम याद करो।**
अगर (a) और (c) में उलझे हो, तो खुद से पूछो: "कौन सा व्याकरण नियम लागू होता है?" नियम याद न आए तो प्रश्न छोड़ दो — 50-50 अंदाज़ा लंबे समय में अंक घटाता है।

**सुनहरा मंत्र:** पहले 15 सेकंड में नियम दिखे तो उत्तर दो; 45 सेकंड में भी संदेह रहे तो चिह्नित करके आगे बढ़ो। अनुमान नहीं, नियम से खेलो!
