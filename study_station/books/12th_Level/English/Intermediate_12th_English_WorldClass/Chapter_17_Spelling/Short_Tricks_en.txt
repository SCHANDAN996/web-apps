# 🪄 Short Tricks + Skip Strategy — Spelling Check

## Trick 1: The "i before e" Box

```
┌─────────────────────────────────────────────┐
│  "i before e, except after c,               │
│   or when sounding like 'ay'                │
│   as in neighbour and weigh."               │
│                                             │
│  ✔ believe, field, niece (i before e)       │
│  ✔ receive, deceive, ceiling (after c → ei) │
│  ✔ eight, vein, freight (ay sound → ei)     │
│  ✘ recieve, beleive, freind                 │
│  Exceptions to memorise: weird, seize,      │
│  height, their, foreign                     │
└─────────────────────────────────────────────┘
```

## Trick 2: "Full" Loses One L

```
┌─────────────────────────────────────────────┐
│  When "full" becomes a suffix, drop one l:  │
│  beauty + full  = beautiful  (not beautifull)│
│  faith + full   = faithful                  │
│  use + full     = useful                    │
│  BUT as a standalone word: full, fill       │
└─────────────────────────────────────────────┘
```

## Trick 3: Silent Letters — Say It Wrong to Spell It Right

```
┌─────────────────────────────────────────────┐
│  Pronounce the silent letter in your head:  │
│  • k-NIFE, k-NEE, k-NOW  (silent k)         │
│  • W-RONG, W-RITE        (silent w)         │
│  • g-nome, g-nat         (silent g)         │
│  • p-sychology, p-neumonia (silent p)       │
│  • D-E-B-T, D-O-U-B-T    (silent b)         │
│  • IS-LAND               (silent s)         │
└─────────────────────────────────────────────┘
```

## Trick 4: Double the Consonant — "1-1-1 Rule"

```
┌─────────────────────────────────────────────┐
│  1 syllable + 1 vowel + 1 final consonant   │
│  → double the consonant before -ing/-ed:    │
│  run → running, stop → stopped,             │
│  big → bigger, swim → swimming              │
│  BUT: rain → raining (2 vowels, no double)  │
│  For 2-syllable words, double only if the   │
│  stress is on the LAST syllable:            │
│  beGIN → beginning ✔ | Open → opening ✘     │
└─────────────────────────────────────────────┘
```

## Trick 5: "-ceed / -cede / -sede" — Only 3 Words to Memorise

```
┌─────────────────────────────────────────────┐
│  Only THREE words end in -ceed:             │
│  succeed, proceed, exceed                   │
│  Only ONE word ends in -sede: supersede     │
│  Everything else: -cede                     │
│  (precede, recede, concede, secede)         │
│  Mnemonic: "S.P.E. ceeds, the rest cede,    │
│  and Superman supersedes."                  │
└─────────────────────────────────────────────┘
```

## Trick 6: Separate — "A Rat in Separate"

```
┌─────────────────────────────────────────────┐
│  There's "A RAT" in sep-A-RAT-e.            │
│  ✔ separate  ✘ seperate                     │
│  (one of the most commonly misspelt words   │
│  in competitive exams!)                     │
└─────────────────────────────────────────────┘
```

## Trick 7: Necessary — "One Collar, Two Sleeves"

```
┌─────────────────────────────────────────────┐
│  A shirt has ONE Collar and TWO Sleeves:    │
│  ne-C-essary → one C, double S              │
│  ✘ neccessary, necesary                     │
│  Same family: success (2C, 2S),             │
│  occasion (2C, 1S), accommodation (2C, 2M)  │
└─────────────────────────────────────────────┘
```

## Trick 8: "-able vs -ible"

```
┌─────────────────────────────────────────────┐
│  If the full word survives → -able:         │
│  comfort → comfortable, read → readable     │
│  If the root is NOT a complete English      │
│  word → -ible:                              │
│  visible (vis- isn't a word), possible,     │
│  terrible, horrible                         │
│  Exceptions to memorise: probable,          │
│  accessible, eligible                       │
└─────────────────────────────────────────────┘
```

## Trick 9: "Stationery vs Stationary"

```
┌─────────────────────────────────────────────┐
│  station-E-ry = Envelopes, pens (items)     │
│  station-A-ry = At rest, not moving         │
│  Memory hook: "E for Envelope,              │
│  A for Automobile standing still."          │
└─────────────────────────────────────────────┘
```

## Trick 10: "Principal vs Principle"

```
┌─────────────────────────────────────────────┐
│  princip-AL = the person is your "pal"      │
│  (head of a school; also: main, money)      │
│  princip-LE = a ruLE, a moral law           │
└─────────────────────────────────────────────┘
```

## Trick 11: "Practice vs Practise" (British English)

```
┌─────────────────────────────────────────────┐
│  Like advice/advise:                        │
│  practi-C-e = noun (C = Common noun)        │
│  practi-S-e = verb (S = verb Sound /z/)     │
│  "I need practice" (noun) ✔                 │
│  "I practise daily" (verb) ✔                │
│  Note: American English uses "practice"     │
│  for both — SSC follows British spelling.   │
└─────────────────────────────────────────────┘
```

## Trick 12: "Embarrass, Millennium, Occurrence" — Double Trouble Club

```
┌─────────────────────────────────────────────┐
│  These words double BOTH letters:           │
│  emba-RR-a-SS  (2R, 2S)                     │
│  mi-LL-e-NN-ium (2L, 2N)                    │
│  o-CC-u-RR-ence (2C, 2R)                    │
│  Mnemonic: "Really Smart Lions Never        │
│  Cross Rivers twice."                       │
└─────────────────────────────────────────────┘
```

## Trick 13: "Government, Environment" — The Hidden N

```
┌─────────────────────────────────────────────┐
│  People say "goverment" — but spell it      │
│  gover-N-ment. The N is silent, not absent! │
│  Same: enviro-N-ment, parli-A-ment          │
│  (parliament hides an "ia")                 │
└─────────────────────────────────────────────┘
```

## Trick 14: "-tion vs -sion"

```
┌─────────────────────────────────────────────┐
│  After N or a verb root → -tion:            │
│  invent → invention, complete → completion  │
│  After S or D (soft sound) → -sion:         │
│  decide → decision, permit → permission,    │
│  divide → division                          │
│  Hook: "D and S slide into -sion."          │
└─────────────────────────────────────────────┘
```

## Trick 15: "Questionnaire, Bureaucracy, Entrepreneur" — French Imports

```
┌─────────────────────────────────────────────┐
│  French words keep French spelling:         │
│  questionn-AI-re (double N + aire)          │
│  bureauc-racy, entrepre-neur, rendezvous    │
│  Don't "fix" them into English patterns —   │
│  examiners test exactly these.              │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy

**Tip 1 — The 15-Second Rule:** Spelling questions are pure fact-recall — you either know the word or you don't. Scan all four options; if the correct spelling jumps out in 15 seconds, mark and move. Never spend 45 seconds staring at four near-identical words — extra time does not create knowledge you don't have.

**Tip 2 — Eliminate, Don't Confirm:** If unsure, hunt for the option you can *prove wrong* (e.g., "recieve" breaks the i-before-e rule). Eliminating two options and guessing between two is far better than freezing on all four. Skip only when all four look equally plausible.

**Tip 3 — Beware the "Looks Right" Trap:** Examiners place the most natural-looking wrong spelling (seperate, occurence, begining) as option (a) to catch fast readers. If an answer feels *too* obvious in the first 3 seconds, re-read all four options once — then decide. If still stuck after 20 seconds, mark for review and skip; return only if time remains.
