# 📋 Important Rules & Tips — Spelling Check

## (a) 12 High-Yield Spelling Rules

| # | Rule | Example | Examiner's Trap |
|---|---|---|---|
| 1 | **"i before e, except after c"** — when the sound is /ee/ | bel**ie**ve, ach**ie**ve BUT rec**ei**ve, dec**ei**t | Trap word: *seize* breaks the rule (also *weird*). Words like *height, foreign* don't have the /ee/ sound, so the rule doesn't apply to them. Exams love "recieve" ❌ → "receive" ✅ |
| 2 | **Silent 'e' is dropped** before a vowel suffix | hope → hop**ing**, make → mak**ing** | But kept before consonant suffix: hope → hope**ful**. Trap: "makeing" ❌ |
| 3 | **Silent 'e' is kept** after c/g before -able/-ous (to keep soft sound) | notic**eable**, courag**eous** | Trap: "noticable" ❌ — looks right, is wrong |
| 4 | **Change y → i** before a suffix (after a consonant) | happy → happ**i**ly, beauty → beaut**i**ful | But keep y before -ing: study → study**ing**. Trap: "studyed" ❌ → "studied" ✅ |
| 5 | **Double the final consonant**: in 1-syllable words ending 1 vowel + 1 consonant, AND in longer words stressed on the last syllable | run → ru**nn**ing; begin → begi**nn**ing (stress on -gin) | No doubling when stress is on the first syllable: open → ope**n**ing (not "openning") |
| 6 | **-ful has only ONE 'l'** | beauti**ful**, use**ful**, grate**ful** | Trap: "greatful" ❌ → "grateful" ✅ (think: a plate FULL of gratitude) |
| 7 | **-ceed / -cede / -sede**: only 3 words take -ceed | ex**ceed**, pro**ceed**, suc**ceed** | All others take -cede (precede, recede); only ONE word takes -sede: super**sede** |
| 8 | **-able vs -ible**: -able is far more common and usually attaches to a complete word; -ible is mostly fixed and must be memorised | read → read**able**, comfort → comfort**able**; poss**ible**, terr**ible**, respons**ible** | Rough guideline only — many exceptions (responsible, digestible use -ible despite full-word roots). Trap: "responsable" ❌ → "responsible" ✅ |
| 9 | **-ent vs -ant / -ence vs -ance**: no fixed rule — memorise high-frequency words | independ**ent**, import**ant**; exist**ence**, perform**ance** | Trap: "independant" ❌ is the single most-tested error |
| 10 | **Double letters in common words** — memorise the "big five" | a**cc**ommodate, o**cc**ur, e**mb**a**rr**ass, co**mm**ittee, ne**ce**ssary | Trap: "accomodate" ❌, "neccessary" ❌ — one letter doubled, one not |
| 11 | **-ary vs -ery**: -ary is far more common | necess**ary**, libr**ary**, secret**ary** | -ery words are few: station**ery** (paper), machin**ery**. Trap: "stationary" (still) vs "stationery" (pens) |
| 12 | **British spellings are standard** in Indian exams | col**our**, hon**our**, cent**re**, program**me** | American forms (color, center) are marked wrong in SSC/Bank papers |

## (b) ⏱️ Time Management — The 15/45-Second Rule

| Type | What it looks like | Time | Strategy |
|---|---|---|---|
| **Fact-based (15 sec)** | "Choose the correctly spelt word" — 4 options, one correct | **15 seconds** | Read all four, spot the rule-breaker (double letter, ie/ei, -ent/-ant), mark and move. Do NOT re-read. |
| **Fact-based (15 sec)** | "Choose the incorrectly spelt word" — find the odd one | **15 seconds** | Scan for the rule you know is violated. If two options look doubtful, pick the one breaking a Rule 1–12 pattern. |
| **Inference-based (45 sec)** | Spelling embedded in a sentence with similar-looking confusables (stationary/stationery, principal/principle) | **45 seconds** | Read the sentence for meaning first, then match the word to context. Meaning decides spelling here. |

**Golden rule:** If a spelling question crosses 45 seconds, mark your first instinct and move on — first instinct on spelling is right far more often than over-thought changes.

## (c) 🔬 Morphology — Root + Affix = Correct Spelling

Knowing word parts lets you *derive* spellings instead of memorising them.

| Root / Affix | Meaning | Example words | Spelling clue |
|---|---|---|---|
| **port** (Latin) | carry | transport, portable, import | port + able → port**able** (full word + able) |
| **dict** (Latin) | say | predict, dictionary, verdict | dict stays intact: pre**dict**ion |
| **scrib/scrip** (Latin) | write | describe, script, inscription | de + scrib + tion → descri**p**tion (b→p before -tion) |
| **mit/mis** (Latin) | send | admit, permission, transmit | per + mis + sion → permi**ss**ion (double s) |
| **spect** (Latin) | look | inspect, respect, spectacle | re + spect → re**spect**ful (one l in -ful) |
| **pre-** (prefix) | before | prefix, predict, precede | pre- never doubles the next letter: pre + cede → precede |
| **dis-** (prefix) | not, apart | disappear, disappoint | dis + appear → dis**a**ppear (one s); dis + appoint → dis**a**ppoint (one s) |
| **un- / in- / re-** | not / not / again | unnecessary, incorrect, rewrite | Prefix never changes the base word's spelling: un + necessary → u**nn**ecessary (double n because base starts with n) |

**Key insight:** Most "double letter" errors vanish if you split the word: *prefix + root*. Disappear = dis + appear (not "dissappear").
