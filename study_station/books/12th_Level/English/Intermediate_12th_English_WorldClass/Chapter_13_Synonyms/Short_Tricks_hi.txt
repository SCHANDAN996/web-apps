# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — पर्यायवाची (Synonyms)

---

## 🎯 12 म्नेमोनिक ट्रिक्स (याद रखने की चाबियाँ)

**ट्रिक 1 — "AB" = दूर जाना**
```
┌─────────────────────────────────────────────┐
│ AB (Latin) = away/दूर                        │
│ Abduct = अपहरण (दूर ले जाना)                │
│ Absent = अनुपस्थित (दूर रहना)               │
└─────────────────────────────────────────────┘
```

**ट्रिक 2 — "BENE" = अच्छा, "MAL" = बुरा**
```
┌─────────────────────────────────────────────┐
│ BENE = good → Benefit, Benevolent (परोपकारी)│
│ MAL  = bad  → Malicious (दुर्भावनापूर्ण),   │
│               Malnutrition (कुपोषण)         │
│ याद करें: "बेने-फिट अच्छा, माल-प्रैक्टिस बुरा"│
└─────────────────────────────────────────────┘
```

**ट्रिक 3 — "CHRONO" = समय की घड़ी**
```
┌─────────────────────────────────────────────┐
│ Chronology = कालक्रम                        │
│ Chronic = पुरानी (बीमारी)                   │
│ Chronicle = इतिहास-लेखन                     │
│ ट्रिक: "क्रोनो-मीटर समय मापता है"           │
└─────────────────────────────────────────────┘
```

**ट्रिक 4 — "OMNI" = सब कुछ**
```
┌─────────────────────────────────────────────┐
│ Omnipotent = सर्वशक्तिमान                   │
│ Omniscient = सर्वज्ञ                         │
│ Omnivorous = सर्वाहारी                      │
│ ट्रिक: "ओमनी-बस में सब बैठते हैं"           │
└─────────────────────────────────────────────┘
```

**ट्रिक 5 — "PHIL" = प्रेम, "PHOBIA" = डर**
```
┌─────────────────────────────────────────────┐
│ Philanthropy = मानवता से प्रेम (परोपकार)    │
│ Hydrophobia = पानी का डर                    │
│ Claustrophobia = बंद जगह का डर              │
│ ट्रिक: "फिल्म = प्यार, फोबिया = फिर भी डर"  │
└─────────────────────────────────────────────┘
```

**ट्रिक 6 — "LOQU/LOC" = बोलना**
```
┌─────────────────────────────────────────────┐
│ Loquacious = बातूनी                         │
│ Eloquent = वाक्पटु                          │
│ Soliloquy = स्वगत कथन (अकेले बोलना)        │
│ ट्रिक: "लोक-सभा में सब बोलते हैं"           │
└─────────────────────────────────────────────┘
```

**ट्रिक 7 — "Cred" = विश्वास**
```
┌─────────────────────────────────────────────┐
│ Credible = विश्वसनीय                        │
│ Incredible = अविश्वसनीय                     │
│ Credulous = अति-भोला (जो सब पर यकीन करे)    │
│ ट्रिक: "Credit card पर बैंक को भरोसा"       │
└─────────────────────────────────────────────┘
```

**ट्रिक 8 — "Dict" = कहना**
```
┌─────────────────────────────────────────────┐
│ Predict = भविष्यवाणी (पहले से कहना)         │
│ Dictator = तानाशाह (जो कहे वही हो)          │
│ Verdict = निर्णय (न्याय का कहना)            │
│ ट्रिक: "Dictionary में कहे गए शब्द"          │
└─────────────────────────────────────────────┘
```

**ट्रिक 9 — "Port" = ले जाना**
```
┌─────────────────────────────────────────────┐
│ Transport = एक जगह से दूसरी जगह ले जाना     │
│ Export = बाहर भेजना | Import = अंदर लाना    │
│ Portable = जिसे उठाकर ले जा सकें            │
│ ट्रिक: "Airport से सामान ले जाते हैं"       │
└─────────────────────────────────────────────┘
```

**ट्रिक 10 — "Spect" = देखना**

┌─────────────────────────────────────────────┐
│ Inspect = जाँचना (अंदर देखना)               │
│ Respect = आदर (दोबारा देखना)               │

```

```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**🚩 नियम 1 — "अनदेखा शब्द = 20 सेकंड की सीमा"**
अगर मुख्य शब्द (जिसका पर्याय पूछा है) आपने कभी नहीं पढ़ा और कोई root/प्रत्यय भी नहीं पहचान पा रहे, तो 20 सेकंड से ज़्यादा न दें। अंदाज़े से टिक करके आगे बढ़ें — Synonym प्रश्न में सोचने से उत्तर नहीं आता, या तो याद है या नहीं।

**🚩 नियम 2 — "दो विकल्पों में फँसे तो पहला अनुमान"**
दो विकल्पों में उलझने पर 30 सेकंड से ज़्यादा न लगाएँ। पहला instinct अक्सर सही होता है। Over-thinking से सही उत्तर भी बदलकर गलत कर देते हैं — यही परीक्षक का "Over-thinking जाल" है।

**🚩 नियम 3 — "Negative marking का गणित"**
जहाँ 0.25–0.50 नकारात्मक अंकन हो, वहाँ पूरी तरह अनजान शब्द पर blind guess न करें। कम से कम से कम 2 विकल्प हटा सकें (root से), तभी टिक करें; वरना खाली छोड़ना बेहतर है।

---

## ⚡ अंतिम 3 सुनहरे सूत्र

1. **Root पहचानो → अर्थ खुल जाएगा** — अनजान शब्द को टुकड़ों में तोड़ो (pre + dict = पहले से कहना)।
2. **विकल्प हटाओ, उत्तर चुनो मत** — पहले 2 स्पष्ट गलत विकल्प काटो; बचे 2 में से चुनना आसान है।
3. **रोज़ 10 शब्द, रिवीज़न 2 दिन बाद** — आज पढ़े शब्दों को 2 दिन बाद बिना देखे बोलो (Blurt करो); जो न निकले, वही फिर से पढ़ो।
