# 🪄 Short Tricks + Skip Strategy — Synonyms

## Trick 1: The Root-First Rule
Before looking at options, break the word into root + affix. If you know the root, you can eliminate 2 options instantly.

```
┌─────────────────────────────────────────────┐
│  BENE = good  →  Benefit, Benevolent,       │
│  Benediction, Benefactor                    │
│  MAL = bad    →  Malice, Malfunction,       │
│  Malevolent, Malnutrition                   │
│  One root = 4+ words unlocked.              │
└─────────────────────────────────────────────┘
```

## Trick 2: The "POS Match" Filter
The synonym must match the **part of speech** of the question word. If the word is a noun, reject verb options even if the meaning is close.

```
┌─────────────────────────────────────────────┐
│  "Candid" (adjective) = frank, honest       │
│  Trap option: "candour" — same meaning but  │
│  a NOUN. In a strict POS question, reject.  │
└─────────────────────────────────────────────┘
```

## Trick 3: Mnemonic — "ABATE the BATE"
**Abate = reduce, lessen.** Picture a flood: "The water ABATED" — the level went down. Words in the same family: *subside, diminish, wane, ebb* — all mean "go down."

## Trick 4: Mnemonic — "CANDID CAMERA"
**Candid = frank, truthful.** A candid camera catches you speaking the truth. Family: *frank, blunt, forthright, outspoken*.

## Trick 5: Mnemonic — "EPHEMERAL = A FEVER for a day"
**Ephemeral = short-lived.** A fever comes and goes quickly. Family: *transient, fleeting, momentary, evanescent*.

## Trick 6: Mnemonic — "GREG the GREGARIOUS"
**Gregarious = sociable.** Greg loves gatherings. Root **GREG = flock/group** → congregate, aggregate, segregate.

## Trick 7: Mnemonic — "LUCID = Like a LUCID (clear) sky"
**Lucid = clear, easy to understand.** Family: *pellucid, transparent, intelligible*. Opposite family: *obscure, vague, ambiguous*.

## Trick 8: Mnemonic — "OBSTINATE = OBSTACLE-maker"
**Obstinate = stubborn.** An obstinate person becomes an obstacle to every plan. Family: *stubborn, adamant, headstrong, intransigent*.

## Trick 9: Mnemonic — "PRAGMATIC = PRACTICAL-matic"
**Pragmatic = practical.** Both start with PRA-. Family: *practical, realistic, sensible*. Trap: *dogmatic* (rigid in beliefs) — looks similar, means the opposite.

## Trick 10: Mnemonic — "VERBOSE = VERBose = too many VERBS (words)"
**Verbose = wordy.** Family: *loquacious, garrulous, prolix*. Opposite: *laconic, terse, concise*.

## Trick 11: Mnemonic — "AMIABLE AMY"
**Amiable = friendly, pleasant.** Amy is always amiable. Family: *affable, genial, cordial, congenial* — the "friendly five."

## Trick 12: Mnemonic — "METICULOUS = METER-checker"
**Meticulous = very careful about details.** One who checks every meter/measurement twice. Family: *scrupulous, fastidious, painstaking*.

## Trick 13: The Positive–Negative Charge Test
Feel the "charge" of the question word (positive/negative/neutral), then delete options with the wrong charge.

```
┌─────────────────────────────────────────────┐
│  "Notorious" = famous for something BAD (-) │
│  Options: famous (+), renowned (+),         │
│  infamous (−) ✓, celebrated (+)             │
│  Only "infamous" carries the same charge.   │
└─────────────────────────────────────────────┘
```

## Trick 14: The Intensity Ladder
Synonyms often differ only in **intensity**. Pick the option at the same step of the ladder.

```
┌─────────────────────────────────────────────┐
│  Anger ladder: annoyed < angry < furious    │
│  < enraged                                  │
│  "Furious" ≠ "annoyed" (too weak)           │
│  "Furious" = "enraged" ✓ (same step)        │
└─────────────────────────────────────────────┘
```

## Trick 15: The 3-Second Elimination Scan
For every synonym question, run this order:
1. **Charge** (positive/negative) — eliminate.
2. **Part of speech** — eliminate.
3. **Root meaning** — eliminate.
Usually one option survives before you even think deeply.

---

## ⏭️ Skip Strategy

**Skip Tip 1 — The Unknown-Word Rule (15-second cap):**
If you don't know the question word AND cannot break it into a known root, do not gamble for more than 15 seconds. Mark it, move on, return only if time remains. Synonym questions are pure recall — staring longer rarely helps.

**Skip Tip 2 — The Two-Tempting-Options Trap:**
When two options both look correct (e.g., "happy" and "elated" for "joyful"), the examiner is testing **intensity**. Re-read the word, apply the Intensity Ladder, pick the closer step, and commit — don't burn 60 seconds oscillating.

**Skip Tip 3 — Never Skip a Root You Know:**
If the word contains a root from your list (BENE, MAL, GREG, LOQU, etc.), always attempt it — these are your highest-accuracy questions. Skip only true blind spots, not root-decodable words.
