# 🪄 Short Tricks + Skip Strategy — Tense

---

## Trick 1 — The "SINCE-FOR" Divider

```
┌─────────────────────────────────────────────┐
│  SINCE = a POINT of time (Monday, 2010, 5 pm)│
│  FOR   = a PERIOD of time (2 days, 5 years)  │
│  Both demand → Perfect / Perfect Continuous  │
│  "I have lived here SINCE 2015 / FOR 9 years"│
└─────────────────────────────────────────────┘
```

## Trick 2 — The "BY THE TIME" Formula

```
┌─────────────────────────────────────────────┐
│  "By the time + Simple Past, Past Perfect"   │
│  By the time the police ARRIVED,             │
│  the thief HAD ESCAPED.                      │
│  Earlier action → had + V3                   │
└─────────────────────────────────────────────┘
```

## Trick 3 — Universal Truth Never Ages

```
┌─────────────────────────────────────────────┐
│  Facts, habits, proverbs → SIMPLE PRESENT    │
│  even after a past reporting verb!           │
│  "The teacher SAID that the earth REVOLVES   │
│  around the sun."  (NOT revolved)            │
└─────────────────────────────────────────────┘
```

## Trick 4 — The "ING-Blockers" List

```
┌─────────────────────────────────────────────┐
│  Stative verbs NEVER take -ing:              │
│  know, believe, love, hate, own, belong,     │
│  seem, understand, want, need, prefer        │
│  ❌ I am knowing him.  ✅ I know him.        │
│  Memory hook: "K-B-L-H-O-B-S-U-W-N-P"        │
│  → "Knowledge Belongs; Love Has Ownership"   │
└─────────────────────────────────────────────┘
```

## Trick 5 — Time-Marker Radar (15-second scan)

```
┌─────────────────────────────────────────────┐
│  yesterday / ago / last → Simple Past        │
│  already / just / yet / ever → Present Perfect│
│  since / for + duration → Perfect OR Perfect │
│    Continuous (action verb → Continuous;     │
│    stative verb → simple Perfect)            │
│  tomorrow / next / soon → Future             │
│  while / when + past → Past Continuous       │
│  Spot the marker → lock the tense → done!    │
└─────────────────────────────────────────────┘
```

## Trick 6 — "HAD" = The Earlier of Two Pasts

```
┌─────────────────────────────────────────────┐
│  Two past actions? Ask: which happened FIRST?│
│  First action  → Past Perfect (had + V3)     │
│  Second action → Simple Past (V2)            │
│  "The train HAD LEFT before I REACHED."      │
└─────────────────────────────────────────────┘
```

## Trick 7 — Present Perfect HATES Past Time Words

```
┌─────────────────────────────────────────────┐
│  ❌ I have seen him yesterday.               │
│  ✅ I saw him yesterday.                     │
│  Rule: yesterday/ago/last/in 2019 kill the   │
│  Present Perfect. Use Simple Past instead.   │
└─────────────────────────────────────────────┘
```

## Trick 8 — "WILL vs GOING TO" in 5 Seconds

```
┌─────────────────────────────────────────────┐
│  Instant decision / promise → WILL           │
│  Pre-planned / visible signs → GOING TO      │
│  "Look at the clouds! It IS GOING TO rain."  │
│  "I'LL help you with that bag." (spontaneous)│
└─────────────────────────────────────────────┘
```

## Trick 9 — The "WHEN-WHILE" Pairing

```
┌─────────────────────────────────────────────┐
│  WHILE + Past Continuous (long action)       │
│  WHEN  + Simple Past (short interrupting act)│
│  "WHILE I WAS WALKING, the phone RANG."      │
│  "WHEN the phone RANG, I WAS WALKING."       │
└─────────────────────────────────────────────┘
```

## Trick 10 — Conditional Time-Clause Freeze

```
┌─────────────────────────────────────────────┐
│  After if / when / unless / until / as soon  │
│  as → NO "will"! Use Simple Present.         │
│  ❌ When he will come, I will tell him.      │
│  ✅ When he comes, I will tell him.          │
│  "Will" lives only in the MAIN clause.       │
└─────────────────────────────────────────────┘
```

## Trick 11 — "IT IS TIME" Goes Backwards

```
┌─────────────────────────────────────────────┐
│  "It is time / It is high time" + Simple Past│
│  (meaning: you should do it NOW)             │
│  "It is high time you STARTED studying."     │
│  Past form, present meaning — classic trap!  │
└─────────────────────────────────────────────┘
```

## Trick 12 — The Perfect-Continuous Duration Test

```
┌─────────────────────────────────────────────┐
│  See "for/since + time" AND an action verb   │
│  still continuing? → have/has been + V-ing   │
│  "She HAS BEEN WAITING for two hours."       │
│  Stative verb or no duration? → simple       │
│  Present Perfect: "I HAVE KNOWN him for      │
│  years." (NOT have been knowing)             │
└─────────────────────────────────────────────┘
```

## Trick 13 — Reported Speech: One Step Back

```
┌─────────────────────────────────────────────┐
│  Reporting verb in past → shift tense back:  │
│  is → was | has → had | will → would         │
│  am doing → was doing | did → had done       │
│  Exception: universal truths stay frozen!    │
└─────────────────────────────────────────────┘
```

## Trick 14 — "HARDLY / SCARCELY / NO SOONER" Trio

```
┌─────────────────────────────────────────────┐
│  Hardly/Scarcely + HAD ... WHEN              │
│  No sooner   + HAD ... THAN                  │
│  "Hardly HAD I REACHED home WHEN it rained." │
│  "No sooner HAD she LEFT THAN he called."    │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy

**Tip 1 — Skip the "Double-Perfect" puzzle (45-sec trap).**
Questions mixing Past Perfect with three or more actions in a scrambled timeline eat time. If the sequence isn't clear in one reading, mark it, bank the easier tense-marker questions first, and return. One tough sequencing question is worth the same mark as a 15-second "since/for" question.

**Tip 2 — Skip when two options both "sound right."**
If your ear can't separate (b) and (c), don't guess by sound — Hindi-speaker ears are exactly what the examiner exploits. Apply the time-marker test (Trick 5). If no marker exists and the rule doesn't come in 10 seconds, skip and revisit; never burn 90 seconds on a coin-flip.

**Tip 3 — Skip long stative-verb sentences last, not first.**
Error-spotting questions with stative verbs (know, own, believe) hidden inside long intervening phrases look intimidating but are pure 15-second fact checks once you spot the verb. Scan for the verb first — if it's a stative verb wearing "-ing", you've found the error instantly. Don't skip these; do them early and fast.
