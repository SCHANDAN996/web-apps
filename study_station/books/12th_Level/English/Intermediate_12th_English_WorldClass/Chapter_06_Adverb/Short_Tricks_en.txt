# 🪄 Short Tricks + Skip Strategy — Adverb

---

## 🎯 Trick 1: The "HOW-WHEN-WHERE-HOW OFTEN" Test

```
┌─────────────────────────────────────────────┐
│  To find the adverb, ask the verb 4 questions:│
│  HOW? (manner) → slowly, well                │
│  WHEN? (time) → now, yesterday, soon         │
│  WHERE? (place) → here, outside, up          │
│  HOW OFTEN? (frequency) → always, rarely     │
│  The answer is your ADVERB.                  │
└─────────────────────────────────────────────┘
```
**Example:** "She sings *beautifully*." → Sings HOW? → beautifully = Adverb of Manner.

---

## 🎯 Trick 2: The "-LY Lie" Detector

```
┌─────────────────────────────────────────────┐
│  Not every -ly word is an adverb!            │
│  FRIENDLY, LONELY, LOVELY, COSTLY,           │
│  LIKELY, BROTHERLY, COWARDLY, SICKLY         │
│  = ADJECTIVES (they describe nouns)          │
│  Mnemonic: "Friendly Lonely Lovely Costly    │
│  Likely Brotherly Cowardly Sickly —          │
│  these 8 LY-words are Adjectives!"           │
└─────────────────────────────────────────────┘
```
**Trap:** ❌ "She spoke friendly." → ✅ "She spoke *in a friendly manner*."

---

## 🎯 Trick 3: FAST-HARD-LATE — Same Form Twins

```
┌─────────────────────────────────────────────┐
│  FAST, HARD, LATE, EARLY, DAILY, STRAIGHT    │
│  work as BOTH adjective and adverb —         │
│  NO -ly needed!                              │
│  ❌ "He ran fastly." → ✅ "He ran fast."     │
│  ❌ "Work hardly." (means: barely work!)     │
│  ✅ "Work hard."                             │
└─────────────────────────────────────────────┘
```
**Memory hook:** *Hardly = almost not; Lately = recently; Lately ≠ Late.*

---

## 🎯 Trick 4: The "Verb's Best Friend" Rule

```
┌─────────────────────────────────────────────┐
│  After an ACTION verb → use ADVERB.          │
│  After a LINKING verb (is, seem, look,       │
│  feel, taste, smell, sound) → use ADJECTIVE. │
│  ✅ "She sings sweetly." (action)            │
│  ✅ "The song sounds sweet." (linking)       │
│  Mnemonic: "Action-Adverb, Linking-Adjective"│
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 5: ENOUGH — The Position Switcher

```
┌─────────────────────────────────────────────┐
│  ENOUGH comes AFTER adjective/adverb,        │
│  but BEFORE a noun.                          │
│  ✅ "He is tall enough." (adj + enough)      │
│  ✅ "He has enough money." (enough + noun)   │
│  ❌ "He is enough tall."                     │
│  Mnemonic: "Enough runs BEHIND describing    │
│  words, AHEAD of things."                    │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 6: TOO vs VERY — The Complaint Detector

```
┌─────────────────────────────────────────────┐
│  VERY = neutral emphasis (good or bad)       │
│  TOO = more than wanted → negative result    │
│  ✅ "The tea is very hot." (just hot)        │
│  ✅ "The tea is too hot to drink." (problem!)│
│  Trick: TOO is always followed by trouble —  │
│  look for "to + verb" after it.              │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 7: Mid-Position Adverbs — The "Before Main, After Be" Rule

```
┌─────────────────────────────────────────────┐
│  Frequency adverbs (always, often, never,    │
│  usually, seldom) sit:                       │
│  • BEFORE the main verb: "He always comes."  │
│  • AFTER 'be' verbs: "He is always late."    │
│  • Between aux + main: "I have never seen."  │
│  Mnemonic: "BAM — Before Action, After be,   │
│  Middle of helpers."                         │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 8: SELDOM / HARDLY / SCARCELY — Negative in Disguise

```
┌─────────────────────────────────────────────┐
│  Seldom, rarely, hardly, scarcely, barely    │
│  are ALREADY negative.                       │
│  ❌ "He hardly does not work."               │
│  ✅ "He hardly works."                       │
│  Trick: "One negative per sentence —         │
│  double negative = double trouble."          │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 9: ONLY — The Meaning Mover

```
┌─────────────────────────────────────────────┐
│  Place ONLY right before the word it limits. │
│  "Only he lent me ₹100." (nobody else did)   │
│  "He lent only me ₹100." (to nobody else)    │
│  "He lent me only ₹100." (not more)          │
│  Trick: In exams, ONLY usually belongs       │
│  before the VERB or the amount/object.       │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 10: MPT Order — Manner, Place, Time

```
┌─────────────────────────────────────────────┐
│  Multiple adverbs in one sentence?           │
│  Order = M → P → T                           │
│  Manner → Place → Time                       │
│  ✅ "She sang beautifully (M) at the hall    │
│      (P) yesterday (T)."                     │
│  Mnemonic: "My Pet Tiger"                    │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 11: Comparative Twins — No Double Comparison

```
┌─────────────────────────────────────────────┐
│  ❌ "more faster" ❌ "most fastest"          │
│  ✅ "faster" ✅ "fastest"                    │
│  Trick: "-er/-est OR more/most — never both. │
│  One ladder, one step."                      │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 12: ELSE + BUT Trap

```
┌─────────────────────────────────────────────┐
│  After ELSE, use BUT (not THAN):             │
│  ✅ "It was nothing else but pride."         │
│  After OTHER/RATHER, use THAN:               │
│  ✅ "He chose nothing other than honesty."   │
│  Mnemonic: "Else-But are Best friends;       │
│  Other-Than are Together."                   │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 13: Adverb vs Adjective — The "Swap Test"

```
┌─────────────────────────────────────────────┐
│  Confused? Replace the word with "quickly".  │
│  If the sentence still makes sense → adverb. │
│  Replace with "good" — if it fits before a   │
│  noun → adjective.                           │
│  "He drives ___." → "drives quickly" ✔       │
│  → adverb slot confirmed.                    │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy

**1. Skip long "improve the sentence" items with 4 nearly identical options on first pass.**
If all four options differ only in adverb placement ("only" / "enough" position), mark it and return. These need careful reading of each option — a 45-second question, not a 15-second one. Attempt it after finishing the quick wins.

**2. Never skip "spot the error" questions where the error is an -ly word.**
These are 15-second Fact-based questions: scan for *fastly, hardly used wrongly, friendly/lovely as adverb, double negative with hardly/seldom*. One glance at the underlined parts usually reveals the trap. Bank these marks first.

**3. Skip if two options both "sound right" and you can't apply a rule.**
Sound-right confusion (e.g., "He did it good" vs "He did it well") means the examiner is testing linking-verb vs action-verb logic. If you can't recall the rule within 10 seconds, don't guess emotionally — flag it, apply the Swap Test (Trick 13) on your second pass, and answer with logic, not ear.
