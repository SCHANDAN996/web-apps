# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति (Short Tricks + Skip Strategy)

## 🎯 12 म्नेमोनिक ट्रिक्स (Mnemonic Tricks)

---

**ट्रिक 1: "SANAM" — Subjunctive की पहचान**

```
┌─────────────────────────────────────────────┐
│ S - Suggest   A - Ask (माँग)                │
│ N - Necessary A - Advice                    │
│ M - Mandate (आदेश)                          │
│ इन शब्दों के बाद "that + subject + V1"      │
│ (to नहीं, -s नहीं!)                         │
│ ✅ He suggested that she GO (not goes).     │
└─────────────────────────────────────────────┘
```

**ट्रिक 2: "FANBOYS" — Conjunctions की जोड़ी**

```
┌─────────────────────────────────────────────┐
│ For, And, Nor, But, Or, Yet, So             │
│ ये दो स्वतंत्र (independent) clauses जोड़ते │
│ हैं — दोनों ओर पूरा subject + verb होना     │
│ चाहिए। Tense समान होना ज़रूरी नहीं;         │
│ context के अनुसार अलग-अलग tense सही है:     │
│ ✅ He was tired, but he is smiling now.     │
│ (जाल: comma के बाद अधूरा clause ❌)          │
└─────────────────────────────────────────────┘
```

**ट्रिक 3: "Neither-Nor = नज़दीक वाला Boss"**

```
┌─────────────────────────────────────────────┐
│ Neither…nor / Either…or / Not only…but also │
│ → Verb हमेशा PASS वाले subject के अनुसार!   │
│ ✅ Neither the boys nor SHE IS coming.      │
│ (she पास है → "is", "are" नहीं)             │
└─────────────────────────────────────────────┘
```

**ट्रिक 4: "UNI = एक, BI = दो, TRI = तीन" (Root Trick)**

```
┌─────────────────────────────────────────────┐
│ Unilateral (एकपक्षीय), Bilingual (द्विभाषी),│
│ Tricolour (तिरंगा) — अंजाना शब्द आए तो      │
│ root तोड़ो, अर्थ खुद बन जाएगा!              │
└─────────────────────────────────────────────┘
```

**ट्रिक 5: "Cede = जाना/सौंपना"**

```
┌─────────────────────────────────────────────┐
│ Precede (पहले जाना), Recede (पीछे हटना),    │
│ Concede (मान लेना/सौंपना), Secede (अलग होना)│
│ याद रखो: "सीड़ी (cede) पर चढ़ना-उतरना"      │
└─────────────────────────────────────────────┘
```

**ट्रिक 6: "Scarcely/Hardly के साथ WHEN, No sooner के साथ THAN"**

```
┌─────────────────────────────────────────────┐
│ ✅ Hardly had he left WHEN it rained.       │
│ ✅ No sooner had he left THAN it rained.    │
│ याद: "Hardly-When जोड़ी, Sooner-Than जोड़ी" │
│ (परीक्षक "than" को "when" से बदलकर जाल बिछाता│
│ है!)                                        │
└─────────────────────────────────────────────┘
```

**ट्रिक 7: "Since = Point, For = Period"**

```
┌─────────────────────────────────────────────┐
│ Since + निश्चित समय-बिंदु (Monday, 2010)    │
│ For + अवधि (two years, a long time)         │
│ याद: "Since = सीधा बिंदु, For = फैली लाइन"  │
└─────────────────────────────────────────────┘
```

**ट्रिक 8: "One of the + Plural Noun + Singular Verb"**

```
┌─────────────────────────────────────────────┐
│ ✅ One of the BOYS WAS absent.              │
│ Noun बहुवचन, Verb एकवचन — उल्टा याद रखो!    │
│ (जाल: "One of the boy was…" ❌)             │
└─────────────────────────────────────────────┘
```

**ट्रिक 9: "Adjective के बाद Infinitive, Preposition के बाद Gerund"**

```
┌─────────────────────────────────────────────┐
│ ✅ He is eager TO LEARN. (to + V1)          │
│ ✅ He is fond OF LEARNING. (V+ing)          │
│ याद: "विशेषण के पीछे TO, पूर्वसर्ग के पीछे  │
│ ING"                                        │
└─────────────────────────────────────────────┘
```

**ट्रिक 10: "The + Adjective = पूरा वर्ग (Plural Verb)"**

```
┌─────────────────────────────────────────────┐
│ ✅ The rich ARE not always happy.           │
│ The poor, the blind, the elderly → सब       │
│ plural verb लेते हैं।                       │
└─────────────────────────────────────────────┘
```

**ट्रिक 11: "Positive शब्दों की सीढ़ी" (Tone Trick)**

```
┌─────────────────────────────────────────────┐
│ गद्यांश/blank में tone पकड़ने की सीढ़ी:     │
│ Optimistic > Neutral > Critical > Pessimistic│
│ Blank से पहले-बाद के शब्द (however, despite,│
│ moreover) देखकर tone की दिशा तय करो।        │
└─────────────────────────────────────────────┘
```

**ट्रिक 12: "However = U-Turn, Moreover = Straight Road"**

```
┌─────────────────────────────────────────────┐
│ However/But/Although → आगे विपरीत विचार     │
│ Moreover/Furthermore/Also → आगे वही विचार   │
│ Blank में शब्द भरने से पहले connector पढ़ो — │
│ आधा उत्तर वहीं मिल जाता है!                 │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**नियम 1: दो विकल्प में 30 सेकंड से ज़्यादा फँसे तो छोड़ो।**
दो विकल्पों में उलझना सामान्य है, लेकिन 30 सेकंड के बाद भी निर्णय न हो तो प्रश्न mark करके आगे बढ़ो। अंत में ताज़े दिमाग से लौटो — अक्सर उत्तर तुरंत दिख जाता है। अंदाज़े से टिक करने से बेहतर है छोड़ना (negative marking में −0.25/−0.50 का नुकसान)।

**नियम 2: अपरिचित idiom/phrasal verb = तुरंत skip।**
Idiom या तो याद है या नहीं — सोचने से नहीं बनेगा। ऐसे प्रश्न को 5 सेकंड में पहचानो और छोड़ दो; उस समय में एक grammar-based प्रश्न हल कर लो जहाँ नियम लगाकर पक्का उत्तर निकलेगा।

**नियम 3: लंबे गद्यांश-आधारित blank को अंत में रखो।**
जिस blank के लिए पूरा पैरा पढ़ना पड़े (tone/inference वाला), उसे पहले round में छोड़ो। पहले सारे 15-सेकंड वाले तथ्यात्मक प्रश्न (preposition, article, subject-verb agreement) निपटाओ, फिर बचे समय में 45-सेकंड वाले तार्किक प्रश्नों पर लौटो।

## ⚡ अंतिम सलाह

- पहले **connector** पढ़ो, फिर **subject** पकड़ो, फिर **verb** जाँचो — यह तीन-कदम वाला क्रम अधिकांश blanks हल कर देता है।
- जो विकल्प "सुनने में सही" लगे, उस पर एक बार नियम लगाकर ज़रूर जाँचो — परीक्षक का पसंदीदा जाल यही है।
- हर mock test के बाद गलत हुए blanks की एक "जाल डायरी" बनाओ — दोहराई गई गलती ही असली दुश्मन है।
