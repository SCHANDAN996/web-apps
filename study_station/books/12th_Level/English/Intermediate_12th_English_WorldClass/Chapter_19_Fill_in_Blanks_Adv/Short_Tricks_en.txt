# 🪄 Short Tricks + Skip Strategy — Fill in the Blanks (Advanced)

## Trick 1 — The "Blank-First, Options-Later" Rule

```
┌─────────────────────────────────────────────┐
│  COVER the options. Read the sentence.      │
│  PREDICT your own word for the blank.       │
│  Then MATCH your prediction to an option.   │
│  Prediction beats temptation — the examiner │
│  designs options to seduce guessers.        │
└─────────────────────────────────────────────┘
```

## Trick 2 — The Two-Signal Scan (15 seconds)

Every blank sentence carries two signals. Find them before touching the options:

```
┌─────────────────────────────────────────────┐
│  SIGNAL 1: LOGIC — is the blank positive,   │
│  negative, or neutral? (clue words: but,    │
│  although, because, despite, moreover)      │
│  SIGNAL 2: GRAMMAR — what form fits?        │
│  (noun/verb/adjective? singular/plural?     │
│  tense? preposition?)                       │
│  An option must pass BOTH gates.            │
└─────────────────────────────────────────────┘
```

## Trick 3 — Mnemonic: "BUD Cries" for Contrast Clues

```
┌─────────────────────────────────────────────┐
│  B-U-D = But, Unless, Despite             │
│  (cousins: although, however, yet)          │
│  When you see BUD, the sentence FLIPS.      │
│  "Despite being rich, he lived ___."        │
│  BUD spotted → opposite of rich → "frugally"│
└─────────────────────────────────────────────┘
```

## Trick 4 — Mnemonic: "SAME Team" for Support Clues

```
┌─────────────────────────────────────────────┐
│  S-A-M-E = Since, And, Moreover, Because   │
│  SAME-team words mean the blank AGREES      │
│  with the rest of the sentence.             │
│  "He was honest, and everyone ___ him."     │
│  SAME team → positive → "trusted"           │
└─────────────────────────────────────────────┘
```

## Trick 5 — The Preposition Handcuff

```
┌─────────────────────────────────────────────┐
│  The word BEFORE or AFTER the blank often   │
│  handcuffs the answer:                      │
│  • depend ___ → ON (also "upon")            │
│  • accused ___ → OF                         │
│  • good ___ → AT                            │
│  • ___ Monday → ON; ___ 2024 → IN           │
│  Check the handcuff FIRST — it can kill     │
│  2–3 options instantly.                     │
└─────────────────────────────────────────────┘
```

## Trick 6 — Mnemonic: "FANBOYS" for Parallel Structure

```
┌─────────────────────────────────────────────┐
│  For-And-Nor-But-Or-Yet-So                  │
│  Around FANBOYS, both sides must MATCH:     │
│  "She likes reading and ___."               │
│  → "swimming" (not "to swim")               │
│  Parallel form = parallel marks.            │
└─────────────────────────────────────────────┘
```

## Trick 7 — The "Sound-Right" Alarm

```
┌─────────────────────────────────────────────┐
│  If an option "sounds right" because you    │
│  HEAR it often in spoken English — be       │
│  suspicious. Spoken English tolerates       │
│  errors exams punish:                       │
│  ✗ "discuss about"  ✓ "discuss"             │
│  ✗ "return back"    ✓ "return"              │
│  ✗ "revert back"    ✓ "revert"              │
│  Sound-right = often exam-wrong.            │
└─────────────────────────────────────────────┘
```

## Trick 8 — Mnemonic: "CARS" for Collective Nouns

```
┌─────────────────────────────────────────────┐
│  C-A-R-S = Committee, Army, team, Staff     │
│  Acting as ONE body → singular verb.        │
│  Acting as MEMBERS (divided) → plural verb. │
│  "The jury ___ divided." → were (members!)  │
│  "The jury ___ given its verdict." → has    │
└─────────────────────────────────────────────┘
```

## Trick 9 — The Intervening Phrase Scissors

```
┌─────────────────────────────────────────────┐
│  When words sit between subject and verb,   │
│  CUT them out with mental scissors:         │
│  "The quality of the apples ___ good."      │
│  Cut "of the apples" → "The quality ___     │
│  good" → WAS (quality is singular).         │
│  The nearest noun is the examiner's decoy.  │
└─────────────────────────────────────────────┘
```

## Trick 10 — Mnemonic: "Each-Every-Either-Neither = ONE"

```
┌─────────────────────────────────────────────┐
│  E-E-E-N → all take SINGULAR verbs.         │
│  "Neither of the boys ___ come." → has      │
│  "Each of the students ___ present." → was  │
│  Remember: "EEN means ONE."                 │
└─────────────────────────────────────────────┘
```

## Trick 11 — The Tone Thermometer (for vocab blanks)

```
┌─────────────────────────────────────────────┐
│  Rate the sentence's tone:                  │
│  HOT (strongly positive/negative) or        │
│  COLD (mild/neutral)?                       │
│  "The critic ___ the film" (scathing review)│
│  → HOT negative → "lambasted", not          │
│  "commented on". Match the temperature.     │
└─────────────────────────────────────────────┘
```

## Trick 12 — Mnemonic: "ROOT Route" for Unknown Words

```
┌─────────────────────────────────────────────┐
│  Unknown word? Take the ROOT route:         │
│  bene- = good → benevolent, benefit         │
│  mal-  = bad  → malicious, malnutrition     │
│  cred- = believe → credible, incredible     │
│  dict- = say  → predict, contradict         │
│  The root narrows 4 options to 2 in seconds.│
└─────────────────────────────────────────────┘
```

## Trick 13 — The Double-Blank Domino

```
┌─────────────────────────────────────────────┐
│  Two blanks? Solve the EASIER blank first.  │
│  One correct fit usually eliminates 2–3     │
│  options; the remaining blank then solves   │
│  itself. Never solve left-to-right by habit │
│  — solve by CONFIDENCE.                     │
└─────────────────────────────────────────────┘
```

## Trick 14 — The "No-Change" Humility Check

```
┌─────────────────────────────────────────────┐
│  In "improve the sentence / no improvement" │
│  blanks, if you cannot name the exact rule  │
│  being broken, the original may be correct. │
│  Changing a correct sentence is the         │
│  over-thinking trap. Doubt without a rule   │
│  = leave it unchanged.                      │
└─────────────────────────────────────────────┘
```

## Trick 15 — The 3-Second Grammar Audit

```
┌─────────────────────────────────────────────┐
│  After choosing, re-read the FULL sentence  │
│  with your answer inserted. Audit:          │
│  1. Subject-verb agreement ✓                │
│  2. Tense consistency ✓                     │
│  3. Preposition fit ✓                       │
│  3 seconds of audit saves 1 mark of regret. │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy — When to Move On

**Skip Tip 1 — The 45-Second Ceiling:**
If a blank needs inference (tone, idiom, unfamiliar vocabulary) and you have no prediction after 45 seconds, mark it and move on. A fact-based grammar blank (agreement, preposition, tense) should take 15 seconds — never donate its time to a stubborn vocab question.

**Skip Tip 2 — The 50-50 Return Rule:**
If you can eliminate exactly 2 options but are stuck between the remaining 2, do NOT guess immediately. Mark the question, finish the section, and return with fresh eyes — the sentence often reads differently the second time. Guess only in the final minutes, and only between your two shortlisted options.

**Skip Tip 3 — The Unknown-Word Exit:**
If the blank demands a word you have genuinely never seen AND the root/prefix gives no clue, skip without guilt. Vocabulary blanks are binary — you either know the word family or you don't. Spending 90 seconds here cannot manufacture knowledge, but it can steal time from three solvable grammar questions.
