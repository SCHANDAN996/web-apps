126. Find the smallest positive integer which when divided by 9 leaves remainder 1, and when divided by 11 leaves remainder 3.
(a) 91 (b) 100 (c) 82 (d) 99
Answer: (a) 91
Solution: We have x = 11k + 3. For k = 0, 1, 2, ..., testing k = 8 gives x = 11(8) + 3 = 91. 91 = 9(10) + 1, satisfying both congruences. The required value is 91. Hence, the correct option is (a).

127. A positive integer N when divided by 5, 6, 7, and 8 leaves remainders 1, 2, 3, and 4 respectively. If N is the smallest such positive integer, what is the remainder when N is divided by 13?
(a) 5 (b) 4 (c) 3 (d) 6
Answer: (b) 4
Solution: Common difference d = 5 - 1 = 6 - 2 = 7 - 3 = 8 - 4 = 4. LCM(5, 6, 7, 8) = 840. N = 840 - 4 = 836. Dividing 836 by 13 gives 836 = 13 * 64 + 4. The required value is 4. Hence, the correct option is (b).
Source: SSC CGL Pattern

128. How many ordered pairs of positive integers (x, y) satisfy the equation x + y = 384 and gcd(x, y) = 24?
(a) 4 (b) 6 (c) 8 (d) 16
Answer: (c) 8
Solution: Let x = 24u and y = 24v with gcd(u, v) = 1. Then u + v = 16. Since 16 is a power of 2, u and v must both be odd. There are phi(16) = 8 coprime ordered pairs. The required value is 8. Hence, the correct option is (c).
Source: SSC CGL Pattern

129. If gcd(2^2024 - 1, 2^1518 - 1) = 2^k - 1, what is the value of k?
(a) 253 (b) 1012 (c) 504 (d) 506
Answer: (d) 506
Solution: By the property of Mersenne-type expressions, gcd(a^m - 1, a^n - 1) = a^gcd(m, n) - 1. Here gcd(2024, 1518) = 506, so k = 506. The required value is 506. Hence, the correct option is (d).

Answer: (a) 360 seconds
Solution: Time per lap: Track 1 = 180/4 = 45 s, Track 2 = 240/6 = 40 s, Track 3 = 300/5 = 60 s. LCM(45, 40, 60) = 360 seconds. The required value is 360 seconds. Hence, the correct option is (a).

131. Let N be the smallest positive integer such that N/2 is a perfect square, N/3 is a perfect cube, and N/5 is a perfect fifth power. What is the exponent of 2 in the prime factorization of N?

Answer: (b) 15
Solution: Let exponent of 2 be a. Then a - 1 is a multiple of 2 (a is odd), and a is a multiple of 3 and 5 (a is multiple of 15). Smallest positive odd multiple of 15 is 15. The required value is 15. Hence, the correct option is (b).

132. For positive integers x and y, if gcd(x, y) = 12 and lcm(x, y) = 432, what is the minimum possible value of (x + y)?
(a) 180 (b) 144 (c) 156 (d) 444
Answer: (c) 156
Solution: Let x = 12u, y = 12v with gcd(u, v) = 1 and u * v = 432 / 12 = 36. Coprime factors of 36 are (1, 36) and (4, 9). Minimal sum is 12 * (4 + 9) = 12 * 13 = 156. The required value is 156. Hence, the correct option is (c).

133. If the HCF of polynomials P(x) = x^3 + x^2 + x + 1 and Q(x) = x^4 - 1 is expressed as a polynomial, what is the degree of this HCF?
(a) 2 (b) 1 (c) 4 (d) 3
Answer: (d) 3
Solution: Factorization: P(x) = (x^2 + 1)(x + 1), and Q(x) = (x^2 - 1)(x^2 + 1) = (x - 1)(x + 1)(x^2 + 1). The HCF is P(x) itself, which has degree 3. The required value is 3. Hence, the correct option is (d).

Solution: Any common divisor of (a + b) and (a - b) must divide their sum 2a and difference 2b, so it divides 2 * gcd(a, b) = 2. Thus the maximum value is 2. The required value is 2. Hence, the correct option is (c).

139. Find the number of integral solutions (x, y) to the linear Diophantine equation 42x + 56y = 98 such that 0 <= x <= 20.
(a) 4 (b) 5 (c) 6 (d) 3
Answer: (b) 5
Solution: Dividing by gcd(42, 56) = 14 gives 3x + 4y = 7. General solution is x = 1 + 4k. For 0 <= 1 + 4k <= 20, k takes values 0, 1, 2, 3, 4 (5 solutions). The required value is 5. Hence, the correct option is (b).

140. What is the highest common factor of (n^2 + 1) and (n + 1) when n is an even positive integer?
(a) 2 (b) n (c) 1 (d) n + 1
Answer: (c) 1
Solution: n^2 + 1 = (n + 1)(n - 1) + 2. Thus gcd(n^2 + 1, n + 1) = gcd(n + 1, 2). Since n is even, n + 1 is odd, so gcd(n + 1, 2) = 1. The required value is 1. Hence, the correct option is (c).

145. What is the greatest common divisor of (n^5 - n) and 30 for every positive integer n?
(a) 15 (b) 6 (c) 10 (d) 30
Answer: (d) 30
Solution: n^5 - n = n(n - 1)(n + 1)(n^2 + 1). By Fermat's Little Theorem and consecutive integers, it is divisible by 5, 2, and 3 for all integers n, hence always divisible by 30. The required value is 30. Hence, the correct option is (d).

149. The HCF and LCM of two polynomials are (x + 3) and (x^3 - 7x + 6) respectively. If one polynomial is (x^2 + 2x - 3), find the other polynomial.
(a) x^2 - x - 6 (b) x^2 + 5x + 6 (c) x^2 - 5x + 6 (d) x^2 + x - 6
Answer: (d) x^2 + x - 6
Solution: x^3 - 7x + 6 = (x - 1)(x + 3)(x - 2). Other polynomial = (HCF * LCM) / (x^2 + 2x - 3) = ((x + 3)(x - 1)(x + 3)(x - 2)) / ((x + 3)(x - 1)) = (x + 3)(x - 2) = x^2 + x - 6. The required value is x^2 + x - 6. Hence, the correct option is (d).
Source: SSC CGL Pattern
