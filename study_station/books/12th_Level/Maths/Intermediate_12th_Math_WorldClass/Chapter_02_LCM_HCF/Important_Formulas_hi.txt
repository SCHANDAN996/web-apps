# महत्वपूर्ण सूत्र: ल.स. एवं म.स. (उन्नत)

| सूत्र का नाम | सूत्र | उपयोग संकेत |
| :--- | :--- | :--- |
| **दो संख्याओं का गुणनफल नियम** | $a \times b = \text{म.स.}(a, b) \times \text{ल.स.}(a, b)$ | यह नियम केवल और केवल दो संख्याओं के लिए मान्य है; तीन संख्याओं पर सीधे लागू न करें |
| **सह-अभाज्य अनुपात रूप** | $a = Hx, \; b = Hy \implies L = Hxy$ | जहाँ $H = \text{म.स.}$ तथा $\gcd(x, y) = 1$ (अर्थात $x, y$ परस्पर सह-अभाज्य अनुपात हैं) |
| **योग एवं अंतर का म.स. संबंध** | $a + b = H(x + y), \; a - b = H(x - y)$ | दो संख्याओं का योग एवं अंतर सदैव उनके महत्तम समापवर्तक (म.स.) का गुणज होता है |
| **सह-अभाज्य युग्मों की संख्या** | $P = xy$ के सह-अभाज्य गुणनखंड युग्म $= 2^{n-1}$ | जहाँ $n$ गुणनफल $xy$ के विभिन्न अभाज्य गुणनखंडों की कुल संख्या है |
| **भिन्नों का महत्तम समापवर्तक (म.स.)** | $\text{म.स.}\left(\frac{a}{b}, \frac{c}{d}\right) = \frac{\text{म.स.}(a, c)}{\text{ल.स.}(b, d)}$ | सूत्र लगाने से पूर्व सभी भिन्नों को उनके सरलतम रूप में बदलना अनिवार्य है |
| **भिन्नों का लघुत्तम समापवर्त्य (ल.स.)** | $\text{ल.स.}\left(\frac{a}{b}, \frac{c}{d}\right) = \frac{\text{ल.स.}(a, c)}{\text{म.स.}(b, d)}$ | अंशों का ल.स. निकालकर उसे हरों के म.स. से विभाजित किया जाता है |
| **ल.स. मॉडल 1 (समान शेषफल $r$)** | $N = \text{ल.स.}(d_1, d_2, d_3) \times k + r$ | जब प्रत्येक भाजक से भाग देने पर प्रत्येक स्थिति में समान शेषफल $r$ बचता हो |
| **ल.स. मॉडल 2 (समान अंतर $K$)** | $N = \text{ल.स.}(d_1, d_2, d_3) \times k - K$ | जब प्रत्येक स्थिति में (भाजक - शेषफल) $= K$ (समान ऋणात्मक शेषफल) प्राप्त हो |
| **म.स. मॉडल 1 (ज्ञात शेषफल $r$)** | $\text{म.स.}(A - r, B - r, C - r)$ | दी गई संख्याओं में से ज्ञात शेषफल घटाकर शेष बची संख्याओं का म.स. ज्ञात करें |
| **म.स. मॉडल 2 (समान अज्ञात शेषफल)** | $\text{म.स.}(\vert A - B \vert, \; \vert B - C \vert, \; \vert C - A \vert)$ | दी गई संख्याओं के युग्मवार धनात्मक अंतरों का महत्तम समापवर्तक निकालें |
| **यूक्लिडियन विभाजन कलनविधि** | $\gcd(a, b) = \gcd(b, a \pmod b)$ | बड़ी संख्या को छोटी संख्या से तब तक भाग दें जब तक शेषफल शून्य न हो जाए |
| **घंटियों का एक साथ बजना (तुल्यकालन)** | $\text{कुल बार} = \left\lfloor \frac{T}{\text{ल.स.}(t_1, t_2, \dots)} \right\rfloor + 1$ | यदि शुरुआत $t=0$ पर एक साथ बजने से हो तो भागफल में 1 जोड़ना न भूलें |
| **वृत्ताकार पथ: आरंभिक बिंदु पर मिलना** | $T_{\text{आरंभ}} = \text{ल.स.}(t_1, t_2, t_3)$ | पहले प्रत्येक धावक का एक चक्कर पूरा करने का समय ($t = \text{दूरी} / \text{चाल}$) निकालें |
| **वृत्ताकार पथ: पथ पर पहली बार मिलना** | $T_{\text{प्रथम}} = \frac{\text{परिधि}}{\text{सापेक्ष चाल}}$ | सापेक्ष चाल: एक ही दिशा में अंतर $\vert v_1 - v_2 \vert$, विपरीत दिशा में योग $v_1 + v_2$ |
| **फर्श पर वर्गाकार टाइलों की न्यूनतम संख्या** | $\text{टाइल्स} = \frac{L \times B}{H^2}, \text{ जहाँ } H = \text{म.स.}(L, B)$ | टाइल की अधिकतम भुजा $H$ लेने पर टाइलों की संख्या न्यूनतम प्राप्त होती है |
| **तीन संख्याओं का अनुपात नियम** | $a=Hx, b=Hy, c=Hz \implies L = H \cdot \text{ल.स.}(x, y, z)$ | यदि $x, y, z$ परस्पर सह-अभाज्य हों, तो $L = Hxyz$ तथा $a \cdot b \cdot c = H^2 \cdot L$ |
| **घात व्यंजकों का म.स. $(a^m - 1)$ एवं $(a^n - 1)$** | $\gcd(a^m - 1, a^n - 1) = a^{\gcd(m, n)} - 1$ | बड़ी घातांक वाली संख्याओं के अंतर का तीव्र बीजगणितीय महत्तम समापवर्तक प्रमेय |
| **घात व्यंजकों का म.स. $(a^m + 1)$ एवं $(a^n + 1)$** | $\gcd(a^m + 1, a^n + 1) = a^{\gcd(m, n)} + 1$ | जब $m / \gcd(m, n)$ और $n / \gcd(m, n)$ दोनों विषम पूर्णांक हों |
| **विभिन्न शेषफलों वाली सबसे बड़ी संख्या** | $\text{म.स.}(A - r_1, B - r_2, C - r_3)$ | प्रत्येक संख्या में से उसका संबंधित शेषफल घटाकर परिणामों का म.स. निकालें |
| **विभाज्य होने वाली सबसे छोटी $n$-अंकीय संख्या** | $\text{न्यूनतम } n\text{-अंक} + (\text{ल.स.} - \text{शेषफल})$ | जहाँ $\text{शेषफल} = 10^{n-1} \pmod{\text{ल.स.}}$ (यदि शेषफल $> 0$ हो) |
| **विभाज्य होने वाली सबसे बड़ी $n$-अंकीय संख्या** | $\text{अधिकतम } n\text{-अंक} - \text{शेषफल}$ | जहाँ $\text{शेषफल} = (10^n - 1) \pmod{\text{ल.स.}}$ |
