# 🪄 ल.स.प. और म.स.प. — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

**🎯 ट्रिक 1: "बड़ा भाई LCM, छोटा भाई HCF"**

```
┌─────────────────────────────────────┐
│ LCM = बड़ा भाई → सबसे बड़ा या बड़ा  │
│ HCF = छोटा भाई → सबसे छोटा या छोटा │
│                                     │
│ याद रखो: "बड़ा = Large, आधा = Half"│
│ LCM संख्याओं से ≥ होता है           │
│ HCF संख्याओं से ≤ होता है           │
└─────────────────────────────────────┘
```
परीक्षा में विकल्प देखकर ही आधे गलत कट जाते हैं — LCM का उत्तर दी गई संख्याओं से छोटा कभी नहीं हो सकता!

---

**🎯 ट्रिक 2: जादुई गुणनफल सूत्र — "दो का खेल"**

```
┌─────────────────────────────────────┐
│  पहली संख्या × दूसरी संख्या         │
│      = LCM × HCF                    │
│                                     │
│  म्नेमोनिक: "दो-दो का हाथ"          │
│  (दो संख्याएँ = दो गुणनफल)          │
└─────────────────────────────────────┘
```
⚠️ यह सूत्र **केवल दो संख्याओं** के लिए! तीन संख्याओं पर लगाया तो गलत — यही परीक्षक का पसंदीदा जाल है।

---

**🎯 ट्रिक 3: अभाज्य गुणनखंड में कौन-सी घात? — "L ऊँचा, H नीचा"**

```
┌─────────────────────────────────────┐
│ LCM → सबसे ऊँची घात (Highest power)│
│ HCF → सबसे नीची घात (Lowest power) │
│                                     │
│ म्नेमोनिक: "L = Lift ऊपर,           │
│            H = नीचे Half"           │
└─────────────────────────────────────┘
```
उदाहरण: 12 = 2²×3, 18 = 2×3² → LCM = 2²×3² = 36, HCF = 2×3 = 6

---

**🎯 ट्रिक 4: HCF में "सिर्फ़ साझा" — COMMON ही KING**

```
┌─────────────────────────────────────┐
│ HCF लेते समय केवल वही अभाज्य गुणक  │
│ जो सभी संख्याओं में COMMON हों।    │
│                                     │
│ म्नेमोनिक: "HCF = साझा खजाना"      │
│ जो सबके पास नहीं, वो खजाने में नहीं │
└─────────────────────────────────────┘
```
LCM में सब कुछ लो (सबसे बड़ी घात के साथ), HCF में सिर्फ़ साझा लो।

---

**🎯 ट्रिक 5: भिन्नों का LCM/HCF — "ऊपर-नीचे उल्टा"**

```
┌─────────────────────────────────────┐
│ भिन्नों का LCM = अंशों का LCM /     │
│                  हरों का HCF        │
│                                     │
│ भिन्नों का HCF = अंशों का HCF /     │
│                  हरों का LCM        │
│                                     │
│ म्नेमोनिक: "L ऊपर L, H ऊपर H —     │
│ नीचे हमेशा उल्टा भाई"              │
└─────────────────────────────────────┘
```
याद रखने का तरीका: ऊपर (अंश) में वही लगाओ जो पूछा है, नीचे (हर) में उसका उल्टा।

---

**🎯 ट्रिक 6: घंटियाँ/बत्तियाँ एक साथ — "मिलन = LCM"**

```
┌─────────────────────────────────────┐
│ "कितने समय बाद एक साथ बजेंगी/       │
│  जलेंगी/मिलेंगे?" → हमेशा LCM      │
│                                     │
│ म्नेमोनिक: "मिलन का मेला = LCM"    │
│ (मेले में सब एक साथ मिलते हैं!)    │
└─────────────────────────────────────┘
```
जैसे ही "एक साथ", "पुनः मिलेंगे", "साथ-साथ" दिखे → बिना सोचे LCM निकालो।

---

**🎯 ट्रिक 7: बाँटना/काटना = HCF — "बाँटो मत, HCF लो"**

```
┌─────────────────────────────────────┐
│ "अधिकतम कितने टुकड़े/डिब्बे/        │
│  समूह बनाए जा सकते हैं?" → HCF     │
│                                     │
│ म्नेमोनिक: "सबसे बड़ा बँटवारा      │
│            = HCF का दरबार"         │
└─────────────────────────────────────┘
```
"अधिकतम/सबसे बड़ा माप जो पूरा-पूरा बाँट दे" → HCF। "न्यूनतम/सबसे छोटा जो सबसे कट जाए" → LCM।

---

**🎯 ट्रिक 8: शेषफल वाले प्रश्न — "शेष घटाओ, LCM निकालो, शेष जोड़ो"**

```
┌─────────────────────────────────────┐
│ "वह न्यूनतम संख्या जिसे a,b,c से    │
│  भाग देने पर प्रत्येक बार शेष r    │
│  बचे"                               │
│                                     │
│ उत्तर = LCM(a,b,c) + r              │
│                                     │
│ म्नेमोनिक: "पहले मिलन, फिर बचत"   │
└─────────────────────────────────────┘
```
उदाहरण: 4, 5, 6 से भाग देने पर शेष 3 → LCM = 60, उत्तर = 63

---

**🎯 ट्रिक 9: शेषफल अलग-अलग हों — "अंतर समान तो घटाओ"**

```
┌─────────────────────────────────────┐
│ a से भाग → शेष p, b से भाग → शेष q │
│ और (a−p) = (b−q) = k (समान अंतर)  │
│                                     │
│ उत्तर = LCM(a,b,...) − k            │
│                                     │
│ म्नेमोनिक: "कमी पूरी करो"          │
│ (k जोड़ने पर पूरा कट जाता!)        │
└─────────────────────────────────────┘
```
उदाहरण: 3,4,5 से भाग पर शेष 2,3,4 → अंतर हर बार 1 → LCM(3,4,5)−1 = 59

---

**🎯 ट्रिक 10: दो संख्याएँ और उनका HCF दिया हो — "HCF को निकालो बाहर"**

```
┌─────────────────────────────────────┐
│ संख्याएँ = HCF × a और HCF × b      │
│ जहाँ a, b सह-अभाज्य (co-prime)     │
│                                     │
│ म्नेमोनिक: "HCF है आम चोर,         │
│ बाहर निकालो, अंदर co-prime जोड़"  │
└─────────────────────────────────────┘
```
यह ट्रिक "संख्याओं का योग/अंतर दिया हो और संख्याएँ निकालनी हों" वाले प्रश्नों में जादू करती है।

---

**🎯 ट्रिक 11: Co-prime पहचानो — "1 का रिश्ता"**

```
┌─────────────────────────────────────┐
│ दो संख्याएँ co-prime ⇔ HCF = 1     │
│ Co-prime का LCM = सीधा गुणनफल!     │
│                                     │
│ म्नेमोनिक: "रिश्ता सिर्फ़ 1 से,    │
│ LCM = सीधा गुणा"                   │
└─────────────────────────────────────┘
```
उदाहरण: 8 और 9 co-prime → LCM = 72 (सीधे गुणा, कोई गुणनखंड नहीं!)

---

**🎯 ट्रिक 12: युक्लिड विभाजन — "घटाते जाओ, HCF पाओ"**

```
┌─────────────────────────────────────┐
│ बड़ी संख्याओं का HCF:               │
│ बड़ी ÷ छोटी → शेषफल से फिर भाग    │
│ ...जब तक शेष 0। अंतिम भाजक = HCF   │
│                                     │
│ म्नेमोनिक: "भाग-भाग के प्यार"      │
│ (जो अंत में पूरा काटे, वही HCF)    │
└─────────────────────────────────────┘
```
बड़ी संख्याएँ (जैसे 1071, 1029) दिखें तो गुणनखंड मत करो — सीधे युक्लिड विधि!

---

**🎯 ट्रिक 13: "न्यूनतम संख्या जो पूरी कटे" vs "अधिकतम संख्या जो काटे"**

```
┌─────────────────────────────────────┐
│ "वह न्यूनतम संख्या जो a,b,c से     │
│  पूरी कट जाए" → LCM                │
│                                     │
│ "वह अधिकतम संख्या जो a,b,c को     │
│  पूरी काट दे" → HCF                │
│                                     │
│ म्नेमोनिक: "कटे = LCM, काटे = HCF"│
└─────────────────────────────────────┘
```
क्रिया की दिशा पकड़ो: संख्या खुद कट रही है (LCM) या दूसरों को काट रही है (HCF)?

---

**🎯 ट्रिक 14: विकल्पों से उल्टी चाल — "Option Attack"**

```
┌─────────────────────────────────────┐
│ LCM/HCF के प्रश्नों में विकल्प     │
│ उठाकर जाँचो:                        │
│ • LCM विकल्प सभी संख्याओं से कटता? │
│ • HCF विकल्प सभी संख्याओं को काटता?│
│                                     │
│ म्नेमोनिक: "उल्टी सीढ़ी —          │
│ विकल्प से प्रश्न की ओर"            │
└─────────────────────────────────────┘
```
समय बचाने की ब्रह्मास्त्र — खासकर जब संख्याएँ बड़ी हों।

---

**🎯 ट्रिक 15: अंतिम ब्रह्मास्त्र — "L-H जोड़ी का नियम"**

```
┌─────────────────────────────────────┐
│ यदि HCF = H और LCM = L,            │
│ संख्याएँ Hx, Hy (x,y co-prime)     │
│ तो L = H × x × y                   │
│                                     │
│ म्नेमोनिक: "H की दुनिया में         │
│ L = H × जोड़ी का गुणा"             │
└─────────────────────────────────────┘
```
इससे "दो संख्याओं का LCM = 84, HCF = 4, एक संख्या 12, दूसरी?" जैसे प्रश्न 10 सेकंड में: दूसरी = (84×4)/12 = 28
