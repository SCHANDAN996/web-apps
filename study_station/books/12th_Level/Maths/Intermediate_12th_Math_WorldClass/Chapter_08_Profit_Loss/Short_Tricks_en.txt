# 🪄 Short Tricks — Profit & Loss (Memory Magic)

---

┌─────────────────────────────────────────────┐
│ **TRICK 1 — The "CP is King" Rule**          │
│                                              │
│ 👑 "The KING always sits on the THRONE."     │
│ Profit % and Loss % are ALWAYS calculated    │
│ on CP (Cost Price) — never on SP.            │
│                                              │
│ Memory hook: **"Percent bows to the KING     │
│ (CP), not the servant (SP)."**               │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 2 — The SP Twin Formulas**           │
│                                              │
│ SP = CP × (100 + P%)/100                     │
│ SP = CP × (100 − L%)/100                     │
│                                              │
│ 🧠 Mnemonic: **"Profit PLUS, Loss LESS"**    │
│ (P-L-P-L: Profit→Plus, Loss→Less)            │
│ Say it like a drumbeat: *Profit-Plus,        │
│ Loss-Less!*                                  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 3 — Dishonest Dealer Trick**         │
│                                              │
│ A shopkeeper uses false weights:             │
│ Profit % = (Error ÷ True weight given) × 100 │
│                                              │
│ 🥷 Mnemonic: **"The CHEAT divides by what    │
│ he GIVES, not what he TAKES."**              │
│ Error on top, delivered weight below.        │
│ Example: gives 900g for 1kg →                │
│ Profit = 100/900 × 100 = 11.11%              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 4 — Successive Discounts**           │
│                                              │
│ Two discounts a% and b%:                     │
│ Net = a + b − (ab/100)                       │
│                                              │
│ 🎢 Mnemonic: **"ADD them, then PUNISH them   │
│ with the product."**                         │
│ 20% + 10% = 30 − 2 = 28% (never 30%!)        │
│ Trap alert: discounts NEVER simply add.      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 5 — Marked Price Ladder**            │
│                                              │
│ MP → (discount) → SP → (profit) → CP         │
│                                              │
│ 🪜 Loci trick: Picture a SHOP SIGNBOARD      │
│ (MP) at the top of a ladder. Climb DOWN      │
│ one rung = discount → SP. Climb DOWN again   │
│ = remove profit → CP.                        │
│ **"Signboard → Counter → Godown"**           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 6 — Same SP, One Profit One Loss**   │
│                                              │
│ Two items sold at same SP, one at x% profit, │
│ one at x% loss → ALWAYS a loss:              │
│ Loss % = x²/100                              │
│                                              │
│ ⚖️ Mnemonic: **"Twin sales, twin fate —      │
│ the SQUARE seals your LOSS."**               │
│ x = 10 → Loss = 100/100 = 1%. Always loss!   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 7 — MP–CP Bridge Formula**           │
│                                              │
│ MP/CP = (100 + P%)/(100 − D%)                │
│                                              │
│ 🌉 Mnemonic: **"Profit climbs UP, Discount   │
│ dives DOWN."**                               │
│ Numerator = profit side (up),                │
│ Denominator = discount side (down).          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 8 — The 4-Letter Family**            │
│                                              │
│ Acronym: **"C-S-M-D"**                       │
│ **C**ost Price → **S**elling Price →         │
│ **M**arked Price → **D**iscount              │
│                                              │
│ 🗣️ Say it: **"Clever Sellers Mark            │
│ Discounts."**                                │
│ CP is real cost, SP is real sale,            │
│ MP is the fake tag, Discount is the drama.   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 9 — Profit on SP vs CP (Exam Trap)** │
│                                              │
│ If profit is x% of SP, then on CP it is      │
│ [x/(100 − x)] × 100 %                        │
│                                              │
│ 🪤 Mnemonic: **"SP-profit is a SHY number —  │
│ it GROWS when it meets CP."**                │
│ 20% on SP = 20/80 = 25% on CP.               │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 10 — Fraction Flash Table**          │
│                                              │
│ 10% = 1/10 | 12.5% = 1/8 | 16.66% = 1/6      │
│ 20% = 1/5 | 25% = 1/4 | 33.33% = 1/3         │
│                                              │
│ 🍕 Mnemonic: **"Pizza slices!"**             │
│ 25% profit? CP = 4 slices, profit = 1 slice, │
│ SP = 5 slices. Solve everything in slices —  │
│ no calculator needed!                        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 11 — Buying & Selling Articles**     │
│                                              │
│ "x articles bought for ₹a, y sold for ₹b":   │
│ Make quantities EQUAL (LCM), then compare.   │
│                                              │
│ 🍎 Mnemonic: **"Equal the APPLES before      │
│ you count the RUPEES."**                     │
│ Never compare money with unequal quantities! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 12 — CP from SP (Reverse Gear)**     │
│                                              │
│ CP = SP × 100/(100 + P%)                     │
│                                              │
│ 🚗 Mnemonic: **"Going BACK to CP? Put the    │
│ car in REVERSE — divide, don't multiply."**  │
│ SP is the destination; CP is home.           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 13 — Discount is on MP Only**        │
│                                              │
│ 🏷️ Mnemonic: **"The TAG gets the CUT."**     │
│ Discount % is always on Marked Price (the    │
│ price tag), never on CP.                     │
│ Picture scissors ✂️ cutting the price TAG.   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 14 — The 15-Second Sanity Check**    │
│                                              │
│ Before marking the answer:                   │
│ • Profit? SP must be BIGGER than CP.         │
│ • Loss? SP must be SMALLER than CP.          │
│ • After discount? SP must be BELOW MP.       │
│                                              │
│ 🔍 Mnemonic: **"BIG-PROFIT, SMALL-LOSS,      │
│ TAG-HIGHEST."**                              │
│ If your answer breaks this, recalculate!     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 15 — The Master Story (Loci)**       │
│                                              │
│ Walk through a market in your mind:          │
│ 1️⃣ GODOWN = CP (where goods are bought)     │
│ 2️⃣ PRICE TAG on shelf = MP                  │
│ 3️⃣ Scissors cut the tag = Discount          │
│ 4️⃣ COUNTER = SP (money changes hands)       │
│ 5️⃣ CASH BOX = Profit (extra coins) or       │
│    empty box = Loss                          │
│                                              │
│ 🛒 One walk = the whole chapter revised!     │
└─────────────────────────────────────────────┘
