# 🪄 लाभ और हानि — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 1: "क्रय पर हिसाब" — सुनहरा नियम │
├─────────────────────────────────────────┤
│ लाभ% और हानि% हमेशा **क्रय मूल्य (CP)** पर │
│ निकालते हैं, कभी विक्रय मूल्य पर नहीं!      │
│                                         │
│ 🧠 याद रखो: "जेब से जो गया, उसी पर हिसाब" │
│ जेब से CP गया → लाभ/हानि CP पर!          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 2: "लाभ = जोड़, हानि = घटाओ"      │
├─────────────────────────────────────────┤
│ लाभ हो → SP = CP × (100 + लाभ%)/100      │
│ हानि हो → SP = CP × (100 − हानि%)/100    │
│                                         │
│ 🧠 म्नेमोनिक: "लड्डू जुड़े, हाथी घटे"      │
│ लाभ → जुड़ता है (+), हानि → घटता है (−)   │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 3: "बराबर लाभ-हानि = हमेशा हानि"  │
├─────────────────────────────────────────┤
│ दो वस्तुएँ, एक पर x% लाभ, दूसरी पर x%     │
│ हानि, SP बराबर → कुल सौदे में **हमेशा हानि**│
│ हानि% = x²/100                          │
│                                         │
│ 🧠 म्नेमोनिक: "बराबरी का खेल, जेब का मेल"  │
│ उदाहरण: 10% लाभ + 10% हानि → 1% हानि     │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 4: "छूट के बाद भी लाभ" — MP सूत्र │
├─────────────────────────────────────────┤
│ MP/CP = (100 + लाभ%)/(100 − छूट%)        │
│                                         │
│ 🧠 म्नेमोनिक: "ऊपर लाभ, नीचे छूट"         │
│ ऊपर (अंश) में लाभ जुड़ता है,              │
│ नीचे (हर) में छूट घटती है।               │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 5: "क्रमिक छूटें कभी न जोड़ो"      │
├─────────────────────────────────────────┤
│ d₁% और d₂% की दो छूटें = एकल छूट          │
│ = d₁ + d₂ − (d₁×d₂)/100                 │
│                                         │
│ 🧠 म्नेमोनिक: "जोड़ो, फिर गुणा-कर-घटाओ"    │
│ 20% + 10% ≠ 30%! असली = 20+10−2 = 28%    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 6: "झूठा वज़न" — दुकानदार की चाल  │
├─────────────────────────────────────────┤
│ 1 kg की जगह g ग्राम तौले →               │
│ लाभ% = (1000 − g)/g × 100               │
│                                         │
│ 🧠 म्नेमोनिक: "कम तौला, ऊपर चढ़ा"         │
│ कमी ऊपर (अंश), असली तौल नीचे (हर)।       │
│ 800 ग्राम तौले → 200/800 × 100 = 25% लाभ  │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 7: "SP बराबर, CP अलग" — तुरंत जाँच│
├─────────────────────────────────────────┤
│ जब दो वस्तुओं का SP बराबर हो और लाभ% =    │
│ हानि% हो, तो बिना सोचे: **हानि = x²/100** │
│                                         │
│ 🧠 लोकस विधि: सोचो दुकान में दो एक जैसी   │
│ कुर्सियाँ एक ही दाम पर बिकीं — मालिक ने    │
│ मुस्कुराया, पर हिसाब में हमेशा घाटा!      │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 8: "लाभ% से SP सीधे" — गुणक ट्रिक │
├─────────────────────────────────────────┤
│ 20% लाभ → SP = CP × 1.2                  │
│ 25% लाभ → SP = CP × 1.25                 │
│ 15% हानि → SP = CP × 0.85                │
│                                         │
│ 🧠 म्नेमोनिक: "दशमलव दोस्त"               │
│ प्रतिशत को दशमलव गुणक बनाओ — गुणा एक      │
│ ही कदम में, दो स्टेप की ज़रूरत खत्म!      │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 9: "CP निकालना? उल्टा चलो"        │
├─────────────────────────────────────────┤
│ SP दिया हो और लाभ% दिया हो →              │
│ CP = SP × 100/(100 + लाभ%)               │
│                                         │
│ 🧠 म्नेमोनिक: "वापसी का रास्ता उल्टा"     │
│ आते वक्त जोड़ा था, तो जाते वक्त भाग दो।   │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 10: "मिलावट वाला दूध"             │
├─────────────────────────────────────────┤
│ दूधवाला पानी मिलाकर लागत मूल्य पर बेचे →  │
│ लाभ% = (पानी/दूध) × 100                  │
│                                         │
│ 🧠 म्नेमोनिक: "पानी ही मुनाफा"            │
│ पानी मुफ्त है — जितना पानी, उतना ही लाभ!  │
│ 1 लीटर पानी + 4 लीटर दूध → 25% लाभ       │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 11: "x वस्तुएँ बेचो, y का लाभ"     │
├─────────────────────────────────────────┤
│ x वस्तुएँ बेचने पर y वस्तुओं के CP के      │
│ बराबर लाभ → लाभ% = y/x × 100             │
│                                         │
│ 🧠 म्नेमोनिक: "ऊपर लाभ, नीचे बिकी संख्या" │
│ 12 बेचने पर 3 के CP का लाभ → 3/12 = 25%  │
│                                         │
│ ⚠️ ध्यान: लाभ y वस्तुओं के **SP** के       │
│ बराबर हो, तभी लाभ% = y/(x − y) × 100     │
│ (12 बेचने पर 3 के SP का लाभ → 3/9 = 33⅓%)│
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 12: "लाभ% = हानि% वाला पेच"       │
├─────────────────────────────────────────┤
│ SP पर लाभ x% हो तो CP पर लाभ =           │
│ x/(100 + x) × 100 ... नहीं! ध्यान दो:     │
│ SP पर x% लाभ = CP पर x/(100−x) × 100     │
│                                         │
│ 🧠 म्नेमोनिक: "आधार बदला, निशाना बदला"    │
│ CP ↔ SP बदलते ही + और − पलट जाते हैं।    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 13: "भिन्न-मित्र" — 25%, 20%, 12.5%│
├─────────────────────────────────────────┤
│ 25% = 1/4, 20% = 1/5, 12.5% = 1/8,       │
│ 33⅓% = 1/3, 16⅔% = 1/6                   │
│                                         │
│ 🧠 म्नेमोनिक: "चार-पाँच-आठ की टोली"       │
│ 25% लाभ → CP 4 तो SP 5! सीधे अनुपात से    │
│ हल, कैलकुलेशन ही खत्म।                   │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 14: "MP–छूट–SP की सीढ़ी"          │
├─────────────────────────────────────────┤
│ MP → (छूट हटाओ) → SP → (लाभ हटाओ) → CP   │
│                                         │
│ 🧠 लोकस विधि: दुकान की सीढ़ी याद करो —    │
│ सबसे ऊपर टैग का दाम (MP), बीच में बिक्री  │
│ का दाम (SP), सबसे नीचे दुकानदार की लागत  │
│ (CP)। ऊपर से नीचे उतरते ही घटता जाता है! │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🎯 ट्रिक 15: "एक्रोनिम — क्र.वि.लाभ.हानि"   │
├─────────────────────────────────────────┤
│ **क्र**य मूल्य → **वि**क्रय मूल्य →        │
│ **लाभ** = वि − क्र → **हानि** = क्र − वि   │
│                                         │
│ 🧠 म्नेमोनिक: "क्रिया विना लाभ हानि"      │
│ बड़े में से छोटा घटाओ — SP बड़ा तो लाभ,   │
│ CP बड़ा तो हानि। बस!                     │
└─────────────────────────────────────────┘
