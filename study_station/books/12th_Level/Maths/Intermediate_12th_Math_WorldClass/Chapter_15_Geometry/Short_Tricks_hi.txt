## ट्रिक 1: त्रिभुज के कोण — "तीनों भाई मिलकर 180"

```
┌─────────────────────────────────────────┐
│  🧠 "तीन भाई एक घर में, मिलकर बँटे 180" │
│                                         │
│  त्रिभुज के तीनों कोणों का योग = 180°   │
│  याद रखो: त्रि-भुज = तीन भाई,           │
│  और घर का किराया = 180 रुपये,           │
│  तीनों मिलकर चुकाते हैं!                │
└─────────────────────────────────────────┘
```

## ट्रिक 2: बहुभुज के कोण — "दो कम करो, 180 से गुणा"

```
┌─────────────────────────────────────────┐
│  🧠 "भुजाओं से 2 कम, फिर 180 का धम"     │
│                                         │
│  n-भुज के अंतःकोणों का योग = (n−2)×180° │
│  प्रत्येक कोण (समबहुभुज) = (n−2)×180°/n │
│  बाह्य कोण = 360°/n                     │
│                                         │
│  उदा: षट्भुज → (6−2)×180 = 720°         │
└─────────────────────────────────────────┘
```

## ट्रिक 4: वृत्त का क्षेत्रफल vs परिधि — "R² खेत, 2R बाड़"

```
┌─────────────────────────────────────────┐
│  🧠 "खेत में R दो बार, बाड़ में R दुगुना"│
│                                         │
│  क्षेत्रफल (खेत) = πr²  → R का वर्ग     │
│  परिधि (बाड़) = 2πr     → R का दुगुना   │
│                                         │
│  खेत बड़ा होता है इसलिए वर्ग (²),       │
│  बाड़ सिर्फ़ घेरती है इसलिए दुगुना (2)! │
└─────────────────────────────────────────┘
```

└─────────────────────────────────────────┘

## ट्रिक 6: त्रिभुज के केंद्र — "GOC I" एक्रोनिम

```
┌─────────────────────────────────────────┐
│  🧠 "GOC-I" (जैसे सेना का जीओसी!)       │
│                                         │
│  G = Centroid (केन्द्रक) → माध्यिकाएँ    │
│  O = Circumcentre (परिकेन्द्र) → लंब     │
│      समद्विभाजक                         │
│  C/I = Incentre (अंतःकेन्द्र) → कोण      │
│      समद्विभाजक                         │
│  Orthocentre (लंबकेन्द्र) → शीर्षलंब     │
│                                         │
│  केन्द्रक माध्यिका को 2:1 में बाँटता है  │
│  "ऊपर 2 हिस्से, नीचे 1"                 │
└─────────────────────────────────────────┘
```

## ट्रिक 14: आयत vs वर्ग — "वर्ग = आयत का VIP भाई"

```
┌─────────────────────────────────────────┐
│  🧠 "हर वर्ग आयत है, हर आयत वर्ग नहीं"  │
│                                         │
│  आयत: क्षेत्रफल = l×b, विकर्ण = √(l²+b²)│
│  वर्ग: क्षेत्रफल = a², विकर्ण = a√2     │
│                                         │
│  वर्ग का विकर्ण = भुजा × √2             │
│  "विकर्ण में रूट-2 का तड़का"            │
└─────────────────────────────────────────┘
```

## ट्रिक 15: कोणों के नाम — "न्यून-सम-अधिक: छोटा, सीधा, मोटा"

```
┌─────────────────────────────────────────┐
│  🧠 शरीर से याद करो:                    │
│                                         │
│  न्यूनकोण (<90°) = दुबला-पतला (छोटा)    │
│  समकोण (=90°) = सीधा खड़ा फौजी          │
│  अधिककोण (90°–180°) = मोटा (फैला हुआ)   │
│  ऋजुकोण (=180°) = लेटा हुआ (सीधी रेखा)  │
│                                         │
│  "पतला-फौजी-मोटा-लेटा"                  │
└─────────────────────────────────────────┘
```
