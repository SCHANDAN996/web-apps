# अध्याय 10: चक्रवृद्धि ब्याज (इंटरमीडिएट / 12वीं स्तर)

## 1. चक्रवृद्धि ब्याज की आधारभूत संकल्पना
चक्रवृद्धि ब्याज (Compound Interest - CI) वह ब्याज है जो प्रारंभिक मूलधन के साथ-साथ पूर्ववर्ती अवधियों के संचित ब्याज पर भी देय होता है। इसे सामान्यतः "ब्याज पर ब्याज" कहा जाता है, जो धन की घातांकीय (Exponential) वृद्धि को दर्शाता है।
- **मूलधन (P):** उधार ली गई अथवा निवेश की गई प्रारंभिक राशि।
- **ब्याज दर (R):** वार्षिक प्रतिशत दर।
- **समय (T अथवा n):** निवेश की कुल अवधि (वर्षों में)।
- **संयोजन आवृत्ति (m):** प्रति वर्ष ब्याज संयोजन की संख्या।
  - वार्षिक: m = 1, दर = R%, समय = T वर्ष।
  - अर्धवार्षिक (छमाही): m = 2, दर = R/2%, समय = 2T अवधियाँ।
  - त्रैमासिक (तिमाही): m = 4, दर = R/4%, समय = 4T अवधियाँ।
  - मासिक: m = 12, दर = R/12%, समय = 12T अवधियाँ।
- **मिश्रधन का मास्टर सूत्र:**
  A = P * [ 1 + R / (100 * m) ]^(m * T)
- **चक्रवृद्धि ब्याज:**
  CI = मिश्रधन - मूलधन = P * [ (1 + R/100)^T - 1 ]

## 2. क्रमिक प्रतिशत (Successive Percentage) विधि
वार्षिक दर r% पर 2 वर्षों के लिए:
- प्रभावी चक्रवृद्धि दर R_eff = 2r + (r^2 / 100)%.
- भिन्न-भिन्न क्रमिक दरों r_1% तथा r_2% के लिए:
  R_eff = r_1 + r_2 + (r_1 * r_2) / 100 %.
- तीन क्रमिक वर्षों (r_1, r_2, r_3) के लिए:
  R_eff = (r_1 + r_2 + r_3) + [ (r_1*r_2 + r_2*r_3 + r_3*r_1) / 100 ] + [ (r_1 * r_2 * r_3) / 10000 ] %.

## 3. ट्री विधि (पास्कल अनुपात विधि)
घातांकों की लंबी गणना से बचने के लिए स्तरवार ब्याज ज्ञात करने की तकनीक:
- **2-वर्षीय संरचना (2 : 1 अनुपात):**
  - प्रथम पद A = P का R% (प्रथम व द्वितीय वर्ष का साधारण ब्याज)।
  - द्वितीय पद B = A का R% (ब्याज पर ब्याज)।
  - कुल CI = 2*A + B।
  - कुल SI = 2*A।
  - अंतर (CI - SI) = B।
- **3-वर्षीय संरचना (3 : 3 : 1 अनुपात):**
  - पद A = P का R%।
  - पद B = A का R%।
  - पद C = B का R%।
  - कुल CI = 3*A + 3*B + C।
  - कुल SI = 3*A।
  - 3 वर्षों का अंतर (CI - SI) = 3*B + C।

## 4. CI और SI के अंतर का विश्लेषण
- **2 वर्षों के अंतर का सूत्र:**
  D_2 = CI_2 - SI_2 = P * (R / 100)^2 = (P * R^2) / 10000.
- **3 वर्षों के अंतर का सूत्र:**
  D_3 = CI_3 - SI_3 = [ P * R^2 * (300 + R) ] / 10^6.
- **3-वर्षीय और 2-वर्षीय अंतर का अनुपात:**
  D_3 / D_2 = (300 + R) / 100 = 3 + (R / 100).

## 5. चक्रवृद्धि ब्याज में गुने का नियम
- यदि कोई धनराशि T वर्षों में k गुनी हो जाती है:
  - 2T वर्षों में वह k^2 * P होगी।
  - 3T वर्षों में वह k^3 * P होगी।
  - m*T वर्षों में वह k^m * P होगी।
- **72 का नियम (दोगुना होने का समय):**
  दोगुना होने का सन्निकट समय T ≈ 72 / R वर्ष।

## 6. समान वार्षिक किश्तें (Installments under CI)
ऋण P को R% चक्रवृद्धि ब्याज पर n समान वार्षिक किश्तों x में चुकाने पर:
  P = [ x / (1 + R/100) ] + [ x / (1 + R/100)^2 ] + ... + [ x / (1 + R/100)^n ]
