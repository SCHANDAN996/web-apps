Q126. (Hard) A loan of Rs 18,200 is to be repaid in three equal annual installments at 20% compound interest per annum. Find the value of each installment.
(A) Rs 8,640  (B) Rs 8,500  (C) Rs 8,800  (D) Rs 8,450

Answer: (A)

Solution:
Rate = 20% = 1/5 => Multiplier = 6/5. Discounting 3 installments: P = 5x / 6 + 25x / 36 + 125x / 216 = (180x + 150x + 125x) / 216 = 455x / 216. Given P = 18200: 18200 = 455x / 216 => x = (18200 * 216) / 455 = 40 * 216 = Rs 8,640. Therefore, the correct value is Rs 8,640, corresponding to option (A).
