Questions 51–75: Medium

51. (Medium) The difference between compound interest and simple interest on a certain sum for 3 years at 10% per annum is Rs 93. Find the sum.
(A) Rs 3,000  (B) Rs 2,500  (C) Rs 3,500  (D) Rs 2,800
Answer: (A) Rs 3,000
Solution: Difference D3 = [P * R^2 * (300 + R)] / 10^6. For R = 10: 93 = [P * 100 * 310] / 10^6 = 31*P / 1000 => P = (93 * 1000) / 31 = Rs 3,000. The required value is Rs 3,000. Hence, the correct option is (A).
Source: SSC CGL Pattern

52. (Medium) On a certain sum, the difference between compound interest and simple interest for 3 years at 5% per annum is Rs 122. Find the principal sum.
(A) Rs 15,000  (B) Rs 16,000  (C) Rs 18,000  (D) Rs 14,000
Answer: (B) Rs 16,000
Solution: Using D3 = [P * R^2 * (300 + R)] / 10^6: 122 = [P * 25 * 305] / 10^6 = 7625*P / 10^6 => P = (122 * 10^6) / 7625 = 122 * (8000 / 61) = 2 * 8000 = Rs 16,000. The required value is Rs 16,000. Hence, the correct option is (B).
Source: SSC CGL Pattern

53. (Medium) The ratio of the difference between compound interest and simple interest for 3 years to that for 2 years is 19 : 6. Find the rate of interest per annum.
(A) 15.00%  (B) 17.50%  (C) 16.67%  (D) 16.00%
Answer: (C) 16.67%
Solution: Ratio D3 / D2 = (300 + R) / 100 = 3 + R/100. Given 19 / 6 = 3 + 1/6: 3 + R/100 = 3 + 1/6 => R/100 = 1/6 => R = 100 / 6 = 16.67% (or 16 2/3%). The required value is 16.67%. Hence, the correct option is (C).
Source: SSC CGL Pattern

59. (Medium) The simple interest on a sum of money for 3 years at 5% per annum is Rs 1,200. Find the compound interest on the same sum at the same rate and for the same period.
(A) Rs 1,261  (B) Rs 1,250  (C) Rs 1,270  (D) Rs 1,280
Answer: (A) Rs 1,261
Solution: Principal P = (1200 * 100) / (5 * 3) = Rs 8,000. Using the 3 : 3 : 1 tree method: Tier 1 interest A = 5% of 8000 = Rs 400. Tier 2 interest B = 5% of 400 = Rs 20. Tier 3 interest C = 5% of 20 = Rs 1. Total CI = 3(400) + 3(20) + 1 = 1200 + 60 + 1 = Rs 1,261. The required value is Rs 1,261. Hence, the correct option is (A).
Source: SSC CGL Pattern

Answer: (B) Rs 266.20

65. (Medium) If the simple interest on a sum for 3 years at 10% per annum is Rs 900, find the difference between the compound interest and simple interest for 3 years on the same sum.
