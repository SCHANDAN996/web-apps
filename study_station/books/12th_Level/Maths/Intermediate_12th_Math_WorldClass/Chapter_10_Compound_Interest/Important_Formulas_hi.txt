# महत्वपूर्ण सूत्र: चक्रवृद्धि ब्याज

| सूत्र का नाम | सूत्र | अनुप्रयोग एवं संदर्भ |
| :--- | :--- | :--- |
| वार्षिक मिश्रधन | A = P * (1 + R/100)^T | वार्षिक संयोजन हेतु |
| अर्धवार्षिक मिश्रधन | A = P * [1 + R/200]^(2T) | छमाही संयोजन हेतु |
| त्रैमासिक मिश्रधन | A = P * [1 + R/400]^(4T) | तिमाही संयोजन हेतु |
| 2-वर्षीय प्रभावी दर | R_eff = 2R + R^2/100 | प्रतिशत हैक |
| 2-वर्षीय ट्री अनुपात | CI = 2A + B | A = P का R%, B = A का R% |
| 3-वर्षीय ट्री अनुपात | CI = 3A + 3B + C | A, B, C क्रमिक ब्याज हैं |
| 2-वर्षीय अंतर (CI - SI) | D_2 = P * (R/100)^2 | अंतर से P या R निकालना |
| 3-वर्षीय अंतर (CI - SI) | D_3 = [P * R^2 * (300 + R)] / 10^6 | 3 वर्षों के अंतर का मानक सूत्र |
| अंतर अनुपात (3-वर्ष / 2-वर्ष) | D_3 / D_2 = (300 + R) / 100 | बिना P के सीधे दर ज्ञात करना |
| घातांकी गुना नियम | T वर्ष में k गुना => m*T वर्ष में k^m गुना | समय और गुने का संबंध |
| भिन्न समय मिश्रधन | A = P*(1+R/100)^a * [1+(b/c * R)/100] | T = a पूर्णांक b/c वर्ष हेतु |
| 2 समान किश्तें | P = x/(1 + R/100) + x/(1 + R/100)^2 | ऋण मुक्ति की वार्षिक किश्तें |
