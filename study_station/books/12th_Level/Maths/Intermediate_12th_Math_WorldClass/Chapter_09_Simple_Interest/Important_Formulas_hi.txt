# 📋 साधारण ब्याज — महत्वपूर्ण सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| साधारण ब्याज (SI) | SI = (P × R × T) / 100 | मूलधन, दर, समय दिए हों तो ब्याज निकालने के लिए |
| मूलधन (P) | P = (SI × 100) / (R × T) | ब्याज, दर, समय से मूलधन ज्ञात करने के लिए |
| दर (R) | R = (SI × 100) / (P × T) | ब्याज, मूलधन, समय से दर ज्ञात करने के लिए |
| समय (T) | T = (SI × 100) / (P × R) | ब्याज, मूलधन, दर से समय ज्ञात करने के लिए |
| मिश्रधन (A) | A = P + SI | कुल वापसी राशि निकालने के लिए |
| मिश्रधन (सीधा) | A = P × (1 + RT/100) | बिना SI अलग से निकाले सीधे मिश्रधन के लिए |
| दर प्रतिदिन (जब T दिनों में) | SI = (P × R × D) / (100 × 365) | समय दिनों में दिया हो तो (साधारण वर्ष = 365 दिन) |
| दर प्रतिमाह (जब T महीनों में) | SI = (P × R × M) / (100 × 12) | समय महीनों में दिया हो तो |
| दो भागों में निवेश | P₁/P₂ = (R₂ × T₂)/(R₁ × T₁) (बराबर ब्याज हेतु) | समान ब्याज पाने के लिए धन किस अनुपात में बाँटें |
| n गुना होने का समय | T = 100(n − 1) / R | कोई राशि R% पर n गुनी कब होगी |
| n गुना होने की दर | R = 100(n − 1) / T | T वर्षों में n गुनी होने पर दर ज्ञात करने के लिए |
| दर बदलने पर ब्याज में अंतर | अंतर = P × (R₂ − R₁) × T / 100 | दर बढ़ने/घटने से ब्याज में फर्क निकालने के लिए |
| किस्त (समान वार्षिक) | P = (100 × x × T) / (100 + RT) | x रु. की T समान वार्षिक किस्तों में चुकता ऋण (या x = P(100 + RT)/(100T)) |
| दो दरों पर समान ब्याज | P₁ : P₂ = R₂T₂ : R₁T₁ | अलग-अलग दर/समय पर समान ब्याज देने वाली राशियों का अनुपात |
| ब्याज = मूलधन का भाग | SI/P = RT/100 | ब्याज मूलधन का कितना अंश है, सीधे जाँचने के लिए |

**संकेत:** P = मूलधन, R = वार्षिक दर (%), T = समय (वर्ष), SI = साधारण ब्याज, A = मिश्रधन, D = दिन, M = महीने, n = गुना, x = किस्त।
