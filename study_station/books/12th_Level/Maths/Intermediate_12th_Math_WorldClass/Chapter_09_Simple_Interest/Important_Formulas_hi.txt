# महत्वपूर्ण सूत्र: साधारण ब्याज (इंटरमीडिएट (12वीं) स्तर)

## 1. मुख्य साधारण ब्याज सूत्र
- साधारण ब्याज: SI = (P * R * T) / 100
- मूलधन: P = (100 * SI) / (R * T)
- ब्याज दर: R = (100 * SI) / (P * T)
- समय: T = (100 * SI) / (P * R)
- मिश्रधन: A = P + SI = P * [ 1 + (R * T) / 100 ]
- मिश्रधन से मूलधन: P = (100 * A) / (100 + R * T)

## 2. परिवर्तनशील ब्याज दरें
- यदि दरें क्रमशः R1 (T1 वर्ष), R2 (T2 वर्ष), R3 (T3 वर्ष) हों:
  कुल SI = (P / 100) * [ R1*T1 + R2*T2 + R3*T3 ]

## 3. गुने के नियम
- n गुना होने में लगा समय: T = [ 100 * (n - 1) ] / R
- n गुना होने के लिए आवश्यक दर: R = [ 100 * (n - 1) ] / T
- दो अवधियों की तुलना: (n1 - 1) / T1 = (n2 - 1) / T2

## 4. पूँजी का विभाजन
- समान ब्याज मिलने पर:
  P1 : P2 : P3 = [ 1 / (R1*T1) ] : [ 1 / (R2*T2) ] : [ 1 / (R3*T3) ]
- समान मिश्रधन मिलने पर:
  P1 : P2 : P3 = [ 1 / (100 + R1*T1) ] : [ 1 / (100 + R2*T2) ] : [ 1 / (100 + R3*T3) ]

## 5. ऋण मुक्ति हेतु वार्षिक किश्त (Installment)
- T वर्षों में देय ऋण D को R% वार्षिक दर पर T समान किश्तों x में चुकाने का सूत्र:
  x = (100 * D) / [ 100 * T + (R * T * (T - 1)) / 2 ]

## 6. पृथक्करण (Alligation) सूत्र
- R1% और R2% पर दो निवेशों का अनुपात (औसत दर R_m%):
  P1 : P2 = (R2 - R_m) : (R_m - R1)

## 7. वास्तविक बट्टा एवं महाजनी बट्टा
- तत्काल धन: PW = (100 * SD) / (100 + R * T)
- वास्तविक बट्टा: TD = (SD * R * T) / (100 + R * T) = (PW * R * T) / 100
- महाजनी बट्टा: BD = (SD * R * T) / 100
- महाजनी लाभ: BG = BD - TD = (TD^2) / PW
- संबंध: SD = (BD * TD) / (BD - TD)
