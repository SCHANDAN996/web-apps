# 🪄 शॉर्ट ट्रिक्स — साधारण ब्याज (Simple Interest)

याद रखें: ये ट्रिक्स तभी काम करती हैं जब मूल सूत्र आपको आता हो। पहले concept पक्का करें, फिर ट्रिक्स से समय बचाएँ।

---

**ट्रिक 1 — मूल सूत्र एक ही है**
```
┌─────────────────────────────────────┐
│  SI = (P × R × T) / 100             │
│  P = मूलधन, R = दर (%), T = समय (वर्ष) │
│  बाकी सब सवाल इसी के उलटे रूप हैं।    │
└─────────────────────────────────────┘
```

**ट्रिक 2 — "कितने गुना" वाला सवाल**
```
┌──────────────────────────────────────────────┐
│  ब्याज = मूलधन का (R × T / 100) गुना          │
│  जैसे: 5% दर, 8 वर्ष → ब्याज = 40% of P      │
│  यानी मिश्रधन = P + 0.40P = 1.40P            │
└──────────────────────────────────────────────┘
```

**ट्रिक 3 — धन दोगुना/तिगुना कब?**
```
┌──────────────────────────────────────────────┐
│  दोगुना → ब्याज = 100% → R × T = 100         │
│  तिगुना → ब्याज = 200% → R × T = 200         │
│  चौगुना → R × T = 300 (हर बार 100 जोड़ें)     │
└──────────────────────────────────────────────┘
```

**ट्रिक 4 — दर या समय बदल जाए तो**
```
┌──────────────────────────────────────────────┐
│  SI सीधे R और T दोनों के समानुपाती है।        │
│  दर दोगुनी → ब्याज दोगुना।                   │
│  समय आधा → ब्याज आधा। कैलकुलेशन बिना उत्तर!  │
└──────────────────────────────────────────────┘
```

**ट्रिक 5 — दो दरों वाला सवाल (अंतर से मूलधन)**
```
┌──────────────────────────────────────────────┐
│  P = (ब्याजों का अंतर × 100) / (दरों का अंतर × T) │
│  जैसे: 6% और 8% पर 3 वर्ष का अंतर ₹60        │
│  P = (60 × 100) / (2 × 3) = ₹1000            │
└──────────────────────────────────────────────┘
```

**ट्रिक 6 — दो समयों वाला सवाल**
```
┌──────────────────────────────────────────────┐
│  P = (ब्याजों का अंतर × 100) / (R × समय का अंतर) │
│  दर वही हो तो समय बदलने से ब्याज का अंतर      │
│  सीधे मूलधन दे देता है।                       │
└──────────────────────────────────────────────┘
```

**ट्रिक 7 — किस्त (installment) में उधार देना**
```
┌──────────────────────────────────────────────┐
│  बराबर वार्षिक किस्त से कर्ज चुकता हो तो:      │
│  कर्ज = किस्तों का योग − कुल ब्याज             │
│  हर किस्त पर अलग-अलग समय का ब्याज लगाएँ।      │
└──────────────────────────────────────────────┘
```

**ट्रिक 8 — मासिक/त्रैमासिक समय को वर्ष में बदलें**
```
┌──────────────────────────────────────────────┐
│  महीने ÷ 12 = वर्ष | दिन ÷ 365 = वर्ष         │
│  73 दिन = 73/365 = 1/5 वर्ष (याद रखें!)       │
│  146 दिन = 2/5 वर्ष, 219 दिन = 3/5 वर्ष       │
└──────────────────────────────────────────────┘
```

**ट्रिक 9 — SI और CI का 2 वर्ष का रिश्ता**
```
┌──────────────────────────────────────────────┐
│  2 वर्ष में: CI − SI = P × (R/100)²           │
│  यानी पहले वर्ष दोनों बराबर, अंतर सिर्फ दूसरे  │
│  वर्ष के "ब्याज पर ब्याज" से आता है।          │
└──────────────────────────────────────────────┘
```

**ट्रिक 10 — प्रतिशत को भिन्न में सोचें**
```
┌──────────────────────────────────────────────┐
│  5% = 1/20 | 10% = 1/10 | 12.5% = 1/8        │
│  16⅔% = 1/6 | 25% = 1/4 | 33⅓% = 1/3         │
│  भिन्न से गुणा-भाग कैलकुलेशन आधी हो जाती है।  │
└──────────────────────────────────────────────┘
```

**ट्रिक 11 — मिश्रधन सीधे निकालें**
```
┌──────────────────────────────────────────────┐
│  A = P × (1 + RT/100)                        │
│  ब्याज अलग न निकालकर एक ही लाइन में मिश्रधन।   │
└──────────────────────────────────────────────┘
```

**ट्रिक 12 — परीक्षक के जाल से बचें**
```
┌──────────────────────────────────────────────┐
│  ✦ दर वार्षिक है या मासिक — पहले पढ़ें।        │
│  ✦ "ब्याज" पूछा है या "मिश्रधन" — अंतर = P।   │
│  ✦ समय महीनों में देकर दर वार्षिक — भूलना नहीं │
│    कि T को वर्ष में बदलना है।                  │
└──────────────────────────────────────────────┘
```

---

**याद रखने का मंत्र:** "दर गुणा समय, बटे सौ — ब्याज का खेल खत्म।" बाकी हर सवाल इसी एक सूत्र का उल्टा-सीधा रूप है।
