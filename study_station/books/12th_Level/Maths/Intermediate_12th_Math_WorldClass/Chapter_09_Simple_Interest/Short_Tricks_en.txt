# 🪄 Simple Interest — Memory Tricks & Mnemonics

---

┌─────────────────────────────────────────────┐
│ **TRICK 1 — The "PART" Formula (Acronym)**  │
├─────────────────────────────────────────────┤
│ SI = **P** × **R** × **T** / 100            │
│ Remember: **"PART of 100"**                 │
│ Principal, Rate, Time —                     │
│ all divided by 100.                         │
│ 🧠 Say it: *"Every SI question is just a    │
│ PART of 100!"*                              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 2 — The "Pirate" Triangle (Loci)**  │
├─────────────────────────────────────────────┤
│ Draw a triangle: SI on top, P·R·T at the    │
│ bottom, ÷100 underneath.                    │
│ Cover what you want:                        │
│ • Cover SI → P×R×T/100                      │
│ • Cover P → SI×100/(R×T)                    │
│ • Cover R → SI×100/(P×T)                    │
│ • Cover T → SI×100/(P×R)                    │
│ 🧠 *"The PRT pirate guards the SI treasure  │
│ — cover one, the rest reveal it!"*          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 3 — "Rate = Time" Doubling Trick**  │
├─────────────────────────────────────────────┤
│ Money DOUBLES (SI = P) when R × T = 100.    │
│ Money TRIPLES when R × T = 200.             │
│ Money becomes N times when R × T = 100(N−1).│
│ 🧠 Keyword: **"RT-100 Club"** —             │
│ to double, R×T must join the 100 club!      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 4 — The "Growing Ladder" (Loci)**   │
├─────────────────────────────────────────────┤
│ Picture money climbing a ladder:            │
│ • Step 1: P (your money)                    │
│ • Step 2: P + SI = Amount (2× = double)     │
│ • Each extra "times" = one more P of        │
│   interest.                                 │
│ 🧠 *"To become N times, you need (N−1)      │
│ salaries of interest!"*                     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 5 — "Same SI Every Year" Rule**     │
├─────────────────────────────────────────────┤
│ In Simple Interest, interest for EVERY year │
│ is identical — it never grows.              │
│ 🧠 Mnemonic: **"SI = Same Interest"**       │
│ (SI literally stands for Same Interest!)    │
│ If year 1 gives ₹500, year 10 gives ₹500.   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 6 — The "73 Days = 1/5 Year" Hack** │
├─────────────────────────────────────────────┤
│ Convert days to years: T = Days/365.        │
│ Quick anchors:                              │
│ • 73 days = 1/5 year                        │
│ • 146 days = 2/5 year                       │
│ • 219 days = 3/5 year                       │
│ 🧠 Keyword: **"73 is a fifth of 365"** —    │
│ memorize 73 and multiply!                   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 7 — The "Month = /12" Switch**      │
├─────────────────────────────────────────────┤
│ Months → Years: divide by 12.               │
│ 6 months = 1/2 yr, 8 months = 2/3 yr,       │
│ 15 months = 5/4 yr.                         │
│ 🧠 Acronym: **"MY-12"** (Months to Years,   │
│ divide by 12) — like a bike number plate!   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 8 — The "Split the Principal" Trick**│
├─────────────────────────────────────────────┤
│ When a sum is split into two parts at       │
│ different rates giving equal SI:            │
│ Parts are in ratio **1/R₁T₁ : 1/R₂T₂**      │
│ 🧠 *"Equal interest? Flip the rate-time     │
│ products upside down!"* (Inverse ratio)     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 9 — The "Rate from Amount" Ladder** │
├─────────────────────────────────────────────┤
│ If ₹P becomes ₹A in T years:                │
│ SI = A − P, then R = (A−P)×100/(P×T).       │
│ 🧠 Story: *"Find what you EARNED (A−P),     │
│ then ask: what percent of P per year?"*     │
│ Keyword: **"Earn first, Rate later."**      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 10 — The "1% Per Year" Anchor**     │
├─────────────────────────────────────────────┤
│ At R% per annum, in T years you earn        │
│ (R×T)% of P as interest.                    │
│ Example: 5% for 4 years = 20% of P = P/5.   │
│ 🧠 *"Multiply R and T — that's your total   │
│ percentage. No formula needed!"*            │
│ Keyword: **"RT = Total %"**                 │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 11 — The "SI vs CI Gap" Trick**     │
├─────────────────────────────────────────────┤
│ For 2 years, CI − SI = P(R/100)²            │
│ (interest on first year's interest).        │
│ 🧠 Mnemonic: **"The gap is the square of    │
│ the rate's shadow."**                       │
│ For 2 years ONLY — memorize P(R/100)²!      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 12 — The "Fraction Rate" Decoder**  │
├─────────────────────────────────────────────┤
│ Convert % to fractions for fast math:       │
│ • 5% = 1/20   • 4% = 1/25                   │
│ • 8% = 2/25   • 12% = 3/25                  │
│ • 6⅔% = 1/15  • 3⅓% = 1/30                  │
│ 🧠 Acronym: **"FRACTION = FAST ACTION"**    │
│ Divide P by the denominator — done!         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 13 — The "Time-Travel Check"**      │
├─────────────────────────────────────────────┤
│ Sanity check every answer:                  │
│ • SI must be LESS than P for small R×T.     │
│ • Amount = P + SI, always bigger than P.    │
│ • If your SI > Amount, you made an error!   │
│ 🧠 *"Interest is the baby, Principal is     │
│ the parent — baby can't outweigh parent    │
│ unless R×T > 100!"*                         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 14 — The "Two Rates, Two Times"     │
│ Grid (Loci)**                               │
├─────────────────────────────────────────────┤
│ For "SI at R₁ for T₁ = SI at R₂ for T₂":    │
│ Just use **R₁T₁ = R₂T₂**.                   │
│ 🧠 Picture a balance scale: rate×time on    │
│ both pans must balance!                     │
│ Keyword: **"Balance the RT scales."**       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 15 — The Master Story (Loci)**      │
├─────────────────────────────────────────────┤
│ Imagine lending ₹100 to a friend:           │
│ • ₹100 = Principal (your wallet)            │
│ • Rate = his promise per year               │
│ • Time = how long he keeps it               │
│ • SI = the "thank you" money                │
│ • Amount = wallet + thank you               │
│ 🧠 *"Every SI problem is just you, a        │
│ friend, and a thank-you note!"*             │
└─────────────────────────────────────────────┘
