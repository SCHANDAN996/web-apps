🪄 प्रायिकता — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

┌─────────────────────────────────────────┐
│ ट्रिक 1: "ऊपर चाहिए, नीचे सब"          │
│ P(E) = अनुकूल परिणाम / कुल परिणाम        │
│ याद रखो: ऊपर वही रखो जो "चाहिए",        │
│ नीचे "सब" कुछ रखो।                       │
│ जैसे ऑर्डर देना: "मुझे चाहिए 2 समोसे,    │
│ कुल थाली में 10" → 2/10                  │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 2: "0 से 1 की सैर"                 │
│ 0 ≤ P(E) ≤ 1                             │
│ प्रायिकता एक सीढ़ी है — नीचे 0           │
│ (असंभव), ऊपर 1 (निश्चित)। इसके बाहर     │
│ कोई उत्तर आए तो समझो कैलकुलेशन गलत!     │
│ परीक्षा में विकल्प 1.2 या −0.3 दिखे तो  │
│ बिना सोचे काट दो।                        │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 3: "पत्नी-पति = 1"                 │
│ P(E) + P(E′) = 1                         │
│ घटना और उसकी "पूरक" (complement) मिलकर  │
│ पूरा परिवार = 1।                          │
│ उपयोग: "कम-से-कम एक" आए तो उल्टा करो —  │
│ 1 − P(एक भी नहीं)।                       │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 4: "कम-से-कम = उल्टा खेल"          │
│ "कम से कम एक" देखते ही घंटी बजाओ 🔔      │
│ सीधे निकालोगे तो केस बहुत; उल्टा करो:    │
│ P(कम से कम एक) = 1 − P(कोई नहीं)         │
│ एक्रोनिम: "कम → कंप्लीमेंट"               │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 5: "या = जोड़, और = गुणा"          │
│ OR (या) → जोड़ना (+)                     │
│ AND (और) → गुणा (×)                      │
│ याद रखो: "या-या करता बच्चा जोड़-जोड़      │
│ खाता है, और-और करता बच्चा गुणा करता है।"│
│ (स्वतंत्र घटनाओं में AND = गुणा)          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 6: "परस्पर अपवर्जी = तेल-पानी"     │
│ Mutually Exclusive: दो घटनाएँ साथ नहीं    │
│ हो सकतीं — जैसे तेल और पानी कभी नहीं     │
│ मिलते। P(A∩B) = 0                        │
│ तो P(A∪B) = P(A) + P(B) — सीधा जोड़!    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 7: "जोड़ का पूरा सूत्र — दो जोड़ो, │
│ एक घटाओ"                                  │
│ P(A∪B) = P(A) + P(B) − P(A∩B)            │
│ तर्क: दोनों को जोड़ा तो बीच का हिस्सा     │
│ दो बार गिना गया — एक बार घटाना पड़ेगा।   │
│ जैसे दो हाथ मिलाओ तो उँगलियाँ दो बार नहीं │
│ गिनते!                                    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 8: "ताश के 52 यार"                 │
│ 52 पत्ते = 4 सूट × 13 पत्ते               │
│ लाल 26 (♥ पान + ♦ ईंट), काले 26          │
│ (♠ हुकुम + ♣ चिड़िया)                     │
│ फेस कार्ड 12 (राजा, रानी, गुलाम × 4)      │
│ इक्का 4। याद रखो: "52 हफ्ते, 4 मौसम" —   │
│ ताश ही कैलेंडर है!                        │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 9: "पासे का जादू — 6 और 36"        │
│ 1 पासा → 6 परिणाम                        │
│ 2 पासे → 36 परिणाम (6×6)                 │
│ योग 7 की प्रायिकता सबसे ज़्यादा = 6/36    │
│ याद रखो: "सात सिंदूर — सबसे लोकप्रिय     │
│ योग 7" (6 तरीके: 1-6, 2-5, 3-4, 4-3,     │
│ 5-2, 6-1)                                 │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 10: "सिक्का उछालो, 2 की घात"       │
│ n सिक्के → कुल परिणाम = 2ⁿ               │
│ 1 सिक्का = 2, 2 सिक्के = 4, 3 सिक्के = 8 │
│ याद रखो: "हर सिक्का दोगुना खेल"           │
│ पासों में: n पासे → 6ⁿ                    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 11: "बिना लौटाए = घटता बर्तन"      │
│ Without replacement: हर बार बर्तन से एक   │
│ चीज़ कम!                                   │
│ 5 गेंदों में से 2 निकालना (बिना लौटाए):   │
│ पहली बार /5, दूसरी बार /4                 │
│ याद रखो: "मिठाई खा ली तो डिब्बे से कम    │
│ हुई — वापस नहीं आएगी!"                    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 12: "सशर्त प्रायिकता = B का घर"    │
│ P(A|B) = P(A∩B) / P(B)                   │
│ मतलब: "B हो चुका है" — अब तुम B की       │
│ दुनिया में खड़े हो, उसी में A का हिस्सा   │
│ देखो। याद रखो: "नई दुनिया B, उसमें A     │
│ का हिस्सा" — हर हमेशा B!                  │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 13: "स्वतंत्र = अपने रास्ते"       │
│ स्वतंत्र घटनाएँ: P(A∩B) = P(A)×P(B)      │
│ एक दूसरे को प्रभावित नहीं करतीं — जैसे    │
│ दिल्ली में बारिश और मुंबई में सिक्का      │
│ उछालना। जाँच: गुणा करके बराबर आए तो       │
│ स्वतंत्र, वरना नहीं।                      │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 14: "लीप ईयर में 53 रविवार"        │
│ लीप वर्ष = 366 दिन = 52 सप्ताह + 2 दिन    │
│ 53वें रविवार के लिए अनुकूल जोड़े:         │
│ (शनि-रवि), (रवि-सोम) → 2/7               │
│ साधारण वर्ष: +1 दिन → 1/7                │
│ याद रखो: "लीप में दो मौके, साधारण में    │
│ एक"                                       │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 15: "जन्मदिन ट्रिक — उल्टा ही सहारा"│
│ "कम से कम दो लोगों का जन्मदिन एक साथ"    │
│ → 1 − P(सबके अलग-अलग)                     │
│ n लोग: 1 − (365×364×…)/(365ⁿ)            │
│ फिर से वही नियम: "कम-से-कम दिखे,          │
│ कंप्लीमेंट लगाओ!"                          │
└─────────────────────────────────────────┘
