# महत्वपूर्ण सूत्र: समय और कार्य

| सूत्र का नाम | सूत्र | अनुप्रयोग एवं संदर्भ |
| :--- | :--- | :--- |
| व्युत्क्रम कार्य नियम | 1 दिन का कार्य = 1 / D | आधारभूत दर सूत्र |
| दो व्यक्तियों का संयुक्त समय | T = (x * y) / (x + y) | 2 व्यक्तियों का संयुक्त कार्य |
| तीन व्यक्तियों का संयुक्त समय | T = (xyz) / (xy + yz + zx) | 3 व्यक्तियों का संयुक्त कार्य |
| कार्यक्षमता अनुपात नियम | E_A : E_B = T_B : T_A | समय और क्षमता का व्युत्क्रम |
| समाप्ति से d दिन पूर्व छोड़ना | T = (कुल कार्य + d * E_जाने वाला) / E_सभी | त्वरित समाधान हैक |
| सर्वमान्य MDH चेन नियम | (M1 * D1 * H1) / W1 = (M2 * D2 * H2) / W2 | बहु-चर समूह कार्य |
| पुरुष-महिला रूपांतरण | m * M = w * W => 1 M = (w/m) W | विषम समूहों की समतुल्यता |
| मजदूरी वितरण नियम | मजदूरी अनुपात = (E_A * t_A) : (E_B * t_B) | किए गए कार्य अनुसार भुगतान |
| कुल कार्य सूत्र | कुल कार्य = कार्यक्षमता * समय | ल.स.प. इकाई विधि |
| अतिरिक्त दिन सूत्र | यदि A को (T+a) और B को (T+b) दिन लगें => T = sqrt(a*b) | त्वरित वर्गमूल हैक |
