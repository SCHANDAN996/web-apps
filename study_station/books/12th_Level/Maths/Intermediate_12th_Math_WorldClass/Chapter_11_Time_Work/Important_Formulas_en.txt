# Important Formulas: Time & Work

| Formula Name | Formula | Application & Context |
| :--- | :--- | :--- |
| Reciprocal Work Rule | 1 Day Work = 1 / D | Base rate formulation |
| Two Persons Joint Work | T = (x * y) / (x + y) | Fast 2-person combination |
| Three Persons Joint Work | T = (xyz) / (xy + yz + zx) | Direct 3-person formula |
| Efficiency Ratio Rule | E_A : E_B = T_B : T_A | Inverse time proportionality |
| Leaving 'd' Days Before End | T = (Total Work + d * E_leaving) / E_all | Magic pre-departure hack |
| Universal Chain Rule | (M1 * D1 * H1) / W1 = (M2 * D2 * H2) / W2 | Multi-variable group work |
| Men-Women Conversion | m * M = w * W => 1 M = (w/m) W | Heterogeneous work equivalence |
| Wage Distribution | Wage_A : Wage_B = (E_A * t_A) : (E_B * t_B) | Remuneration according to work |
| Work Done with Efficiency | Total Work = Efficiency * Time | Unit calculation in LCM method |
| Extra Days Formula | If A takes (T+a) & B takes (T+b) => T = sqrt(a * b) | Symmetrical excess days hack |
