🪄 समय और कार्य — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

┌─────────────────────────────────────────┐
│ ट्रिक 1: "LCM = कुल काम की थाली" 🍽️      │
│                                         │
│ A अकेला 10 दिन, B अकेला 15 दिन में काम  │
│ करे, तो कुल काम = LCM(10,15) = 30 रोटियाँ│
│ मान लो। A रोज़ 3 रोटी, B रोज़ 2 रोटी    │
│ बनाता है। साथ में = 5 रोटी/दिन →        │
│ 30 ÷ 5 = 6 दिन।                         │
│ 💡 याद रखो: "थाली में LCM, बाँटो रोज़     │
│ की क्षमता से!"                          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 2: "उल्टा नियम" 🔄                 │
│                                         │
│ दिन ↔ क्षमता हमेशा उल्टे (reciprocal)   │
│ होते हैं। A को 12 दिन → क्षमता 1/12।    │
│ 💡 मंत्र: "जितने दिन, उतना ही भाग —     │
│ दिन बड़ा तो काम छोटा!"                  │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 3: "MDH मसाला" 🌶️                  │
│                                         │
│ M₁D₁H₁ = M₂D₂H₂                         │
│ (Men × Days × Hours)                    │
│ 💡 याद रखो: "आदमी-दिन-घंटे का मसाला     │
│ दोनों तरफ बराबर!" काम वही तो MDH वही।   │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 4: "आदमी बढ़े, दिन घटे" ⚖️         │
│                                         │
│ आदमी × दिन = स्थिर। आदमी दोगुने →       │
│ दिन आधे।                                │
│ 💡 कीवर्ड: "सी-सॉ (Seesaw)" — एक तरफ    │
│ ऊपर तो दूसरी नीचे!                      │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 5: "छोड़कर जाने वाला ट्रिक" 🚪     │
│                                         │
│ A और B मिलकर काम कर रहे हैं, A बीच में   │
│ छोड़ दे → पहले दोनों का साथ वाला काम    │
│ निकालो, फिर बचा काम अकेले B से।         │
│ 💡 मंत्र: "जो गया उसे भूलो, जो बचा      │
│ उससे पूरा करो!"                         │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 6: "बारी-बारी = जोड़ी-जोड़ी" 👯    │
│                                         │
│ A और B एक-एक दिन बारी-बारी काम करें,    │
│ तो 2 दिन का काम एक "जोड़ी" में गिनो।    │
│ कुल काम ÷ जोड़ी का काम = कितनी जोड़ियाँ।│
│ 💡 याद रखो: "डांस में जोड़ी, काम में     │
│ जोड़ी — 2 दिन = 1 टर्न!"                │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 7: "नकारात्मक नल" 🚰❌              │
│                                         │
│ भरने वाला नल +, खाली करने वाला नल −।    │
│ शुद्ध दर = भरने की दर − खाली की दर।     │
│ 💡 मंत्र: "चोर नल माइनस, मेहनती नल      │
│ प्लस!"                                  │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 8: "टंकी = काम ही" 🛢️              │
│                                         │
│ पाइप-टंकी के सवाल Time & Work जैसे ही   │
│ हैं — भरना = काम करना, खाली करना =      │
│ काम बिगाड़ना।                            │
│ 💡 कीवर्ड: "टंकी भी मज़दूर है — बस एक    │
│ उल्टा मज़दूर!"                          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 9: "क्षमता अनुपात = दिन का उल्टा" │
│ 🔃                                      │
│                                         │
│ A:B की क्षमता 3:2 है → दिनों का अनुपात  │
│ 2:3 होगा।                               │
│ 💡 मंत्र: "ताकत पलटी, तो समय पलटा!"     │
│ (लोकस विधि: ताकत और समय को आईने के      │
│ सामने खड़ा करो — उल्टे दिखते हैं!)      │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 10: "x दिन पहले छोड़ा" ⏰          │
│                                         │
│ A काम खत्म होने से x दिन पहले छोड़ दे,  │
│ तो A के हिस्से का बचा काम = B ने आखिरी  │
│ x दिनों में अकेले किया।                 │
│ 💡 मंत्र: "जितने दिन पहले भागा, उतने    │
│ दिन अंत में अकेला!"                     │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 11: "मज़दूरी = काम का हिस्सा" 💰   │
│                                         │
│ मज़दूरी हमेशा किए गए काम (क्षमता × दिन)  │
│ के अनुपात में बँटती है, दिनों के अनुपात │
│ में नहीं!                               │
│ 💡 मंत्र: "जितना काम, उतनी कमाई —       │
│ दिन नहीं, काम देखो!"                    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 12: "एक्रोनिम: क-द-क" 🔤           │
│                                         │
│ क्षमता × दिन = कुल काम                  │
│ (Efficiency × Days = Total Work)        │
│ 💡 याद रखो: "क-द-क" — क्षमता, दिन,      │
│ काम! तीनों में से कोई दो पता हों तो     │
│ तीसरा खुद निकल आएगा।                    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 13: "दोगुनी क्षमता = आधा समय" ⚡   │
│                                         │
│ B, A से दोगुना तेज़ है → B को आधा समय   │
│ लगेगा। तीन गुना तेज़ → एक-तिहाई समय।    │
│ 💡 मंत्र: "रफ्तार जितनी, समय उतना       │
│ उल्टा!"                                 │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 14: "1 दिन का काम जोड़ो" ➕        │
│                                         │
│ साथ काम करने पर: 1 दिन का कुल काम =     │
│ 1/a + 1/b। फिर उल्टा करो → कुल दिन।     │
│ 💡 मंत्र: "पहले जोड़ो, फिर पलटो!"       │
│ (जोड़ो = दरें जोड़ो, पलटो = दिन निकालो) │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 15: "परीक्षा हॉल की 30-सेकंड      │
│ चेकलिस्ट" ✅                            │
│                                         │
│ ① कुल काम = LCM मानो                    │
│ ② हर मज़दूर की 1-दिन क्षमता लिखो        │
│ ③ जोड़ो/घटाओ (चोर नल घटेगा!)            │
│ ④ कुल काम ÷ शुद्ध क्षमता = दिन          │
│ 💡 एक्रोनिम: "क-क्ष-जो-भा" — कुल,       │
│ क्षमता, जोड़, भाग!                      │
└─────────────────────────────────────────┘
