26. In how many different ways can the letters of the word "LEADER" be arranged?
(a) 720 (b) 360 (c) 120 (d) 240
Answer: (b)
Solution: The tempting answer 720 comes from 6! without noticing the repetition. The word LEADER has 6 letters with E repeated twice, so arrangements = 6!/2! = 720/2 = 360, so the answer is 360.

27. How many 4-digit numbers can be formed using the digits 1, 2, 3, 4, 5 if no digit is repeated?
(a) 60 (b) 625 (c) 24 (d) 120
Answer: (d)
Solution: Choosing 4! = 24 is the trap — that only arranges 4 fixed digits and ignores the choice of which 4 digits to use. Number of ways = ⁵P₄ = 5 × 4 × 3 × 2 = 120, so the answer is 120.

28. In how many ways can 5 boys and 3 girls be seated in a row so that all the girls sit together?
(a) 720 (b) 40320 (c) 1440 (d) 4320
Answer: (d)
Solution: Treating all 8 people as distinct gives 40320, which ignores the "girls together" condition. Tie the 3 girls into one block: 6 units arrange in 6! = 720 ways, and girls arrange within the block in 3! = 6 ways, giving 720 × 6 = 4320, so the answer is 4320.

29. A committee of 4 is to be formed from 6 men and 4 women such that it contains at least one woman. In how many ways can this be done?
(a) 210 (b) 180 (c) 195 (d) 200
Answer: (c)
Solution: The trap is computing ⁴C₁ × ⁹C₃ = 336, which double-counts committees with more than one woman. Use complement: total committees ¹⁰C₄ = 210 minus all-men committees ⁶C₄ = 15, giving 210 − 15 = 195, so the answer is 195.

Answer: (d)
Solution: The trap is 7! = 5040, which counts rotations of the same arrangement as different. In circular permutations, fix one person and arrange the rest: (7 − 1)! = 6! = 720, so the answer is 720.

36. If ⁿP₂ = 30, find the value of n.
(a) 5 (b) 7 (c) 6 (d) 8
Answer: (c)
Solution: Guessing n = 5 gives ⁵P₂ = 20, which is too small. Solve n(n − 1) = 30, so n² − n − 30 = 0, giving (n − 6)(n + 5) = 0, hence n = 6, so the answer is 6.

Answer: (c)
Solution: The trap is answering 240, which is only the "together" count, not the "never together" count. Total arrangements = 6! = 720; together = 2 × 5! = 240; never together = 720 − 240 = 480, so the answer is 480.

50. A question paper has two sections of 5 questions each. A student must attempt 6 questions, choosing at least 2 from each section. In how many ways can this be done?
(a) 200 (b) 400 (c) 300 (d) 250
Answer: (a)
Solution: The trap is ¹⁰C₆ = 210, which ignores the minimum-2-per-section rule. Valid splits are (2,4), (3,3), (4,2): ⁵C₂×⁵C₄ + ⁵C₃×⁵C₃ + ⁵C₄×⁵C₂ = 50 + 100 + 50 = 200, so the answer is 200.
