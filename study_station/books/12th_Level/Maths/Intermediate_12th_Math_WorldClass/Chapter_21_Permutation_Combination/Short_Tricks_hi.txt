# 🪄 क्रमचय और संचय — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 1: "क्रम में क्रम, संचय में चयन"** │
│                                             │
│ क्रमचय (Permutation) → **क्रम** मायने रखता है │
│ संचय (Combination) → सिर्फ़ **चयन**, क्रम नहीं │
│                                             │
│ 🧠 याद रखो: **"P = Position, C = Chuno-bas"** │
│ Position बदली तो P, सिर्फ़ चुना तो C।        │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 2: ताला-चाबी वाली कहानी** 🔑        │
│                                             │
│ ताले का कोड 123 और 321 अलग-अलग हैं →       │
│ क्रम मायने रखता है → **Permutation**        │
│                                             │
│ सब्ज़ी की टोकरी में आलू-प्याज़ किसी भी      │
│ क्रम में रखो, वही टोकरी → **Combination**   │
│                                             │
│ 🧠 "ताला = P, टोकरी = C"                    │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 3: "C में काट-छाँट"** ✂️            │
│                                             │
│ ⁿCᵣ = ⁿPᵣ / r!                              │
│                                             │
│ Combination में r! से **काट-छाँट** होती है,  │
│ क्योंकि क्रम के नकली नकल (duplicates)        │
│ काट दिए जाते हैं।                           │
│                                             │
│ 🧠 "C = काटो, P = पूरा"                     │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 4: गुणन नियम = "और", योग नियम = "या"** │
│                                             │
│ काम A **और** काम B दोनों करने हैं → **गुणा** │
│ काम A **या** काम B (कोई एक) → **जोड़**      │
│                                             │
│ 🧠 "और-गुणा, या-जोड़"                        │
│ (AND → ×, OR → +)                           │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 5: "दर्पण जुड़वाँ" — ⁿCᵣ = ⁿCₙ₋ᵣ** 🪞 │
│                                             │
│ 10 में से 3 चुनना = 10 में से 7 **छोड़ना**   │
│ दर्पण में देखो — चुनना और छोड़ना एक ही बात! │
│                                             │
│ 🧠 बड़ा r आए तो उसे n−r बनाकर छोटा कर लो।   │
│ जैसे ¹⁰C₈ = ¹⁰C₂ = 45                       │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 6: गोल घूमो, एक को बैठाओ** ⭕       │
│                                             │
│ गोल मेज़ पर n लोग → (n−1)! व्यवस्थाएँ       │
│                                             │
│ क्यों? एक व्यक्ति को **ज़बरदस्ती बैठा दो**  │
│ (घूर्णन से बचने के लिए), बाकी n−1 को        │
│ सजाओ → (n−1)!                               │
│                                             │
│ 🧠 "गोल = एक कम का factorial"               │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 7: माला में आधा** 📿                │
│                                             │
│ माला/हार (necklace) में n मोतियों की        │
│ व्यवस्था = (n−1)! / 2                       │
│                                             │
│ क्योंकि माला **पलट** सकती है — घड़ी की      │
│ दिशा और उल्टी दिशा एक ही दिखती हैं,         │
│ इसलिए आधा कर दो।                            │
│                                             │
│ 🧠 "माला पलटी, आधा कटी"                     │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 8: "साथ रहो = गठरी बांधो"** 🎁      │
│                                             │
│ "A और B हमेशा साथ बैठें" → दोनों को एक      │
│ **गठरी** (bundle) बांध दो → (n−1) वस्तुएँ   │
│ फिर गठरी के अंदर 2! से गुणा।                │
│                                             │
│ 🧠 "साथ = बांधो, अंदर गुणा करो"             │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 9: "कभी साथ नहीं = खाली जगह घुसाओ"** │
│                                             │
│ "A और B कभी साथ न बैठें" → पहले बाकी लोगों │
│ को बैठाओ, फिर बनी **खाली जगहों (gaps)** में │
│ A और B को घुसाओ।                            │
│                                             │
│ n लोग बैठे → n+1 खाली जगहें।                │
│                                             │
│ 🧠 "दुश्मनी है तो दूरी = Gap Method"        │
└─────────────────────────────────────────────┘

---

┌──────────────────────────────────────────────┐
│ **ट्रिक 10: "कुल माइनस बुरा"** ➖            │
│                                              │
│ "कम से कम एक…" वाले प्रश्नों में:            │
│ उत्तर = कुल व्यवस्थाएँ − बुरी व्यवस्थाएँ     │
│                                              │
│ जैसे "कम से कम एक स्वर" = कुल − (कोई स्वर   │
│ नहीं)                                        │
│                                              │
│ 🧠 "कम से कम = कुल से घटा"                   │
└──────────────────────────────────────────────┘

---

┌──────────────────────────────────────────────┐
│ **ट्रिक 11: "समान चीज़ = भाग दे दो"** ➗     │
│                                              │
│ n वस्तुएँ, जिनमें p एक जैसी, q एक जैसी →    │
│ कुल व्यवस्थाएँ = n! / (p! × q!)              │
│                                              │
│ जैसे ALLAHABAD में A चार बार, L दो बार →    │
│ 9! / (4! × 2!)                               │
│                                              │
│ 🧠 "जुड़वाँ दिखे, factorial से काटो"         │
└──────────────────────────────────────────────┘

---

┌──────────────────────────────────────────────┐
│ **ट्रिक 12: "0 और 1 का जादू"** ✨            │
│                                              │
│ ⁿC₀ = ⁿCₙ = 1  (कुछ न चुनो या सब चुनो —     │
│ एक ही तरीका)                                 │
│ ⁿC₁ = n        (एक चुनने के n तरीके)         │
│ 0! = 1         (खाली भी एक व्यवस्था है!)    │
│                                              │
│ 🧠 "खाली हाथ भी एक स्टाइल है — 0! = 1"      │
└──────────────────────────────────────────────┘

---

┌──────────────────────────────────────────────┐
│ **ट्रिक 13: "पास्कल की सीढ़ी"** 🪜           │
│                                              │
│ ⁿCᵣ₋₁ + ⁿCᵣ = ⁿ⁺¹Cᵣ                          │
│                                              │
│ नीचे की सीढ़ी के दो पड़ोसी जुड़कर ऊपर की     │
│ सीढ़ी बनाते हैं।                             │
│                                              │
│ 🧠 "दो पड़ोसी मिले, ऊपर वाला बना"            │
└──────────────────────────────────────────────┘

---

┌──────────────────────────────────────────────┐
│ **ट्रिक 14: "रैंकिंग = P, चुनाव = C"** 🏆    │
│                                              │
│ प्रश्न में ये शब्द दिखें तो तुरंत पहचानो:    │
│ • व्यवस्था, क्रम, रैंक, पद (अध्यक्ष/सचिव    │
│   अलग-अलग), संख्या बनाना → **P**            │
│ • समिति, टीम, चयन, समूह, चुनाव → **C**      │
│                                              │
│ 🧠 "पद-पद P, पार्टी-पार्टी C"                │
└──────────────────────────────────────────────┘

---

┌──────────────────────────────────────────────┐
│ **ट्रिक 15: "अंक बनाना? पहले स्थान की मर्यादा"** │
│                                              │
│ अंकों से संख्या बनाने के प्रश्नों में:       │
│ 1. पहले **सबसे बाएँ स्थान** भरो (वहाँ 0     │
│    नहीं आ सकता)                              │
│ 2. फिर बाकी स्थान                            │
│ 3. "सम संख्या" कहा तो **इकाई स्थान पहले**   │
│    भरो (0, 2, 4, 6, 8 से)                    │
│                                              │
│ 🧠 "पाबंदी वाला स्थान पहले, बाकी बाद में"    │
└──────────────────────────────────────────────┘
