Questions 1–25: Easy

1. If x : y = 3 : 4 and y : z = 8 : 9, find the ratio x : z.
(a) 2 : 3 (b) 3 : 4 (c) 1 : 2 (d) 3 : 2
Answer: (a) 2 : 3
Solution: Ratio x / z = (x / y) * (y / z) = (3 / 4) * (8 / 9) = 24 / 36 = 2 / 3. The required value is 2 : 3. Hence, the correct option is (a).
Source: SSC CGL Pattern

2. Find the duplicate ratio of 4 : 5.
(a) 2 : sqrt(5) (b) 16 : 25 (c) 64 : 125 (d) 8 : 10
Answer: (b) 16 : 25
Solution: The duplicate ratio of a : b is defined as a^2 : b^2. Here 4^2 : 5^2 = 16 : 25. The required value is 16 : 25. Hence, the correct option is (b).
Source: SSC CGL Pattern

3. Find the sub-duplicate ratio of 81 : 121.
(a) 81 : 121 (b) 3 : sqrt(11) (c) 9 : 11 (d) 27 : 11
Answer: (c) 9 : 11
Solution: The sub-duplicate ratio of a : b is defined as sqrt(a) : sqrt(b). Here sqrt(81) : sqrt(121) = 9 : 11. The required value is 9 : 11. Hence, the correct option is (c).
Source: SSC CGL Pattern

4. Find the triplicate ratio of 2 : 3.
(a) 4 : 9 (b) 6 : 9 (c) 16 : 81 (d) 8 : 27
Answer: (d) 8 : 27
Solution: The triplicate ratio of a : b is defined as a^3 : b^3. Here 2^3 : 3^3 = 8 : 27. The required value is 8 : 27. Hence, the correct option is (d).
Source: SSC CGL Pattern

5. Find the sub-triplicate ratio of 64 : 343.
(a) 4 : 7 (b) 8 : 19 (c) 16 : 49 (d) 2 : 3
Answer: (a) 4 : 7
Solution: The sub-triplicate ratio is the cube root ratio: 64^(1/3) : 343^(1/3) = 4 : 7. The required value is 4 : 7. Hence, the correct option is (a).
Source: SSC CGL Pattern

6. Find the inverse ratio of 5 : 8.
(a) 5 : 8 (b) 8 : 5 (c) 25 : 64 (d) 10 : 16
Answer: (b) 8 : 5
Solution: The inverse ratio of a : b is (1/a) : (1/b) = b : a. Hence, the inverse of 5 : 8 is 8 : 5. The required value is 8 : 5. Hence, the correct option is (b).
Source: SSC CGL Pattern

7. Find the compound ratio of 2 : 3, 6 : 7, and 14 : 15.
(a) 4 : 15 (b) 6 : 15 (c) 8 : 15 (d) 12 : 35
Answer: (c) 8 : 15
Solution: Compound ratio = (2 * 6 * 14) / (3 * 7 * 15) = (168) / (315) = 8 / 15. The required value is 8 : 15. Hence, the correct option is (c).
Source: SSC CGL Pattern

8. If u : v = 2 : 3 and v : w = 4 : 5, find the combined ratio u : v : w.
(a) 6 : 12 : 15 (b) 8 : 10 : 15 (c) 4 : 6 : 15 (d) 8 : 12 : 15
Answer: (d) 8 : 12 : 15
Solution: Multiplying the first ratio by 4 and the second by 3 equalizes the common term v: u : v : w = (2 * 4) : (3 * 4) : (5 * 3) = 8 : 12 : 15. The required value is 8 : 12 : 15. Hence, the correct option is (d).
Source: SSC CGL Pattern

9. An amount of Rs 750 is distributed among p, q, and r in the ratio 2 : 3 : 5. Find the share of q.
(a) Rs 225 (b) Rs 150 (c) Rs 375 (d) Rs 250
Answer: (a) Rs 225
Solution: Sum of ratio terms = 2 + 3 + 5 = 10 parts. 10 parts = 750 => 1 part = 75. Share of q = 3 * 75 = Rs 225. The required value is Rs 225. Hence, the correct option is (a).
Source: SSC CGL Pattern

10. If 2a = 3b = 4c, find the ratio a : b : c.
(a) 2 : 3 : 4 (b) 6 : 4 : 3 (c) 4 : 3 : 2 (d) 3 : 4 : 6
Answer: (b) 6 : 4 : 3
Solution: Let 2a = 3b = 4c = 12k (where 12 is LCM of 2, 3, 4). Then a = 6k, b = 4k, c = 3k. Hence, a : b : c = 6 : 4 : 3. The required value is 6 : 4 : 3. Hence, the correct option is (b).
Source: SSC CGL Pattern

11. If a / 3 = b / 4 = c / 7, find the value of (a + b + c) / c.
(a) 3 (b) 7 (c) 2 (d) 1/2
Answer: (c) 2
Solution: Let a / 3 = b / 4 = c / 7 = k. Then a = 3k, b = 4k, c = 7k. Thus, (a + b + c) / c = (3k + 4k + 7k) / (7k) = 14k / 7k = 2. The required value is 2. Hence, the correct option is (c).
Source: SSC CGL Pattern

12. If x : y = 5 : 2, find the value of (8x + 9y) : (8x + 2y).
(a) 27 : 22 (b) 29 : 24 (c) 25 : 22 (d) 29 : 22
Answer: (d) 29 : 22
Solution: Substituting x = 5 and y = 2: (8 * 5 + 9 * 2) / (8 * 5 + 2 * 2) = (40 + 18) / (40 + 4) = 58 / 44 = 29 / 22. The required value is 29 : 22. Hence, the correct option is (d).
Source: SSC CGL Pattern

13. Two numbers are in the ratio 3 : 5. If 9 is subtracted from each, the new ratio becomes 12 : 23. Find the smaller number.
(a) 33 (b) 30 (c) 36 (d) 27
Answer: (a) 33
Solution: Let numbers be 3x and 5x. (3x - 9) / (5x - 9) = 12 / 23. Cross-multiplying: 23(3x - 9) = 12(5x - 9) => 69x - 207 = 60x - 108 => 9x = 99 => x = 11. Smaller number = 3x = 3 * 11 = 33. The required value is 33. Hence, the correct option is (a).
Source: SSC CGL Pattern

14. Find the fourth proportional to 4, 9, and 12.
(a) 24 (b) 27 (c) 28 (d) 30
Answer: (b) 27
Solution: If 4 : 9 :: 12 : x, then product of extremes equals product of means: 4 * x = 9 * 12 => 4x = 108 => x = 27. The required value is 27. Hence, the correct option is (b).
Source: SSC CGL Pattern

15. Find the third proportional to 9 and 12.
(a) 15 (b) 18 (c) 16 (d) 14
Answer: (c) 16
Solution: Third proportional x = b^2 / a = 12^2 / 9 = 144 / 9 = 16. The required value is 16. Hence, the correct option is (c).

16. Find the mean proportional between 4 and 16.
(a) 10 (b) 6 (c) 12 (d) 8
Answer: (d) 8
Solution: Mean proportional x = sqrt(a * b) = sqrt(4 * 16) = sqrt(64) = 8. The required value is 8. Hence, the correct option is (d).
Source: SSC CGL Pattern

17. The ratio of boys to girls in a school is 4 : 3. If there are 480 boys, what is the total number of students in the school?
(a) 840 (b) 800 (c) 860 (d) 720
Answer: (a) 840
Solution: Boys = 4 parts = 480 => 1 part = 120. Total students = 4 + 3 = 7 parts = 7 * 120 = 840. The required value is 840. Hence, the correct option is (a).
Source: SSC CGL Pattern

18. Divide Rs 1,170 among A, B, and C in the ratio 2 : 3 : 4. Find the share of C.
(a) Rs 480 (b) Rs 520 (c) Rs 500 (d) Rs 540
Answer: (b) Rs 520
Solution: Total parts = 2 + 3 + 4 = 9 parts. 9 parts = 1,170 => 1 part = 130. Share of C = 4 * 130 = Rs 520. The required value is Rs 520. Hence, the correct option is (b).
Source: SSC CGL Pattern

19. If a : b = 5 : 7 and c : d = 2a : 3b, find the ratio ac : bd.
(a) 25 : 49 (b) 10 : 21 (c) 50 : 147 (d) 20 : 63
Answer: (c) 50 : 147
Solution: Given c / d = (2/3) * (a / b) = (2/3) * (5/7) = 10 / 21. Then (ac) / (bd) = (a / b) * (c / d) = (5 / 7) * (10 / 21) = 50 / 147. The required value is 50 : 147. Hence, the correct option is (c).
Source: SSC CGL Pattern

20. What must be added to each term of the ratio 7 : 11 so as to make it equal to 3 : 4?
(a) 4 (b) 6 (c) 3 (d) 5
Answer: (d) 5
Solution: Equation: (7 + x) / (11 + x) = 3 / 4 => 4(7 + x) = 3(11 + x) => 28 + 4x = 33 + 3x => x = 5. The required value is 5. Hence, the correct option is (d).
Source: SSC CGL Pattern

21. What quantity must be subtracted from each term of the ratio 17 : 24 so that it becomes equal to 1 : 2?
(a) 10 (b) 8 (c) 12 (d) 9
Answer: (a) 10
Solution: (17 - x) / (24 - x) = 1 / 2 => 2(17 - x) = 24 - x => 34 - 2x = 24 - x => x = 10. The required value is 10. Hence, the correct option is (a).
Source: SSC CGL Pattern

22. Find the fourth proportional to 0.12, 0.21, and 8.

Answer: (b) 14
Solution: Fourth proportional x = (b * c) / a = (0.21 * 8) / 0.12 = 1.68 / 0.12 = 14. The required value is 14. Hence, the correct option is (b).

23. If x : y = 2 : 3, find the value of (3x + 2y) : (9x + 5y).
(a) 3 : 11 (b) 5 : 12 (c) 4 : 11 (d) 4 : 13
Answer: (c) 4 : 11
Solution: Substitute x = 2, y = 3: (3*2 + 2*3) / (9*2 + 5*3) = (6 + 6) / (18 + 15) = 12 / 33 = 4 / 11. The required value is 4 : 11. Hence, the correct option is (c).
Source: SSC CGL Pattern

24. Find the mean proportional between 0.32 and 0.02.
(a) 0.80 (b) 0.04 (c) 0.016 (d) 0.08
Answer: (d) 0.08
Solution: Mean proportional = sqrt(0.32 * 0.02) = sqrt(0.0064) = 0.08. The required value is 0.08. Hence, the correct option is (d).
Source: SSC CGL Pattern

25. Two numbers are in the ratio 7 : 9. If the sum of the numbers is 288, find the difference between the numbers.
(a) 32 (b) 36 (c) 40 (d) 28
Answer: (b) 36
Solution: Total parts = 7 + 9 = 16 parts = 288 => 1 part = 288 / 16 = 18. Difference between numbers = 9 - 7 = 2 parts = 2 * 18 = 36. The required value is 36. Hence, the correct option is (b).
Source: SSC CGL Pattern
