# 🪄 शॉर्ट ट्रिक्स — अनुपात और समानुपात

---

**🎯 ट्रिक 1: "आगे-पीछे" नियम (अनुपात का क्रम)**

```
┌─────────────────────────────────────┐
│  a : b में पहला = आगे वाला (a)      │
│  दूसरा = पीछे वाला (b)              │
│  "A का B से अनुपात" = A/B           │
│  याद रखो: जो पहले बोला, वो ऊपर!     │
└─────────────────────────────────────┘
```
"राम का श्याम से अनुपात 3:2" → राम/श्याम = 3/2। जो नाम पहले आया, वही अंश में।

---

**🎯 ट्रिक 2: "क्रॉस गुणा = क्रॉस निशान" (समानुपात जाँच)**

```
┌─────────────────────────────────────┐
│  a:b :: c:d हो तो a×d = b×c         │
│  ट्रिक: "बाहर-बाहर = अंदर-अंदर"     │
│  बाहरी पदों का गुणनफल =             │
│  मध्य पदों का गुणनफल                │
└─────────────────────────────────────┘
```
म्नेमोनिक: **"बा-बा = अं-अं"** — बाहर×बाहर = अंदर×अंदर।

---

**🎯 ट्रिक 3: "K भाई" ट्रिक (अनुपात से वास्तविक मान)**

```
┌─────────────────────────────────────┐
│  अनुपात 3:5 दिखे तो मान लो 3k, 5k   │
│  k = "कॉमन भाई" — हर अनुपात में     │
│  छिपा होता है!                      │
│  योग दिया हो तो k = योग/(अनुपात योग)│
└─────────────────────────────────────┘
```
उदाहरण: 3:5, योग 80 → k = 80/8 = 10 → मान 30, 50।

---

**🎯 ट्रिक 4: "सिक्का उल्टाओ" (व्युत्क्रम अनुपात)**

```
┌─────────────────────────────────────┐
│  a:b का व्युत्क्रम = b:a             │
│  1/a : 1/b = b:a (उलट जाता है!)     │
│  ट्रिक: "भिन्न उल्टी, अनुपात उल्टा" │
└─────────────────────────────────────┘
```
1/2 : 1/3 = 3:2 — बस संख्याएँ उलट दो, LCM की ज़हमत ही नहीं!

---

**🎯 ट्रिक 5: "LCM राजा" (भिन्नों का अनुपात)**

```
┌─────────────────────────────────────┐
│  2/3 : 3/4 : 4/5 सरल करना हो तो     │
│  हरों का LCM लो, सबको उससे गुणा करो │
│  ट्रिक: "हर मारो, अनुपात पाओ"       │
└─────────────────────────────────────┘
```
LCM 60 → 40 : 45 : 48। हर गायब, सीधा पूर्णांक अनुपात!

---

**🎯 ट्रिक 6: "जोड़-घटा जादू" (Componendo-Dividendo)**

```
┌─────────────────────────────────────┐
│  a/b = c/d हो तो                    │
│  (a+b)/(a−b) = (c+d)/(c−d)          │
│  म्नेमोनिक: "ऊपर जोड़, नीचे घटा"   │
│  C-D = "CD प्लेयर" — जोड़ ऊपर चले, │
│  घटाव नीचे!                         │
└─────────────────────────────────────┘
```
x/y = 5/3 हो तो (x+y)/(x−y) = 8/2 = 4 — सीधे, बिना x,y निकाले!

---

**🎯 ट्रिक 7: "तालाब का पानी" (मिश्रण में अनुपात)**

```
┌─────────────────────────────────────┐
│  दूध:पानी = 4:1 में सिर्फ़ पानी     │
│  मिलाया जाए (कुछ निकाला न गया हो)   │
│  → दूध की मात्रा वही रहती है!       │
│  ट्रिक: "जो न मिलाया, वो अटल"       │
│  उसी को दोनों अनुपातों में बराबर    │
│  करके समीकरण बनाओ                   │
└─────────────────────────────────────┘
```
⚠️ **सावधानी:** यह ट्रिक तभी लगाओ जब मिश्रण से कुछ **निकाला न गया** हो, केवल दूसरा घटक मिलाया गया हो। अगर मिश्रण का कुछ भाग निकालकर पानी मिलाया गया है, तो दूध भी उसी अनुपात में निकल गया — यानी दूध **घट जाता है**। ऐसे प्रश्नों में निकाले गए भाग को अलग से घटाकर हल करो।

**🎯 ट्रिक 8: "गुणा-श्रृंखला" (a:b और b:c मिलाना)**

```
┌─────────────────────────────────────┐
│  a:b = 2:3, b:c = 4:5 हो तो         │
│  b को बराबर करो: 3 और 4 का LCM=12   │
│  a:b:c = 8:12:15                    │
│  ट्रिक: "बीच वाला पुल, दोनों किनारे │
│  जोड़ता है" — पुल (b) बराबर करो!    │
└─────────────────────────────────────┘
```
शॉर्टकट: a:b:c = (2×4):(3×4):(3×5) = 8:12:15 — क्रॉस गुणा से सीधे!

**🎯 ट्रिक 9: "प्रतिशत = सौ का अनुपात"**

```
┌─────────────────────────────────────┐
│  20% = 20:100 = 1:5                 │
│  ट्रिक: "% हटाओ, :100 लगाओ"         │
│  25% = 1/4, 12.5% = 1/8,            │
│  33.33% = 1/3 — ये तीन रट लो!       │
└─────────────────────────────────────┘
```
म्नेमोनिक: **"चौथाई-पच्चीस, आठवाँ-साढ़े-बारह, तिहाई-तैंतीस"**

**🎯 ट्रिक 10: "आयु का अंतर कभी नहीं बदलता"**

```
┌─────────────────────────────────────┐
│  आयु-अनुपात के प्रश्नों में:        │
│  अनुपात बदलता है, अंतर नहीं!        │
│  ट्रिक: "अंतर अटल, अनुपात चंचल"     │
│  दोनों समय के अनुपात-अंतर बराबर करो │
└─────────────────────────────────────┘
```
5:3 (अंतर 2) बाद में 7:5 (अंतर 2) — अंतर पहले से बराबर? तो सीधे k निकालो!

**🎯 ट्रिक 11: "बंटवारे का भाई-भाई" (राशि का विभाजन)**

```
┌─────────────────────────────────────┐
│  ₹X को a:b:c में बाँटना हो तो       │
│  हिस्सा = X × (अपना अनुपात/कुल योग) │
│  ट्रिक: "कुल रोटी में अपना टुकड़ा"  │
│  हर बार हर में अनुपातों का योग!     │
└─────────────────────────────────────┘
```
₹900 में 2:3:4 → पहला हिस्सा = 900 × 2/9 = ₹200।

**🎯 ट्रिक 12: "वर्ग-घन सीढ़ी" (Duplicate/Triplicate Ratio)**

```
┌─────────────────────────────────────┐
│  a:b का द्विगुण (duplicate) = a²:b² │
│  त्रिगुण (triplicate) = a³:b³       │
│  उप-द्विगुण = √a:√b                 │
│  म्नेमोनिक: "दु-दो, त्रि-तीन,       │
│  उप-उल्टा (जड़)"                    │
└─────────────────────────────────────┘
```
"दु" में दो अक्षर → घात 2; "त्रि" में तीन → घात 3; "उप" = उल्टा → वर्गमूल!

**🎯 ट्रिक 13: "आय-खर्च जोड़ी" (Income-Expenditure)**

```
┌─────────────────────────────────────┐
│  आय अनुपात a:b, खर्च अनुपात c:d हो  │
│  तो बचत = (ak − cl) : (bk − dl)     │
│  ट्रिक: "आय k से, खर्च l से —       │
│  अलग-अलग k, अलग-अलग l!"             │
└─────────────────────────────────────┘
```
सबसे बड़ा जाल: दोनों में एक ही k मत लगाओ! आय और खर्च के गुणक अलग-अलग होते हैं।

**🎯 ट्रिक 14: "एक रुपया-एक सिक्का" (सिक्कों के प्रश्न)**

```
┌─────────────────────────────────────┐
│  सिक्कों का मूल्य-अनुपात दिया हो तो │
│  सिक्कों की संख्या = मूल्य/मूल्य-प्रति-सिक्का │
│  ट्रिक: "रुपये में भाग, सिक्के पाओ" │
└─────────────────────────────────────┘
```
50p, 25p के सिक्कों का मूल्य 4:3 → संख्या = 4/0.5 : 3/0.25 = 8:12 = 2:3।

**🎯 ट्रिक 15: "तीसरा-चौथा-मध्य समानुपाती" (तीनों एक साथ)**

```
┌─────────────────────────────────────┐
│  तृतीय समानुपाती: a:b :: b:x → x=b²/a│
│  मध्य समानुपाती: x = √(ab)          │
│  चतुर्थ समानुपाती: a:b :: c:x → x=bc/a│
│  म्नेमोनिक: "तीसरे में b दो बार,    │
│  मध्य में जड़, चौथे में क्रॉस!"     │
└─────────────────────────────────────┘
```
"तीसरा" = तीसरा पद b दोहराता है (b²/a); "मध्य" = बीच में बैठता है (√ab); "चौथा" = क्रॉस गुणा (bc/a)।
