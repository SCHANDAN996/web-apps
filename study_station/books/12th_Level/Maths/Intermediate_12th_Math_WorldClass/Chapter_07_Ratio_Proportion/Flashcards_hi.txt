# फ्लैशकार्ड: अनुपात और समानुपात में दक्षता

## कार्ड 1: मध्यानुपाती (Mean Proportional)
- **प्रश्न:** दो संख्याओं a और b का मध्यानुपाती क्या होता है?
- **उत्तर:** मध्यानुपाती = sqrt(a * b)।

## कार्ड 2: तृतीयानुपाती (Third Proportional)
- **प्रश्न:** दो राशियों a और b का तृतीयानुपाती क्या होता है?
- **उत्तर:** तृतीयानुपाती x = b^2 / a।

## कार्ड 3: चतुर्थानुपाती (Fourth Proportional)
- **प्रश्न:** तीन राशियों a, b और c का चतुर्थानुपाती क्या होता है?
- **उत्तर:** चतुर्थानुपाती x = (b * c) / a।

## कार्ड 4: अनुपात संयोजन नियम
- **प्रश्न:** यदि a : b = 2 : 3 तथा b : c = 4 : 5 हो, तो a : b : c क्या होगा?
- **उत्तर:** a : b : c = 8 : 12 : 15।

## कार्ड 5: योगानुपात-अंतरानुपात नियम
- **प्रश्न:** यदि a / b = c / d हो, तो C&D नियम क्या है?
- **उत्तर:** (a + b) / (a - b) = (c + d) / (c - d)।

## कार्ड 6: वर्गानुपात और वर्गमूलानुपात
- **प्रश्न:** a : b का वर्गानुपात और वर्गमूलानुपात क्या है?
- **उत्तर:** वर्गानुपात = a^2 : b^2; वर्गमूलानुपात = sqrt(a) : sqrt(b)।
