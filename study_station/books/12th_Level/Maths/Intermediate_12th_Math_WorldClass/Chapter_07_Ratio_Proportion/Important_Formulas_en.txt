# 📋 Important Formulas — Ratio & Proportion

| Formula Name | Formula | Use-Hint |
|---|---|---|
| Ratio | a : b = a/b | Comparing two quantities of the same unit |
| Ratio in simplest form | a : b = (a÷HCF) : (b÷HCF) | Always reduce by the HCF |
| Compound ratio | (a:b) × (c:d) = ac : bd | Combining two or more ratios |
| Duplicate ratio | a² : b² | When each term is squared |
| Triplicate ratio | a³ : b³ | When each term is cubed |
| Sub-duplicate ratio | √a : √b | When square root of each term is taken |
| Sub-triplicate ratio | ∛a : ∛b | When cube root of each term is taken |
| Inverse (reciprocal) ratio | a : b → 1/a : 1/b = b : a | Speed–time, work–time type questions |
| Proportion | a : b :: c : d ⇒ a/b = c/d | Two equal ratios |
| Product rule | a × d = b × c (extremes × means) | Solving any proportion |
| Continued proportion | a : b = b : c ⇒ b² = ac | b is the mean proportional |
| Mean proportional | b = √(ac) | "Mean proportional between a and c" |
| Third proportional | a : b = b : c ⇒ c = b²/a | "Third proportional to a and b" |
| Fourth proportional | a : b = c : d ⇒ d = bc/a | "Fourth proportional to a, b, c" |
| Componendo | (a+b)/b = (c+d)/d | When a/b = c/d |
| Dividendo | (a−b)/b = (c−d)/d | When a/b = c/d |
| Componendo-Dividendo | (a+b)/(a−b) = (c+d)/(c−d) | Questions with (x+y)/(x−y) form |
| Addendo | a/b = c/d = e/f = (a+c+e)/(b+d+f) | Equal ratios — add numerators and denominators |
| Dividing an amount in ratio a:b | First share = N × a/(a+b); Second = N × b/(a+b) | Distribution of money/profit |
| Ratio change (add/subtract) | (a+x)/(b+x) = new ratio | "What should be added so that…" |
| Income–Expenditure | Savings = Income − Expenditure | Income ratio × expenditure ratio problems |
| Two numbers in ratio with LCM/HCF | Numbers = a×k, b×k (k = common factor) | Use HCF/LCM to find k |
| Coins ratio | Value = (no. of coins) × (coin value) | Convert coin-count ratio to value ratio |
| A:B and B:C combined | Make B equal (LCM), then A:B:C | Joining two ratios with a common term |
| Percentage to ratio | x% : y% = x : y | Converting percentage shares to ratio |
| Mixture ratio (alligation) | (dearer − mean) : (mean − cheaper) | Mixing two items at given prices |
| Ages in ratio | Present ages = a·k, b·k; adjust ±years | "After x years the ratio becomes…" |
| Partnership | Profit ratio = (Investment × Time) ratio | Capitals invested for different durations |
| Speed–Time inverse | Speed ratio a:b ⇒ Time ratio b:a | Same distance, different speeds |
| Work–Time inverse | Efficiency ratio a:b ⇒ Time ratio b:a | Same work, different workers |
