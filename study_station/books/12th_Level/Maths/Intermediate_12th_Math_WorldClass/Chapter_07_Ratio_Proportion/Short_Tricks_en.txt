# 🪄 Short Tricks & Mnemonics — Ratio & Proportion

---

┌─────────────────────────────────────────────┐
│ **TRICK 1 — "RATS" for Ratio Basics**        │
│                                              │
│ **R**atio **A**lways **T**akes **S**implest form │
│                                              │
│ Before ANY calculation, divide both terms by │
│ their HCF. 12:18 → 2:3. A rat gnaws numbers  │
│ down to the bone!                            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 2 — The "K-Factory" (Keyword)**      │
│                                              │
│ Whenever you see a ratio a:b, shout:         │
│ **"Call them ak and bk!"**                   │
│                                              │
│ Boys : Girls = 3:5 → Boys = 3k, Girls = 5k. │
│ The letter **k** is your magic factory that  │
│ turns ratios into real numbers.              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 3 — "Cross the River" (Loci)**       │
│                                              │
│ Proportion a:b :: c:d? Picture a river with  │
│ two stepping stones on each side. To cross,  │
│ you jump DIAGONALLY:                         │
│                                              │
│ **a × d = b × c** (Product of extremes =     │
│ product of means)                            │
│                                              │
│ Never jump straight across — always cross!   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 4 — "MEAN people stay INSIDE"**      │
│                                              │
│ In a : b :: c : d —                         │
│ • Means = b, c → the **INNER** two           │
│ • Extremes = a, d → the **OUTER** two        │
│                                              │
│ Memory hook: "Mean people stay inside the    │
│ house; Extremists are thrown OUTside."       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 5 — "Pizza Slice" for a:b → %**      │
│                                              │
│ To convert a ratio to a percentage:          │
│ **Part ÷ Whole × 100**                       │
│                                              │
│ If pizza is cut 3:1 between you and friend,  │
│ your share = 3/(3+1) × 100 = 75%.            │
│ Always ADD the ratio parts first — that's    │
│ your whole pizza!                            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 6 — "DIM" for Direct & Inverse**     │
│ (Acronym)                                    │
│                                              │
│ **D**irect → **I**ncrease matches increase   │
│ **M**irror (Inverse) → opposite moves        │
│                                              │
│ Direct: more workers → more work done.       │
│ Inverse: more workers → LESS time.           │
│ Inverse is a MIRROR — everything flips!      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 7 — "Flip & Multiply" for Inverse**  │
│                                              │
│ Inverse proportion problems?                 │
│ **Flip the second ratio, then equate.**      │
│                                              │
│ Men × Days = constant                        │
│ M₁ × D₁ = M₂ × D₂                            │
│                                              │
│ Hook: "Inverse = Invert = Flip it!"          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 8 — "COMPO-DIV" the Chef (Loci)**    │
│                                              │
│ Componendo-Dividendo:                        │
│ If a/b = c/d, then (a+b)/(a−b) = (c+d)/(c−d)│
│                                              │
│ Picture a chef named **COMPO-DIV** who       │
│ always cooks two dishes: one with PLUS (+)   │
│ on top, one with MINUS (−) below.            │
│ Plus upstairs, Minus downstairs!             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 9 — "Duplicate = Double-Trouble"**   │
│ (Keyword)                                    │
│                                              │
│ • Duplicate ratio of a:b = a² : b²           │
│ • Triplicate ratio = a³ : b³                 │
│ • Sub-duplicate = √a : √b                    │
│                                              │
│ Hook: "DUPLICATE means DOUBLE the trouble —  │
│ SQUARE it! TRIPlicate = TRIPLE = CUBE it!"   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 10 — "The Salary Thief" (Loci)**     │
│                                              │
│ Two salaries in ratio 4:5, both increased    │
│ by ₹2000, new ratio 5:6?                     │
│                                              │
│ Imagine the ₹2000 as a THIEF who steals into │
│ both houses equally. Set up:                 │
│ (4k+2000)/(5k+2000) = 5/6 → cross-multiply!  │
│                                              │
│ Rule: Same addition to both → use k-method.  │
│ Note: adding the same amount to both terms   │
│ keeps their DIFFERENCE unchanged — but the   │
│ RATIO still changes, so never assume the     │
│ ratio stays the same.                        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 11 — "CHAIN-gang" for Continued**    │
│ **Proportion (Acronym + Image)**             │
│                                              │
│ a:b = 2:3 and b:c = 4:5, find a:b:c?         │
│                                              │
│ Make **b** the common LINK in the chain:     │
│ LCM of 3 and 4 = 12.                         │
│ a:b = 8:12, b:c = 12:15 → a:b:c = 8:12:15    │
│                                              │
│ Hook: "The middle term is the CHAIN LINK —   │
│ weld both sides to the same size!"           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 12 — "Mean Proportional = Geo-       │
│ Middle" (Keyword)**                          │
│                                              │
│ Mean proportional between a and b = √(ab)    │
│                                              │
│ Hook: "The GEOMETRIC middle child — multiply │
│ the parents, take the ROOT of the family!"   │
│                                              │
│ Between 4 and 9: √(4×9) = √36 = 6.           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 13 — "Third Wheel" for Third**       │
│ **Proportional (Loci)**                      │
│                                              │
│ Third proportional to a, b = b²/a            │
│                                              │
│ Picture three friends on a bike: a, b, and   │
│ the THIRD WHEEL x, where a:b :: b:x.         │
│ The middle friend b gets on TWICE (b²),      │
│ and poor a gets left under (divided).        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 14 — "PARTS First, PANIC Never"**    │
│ (Acronym-style mantra)                       │
│                                              │
│ Dividing ₹X in ratio a:b:c?                  │
│ Step 1: Total parts = a+b+c                  │
│ Step 2: One part = X ÷ (a+b+c)               │
│ Step 3: Multiply each share                  │
│                                              │
│ Chant: **"PARTS first, panic never!"**       │
│ Most mistakes in such questions happen at    │
│ Step 1 — so add the parts carefully.         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 15 — "The Invertendo Backflip"**     │
│ (Keyword)                                    │
│                                              │
│ Invertendo: if a/b = c/d, then b/a = d/c.    │
│                                              │
│ Hook: "INVERTENDO = the gymnast's BACKFLIP — │
│ both fractions flip together, and the        │
│ equality still lands on its feet!"           │
│                                              │
│ Bonus family: Alternendo (swap the middles), │
│ Componendo (add 1), Dividendo (subtract 1).  │
└─────────────────────────────────────────────┘
