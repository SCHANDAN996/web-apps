# महत्वपूर्ण सूत्र: अनुपात और समानुपात

## 1. समानुपात के सूत्र
- बाह्य पदों का गुणन = मध्य पदों का गुणन: a * d = b * c
- चतुर्थानुपाती: x = (b * c) / a
- तृतीयानुपाती: x = b^2 / a
- मध्यानुपाती: x = sqrt(a * b)

## 2. विशिष्ट अनुपात सूत्र
- वर्गानुपात = a^2 : b^2
- वर्गमूलानुपात = sqrt(a) : sqrt(b)
- घनानुपात = a^3 : b^3
- घनमूलानुपात = a^(1/3) : b^(1/3)
- मिश्र अनुपात = (ace) : (bdf)

## 3. योगानुपात एवं अंतरानुपात (C&D)
- यदि a / b = c / d हो, तो:
  (a + b) / (a - b) = (c + d) / (c - d)

## 4. राशि वितरण सूत्र
- राशि S को p : q : r में बाँटने पर:
  A का भाग = S * [p / (p + q + r)]
  B का भाग = S * [q / (p + q + r)]
  C का भाग = S * [r / (p + q + r)]

## 5. सिक्कों का कुल मूल्य
- कुल मूल्य = योग (सिक्कों की संख्या * सिक्के का मूल्य)
