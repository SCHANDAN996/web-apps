26. A bag contains Rs 1, 50 paise, and 25 paise coins in the ratio 5 : 6 : 8. If the total money in the bag is Rs 210, find the number of 50 paise coins.
(a) 126 (b) 105 (c) 140 (d) 112
Answer: (a) 126
Solution: Value ratio = (5 * 1) : (6 * 0.50) : (8 * 0.25) = 5 : 3 : 2. Sum of parts = 10 parts = Rs 210 => 1 part = Rs 21. Total value of 50 paise coins = 3 * 21 = Rs 63. Number of 50 paise coins = 63 / 0.50 = 126 coins. The required value is 126. Hence, the correct option is (a).
Source: SSC CGL Pattern

27. A box contains 280 coins of Rs 1, 50 paise, and 25 paise. The values of each kind of the coins are in the ratio 8 : 4 : 3. Find the number of 50 paise coins.
(a) 64 (b) 80 (c) 96 (d) 72
Answer: (b) 80
Solution: Ratio of number of coins = (8 / 1) : (4 / 0.50) : (3 / 0.25) = 8 : 8 : 12 = 2 : 2 : 3. Total coin parts = 2 + 2 + 3 = 7 parts. 7 parts = 280 coins => 1 part = 40. Number of 50 paise coins = 2 * 40 = 80 coins. The required value is 80. Hence, the correct option is (b).
Source: SSC CGL Pattern

28. The monthly incomes of two persons are in the ratio 5 : 4 and their monthly expenditures are in the ratio 3 : 2. If each saves Rs 1,600 per month, find the monthly income of the first person.
(a) Rs 3,200 (b) Rs 4,800 (c) Rs 4,000 (d) Rs 3,600
Answer: (c) Rs 4,000
Solution: Ratio difference between income and expenditure is (5 - 3) = 2 and (4 - 2) = 2 parts. 2 parts = Rs 1,600 => 1 part = Rs 800. Monthly income of first person = 5 * 800 = Rs 4,000. The required value is Rs 4,000. Hence, the correct option is (c).

Answer: (a) 0.64

31. If a : b = 2 : 3, b : c = 4 : 5, and c : d = 6 : 7, find the ratio a : d.
(a) 8 : 35 (b) 16 : 35 (c) 12 : 35 (d) 16 : 25
Answer: (b) 16 : 35
Solution: Product of fractions: a / d = (a / b) * (b / c) * (c / d) = (2 / 3) * (4 / 5) * (6 / 7) = 48 / 105 = 16 / 35. The required value is 16 : 35. Hence, the correct option is (b).

32. If a : b : c = 2 : 3 : 4, find the ratio (a / b) : (b / c) : (c / a).
(a) 4 : 9 : 16 (b) 2 : 3 : 4 (c) 8 : 9 : 24 (d) 6 : 8 : 12
Answer: (c) 8 : 9 : 24
Solution: a / b = 2 / 3, b / c = 3 / 4, c / a = 4 / 2 = 2. Ratio = 2/3 : 3/4 : 2. Multiplying by LCM(3, 4) = 12: (2/3 * 12) : (3/4 * 12) : (2 * 12) = 8 : 9 : 24. The required value is 8 : 9 : 24. Hence, the correct option is (c).
Source: SSC CGL Pattern

33. Two numbers are in the ratio 1 1/2 : 2 2/3. When each is increased by 15, the ratio becomes 1 2/3 : 2 1/2. What is the greater number?
(a) 40 (b) 36 (c) 54 (d) 48
Answer: (d) 48
Solution: Initial ratio is 3/2 : 8/3 = 9 : 16. New ratio is 5/3 : 5/2 = 2 : 3. Setting the proportion: (9x + 15) / (16x + 15) = 2 / 3. Cross multiplying: 3(9x + 15) = 2(16x + 15) => 27x + 45 = 32x + 30 => 5x = 15 => x = 3. The greater number is 16x = 16 * 3 = 48. The required value is 48. Hence, the correct option is (d).
Source: SSC CGL Pattern

34. A sum of Rs 8,670 is divided among A, B, and C such that A's share is 2/3 of B's share, and B's share is 1/4 of C's share. How much does B receive?
(a) Rs 1,530 (b) Rs 1,020 (c) Rs 6,120 (d) Rs 1,600
Answer: (a) Rs 1,530
Solution: A : B = 2 : 3. B : C = 1 : 4 = 3 : 12. Thus, A : B : C = 2 : 3 : 12. Sum of parts = 2 + 3 + 12 = 17 parts. 17 parts = 8,670 => 1 part = 8,670 / 17 = 510. B's share = 3 * 510 = Rs 1,530. The required value is Rs 1,530. Hence, the correct option is (a).
Source: SSC CGL Pattern

35. Find the number that must be added to each of 7, 16, 43, and 79 so that the resulting numbers are in proportion.
(a) 3 (b) 5 (c) 4 (d) 6
Answer: (b) 5
Solution: Using formula: x = (ad - bc) / [(b + c) - (a + d)] = (7 * 79 - 16 * 43) / [(16 + 43) - (7 + 79)] = (553 - 688) / (59 - 86) = -135 / -27 = 5. The required value is 5. Hence, the correct option is (b).
Source: SSC CGL Pattern

37. If x is the mean proportional between 12.8 and 64.8, find the value of x.
(a) 26.4 (b) 30.2 (c) 27.6 (d) 28.8
Answer: (d) 28.8
Solution: Mean proportional = sqrt(12.8 * 64.8) = sqrt((128 * 648) / 100) = sqrt((64 * 2 * 324 * 2) / 100) = sqrt(64 * 324 * 4 / 100) = (8 * 18 * 2) / 10 = 288 / 10 = 28.8. The required value is 28.8. Hence, the correct option is (d).

39. Salaries of Ravi and Sumit are in the ratio 2 : 3. If the salary of each is increased by Rs 4,000, the new ratio becomes 40 : 57. What is Sumit's present salary?
(a) Rs 38,000 (b) Rs 34,000 (c) Rs 36,000 (d) Rs 32,000
Answer: (b) Rs 34,000
Solution: Equation: (2x + 4000) / (3x + 4000) = 40 / 57 => 57(2x + 4000) = 40(3x + 4000) => 114x + 228,000 = 120x + 160,000 => 6x = 68,000 => 3x = 34,000. Therefore, Sumit's present salary is 3x = Rs 34,000. The required value is Rs 34,000. Hence, the correct option is (b).
Source: SSC CGL Pattern

40. If (x + y) : (x - y) = 4 : 1, find the value of (x^2 + y^2) : (x^2 - y^2).
(a) 16 : 9 (b) 15 : 8 (c) 17 : 8 (d) 17 : 9
Answer: (c) 17 : 8
Solution: Applying Componendo and Dividendo: x / y = (4 + 1) / (4 - 1) = 5 / 3. Then x^2 / y^2 = 25 / 9. Applying C&D again: (x^2 + y^2) / (x^2 - y^2) = (25 + 9) / (25 - 9) = 34 / 16 = 17 / 8. The required value is 17 : 8. Hence, the correct option is (c).
Source: SSC CGL Pattern

44. The ratio of ages of two persons is 5 : 7. Eighteen years ago, their ages were in the ratio 8 : 13. Find their present ages.
(a) 45 and 63 years (b) 40 and 56 years (c) 50 and 70 years (d) 55 and 77 years
Answer: (c) 50 and 70 years
Solution: (5x - 18) / (7x - 18) = 8 / 13 => 13(5x - 18) = 8(7x - 18) => 65x - 234 = 56x - 144 => 9x = 90 => x = 10. Present ages are 5 * 10 = 50 and 7 * 10 = 70 years. The required value is 50 and 70 years. Hence, the correct option is (c).
Source: SSC CGL Pattern

45. A sum of Rs 427 is to be divided among A, B, and C in such a way that 3 times A's share, 4 times B's share, and 7 times C's share are all equal. Find C's share.

Answer: (d) Rs 84
Solution: Let 3A = 4B = 7C = 84k (LCM of 3, 4, 7 is 84). Then A = 28k, B = 21k, C = 12k. Ratio A : B : C = 28 : 21 : 12. Sum of parts = 28 + 21 + 12 = 61 parts. 61 parts = 427 => 1 part = 427 / 61 = 7. C's share = 12 * 7 = Rs 84. The required value is Rs 84. Hence, the correct option is (d).
Source: SSC CGL Pattern

48. Two numbers are in the ratio 2 : 3. If 2 is subtracted from the first and 2 is added to the second, the ratio becomes 1 : 2. Find the sum of the two numbers.
(a) 25 (b) 35 (c) 30 (d) 28
Answer: (c) 30
Solution: (2x - 2) / (3x + 2) = 1 / 2 => 2(2x - 2) = 3x + 2 => 4x - 4 = 3x + 2 => x = 6. Sum of numbers = 2x + 3x = 5x = 5 * 6 = 30. The required value is 30. Hence, the correct option is (c).
Source: SSC CGL Pattern

49. In a mixture of 60 liters, the ratio of milk and water is 2 : 1. If this ratio is to be 1 : 2, then the quantity of water to be further added is:
(a) 40 liters (b) 50 liters (c) 30 liters (d) 60 liters
Answer: (d) 60 liters
Solution: Initial Milk = 60 * (2/3) = 40 liters, Water = 20 liters. In the new mixture, milk is 1 part = 40 liters, so water must be 2 parts = 80 liters. Water to be added = 80 - 20 = 60 liters. The required value is 60 liters. Hence, the correct option is (d).
Source: SSC CGL Pattern

50. The ratio of the number of boys to that of girls in a school of 432 pupils is 5 : 4. When some new boys and girls are admitted, the number of boys increases by 12 and the ratio of boys to girls becomes 7 : 6. Find the number of new girls admitted.
(a) 20 (b) 24 (c) 28 (d) 16
Answer: (b) 24
Solution: Total pupils = 432 in ratio 5 : 4 => Boys = 432 * 5/9 = 240, Girls = 432 * 4/9 = 192. New boys = 240 + 12 = 252. If ratio of Boys to Girls is 7 : 6: 7 parts = 252 => 1 part = 36. Total new girls = 6 * 36 = 216. New girls admitted = 216 - 192 = 24. The required value is 24. Hence, the correct option is (b).
Source: SSC CGL Pattern
