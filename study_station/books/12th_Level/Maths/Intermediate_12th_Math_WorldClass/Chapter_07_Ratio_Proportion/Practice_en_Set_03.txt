51. The monthly incomes of two persons are in the ratio 5 : 3 and their monthly expenditures are in the ratio 9 : 5. If they save Rs 1,300 and Rs 900 respectively, find the monthly income of the first person.
(a) Rs 4,000 (b) Rs 3,600 (c) Rs 4,500 (d) Rs 3,200
Answer: (a) Rs 4,000
Solution: Using cross multiplication: (5 * 5 - 3 * 9)x = 5 * (-1300) - 9 * (-900) => (25 - 27)x = -6500 + 8100 => -2x = 1600... absolute difference: |25 - 27|x = |8100 - 6500| => 2x = 1600 => x = 800. Monthly income of first person = 5 * 800 = Rs 4,000. The required value is Rs 4,000. Hence, the correct option is (a).
Source: SSC CGL Pattern

52. If a : b = 1 : 2, b : c = 3 : 4, c : d = 5 : 6, and d : e = 7 : 8, find the ratio a : e.
(a) 35 : 256 (b) 35 : 128 (c) 35 : 64 (d) 7 : 32
Answer: (b) 35 : 128
Solution: Ratio a / e = (a / b) * (b / c) * (c / d) * (d / e) = (1 / 2) * (3 / 4) * (5 / 6) * (7 / 8) = 105 / 384 = 35 / 128. The required value is 35 : 128. Hence, the correct option is (b).

53. A sum of Rs 1,300 is divided among P, Q, R, and S such that (P's share / Q's share) = (Q's share / R's share) = (R's share / S's share) = 2/3. What is P's share?
(a) Rs 240 (b) Rs 360 (c) Rs 160 (d) Rs 540
Answer: (c) Rs 160
Solution: The continuous ratio P : Q : R : S = 2^3 : (2^2 * 3) : (2 * 3^2) : 3^3 = 8 : 12 : 18 : 27. Sum of parts = 8 + 12 + 18 + 27 = 65 parts. 65 parts = 1,300 => 1 part = 20. P's share = 8 * 20 = Rs 160. The required value is Rs 160. Hence, the correct option is (c).
Source: SSC CGL Pattern

54. A sum of Rs 3,000 is distributed among A, B, and C such that A receives 1/3 as much as B and C together receive, and B receives 2/3 as much as A and C together receive. Find the share of C.
(a) Rs 1,200 (b) Rs 750 (c) Rs 950 (d) Rs 1,050
Answer: (d) Rs 1,050
Solution: A = (1/3)(B + C) => A / (B + C) = 1 / 3 => A / (A + B + C) = 1 / 4. A's share = 3000 * 1/4 = Rs 750. Also, B = (2/3)(A + C) => B / (A + C) = 2 / 3 => B / (A + B + C) = 2 / 5. B's share = 3000 * 2/5 = Rs 1,200. C's share = 3000 - (750 + 1200) = 3000 - 1950 = Rs 1,050. The required value is Rs 1,050. Hence, the correct option is (d).
Source: SSC CGL Pattern

55. In a mixture of 45 liters, the ratio of liquid A and liquid B is 7 : 2. If 10 liters of liquid B is added to the mixture, what will be the ratio of liquid A and liquid B in the new mixture?
(a) 7 : 4 (b) 7 : 5 (c) 3 : 2 (d) 5 : 3
Answer: (a) 7 : 4
Solution: Initial volume of liquid A = 45 * (7 / 9) = 35 liters, and liquid B = 45 * (2 / 9) = 10 liters. Adding 10 liters of B gives 10 + 10 = 20 liters of liquid B. New ratio of A to B = 35 : 20 = 7 : 4. The required value is 7 : 4. Hence, the correct option is (a).
Source: SSC CGL Pattern

57. The ratio of the incomes of two persons is 9 : 7 and the ratio of their expenditures is 4 : 3. If each of them manages to save Rs 2,000 per month, find their monthly incomes.
(a) Rs 16,000 and Rs 12,000 (b) Rs 20,000 and Rs 15,000 (c) Rs 18,000 and Rs 14,000 (d) Rs 27,000 and Rs 21,000
Answer: (c) Rs 18,000 and Rs 14,000
Solution: Using cross multiplication: (9 * 3 - 7 * 4)x = 2,000 * (3 - 4) => (27 - 28)x = -2,000 => -x = -2,000 => x = 2,000. Monthly incomes are 9 * 2,000 = Rs 18,000 and 7 * 2,000 = Rs 14,000. The required value is Rs 18,000 and Rs 14,000. Hence, the correct option is (c).

58. A person divides Rs 6,800 among A, B, and C in the ratio 1/2 : 1/4 : 5/16. Find the largest share.
(a) Rs 2,800 (b) Rs 3,000 (c) Rs 3,400 (d) Rs 3,200
Answer: (d) Rs 3,200
Solution: Multiplying each fraction by LCM(2, 4, 16) = 16: (1/2 * 16) : (1/4 * 16) : (5/16 * 16) = 8 : 4 : 5. Sum of parts = 8 + 4 + 5 = 17 parts. 17 parts = 6,800 => 1 part = 400. Largest share (A) = 8 * 400 = Rs 3,200. The required value is Rs 3,200. Hence, the correct option is (d).

59. The ratio of the quantities of sugar in two mixtures is 3 : 5 and 4 : 7. If equal weights of the two mixtures are taken, find the ratio of sugar in the combined mixture to total weight.
(a) 65 : 176 (b) 63 : 176 (c) 67 : 176 (d) 35 : 88
Answer: (a) 65 : 176
Solution: In mixture 1, fraction of sugar = 3 / (3 + 5) = 3/8. In mixture 2, fraction of sugar = 4 / (4 + 7) = 4/11. Sum of sugar in 1 unit each = 3/8 + 4/11 = (33 + 32) / 88 = 65 / 88. Total weight of both units = 2. Ratio to total weight = (65 / 88) / 2 = 65 / 176. The required value is 65 : 176. Hence, the correct option is (a).
Source: SSC CGL Pattern

62. If (3a + 5b) : (3a - 5b) = 5 : 1, find the ratio a : b.

Answer: (d) 5 : 2
Solution: Using Componendo and Dividendo: (3a) / (5b) = (5 + 1) / (5 - 1) = 6 / 4 = 3 / 2. Therefore, a / b = (3 / 2) * (5 / 3) = 5 / 2. The required value is 5 : 2. Hence, the correct option is (d).

63. If x / 5 = y / 8, find the value of (x + 5) : (y + 8).
(a) 5 : 8 (b) 1 : 1 (c) 10 : 16 (d) 8 : 5
Answer: (a) 5 : 8
Solution: Let x / 5 = y / 8 = k. Then x = 5k, y = 8k. (x + 5) / (y + 8) = (5k + 5) / (8k + 8) = 5(k + 1) / 8(k + 1) = 5 / 8. The required value is 5 : 8. Hence, the correct option is (a).
Source: SSC CGL Pattern

64. A man leaves Rs 86,000 to be divided among 5 sons, 4 daughters, and 2 nephews. If each daughter receives 4 times as much as each nephew, and each son receives 5 times as much as each nephew, how much does each daughter receive?
(a) Rs 6,000 (b) Rs 8,000 (c) Rs 10,000 (d) Rs 7,500
Answer: (b) Rs 8,000
Solution: Let nephew's share = x. Daughter = 4x, Son = 5x. Total sum = 5(5x) + 4(4x) + 2(x) = 25x + 16x + 2x = 43x. 43x = 86,000 => x = 2,000. Each daughter receives 4x = 4 * 2,000 = Rs 8,000. The required value is Rs 8,000. Hence, the correct option is (b).
Source: SSC CGL Pattern

65. The ratio of the number of students in three classes is 2 : 3 : 5. If 20 students are increased in each class, the ratio becomes 4 : 5 : 7. What was the total number of students in the three classes initially?
(a) 90 (b) 120 (c) 100 (d) 110
Answer: (c) 100
Solution: Each ratio term increases by 4 - 2 = 2 parts, 5 - 3 = 2 parts, 7 - 5 = 2 parts. 2 parts = 20 students => 1 part = 10 students. Total initial students = 2 + 3 + 5 = 10 parts = 10 * 10 = 100 students. The required value is 100. Hence, the correct option is (c).

(a) Rs 400,000 (b) Rs 360,000 (c) Rs 450,000 (d) Rs 320,000

Price of A last year = 4x = 4 * 90,000 = Rs 360,000. The required value is Rs 360,000. Hence, the correct option is (b).

73. A person distributes Rs 210 among some boys and girls such that each boy gets 50 paise and each girl gets 25 paise. If the ratio of boys to girls is 5 : 4, find the total number of children.
(a) 450 (b) 480 (c) 540 (d) 500
Answer: (c) 540
Solution: Let the number of boys be 5x and girls be 4x. Total value in Rupees = (5x * 0.50) + (4x * 0.25) = 2.5x + 1.0x = 3.5x. Since 3.5x = 210, x = 210 / 3.5 = 60. Total children = 5x + 4x = 9x = 9 * 60 = 540. The required value is 540. Hence, the correct option is (c).
Source: SSC CGL Pattern

74. If (4x^2 - 3y^2) : (2x^2 + 5y^2) = 12 : 19, find the ratio x : y.
(a) 2 : 3 (b) 4 : 3 (c) 3 : 4 (d) 3 : 2
Answer: (d) 3 : 2
Solution: Cross multiplying: 19(4x^2 - 3y^2) = 12(2x^2 + 5y^2) => 76x^2 - 57y^2 = 24x^2 + 60y^2 => 52x^2 = 117y^2 => x^2 / y^2 = 117 / 52 = 9 / 4 => x / y = 3 / 2. The required value is 3 : 2. Hence, the correct option is (d).
Source: SSC CGL Pattern
