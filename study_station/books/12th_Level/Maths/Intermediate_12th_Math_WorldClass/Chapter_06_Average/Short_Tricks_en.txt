# 🪄 Average — Short Tricks & Memory Hacks

---

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 1 — The "See-Saw" Rule (Average = Balance Point)**  │
├─────────────────────────────────────────────────────────────┤
│ Imagine numbers sitting on a see-saw. The AVERAGE is the    │
│ exact point where it balances perfectly. Numbers above the  │
│ average pull up exactly as much as numbers below pull down. │
│                                                             │
│ 💡 Use: Total of (value − average) over all values = 0      │
│ Memory hook: *"Average is the Balancer!"*                   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 2 — "SANT" Acronym for the Master Formula**         │
├─────────────────────────────────────────────────────────────┤
│ **S**um = **A**verage × **N**umber of **T**erms             │
│                                                             │
│ Say it like a name: "SANT gives you everything!"            │
│ If you know any 2 of Sum, Average, Number — the 3rd is free.│
│                                                             │
│ 💡 Use: Every average problem is just SANT rearranged.      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 3 — The "New Kid" Trick (Person Joins/Leaves)**     │
├─────────────────────────────────────────────────────────────┤
│ When a new person joins and average RISES:                  │
│ New person's value = New average + (Old members × Rise)     │
│                                                             │
│ 🧠 Picture: The new kid must bring his own share PLUS pay   │
│ a "tip" to every old member to raise their average.         │
│ Memory hook: *"New kid pays everyone a tip!"*               │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 4 — "Replacement = Robbery" Trick**                 │
├─────────────────────────────────────────────────────────────┤
│ When a person is REPLACED and average increases by 'x'      │
│ over 'n' people:                                            │
│ New person = Old person + (n × x)                           │
│                                                             │
│ 🧠 Picture: The newcomer "robs" the gap — he must be        │
│ heavier/taller by the total gain of the whole group.        │
│ Memory hook: *"Replacement pays the whole group's raise."*  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 5 — "AP = Middle Man" (Consecutive Numbers)**       │
├─────────────────────────────────────────────────────────────┤
│ Average of consecutive / arithmetic progression numbers     │
│ = the MIDDLE term = (First + Last) ÷ 2                      │
│                                                             │
│ 🧠 Picture: Numbers stand in a queue holding hands — the    │
│ average is always the guy in the exact middle.              │
│ Memory hook: *"Odd count? Middle man. Even? Average the     │
│ two middle men."*                                           │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 6 — "1 to n? Just (n+1)/2"**                        │
├─────────────────────────────────────────────────────────────┤
│ Average of first n natural numbers = (n + 1) / 2            │
│                                                             │
│ 🧠 Keyword: "One-more-half" — add 1 to n, cut in half.      │
│ Example: Average of 1 to 99 = (99+1)/2 = 50. Done in 3 sec! │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 7 — "Even = n+1, Odd = n" (The Twins Trick)**       │
├─────────────────────────────────────────────────────────────┤
│ Average of first n EVEN numbers = n + 1                     │
│ Average of first n ODD numbers = n                          │
│                                                             │
│ 🧠 Mnemonic: **"Even is Extra (+1), Odd is Ordinary (n)"**  │
│ Example: First 10 even numbers → avg = 11.                  │
│          First 10 odd numbers → avg = 10.                   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 8 — The "Assumed Average" Ladder**                  │
├─────────────────────────────────────────────────────────────┤
│ For big ugly numbers (e.g., 47, 52, 49, 51, 48):            │
│ 1. ASSUME a round average (say 50).                         │
│ 2. Write deviations: −3, +2, −1, +1, −2 → sum = −3          │
│ 3. Real average = 50 + (−3/5) = 49.4                        │
│                                                             │
│ 🧠 Memory hook: *"Climb the ladder from a round number!"*   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 9 — "Speed Trap: 2xy/(x+y)" (Round Trip)**          │
├─────────────────────────────────────────────────────────────┤
│ Same distance at speeds x and y →                           │
│ Average speed = 2xy / (x + y)  [NEVER (x+y)/2!]             │
│                                                             │
│ 🧠 Mnemonic: **"Twice the Product over the Sum"** — chant:  │
│ "2-Product-Sum! 2-Product-Sum!"                             │
│ Trap alert: Examiners ALWAYS offer (x+y)/2 as an option.    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 10 — "Weighted Average = Tug of War"**              │
├─────────────────────────────────────────────────────────────┤
│ Combined average leans toward the BIGGER group.             │
│ Combined avg = (n₁a₁ + n₂a₂) / (n₁ + n₂)                    │
│                                                             │
│ 🧠 Picture: Tug of war — the team with more people pulls    │
│ the average toward their side.                              │
│ Quick check: Answer must lie BETWEEN the two averages.      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 11 — "Alligation Cross" (The X-Mix)**               │
├─────────────────────────────────────────────────────────────┤
│ To find ratio of two groups from combined average:          │
│         a₁ ──────╲                                          │
│                   ╲                                         │
│                    A (combined)                             │
│                   ╱                                         │
│         a₂ ──────╱                                          │
│ Ratio n₁ : n₂ = (A − a₂) : (a₁ − A)  ← CROSS subtract!      │
│                                                             │
│ 🧠 Memory hook: *"Cross the X, get the mix!"*               │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 12 — "Wrong Entry? Fix the Sum First"**             │
├─────────────────────────────────────────────────────────────┤
│ If a number was misread (e.g., 83 read as 38):              │
│ Correct sum = Wrong sum − Wrong value + Right value         │
│                                                             │
│ 🧠 Mnemonic: **"Kick out the fake, welcome the real."**     │
│ Then divide by n for the corrected average.                 │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 13 — "Age Problems: Everyone Ages Together"**       │
├─────────────────────────────────────────────────────────────┤
│ After 'x' years, EVERY member's age rises by x.             │
│ New average = Old average + x (for the same group).         │
│                                                             │
│ 🧠 Memory hook: *"Time machine moves everyone equally!"*    │
│ Trap: If members change (join/leave), this rule DIES.       │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 14 — "Squares & Cubes: The Big Brothers"**          │
├─────────────────────────────────────────────────────────────┤
│ Avg of first n squares = (n+1)(2n+1)/6                      │
│ Avg of first n cubes = n(n+1)²/4                            │
│                                                             │
│ 🧠 Mnemonic: **"Squares: 1-2-6 family"** → (n+1)(2n+1)/6    │
│                **"Cubes: square the average of naturals"**  │
│ → [n(n+1)/2]² ÷ n = n(n+1)²/4                               │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 15 — The "3-Second Sanity Check"**                  │
├─────────────────────────────────────────────────────────────┤
│ Before marking any answer:                                  │
│ ✔ Is the average BETWEEN the smallest and largest value?    │
│ ✔ For combined groups — is it closer to the bigger group?   │
│ ✔ For speed — is it LESS than (x+y)/2?                      │
│                                                             │
│ 🧠 Memory hook: *"If it fails the sanity check, it's a      │
│ trap option!"* — eliminates 2 wrong options instantly.      │
└─────────────────────────────────────────────────────────────┘
