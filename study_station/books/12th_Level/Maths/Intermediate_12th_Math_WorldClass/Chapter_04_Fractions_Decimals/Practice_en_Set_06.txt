126. How many positive integer solutions (x, y, z) with x <= y <= z satisfy the unit fraction equation 1/x + 1/y + 1/z = 1?
(a) 3 (b) 4 (c) 6 (d) 1
Answer: (a) 3
Solution: Since x <= y <= z, 3/x >= 1 => x <= 3. For x = 2, (y, z) = (3, 6) or (4, 4). For x = 3, (y, z) = (3, 3). Total solutions = 3. The required value is 3. Hence, the correct option is (a).
Source: SSC CGL Pattern

129. What is the sum of all fractions in the Farey sequence of order 5 strictly between 0 and 1?
(a) 4 (b) 5 (c) 11/2 (d) 9/2
Answer: (d) 9/2
Solution: Fractions pair symmetrically as p/q and (q-p)/q summing to 1. Pairs: (1/3, 2/3), (1/4, 3/4), (1/5, 4/5), (2/5, 3/5) plus 1/2. Sum = 4 + 0.5 = 9/2. The required value is 9/2. Hence, the correct option is (d).
Source: State PCS Pattern

130. How many total fractions are there in the Farey sequence of order 6 between 0 and 1, including both 0 and 1?
(a) 13 (b) 12 (c) 14 (d) 11
Answer: (a) 13
Solution: |F_6| = 1 + sum_{k=1}^6 phi(k) = 1 + (1 + 1 + 2 + 2 + 4 + 2) = 1 + 12 = 13 fractions. The required value is 13. Hence, the correct option is (a).

131. If 1/x + 1/y = 1/12 for positive integers x and y with x < y, how many pairs (x, y) exist?
(a) 8 (b) 7 (c) 15 (d) 6
Answer: (b) 7
Solution: (x - 12)(y - 12) = 144. 144 has 15 factors. Excluding x = y = 24 and taking x < y gives (15 - 1) / 2 = 7 pairs. The required value is 7. Hence, the correct option is (b).

Solution: 29 / 37 = (29 * 27) / (37 * 27) = 783 / 999 = 0.bar(783). Thus a = 7, b = 8, c = 3. Product = 7 * 8 * 3 = 168. The required value is 168. Hence, the correct option is (d).

134. Find the value of the infinite continued fraction x = 1 / (3 - 1 / (3 - 1 / (3 - ...))).

Answer: (a) (3 - sqrt(5))/2
Solution: x = 1 / (3 - x) => x^2 - 3x + 1 = 0. Since x < 1, the root is (3 - sqrt(5)) / 2. The required value is (3 - sqrt(5))/2. Hence, the correct option is (a).

143. A reduced proper fraction has denominator 140. If its decimal representation terminates, how many such distinct fractions exist?
(a) 19 (b) 8 (c) 10 (d) 4
Answer: (b) 8
Solution: For p/140 to terminate, p must be a multiple of 7: p = 7k. Then p/140 = k/20. For it to be reduced, gcd(k, 20) = 1. Number of values is phi(20) = 8. The required value is 8. Hence, the correct option is (b).
Source: SSC CGL Pattern
