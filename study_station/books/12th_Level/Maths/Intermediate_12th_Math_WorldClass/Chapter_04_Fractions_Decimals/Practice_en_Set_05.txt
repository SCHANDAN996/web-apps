Questions 101–125: Hard

101. Find the sum of the infinite decimal series S = 0.6 + 0.06 + 0.006 + 0.0006 + ...
(a) 2/3 (b) 3/5 (c) 6/11 (d) 7/10
Answer: (a) 2/3
Solution: S = 0.6666... = 0.bar(6) = 6/9 = 2/3. The required value is 2/3. Hence, the correct option is (a).
Source: SSC CGL Pattern

102. Evaluate: (0.bar(6) + 0.bar(7) + 0.bar(8)) / (0.bar(3) + 0.bar(4) + 0.bar(5)).
(a) 1.5 (b) 1.75 (c) 2.0 (d) 1.66
Answer: (b) 1.75
Solution: Numerator = (6 + 7 + 8)/9 = 21/9. Denominator = (3 + 4 + 5)/9 = 12/9. Ratio = 21 / 12 = 7/4 = 1.75. The required value is 1.75. Hence, the correct option is (b).

107. What is the maximum possible period length of the decimal expansion of 1/p, where p is a prime number other than 2 and 5?
(a) p (b) p + 1 (c) p - 1 (d) p/2
Answer: (c) p - 1
Solution: By Fermat's Little Theorem, 10^(p-1) = 1 (mod p), so the maximum period length is p - 1. The required value is p - 1. Hence, the correct option is (c).

112. A fraction p/q is such that adding 2 to its numerator yields 1/2, and adding 1 to its denominator yields 1/3. Find the sum (p + q).
(a) 18 (b) 20 (c) 21 (d) 19
Answer: (d) 19
Solution: 2p + 4 = q and 3p = q + 1. Solving gives p = 5, q = 14. Sum = 5 + 14 = 19. The required value is 19. Hence, the correct option is (d).

121. Find the sum of the infinite arithmetico-geometric series S = 1/10 + 2/10^2 + 3/10^3 + 4/10^4 + ...

Solution: S - (1/10)S = (9/10)S = 1/10 + 1/100 + ... = (1/10)/(9/10) = 1/9. Thus S = (1/9) * (10/9) = 10/81. The required value is 10/81. Hence, the correct option is (a).

122. If 0.bar(u v) + 0.bar(v u) = 1.bar(4) for decimal digits u and v, find the sum (u + v).

Solution: (u + v)/9 = 1.bar(4) = (14 - 1)/9 = 13/9. Thus u + v = 13. The required value is 13. Hence, the correct option is (b).

123. Find the positive value represented by the periodic continued fraction x = 1 + 1 / (2 + 1 / (1 + 1 / (2 + ...))).
(a) (sqrt(3) - 1)/2 (b) sqrt(3) (c) (1 + sqrt(3))/2 (d) 1 + sqrt(3)
Answer: (c) (1 + sqrt(3))/2
Solution: x = 1 + 1/(2 + 1/x) => 2x^2 - 2x - 1 = 0. The positive root is x = (1 + sqrt(3)) / 2. The required value is (1 + sqrt(3))/2. Hence, the correct option is (c).
Source: SSC CGL Pattern

124. How many pairs of positive integers (u, v) with u <= v satisfy the Diophantine equation 1/u + 1/v = 1/6?
(a) 9 (b) 6 (c) 4 (d) 5
Answer: (d) 5
Solution: (u - 6)(v - 6) = 36. For u <= v, (u - 6) takes the 5 factors of 36 that are <= 6: {1, 2, 3, 4, 6}, yielding exactly 5 pairs. The required value is 5. Hence, the correct option is (d).
Source: SSC CGL Pattern

125. If the decimal expansion of 1/n has a purely repeating period of length exactly 3, what is the smallest positive integer n > 1?
(a) 37 (b) 27 (c) 9 (d) 111
Answer: (b) 27
Solution: n must divide 10^3 - 1 = 999 = 27 * 37 without dividing 10^1 - 1 = 9. The smallest divisor of 999 with period 3 is 27 (1/27 = 0.bar(037)). The required value is 27. Hence, the correct option is (b).
Source: SSC CGL Pattern
