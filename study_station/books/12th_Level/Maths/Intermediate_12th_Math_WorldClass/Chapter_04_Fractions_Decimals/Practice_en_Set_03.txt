51. Find the value of sqrt(0.bar(4)).
(a) 0.bar(6) (b) 0.bar(2) (c) 0.2 (d) 0.4
Answer: (a) 0.bar(6)
Solution: 0.bar(4) = 4/9. Square root is sqrt(4/9) = 2/3 = 0.666... = 0.bar(6). The required value is 0.bar(6). Hence, the correct option is (a).
Source: SSC CGL Pattern

52. Find the value of sqrt(1.bar(7)).
(a) 1.bar(4) (b) 1.bar(3) (c) 1.3 (d) 1.25
Answer: (b) 1.bar(3)
Solution: 1.bar(7) = 1 + 7/9 = 16/9. Square root is sqrt(16/9) = 4/3 = 1.333... = 1.bar(3). The required value is 1.bar(3). Hence, the correct option is (b).
Source: SSC CGL Pattern

54. If a proper fraction satisfies x = p/q < 1 and k > 0, which inequality is always true?
(a) (p + k)/(q + k) < p/q (b) (p + k)/(q + k) = p/q (c) Depends on the value of k (d) (p + k)/(q + k) > p/q
Answer: (d) (p + k)/(q + k) > p/q
Solution: Adding equal positive amounts to numerator and denominator of a proper fraction always increases its value toward 1. The required value is (p + k)/(q + k) > p/q. Hence, the correct option is (d).

69. If 1/5 of a pencil is black, 1/2 of the remainder is white, and the remaining 3.5 cm is blue, find the total length of the pencil.

Answer: (c) 8.75 cm
Solution: Remainder after black = 4/5. Remainder after white = (1/2) * (4/5) = 2/5. (2/5)L = 3.5 => L = 3.5 * 5 / 2 = 8.75 cm. The required value is 8.75 cm. Hence, the correct option is (c).

74. A fraction becomes 1/2 when 1 is subtracted from its numerator, and becomes 1/3 when 8 is added to its denominator. Find the fraction in lowest terms.
(a) 4/7 (b) 5/8 (c) 7/12 (d) 3/5
Answer: (d) 3/5
Solution: (x - 1)/y = 1/2 => 2x - y = 2, and x/(y + 8) = 1/3 => 3x - y = 8. Solving gives x = 6, y = 10. Fraction is 6/10 = 3/5. The required value is 3/5. Hence, the correct option is (d).
Source: SSC CGL Pattern
