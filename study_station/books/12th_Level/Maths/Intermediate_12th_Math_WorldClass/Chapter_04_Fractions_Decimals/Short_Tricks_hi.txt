# 🪄 भिन्न और दशमलव — स्मृति-सहायक ट्रिक्स (Short Tricks)

---

**🎁 ट्रिक 1: "ऊपर अंश, नीचे हर" — उँगली-नाक ट्रिक**

```
┌─────────────────────────────────────┐
│ अंश (Numerator) = ऊपर वाला          │
│ हर (Denominator) = नीचे वाला        │
│                                     │
│ याद करो: "अंश ऊपर, हर नीचे —        │
│ जैसे आँख ऊपर, होंठ नीचे!" 👁️👄      │
│                                     │
│ अ = आँख = ऊपर | ह = होंठ = नीचे     │
└─────────────────────────────────────┘
```

---

**🎁 ट्रिक 2: भिन्न की तुलना — "क्रॉस-गुणा तीर" ✖️**

```
┌─────────────────────────────────────┐
│ a/b और c/d में कौन बड़ा?            │
│                                     │
│ तीर चलाओ: a×d ⚔️ c×b                │
│ जिस तरफ बड़ा गुणनफल, वही भिन्न बड़ी!│
│                                     │
│ मंत्र: "क्रॉस करो, बड़े को जिताओ"   │
│ जैसे: 3/4 vs 5/7                    │
│ 3×7=21 vs 5×4=20 → 3/4 बड़ी!        │
└─────────────────────────────────────┘
```

---

**🎁 ट्रिक 3: भिन्न का भाग — "पलटी मारो, गुणा करो" 🔄**

```
┌─────────────────────────────────────┐
│ भाग देखते ही: दूसरी भिन्न उल्टी,    │
│ चिन्ह गुणा का!                      │
│                                     │
│ (a/b) ÷ (c/d) = (a/b) × (d/c)       │
│                                     │
│ कहानी: "भाग डरावना है, तो दूसरी     │
│ भिन्न पलटी मारकर गुणा बन जाती है!"  │
│                                     │
│ एक्रोनिम: "प-ग" = पलटो-गुणा करो     │
└─────────────────────────────────────┘
```

---

**🎁 ट्रिक 4: दशमलव का गुणा — "अंक गिनो, पॉइंट रखो" 🔢**

```
┌─────────────────────────────────────┐
│ दशमलव गुणा में:                     │
│ 1) पहले बिना पॉइंट गुणा करो         │
│ 2) दोनों संख्याओं के दशमलव-स्थान    │
│    जोड़ो                            │
│ 3) उतने स्थान बाद पॉइंट लगाओ        │
│                                     │
│ मंत्र: "गुणा सीधा, पॉइंट गिनती"     │
│ 0.2 × 0.3 → 2×3=6, स्थान 1+1=2      │
│ → 0.06 ✅                           │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 5: 10, 100, 1000 से गुणा/भाग — "पॉइंट की सैर" 🚶**

```
┌─────────────────────────────────────┐
│ ×10, ×100 → पॉइंट दाएँ भागता है ➡️  │
│ ÷10, ÷100 → पॉइंट बाएँ भागता है ⬅️  │
│                                     │
│ शून्य जितने, कदम उतने!              │
│                                     │
│ याद करो: "गुणा = दौड़ दाएँ,         │
│ भाग = पीछे बाएँ"                    │
│ 4.567 × 100 = 456.7 (2 कदम दाएँ)    │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 6: सामान्य भिन्न-दशमलव — "आधा-चौथाई परिवार" 👨‍👩‍👧**

```
┌─────────────────────────────────────┐
│ रटो ये परिवार:                      │
│ 1/2 = 0.5  (आधा = पचास)             │
│ 1/4 = 0.25 (चौथाई = पच्चीस)         │
│ 3/4 = 0.75 (तीन-चौथाई = पचहत्तर)    │
│ 1/5 = 0.2  | 1/8 = 0.125            │
│                                     │
│ ट्रिक: "रुपये-पैसे सोचो!"           │
│ 1/4 रुपया = 25 पैसे = 0.25 💰       │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 7: 1/9 परिवार — "नौ का जादू" ✨**

```
┌─────────────────────────────────────┐
│ 1/9 = 0.111…  (1 की बारात)          │
│ 2/9 = 0.222…  (2 की बारात)          │
│ 5/9 = 0.555…                        │
│                                     │
│ नियम: ऊपर जो अंक, वही दशमलव में     │
│ बार-बार दौड़ता है!                  │
│                                     │
│ बोनस: 1/11 = 0.0909… (09 की जोड़ी)  │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 8: आवर्ती दशमलव → भिन्न — "9 का चश्मा" 👓**

```
┌─────────────────────────────────────┐
│ 0.777… = 7/9                        │
│ 0.232323… = 23/99                   │
│ 0.456456… = 456/999                 │
│                                     │
│ नियम: जितने अंक दोहराते हैं,        │
│ नीचे उतने 9 बैठा दो!                │
│                                     │
│ मंत्र: "दोहराव गिनो, नौ भरो"        │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 9: मिश्र आवर्ती — "9 और 0 की टीम" 🤝**

```
┌─────────────────────────────────────┐
│ 0.1666… = ?                         │
│                                     │
│ सूत्र: (पूरी संख्या − बिना-बार वाली)│
│ ÷ (बार अंकों के 9 + बिना-बार के 0)  │
│                                     │
│ 0.1666… = (16−1)/90 = 15/90 = 1/6   │
│                                     │
│ याद करो: "बार वाले को 9,            │
│ बिना-बार को 0 — टीम बन गई!"         │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 10: उचित/अनुचित भिन्न — "पेट भरा या उल्टा?" 🍽️**

```
┌─────────────────────────────────────┐
│ उचित भिन्न: अंश < हर (पेट छोटा,     │
│ ऊपर हल्का) → मान 1 से छोटा          │
│                                     │
│ अनुचित भिन्न: अंश ≥ हर (ऊपर मोटा!)  │
│ → मान 1 या उससे बड़ा                │
│                                     │
│ ट्रिक: "ऊपर मोटा = अनुचित,          │
│ नीचे मोटा = उचित"                   │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 11: भिन्नों का जोड़ — "हर भाई-भाई" 👬**

```
┌─────────────────────────────────────┐
│ हर समान → सीधे अंश जोड़ो            │
│ हर अलग → पहले LCM से हर बराबर करो   │
│                                     │
│ शॉर्टकट (2 भिन्न):                  │
│ a/b + c/d = (ad + bc)/(bd)          │
│                                     │
│ मंत्र: "क्रॉस जोड़ो, नीचे गुणा"     │
│ 1/2 + 1/3 = (3+2)/6 = 5/6 ✅        │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 12: दशमलव तुलना — "शून्य जोड़ो, बराबर करो" ⚖️**

```
┌─────────────────────────────────────┐
│ 0.5 vs 0.45 — कौन बड़ा?             │
│                                     │
│ दशमलव बाद अंक बराबर करो:            │
│ 0.50 vs 0.45 → 50 > 45 ✅           │
│                                     │
│ ट्रिक: "दाएँ शून्य जोड़ना मुफ़्त है, │
│ मान नहीं बदलता!"                    │
│ 0.5 = 0.50 = 0.500                  │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 13: प्रतिशत कनेक्शन — "100 का पुल" 🌉**

```
┌─────────────────────────────────────┐
│ भिन्न → प्रतिशत: ×100               │
│ दशमलव → प्रतिशत: पॉइंट 2 कदम दाएँ   │
│                                     │
│ 3/4 → 75%  |  0.6 → 60%             │
│                                     │
│ याद करो: "प्रतिशत पाने हर बार,      │
│ सौ से कर दो प्यार!" 💯              │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 14: लोकस विधि — "भिन्न-महल" 🏰**

```
┌─────────────────────────────────────┐
│ एक महल कल्पना करो:                  │
│                                     │
│ 🏰 छत = अंश (ऊपर)                   │
│ 🧱 नींव = हर (नीचे)                 │
│ 🚪 दरवाज़ा = भाग-चिन्ह (÷)          │
│ 🔄 लिफ्ट = पलटी (भाग → गुणा)        │
│                                     │
│ महल घूमते ही सारे नियम याद!         │
│ "छत हल्की, नींव मज़बूत = उचित महल"  │
└─────────────────────────────────────┘
```

**🎁 ट्रिक 15: परीक्षा-हॉल सुपर-ट्रिक — "1 से गुणा" ⚡**

```
┌─────────────────────────────────────┐
│ दो भिन्नों के बीच अंतर निकालना हो   │
│ या तुलना में दिमाग चकराए —          │
│                                     │
│ दोनों को दशमलव में बदलो:            │
│ भाग दो, तुरंत तुलना करो!            │
│                                     │
│ 7/8 = 0.875, 5/6 = 0.833…           │
│ → 7/8 बड़ी! ✅                      │
│                                     │
│ मंत्र: "शक हो तो भाग दे दो,         │
│ दशमलव सच बता देगा!"                 │
└─────────────────────────────────────┘
```
