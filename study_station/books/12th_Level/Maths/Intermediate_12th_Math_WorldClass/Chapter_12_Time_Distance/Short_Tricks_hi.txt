# 🪄 समय और दूरी — स्मृति-सहायक ट्रिक्स (Short Tricks)

---

**🎯 ट्रिक 1: "चाल-समय-दूरी का त्रिकोण" (DST Triangle)**

```
┌─────────────────────────────────────┐
│  एक त्रिकोण बनाओ: ऊपर D (दूरी),     │
│  नीचे S (चाल) और T (समय)।           │
│  जो छिपाना है, वही निकलेगा!          │
│  D = S × T,  S = D/T,  T = D/S      │
│  याद रखो: "दादा सोते टाइम पर" 😴    │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 2: km/h ↔ m/s का जादुई अंक "18"**

```
┌─────────────────────────────────────┐
│  km/h → m/s : × 5/18 (छोटा बनाना,   │
│  तो छोटा 5 ऊपर)                      │
│  m/s → km/h : × 18/5 (बड़ा बनाना,   │
│  तो बड़ा 18 ऊपर)                     │
│  मंत्र: "छोटे को 5, बड़े को 18" 🎩  │
└─────────────────────────────────────┘
```

**🎯 ट्रिक 3: औसत चाल — "समान दूरी = हार्मोनिक जुड़वाँ"**

```
┌─────────────────────────────────────┐
│  आने-जाने की दूरी बराबर हो तो:      │
│  औसत चाल = 2xy/(x+y)                │
│  याद रखो: "दो का गुणा, ऊपर-नीचे     │
│  जोड़" — 2 लड़के (x,y) गुणा में      │
│  ऊपर, जोड़ में नीचे! 👬              │
│  कभी (x+y)/2 मत लगाना — वो जाल है!  │
└─────────────────────────────────────┘
```

**🎯 ट्रिक 4: ट्रेन × खंभा = "सिर्फ़ अपनी लंबाई"**

```
┌─────────────────────────────────────┐
│  ट्रेन खंभा/आदमी पार करे →          │
│  दूरी = सिर्फ़ ट्रेन की लंबाई        │
│  ट्रेन पुल/प्लेटफॉर्म पार करे →     │
│  दूरी = ट्रेन + पुल की लंबाई         │
│  मंत्र: "खंभा पतला, पुल मोटा —      │
│  पतले को भूलो, मोटे को जोड़ो!" 🚂   │
└─────────────────────────────────────┘
```

**🎯 ट्रिक 5: दो ट्रेनें — "आमने-सामने जोड़ो, पीछा घटाओ"**

```
┌─────────────────────────────────────┐
│  विपरीत दिशा: चालें जुड़ती हैं       │
│  (S₁ + S₂) — दोनों मिलकर पार करतीं  │
│  समान दिशा: चालें घटती हैं           │
│  (S₁ − S₂) — पीछा करना मुश्किल!     │
│  लंबाई हमेशा जुड़ेगी (L₁ + L₂)       │
│  मंत्र: "दुश्मनी में तेज़ी,           │
│  दोस्ती में धीमी" ⚔️🤝              │
└─────────────────────────────────────┘
```

**🎯 ट्रिक 6: नाव-धारा — "B का नौका-विहार"**

```
┌─────────────────────────────────────┐
│  धारा के साथ (Downstream) = B + W   │
│  धारा के विपरीत (Upstream) = B − W  │
│  नाव की चाल B = (D + U)/2           │
│  धारा की चाल W = (D − U)/2          │
│  मंत्र: "बड़ा भाई B बीच में,         │
│  छोटा W घटकर आता है" 🚣             │
│  (D = साथ, U = विपरीत)              │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 7: देर-जल्दी वाला सवाल — "गुणा भाग अंतर"**

```
┌─────────────────────────────────────┐
│  चाल S₁ से t₁ देर, चाल S₂ से t₂     │
│  पहले पहुँचे, तो दूरी =             │
│  (S₁×S₂)/(S₂−S₁) × (t₁+t₂)          │
│  मंत्र: "चालों का गुणा, अंतर से      │
│  भाग, समय जुड़ जाता है" ⏰          │
│  (दोनों देर या दोनों जल्दी हो तो    │
│  समय का अंतर लें)                    │
└─────────────────────────────────────┘
```

**🎯 ट्रिक 8: चाल बदलने पर समय — "उल्टा खेल"**

```
┌─────────────────────────────────────┐
│  चाल a:b बदले → समय b:a हो जाता है  │
│  (चाल और समय उल्टे प्रेमी हैं 💔)   │
│  मंत्र: "चाल जितनी बढ़ाओ,            │
│  समय उतना ही उल्टा घटाओ"            │
│  जैसे: चाल 2:3 → समय 3:2            │
└─────────────────────────────────────┘
```

**🎯 ट्रिक 9: रेस (दौड़) — "स्टार्ट = हेडस्टार्ट"**

```
┌─────────────────────────────────────┐
│  "A, B को 10 मीटर की बढ़त देता है"  │
│  = B, 10 मीटर आगे से दौड़ता है       │
│  "A, B को 5 सेकंड से हराता है" =    │
│  B को 5 सेकंड और लगते हैं            │
│  मंत्र: "मीटर में बढ़त = जगह की,     │
│  सेकंड में बढ़त = वक़्त की" 🏃      │
└─────────────────────────────────────┘
```

**🎯 ट्रिक 10: गोलाकार ट्रैक — "LCM से मिलन"**

```
┌─────────────────────────────────────┐
│  दो धावक गोल घेरे में एक ही बिंदु    │
│  से समान दिशा में दौड़ें, तो पहली    │
│  मुलाकात = LCM(उनके एक-एक चक्कर     │
│  के समय)                             │
│  मंत्र: "गोल घेरा, LCM मेरा" 🔄     │
│  विपरीत दिशा में पहली भेंट =         │
│  ट्रैक ÷ (चालों का योग)              │
└─────────────────────────────────────┘
```

**🎯 ट्रिक 11: "आधी दूरी, आधे समय" वाला फर्क**

```
┌─────────────────────────────────────┐
│  आधी *दूरी* x से, आधी y से →        │
│  औसत = 2xy/(x+y)                    │
│  आधा *समय* x से, आधा y से →         │
│  औसत = (x+y)/2  (सीधा औसत!)         │
│  मंत्र: "दूरी में हार्मोनिक,          │
│  समय में साधारण" ⚖️                 │
└─────────────────────────────────────┘
```

**🎯 ट्रिक 12: बंदूक की आवाज़ / रोशनी वाला सवाल**

```
┌─────────────────────────────────────┐
│  गोली और आवाज़ में समय का अंतर हो,   │
│  तो दूरी = (V₁×V₂)/(V₁−V₂) × Δt     │
│  मंत्र: "तेज़-धीमे का गुणा,           │
│  अंतर से भाग, समय से गुणा" 🔫       │
│  (यही ट्रिक 7 का चचेरा भाई है!)      │
└─────────────────────────────────────┘
```

```
│  ज़्यादातर गलतियाँ इकाई बदलने        │

└─────────────────────────────────────┘
```
