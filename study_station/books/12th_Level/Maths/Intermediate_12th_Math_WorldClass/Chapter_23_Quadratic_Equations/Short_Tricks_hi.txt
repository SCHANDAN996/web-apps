# 🪄 शॉर्ट ट्रिक्स — द्विघात समीकरण एवं श्रेणी

---

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 1: मूलों का सूत्र — "माइनस बी वाला कुआँ"      │
├─────────────────────────────────────────────┤
│ मंत्र: **"बी उल्टा, जड़ में बी-स्क्वायर माइनस चार-ऐसी,   │
│ बटा दो-ए"**                                          │
│ x = [−b ± √(b² − 4ac)] / 2a                          │
│ याद रखें: कुएँ में उतरने से पहले b का निशान **उल्टा**     │
│ होता है — "कुएँ में बी पलट गया!"                        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 2: विविक्तकर (Discriminant) — "D है डॉक्टर"     │
├─────────────────────────────────────────────┤
│ D = b² − 4ac — यह मूलों का **डॉक्टर** है, रिपोर्ट देखकर  │
│ बताता है मूल कैसे हैं:                                  │
│ • D > 0 → दो अलग-अलग असली मूल (दो स्वस्थ मरीज़)          │
│ • D = 0 → दो बराबर मूल (जुड़वाँ मरीज़)                    │
│ • D < 0 → कोई वास्तविक मूल नहीं (मरीज़ ही नहीं!)          │
│ एक्रोनिम: **"बड़ा-दो, जीरो-जुड़वाँ, छोटा-खाली"**            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 3: मूलों का योग — "उल्टा बी, सीधा ए"           │
├─────────────────────────────────────────────┤
│ मूलों का योग = **−b/a**                                  │
│ मूलों का गुणनफल = **+c/a**                               │
│ म्नेमोनिक: **"योग में बी शर्माकर उल्टा (−) हो जाता है,    │
│ गुणन में सी (C) सीधा-सादा रहता है"**                     │
│ कीवर्ड: योग = उल्टा, गुणन = सीधा                         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 4: मूलों से समीकरण बनाना — "एक्स-स्क्वायर की    │
│ शादी"                                                  │
├─────────────────────────────────────────────┤
│ x² − (मूलों का योग)x + (मूलों का गुणनफल) = 0             │
│ म्नेमोनिक: **"शादी में योग घटता है, गुणन जुड़ता है"**      │
│ यानी: x² − (योग)x + (गुणन) = 0                           │
│ निशान याद रखें: **− +** (पहले माइनस, फिर प्लस)            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 5: गुणनखंड विधि — "गुणन c, जोड़ b"              │
├─────────────────────────────────────────────┤
│ x² + bx + c = 0 को तोड़ने के लिए ऐसी दो संख्याएँ खोजो:    │
│ **गुणनफल = c, योग = b**                                  │
│ म्नेमोनिक: **"गुणन में सी (C), जोड़ में बी (B)"**          │
│ उदाहरण: x² + 5x + 6 → 2 और 3 (गुणन 6, जोड़ 5) ✓          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 6: AP का nवाँ पद — "पहला पद प्लस सीढ़ियाँ"       │
├─────────────────────────────────────────────┤
│ Tₙ = a + (n − 1)d                                      │
│ म्नेमोनिक: **"पहली सीढ़ी पर खड़े होकर (n−1) सीढ़ियाँ चढ़ो"** │
│ ध्यान दें: n नहीं, **(n−1)** — क्योंकि पहला पद पहले से    │
│ मौजूद है! परीक्षा में यही सबसे बड़ा ट्रैप है।              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 7: AP का योग — "जोड़ी बनाओ, आधा करो"            │
├─────────────────────────────────────────────┤
│ Sₙ = n/2 × (पहला पद + आखिरी पद) = n/2 [2a + (n−1)d]      │
│ म्नेमोनिक: **"पहला + आखिरी, गुणा पद-संख्या, भाग दो"**      │
│ गॉस की कहानी याद करो: 1 से 100 तक का योग =               │
│ 100/2 × (1+100) = 50 × 101 = 5050                        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 8: AP में बीच का पद — "समान दूरी का राजा"        │
├─────────────────────────────────────────────┤
│ AP में किसी पद से समान दूरी पर स्थित दो पदों का योग       │
│ हमेशा बराबर होता है:                                     │
│ a₁ + aₙ = a₂ + aₙ₋₁ = a₃ + aₙ₋₂ = ...                    │
│ म्नेमोनिक: **"किनारे से अंदर चलो, जोड़ी का योग वही"**      │
│ उपयोग: योग निकालने में सीधे Sₙ = n/2 × (कोई भी जोड़ी)     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 9: GP का nवाँ पद — "गुणा की सीढ़ी"              │
├─────────────────────────────────────────────┤
│ Tₙ = a × rⁿ⁻¹                                          │
│ म्नेमोनिक: **"AP में जोड़, GP में गुणा — दोनों में (n−1)"**  │
│ कीवर्ड: AP = Arithmetic = Add | GP = Geometric = गुणा    │
│ **"A मतलब Add, G मतलब गुणा"**                            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 10: GP का योग — "r की ताकत माइनस एक"            │
├─────────────────────────────────────────────┤
│ Sₙ = a(rⁿ − 1)/(r − 1)  [जब r > 1]                       │
│ Sₙ = a(1 − rⁿ)/(1 − r)  [जब r < 1]                       │
│ म्नेमोनिक: **"ऊपर जो, नीचे वही — दोनों से एक घटाओ"**       │
│ (ऊपर rⁿ − 1, नीचे r − 1 — निशान एक जैसे रखो!)            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 11: अनंत GP — "एक बटा एक माइनस आर"              │
├─────────────────────────────────────────────┤
│ S∞ = a/(1 − r),  केवल जब |r| < 1                         │
│ म्नेमोनिक: **"अनंत तब तक, जब तक आर छोटा"**               │
│ याद रखें: r ≥ 1 हो तो योग अनंत हो जाता है — सवाल ही       │
│ खत्म! परीक्षक r = 2 देकर धोखा देता है।                    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 12: AM-GM — "जोड़ का भाई, गुणा से बड़ा"          │
├─────────────────────────────────────────────┤
│ दो धनात्मक संख्याओं के लिए: AM ≥ GM                      │
│ (a+b)/2 ≥ √(ab)                                          │
│ म्नेमोनिक: **"Arithmetic हमेशा Geometric से बड़ा या       │
│ बराबर — A आता है G से पहले, इसलिए आगे रहता है!"**         │
│ बराबरी कब? जब दोनों संख्याएँ बराबर हों।                     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 13: तीन पद AP में — "बीच वाला औसत"              │
├─────────────────────────────────────────────┤
│ तीन संख्याएँ AP में हों तो: बीच वाली = (पहली + तीसरी)/2   │
│ यानी 2b = a + c                                          │
│ म्नेमोनिक: **"बीच वाला बिचौलिया — दोनों का औसत"**         │
│ तीन पद मानने की ट्रिक: **a − d, a, a + d** लो —           │
│ योग तुरंत 3a हो जाता है, हल आसान!                        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 14: तीन पद GP में — "बीच वाला ज्यामितीय औसत"     │
├─────────────────────────────────────────────┤
│ तीन संख्याएँ GP में हों तो: b² = ac                      │
│ म्नेमोनिक: **"GP में बीच का वर्ग = किनारों का गुणन"**      │
│ तीन पद मानने की ट्रिक: **a/r, a, ar** लो —                │
│ गुणनफल तुरंत a³ हो जाता है!                               │
│ जोड़ी याद रखें: AP में (a−d, a, a+d) | GP में (a/r, a, ar) │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 15: प्राकृत संख्याओं के योग — "1-2-3 की त्रिकोणी │
│ सेना"                                                  │
├─────────────────────────────────────────────┤
│ • 1+2+3+...+n = n(n+1)/2                                 │
│ • 1²+2²+...+n² = n(n+1)(2n+1)/6                          │
│ • 1³+2³+...+n³ = [n(n+1)/2]²                             │
│ म्नेमोनिक: **"घन का योग = साधारण योग का वर्ग!"**          │
│ (तीसरा सूत्र पहले का ही वर्ग है — दो याद करो, तीसरा फ्री!) │
└─────────────────────────────────────────────┘

---

💡 **अंतिम गुरुमंत्र:** द्विघात में **"D डॉक्टर"** और श्रेणी में **"A मतलब Add, G मतलब गुणा"** — ये दो ट्रिक्स अकेले आधे अध्याय को संभाल लेती हैं। 2 दिन बाद इन्हें ज़रूर दोहराएँ!
