# 📋 महत्वपूर्ण सूत्र — द्विघात समीकरण एवं श्रेणी

## 1. द्विघात समीकरण (Quadratic Equations)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| मानक रूप | ax² + bx + c = 0 (a ≠ 0) | हर द्विघात समीकरण को पहले इस रूप में लाएँ |
| मूलों का सूत्र (श्रीधराचार्य) | x = [−b ± √(b² − 4ac)] / 2a | जब गुणनखंड संभव न हो |
| विविक्तकर (Discriminant) | D = b² − 4ac | मूलों की प्रकृति जाँचने के लिए |
| मूलों की प्रकृति | D > 0 → दो भिन्न वास्तविक मूल; D = 0 → दो बराबर मूल; D < 0 → कोई वास्तविक मूल नहीं | बिना हल किए मूलों का स्वभाव बताने के लिए |
| मूलों का योग | α + β = −b/a | मूल ज्ञात किए बिना योग निकालने के लिए |
| मूलों का गुणनफल | αβ = c/a | मूल ज्ञात किए बिना गुणनफल निकालने के लिए |
| मूलों से समीकरण बनाना | x² − (α + β)x + αβ = 0 | मूल दिए हों तो समीकरण बनाने के लिए |
| मूलों का अंतर | \|α − β\| = √D / \|a\| | मूलों के बीच का अंतर निकालने के लिए (a ऋणात्मक होने पर भी \|a\| लें) |
| α² + β² | (α + β)² − 2αβ | मूलों के वर्गों का योग |
| α³ + β³ | (α + β)³ − 3αβ(α + β) | मूलों के घनों का योग |
| 1/α + 1/β | (α + β) / αβ | मूलों के व्युत्क्रमों का योग |
| उभयनिष्ठ मूल की शर्त (एक मूल समान) | (c₁a₂ − c₂a₁)² = (b₁c₂ − b₂c₁)(a₁b₂ − a₂b₁) | दो समीकरणों में एक मूल उभयनिष्ठ हो तो |
| न्यूनतम/अधिकतम मान (a > 0 न्यूनतम, a < 0 अधिकतम) | x = −b/2a पर, मान = (4ac − b²)/4a | द्विघात व्यंजक का चरम मान |

## 2. समांतर श्रेणी (Arithmetic Progression — AP)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| nवाँ पद | aₙ = a + (n − 1)d | कोई भी पद सीधे निकालने के लिए |
| सार्व अंतर | d = a₂ − a₁ | श्रेणी AP है या नहीं, जाँचने के लिए |
| प्रथम n पदों का योग | Sₙ = n/2 [2a + (n − 1)d] | जब अंतिम पद ज्ञात न हो |
| योग (अंतिम पद ज्ञात हो) | Sₙ = n/2 (a + l) | जब प्रथम और अंतिम पद दिए हों |
| nवाँ पद (योग से) | aₙ = Sₙ − Sₙ₋₁ | योग दिया हो तो पद निकालने के लिए |
| समांतर माध्य | A = (a + b)/2 | दो संख्याओं के बीच समांतर माध्य |
| तीन पद मानना | a − d, a, a + d | तीन क्रमागत पदों वाले प्रश्नों में |
| चार पद मानना | a − 3d, a − d, a + d, a + 3d | चार क्रमागत पदों वाले प्रश्नों में |
| 1 से n तक प्राकृत संख्याओं का योग | n(n + 1)/2 | लगातार संख्याओं का योग |
| प्रथम n वर्गों का योग | n(n + 1)(2n + 1)/6 | 1² + 2² + … + n² |
| प्रथम n घनों का योग | [n(n + 1)/2]² | 1³ + 2³ + … + n³ |

## 3. गुणोत्तर श्रेणी (Geometric Progression — GP)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| nवाँ पद | aₙ = a·rⁿ⁻¹ | कोई भी पद निकालने के लिए |
| सार्व अनुपात | r = a₂/a₁ | श्रेणी GP है या नहीं, जाँचने के लिए |
| n पदों का योग (r ≠ 1) | Sₙ = a(rⁿ − 1)/(r − 1), r > 1; Sₙ = a(1 − rⁿ)/(1 − r), r < 1 | सीमित पदों का योग |
| अनंत पदों का योग (\|r\| < 1) | S∞ = a/(1 − r) | अनंत श्रेणी का योग |
| गुणोत्तर माध्य | G = √(ab) | दो संख्याओं के बीच गुणोत्तर माध्य |
| तीन पद मानना | a/r, a, ar | तीन क्रमागत पदों वाले प्रश्नों में |
| n पदों का गुणनफल | Pₙ = aⁿ·rⁿ⁽ⁿ⁻¹⁾/² = (a·aₙ)^(n/2) | पदों के गुणनफल वाले प्रश्नों में |

## 4. हरात्मक श्रेणी एवं अन्य (HP & Misc.)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| हरात्मक माध्य | H = 2ab/(a + b) | दो संख्याओं के बीच हरात्मक माध्य |
| AM–GM–HM संबंध | AM ≥ GM ≥ HM तथा G² = A × H | माध्यों की तुलना वाले प्रश्नों में |
| HP का nवाँ पद | संगत AP के nवें पद का व्युत्क्रम | HP के प्रश्न AP में बदलकर हल करें |
| विषम संख्याओं का योग | 1 + 3 + 5 + … (n पद) = n² | क्रमागत विषम संख्याओं का योग |
| सम संख्याओं का योग | 2 + 4 + 6 + … (n पद) = n(n + 1) | क्रमागत सम संख्याओं का योग |
| अंकगणित-गुणोत्तर श्रेणी (AGP) | S∞ = a/(1 − r) + dr/(1 − r)² (\|r\| < 1) | a + (a+d)r + (a+2d)r² + … का योग |
