126. The roots of the equation x² − (√3 + 1)x + √3 = 0 are 1 and √3. What is the sum of the squares of the roots?
(a) 2 (b) 4 (c) 3 (d) 5
Answer: (b)
Solution: Factoring gives (x − 1)(x − √3) = 0, so the roots are 1 and √3. The tempting wrong choice is 2√3, obtained by wrongly squaring the sum of roots instead of summing the squares. Sum of squares = 1² + (√3)² = 1 + 3, so the answer is 4.

127. If α and β are the roots of 2x² − 5x + 3 = 0, then the value of α² + β² is:
(a) 25/4 (b) 13/4 (c) 3/2 (d) 5/2
Answer: (b)
Solution: Sum of roots α + β = 5/2 and product αβ = 3/2. The trap is 25/4, which is just (α + β)² without subtracting 2αβ. α² + β² = (α + β)² − 2αβ = 25/4 − 3 = 13/4, so the answer is 13/4.

128. For which value(s) of k does the equation (k + 1)x² − 2(k − 1)x + 1 = 0 have equal roots?
(a) k = 1 only (b) k = 3 only (c) k = 0 or k = 3 (d) k = −1 only
Answer: (c)
Solution: For equal roots, discriminant = 0: 4(k − 1)² − 4(k + 1) = 0, giving k² − 3k = 0, so k(k − 3) = 0. The trap is choosing k = 3 only and forgetting that k = 0 also satisfies the equation (it gives x² + 2x + 1 = 0, a perfect square). Hence k = 0 or k = 3, so the answer is k = 0 or k = 3.

129. The sum of the first n odd natural numbers is 441. The value of n is:
(a) 19 (b) 20 (c) 22 (d) 21
Answer: (d)
Solution: The sum of the first n odd numbers is n², so n² = 441. The trap is taking n = 441/2 ≈ 220 or mis-remembering the formula as n(n+1). Since √441 = 21, the answer is 21.

132. The sum of the infinite series 4 + 4/3 + 4/9 + … is:
(a) 6 (b) 5 (c) 8 (d) 12
Answer: (a)
Solution: Here a = 4 and r = 1/3, so S = a/(1 − r) = 4/(2/3). The trap is using a/(1 + r) = 3, which applies to alternating signs. S = 4 × 3/2, so the answer is 6.

133. If the roots of x² − px + q = 0 differ by 1, then:
(a) p² − 4q = 1 (b) p² + 4q = 1 (c) q² − 4p = 1 (d) p² − 2q = 1
Answer: (a)
Solution: (α − β)² = (α + β)² − 4αβ = p² − 4q. Since the roots differ by 1, (α − β)² = 1. The trap is writing p² + 4q by mishandling the sign of the product term. Hence p² − 4q = 1, so the answer is p² − 4q = 1.

134. If x + 1/x = 4, then the value of x³ + 1/x³ is:

135. The quadratic equation whose roots are 2 + √3 and 2 − √3 is:
(a) x² − 4x − 1 = 0 (b) x² + 4x + 1 = 0 (c) x² − 4x + 1 = 0 (d) x² − 4x + 7 = 0
Answer: (c)
Solution: Sum of roots = 4, product = (2 + √3)(2 − √3) = 4 − 3 = 1. The trap is product = 7, obtained by adding 4 + 3 instead of using the difference of squares. Equation: x² − (sum)x + product = 0, so the answer is x² − 4x + 1 = 0.

139. The nature of the roots of 3x² − 4x + 2 = 0 is:

Answer: (b)
Solution: x² − 5x + 6 = (x − 2)(x − 3) < 0 holds when one factor is positive and the other negative, i.e. between the roots. The trap is "x < 2 or x > 3", which is the solution of the greater-than inequality. Strict inequality excludes endpoints, so the answer is 2 < x < 3.
