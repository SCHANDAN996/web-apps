1. What is the value of sin 30°?
(a) 1/√2 (b) √3/2 (c) 1/2 (d) 1
Answer: (c)
Solution: The standard value of sin 30° is 1/2. Many students confuse it with cos 30° = √3/2, but sine increases from 0 to 1 as the angle goes from 0° to 90°, and at 30° it is exactly 1/2. So the answer is 1/2.
Source: NCERT Class 10 Mathematics

2. What is the value of cos 60°?
(a) √3/2 (b) 1/2 (c) 1 (d) 0
Answer: (b)
Solution: cos 60° = 1/2. The tempting option √3/2 is actually sin 60°, not cos 60°. Remember that cos 60° equals sin 30°, both being 1/2. So the answer is 1/2.
Source: NCERT Class 10 Mathematics

3. What is the value of tan 45°?
(a) 1 (b) 1/√3 (c) 0 (d) √3
Answer: (a)
Solution: tan 45° = sin 45°/cos 45° = (1/√2)/(1/√2) = 1. The option 1/√3 is tan 30°, a common mix-up. So the answer is 1.
Source: NCERT Class 10 Mathematics

4. What is the value of sin²θ + cos²θ for any angle θ?
(a) 0 (b) 2 (c) 1 (d) Depends on θ
Answer: (c)
Solution: This is the fundamental Pythagorean identity: sin²θ + cos²θ = 1 for every angle θ. It never depends on the value of θ, so the last option is a trap. So the answer is 1.
Source: NCERT Class 10 Mathematics

5. If sin A = 1/2 and A is acute, what is the value of A?
(a) 60° (b) 30° (c) 45° (d) 90°
Answer: (b)
Solution: sin 30° = 1/2, so A = 30°. The trap is 60°, because cos 60° is also 1/2 — but the question asks about sine, not cosine. So the answer is 30°.
Source: NCERT Class 10 Mathematics

6. What is the value of cos 0°?
(a) 0 (b) 1/2 (c) 1 (d) √3/2
Answer: (c)
Solution: cos 0° = 1, since cosine starts at its maximum value 1 at 0° and decreases to 0 at 90°. Students often swap this with sin 0° = 0. So the answer is 1.

7. What is the value of sin 90°?
(a) 1 (b) 0 (c) 1/2 (d) √3/2
Answer: (a)
Solution: sin 90° = 1, the maximum value of sine. The option 0 is cos 90°, a frequent confusion. So the answer is 1.

8. What is the value of tan 60°?
(a) √3 (b) 1/√3 (c) 1 (d) Not defined
Answer: (a)
Solution: tan 60° = sin 60°/cos 60° = (√3/2)/(1/2) = √3. The option 1/√3 is tan 30°, its reciprocal — a classic trap. So the answer is √3.
Source: NCERT Class 10 Mathematics

9. If tan θ = 1, what is the value of θ (acute)?
(a) 30° (b) 90° (c) 60° (d) 45°
Answer: (d)
Solution: tan 45° = 1, so θ = 45°. Only at 45° are sine and cosine equal, making their ratio 1. So the answer is 45°.
Source: NCERT Class 10 Mathematics

10. What is the value of sec²θ − tan²θ?
(a) 1 (b) 0 (c) 2 (d) −1
Answer: (a)
Solution: From the identity 1 + tan²θ = sec²θ, we get sec²θ − tan²θ = 1. The option 0 tempts students who think the two terms cancel, but they are not equal. So the answer is 1.
Source: NCERT Class 10 Mathematics

11. What is the value of cosec²θ − cot²θ?
(a) 2 (b) 0 (c) −1 (d) 1
Answer: (d)
Solution: From the identity 1 + cot²θ = cosec²θ, we get cosec²θ − cot²θ = 1. Do not confuse the sign: cosec²θ − cot²θ = 1, not −1. So the answer is 1.
Source: NCERT Class 10 Mathematics

12. What is the value of sin 60°?
(a) √3/2 (b) 1/√2 (c) 1/2 (d) 1
Answer: (a)
Solution: sin 60° = √3/2. The option 1/2 is cos 60°, the complementary value — a very common swap. So the answer is √3/2.

13. What is the value of cos 30°?
(a) 1/2 (b) 1/√2 (c) √3/2 (d) 0
Answer: (c)
Solution: cos 30° = √3/2. Since cos 30° = sin 60°, both equal √3/2. The option 1/2 is sin 30°, the trap. So the answer is √3/2.

14. What is the value of tan 30°?
(a) √3 (b) 1 (c) 1/√3 (d) 1/2
Answer: (c)
Solution: tan 30° = sin 30°/cos 30° = (1/2)/(√3/2) = 1/√3. The option √3 is tan 60°, its reciprocal. So the answer is 1/√3.

15. What is the value of sin 0°?
(a) 1 (b) Not defined (c) 1/2 (d) 0
Answer: (d)
Solution: sin 0° = 0, since sine starts at 0 and rises to 1 at 90°. The option 1 is cos 0°, a common confusion. So the answer is 0.

16. What is the value of cos 90°?
(a) 1 (b) 1/2 (c) √3/2 (d) 0
Answer: (d)
Solution: cos 90° = 0, since cosine falls from 1 at 0° to 0 at 90°. The option 1 is sin 90°, the usual mix-up. So the answer is 0.

17. If sin θ = cos θ and θ is acute, what is θ?
(a) 30° (b) 60° (c) 45° (d) 90°
Answer: (c)
Solution: sin θ = cos θ means tan θ = 1, so θ = 45°. Only at 45° do sine and cosine take the same value 1/√2. So the answer is 45°.
Source: NCERT Class 10 Mathematics

18. What is the value of 2 sin 30° cos 30°?
(a) 1/2 (b) √3/2 (c) 1 (d) √3
Answer: (b)
Solution: 2 sin 30° cos 30° = 2 × (1/2) × (√3/2) = √3/2. Alternatively, 2 sin A cos A = sin 2A = sin 60° = √3/2. The option 1/2 comes from forgetting to multiply by cos 30°. So the answer is √3/2.
Source: NCERT Class 10 Mathematics

19. What is the value of sin 45° + cos 45°?
(a) 1 (b) 1/√2 (c) 2 (d) √2
Answer: (d)
Solution: sin 45° + cos 45° = 1/√2 + 1/√2 = 2/√2 = √2. The trap is 1, which is the value of sin²45° + cos²45°, not the plain sum. So the answer is √2.
Source: NCERT Class 10 Mathematics

20. What is the value of tan 90°?
(a) 0 (b) Not defined (c) √3 (d) 1
Answer: (b)
Solution: tan 90° = sin 90°/cos 90° = 1/0, which is not defined. Students who think of tan as always finite pick 1 or √3, but division by zero makes it undefined. So the answer is "Not defined".
Source: NCERT Class 10 Mathematics

21. If sin θ = 3/5, what is the value of cos θ (θ acute)?
(a) 4/5 (b) 3/4 (c) 5/4 (d) 2/5
Answer: (a)
Solution: Using sin²θ + cos²θ = 1: cos²θ = 1 − 9/25 = 16/25, so cos θ = 4/5 (positive since θ is acute). The option 3/4 is tan θ, a tempting mix-up of ratios. So the answer is 4/5.
Source: NCERT Class 10 Mathematics

22. If tan θ = 3/4, what is the value of (sin θ + cos θ)?
(a) 5/7 (b) 7/5 (c) 1 (d) 7/25
Answer: (b)
Solution: tan θ = 3/4 gives a 3-4-5 triangle, so sin θ = 3/5 and cos θ = 4/5. Then sin θ + cos θ = 3/5 + 4/5 = 7/5. The option 5/7 is the reciprocal, a careless slip. So the answer is 7/5.
Source: NCERT Class 10 Mathematics

23. What is the value of (sin 60° cos 30° + cos 60° sin 30°)?
(a) 1/2 (b) √3/2 (c) 0 (d) 1
Answer: (d)
Solution: This is sin(A + B) with A = 60°, B = 30°, so it equals sin 90° = 1. Direct check: (√3/2)(√3/2) + (1/2)(1/2) = 3/4 + 1/4 = 1. So the answer is 1.
Source: NCERT Class 10 Mathematics

24. If cosec θ = 2 and θ is acute, what is the value of cot θ?
(a) 1/2 (b) √3 (c) 1/√3 (d) 2
Answer: (b)
Solution: cosec θ = 2 means sin θ = 1/2, so θ = 30°. Then cot 30° = cos 30°/sin 30° = (√3/2)/(1/2) = √3. The option 1/√3 is tan 30°, not cot 30°. So the answer is √3.
Source: NCERT Class 10 Mathematics

25. What is the value of (1 + tan²45°)/(1 + cot²45°)?
(a) 1 (b) 2 (c) 1/2 (d) 4
Answer: (a)
Solution: tan 45° = cot 45° = 1, so the expression is (1 + 1)/(1 + 1) = 2/2 = 1. The option 2 tempts those who only compute the numerator and forget the denominator. So the answer is 1.
Source: NCERT Class 10 Mathematics
