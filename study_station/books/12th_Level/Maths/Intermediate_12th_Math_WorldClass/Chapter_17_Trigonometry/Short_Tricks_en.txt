## 🎯 Trick 3: The 0-1-2-3-4 Finger Table (sin values)

```
┌─────────────────────────────────────────────┐
│  Angle:   0°    30°    45°    60°    90°    │
│  Number:  0     1      2      3      4      │
│                                             │
│  sin θ = √(number)/2                        │
│                                             │
│  sin 0°  = √0/2 = 0                         │
│  sin 30° = √1/2 = 1/2                       │
│  sin 45° = √2/2 = 1/√2                      │
│  sin 60° = √3/2                             │
│  sin 90° = √4/2 = 1                         │
│                                             │
│  cos = same table READ BACKWARDS!           │
│  tan = sin ÷ cos                            │
└─────────────────────────────────────────────┘
```
**Use:** Never memorize the value table again — just count 0,1,2,3,4 and take √n/2.

│  → Sin SHARES: mixes with everyone          │
│    (sign stays SAME: + gives +)             │
│                                             │
│  cos(A + B) = cosA·cosB − sinA·sinB         │
│  → Cos is SELFISH: keeps own kind together  │
│    (sign FLIPS: + gives −)                  │
│                                             │
│  Hook: "Sin mixes happily,                  │
│         Cos flips the sign!"                │
└─────────────────────────────────────────────┘
```
**Use:** Never confuse the ± signs in expansion formulas again.

│                                             │
│  cos 2θ = cos²θ − sin²θ                     │
│         = 2cos²θ − 1                        │

│  ("Cos has THREE disguises — pick any!")    │
│                                             │

│  ("Tan divides by 1 minus its square")      │
└─────────────────────────────────────────────┘
```
**Use:** In cos 2θ questions, choose the disguise that matches the given data (only sin given? use 1 − 2sin²θ).

```

│  ("Sin and Cos live in a CAGE from −1 to 1")│
│                                             │
│  tan θ and cot θ → any value (−∞ to +∞)     │
│  sec θ and cosec θ → NEVER between −1 and 1 │
│  ("Bodyguards stay OUTSIDE the cage")       │
│                                             │
│  a sin θ + b cos θ → max = √(a² + b²),      │
│                      min = −√(a² + b²)      │
└─────────────────────────────────────────────┘
```
**Use:** "Max value of 3 sin θ + 4 cos θ?" → √(9+16) = 5. Two seconds, no working.
