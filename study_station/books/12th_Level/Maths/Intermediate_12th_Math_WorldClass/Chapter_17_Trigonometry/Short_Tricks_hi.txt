# 🪄 त्रिकोणमिति की शॉर्ट ट्रिक्स (Short Tricks)

---

## ट्रिक 1: "पंडित बद्री प्रसाद हर हर बोले" — sin, cos, tan का जादू

```
┌─────────────────────────────────────────────┐
│  पंडित बद्री प्रसाद, हर हर बोले,            │
│  सोना चांदी तोले!                           │
│                                             │
│  sin θ = लंब/कर्ण   → पंडित/हर             │
│  cos θ = आधार/कर्ण  → बद्री/हर             │
│  tan θ = लंब/आधार   → प्रसाद/बोले          │
└─────────────────────────────────────────────┘
```
**कैसे याद रखें:** पहले अक्षर देखो — ल/क, आ/क, ल/आ। "पंडित बद्री प्रसाद हर हर बोले" बोलते ही तीनों अनुपात याद!

## ट्रिक 2: "All Students Take Coffee" — चतुर्थांशों में चिह्न

```
┌─────────────────────────────────────────────┐
│  चतुर्थांश:   I      II     III    IV       │
│  याद रखो:    All   Students Take Coffee     │
│                                             │
│  I   → सभी + (All)                          │
│  II  → केवल sin + (Students)                │
│  III → केवल tan + (Take)                    │
│  IV  → केवल cos + (Coffee)                  │
└─────────────────────────────────────────────┘
```
**ट्रैप अलर्ट:** जहाँ sin धनात्मक है वहाँ cosec भी, जहाँ cos वहाँ sec, जहाँ tan वहाँ cot — जोड़े में याद रखो!

## ट्रिक 3: "0, 1, 2, 3, 4 की जड़ें" — sin की मान-तालिका 5 सेकंड में

```
┌─────────────────────────────────────────────┐
│  sin 0°, 30°, 45°, 60°, 90°                 │
│                                             │
│  = √(0/4), √(1/4), √(2/4), √(3/4), √(4/4)  │
│  = 0, 1/2, 1/√2, √3/2, 1                    │
│                                             │
│  cos = उल्टा क्रम (4,3,2,1,0)               │
│  tan = sin ÷ cos                            │
└─────────────────────────────────────────────┘
```
**जादू:** अंगुलियों पर 0 से 4 गिनो, 4 से भाग दो, वर्गमूल लो — तालिका तैयार!

## ट्रिक 4: "हथेली की अंगुलियाँ" — बिना कॉपी के मान निकालो

```
┌─────────────────────────────────────────────┐
│  बाईं हथेली खोलो:                           │
│  छोटी उंगली=0°, अंगूठा=90°, बीच में        │
│  30°, 45°, 60°                              │
│                                             │
│  sin निकालना हो → उस उंगली के नीचे की       │
│  उंगलियाँ गिनो → √n/2                       │
│  cos निकालना हो → ऊपर की उंगलियाँ गिनो     │
└─────────────────────────────────────────────┘
```
**उदाहरण:** sin 30° → छोटी उंगली के नीचे 0 उंगलियाँ? नहीं — 30° वाली उंगली मोड़ो, नीचे 1 उंगली → √1/2 = 1/2 ✔

## ट्रिक 5: "SC² का परिवार" — तीन मूल सर्वसमिकाएँ

```
┌─────────────────────────────────────────────┐
│  sin²θ + cos²θ = 1        (मूल)             │
│  1 + tan²θ = sec²θ        (÷ cos²θ)         │
│  1 + cot²θ = cosec²θ      (÷ sin²θ)         │
│                                             │
│  ट्रिक: "एक के साथ tan-sec, cot-cosec       │
│  जुड़े रहते हैं"                             │
└─────────────────────────────────────────────┘
```
**याद रखें:** tan का साथी sec, cot का साथी cosec — "T-S जोड़ी, C-C जोड़ी"।

---

## ट्रिक 6: "90° पर नाम बदल जाता है" — पूरक कोण

```
┌─────────────────────────────────────────────┐
│  sin(90°−θ) = cos θ                         │
│  tan(90°−θ) = cot θ                         │
│  sec(90°−θ) = cosec θ                       │
│                                             │
│  ट्रिक: "90° आते ही 'को' लग जाता है"        │
│  sin→cos, tan→cot, sec→cosec                │
└─────────────────────────────────────────────┘
```
**जाँच:** sin(90°−30°) = sin 60° = √3/2 = cos 30° ✔

## ट्रिक 7: "ऊँचाई-दूरी में tan ही राजा"

```
┌─────────────────────────────────────────────┐
│  उन्नयन कोण (Angle of Elevation) के सवालों  │
│  में 90% बार tan θ लगता है:                 │
│                                             │
│  tan θ = ऊँचाई / दूरी                      │
│                                             │
│  ट्रिक: "ऊपर देखो तो tan लगाओ,              │
│  ऊँचाई ऊपर, दूरी नीचे"                      │
└─────────────────────────────────────────────┘
```
**याद रखें:** अवनमन कोण (Depression) में भी वही tan — क्षैतिज रेखा से नीचे देखना।

## ट्रिक 8: "30-60-90 का अनुपात 1 : √3 : 2"

```
┌─────────────────────────────────────────────┐
│  30°-60°-90° त्रिभुज की भुजाएँ:              │
│  30° के सामने = 1 (सबसे छोटी)              │
│  60° के सामने = √3                          │
│  90° के सामने = 2 (कर्ण)                    │
│                                             │
│  ट्रिक: "छोटा कोण, छोटी भुजा —              │
│  1, √3, 2 की सीढ़ी"                         │
└─────────────────────────────────────────────┘
```
**उपयोग:** कर्ण 10 है और कोण 30°? तो सामने की भुजा = 5, आधार = 5√3 — बिना सूत्र के!

## ट्रिक 9: "45-45-90 = 1 : 1 : √2"

```
┌─────────────────────────────────────────────┐
│  समद्विबाहु समकोण त्रिभुज:                  │
│  दोनों लंब-आधार बराबर = 1, 1               │
│  कर्ण = √2                                  │
│                                             │
│  ट्रिक: "45-45 में जुड़वाँ भुजाएँ,           │
│  कर्ण में √2 का तड़का"                      │
└─────────────────────────────────────────────┘
```
**उपयोग:** sin 45° = 1/√2 — सीधे अनुपात से!

## ट्रिक 10: "sin बढ़ता है, cos घटता है" — 0° से 90° तक

```
┌─────────────────────────────────────────────┐
│  0° → 90°:                                  │
│  sin: 0 → 1 (बढ़ता ↗)                       │
│  cos: 1 → 0 (घटता ↘)                        │
│  tan: 0 → ∞ (रॉकेट 🚀)                      │
│                                             │
│  ट्रिक: "sin सीढ़ी चढ़ता है,                │
│  cos उतरता है, tan उड़ जाता है"             │
└─────────────────────────────────────────────┘
```
**ट्रैप अलर्ट:** tan 90° = अपरिभाषित (कर्ण नहीं, आधार 0 हो जाता है)!

## ट्रिक 11: "धनात्मक-ऋणात्मक का घड़ी-नियम"

```
┌─────────────────────────────────────────────┐
│  sin(−θ) = −sin θ    (विषम फलन)             │
│  cos(−θ) = +cos θ    (सम फलन)               │
│  tan(−θ) = −tan θ                           │
│                                             │
│  ट्रिक: "cos है दयालु — माइनस को            │
│  माफ़ कर देता है"                           │
└─────────────────────────────────────────────┘
```
**याद रखें:** तीनों में से केवल cos ऋणात्मक कोण को धनात्मक बना देता है।

## ट्रिक 12: "2θ के सूत्र — sin का डबल, cos का ट्रिपल रूप"

```
┌─────────────────────────────────────────────┐
│  sin 2θ = 2 sin θ cos θ  (एक ही रूप)        │
│  cos 2θ = cos²θ − sin²θ                     │
│         = 2cos²θ − 1                        │
│         = 1 − 2sin²θ     (तीन रूप!)         │
│                                             │
│  ट्रिक: "sin सीधा-सादा, cos के तीन चेहरे"   │
└─────────────────────────────────────────────┘
```
**परीक्षा टिप:** cos 2θ के तीनों रूपों में से प्रश्न के अनुसार चुनो — sin दिखे तो तीसरा, cos दिखे तो दूसरा।

## ट्रिक 13: "√3 ≈ 1.732 — ऊँचाई-दूरी की फास्ट कैलकुलेशन"

```
┌─────────────────────────────────────────────┐
│  √3 = 1.732, √2 = 1.414 (रट लो!)            │
│                                             │
│  60° वाले सवाल: ऊँचाई = दूरी × 1.732        │
│  30° वाले सवाल: ऊँचाई = दूरी ÷ 1.732        │
│                                             │
│  ट्रिक: "60 गुणा, 30 भाग"                   │
└─────────────────────────────────────────────┘
```
**उदाहरण:** दूरी 100 मी, कोण 60° → ऊँचाई = 173.2 मी (विकल्पों में 173 दिखे तो तुरंत टिक!)

## ट्रिक 14: "समान ऊँचाई, दो कोण — दूरी का जादू"

```
┌─────────────────────────────────────────────┐
│  एक ही मीनार को दो बिंदुओं से 30° और 60°    │
│  पर देखा जाए तो:                            │
│                                             │
│  दूर वाला बिंदु = 30°, पास वाला = 60°       │
│  और दूरियों का अनुपात = 3 : 1               │
│                                             │
│  ट्रिक: "कोण दुगुना, दूरी तिगुनी"           │
└─────────────────────────────────────────────┘
```
**क्यों:** d = h/tan θ → d₃₀ : d₆₀ = tan60° : tan30° = √3 : 1/√3 = 3 : 1 ✔

## ट्रिक 15: "sin² + cos² = 1 — हर सवाल की चाबी"

```
┌─────────────────────────────────────────────┐
│  sin θ = 3/5 दिया हो और cos θ पूछे:         │
│  त्रिभुज बनाओ — लंब 3, कर्ण 5,              │
│  आधार = √(25−9) = 4 (पाइथागोरस त्रिक!)     │
│  cos θ = 4/5 ✔                              │
│                                             │
│  ट्रिक: "3-4-5 त्रिक याद रखो,               │
│  आधा पेपर वहीं से निकलेगा"                   │
└─────────────────────────────────────────────┘
```
**बोनस त्रिकें:** 3-4-5, 5-12-13, 8-15-17, 7-24-25 — ये पाइथागोरस त्रिक परीक्षा में बार-बार आते हैं!
