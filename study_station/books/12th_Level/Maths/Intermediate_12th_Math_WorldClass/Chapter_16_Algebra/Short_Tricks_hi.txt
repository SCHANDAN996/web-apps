# 🪄 बीजगणित — शॉर्ट ट्रिक्स और स्मृति-सहायक तकनीकें

---

**🎯 ट्रिक 1: (a+b)² की "पहला-दुगना-आखिरी" ताली**

```
┌─────────────────────────────────────────┐
│ (a+b)² = a² + 2ab + b²                  │
│                                         │
│ याद रखो: "पहले का वर्ग, दोनों का दुगना  │
│ गुणा, आखिरी का वर्ग"                    │
│                                         │
│ ताली बजाओ: 👏 पहला! 👏👏 दुगना! 👏 आखिरी!│
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 2: (a−b)² में बीच का माइनस — "डरावना बीचवाला"**

```
┌─────────────────────────────────────────┐
│ (a−b)² = a² − 2ab + b²                  │
│                                         │
│ कहानी: माइनस वाला बीच का पद डरावना है,  │
│ वो अकेला ही माइनस लेता है। b² बहादुर    │
│ है — वो हमेशा प्लस रहता है!             │
│                                         │
│ मंत्र: "बीच डरा, आखिरी बचा"             │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 3: a² − b² = "जोड़ो-घटाओ जुगलबंदी"**

```
┌─────────────────────────────────────────┐
│ a² − b² = (a+b)(a−b)                    │
│                                         │
│ कीवर्ड: "वर्गों का अंतर = जोड़ × घटाव"  │
│                                         │
│ उदाहरण: 99² − 1 = (99+1)(99−1)          │
│              = 100 × 98 = 9800          │
│                                         │
│ परीक्षा में सीधे यही पूछा जाता है!      │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 4: घन वाले सूत्र — "घन-घन-तीनगुना" सीढ़ी**

```
┌─────────────────────────────────────────┐
│ (a+b)³ = a³ + b³ + 3ab(a+b)             │
│ (a−b)³ = a³ − b³ − 3ab(a−b)             │
│                                         │
│ सीढ़ी याद करो:                          │
│ सीढ़ी 1: दोनों का घन (a³, b³)           │
│ सीढ़ी 2: 3ab और कोष्ठक में वही (a±b)    │
│                                         │
│ मंत्र: "घन-घन, फिर तीन-ए-बी कोष्ठक"     │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 5: a³ + b³ का "सोप-बक्सा" (SOP-BOX)**

```
┌─────────────────────────────────────────┐
│ a³ + b³ = (a+b)(a² − ab + b²)           │
│                                         │
│ ट्रिक: पहला कोष्ठक = वही चिह्न (+)      │
│ दूसरा कोष्ठक = उल्टा चिह्न (−) बीच में  │
│                                         │
│ याद रखो: "पहला साथी, दूसरा विरोधी"      │
│ a³ − b³ = (a−b)(a² + ab + b²) — बस      │
│ चिह्न उलट दो!                           │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 6: x + 1/x वाले सवाल — "पावर दोगुनी, दो घटाओ"**

```
┌─────────────────────────────────────────┐
│ अगर x + 1/x = k, तो:                    │
│ x² + 1/x² = k² − 2                      │
│ x³ + 1/x³ = k³ − 3k                     │
│                                         │
│ मंत्र: "वर्ग चाहिए? वर्ग करो, दो उड़ाओ। │
│ घन चाहिए? घन करो, तीन-के घटाओ।"         │
│                                         │
│ माइनस वाले में: x − 1/x = k ⇒           │
│ x² + 1/x² = k² + 2 ("माइनस मिले तो      │
│ दो जोड़ो")                              │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 7: द्विघात सूत्र — "रात्रि का भजन"**

```
┌─────────────────────────────────────────┐
│ ax² + bx + c = 0 का मूल:                │
│ x = [−b ± √(b² − 4ac)] / 2a             │
│                                         │
│ गाओ: "माइनस बी, प्लस-माइनस रूट,         │
│ बी-स्क्वायर माइनस फोर-ए-सी,             │
│ बटे में टू-ए!"                          │
│                                         │
│ (ये दुनिया का सबसे फेमस गणित-गाना है —  │
│ एक बार गा लिया तो जीवनभर याद!)          │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 8: विविक्तकर (Discriminant) — "D = नियता"**

```
┌─────────────────────────────────────────┐
│ D = b² − 4ac                            │
│                                         │
│ D > 0 → दो अलग-अलग मूल ("दो भाई")       │
│ D = 0 → दो बराबर मूल ("जुड़वाँ")        │
│ D < 0 → कोई वास्तविक मूल नहीं ("अदृश्य")│
│                                         │
│ एक्रोनिम: "बड़ा-दो, जीरो-जुड़वाँ,        │
│ छोटा-गायब"                              │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 9: मूलों का योग/गुणन — "उल्टा-सीधा" नियम**

```
┌─────────────────────────────────────────┐
│ ax² + bx + c = 0 के लिए:                │
│ मूलों का योग = −b/a  (उल्टा चिह्न!)     │
│ मूलों का गुणन = c/a  (सीधा चिह्न)       │
│                                         │
│ ट्रिक: "योग शर्माता है — चिह्न पलटता    │
│ है; गुणन बेफिक्र — जैसा है वैसा"        │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 10: (a+b+c)² — "तीनों के वर्ग, तीनों की जोड़ी"**

```
┌─────────────────────────────────────────┐
│ (a+b+c)² = a² + b² + c² + 2(ab+bc+ca)   │

│ हर एक ने अपना वर्ग (सेल्फी) लिया, फिर   │
│ तीनों जोड़ियों ने दुगुनी मस्ती की!      │
│                                         │
│ मंत्र: "सेल्फी-सेल्फी-सेल्फी, फिर       │
│ जोड़ी-जोड़ी-जोड़ी दुगनी"                │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 12: घातांक नियम — "गुणा में जुड़ते, भाग में घटते"**

```
┌─────────────────────────────────────────┐
│ aᵐ × aⁿ = aᵐ⁺ⁿ   (गुणा → घात जुड़े)     │
│ aᵐ ÷ aⁿ = aᵐ⁻ⁿ   (भाग → घात घटे)        │
│ (aᵐ)ⁿ = aᵐⁿ      (घात पर घात → गुणा)    │
│ a⁰ = 1           (शून्य घात = एक)       │
│                                         │
│ चार-पंक्ति कविता:                       │
│ "गुणा में जुड़े, भाग में घटे,           │
│  घात पर घात गुणा हो जाए,                │
│  शून्य घात सबको एक बनाए!"               │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 15: शेषफल प्रमेय — "शून्य बनाओ, डाल दो"**

```
┌─────────────────────────────────────────┐
│ p(x) को (x − a) से भाग देने पर          │
│ शेषफल = p(a)                            │
│                                         │
│ ट्रिक: "भाजक को शून्य बनाओ,             │
│ x की जगह वो मान डाल दो!"                │
│                                         │
│ उदाहरण: x² + 3x + 2 को (x−1) से भाग?    │
│ x = 1 डालो: 1 + 3 + 2 = 6 = शेषफल ✓     │
│                                         │
│ लंबी भाग करने की ज़रूरत ही नहीं!        │
└─────────────────────────────────────────┘
```

**🎯 ट्रिक 16: AP का nवाँ पद — "पहला पद + सीढ़ियाँ"**

```
┌─────────────────────────────────────────┐
│ AP में: aₙ = a + (n−1)d                 │
│                                         │
│ कहानी: पहली सीढ़ी पर खड़े हो (a)।       │
│ nवीं सीढ़ी तक जाना है — पर पहली पर तो   │
│ पहले से हो, इसलिए (n−1) कदम चलो,        │
│ हर कदम d का!                            │
│                                         │
│ ट्रैप अलर्ट: n कदम नहीं, (n−1) कदम!     │
│ यही गलती सबसे ज़्यादा होती है।          │
└─────────────────────────────────────────┘
```
