1. If x + 5 = 12, then the value of x is
(a) 5 (b) 17 (c) 7 (d) 60
Answer: (c)
Solution: Subtracting 5 from both sides gives x = 12 − 5 = 7. Option 17 comes from wrongly adding 5 to 12 instead of subtracting. So the answer is 7.
Source: NCERT Class 7 Mathematics

2. The value of 3x when x = 4 is
(a) 7 (b) 43 (c) 34 (d) 12
Answer: (d)
Solution: 3x means 3 × x, so 3 × 4 = 12. Option 7 comes from wrongly adding 3 and 4 instead of multiplying. So the answer is 12.
Source: NCERT Class 6 Mathematics

3. Simplify: 5a + 3a − 2a
(a) 5a (b) 10a (c) 4a (d) 6a
Answer: (d)
Solution: Like terms combine: 5a + 3a = 8a, then 8a − 2a = 6a. Option 10a comes from ignoring the subtraction of 2a. So the answer is 6a.
Source: NCERT Class 7 Mathematics

4. If 2x = 18, then x equals
(a) 9 (b) 20 (c) 16 (d) 36
Answer: (a)
Solution: Dividing both sides by 2 gives x = 18 ÷ 2 = 9. Option 16 comes from wrongly subtracting 2 from 18. So the answer is 9.
Source: NCERT Class 7 Mathematics

5. The expanded form of (a + b)² is
(a) a² + b² (b) a² − 2ab + b² (c) a² + 2ab + b² (d) 2a + 2b
Answer: (c)
Solution: (a + b)² = (a + b)(a + b) = a² + ab + ba + b² = a² + 2ab + b². Option a² + b² is the classic trap of forgetting the middle term 2ab. So the answer is a² + 2ab + b².
Source: NCERT Class 8 Mathematics

6. The expanded form of (a − b)² is
(a) a² − b² (b) a² + 2ab + b² (c) a² − 2ab + b² (d) a² + b²
Answer: (c)
Solution: (a − b)² = a² − 2ab + b²; only the middle term is negative, the last term stays positive. Option a² − b² is the trap of confusing this with the difference of squares. So the answer is a² − 2ab + b².
Source: NCERT Class 8 Mathematics

7. The value of a² − b² when a = 5 and b = 3 is

Answer: (b)
Solution: a² − b² = (a + b)(a − b) = 8 × 2 = 16. Option 4 comes from wrongly computing (a − b)² = 2² = 4. So the answer is 16.

10. Simplify: 4x × 3x
(a) 12x² (b) 12x (c) 7x (d) 7x²
Answer: (a)
Solution: 4x × 3x = (4 × 3)(x × x) = 12x². Option 12x is the trap of forgetting that x × x = x². So the answer is 12x².

Solution: x = 10 − 4 = 6, and checking: 6 + 4 = 10. Option 14 comes from wrongly adding 4 to 10. So the answer is x = 6.

14. The product of (x + 2) and (x + 3) is
(a) x² + 5x + 6 (b) x² + 6x + 5 (c) x² + 5x + 5 (d) 2x + 5
Answer: (a)
Solution: (x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6. Option 2x + 5 is the trap of adding the brackets instead of multiplying. So the answer is x² + 5x + 6.

15. If 5x − 3 = 12, then x equals
(a) 5 (b) 9/5 (c) 15 (d) 3
Answer: (d)
Solution: 5x = 12 + 3 = 15, so x = 15 ÷ 5 = 3. Option 9/5 comes from wrongly subtracting 3 from 12 before dividing. So the answer is 3.

16. The value of (10)² − (8)² is
(a) 4 (b) 36 (c) 2 (d) 164
Answer: (b)
Solution: Using a² − b² = (a + b)(a − b): 18 × 2 = 36. Option 4 is the trap of computing (10 − 8)² = 2². So the answer is 36.

17. Simplify: 2(x + 3) + 3(x + 1)

Answer: (d)
Solution: 2x + 6 + 3x + 3 = 5x + 9. Option 5x + 6 is the trap of forgetting to distribute 3 to the 1 in the second bracket. So the answer is 5x + 9.

18. If x + y = 10 and x − y = 4, then x equals
(a) 3 (b) 6 (c) 7 (d) 14
Answer: (c)
Solution: Adding the two equations: 2x = 14, so x = 7. Option 3 is the value of y, not x — a common mix-up. So the answer is 7.

19. The factors of x² + 7x + 12 are
(a) (x + 1)(x + 12) (b) (x + 2)(x + 6) (c) (x + 3)(x + 4) (d) (x − 3)(x − 4)
Answer: (c)
Solution: We need two numbers with product 12 and sum 7; those are 3 and 4, giving (x + 3)(x + 4). Option (x + 2)(x + 6) has product 12 but sum 8, so it fails the sum test. So the answer is (x + 3)(x + 4).
Source: NCERT Class 8 Mathematics

(a) 3 (b) 0 (c) 1 (d) −3

21. If x + 1/x = 4, then the value of x² + 1/x² is
(a) 16 (b) 14 (c) 12 (d) 18
Answer: (b)
Solution: Squaring: (x + 1/x)² = x² + 2 + 1/x² = 16, so x² + 1/x² = 16 − 2 = 14. Option 16 is the trap of forgetting to subtract 2 after squaring. So the answer is 14.
Source: NCERT Class 9 Mathematics

22. If a + b = 7 and ab = 10, then the value of a² + b² is
(a) 49 (b) 59 (c) 39 (d) 29
Answer: (d)
Solution: a² + b² = (a + b)² − 2ab = 49 − 20 = 29. Option 49 is the trap of assuming a² + b² equals (a + b)² directly. So the answer is 29.
Source: NCERT Class 9 Mathematics

23. The value of (x + 5)² − (x − 5)² is
(a) 20x (b) 10x (c) 50 (d) 2x² + 50
Answer: (a)
Solution: Using A² − B² = (A + B)(A − B): (2x)(10) = 20x. Option 10x comes from wrongly taking (A − B) as 5 instead of 10. So the answer is 20x.
Source: NCERT Class 8 Mathematics

24. If 2x + 3y = 12 and x + y = 5, then the value of y is
(a) 2 (b) 3 (c) 5 (d) 4
Answer: (a)
Solution: From the second equation x = 5 − y; substituting: 2(5 − y) + 3y = 12, so 10 + y = 12 and y = 2. Option 3 is the value of x, not y — a common mix-up. So the answer is 2.
Source: NCERT Class 10 Mathematics

25. If x − 1/x = 3, then the value of x² + 1/x² is
(a) 9 (b) 7 (c) 11 (d) 6
Answer: (c)
Solution: Squaring: (x − 1/x)² = x² − 2 + 1/x² = 9, so x² + 1/x² = 9 + 2 = 11. Option 7 is the trap of subtracting 2, which applies to the plus case, not the minus case. So the answer is 11.
Source: NCERT Class 9 Mathematics
