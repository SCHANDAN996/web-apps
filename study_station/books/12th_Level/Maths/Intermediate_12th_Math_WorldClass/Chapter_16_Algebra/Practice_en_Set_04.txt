76. If x + 1/x = 5, then the value of x² + 1/x² is
(a) 25 (b) 23 (c) 27 (d) 21
Answer: (b)
Solution: The trap is squaring 5 directly to get 25, forgetting the cross term. Using (x + 1/x)² = x² + 1/x² + 2, we get 25 = x² + 1/x² + 2, so x² + 1/x² = 25 − 2 = 23. So the answer is 23.
Source: NCERT Class 9 Mathematics

77. If a + b = 10 and ab = 21, then the value of a² + b² is
(a) 79 (b) 100 (c) 58 (d) 42
Answer: (c)
Solution: The tempting error is writing a² + b² = (a + b)² = 100, ignoring the product term. Actually a² + b² = (a + b)² − 2ab = 100 − 42 = 58. So the answer is 58.
Source: NCERT Class 9 Mathematics

78. If x − 1/x = 3, then the value of x² + 1/x² is
(a) 7 (b) 9 (c) 11 (d) 13
Answer: (c)
Solution: Many students subtract 2 and get 7, but for the minus form the identity is (x − 1/x)² = x² + 1/x² − 2, so x² + 1/x² = 9 + 2 = 11. So the answer is 11.
Source: NCERT Class 9 Mathematics

79. The factors of x² + 7x + 12 are
(a) (x − 3)(x − 4) (b) (x + 3)(x + 4) (c) (x + 6)(x + 2) (d) (x − 6)(x − 2)
Answer: (b)
Solution: We need two numbers with product 12 and sum 7; those are 3 and 4, both positive since both signs in the expression are positive. Choosing negative signs would give sum −7, and 6 and 2 give sum 8. So the answer is (x + 3)(x + 4).
Source: NCERT Class 9 Mathematics

80. If x + y = 8 and x − y = 4, then the value of xy is
(a) 10 (b) 12 (c) 16 (d) 6
Answer: (b)
Solution: Adding the equations gives 2x = 12, so x = 6 and y = 2, hence xy = 12. The trap is computing x² − y² = (x+y)(x−y) = 32 and confusing it with xy. So the answer is 12.
Source: NCERT Class 8 Mathematics

81. If x² − 5x + 6 = 0, then the sum of the roots is
(a) −6 (b) −5 (c) 6 (d) 5
Answer: (d)
Solution: The trap is taking the coefficient −5 as the sum directly. For ax² + bx + c = 0, sum of roots = −b/a = −(−5)/1 = 5. The roots 2 and 3 confirm this. So the answer is 5.
Source: NCERT Class 10 Mathematics

82. The product of the roots of 2x² − 7x + 3 = 0 is
(a) 3 (b) 7/2 (c) 3/2 (d) −3/2
Answer: (c)
Solution: The trap is answering 3, forgetting to divide by the coefficient of x². Product of roots = c/a = 3/2. So the answer is 3/2.
Source: NCERT Class 10 Mathematics

83. If a³ + b³ = 91 and a + b = 7, then the value of ab is
(a) 9 (b) 6 (c) 7 (d) 12
Answer: (d)
Solution: Using a³ + b³ = (a + b)³ − 3ab(a + b): 91 = 343 − 21ab, so 21ab = 252 and ab = 12. The trap is dividing 252 by 7 instead of 21, which gives 36. So the answer is 12.
Source: NCERT Class 9 Mathematics

84. The value of (x + 3)² − (x − 3)² is
(a) 12x (b) 6x (c) 18 (d) 2x² + 18
Answer: (a)
Solution: Using a² − b² = (a − b)(a + b): here the difference of the bases is 6 and the sum is 2x, giving 12x. The trap is expanding and wrongly keeping the constant 18. So the answer is 12x.
Source: NCERT Class 8 Mathematics

85. If 2x + 3y = 12 and 3x + 2y = 13, then the value of x + y is
(a) 7 (b) 4 (c) 5 (d) 6
Answer: (c)
Solution: The quick method: add both equations to get 5x + 5y = 25, so x + y = 5. Solving separately (x = 3, y = 2) also works but wastes time. So the answer is 5.
Source: NCERT Class 10 Mathematics

86. If x = 2 + √3, then the value of x + 1/x is
(a) 4 (b) 2√3 (c) 2 (d) 3
Answer: (a)
Solution: 1/x = 1/(2 + √3) = (2 − √3)/((2+√3)(2−√3)) = 2 − √3. Adding: x + 1/x = (2 + √3) + (2 − √3) = 4. The trap is leaving the answer as 2√3 by adding incorrectly. So the answer is 4.
Source: NCERT Class 9 Mathematics

87. The remainder when x³ + 2x² − 3x + 1 is divided by (x − 1) is
(a) 3 (b) 0 (c) −1 (d) 1
Answer: (d)
Solution: By the Remainder Theorem, substitute x = 1: 1 + 2 − 3 + 1 = 1. The trap is assuming divisibility and answering 0 without checking. So the answer is 1.
Source: NCERT Class 9 Mathematics

88. If x + 1/x = 2, then the value of x¹⁰ + 1/x¹⁰ is
(a) 20 (b) 10 (c) 1024 (d) 2
Answer: (d)
Solution: x + 1/x = 2 implies (x − 1)² = 0, so x = 1. Then x¹⁰ + 1/x¹⁰ = 1 + 1 = 2. The trap is computing powers of 2 mechanically. So the answer is 2.
Source: NCERT Class 9 Mathematics

89. The factors of a² − b² − 2b − 1 are
(a) (a + b)(a − b) − 1 (b) (a + b + 1)(a − b − 1) (c) (a + b − 1)(a − b + 1) (d) (a − b − 1)(a + b − 1)
Answer: (b)
Solution: Rewrite as a² − (b² + 2b + 1) = a² − (b + 1)² = (a + b + 1)(a − b − 1). The trap is treating the last three terms as non-factorable. So the answer is (a + b + 1)(a − b − 1).
Source: NCERT Class 9 Mathematics

90. If x² + y² = 29 and xy = 10, then the value of x + y (x, y positive) is
(a) 9 (b) 49 (c) 7 (d) √29
Answer: (c)
Solution: (x + y)² = x² + y² + 2xy = 29 + 20 = 49, so x + y = 7 (positive root). The trap is answering 49, forgetting the square root. So the answer is 7.
Source: NCERT Class 9 Mathematics

91. The quadratic equation whose roots are 3 and −5 is
(a) x² + 2x + 15 = 0 (b) x² − 2x − 15 = 0 (c) x² − 2x + 15 = 0 (d) x² + 2x − 15 = 0
Answer: (d)
Solution: Sum of roots = 3 + (−5) = −2, product = −15. Equation: x² − (sum)x + product = x² + 2x − 15 = 0. The trap is a sign error, giving x² − 2x − 15. So the answer is x² + 2x − 15 = 0.
Source: NCERT Class 10 Mathematics

92. If a + b + c = 0, then the value of a³ + b³ + c³ is
(a) 3abc (b) 0 (c) abc (d) (a + b + c)³
Answer: (a)
Solution: The standard identity: if a + b + c = 0, then a³ + b³ + c³ = 3abc. The trap is answering 0, confusing the sum with the sum of cubes. So the answer is 3abc.
Source: NCERT Class 9 Mathematics

93. The value of (0.98)² is
(a) 0.9804 (b) 0.96 (c) 0.9604 (d) 0.964
Answer: (c)
Solution: (0.98)² = (1 − 0.02)² = 1 − 0.04 + 0.0004 = 0.9604. The trap is writing 0.96 by dropping the small term 0.0004. So the answer is 0.9604.
Source: NCERT Class 8 Mathematics

94. If 3ˣ = 81, then the value of x is
(a) 4 (b) 3 (c) 27 (d) 9
Answer: (a)
Solution: 81 = 3⁴, so x = 4. The trap is dividing 81 by 3 to get 27, confusing exponent with multiplication. So the answer is 4.
Source: NCERT Class 8 Mathematics

95. If x/y = 2/3, then the value of (5x + 3y)/(5x − 3y) is
(a) 11 (b) 1 (c) 9 (d) 19
Answer: (d)
Solution: Put x = 2k and y = 3k: numerator = 10k + 9k = 19k, denominator = 10k − 9k = k, so the ratio is 19. The trap is adding the coefficients directly and answering 9 or 11 without substituting the ratio. So the answer is 19.
Source: PYQ-style

96. If x² − 3x + 1 = 0, then the value of x² + 1/x² is
(a) 3 (b) 7 (c) 11 (d) 9
Answer: (b)
Solution: Divide by x: x − 3 + 1/x = 0, so x + 1/x = 3. Then x² + 1/x² = 9 − 2 = 7. The trap is answering 9 by squaring without subtracting 2. So the answer is 7.
Source: NCERT Class 10 Mathematics

97. The HCF of x² − 4 and x² − 5x + 6 is
(a) (x − 2) (b) (x + 2) (c) (x − 3) (d) (x² − 4)
Answer: (a)
Solution: x² − 4 = (x − 2)(x + 2) and x² − 5x + 6 = (x − 2)(x − 3). The common factor is (x − 2). The trap is picking (x − 3), which does not divide x² − 4. So the answer is (x − 2).
Source: NCERT Class 10 Mathematics

98. If 2ˣ × 4ʸ = 64 and x + 2y = 6, then the value of x when y = 2 is
(a) 2 (b) 4 (c) 6 (d) 3
Answer: (a)
Solution: Since 4ʸ = 2²ʸ, the equation becomes 2^(x + 2y) = 2⁶, giving x + 2y = 6. With y = 2, x = 6 − 4 = 2. The trap is treating 4ʸ as 4 × 2ʸ. So the answer is 2.
Source: NCERT Class 9 Mathematics

99. If a = 101, then the value of a² − 2a + 1 is
(a) 10201 (b) 10000 (c) 9801 (d) 10001
Answer: (b)
Solution: a² − 2a + 1 = (a − 1)² = 100² = 10000. The trap is computing 101² = 10201 and stopping there. So the answer is 10000.
Source: NCERT Class 8 Mathematics

100. If x + y = 12 and x² + y² = 80, then the value of xy is
(a) 32 (b) 64 (c) 16 (d) 40
Answer: (a)
Solution: (x + y)² = x² + y² + 2xy gives 144 = 80 + 2xy, so 2xy = 64 and xy = 32. The trap is answering 64, forgetting to divide by 2. So the answer is 32.
Source: NCERT Class 9 Mathematics
