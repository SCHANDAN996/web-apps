# 📋 बीजगणित — महत्वपूर्ण सूत्र (Important Formulas)

## 1. बीजीय सर्वसमिकाएँ (Algebraic Identities)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| वर्ग सर्वसमिका (योग) | (a + b)² = a² + 2ab + b² | दो पदों के योग का वर्ग |
| वर्ग सर्वसमिका (अंतर) | (a − b)² = a² − 2ab + b² | दो पदों के अंतर का वर्ग |
| वर्गों का अंतर | a² − b² = (a + b)(a − b) | गुणनखंड या त्वरित गुणा (जैसे 98×102) |
| तीन पदों का वर्ग | (a + b + c)² = a² + b² + c² + 2(ab + bc + ca) | तीन पदों के योग का वर्ग |
| घन सर्वसमिका (योग) | (a + b)³ = a³ + b³ + 3ab(a + b) | योग का घन |
| घन सर्वसमिका (अंतर) | (a − b)³ = a³ − b³ − 3ab(a − b) | अंतर का घन |
| घनों का योग | a³ + b³ = (a + b)(a² − ab + b²) | गुणनखंड |
| घनों का अंतर | a³ − b³ = (a − b)(a² + ab + b²) | गुणनखंड |
| घनों का योग (विशेष) | a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) | जब a + b + c = 0 हो, तो a³ + b³ + c³ = 3abc |
| x + 1/x वाला नियम | x² + 1/x² = (x + 1/x)² − 2 | जब x + 1/x का मान दिया हो |
| x − 1/x वाला नियम | x² + 1/x² = (x − 1/x)² + 2 | जब x − 1/x का मान दिया हो |
| घन रूप | x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) | x + 1/x से घन निकालना |
| घन रूप (ऋणात्मक) | x³ − 1/x³ = (x − 1/x)³ + 3(x − 1/x) | x − 1/x से घन निकालना |

## 2. घातांक के नियम (Laws of Exponents)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| गुणन नियम | aᵐ × aⁿ = aᵐ⁺ⁿ | आधार समान, घातें जुड़ती हैं |
| भाग नियम | aᵐ ÷ aⁿ = aᵐ⁻ⁿ | आधार समान, घातें घटती हैं |
| घात की घात | (aᵐ)ⁿ = aᵐⁿ | घातों का गुणन |
| शून्य घात | a⁰ = 1 (a ≠ 0) | किसी भी संख्या की घात 0 |
| ऋणात्मक घात | a⁻ᵐ = 1/aᵐ | घात उलटने पर व्युत्क्रम |
| भिन्न घात | a^(m/n) = ⁿ√(aᵐ) | घातांक और मूल का संबंध |
| गुणनफल की घात | (ab)ᵐ = aᵐbᵐ | गुणनफल पर घात |
| भिन्न की घात | (a/b)ᵐ = aᵐ/bᵐ | भिन्न पर घात |

## 3. द्विघात समीकरण (Quadratic Equations)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| मानक रूप | ax² + bx + c = 0 (a ≠ 0) | द्विघात समीकरण पहचानना |
| श्रीधराचार्य सूत्र | x = [−b ± √(b² − 4ac)] / 2a | मूल निकालने का सीधा सूत्र |
| विविक्तकर (Discriminant) | D = b² − 4ac | मूलों की प्रकृति जाँचना |
| मूलों की प्रकृति | D > 0 → दो भिन्न वास्तविक मूल; D = 0 → दो समान मूल; D < 0 → कोई वास्तविक मूल नहीं | बिना हल किए मूलों का स्वभाव |
| मूलों का योग | α + β = −b/a | मूलों से समीकरण बनाना |
| मूलों का गुणनफल | αβ = c/a | मूलों से समीकरण बनाना |
| समीकरण निर्माण | x² − (α + β)x + αβ = 0 | मूल दिए हों तो समीकरण बनाना |

## 4. समांतर श्रेढ़ी (Arithmetic Progression — AP)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| nवाँ पद | aₙ = a + (n − 1)d | कोई भी पद निकालना |
| सार्व अंतर | d = a₂ − a₁ | श्रेढ़ी AP है या नहीं जाँचना |
| n पदों का योग | Sₙ = n/2 [2a + (n − 1)d] | पहला पद और d ज्ञात हो |
| योग (अंतिम पद से) | Sₙ = n/2 (a + l) | पहला और अंतिम पद ज्ञात हो |
| nवाँ पद (योग से) | aₙ = Sₙ − Sₙ₋₁ | योगफल से पद निकालना |

## 5. गुणोत्तर श्रेढ़ी (Geometric Progression — GP)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| nवाँ पद | aₙ = arⁿ⁻¹ | कोई भी पद निकालना |
| सार्व अनुपात | r = a₂/a₁ | GP जाँचना |
| n पदों का योग (r ≠ 1) | Sₙ = a(rⁿ − 1)/(r − 1), r > 1 | योग निकालना |
| n पदों का योग (r < 1) | Sₙ = a(1 − rⁿ)/(1 − r) | योग निकालना |
| अनंत श्रेढ़ी का योग | S∞ = a/(1 − r), जहाँ \|r\| < 1 | अनंत पदों का योग |

## 6. माध्य संबंध (Means)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| समांतर माध्य (AM) | A = (a + b)/2 | दो संख्याओं के बीच AM |
| गुणोत्तर माध्य (GM) | G = √(ab) | दो संख्याओं के बीच GM |
| हरात्मक माध्य (HM) | H = 2ab/(a + b) | दो संख्याओं के बीच HM |
| संबंध | AM ≥ GM ≥ HM तथा G² = A × H | तुलना वाले प्रश्नों में |

## 7. अन्य उपयोगी सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| प्रथम n प्राकृत संख्याओं का योग | 1 + 2 + … + n = n(n + 1)/2 | क्रमागत संख्याओं का योग |
| प्रथम n वर्गों का योग | 1² + 2² + … + n² = n(n + 1)(2n + 1)/6 | वर्गों का योग |
| प्रथम n घनों का योग | 1³ + 2³ + … + n³ = [n(n + 1)/2]² | घनों का योग |
| n सम संख्याओं का योग | 2 + 4 + … + 2n = n(n + 1) | सम संख्याओं का योग |
| n विषम संख्याओं का योग | 1 + 3 + … + (2n − 1) = n² | विषम संख्याओं का योग |
| शेषफल प्रमेय | p(x) को (x − a) से भाग देने पर शेषफल = p(a) | बहुपद का शेषफल |
| गुणनखंड प्रमेय | यदि p(a) = 0, तो (x − a), p(x) का गुणनखंड है | बहुपद के गुणनखंड |
