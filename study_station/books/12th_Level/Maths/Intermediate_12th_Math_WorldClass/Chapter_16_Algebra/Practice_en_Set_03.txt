51. If x + 1/x = 5, then the value of x² + 1/x² is
(a) 27 (b) 25 (c) 23 (d) 21
Answer: (c)
Solution: The trap is squaring 5 directly to get 25, forgetting the cross term. Squaring both sides: (x + 1/x)² = x² + 1/x² + 2, so 25 = x² + 1/x² + 2, giving x² + 1/x² = 23. So the answer is 23.

52. If a + b = 10 and ab = 21, then the value of a² + b² is
(a) 58 (b) 79 (c) 100 (d) 42
Answer: (a)
Solution: The tempting wrong option 100 comes from squaring a + b directly. Using (a + b)² = a² + b² + 2ab, we get 100 = a² + b² + 42, so a² + b² = 58. So the answer is 58.

53. If x − 1/x = 3, then the value of x² + 1/x² is
(a) 7 (b) 9 (c) 11 (d) 13
Answer: (c)
Solution: Many students square 3 to get 9 and stop, but the cross term here adds 2, not subtracts. (x − 1/x)² = x² + 1/x² − 2, so 9 = x² + 1/x² − 2, giving x² + 1/x² = 11. So the answer is 11.

74. If a + b = 5 and a² + b² = 13, then the value of a³ + b³ is
(a) 35 (b) 65 (c) 125 (d) 50
Answer: (a)
Solution: First find ab: (a + b)² = a² + b² + 2ab gives 25 = 13 + 2ab, so ab = 6. Then a³ + b³ = (a + b)(a² + b² − ab) = 5(13 − 6) = 35. The trap is cubing 5 to get 125, so the answer is 35.
Source: NCERT Class 9 Mathematics
