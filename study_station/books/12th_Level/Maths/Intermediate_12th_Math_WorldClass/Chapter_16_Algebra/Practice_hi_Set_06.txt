126. यदि x + 1/x = 5, तो x³ + 1/x³ का मान है:
(a) 110 (b) 125 (c) 100 (d) 115
उत्तर: (a)
हल: जाल यह है कि 5 का सीधे घन करके 125 उत्तर दे दिया जाए, जिससे क्रॉस पद छूट जाता है। सर्वसमिका x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 125 − 15 = 110 का प्रयोग करें, इसलिए उत्तर 110 है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

127. यदि a + b + c = 0, तो (a²/bc + b²/ca + c²/ab) का मान है:
(a) 0 (b) 1 (c) 3 (d) −3
उत्तर: (c)
हल: लुभाने वाला गलत विकल्प 0 है, क्योंकि a + b + c = 0 देखकर ऐसा मान लिया जाता है। पदों को मिलाने पर (a³ + b³ + c³)/abc मिलता है, और चूँकि a + b + c = 0 से a³ + b³ + c³ = 3abc होता है, व्यंजक 3abc/abc = 3 के बराबर है, इसलिए उत्तर 3 है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

128. यदि x² − 3x + 1 = 0, तो x³ + 1/x³ का मान है:
(a) 18 (b) 27 (c) 9 (d) 36
उत्तर: (a)
हल: x से भाग देने पर x + 1/x = 3 मिलता है, और जाल यह है कि 3 का सीधे घन करके 27 उत्तर दे दिया जाए। तब x³ + 1/x³ = 3³ − 3×3 = 27 − 9 = 18, इसलिए उत्तर 18 है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

129. यदि a² + b² + c² = ab + bc + ca, तो निम्नलिखित में से कौन सत्य है?
(a) a + b + c = 0 (b) a = b = c (c) a + b = c (d) a² = b² + c²
उत्तर: (b)
हल: जाल यह है कि a + b + c = 0 चुन लिया जाए, जो एक अलग मानक शर्त है। 2 से गुणा करके पुनर्व्यवस्थित करने पर (a−b)² + (b−c)² + (c−a)² = 0 मिलता है, और वर्गों का योग तभी शून्य होता है जब प्रत्येक वर्ग शून्य हो, अतः a = b = c, इसलिए उत्तर a = b = c है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

130. यदि x = 2 + √3, तो x² + 1/x² का मान है:
(a) 14 (b) 12 (c) 16 (d) 10
उत्तर: (a)
हल: जाल यह है कि केवल x का वर्ग करके 12 अनुमान लगा लिया जाए। परिमेयकरण से 1/x = 2 − √3 मिलता है, अतः x + 1/x = 4, और x² + 1/x² = (x + 1/x)² − 2 = 16 − 2 = 14, इसलिए उत्तर 14 है।
स्रोत: NCERT कक्षा 9 गणित (संख्या पद्धति)

131. यदि x + y = 7 और xy = 10, तो x³ + y³ का मान है:
(a) 133 (b) 343 (c) 210 (d) 91
उत्तर: (a)
हल: जाल यह है कि 7 का घन करके 343 उत्तर दे दिया जाए, जिससे गुणनफल वाला पद छूट जाता है। x³ + y³ = (x + y)³ − 3xy(x + y) = 343 − 3×10×7 = 343 − 210 = 133 का प्रयोग करें, इसलिए उत्तर 133 है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

132. यदि a + b + c = 6 और ab + bc + ca = 11, तो a³ + b³ + c³ − 3abc का मान है:
(a) 36 (b) 6 (c) 18 (d) 12
उत्तर: (c)
हल: जाल यह है कि a, b, c को अलग-अलग निकालने की कोशिश की जाए, जो अनावश्यक है। a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) का प्रयोग करें; अब a² + b² + c² = 36 − 22 = 14, अतः व्यंजक = 6 × (14 − 11) = 18, इसलिए उत्तर 18 है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

133. यदि x = 3 + 2√2, तो √x − 1/√x का मान है:
(a) 4 (b) 2√2 (c) 2 (d) √2
उत्तर: (c)
हल: जाल यह है कि करणी के वर्गमूल में गलती हो जाए; ध्यान दें कि x = (√2 + 1)², अतः √x = √2 + 1 और 1/√x = √2 − 1। इनका अंतर (√2 + 1) − (√2 − 1) = 2 है, इसलिए उत्तर 2 है।
स्रोत: NCERT कक्षा 9 गणित (संख्या पद्धति)

134. यदि x² + 1/x² = 7, तो x − 1/x (x > 1) का मान है:
(a) 3 (b) √5 (c) √7 (d) 5
उत्तर: (b)
हल: जाल यह है कि −2 के समायोजन को भूलकर सीधे √7 ले लिया जाए। चूँकि (x − 1/x)² = x² + 1/x² − 2 = 7 − 2 = 5, और x > 1 होने से यह धनात्मक है, x − 1/x = √5, इसलिए उत्तर √5 है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

135. x³ − 6x² + 11x − 6 के गुणनखंड हैं:
(a) (x−1)(x−2)(x+3) (b) (x+1)(x−2)(x−3) (c) (x−1)(x+2)(x−3) (d) (x−1)(x−2)(x−3)
उत्तर: (d)
हल: जाल किसी एक गुणनखंड में चिह्न की गलती है, जिसका गलत विकल्प फायदा उठाते हैं। x = 1 रखने पर 0 मिलता है, अतः (x−1) एक गुणनखंड है; भाग देने पर x² − 5x + 6 = (x−2)(x−3) मिलता है, इसलिए उत्तर (x−1)(x−2)(x−3) है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

136. यदि 2ˣ = 3ʸ = 6⁻ᶻ, तो 1/x + 1/y + 1/z का मान है:
(a) 1 (b) 2 (c) −1 (d) 0
उत्तर: (d)
हल: जाल यह है कि योग धनात्मक ही होगा, ऐसा मान लिया जाए। मान लें 2ˣ = 3ʸ = 6⁻ᶻ = k; तब 2 = k^(1/x), 3 = k^(1/y), 6 = k^(−1/z)। चूँकि 2 × 3 = 6, हमें k^(1/x + 1/y) = k^(−1/z) मिलता है, अतः 1/x + 1/y + 1/z = 0, इसलिए उत्तर 0 है।
स्रोत: NCERT कक्षा 9 गणित (संख्या पद्धति)

137. यदि x + 1/x = 2cosθ, तो x³ + 1/x³ का मान है:
(a) cos3θ (b) 2cos²θ (c) 8cos³θ (d) 2cos3θ
उत्तर: (d)
हल: जाल यह है कि घन करके 8cos³θ उत्तर दे दिया जाए, जिससे घटाने वाला पद छूट जाता है। x³ + 1/x³ = (2cosθ)³ − 3(2cosθ) = 8cos³θ − 6cosθ = 2(4cos³θ − 3cosθ) = 2cos3θ, इसलिए उत्तर 2cos3θ है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

138. यदि a/b + b/a = 2 (a, b > 0), तो a³ + b³ का मान है:
(a) 2a³ (b) 0 (c) a²b (d) 2ab
उत्तर: (a)
हल: जाल यह है कि शर्त का प्रयोग किए बिना प्रसार कर दिया जाए। a/b + b/a = 2 से a² + b² = 2ab मिलता है, अर्थात् (a−b)² = 0, अतः a = b। तब a³ + b³ = 2a³, इसलिए उत्तर 2a³ है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

139. यदि x = √3 + √2 और y = √3 − √2, तो x³ − y³ का मान है:
(a) 24√2 (b) 22√2 (c) 20√2 (d) 18√2
उत्तर: (b)
हल: जाल यह है कि प्रत्येक करणी का अलग-अलग घन करके चिह्नों में गलती हो जाए। यहाँ x − y = 2√2 और xy = 3 − 2 = 1, अतः x³ − y³ = (x−y)³ + 3xy(x−y) = 16√2 + 6√2 = 22√2, इसलिए उत्तर 22√2 है।
स्रोत: NCERT कक्षा 9 गणित (संख्या पद्धति)

140. यदि x⁴ + 1/x⁴ = 47, तो x + 1/x (x > 0) का मान है:
(a) 3 (b) 7 (c) √47 (d) 5
उत्तर: (a)
हल: जाल यह है कि 47 का सीधे चतुर्थ मूल ले लिया जाए। पहले x² + 1/x² = √(47 + 2) = 7, फिर (x + 1/x)² = 7 + 2 = 9, जिससे x + 1/x = 3 मिलता है, इसलिए उत्तर 3 है।

141. यदि a + b + c = 9 और a² + b² + c² = 35, तो ab + bc + ca का मान है:
(a) 13 (b) 23 (c) 26 (d) 46
उत्तर: (b)
हल: जाल यह है कि 81 में से 35 घटाकर 2 के गुणक को भूल जाएँ। चूँकि (a + b + c)² = a² + b² + c² + 2(ab + bc + ca), हमें 81 = 35 + 2(ab + bc + ca) मिलता है, अतः ab + bc + ca = 23, इसलिए उत्तर 23 है।

142. यदि x = 5 − 2√6, तो x² − 10x + 1 का मान है:
(a) 1 (b) 2 (c) −1 (d) 0
उत्तर: (d)
हल: जाल यह है कि मान रखकर पूरा प्रसार किया जाए, जिससे अंकगणितीय चूक होती है। चूँकि x = 5 − 2√6, हमें x − 5 = −2√6 मिलता है, अतः (x − 5)² = 24, अर्थात् x² − 10x + 25 = 24, जिससे x² − 10x + 1 = 0, इसलिए उत्तर 0 है।
स्रोत: NCERT कक्षा 9 गणित (संख्या पद्धति)

143. यदि p + q + r = 0, तो p²/(p² − qr) + q²/(q² − rp) + r²/(r² − pq) का मान है:
(a) 0 (b) 1 (c) 2 (d) 3
उत्तर: (c)
हल: जाल यह है कि p + q + r = 0 देखकर 0 अनुमान लगा लिया जाए। चूँकि p + q + r = 0, हमें p² − qr = −(pq + qr + rp) मिलता है, अतः प्रत्येक पद −p²/(pq + qr + rp) बन जाता है और योग −(p² + q² + r²)/(pq + qr + rp) होता है। p² + q² + r² = −2(pq + qr + rp) का प्रयोग करने पर योग 2 के बराबर आता है, इसलिए उत्तर 2 है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

144. यदि x² + y² + z² = xy + yz + zx और x = 1, तो (10x⁴ + 5y⁴ + 7z⁴)/(13x²y² + 6y²z² + 3z²x²) का मान है:
(a) 0 (b) 2 (c) 22/13 (d) 1
उत्तर: (d)

स्रोत: NCERT कक्षा 9 गणित (बहुपद)

146. यदि a = 7 + 4√3, तो √a + 1/√a का मान है:

147. यदि x + y + z = 0, तो (x + y)²/xy + (y + z)²/yz + (z + x)²/zx का मान है:
(a) −6 (b) −3 (c) 6 (d) 3
उत्तर: (d)
हल: जाल यह है कि x + y + z = 0 देखकर योग ऋणात्मक ही होगा, ऐसा मान लिया जाए। चूँकि x + y = −z, पहला पद z²/xy = z³/(xyz) है, और इसी प्रकार शेष दो पद भी। कुल योग (x³ + y³ + z³)/(xyz) = 3xyz/(xyz) = 3 है, इसलिए उत्तर 3 है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

148. यदि x = 1 + √2 + √3, तो x² − 2x − 4 का मान है:
(a) √6 (b) 2√6 (c) 4√6 (d) 0
उत्तर: (b)
हल: जाल यह है कि तीनों करणी पदों के साथ x² का पूरा प्रसार करके चिह्नों में चूक हो जाए। x − 1 = √2 + √3 लिखें, अतः (x − 1)² = 5 + 2√6, अर्थात् x² − 2x + 1 = 5 + 2√6, जिससे x² − 2x − 4 = 2√6, इसलिए उत्तर 2√6 है।
स्रोत: NCERT कक्षा 9 गणित (संख्या पद्धति)

149. यदि a + 1/b = 1 और b + 1/c = 1, तो c + 1/a का मान है:
(a) −1 (b) 0 (c) 1 (d) 2
उत्तर: (c)
हल: जाल यह है कि सममिति देखकर 0 मान लिया जाए। पहले समीकरण से a = (b − 1)/b, अतः 1/a = b/(b − 1); दूसरे से c = 1/(1 − b)। तब c + 1/a = 1/(1 − b) + b/(b − 1) = (1 − b)/(1 − b) = 1, इसलिए उत्तर 1 है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)

150. यदि x² − 4x + 1 = 0, तो x³ + 1/x³ का मान है:
(a) 64 (b) 48 (c) 52 (d) 56
उत्तर: (c)
हल: जाल यह है कि सुधार पद के बिना 4 का घन करके 64 उत्तर दे दिया जाए। समीकरण को x से भाग देने पर x + 1/x = 4 मिलता है, अतः x³ + 1/x³ = 4³ − 3×4 = 64 − 12 = 52, इसलिए उत्तर 52 है।
स्रोत: NCERT कक्षा 9 गणित (बहुपद)
