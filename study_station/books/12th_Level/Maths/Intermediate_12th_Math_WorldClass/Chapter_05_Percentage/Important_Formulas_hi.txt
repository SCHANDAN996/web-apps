# महत्वपूर्ण सूत्र एवं रणनीतिक नियम: प्रतिशत

1. गुणक (Multiplier) रूपांतरण:
   - +r% वृद्धि -> गुणक M = (1 + r/100)
   - -r% कमी -> गुणक M = (1 - r/100)

2. गुणनफल स्थिरता नियम (AB नियम):
   - +a/b की वृद्धि -> क्षतिपूरक कमी -a/(b + a)
   - -a/b की कमी -> क्षतिपूरक वृद्धि +a/(b - a)

3. क्रमिक प्रतिशत परिवर्तन:
   - कुल % = x + y + (xy / 100)
   - समान वृद्धि व कमी x%: शुद्ध हानि = -(x^2 / 100)%

4. चुनाव सूत्र:
   - डाले गए मत = कुल मतदाता × (1 - अनुपस्थित%)
   - वैध मत = डाले गए मत - अवैध मत
   - जीत का अंतर = (2W - 100)% × वैध मत

5. मानक भिन्न-प्रतिशत मान:
   - 1/2 = 50%, 1/3 = 33.33%, 1/4 = 25%, 1/5 = 20%
   - 1/6 = 16.67%, 1/7 = 14.28%, 1/8 = 12.5%, 1/9 = 11.11%
   - 1/11 = 9.09%, 1/12 = 8.33%, 1/16 = 6.25%
