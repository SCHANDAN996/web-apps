# Important Formulas & Strategic Rules: Percentage

1. Multiplier Conversion:
   - +r% increase -> Multiplier M = (1 + r/100)
   - -r% decrease -> Multiplier M = (1 - r/100)

2. Product Constancy (AB = C where C is constant):
   - Increase of +a/b -> Compensatory decrease of -a/(b + a)
   - Decrease of -a/b -> Compensatory increase of +a/(b - a)

3. Successive Percentage Change:
   - Net % = x + y + (xy / 100)
   - Equal increase & decrease of x%: Net Loss = -(x^2 / 100)%

4. Election Analytics:
   - Polled Votes = Registered * (1 - Non-voting%)
   - Valid Votes = Polled - Invalid
   - Winning Margin = (Winner% - Loser%) * Valid Votes = (2W - 100)% * Valid Votes

5. Income-Expenditure Dynamic:
   - Income = Expenditure + Savings
   - Delta(I) = (E/I)*Delta(E) + (S/I)*Delta(S)

6. Standard Fraction-Percentage Equivalents:
   - 1/2 = 50%, 1/3 = 33.33%, 1/4 = 25%, 1/5 = 20%
   - 1/6 = 16.67%, 1/7 = 14.28%, 1/8 = 12.5%, 1/9 = 11.11%
   - 1/11 = 9.09%, 1/12 = 8.33%, 1/13 = 7.69%, 1/14 = 7.14%
   - 1/15 = 6.67%, 1/16 = 6.25%, 1/20 = 5%, 1/25 = 4%
