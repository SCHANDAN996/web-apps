# 📋 Important Formulas — Percentage

| Formula Name | Formula | Use-Hint |
|---|---|---|
| Percentage Meaning | x% = x/100 | Convert any percentage to a fraction |
| Percentage of a Number | (x/100) × N | Find "x% of N" |
| Value from Percentage | N = (Part × 100)/x | Whole value when a part and its % are given |
| Percentage Change | % Change = (Change/Original) × 100 | Increase or decrease compared to the original value |
| Percentage Increase | % Increase = ((New − Old)/Old) × 100 | Growth questions (salary, price, population) |
| Percentage Decrease | % Decrease = ((Old − New)/Old) × 100 | Reduction questions (discount, depreciation) |
| New Value after Increase | New = Old × (1 + x/100) | Direct final value after x% rise |
| New Value after Decrease | New = Old × (1 − x/100) | Direct final value after x% fall |
| Successive Change (a% then b%) | Net % = a + b + (ab/100) | Two consecutive changes; use − sign for decrease |
| Net Change (Increase then Decrease of x%) | Net % = −x²/100 | Same % up then down (or vice versa) → always a net decrease |
| A is x% more than B | B is less than A by (x/(100+x)) × 100% | Reverse comparison when A > B |
| A is x% less than B | B is more than A by (x/(100−x)) × 100% | Reverse comparison when A < B |
| Price ↑ x%, Consumption ↓ | Reduction in consumption = (x/(100+x)) × 100% | Keep expenditure constant when price rises |
| Price ↓ x%, Consumption ↑ | Increase in consumption = (x/(100−x)) × 100% | Keep expenditure constant when price falls |
| Population after n years (Growth) | Pₙ = P(1 + r/100)ⁿ | Population/amount growing at r% per year |
| Population n years ago | P₀ = Pₙ / (1 + r/100)ⁿ | Find past value from present value |
| Depreciation after n years | Vₙ = V(1 − r/100)ⁿ | Machine/asset value falling at r% per year |
| Election (Winner gets x% of valid votes) | Winner's votes = (x/100) × Valid votes | Valid votes = Total votes − Invalid votes |
| Marks: Pass % | Pass marks = (Pass %/100) × Max marks | Fail-by-marks problems: add the shortfall |
| Fraction ↔ Percentage | 1/2 = 50%, 1/3 = 33⅓%, 1/4 = 25%, 1/5 = 20%, 1/6 = 16⅔%, 1/8 = 12½%, 1/9 = 11⅑%, 1/11 = 9 1/11%, 1/12 = 8⅓% | Memorise for instant conversion in exams |
| Percentage to Ratio | x% = x : 100 | Convert % into ratio form |
| Expenditure = Price × Consumption | E = P × C | Base identity for price–consumption problems |
| % of % | x% of y% of N = (x/100)(y/100)N | Nested percentage questions |
| Scoring % (Two subjects) | Overall % = (Total marks obtained/Total max marks) × 100 | Aggregate percentage across papers |
| Income–Expenditure–Savings | Savings = Income − Expenditure; Savings % = (Savings/Income) × 100 | Salary–savings word problems |
