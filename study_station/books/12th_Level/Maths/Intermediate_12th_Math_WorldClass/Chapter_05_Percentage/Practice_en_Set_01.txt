Questions 1–25: Easy

1. Convert the fraction 7/16 into its percentage equivalent.
(a) 43.75% (b) 42.50% (c) 44.25% (d) 41.75%
Answer: (a) 43.75%
Solution: (7 / 16) * 100% = 700 / 16% = 43.75%. The required value is 43.75%. Hence, the correct option is (a).
Source: SSC CGL Pattern

2. Convert 14 2/7% into its simplest fractional form.
(a) 1/14 (b) 1/7 (c) 2/7 (d) 1/6
Answer: (b) 1/7
Solution: 14 2/7% = (100 / 7)% = (100 / 7) / 100 = 1/7. The required value is 1/7. Hence, the correct option is (b).
Source: SSC CGL Pattern

3. What is 37.5% of 640?
(a) 220 (b) 260 (c) 240 (d) 280
Answer: (c) 240
Solution: Here, 37.5% is equivalent to the fraction 3/8. Therefore, 640 * (3/8) = 80 * 3 = 240. The required value is 240. Hence, the correct option is (c).
Source: SSC CGL Pattern

4. If 25% of a number x is 75, what is 80% of the same number x?
(a) 200 (b) 260 (c) 220 (d) 240
Answer: (d) 240
Solution: Since 25% of x is 75, the number x is 75 * 4 = 300. Thus 80% of 300 = 300 * 0.8 = 240. The required value is 240. Hence, the correct option is (d).
Source: SSC CGL Pattern

5. The salary of an employee is increased from Rs 24,000 to Rs 30,000. Find the percentage increase in salary.
(a) 25% (b) 20% (c) 30% (d) 24%
Answer: (a) 25%
Solution: Increase = 30,000 - 24,000 = 6,000. Percentage increase = (6,000 / 24,000) * 100% = (1/4) * 100% = 25%. The required value is 25%. Hence, the correct option is (a).
Source: SSC CGL Pattern

6. If the price of a book drops from Rs 500 to Rs 425, what is the percentage decrease?
(a) 17.65% (b) 15% (c) 12.5% (d) 14%
Answer: (b) 15%
Solution: Decrease = 500 - 425 = 75. Percentage decrease = (75 / 500) * 100% = 15%. The required value is 15%. Hence, the correct option is (b).
Source: SSC CGL Pattern

10. What percentage of 1 hour and 15 minutes is 45 minutes?
(a) 50% (b) 60% (c) 66 2/3% (d) 75%
Answer: (b) 60%
Solution: Total time 1 hour 15 minutes = 75 minutes. Percentage = (45 / 75) * 100% = (3/5) * 100% = 60%. The required value is 60%. Hence, the correct option is (b).

11. If 12.5% of a number is added to itself, the result becomes 810. Find the original number.
(a) 700 (b) 750 (c) 720 (d) 760
Answer: (c) 720
Solution: Fraction 12.5% = 1/8. Original number + (1/8)*number = (9/8)*number = 810. Number = 810 * (8/9) = 90 * 8 = 720. The required value is 720. Hence, the correct option is (c).
Source: SSC CGL Pattern

12. If 16 2/3% of a number is subtracted from itself, the result is 550. Find the original number.
(a) 600 (b) 640 (c) 700 (d) 660
Answer: (d) 660
Solution: Fraction 16 2/3% = 1/6. (1 - 1/6) = 5/6 of number = 550. Number = 550 * (6/5) = 110 * 6 = 660. The required value is 660. Hence, the correct option is (d).
Source: SSC CGL Pattern

13. In a class of 80 students, 65% are boys. How many girls are there in the class?
(a) 28 (b) 26 (c) 32 (d) 30
Answer: (a) 28
Solution: Percentage of girls = 100% - 65% = 35%. Number of girls = 80 * 0.35 = 28. The required value is 28. Hence, the correct option is (a).
Source: SSC CGL Pattern

15. If 60% of (x - y) = 40% of (x + y), find the ratio of x to y.
(a) 3 : 2 (b) 5 : 2 (c) 5 : 1 (d) 4 : 1
Answer: (c) 5 : 1
Solution: 60*(x - y) = 40*(x + y) => 3(x - y) = 2(x + y) => 3x - 3y = 2x + 2y => x = 5y => x / y = 5 / 1. The required value is 5 : 1. Hence, the correct option is (c).
Source: SSC CGL Pattern

16. Two numbers are respectively 20% and 50% more than a third number. What percentage is the first number of the second number?
(a) 70% (b) 85% (c) 75% (d) 80%
Answer: (d) 80%
Solution: Let the third number be 100. First number = 120, second number = 150. Required percentage = (120 / 150) * 100% = (4/5) * 100% = 80%. The required value is 80%. Hence, the correct option is (d).
Source: SSC CGL Pattern

18. A person spends 65% of his salary and saves Rs 5,250 per month. Find his monthly salary.

Answer: (b) Rs 15,000
Solution: Savings percentage = 100% - 65% = 35%. 35% of Salary = 5,250. Salary = 5,250 / 0.35 = 15,000. The required value is Rs 15,000. Hence, the correct option is (b).

19. If 20% of a is equal to b, then b% of 20 is the same as which of the following?
(a) 5% of a (b) 20% of a (c) 4% of a (d) 2% of a
Answer: (c) 4% of a
Solution: b = 0.20 * a. b% of 20 = (b / 100) * 20 = (0.20 * a / 100) * 20 = (4 / 100) * a = 4% of a. The required value is 4% of a. Hence, the correct option is (c).
Source: SSC CGL Pattern

22. A fruit seller had some apples. He sells 40% of them and still has 420 apples. How many apples did he have originally?
(a) 600 (b) 700 (c) 750 (d) 680
Answer: (b) 700
Solution: Remaining percentage = 100% - 40% = 60%. 60% of total apples = 420. Total = 420 / 0.60 = 700. The required value is 700. Hence, the correct option is (b).
Source: SSC CGL Pattern

23. If x% of y is 100 and y% of z is 200, find the relation between x and z.
(a) x = 2z (b) z = x (c) z = 2x (d) z = 4x
Answer: (c) z = 2x
Solution: (x * y) / 100 = 100 and (y * z) / 100 = 200. Dividing the second equation by the first: (y*z) / (x*y) = 200 / 100 => z / x = 2 => z = 2x. The required value is z = 2x. Hence, the correct option is (c).
Source: SSC CGL Pattern

24. A number is increased by 10% and then decreased by 10%. What is the net percentage change in the number?
(a) No change (b) 1% increase (c) 2% decrease (d) 1% decrease
Answer: (d) 1% decrease
Solution: Net change = a + b + (ab / 100) = 10 - 10 + (10 * (-10) / 100) = -1%. Hence, 1% decrease. The required value is 1% decrease. Hence, the correct option is (d).
Source: SSC CGL Pattern

25. If 0.08% of a number is 64, find the number.
(a) 8,000 (b) 80,000 (c) 800,000 (d) 64,000
Answer: (b) 80,000
Solution: (0.08 / 100) * n = 64 => n = (64 * 100) / 0.08 = 6400 / 0.08 = 80,000. The required value is 80,000. Hence, the correct option is (b).
Source: SSC CGL Pattern
