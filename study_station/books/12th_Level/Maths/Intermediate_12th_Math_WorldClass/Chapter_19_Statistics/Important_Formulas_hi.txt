# 📋 सांख्यिकी — महत्वपूर्ण सूत्र

## 1. केंद्रीय प्रवृत्ति के माप (Measures of Central Tendency)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| समांतर माध्य (अवर्गीकृत) | x̄ = Σx / n | सीधे दिए गए प्रेक्षणों का औसत |
| समांतर माध्य (वर्गीकृत) | x̄ = Σfx / Σf | बारंबारता सारणी दी हो तब |
| कल्पित माध्य विधि | x̄ = A + (Σfd / Σf), जहाँ d = x − A | बड़ी संख्याएँ हों तो गणना आसान करने के लिए |
| पद-विचलन विधि | x̄ = A + (Σfd′ / Σf) × h, जहाँ d′ = (x − A)/h | वर्ग-माप (h) समान हो तब |
| माध्य परिवर्तन (प्रेक्षण जुड़ने/हटने पर) | नया माध्य = (पुराना माध्य × n ± कुल परिवर्तन) / (n ± जुड़े/हटे प्रेक्षणों की संख्या) | कोई प्रेक्षण जुड़े या हटे तब — हर में n भी बदलता है |
| माध्य परिवर्तन (प्रतिस्थापन पर) | नया माध्य = (पुराना माध्य × n − गलत मान + सही मान) / n | एक प्रेक्षण दूसरे से बदले तब (n अपरिवर्तित) |
| संयुक्त माध्य | x̄ = (n₁x̄₁ + n₂x̄₂) / (n₁ + n₂) | दो समूहों का मिलाकर माध्य |
| माध्यिका (अवर्गीकृत) | n विषम: ((n+1)/2)वाँ पद; n सम: (n/2वाँ + (n/2+1)वाँ पद)/2 | आरोही क्रम में क्रमित आँकड़ों का मध्य मान |
| माध्यिका (वर्गीकृत) | M = l + [(N/2 − cf) / f] × h | N/2 से ऊपर वाला वर्ग = माध्यिका वर्ग |
| बहुलक (अवर्गीकृत) | सबसे अधिक बारंबारता वाला मान | जो मान सबसे ज़्यादा बार आए |
| बहुलक (वर्गीकृत) | Z = l + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × h | अधिकतम बारंबारता वाला वर्ग = बहुलक वर्ग |
| अनुभवजन्य संबंध | बहुलक = 3 × माध्यिका − 2 × माध्य | दो माप दिए हों, तीसरा निकालने के लिए |

## 2. विचलन के माप (Measures of Dispersion)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| परिसर (Range) | R = अधिकतम मान − न्यूनतम मान | सबसे सरल विचलन माप |
| माध्य विचलन | MD = Σ\|x − x̄\| / n | माध्य से औसत दूरी |
| प्रसरण (Variance) | σ² = Σ(x − x̄)² / n | माध्य से विचलनों के वर्गों का औसत |
| प्रसरण (वर्गीकृत) | σ² = Σf(x − x̄)² / Σf | बारंबारता सारणी के लिए |
| प्रसरण (लघु विधि) | σ² = (Σx²/n) − x̄² | सीधी गणना में तेज़ |
| मानक विचलन | σ = √प्रसरण | प्रसरण का वर्गमूल |
| विचरण गुणांक (CV) | CV = (σ / x̄) × 100 | दो श्रेणियों की स्थिरता/एकरूपता की तुलना |

## 3. अन्य महत्वपूर्ण नियम

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| चतुर्थक | Q₁ = (n+1)/4 वाँ पद; Q₃ = 3(n+1)/4 वाँ पद | आँकड़ों को चार बराबर भागों में बाँटना |
| अंतर-चतुर्थक परिसर | IQR = Q₃ − Q₁ | मध्य 50% आँकड़ों का फैलाव |
| चतुर्थक विचलन | QD = (Q₃ − Q₁) / 2 | अर्ध-अंतर-चतुर्थक परिसर |
| माध्यिका-बहुलक संबंध | माध्यिका = माध्य + (1/3)(बहुलक − माध्य) = (बहुलक + 2 × माध्य) / 3 | अनुभवजन्य संबंध का दूसरा रूप |
| भारित माध्य | x̄w = Σwx / Σw | भार (weight) दिए हों तब |
| गुणोत्तर माध्य | GM = ⁿ√(x₁·x₂·…·xₙ) | वृद्धि दरों का औसत |
| हरात्मक माध्य | HM = n / Σ(1/x) | चाल/दर का औसत (समान दूरी) |
| AM–GM–HM संबंध | AM ≥ GM ≥ HM; GM² = AM × HM | दो धनात्मक संख्याओं के लिए |

## 4. माध्य पर आधारित परीक्षा-योग्य नियम

| नियम | कथन | उपयोग-संकेत |
|---|---|---|
| प्रत्येक प्रेक्षण में स्थिरांक जोड़ने पर | नया माध्य = पुराना माध्य + k | हर प्रेक्षण में k जुड़े तो माध्य में भी k जुड़ता है (n अपरिवर्तित) |
| प्रेक्षण गुणा पर | नया माध्य = k × पुराना माध्य | हर प्रेक्षण k से गुणा हो तो माध्य भी k गुणा |
| गलत प्रेक्षण सुधार | सही योग = गलत माध्य × n − गलत मान + सही मान | "गलती से X लिखा गया, सही Y था" वाले प्रश्न |
| क्रमागत संख्याओं का माध्य | माध्य = (पहली + अंतिम) / 2 | क्रमागत/समांतर श्रेणी के प्रश्नों में तुरंत |
