# महत्वपूर्ण सूत्र (Important Formulas)

यह पृष्ठ परीक्षा में बार-बार काम आने वाले मुख्य गणितीय सूत्रों का संकलन है। हर सूत्र को याद करें और अभ्यास प्रश्नों में लगाकर देखें।

---

## 1. संख्या पद्धति (Number System)

- प्रथम n प्राकृत संख्याओं का योग = n(n + 1) / 2
- प्रथम n सम संख्याओं का योग = n(n + 1)
- प्रथम n विषम संख्याओं का योग = n²
- प्रथम n प्राकृत संख्याओं के वर्गों का योग = n(n + 1)(2n + 1) / 6
- प्रथम n प्राकृत संख्याओं के घनों का योग = [n(n + 1) / 2]²
- (a + b)² = a² + 2ab + b²
- (a − b)² = a² − 2ab + b²
- a² − b² = (a + b)(a − b)
- a³ + b³ = (a + b)(a² − ab + b²)
- a³ − b³ = (a − b)(a² + ab + b²)
- (a + b)³ = a³ + b³ + 3ab(a + b)
- (a − b)³ = a³ − b³ − 3ab(a − b)

## 2. प्रतिशत (Percentage)

- x% का भिन्न रूप = x / 100
- प्रतिशत वृद्धि = (वृद्धि / मूल मान) × 100
- प्रतिशत कमी = (कमी / मूल मान) × 100
- यदि कोई मान पहले a% बढ़े और फिर b% घटे, तो कुल परिवर्तन = a − b − (ab / 100)%
- जनसंख्या/मूल्य में लगातार वृद्धि: n वर्ष बाद मान = P(1 + r/100)ⁿ

## 3. लाभ और हानि (Profit and Loss)

- लाभ = विक्रय मूल्य (SP) − क्रय मूल्य (CP)
- हानि = क्रय मूल्य (CP) − विक्रय मूल्य (SP)
- लाभ % = (लाभ / CP) × 100
- हानि % = (हानि / CP) × 100
- SP = CP × (100 + लाभ%) / 100
- SP = CP × (100 − हानि%) / 100
- छूट = अंकित मूल्य (MP) − विक्रय मूल्य (SP)
- छूट % = (छूट / MP) × 100

## 4. साधारण और चक्रवृद्धि ब्याज (Simple & Compound Interest)

- साधारण ब्याज (SI) = (P × R × T) / 100
- मिश्रधन (साधारण ब्याज) = P + SI
- चक्रवृद्धि ब्याज पर मिश्रधन = P(1 + R/100)ᵀ
- चक्रवृद्धि ब्याज (CI) = P(1 + R/100)ᵀ − P
- 2 वर्ष के लिए CI − SI = P(R/100)²
- अर्धवार्षिक चक्रवृद्धि: दर = R/2, समय = 2T

## 5. समय और कार्य (Time and Work)

- कार्य = समय × कार्यक्षमता (दक्षता)
- यदि A काम को x दिनों में करता है, तो 1 दिन का काम = 1/x
- A और B मिलकर 1 दिन में करेंगे = 1/x + 1/y
- मिलकर पूरा काम करने का समय = xy / (x + y)

## 6. समय, चाल और दूरी (Time, Speed and Distance)

- चाल = दूरी / समय
- दूरी = चाल × समय
- समय = दूरी / चाल
- km/h को m/s में बदलने के लिए × 5/18
- m/s को km/h में बदलने के लिए × 18/5
- औसत चाल (समान दूरी, दो चालें a और b) = 2ab / (a + b)
- रेलगाड़ी किसी खंभे को पार करे: दूरी = गाड़ी की लंबाई
- रेलगाड़ी किसी पुल/प्लेटफ़ॉर्म को पार करे: दूरी = गाड़ी की लंबाई + पुल की लंबाई

## 7. अनुपात और समानुपात (Ratio and Proportion)

- a : b = c : d हो तो a × d = b × c
- यदि a : b और b : c दिया हो, तो a : b : c ज्ञात करने के लिए b के मान बराबर करें
- किसी राशि को a : b में बाँटना: पहला भाग = राशि × a / (a + b)

## 8. औसत (Average)

- औसत = सभी पदों का योग / पदों की संख्या
- यदि n संख्याओं का औसत x है, तो कुल योग = n × x

## 9. क्षेत्रमिति (Mensuration)

- वर्ग: क्षेत्रफल = भुजा², परिमाप = 4 × भुजा, विकर्ण = भुजा × √2
- आयत: क्षेत्रफल = लंबाई × चौड़ाई, परिमाप = 2(लंबाई + चौड़ाई)
- त्रिभुज: क्षेत्रफल = ½ × आधार × ऊँचाई
- समबाहु त्रिभुज: क्षेत्रफल = (√3 / 4) × भुजा²
- वृत्त: क्षेत्रफल = πr², परिधि = 2πr
- घन: आयतन = भुजा³, पृष्ठीय क्षेत्रफल = 6 × भुजा²
- घनाभ: आयतन = l × b × h, पृष्ठीय क्षेत्रफल = 2(lb + bh + hl)
- बेलन: आयतन = πr²h, वक्र पृष्ठ = 2πrh, कुल पृष्ठ = 2πr(r + h)
- शंकु: आयतन = (1/3)πr²h, वक्र पृष्ठ = πrl (जहाँ l = तिर्यक ऊँचाई)
- गोला: आयतन = (4/3)πr³, पृष्ठीय क्षेत्रफल = 4πr²

## 10. त्रिकोणमिति (Trigonometry)

- sin²θ + cos²θ = 1
- 1 + tan²θ = sec²θ
- 1 + cot²θ = cosec²θ
- sin 0° = 0, sin 30° = 1/2, sin 45° = 1/√2, sin 60° = √3/2, sin 90° = 1
- cos 0° = 1, cos 30° = √3/2, cos 45° = 1/√2, cos 60° = 1/2, cos 90° = 0
- tan 0° = 0, tan 30° = 1/√3, tan 45° = 1, tan 60° = √3
