# 🪄 Short Tricks & Mnemonics — Mensuration

---

┌─────────────────────────────────────────────┐
│ **TRICK 1 — "PAST" for the 2D Shapes**      │
├─────────────────────────────────────────────┤
│ **P**erimeter = Add Sides Totally!          │
│ Remember: **PAST** → Perimeter = Add        │
│ Sides Together.                             │
│ Whatever the shape — triangle, square,      │
│ pentagon — just walk around the boundary    │
│ and ADD every side. Perimeter is a "walk",  │
│ Area is a "carpet".                         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 2 — The Carpet vs The Fence**       │
├─────────────────────────────────────────────┤
│ **Area = Carpet (inside), Perimeter =       │
│ Fence (outside)**                           │
│ Picture your room: the CARPET covers the    │
│ floor (Area, unit²), the FENCE runs around  │
│ the garden (Perimeter, unit¹).              │
│ Exam trap: if the answer has cm², it was    │
│ an Area question — never mix the units!     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 3 — "Half-Bhuj" for Triangle Area** │
├─────────────────────────────────────────────┤
│ Area of triangle = **½ × base × height**    │
│ Memory hook: A triangle is exactly HALF of  │
│ a rectangle cut diagonally. So:             │
│ "Rectangle ka aadha bhai" → ½ × b × h.      │
│ If you forget the ½, you'll double the      │
│ answer — the most common exam trap!         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 4 — "Pi-r-squared is a PIZZA"**     │
├─────────────────────────────────────────────┤
│ Circle Area = **πr²** (a round pizza covers │
│ a surface → r²).                            │
│ Circumference = **2πr** (the crust runs     │
│ around → single r, doubled).                │
│ Keyword: **"Area is SQUARED, Crust is       │
│ DOUBLED."** Never swap them!                │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 5 — "22/7 = 3 and a bit"**          │
├─────────────────────────────────────────────┤
│ π ≈ **22/7** when radius is a multiple of 7 │
│ (7, 14, 21…) — the 7 cancels beautifully.   │
│ π ≈ **3.14** for decimals.                  │
│ Trick: see radius 14? Instantly pick 22/7   │
│ and watch the calculation melt.             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 6 — "CSA is the WALL, TSA adds      │
│ the ROOF & FLOOR"**                         │
├─────────────────────────────────────────────┤
│ Cylinder: CSA = **2πrh** (just the curved   │
│ wall — like painting a pillar).             │
│ TSA = **2πrh + 2πr²** (wall + top lid +     │
│ bottom lid).                                │
│ Hook: "TSA = CSA + 2 circles." If the box   │
│ is OPEN (no lid), subtract one πr²!         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 7 — "Cone = 1/3 of its Cylinder"**  │
├─────────────────────────────────────────────┤
│ Volume of cone = **(1/3)πr²h**              │
│ Story: 3 cones of ice-cream fill exactly 1  │
│ cylinder of the same base & height.         │
│ Acronym: **"3 CONES = 1 CAN"**              │
│ Same trick for pyramid: ⅓ × base area × h.  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 8 — "Sphere: 4 Balls, 4/3 Volume"** │
├─────────────────────────────────────────────┤
│ Surface area of sphere = **4πr²**           │
│ (4 circle-skins wrap one ball).             │
│ Volume = **(4/3)πr³**                       │
│ Chant: **"FOUR skins, FOUR-THIRDS filling."**│
│ Hemisphere? Just HALVE it — then add πr²    │
│ for the flat face in TSA!                   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 9 — "Cube: 6-12-8"**                │
├─────────────────────────────────────────────┤
│ A cube has **6 Faces, 12 Edges, 8 Vertices**│
│ Memory: **"6-12-8, the cube is great!"**    │
│ (Imagine standing at a room's corner: 8     │
│ corners, 12 edges, 6 walls.)                │
│ Also: face diagonal = a√2, body diagonal    │
│ = a√3 — "BODY is BIGGER, so √3."            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 10 — "Cuboid = Matchbox Formula"**  │
├─────────────────────────────────────────────┤
│ TSA of cuboid = **2(lb + bh + hl)**         │
│ Trick: a matchbox has 3 PAIRS of identical  │
│ faces — front/back, top/bottom, left/right. │
│ So: add the 3 different faces, then DOUBLE. │
│ Volume = l × b × h = "Length-Breadth-Height │
│ multiply karo, volume pao!"                 │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 11 — "Trapezium: Average the        │
│ Parallel Sides"**                           │
├─────────────────────────────────────────────┤
│ Area = **½ × (sum of parallel sides) × h**  │
│ Hook: the two parallel sides are two friends│
│ of different heights — take their AVERAGE,  │
│ then multiply by height.                    │
│ ½(a+b) is just the average!                 │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 12 — "Rhombus: Diagonals Dance"**   │
├─────────────────────────────────────────────┤
│ Area = **½ × d₁ × d₂**                      │
│ Picture a kite (patang): its area is half   │
│ the product of its two sticks (diagonals).  │
│ Keyword: **"KITE = ½ × stick × stick."**    │
│ Works for rhombus AND kite!                 │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 13 — "Path Problems: OUT minus IN"**│
├─────────────────────────────────────────────┤
│ Path around a rectangle (width w):          │
│ Path OUTSIDE: Area = (l+2w)(b+2w) − lb      │
│ Path INSIDE:  Area = lb − (l−2w)(b−2w)      │
│ Trick: **"Outside path → ADD 2w; Inside     │
│ path → SUBTRACT 2w."** Then big − small.    │
│ Most path questions are solved with this    │
│ one line!                                   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 14 — "Scaling: Square for Area,     │
│ Cube for Volume"**                          │
├─────────────────────────────────────────────┤
│ If radius/side becomes **k times**:         │
│ • Perimeter → k times                       │
│ • Area → **k²** times                       │
│ • Volume → **k³** times                     │
│ Acronym: **"PAV = 1-2-3"** (Perimeter-1,    │
│ Area-2, Volume-3 powers).                   │
│ Radius doubled? Area ×4, Volume ×8. Done!   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 15 — "Heron's S: Semi-perimeter     │
│ Sandwich"**                                 │
├─────────────────────────────────────────────┤
│ Area = **√[s(s−a)(s−b)(s−c)]**, s=(a+b+c)/2 │
│ Story: Hero the hero makes a SANDWICH of    │
│ four layers — s, s−a, s−b, s−c — then takes │
│ the square root (cuts it diagonally!).      │
│ Use ONLY when all 3 sides are given and     │
│ height is unknown.                          │
└─────────────────────────────────────────────┘
