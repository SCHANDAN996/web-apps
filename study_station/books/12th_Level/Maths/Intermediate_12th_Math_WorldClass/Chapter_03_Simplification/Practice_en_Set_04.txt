76. Find the sum of the series S = 1/(1*2*3) + 1/(2*3*4) + 1/(3*4*5) + 1/(4*5*6).
(a) 7/30 (b) 14/30 (c) 1/6 (d) 4/15
Answer: (a) 7/30
Solution: Using partial fractions: S = (1/2) * [1/(1*2) - 1/(5*6)] = (1/2) * [1/2 - 1/30] = (1/2) * (14/30) = 7/30. The required value is 7/30. Hence, the correct option is (a).
Source: SSC CGL Pattern

77. If x = 2 + sqrt(3), find the value of (x^4 + 1/x^4).
(a) 196 (b) 194 (c) 192 (d) 198
Answer: (b) 194
Solution: x + 1/x = (2 + sqrt(3)) + (2 - sqrt(3)) = 4. Then x^2 + 1/x^2 = 4^2 - 2 = 14. Finally x^4 + 1/x^4 = 14^2 - 2 = 194. The required value is 194. Hence, the correct option is (b).
Source: SSC CGL Pattern

84. If a = 25, b = 15, and c = -10, find the value of (a^3 + b^3 + c^3 - 3abc) / ((a - b)^2 + (b - c)^2 + (c - a)^2).

Solution: Since a^3 + b^3 + c^3 - 3abc = 0.5 * (a + b + c) * [(a - b)^2 + (b - c)^2 + (c - a)^2], the ratio is 0.5 * (a + b + c) = 0.5 * (25 + 15 - 10) = 15. The required value is 15. Hence, the correct option is (a).

100. If x = (sqrt(5) + sqrt(3)) / (sqrt(5) - sqrt(3)) and y = 1/x, find the value of (x^3 + y^3).
(a) 512 (b) 488 (c) 496 (d) 476
Answer: (b) 488
Solution: x + y = 2(5 + 3)/(5 - 3) = 8, and xy = 1. Then x^3 + y^3 = (x + y)^3 - 3xy(x + y) = 8^3 - 3(1)(8) = 512 - 24 = 488. The required value is 488. Hence, the correct option is (b).
Source: SSC CGL Pattern
