Questions 101–125: Hard

101. Find the value of (10^4 + 4 * 5^4) / (10^2 + 2 * 5^2 + 2 * 10 * 5).
(a) 50 (b) 100 (c) 25 (d) 75
Answer: (a) 50
Solution: By Sophie Germain identity: (a^4 + 4b^4) / (a^2 + 2b^2 + 2ab) = a^2 + 2b^2 - 2ab. With a = 10, b = 5: 100 + 50 - 100 = 50. The required value is 50. Hence, the correct option is (a).
Source: SSC CGL Pattern

102. If x^2 - 3x + 1 = 0, find the value of (x^5 + 1/x^5).
(a) 126 (b) 123 (c) 120 (d) 129
Answer: (b) 123
Solution: x + 1/x = 3. Then x^2 + 1/x^2 = 7 and x^3 + 1/x^3 = 18. Product (x^2 + 1/x^2)(x^3 + 1/x^3) - (x + 1/x) = 7 * 18 - 3 = 123. The required value is 123. Hence, the correct option is (b).
Source: SSC CGL Pattern

103. If x = cbrt(2 + sqrt(5)) + cbrt(2 - sqrt(5)), find the value of (x^3 + 3x).
(a) 2 (b) 0 (c) 4 (d) -4
Answer: (c) 4
Solution: Cubing both sides: x^3 = (2 + sqrt(5)) + (2 - sqrt(5)) + 3*cbrt((2+sqrt(5))(2-sqrt(5)))*x = 4 + 3(-1)x = 4 - 3x. Hence x^3 + 3x = 4. The required value is 4. Hence, the correct option is (c).
Source: SSC CGL Pattern

109. If a + 1/b = 1 and b + 1/c = 1, find the value of (c + 1/a).

Answer: (a) 1
Solution: b = 1/(1 - a). Then 1/c = 1 - b = -a/(1 - a) => c = (a - 1)/a = 1 - 1/a. Thus c + 1/a = 1. The required value is 1. Hence, the correct option is (a).

113. If x = (sqrt(2) + 1) / (sqrt(2) - 1), find the value of (x^2 + x + 1).
(a) 21 + 14*sqrt(2) (b) 21 - 14*sqrt(2) (c) 17 + 12*sqrt(2) (d) 24 + 16*sqrt(2)
Answer: (a) 21 + 14*sqrt(2)
Solution: x = (sqrt(2) + 1)^2 = 3 + 2*sqrt(2). Then x^2 - 6x + 1 = 0, so x^2 + 1 = 6x. Expression is 6x + x = 7x = 7(3 + 2*sqrt(2)) = 21 + 14*sqrt(2). The required value is 21 + 14*sqrt(2). Hence, the correct option is (a).
Source: SSC CGL Pattern

114. If a^2 + b^2 + 1/a^2 + 1/b^2 = 4 for real numbers a and b, find the value of (a^2 + b^2).
(a) 4 (b) 2 (c) 1 (d) 0
Answer: (b) 2
Solution: (a - 1/a)^2 + (b - 1/b)^2 = 4 - 4 = 0 implies a^2 = 1 and b^2 = 1. Therefore a^2 + b^2 = 2. The required value is 2. Hence, the correct option is (b).
