# महत्वपूर्ण सूत्र एवं बीजगणितीय सर्वसमिकाएं: सरलीकरण

1. VBODMAS का वरीयता क्रम:
   रेखा कोष्ठक (Vinculum) > () > {} > [] > 'का' (Of) > भाग / गुणा (बाएं से दाएं) > जोड़ / घटाव (बाएं से दाएं)

2. त्रिघात सर्वसमिकाएं:
   - a^3 + b^3 = (a + b)(a^2 - ab + b^2)
   - a^3 - b^3 = (a - b)(a^2 + ab + b^2)
   - a^3 + b^3 + c^3 - 3abc = (a + b + c)(a^2 + b^2 + c^2 - ab - bc - ca)
   - (a - b)^3 + (b - c)^3 + (c - a)^3 = 3(a - b)(b - c)(c - a)

3. द्विघात सममित संबंध:
   - (a + b)^2 + (a - b)^2 = 2(a^2 + b^2)
   - (a + b)^2 - (a - b)^2 = 4ab
   - a^2 + b^2 + c^2 - ab - bc - ca = 0.5 * [(a - b)^2 + (b - c)^2 + (c - a)^2]

4. करणी सूत्र:
   - sqrt(a + 2*sqrt(b)) = sqrt(x) + sqrt(y), जहाँ x + y = a और xy = b
   - sqrt(a - 2*sqrt(b)) = sqrt(x) - sqrt(y), जहाँ x > y, x + y = a और xy = b
   - sqrt(x + sqrt(x + ...)) = (sqrt(4x + 1) + 1) / 2
   - sqrt(x - sqrt(x - ...)) = (sqrt(4x + 1) - 1) / 2
   - sqrt(x * sqrt(x * ...)) = x

5. टेलीस्कोपिक श्रेणी सूत्र:
   - 1 / [n * (n + k)] = (1 / k) * [1/n - 1/(n + k)]
