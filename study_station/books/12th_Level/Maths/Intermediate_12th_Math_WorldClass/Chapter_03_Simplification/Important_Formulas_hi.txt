# 📋 महत्वपूर्ण सूत्र — सरलीकरण (Simplification)

## 1. क्रिया-क्रम नियम (BODMAS)

| सूत्र का नाम | सूत्र/नियम | उपयोग-संकेत |
|---|---|---|
| BODMAS क्रम | Bracket → Of → Division → Multiplication → Addition → Subtraction | हर सरलीकरण प्रश्न में पहले यही क्रम लगाएँ |
| कोष्ठक का क्रम | ( ) → { } → [ ] | छोटे कोष्ठक पहले, फिर मंजला, फिर बड़ा |
| 'का' (Of) का अर्थ | 'का' = × (गुणा) | "2/3 का 15" = 2/3 × 15 = 10 |
| रेखा-कोष्ठक (Bar/Vinculum) | a − b̅−̅c̅ = a − (b − c) | बार वाला भाग सबसे पहले हल करें |

## 2. वर्ग और घन के सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| (a + b)² | a² + 2ab + b² | दो पदों के योग का वर्ग |
| (a − b)² | a² − 2ab + b² | दो पदों के अंतर का वर्ग |
| a² − b² | (a + b)(a − b) | दो वर्गों का अंतर — तेज़ गुणा में काम आता है |
| (a + b)² + (a − b)² | 2(a² + b²) | जब योग और अंतर दोनों के वर्ग जुड़े हों |
| (a + b)² − (a − b)² | 4ab | ab निकालने की शॉर्टकट |
| (a + b)³ | a³ + 3a²b + 3ab² + b³ | योग का घन |
| (a − b)³ | a³ − 3a²b + 3ab² − b³ | अंतर का घन |
| a³ + b³ | (a + b)(a² − ab + b²) | घनों का योग |
| a³ − b³ | (a − b)(a² + ab + b²) | घनों का अंतर |
| a³ + b³ + c³ − 3abc | (a + b + c)(a² + b² + c² − ab − bc − ca) | यदि a + b + c = 0, तो a³ + b³ + c³ = 3abc |

## 3. वर्गमूल और घनमूल

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| वर्गमूल | √(a × b) = √a × √b | गुणनफल का वर्गमूल अलग-अलग निकालें |
| भाग का वर्गमूल | √(a/b) = √a / √b | भिन्न के अंदर वर्गमूल |
| घनमूल | ∛(a × b) = ∛a × ∛b | घनमूल में भी गुणा बँटता है |
| इकाई अंक से वर्गमूल | इकाई अंक 1→1/9, 4→2/8, 5→5, 6→4/6, 9→3/7, 0→0 | पूर्ण वर्ग का वर्गमूल जल्दी पहचानने में |
| पूर्ण वर्ग पहचान | वर्ग का इकाई अंक कभी 2, 3, 7, 8 नहीं होता | विकल्प काटने (elimination) में |

## 4. घातांक के नियम (Laws of Indices)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| गुणा नियम | aᵐ × aⁿ = aᵐ⁺ⁿ | आधार समान, घातें जुड़ती हैं |
| भाग नियम | aᵐ ÷ aⁿ = aᵐ⁻ⁿ | आधार समान, घातें घटती हैं |
| घात की घात | (aᵐ)ⁿ = aᵐⁿ | घातें गुणा होती हैं |
| शून्य घात | a⁰ = 1 (a ≠ 0) | किसी भी संख्या की घात 0 = 1 |
| ऋणात्मक घात | a⁻ᵐ = 1/aᵐ | ऋण घात = उल्टा |
| भिन्न घात | a^(m/n) = ⁿ√(aᵐ) | भिन्न घात = मूल |
| (ab)ᵐ | aᵐ × bᵐ | गुणनफल की घात |
| (a/b)ᵐ | aᵐ / bᵐ | भिन्न की घात |

## 5. भिन्न (Fractions)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| भिन्नों का योग | a/b + c/d = (ad + bc)/bd | हर समान करके जोड़ें |
| भिन्नों का गुणा | a/b × c/d = ac/bd | अंश × अंश, हर × हर |
| भिन्नों का भाग | a/b ÷ c/d = a/b × d/c | दूसरी भिन्न उलटकर गुणा |
| मिश्र भिन्न | p q/r = (pr + q)/r | मिश्र भिन्न को साधारण भिन्न में बदलें |
| भिन्नों की तुलना | a/b ⋛ c/d ⟺ ad ⋛ bc | तिरछा गुणा (cross-multiplication) से तुलना |

## 6. दशमलव और प्रतिशत

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| प्रतिशत → भिन्न | x% = x/100 | प्रतिशत हटाने पर 100 से भाग |
| भिन्न → प्रतिशत | a/b = (a/b × 100)% | भिन्न को 100 से गुणा |
| आवर्ती दशमलव | 0.aaa… = a/9 | एक अंक दोहराए तो हर 9 |
| दो अंक आवर्ती | 0.ababab… = ab/99 | दो अंक दोहराए तो हर 99 |
| मिश्र आवर्ती | 0.abbb… = (ab − a)/90 | बिन-दोहरा अंक के लिए हर में 0 |

## 8. श्रेणी के योग (Series)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| प्रथम n प्राकृत संख्याओं का योग | n(n + 1)/2 | 1 + 2 + 3 + … + n |
| प्रथम n वर्गों का योग | n(n + 1)(2n + 1)/6 | 1² + 2² + … + n² |
| प्रथम n घनों का योग | [n(n + 1)/2]² | 1³ + 2³ + … + n³ |
| प्रथम n सम संख्याओं का योग | n(n + 1) | 2 + 4 + 6 + … + 2n |
| प्रथम n विषम संख्याओं का योग | n² | 1 + 3 + 5 + … (n पद) |

## 9. तेज़ गुणा के सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| 5 से गुणा | a × 5 = (a × 10)/2 | आधा करके 0 लगाएँ |
| 25 से गुणा | a × 25 = (a × 100)/4 | 100 से गुणा, 4 से भाग |
| 125 से गुणा | a × 125 = (a × 1000)/8 | 1000 से गुणा, 8 से भाग |
| 11 से गुणा (दो अंक) | (10a + b) × 11 = 100a + 10(a + b) + b | अंकों का योग बीच में रखें; यदि a + b ≥ 10 हो, तो बीच में (a + b) का इकाई अंक लिखें और 1 हासिल (carry) बाएँ अंक में जोड़ें — जैसे 76 × 11 = 7 (7+6=13) 6 → 836 |
| निकट-वर्ग गुणा | (a + b)(a − b) = a² − b² | जैसे 48 × 52 = 50² − 2² = 2496 |
| 9, 99, 999 से गुणा | a × 99 = a × 100 − a | एक कम करके पूरक लगाएँ |

## 10. विभाज्यता के नियम (Divisibility)

| संख्या | नियम | उपयोग-संकेत |
|---|---|---|
| 2 | इकाई अंक सम (0, 2, 4, 6, 8) | शेषफल/भाग जाँच में |
| 3 | अंकों का योग 3 से विभाज्य | बड़ी संख्या की जाँच |
| 4 | अंतिम दो अंक 4 से विभाज्य | त्वरित जाँच |
| 5 | इकाई अंक 0 या 5 | त्वरित जाँच |
| 6 | 2 और 3 दोनों से विभाज्य | संयुक्त जाँच |
| 8 | अंतिम तीन अंक 8 से विभाज्य | त्वरित जाँच |
| 9 | अंकों का योग 9 से विभाज्य | बड़ी संख्या की जाँच |
| 11 | (विषम स्थानों के अंकों का योग) − (सम स्थानों के अंकों का योग) = 0 या 11 का गुणज | 11 की जाँच |
