51. Find the value of the continued fraction x = 1 + 1 / (1 + 1 / (1 + 1/3)).
(a) 11/7 (b) 7/4 (c) 4/3 (d) 8/7
Answer: (a) 11/7
Solution: Bottom-up evaluation: 1 + 1/3 = 4/3. Then 1 + 1/(4/3) = 1 + 3/4 = 7/4. Finally x = 1 + 1/(7/4) = 1 + 4/7 = 11/7. The required value is 11/7. Hence, the correct option is (a).
Source: SSC CGL Pattern

52. If 5/14 = 1 / (x + 1 / (y + 1/z)), where x, y, z are positive integers, find the value of (x + y + z).
(a) 8 (b) 7 (c) 6 (d) 9
Answer: (b) 7
Solution: 14/5 = 2 + 4/5 = 2 + 1/(5/4) = 2 + 1/(1 + 1/4). Thus x = 2, y = 1, z = 4. Sum = 2 + 1 + 4 = 7. The required value is 7. Hence, the correct option is (b).
Source: SSC CGL Pattern

53. Find the sum of the telescoping series S = 1/(1*3) + 1/(3*5) + 1/(5*7) + ... + 1/(19*21).

Answer: (c) 10/21
Solution: Common difference d = 2. S = (1/2) * [1/1 - 1/21] = (1/2) * (20/21) = 10/21. The required value is 10/21. Hence, the correct option is (c).

55. For distinct real numbers x, y, z, find the value of [(x - y)^3 + (y - z)^3 + (z - x)^3] / [9(x - y)(y - z)(z - x)].
(a) 1/3 (b) 1 (c) 3 (d) 1/9
Answer: (a) 1/3
Solution: Let u = x - y, v = y - z, w = z - x. Then u + v + w = 0, so u^3 + v^3 + w^3 = 3uvw. The fraction becomes 3uvw / 9uvw = 1/3. The required value is 1/3. Hence, the correct option is (a).
Source: SSC CGL Pattern

56. Find the value of the infinite radical x = sqrt(20 - sqrt(20 - sqrt(20 - ...))).
(a) 5 (b) 4 (c) 2 (d) 10
Answer: (b) 4
Solution: x^2 = 20 - x => x^2 + x - 20 = 0 => (x + 5)(x - 4) = 0. Since x > 0, x = 4. The required value is 4. Hence, the correct option is (b).

57. Evaluate the infinite radical expression x = sqrt(7 * sqrt(7 * sqrt(7 * ...))).

Answer: (c) 7
Solution: Squaring both sides: x^2 = 7x => x(x - 7) = 0. Since x != 0, x = 7. The required value is 7. Hence, the correct option is (c).

58. Find the value of sqrt(3 * sqrt(3 * sqrt(3 * sqrt(3)))) having exactly four nested square roots.
(a) 3^(7/8) (b) 3^(31/32) (c) 3 (d) 3^(15/16)
Answer: (d) 3^(15/16)
Solution: For n nested roots, the exponent is (2^n - 1) / 2^n. For n = 4, exponent is (16 - 1) / 16 = 15/16, so the value is 3^(15/16). The required value is 3^(15/16). Hence, the correct option is (d).

59. If x = (sqrt(5) + 1) / (sqrt(5) - 1) and y = (sqrt(5) - 1) / (sqrt(5) + 1), find the value of (x^2 + y^2).
(a) 7 (b) 9 (c) 11 (d) 5
Answer: (a) 7
Solution: x + y = 2(5 + 1) / (5 - 1) = 12 / 4 = 3, and xy = 1. Then x^2 + y^2 = (x + y)^2 - 2xy = 3^2 - 2(1) = 7. The required value is 7. Hence, the correct option is (a).

64. If x + 1/x = 4, find the value of (x^3 + 1/x^3).

Answer: (b) 52
Solution: x^3 + 1/x^3 = (x + 1/x)^3 - 3(x + 1/x) = 4^3 - 3(4) = 64 - 12 = 52. The required value is 52. Hence, the correct option is (b).
