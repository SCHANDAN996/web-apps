# 🪄 सरलीकरण — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

**🎯 ट्रिक 1: BODMAS का जादुई मंत्र — "बड़े ओफ दादा माँ आए ससुराल"**

```
┌─────────────────────────────────────────────┐
│ B → Bracket (कोष्ठक)                        │
│ O → Of (का)                                 │
│ D → Division (भाग)                          │
│ M → Multiplication (गुणा)                   │
│ A → Addition (जोड़)                         │
│ S → Subtraction (घटाव)                      │
│                                             │
│ याद करो: "बड़े ओफ दादा माँ आए ससुराल"      │
│ ब-ओ-द-म-आ-स = B-O-D-M-A-S                  │
└─────────────────────────────────────────────┘
```
क्रम कभी मत बदलो — पहले कोष्ठक, फिर 'का', फिर भाग-गुणा, फिर जोड़-घटाव!

**🎯 ट्रिक 2: कोष्ठकों का क्रम — "छोटा भाई पहले, बड़ा बाद में"**

```
┌─────────────────────────────────────────────┐
│ क्रम: ( ) → { } → [ ]                       │
│                                             │
│ याद करो: परिवार में खाना पहले सबसे छोटे    │
│ बच्चे ( ) को, फिर बीच वाले { } को,         │
│ फिर सबसे बड़े [ ] को मिलता है।             │
│                                             │
│ सुलझाओ भी उसी क्रम में: अंदर से बाहर!      │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 3: 'Of' का धोखा — "का = गुणा, पर पहले!"**

```
┌─────────────────────────────────────────────┐
│ "का" (of) देखते ही × लगाओ,                 │
│ पर याद रखो — यह ÷ से भी पहले होता है!      │
│                                             │
│ जैसे: 24 ÷ 4 का 2 = 24 ÷ (4×2) = 3         │
│ (गलती: 24÷4=6, फिर 6×2=12 ✗)              │
│                                             │
│ मंत्र: "का है तो पहले बांध दो!"            │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 4: 5 से गुणा — "आधा करके शून्य लगाओ"**

```
┌─────────────────────────────────────────────┐
│ किसी संख्या × 5 = (संख्या ÷ 2) × 10        │
│                                             │
│ जैसे: 248 × 5 → 248 का आधा = 124 → 1240    │
│                                             │
│ ट्रिक: "पाँच का खेल — आधा-आधा,             │
│ पीछे शून्य का मेला!"                        │
└─────────────────────────────────────────────┘
```

---

**🎯 ट्रिक 5: 25 से गुणा — "चौथाई करके दो शून्य"**

```
┌─────────────────────────────────────────────┐
│ संख्या × 25 = (संख्या ÷ 4) × 100           │
│                                             │
│ जैसे: 84 × 25 → 84 ÷ 4 = 21 → 2100         │
│                                             │
│ याद करो: 25 पैसे = चौथाई रुपया!            │
│ 4 चौथाई = 100 पैसे (1 रुपया)               │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 6: 125 से गुणा — "आठवाँ हिस्सा, तीन शून्य"**

```
┌─────────────────────────────────────────────┐
│ संख्या × 125 = (संख्या ÷ 8) × 1000         │
│                                             │
│ जैसे: 64 × 125 → 64 ÷ 8 = 8 → 8000         │
│                                             │
│ श्रृंखला याद करो: 5→2, 25→4, 125→8         │
│ (हर बार दोगुना: 2, 4, 8)                   │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 7: 11 से गुणा — "जोड़कर बीच में भरो"**

```
┌─────────────────────────────────────────────┐
│ दो अंकों की संख्या × 11:                   │
│ अंकों को जोड़ो, बीच में रखो!               │
│                                             │
│ जैसे: 43 × 11 → 4 _ 3 → 4+3=7 → 473        │
│                                             │
│ अगर जोड़ 10 से ज़्यादा हो:                 │
│ 85 × 11 → 8+5=13 → 8+1=9, बीच में 3 → 935  │
│                                             │
│ मंत्र: "ग्यारह का सैंडविच — जोड़ बीच में!" │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 8: 9, 99, 999 से गुणा — "एक कम, फिर पूरक"**

```
┌─────────────────────────────────────────────┐
│ संख्या × 9 = संख्या × 10 − संख्या          │
│ संख्या × 99 = संख्या × 100 − संख्या        │
│                                             │
│ जैसे: 47 × 99 = 4700 − 47 = 4653           │
│                                             │
│ याद करो: "नौ का नखरा — दस बनकर             │
│ एक अपना वापस लेता है!"                     │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 9: वर्ग अंत 5 वाले — "पाँच-पच्चीस, आगे गुणा-बढ़िया"**

```
┌─────────────────────────────────────────────┐
│ (X5)² = X × (X+1) के आगे 25 लगाओ           │
│                                             │
│ जैसे: 75² → 7 × 8 = 56 → 5625              │
│       115² → 11 × 12 = 132 → 13225         │
│                                             │
│ मंत्र: "पीछे पच्चीस पक्का,                 │
│ आगे अंक अपने अगले से गुणा!"                │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 10: a² − b² — "जोड़-घटाव का हाथ मिलाओ"**

```
┌─────────────────────────────────────────────┐
│ a² − b² = (a + b)(a − b)                   │
│                                             │
│ जैसे: 102² − 98² = (102+98)(102−98)        │
│                  = 200 × 4 = 800           │
│                                             │
│ याद करो: "दो वर्गों की लड़ाई में            │
│ जोड़ और घटाव हाथ मिला लेते हैं!"           │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 11: (a+b)² और (a−b)² — "पहला-दूसरा, दोगुना बीच का"**

```
┌─────────────────────────────────────────────┐
│ (a+b)² = a² + 2ab + b²                     │
│ (a−b)² = a² − 2ab + b²                     │
│                                             │
│ कहानी: पहले का वर्ग + आखिरी का वर्ग,       │
│ बीच में दोनों की दोगुनी दोस्ती (2ab)।      │
│ जोड़ में दोस्ती खुश (+),                   │
│ घटाव में दोस्ती नाराज़ (−)!                │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 12: भिन्नों की तुलना — "क्रॉस गुणा, तीर की जंग"**

```
┌─────────────────────────────────────────────┐
│ 3/7 बनाम 4/9 — कौन बड़ा?                   │
│                                             │
│ क्रॉस गुणा: 3×9 = 27  और  4×7 = 28         │
│ 28 > 27, इसलिए 4/9 बड़ा!                   │
│                                             │
│ ट्रिक: "तीर चलाओ ऊपर की ओर —               │
│ जिस तीर का अंक बड़ा, वही भिन्न बड़ी!"      │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 13: प्रतिशत ↔ भिन्न — "परिवार की याददाश्त"**

```
┌─────────────────────────────────────────────┐
│ 1/2 = 50%    1/3 = 33.33%   1/4 = 25%      │
│ 1/5 = 20%    1/6 = 16.66%   1/8 = 12.5%    │
│ 1/10 = 10%   1/12 = 8.33%   1/16 = 6.25%   │
│                                             │
│ ट्रिक: "हर जितना बड़ा, प्रतिशत उतना छोटा"  │
│ 1/8 = 12.5% याद रहे, तो 3/8 = 37.5%        │
│ (बस गुणा कर दो!)                            │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 16: लोकस विधि — "BODMAS की सीढ़ी"**

```
┌─────────────────────────────────────────────┐
│ अपने घर की सीढ़ी कल्पना करो (ऊपर से नीचे): │
│                                             │
│ छत      → Bracket (छत सबसे पहले बनती है)   │
│ दरवाज़ा  → Of ('का' का दरवाज़ा)            │
│ कमरा    → Division (कमरे बाँटे जाते हैं)   │
│ सामान   → Multiplication (सामान गुणा बढ़ता)│
│ रसोई    → Addition (रसोई में जुड़ता है)    │
│ कूड़ादान → Subtraction (कचरा घटता है)      │
│                                             │
│ घर घूमते ही क्रम याद!                      │
└─────────────────────────────────────────────┘
```
