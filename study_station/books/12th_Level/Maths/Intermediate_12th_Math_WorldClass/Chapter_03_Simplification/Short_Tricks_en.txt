# 🪄 Short Tricks — Simplification (Memory Tricks)

---

┌─────────────────────────────────────────────┐
│ **TRICK 1 — The BODMAS Policeman** 🚔        │
├─────────────────────────────────────────────┤
│ Imagine a strict traffic policeman named     │
│ **B.O.D.M.A.S.** who controls the order of   │
│ vehicles at a crossing:                      │
│ **B**rackets stop first, then **O**rders     │
│ (powers), then **D**ivision & **M**ultipli-  │
│ cation race together (left to right), and    │
│ **A**ddition & **S**ubtraction walk last.    │
│ 🧠 Chant: "**B**ig **O**fficers **D**rive    │
│ **M**adly, **A**unt **S**houts!"             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 2 — The Bracket Onion** 🧅           │
├─────────────────────────────────────────────┤
│ Brackets are an onion — peel from INSIDE     │
│ out: ( ) → { } → [ ].                        │
│ 🧠 Memory line: "**S**mall **C**urly **B**ig │
│ boys" — Small ( ), Curly { }, Big [ ].       │
│ Never peel the outer layer first, or the     │
│ onion (and your answer) makes you cry!       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 3 — The Bar is a Hidden Bracket** 📏 │
├─────────────────────────────────────────────┤
│ A vinculum (bar) drawn over a whole          │
│ expression, like 5 + 3 × 2̅  (bar over the    │
│ full "3 × 2"), is a NINJA bracket —          │
│ invisible but strikes FIRST, even before     │
│ ( ). So 5 + 3 × 2̅ = 5 + 6 = 11.              │
│ Remember: the bar must cover an EXPRESSION,  │
│ not a single digit — a bar over one digit    │
│ alone does nothing.                          │
│ 🧠 Trick: "**Bar Before Bracket**" — B-B,    │
│ like a baby saying "ba-ba" comes before      │
│ everything else.                             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 4 — The ×5 Half-Ten Trick** ✋       │
├─────────────────────────────────────────────┤
│ To multiply any number by 5:                 │
│ Cut it in HALF, then stick a ZERO (×10).     │
│ 246 × 5 → half of 246 = 123 → 1230.          │
│ 🧠 Picture: a hand (5 fingers) chops the     │
│ number in half, then a zero balloon inflates │
│ it back. "Half, then balloon!"               │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 5 — The ×25 Quarter-Century** 🪙     │
├─────────────────────────────────────────────┤
│ 25 = 100/4. So ×25 = divide by 4, add two    │
│ zeros.  48 × 25 → 48/4 = 12 → 1200.          │
│ 🧠 Loci: imagine a 25-paise coin cut into    │
│ 4 quarters, then a ₹100 note appears.        │
│ "Quarter it, then make it a century!"        │
│ Same family: ×50 → half, two zeros;          │
│ ×125 → divide by 8, three zeros.             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 6 — The 9-Finger Multiplier** 🖐️     │
├─────────────────────────────────────────────┤
│ ×9 = ×10 minus the number itself.            │
│ 37 × 9 = 370 − 37 = 333.                     │
│ ×99 = ×100 minus the number.                 │
│ 🧠 Acronym: "**N**ine is **N**early ten —    │
│ give ten, take one back." The shopkeeper     │
│ gives you 10, you return 1.                  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 7 — The (a+b)(a−b) Twin Houses** 🏠🏠│
├─────────────────────────────────────────────┤
│ a² − b² = (a+b)(a−b). Two twin brothers      │
│ live in two houses: one ADDS, one SUBTRACTS. │
│ 103 × 97 = (100+3)(100−3) = 10000 − 9 = 9991.│
│ 🧠 Trick: "Same middle, opposite signs —     │
│ square the big, square the small, subtract." │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 8 — The (a+b)² Sandwich** 🥪         │
├─────────────────────────────────────────────┤
│ (a+b)² = a² + 2ab + b².                      │
│ It's a sandwich: bread a² on top, bread b²   │
│ at bottom, and DOUBLE filling 2ab inside.    │
│ 52² = 2500 + 200 + 4 = 2704 (a=50, b=2).     │
│ 🧠 "First² + twice-both + last²" — say it    │
│ like a rap: "First-squared, twice-both,      │
│ last-squared!"                               │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 9 — The Percentage Swap** 🔄         │
├─────────────────────────────────────────────┤
│ x% of y = y% of x. Always!                   │
│ 8% of 25 = 25% of 8 = 2. Pick the easier     │
│ side!                                        │
│ 🧠 Picture two friends swapping seats on a   │
│ bus — the journey (answer) stays the same.   │
│ "Percent friends can swap seats!"            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 10 — The Fraction-Percent Family** 👨‍👩‍👧│
├─────────────────────────────────────────────┤
│ Memorise the family photo:                   │
│ 1/2=50%, 1/3=33.33%, 1/4=25%, 1/5=20%,       │
│ 1/6=16.66%, 1/8=12.5%, 1/10=10%, 1/12=8.33%. │
│ 🧠 Loci: walk through your house — door is   │
│ 1/2 (50%), window 1/4 (25%), fan 1/5 (20%),  │
│ table 1/8 (12.5%). One walk = full table!    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 11 — The 11 Sandwich Split** 🍔      │
├─────────────────────────────────────────────┤
│ ×11 for 2-digit numbers: split the digits,   │
│ put their SUM in the middle.                 │
│ 43 × 11 → 4 _(4+3)_ 3 = 473.                 │
│ If sum > 9, carry 1: 85 × 11 → 8_13_5 = 935. │
│ 🧠 "Split the burger, stuff the sum inside!" │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 12 — The Divisibility Detective** 🕵️ │
├─────────────────────────────────────────────┤
│ Quick checks before dividing:                │
│ • 3 & 9 → digit SUM divisible by 3/9         │
│ • 4 → last TWO digits divisible by 4         │
│ • 8 → last THREE digits divisible by 8       │
│ • 11 → (sum of odd places) − (sum of even    │
│   places) = 0 or multiple of 11              │
│ 🧠 Acronym: "**S**um for **3**-**9**,        │
│ **T**ails for **4**-**8**, **S**ee-saw       │
│ for **11**" (S-T-S = "Sit, Test, Solve!")    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 13 — The Squares-Ending-in-5 Gun** 🔫│
├─────────────────────────────────────────────┤
│ Any number ending in 5: (N5)² = N×(N+1) then │
│ glue 25 at the end.                          │
│ 75² → 7×8 = 56, glue 25 → 5625.              │
│ 🧠 "Shoot the number at its next neighbour,  │
│ then stick a 25 bullet at the end!"          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 14 — The Approximation Ruler** 📐    │
├─────────────────────────────────────────────┤
│ In exams, when options are far apart, ROUND  │
│ first, calculate fast: 49.8% of 401 ≈ 50%    │
│ of 400 = 200.                                │
│ 🧠 Trick: "**F**ar **O**ptions = **F**ast    │
│ **R**ounding" (FO-FR: "Go For it, Friend!"). │
│ Close options = full calculation. The ruler  │
│ measures the OPTIONS first, not the numbers! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **TRICK 15 — The Reciprocal Ladder** 🪜      │
├─────────────────────────────────────────────┤
│ Dividing by a fraction = multiplying by its  │
│ flip: a ÷ (b/c) = a × (c/b).                 │
│ 🧠 Picture the fraction doing a SOMERSAULT   │
│ on a ladder — it flips upside down, and the  │
│ ÷ sign somersaults into ×.                   │
│ "Flip the second, change the sign!"          │
└─────────────────────────────────────────────┘
