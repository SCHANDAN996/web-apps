1. Find the value of 48 / 12 * (9 - 5) + 3.
(a) 19 (b) 4 (c) 16 (d) 22
Answer: (a) 19
Solution: First evaluate parentheses: 9 - 5 = 4. Next division: 48 / 12 = 4. Then multiplication: 4 * 4 = 16. Finally addition: 16 + 3 = 19. The required value is 19. Hence, the correct option is (a).
Source: SSC CGL Pattern

2. Find the value of 240 / [8 * (3 + 2)] of 2.
(a) 12 (b) 3 (c) 6 (d) 24
Answer: (b) 3
Solution: Inside brackets: 3 + 2 = 5, then 8 * 5 = 40. By VBODMAS, 'of' precedes division: 40 of 2 = 80. Then 240 / 80 = 3. The required value is 3. Hence, the correct option is (b).
Source: SSC CGL Pattern

3. Evaluate: 15 + 6 * (4 - 1)^2 - 20 / 4.
(a) 59 (b) 69 (c) 64 (d) 74
Answer: (c) 64
Solution: (4 - 1)^2 = 3^2 = 9. Multiplication gives 6 * 9 = 54. Division gives 20 / 4 = 5. Total = 15 + 54 - 5 = 64. The required value is 64. Hence, the correct option is (c).
Source: SSC CGL Pattern

5. Evaluate: (0.35 * 0.35 - 0.15 * 0.15) / (0.35 - 0.15).
(a) 0.50 (b) 0.20 (c) 0.70 (d) 0.40
Answer: (a) 0.50
Solution: Using identity (a^2 - b^2) / (a - b) = a + b. Here a = 0.35 and b = 0.15. Value = 0.35 + 0.15 = 0.50. The required value is 0.50. Hence, the correct option is (a).
