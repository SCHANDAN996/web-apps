126. Find the value of 1 / (1 + sqrt(2) + sqrt(3)) + 1 / (1 - sqrt(2) + sqrt(3)).
(a) 1 (b) sqrt(2) (c) sqrt(3) (d) 2
Answer: (a) 1
Solution: Group as (1 + sqrt(3)) +- sqrt(2). Sum = 2(1 + sqrt(3)) / [(1 + sqrt(3))^2 - 2] = 2(1 + sqrt(3)) / [2 + 2*sqrt(3)] = 1. The required value is 1. Hence, the correct option is (a).
Source: SSC CGL Pattern

127. If x = (sqrt(3) + 1) / 2, find the value of (4x^3 + 2x^2 - 8x + 7).
(a) 8 (b) 10 (c) 12 (d) 6
Answer: (b) 10
Solution: 2x - 1 = sqrt(3) => 4x^2 - 4x - 2 = 0 => 2x^2 - 2x - 1 = 0. Dividing 4x^3 + 2x^2 - 8x + 7 by (2x^2 - 2x - 1) gives remainder 10. The required value is 10. Hence, the correct option is (b).
Source: SSC CGL Pattern

128. Evaluate the telescoping series S = 3/(1^2 * 2^2) + 5/(2^2 * 3^2) + 7/(3^2 * 4^2) + ... + 19/(9^2 * 10^2).
(a) 19/100 (b) 9/10 (c) 99/100 (d) 1
Answer: (c) 99/100
Solution: Each term is [(k+1)^2 - k^2] / [k^2 * (k+1)^2] = 1/k^2 - 1/(k+1)^2. Telescoping sum = 1/1^2 - 1/10^2 = 1 - 1/100 = 99/100. The required value is 99/100. Hence, the correct option is (c).
Source: SSC CGL Pattern

129. If x^4 + 1/x^4 = 727 for x > 1, find the value of (x - 1/x).
(a) 27 (b) sqrt(29) (c) 25 (d) 5
Answer: (d) 5
Solution: (x^2 + 1/x^2)^2 = 727 + 2 = 729 => x^2 + 1/x^2 = 27. Then (x - 1/x)^2 = 27 - 2 = 25. For x > 1, x - 1/x = 5. The required value is 5. Hence, the correct option is (d).
Source: SSC CGL Pattern

130. Find the value of cbrt(sqrt(5) + 2) - cbrt(sqrt(5) - 2).
(a) 1 (b) 2 (c) sqrt(5) (d) 0

Solution: Let x = u - v. Then uv = cbrt(5 - 4) = 1. x^3 = (sqrt(5)+2) - (sqrt(5)-2) - 3(1)x = 4 - 3x. Then x^3 + 3x - 4 = 0 has real root x = 1. The required value is 1. Hence, the correct option is (a).

132. If a = (sqrt(5) + 1)/(sqrt(5) - 1) and b = (sqrt(5) - 1)/(sqrt(5) + 1), find (a^2 + ab + b^2) / (a^2 - ab + b^2).
(a) 3/4 (b) 5/3 (c) 4/3 (d) 7/6
Answer: (c) 4/3
Solution: a + b = 3, ab = 1 => a^2 + b^2 = 7. Numerator = 7 + 1 = 8. Denominator = 7 - 1 = 6. Ratio = 8/6 = 4/3. The required value is 4/3. Hence, the correct option is (c).

133. If x = (sqrt(a + 2b) + sqrt(a - 2b)) / (sqrt(a + 2b) - sqrt(a - 2b)), find the value of (bx^2 - ax + b).

Answer: (d) 0
Solution: Applying componendo and dividendo: (x + 1)/(x - 1) = sqrt(a + 2b)/sqrt(a - 2b). Squaring and applying C&D again gives b(x^2 + 1) = ax, so bx^2 - ax + b = 0. The required value is 0. Hence, the correct option is (d).

137. If x + y + z = 1, xy + yz + zx = -1, and xyz = -1, find the value of (x^3 + y^3 + z^3).

Answer: (d) 1
Solution: x^3 + y^3 + z^3 - 3xyz = (x + y + z)[(x + y + z)^2 - 3(xy + yz + zx)] = 1 * [1 - 3(-1)] = 4. Then x^3 + y^3 + z^3 = 4 + 3(-1) = 1. The required value is 1. Hence, the correct option is (d).

149. If real numbers a, b, c satisfy a + b + c = 0 and a^2 + b^2 + c^2 = 16, find the value of (a^4 + b^4 + c^4).

Answer: (d) 128
Solution: ab + bc + ca = -8. Then a^2*b^2 + b^2*c^2 + c^2*a^2 = (-8)^2 = 64. Thus a^4 + b^4 + c^4 = (16)^2 - 2(64) = 256 - 128 = 128. The required value is 128. Hence, the correct option is (d).
Source: SSC CGL Pattern
