# Pattern Analysis: Simplification & Approximation (Intermediate / 12th Level)

Analysis of recurring patterns from SSC CGL Tier-2, IBPS PO, and State PCS examinations:
- Dominant Question Types:
  1. Multi-layered VBODMAS expressions involving vinculum and 'of' operations.
  2. Algebraic camouflage using decimal numbers representing cubic sum identities.
  3. Infinite nested radicals and continued fractions with variable equating.
  4. Telescoping partial fraction series with varying denominator common differences.

---

Q1. (Medium) Find the value of 1800 / [10 * {(12 - 6) + (24 - 12)}] of 2.
(A) 5  (B) 10  (C) 20  (D) 1
Answer: (A)
Solution: Inside brackets: (12 - 6) + (24 - 12) = 6 + 12 = 18. Inside braces: 10 * 18 = 180. The expression becomes 1800 / [180] of 2. By VBODMAS, 'of' has precedence over division: 180 of 2 = 360. Then 1800 / 360 = 5. Therefore, the correct value is 5, corresponding to option (A).
Source: SSC CGL Pattern

Q2. (Medium) Evaluate: (0.76 * 0.76 * 0.76 + 0.24 * 0.24 * 0.24) / (0.76 * 0.76 - 0.76 * 0.24 + 0.24 * 0.24).
(A) 0.52  (B) 1.0  (C) 0.76  (D) 0.24
Answer: (B)
Solution: Notice the algebraic form (a^3 + b^3) / (a^2 - ab + b^2) where a = 0.76 and b = 0.24. This simplifies directly to a + b = 0.76 + 0.24 = 1.0. Therefore, the correct value is 1.0, corresponding to option (B).
Source: SSC CGL Pattern

Q3. (Medium) Find the value of sqrt(7 + 2 * sqrt(10)) + sqrt(7 - 2 * sqrt(10)).
(A) 2*sqrt(2)  (B) 2*sqrt(5)  (C) sqrt(10)  (D) 7
Answer: (B)
Solution: Find numbers x and y such that x + y = 7 and xy = 10. The numbers are 5 and 2. Thus sqrt(7 + 2*sqrt(10)) = sqrt(5) + sqrt(2) and sqrt(7 - 2*sqrt(10)) = sqrt(5) - sqrt(2). Their sum is (sqrt(5) + sqrt(2)) + (sqrt(5) - sqrt(2)) = 2*sqrt(5). Therefore, the correct value is 2*sqrt(5), corresponding to option (B).
Source: State PCS Pattern

Q4. (Hard) If x = 1 + 1 / (1 + 1 / (1 + 1/2)), find the value of 2x + 4/5.
(A) 3  (B) 4  (C) 5  (D) 19/5
Answer: (B)
Solution: Bottom-up evaluation: 1 + 1/2 = 3/2. Next: 1 + 1/(3/2) = 1 + 2/3 = 5/3. Then: x = 1 + 1/(5/3) = 1 + 3/5 = 8/5. Evaluating 2x + 4/5: 2(8/5) + 4/5 = 16/5 + 4/5 = 20/5 = 4. Therefore, the correct value is 4, corresponding to option (B).
Source: SSC CGL Pattern

Q5. (Hard) Find the sum of the series S = 1/(1*4) + 1/(4*7) + 1/(7*10) + ... + 1/(16*19).
(A) 5/19  (B) 6/19  (C) 18/19  (D) 1/19
Answer: (B)
Solution: Common difference between factors is d = 3. Decomposing: S = (1/3) * [(1/1 - 1/4) + (1/4 - 1/7) + ... + (1/16 - 1/19)]. Telescoping cancellation yields S = (1/3) * [1 - 1/19] = (1/3) * (18/19) = 6/19. Therefore, the correct value is 6/19, corresponding to option (B).
Source: SSC CGL Pattern

Q6. (Medium) If a = 997, b = 998, c = 999, find the value of a^2 + b^2 + c^2 - ab - bc - ca.
(A) 1  (B) 3  (C) 6  (D) 0
Answer: (B)
Solution: Using identity a^2 + b^2 + c^2 - ab - bc - ca = 0.5 * [(a - b)^2 + (b - c)^2 + (c - a)^2]. Here a - b = -1, b - c = -1, c - a = 2. Value = 0.5 * [(-1)^2 + (-1)^2 + 2^2] = 0.5 * [1 + 1 + 4] = 0.5 * 6 = 3. Therefore, the correct value is 3, corresponding to option (B).
Source: SSC CGL Pattern

Q7. (Hard) Evaluate the infinite radical x = sqrt(12 + sqrt(12 + sqrt(12 + ...))).
(A) 3  (B) 4  (C) 6  (D) 12
Answer: (B)
Solution: Squaring both sides: x^2 = 12 + x, which gives x^2 - x - 12 = 0. Factoring: (x - 4)(x + 3) = 0. Since x > 0, x = 4. Therefore, the correct value is 4, corresponding to option (B).
Source: IBPS PO Pattern

Q8. (Hard) If a + b + c = 0, what is the value of (a + b)^3 + (b + c)^3 + (c + a)^3?
(A) 0  (B) -3abc  (C) 3abc  (D) 3(a^3 + b^3 + c^3)
Answer: (B)
Solution: Since a + b + c = 0, we have a + b = -c, b + c = -a, c + a = -b. Substituting gives (-c)^3 + (-a)^3 + (-b)^3 = -(a^3 + b^3 + c^3). Since a + b + c = 0, a^3 + b^3 + c^3 = 3abc. Hence the value is -3abc. Therefore, the correct value is -3abc, corresponding to option (B).
Source: State PCS Pattern

Q9. (Medium) Approximate the value of sqrt(49.08 * 16.02) + 12.01 * 5.98.
(A) 92  (B) 100  (C) 84  (D) 110
Answer: (B)
Solution: Approximating to nearest round numbers: sqrt(49 * 16) + 12 * 6 = (7 * 4) + 72 = 28 + 72 = 100. Therefore, the approximate value is 100, corresponding to option (B).
Source: IBPS PO Pattern

Q10. (Hard) Find the value of 1 / (sqrt(9) - sqrt(8)) - 1 / (sqrt(8) - sqrt(7)) + 1 / (sqrt(7) - sqrt(6)) - 1 / (sqrt(6) - sqrt(5)) + 1 / (sqrt(5) - sqrt(4)).
(A) 5  (B) 1  (C) 0  (D) 3
Answer: (A)
Solution: Rationalizing each term 1 / (sqrt(n) - sqrt(n-1)) gives (sqrt(n) + sqrt(n-1)). The series becomes: (sqrt(9) + sqrt(8)) - (sqrt(8) + sqrt(7)) + (sqrt(7) + sqrt(6)) - (sqrt(6) + sqrt(5)) + (sqrt(5) + sqrt(4)). All intermediate terms cancel, leaving sqrt(9) + sqrt(4) = 3 + 2 = 5. Therefore, the correct value is 5, corresponding to option (A).
Source: SSC CGL Pattern
