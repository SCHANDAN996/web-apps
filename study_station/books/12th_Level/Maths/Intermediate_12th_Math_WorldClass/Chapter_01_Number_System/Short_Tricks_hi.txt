# 🪄 संख्या प्रणाली (उन्नत) — शॉर्ट ट्रिक्स

---

**🎯 ट्रिक 1: विभाज्यता का परिवार — "2-3-5 की टोली"**

```
┌─────────────────────────────────────────────┐
│  2 → आखिरी अंक सम हो                        │
│  3 → अंकों का योग 3 से कटे                  │
│  5 → आखिरी अंक 0 या 5                       │
│  याद करो: "दो-तीन-पाँच, अंत-योग-शून्य-पाँच" │
└─────────────────────────────────────────────┘
```
2 अंतिम अंक देखता है, 3 योग देखता है, 5 सिर्फ़ 0 या 5 देखता है।

**🎯 ट्रिक 2: 11 की विभाज्यता — "झूला-झूली नियम"**

```
┌─────────────────────────────────────────────┐
│  विषम स्थान के अंकों का योग − सम स्थान के   │
│  अंकों का योग = 0 या 11 का गुणज             │
│  याद करो: अंक झूले पर बैठे हैं — एक ऊपर,   │
│  एक नीचे। दोनों तरफ़ का "वज़न" बराबर या    │
│  11 का फ़र्क़ हो तो संख्या 11 से कटती है!   │
└─────────────────────────────────────────────┘
```
उदाहरण: 918282 → (9+8+8)−(1+2+2) = 25−5 = 20 ✗ नहीं कटती।

**🎯 ट्रिक 3: 4, 8, 16 की विभाज्यता — "आखिरी अंकों की सीढ़ी"**

```
┌─────────────────────────────────────────────┐
│  4  → आखिरी 2 अंक  (2² = 4)                 │
│  8  → आखिरी 3 अंक  (2³ = 8)                 │
│  16 → आखिरी 4 अंक  (2⁴ = 16)                │
│  याद करो: "घात जितनी, अंक उतने!"            │
└─────────────────────────────────────────────┘
```

┌─────────────────────────────────────────────┐

**🎯 ट्रिक 5: शेषफल प्रमेय — "छोटा बच्चा बँटवारा"**

```
┌─────────────────────────────────────────────┐
│  (a × b) mod n = [(a mod n) × (b mod n)]    │
│  mod n                                      │
│  याद करो: मिठाई बाँटने से पहले हर बच्चे का  │
│  "शेष" निकाल लो, फिर गुणा करो — बड़ी संख्या │
│  से कभी मत घबराओ!                           │
└─────────────────────────────────────────────┘
```
उदाहरण: 47 × 53 का 9 से शेष → (2 × 8) = 16 → 16 mod 9 = **7**

**🎯 ट्रिक 6: इकाई अंक — "चक्र की घड़ी"**

```
┌─────────────────────────────────────────────┐

└─────────────────────────────────────────────┘
```
घात को 4 से भाग दो, शेषफल ही साइकिल की पोज़ीशन है।

**🎯 ट्रिक 7: फर्मा का छोटा प्रमेय — "प्रधानमंत्री का वादा"**

```
┌─────────────────────────────────────────────┐
│  aᵖ⁻¹ ≡ 1 (mod p), जहाँ p अभाज्य,           │
│  gcd(a,p) = 1                               │
│  याद करो: "अभाज्य PM के सामने हर संख्या     │
│  (p−1) घात पर झुककर 1 बन जाती है!"          │
└─────────────────────────────────────────────┘
```
उदाहरण: 2¹⁰⁰ mod 11 → 2¹⁰ ≡ 1 → (2¹⁰)¹⁰ ≡ 1

**🎯 ट्रिक 8: यूलर का टोशेंट φ(n) — "सगे-संबंधी गिनती"**

```
┌─────────────────────────────────────────────┐
│  φ(n) = n × (1−1/p₁)(1−1/p₂)…               │
│  याद करो: n के "सगे" वही जो n से न कटते हों।│
│  हर अभाज्य गुणक अपना हिस्सा काट लेता है!    │
│  φ(12) = 12 × (1−1/2)(1−1/3) = 4            │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 13: aⁿ − bⁿ और aⁿ + bⁿ — "घात का पासपोर्ट"**

```
┌─────────────────────────────────────────────┐
│  aⁿ − bⁿ → हमेशा (a−b) से कटता है           │
│  aⁿ + bⁿ → (a+b) से कटता है, सिर्फ़ जब n    │
│  विषम हो                                    │
│  याद करो: "माइनस सबके साथ, प्लस सिर्फ़      │
│  विषम के साथ!"                              │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 14: सम-विषम पहचान — "EEOO का खेल"**

```
┌─────────────────────────────────────────────┐
│  सम + सम = सम | विषम + विषम = सम            │
│  सम + विषम = विषम                           │
│  सम × कुछ भी = सम                           │
│  विषम × विषम = विषम                         │
│  याद करो: "गुणा में सम राजा है — एक सम आया, │
│  सब सम हो गया!"                             │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 15: वर्गों का योग — "घन-वर्ग जुगलबंदी"**

```
┌─────────────────────────────────────────────┐
│  1²+2²+…+n² = n(n+1)(2n+1)/6                │
│  1³+2³+…+n³ = [n(n+1)/2]²                   │
│  याद करो: "घनों का योग = योग का वर्ग!"      │
│  (पहले n संख्याओं के योग को ही वर्ग कर दो)  │
└─────────────────────────────────────────────┘
```
उदाहरण: 1³+…+10³ = (55)² = 3025
