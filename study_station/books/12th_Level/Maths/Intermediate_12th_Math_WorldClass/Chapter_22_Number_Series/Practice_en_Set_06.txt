126. Find the missing term: 3, 10, 29, 66, 127, ?
(a) 216 (b) 224 (c) 218 (d) 230
Answer: (c)
Solution: The tempting option 216 comes from assuming cubes only (6³ = 216), but the pattern is n³ + 2: 1³+2 = 3, 2³+2 = 10, 3³+2 = 29, 4³+2 = 66, 5³+2 = 127, so next is 6³+2 = 218. So the answer is 218.
Source: PYQ-style

127. Find the missing term: 2, 6, 21, 88, 445, ?
(a) 1780 (b) 2230 (c) 2676 (d) 2670
Answer: (c)
Solution: The trap is to look for a constant multiplier; here the multiplier itself increases: 2×2+2 = 6, 6×3+3 = 21, 21×4+4 = 88, 88×5+5 = 445, so next is 445×6+6 = 2676. So the answer is 2676.
Source: PYQ-style

128. Find the wrong term: 4, 9, 25, 49, 121, 168, 289

129. Find the missing term: 1, 4, 27, 256, 3125, ?

130. Find the missing term: 8, 15, 28, 53, 102, ?
