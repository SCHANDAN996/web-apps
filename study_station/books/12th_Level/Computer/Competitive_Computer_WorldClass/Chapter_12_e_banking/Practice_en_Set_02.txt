26. Which of the following is the full form of IMPS in the context of Indian electronic banking?
(a) Immediate Mobile Payment System (b) Instant Money Payment Service (c) Integrated Mobile Payment Solution (d) Immediate Payment Service
Answer: (d)
Solution: The tempting option (a) uses "Mobile" which sounds plausible since IMPS works on mobile, but the official RBI/NPCI terminology is "Immediate Payment Service" — it is channel-agnostic and works via internet banking, mobile apps, and ATMs, so the answer is Immediate Payment Service.
Source: NPCI official documentation

27. NEFT settlement occurs in batches at fixed intervals. What is the current batch frequency for NEFT transactions as per RBI guidelines?
(a) Every 30 minutes (b) Every hour (c) Every 15 minutes (d) Real-time continuous
Answer: (a)
Solution: Option (d) describes RTGS, not NEFT. NEFT operates in half-hourly batches (48 batches per day) since December 2019, making "Every 30 minutes" the correct frequency, so the answer is Every 30 minutes.
Source: RBI NEFT procedural guidelines

28. RTGS stands for Real Time Gross Settlement. What is the minimum transaction amount for RTGS as per current RBI norms?
(a) ₹2 lakh (b) ₹1 lakh (c) ₹5 lakh (d) No minimum limit
Answer: (a)
Solution: Option (b) was the old limit before 2014; the current minimum is ₹2 lakh with no upper ceiling. RTGS is meant for high-value transactions, so the answer is ₹2 lakh.

29. UPI (Unified Payments Interface) was developed by which organization?
(a) NPCI (b) RBI (c) Indian Banks' Association (d) Ministry of Finance
Answer: (a)
Solution: Option (b) RBI regulates UPI but NPCI (National Payments Corporation of India) developed and operates it. This distinction between regulator and operator is a common trap, so the answer is NPCI.
Source: NPCI official website

30. In UPI, what does the "VPA" stand for?
(a) Verified Payment Account (b) Virtual Payment Address (c) Virtual Private Account (d) Verified Payment Address
Answer: (b)
Solution: Option (a) and (d) use "Verified" which sounds authoritative but incorrect; "Virtual Payment Address" is the unique identifier (like user@bank) that replaces sharing bank account details, so the answer is Virtual Payment Address.

31. Which of the following authentication factors does UPI 2FA (Two-Factor Authentication) typically combine?
(a) Something you know + Something you know (b) Something you know + Something you are (c) Something you have + Something you are (d) Something you know + Something you have
Answer: (d)
Solution: Option (a) describes single-factor (two passwords). UPI combines MPIN (something you know) with registered mobile device/OTP (something you have), making it true 2FA, so the answer is Something you know + Something you have.
Source: RBI circular on digital payment security

32. What is the per-transaction limit for UPI as per current NPCI guidelines for general categories?
(a) ₹50,000 (b) ₹5 lakh (c) ₹2 lakh (d) ₹1 lakh
Answer: (d)
Solution: Option (c) is the RTGS minimum; UPI's standard per-transaction cap is ₹1 lakh (higher for specific categories like capital markets, tax payments), so the answer is ₹1 lakh.

33. Which protocol ensures encryption between a user's browser and the bank's internet banking server?
(a) HTTP (b) HTTPS/TLS (c) FTP (d) SMTP
Answer: (b)
Solution: Option (a) HTTP sends data in plain text — a major security risk. HTTPS uses TLS (formerly SSL) to encrypt the session, protecting credentials and transaction data, so the answer is HTTPS/TLS.
Source: CERT-In safe banking guidelines

34. "Phishing" in e-banking context refers to:

Answer: (a)
Solution: Option (b) describes skimming, (c) describes malware-based theft, (d) is DoS. Phishing specifically uses social engineering (fake emails/sites) to trick users into revealing credentials, so the answer is Fraudulent attempts to obtain sensitive information by disguising as trustworthy entity.

40. Which of the following is a prepaid payment instrument (PPI) issued by banks/non-banks?

Answer: (a)

41. The RBI's "Zero Liability" policy for unauthorized electronic transactions applies when the customer reports the fraud within:
(a) 24 hours (b) 7 working days (c) 3 working days (d) 30 days
Answer: (c)
Solution: Option (a) is too short; (b) and (d) are for limited liability tiers. Full zero liability applies if reported within 3 working days of receiving the alert, provided no customer negligence, so the answer is 3 working days.

42. What does "Tokenisation" of card data mean in e-commerce payments?
(a) Encrypting the card number with a bank-specific key (b) Storing card details in a password-protected vault (c) Replacing actual card details with a unique alternate code (token) for a specific device/merchant (d) Converting card number to a QR code
Answer: (c)
Solution: Option (a) describes encryption; tokenisation substitutes the PAN with a surrogate value (token) scoped to a merchant/device, rendering stolen tokens useless elsewhere, so the answer is Replacing actual card details with a unique alternate code (token) for a specific device/merchant.
Source: RBI tokenisation guidelines

43. Which of the following is the correct sequence of steps in a typical UPI "Collect Request" (Pull) flow?
(a) Payer initiates → Payee receives → NPCI routes → Bank debits (b) NPCI initiates → Payee requests → Payer approves → Bank settles (c) Bank initiates → NPCI routes → Payee receives → Payer pays (d) Payee initiates request → NPCI routes → Payer approves → Bank debits/credits
Answer: (d)
Solution: Option (a) describes Push flow. In Pull, the payee (merchant) initiates the collect request, NPCI routes to payer's PSP, payer authorizes via MPIN, then banks settle, so the answer is Payee initiates request → NPCI routes → Payer approves → Bank debits/credits.
Source: NPCI UPI collect request flow documentation

48. Which of the following statements about NEFT vs RTGS is CORRECT?

Solution: Option (a) reverses the limits; (d) reverses settlement modes; (c) both are now 24x7.
