1. Which of the following is an input device that converts printed text into digital format?
(a) Scanner (b) Speaker (c) Printer (d) Monitor
Answer: (a)
Solution: A scanner captures images or text from physical documents and converts them into digital form; a monitor and speaker are output devices, and a printer produces hard copy, so the answer is Scanner.
Source: NCERT Class 9 Computer Science

2. The port commonly used to connect a modern mouse or keyboard to a computer is:
(a) HDMI (b) PS/2 (c) VGA (d) USB
Answer: (d)
Solution: USB (Universal Serial Bus) is the standard port for keyboards and mice today; PS/2 is legacy, while VGA and HDMI are video ports, so the answer is USB.
Source: Microsoft Support

3. Which output device produces a hard copy of a document?
(a) Projector (b) Speaker (c) Monitor (d) Printer
Answer: (d)
Solution: A printer creates physical copies on paper; monitors and projectors display soft copy, and speakers produce sound, so the answer is Printer.
Source: NCERT Class 9 Computer Science

4. HDMI port is primarily used for:
(a) Audio and video transmission (b) Network connection (c) Connecting legacy printers (d) Power supply
Answer: (a)
Solution: HDMI (High-Definition Multimedia Interface) carries both high-definition video and audio signals; Ethernet handles network, legacy printers use USB or parallel, and power uses separate connectors, so the answer is Audio and video transmission.
Source: Microsoft Learn

5. A microphone is classified as:
(a) Input device (b) Output device (c) Storage device (d) Processing device
Answer: (a)
Solution: A microphone captures sound waves and converts them into digital signals for the computer, making it an input device; speakers perform the opposite output function, so the answer is Input device.
Source: NCERT Class 9 Computer Science

6. Which port is typically used for wired internet (Ethernet) connection?
(a) USB (b) HDMI (c) RJ-45 (d) VGA
Answer: (c)
Solution: RJ-45 is the standard connector for Ethernet cables; USB is for peripherals, HDMI for video/audio, and VGA for analog video, so the answer is RJ-45.
Source: Microsoft Support

7. VGA port transmits:
(a) Digital video only (b) Network data (c) Analog video only (d) Both audio and video
Answer: (c)
Solution: VGA (Video Graphics Array) carries analog video signals only; it does not carry audio or digital video natively, so the answer is Analog video only.
Source: Microsoft Learn

8. Which of the following is a pointing input device?
(a) Mouse (b) Microphone (c) Scanner (d) Keyboard
Answer: (a)
Solution: A mouse controls the cursor position on screen, making it a pointing device; keyboards enter text, scanners digitize images, and microphones capture audio, so the answer is Mouse.
Source: NCERT Class 9 Computer Science

9. The shortcut key to open Task Manager directly in Windows is:
(a) Ctrl + Alt + Del (b) Win + R (c) Ctrl + Shift + Esc (d) Ctrl + Esc
Answer: (c)
Solution: Ctrl + Shift + Esc opens Task Manager immediately; Ctrl + Alt + Del shows a security screen first, Win + R opens Run, and Ctrl + Esc opens Start menu, so the answer is Ctrl + Shift + Esc.
Source: Microsoft Support

10. Which port is used to connect external storage devices like pen drives?
(a) HDMI (b) VGA (c) RJ-45 (d) USB
Answer: (d)
Solution: USB ports are the universal interface for flash drives and external hard disks; HDMI and VGA are video ports, RJ-45 is for network, so the answer is USB.
Source: Microsoft Support

11. A webcam is an example of:
(a) Output device (b) Input device (c) Storage device (d) Communication device
Answer: (b)
Solution: A webcam captures video and sends it to the computer, functioning as an input device; it does not display or store data primarily, so the answer is Input device.
Source: NCERT Class 9 Computer Science

12. Which of the following ports supports both data transfer and video output on modern laptops?
(a) USB Type-A (b) HDMI (c) USB Type-C (d) RJ-45
Answer: (c)
Solution: USB Type-C with Thunderbolt or DisplayPort Alt Mode can carry data, video, and power; USB Type-A is data only, HDMI is video only, RJ-45 is network only, so the answer is USB Type-C.
Source: Microsoft Learn

13. The shortcut to lock a Windows computer quickly is:
(a) Win + L (b) Win + D (c) Ctrl + L (d) Alt + F4
Answer: (a)
Solution: Win + L locks the session instantly; Win + D shows desktop, Ctrl + L is not a standard system shortcut, Alt + F4 closes the active window, so the answer is Win + L.
Source: Microsoft Support

14. Which device converts digital signals from computer into analog sound?
(a) Microphone (b) Speaker (c) Scanner (d) Keyboard
Answer: (b)
Solution: Speakers receive digital audio data and convert it to analog sound waves; microphones do the reverse, scanners and keyboards are unrelated, so the answer is Speaker.
Source: NCERT Class 9 Computer Science

15. PS/2 port is a legacy interface mainly used for:
(a) Monitor (b) Keyboard and mouse (c) Printer (d) Network
Answer: (b)
Solution: PS/2 (Personal System/2) connectors were standard for keyboards (purple) and mice (green) before USB; they are not used for monitors, printers, or network, so the answer is Keyboard and mouse.
Source: Microsoft Support

16. Which port is commonly colored blue on a computer to indicate USB 3.0?
(a) USB 2.0 (b) USB 3.0 (c) HDMI (d) VGA
Answer: (b)
Solution: USB 3.0 ports and connectors are typically blue to distinguish them from black USB 2.0 ports; HDMI and VGA are video ports with different colors, so the answer is USB 3.0.
Source: Microsoft Learn

17. A plotter is an output device used primarily for:
(a) Printing high-quality photos (b) Scanning documents (c) Printing large-format technical drawings (d) Playing audio
Answer: (c)
Solution: Plotters use pens to draw continuous lines for engineering/architectural drawings; photo printers use inkjet/laser, speakers play audio, scanners are input, so the answer is Printing large-format technical drawings.
Source: NCERT Class 10 Computer Science

18. The shortcut to open File Explorer in Windows is:
(a) Ctrl + E (b) Win + R (c) Alt + E (d) Win + E
Answer: (d)
Solution: Win + E launches File Explorer directly; Win + R opens Run dialog, Ctrl + E focuses search in some apps, Alt + E is not a standard system shortcut, so the answer is Win + E.
Source: Microsoft Support

19. Which of the following is NOT an input device?
(a) Keyboard (b) Mouse (c) Scanner (d) Monitor
Answer: (d)
Solution: Monitor displays output; keyboard, mouse, and scanner all send data into the computer, so the answer is Monitor.
Source: NCERT Class 9 Computer Science

20. DisplayPort is a digital interface mainly used for:
(a) Audio only (b) Network connectivity (c) Video and audio to monitors (d) Connecting printers
Answer: (c)
Solution: DisplayPort carries high-resolution video and audio to displays; it is not for audio only, network, or printers, so the answer is Video and audio to monitors.
Source: Microsoft Learn

21. A laptop has a USB-C port that supports USB 3.1 data only (no DisplayPort Alt Mode). The user connects a USB-C to HDMI cable to a monitor. What will happen?
(a) No video signal because the port lacks video output capability (b) Video will display at 1080p 60Hz (c) Video will display at 4K 60Hz (d) The monitor will show an error message
Answer: (a)
Solution: A USB-C port without DisplayPort Alt Mode cannot transmit video signals; a USB-C to HDMI cable relies on the port's video capability, so no video signal will appear, so the answer is No video signal because the port lacks video output capability.
Source: Microsoft Learn

22. Which statement about USB versions is correct?
(a) USB 3.1 Gen 1 is same as USB 3.0 (b) USB 2.0 max speed is 5 Gbps (c) USB 3.0 max speed is 480 Mbps (d) USB 3.2 Gen 2×2 max speed is 10 Gbps
Answer: (a)
Solution: USB 3.1 Gen 1 was a rebrand of USB 3.0 (5 Gbps); USB 2.0 is 480 Mbps, USB 3.0 is 5 Gbps, USB 3.2 Gen 2×2 is 20 Gbps, so the answer is USB 3.1 Gen 1 is same as USB 3.0.
Source: Microsoft Learn

23. In Windows, the shortcut Win + Shift + S is used to:
(a) Open Settings (b) Take a screenshot snip (c) Open Search (d) Switch user
Answer: (b)
Solution: Win + Shift + S launches the Snip & Sketch tool for area screenshots; Win + I opens Settings, Win + Q/S opens Search, Ctrl + Alt + Del → Switch user changes user, so the answer is Take a screenshot snip.
Source: Microsoft Support

24. A computer has only USB 2.0 ports. A user plugs in a USB 3.0 flash drive. What will be the effective transfer speed?
(a) 5 Gbps (b) 480 Mbps (c) 10 Gbps (d) 20 Gbps
Answer: (b)
Solution: USB is backward compatible; the speed is limited by the slower port (USB 2.0 = 480 Mbps), not the device capability, so the answer is 480 Mbps.
Source: Microsoft Learn

25. Which of the following keyboard shortcuts works in Microsoft Word but NOT in most web browsers?
(a) Ctrl + C (b) Ctrl + V (c) Ctrl + S (d) Ctrl + B
Answer: (d)
Solution: Ctrl + B toggles bold formatting in Word; in browsers it often opens bookmarks or has no effect. Ctrl + C, V, S (copy, paste, save) work similarly in both, so the answer is Ctrl + B.
Source: Microsoft Support
