126. Which port is commonly used to connect a modern external hard drive to a computer?
(a) VGA (b) PS/2 (c) USB 3.0 (d) Parallel
Answer: (c)
Solution: The tempting wrong option is VGA, which is a video interface and cannot transfer storage data. USB 3.0 provides high‑speed data transfer for external drives, so the answer is USB 3.0.
