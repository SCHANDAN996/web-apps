Memory Storage and Backup — Simple Explanations

Think of your computer's memory like a desk and a filing cabinet.

**Primary Memory (RAM)** is the top of your desk. You spread out the papers you are working on *right now*. It is fast, but the desk is small. When you shut down the computer (turn off the power), everything on the desk vanishes. That is why RAM is called **volatile memory**.

**Secondary Storage (HDD, SSD, USB drive, SD card)** is the filing cabinet. You put finished work or bulk supplies there. It holds much more, and the papers stay safe even when the lights go out. That is **non-volatile memory**.

**Cache memory** is a tiny sticky-note pad stuck to the monitor. The CPU keeps the most urgent numbers there so it does not have to walk to the desk (RAM) every time. It is the fastest but smallest of all.

**Virtual memory** is a reserved drawer in the filing cabinet that the system pretends is extra desk space. When the desk (RAM) overflows, Windows moves less-used papers to this drawer (page file on the SSD/HDD). It prevents crashes but works slower than real RAM.

**Backup** means making a second copy of your important files and keeping that copy in a different place — an external drive, a network share, or the cloud. If the original is lost (hardware failure, ransomware, accidental delete), you restore from the backup.

**3-2-1 Rule (practical guideline):** Keep **3** copies of critical data (original + 2 backups), on **2** different media types (e.g., internal SSD + external HDD), with **1** copy off-site (cloud or another building).

### Recall Questions

**1. Which memory loses its content when the power is switched off?**  
RAM (Random Access Memory). It is volatile; only secondary storage retains data without power.

**2. Why is an SSD faster than a traditional hard disk (HDD)?**  
An SSD has no moving parts — it uses flash memory chips. An HDD spins platters and moves a read/write head, which takes physical time.

**3. What happens when RAM is full and you open another program?**  
The OS uses virtual memory (page file on the SSD/HDD) to swap out less-active data. The system keeps running but slows down because disk access is much slower than RAM.

**4. If you delete a file from an external USB drive, does it go to the Recycle Bin?**  
No. By default, Windows sends only files deleted from internal fixed drives to the Recycle Bin. Removable media deletions are permanent unless you use third-party tools or enable the policy.

**5. What is the minimum number of copies the 3-2-1 backup rule recommends for important data?**  
Three copies total: the working original plus two independent backups.
