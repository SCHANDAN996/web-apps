26. Which type of memory retains data without power and stores the BIOS/UEFI firmware?
(a) RAM (b) ROM (c) Cache (d) Virtual Memory
Answer: (b)
Solution: RAM loses data when power is off, making it a common trap for those confusing volatile and non-volatile memory; ROM is non-volatile and permanently stores firmware like BIOS/UEFI, so the answer is ROM.
Source: NCERT Class 11 Computer Science

27. What is the primary function of cache memory in a computer system?
(a) Permanent data storage (b) Backup of hard disk (c) Store operating system files (d) Reduce CPU-memory speed gap
Answer: (d)
Solution: Cache is often mistaken for permanent storage, but it is a small, fast volatile memory that bridges the speed gap between CPU and main RAM, so the answer is Reduce CPU-memory speed gap.
Source: Microsoft Learn - Memory hierarchy

28. Which storage device uses magnetic platters and read/write heads for data access?
(a) SSD (b) HDD (c) USB Flash Drive (d) Optical Disc
Answer: (b)
Solution: SSDs use flash memory with no moving parts, a frequent confusion point; HDDs specifically use spinning magnetic platters and mechanical heads, so the answer is HDD.
Source: NCERT Class 9 Information Technology

29. In the memory hierarchy, which level is closest to the CPU and fastest?
(a) Main Memory (RAM) (b) Secondary Storage (c) Virtual Memory (d) Cache Memory
Answer: (d)
Solution: RAM is larger but slower than cache; cache sits directly on or near the CPU die for fastest access, so the answer is Cache Memory.
Source: Microsoft Learn - Computer architecture

30. What does SSD stand for in storage technology?
(a) System Storage Device (b) Super Speed Disk (c) Solid State Drive (d) Secure Storage Drive

31. Which backup method copies only files that have changed since the last backup of any type?
(a) Full Backup (b) Differential Backup (c) Incremental Backup (d) Mirror Backup
Answer: (c)
Solution: Differential backup copies changes since the last full backup, a common mix-up; incremental backup copies changes since the last backup of any type, so the answer is Incremental Backup.

32. What is the main advantage of RAID 1 (mirroring) over RAID 0 (striping)?
(a) Higher performance (b) Larger capacity (c) Lower cost (d) Data redundancy

Solution: RAID 0 offers higher performance and capacity but no redundancy; RAID 1 provides fault tolerance through mirroring, so the answer is Data redundancy.

33. Which file system is natively supported by Windows for large partitions and includes features like encryption and compression?
(a) FAT32 (b) exFAT (c) ext4 (d) NTFS

34. What is virtual memory in an operating system?
(a) Physical RAM expansion (b) Hard disk space used as RAM extension (c) Cache memory allocation (d) ROM shadowing

(a) RAID 0 (b) RAID 1 (c) RAID 5 (d) RAID 10

42. Which memory type requires periodic refreshing to maintain stored data?
(a) SRAM (b) Flash Memory (c) ROM (d) DRAM
Answer: (d)
Solution: SRAM uses flip-flops and doesn't need refresh; DRAM stores charge in capacitors that leak, requiring periodic refresh, so the answer is DRAM.

Solution: NAND Flash is for bulk storage (SSDs, USB); NOR Flash allows random access and execute-in-place, ideal for firmware, so the answer is NOR Flash.

(a) 8 GB (b) 16 GB (c) 8 TB (or 128 TB depending on Windows version) (d) 24 GB
Answer: (c)
Solution: Physical RAM + page file limits committed memory, not virtual address space; 64-bit Windows provides 8 TB (or 128 TB) user-mode virtual address space per process, so the answer is 8 TB (or 128 TB depending on Windows version).
