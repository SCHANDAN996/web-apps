कार्ड 1
सामने: प्राथमिक मेमोरी (Primary Memory) और द्वितीयक मेमोरी (Secondary Memory) में मुख्य अंतर क्या है?
पीछे: प्राथमिक मेमोरी (RAM, ROM) CPU द्वारा सीधे एक्सेस होती है, वोलेटाइल (RAM) या नॉन-वोलेटाइल (ROM) होती है, और तेज़ लेकिन महंगी होती है। द्वितीयक मेमोरी (HDD, SSD, USB) स्थायी स्टोरेज देती है, CPU सीधे एक्सेस नहीं कर सकता (डेटा पहले RAM में आता है), सस्ती और बड़ी क्षमता वाली होती है।
स्रोत: NCERT कक्षा 11 कंप्यूटर विज्ञान

कार्ड 2
सामने: SRAM और DRAM में क्या अंतर है?
पीछे: SRAM (Static RAM) फ्लिप-फ्लॉप उपयोग करती है, रिफ्रेश की ज़रूरत नहीं, तेज़, महंगी, कम घनत्व — कैश मेमोरी में उपयोग। DRAM (Dynamic RAM) कैपेसिटर उपयोग करती है, आवधिक रिफ्रेश ज़रूरी, धीमी, सस्ती, उच्च घनत्व — मुख्य सिस्टम RAM (DDR4, DDR5) में उपयोग।
स्रोत: Microsoft Learn - Memory Architecture

कार्ड 3
सामने: ROM के मुख्य प्रकार और उनके उपयोग बताइए।
पीछे: PROM — एक बार प्रोग्राम योग्य (फ्यूज़ जलाकर)। EPROM — UV प्रकाश से मिटाई जा सकती है (विंडो वाली चिप)। EEPROM — विद्युतीय रूप से मिटाई/लिखी जा सकती है (बाइट-स्तर)। फ्लैश मेमोरी — EEPROM का ब्लॉक-स्तरीय संस्करण, USB ड्राइव/SSD/BIOS चिप में उपयोग।
स्रोत: Intel Memory Technology Guide

कार्ड 4
सामने: कैश मेमोरी (L1, L2, L3) का कार्य और विशेषताएँ क्या हैं?
पीछे: कैश CPU और RAM के बीच तेज़ बफर है। L1 — कोर के अंदर, सबसे तेज़, सबसे छोटी (KB)। L2 — कोर के अंदर/पास, मध्यम आकार (KB-MB)। L3 — कोर के बीच साझा, सबसे बड़ी (MB)। सिद्धांत: स्थानिक और लौकिक स्थानीयता (Locality of Reference)।
स्रोत: AMD/Intel Processor Documentation

कार्ड 5
सामने: HDD (Hard Disk Drive) की आंतरिक संरचना और डेटा एक्सेस विधि बताइए।
पीछे: HDD में घूमती प्लैटर्स (डिस्क), रीड/राइट हेड, एक्चुएटर आर्म, स्पिंडल मोटर होते हैं। डेटा ट्रैक और सेक्टर में मैग्नेटिक रूप से स्टोर होता है। एक्सेस समय = सीक टाइम + रोटेशनल लेटेंसी + ट्रांसफर टाइम। यांत्रिक भागों के कारण धीमी, शोर, झटके से खराब होने का खतरा।
स्रोत: Seagate/WD Technical Specifications

कार्ड 6
सामने: SSD (Solid State Drive) HDD से कैसे भिन्न है और इसके प्रकार क्या हैं?
पीछे: SSD में कोई यांत्रिक भाग नहीं, NAND फ्लैश मेमोरी उपयोग करती है। तेज़ (कम लेटेंसी, उच्च IOPS), मौन, टिकाऊ, कम बिजली खपत। प्रकार: SATA SSD (AHCI प्रोटोकॉल, ~550 MB/s), NVMe SSD (PCIe बस, ~3500-7000+ MB/s), M.2 — फॉर्म फैक्टर (SATA या NVMe दोनों हो सकते हैं)।
स्रोत: Samsung/Intel SSD Whitepapers

कार्ड 7
सामने: ऑप्टिकल स्टोरेज (CD, DVD, Blu-ray) की क्षमता और लेज़र तरंगदैर्ध्य बताइए।
पीछे: CD — 700 MB, 780 nm इन्फ्रारेड लेज़र। DVD — 4.7 GB (सिंगल लेयर), 650 nm लाल लेज़र। Blu-ray — 25 GB (सिंगल लेयर), 405 nm नीली लेज़र। छोटी तरंगदैर्ध्य = छोटा पिट = अधिक घनत्व। R = रिकॉर्ड करने योग्य (एक बार), RW = रीराइटेबल।
स्रोत: Optical Storage Technology Association

कार्ड 8
सामने: USB फ्लैश ड्राइव और मेमोरी कार्ड में प्रयुक्त तकनीक और इंटरफेस संस्करण बताइए।
पीछे: दोनों NAND फ्लैश मेमोरी उपयोग करते हैं। USB संस्करण: USB 2.0 (480 Mbps), USB 3.0/3.1 Gen 1 (5 Gbps), USB 3.1 Gen 2 (10 Gbps), USB 3.2/USB4 (20-40 Gbps)। मेमोरी कार्ड: SD, microSD, UHS-I/II/III स्पीड क्लास (क्लास 10, U1, U3, V30, V60, V90) वीडियो रिकॉर्डिंग के लिए।
स्रोत: USB-IF / SD Association Specifications

कार्ड 9
सामने: क्लाउड स्टोरेज के प्रकार और विशेषताएँ क्या हैं?
पीछे: पब्लिक क्लाउड (Google Drive, OneDrive, Dropbox) — साझा इन्फ्रास्ट्रक्चर। प्राइवेट क्लाउड — संगठन का अपना। हाइब्रिड — दोनों का मिश्रण। विशेषताएँ: कहीं से भी एक्सेस, स्वचालित सिंक, संस्करण इतिहास, साझाकरण, रिडंडेंसी (मल्टी-रीजन रेप्लिकेशन)। सुरक्षा: एन्क्रिप्शन (इन-ट्रांजिट TLS, एट-रेस्ट AES-256), 2FA।
स्रोत: NIST SP 800-145 / Microsoft Azure Documentation

कार्ड 10
सामने: बैकअप के तीन मुख्य प्रकार (Full, Incremental, Differential) में अंतर समझाइए।
पीछे: फुल बैकअप — सभी डेटा की पूरी कॉपी, धीमा, अधिक स्थान, रिस्टोर सबसे तेज़। इन्क्रीमेंटल — केवल पिछले बैकअप (किसी भी प्रकार) के बाद बदला डेटा, सबसे तेज़/कम स्थान, रिस्टोर धीमा (फुल + सभी इन्क्रीमेंटल चाहिए)। डिफरेंशियल — पिछले फुल बैकअप के बाद बदला डेटा, मध्यम गति/स्थान, रिस्टोर तेज़ (फुल + नवीनतम डिफरेंशियल)।
स्रोत: Microsoft Learn - Backup Types

कार्ड 11
सामने: RAID के सामान्य स्तर (0, 1, 5, 6, 10) और उनके उपयोग बताइए।
पीछे: RAID 0 — स्ट्रिपिंग, प्रदर्शन, कोई रिडंडेंसी नहीं। RAID 1 — मिररिंग, रिडंडेंसी, 50% क्षमता उपयोग। RAID 5 — स्ट्रिपिंग + डिस्ट्रिब्यूटेड पैरिटी, न्यूनतम 3 डिस्क, 1 डिस्क फेल सहन। RAID 6 — डुअल पैरिटी, न्यूनतम 4 डिस्क, 2 डिस्क फेल सहन। RAID 10 — मिरर + स्ट्रिप, न्यूनतम 4 डिस्क, उच्च प्रदर्शन + रिडंडेंसी।
स्रोत: SNIA RAID Primer

कार्ड 12
सामने: Windows में प्रयुक्त मुख्य फाइल सिस्टम (NTFS, FAT32, exFAT, ReFS) की विशेषताएँ बताइए।
पीछे: NTFS — Windows डिफॉल्ट, बड़ी फाइल/वॉल्यूम, अनुमतियाँ, एन्क्रिप्शन (EFS), जर्नलिंग, कंप्रेशन। FAT32 — पुराना, 4 GB फाइल सीमा, 32 GB वॉल्यूम सीमा (Windows फॉर्मेट), व्यापक संगतता। exFAT — FAT64, बड़ी फाइल/वॉल्यूम, कोई अनुमति नहीं, फ्लैश ड्राइव के लिए बेहतर। ReFS — सर्वर/वर्कस्टेशन, रेजिलिएंसी, इंटीग्रिटी स्ट्रीम, कोई बूट सपोर्ट नहीं।
स्रोत: Microsoft Learn - File Systems

कार्ड 13
सामने: वर्चुअल मेमोरी (पेज फाइल) क्या है और यह कैसे काम करती है?
पीछे: जब भौतिक RAM भर जाता है, OS कम उपयोग वाले मेमोरी पेज (आमतौर पर 4 KB) को डिस्क पर पेज फाइल (pagefile.sys) में स्वैप आउट करता है। इससे एड्रेस स्पेस RAM से बड़ा हो सकता है। थ्रैशिंग — अत्यधिक पेजिंग से प्रदर्शन गिरावट। Windows डिफॉल्ट: सिस्टम-प्रबंधित आकार (RAM के 1-3x तक)।
स्रोत: Windows Internals (Microsoft Press)

कार्ड 14
सामने: मेमोरी पदानुक्रम (Memory Hierarchy) का सिद्धांत और स्तर बताइए।
पीछे: तेज़/महंगा/छोटा (ऊपर) → धीमा/सस्ता/बड़ा (नीचे)। स्तर: रजिस्टर → L1/L2/L3 कैश → मुख्य RAM → SSD/HDD → ऑप्टिकल/टेप → क्लाउड/ऑफलाइन। सिद्धांत: स्थानीयता (Locality) — प्रोग्राम हाल ही में उपयोग डेटा (लौकिक) और आस-पास के डेटा (स्थानिक) को एक्सेस करते हैं।
स्रोत: Hennessy & Patterson - Computer Architecture

कार्ड 15
सामने: डेटा रिकवरी के सामान्य परिदृश्य और सावधानियाँ क्या हैं?
पीछे: आकस्मिक डिलीट — रीसायकल बिन / फाइल रिकवरी सॉफ्टवेयर (डेटा ओवरराइट न होने तक)। फॉर्मेट ड्राइव — क्विक फॉर्मेट में डेटा रहता है, डीप स्कैन से रिकवरी संभव। भौतिक क्षति (HDD हेड क्रैश, SSD कंट्रोलर फेल) — पेशेवर क्लीनरूम सेवा ज़रूरी। सावधानी: प्रभावित ड्राइव पर लिखना बंद करें, तुरंत इमेज बनाएं।
स्रोत: CERT-In Advisory / NIST SP 800-86

कार्ड 16
सामने: 3-2-1 बैकअप नियम क्या है और यह क्यों महत्वपूर्ण है?
पीछे: 3 कॉपी (मूल + 2 बैकअप), 2 अलग मीडिया प्रकार (जैसे लोकल SSD + एक्सटर्नल HDD, या लोकल + क्लाउड), 1 ऑफसाइट कॉपी (क्लाउड/दूरस्थ सर्वर/ऑफलाइन टेप)। यह हार्डवेयर फेलियर, रैंसमवेयर, आग/बाढ़, मानवीय त्रुटि से बचाता है। रैंसमवेयर के लिए: एक कॉपी ऑफलाइन/इम्यूटेबल (WORM) रखें।
स्रोत: US-CERT / Veeam Backup Best Practices

कार्ड 17
सामने: स्टोरेज इंटरफेस (SATA, SAS, NVMe, USB, Thunderbolt) की तुलना बताइए।
पीछे: SATA III — 6 Gbps (~550 MB/s), HDD/SATA SSD, AHCI प्रोटोकॉल। SAS — 12/24 Gbps, एंटरप्राइज, डुअल पोर्ट, कमांड क्यूइंग। NVMe — PCIe लेन (x4 आम), 32 Gbps+ (PCIe 4.0), हज़ारों क्यू, CPU के करीब। USB 3.2 Gen 2x2 — 20 Gbps। Thunderbolt 3/4 — 40 Gbps, PCIe + DisplayPort, डेज़ी चेन।
स्रोत: T13/T10 Standards / NVMe Spec / USB-IF / Intel Thunderbolt

कार्ड 18
सामने: स्टोरेज क्षमता इकाइयाँ (दशमलव बनाम बाइनरी) और Windows में दिखाई देने वाला अंतर समझाइए।
पीछे: दशमलव (SI): 1 KB = 10³ B, 1 MB = 10⁶ B, 1 GB = 10⁹ B, 1 TB = 10¹² B — निर्माता उपयोग करते हैं। बाइनरी (IEC): 1 KiB = 2¹⁰ B, 1 MiB = 2²⁰ B, 1 GiB = 2³⁰ B, 1 TiB = 2⁴⁰ B — OS उपयोग करता है। इसलिए 1 TB ड्राइव Windows में ~931 GiB दिखती है (10¹² ÷ 2³⁰ ≈ 931)।
स्रोत: IEC 60027-2 / NIST Guidelines
