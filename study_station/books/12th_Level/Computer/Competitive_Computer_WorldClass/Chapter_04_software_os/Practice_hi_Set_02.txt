26. निम्नलिखित में से कौन सिस्टम सॉफ़्टवेयर का उदाहरण है?
(a) Microsoft Word (b) Google Chrome (c) Adobe Photoshop (d) Windows 10
उत्तर: (d)
हल: वर्ड, फोटोशॉप और क्रोम जैसे एप्लिकेशन सॉफ़्टवेयर ऑपरेटिंग सिस्टम के ऊपर चलते हैं; वे सिस्टम सॉफ़्टवेयर नहीं हैं। Windows 10 स्वयं ऑपरेटिंग सिस्टम है, जो हार्डवेयर का प्रबंधन करता है और एप्लिकेशन के लिए प्लेटफ़ॉर्म प्रदान करता है, इसलिए उत्तर Windows 10 है।
स्रोत: NCERT कक्षा 11 कंप्यूटर विज्ञान

27. ऑपरेटिंग सिस्टम का प्राथमिक कार्य है:
(a) हार्डवेयर संसाधनों का प्रबंधन (b) दस्तावेज़ बनाना (c) इंटरनेट ब्राउज़ करना (d) छवियाँ संपादित करना
उत्तर: (a)
हल: दस्तावेज़ बनाना, ब्राउज़ करना और छवियाँ संपादित करना एप्लिकेशन सॉफ़्टवेयर द्वारा किए जाने वाले कार्य हैं। OS एप्लिकेशन और हार्डवेयर के बीच मध्यस्थ के रूप में कार्य करता है, CPU, मेमोरी, स्टोरेज और I/O उपकरणों का प्रबंधन करता है, इसलिए उत्तर हार्डवेयर संसाधनों का प्रबंधन है।
स्रोत: NCERT कक्षा 11 कंप्यूटर विज्ञान

28. आधुनिक Windows इंस्टॉलेशन के लिए डिफ़ॉल्ट फाइल सिस्टम कौन सा है?
(a) FAT16 (b) FAT32 (c) NTFS (d) ext4
उत्तर: (c)
हल: FAT16 और FAT32 आकार और सुरक्षा सीमाओं वाले पुराने फाइल सिस्टम हैं; ext4 लिनक्स में उपयोग होता है। NTFS (New Technology File System) बड़े वॉल्यूम, फाइल अनुमतियाँ, एन्क्रिप्शन का समर्थन करता है और Windows NT के बाद से Windows के लिए डिफ़ॉल्ट है, इसलिए उत्तर NTFS है।
स्रोत: Microsoft Learn - File Systems

29. वर्चुअल मेमोरी कंप्यूटर को अनुमति देती है:
(a) भौतिक RAM बढ़ाएँ (b) फ़ाइलों को स्वचालित रूप से संपीड़ित करें (c) CPU को तेज़ करें (d) हार्ड डिस्क स्थान को अस्थायी RAM के रूप में उपयोग करें
उत्तर: (d)
हल: वर्चुअल मेमोरी भौतिक RAM नहीं जोड़ती या CPU को तेज़ नहीं करती; यह हार्ड डिस्क के एक हिस्से (पेज फाइल) का उपयोग उपलब्ध मेमोरी को बढ़ाने के लिए करती है जब RAM भर जाता है, इसलिए उत्तर हार्ड डिस्क स्थान को अस्थायी RAM के रूप में उपयोग करें है।
स्रोत: Microsoft Learn - Memory Management

(a) सभी विंडोज़ को छोटा करता है (b) फाइल एक्सप्लोरर खोलता है (c) कंप्यूटर लॉक करता है (d) सेटिंग्स खोलता है
उत्तर: (c)
हल: Win+E फाइल एक्सप्लोरर खोलता है; Win+D सभी विंडोज़ को छोटा करता है; Win+I सेटिंग्स खोलता है। Win+L तुरंत सत्र को लॉक करता है और साइन-इन स्क्रीन दिखाता है, जो दूर जाने पर सुरक्षा की सर्वोत्तम प्रथा है, इसलिए उत्तर कंप्यूटर लॉक करता है।
स्रोत: Microsoft Support - Keyboard Shortcuts in Windows

46. निम्नलिखित में से कौन डिफ़ॉल्ट रूप से वैध Windows पावर प्लान नहीं है?
(a) Maximum performance (b) Power saver (c) High performance (d) Balanced
उत्तर: (a)
हल: Balanced, Power saver और High performance तीन बिल्ट-इन प्लान हैं। "Maximum performance" डिफ़ॉल्ट प्लान नाम नहीं है (हालाँकि Ultimate Performance कुछ संस्करणों में छिपे प्लान के रूप में मौजूद है), इसलिए उत्तर Maximum performance है।
स्रोत: Microsoft Support - Power Plans

47. सिस्टम कॉन्फ़िगरेशन टूल (msconfig) मुख्य रूप से उपयोग किया जाता है:
(a) रजिस्ट्री को सीधे संपादित करने के लिए (b) स्टार्टअप प्रोग्राम और बूट विकल्प प्रबंधित करने के लिए (c) हार्ड ड्राइव फ़ॉर्मेट करने के लिए (d) Windows अपडेट इंस्टॉल करने के लिए
उत्तर: (b)
हल: Msconfig रजिस्ट्री को सीधे संपादित नहीं करता, ड्राइव फ़ॉर्मेट नहीं करता, या अपडेट इंस्टॉल नहीं करता। यह नियंत्रित करता है कि कौन सी सेवाएँ और स्टार्टअप आइटम लोड हों, और बूट पैरामीटर्स को कॉन्फ़िगर करता है जैसे सेफ मोड, इसलिए उत्तर स्टार्टअप प्रोग्राम और बूट विकल्प प्रबंधित करना है।
स्रोत: Microsoft Support - System Configuration

48. Windows Defender (Microsoft Defender Antivirus) वर्गीकृत है:
(a) केवल फ़ायरवॉल के रूप में (b) थर्ड-पार्टी एंटीवायरस के रूप में (c) बिल्ट-इन एंटीमैलवेयर सुरक्षा के रूप में (d) बैकअप यूटिलिटी के रूप में
उत्तर: (c)
हल: यह केवल फ़ायरवॉल नहीं, थर्ड-पार्टी नहीं, और बैकअप टूल नहीं है। यह Windows Security का एकीकृत, रीयल-टाइम एंटीमैलवेयर घटक है जो वायरस, स्पायवेयर और अन्य खतरों के लिए स्कैन करता है, इसलिए उत्तर बिल्ट-इन एंटीमैलवेयर सुरक्षा है।
स्रोत: Microsoft Learn - Microsoft Defender Antivirus

49. उन्नत कमांड प्रॉम्प्ट में `sfc /scannow` कमांड:
(a) अस्थायी फ़ाइलें साफ़ करता है (b) डिस्क को खराब सेक्टर के लिए जाँचता है (c) हार्ड ड्राइव को डीफ़्रैग्मेन्ट करता है (d) संरक्षित सिस्टम फ़ाइलों को स्कैन और मरम्मत करता है
उत्तर: (d)
हल: `sfc` (System File Checker) अस्थायी फ़ाइलें साफ़ नहीं करता, डीफ़्रैग्मेन्ट नहीं करता, या खराब सेक्टर की जाँच नहीं करता (वह CHKDSK है)। यह Windows संरक्षित सिस्टम फ़ाइलों की अखंडता की पुष्टि करता है और भ्रष्ट संस्करणों को कैश्ड प्रतियों से बदल देता है, इसलिए उत्तर संरक्षित सिस्टम फ़ाइलों को स्कैन और मरम्मत करता है।
स्रोत: Microsoft Support - System File Checker

50. Windows Update के बारे में कौन सा कथन सही है?
(a) यह केवल Microsoft Office अपडेट करता है (b) इसके लिए पेड सब्सक्रिप्शन आवश्यक है (c) इसे रोका नहीं जा सकता (d) यह Windows के लिए सुरक्षा पैच, ड्राइवर अपडेट और फीचर अपडेट प्रदान करता है
उत्तर: (d)
हल: Windows Update OS, ड्राइवर्स और फीचर्स को कवर करता है — केवल Office नहीं। इसे 35 दिनों तक रोका जा सकता है (Pro/Enterprise में) और लाइसेंस प्राप्त Windows के लिए मुफ़्त है। यह संचयी सुरक्षा पैच, ड्राइवर अपडेट और अर्ध-वार्षिक फीचर अपडेट प्रदान करता है, इसलिए उत्तर यह Windows के लिए सुरक्षा पैच, ड्राइवर अपडेट और फीचर अपडेट प्रदान करता है।
स्रोत: Microsoft Learn - Windows Update
