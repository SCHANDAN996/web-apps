126. Which type of software acts as an interface between the user and the computer hardware?
(a) Application software (b) Utility software (c) System software (d) Firmware
Answer: (c)
Solution: Application software performs specific user tasks, while system software manages hardware and provides a platform for applications; firmware is embedded in hardware. The trap is choosing application software because users interact with it directly, but the interface to hardware is the OS, so the answer is System software.
Source: NCERT Class 11 Computer Science

131. Which scheduling algorithm assigns the CPU to the process with the smallest next CPU burst?

Answer: (d)
Solution: FCFS uses arrival order, Round Robin uses time slices, Priority uses priority values; Shortest Job Next selects the process with the shortest estimated burst. The trap is confusing it with Round Robin because both aim for fairness, so the answer is Shortest Job Next.
