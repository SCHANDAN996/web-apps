सॉफ्टवेयर और ऑपरेटिंग सिस्टम

कंप्यूटर को चलाने के लिए दो मुख्य चीज़ें चाहिए: हार्डवेयर (भौतिक भाग) और सॉफ्टवेयर (निर्देशों का समूह)। सॉफ्टवेयर वे प्रोग्राम और डेटा हैं जो हार्डवेयर को बताते हैं कि क्या करना है। इसे मोटे तौर पर **दो मुख्य श्रेणियों** में बाँटा जाता है:

1. **सिस्टम सॉफ्टवेयर (System Software)** — हार्डवेयर को नियंत्रित करता है और अन्य सॉफ्टवेयर के लिए मंच प्रदान करता है। इसमें ऑपरेटिंग सिस्टम (OS), डिवाइस ड्राइवर, फर्मवेयर, **यूटिलिटी सॉफ्टवेयर** (सिस्टम रखरखाव के छोटे टूल: डिस्क क्लीनअप, डीफ़्रैगमेंटेशन, एंटीवायरस, बैकअप, फ़ाइल कम्प्रेशन) आदि आते हैं।
2. **एप्लिकेशन सॉफ्टवेयर (Application Software)** — उपयोगकर्ता के विशिष्ट कार्य पूरे करता है: वर्ड प्रोसेसर, स्प्रेडशीट, ब्राउज़र, मीडिया प्लेयर, अकाउंटिंग पैकेज आदि।

---

### ऑपरेटिंग सिस्टम (Operating System — OS)

ऑपरेटिंग सिस्टम सबसे महत्त्वपूर्ण सिस्टम सॉफ्टवेयर है। यह हार्डवेयर और उपयोगकर्ता/एप्लिकेशन के बीच मध्यस्थ का काम करता है। इसके मुख्य कार्य:

- **प्रोसेस प्रबंधन** — प्रोग्राम को CPU समय देना, शेड्यूलिंग, सिंक्रनाइज़ेशन, डेडलॉक रोकथाम।
- **मेमोरी प्रबंधन** — RAM आवंटन/मुक्त करना, वर्चुअल मेमोरी, पेजिंग, सेगमेंटेशन।
- **फ़ाइल सिस्टम प्रबंधन** — फ़ाइल/फ़ोल्डर बनाना, पढ़ना, लिखना, हटाना, अनुमति (permission), नामकरण नियम।
- **डिवाइस प्रबंधन** — ड्राइवर के ज़रिए इनपुट/आउटपुट डिवाइस (कीबोर्ड, माउस, प्रिंटर, डिस्क) से संचार।
- **सुरक्षा और अभिगम नियंत्रण** — उपयोगकर्ता खाते, पासवर्ड, एन्क्रिप्शन, फ़ायरवॉल, ऑडिट लॉग।
- **यूज़र इंटरफ़ेस** — कमांड लाइन (CLI) और ग्राफ़िकल (GUI) दोनों।

**प्रमुख OS प्रकार**  
- **विंडोज़ (Windows)** — माइक्रोसॉफ्ट का मालिकाना GUI-आधारित OS। घरेलू/कार्यालय PC में सबसे आम। संस्करण: Windows 7, 8/8.1, 10, 11 (परीक्षा में स्थिर अवधारणाओं पर ध्यान दें, संस्करण-विशिष्ट नई सुविधाओं पर नहीं)।  
- **लिनक्स (Linux)** — ओपन-सोर्स कर्नेल पर आधारित अनेक वितरण (Ubuntu, Fedora, CentOS, Debian, Kali)। सर्वर, एम्बेडेड सिस्टम, सुपरकंप्यूटर में प्रचलित।  
- **macOS** — ऐप्पल के मैक हार्डवेयर के लिए। यूनिक्स-आधारित।  
- **मोबाइल OS** — Android (लिनक्स कर्नेल), iOS (Darwin/BSD कर्नेल)।  
- **रियल-टाइम OS (RTOS)** — समय-महत्वपूर्ण सिस्टम (वायुयान, चिकित्सा उपकरण, औद्योगिक नियंत्रण)।

**फ़ाइल सिस्टम**  
- Windows: FAT32, exFAT, NTFS (आधुनिक Windows का डिफ़ॉल्ट; अनुमति, एन्क्रिप्शन, जर्नलिंग समर्थन)।  
- Linux: ext4, XFS, Btrfs।  
- macOS: APFS, HFS+।  
परीक्षा में NTFS की विशेषताएँ (फ़ाइल/फ़ोल्डर अनुमति, EFS एन्क्रिप्शन, डिस्क कोटा, जर्नलिंग) अक्सर पूछी जाती हैं।

**मेमोरी प्रबंधन अवधारणाएँ**  
- **वर्चुअल मेमोरी** — हार्ड डिस्क के भाग को RAM की तरह उपयोग करना (पेज फ़ाइल / स्वैप स्पेस)।  
- **पेजिंग** — मेमोरी को निश्चित आकार के पेज में बाँटना।  
- **थ्रैशिंग** — अत्यधिक पेज स्वैपिंग से CPU उपयोग गिरना।  
- **कैश मेमोरी** — CPU और RAM के बीच तेज़ बफ़र (L1, L2, L3)।

**प्रोसेस स्टेट्स** — New, Ready, Running, Waiting (Blocked), Terminated। शेड्यूलिंग एल्गोरिदम: FCFS, SJF, Round Robin, Priority।

### विंडोज़ मूल बातें (SSC/बैंक परीक्षा के लिए स्थिर ज्ञान)

- **बूट प्रक्रिया** — POST → BIOS/UEFI → बूटलोडर (Windows Boot Manager) → कर्नेल (ntoskrnl.exe) → सत्र प्रबंधक (smss.exe) → Winlogon → एक्सप्लोरर (explorer.exe)।  
- **रजिस्ट्री** — पदानुक्रमित डेटाबेस जो कॉन्फ़िगरेशन संग्रहीत करता है (HKEY_LOCAL_MACHINE, HKEY_CURRENT_USER आदि)।  
- **सर्विसेज** — पृष्ठभूमि प्रक्रियाएँ (services.msc से प्रबंधित)।  
- **टास्क मैनेजर** — प्रक्रिया, प्रदर्शन, स्टार्टअप, उपयोगकर्ता टैब (Ctrl+Shift+Esc)।  
- **कंट्रोल पैनल / सेटिंग्स** — सिस्टम कॉन्फ़िगरेशन।  
- **कमांड प्रॉम्प्ट (cmd) और PowerShell** — CLI टूल। PowerShell ऑब्जेक्ट-आधारित स्क्रिप्टिंग भाषा है।  
- **सुरक्षा फीचर** — BitLocker (ड्राइव एन्क्रिप्शन), Windows Defender, UAC (User Account Control), Windows Firewall, Windows Update।

### कीबोर्ड शॉर्टकट (स्कोप सहित)

परीक्षा में शॉर्टकट के **दायरे** (scope) पर प्रश्न आते हैं: कौन सा शॉर्टकट केवल विंडोज़ में काम करता है, कौन सा केवल MS Office में, और कौन सा ब्राउज़र में। इन्हें मिलाएँ नहीं।

**विंडोज़ (सिस्टम-वाइड)**  
- Win + D — डेस्कटॉप दिखाएँ/छिपाएँ  
- Win + E — फ़ाइल एक्सप्लोरर खोलें  
- Win + L — कंप्यूटर लॉक करें  
- Win + R — रन डायलॉग  
- Win + I — सेटिंग्स खोलें  
- Win + Tab — टास्क व्यू (वर्चुअल डेस्कटॉप)  
- Alt + Tab — खुली विंडो के बीच स्विच  
- Ctrl + Shift + Esc — टास्क मैनेजर  
- Win + Pause/Break — सिस्टम प्रॉपर्टीज  
- Win + S — खोज  
- Win + PrtScn — स्क्रीनशॉट (Pictures\Screenshots में सहेजा जाता है)  
- Alt + F4 — सक्रिय विंडो बंद करें / शटडाउन डायलॉग (डेस्कटॉप पर)

**MS Office (Word/Excel/PowerPoint में सामान्य)**  
- Ctrl + N — नया दस्तावेज़  
- Ctrl + O — खोलें  
- Ctrl + S — सहेजें

- Ctrl + C / X / V — कॉपी / कट / पेस्ट

- Ctrl + A — सभी चुनें  
- Ctrl + B / I / U — बोल्ड / इटैलिक / अंडरलाइन  
- Ctrl + F — खोजें  
- Ctrl + H — बदलें  
- Ctrl + Home / End — दस्तावेज़ की शुरुआत / अंत  
- **Excel विशिष्ट**: Ctrl + Shift + L (फ़िल्टर टॉगल), F2 (सेल संपादित करें), Alt + = (ऑटोसम), Ctrl + ` (फ़ॉर्मूला दिखाएँ/छिपाएँ)  
- **PowerPoint विशिष्ट**: F5 (स्लाइड शो शुरू), Shift+F5 (वर्तमान स्लाइड से शो), Ctrl+M (नई स्लाइड)

**ब्राउज़र (Chrome/Edge/Firefox — सामान्य)**

- Ctrl + L / Alt + D / F6 — एड्रेस बार पर फोकस  
- Ctrl + R / F5 — रीलोड

- Ctrl + H — हिस्ट्री

- Ctrl + D — बुकमार्क जोड़ें

**नोट**: Win+शॉर्टकट केवल विंडोज़ शेल में काम करते हैं; Ctrl+शॉर्टकट प्रायः एप्लिकेशन के अंदर काम करते हैं; ब्राउज़र शॉर्टकट केवल ब्राउज़र विंडो सक्रिय होने पर काम करते हैं। परीक्षा में "Ctrl+T विंडोज़ एक्सप्लोरर में नया टैब खोलता है" — गलत है (यह ब्राउज़र शॉर्टकट है)।

### छह कार्य-उदाहरण (Worked Examples)

**उदाहरण 1: फ़ाइल सिस्टम चयन**  
*प्रश्न*: 32 GB की USB ड्राइव को Windows और Linux दोनों पर पढ़ने-लिखने के लिए फ़ॉर्मैट करना है। कौन सा फ़ाइल सिस्टम चुनेंगे?  
*हल*: **exFAT**। कारण: FAT32 4 GB से बड़ी फ़ाइल नहीं ले सकता; NTFS लिनक्स पर लिखने के लिए अतिरिक्त ड्राइवर/कॉन्फ़िगरेशन माँगता है; exFAT दोनों OS पर मूल रूप से समर्थित है और बड़ी फ़ाइलों का समर्थन करता है।  
*सामान्य गलती*: NTFS चुनना और मान लेना कि यह हर जगह लिखने योग्य है।

**उदाहरण 2: वर्चुअल मेमोरी आकार**  
*प्रश्न*: 8 GB RAM वाले सिस्टम पर Windows में पेज फ़ाइल (वर्चुअल मेमोरी) का अनुशंसित प्रारंभिक आकार क्या है?  
*हल*: Windows डिफ़ॉल्ट रूप से **सिस्टम-प्रबंधित** आकार रखता है। मैन्युअल सेट करने पर सामान्य दिशानिर्देश: प्रारंभिक आकार = RAM का 1.5 गुना (12 GB), अधिकतम = RAM का 3 गुना (24 GB)। SSD पर पेज फ़ाइल रखना प्रदर्शन के लिए बेहतर है।  
*सामान्य गलती*: "पेज फ़ाइल बंद कर दो, RAM बहुत है" — इससे सिस्टम अस्थिर हो सकता है (कुछ एप्लिकेशन पेज फ़ाइल मानते हैं)।

**उदाहरण 3: प्रोसेस स्टेट ट्रांज़िशन**  
*प्रश्न*: एक प्रोसेस Running स्टेट में है और I/O ऑपरेशन (डिस्क रीड) का अनुरोध करती है। अगली स्टेट क्या होगी?  
*हल*: **Waiting (Blocked)**। I/O पूरा होने तक प्रोसेस CPU छोड़ देती है। I/O पूरा होने पर यह Ready कतार में जाती है।  
*सामान्य गलती*: Ready या Terminated लिखना। Ready तब होती है जब टाइम स्लाइस समाप्त हो या उच्च प्राथमिकता वाली प्रोसेस आ जाए।

**उदाहरण 4: शॉर्टकट स्कोप पहचान**  
*प्रश्न*: निम्न में से कौन सा शॉर्टकट **केवल** ब्राउज़र में काम करता है, Word में नहीं?  
(a) Ctrl+S  (b) Ctrl+T  (c) Ctrl+Z  (d) Ctrl+P  
*हल*: **(b) Ctrl+T**। ब्राउज़र में नया टैब खोलता है; Word में यह "हैंगिंग इंडेंट" बढ़ाता है (नया टैब नहीं)। Ctrl+S, Ctrl+Z, Ctrl+P दोनों में काम करते हैं (सहेजें, पूर्ववत, प्रिंट)।  
*सामान्य गलती*: सभी Ctrl+शॉर्टकट को सार्वभौमिक मानना।

**उदाहरण 5: Windows सुरक्षा फीचर पहचान**  
*प्रश्न*: कौन सा फीचर पूरी ड्राइव को एन्क्रिप्ट करता है और बूट से पहले प्रमाणीकरण माँगता है?  
*हल*: **BitLocker Drive Encryption**। यह TPM (Trusted Platform Module) 1.2/2.0 के साथ या पासवर्ड/USB कुंजी के साथ काम करता है। EFS (Encrypting File System) केवल व्यक्तिगत फ़ाइल/फ़ोल्डर एन्क्रिप्ट करता है, पूरी ड्राइव नहीं।  
*सामान्य गलती*: EFS और BitLocker को एक समझना।

**उदाहरण 6: लिनक्स फ़ाइल अनुमति व्याख्या**  
*प्रश्न*: `ls -l` आउटपुट में `-rw-r--r--` का अर्थ क्या है?  
*हल*:  
- पहला `-` — सामान्य फ़ाइल (d = डायरेक्टरी, l = सिम्बोलिक लिंक)।  
- `rw-` — मालिक (owner) पढ़/लिख सकता है, एक्ज़ीक्यूट नहीं।  
- `r--` — समूह (group) केवल पढ़ सकता है।  
- `r--` — अन्य (others) केवल पढ़ सकते हैं।  
अंकों में: **644** (4+2+0, 4+0+0, 4+0+0)।  
*सामान्य गलती*: `rwx` को 777 पढ़ना और लिखना कि "सभी को पूर्ण अधिकार" — सुरक्षा जोखिम।

### सामान्य त्रुटियाँ और भ्रम (Common Errors & Misconceptions)

1. **"OS और कर्नेल एक ही हैं"** — कर्नेल OS का **मुख्य** भाग है (मेमोरी, प्रोसेस, डिवाइस प्रबंधन); OS में कर्नेल के अलावा शेल, यूटिलिटी, लाइब्रेरी, GUI भी शामिल हैं।  
2. **"Linux वायरस-मुक्त है"** — Linux पर मालवेयर कम हैं, लेकिन शून्य नहीं। रूटकिट, क्रिप्टोमाइनर, गलत कॉन्फ़िगरेशन से समझौता संभव है।  
3. **"अधिक RAM = हमेशा तेज़"** — 32-बिट OS 4 GB से अधिक RAM उपयोग नहीं कर सकता; एप्लिकेशन 64-बिट होने चाहिए; बॉटलनेक CPU/डिस्क भी हो सकते हैं।  
4. **"NTFS केवल Windows के लिए है"** — Linux में `ntfs-3g` ड्राइवर से पढ़/लिख संभव है; macOS केवल पढ़ सकता है (लिखने के लिए तृतीय-पक्ष टूल चाहिए)।  
5. **"Safe Mode सभी ड्राइवर लोड करता है"** — Safe Mode न्यूनतम ड्राइवर/सेवा लोड करता है (नेटवर्किंग के साथ/बिना)। ड्राइवर समस्या निवारण के लिए उपयोगी।  
6. **"Ctrl+Alt+Del केवल टास्क मैनेजर खोलता है"** — Windows में यह सुरक्षा ध्यान (Security Attention Sequence) है; हार्डवेयर इंटरप्ट के कारण स्पूफ नहीं किया जा सकता। विकल्प: टास्क मैनेजर, लॉक, स्विच यूजर, साइन आउट, पावर।  
7. **"BIOS और UEFI समान हैं"** — UEFI आधुनिक रिप्लेसमेंट है: GPT डिस्क सपोर्ट, सिक्योर बूट, तेज़ बूट, माउस सपोर्ट, 2 TB+ बूट डिस्क। BIOS MBR तक सीमित।  
8. **"पेज फ़ाइल = रैम"** — पेज फ़ाइल डिस्क पर है, RAM से बहुत धीमी। थ्रैशिंग तब होती है जब RAM कम और पेज फ़ाइल पर अत्यधिक निर्भरता हो।  
9. **"एडमिनिस्ट्रेटर खाते से रोज़ काम करना ठीक है"** — सुरक्षा सिद्धांत: कम से कम विशेषाधिकार (Least Privilege)। मानक खाता उपयोग करें; UAC प्रॉम्प्ट पर सहमति दें।  
10. **"शॉर्टकट कुंजियाँ सभी प्रोग्राम में समान काम करती हैं"** — जैसा ऊपर दिखाया, स्कोप भिन्न होता है। परीक्षा में "Ctrl+T Word में नया टैब खोलता है" जैसे कथन गलत होंगे।  
11. **"Windows Update बंद करना सुरक्षित है"** — सुरक्षा पैच न मिलने से शून्य-दिन (zero-day) हमलों का खतरा बढ़ता है। WSUS/Intune से प्रबंधित अपडेट बेहतर।  
12. **"फायरवॉल और एंटीवायरस एक ही हैं"** — फायरवॉल नेटवर्क ट्रैफ़िक फ़िल्टर करता है (पोर्ट/IP नियम); एंटीवायरस फ़ाइल/मेमोरी में मालवेयर सिग्नेचर/व्यवहार जाँचता है। दोनों पूरक हैं।  
13. **"कमांड प्रॉम्प्ट और PowerShell समान हैं"** — cmd पारंपरिक बैच कमांड; PowerShell .NET ऑब्जेक्ट पाइपलाइन, रिमोटिंग, मॉड्यूल, DSC देता है।  
14. **"सिस्टम रिस्टोर फ़ाइलें वापस लाता है"** — सिस्टम रिस्टोर केवल सिस्टम फ़ाइल, रजिस्ट्री, ड्राइवर, इंस्टॉल प्रोग्राम को पिछले बिंदु पर लौटाता है; उपयोगकर्ता दस्तावेज़ (Documents, Pictures) प्रभावित नहीं होते।  
15. **"32-बिट प्रोग्राम 64-बिट OS पर नहीं चलते"** — WoW64 (Windows 32-bit on Windows 64-bit) सबसिस्टम 32-बिट एप्लिकेशन चलाता है; उल्टा संभव नहीं।

### परीक्षा-दृष्टि से मुख्य बिंदु (Exam Pointers)

- **OS परिभाषा, कार्य, प्रकार** — परिभाषा-आधारित MCQ आम।  
- **फ़ाइल सिस्टम तुलना** — FAT32 vs NTFS vs exFAT सीमा, विशेषताएँ।  
- **मेमोरी प्रबंधन शब्दावली** — वर्चुअल मेमोरी, पेजिंग, थ्रैशिंग, स्वैप, पेज फ़ॉल्ट।  
- **प्रोसेस स्टेट और शेड्यूलिंग** — स्टेट डायग्राम, एल्गोरिदम विशेषताएँ (FCFS कॉन्वॉय इफेक्ट, SJF स्टार्वेशन, RR टाइम क्वांटम)।  
- **Windows टूल** — टास्क मैनेजर, msconfig, services.msc, regedit, gpedit.msc (Pro/Enterprise), dism, sfc /scannow।  
- **शॉर्टकट स्कोप** — Win+ vs Ctrl+ vs ब्राउज़र; Office-विशिष्ट।  
- **सुरक्षा फीचर** — BitLocker, EFS, UAC, Windows Defender, Firewall, Secure Boot, TPM।  
- **लिनक्स मूल** — फ़ाइल अनुमति (chmod, chown), निर्देशिका संरचना (/etc, /var, /home, /root, /mnt), बुनियादी कमांड (ls, cp, mv, rm, grep, find, top, ps, df, du, tar, ssh)।  
- **बूट प्रक्रिया** — POST, BIOS/UEFI, बूटलोडर, कर्नेल, init/systemd, लॉगऑन।  
- **नेटवर्क कमांड** — ipconfig / ifconfig, ping, tracert / traceroute, nslookup, netstat, netsh।  

इन अवधारणाओं को समझकर, रटकर नहीं, आप SSC CHSL/CGL, बैंक, रेलवे के कंप्यूटर ज्ञान प्रश्न आत्मविश्वास से हल कर पाएँगे। अभ्यास के लिए अध्याय के अंत में दिए गए प्रैक्टिस सेट हल करें।
