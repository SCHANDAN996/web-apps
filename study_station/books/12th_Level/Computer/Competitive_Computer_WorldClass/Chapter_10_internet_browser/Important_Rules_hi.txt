इंटरनेट और ब्राउज़र — 15 महत्वपूर्ण नियम

नियम 1 — URL संरचना स्थिर रहती है  
प्रत्येक URL का निश्चित क्रम होता है: `scheme://host[:port]/path[?query][#fragment]`।  
उदाहरण: `https://www.incometax.gov.in/iec/foportal/login` में scheme = https, host = www.incometax.gov.in, path = /iec/foportal/login।  
अपवाद: पोर्ट लिखना वैकल्पिक है; डिफ़ॉल्ट HTTP के लिए 80, HTTPS के लिए 443 होता है।  
सामान्य गलती: छात्र `http://` और `https://` को एक मान लेते हैं; परीक्षा में पूछा जा सकता है कि कौन सा पोर्ट डिफ़ॉल्ट है।

नियम 2 — HTTPS, HTTP पर TLS/SSL जोड़ता है  
HTTPS = HTTP + TLS (पहले SSL)। यह डेटा को एन्क्रिप्ट करता है और सर्वर की पहचान प्रमाणित करता है।  
उदाहरण: बैंकिंग साइट `https://` पर खुलती है; पैडलॉक आइकन TLS सत्र सक्रिय होने का संकेत देता है।  
अपवाद: स्वयं-हस्ताक्षरित प्रमाणपत्र (self-signed certificate) ब्राउज़र चेतावनी देता है, फिर भी कनेक्शन एन्क्रिप्टेड रहता है।  
सामान्य गलती: "HTTPS का अर्थ HTTP Secure है" — सही वाक्यांश "HTTP over TLS" है।

नियम 3 — DNS डोमेन नाम को IP में बदलता है  
DNS (Domain Name System) पदानुक्रमित है: रूट → TLD (.in, .gov) → सेकंड-लेवल → सबडोमेन।  
उदाहरण: `www.uidai.gov.in` का समाधान: रूट → .in → .gov.in → uidai.gov.in → www।  
अपवाद: `/etc/hosts` (Windows: `C:\Windows\System32\drivers\etc\hosts`) स्थानीय प्रविष्टि DNS से पहले जाँची जाती है।  
सामान्य गलती: DNS को "डोमेन नाम सर्वर" लिखना; सही "डोमेन नाम प्रणाली" है।

नियम 4 — ब्राउज़र कैश और कुकीज़ अलग-अलग हैं  
कैश: स्थिर संसाधन (HTML, CSS, JS, चित्र) स्थानीय प्रति के रूप में संग्रहीत।  
कुकीज़: सर्वर द्वारा भेजे गए छोटे डेटा टुकड़े (सत्र ID, प्राथमिकताएँ) जो हर अनुरोध के साथ वापस जाते हैं।  
उदाहरण: लॉगिन के बाद "Remember me" कुकी सेट करता है; कैश लोगो चित्र रखता है।  
अपवाद: `Cache-Control: no-store` हेडर कैश रोकता है; `HttpOnly` कुकी JavaScript से अप्राप्य होती है।  
सामान्य गलती: कैश साफ़ करने से लॉगआउट हो जाता है — वास्तव में कुकीज़ साफ़ करने से होता है।

नियम 5 — इन्कॉग्निटो/निजी मोड केवल स्थानीय इतिहास छुपाता है  
यह ब्राउज़र को इतिहास, कुकीज़, फॉर्म डेटा स्थानीय रूप से न सहेजने का निर्देश देता है।  
उदाहरण: साइबर कैफे में निजी विंडो खोलने से अगला उपयोगकर्ता आपका इतिहास नहीं देख पाता।  
अपवाद: ISP, नियोक्ता, वेबसाइट सर्वर अभी भी ट्रैफ़िक देख सकते हैं; VPN/TOR अलग उपकरण हैं।  
सामान्य गलती: "इन्कॉग्निटो मुझे गुमनाम बनाता है" — यह केवल स्थानीय मशीन पर गुमनामी देता है।

नियम 6 — एक्सटेंशन/ऐड-ऑन ब्राउज़र अनुमतियों के अधीन होते हैं  
एक्सटेंशन मैनिफेस्ट (Manifest V3 अब मानक) में घोषित अनुमतियाँ माँगते हैं: `activeTab`, `storage`, `declarativeNetRequest` आदि।  
उदाहरण: विज्ञापन अवरोधक `declarativeNetRequest` अनुमति का उपयोग करते हैं।  
अपवाद: ब्राउज़र स्टोर नीति बदलने पर पुराने एक्सटेंशन अक्षम हो सकते हैं (Manifest V2 → V3 संक्रमण)।  
सामान्य गलती: हर एक्सटेंशन को "प्लगइन" कहना; प्लगइन (NPAPI/PPAPI) अब अप्रचलित हैं।

नियम 7 — ब्राउज़र इंजन रेंडरिंग तय करता है  
मुख्य इंजन: Blink (Chrome, Edge, Opera), WebKit (Safari), Gecko (Firefox)।  
उदाहरण: CSS `grid` सभी आधुनिक इंजन में समर्थित; पुराने `-webkit-` उपसर्ग केवल WebKit/Blink के लिए थे।  
अपवाद: iOS पर हर ब्राउज़र WebKit उपयोग करने को बाध्य है (Apple नीति)।  
सामान्य गलती: "Chrome और Edge एक ही हैं" — दोनों Blink उपयोग करते हैं, पर UI, सेवाएँ, अद्यतन चक्र अलग हैं।

नियम 8 — HTTP विधियाँ संसाधन पर क्रिया दर्शाती हैं  
GET (पढ़ें), POST (बनाएँ/प्रक्रिया), PUT (पूरा बदलें), PATCH (आंशिक बदलें), DELETE (हटाएँ)।  
उदाहरण: लॉगिन फॉर्म POST भेजता है; प्रोफ़ाइल अद्यतन PATCH भेज सकता है।  
अपवाद: HTML फॉर्म केवल GET/POST जानते हैं; PUT/PATCH/DELETE JavaScript (fetch/XHR) से भेजे जाते हैं।  
सामान्य गलती: GET को केवल इडेम्पोटेंट मानना — GET सुरक्षित (safe) और इडेम्पोटेंट दोनों है; संवेदनशील डेटा URL में न डालें।

नियम 9 — स्थिति कोड तीन अंकों के समूह में अर्थ देते हैं  
1xx सूचनात्मक, 2xx सफलता, 3xx पुनर्निर्देशन, 4xx क्लाइंट त्रुटि, 5xx सर्वर त्रुटि।  
उदाहरण: 200 OK, 301 Moved Permanently, 302 Found, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable।  
अपवाद: 304 Not Modified कैश सत्यापन के लिए; बॉडी नहीं होती।  
सामान्य गलती: 301 और 302 को एक मानना — 301 स्थायी (SEO लिंक जूस पास करता है), 302 अस्थायी।

नियम 10 — CORS क्रॉस-ओरिजन अनुरोध नियंत्रित करता है  
ब्राउज़र डिफ़ॉल्ट रूप से अलग ओरिजन (scheme+host+port) पर AJAX रोकता है; सर्वर `Access-Control-Allow-Origin` हेडर देकर अनुमति देता है।  
उदाहरण: `https://app.example.com` API `https://api.example.com` को कॉल करता है; API हेडर में `Access-Control-Allow-Origin: https://app.example.com` लौटाता है।  
अपवाद: सरल अनुरोध (GET/POST, सीमित हेडर) प्रीफ्लाइट (OPTIONS) नहीं भेजते।  
सामान्य गलती: CORS को सर्वर-साइड सुरक्षा मानना — यह ब्राउज़र-लागू नीति है; curl/Postman पर लागू नहीं होती।

नियम 11 — TLS संस्करण और सिफर सुइट सुरक्षा तय करते हैं  
TLS 1.2 (2008) और 1.3 (2018) मानक; 1.0/1.1 असुरक्षित (ब्राउज़र अक्षम कर चुके)।  
उदाहरण: `TLS_AES_256_GCM_SHA384` TLS 1.3 अनिवार्य सिफर सुइट।  
अपवाद: पुराने सर्वर/क्लाइंट TLS 1.2 पर फॉलबैक कर सकते हैं; `SSLv2/SSLv3` पूरी तरह निषिद्ध।  
सामान्य गलती: "SSL सर्टिफिकेट" कहना — प्रमाणपत्र X.509 है; प्रोटोकॉल TLS है।

नियम 12 — HSTS ब्राउज़र को केवल HTTPS पर बाध्य करता है  
सर्वर `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload` भेजता है; ब्राउज़र भविष्य के सभी अनुरोध HTTPS में बदल देता है।  
उदाहरण: `https://www.sbi.co.in` HSTS सूची में है; `http://` टाइप करने पर भी ब्राउज़र `https://` पर जाता है।  
अपवाद: पहली विज़िट (TOFU) पर HSTS सक्रिय नहीं होता; `preload` सूची में डोमेन जमा करके इससे बचा जाता है।  
सामान्य गलती: HSTS को रीडायरेक्ट समझना — यह ब्राउज़र-स्तरीय आंतरिक पुनर्लेखन है, सर्वर रीडायरेक्ट नहीं।

नियम 13 — CSP (Content Security Policy) XSS कम करता है  
सर्वर `Content-Security-Policy` हेडर में अनुमत स्रोत घोषित करता है: `script-src 'self' https://cdn.example.com`।  
उदाहरण: इनलाइन स्क्रिप्ट `<script>alert(1)</script>` CSP `script-src 'self'` के साथ ब्लॉक होती है।  
अपवाद: `'unsafe-inline'` या नॉन्स/हैश से इनलाइन अनुमत किया जा सकता है (अनुशंसित नहीं)।  
सामान्य गलती: CSP को सर्वर-साइड वैलिडेशन का विकल्प मानना — यह रक्षा-में-गहराई (defense-in-depth) परत है।

नियम 14 — वेब स्टोरेज: localStorage, sessionStorage, IndexedDB  
localStorage: स्थायी (कोई समाप्ति नहीं), 5–10 MB, सिंक्रोनस, समान ओरिजन।  
sessionStorage: टैब बंद होने तक, समान API।  
IndexedDB: असिंक्रोनस, बड़ी मात्रा, सूचकांक/लेनदेन समर्थन।  
उदाहरण: टोकन localStorage में; फॉर्म ड्राफ्ट sessionStorage में।  
अपवाद: निजी मोड में storage सत्र समाप्ति पर मिट जाता है; कोटा पार करने पर `QuotaExceededError`।  
सामान्य गलती: localStorage को कुकी समझना — यह सर्वर को स्वचालित नहीं भेजा जाता।

नियम 15 — ब्राउज़र शॉर्टकट (Windows) परीक्षा में पूछे जाते हैं  
नया टैब: `Ctrl+T` | टैब बंद: `Ctrl+W` | बंद टैब पुनः खोलें: `Ctrl+Shift+T`  
पता बार फोकस: `Ctrl+L` / `F6` / `Alt+D` | खोज: `Ctrl+F` | रीलोड: `F5` / `Ctrl+R`  
हार्ड रीलोड (कैश बायपास): `Ctrl+F5` / `Ctrl+Shift+R`  
डेवलपर टूल: `F12` / `Ctrl+Shift+I` | डाउनलोड: `Ctrl+J` | इतिहास: `Ctrl+H`  
पूर्ण-स्क्रीन: `F11` | ज़ूम: `Ctrl++` / `Ctrl+-` / `Ctrl+0` (रीसेट)  
निजी विंडो: `Ctrl+Shift+N` (Chrome/Edge) | `Ctrl+Shift+P` (Firefox)  
नोट: मैक पर `Ctrl` → `Cmd`; लिनक्स पर समान।  
सामान्य गलती: `Ctrl+N` को निजी विंडो समझना — यह सामान्य नई विंडो खोलता है।
