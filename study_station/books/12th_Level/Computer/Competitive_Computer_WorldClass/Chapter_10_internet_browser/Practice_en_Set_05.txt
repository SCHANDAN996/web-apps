101. What does the "https" in a website address indicate?
(a) The site loads faster than http sites (b) The site uses a secure encrypted connection (c) The site is a government website (d) The site requires a login
Answer: (b)
Solution: Many candidates confuse "https" with speed or site type; the "s" stands for "secure" and means the connection uses TLS/SSL encryption to protect data in transit, so the answer is the site uses a secure encrypted connection.
Source: PYQ-style

102. Which part of the URL "https://www.example.com/path/page.html" identifies the specific server on the internet?
(a) https:// (b) www.example.com (c) /path/page.html (d) The entire string
Answer: (b)
Solution: The domain name "www.example.com" (or just "example.com") is resolved by DNS to an IP address that locates the server; the protocol and path come after the server is identified, so the answer is www.example.com.
Source: PYQ-style

103. What is the primary function of a web browser?
(a) To host websites on a server (b) To create HTML code automatically (c) To register domain names (d) To request and display web pages from servers
Answer: (d)
Solution: A browser is a client application that sends HTTP requests to servers and renders the received HTML/CSS/JS; it does not host sites or register domains, so the answer is to request and display web pages from servers.

104. Which of the following is a search engine, not a web browser?
(a) Google Chrome (b) Mozilla Firefox (c) Google Search (d) Microsoft Edge
Answer: (c)
Solution: Chrome, Firefox, and Edge are browsers that render pages; Google Search is a service that indexes and retrieves web content, so the answer is Google Search.

105. What is the main purpose of HTTP cookies?
(a) To encrypt data between browser and server (b) To speed up internet connection (c) To store user preferences and session data on the client side (d) To block malicious websites
Answer: (c)
Solution: Cookies are small text files stored by the browser to remember stateful information like login sessions or preferences; they do not encrypt traffic or block sites, so the answer is to store user preferences and session data on the client side.

106. What does "clearing the browser cache" remove?
(a) Temporary copies of web page resources like images and scripts (b) Saved passwords and autofill data (c) Browser history and bookmarks (d) Installed extensions and themes
Answer: (a)
Solution: Cache stores local copies of static assets to load pages faster on revisits; clearing it frees space and forces fresh downloads, but does not affect passwords, history, or extensions, so the answer is temporary copies of web page resources like images and scripts.

107. What does DNS (Domain Name System) primarily do?
(a) Assigns IP addresses to devices (b) Encrypts web traffic (c) Translates domain names into IP addresses (d) Hosts website files
Answer: (c)
Solution: DNS is the internet's phonebook — it resolves human-readable names like "example.com" to numeric IP addresses; it does not assign IPs (DHCP does) or host files, so the answer is translates domain names into IP addresses.

108. Which of the following is a valid IPv4 address format?
(a) 192.168.1.256 (b) 2001:0db8:85a3::8a2e:0370:7334 (c) www.example.com (d) 172.16.254.1
Answer: (d)
Solution: IPv4 uses four decimal octets (0–255); 256 is invalid, the second option is IPv6, and the last is a domain name, so the answer is 172.16.254.1.

Answer: (d)

(a) 404 (b) 301 (c) 200 (d) 500
Answer: (a)
Solution: 200 means OK, 301 is permanent redirect, 500 is server error; 404 is the standard code for a resource that does not exist, so the answer is 404.

(a) To prove the site loads fast (b) To improve search engine ranking automatically (c) To verify the site's identity and enable encrypted HTTPS connections (d) To prevent all types of cyber attacks
Answer: (c)
Solution: Certificates bind a public key to a verified domain owner, enabling HTTPS encryption and identity assurance; they do not guarantee speed, SEO, or total security, so the answer is to verify the site's identity and enable encrypted HTTPS connections.

123. What is the key difference between a static and a dynamic web page?
(a) Static pages show the same content to every user; dynamic pages generate content per request (b) Static pages use HTML only; dynamic pages require Java (c) Static pages load slower (d) Dynamic pages cannot be cached
Answer: (a)
Solution: Static pages are pre-written files served identically; dynamic pages are generated by server-side code (PHP, Python, etc.) per request using databases or user data; speed and caching depend on implementation, so the answer is static pages show the same content to every user; dynamic pages generate content per request.

125. Which of the following is a browser rendering engine?
(a) Blink (b) V8 (c) Node.js (d) npm
Answer: (a)
Solution: Blink (used in Chrome/Edge) and WebKit (Safari) are rendering engines that parse HTML/CSS and paint pixels; V8 is a JavaScript engine, Node.js is a JS runtime, npm is a package manager, so the answer is Blink.
