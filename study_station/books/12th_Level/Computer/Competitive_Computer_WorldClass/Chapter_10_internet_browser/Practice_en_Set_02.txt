26. What does HTTP stand for?
(a) HyperText Transfer Protocol (b) HighText Transfer Protocol (c) HyperText Transmission Protocol (d) High Transfer Text Protocol
Answer: (a)
Solution: The term "Transmission" in Option C is a common confusion because data is transmitted, but the standard name uses "Transfer"; the correct expansion is HyperText Transfer Protocol, so the answer is HyperText Transfer Protocol.
Source: NCERT Class 10 Computer Science

27. Which protocol is used for secure web browsing?
(a) HTTPS (b) FTP (c) HTTP (d) SMTP
Answer: (a)
Solution: HTTP sends data in plain text, and FTP is for file transfer; HTTPS adds SSL/TLS encryption for security, so the answer is HTTPS.
Source: Microsoft Learn – HTTPS overview

28. What is the default port number for HTTP?
(a) 80 (b) 21 (c) 443 (d) 25
Answer: (a)
Solution: Port 443 is for HTTPS, port 21 for FTP, and port 25 for SMTP; HTTP uses port 80 by default, so the answer is 80.
Source: IANA Service Name and Transport Protocol Port Number Registry

29. Which of the following is NOT a valid top-level domain?
(a) .com (b) .local (c) .net (d) .org
Answer: (b)
Solution: .local is reserved for local networks (mDNS) and not a public top-level domain like .com, .org, or .net, so the answer is .local.
Source: ICANN Root Zone Database

30. What does DNS stand for?
(a) Domain Name System (b) Dynamic Name Server (c) Distributed Network System (d) Digital Name Service
Answer: (a)
Solution: "Dynamic Name Server" sounds plausible because DNS records can change, but the official name is Domain Name System, so the answer is Domain Name System.
Source: RFC 1034 / NCERT Class 12 Computer Science

31. Which web browser is developed by the Mozilla Foundation?

33. Which protocol is used for sending emails?

34. What does URL stand for?

36. What is the primary function of a cookie in web browsing?

38. What does ISP stand for?

39. Which of the following is a search engine?

40. What is phishing?

41. Which email protocol keeps messages on the server and synchronizes across devices?
(a) POP3 (b) IMAP (c) SMTP (d) FTP

42. What does an IP address represent?
(a) A website name (b) An email address (c) A unique identifier for a device on a network (d) A browser version
Answer: (c)
Solution: A domain name represents a website; an IP address is the numeric label identifying each network device, so the answer is A unique identifier for a device on a network.

43. Which of the following is a valid IPv4 address?
(a) 256.1.1.1 (b) 192.168.1.1 (c) 192.168.1.1.1 (d) 192.168.1
Answer: (b)
Solution: Each octet must be 0–255; 256 is invalid, and an IPv4 address has exactly four octets, so the answer is 192.168.1.1.
Source: RFC 791 / IANA IPv4 Address Space Registry
