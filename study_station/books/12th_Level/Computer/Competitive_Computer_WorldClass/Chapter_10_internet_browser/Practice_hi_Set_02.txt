26. HTTP का पूर्ण रूप क्या है?
(a) HyperText Transfer Protocol (b) HighText Transfer Protocol (c) HyperText Transmission Protocol (d) High Transfer Text Protocol
उत्तर: (a)
हल: विकल्प C में "Transmission" शब्द एक सामान्य भ्रम है क्योंकि डेटा प्रसारित होता है, लेकिन मानक नाम में "Transfer" प्रयुक्त होता है; सही विस्तार HyperText Transfer Protocol है, इसलिए उत्तर HyperText Transfer Protocol है।
स्रोत: NCERT कक्षा 10 कंप्यूटर विज्ञान

27. सुरक्षित वेब ब्राउज़िंग के लिए किस प्रोटोकॉल का उपयोग किया जाता है?
(a) HTTPS (b) FTP (c) HTTP (d) SMTP
उत्तर: (a)
हल: HTTP डेटा को सादे पाठ में भेजता है, और FTP फ़ाइल स्थानांतरण के लिए है; HTTPS सुरक्षा के लिए SSL/TLS एन्क्रिप्शन जोड़ता है, इसलिए उत्तर HTTPS है।
स्रोत: Microsoft Learn – HTTPS अवलोकन

28. HTTP के लिए डिफ़ॉल्ट पोर्ट संख्या क्या है?
(a) 80 (b) 21 (c) 443 (d) 25
उत्तर: (a)
हल: पोर्ट 443 HTTPS के लिए है, पोर्ट 21 FTP के लिए, और पोर्ट 25 SMTP के लिए; HTTP डिफ़ॉल्ट रूप से पोर्ट 80 का उपयोग करता है, इसलिए उत्तर 80 है।
स्रोत: IANA सेवा नाम और ट्रांसपोर्ट प्रोटोकॉल पोर्ट संख्या रजिस्ट्री

29. निम्नलिखित में से कौन सा वैध शीर्ष-स्तरीय डोमेन नहीं है?
(a) .com (b) .local (c) .net (d) .org
उत्तर: (b)
हल: .local स्थानीय नेटवर्क (mDNS) के लिए आरक्षित है और .com, .org, या .net की तरह सार्वजनिक शीर्ष-स्तरीय डोमेन नहीं है, इसलिए उत्तर .local है।
स्रोत: ICANN रूट ज़ोन डेटाबेस

30. DNS का पूर्ण रूप क्या है?
(a) Domain Name System (b) Dynamic Name Server (c) Distributed Network System (d) Digital Name Service
उत्तर: (a)
हल: "Dynamic Name Server" प्रशंसनीय लगता है क्योंकि DNS रिकॉर्ड बदल सकते हैं, लेकिन आधिकारिक नाम Domain Name System है, इसलिए उत्तर Domain Name System है।
स्रोत: RFC 1034 / NCERT कक्षा 12 कंप्यूटर विज्ञान

31. कौन सा वेब ब्राउज़र Mozilla Foundation द्वारा विकसित है?
(a) Edge (b) Chrome (c) Firefox (d) Safari
उत्तर: (c)
हल: Chrome Google का है, Edge Microsoft का, Safari Apple का; Firefox Mozilla Foundation का ओपन-सोर्स ब्राउज़र है, इसलिए उत्तर Firefox है।
स्रोत: Mozilla Foundation आधिकारिक साइट

32. Windows पर अधिकांश ब्राउज़रों में नया टैब खोलने का कीबोर्ड शॉर्टकट क्या है?
(a) Alt+T (b) Ctrl+N (c) Ctrl+Shift+N (d) Ctrl+T
उत्तर: (d)
हल: Ctrl+N नई विंडो खोलता है, Ctrl+Shift+N इनकॉग्निटो/निजी विंडो खोलता है; मानक नया-टैब शॉर्टकट Ctrl+T है, इसलिए उत्तर Ctrl+T है।
स्रोत: Microsoft Support – Microsoft Edge में कीबोर्ड शॉर्टकट / Chrome सहायता

33. ईमेल भेजने के लिए किस प्रोटोकॉल का उपयोग किया जाता है?
(a) POP3 (b) SMTP (c) IMAP (d) HTTP
उत्तर: (b)
हल: POP3 और IMAP ईमेल प्राप्त करने के लिए हैं; SMTP (Simple Mail Transfer Protocol) भेजने को संभालता है, इसलिए उत्तर SMTP है।
स्रोत: RFC 5321 / NCERT कक्षा 12 कंप्यूटर विज्ञान

34. URL का पूर्ण रूप क्या है?
(a) Universal Resource Link (b) Uniform Resource Locator (c) Uniform Reference Locator (d) Universal Reference Link
उत्तर: (b)
हल: "Universal Resource Link" एक सामान्य गलत विस्तार है; सही शब्द Uniform Resource Locator है, इसलिए उत्तर Uniform Resource Locator है।
स्रोत: RFC 1738 / NCERT कक्षा 10 कंप्यूटर विज्ञान

35. निम्नलिखित में से कौन सा वेब ब्राउज़र नहीं है?
(a) Outlook (b) Firefox (c) Edge (d) Chrome
उत्तर: (a)
हल: Outlook एक ईमेल क्लाइंट और व्यक्तिगत सूचना प्रबंधक है, वेब ब्राउज़र नहीं, इसलिए उत्तर Outlook है।
स्रोत: Microsoft 365 दस्तावेज़ीकरण

36. वेब ब्राउज़िंग में कुकी का प्राथमिक कार्य क्या है?
(a) डेटा एन्क्रिप्ट करना (b) इंटरनेट गति बढ़ाना (c) विज्ञापन ब्लॉक करना (d) उपयोगकर्ता प्राथमिकताओं और सत्र डेटा को संग्रहीत करना
उत्तर: (d)
हल: कुकीज़ कनेक्शन को तेज़ नहीं करतीं, विज्ञापन ब्लॉक नहीं करतीं, या डेटा एन्क्रिप्ट नहीं करतीं; वे छोटी टेक्स्ट फ़ाइलें हैं जो उपयोगकर्ता स्थिति को याद रखती हैं, इसलिए उत्तर उपयोगकर्ता प्राथमिकताओं और सत्र डेटा को संग्रहीत करना है।
स्रोत: MDN Web Docs – HTTP कुकीज़

37. Windows पर अधिकांश ब्राउज़रों में फुल-स्क्रीन मोड टॉगल करने वाली कुंजी कौन सी है?
(a) F11 (b) Ctrl+R (c) Alt+Enter (d) F5
उत्तर: (a)
हल: F5 और Ctrl+R पृष्ठ को रीफ्रेश करते हैं, Alt+Enter के अन्य उपयोग हैं; F11 मानक फुल-स्क्रीन टॉगल है, इसलिए उत्तर F11 है।
स्रोत: Microsoft Support – ब्राउज़रों में कीबोर्ड शॉर्टकट

38. ISP का पूर्ण रूप क्या है?
(a) Internet Service Provider (b) Internal System Protocol (c) International Standard Protocol (d) Internet Security Provider
उत्तर: (a)
हल: अन्य विकल्प तकनीकी लगते हैं लेकिन मानक विस्तार नहीं हैं; ISP का अर्थ Internet Service Provider है, इसलिए उत्तर Internet Service Provider है।
स्रोत: NCERT कक्षा 10 कंप्यूटर विज्ञान

39. निम्नलिखित में से कौन सा खोज इंजन है?
(a) Chrome (b) Firefox (c) Edge (d) Google

हल: Chrome, Firefox, और Edge वेब ब्राउज़र हैं; Google एक खोज इंजन है (हालांकि यह एक ब्राउज़र भी बनाता है), इसलिए उत्तर Google है।
स्रोत: NCERT कक्षा 10 कंप्यूटर विज्ञान

40. फ़िशिंग क्या है?
(a) एक प्रकार का मैलवेयर (b) एक ब्राउज़र सुविधा (c) संवेदनशील जानकारी प्राप्त करने का कपटपूर्ण प्रयास (d) एक नेटवर्क प्रोटोकॉल
उत्तर: (c)
हल: फ़िशिंग मैलवेयर, सुविधा, या प्रोटोकॉल नहीं है; यह एक सोशल-इंजीनियरिंग हमला है जो उपयोगकर्ताओं को क्रेडेंशियल प्रकट करने के लिए धोखा देता है, इसलिए उत्तर संवेदनशील जानकारी प्राप्त करने का कपटपूर्ण प्रयास है।
स्रोत: CERT-In परामर्श – फ़िशिंग हमले

41. कौन सा ईमेल प्रोटोकॉल संदेशों को सर्वर पर रखता है और उपकरणों में सिंक्रनाइज़ करता है?
(a) POP3 (b) IMAP (c) SMTP (d) FTP
उत्तर: (b)
हल: POP3 आमतौर पर डाउनलोड करके सर्वर से हटा देता है; IMAP मेल को सर्वर पर छोड़ देता है ताकि बहु-उपकरण सिंक हो सके, इसलिए उत्तर IMAP है।
स्रोत: RFC 3501 / Microsoft Support – POP बनाम IMAP

42. IP पता क्या दर्शाता है?
(a) एक वेबसाइट नाम (b) एक ईमेल पता (c) नेटवर्क पर एक उपकरण का अद्वितीय पहचानकर्ता (d) एक ब्राउज़र संस्करण
उत्तर: (c)
हल: डोमेन नाम एक वेबसाइट को दर्शाता है; IP पता प्रत्येक नेटवर्क उपकरण की पहचान करने वाला संख्यात्मक लेबल है, इसलिए उत्तर नेटवर्क पर एक उपकरण का अद्वितीय पहचानकर्ता है।
स्रोत: RFC 791 / NCERT कक्षा 12 कंप्यूटर विज्ञान

43. निम्नलिखित में से कौन सा वैध IPv4 पता है?
(a) 256.1.1.1 (b) 192.168.1.1 (c) 192.168.1.1.1 (d) 192.168.1
उत्तर: (b)
हल: प्रत्येक ऑक्टेट 0–255 होना चाहिए; 256 अमान्य है, और एक IPv4 पते में ठीक चार ऑक्टेट होते हैं, इसलिए उत्तर 192.168.1.1 है।
स्रोत: RFC 791 / IANA IPv4 पता स्थान रजिस्ट्री

44. ब्राउज़र कैश का उद्देश्य क्या है?
(a) पासवर्ड संग्रहीत करना (b) बुकमार्क प्रबंधित करना (c) पॉप-अप ब्लॉक करना (d) तेज़ लोडिंग के लिए वेब पृष्ठों की प्रतियाँ संग्रहीत करना
उत्तर: (d)
हल: पासवर्ड पासवर्ड मैनेजर में रखे जाते हैं, पॉप-अप ब्लॉकर द्वारा संभाले जाते हैं, बुकमार्क अलग होते हैं; कैश पृष्ठ संसाधनों को स्थानीय रूप से संग्रहीत करता है ताकि दोबारा विज़िट तेज़ हो, इसलिए उत्तर तेज़ लोडिंग के लिए वेब पृष्ठों की प्रतियाँ संग्रहीत करना है।
स्रोत: MDN Web Docs – HTTP कैशिंग

45. Windows पर Chrome में इतिहास पृष्ठ खोलने का कीबोर्ड शॉर्टकट क्या है?
(a) Ctrl+J (b) Ctrl+Y (c) Ctrl+H (d) Ctrl+Shift+H
उत्तर: (c)
हल: Ctrl+J डाउनलोड खोलता है, Ctrl+Y किसी क्रिया को दोहराता है, Ctrl+Shift+H मानक नहीं है; Ctrl+H सामान्य इतिहास शॉर्टकट है, इसलिए उत्तर Ctrl+H है।
स्रोत: Chrome सहायता – कीबोर्ड शॉर्टकट

46. HTTP और HTTPS में मुख्य अंतर क्या है?
(a) HTTPS पोर्ट 80 का उपयोग करता है, HTTP पोर्ट 443 का (b) HTTP डेटा एन्क्रिप्ट करता है, HTTPS नहीं (c) HTTPS SSL/TLS का उपयोग करके डेटा एन्क्रिप्ट करता है, HTTP नहीं (d) HTTPS केवल बैंकिंग साइटों के लिए है
उत्तर: (c)
हल: विकल्प A में पोर्ट उलटे हैं, और HTTPS बैंकिंग तक सीमित नहीं है; मुख्य अंतर HTTPS में SSL/TLS एन्क्रिप्शन है, इसलिए उत्तर HTTPS SSL/TLS का उपयोग करके डेटा एन्क्रिप्ट करता है, HTTP नहीं है।
स्रोत: RFC 2818 / Microsoft Learn – HTTPS

47. कुकीज़ के बारे में कौन सा कथन सही है?
(a) कुकीज़ वेबसाइटों द्वारा संग्रहीत छोटी टेक्स्ट फ़ाइलें हैं (b) कुकीज़ हमेशा एन्क्रिप्टेड होती हैं (c) कुकीज़ आपके कंप्यूटर पर कोड निष्पादित कर सकती हैं (d) कुकीज़ आपकी हार्ड ड्राइव तक पहुँच सकती हैं
उत्तर: (a)
हल: कुकीज़ कोड नहीं चला सकतीं, हमेशा एन्क्रिप्टेड नहीं होतीं, और मनमानी फ़ाइलें नहीं पढ़ सकतीं; वे साइटों द्वारा भेजी गई सरल टेक्स्ट फ़ाइलें हैं, इसलिए उत्तर कुकीज़ वेबसाइटों द्वारा संग्रहीत छोटी टेक्स्ट फ़ाइलें हैं।
स्रोत: MDN Web Docs – HTTP कुकीज़

48. HTTPS में 'S' का क्या अर्थ है?
(a) Socket (b) Standard (c) System (d) Secure
उत्तर: (d)
हल: 'S' HTTP में जोड़े गए सुरक्षित (एन्क्रिप्टेड) लेयर को दर्शाता है, न कि socket, standard, या system, इसलिए उत्तर Secure है।
स्रोत: RFC 2818 / NCERT कक्षा 12 कंप्यूटर विज्ञान

49. कौन सा प्रोटोकॉल डोमेन नामों को IP पतों में बदलता है?
(a) DHCP (b) FTP (c) HTTP (d) DNS
उत्तर: (d)
हल: DHCP उपकरणों को IP पते असाइन करता है, HTTP वेब पृष्ठ स्थानांतरित करता है, FTP फ़ाइलें स्थानांतरित करता है; DNS नामों को IP में मैप करता है, इसलिए उत्तर DNS है।
स्रोत: RFC 1035 / NCERT कक्षा 12 कंप्यूटर विज्ञान

50. मैन-इन-द-मिडल हमला क्या है?
(a) एक ब्राउज़र क्रैश (b) एक वायरस जो ईमेल के माध्यम से फैलता है (c) एक हमला जहां हमलावर दो पक्षों के बीच संचार को रोकता है (d) एक प्रकार का फ़िशिंग ईमेल
उत्तर: (c)
हल: यह वायरस, क्रैश, या फ़िशिंग ईमेल नहीं है; यह एक संचार चैनल का सक्रिय अवरोधन है, इसलिए उत्तर एक हमला जहां हमलावर दो पक्षों के बीच संचार को रोकता है।
स्रोत: CERT-In परामर्श – मैन-इन-द-मिडल हमले
