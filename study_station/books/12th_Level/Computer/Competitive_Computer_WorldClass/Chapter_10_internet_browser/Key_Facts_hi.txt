इंटरनेट और ब्राउज़र — मुख्य तथ्य (25 संशोधन बिंदु)

1. **इंटरनेट की परिभाषा** — इंटरनेट विश्वभर के कंप्यूटर नेटवर्कों का एक वैश्विक नेटवर्क है जो TCP/IP प्रोटोकॉल सूट का उपयोग करके आपस में जुड़े होते हैं।  
   स्रोत: NCERT कक्षा 10 कंप्यूटर विज्ञान

2. **वर्ल्ड वाइड वेब (WWW)** — WWW इंटरनेट पर हाइपरटेक्स्ट दस्तावेजों (वेब पेज) का संग्रह है जो हाइपरलिंक द्वारा जुड़े होते हैं; इसका आविष्कार टिम बर्नर्स-ली ने 1989 में किया।  
   स्रोत: W3C आधिकारिक इतिहास

3. **ब्राउज़र का कार्य** — वेब ब्राउज़र एक क्लाइंट सॉफ्टवेयर है जो HTTP/HTTPS के माध्यम से वेब सर्वर से संसाधन (HTML, CSS, JS, चित्र) मांगता है, उन्हें रेंडर करता है और उपयोगकर्ता को प्रदर्शित करता है।  
   स्रोत: MDN Web Docs (Mozilla)

4. **मुख्य ब्राउज़र इंजन** — Blink (Chrome, Edge, Opera), Gecko (Firefox), WebKit (Safari) — ये इंजन HTML/CSS को पार्स करके पिक्सेल में बदलते हैं।  
   स्रोत: ब्राउज़र विक्रेताओं की आधिकारिक दस्तावेज़ीकरण

5. **URL संरचना** — `scheme://host:port/path?query#fragment` — उदाहरण: `https://www.example.com:443/page?id=1#section`।  
   स्रोत: RFC 3986

6. **HTTP बनाम HTTPS** — HTTP (पोर्ट 80) सादे पाठ में डेटा भेजता है; HTTPS (पोर्ट 443) TLS/SSL एन्क्रिप्शन जोड़ता है, जिससे गोपनीयता और अखंडता सुनिश्चित होती है।  
   स्रोत: CERT-In सुरक्षा दिशानिर्देश

7. **DNS (डोमेन नेम सिस्टम)** — डोमेन नाम (जैसे `google.com`) को IP पते (जैसे `142.250.190.46`) में बदलता है; पदानुक्रम: रूट → TLD → प्राधिकारी नेमसर्वर।  
   स्रोत: NCERT कक्षा 12 कंप्यूटर विज्ञान

8. **IP पता संस्करण** — IPv4 (32-बिट, लगभग 4.3 अरब पते) और IPv6 (128-बिट, विशाल पता स्थान); भारत में IPv6 अपनाने की नीति DoT द्वारा संचालित।  
   स्रोत: DoT भारत IPv6 रोडमैप

9. **कुकीज़** — सर्वर द्वारा ब्राउज़र में संग्रहीत छोटी टेक्स्ट फाइलें (आमतौर पर ≤4 KB) जो सत्र प्रबंधन, वैयक्तिकरण, ट्रैकिंग के लिए उपयोग होती हैं; `HttpOnly` और `Secure` फ्लैग सुरक्षा बढ़ाते हैं।  
   स्रोत: RFC 6265

10. **कैश और कैश-कंट्रोल** — ब्राउज़र स्थिर संसाधनों की स्थानीय प्रति रखता है; `Cache-Control: max-age=3600` जैसे हेडर कैश अवधि निर्धारित करते हैं।  
    स्रोत: HTTP/1.1 विनिर्देश (RFC 7234)

11. **सत्र और स्थानीय भंडारण** — `sessionStorage` (टैब बंद होने तक), `localStorage` (कोई समाप्ति नहीं), दोनों प्रति-उत्पत्ति (origin) 5–10 MB तक; कुकीज़ के विपरीत सर्वर को स्वचालित नहीं भेजे जाते।  
    स्रोत: WHATWG HTML Living Standard

12. **समान-मूल नीति (Same-Origin Policy)** — ब्राउज़र सुरक्षा मॉडल जो एक मूल (scheme+host+port) के स्क्रिप्ट को दूसरे मूल के डेटा तक पहुँचने से रोकता है; CORS हेडर नियंत्रित अपवाद देते हैं।  
    स्रोत: MDN Web Docs

13. **CORS (क्रॉस-ओरिजिन रिसोर्स शेयरिंग)** — सर्वर `Access-Control-Allow-Origin` हेडर भेजकर चुनिंदा क्रॉस-ओरिजिन अनुरोधों की अनुमति देता है; प्रीफ्लाइट `OPTIONS` अनुरोध जटिल अनुरोधों के लिए आवश्यक।  
    स्रोत: W3C CORS विनिर्देश

14. **वेब सॉकेट** — `ws://` / `wss://` प्रोटोकॉल एक ही TCP कनेक्शन पर पूर्ण-द्विदिश संचार सक्षम करता है; HTTP पोलिंग की तुलना में कम ओवरहेड।  
    स्रोत: RFC 6455

15. **प्रगतिशील वेब ऐप (PWA)** — सेवा कर्मी (service worker), वेब ऐप मैनिफेस्ट, HTTPS का उपयोग करके ऑफ़लाइन कार्य, पुश सूचना, इंस्टॉल करने योग्य अनुभव प्रदान करते हैं।  
    स्रोत: Google Web Fundamentals / MDN

16. **ब्राउज़र एक्सटेंशन** — मैनिफेस्ट V3 (Chrome/Edge/Firefox) पृष्ठभूमि स्क्रिप्ट को सेवा कर्मी में बदलता है, `declarativeNetRequest` API से सामग्री अवरोधन; अनुमति मॉडल उपयोगकर्ता सहमति लागू करता है।  
    स्रोत: Chrome Developers / Mozilla Add-ons दस्तावेज़

17. **खोज इंजन क्रॉलिंग और इंडेक्सिंग** — क्रॉलर (बॉट) `robots.txt` और साइटमैप का पालन करते हैं; इंडेक्सिंग सामग्री को खोज योग्य बनाता है; रैंकिंग एल्गोरिदम (PageRank आदि) प्रासंगिकता क्रम तय करते हैं।  
    स्रोत: Google Search Central दस्तावेज़

18. **सामान्य ब्राउज़र शॉर्टकट (Windows/Linux)** — `Ctrl+T` नया टैब, `Ctrl+W` टैब बंद, `Ctrl+Shift+T` अंतिम बंद टैब पुनः खोलें, `Ctrl+L` / `F6` पता बार, `Ctrl+H` इतिहास, `Ctrl+J` डाउनलोड, `F5` / `Ctrl+R` रीलोड, `Ctrl+Shift+R` हार्ड रीलोड (कैश बायपास)।  
    स्रोत: ब्राउज़र विक्रेता आधिकारिक शॉर्टकट सूची

19. **निजी/इंकॉग्निटो मोड** — स्थानीय इतिहास, कुकीज़, फॉर्म डेटा सत्र के बाद मिटा देता है; ISP, नियोक्ता, वेबसाइट को IP/फिंगरप्रिंट से ट्रैक करने से **नहीं** रोकता।  
    स्रोत: ब्राउज़र सहायता पृष्ठ (Chrome, Firefox, Edge)

20. **सुरक्षा संकेतक** — पता बार में पैडलॉक = वैध TLS प्रमाणपत्र; "सुरक्षित नहीं" चेतावनी = HTTP या प्रमाणपत्र त्रुटि; EV प्रमाणपत्र पहले संगठन नाम दिखाते थे (अब अधिकांश UI में हटा दिया गया)।  
    स्रोत: CERT-In सुरक्षित ब्राउज़िंग दिशानिर्देश

21. **पॉप-अप अवरोधक** — ब्राउज़र डिफ़ॉल्ट रूप से अनुरोधित पॉप-अप (`window.open` उपयोगकर्ता जेस्चर के बिना) अवरुद्ध करते हैं; प्रति-साइट अनुमति सेटिंग में प्रबंधनीय।  
    स्रोत: HTML Living Standard / ब्राउज़र दस्तावेज़

22. **डाउनलोड प्रबंधन** — ब्राउज़र डिफ़ॉल्ट डाउनलोड फ़ोल्डर उपयोग करता है; `Content-Disposition: attachment` हेडर फ़ाइल नाम सुझाता है; मैलवेयर स्कैनिंग (SmartScreen, Safe Browsing) स्वचालित चलती है।  
    स्रोत: Microsoft SmartScreen / Google Safe Browsing API दस्तावेज़

23. **पासवर्ड प्रबंधक** — ब्राउज़र अंतर्निहित प्रबंधक एन्क्रिप्टेड संग्रहण (Windows DPAPI, macOS Keychain, Linux libsecret) प्रदान करते हैं; मास्टर पासवर्ड/बायोमेट्रिक अतिरिक्त सुरक्षा जोड़ते हैं।  
    स्रोत: ब्राउज़र सुरक्षा श्वेत-पत्र

24. **वेब पहुंचयोग्यता (WCAG)** — सिमेंटिक HTML (`<nav>`, `<main>`, `<button>`), ARIA लेबल, रंग विपरीत अनुपात (≥4.5:1), कीबोर्ड नेविगेशन विकलांग उपयोगकर्ताओं के लिए आवश्यक।  
    स्रोत: W3C WCAG 2.1 दिशानिर्देश

25. **ब्राउज़र अद्यतन नीति** — प्रमुख ब्राउज़र (Chrome, Edge, Firefox) 4–6 सप्ताह के चक्र में सुरक्षा पैच जारी करते हैं; स्वचालित अद्यतन डिफ़ॉल्ट सक्षम; उद्यम नीतियाँ (Group Policy, Intune) अद्यतन चैनल नियंत्रित करती हैं।  
    स्रोत: ब्राउज़र विक्रेता रिलीज़ नोट्स / Microsoft Learn / Chrome Enterprise दस्तावेज़
