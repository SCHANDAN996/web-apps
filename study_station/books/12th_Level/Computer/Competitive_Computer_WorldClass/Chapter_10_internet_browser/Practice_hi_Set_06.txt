126. HTTP का पूर्ण रूप क्या है?
(a) High Transfer Text Protocol (b) HyperText Transfer Protocol (c) Hyperlink Transfer Text Protocol (d) Home Tool Transfer Protocol
उत्तर: (b)
हल: कई उम्मीदवार समान उच्चारण वाले वाक्यांशों के साथ पूर्ण रूप को भ्रमित करते हैं; सही पूर्ण रूप HyperText Transfer Protocol है, इसलिए उत्तर HyperText Transfer Protocol है।
स्रोत: PYQ-style

127. कौन सा प्रोटोकॉल इंटरनेट पर सुरक्षित संचार प्रदान करता है?
(a) HTTP (b) FTP (c) SMTP (d) HTTPS
उत्तर: (d)
हल: एक आम जाल HTTP चुनना है क्योंकि यह अधिक परिचित है; सुरक्षित संस्करण एन्क्रिप्शन का उपयोग करता है, इसलिए उत्तर HTTPS है।
स्रोत: PYQ-style

128. HTTPS के लिए डिफ़ॉल्ट पोर्ट संख्या क्या है?
(a) 80 (b) 443 (c) 21 (d) 25
उत्तर: (b)
हल: पोर्ट 80 को अक्सर गलती से सुरक्षित ट्रैफ़िक के लिए चुना जाता है; HTTPS के लिए मानक पोर्ट 443 है, इसलिए उत्तर 443 है।
स्रोत: PYQ-style

129. कौन सा घटक डोमेन नामों को IP पतों में अनुवादित करता है?
(a) URL (b) DHCP (c) DNS (d) ISP
उत्तर: (c)
हल: DHCP गतिशील रूप से IP पते निर्दिष्ट करता है, लेकिन नाम समाधान DNS द्वारा किया जाता है, इसलिए उत्तर DNS है।
स्रोत: PYQ-style

130. URL का पूर्ण रूप क्या है?
(a) Uniform Resource Locator (b) Universal Resource Link (c) Uniform Reference Locator (d) Unique Resource Locator
उत्तर: (a)
हल: "Universal" शब्द एक आम भटकाव है; मानक परिभाषा Uniform Resource Locator है, इसलिए उत्तर Uniform Resource Locator है।
स्रोत: PYQ-style

131. URL का कौन सा भाग प्रयुक्त प्रोटोकॉल की पहचान करता है?
(a) query (b) host (c) path (d) scheme
उत्तर: (d)
हल: होस्ट सर्वर को निर्दिष्ट करता है, जबकि स्कीम http या https जैसे प्रोटोकॉल को इंगित करता है, इसलिए उत्तर scheme है।
स्रोत: PYQ-style

132. वेब ब्राउज़र के कैश का कार्य क्या है?
(a) उपयोगकर्ता पासवर्ड संग्रहीत करना (b) डेटा ट्रांसमिशन एन्क्रिप्ट करना (c) कुकीज़ प्रबंधित करना (d) तेज़ लोडिंग के लिए वेब संसाधनों की प्रतियाँ संग्रहीत करना
उत्तर: (d)
हल: कुकीज़ सत्र डेटा संभालती हैं, लेकिन कैश बाद की विज़िट को तेज़ करने के लिए संसाधन प्रतियाँ संग्रहीत करता है, इसलिए उत्तर तेज़ लोडिंग के लिए वेब संसाधनों की प्रतियाँ संग्रहीत करना है।
स्रोत: PYQ-style

133. कौन सा HTTP स्टेटस कोड सफल अनुरोध को इंगित करता है?
(a) 500 (b) 404 (c) 200 (d) 301
उत्तर: (c)
हल: 404 नहीं मिला का संकेत देता है और 500 सर्वर त्रुटि का; 200 का अर्थ OK है, इसलिए उत्तर 200 है।
स्रोत: PYQ-style

134. "IP address" शब्द किसे संदर्भित करता है?
(a) Internet Protocol address (b) Internal Process address (c) Internet Provider address (d) Interface Port address
उत्तर: (a)
हल: संक्षिप्त नाम IP का अर्थ Internet Protocol है, Internal Process नहीं, इसलिए उत्तर Internet Protocol address है।
स्रोत: PYQ-style

135. ईमेल भेजने के लिए किस प्रोटोकॉल का उपयोग किया जाता है?
(a) SMTP (b) FTP (c) HTTP (d) POP3
उत्तर: (a)
हल: POP3 मेल पुनर्प्राप्त करता है, जबकि SMTP भेजने के लिए उपयोग किया जाता है, इसलिए उत्तर SMTP है।
स्रोत: PYQ-style

136. वेब ब्राउज़िंग में कुकी का उद्देश्य क्या है?
(a) नेटवर्क ट्रैफ़िक एन्क्रिप्ट करना (b) उपयोगकर्ता प्राथमिकताएँ और सत्र डेटा संग्रहीत करना (c) छवियाँ कैश करना (d) डोमेन नाम समाधान करना
उत्तर: (b)
हल: कैशिंग और एन्क्रिप्शन अलग तंत्र हैं; कुकीज़ विशेष रूप से सत्र और प्राथमिकता डेटा रखती हैं, इसलिए उत्तर उपयोगकर्ता प्राथमिकताएँ और सत्र डेटा संग्रहीत करना है।
स्रोत: PYQ-style

137. निम्नलिखित में से कौन सा एक वैध शीर्ष-स्तरीय डोमेन है?

स्रोत: PYQ-style

141. संसाधन को संशोधित किए बिना पुनर्प्राप्त करने के लिए किस HTTP विधि का उपयोग किया जाता है?

142. प्रॉक्सी सर्वर की भूमिका क्या है?
(a) वेबसाइट होस्ट करना (b) IP पते निर्दिष्ट करना (c) ईमेल एन्क्रिप्ट करना (d) क्लाइंट अनुरोधों के लिए मध्यस्थ के रूप में कार्य करना

स्रोत: PYQ-style

143. निम्नलिखित में से कौन सा एक स्टेटलेस प्रोटोकॉल की विशेषता है?
(a) अनुरोधों के बीच कोई क्लाइंट संदर्भ संग्रहीत नहीं होता (b) सर्वर पर सत्र डेटा बनाए रखता है (c) लगातार कनेक्शन की आवश्यकता होती है (d) प्रमाणीकरण के लिए कुकीज़ का उपयोग करता है

स्रोत: PYQ-style

144. नेटवर्किंग में "बैंडविड्थ" शब्द किसे संदर्भित करता है?

स्रोत: PYQ-style

145. कौन सा प्रोटोकॉल नेटवर्क पर रिमोट टर्मिनल एक्सेस प्रदान करता है?

स्रोत: PYQ-style

146. एक URL में, कौन सा घटक डोमेन नाम के बाद और क्वेरी स्ट्रिंग से पहले आता है?
(a) scheme (b) fragment (c) path (d) port
उत्तर: (c)
हल: पथ संसाधन स्थान की पहचान करता है; फ्रैगमेंट क्वेरी के बाद आता है, स्कीम डोमेन से पहले, पोर्ट प्राधिकरण का हिस्सा है, इसलिए उत्तर path है।
स्रोत: PYQ-style

147. TLS हैंडशेक का प्राथमिक उद्देश्य क्या है?
(a) डोमेन नाम समाधान करना (b) ट्रांसमिशन से पहले डेटा संपीड़ित करना (c) सर्वर को प्रमाणित करना और एन्क्रिप्शन कुंजियों पर बातचीत करना (d) स्थिर संपत्तियों को कैश करना

स्रोत: PYQ-style

148. निम्नलिखित में से कौन सा वैध HTTP अनुरोध हेडर नहीं है?

स्रोत: PYQ-style

149. "फ़िशिंग" शब्द किसका वर्णन करता है?
(a) विश्वसनीय इकाई के रूप में प्रस्तुत करके संवेदनशील जानकारी प्राप्त करने का कपटपूर्ण प्रयास (b) नेटवर्क हमला जो सर्वर को ट्रैफ़िक से भर देता है (c) सॉफ़्टवेयर भेद्यता का शोषण करना (d) अनएन्क्रिप्टेड ट्रैफ़िक को इंटरसेप्ट करना
उत्तर: (a)
हल: फ्लडिंग DoS है, भेद्यता शोषण एक एक्सप्लॉइट है, इंटरसेप्शन स्निफिंग है; फ़िशिंग विशेष रूप से धोखे का उपयोग करता है, इसलिए उत्तर विश्वसनीय इकाई के रूप में प्रस्तुत करके संवेदनशील जानकारी प्राप्त करने का कपटपूर्ण प्रयास है।
स्रोत: PYQ-style
