126. Which tab in the PowerPoint ribbon contains the New Slide button?
(a) View (b) Insert (c) Design (d) Home
Answer: (d)
Solution: The New Slide button is located in the Slides group on the Home tab; Insert tab has options for adding objects like tables and pictures, Design tab handles themes, and View tab controls presentation views, so the answer is Home.

127. What is the default file extension for a PowerPoint presentation saved in the modern XML-based format?
(a) .ppt (b) .pptx (c) .pps (d) .potx
Answer: (b)
Solution: Since PowerPoint 2007, the default format uses Office Open XML with extension .pptx; .ppt is the legacy binary format, .pps is a show file, and .potx is a template, so the answer is .pptx.

Answer: (a)
Solution: Slide Sorter view displays thumbnail images of all slides for drag-and-drop reordering; Normal view shows one slide with notes, Reading view is for full-screen review, and Outline view shows text hierarchy, so the answer is Slide Sorter view.

129. What keyboard shortcut starts a slide show from the current slide in PowerPoint for Windows?
(a) F5 (b) Ctrl+F5 (c) Shift+F5 (d) Alt+F5

131. In PowerPoint, what does the term "placeholder" refer to?
