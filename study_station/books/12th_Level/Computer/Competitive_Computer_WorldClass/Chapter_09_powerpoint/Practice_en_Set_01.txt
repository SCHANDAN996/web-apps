1. Which file extension is used for a PowerPoint presentation in the modern XML-based format?
(a) .ppt (b) .pptx (c) .pps (d) .potx
Answer: (b)
Solution: The .ppt extension belongs to the legacy binary format (PowerPoint 97-2003), while .pptx is the default XML-based format introduced in PowerPoint 2007; .pps is a show file and .potx is a template, so the answer is .pptx.
Source: Microsoft Support – File formats in PowerPoint

2. In which view can you see thumbnail images of all slides on the left and edit the selected slide in the main pane?
(a) Normal (b) Notes Page (c) Slide Sorter (d) Reading View
Answer: (a)
Solution: Slide Sorter shows only thumbnails; Notes Page displays speaker notes; Reading View is for full-screen preview without editing. Normal view combines the thumbnail pane and the slide editing pane, so the answer is Normal.
Source: Microsoft Learn – PowerPoint views

3. What is the keyboard shortcut to start a slide show from the current slide in PowerPoint for Windows?
(a) Shift+F5 (b) Alt+F5 (c) Ctrl+F5 (d) F5
Answer: (a)
Solution: F5 starts the show from the first slide; Shift+F5 begins from the currently selected slide. Ctrl+F5 and Alt+F5 are not standard PowerPoint shortcuts for this action, so the answer is Shift+F5.
Source: Microsoft Support – Keyboard shortcuts in PowerPoint

4. Which tab on the Ribbon contains the "New Slide" button?
(a) Insert (b) Home (c) Design (d) Transitions
Answer: (b)
Solution: The Home tab holds the New Slide button along with layout and reset commands; Insert tab adds objects, Design changes themes, Transitions handles slide change effects, so the answer is Home.
Source: Microsoft Learn – PowerPoint Ribbon overview

5. A placeholder that holds text, pictures, charts, or other content on a slide layout is called a:
(a) Text box (b) Shape (c) SmartArt (d) Content placeholder
Answer: (d)
Solution: A text box is a free-floating object; a content placeholder is the predefined area on a layout that accepts multiple content types. Shapes and SmartArt are specific objects, not the generic placeholder, so the answer is Content placeholder.
Source: Microsoft Support – Add placeholders to a slide layout

6. Which view is best suited for rearranging the order of slides by dragging thumbnails?
(a) Slide Sorter (b) Outline (c) Normal (d) Notes Page
Answer: (a)
Solution: Normal view allows editing one slide at a time; Outline shows text hierarchy; Notes Page is for speaker notes. Slide Sorter displays all thumbnails in a grid for easy drag-and-drop reordering, so the answer is Slide Sorter.
Source: Microsoft Learn – Work with slides in Slide Sorter view

7. The "Transition" effects control:
(a) Animation of objects within a slide (b) Theme colors applied to slides (c) How one slide replaces another during a show (d) Timing of automatic slide advance
Answer: (c)
Solution: Animations apply to objects on a slide; transitions govern the visual effect when moving from one slide to the next. Timing and theme colors are separate settings, so the answer is How one slide replaces another during a show.
Source: Microsoft Support – Add transitions between slides

8. Which keyboard shortcut inserts a new slide with the same layout as the current slide in PowerPoint for Windows?
(a) Ctrl+Alt+M (b) Ctrl+N (c) Ctrl+M (d) Ctrl+Shift+M
Answer: (c)
Solution: Ctrl+N creates a new presentation; Ctrl+M adds a new slide using the current layout. The other combinations are not standard for this function, so the answer is Ctrl+M.
Source: Microsoft Support – Keyboard shortcuts in PowerPoint

9. What does the "Slide Master" control?
(a) Individual slide content (b) Animation order on a single slide (c) Global layout, fonts, colors, and placeholders for all slides (d) Transition speed between slides
Answer: (c)
Solution: Slide Master defines the master layout, theme fonts, colors, and placeholder positions inherited by all slides. Individual content, animation order, and transition speed are set per slide or in other panes, so the answer is Global layout, fonts, colors, and placeholders for all slides.
Source: Microsoft Learn – Use slide masters to customize a presentation

10. Which file format should you choose to save a presentation as a video?
(a) .ppsx (b) .pptx (c) .pdf (d) .mp4
Answer: (d)
Solution: .pptx is the editable presentation; .pdf is for print/portable documents; .ppsx opens directly in show mode. Exporting to video creates an .mp4 (or .wmv) file, so the answer is .mp4.
Source: Microsoft Support – Turn your presentation into a video

11. The "Animation Pane" is used to:
(a) Reorder slides (b) Set slide transition timing (c) Edit speaker notes (d) Manage entrance, emphasis, exit, and motion path effects on objects
Answer: (d)
Solution: Slide order is managed in Slide Sorter; transition timing is in the Transitions tab; speaker notes are in Notes Page or Normal view. The Animation Pane lists and sequences object-level animations, so the answer is Manage entrance, emphasis, exit, and motion path effects on objects.
Source: Microsoft Learn – Animate text or objects

12. Which shortcut starts the presentation from the first slide in PowerPoint for Windows?
(a) F5 (b) Shift+F5 (c) Ctrl+F5 (d) Alt+F5
Answer: (a)
Solution: Shift+F5 starts from the current slide; F5 always begins from slide 1. The other combinations are not standard for starting a show, so the answer is F5.
Source: Microsoft Support – Keyboard shortcuts in PowerPoint

13. A "handout" in PowerPoint typically prints:
(a) One slide per page with notes (b) Multiple slides per page for audience distribution (c) Only the outline text (d) Full-screen slide images
Answer: (b)
Solution: Handouts are designed to print 1, 2, 3, 4, 6, or 9 slides per page for audience handouts. Notes pages print one slide with notes; outline prints text only; full-screen images are not a print layout, so the answer is Multiple slides per page for audience distribution.
Source: Microsoft Support – Print handouts

14. Which tab contains the "Slide Size" option to switch between Standard (4:3) and Widescreen (16:9)?
(a) Home (b) View (c) Insert (d) Design
Answer: (d)
Solution: The Design tab holds Slide Size, Themes, Variants, and Background settings. Home, Insert, and View tabs do not contain slide dimension controls, so the answer is Design.
Source: Microsoft Learn – Change the size of your slides

15. What is the purpose of "Presenter View"?
(a) Record narration automatically (b) Show the same slide on two monitors (c) Display speaker notes, next slide preview, and timer on the presenter's screen while audience sees only the slide (d) Broadcast the show over the internet
Answer: (c)
Solution: Presenter View uses dual monitors: the projector shows the current slide, while the presenter sees notes, upcoming slide, and elapsed time. It does not duplicate the slide, record narration, or broadcast, so the answer is Display speaker notes, next slide preview, and timer on the presenter's screen while audience sees only the slide.
Source: Microsoft Support – Use Presenter View

16. Which of the following is NOT a valid PowerPoint view?
(a) Normal (b) Print Layout (c) Outline (d) Slide Sorter
Answer: (b)
Solution: Normal, Slide Sorter, and Outline (accessible in Normal's left pane) are standard PowerPoint views. Print Layout is a Word view, not a PowerPoint view, so the answer is Print Layout.
Source: Microsoft Learn – PowerPoint views

17. The "Reuse Slides" feature allows you to:
(a) Import slides from another presentation while keeping source formatting (b) Merge two presentations into one file automatically (c) Delete unused layouts (d) Duplicate the current slide
Answer: (a)
Solution: Duplicate Slide copies within the same file; Reuse Slides opens a pane to browse and insert slides from another .pptx, optionally preserving original formatting. It does not delete layouts or auto-merge files, so the answer is Import slides from another presentation while keeping source formatting.
Source: Microsoft Support – Reuse slides from another presentation

18. Which shortcut opens the "Find" dialog in PowerPoint for Windows?
(a) Ctrl+F (b) Ctrl+H (c) Ctrl+G (d) Ctrl+Shift+F
Answer: (a)
Solution: Ctrl+H opens Replace; Ctrl+G is not standard; Ctrl+Shift+F is not the default Find shortcut. Ctrl+F is the universal Find shortcut across Office apps, so the answer is Ctrl+F.
Source: Microsoft Support – Keyboard shortcuts in PowerPoint

19. A "theme" in PowerPoint consists of:
(a) Only a color scheme (b) Only background images (c) Only transition styles (d) A coordinated set of colors, fonts, effects, and slide layouts
Answer: (d)
Solution: A theme bundles a color palette, font pair, effect style (shadows, lines), and slide master layouts. It is more than just colors, backgrounds, or transitions, so the answer is A coordinated set of colors, fonts, effects, and slide layouts.
Source: Microsoft Learn – Apply a theme to your presentation

20. Which command removes all animations from a selected object in PowerPoint?
(a) Animation Painter (b) "None" in the Animation gallery (c) Clear All Animations button (d) Delete key
Answer: (b)
Solution: Animation Painter copies animations to another object; the Delete key removes the object itself; there is no single "Clear All Animations" button for a single object. Selecting "None" from the Animation gallery clears all animations from the selected object while keeping the object, so the answer is "None" in the Animation gallery.
Source: Microsoft Support – Remove an animation effect

21. In a motion path animation, the "Edit Points" option allows you to:
(a) Lock the object to the path (b) Change the speed of the animation (c) Reverse the direction of the path (d) Modify the shape of the path by adding, deleting, or moving anchor points
Answer: (d)
Solution: Speed is set in Timing; Reverse Path Direction is a separate command; locking is not a standard option. Edit Points lets you reshape the custom path by manipulating its vertices, so the answer is Modify the shape of the path by adding, deleting, or moving anchor points.
Source: Microsoft Learn – Edit a motion path

22. The "Morph" transition requires which condition to work smoothly between two slides?
(a) Objects on both slides must have matching names or be recognized as the same object (b) The transition duration must be set to 0 seconds (c) Both slides must use the same layout (d) Both slides must have the same theme
Answer: (a)
Solution: Morph matches objects by name or visual similarity to animate changes in position, size, color, etc. Same theme, layout, or zero duration are not requirements, so the answer is Objects on both slides must have matching names or be recognized as the same object.
Source: Microsoft Support – Use the Morph transition

23. Which feature lets you record slide timings, narration, and laser pointer gestures in one pass?
(a) Screen Recording (b) Rehearse Timings (c) Record Slide Show (d) Audio Recording
Answer: (c)
Solution: Rehearse Timings only records slide advance times; Screen Recording captures screen activity; Audio Recording inserts audio clips. Record Slide Show captures timings, narration, ink, and laser pointer together, so the answer is Record Slide Show.
Source: Microsoft Support – Record a slide show with narration and slide timings

24. When you save a presentation as a "PowerPoint Show (.ppsx)", what happens when the file is double-clicked?
(a) Opens in Slide Sorter view (b) Opens in edit mode (c) Opens directly in Slide Show mode (d) Prompts for a password
Answer: (c)
Solution: .pptx opens in edit mode; .ppsx launches immediately into full-screen Slide Show. It does not open in Slide Sorter or ask for a password unless separately protected, so the answer is Opens directly in Slide Show mode.
Source: Microsoft Support – Save a presentation as a show

25. The "Selection Pane" is most useful for:
(a) Changing the slide background (b) Selecting, hiding, renaming, and reordering overlapping objects on a slide (c) Managing slide transitions (d) Editing the slide master
Answer: (b)
Solution: Background is changed via Design tab; transitions via Transitions tab; slide master via View tab. The Selection Pane lists every object on the current slide, allowing selection, visibility toggle, renaming, and z-order changes, so the answer is Selecting, hiding, renaming, and reordering overlapping objects on a slide.
Source: Microsoft Support – Use the Selection Pane
