101. Which view in PowerPoint displays thumbnail versions of all slides in a vertical pane on the left side of the window?
(a) Slide Sorter view (b) Reading view (c) Normal view (d) Outline view
Answer: (c)
Solution: Normal view is the default editing view that shows the slide pane, the thumbnails pane on the left, and the notes pane at the bottom; Slide Sorter view shows only thumbnails in a grid, Outline view shows text outline, and Reading view is for full-screen preview without editing, so the answer is Normal view.
Source: Microsoft Support – PowerPoint views

102. What is the keyboard shortcut to start a slide show from the current slide in PowerPoint for Windows?
(a) Shift+F5 (b) F5 (c) Ctrl+F5 (d) Alt+F5
Answer: (a)
Solution: F5 starts the show from the first slide; Shift+F5 starts from the currently selected slide, which is a common trap because many users memorize only F5, so the answer is Shift+F5.
Source: Microsoft Support – Keyboard shortcuts for PowerPoint

103. Which file format saves a presentation as a sequence of images, one per slide, suitable for viewing without PowerPoint?
(a) .pptx (b) .pdf (c) .png (d) .ppsx
Answer: (c)
Solution: .pptx is the editable format, .pdf creates a multi-page document, .ppsx opens directly in show mode but still requires PowerPoint; exporting to .png (or .jpg) produces separate image files for each slide, so the answer is .png.
Source: Microsoft Support – Save a presentation as images

104. In Slide Master view, changes made to the top-most slide thumbnail affect which slides?
(a) All slides using that master layout (b) Only the first slide (c) Only slides with the Title layout (d) Only the current slide
Answer: (a)
Solution: The top thumbnail in Slide Master is the master slide; edits there propagate to every layout beneath it and therefore to all slides based on those layouts, while layout thumbnails control only their specific layout, so the answer is all slides using that master layout.
Source: Microsoft Support – Use slide masters

105. What does the Morph transition do in PowerPoint?
(a) Fades between slides (b) Zooms into a specific part of the slide (c) Flips the slide like a page (d) Animates the movement and transformation of objects between slides
Answer: (d)
Solution: The Morph transition automatically animates the movement, size, rotation, and color changes of objects between two slides, creating a smooth transformation; it is not a simple fade, zoom, or flip, so the answer is animates the movement and transformation of objects between slides.
Source: Microsoft Support – Morph transition

106. What does the "Reuse Slides" feature do?
(a) Deletes duplicate slides (b) Imports slides from another presentation file (c) Recycles deleted slides from the Recycle Bin (d) Creates a copy of the current slide
Answer: (b)
Solution: Reuse Slides opens a pane to browse and insert slides from another .pptx file while keeping formatting options; it does not delete duplicates, access the Recycle Bin, or simply duplicate the current slide, so the answer is imports slides from another presentation file.
Source: Microsoft Support – Reuse slides

107. Which keyboard shortcut duplicates the selected object in PowerPoint for Windows?
(a) Ctrl+X (b) Ctrl+C (c) Ctrl+V (d) Ctrl+D
Answer: (d)
Solution: Ctrl+D creates a duplicate of the selected object in place; Ctrl+C copies, Ctrl+V pastes, and Ctrl+X cuts, so the answer is Ctrl+D.
Source: Microsoft Support – Keyboard shortcuts for PowerPoint

108. What is the purpose of the "Selection Pane" in PowerPoint?
(a) To select multiple slides at once (b) To manage visibility and stacking order of objects on a slide (c) To choose color themes (d) To select animation triggers
Answer: (b)
Solution: The Selection Pane lists every object on the current slide, allowing you to hide/show, reorder, and rename them; it does not select slides, choose themes, or handle animation triggers directly, so the answer is manage visibility and stacking order of objects on a slide.
Source: Microsoft Support – Selection Pane

109. Which chart type is most appropriate for showing parts of a whole across a single data series?
(a) Scatter (b) Line (c) Clustered Column (d) Pie
Answer: (d)
Solution: Clustered Column compares values across categories, Line shows trends over time, Scatter shows correlation; a Pie chart represents proportional parts of a single series total, so the answer is Pie.
Source: Microsoft Support – Available chart types

110. What happens when you press the "B" key during a running slide show?
(a) Goes to the previous slide (b) Toggles a black screen (c) Opens the pointer options (d) Ends the show
Answer: (b)
Solution: "B" or "." blanks the screen to black (press again to resume); "P" or Backspace goes previous, Ctrl+P changes pointer, Esc ends the show, so the answer is toggles a black screen.
Source: Microsoft Support – Slide show shortcuts

111. Which SmartArt category is best for showing a process with sequential steps?
(a) List (b) Hierarchy (c) Process (d) Cycle
Answer: (c)
Solution: List shows non-sequential items, Cycle shows a repeating loop, Hierarchy shows reporting structure; Process layouts are designed for step-by-step sequences with directional arrows, so the answer is Process.
Source: Microsoft Support – Choose a SmartArt graphic

112. In PowerPoint, what does "Compress Pictures" do?
(a) Reduces the file size by lowering image resolution and removing cropped areas (b) Converts images to vector format (c) Applies lossless ZIP compression to the entire file (d) Merges overlapping images into one
Answer: (a)
Solution: Compress Pictures reduces resolution to a chosen PPI, deletes cropped-out areas, and can discard editing data; it does not vectorize, ZIP the whole file, or merge images, so the answer is reduces the file size by lowering image resolution and removing cropped areas.
Source: Microsoft Support – Reduce file size by compressing pictures

113. Which view allows you to rearrange slides by dragging thumbnails in a grid layout?
(a) Normal view (b) Outline view (c) Slide Sorter view (d) Notes Page view
Answer: (c)
Solution: Slide Sorter displays all slides as equal-sized thumbnails in a grid, ideal for reordering; Normal view has a vertical thumbnail pane, Notes Page shows speaker notes, Outline view shows text hierarchy, so the answer is Slide Sorter view.
Source: Microsoft Support – PowerPoint views

114. What is the function of the "Eyedropper" tool in PowerPoint?
(a) Copies animation effects between objects (b) Selects text with similar formatting (c) Measures distance between objects (d) Picks a color from anywhere on screen to apply to an object
Answer: (d)
Solution: The Eyedropper samples any visible color on the screen (even outside PowerPoint) and applies it as fill, outline, or font color; it does not select text, copy animations, or measure distances, so the answer is picks a color from anywhere on screen to apply to an object.
Source: Microsoft Support – Eyedropper tool

115. Which option in "Save As" creates a file that opens directly in slide show mode?
(a) PowerPoint Presentation (.pptx) (b) PowerPoint Show (.ppsx) (c) PDF (.pdf) (d) PowerPoint Template (.potx)
Answer: (b)
Solution: .ppsx (PowerPoint Show) launches immediately in full-screen show mode; .pptx opens in edit mode, .pdf opens in a PDF reader, .potx creates a new presentation from the template, so the answer is PowerPoint Show (.ppsx).
Source: Microsoft Support – File formats

116. What does the "Align" command under the Arrange group do?
(a) Distributes slides evenly in the thumbnail pane (b) Justifies text in all text boxes (c) Centers the slide title automatically (d) Aligns selected objects relative to each other or the slide
Answer: (d)
Solution: Align works on selected shapes, pictures, or text boxes — aligning left/center/right/top/middle/bottom or distributing horizontally/vertically; it does not affect slide order, text justification globally, or titles alone, so the answer is aligns selected objects relative to each other or the slide.
Source: Microsoft Support – Align objects

117. Which keyboard shortcut inserts a new slide in Normal view (Windows)?
(a) Ctrl+N (b) Ctrl+Shift+N (c) Ctrl+M (d) Enter
Answer: (c)
Solution: Ctrl+N creates a new presentation file, Ctrl+Shift+N is not standard, Enter in the thumbnail pane may add a slide but the dedicated shortcut is Ctrl+M, so the answer is Ctrl+M.
Source: Microsoft Support – Keyboard shortcuts for PowerPoint

118. What is the purpose of "Action Settings" on an object?
(a) Defines what happens when the object is clicked or hovered during a show (b) Sets the animation entrance effect (c) Assigns a macro to run on slide load (d) Changes the object's fill color on click
Answer: (a)
Solution: Action Settings (Insert → Action) lets you assign hyperlink, run program, play sound, or run macro on mouse click or mouse over; it is separate from animation effects, slide-load macros, or fill changes, so the answer is defines what happens when the object is clicked or hovered during a show.
Source: Microsoft Support – Add an action

119. Which feature allows you to record narration and slide timings for a self-running presentation?
(a) Record Slide Show (b) Rehearse Timings (c) Screen Recording (d) Audio Browser
Answer: (a)
Solution: Record Slide Show (Slide Show tab) captures narration, ink gestures, and per-slide timings in one workflow; Rehearse Timings only records timings without audio, Screen Recording captures screen video, Audio Browser inserts existing audio files, so the answer is Record Slide Show.
Source: Microsoft Support – Record a slide show

120. What does "Match Case" do in the Find/Replace dialog?
(a) Finds only whole words (b) Distinguishes uppercase and lowercase letters (c) Searches only in slide titles (d) Replaces formatting only
Answer: (b)
Solution: Match Case makes the search case-sensitive (e.g., "PowerPoint" ≠ "powerpoint"); "Find whole words only" is a separate checkbox, it does not limit to titles or formatting, so the answer is distinguishes uppercase and lowercase letters.
Source: Microsoft Support – Find and replace text

121. In a chart, which element displays the values of data points directly on the chart?
(a) Legend (b) Data Labels (c) Axis Titles (d) Gridlines
Answer: (b)
Solution: Legend identifies series colors, Axis Titles label axes, Gridlines aid reading values; Data Labels show the actual numeric or percentage value on each column, bar, pie slice, or point, so the answer is Data Labels.
Source: Microsoft Support – Add data labels

122. Which option in the Animation Pane lets you start an animation automatically after the previous one finishes?
(a) After Previous (b) With Previous (c) On Click (d) Trigger
Answer: (a)
Solution: On Click waits for user input, With Previous starts simultaneously with the previous animation, Trigger waits for a specific object click; After Previous starts when the preceding animation ends, so the answer is After Previous.
Source: Microsoft Support – Set animation timing

123. What is the effect of checking "Lock Aspect Ratio" in the Size pane for a picture?
(a) Disables compression for that picture (b) Prevents the picture from being moved (c) Locks the picture to the slide background (d) Keeps width-to-height proportion constant when resizing
Answer: (d)
Solution: Lock Aspect Ratio ensures that changing width automatically adjusts height proportionally (and vice versa) so the image does not distort; it does not restrict movement, lock to background, or affect compression, so the answer is keeps width-to-height proportion constant when resizing.
Source: Microsoft Support – Crop and resize pictures

124. In PowerPoint's Print dialog, which option prints one slide per page with the speaker notes below?
(a) Handouts (b) Full Page Slides (c) Notes Pages (d) Outline
Answer: (c)
Solution: Notes Pages prints each slide on a separate page with the associated speaker notes beneath; Handouts prints multiple slides per page with lines for audience notes, Full Page Slides prints only the slide, and Outline prints the text outline, so the answer is Notes Pages.
Source: Microsoft Support – Print handouts and notes

125. In PowerPoint's Accessibility Checker, what does the "Missing Alt Text" warning indicate?
(a) An image, chart, or shape lacks alternative text for screen readers (b) A slide has no title (c) The presentation has no theme applied (d) A hyperlink has no ScreenTip
Answer: (a)
Solution: Missing Alt Text flags non-text objects (pictures, charts, SmartArt, shapes) without descriptive alternative text, which screen readers need; missing slide title is a separate warning, theme and ScreenTip are unrelated, so the answer is an image, chart, or shape lacks alternative text for screen readers.
Source: Microsoft Support – Accessibility Checker
