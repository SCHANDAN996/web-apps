Card 1
Front: What is the default file extension for a PowerPoint presentation (since PowerPoint 2007)?
Back: .pptx (Office Open XML format). The legacy binary format uses .ppt.

Card 2
Front: Which view shows all slides as thumbnails and allows easy reordering?
Back: Slide Sorter view (View tab → Slide Sorter or status bar icon).

Card 3
Front: Keyboard shortcut (Windows) to start a slide show from the current slide.
Back: Shift + F5. (F5 starts from the first slide.)

Card 4
Front: Keyboard shortcut (Windows) to insert a new slide in the current presentation.
Back: Ctrl + M. (Ctrl + N creates a new presentation file.)

Card 5
Front: What is the purpose of the Slide Master?
Back: It controls the default layout, fonts, colours, placeholders, and background for all slides that use that master. Changes to the Slide Master propagate to dependent layouts.

Card 6
Front: Which tab contains the "Rehearse Timings" feature?
Back: Slide Show tab → Rehearse Timings. It records the time spent on each slide for automatic advance.

Card 7
Front: Difference between "Transition" and "Animation" in PowerPoint.
Back: Transition: effect when moving from one slide to the next (Slide Transitions tab). Animation: effect applied to individual objects (text, images, shapes) within a slide (Animations tab).

Card 8
Front: What does "Trigger" mean in the Animation pane?
Back: A trigger starts an animation when a specific object is clicked (or on bookmark), instead of automatically or with previous/after previous.

Card 9
Front: How do you make a picture transparent in modern PowerPoint (Office 365 / 2019+)?
Back: Select picture → Picture Format tab → Transparency dropdown → choose a preset or "Picture Transparency Options" for fine control. (Older versions require filling a shape with the picture.)

Card 10
Front: Shortcut to open the "Find" dialog in PowerPoint (Windows).
Back: Ctrl + F. (Ctrl + H opens Find & Replace.)

Card 11
Front: What is "Presenter View" and which hardware setup is required?
Back: Presenter View shows current slide, next slide, notes, and timer on the presenter's screen while the audience sees only the slide show. Requires a second monitor or projector (extended display mode).

Card 12
Front: Which feature combines multiple presentations into one while keeping formatting?
Back: "Reuse Slides" (Home tab → New Slide dropdown → Reuse Slides) or "Compare" (Review tab → Compare) to merge changes from another file.

Card 13
Front: What is the maximum number of slides in a .pptx file?
Back: No hard limit imposed by the format; practical limits depend on available memory and file size (typically hundreds of thousands of slides).

Card 14
Front: Shortcut to duplicate a selected object (shape, text box, image) in PowerPoint (Windows).
Back: Ctrl + D. (Ctrl + C then Ctrl + V also works but Ctrl + D is faster and keeps alignment.)

Card 15
Front: What does "Embed Fonts in the File" do (File → Options → Save)?
Back: Includes the font files inside the .pptx so the presentation looks identical on computers that lack those fonts. Increases file size.

Card 16
Front: How to convert a PowerPoint presentation to a video (MP4)?
Back: File → Export → Create a Video → choose quality, timings/narrations → Create Video. Requires PowerPoint 2010 or later.

Card 17
Front: What is "Action Settings" used for?
Back: Assigns an action (hyperlink, run program, run macro, play sound, etc.) to an object when clicked or hovered (Insert → Action).

Card 18
Front: Shortcut to align selected objects to the centre of the slide (Windows).
Back: Select objects → Home → Arrange → Align → Align Center (horizontal) and Align Middle (vertical). No single default shortcut; add to Quick Access Toolbar for one-click access.
