76. What is the default file extension for a PowerPoint presentation saved in the modern XML-based format?
(a) .pptx (b) .ppt (c) .pps (d) .potx
Answer: (a)
Solution: The .ppt extension belongs to the legacy binary format used up to PowerPoint 2003, while .pptx has been the default since PowerPoint 2007; .pps is a show file and .potx is a template, so the answer is .pptx.
Source: Microsoft Support – File formats in PowerPoint

77. Which view appears by default when you launch PowerPoint and create a new blank presentation?
(a) Slide Sorter (b) Normal (c) Notes Page (d) Reading View
Answer: (b)
Solution: Normal view shows the slide, thumbnails, and notes pane together and is the default editing view; Slide Sorter and Notes Page are specialized views, and Reading View is for previewing, so the answer is Normal.
