26. Which tab in the PowerPoint Ribbon contains the New Slide, Layout, and Reset commands?
(a) View (b) Insert (c) Design (d) Home
Answer: (d)
Solution: The Insert tab is for adding objects like tables and pictures, while Design handles themes and variants; the Home tab holds the core slide-management commands New Slide, Layout, and Reset, so the answer is Home.

27. What is the default keyboard shortcut in PowerPoint for Windows to insert a new slide?
(a) Ctrl+M (b) Ctrl+N (c) Ctrl+Shift+N (d) Alt+N
Answer: (a)
Solution: Ctrl+N creates a new presentation file, not a slide within the current file; Ctrl+M is the dedicated shortcut to add a new slide using the current layout, so the answer is Ctrl+M.

28. Which view shows thumbnail versions of all slides and allows easy reordering by drag-and-drop?

Answer: (a)

30. Which command removes all manual formatting from selected text and returns it to the default style of the current theme?
(a) Format Painter (b) Reset (c) Clear All Formatting (d) Replace Fonts

31. When inserting a picture from a file, which tab and group contain the Pictures command?

32. What is the key difference between a transition and an animation in PowerPoint?
(a) Transitions control how slides change; animations control object movement on a slide (b) Transitions apply to objects; animations apply to slides (c) Transitions are only available in Slide Show view; animations work in all views (d) Animations can have sound; transitions cannot
Answer: (a)
Solution: The trap is reversing the scope — transitions govern the visual effect when moving from one slide to the next, while animations govern the entrance, emphasis, exit, or motion paths of individual objects on a single slide, so the answer is transitions control how slides change; animations control object movement on a slide.

33. What is the primary purpose of the Slide Master?
(a) To create a custom slide show for different audiences (b) To define the default layout, theme, and placeholder positions for all slides (c) To rehearse and record slide timings (d) To compress media files in the presentation
Answer: (b)
Solution: Custom slide shows are created in the Slide Show tab, rehearsal timings use Rehearse Timings, and media compression is in File ▸ Info; the Slide Master stores the master layout, theme fonts, colors, and placeholder positions that propagate to all slides, so the answer is to define the default layout, theme, and placeholder positions for all slides.
