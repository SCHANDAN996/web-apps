126. Which protocol is used for sending outgoing email messages from a client to a mail server?
(a) SMTP (b) IMAP (c) POP3 (d) HTTP
Answer: (a)
Solution: IMAP and POP3 are used for retrieving incoming mail, while HTTP is for web traffic; SMTP (Simple Mail Transfer Protocol) is the standard for sending mail, so the answer is SMTP.
Source: PYQ-style

127. What does the "CC" field in an email stand for?
(a) Confidential Copy (b) Carbon Copy (c) Certified Copy (d) Computer Copy
Answer: (b)
Solution: "Confidential Copy" and "Certified Copy" are plausible-sounding distractors, but CC originates from carbon paper duplication and means Carbon Copy, so the answer is Carbon Copy.
Source: PYQ-style

128. Which protocol allows an email client to synchronize messages across multiple devices by keeping mail on the server?
(a) FTP (b) POP3 (c) SMTP (d) IMAP
Answer: (d)
Solution: POP3 typically downloads and deletes from the server, while FTP is for file transfer; IMAP (Internet Message Access Protocol) leaves messages on the server for multi-device sync, so the answer is IMAP.

129. What is the default port number for SMTP with STARTTLS encryption?
(a) 993 (b) 465 (c) 587 (d) 25
Answer: (c)
Solution: Port 25 is plain SMTP, 465 is legacy SMTPS, and 993 is IMAPS; the modern submission port with STARTTLS is 587, so the answer is 587.

130. In an email header, which field indicates the actual sender's email address?
(a) From (b) Return-Path (c) Sender (d) Reply-To
Answer: (b)
Solution: "From" can be spoofed and "Reply-To" directs replies; Return-Path (also called envelope sender) records the actual SMTP MAIL FROM address used for bounce handling, so the answer is Return-Path.

132. Which email folder typically stores messages that have been sent successfully?
(a) Drafts (b) Outbox (c) Archive (d) Sent
Answer: (d)

133. What is the primary purpose of the BCC field?
(a) To hide recipient addresses from each other (b) To send a copy to the server administrator (c) To mark the message as high priority (d) To request a read receipt
Answer: (a)
Solution: BCC (Blind Carbon Copy) conceals the listed addresses from all other recipients, unlike CC; it does not notify administrators or request receipts, so the answer is To hide recipient addresses from each other.

(a) Personalized greeting with your full name (b) Digital signature from a known contact (c) Urgent threat of account closure (d) Attachment in PDF format
Answer: (c)
Solution: Legitimate organizations rarely threaten immediate closure; urgency and fear are classic social-engineering tactics, while personalized greetings and digital signatures suggest authenticity, so the answer is Urgent threat of account closure.

136. Which protocol uses port 993 by default?
(a) POP3S (b) HTTPS (c) IMAPS (d) SMTPS
Answer: (c)
Solution: POP3S uses 995, SMTPS uses 465, and HTTPS uses 443; IMAP over SSL/TLS (IMAPS) defaults to port 993, so the answer is IMAPS.

137. In Gmail, which keyboard shortcut composes a new message?

Answer: (b)
Solution: Ctrl+N is a browser/OS shortcut, M mutes a thread, and N moves to next message; pressing C (with keyboard shortcuts enabled) opens a new compose window, so the answer is C.

138. What is the function of an email "signature" block?
(a) To encrypt the message (b) To automatically append contact details (c) To verify the sender's identity cryptographically (d) To schedule delayed delivery
Answer: (b)
Solution: Encryption and cryptographic verification use S/MIME or PGP, not a signature block; scheduling is a separate feature; a signature block simply appends predefined text like name and phone, so the answer is To automatically append contact details.

140. What does "Reply All" do?
(a) Replies only to the sender (b) Sends a read receipt (c) Forwards the message to a new address (d) Replies to the sender and all CC recipients
Answer: (d)
Solution: Reply goes to sender only, Forward creates a new message, and read receipts are requested separately; Reply All includes everyone in To and CC (but not BCC), so the answer is Replies to the sender and all CC recipients.

145. What does "whitelisting" an email address do?
(a) Blocks all mail from that address (b) Marks mail from that address as spam (c) Ensures mail from that address bypasses spam filters (d) Deletes mail from that address after 30 days
Answer: (c)

146. What does DKIM (DomainKeys Identified Mail) primarily verify?
(a) The sender's IP address (b) The recipient's email address (c) The integrity of the message content and headers (d) The email's spam score
Answer: (c)
Solution: SPF checks the sender's IP address, while DKIM uses a cryptographic signature to ensure the message content and headers have not been altered in transit; it does not verify the recipient or assign a spam score, so the answer is The integrity of the message content and headers.
Source: PYQ-style

147. Which email authentication method allows the receiving server to check if an IP is authorized to send for a domain?
(a) DMARC (b) DKIM (c) SPF (d) S/MIME
Answer: (c)
Solution: DKIM verifies message integrity via cryptographic signature, DMARC sets policy for SPF/DKIM failures, and S/MIME encrypts content; SPF (Sender Policy Framework) publishes authorized sending IPs in DNS, so the answer is SPF.
Source: PYQ-style

148. In a corporate Exchange environment, what is the purpose of a "Distribution Group"?

Answer: (b)
Solution: Archiving uses retention policies, folder permissions use ACLs, and meeting scheduling uses calendaring; a distribution group expands to member addresses for one-to-many mail, so the answer is To send email to multiple recipients via a single address.

150. An email header shows "DKIM=pass" and "SPF=pass" but "DMARC=fail". What is the most likely cause?
(a) The From domain does not align with SPF or DKIM domains (b) The sending IP is not in the SPF record (c) The DKIM signature failed verification (d) The message was modified in transit
Answer: (a)
Solution: SPF and DKIM both passed, so (b) and (c) are contradicted; modification would break DKIM; DMARC requires identifier alignment (From domain matches SPF mail-from or DKIM d= domain), so misalignment causes failure despite individual passes, so the answer is The From domain does not align with SPF or DKIM domains.
Source: PYQ-style
