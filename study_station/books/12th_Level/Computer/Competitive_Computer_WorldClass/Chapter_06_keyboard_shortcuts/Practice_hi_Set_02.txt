26. Windows में Run डायलॉग बॉक्स खोलने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Windows+E (b) Windows+X (c) Windows+D (d) Windows+R
उत्तर: (d)
हल: कई उपयोगकर्ता Run डायलॉग को File Explorer (Windows+E) या Quick Link मेनू (Windows+X) समझ लेते हैं, लेकिन Run डायलॉग विशेष रूप से Windows+R से लॉन्च होता है, इसलिए उत्तर Windows+R है।
स्रोत: Microsoft Support

27. Microsoft Word में, चयनित टेक्स्ट पर बोल्ड फॉर्मेटिंग लागू करने के लिए कौन सा शॉर्टकट है?
(a) Ctrl+I (b) Ctrl+U (c) Ctrl+B (d) Ctrl+Shift+B
उत्तर: (c)
हल: लुभाने वाले गलत विकल्प Ctrl+I इटैलिक के लिए और Ctrl+U अंडरलाइन के लिए हैं, लेकिन बोल्ड फॉर्मेटिंग Ctrl+B से लागू होती है, इसलिए उत्तर Ctrl+B है।
स्रोत: Microsoft Support

28. Windows में Alt+Tab शॉर्टकट क्या करता है?
(a) Task Manager खोलता है (b) सक्रिय विंडो बंद करता है (c) खुले एप्लिकेशन के बीच स्विच करता है (d) सभी विंडो मिनिमाइज़ करता है
उत्तर: (c)
हल: Alt+F4 सक्रिय विंडो बंद करता है, Ctrl+Shift+Esc Task Manager खोलता है, और Windows+M सभी विंडो मिनिमाइज़ करता है; Alt+Tab खुले एप्लिकेशन के बीच साइकिल करता है, इसलिए उत्तर खुले एप्लिकेशन के बीच स्विच करता है।
स्रोत: Microsoft Support

29. Microsoft Word में पूरे डॉक्यूमेंट को चुनने के लिए कौन सा शॉर्टकट है?
(a) Ctrl+Y (b) Ctrl+S (c) Ctrl+Z (d) Ctrl+A
उत्तर: (d)
हल: Ctrl+S डॉक्यूमेंट सेव करता है, Ctrl+Z अंतिम क्रिया को पूर्ववत करता है, और Ctrl+Y पूर्ववत की गई क्रिया को फिर से करता है; सभी सामग्री चुनने के लिए Ctrl+A उपयोग होता है, इसलिए उत्तर Ctrl+A है।
स्रोत: Microsoft Support

30. वेब ब्राउज़र में, डाउनलोड पेज खोलने के लिए कौन सा शॉर्टकट है?

स्रोत: Microsoft Learn

31. Windows में Task Manager सीधे खोलने का शॉर्टकट क्या है?
(a) Ctrl+Shift+Esc (b) Windows+X (c) Ctrl+Alt+Del (d) Ctrl+Esc
उत्तर: (a)
हल: Ctrl+Alt+Del सिक्योरिटी ऑप्शन स्क्रीन खोलता है, Windows+X Quick Link मेनू खोलता है, और Ctrl+Esc Start मेनू खोलता है; Task Manager सीधे Ctrl+Shift+Esc से खुलता है, इसलिए उत्तर Ctrl+Shift+Esc है।
स्रोत: Microsoft Support

32. Microsoft Excel में, नई वर्कशीट डालने के लिए कौन सा शॉर्टकट है?
(a) Shift+F11 (b) Ctrl+N (c) Ctrl+Shift+N (d) Alt+Shift+F1
उत्तर: (a)
हल: Ctrl+N नई वर्कबुक बनाता है, Ctrl+Shift+N मानक Excel शॉर्टकट नहीं है, और Alt+Shift+F1 चार्ट शीट डालता है; नई वर्कशीट Shift+F11 से डाली जाती है, इसलिए उत्तर Shift+F11 है।
स्रोत: Microsoft Support

33. Windows कंप्यूटर को तुरंत लॉक करने के लिए कौन सा शॉर्टकट है?
(a) Windows+Space (b) Windows+K (c) Windows+L (d) Ctrl+Alt+L
उत्तर: (c)
हल: Windows+K वायरलेस डिस्प्ले के लिए Connect पेन खोलता है, Ctrl+Alt+L मानक Windows शॉर्टकट नहीं है, और Windows+Space इनपुट भाषा बदलता है; सत्र लॉक करने के लिए Windows+L उपयोग होता है, इसलिए उत्तर Windows+L है।
स्रोत: Microsoft Support

34. Microsoft PowerPoint में, वर्तमान स्लाइड से स्लाइड शो शुरू करने के लिए कौन सा शॉर्टकट है?

उत्तर: (d)
हल: F5 स्लाइड शो को शुरुआत से शुरू करता है, Ctrl+F5 मानक स्लाइड शो शॉर्टकट नहीं है, और Alt+F5 प्रेजेंटर व्यू खोलता है; वर्तमान स्लाइड से शुरू करने के लिए Shift+F5 उपयोग होता है, इसलिए उत्तर Shift+F5 है।
स्रोत: Microsoft Support

35. अधिकांश आधुनिक वेब ब्राउज़र में Ctrl+Shift+T क्या करता है?
(a) नया टैब खोलता है (b) अंतिम बंद टैब को फिर से खोलता है (c) डाउनलोड पेज खोलता है (d) वर्तमान टैब बंद करता है

स्रोत: Microsoft Learn

36. Windows File Explorer में, चयनित फाइल या फोल्डर का नाम बदलने के लिए कौन सा शॉर्टकट है?

स्रोत: Microsoft Support

37. Windows Settings ऐप खोलने के लिए कौन सा शॉर्टकट है?

38. Microsoft Word में, पेज ब्रेक बनाने के लिए कौन सा शॉर्टकट है?
(a) Shift+Enter (b) Ctrl+Shift+Enter (c) Alt+Enter (d) Ctrl+Enter
उत्तर: (d)

स्रोत: Microsoft Support
