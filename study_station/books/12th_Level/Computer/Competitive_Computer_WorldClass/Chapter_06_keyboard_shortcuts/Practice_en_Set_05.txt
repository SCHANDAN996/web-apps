101. What is the keyboard shortcut to copy selected text in Windows?
(a) Ctrl+Z (b) Ctrl+V (c) Ctrl+C (d) Ctrl+X
Answer: (c)
Solution: The tempting option is Ctrl+V which pastes, but copying uses Ctrl+C, so the answer is Ctrl+C.
Source: Microsoft Support
