# कीबोर्ड शॉर्टकट

## परिचय

कीबोर्ड शॉर्टकट (Keyboard Shortcuts) वे कुंजी-संयोजन (key combinations) हैं जो माउस के बिना किसी कार्य को तेज़ी से पूरा करते हैं। SSC CHSL, CGL, बैंकिंग और रेलवे परीक्षाओं के कंप्यूटर ज्ञान भाग में ये नियमित रूप से पूछे जाते हैं। इस अध्याय में हम Windows ऑपरेटिंग सिस्टम, Microsoft Office अनुप्रयोगों (Word, Excel, PowerPoint) और प्रमुख वेब ब्राउज़रों के स्थिर, संस्करण-निरपेक्ष शॉर्टकट कवर करेंगे। सभी तथ्य Microsoft आधिकारिक दस्तावेज़ीकरण (Microsoft Support / Microsoft Learn) और ब्राउज़र विक्रेताओं के आधिकारिक पृष्ठों पर आधारित हैं।

---

## 1. मूल अवधारणाएँ और संकेतन

| संकेत | अर्थ |
|------|------|
| `Ctrl` | Control कुंजी (दोनों ओर) |
| `Alt` | Alternate कुंजी |
| `Shift` | Shift कुंजी |
| `Win` | Windows लोगो कुंजी (⊞) |
| `+` | कुंजियाँ एक साथ दबाएँ |
| `,` (कॉमा) | क्रमिक दबाएँ: पहली छोड़कर दूसरी दबाएँ |

**उदाहरण**: `Ctrl + C` का अर्थ — Ctrl दबाए रखें, फिर C दबाएँ, दोनों छोड़ें।  
`Alt, F, S` का अर्थ — Alt दबाकर छोड़ें, फिर F दबाएँ, फिर S दबाएँ (मेनू शॉर्टकट)।

## 2. Windows ऑपरेटिंग सिस्टम शॉर्टकट

ये शॉर्टकट Windows 10 और Windows 11 दोनों में समान रूप से काम करते हैं (Microsoft Learn: "Windows keyboard shortcuts")।

### 2.1 सिस्टम-स्तरीय

| शॉर्टकट | कार्य |
|----------|-------|
| `Win` | प्रारंभ मेनू खोलें/बंद करें |
| `Win + D` | डेस्कटॉप दिखाएँ (सभी विंडो न्यूनतम/पुनर्स्थापित) |
| `Win + E` | फ़ाइल एक्सप्लोरर खोलें |
| `Win + L` | कंप्यूटर लॉक करें |
| `Win + R` | "चलाएँ" संवाद खोलें |
| `Win + I` | सेटिंग्स खोलें |
| `Win + A` | **Windows 10:** एक्शन सेंटर खोलें; **Windows 11:** क्विक सेटिंग्स खोलें (नेटवर्क, वॉल्यूम, बैटरी आदि) |
| `Win + N` | **केवल Windows 11:** सूचना केंद्र (Notification Center) खोलें |
| `Win + S` / `Win + Q` | खोज खोलें |
| `Win + Tab` | कार्य दृश्य (Task View) — वर्चुअल डेस्कटॉप प्रबंधन |
| `Win + Ctrl + D` | नया वर्चुअल डेस्कटॉप बनाएँ |
| `Win + Ctrl + ←/→` | वर्चुअल डेस्कटॉप के बीच स्विच करें |
| `Win + Ctrl + F4` | वर्तमान वर्चुअल डेस्कटॉप बंद करें |
| `Win + PrtScn` | स्क्रीनशॉट लेकर Pictures\Screenshots में सहेजें |
| `Win + Shift + S` | स्निपिंग टूल / स्निप और स्केच — क्षेत्र चयन स्क्रीनशॉट |

### 2.2 विंडो प्रबंधन

| शॉर्टकट | कार्य |
|----------|-------|
| `Win + ↑` | विंडो अधिकतम करें |
| `Win + ↓` | विंडो न्यूनतम/पुनर्स्थापित करें |
| `Win + ←` | विंडो को बाएँ आधे में स्नैप करें |
| `Win + →` | विंडो को दाएँ आधे में स्नैप करें |
| `Alt + Tab` | खुली विंडो के बीच स्विच करें (दबाए रखें, Tab से चुनें) |
| `Alt + F4` | सक्रिय विंडो बंद करें / शटडाउन संवाद (डेस्कटॉप पर) |
| `Ctrl + Shift + Esc` | सीधे टास्क मैनेजर खोलें |

### 2.3 पहुँच-योग्यता (Accessibility)

| शॉर्टकट | कार्य |
|----------|-------|
| `Win + U` | पहुँच-योग्यता सेटिंग्स खोलें |
| `Win + +` (प्लस) | मैग्नीफायर चालू/ज़ूम इन |
| `Win + -` (माइनस) | मैग्नीफायर ज़ूम आउट |
| `Win + Esc` | मैग्नीफायर बंद करें |
| `Win + Ctrl + Enter` | नैरेटर चालू/बंद करें |

| शॉर्टकट | कार्य |
|----------|-------|
| `Ctrl + B` | बोल्ड (Bold) |

| `Ctrl + U` | अंडरलाइन (Underline) |

| `Ctrl + Q` | पैराग्राफ़ स्वरूपण हटाएँ |
| `Ctrl + E` | केंद्र संरेखित करें |
| `Ctrl + L` | बाएँ संरेखित करें |
| `Ctrl + R` | दाएँ संरेखित करें |

| `Ctrl + 2` | दोहरी लाइन रिक्ति |
| `Ctrl + 5` | 1.5 लाइन रिक्ति |

### 3.3 नेविगेशन और चयन

| शॉर्टकट | कार्य |
|----------|-------|
| `Ctrl + ←/→` | शब्द-दर-शब्द कर्सर ले जाएँ |
| `Ctrl + ↑/↓` | पैराग्राफ़-दर-पैराग्राफ़ कर्सर ले जाएँ |
| `Home` / `End` | पंक्ति की शुरुआत/अंत |
| `Ctrl + Home` / `Ctrl + End` | दस्तावेज़ की शुरुआत/अंत |
| `Shift + ←/→/↑/↓` | अक्षर/पंक्ति चयन बढ़ाएँ |
| `Ctrl + Shift + ←/→` | शब्द चयन बढ़ाएँ |
| `Ctrl + Shift + ↑/↓` | पैराग्राफ़ चयन बढ़ाएँ |
| `Ctrl + F` | खोजें |
| `Ctrl + H` | ढूँढें और बदलें |
| `Ctrl + G` | जाएँ (Go To) — पृष्ठ, अनुभाग, बुकमार्क |

### 3.4 विशेष कार्य

| शॉर्टकट | कार्य |
|----------|-------|
| `Ctrl + K` | हाइपरलिंक डालें |
| `Ctrl + Enter` | पृष्ठ विराम डालें |
| `Shift + Enter` | लाइन विराम (पैराग्राफ़ विराम नहीं) |
| `Alt + Ctrl + C` | कॉपीराइट चिह्न (©) |
| `Alt + Ctrl + R` | पंजीकृत ट्रेडमार्क (®) |
| `Alt + Ctrl + T` | ट्रेडमार्क (™) |
| `F7` | वर्तनी और व्याकरण जाँच |
| `Shift + F7` | थिसॉरस (पर्यायवाची) |
| `Alt + Shift + D` | वर्तमान दिनांक डालें |
| `Alt + Shift + T` | वर्तमान समय डालें |

## 4. Microsoft Excel शॉर्टकट

Excel के शॉर्टकट डेटा प्रविष्टि, नेविगेशन और सूत्र कार्य के लिए महत्वपूर्ण हैं (Microsoft Support: "Keyboard shortcuts in Excel")।

### 4.1 वर्कबुक और शीट

| शॉर्टकट | कार्य |
|----------|-------|
| `Ctrl + N` | नई वर्कबुक |
| `Ctrl + O` | खोलें |
| `Ctrl + S` | सहेजें |
| `F12` | इस रूप में सहेजें |
| `Ctrl + P` | प्रिंट |
| `Ctrl + W` | वर्कबुक बंद करें |
| `Ctrl + F4` | सक्रिय विंडो बंद करें |
| `Alt + F4` | Excel बंद करें |
| `Shift + F11` | नई वर्कशीट डालें |
| `Ctrl + PageUp / PageDown` | शीट्स के बीच नेविगेट करें |
| `Alt, H, O, R` (क्रमिक) | शीट नाम बदलें (रिबन पथ: Home → Format → Rename Sheet) |

### 4.2 सेल नेविगेशन और चयन

| शॉर्टकट | कार्य |
|----------|-------|
| `Ctrl + ←/→/↑/↓` | डेटा क्षेत्र की सीमा तक कूदें |
| `Ctrl + Home` | सेल A1 पर जाएँ |
| `Ctrl + End` | प्रयुक्त सीमा का अंतिम सेल |
| `Ctrl + G` / `F5` | "जाएँ" संवाद |
| `Shift + Space` | पूरी पंक्ति चुनें |
| `Ctrl + Space` | पूरा स्तंभ चुनें |
| `Ctrl + A` | वर्तमान क्षेत्र चुनें (दबाएँ दोबारा → पूरी शीट) |
| `Ctrl + Shift + ←/→/↑/↓` | चयन को डेटा सीमा तक बढ़ाएँ |
| `Ctrl + Shift + Home` | चयन को A1 तक बढ़ाएँ |
| `Ctrl + Shift + End` | चयन को अंतिम प्रयुक्त सेल तक बढ़ाएँ |

### 4.3 संपादन और डेटा प्रविष्टि

| शॉर्टकट | कार्य |
|----------|-------|
| `F2` | सक्रिय सेल संपादित करें |
| `Enter` | प्रविष्टि पूरी करके नीचे जाएँ |
| `Shift + Enter` | प्रविष्टि पूरी करके ऊपर जाएँ |
| `Tab` | प्रविष्टि पूरी करके दाएँ जाएँ |
| `Shift + Tab` | प्रविष्टि पूरी करके बाएँ जाएँ |
| `Alt + Enter` | सेल के अंदर नई पंक्ति (लाइन ब्रेक) |
| `Ctrl + D` | ऊपर वाले सेल से भरें (Fill Down) |
| `Ctrl + R` | बाएँ वाले सेल से भरें (Fill Right) |
| `Ctrl + ;` | आज की दिनांक डालें |
| `Ctrl + Shift + ;` | वर्तमान समय डालें |
| `Ctrl + '` (एकल उद्धरण) | ऊपर वाले सेल का सूत्र कॉपी करें |
| `Ctrl + Shift + "` (दोहरा उद्धरण) | ऊपर वाले सेल का मान कॉपी करें |
| `Delete` | सेल सामग्री साफ़ करें (स्वरूपण नहीं) |
| `Ctrl + -` (माइनस) | सेल/पंक्ति/स्तंभ हटाएँ संवाद |
| `Ctrl + Shift + +` (प्लस) | सेल/पंक्ति/स्तंभ डालें संवाद |

### 4.4 सूत्र और फ़ंक्शन

| शॉर्टकट | कार्य |
|----------|-------|
| `=` | सूत्र शुरू करें |
| `Shift + F3` | फ़ंक्शन डालें संवाद |
| `Ctrl + Shift + A` | सूत्र टाइप करते समय तर्क नाम डालें |
| `F4` | सापेक्ष/निरपेक्ष संदर्भ टॉगल करें (A1 → $A$1 → A$1 → $A1) |
| `F9` | सभी वर्कबुक पुनर्गणना करें |
| `Shift + F9` | सक्रिय शीट पुनर्गणना करें |
| `Ctrl + ` ` (बैकटिक/ग्रेव एक्सेंट) | सूत्र/मान दृश्य टॉगल करें |
| `Alt + =` | ऑटोसम (Σ) डालें |

### 4.5 स्वरूपण

| शॉर्टकट | कार्य |
|----------|-------|
| `Ctrl + 1` | सेल स्वरूपण संवाद खोलें |
| `Ctrl + B` / `Ctrl + I` / `Ctrl + U` | बोल्ड/इटैलिक/अंडरलाइन |
| `Ctrl + Shift + ~` | सामान्य स्वरूप |
| `Ctrl + Shift + $` | मुद्रा स्वरूप (दो दशमलव) |
| `Ctrl + Shift + %` | प्रतिशत स्वरूप (कोई दशमलव नहीं) |
| `Ctrl + Shift + #` | दिनांक स्वरूप (दिन-माह-वर्ष) |
| `Ctrl + Shift + @` | समय स्वरूप (घंटा:मिनट AM/PM) |
| `Ctrl + Shift + !` | संख्या स्वरूप (हज़ार विभाजक, दो दशमलव) |
| `Ctrl + Shift + ^` | वैज्ञानिक स्वरूप (दो दशमलव) |

### 4.6 पंक्ति/स्तंभ छिपाना-दिखाना

| शॉर्टकट | कार्य |
|----------|-------|
| `Ctrl + 9` | चयनित पंक्तियाँ छिपाएँ |
| `Ctrl + Shift + 9` | पंक्तियाँ दिखाएँ |
| `Ctrl + 0` (शून्य) | चयनित स्तंभ छिपाएँ |
| `Ctrl + Shift + 0` | स्तंभ दिखाएँ (नोट: कुछ क्षेत्रीय सेटिंग में यह IME टॉगल कर सकता है; विश्वसनीय विकल्प: `Alt, H, O, U, L`) |

## 6. वेब ब्राउज़र शॉर्टकट (Chrome, Edge, Firefox)

## 7. कार्य-आधारित उदाहरण (Worked Examples)

### उदाहरण 1: Word में तेज़ स्वरूपण
**स्थिति**: एक पैराग्राफ़ को बोल्ड, केंद्र-संरेखित और 1.5 लाइन रिक्ति देनी है।  
**चरण**:
1. पैराग्राफ़ में कहीं क्लिक करें।
2. `Ctrl + B` → बोल्ड।
3. `Ctrl + E` → केंद्र संरेखण।
4. `Ctrl + 5` → 1.5 लाइन रिक्ति।  
**परिणाम**: तीन कुंजी-संयोजनों में स्वरूपण पूरा। माउस से रिबन पर जाने की तुलना में बहुत तेज़।

---

### उदाहरण 2: Excel में डेटा क्षेत्र चुनकर योग करना
**स्थिति**: A1:A100 में संख्याएँ हैं; A101 में योग चाहिए।  
**चरण**:
1. A1 पर जाएँ (`Ctrl + Home`)।
2. `Ctrl + Shift + ↓` → A1:A100 चुन लिया।
3. `Alt + =` → ऑटोसम सूत्र `=SUM(A1:A100)` A101 में डाल देता है।  
**परिणाम**: बिना माउस ड्रैग किए पूर्ण क्षेत्र चयन और सूत्र प्रविष्टि।

---

### उदाहरण 3: Excel में निरपेक्ष संदर्भ टॉगल
**स्थिति**: सूत्र `=B2*C1` लिख रहे हैं; C1 को निरपेक्ष (`$C$1`) बनाना है।  
**चरण**:
1. सूत्र बार में C1 पर कर्सर रखें।
2. `F4` दबाएँ → `$C$1`।
3. फिर `F4` → `C$1` (मिश्रित: पंक्ति निरपेक्ष)।
4. फिर `F4` → `$C1` (स्तंभ निरपेक्ष)।
5. फिर `F4` → `C1` (सापेक्ष)।  
**नोट**: प्रत्येक दबाव अगले संदर्भ प्रकार पर चक्रित करता है।

---

### उदाहरण 4: PowerPoint में स्लाइड शो के दौरान पेन और इरेज़र उपयोग
**स्थिति**: प्रस्तुति चल रही है; स्लाइड पर लाल घेरा बनाना है, फिर एक स्ट्रोक मिटाना है।  
**चरण**:
1. `Ctrl + P` → पेन मोड सक्रिय (कर्सर पेन बन जाता है)।
2. माउस/टच से घेरा खींचें।
3. `Ctrl + E` → इरेज़र मोड (कर्सर इरेज़र बन जाता है)।
4. मिटाने वाला स्ट्रोक पर क्लिक/ड्रैग करें।
5. `Ctrl + A` → तीर मोड पर लौटें।  
**महत्वपूर्ण**: `E` दबाने से **सभी** पेन/हाइलाइटर चिह्न मिट जाते हैं; केवल अंतिम स्ट्रोक मिटाने के लिए `Ctrl + E` (इरेज़र) का उपयोग करें।

---

### उदाहरण 5: ब्राउज़र में बंद टैब पुनर्स्थापित करना
**स्थिति**: गलती से महत्त्वपूर्ण टैब बंद हो गया।  
**चरण**: `Ctrl + Shift + T` दबाएँ। टैब उसी स्थिति (स्क्रॉल, फॉर्म डेटा) में वापस खुल जाता है।  
**दोहराएँ**: बार-बार दबाने से क्रमशः पुराने बंद टैब खुलते हैं (सत्र इतिहास)।

---

### उदाहरण 6: Windows में वर्चुअल डेस्कटॉप बनाकर कार्य अलग करना
**स्थिति**: एक डेस्कटॉप पर ब्राउज़र-शोध, दूसरे पर Excel-रिपोर्ट।  
**चरण**:
1. `Win + Tab` → कार्य दृश्य खोलें।
2. `Win + Ctrl + D` → नया डेस्कटॉप (Desktop 2) बनेगा और स्विच हो जाएगा।
3. Desktop 2 पर Excel खोलें (`Win + E` → फोल्डर → फाइल)।
4. `Win + Ctrl + ←` → Desktop 1 (ब्राउज़र) पर वापस।  
**लाभ**: `Alt + Tab` केवल सक्रिय डेस्कटॉप की विंडो दिखाता है; कार्य संदर्भ साफ़ रहता है।

## 8. सामान्य त्रुटियाँ और उनसे बचाव

| ब्राउज़र में `Backspace` पीछे जाने के लिए काम न करना | `Alt + ←` या माउस बैक बटन; Chrome/Edge में `Backspace` डिफ़ॉल्ट रूप से अक्षम है (फॉर्म में टाइप करते समय गलती रोकने के लिए); Firefox में भी डिफ़ॉल्ट अक्षम | सेटिंग्स → शॉर्टकट में पुनः सक्षम किया जा सकता है |
| `Win + PrtScn` स्क्रीनशॉट न मिलना | फ़ाइल `Pictures\Screenshots` फ़ोल्डर में सहेजी जाती है; क्लिपबोर्ड में नहीं | `PrtScn` अकेला क्लिपबोर्ड में कॉपी करता है; `Win+PrtScn` फ़ाइल बनाता है |
| `F12` को "सहेजें" समझना | `F12` = **इस रूप में सहेजें** (Save As); `Ctrl + S` = सहेजें | भ्रम से मूल फ़ाइल अधिलेखित हो सकती है |
| Excel में `Ctrl + A` एक बार दबाकर पूरी शीट चुनने की उम्मीद | डेटा क्षेत्र में `Ctrl + A` → वर्तमान क्षेत्र; **दूसरी बार** → पूरी शीट | इरादतन डिज़ाइन: डेटा तालिका पहले चुनने के लिए |

## 9. परीक्षा-उन्मुख संकेत

1. **स्कोप पहचानें**: प्रश्न में "Word में", "Excel में", "Windows में", "ब्राउज़र में" स्पष्ट हो तो उसी दायरे का शॉर्टकट चुनें। `Ctrl + P` सभी में प्रिंट है, लेकिन `Ctrl + Shift + L` Word में बुलेट टॉगल है, Excel में फ़िल्टर टॉगल है।
2. **संस्करण-निरपेक्षता**: Windows 10/11, Office 2016–365 में मूल शॉर्टकट अपरिवर्तित हैं। "नए संस्करण में बदल गया" जैसे कथन पर भरोसा न करें जब तक Microsoft दस्तावेज़ न दिखाए।
3. **मेनू एक्सेलेरेटर (Alt क्रमिक)**: `Alt, H, V, P` (चिपकाएँ → मान) जैसे क्रमिक शॉर्टकट रिबन टैब/बटन के पहले अक्षर पर आधारित हैं; ये भाषा/थीम पर निर्भर नहीं करते।
4. **नकारात्मक वाक्य**: "निम्न में से कौन सा शॉर्टकट **नहीं** करता…" — विकल्पों में एक गलत कार्य होगा; उसे पहचानें।
5. **मैक बनाम विंडोज**: परीक्षा Windows परिवेश मानती है; `Cmd` (⌘) आधारित विकल्प गलत होंगे।
6. **ब्राउज़र अंतर**: `Ctrl+Shift+N` (इनकॉग्निटो) केवल Chrome/Edge में; Firefox में `Ctrl+Shift+P`। `Backspace` पीछे जाने के लिए Firefox में डिफ़ॉल्ट अक्षम — `Alt+←` सार्वभौमिक है।
