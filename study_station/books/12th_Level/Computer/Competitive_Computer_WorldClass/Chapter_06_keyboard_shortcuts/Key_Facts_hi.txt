**कीबोर्ड शॉर्टकट — 25 मुख्य बिंदु**

1. **Win + D** — सभी खुली विंडो को न्यूनतम (minimize) करके डेस्कटॉप दिखाता है; दोबारा दबाने पर विंडो वापस आ जाती हैं। (Windows)

2. **Win + E** — फ़ाइल एक्सप्लोरर (File Explorer) खोलता है। (Windows)

3. **Win + L** — कंप्यूटर को तुरंत लॉक (Lock) करता है; पासवर्ड/पिन के बिना कोई एक्सेस नहीं कर सकता। (Windows)

4. **Alt + Tab** — खुले प्रोग्राम के बीच तेज़ी से स्विच करता है; Alt दबाए रखकर Tab दबाते रहें। (Windows)

5. **Ctrl + Shift + Esc** — सीधे टास्क मैनेजर (Task Manager) खोलता है; Ctrl+Alt+Del → Task Manager से तेज़। (Windows)

6. **Win + R** — “रन” (Run) डायलॉग खोलता है; कमांड जैसे `cmd`, `msconfig`, `control` टाइप करके एंटर दबाएँ। (Windows)

7. **Win + I** — विंडोज़ सेटिंग्स (Settings) ऐप खोलता है। (Windows 10/11)

8. **Win + S** — सर्च बार खोलता है; ऐप, फ़ाइल, सेटिंग खोजने के लिए। (Windows 10/11)

9. **Win + Q** — Windows 10 में सर्च/कॉर्टाना खोलता है; Windows 11 में Microsoft Teams चैट खोलता है। (संस्करण-निर्भर)

10. **Ctrl + C / Ctrl + X / Ctrl + V** — क्रमशः कॉपी, कट, पेस्ट; लगभग हर विंडोज़ ऐप और ब्राउज़र में काम करते हैं। (Universal)

11. **Ctrl + Z / Ctrl + Y** — पूर्ववत (Undo) और फिर से करें (Redo); टेक्स्ट एडिटर, ऑफिस, ब्राउज़र फ़ॉर्म में उपयोगी। (Universal)

12. **Ctrl + A** — वर्तमान विंडो/दस्तावेज़ में सब कुछ चुनता (Select All) है। (Universal)

13. **Ctrl + S** — वर्तमान फ़ाइल सेव करता है; आदत बनाएँ हर मिनट दबाने की। (Universal)

14. **Ctrl + P** — प्रिंट डायलॉग खोलता है। (Universal)

15. **Ctrl + F** — वर्तमान दस्तावेज़/वेबपेज में “ढूँढें” (Find) बार खोलता है। (Universal)

16. **Alt + F4** — सक्रिय विंडो बंद करता है; डेस्कटॉप पर दबाने से शटडाउन डायलॉग आता है। (Windows)

17. **Win + ← / → / ↑ / ↓** — सक्रिय विंडो को बाएँ/दाएँ आधी स्क्रीन पर स्नैप (Snap) करता है; ↑ से मैक्सिमाइज़, ↓ से रिस्टोर/मिनिमाइज़। (Windows 10/11)

18. **Win + Tab** — टास्क व्यू (Task View) खोलता है; वर्चुअल डेस्कटॉप बनाने/स्विच करने के लिए। (Windows 10/11)

19. **Ctrl + N** — नई विंडो खोलता है; ब्राउज़र और फ़ाइल एक्सप्लोरर दोनों में। **Ctrl + T** — नया टैब खोलता है; ब्राउज़र में (सभी संस्करण) और फ़ाइल एक्सप्लोरर में (केवल Windows 11)। (Browser / Explorer)

20. **Ctrl + W / Ctrl + F4** — वर्तमान टैब बंद करता है; ब्राउज़र, ऑफिस टैब, फ़ाइल एक्सप्लोरर टैब (Windows 11) में काम करता है। (Browser / Office / Explorer)

21. **Ctrl + Shift + T** — अंतिम बंद टैब फिर से खोलता है (ब्राउज़र में कई बार दबाकर इतिहास में पीछे जा सकते हैं)। (Browser)

22. **Ctrl + Tab / Ctrl + Shift + Tab** — अगले/पिछले टैब पर जाता है। (Browser)

23. **F5 / Ctrl + R** — पेज रीफ्रेश (Reload) करता है; Ctrl+F5 कैश बायपास करके हार्ड रीफ्रेश करता है। (Browser)

24. **Ctrl + D** — वर्तमान पेज को बुकमार्क (Bookmark) करता है। (Browser)

25. **Alt + D / F6 / Ctrl + L** — एड्रेस बार (Address Bar) पर फोकस ले जाता है; यूआरएल टाइप करने के लिए माउस की ज़रूरत नहीं। (Browser)
