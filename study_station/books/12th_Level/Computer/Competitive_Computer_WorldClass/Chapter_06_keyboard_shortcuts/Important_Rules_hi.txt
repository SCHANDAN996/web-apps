# कीबोर्ड शॉर्टकट — 15 महत्वपूर्ण नियम

## नियम 1: विंडोज़ की (Win) सिस्टम-स्तरीय शॉर्टकट का मुख्य संशोधक है
विंडोज़ की (⊞) दबाकर रखें और दूसरी कुंजी दबाएँ — यह OS-स्तर की क्रिया शुरू करता है, किसी ऐप के अंदर की नहीं।
उदाहरण: `Win + E` → फाइल एक्सप्लोरर खोलता है; `Win + D` → डेस्कटॉप दिखाता/छिपाता है।
अपवाद: कुछ OEM कीबोर्ड पर `Win` लेबल `Start` या लोगो हो सकता है; कार्य समान रहता है।

## नियम 2: Ctrl + अक्षर = संपादन/नेविगेशन (लगभग सभी विंडोज़ ऐप में)
`Ctrl + C` (कॉपी), `Ctrl + V` (पेस्ट), `Ctrl + X` (कट), `Ctrl + Z` (पूर्ववत्), `Ctrl + Y` (फिर से करें) — ये सार्वभौमिक हैं।
उदाहरण: नोटपैड, वर्ड, एक्सप्लोरर, ब्राउज़र एड्रेस बार — सभी में काम करते हैं।
अपवाद: कुछ टर्मिनल/कमांड प्रॉम्प्ट में `Ctrl + V` पेस्ट नहीं करता (वहाँ राइट-क्लिक या `Ctrl + Shift + V` प्रयुक्त होता है)।

## नियम 3: Alt + अक्षर = मेन्यू/रिबन एक्सेस (की-टिप्स)
`Alt` दबाएँ → रिबन/मेन्यू पर अक्षर दिखते हैं; वह अक्षर दबाएँ → वह टैब/कमांड खुलता है।
उदाहरण: वर्ड में `Alt → H → F → S` → फॉन्ट साइज़ ड्रॉपडाउन।
अपवाद: ब्राउज़र में `Alt` अकेले मेन्यू बार फोकस करता है (यदि दृश्यमान हो); क्रोम/एज में मेन्यू बार डिफ़ॉल्ट छिपा होता है।

## नियम 4: फंक्शन कुंजियाँ (F1–F12) संदर्भ-निर्भर हैं
`F1` → सहायता (लगभग हर ऐप); `F2` → नाम बदलें (एक्सप्लोरर, डेस्कटॉप); `F5` → रीफ्रेश (एक्सप्लोरर, ब्राउज़र); `F11` → पूर्ण-स्क्रीन टॉगल (ब्राउज़र, एक्सप्लोरर)।
उदाहरण: एक्सेल में `F2` सेल संपादन मोड; `F4` अंतिम क्रिया दोहराता है।
अपवाद: लैपटॉप पर `Fn` लॉक सक्षम होने पर `F1–F12` मीडिया कुंजियाँ बन जाते हैं; तब `Fn + F5` दबाना पड़ता है।

## नियम 5: Win + संख्या (1–9) टास्कबार पिन किए ऐप लॉन्च/स्विच करता है
टास्कबार पर बाएँ से गिनें: `Win + 1` पहला पिन किया ऐप, `Win + 2` दूसरा, आदि।
उदाहरण: यदि ब्राउज़र पहला पिन है, `Win + 1` उसे खोलता/फोकस करता है।
अपवाद: केवल पिन किए ऐप पर लागू; चल रहे लेकिन अनपिन ऐप पर काम नहीं करता।

## नियम 6: वर्चुअल डेस्कटॉप: Win + Ctrl + D (नया), Win + Ctrl + ←/→ (स्विच), Win + Ctrl + F4 (बंद)
एक साथ कई कार्य-प्रवाह अलग रखने के लिए।
उदाहरण: `Win + Ctrl + D` → नया डेस्कटॉप; `Win + Tab` → टास्क व्यू में सभी डेस्कटॉप दिखते हैं।
अपवाद: विंडोज़ 10/11 दोनों में समान; विंडोज़ 7 में वर्चुअल डेस्कटॉप मूल रूप से नहीं है।

## नियम 7: स्नैप असिस्ट: Win + ←/→/↑/↓ विंडो को स्क्रीन किनारे/कोने में स्नैप करता है
`Win + ←` → बाएँ आधा; `Win + →` → दाएँ आधा; फिर `Win + ↑` → ऊपरी कोना (क्वार्टर)।
उदाहरण: दो ब्राउज़र विंडो साइड-बाई-साइड तुलना के लिए।
अपवाद: यदि विंडो पहले से अधिकतम है, `Win + ↓` पहले पुनर्स्थापित करता है, दूसरी बार न्यूनतम करता है।

## नियम 8: क्लिपबोर्ड इतिहास: Win + V (सक्षम होने पर)
सेटिंग्स → सिस्टम → क्लिपबोर्ड → "क्लिपबोर्ड इतिहास" चालू करें। फिर `Win + V` → पिछले 25 आइटम में से चुनें।
उदाहरण: एक के बाद एक कई टेक्स्ट/इमेज कॉपी करें, फिर किसी भी क्रम में पेस्ट करें।
अपवाद: डिफ़ॉल्ट बंद; पुनरारंभ पर इतिहास साफ़ होता है (पिन किए आइटम छोड़कर)।

## नियम 9: स्क्रीनशॉट: Win + Shift + S → स्निपिंग टूल बार (आयत, फ्रीफॉर्म, विंडो, पूर्ण-स्क्रीन)
चयन क्लिपबोर्ड पर जाता है; अधिसूचना क्लिक करके एनोटेट/सेव करें।
उदाहरण: त्रुटि संदेश का भाग कैप्चर करके चैट/ईमेल में पेस्ट।
अपवाद: `PrtSc` अकेला पूर्ण स्क्रीन क्लिपबोर्ड पर; `Win + PrtSc` → चित्र → स्क्रीनशॉट फ़ोल्डर में PNG सेव करता है।

## नियम 10: माइक्रोसॉफ्ट ऑफिस (वर्ड/एक्सेल/पावरपॉइंट) में Ctrl + Shift + तीर = शब्द/सेल ब्लॉक चयन
`Ctrl + Shift + →` → अगले शब्द तक चयन; एक्सेल में `Ctrl + Shift + ↓` → नीचे डेटा अंत तक चयन।
उदाहरण: एक्सेल में 10,000 पंक्तियाँ तुरंत चुनने के लिए।
अपवाद: खाली सेल/शब्द सीमा पर रुकता है; फ़िल्टर्ड पंक्तियाँ शामिल नहीं होतीं।

## नियम 11: एक्सेल में F4 = निरपेक्ष संदर्भ टॉगल (सूत्र बार में)
सेल संदर्भ पर कर्सर रखकर `F4` दबाएँ: `A1 → $A$1 → A$1 → $A1 → A1` चक्र।
उदाहरण: सूत्र कॉपी करते समय पंक्ति/स्तंभ लॉक करने के लिए।
अपवाद: केवल सूत्र संपादन मोड में काम करता है; सेल चयन मोड में `F4` अंतिम क्रिया दोहराता है।

## नियम 12: ब्राउज़र (क्रोम/एज/फायरफॉक्स) सार्वभौमिक शॉर्टकट
`Ctrl + T` नया टैब; `Ctrl + W` टैब बंद; `Ctrl + Shift + T` अंतिम बंद टैब पुनः खोलें; `Ctrl + Tab` / `Ctrl + Shift + Tab` अगला/पिछला टैब; `Ctrl + L` / `Alt + D` / `F6` एड्रेस बार फोकस; `Ctrl + + / - / 0` ज़ूम इन/आउट/रीसेट।
नई निजी/इनकॉग्निटो विंडो: क्रोम/एज में `Ctrl + Shift + N`, फायरफॉक्स में `Ctrl + Shift + P`।
उदाहरण: गलती से बंद टैब `Ctrl + Shift + T` से तुरंत वापस।
अपवाद: फायरफॉक्स में `Ctrl + Shift + T` निजी विंडो में काम नहीं करता; `Ctrl + N` नई विंडो।

## नियम 13: एक्सेसिबिलिटी शॉर्टकट (स्टिकी कीज़, फिल्टर कीज़, मैग्नीफायर)
`Shift` 5 बार दबाएँ → स्टिकी कीज़ चालू/बंद; `Win + +` / `Win + -` → मैग्नीफायर ज़ूम; `Win + Esc` → मैग्नीफायर बंद।
उदाहरण: एक हाथ से `Ctrl + Alt + Del` दबाने के लिए स्टिकी कीज़ सक्षम करें।
अपवाद: गेम/फुल-स्क्रीन ऐप में ये हॉटकी अवरुद्ध हो सकती हैं।

## नियम 14: कमांड प्रॉम्प्ट / पावरशेल / विंडोज़ टर्मिनल में टेक्स्ट चयन/कॉपी/पेस्ट
**कमांड प्रॉम्प्ट/पावरशेल (लीगेसी कंसोल):** कीबोर्ड से मार्क मोड शुरू करने का कोई मानक `Ctrl + M` शॉर्टकट नहीं है — माउस से चयन करें या `Alt + Space → Edit → Mark` प्रयुक्त होता है।  
**विंडोज़ टर्मिनल (आधुनिक):** `Ctrl + Shift + M` → मार्क मोड टॉगल करता है (तीर कुंजियों से चयन); `Enter` → कॉपी; `Ctrl + V` / राइट-क्लिक → पेस्ट (विंडोज़ 10 1809+ में डिफ़ॉल्ट सक्षम)।  
उदाहरण: विंडोज़ टर्मिनल में लंबा आउटपुट चुनकर कॉपी करने के लिए `Ctrl + Shift + M`, तीर कुंजियाँ, `Enter`, फिर `Ctrl + V` से पेस्ट।  
अपवाद: लीगेसी कंसोल मोड सक्षम होने पर `Ctrl + V` काम नहीं करता; सेटिंग्स → प्रॉपर्टीज़ → "लीगेसी कंसोल उपयोग करें" अनचेक करें।

## नियम 15: शटडाउन/पावर मेन्यू: Win + X → U → U (शटडाउन), U → R (पुनरारंभ), U → S (स्लीप)
`Win + X` → क्विक लिंक मेन्यू; `U` → शटडाउन/साइन आउट सबमेन्यू; फिर अक्षर दबाएँ।
उदाहरण: माउस बिना तुरंत पुनरारंभ: `Win + X, U, R`।
अपवाद: `Alt + F4` डेस्कटॉप पर भी समान डायलॉग खोलता है; लैपटॉप पावर बटन सेटिंग्स (कंट्रोल पैनल → पावर विकल्प) इसे ओवरराइड कर सकती हैं।
