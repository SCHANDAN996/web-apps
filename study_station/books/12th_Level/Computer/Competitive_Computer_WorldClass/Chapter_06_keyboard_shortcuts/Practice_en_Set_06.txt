126. Which keyboard shortcut opens the Run dialog box in Windows?
(a) Windows + D (b) Windows + E (c) Windows + R (d) Windows + X
Answer: (c)
Solution: Many candidates confuse Windows + E, which opens File Explorer, with the Run dialog shortcut. The correct combination to open the Run dialog box directly is Windows + R, so the answer is Windows + R.
