26. Which keyboard shortcut opens the Run dialog box in Windows?
(a) Windows+E (b) Windows+X (c) Windows+D (d) Windows+R
Answer: (d)
Solution: Many users confuse the Run dialog with File Explorer (Windows+E) or the Quick Link menu (Windows+X), but the Run dialog is specifically launched with Windows+R, so the answer is Windows+R.
Source: Microsoft Support

27. In Microsoft Word, which shortcut applies bold formatting to selected text?
(a) Ctrl+I (b) Ctrl+U (c) Ctrl+B (d) Ctrl+Shift+B
Answer: (c)
Solution: The tempting wrong options are Ctrl+I for italic and Ctrl+U for underline, but bold formatting is applied with Ctrl+B, so the answer is Ctrl+B.
Source: Microsoft Support

28. What does the shortcut Alt+Tab do in Windows?
(a) Opens Task Manager (b) Closes the active window (c) Switches between open applications (d) Minimizes all windows
Answer: (c)
Solution: Alt+F4 closes the active window, Ctrl+Shift+Esc opens Task Manager, and Windows+M minimizes all windows; Alt+Tab cycles through open applications, so the answer is switches between open applications.
Source: Microsoft Support

29. Which shortcut selects the entire document in Microsoft Word?
(a) Ctrl+Y (b) Ctrl+S (c) Ctrl+Z (d) Ctrl+A
Answer: (d)
Solution: Ctrl+S saves the document, Ctrl+Z undoes the last action, and Ctrl+Y redoes the last undone action; selecting all content uses Ctrl+A, so the answer is Ctrl+A.
Source: Microsoft Support
