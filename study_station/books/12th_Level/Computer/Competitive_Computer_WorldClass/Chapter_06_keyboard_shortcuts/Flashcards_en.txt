Card 1
Front: What is the keyboard shortcut to open the Start Menu in Windows?
Back: Press the Windows key (⊞ Win) or Ctrl + Esc to open the Start Menu in Windows.

Card 2
Front: Which shortcut locks the computer instantly in Windows?
Back: Press ⊞ Win + L to lock the computer immediately.

Card 3
Front: How do you open File Explorer using a keyboard shortcut in Windows?
Back: Press ⊞ Win + E to open File Explorer.

Card 4
Front: What is the shortcut to open the Run dialog box in Windows?
Back: Press ⊞ Win + R to open the Run dialog box.

Card 5
Front: Which shortcut opens the Task Manager directly in Windows?
Back: Press Ctrl + Shift + Esc to open Task Manager directly.

Card 6
Front: How do you switch between open applications in Windows?
Back: Press Alt + Tab to cycle through open applications; hold Alt and press Tab repeatedly to select.

Card 7
Front: What is the shortcut to minimize all open windows and show the desktop in Windows?
Back: Press ⊞ Win + D to minimize all windows and show the desktop; press again to restore.

Card 8
Front: Which shortcut opens the Settings app in Windows 10/11?
Back: Press ⊞ Win + I to open the Settings app.

Card 9
Front: In Microsoft Word, what is the shortcut to save a document?
Back: Press Ctrl + S to save the current document in Microsoft Word (and most Office applications).

Card 10
Front: What is the shortcut to undo the last action in Microsoft Office applications?
Back: Press Ctrl + Z to undo the last action; press Ctrl + Y (or Ctrl + Shift + Z) to redo.

Card 11
Front: How do you apply bold formatting to selected text in Microsoft Word?
Back: Press Ctrl + B to toggle bold formatting on selected text.

Card 12
Front: What is the shortcut to open the Find dialog in Microsoft Word, Excel, and PowerPoint?
Back: Press Ctrl + F to open the Find dialog (or Navigation pane in newer versions).

Card 13
Front: In Microsoft Excel, which shortcut inserts a new worksheet?
Back: Press Shift + F11 to insert a new worksheet in the current workbook.

Card 14
Front: What is the shortcut to start a slide show from the beginning in Microsoft PowerPoint?
Back: Press F5 to start the slide show from the first slide; press Shift + F5 to start from the current slide.

Card 15
Front: In web browsers (Chrome, Edge, Firefox), what is the shortcut to open a new tab?
Back: Press Ctrl + T to open a new tab in most modern web browsers.

Card 16
Front: How do you reopen the last closed tab in a web browser?
Back: Press Ctrl + Shift + T to reopen the most recently closed tab; repeat to reopen earlier closed tabs.

Card 17
Front: What is the shortcut to refresh or reload the current web page in browsers?
Back: Press F5 or Ctrl + R to reload the current page; press Ctrl + F5 (or Shift + F5) for a hard refresh bypassing cache.

Card 18
Front: Which shortcut opens the browser's History page in Chrome and Edge?
Back: Press Ctrl + H to open the History page in Google Chrome and Microsoft Edge.
