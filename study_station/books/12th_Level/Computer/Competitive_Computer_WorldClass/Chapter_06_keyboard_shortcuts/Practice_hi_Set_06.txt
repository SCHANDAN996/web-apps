126. Windows में Run डायलॉग बॉक्स खोलने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Windows + D (b) Windows + E (c) Windows + R (d) Windows + X
उत्तर: (c)
हल: कई उम्मीदवार Windows + E को भ्रमित करते हैं, जो File Explorer खोलता है, Run डायलॉग शॉर्टकट के साथ। Run डायलॉग बॉक्स को सीधे खोलने के लिए सही संयोजन Windows + R है, इसलिए उत्तर Windows + R है।
