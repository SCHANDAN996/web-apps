**KEYBOARD SHORTCUTS — 25 REVISION POINTS**

1. **Ctrl + C / Ctrl + X / Ctrl + V** — Copy, Cut, Paste. Work across Windows Explorer, Office apps, browsers, and most editable fields.  
   *Source: Microsoft Support — Keyboard shortcuts in Windows*

2. **Ctrl + Z / Ctrl + Y** — Undo and Redo. Universal in Word, Excel, PowerPoint, Notepad, and browser text boxes.  
   *Source: Microsoft Support — Keyboard shortcuts in Office*

3. **Ctrl + A** — Select All. In Word selects entire document; in Excel selects current region (press again for whole sheet); in Explorer selects all files in folder.  
   *Source: Microsoft Support — Keyboard shortcuts in Windows*

4. **Ctrl + S** — Save. In Office apps saves current file; in browsers often opens “Save Page As” dialog.  
   *Source: Microsoft Support — Keyboard shortcuts in Office*

5. **Ctrl + P** — Print. Opens Print dialog in Office, browsers, Notepad, and most print-capable apps.  
   *Source: Microsoft Support — Keyboard shortcuts in Windows*

6. **Ctrl + F** — Find. Opens search/find pane in Word, Excel, PowerPoint, browsers, PDF readers, and Notepad.  
   *Source: Microsoft Support — Keyboard shortcuts in Office*

7. **Ctrl + H** — Replace. Opens Find & Replace dialog in Word, Excel, PowerPoint, and Notepad.  
   *Source: Microsoft Support — Keyboard shortcuts in Office*

8. **Ctrl + N** — New. Creates new document (Word), workbook (Excel), presentation (PowerPoint), window (Explorer), or **new window** (browser). Ctrl+T opens a new tab in browsers.  
   *Source: Microsoft Support — Keyboard shortcuts in Windows / Office; Microsoft Edge Keyboard Shortcuts / Chrome Keyboard Shortcuts*

9. **Ctrl + O** — Open. Opens file dialog in Office apps, browsers (for local files), and many editors.  
   *Source: Microsoft Support — Keyboard shortcuts in Office*

10. **Ctrl + W / Ctrl + F4** — Close current tab/document/window. In browsers closes tab; in Office closes document (prompts to save).  
    *Source: Microsoft Support — Keyboard shortcuts in Windows*

11. **Alt + F4** — Close active application window. If no app is focused, opens Windows shutdown dialog.  
    *Source: Microsoft Support — Keyboard shortcuts in Windows*

12. **Alt + Tab** — Switch between open applications. Hold Alt, press Tab repeatedly to cycle; release to select.  
    *Source: Microsoft Support — Keyboard shortcuts in Windows*

13. **Win + D** — Show/Hide Desktop (minimize/restore all windows).  
    *Source: Microsoft Support — Windows logo key shortcuts*

14. **Win + E** — Open File Explorer.  
    *Source: Microsoft Support — Windows logo key shortcuts*

15. **Win + L** — Lock PC / Switch user.  
    *Source: Microsoft Support — Windows logo key shortcuts*

16. **Win + R** — Open Run dialog.  
    *Source: Microsoft Support — Windows logo key shortcuts*

17. **Win + I** — Open Settings app (Windows 10/11).  
    *Source: Microsoft Support — Windows logo key shortcuts*

18. **Ctrl + Shift + Esc** — Open Task Manager directly.  
    *Source: Microsoft Support — Keyboard shortcuts in Windows*

19. **Ctrl + Shift + N** — Create new folder in File Explorer.  
    *Source: Microsoft Support — Keyboard shortcuts in Windows*

20. **F2** — Rename selected file/folder in Explorer; edit active cell in Excel.  
    *Source: Microsoft Support — Keyboard shortcuts in Windows / Excel*

21. **Ctrl + Arrow Keys** — In Word: move by word; in Excel: jump to edge of data region; in Explorer: navigate without selecting.  
    *Source: Microsoft Support — Keyboard shortcuts in Office*

22. **Ctrl + Home / Ctrl + End** — In Word: go to start/end of document; in Excel: go to cell A1 / last used cell.  
    *Source: Microsoft Support — Keyboard shortcuts in Office*

23. **Browser: Ctrl + T / Ctrl + Shift + T** — New tab / Reopen last closed tab. Work in Chrome, Edge, Firefox.  
    *Source: Microsoft Edge Keyboard Shortcuts / Chrome Keyboard Shortcuts*

24. **Browser: Ctrl + Tab / Ctrl + Shift + Tab** — Next tab / Previous tab.  
    *Source: Microsoft Edge Keyboard Shortcuts / Chrome Keyboard Shortcuts*

25. **Browser: Ctrl + L / F6 / Alt + D** — Focus address bar (Omnibox).  
    *Source: Microsoft Edge Keyboard Shortcuts / Chrome Keyboard Shortcuts*
