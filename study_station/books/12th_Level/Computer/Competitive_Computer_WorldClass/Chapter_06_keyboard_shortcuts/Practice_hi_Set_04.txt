76. Windows में Run डायलॉग बॉक्स खोलने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Windows + D (b) Windows + E (c) Windows + R (d) Windows + L
उत्तर: (c)
हल: लुभाने वाला गलत विकल्प Windows + E है, जो File Explorer खोलता है, Run डायलॉग नहीं। Windows + D डेस्कटॉप दिखाता है, और Windows + L कंप्यूटर लॉक करता है। Run डायलॉग के लिए सही शॉर्टकट Windows + R है।
स्रोत: PYQ-style

77. Microsoft Word में, चयनित टेक्स्ट पर बोल्ड फॉर्मेटिंग लागू करने के लिए कौन सा शॉर्टकट है?
(a) Ctrl + I (b) Ctrl + U (c) Ctrl + B (d) Ctrl + Shift + B
उत्तर: (c)
हल: लुभाने वाला गलत विकल्प Ctrl + I है, जो इटैलिक फॉर्मेटिंग लागू करता है, बोल्ड नहीं। Ctrl + U अंडरलाइन लागू करता है, और Ctrl + Shift + B बोल्ड के लिए मानक Word शॉर्टकट नहीं है। बोल्ड के लिए सही शॉर्टकट Ctrl + B है।
स्रोत: PYQ-style

78. Windows में Alt + Tab शॉर्टकट क्या करता है?
(a) Task Manager खोलता है (b) Start मेनू खोलता है (c) वर्तमान विंडो बंद करता है (d) खुले एप्लिकेशन के बीच स्विच करता है
उत्तर: (d)
हल: लुभाने वाला गलत विकल्प Alt + F4 है, जो वर्तमान विंडो बंद करता है, लेकिन वह यहाँ सूचीबद्ध नहीं है। Ctrl + Shift + Esc Task Manager खोलता है, और Windows की Start मेनू खोलती है। Alt + Tab खुले एप्लिकेशन के बीच चक्रित करता है।
स्रोत: PYQ-style

79. वेब ब्राउज़र (Chrome, Edge, Firefox) में, कौन सा शॉर्टकट नया टैब खोलता है?
(a) Ctrl + W (b) Ctrl + N (c) Ctrl + T (d) Ctrl + Shift + T
उत्तर: (c)
हल: लुभाने वाला गलत विकल्प Ctrl + N है, जो नई विंडो खोलता है, नया टैब नहीं। Ctrl + W वर्तमान टैब बंद करता है, और Ctrl + Shift + T अंतिम बंद टैब को फिर से खोलता है। नए टैब के लिए सही शॉर्टकट Ctrl + T है।
स्रोत: PYQ-style

80. कौन सा शॉर्टकट किसी दस्तावेज़ या विंडो में सभी सामग्री का चयन करता है?
(a) Ctrl + A (b) Ctrl + C (c) Ctrl + V (d) Ctrl + X
उत्तर: (a)
हल: लुभाने वाला गलत विकल्प Ctrl + C है, जो चयनित सामग्री को कॉपी करता है, लेकिन सब कुछ चयन नहीं करता। Ctrl + V पेस्ट करता है, और Ctrl + X कट करता है। सभी का चयन करने के लिए सार्वभौमिक शॉर्टकट Ctrl + A है।
स्रोत: PYQ-style

81. Windows में, Windows + E दबाने से कौन सा एप्लिकेशन खुलता है?
(a) File Explorer (b) Control Panel (c) Settings (d) Task Manager
उत्तर: (a)
हल: लुभाने वाला गलत विकल्प Windows + I है, जो Settings खोलता है, लेकिन वह सूचीबद्ध नहीं है। Windows + X क्विक लिंक मेनू खोलता है (Control Panel एक्सेस के साथ), और Ctrl + Shift + Esc Task Manager खोलता है। Windows + E सीधे File Explorer खोलता है।
स्रोत: PYQ-style

82. अधिकांश Windows एप्लिकेशन में अंतिम क्रिया को पूर्ववत (undo) करने का शॉर्टकट क्या है?
(a) Ctrl + Z (b) Ctrl + Y (c) Ctrl + U (d) Ctrl + Shift + Z
उत्तर: (a)
हल: लुभाने वाला गलत विकल्प Ctrl + Y है, जो पूर्ववत की गई क्रिया को फिर से करता (redo) है, पूर्ववत नहीं। Ctrl + U आमतौर पर वर्ड प्रोसेसर में अंडरलाइन लागू करता है, और Ctrl + Shift + Z कुछ ऐप्स में वैकल्पिक redo है। मानक undo शॉर्टकट Ctrl + Z है।
स्रोत: PYQ-style

83. Microsoft Excel में, कौन सा शॉर्टकट नई वर्कशीट डालता है?
(a) Ctrl + N (b) Alt + N (c) Shift + F11 (d) Ctrl + Shift + N
उत्तर: (c)
हल: लुभाने वाला गलत विकल्प Ctrl + N है, जो नई वर्कबुक बनाता है, वर्तमान वर्कबुक के भीतर नई वर्कशीट नहीं। Alt + N Insert टैब खोलता है, और Ctrl + Shift + N इसके लिए मानक Excel शॉर्टकट नहीं है। Shift + F11 नई वर्कशीट डालता है।
स्रोत: PYQ-style

84. कौन सा शॉर्टकट Windows कंप्यूटर को तुरंत लॉक करता है?
(a) Windows + X (b) Windows + D (c) Windows + K (d) Windows + L
उत्तर: (d)
हल: लुभाने वाला गलत विकल्प Windows + D है, जो डेस्कटॉप दिखाता है लेकिन सत्र लॉक नहीं करता। Windows + K वायरलेस डिस्प्ले के लिए Connect पेन खोलता है, और Windows + X क्विक लिंक मेनू खोलता है। Windows + L कंप्यूटर लॉक करता है।
स्रोत: PYQ-style

85. ब्राउज़र में, कौन सा शॉर्टकट हार्ड रीलोड करता है (कैश को अनदेखा करके)?
(a) F5 (b) Ctrl + F5 (c) Ctrl + R (d) Ctrl + Shift + F5
उत्तर: (b)
हल: लुभाने वाला गलत विकल्प F5 या Ctrl + R है, जो पेज रीलोड करते हैं लेकिन कैश्ड सामग्री का उपयोग कर सकते हैं। Ctrl + Shift + F5 मानक शॉर्टकट नहीं है। हार्ड रीलोड के लिए सही शॉर्टकट Ctrl + F5 है।
स्रोत: PYQ-style

86. Windows में Ctrl + Shift + Esc सीधे क्या खोलता है?
(a) Command Prompt (b) Task Manager (c) Run डायलॉग (d) System Properties
उत्तर: (b)
हल: लुभाने वाला गलत विकल्प Ctrl + Alt + Del है, जो एक सुरक्षा स्क्रीन खोलता है जहाँ से Task Manager लॉन्च किया जा सकता है, लेकिन सीधे नहीं। Windows + R Run खोलता है, और Windows + Pause/Break System Properties खोलता है। Ctrl + Shift + Esc सीधे Task Manager खोलता है।
स्रोत: PYQ-style

87. Microsoft Word में, कौन सा शॉर्टकट चयनित पैराग्राफ को केंद्र में संरेखित करता है?
(a) Ctrl + J (b) Ctrl + R (c) Ctrl + L (d) Ctrl + E
उत्तर: (d)
हल: लुभाने वाला गलत विकल्प Ctrl + J है, जो पैराग्राफ को जस्टिफाई करता है, केंद्र में नहीं। Ctrl + L बाएँ संरेखित करता है, और Ctrl + R दाएँ संरेखित करता है। केंद्र संरेखण के लिए शॉर्टकट Ctrl + E है।
स्रोत: PYQ-style

88. कौन सा शॉर्टकट डेस्कटॉप दिखाने को टॉगल करता है (सभी खुली विंडो को छोटा करता है और फिर से दबाने पर उन्हें पुनर्स्थापित करता है)?
(a) Windows + M (b) Windows + D (c) Windows + , (कॉमा) (d) Windows + Home
उत्तर: (b)
हल: लुभाने वाला गलत विकल्प Windows + M है, जो सभी विंडो को छोटा करता है लेकिन टॉगल नहीं करता — फिर से दबाने पर वे पुनर्स्थापित नहीं होतीं। Windows + , केवल डेस्कटॉप पर झाँकता है, और Windows + Home सक्रिय विंडो को छोड़कर सभी को छोटा करता है। Windows + D डेस्कटॉप दिखाने को टॉगल करता है।
स्रोत: PYQ-style

89. File Explorer में, कौन सा शॉर्टकट चयनित फ़ाइल या फ़ोल्डर का नाम बदलता है?
(a) F4 (b) F3 (c) F5 (d) F2

स्रोत: PYQ-style

स्रोत: PYQ-style

91. Windows में, कौन सा शॉर्टकट क्विक लिंक मेनू (पावर यूज़र मेनू) खोलता है?

93. Microsoft Excel में, कौन सा शॉर्टकट चयनित सेल पर करेंसी फॉर्मेट लागू करता है?

स्रोत: PYQ-style

100. Windows डेस्कटॉप पर बिना किसी एप्लिकेशन के फोकस के Alt + F4 दबाने का परिणाम क्या होता है?
(a) Task Manager खोलता है (b) शट डाउन Windows डायलॉग खोलता है (c) File Explorer बंद करता है (d) कुछ नहीं करता
उत्तर: (b)
हल: लुभाने वाला गलत विकल्प यह है कि Alt + F4 हमेशा सक्रिय विंडो बंद करता है, लेकिन डेस्कटॉप पर बिना किसी विंडो के फोकस के, यह शट डाउन Windows डायलॉग (शट डाउन / रीस्टार्ट / स्लीप आदि) लाता है। यह Task Manager नहीं खोलता, और File Explorer को तब तक बंद नहीं करता जब तक वह सक्रिय विंडो न हो। सही व्यवहार शट डाउन डायलॉग है।
स्रोत: PYQ-style
