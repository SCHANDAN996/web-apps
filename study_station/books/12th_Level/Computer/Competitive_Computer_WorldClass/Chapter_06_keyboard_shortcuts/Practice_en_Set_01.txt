1. Which keyboard shortcut copies the selected item to the clipboard in Windows?
(a) Ctrl+X (b) Ctrl+V (c) Ctrl+C (d) Ctrl+Z
Answer: (c)
Solution: The tempting wrong option is Ctrl+V, which pastes instead of copying; Ctrl+X cuts, and Ctrl+Z undoes, so the answer is Ctrl+C.
Source: Microsoft Support - Keyboard shortcuts in Windows

2. Which keyboard shortcut pastes the clipboard contents at the cursor position?

Answer: (a)
Solution: The tempting wrong option is Ctrl+C, which copies rather than pastes; Ctrl+X cuts, and Ctrl+Z undoes, so the answer is Ctrl+V.
Source: Microsoft Support - Keyboard shortcuts in Windows

3. Which keyboard shortcut cuts the selected item and places it on the clipboard?
(a) Ctrl+Z (b) Ctrl+V (c) Ctrl+C (d) Ctrl+X
Answer: (d)
Solution: The tempting wrong option is Ctrl+C, which only copies without removing the original; Ctrl+V pastes, and Ctrl+Z undoes, so the answer is Ctrl+X.

4. Which keyboard shortcut reverses the last action in most Windows applications?

Answer: (b)
Solution: The tempting wrong option is Ctrl+Y, which redoes an undone action but is not listed; among the given choices, Ctrl+Z is the standard undo shortcut, so the answer is Ctrl+Z.
