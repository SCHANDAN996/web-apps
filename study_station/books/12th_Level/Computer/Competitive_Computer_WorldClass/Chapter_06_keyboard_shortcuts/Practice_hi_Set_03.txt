51. Windows में File Explorer खोलने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Win+E (b) Win+R (c) Win+F (d) Win+X
उत्तर: (a)
हल: Win+F सर्च बॉक्स खोलता है, Win+R रन डायलॉग खोलता है, और Win+X क्विक लिंक मेनू खोलता है; Win+E File Explorer के लिए समर्पित शॉर्टकट है, इसलिए उत्तर Win+E है।
स्रोत: Microsoft Support — Windows keyboard shortcuts

52. Windows में Win+L शॉर्टकट क्या करता है?
(a) कंप्यूटर लॉक करता है (b) Task Manager खोलता है (c) सभी विंडो मिनिमाइज़ करता है (d) Settings खोलता है
उत्तर: (a)
हल: Win+I Settings खोलता है, Ctrl+Shift+Esc Task Manager खोलता है, और Win+D सभी विंडो मिनिमाइज़ करता है; Win+L तुरंत सत्र लॉक करता है, इसलिए उत्तर कंप्यूटर लॉक करता है।
स्रोत: Microsoft Support — Windows keyboard shortcuts

53. Microsoft Word में, कौन सा शॉर्टकट वर्तमान दस्तावेज़ को सेव करता है?

54. Microsoft Excel में AutoFilter को ऑन/ऑफ टॉगल करने वाला कौन सा शॉर्टकट है?
(a) Ctrl+Shift+F (b) Alt+Down Arrow (c) Ctrl+Shift+L (d) Ctrl+L
उत्तर: (c)

55. Microsoft PowerPoint में, कौन सी की स्लाइडशो को शुरुआत से शुरू करती है?

57. Windows में Alt+Tab क्या करता है?

59. कौन सी की Excel में सक्रिय सेल की सामग्री को सीधे संपादित करने की अनुमति देती है?
