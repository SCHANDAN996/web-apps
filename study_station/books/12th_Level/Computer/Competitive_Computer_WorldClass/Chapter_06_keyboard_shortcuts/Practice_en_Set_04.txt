76. Which keyboard shortcut opens the Run dialog box in Windows?
(a) Windows + D (b) Windows + E (c) Windows + R (d) Windows + L
Answer: (c)
Solution: The tempting wrong option is Windows + E, which opens File Explorer, not the Run dialog. Windows + D shows the desktop, and Windows + L locks the computer. The correct shortcut for the Run dialog is Windows + R.
Source: PYQ-style

77. In Microsoft Word, which shortcut applies bold formatting to selected text?
(a) Ctrl + I (b) Ctrl + U (c) Ctrl + B (d) Ctrl + Shift + B
Answer: (c)
Solution: The tempting wrong option is Ctrl + I, which applies italic formatting, not bold. Ctrl + U applies underline, and Ctrl + Shift + B is not a standard Word shortcut for bold. The correct shortcut for bold is Ctrl + B.
Source: PYQ-style

78. What does the shortcut Alt + Tab do in Windows?
(a) Opens Task Manager (b) Opens the Start menu (c) Closes the current window (d) Switches between open applications
Answer: (d)
Solution: The tempting wrong option is Alt + F4, which closes the current window, but that is not listed here. Ctrl + Shift + Esc opens Task Manager, and the Windows key opens the Start menu. Alt + Tab cycles through open applications.
Source: PYQ-style

79. In a web browser (Chrome, Edge, Firefox), which shortcut opens a new tab?
(a) Ctrl + W (b) Ctrl + N (c) Ctrl + T (d) Ctrl + Shift + T
Answer: (c)
Solution: The tempting wrong option is Ctrl + N, which opens a new window, not a new tab. Ctrl + W closes the current tab, and Ctrl + Shift + T reopens the last closed tab. The correct shortcut for a new tab is Ctrl + T.
Source: PYQ-style

80. Which shortcut selects all content in a document or window?
(a) Ctrl + A (b) Ctrl + C (c) Ctrl + V (d) Ctrl + X
Answer: (a)
Solution: The tempting wrong option is Ctrl + C, which copies selected content, but does not select everything. Ctrl + V pastes, and Ctrl + X cuts. The universal shortcut for Select All is Ctrl + A.
Source: PYQ-style

81. In Windows, pressing Windows + E opens which application?
(a) File Explorer (b) Control Panel (c) Settings (d) Task Manager
Answer: (a)
Solution: The tempting wrong option is Windows + I, which opens Settings, but that is not listed. Windows + X opens the Quick Link menu (with Control Panel access), and Ctrl + Shift + Esc opens Task Manager. Windows + E directly opens File Explorer.

82. What is the shortcut to undo the last action in most Windows applications?
(a) Ctrl + Z (b) Ctrl + Y (c) Ctrl + U (d) Ctrl + Shift + Z
Answer: (a)
Solution: The tempting wrong option is Ctrl + Y, which redoes an undone action, not undo. Ctrl + U typically applies underline in word processors, and Ctrl + Shift + Z is an alternative redo in some apps. The standard undo shortcut is Ctrl + Z.

83. In Microsoft Excel, which shortcut inserts a new worksheet?
(a) Ctrl + N (b) Alt + N (c) Shift + F11 (d) Ctrl + Shift + N
Answer: (c)
Solution: The tempting wrong option is Ctrl + N, which creates a new workbook, not a new worksheet within the current workbook. Alt + N opens the Insert tab, and Ctrl + Shift + N is not a standard Excel shortcut for this. Shift + F11 inserts a new worksheet.

(a) Command Prompt (b) Task Manager (c) Run dialog (d) System Properties
Answer: (b)
Solution: The tempting wrong option is Ctrl + Alt + Del, which opens a security screen from where Task Manager can be launched, but not directly. Windows + R opens Run, and Windows + Pause/Break opens System Properties. Ctrl + Shift + Esc opens Task Manager directly.

87. In Microsoft Word, which shortcut centers the selected paragraph?
(a) Ctrl + J (b) Ctrl + R (c) Ctrl + L (d) Ctrl + E
Answer: (d)
Solution: The tempting wrong option is Ctrl + J, which justifies the paragraph, not centers it. Ctrl + L aligns left, and Ctrl + R aligns right. The shortcut for center alignment is Ctrl + E.

88. Which shortcut toggles showing the desktop (minimizes all open windows and restores them when pressed again)?
(a) Windows + M (b) Windows + D (c) Windows + , (comma) (d) Windows + Home
Answer: (b)
Solution: The tempting wrong option is Windows + M, which minimizes all windows but does not toggle — pressing it again does not restore them. Windows + , only peeks at the desktop, and Windows + Home minimizes all except the active window. Windows + D toggles show desktop.

94. What does Windows + PrtScn do in Windows 10/11?

Answer: (d)

(a) Formula view (b) Gridlines (c) Headings (d) Full screen mode
Answer: (a)
Solution: The tempting wrong option is Ctrl + Shift + ` which does not exist as a standard toggle. View tab options control gridlines and headings, and there is no single shortcut for full screen in Excel. Ctrl + ` toggles between showing formulas and showing results in cells.

100. What is the result of pressing Alt + F4 on the Windows desktop with no application focused?
(a) Opens Task Manager (b) Opens Shut Down Windows dialog (c) Closes File Explorer (d) Does nothing
Answer: (b)
Solution: The tempting wrong option is that Alt + F4 always closes the active window, but on the desktop with no window focused, it brings up the Shut Down Windows dialog (Shut down / Restart / Sleep etc.). It does not open Task Manager, and it does not close File Explorer unless that is the active window. The correct behavior is the Shut Down dialog.
Source: PYQ-style
