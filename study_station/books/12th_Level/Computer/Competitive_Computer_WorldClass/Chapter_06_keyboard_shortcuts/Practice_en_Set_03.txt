51. Which keyboard shortcut opens File Explorer in Windows?
(a) Win+E (b) Win+R (c) Win+F (d) Win+X
Answer: (a)
Solution: Win+F opens the search box, Win+R opens the Run dialog, and Win+X opens the Quick Link menu; Win+E is the dedicated shortcut for File Explorer, so the answer is Win+E.
Source: Microsoft Support — Windows keyboard shortcuts

52. What does the Win+L shortcut do in Windows?
(a) Locks the computer (b) Opens Task Manager (c) Minimizes all windows (d) Opens Settings
Answer: (a)
Solution: Win+I opens Settings, Ctrl+Shift+Esc opens Task Manager, and Win+D minimizes all windows; Win+L immediately locks the session, so the answer is Locks the computer.
Source: Microsoft Support — Windows keyboard shortcuts
