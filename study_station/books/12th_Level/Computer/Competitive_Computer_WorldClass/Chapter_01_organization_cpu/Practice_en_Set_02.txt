26. What is the primary function of the ALU in CPU?
(a) Control clock speed (b) Store instructions (c) Manage I/O devices (d) Perform arithmetic and logical operations
Answer: (d)
Solution: Many candidates confuse the ALU with the control unit, but the ALU specifically performs arithmetic and logical operations, while the control unit generates control signals. So the answer is (d).
Source: PYQ-style

27. Which register holds the address of the next instruction to be fetched?
(a) Program Counter (b) Accumulator (c) Instruction Register (d) Stack Pointer
Answer: (a)
Solution: The Instruction Register holds the current instruction, not the next address; the Program Counter stores the address of the next instruction to be fetched. So the answer is (a).
Source: PYQ-style

28. In a typical von Neumann architecture, which bus carries data between CPU and memory?
(a) Data bus (b) Control bus (c) Address bus (d) Expansion bus
Answer: (a)
Solution: The address bus carries memory addresses, the control bus carries control signals, and the data bus carries the actual data between CPU and memory. So the answer is (a).
Source: PYQ-style

29. What is the purpose of the instruction decode stage in the fetch-decode-execute cycle?
(a) Retrieve instruction from memory (b) Update program counter (c) Write result to register (d) Determine operation and operands
Answer: (d)
Solution: The fetch stage retrieves the instruction; the decode stage interprets the opcode and identifies operands. So the answer is (d).
Source: PYQ-style

30. Which component of CPU generates control signals for instruction execution?

Solution: The ALU performs arithmetic/logic, while the Control Unit generates the necessary control signals for each instruction. So the answer is (c).

33. In pipelining, what is a hazard?
(a) A delay caused by instruction dependency (b) A type of cache miss (c) An error in ALU (d) A power failure
Answer: (a)
Solution: A pipeline hazard arises when an instruction depends on the result of a previous instruction that has not yet completed. So the answer is (a).
