51. Which component of the CPU performs arithmetic and logical operations?
(a) Arithmetic Logic Unit (b) Control Unit (c) Register Array (d) System Bus
Answer: (a)
Solution: The Control Unit directs operations but does not execute calculations; the Arithmetic Logic Unit (ALU) is specifically designed for arithmetic and logical tasks, so the answer is Arithmetic Logic Unit.

52. What is the primary function of the Program Counter (PC) register?
(a) Store the current instruction being executed (b) Manage interrupt priorities (c) Store the result of the last ALU operation (d) Hold the address of the next instruction to be fetched
Answer: (d)
Solution: The Instruction Register holds the current instruction; the Program Counter holds the address of the next instruction to maintain sequential execution, so the answer is Hold the address of the next instruction to be fetched.

53. In the fetch-decode-execute cycle, which step retrieves the instruction from memory?
(a) Decode (b) Fetch (c) Execute (d) Write-back
Answer: (b)
Solution: Decode interprets the instruction and Execute carries it out; Fetch is the dedicated step that reads the instruction from memory using the Program Counter, so the answer is Fetch.
