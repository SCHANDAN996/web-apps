26. OSI मॉडल की कौन सी परत तार्किक एड्रेसिंग और रूटिंग के लिए जिम्मेदार है?
(a) नेटवर्क परत (b) डेटा लिंक परत (c) भौतिक परत (d) ट्रांसपोर्ट परत
उत्तर: (a)
हल: डेटा लिंक परत भौतिक एड्रेसिंग (MAC) संभालती है, जबकि नेटवर्क परत तार्किक एड्रेसिंग (IP) और रूटिंग निर्णय संभालती है। ट्रांसपोर्ट परत एंड-टू-एंड डिलीवरी प्रबंधित करती है। इसलिए उत्तर नेटवर्क परत है।

27. TCP और UDP में प्राथमिक अंतर क्या है?
(a) TCP कनेक्शनलेस है; UDP कनेक्शन-ओरिएंटेड है (b) TCP डिलीवरी की गारंटी देता है; UDP नहीं देता (c) TCP पोर्ट नंबर उपयोग करता है; UDP नहीं करता (d) TCP UDP से तेज है
उत्तर: (b)
हल: UDP कनेक्शनलेस है और डिलीवरी, ऑर्डरिंग या त्रुटि पुनर्प्राप्ति की गारंटी नहीं देता, जिससे यह तेज लेकिन अविश्वसनीय होता है। TCP विश्वसनीय, क्रमबद्ध डिलीवरी प्रदान करता है। जाल यह सोचना है कि UDP पोर्ट का उपयोग नहीं करता — दोनों पोर्ट नंबर उपयोग करते हैं। इसलिए उत्तर है TCP डिलीवरी की गारंटी देता है; UDP नहीं देता।

32. DNS का प्राथमिक कार्य क्या है?
(a) IP एड्रेस डायनामिकली असाइन करना (b) वेब ट्रैफिक एन्क्रिप्ट करना (c) डोमेन नेम को IP एड्रेस में रिजॉल्व करना (d) नेटवर्क के बीच पैकेट रूट करना

33. कौन सा प्रोटोकॉल क्लाइंट द्वारा सर्वर से स्वचालित रूप से IP एड्रेस प्राप्त करने के लिए उपयोग किया जाता है?
(a) DNS (b) ICMP (c) ARP (d) DHCP
उत्तर: (d)
हल: DHCP (डायनामिक होस्ट कॉन्फिगरेशन प्रोटोकॉल) IP एड्रेस असाइनमेंट को स्वचालित करता है। DNS नेम रिजॉल्व करता है, ARP IP को MAC से मैप करता है, ICMP त्रुटि रिपोर्टिंग के लिए है (पिंग)। इसलिए उत्तर DHCP है।
स्रोत: Microsoft Learn — DHCP अवलोकन

34. ब्राउज़र और सर्वर के बीच डेटा एन्क्रिप्ट करने के लिए HTTPS किस प्रोटोकॉल का उपयोग करता है?
(a) केवल SSL (b) SSL/TLS (c) केवल TLS (d) SSH

स्रोत: Microsoft Learn — HTTPS

37. IPv6 एड्रेस कितने बिट्स लंबा होता है?
(a) 32 (b) 64 (c) 128 (d) 256

41. VLAN का प्राथमिक उद्देश्य क्या है?
(a) ब्रॉडकास्ट डोमेन को तार्किक रूप से सेगमेंट करना (b) भौतिक केबल लंबाई बढ़ाना (c) वायरलेस ट्रैफिक एन्क्रिप्ट करना (d) IP एड्रेस स्वचालित रूप से असाइन करना
उत्तर: (a)
हल: VLAN (वर्चुअल LAN) एक स्विच को अतिरिक्त हार्डवेयर के बिना कई ब्रॉडकास्ट डोमेन में तार्किक रूप से सेगमेंट करते हैं। वे ट्रैफिक एन्क्रिप्ट नहीं करते (वह WPA2/VPN है) या IP असाइन नहीं करते (वह DHCP है)। इसलिए उत्तर है ब्रॉडकास्ट डोमेन को तार्किक रूप से सेगमेंट करना।
स्रोत: Microsoft Learn — वर्चुअल LAN

42. कौन सी तकनीक निजी नेटवर्क पर कई उपकरणों को एक ही पब्लिक IP एड्रेस साझा करने की अनुमति देती है?

उत्तर: (d)
हल: QoS ट्रैफिक (वॉयस, वीडियो, डेटा) को वर्गीकृत और प्राथमिकता देता है ताकि महत्वपूर्ण एप्लिकेशन के लिए प्रदर्शन सुनिश्चित हो सके। यह IP असाइन नहीं करता, नेम रिजॉल्व नहीं करता, या एन्क्रिप्ट नहीं करता। इसलिए उत्तर है ट्रैफिक प्राथमिकता और बैंडविड्थ आवंटन।

50. क्लाउड नेटवर्किंग में, VPC (वर्चुअल प्राइवेट क्लाउड) क्या है?
(a) एक भौतिक डेटा सेंटर (b) एक VPN प्रोटोकॉल (c) एक पब्लिक क्लाउड का तार्किक रूप से अलग किया गया खंड (d) एक प्रकार का लोड बैलेंसर
उत्तर: (c)
हल: एक VPC एक पब्लिक क्लाउड प्रोवाइडर (AWS, Azure, GCP) के भीतर एक तार्किक रूप से अलग वर्चुअल नेटवर्क है, जो IP रेंज, सबनेट, रूटिंग पर नियंत्रण देता है। यह भौतिक हार्डवेयर, VPN प्रोटोकॉल, या लोड बैलेंसर नहीं है। इसलिए उत्तर है एक पब्लिक क्लाउड का तार्किक रूप से अलग किया गया खंड।
