1. Which layer of the OSI model is responsible for logical addressing and routing?
(a) Physical (b) Data Link (c) Transport (d) Network
Answer: (d)
Solution: The Physical layer deals with bits, the Data Link layer handles MAC addressing, and the Transport layer manages end‑to‑end delivery; logical addressing (IP addresses) and routing are functions of the Network layer, so the correct answer is "Network".

3. Which protocol provides connection‑oriented reliable data transfer in the TCP/IP suite?
(a) TCP (b) IP (c) UDP (d) ICMP
Answer: (a)
Solution: UDP is connectionless, IP handles addressing and routing, ICMP is for control messages; TCP establishes a connection and guarantees delivery, so the correct answer is "TCP".

4. In IPv4, how many bits are used for the network portion in a /24 subnet mask?

5. Which device operates primarily at the Data Link layer and forwards frames based on MAC addresses?
(a) Hub (b) Router (c) Repeater (d) Switch
Answer: (d)
Solution: A hub repeats signals to all ports, a router works at Network layer, a repeater only regenerates signals; a switch learns MAC addresses and forwards frames accordingly, so the correct answer is "Switch".
