126. Which layer of the OSI model is responsible for logical addressing and routing?
(a) Physical layer (b) Data Link layer (c) Transport layer (d) Network layer
Answer: (d)
Solution: The Data Link layer handles physical addressing (MAC), while the Network layer handles logical addressing (IP) and routing; the Physical layer deals with bits and the Transport layer with end-to-end delivery, so the answer is Network layer.
Source: NCERT Class 12 Computer Science

127. What is the default subnet mask for a Class B IPv4 address?
(a) 255.0.0.0 (b) 255.255.0.0 (c) 255.255.255.0 (d) 255.255.255.255
Answer: (b)
Solution: Class A uses 255.0.0.0, Class C uses 255.255.255.0, and 255.255.255.255 is a limited broadcast; Class B defaults to 255.255.0.0, so the answer is 255.255.0.0.
Source: Microsoft Learn – IPv4 addressing

128. Which protocol operates at the Transport layer and provides connectionless, unreliable delivery?
(a) TCP (b) ICMP (c) IP (d) UDP

129. What is the maximum data size of an Ethernet frame (excluding preamble and FCS)?
(a) 9000 bytes (b) 1518 bytes (c) 1522 bytes (d) 1500 bytes

130. Which device operates at the Data Link layer and forwards frames based on MAC addresses?

132. Which IPv4 address range is reserved for private networks in Class A?

141. What is the maximum number of hosts in a /26 IPv4 subnet?
