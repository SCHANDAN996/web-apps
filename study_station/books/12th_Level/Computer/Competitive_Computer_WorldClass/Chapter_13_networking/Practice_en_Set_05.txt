101. Which layer of the OSI model is responsible for logical addressing and routing?
(a) Physical (b) Data Link (c) Network (d) Transport
Answer: (c)
Solution: The tempting wrong option is Data Link because it handles framing and MAC addressing, but logical addressing and routing are functions of the Network layer, so the answer is C.
Source: PYQ-style

102. In the TCP/IP model, which protocol provides reliable, connection‑oriented data transfer?
(a) ICMP (b) UDP (c) IP (d) TCP
Answer: (d)
Solution: The tempting wrong option is UDP because it is also a transport protocol, but UDP is connectionless and unreliable, whereas TCP guarantees delivery, so the answer is A.
Source: PYQ-style

103. What is the default subnet mask for a Class C IPv4 network?
(a) 255.0.0.0 (b) 255.255.255.0 (c) 255.255.0.0 (d) 255.255.255.255
Answer: (b)
Solution: The tempting wrong option is 255.255.0.0 which belongs to Class B, but Class C uses 24 network bits giving 255.255.255.0, so the answer is C.
