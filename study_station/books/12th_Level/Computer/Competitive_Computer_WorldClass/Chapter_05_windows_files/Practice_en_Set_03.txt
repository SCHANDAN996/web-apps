51. Which keyboard shortcut opens File Explorer in Windows 10 and Windows 11?
(a) Windows + E (b) Ctrl + E (c) Alt + E (d) Shift + E
Answer: (a)
Solution: Many candidates confuse Ctrl + E (which focuses the search/address bar inside an already-open File Explorer) with the global shortcut that launches File Explorer from anywhere; the correct global shortcut is Windows + E, so the answer is Windows + E.
Source: Microsoft Support - Windows keyboard shortcuts
