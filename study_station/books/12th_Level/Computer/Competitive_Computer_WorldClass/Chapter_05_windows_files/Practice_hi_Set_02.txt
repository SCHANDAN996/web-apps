26. आधुनिक Windows इंस्टॉलेशन में आंतरिक ड्राइव के लिए डिफ़ॉल्ट फाइल सिस्टम कौन सा है?
(a) FAT32 (b) exFAT (c) ReFS (d) NTFS
उत्तर: (d)
हल: FAT32 अधिकतम 4 GB फ़ाइल आकार तक सीमित है और इसमें आधुनिक सुरक्षा सुविधाओं का अभाव है, जो इसे डिफ़ॉल्ट सिस्टम ड्राइव फॉर्मेट के लिए अनुपयुक्त बनाता है; NTFS बड़े वॉल्यूम, फ़ाइल-स्तरीय अनुमतियाँ, एन्क्रिप्शन और जर्नलिंग का समर्थन करता है, इसलिए उत्तर NTFS है।
स्रोत: Microsoft Learn – File Systems Overview

27. FAT32 द्वारा समर्थित अधिकतम व्यक्तिगत फ़ाइल आकार क्या है?
(a) 4 GB (b) 2 GB (c) 8 GB (d) 16 GB
उत्तर: (a)
हल: 4 GB की सीमा FAT32 डायरेक्ट्री एंट्री में 32-बिट फ़ाइल लंबाई फ़ील्ड से आती है; exFAT और NTFS इस प्रतिबंध को हटाते हैं, इसलिए उत्तर 4 GB है।
स्रोत: Microsoft Support – FAT32 Specification

28. कौन सा एट्रिब्यूट किसी फ़ाइल को सामान्य डायरेक्ट्री लिस्टिंग में तब तक प्रदर्शित होने से रोकता है जब तक "Hidden items" सक्षम न हो?
(a) Hidden (b) System (c) Read-only (d) Archive
उत्तर: (a)
हल: Read-only एट्रिब्यूट केवल लेखन को ब्लॉक करता है; Hidden एट्रिब्यूट विशेष रूप से एक्सप्लोरर और /a:h के बिना dir कमांड में दृश्यता को नियंत्रित करता है, इसलिए उत्तर Hidden है।
स्रोत: Microsoft Learn – File Attributes

29. जब आप किसी फ़ाइल को एक NTFS वॉल्यूम से दूसरे NTFS वॉल्यूम पर ड्रैग करते हैं, तो डिफ़ॉल्ट रूप से कौन सा ऑपरेशन होता है?
(a) Move (b) विकल्प के लिए संकेत (c) शॉर्टकट बनाएँ (d) Copy
उत्तर: (d)
हल: समान वॉल्यूम के भीतर ड्रैग करने पर फ़ाइल मूव होती है; वॉल्यूम के बीच ड्रैग करने पर यह कॉपी होती है — एक सामान्य जाल यह मानना है कि हर जगह मूव होता है, इसलिए उत्तर Copy है।
स्रोत: Microsoft Support – Drag-and-Drop Behavior

30. Windows में फाइल एक्सप्लोरर खोलने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Ctrl+E (b) Shift+E (c) Alt+E (d) Win+E
उत्तर: (d)
हल: Ctrl+E कई ऐप्स में सर्च/एड्रेस बार पर फोकस करता है जिसमें ब्राउज़र शामिल हैं; Win+E फाइल एक्सप्लोरर के लिए सिस्टम-वाइड शॉर्टकट है, इसलिए उत्तर Win+E है।
स्रोत: Microsoft Support – Windows Keyboard Shortcuts

31. जब किसी फ़ाइल पर "Archive" एट्रिब्यूट सेट होता है तो यह क्या दर्शाता है?
(a) फ़ाइल अंतिम बैकअप के बाद संशोधित हुई है (b) फ़ाइल रीड-ओनली है (c) फ़ाइल एन्क्रिप्टेड है (d) फ़ाइल संपीड़ित है
उत्तर: (a)
हल: बैकअप सॉफ़्टवेयर पारंपरिक रूप से बैकअप के बाद Archive एट्रिब्यूट को क्लियर करता है; यह फ़ाइल बदलने पर स्वचालित रूप से सेट होता है, संपीड़न या एन्क्रिप्शन द्वारा नहीं, इसलिए उत्तर फ़ाइल अंतिम बैकअप के बाद संशोधित हुई है।
स्रोत: Microsoft Learn – File Attribute Constants

32. कमांड प्रॉम्प्ट में कौन सी कमांड ड्राइव की पूर्ण डायरेक्ट्री ट्री प्रदर्शित करती है?
(a) dir /s (b) dir /tree (c) tree (d) list
उत्तर: (c)
हल: dir /s फ़ाइलों को रिकर्सिवली सूचीबद्ध करता है लेकिन ट्री डायग्राम में नहीं; tree कमांड लाइन कैरेक्टर्स का उपयोग करके पदानुक्रमित संरचना बनाता है, इसलिए उत्तर tree है।
स्रोत: Microsoft Learn – Tree Command

33. NTFS में, कौन सी अनुमति किसी उपयोगकर्ता को फ़ोल्डर की सामग्री सूचीबद्ध किए बिना सबफ़ोल्डर्स में फ़ाइलों तक पहुँचने के लिए फ़ोल्डर को पार करने की अनुमति देती है?
(a) Read (b) Traverse folder / Execute file (c) List folder contents (d) Read & execute
उत्तर: (b)
हल: "List folder contents" नाम दिखाता है; "Traverse folder / Execute file" विशेष रूप से पैरेंट की लिस्टिंग देखे बिना फ़ोल्डर के माध्यम से गहरी वस्तुओं तक पहुँचने की अनुमति देता है, इसलिए उत्तर Traverse folder / Execute file है।
स्रोत: Microsoft Learn – NTFS Permissions

34. किसी फ़ोल्डर पर NTFS संपीड़न सक्षम करने का क्या प्रभाव होता है?
(a) केवल नई फ़ाइलें संपीड़ित होती हैं (b) मौजूदा फ़ाइलें संपीड़ित होती हैं; नई फ़ाइलें संपीड़न विरासत में प्राप्त करती हैं (c) फ़ोल्डर रीड-ओनली बन जाता है (d) फ़ोल्डर एन्क्रिप्ट हो जाता है
उत्तर: (b)
हल: NTFS संपीड़न मौजूदा फ़ाइलों पर लागू होता है और फ़ोल्डर पर संपीड़न एट्रिब्यूट सेट करता है ताकि नई बनाई गई फ़ाइलें भी संपीड़ित हों; यह एन्क्रिप्ट या रीड-ओनली नहीं बनाता, इसलिए उत्तर मौजूदा फ़ाइलें संपीड़ित होती हैं; नई फ़ाइलें संपीड़न विरासत में प्राप्त करती हैं।
स्रोत: Microsoft Learn – NTFS Compression

35. Windows शॉर्टकट (लिंक) फ़ाइल के लिए कौन सा फ़ाइल एक्सटेंशन उपयोग किया जाता है?
(a) .shortcut (b) .url (c) .lnk (d) .link

स्रोत: Microsoft Learn – Shell Links

36. जब आप Shift+Delete का उपयोग करके NTFS वॉल्यूम से कोई फ़ाइल डिलीट करते हैं तो क्या होता है?
(a) रीसायकल बिन में जाता है (b) फ़ाइल संपीड़ित होती है (c) बैकअप कॉपी बनती है (d) रीसायकल बिन को बायपास करके स्थायी रूप से डिलीट हो जाती है

हल: सामान्य Delete रीसायकल बिन में भेजता है; Shift+Delete फ़ाइल एंट्री को तुरंत रीसायकल बिन की भागीदारी के बिना हटा देता है, इसलिए उत्तर रीसायकल बिन को बायपास करके स्थायी रूप से डिलीट हो जाती है।
स्रोत: Microsoft Support – Delete Files Permanently

37. Windows में डिस्क पार्टीशन बनाने और प्रबंधित करने वाला कौन सा टूल है?
(a) Disk Cleanup (b) Disk Management (c) Disk Defragmenter (d) Storage Sense
उत्तर: (b)
हल: Disk Cleanup स्थान खाली करता है; Defragmenter लेआउट ऑप्टिमाइज़ करता है; Storage Sense स्वचालित सफाई करता है; केवल Disk Management (diskmgmt.msc) पार्टीशन बनाता, हटाता, फॉर्मेट और रिसाइज़ करता है, इसलिए उत्तर Disk Management है।
स्रोत: Microsoft Learn – Disk Management

38. सिस्टम ड्राइव पर pagefile.sys फ़ाइल का उद्देश्य क्या है?
(a) RAM भर जाने पर वर्चुअल मेमोरी के रूप में कार्य करता है (b) Windows अपडेट फ़ाइलें रखता है (c) उपयोगकर्ता दस्तावेज़ संग्रहीत करता है (d) बूट कॉन्फ़िगरेशन रखता है
उत्तर: (a)
हल: pagefile.sys वर्चुअल मेमोरी के रूप में उपयोग की जाने वाली पेजिंग फ़ाइल है; यह दस्तावेज़ों, अपडेट या बूट कॉन्फ़िगरेशन के लिए नहीं है (जो BCD है), इसलिए उत्तर RAM भर जाने पर वर्चुअल मेमोरी के रूप में कार्य करता है।
स्रोत: Microsoft Learn – Virtual Memory

39. कौन सा एनवायरनमेंट वेरिएबल वर्तमान उपयोगकर्ता के प्रोफ़ाइल फ़ोल्डर का पथ रखता है?

41. Windows में फ़ोल्डर पर "Read-only" एट्रिब्यूट वास्तव में क्या करता है?
(a) फ़ोल्डर को रीनेम होने से रोकता है (b) फ़ोल्डर को सिस्टम फ़ोल्डर के रूप में चिह्नित करता है (c) अंदर की किसी भी फ़ाइल को संशोधित होने से रोकता है (d) Windows फ़ोल्डर्स के लिए इसे अनदेखा करता है; केवल फ़ाइलों पर लागू होता है

49. कौन सी सुविधा नया पार्टीशन बनाए बिना किसी फ़ोल्डर को ड्राइव लेटर के रूप में माउंट करने की अनुमति देती है?
(a) Subst (b) Diskpart (c) Mountvol (d) Junction
उत्तर: (a)
हल: subst किसी पथ को ड्राइव लेटर से मैप करता है; mountvol वॉल्यूम माउंट पॉइंट प्रबंधित करता है; junction डायरेक्ट्री जंक्शन (रिपार्स पॉइंट) बनाता है; diskpart पार्टीशन प्रबंधित करता है, इसलिए उत्तर Subst है।
स्रोत: Microsoft Learn – Subst Command

50. बैच फ़ाइल में, कौन सा वेरिएबल बैच स्क्रिप्ट का पूर्ण पथ रखता है?
(a) %0 (b) %~dp0 (c) %* (d) %1
उत्तर: (b)
हल: %0 स्क्रिप्ट का नाम है जैसा आमंत्रित किया गया; %~dp0 स्क्रिप्ट के ड्राइव और पथ तक विस्तारित होता है (केवल डायरेक्ट्री); %1 पहला आर्गुमेंट है; %* सभी आर्गुमेंट्स हैं, इसलिए उत्तर %~dp0 है।
स्रोत: Microsoft Learn – Batch File Parameters
