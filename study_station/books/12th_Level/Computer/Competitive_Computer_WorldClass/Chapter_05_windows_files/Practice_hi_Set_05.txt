101. Windows में File Explorer खोलने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Ctrl + E (b) Shift + E (c) Alt + E (d) Win + E
उत्तर: (d)
हल: कई उपयोगकर्ता Ctrl+E (जो पहले से खुले Explorer में सर्च/एड्रेस बार पर फोकस करता है) को ग्लोबल शॉर्टकट समझ लेते हैं; Windows-key कॉम्बिनेशन Win+E सीधे एक नई File Explorer विंडो लॉन्च करता है, इसलिए उत्तर Win + E है।
स्रोत: Microsoft Learn – Windows keyboard shortcuts

102. File Explorer में किसी फाइल पर Delete दबाने पर क्या होता है?
(a) फाइल तुरंत स्थायी रूप से मिट जाती है (b) फाइल Recycle Bin में चली जाती है (c) फाइल ZIP आर्काइव में कंप्रेस हो जाती है (d) फाइल अपने आप रीनेम हो जाती है
उत्तर: (b)
हल: एक आम जाल यह सोचना है कि Delete फाइल को हमेशा के लिए हटा देता है; डिफ़ॉल्ट रूप से Windows फाइल को Recycle Bin में भेजता है ताकि उसे रिस्टोर किया जा सके, इसलिए उत्तर Recycle Bin में चली जाती है।
स्रोत: Microsoft Support – Delete files or folders in File Explorer

103. कौन सा की कॉम्बिनेशन किसी चयनित फाइल को Recycle Bin को बायपास करके स्थायी रूप से डिलीट करता है?
(a) Alt + Delete (b) Ctrl + Delete (c) Shift + Delete (d) Win + Delete
उत्तर: (c)
हल: उपयोगकर्ता अक्सर Ctrl+Delete (जो कुछ खास नहीं करता) या Alt+Delete आज़माते हैं; दस्तावेज़ीकृत शॉर्टकट जो Recycle Bin को छोड़ देता है वह Shift+Delete है, इसलिए उत्तर Shift + Delete है।
स्रोत: Microsoft Learn – Keyboard shortcuts in Windows

104. File Explorer में कौन सा व्यू फाइल नामों को छोटे आइकन और आकार व संशोधन तिथि जैसे विवरण के साथ दिखाता है?
(a) Details (b) List (c) Tiles (d) Content
उत्तर: (a)
हल: Details व्यू विशेष रूप से Name, Date modified, Type और Size जैसे कॉलम प्रदर्शित करने के लिए डिज़ाइन किया गया है; List और Tiles कम मेटाडेटा दिखाते हैं, इसलिए उत्तर Details है।
स्रोत: Microsoft Support – Change the view of a folder in File Explorer

105. File Explorer में Quick Access टूलबार की डिफ़ॉल्ट लोकेशन क्या है?
(a) निचला-बायाँ कोना (b) एड्रेस बार के दाईं ओर (c) रिबन के ऊपर ऊपर-बायाँ कोना (d) नेविगेशन पेन के अंदर
उत्तर: (c)
हल: कुछ उम्मीदवार नेविगेशन पेन में Quick Access *फोल्डर* को Quick Access *टूलबार* (जिसमें पिन किए गए कमांड होते हैं) समझ लेते हैं; टूलबार डिफ़ॉल्ट रूप से रिबन के ऊपर होता है, इसलिए उत्तर ऊपर-बायाँ कोना, रिबन के ऊपर है।
स्रोत: Microsoft Learn – Customize the Quick Access Toolbar

106. कौन सा फाइल एट्रिब्यूट दर्शाता है कि फाइल को बैकअप सॉफ़्टवेयर द्वारा बैकअप किया जाना चाहिए?
(a) Read-only (b) Hidden (c) System (d) Archive
उत्तर: (d)
हल: Archive एट्रिब्यूट फाइल बदलने पर अपने आप सेट हो जाता है और बैकअप प्रोग्राम कॉपी करने के बाद इसे क्लियर कर देते हैं; Read-only और Hidden अलग उद्देश्य पूरा करते हैं, इसलिए उत्तर Archive है।
स्रोत: Microsoft Learn – File attribute constants

107. File Explorer में एकाधिक नॉन-एडजेसेंट (गैर-आसन्न) फाइलों को कैसे चुनते हैं?
(a) Ctrl दबाकर प्रत्येक फाइल पर क्लिक करें (b) Shift दबाकर प्रत्येक फाइल पर क्लिक करें (c) Alt दबाकर प्रत्येक फाइल पर क्लिक करें (d) उनके चारों ओर आयत खींचें
उत्तर: (a)
हल: Shift+click एक सन्निहित रेंज चुनता है; Ctrl+click व्यक्तिगत फाइलों को टॉगल करता है बिना दूसरों को प्रभावित किए, जो इसे नॉन-एडजेसेंट चयन की सही विधि बनाता है, इसलिए उत्तर Ctrl दबाकर प्रत्येक फाइल पर क्लिक करें है।
स्रोत: Microsoft Support – Select multiple files or folders

108. जब आप ZIP फाइल पर राइट-क्लिक करके "Extract All" कमांड देते हैं तो क्या होता है?
(a) उसी नाम का एक फोल्डर बनाता है और सामग्री वहाँ कॉपी करता है (b) सामग्री कॉपी करने के बाद ZIP फाइल डिलीट कर देता है (c) ZIP फाइल को और कंप्रेस करता है (d) ZIP फाइल को Recycle Bin में ले जाता है
उत्तर: (a)
हल: एक लुभावना गलत विकल्प यह है कि यह आर्काइव को डिलीट कर देता है; Windows वास्तव में एक नया फोल्डर (आमतौर पर ZIP के नाम पर) बनाता है और निकाली गई फाइलें वहाँ रखता है, मूल ZIP को बरकरार रखते हुए, इसलिए उत्तर उसी नाम का एक फोल्डर बनाता है और सामग्री वहाँ कॉपी करता है।
स्रोत: Microsoft Support – Zip and unzip files

109. कौन सा पथ प्रारूप Windows में एक वैध एब्सोल्यूट पथ है?
(a) Documents\Report.docx (b) ..\Report.docx (c) C:\Users\Name\Documents\Report.docx (d) ~\Report.docx
उत्तर: (c)
हल: Documents\Report.docx या ..\Report.docx जैसे रिलेटिव पथ करंट डायरेक्टरी पर निर्भर करते हैं; केवल ड्राइव लेटर और रूट बैकस्लैश से शुरू होने वाला पथ एब्सोल्यूट होता है, इसलिए उत्तर C:\Users\Name\Documents\Report.docx है।
स्रोत: Microsoft Learn – File path formats on Windows systems

110. File Explorer में "Libraries" फीचर का क्या कार्य है?
(a) फाइलों को स्वचालित रूप से एन्क्रिप्ट करता है (b) जगह बचाने के लिए फोल्डरों को कंप्रेस करता है (c) अलग-अलग स्थानों के फोल्डरों को एक ही व्यू में समूहित करता है (d) डेस्कटॉप पर शॉर्टकट बनाता है
उत्तर: (c)
हल: Libraries फाइलों को मूव या कंप्रेस नहीं करतीं; वे शामिल फोल्डरों (जैसे Documents, Pictures) का एक वर्चुअल एग्रीगेटेड व्यू प्रदान करती हैं चाहे भौतिक स्थान कुछ भी हो, इसलिए उत्तर अलग-अलग स्थानों के फोल्डरों को एक ही व्यू में समूहित करता है।
स्रोत: Microsoft Support – Include folders in a library

116. पारंपरिक Windows फाइल पथ (MAX_PATH) की अधिकतम लंबाई क्या है?
(a) 128 कैरेक्टर (b) 512 कैरेक्टर (c) 260 कैरेक्टर (d) 1024 कैरेक्टर
उत्तर: (c)
हल: क्लासिक MAX_PATH सीमा 260 कैरेक्टर है (ड्राइव लेटर, कोलन, बैकस्लैश, पथ के लिए 256 कैरेक्टर, और नल टर्मिनेटर); लॉन्ग-पाथ सपोर्ट Group Policy के माध्यम से सक्षम किया जा सकता है, लेकिन डिफ़ॉल्ट 260 ही रहता है, इसलिए उत्तर 260 कैरेक्टर है।
स्रोत: Microsoft Learn – Naming files, paths, and namespaces

122. कौन सी NTFS परमिशन उपयोगकर्ता को फाइलों और सबफोल्डर्स तक पहुँचने के लिए फोल्डर को पार करने की अनुमति देती है लेकिन फोल्डर की सामग्री सूचीबद्ध नहीं करने देती?

123. Windows 10 और बाद के संस्करणों में "Compact OS" फीचर क्या करता है?
(a) पूरे ड्राइव को NTFS कंप्रेशन से कंप्रेस करता है (b) सिस्टम फाइलों को कंप्रेस्ड स्टेट में संग्रहीत करके डिस्क स्पेस बचाता है (c) OS के लिए एक कॉम्पैक्ट वर्चुअल हार्ड डिस्क बनाता है (d) अनुपयोगी Windows घटकों को स्वचालित रूप से हटा देता है
उत्तर: (b)
हल: Compact OS व्यक्तिगत सिस्टम फाइलों को कंप्रेस करता है (पूरे वॉल्यूम को नहीं) और उन्हें अलग WIMBoot कंटेनर के बिना उपयोग योग्य रखता है; यह घटकों को नहीं हटाता, इसलिए उत्तर सिस्टम फाइलों को कंप्रेस्ड स्टेट में संग्रहीत करके डिस्क स्पेस बचाता है।

124. कौन सा कमांड-लाइन टूल भ्रष्ट संस्करणों को कैश्ड कॉपियों से बदलकर Windows सिस्टम फाइलों की मरम्मत करता है?
(a) chkdsk (b) sfc /scannow (c) dism /online /cleanup-image /restorehealth (d) diskpart
उत्तर: (b)
हल: chkdsk फाइल सिस्टम की जाँच करता है, DISM कंपोनेंट स्टोर की मरम्मत करता है, और diskpart पार्टीशन प्रबंधित करता है; sfc /scannow विशेष रूप से स्थानीय कैश से संरक्षित सिस्टम फाइलों को स्कैन और प्रतिस्थापित करता है, इसलिए उत्तर sfc /scannow है।

125. Robocopy का उपयोग करते समय, कौन सा स्विच सोर्स डायरेक्टरी को डेस्टिनेशन पर मिरर करता है (डेस्टिनेशन में अतिरिक्त फाइलों को डिलीट सहित)?
(a) /E (b) /Z (c) /COPYALL (d) /MIR
उत्तर: (d)
हल: /E खाली सबडायरेक्टरीज़ सहित कॉपी करता है लेकिन डेस्टिनेशन एक्स्ट्रा को पर्ज नहीं करता; /MIR में /E और /PURGE दोनों निहित हैं, जिससे डेस्टिनेशन एक सटीक मिरर बन जाता है, इसलिए उत्तर /MIR है।
