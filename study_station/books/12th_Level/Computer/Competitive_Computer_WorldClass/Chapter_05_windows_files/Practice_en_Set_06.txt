126. Which keyboard shortcut opens File Explorer in Windows 10 and Windows 11?
(a) Ctrl + E (b) Shift + E (c) Alt + E (d) Win + E
Answer: (d)
Solution: Ctrl + E focuses the search/address bar inside an already-open Explorer window, while Win + E launches a new File Explorer window from anywhere in Windows. So the correct shortcut is Win + E.

139. Which file system feature allows a single file to have multiple directory entries (names) on the same NTFS volume without duplicating data?
