126. Windows 10 और Windows 11 में File Explorer खोलने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Ctrl + E (b) Shift + E (c) Alt + E (d) Win + E
उत्तर: (d)
हल: Ctrl + E पहले से खुले Explorer विंडो के अंदर सर्च/एड्रेस बार पर फोकस करता है, जबकि Win + E Windows में कहीं से भी एक नया File Explorer विंडो लॉन्च करता है। इसलिए सही शॉर्टकट Win + E है।
स्रोत: Microsoft Learn — Windows keyboard shortcuts

127. File Explorer में, कौन सा व्यू लेआउट बड़े आइकन दिखाता है जिनके नीचे फाइल नाम होते हैं और जो फोटो प्रीव्यू के लिए सबसे अच्छा है?
(a) Large icons (b) List (c) Details (d) Content
उत्तर: (a)
हल: Details व्यू कॉलम दिखाता है (Name, Date, Size); List व्यू छोटे आइकन कॉलम में दिखाता है; Content व्यू मीडियम आइकन के साथ मेटाडेटा का स्निपेट दिखाता है। Large icons बड़े थंबनेल दिखाता है जो फोटो के लिए आदर्श है। इसलिए उत्तर Large icons है।
स्रोत: Microsoft Support — Change the view of files in File Explorer

128. जब आप Windows में आंतरिक NTFS ड्राइव पर संग्रहीत फाइल पर Delete दबाते हैं तो क्या होता है?
(a) फाइल Recycle Bin में चली जाती है (b) फाइल तुरंत स्थायी रूप से मिट जाती है (c) फाइल कंप्रेस होकर छिप जाती है (d) फाइल एक अस्थायी फोल्डर में चली जाती है
उत्तर: (a)
हल: कई उपयोगकर्ता सोचते हैं कि Delete स्थायी रूप से मिटा देता है, लेकिन आंतरिक NTFS वॉल्यूम पर Windows फाइल को Recycle Bin में भेजता है जब तक कि Shift + Delete उपयोग न किया जाए। इसलिए फाइल Recycle Bin में चली जाती है।
स्रोत: Microsoft Support — Recycle Bin in Windows

149. Windows 10/11 में "Compact OS" फीचर किसके लिए डिज़ाइन किया गया है:
(a) उपयोगकर्ता दस्तावेज़ कंप्रेस करके स्पेस बचाना (b) पूरे ड्राइव पर NTFS कंप्रेशन सक्षम करना (c) चयनित फोल्डर के कंप्रेस्ड आर्काइव बनाना (d) सिस्टम फाइलों और Windows Store ऐप्स को कंप्रेस करके फुटप्रिंट कम करना
उत्तर: (d)
हल: Compact OS OS बाइनरी और मॉडर्न ऐप्स को लक्षित करता है, उपयोगकर्ता डेटा को नहीं; यह फोल्डर आर्काइवर नहीं है और न ही फुल-ड्राइव NTFS कंप्रेशन टॉगल है। इसलिए यह सिस्टम फाइलों और Windows Store ऐप्स को कंप्रेस करता है।
स्रोत: Microsoft Learn — Compact OS

150. एक उपयोगकर्ता Network and Sharing Center में "File and printer sharing" सक्षम करता है लेकिन दूसरे PC से शेयर्ड फोल्डर एक्सेस नहीं कर पाता। SMB ट्रैफिक के लिए Windows Defender Firewall के माध्यम से कौन सा अतिरिक्त Windows कंपोनेंट अनुमति दी जानी चाहिए?
(a) Network Discovery (b) File and Printer Sharing (SMB-In) (c) Remote Desktop (d) Windows Management Instrumentation (WMI-In)
उत्तर: (b)
हल: Network Discovery डिवाइस खोजने में मदद करता है लेकिन SMB पोर्ट नहीं खोलता; Remote Desktop RDP उपयोग करता है; WMI प्रबंधन के लिए है। फायरवॉल नियम "File and Printer Sharing (SMB-In)" स्पष्ट रूप से इनबाउंड SMB/TCP 445 की अनुमति देता है। इसलिए नियम File and Printer Sharing (SMB-In) है।
स्रोत: Microsoft Learn — File and printer sharing firewall rules
