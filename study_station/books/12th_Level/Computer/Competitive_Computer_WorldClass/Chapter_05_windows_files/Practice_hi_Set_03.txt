51. Windows 10 और Windows 11 में File Explorer खोलने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Windows + E (b) Ctrl + E (c) Alt + E (d) Shift + E
उत्तर: (a)
हल: कई उम्मीदवार Ctrl + E (जो पहले से खुले File Explorer में सर्च/एड्रेस बार पर फोकस करता है) को उस ग्लोबल शॉर्टकट समझ लेते हैं जो कहीं से भी File Explorer लॉन्च करता है; सही ग्लोबल शॉर्टकट Windows + E है, इसलिए उत्तर Windows + E है।
स्रोत: Microsoft Support - Windows keyboard shortcuts

52. File Explorer में कौन सा व्यू लेआउट बड़े आइकन दिखाता है जिनके नीचे फाइल नाम होते हैं और जो फोटो प्रीव्यू के लिए सबसे अच्छा है?
(a) Details (b) List (c) Content (d) Large icons
उत्तर: (d)
हल: Details व्यू कॉलम (Name, Date, Size) दिखाता है और अक्सर फोटो ब्राउज़िंग के लिए गलती से चुना जाता है; Large icons बड़े थंबनेल दिखाता है जो इमेज के लिए आदर्श हैं, इसलिए उत्तर Large icons है।
स्रोत: Microsoft Learn - File Explorer views

53. Windows 10/11 में आंतरिक NTFS ड्राइव पर संग्रहीत फाइल पर Delete दबाने पर क्या होता है?
(a) फाइल तुरंत स्थायी रूप से मिट जाती है (b) फाइल एक छिपे सिस्टम फोल्डर में चली जाती है (c) फाइल कंप्रेस होकर आर्काइव हो जाती है (d) फाइल Recycle Bin में चली जाती है
उत्तर: (d)
हल: एक आम जाल यह सोचना है कि Delete फाइल को स्थायी रूप से हटा देता है (Shift + Delete ऐसा करता है); मानक Delete कुंजी फाइल को रिकवरी के लिए Recycle Bin में भेजती है, इसलिए उत्तर The file is moved to the Recycle Bin है।
स्रोत: Microsoft Support - Recycle Bin behavior

54. कौन सा की कॉम्बिनेशन चयनित फाइल को Recycle Bin को बायपास करके स्थायी रूप से डिलीट करता है?

57. File Explorer के View टैब पर "Hidden items" चेकबॉक्स क्या करता है?
(a) छिपी फाइलों को डिलीट करता है (b) छिपी फाइलों को कंप्रेस करके स्पेस बचाता है (c) चयनित फाइलों को एन्क्रिप्ट करता है (d) Hidden एट्रिब्यूट वाली फाइलों/फोल्डरों को दिखाता या छिपाता है

58. कौन सा फाइल एट्रिब्यूट, जब सेट हो, फाइल को मॉडिफाई होने से रोकता है लेकिन पढ़ने की अनुमति देता है?
(a) Hidden (b) System (c) Archive (d) Read-only
उत्तर: (d)
हल: Archive एट्रिब्यूट बैकअप सॉफ्टवेयर के लिए है, Hidden और System विजिबिलिटी प्रभावित करते हैं; Read-only विशेष रूप से लिखने को ब्लॉक करता है जबकि पढ़ने की अनुमति देता है, इसलिए उत्तर Read-only है।
स्रोत: Microsoft Learn - File attributes

59. Windows 10/11 में कौन सी सुविधा अस्थायी फाइलों और एक निर्धारित अवधि से पुरानी Recycle Bin आइटम्स को डिलीट करके स्वचालित रूप से स्पेस खाली करती है?

स्रोत: Microsoft Support - Storage Sense

(a) फोल्डर का ZIP आर्काइव बनाता है (b) उस फोल्डर में फाइलों पर NTFS कंप्रेशन लागू करता है (c) फोल्डर को EFS से एन्क्रिप्ट करता है (d) फोल्डर को कंप्रेस्ड ड्राइव पर ले जाता है

73. कौन सा NTFS परमिशन कॉम्बिनेशन यूजर को फोल्डर में फाइलें बनाने की अनुमति देता है लेकिन दूसरों द्वारा बनाई गई फाइलों को डिलीट करने की नहीं?

75. Windows 11 में, कौन सी सुविधा पूर्ण सिस्टम इमेज बनाने के लिए क्लासिक "Backup and Restore (Windows 7)" को प्रतिस्थापित करती है?
(a) File History (b) System Image Backup (अभी भी Control Panel के माध्यम से उपलब्ध) (c) OneDrive folder backup (d) Reset this PC
उत्तर: (b)
हल: File History केवल यूजर लाइब्रेरी का बैकअप लेता है; OneDrive फोल्डर सिंक करता है; Reset Windows को रीइंस्टॉल करता है। लिगेसी System Image Backup टूल Windows 11 में Control Panel > Backup and Restore (Windows 7) के माध्यम से अभी भी सुलभ है, इसलिए उत्तर System Image Backup (still available via Control Panel) है।
स्रोत: Microsoft Support - System image backup
