**विंडोज और फाइल प्रबंधन — मुख्य तथ्य (Key Facts)**

1. **ऑपरेटिंग सिस्टम (OS)** — कंप्यूटर हार्डवेयर और सॉफ्टवेयर संसाधनों का प्रबंधन करता है; उपयोगकर्ता और हार्डवेयर के बीच मध्यस्थ है। Windows, Linux, macOS प्रमुख OS हैं।  
   *स्रोत: Microsoft Learn — Windows fundamentals*

2. **विंडोज संस्करण** — Windows 10 (2015) और Windows 11 (2021) वर्तमान मुख्यधारा संस्करण हैं; दोनों NT कर्नेल पर आधारित हैं। परीक्षा में "नवीनतम संस्करण" के स्थान पर विशिष्ट संस्करण संख्या पूछी जा सकती है।  
   *स्रोत: Microsoft Windows release information*

3. **फाइल सिस्टम** — NTFS (New Technology File System) Windows का डिफ़ॉल्ट फाइल सिस्टम है; यह अनुमति (permissions), एन्क्रिप्शन (EFS), डिस्क कोटा, जर्नलिंग का समर्थन करता है। FAT32 पुराना है, 4 GB से बड़ी फाइल नहीं रख सकता।  
   *स्रोत: Microsoft Learn — File systems overview*

4. **ड्राइव अक्षर** — Windows में प्रत्येक वॉल्यूम को एक अक्षर (C:, D:, …) दिया जाता है; C: आमतौर पर सिस्टम/बूट पार्टीशन होता है। नेटवर्क ड्राइव को मैप करने पर भी अक्षर मिलता है।  
   *स्रोत: Microsoft Support — Drive letters*

5. **फाइल एक्सटेंशन** — फाइल नाम के अंत में डॉट (.) के बाद का भाग (जैसे .docx, .pdf, .exe) फाइल प्रकार दर्शाता है; Windows डिफ़ॉल्ट रूप से ज्ञात एक्सटेंशन छिपाता है — Folder Options → View → "Hide extensions for known file types" अनचेक करें।  
   *स्रोत: Microsoft Support — File extensions*

6. **पथ (Path)** — फाइल/फोल्डर का पूर्ण पता; निरपेक्ष पथ (Absolute) ड्राइव से शुरू होता है (C:\Users\Name\Doc.txt), सापेक्ष पथ (Relative) वर्तमान फोल्डर से (..\Doc.txt)।  
   *स्रोत: Microsoft Learn — File paths*

7. **फाइल विशेषताएँ (Attributes)** — Read-only, Hidden, System, Archive; `attrib` कमांड या Properties → General टैब से देख/बदल सकते हैं।  
   *स्रोत: Microsoft Learn — File attributes*

8. **फोल्डर/डायरेक्टरी संरचना** — Windows पदानुक्रमित (हाइरार्किकल) ट्री संरचना उपयोग करता है: रूट (\) → फोल्डर → सबफोल्डर → फाइल। विशेष फोल्डर: Desktop, Documents, Downloads, AppData (छिपा)।  
   *स्रोत: Microsoft Learn — Special folders*

9. **फाइल/फोल्डर ऑपरेशन** — Copy (Ctrl+C), Cut (Ctrl+X), Paste (Ctrl+V), Delete (Del → Recycle Bin), Rename (F2), New Folder (Ctrl+Shift+N)। Drag-drop: समान ड्राइव पर Move, अलग ड्राइव पर Copy; Ctrl दबाकर बलपूर्वक Copy, Shift दबाकर बलपूर्वक Move।  
   *स्रोत: Microsoft Support — Keyboard shortcuts in Windows*

10. **रिसाइकल बिन (Recycle Bin)** — हटाई गई फाइलें अस्थायी रूप से यहाँ जाती हैं; प्रत्येक ड्राइव का अपना रिसाइकल बिन होता है; Shift+Delete स्थायी हटाता है (बिन बायपास)। आकार सीमा सेट की जा सकती है।  
    *स्रोत: Microsoft Support — Recycle Bin*

11. **शॉर्टकट (Shortcut)** — मूल फाइल/फोल्डर/एप का संकेतक (.lnk फाइल); तीर वाला छोटा आइकन; मूल को नहीं हटाता; Properties → Target में पथ दिखाता है।  
    *स्रोत: Microsoft Learn — Shortcuts*

12. **कंप्रेशन (Compression)** — NTFS फाइल/फोल्डर कंप्रेशन (Properties → Advanced → "Compress contents to save disk space") केवल NTFS पर काम करता है; ZIP फोल्डर (Send to → Compressed folder) पोर्टेबल है।  
    *स्रोत: Microsoft Learn — NTFS compression*

13. **अनुमतियाँ (Permissions — NTFS)** — Full control, Modify, Read & execute, List folder contents, Read, Write; Allow/Deny; विरासत (Inheritance) डिफ़ॉल्ट चालू; Effective Access टैब से जाँचें। Share permissions (Network) अलग हैं — अधिक प्रतिबंधात्मक लागू होता है।  
    *स्रोत: Microsoft Learn — NTFS permissions*

14. **बिटलॉकर (BitLocker)** — पूर्ण ड्राइव एन्क्रिप्शन (Windows Pro/Enterprise/Education); TPM 1.2+ हार्डवेयर सहायता; रिकवरी कुंजी Microsoft खाते/USB/प्रिंट में सहेजें।  
    *स्रोत: Microsoft Learn — BitLocker overview*

15. **डिस्क प्रबंधन (Disk Management — diskmgmt.msc)** — पार्टीशन बनाना/हटाना/फॉर्मेट करना/आकार बदलना (Extend/Shrink), ड्राइव अक्षर बदलना, MBR/GPT रूपांतरण (डेटा हानि के साथ)।  
    *स्रोत: Microsoft Learn — Disk Management*

16. **स्टोरेज सेंस (Storage Sense)** — Windows 10/11 में अस्थायी फाइलें, रिसाइकल बिन, पुरानी डाउनलोड स्वचालित हटाने के लिए Settings → System → Storage → Storage Sense।  
    *स्रोत: Microsoft Support — Storage Sense*

17. **फाइल एक्सप्लोरर (File Explorer — Win+E)** — नेविगेशन पेन (Quick Access, This PC, Network), रिबन (Home, Share, View), एड्रेस बार, प्रीव्यू पेन (Alt+P), डिटेल्स पेन (Alt+Shift+P)।  
    *स्रोत: Microsoft Support — File Explorer*

18. **क्विक एक्सेस (Quick Access)** — पिन किए गए फोल्डर + हालिया फाइलें; फोल्डर राइट-क्लिक → "Pin to Quick Access"; Options → General → "Open File Explorer to: This PC" बदल सकते हैं।  
    *स्रोत: Microsoft Support — Quick Access*

19. **लाइब्रेरी (Libraries)** — Documents, Music, Pictures, Videos आदि वर्चुअल संग्रह; एकाधिक फोल्डर शामिल कर सकते हैं; डिफ़ॉल्ट सेव लोकेशन सेट कर सकते हैं; View → Navigation pane → Show libraries।  
    *स्रोत: Microsoft Learn — Libraries*

20. **खोज (Search)** — फाइल एक्सप्लोरर खोज बॉक्स (Ctrl+E/F3) — इंडेक्सिंग विकल्प (Indexing Options) से स्थान/फाइल प्रकार जोड़ें/हटाएँ; उन्नत क्वेरी सिंटैक्स: `name:.pdf`, `date:>01/01/2024`, `size:>10MB`, `kind:document`।  
    *स्रोत: Microsoft Learn — Advanced Query Syntax*

21. **कमांड प्रॉम्प्ट (cmd) / पावरशेल (PowerShell) फाइल कमांड** — `dir`, `cd`, `md`/`mkdir`, `rd`/`rmdir`, `copy`, `move`, `del`, `ren`, `type`, `attrib`, `xcopy`/`robocopy` (मजबूत कॉपी), `tree`। PowerShell में `Get-ChildItem`, `Copy-Item`, `Remove-Item` आदि।  
    *स्रोत: Microsoft Learn — Command-line reference*

22. **विंडोज शॉर्टकट कुंजियाँ (Windows scope)** — Win+E (Explorer), Win+R (Run), Win+I (Settings), Win+X (Quick Link), Win+L (Lock), Win+D (Desktop), Win+Tab (Task View), Win+Shift+S (Snip), Alt+Tab (Switch apps), Ctrl+Shift+Esc (Task Manager)।  
    *स्रोत: Microsoft Support — Windows keyboard shortcuts*

23. **ब्राउज़र शॉर्टकट (Browser scope — Windows नहीं)** — Ctrl+T (नया टैब), Ctrl+W (बंद टैब), Ctrl+Shift+T (पुनः खोलें), Ctrl+Tab/Shift+Tab (अगला/पिछला टैब), F5/Ctrl+R (रिफ्रेश), Ctrl+L/Alt+D (एड्रेस बार), Ctrl+H (इतिहास), Ctrl+J (डाउनलोड)। ये ब्राउज़र-विशिष्ट हैं, OS नहीं।  
    *स्रोत: Chrome/Edge keyboard shortcuts documentation*

24. **फाइल नामकरण नियम** — अधिकतम 255 वर्ण (पथ सहित 260, लंबे पथ सक्षम होने पर 32,767); प्रतिबंधित वर्ण: `< > : " / \ | ? *`; आरक्षित नाम: CON, PRN, AUX, NUL, COM1–9, LPT1–9।  
    *स्रोत: Microsoft Learn — Naming files, paths, and namespaces*

25. **सामान्य गलतियाँ** — (क) एक्सटेंशन छिपे होने पर `photo.jpg.exe` को `photo.jpg` समझना; (ख) शॉर्टकट हटाकर मूल फाइल हटी समझना; (ग) FAT32 पर 4 GB+ फाइल कॉपी न होना; (घ) Share permission को NTFS permission समझना; (ङ) Shift+Delete के बाद रिकवरी असंभव मानना (तृतीय-पक्ष टूल से संभव)।  
    *स्रोत: Microsoft Support — Common file management issues*
