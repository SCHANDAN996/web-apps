76. आधुनिक Windows इंस्टॉलेशन के लिए डिफ़ॉल्ट फाइल सिस्टम कौन सा है जो फाइल-स्तरीय अनुमतियों, एन्क्रिप्शन और डिस्क कोटा का समर्थन करता है?
(a) FAT32 (b) NTFS (c) ReFS (d) exFAT
उत्तर: (b)
हल: FAT32 और exFAT में ACL और EFS जैसी अंतर्निहित फाइल-स्तरीय सुरक्षा सुविधाओं का अभाव होता है; ReFS सर्वर लचीलापन के लिए डिज़ाइन किया गया है, डिफ़ॉल्ट क्लाइंट इंस्टॉलेशन के लिए नहीं। NTFS सूचीबद्ध सभी सुविधाएँ प्रदान करता है और Windows सिस्टम वॉल्यूम के लिए डिफ़ॉल्ट है, इसलिए उत्तर NTFS है।
स्रोत: Microsoft Learn – NTFS overview

77. एक उपयोगकर्ता NTFS वॉल्यूम से FAT32 USB ड्राइव पर एक फाइल कॉपी करता है। कॉपी के दौरान कौन सा NTFS-विशिष्ट गुण खो जाता है?
(a) फाइल नाम (b) फाइल आकार (c) वैकल्पिक डेटा स्ट्रीम (d) निर्माण टाइमस्टैम्प
उत्तर: (c)
हल: फाइल नाम, आकार और बुनियादी टाइमस्टैम्प FAT32 पर संरक्षित रहते हैं; वैकल्पिक डेटा स्ट्रीम (ADS) केवल NTFS की सुविधा है और FAT32 पर संग्रहीत नहीं की जा सकती, इसलिए उत्तर वैकल्पिक डेटा स्ट्रीम है।
स्रोत: Microsoft Learn – Alternate Data Streams

78. फाइल एक्सप्लोरर में, कौन सा कीबोर्ड शॉर्टकट चयनित फाइल को रीसायकल बिन में भेजे बिना स्थायी रूप से हटा देता है?
(a) Ctrl + Delete (b) Delete (c) Shift + Delete (d) Alt + Delete
उत्तर: (c)
हल: Delete रीसायकल बिन में ले जाता है; Ctrl+Delete और Alt+Delete का एक्सप्लोरर में कोई मानक डिलीट फ़ंक्शन नहीं है। Shift+Delete तत्काल स्थायी डिलीशन के लिए रीसायकल बिन को बायपास करता है, इसलिए उत्तर Shift + Delete है।
स्रोत: Microsoft Support – Keyboard shortcuts in Windows

79. FAT32 वॉल्यूम पर समर्थित अधिकतम व्यक्तिगत फाइल आकार क्या है?
(a) 2 GB (b) 4 GB (c) 8 GB (d) 16 GB
उत्तर: (b)
हल: FAT32 32-बिट फाइल आवंटन तालिका का उपयोग करता है जिसमें 4-बाइट फाइल आकार फ़ील्ड होता है, जो एक फाइल को 4,294,967,295 बाइट्स (4 GB घटा 1 बाइट) तक सीमित करता है। exFAT और NTFS बहुत बड़ी फाइलों का समर्थन करते हैं, इसलिए उत्तर 4 GB है।
स्रोत: Microsoft Learn – FAT32 specification

80. कौन सी कमांड कमांड प्रॉम्प्ट में वर्तमान फ़ोल्डर से शुरू होने वाली पूर्ण डायरेक्ट्री ट्री संरचना प्रदर्शित करती है?
(a) dir /s (b) tree (c) dir /a (d) ls -R
उत्तर: (b)
हल: dir /s फाइलों को रिकर्सिवली सूचीबद्ध करता है लेकिन ट्री के रूप में नहीं; dir /a छिपी फाइलें दिखाता है; ls -R एक लिनक्स कमांड है। tree कमांड एक ग्राफिकल डायरेक्ट्री ट्री प्रस्तुत करता है, इसलिए उत्तर tree है।
स्रोत: Microsoft Learn – tree command

81. एक फाइल पर Read-only और Hidden गुण सेट हैं। कौन सी attrib कमांड एक चरण में दोनों गुणों को हटा देती है?
(a) attrib -r -h filename (b) attrib +r +h filename (c) attrib -r +h filename (d) attrib +r -h filename

हल: प्लस चिह्न गुण जोड़ते हैं; माइनस चिह्न उन्हें हटाते हैं। Read-only (r) और Hidden (h) दोनों को साफ़ करने के लिए दोनों के आगे माइनस होना चाहिए, इसलिए उत्तर attrib -r -h filename है।
स्रोत: Microsoft Learn – attrib command

82. कौन सी Windows सुविधा किसी फ़ोल्डर को फ़ाइलों की नकल किए बिना नेविगेशन फलक में कई स्थानों पर प्रकट होने देती है?
(a) लाइब्रेरी (b) सिम्बोलिक लिंक (c) शॉर्टकट (d) जंक्शन पॉइंट
उत्तर: (a)

83. जब किसी फाइल को NTFS कम्प्रेशन का उपयोग करके संपीड़ित किया जाता है, तो डिस्क पर उसका फाइल आकार उसके वास्तविक आकार की तुलना में क्या होता है?
(a) डिस्क पर आकार बड़ा हो जाता है (b) डिस्क पर आकार शून्य हो जाता है (c) डिस्क पर आकार छोटा हो जाता है (d) दोनों समान रहते हैं
उत्तर: (c)
हल: NTFS कम्प्रेशन फाइल के लिए आवंटित क्लस्टर को कम कर देता है, इसलिए डिस्क पर आकार (आवंटित स्थान) तार्किक फाइल आकार से छोटा होता है। फाइल सामग्री पढ़ने पर पारदर्शी रूप से डीकंप्रेस हो जाती है, इसलिए उत्तर डिस्क पर आकार छोटा हो जाता है।
स्रोत: Microsoft Learn – NTFS compression

84. कौन सा एनवायरनमेंट वेरिएबल वर्तमान उपयोगकर्ता के प्रोफ़ाइल फ़ोल्डर का पथ रखता है (जैसे C:\Users\Name)?

स्रोत: Microsoft Learn – Environment variables

85. एक उपयोगकर्ता नेटवर्क शेयर पर किसी फाइल को संशोधित नहीं कर सकता, भले ही फाइल पर उसका Full Control NTFS अनुमति हो। सबसे संभावित कारण क्या है?

उत्तर: (a)
हल: प्रभावी अनुमति NTFS और शेयर अनुमतियों में से सबसे अधिक प्रतिबंधात्मक होती है। Full Control NTFS के साथ Read शेयर का परिणाम Read प्रभावी एक्सेस होता है। एन्क्रिप्शन, कम्प्रेशन, या ऑफ़लाइन स्थिति शेयर अनुमतियों को ओवरराइड नहीं करते, इसलिए उत्तर शेयर अनुमति Read है।

89. "Hide extensions for known file types" सक्षम होने पर एक फाइल फाइल एक्सप्लोरर में "report.docx" के रूप में दिखाई देती है। डिस्क पर वास्तविक फाइल नाम हो सकता है:
(a) report (b) report.doc (c) report.docx (d) report.docx.exe
उत्तर: (d)
हल: "Hide extensions for known file types" सक्षम होने पर, .exe जैसे ज्ञात एक्सटेंशन छिप जाते हैं। "report.docx.exe" नाम की फाइल "report.docx" के रूप में प्रदर्शित होगी क्योंकि .exe भाग छिपा होता है, जबकि .docx भाग दृश्यमान रहता है। यह मैलवेयर द्वारा निष्पादन योग्य फाइलों को छिपाने के लिए इस्तेमाल की जाने वाली एक सामान्य तरकीब है। अन्य विकल्प इस सेटिंग के तहत "report.docx" के रूप में प्रदर्शित नहीं होंगे, इसलिए उत्तर report.docx.exe है।
स्रोत: Microsoft Support – Show or hide file extensions

(a) Write (b) Modify (c) Full Control (d) Read
उत्तर: (d)
हल: प्रभावी नेटवर्क अनुमति = शेयर और NTFS में से सबसे अधिक प्रतिबंधात्मक। Read शेयर + Modify NTFS = Read प्रभावी। उपयोगकर्ता नेटवर्क पर लिख या संशोधित नहीं कर सकता, इसलिए उत्तर Read है।
स्रोत: Microsoft Learn – Effective permissions

98. कौन सी सुविधा किसी वॉल्यूम को ड्राइव अक्षर असाइन करने के बजाय मौजूदा NTFS वॉल्यूम पर फ़ोल्डर के रूप में माउंट करने की अनुमति देती है?
(a) जंक्शन पॉइंट (b) वॉल्यूम माउंट पॉइंट (c) सिम्बोलिक लिंक (d) हार्ड लिंक
उत्तर: (b)
हल: जंक्शन पॉइंट समान वॉल्यूम पर डायरेक्टरी लिंक करते हैं; सिम्बोलिक लिंक वॉल्यूम पार कर सकते हैं लेकिन फाइल/फ़ोल्डर स्तर के हैं; हार्ड लिंक केवल फाइलों के लिए हैं। वॉल्यूम माउंट पॉइंट किसी वॉल्यूम को खाली NTFS फ़ोल्डर पर असाइन करते हैं, इसलिए उत्तर वॉल्यूम माउंट पॉइंट है।
स्रोत: Microsoft Learn – Volume mount points

99. बैच फाइल में, कौन सा वेरिएबल बैच स्क्रिप्ट का पूर्ण पथ दर्शाता है?
(a) %~dp0 (b) %1 (c) %* (d) %0
उत्तर: (a)
हल: %0 वह स्क्रिप्ट नाम है जैसा आह्वान किया गया; %1 पहला तर्क है; %* सभी तर्क हैं। %~dp0 स्क्रिप्ट के ड्राइव और पथ पर विस्तारित होता है (केवल डायरेक्टरी), इसलिए उत्तर %~dp0 है।
स्रोत: Microsoft Learn – Batch file parameters

100. एक उपयोगकर्ता Windows 10 पर "Compact OS" सक्षम करता है। प्राथमिक प्रभाव क्या है?
(a) डिस्क स्थान बचाने के लिए सिस्टम फाइलों को संपीड़ित करता है (b) उपयोगकर्ता दस्तावेजों को संपीड़ित करता है (c) C: पर NTFS कम्प्रेशन सक्षम करता है (d) RAM उपयोग कम करता है
उत्तर: (a)
हल: Compact OS Windows सिस्टम फाइलों को संपीड़ित अवस्था में संग्रहीत करता है (WIMBoot के समान) ताकि छोटे ड्राइव पर पदचिह्न कम हो। यह उपयोगकर्ता डेटा को संपीड़ित नहीं करता, पूर्ण-वॉल्यूम NTFS कम्प्रेशन सक्षम नहीं करता, या RAM को प्रभावित नहीं करता, इसलिए उत्तर डिस्क स्थान बचाने के लिए सिस्टम फाइलों को संपीड़ित करता है।
स्रोत: Microsoft Learn – Compact OS
