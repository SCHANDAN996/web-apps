1. Windows में टास्कबार का प्राथमिक कार्य क्या है?
(a) केवल स्थापित अनुप्रयोगों की सूची प्रदर्शित करता है (b) चल रहे प्रोग्राम, प्रारंभ बटन, सिस्टम ट्रे और समय दिखाता है (c) फ़ाइल अनुमतियों और सुरक्षा सेटिंग्स का प्रबंधन करता है (d) कंप्यूटर के हार्डवेयर ड्राइवरों को नियंत्रित करता है
उत्तर: (b)
हल: टास्कबार को अक्सर प्रारंभ मेनू या एक साधारण ऐप लॉन्चर समझ लिया जाता है, लेकिन यह लगातार चल रहे प्रोग्राम, प्रारंभ बटन, सिस्टम ट्रे आइकन और घड़ी दिखाता है, इसलिए उत्तर है चल रहे प्रोग्राम, प्रारंभ बटन, सिस्टम ट्रे और समय दिखाता है।
स्रोत: Microsoft Learn – Windows fundamentals

2. Windows में रन डायलॉग बॉक्स खोलने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Ctrl + Shift + Esc (b) Windows key + E (c) Windows key + R (d) Windows key + D
उत्तर: (c)
हल: Windows key + E फाइल एक्सप्लोरर खोलता है, Windows key + D डेस्कटॉप दिखाता है, और Ctrl + Shift + Esc टास्क मैनेजर खोलता है; रन डायलॉग विशेष रूप से Windows key + R से खुलता है, इसलिए उत्तर है Windows key + R।
स्रोत: Microsoft Support – Keyboard shortcuts in Windows

3. फाइल एक्सप्लोरर में, "क्विक एक्सेस" अनुभाग क्या प्रदर्शित करता है?
(a) केवल सिस्टम फ़ाइलें और फ़ोल्डर (b) सभी ड्राइव और नेटवर्क स्थान (c) रीसायकल बिन से हटाई गई फ़ाइलें (d) अक्सर उपयोग किए जाने वाले फ़ोल्डर और हाल ही में एक्सेस की गई फ़ाइलें
उत्तर: (d)
हल: क्विक एक्सेस को अक्सर "दिस पीसी" या रीसायकल बिन समझ लिया जाता है, लेकिन यह त्वरित नेविगेशन के लिए अक्सर उपयोग किए जाने वाले फ़ोल्डरों और हाल ही में खोली गई फ़ाइलों को गतिशील रूप से पिन करता है, इसलिए उत्तर है अक्सर उपयोग किए जाने वाले फ़ोल्डर और हाल ही में एक्सेस की गई फ़ाइलें।
स्रोत: Microsoft Learn – File Explorer overview

4. फाइल एक्सप्लोरर में किसी चयनित फ़ाइल पर डिलीट कुंजी दबाने पर क्या होता है (डिफ़ॉल्ट व्यवहार)?
(a) फ़ाइल तुरंत स्थायी रूप से मिटा दी जाती है (b) फ़ाइल रीसायकल बिन में चली जाती है (c) फ़ाइल ZIP आर्काइव में संपीड़ित हो जाती है (d) फ़ाइल क्लिपबोर्ड पर कॉपी हो जाती है
उत्तर: (b)
हल: कई उपयोगकर्ता सोचते हैं कि डिलीट फ़ाइल को स्थायी रूप से हटा देता है, लेकिन डिफ़ॉल्ट रूप से यह फ़ाइल को पुनर्प्राप्ति के लिए रीसायकल बिन में भेजता है; स्थायी विलोपन के लिए Shift + Delete आवश्यक है, इसलिए उत्तर है फ़ाइल रीसायकल बिन में चली जाती है।
स्रोत: Microsoft Support – Delete files or folders

5. कौन सा फ़ाइल विशेषता किसी फ़ाइल को गलती से संशोधित या हटाए जाने से रोकता है?
(a) Hidden (b) System (c) Read-only (d) Archive
उत्तर: (c)
हल: Hidden विशेषता केवल सामान्य दृश्य में फ़ाइल को छुपाती है, जबकि Read-only विशेष रूप से लेखन संचालन को ब्लॉक करता है; System OS फ़ाइलों को चिह्नित करता है, और Archive बैकअप के लिए उपयोग किया जाता है, इसलिए उत्तर है Read-only।
स्रोत: Microsoft Learn – File attributes

6. Windows में शॉर्टकट (".lnk" फ़ाइल) का उद्देश्य क्या है?
(a) मूल फ़ाइल या प्रोग्राम स्थान का संकेतक प्रदान करता है (b) सुरक्षा के लिए मूल फ़ाइल को एन्क्रिप्ट करता है (c) स्थान बचाने के लिए मूल फ़ाइल को संपीड़ित करता है (d) मूल फ़ाइल की एक डुप्लिकेट प्रति बनाता है
उत्तर: (a)
हल: शॉर्टकट को अक्सर कॉपी या संपीड़ित संस्करण समझ लिया जाता है, लेकिन यह केवल एक छोटी संकेतक फ़ाइल है जो डेटा की नकल किए बिना लक्ष्य पर पुनर्निर्देशित करती है, इसलिए उत्तर है मूल फ़ाइल या प्रोग्राम स्थान का संकेतक प्रदान करता है।
स्रोत: Microsoft Learn – Create a shortcut

7. कौन सा कीबोर्ड शॉर्टकट सीधे फाइल एक्सप्लोरर खोलता है?
(a) Ctrl + E (b) Windows key + F (c) Windows key + X (d) Windows key + E
उत्तर: (d)
हल: Windows key + F खोज खोलता है (या फीडबैक हब), Windows key + X पावर यूजर मेनू खोलता है, और Ctrl + E ब्राउज़र में खोज बॉक्स पर फोकस करता है; फाइल एक्सप्लोरर विशिष्ट रूप से Windows key + E से लॉन्च होता है, इसलिए उत्तर है Windows key + E।
स्रोत: Microsoft Support – Keyboard shortcuts in Windows

8. "रीसायकल बिन" क्या संग्रहीत करता है?
(a) संपीड़ित सिस्टम बैकअप (b) हटाई गई फ़ाइलें और फ़ोल्डर जब तक खाली न किया जाए (c) अस्थायी इंटरनेट फ़ाइलें (d) स्थापित एप्लिकेशन इंस्टॉलर
उत्तर: (b)
हल: रीसायकल बिन बैकअप या कैश फ़ोल्डर नहीं है; यह उपयोगकर्ता द्वारा हटाए गए आइटम को अस्थायी रूप से रखता है, जिससे बिन खाली होने तक पुनर्स्थापना संभव होती है, इसलिए उत्तर है हटाई गई फ़ाइलें और फ़ोल्डर जब तक खाली न किया जाए।
स्रोत: Microsoft Support – Recycle Bin

9. फाइल एक्सप्लोरर में कौन सा दृश्य फ़ाइल विवरण जैसे आकार, प्रकार और संशोधन तिथि को कॉलम में दिखाता है?
(a) Icons view (b) List view (c) Details view (d) Tiles view
उत्तर: (c)
हल: Icons और Tiles थंबनेल या बड़े आइकन दिखाते हैं जिनमें सीमित मेटाडेटा होता है, List केवल नाम दिखाता है; Details view आकार, प्रकार, तिथि आदि के लिए कॉलम के साथ सारणीबद्ध लेआउट प्रस्तुत करता है, इसलिए उत्तर है Details view।
स्रोत: Microsoft Learn – Change the view in File Explorer

10. आधुनिक Windows संस्करणों में उपयोगकर्ता दस्तावेज़ों का डिफ़ॉल्ट स्थान क्या है?
(a) C:\Users\<username>\Documents (b) C:\Windows\Documents (c) C:\Program Files\Documents (d) C:\Documents and Settings\Documents
उत्तर: (a)
हल: पुराने संस्करण "Documents and Settings" का उपयोग करते थे, लेकिन Windows Vista के बाद से मानक प्रोफ़ाइल पथ C:\Users\<username>\Documents है; Windows और Program Files जैसे सिस्टम फ़ोल्डर OS और ऐप्स के लिए हैं, इसलिए उत्तर है C:\Users\<username>\Documents।
स्रोत: Microsoft Learn – User profile folders

11. कौन सा कुंजी संयोजन चयनित फ़ाइल को रीसायकल बिन को बायपास करके स्थायी रूप से हटा देता है?
(a) Windows key + Delete (b) Ctrl + Delete (c) Alt + Delete (d) Shift + Delete
उत्तर: (d)
हल: Ctrl + Delete का कोई मानक डिलीट फ़ंक्शन नहीं है, Alt + Delete उपयोग नहीं किया जाता, और Windows key + Delete डिफ़ॉल्ट शॉर्टकट नहीं है; Shift + Delete स्थायी विलोपन के लिए प्रलेखित संयोजन है, इसलिए उत्तर है Shift + Delete।
स्रोत: Microsoft Support – Keyboard shortcuts in Windows

12. Windows में "लाइब्रेरी" सुविधा क्या करती है?
(a) विभिन्न स्थानों के फ़ोल्डरों को एक ही दृश्य में एकत्रित करती है (b) सुरक्षा के लिए फ़ाइलों को एन्क्रिप्ट करती है (c) डिस्क स्थान बचाने के लिए फ़ोल्डरों को संपीड़ित करती है (d) महत्वपूर्ण फ़ाइलों की बैकअप प्रतियां बनाती है
उत्तर: (a)
हल: लाइब्रेरी को अक्सर बैकअप या संपीड़न टूल समझ लिया जाता है, लेकिन ये आभासी संग्रह हैं जो कई भौतिक फ़ोल्डरों (जैसे Documents, Pictures) की सामग्री को फ़ाइलों को स्थानांतरित किए बिना एक विंडो में प्रदर्शित करते हैं, इसलिए उत्तर है विभिन्न स्थानों के फ़ोल्डरों को एक ही दृश्य में एकत्रित करती है।
स्रोत: Microsoft Learn – Libraries

13. कौन सा कुंजी संयोजन सीधे टास्क मैनेजर खोलता है?
(a) Ctrl + Alt + Delete (b) Ctrl + Shift + Esc (c) Windows key + X (d) Ctrl + Esc
उत्तर: (b)
हल: Ctrl + Alt + Delete एक सुरक्षा स्क्रीन खोलता है जिसमें टास्क मैनेजर एक विकल्प के रूप में होता है, Windows key + X पावर यूजर मेनू खोलता है, और Ctrl + Esc प्रारंभ मेनू खोलता है; Ctrl + Shift + Esc तुरंत टास्क मैनेजर लॉन्च करता है, इसलिए उत्तर है Ctrl + Shift + Esc।
स्रोत: Microsoft Support – Keyboard shortcuts in Windows

14. Windows में "स्नैप" सुविधा का कार्य क्या है?
(a) कंप्यूटर स्क्रीन को लॉक करता है (b) स्क्रीन का स्क्रीनशॉट लेता है (c) स्क्रीन किनारों पर खींचे जाने पर विंडोज़ को स्वचालित रूप से अगल-बगल व्यवस्थित करता है (d) एक पुनर्स्थापना बिंदु बनाता है
उत्तर: (c)
हल: स्नैप को स्क्रीनशॉट (Win+Shift+S) या लॉक (Win+L) समझ लिया जाता है, लेकिन यह विशेष रूप से विंडोज़ का आकार बदलता है और उन्हें स्क्रीन के आधे या चौथाई भाग में स्थित करता है जब उन्हें किनारों या कोनों पर खींचा जाता है, इसलिए उत्तर है स्क्रीन किनारों पर खींचे जाने पर विंडोज़ को स्वचालित रूप से अगल-बगल व्यवस्थित करता है।
स्रोत: Microsoft Learn – Snap windows

15. कौन सा फ़ाइल एक्सटेंशन Windows द्वारा मूल रूप से समर्थित संपीड़ित (ज़िप्ड) फ़ोल्डर को इंगित करता है?
(a) .rar (b) .tar (c) .7z (d) .zip
उत्तर: (d)
हल: Windows मूल रूप से .zip को "Compressed (zipped) folder" के रूप में समर्थन करता है; .rar, .7z, और .tar के लिए तृतीय-पक्ष टूल आवश्यक हैं, इसलिए उत्तर है .zip।
स्रोत: Microsoft Support – Zip and unzip files

16. जब किसी फ़ाइल या फ़ोल्डर पर "Hidden" विशेषता लागू की जाती है तो यह क्या करती है?
(a) सामान्य निर्देशिका सूचियों में फ़ाइल को प्रकट होने से रोकती है (b) फ़ाइल को बैकअप के लिए चिह्नित करती है (c) फ़ाइल सामग्री को एन्क्रिप्ट करती है (d) एक निर्धारित समय के बाद फ़ाइल को हटा देती है
उत्तर: (a)
हल: Hidden न तो हटाता है, न एन्क्रिप्ट करता है, न बैकअप शेड्यूल करता है; यह केवल फाइल एक्सप्लोरर को तब तक आइटम न दिखाने के लिए कहता है जब तक व्यू टैब में "Hidden items" सक्षम न हो, इसलिए उत्तर है सामान्य निर्देशिका सूचियों में फ़ाइल को प्रकट होने से रोकती है।
स्रोत: Microsoft Learn – File attributes

17. Windows 10/11 में कौन सा सेटिंग्स पृष्ठ उपयोगकर्ता खातों और साइन-इन विकल्पों का प्रबंधन करता है?
(a) Accounts (b) Network & Internet (c) System (d) Devices
उत्तर: (a)
हल: System हार्डवेयर/OS जानकारी संभालता है, Network & Internet कनेक्शन प्रबंधित करता है, Devices बाह्य उपकरणों को संभालता है; Accounts विशेष रूप से उपयोगकर्ता प्रोफ़ाइल, पासवर्ड और साइन-इन विकल्पों के लिए है, इसलिए उत्तर है Accounts।
स्रोत: Microsoft Learn – Manage user accounts

18. "रन" कमांड (Win+R) का उद्देश्य क्या है?
(a) एक नया उपयोगकर्ता सत्र शुरू करता है (b) एक सिस्टम डायग्नोस्टिक स्कैन चलाता है (c) नाम से एक विशिष्ट कमांड निष्पादित करता है, एक फ़ोल्डर खोलता है, या एक प्रोग्राम लॉन्च करता है (d) स्रोत कोड संकलित करता है
उत्तर: (c)
हल: रन डायग्नोस्टिक, सत्र या कंपाइलर टूल नहीं है; यह निष्पादन योग्य नाम, पथ, या शेल कमांड (जैसे "cmd", "control", "shell:startup") स्वीकार करके उन्हें सीधे लॉन्च करता है, इसलिए उत्तर है नाम से एक विशिष्ट कमांड निष्पादित करता है, एक फ़ोल्डर खोलता है, या एक प्रोग्राम लॉन्च करता है।
स्रोत: Microsoft Support – Run command

19. कौन सा कीबोर्ड शॉर्टकट सभी खुली विंडोज़ को छोटा करता है और डेस्कटॉप दिखाता है (टॉगल)?
(a) Windows key + M (b) Windows key + Down arrow (c) Windows key + Home (d) Windows key + D
उत्तर: (d)
हल: Win+M सभी विंडोज़ को छोटा करता है लेकिन टॉगल नहीं करता; Win+Home सक्रिय विंडो को छोड़कर सभी को छोटा करता है; Win+Down arrow केवल सक्रिय विंडो को छोटा करता है; Win+D शो डेस्कटॉप को टॉगल करता है, इसलिए उत्तर है Windows key + D।
स्रोत: Microsoft Support – Keyboard shortcuts in Windows

20. जब आप फाइल एक्सप्लोरर एड्रेस बार के खाली क्षेत्र पर क्लिक करते हैं तो यह क्या प्रदर्शित करता है?
(a) संपादन योग्य टेक्स्ट प्रारूप में पूर्ण पथ (b) हाल की फ़ाइलों की सूची (c) फ़ाइल गुण संवाद (d) खोज बॉक्स
उत्तर: (a)
हल: एड्रेस बार पर क्लिक करने से ब्रेडक्रंब पथ संपादन योग्य टेक्स्ट पथ में परिवर्तित हो जाता है (जैसे "C:\Users\Name\Documents") त्वरित कॉपी या टाइपिंग के लिए; यह हाल की फ़ाइलें, गुण, या खोज नहीं दिखाता, इसलिए उत्तर है संपादन योग्य टेक्स्ट प्रारूप में पूर्ण पथ।
स्रोत: Microsoft Learn – File Explorer address bar

21. एक उपयोगकर्ता USB ड्राइव से Documents फ़ोल्डर में फ़ाइल कॉपी करना चाहता है जबकि मूल USB पर बनी रहे। डिफ़ॉल्ट रूप से अलग-अलग ड्राइव के बीच कौन सी ड्रैग-एंड-ड्रॉप क्रिया इसे प्राप्त करती है?
(a) बाएं माउस बटन से खींचते समय Ctrl दबाए रखें (b) बाएं माउस बटन से खींचें (c) दाएं माउस बटन से खींचें और "Copy here" चुनें (d) बाएं माउस बटन से खींचते समय Shift दबाए रखें
उत्तर: (b)
हल: अलग-अलग ड्राइव के बीच, बाएं-ड्रैग डिफ़ॉल्ट रूप से कॉपी करता है; Ctrl+ड्रैग समान ड्राइव पर भी कॉपी बाध्य करता है, Shift+ड्रैग मूव बाध्य करता है, और राइट-ड्रैग मेनू दिखाता है; प्रश्न डिफ़ॉल्ट व्यवहार पूछता है, इसलिए उत्तर है बाएं माउस बटन से खींचें।
स्रोत: Microsoft Support – Copy or move files and folders

22. NTFS फ़ाइल अनुमतियों के बारे में निम्नलिखित में से कौन सा कथन सही है?
(a) "Read" अनुमति उपयोगकर्ता को फ़ाइल सामग्री संशोधित करने की अनुमति देती है (b) "Write" अनुमति उपयोगकर्ता को फ़ाइल हटाने की अनुमति देती है (c) "Modify" अनुमति में Read, Write, और Delete शामिल हैं (d) "Full Control" केवल अनुमतियाँ बदलने की अनुमति देता है
उत्तर: (c)
हल: Read संशोधन की अनुमति नहीं देता; Write अकेले Delete प्रदान नहीं करता; Full Control में अनुमति परिवर्तन शामिल हैं लेकिन अन्य सभी क्रियाएं भी; Modify मानक स्तर है जो Read, Write, और Delete को अनुमति-परिवर्तन अधिकारों के बिना बंडल करता है, इसलिए उत्तर है Modify अनुमति में Read, Write, और Delete शामिल हैं।
स्रोत: Microsoft Learn – NTFS permissions

23. फाइल एक्सप्लोरर के व्यू टैब में "File name extensions" सक्षम करने का क्या प्रभाव होता है?
(a) ज्ञात फ़ाइल प्रकारों के लिए एक्सटेंशन छुपाता है (b) फ़ाइल नामों को एन्क्रिप्ट करता है (c) फ़ाइलें खोलने के लिए डिफ़ॉल्ट प्रोग्राम बदलता है (d) सभी फ़ाइलों के लिए एक्सटेंशन दिखाता है (जैसे .txt, .pdf)
उत्तर: (d)
हल: इस विकल्प को अक्सर एक्सटेंशन छुपाने के रूप में गलत पढ़ा जाता है, लेकिन इसे सक्षम करने से एक्सटेंशन प्रकट होते हैं; यह एसोसिएशन नहीं बदलता या नाम एन्क्रिप्ट नहीं करता, इसलिए उत्तर है सभी फ़ाइलों के लिए एक्सटेंशन दिखाता है (जैसे .txt, .pdf)।
स्रोत: Microsoft Support – Show file extensions

24. एक उपयोगकर्ता Windows key + L दबाता है। क्या होता है?
(a) लॉक स्क्रीन खोलता है / कंप्यूटर लॉक करता है (b) सेटिंग्स ऐप खोलता है (c) रन डायलॉग खोलता है (d) सभी विंडोज़ छोटी करता है

25. कौन सा वातावरण चर प्रति-उपयोगकर्ता "AppData\Roaming" फ़ोल्डर को संदर्भित करता है?
(a) %LOCALAPPDATA% (b) %APPDATA% (c) %USERPROFILE%\AppData\Local (d) %SYSTEMROOT%\AppData
उत्तर: (b)
हल: %LOCALAPPDATA% AppData\Local को इंगित करता है; %USERPROFILE%\AppData\Local Local का विस्तारित रूप है; %SYSTEMROOT% Windows निर्देशिका है; %APPDATA% विशेष रूप से Roaming फ़ोल्डर तक विस्तारित होता है, इसलिए उत्तर है %APPDATA%।
स्रोत: Microsoft Learn – Environment variables
