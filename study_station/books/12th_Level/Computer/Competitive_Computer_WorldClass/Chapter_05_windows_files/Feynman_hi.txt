# विंडोज और फाइल प्रबंधन — फ़ाइनमैन शैली में समझ

## रोज़मर्रा की उपमा: आपका डिजिटल घर

कल्पना करें कि **Windows (विंडोज़)** एक बड़ा घर है।  
- **Desktop (डेस्कटॉप)** = घर का मुख्य हॉल — यहाँ आप तुरंत काम की चीज़ें रखते हैं।  
- **File Explorer (फाइल एक्सप्लोरर)** = घर का नक्शा और अलमारियाँ — हर कमरे (फोल्डर) में क्या रखा है, दिखाता है।  
- **Folder (फोल्डर)** = अलमारी का एक खाना — संबंधित कागज़ (फाइलें) एक साथ रखने के लिए।  
- **File (फाइल)** = कागज़ का टुकड़ा — जिस पर असली जानकारी (टेक्स्ट, फोटो, प्रोग्राम) लिखी है।  
- **Recycle Bin (रीसायकल बिन)** = कूड़ेदान — गलती से फेंकी चीज़ यहाँ से वापस ली जा सकती है, जब तक खाली न कर दें।  
- **Shortcut (शॉर्टकट)** = दीवार पर लगा तीर का निशान — असली चीज़ जहाँ है वहीं रहती है, बस यहाँ से जल्दी पहुँच जाते हैं।  
- **Path (पथ/रास्ता)** = पूरा पता: `C:\Users\Ravi\Documents\Resume.pdf` — जैसे "मकान नं. 5, गली 3, शहर दिल्ली"।

## मूल क्रियाएँ (Basic Operations)

| क्रिया | माउस से | कीबोर्ड शॉर्टकट (Windows) | उपमा |
|---|---|---|---|
| **कॉपी (Copy)** | राइट-क्लिक → Copy | `Ctrl + C` | फोटोकॉपी कराना — मूल वहीं रहता है |
| **कट (Cut)** | राइट-क्लिक → Cut | `Ctrl + X` | कागज़ काटकर हाथ में लेना — मूल जगह से हट जाएगा |
| **पेस्ट (Paste)** | राइट-क्लिक → Paste | `Ctrl + V` | हाथ का कागज़ नई जगह रखना |
| **नाम बदलें (Rename)** | राइट-क्लिक → Rename | `F2` | फाइल पर नया लेबल चिपकाना |
| **हटाएँ (Delete)** | राइट-क्लिक → Delete | `Delete` | रीसायकल बिन में डालना |
| **स्थायी हटाएँ** | — | `Shift + Delete` | सीधे कूड़ा जलाना — वापस नहीं मिलेगा |
| **नया फोल्डर** | राइट-क्लिक → New → Folder | `Ctrl + Shift + N` | नई अलमारी बनाना |
| **सब चुनें (Select All)** | — | `Ctrl + A` | कमरे का सारा सामान एक साथ उठाना |

> **नोट:** ब्राउज़र में `Ctrl + T` (नया टैब), `Ctrl + W` (टैब बंद) जैसे शॉर्टकट **Windows Explorer** में काम नहीं करते — वे ब्राउज़र-स्कोप (browser-scope) हैं।

## फाइल एक्सटेंशन (File Extension) — पहचान पत्र

`Report.docx` में `.docx` एक्सटेंशन बताता है कि यह **Word दस्तावेज़** है।  
Windows डिफ़ॉल्ट में एक्सटेंशन छिपा रखता है — **View → File name extensions** टिक करके दिखाएँ।  
गलत एक्सटेंशन (जैसे `.exe` को `.pdf` लिख देना) फाइल खोलने में दिक्कत देता है, डेटा नहीं बदलता।

---

## खोज (Search) और फ़िल्टर

- **Quick Access (क्विक एक्सेस)**: बार-बार खुलने वाले फोल्डर यहाँ पिन करें — जैसे फ्रिज पर चिपकी पर्ची।  
- **Search Box (ऊपर दाएँ)**: `*.pdf` → केवल PDF फाइलें; `ext:.pdf` → केवल PDF फाइलें; `date:last week` → पिछले हफ्ते की फाइलें।  
- **Sort/Group by**: Date modified, Type, Size — जैसे अलमारी में कपड़े रंग/आकार से लगाना।

## आम गलतियाँ (Common Mistakes)

1. **शॉर्टकट को असली फाइल समझकर डिलीट करना** — शॉर्टकट पर तीर का निशान (↗) होता है; डिलीट करने से असली फाइल नहीं जाती।  
2. **`Shift + Delete` बिना बैकअप** — रीसायकल बिन बायपास होता है, रिकवरी मुश्किल।  
3. **एक्सटेंशन छिपे रहने पर `virus.pdf.exe` को PDF समझ खोलना** — हमेशा एक्सटेंशन दिखाएँ।  
4. **C: ड्राइव (सिस्टम ड्राइव) भर देना** — Windows अपडेट/पेज फाइल के लिए 15–20% खाली रखें।  
5. **एक ही नाम की फाइल पेस्ट करके "Replace" दबा देना** — पुराना डेटा खो जाता है; बेहतर: "Compare info" या नया नाम रखें।

## 5 रीकॉल प्रश्न (Recall Questions)

**प्रश्न 1**  
`Ctrl + C` और `Ctrl + X` में मूल अंतर क्या है?  
**उत्तर:** `Ctrl + C` (Copy) मूल फाइल वहीं रखता है, डुप्लिकेट बनाता है; `Ctrl + X` (Cut) मूल फाइल को स्रोत से हटाकर क्लिपबोर्ड में ले जाता है।

**प्रश्न 2**  
फाइल एक्सटेंशन दिखाना क्यों ज़रूरी है?  
**उत्तर:** छिपे एक्सटेंशन में मैलवेयर `photo.jpg.exe` को `photo.jpg` दिखा सकता है; एक्सटेंशन देखने पर असली टाइप पता चलता है।

**प्रश्न 3**  
`Shift + Delete` कब उपयोग करें?  
**उत्तर:** केवल जब आप **पूरी तरह निश्चित** हों कि फाइल कभी वापस नहीं चाहिए — यह रीसायकल बिन बायपास कर देता है।

**प्रश्न 4**  
शॉर्टकट और असली फाइल में दृश्य अंतर क्या है?  
**उत्तर:** शॉर्टकट के आइकन पर छोटा तीर (↗) लगा होता है; असली फाइल पर नहीं।

**प्रश्न 5**  
`C:\Users\Anita\Documents\Budget.xlsx` में `C:\` क्या दर्शाता है?  
**उत्तर:** `C:\` रूट डायरेक्टरी (root directory) है — स्टोरेज डिवाइस का सबसे ऊपरी स्तर, जहाँ से सब फोल्डर शुरू होते हैं।
