101. Microsoft Word रिबन में कौन सा टैब फ़ॉन्ट प्रकार, आकार और रंग बदलने के आदेशों को समाहित करता है?
(a) Home (b) Layout (c) Insert (d) View
उत्तर: (a)
हल: Insert टैब तालिकाओं और चित्रों जैसे ऑब्जेक्ट जोड़ने के लिए है, जबकि Layout पेज सेटअप संभालता है; Home टैब फ़ॉन्ट, पैराग्राफ और स्टाइल जैसे सभी बुनियादी टेक्स्ट फ़ॉर्मेटिंग आदेशों को समूहित करता है, इसलिए उत्तर Home है।

102. Microsoft Word 2007 या बाद के संस्करण में बनाए गए दस्तावेज़ का डिफ़ॉल्ट फ़ाइल एक्सटेंशन क्या है?
(a) .doc (b) .txt (c) .docx (d) .rtf
उत्तर: (c)
हल: पुराना .doc प्रारूप Word 2003 तक उपयोग होता था; .docx Office Open XML प्रारूप है जिसे Word 2007 में पेश किया गया और यह डिफ़ॉल्ट बना हुआ है, इसलिए उत्तर .docx है।

104. Word में रूलर का मुख्य उपयोग है:
(a) दस्तावेज़ की लंबाई सेंटीमीटर में मापना (b) पेज को ज़ूम इन और आउट करना (c) टैब, इंडेंट और मार्जिन को विज़ुअली सेट करना (d) शब्दों और वर्णों की गिनती करना
उत्तर: (c)
हल: रूलर पैराग्राफ इंडेंट, टैब स्टॉप और पेज मार्जिन को समायोजित करने का विज़ुअल तरीका प्रदान करता है; यह कुल दस्तावेज़ लंबाई नहीं मापता या शब्द नहीं गिनता, इसलिए उत्तर Set tabs, indents, and margins visually है।
स्रोत: Microsoft Support – Use the ruler in Word

105. कौन सा दृश्य दस्तावेज़ को वैसा दिखाता है जैसा यह प्रिंट होने पर दिखाई देगा, जिसमें मार्जिन, हेडर और फुटर शामिल हैं?

स्रोत: Microsoft Support – Switch between views in Word

108. कौन सी सुविधा टेक्स्ट को दाएं मार्जिन पर पहुंचने पर स्वचालित रूप से अगली लाइन पर ले जाती है?

115. कौन सी सुविधा आपको सहयोगियों द्वारा किए गए सम्मिलन, विलोपन और फ़ॉर्मेटिंग परिवर्तनों का ट्रैक रखने की अनुमति देती है?

116. दस्तावेज़ को इस तरह सुरक्षित करने के लिए कि केवल ट्रैक किए गए परिवर्तन किए जा सकें, उपयोग करें:
(a) Encrypt with Password (b) Add a Digital Signature (c) Mark as Final (d) Restrict Editing → Allow only this type of editing → Tracked changes
उत्तर: (d)
हल: "Tracked changes" चयनित करके Restrict Editing लागू करता है कि सभी संपादन रिकॉर्ड किए जाएं; Encrypt with Password पूरी फ़ाइल को लॉक करता है, और Mark as Final केवल एक विज़ुअल संकेतक है, इसलिए उत्तर Restrict Editing → Allow only this type of editing → Tracked changes है।
स्रोत: Microsoft Support – Protect a document

125. Word में कौन सी मैक्रो सुरक्षा सेटिंग केवल डिजिटली हस्ताक्षरित मैक्रो को बिना प्रॉम्प्ट के चलाने की अनुमति देती है?

हल: "Disable all macros except digitally signed macros" सेटिंग हस्ताक्षरित मैक्रो को स्वचालित रूप से चलाने की अनुमति देती है जबकि अहस्ताक्षरित को अक्षम करती है; "Enable all macros" किसी भी मैक्रो को चलाता है, जो असुरक्षित है, इसलिए उत्तर Disable all macros except digitally signed macros है।
स्रोत: Microsoft Support – Macro security settings
