Card 1
Front: What is the default file extension for Microsoft Word documents (Word 2007 and later)?
Back: .docx

Card 2
Front: Which keyboard shortcut opens the Save As dialog box in Word (Windows)?
Back: F12

Card 3
Front: What is the function of Ctrl + Z in Word?
Back: Undo the last action.

Card 4
Front: Which view shows the document as it will appear when printed, including margins and page breaks?
Back: Print Layout view.

Card 5
Front: What does the "Track Changes" feature do?
Back: Records insertions, deletions, and formatting changes so they can be reviewed, accepted, or rejected.

Card 6
Front: Which tab on the Ribbon contains the Page Setup group (margins, orientation, size)?
Back: Layout tab.

Card 7
Front: What is the purpose of a Section Break in Word?
Back: Allows different page formatting (margins, orientation, headers/footers, columns) within the same document.

Card 8
Front: Which shortcut applies the Heading 1 style to the current paragraph?
Back: Ctrl + Alt + 1

Card 9
Front: What is the difference between a page break and a section break?
Back: A page break only forces a new page; a section break also allows independent page formatting for the new section.

Card 10
Front: How do you insert a non-breaking space (prevents line break between two words)?
Back: Ctrl + Shift + Spacebar

Card 11
Front: What is the maximum number of columns you can create in a Word document using the Columns dialog?
Back: 13 columns.

Card 12
Front: Which feature automatically creates a table of contents based on heading styles?
Back: References tab → Table of Contents.

Card 13
Front: What does the "Mail Merge" feature do?
Back: Combines a main document with a data source to produce personalized letters, labels, or emails for multiple recipients.

Card 14
Front: Which shortcut moves the cursor to the beginning of the document?
Back: Ctrl + Home

Card 15
Front: What is the purpose of the "Format Painter" tool?
Back: Copies formatting from one selection and applies it to another.

Card 16
Front: How do you insert a comment in a Word document?
Back: Select text → Review tab → New Comment (or Ctrl + Alt + M).

Card 17
Front: What is the default line spacing in Word (since Word 2007)?
Back: 1.15 lines with 10 pt spacing after paragraphs.

Card 18
Front: Which file format should you use to ensure a document cannot be easily edited and looks the same on any device?
Back: PDF (Portable Document Format) — use File → Save As → PDF.
