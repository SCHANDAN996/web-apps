126. Which tab on the Ribbon contains the commands for changing font type, size, and color?
(a) Insert (b) View (c) Home (d) Layout
Answer: (c)
Solution: The Insert tab is for adding objects like tables and pictures, while Layout handles page setup; the Home tab groups all basic text formatting commands such as font, paragraph, and styles, so the answer is Home.
Source: Microsoft Support – Word Ribbon overview

127. What is the keyboard shortcut to save a document in Microsoft Word on Windows?
(a) Ctrl + N (b) Ctrl + P (c) Ctrl + O (d) Ctrl + S
Answer: (d)
Solution: Ctrl + P opens the Print dialog, Ctrl + O opens a file, and Ctrl + N creates a new document; the standard shortcut for saving is Ctrl + S, so the answer is Ctrl + S.
Source: Microsoft Learn – Keyboard shortcuts in Word

128. Which view shows the document as it will appear when printed, including margins, headers, and footers?
(a) Print Layout (b) Web Layout (c) Outline (d) Draft
Answer: (a)
Solution: Draft view hides margins and headers/footers, Web Layout optimizes for screen reading, and Outline shows heading structure; Print Layout displays the exact printed appearance, so the answer is Print Layout.
Source: Microsoft Support – Switch between views

129. To select an entire paragraph quickly, a user can:
(a) Triple-click anywhere in the paragraph (b) Click the left margin once (c) Press Ctrl + A (d) Double-click anywhere in the paragraph
Answer: (a)
Solution: Double-click selects a word, Ctrl + A selects the whole document, and a single margin click selects a line; triple-clicking anywhere in the paragraph selects the entire paragraph, so the answer is triple-click anywhere in the paragraph.
Source: Microsoft Learn – Select text

130. The command to reverse the last action performed in Word is:
(a) Undo (b) Repeat (c) Redo (d) Restore
Answer: (a)
Solution: Redo reapplies an undone action, Repeat duplicates the last command, and Restore is not a standard editing command; Undo reverses the most recent action, so the answer is Undo.
Source: Microsoft Support – Undo, redo, or repeat an action

131. Which shortcut key combination opens the Find and Replace dialog box with the Replace tab active?
(a) Ctrl + H (b) Ctrl + F (c) Ctrl + G (d) Ctrl + R
Answer: (a)
Solution: Ctrl + F opens the Find tab, Ctrl + G opens Go To, and Ctrl + R aligns text right; Ctrl + H directly opens the Replace tab, so the answer is Ctrl + H.
Source: Microsoft Learn – Keyboard shortcuts for Find and Replace

132. What does the "Clear All Formatting" button on the Home tab do?
(a) Deletes the selected text (b) Resets selected text to default font and paragraph settings (c) Removes only bold and italic (d) Clears the clipboard
Answer: (b)
Solution: It does not delete text, nor does it only remove bold/italic, and it does not affect the clipboard; it resets the selection to the default style formatting, so the answer is resets selected text to default font and paragraph settings.
Source: Microsoft Support – Clear formatting

133. What is the keyboard shortcut to apply double line spacing to a paragraph in Microsoft Word?
(a) Ctrl + 1 (b) Ctrl + 5 (c) Ctrl + 2 (d) Ctrl + 0
Answer: (c)
Solution: Ctrl + 1 sets single spacing, Ctrl + 5 sets 1.5 spacing, and Ctrl + 0 adds or removes spacing before a paragraph; Ctrl + 2 directly applies double line spacing, so the answer is Ctrl + 2.
Source: Microsoft Support – Keyboard shortcuts for line spacing

134. Which of the following is NOT a valid bullet list style in Word's default bullet library?
(a) Solid round bullet (b) Checkbox bullet (c) Hollow square bullet (d) Arrow bullet
Answer: (b)
Solution: Solid round, hollow square, and arrow bullets are built-in; checkbox bullets require a symbol or content control, not the default bullet library, so the answer is Checkbox bullet.
Source: Microsoft Support – Create a bulleted list

135. The Page Setup dialog box allows the user to change all of the following EXCEPT:
(a) Margins (b) Paper size (c) Orientation (d) Font color
Answer: (d)
Solution: Margins, paper size, and orientation are page-level settings in Page Setup; font color is a character formatting option found on the Home tab, so the answer is Font color.
Source: Microsoft Support – Set page margins

136. A header appears in which part of a printed page?
(a) Bottom margin (b) Left margin (c) Top margin (d) Right margin
Answer: (c)
Solution: Footers appear in the bottom margin; left and right margins are vertical edges; headers are positioned in the top margin area, so the answer is Top margin.
Source: Microsoft Support – Add a header or footer

137. To insert a page break at the current cursor position, the shortcut is:
(a) Alt + Enter (b) Ctrl + Enter (c) Ctrl + Shift + Enter (d) Shift + Enter
Answer: (b)
Solution: Ctrl + Shift + Enter inserts a column break, Alt + Enter is not a standard Word shortcut, and Shift + Enter creates a line break; Ctrl + Enter inserts a page break, so the answer is Ctrl + Enter.
Source: Microsoft Learn – Insert a page break

138. Which tab contains the command to insert a table?
(a) Home (b) Layout (c) References (d) Insert
Answer: (d)
Solution: Home has text formatting, Layout has page setup, and References has citations; the Insert tab groups tables, pictures, shapes, and other objects, so the answer is Insert.
Source: Microsoft Support – Insert a table

139. When a picture is selected, which contextual tab appears on the Ribbon?
(a) Image Tools (b) Drawing Tools (c) Graphics Format (d) Picture Format
Answer: (d)
Solution: Drawing Tools appears for shapes, Image Tools and Graphics Format are not standard tab names; selecting a picture activates the Picture Format tab, so the answer is Picture Format.
Source: Microsoft Support – Format pictures

140. The default file extension for a Word document saved in the current format is:
(a) .doc (b) .docx (c) .rtf (d) .dotx
Answer: (b)
Solution: .doc is the legacy binary format, .dotx is a template, and .rtf is Rich Text Format; the modern default is .docx, so the answer is .docx.
Source: Microsoft Support – File formats in Word

141. Which feature automatically corrects common typing errors like "teh" to "the" as you type?
(a) AutoText (b) AutoComplete (c) AutoCorrect (d) AutoFormat
Answer: (c)
Solution: AutoText stores reusable content, AutoComplete suggests words, and AutoFormat applies formatting; AutoCorrect fixes spelling and capitalization errors automatically, so the answer is AutoCorrect.
Source: Microsoft Support – AutoCorrect options

142. To apply a heading style that appears in the Navigation pane, the user should use:
(a) Styles gallery on the Home tab (b) Bold and large font size (c) Font dialog box (d) Paragraph dialog box
Answer: (a)
Solution: Manual formatting does not create outline levels, Font and Paragraph dialogs do not assign heading styles; the Styles gallery applies built-in heading styles that populate the Navigation pane, so the answer is Styles gallery on the Home tab.
Source: Microsoft Support – Use heading styles

143. The "Track Changes" feature is located on which tab?
(a) References (b) View (c) Layout (d) Review
Answer: (d)
Solution: View controls document display, References manages citations, Layout handles page setup; Review contains tracking, comments, and comparing tools, so the answer is Review.
Source: Microsoft Support – Track changes

144. Which command combines multiple documents into one by inserting the content of other files?
(a) Insert Text from File (b) Insert Object (c) Combine Documents (d) Compare Documents
Answer: (a)
Solution: Insert Object embeds files, Combine merges revisions, Compare shows differences; Insert Text from File inserts the content of another file at the cursor, so the answer is Insert Text from File.
Source: Microsoft Support – Insert the contents of a file

145. To prevent accidental changes to a document, a user can apply:
(a) Read Mode (b) Restrict Editing (c) Protect Document with password (d) Both (b) and (c)
Answer: (d)
Solution: Read Mode is a view, not protection; Restrict Editing limits formatting/editing types, and password protection encrypts the file; both (b) and (c) are valid protection methods, so the answer is Both (b) and (c).
Source: Microsoft Support – Protect a document

146. The keyboard shortcut to open the Print preview and Print dialog is:
(a) Alt + P (b) Ctrl + Shift + P (c) Ctrl + P (d) Ctrl + F2
Answer: (c)
Solution: Ctrl + Shift + P opens the Font dialog, Alt + P has no standard function, Ctrl + F2 opens Print Preview in some versions; the universal shortcut is Ctrl + P, so the answer is Ctrl + P.
Source: Microsoft Learn – Print shortcuts

147. Which of the following is a valid method to create a numbered list?
(a) Type "1." and press Space (b) Click the Numbering button on the Home tab (c) Press Ctrl + Shift + L (d) Both (a) and (b)
Answer: (d)
Solution: Ctrl + Shift + L applies the List Bullet style, not numbering; typing "1." + Space triggers AutoFormat numbering, and the Numbering button starts a numbered list, so the answer is Both (a) and (b).
Source: Microsoft Support – Create a numbered list

148. The "Format Painter" tool copies:
(a) Formatting only (b) Paragraph structure only (c) Both text and formatting (d) Text content
Answer: (a)
Solution: It does not copy text content or paragraph structure; it copies character and paragraph formatting from the source to the destination, so the answer is Formatting only.
Source: Microsoft Support – Copy formatting with Format Painter

149. Which of the following is NOT a valid data source for Mail Merge in Microsoft Word?
(a) An existing Excel file (b) A PDF file (c) A new list typed in Word (d) Outlook contacts
Answer: (b)
Solution: Mail Merge accepts data from Excel files, Outlook contacts, and lists typed directly in Word; a PDF file cannot be used directly as a data source, so the answer is A PDF file.
Source: Microsoft Support – Mail merge data sources

150. When a section break "Next Page" is inserted, the new section starts:
(a) On the same page (b) On the next page (c) On the next even page (d) On the next odd page
Answer: (b)
Solution: Continuous starts on the same page, Even Page and Odd Page force specific parity; Next Page always begins the new section on the following page, so the answer is On the next page.
Source: Microsoft Support – Section breaks
