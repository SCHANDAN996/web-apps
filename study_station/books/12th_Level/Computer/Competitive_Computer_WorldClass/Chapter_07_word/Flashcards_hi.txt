कार्ड 1
सामने: MS Word में नया दस्तावेज़ बनाने का डिफ़ॉल्ट कीबोर्ड शॉर्टकट (Windows/Office) क्या है?
पीछे: Ctrl + N — यह Word एप्लिकेशन के अंदर नया ब्लैंक दस्तावेज़ खोलता है। ब्राउज़र में Ctrl + N नई विंडो खोलता है, Word दस्तावेज़ नहीं।

कार्ड 2
सामने: किसी खुले दस्तावेज़ को सहेजने (Save) का शॉर्टकट क्या है? यदि दस्तावेज़ पहले कभी सहेजा नहीं गया तो क्या होगा?
पीछे: Ctrl + S — पहले से सहेजे गए दस्तावेज़ को अपडेट करता है; नए दस्तावेज़ पर "Save As" डायलॉग खुलता है। ब्राउज़र में Ctrl + S पेज सहेजता है, Word फ़ाइल नहीं।

कार्ड 3
सामने: "Save As" डायलॉग खोलने का शॉर्टकट क्या है? यह कब उपयोगी है?
पीछे: F12 (या Fn + F12) — नया नाम/स्थान/फॉर्मेट में सहेजने के लिए। यह Word का डिफ़ॉल्ट शॉर्टकट है।

कार्ड 4
सामने: दस्तावेज़ प्रिंट करने का शॉर्टकट और प्रिंट पूर्वावलोकन (Print Preview) कैसे खोलें?
पीछे: Ctrl + P — प्रिंट डायलॉग सहित पूर्वावलोकन खोलता है। ब्राउज़र में Ctrl + P ब्राउज़र का अपना प्रिंट इंजन उपयोग करता है, Word का नहीं।

कार्ड 5
सामने: टेक्स्ट को बोल्ड, इटैलिक, अंडरलाइन करने के शॉर्टकट क्या हैं?
पीछे: Ctrl + B (Bold), Ctrl + I (Italic), Ctrl + U (Underline) — ये टॉगल हैं; दोबारा दबाने से प्रभाव हट जाता है। ब्राउज़र के संपादक में भी यही काम करते हैं।

कार्ड 6
सामने: पैराग्राफ़ को बाएँ, केंद्र, दाएँ, दोनों ओर संरेखित (Justify) करने के शॉर्टकट बताएँ।
पीछे: Ctrl + L (Left), Ctrl + E (Center), Ctrl + R (Right), Ctrl + J (Justify) — चयनित पैराग्राफ़ पर लागू होते हैं।

कार्ड 7
सामने: फॉन्ट आकार बढ़ाने/घटाने के कीबोर्ड शॉर्टकट क्या हैं?
पीछे: Ctrl + Shift + > (बढ़ाएँ), Ctrl + Shift + < (घटाएँ) — चयनित टेक्स्ट पर काम करते हैं। Ctrl + [ और Ctrl + ] भी क्रमशः घटाते/बढ़ाते हैं (1 पॉइंट)।

कार्ड 8
सामने: "Find" (खोजें), "Replace" (बदलें), "Go To" (जाएँ) डायलॉग खोलने के शॉर्टकट क्या हैं?
पीछे: Ctrl + F (Find), Ctrl + H (Replace), Ctrl + G (Go To) — तीनों एक ही डायलॉग के अलग टैब खोलते हैं। ब्राउज़र में Ctrl + F केवल पेज खोजता है।

कार्ड 9
सामने: पूर्ववत् (Undo) और पुनः करें (Redo) के शॉर्टकट क्या हैं? कितने चरण याद रहते हैं?
पीछे: Ctrl + Z (Undo), Ctrl + Y (Redo) — Word डिफ़ॉल्ट रूप से 100 Undo स्तर रखता है (Options → Advanced में बदल सकते हैं)। ब्राउज़र में भी Ctrl + Z/Y काम करते हैं लेकिन अलग इतिहास।

कार्ड 10
सामने: पूरे दस्तावेज़ का चयन (Select All), एक शब्द, एक पंक्ति, एक पैराग्राफ़ चुनने के शॉर्टकट बताएँ।
पीछे: Ctrl + A (सब), डबल-क्लिक (शब्द), बाएँ मार्जिन में क्लिक (पंक्ति), पैराग्राफ़ में ट्रिपल-क्लिक (पैराग्राफ़), बाएँ मार्जिन में ट्रिपल-क्लिक (पूरा दस्तावेज़)।

कार्ड 11
सामने: पेज ब्रेक (Page Break) और सेक्शन ब्रेक (Section Break) डालने के शॉर्टकट क्या हैं?
पीछे: Ctrl + Enter (Page Break) — Layout → Breaks → Section Breaks (Next Page/Continuous/Even/Odd) के लिए कोई डिफ़ॉल्ट शॉर्टकट नहीं; Alt → P → B → दिशा कुंजी → Enter से डालें।

कार्ड 12
सामने: हेडर/फुटर संपादन मोड में जाने और बंद करने के शॉर्टकट क्या हैं?
पीछे: Alt → V → H (पुराना मेन्यू) या Insert → Header → Edit Header; बंद करने के लिए Esc या Close Header/Footer बटन। डबल-क्लिक शीर्ष/निचले मार्जिन पर भी खोलता है।

कार्ड 13
सामने: टेबल में नई पंक्ति जोड़ने, सेल विभाजित करने, पंक्ति/स्तंभ हटाने के शॉर्टकट बताएँ।
पीछे: Tab (अंतिम सेल में नई पंक्ति), Alt + Shift + ↑/↓ (पंक्ति ऊपर/नीचे ले जाएँ), Layout टैब → Delete → Rows/Columns/Cells — सीधे शॉर्टकट नहीं; संदर्भ मेन्यू (Shift + F10) से तेज़।

कार्ड 14
सामने: "Track Changes" (परिवर्तन ट्रैक करें) चालू/बंद करने और अगले/पिछले परिवर्तन पर जाने के शॉर्टकट क्या हैं?
पीछे: Ctrl + Shift + E (टॉगल), Alt + Shift + N (अगला), Alt + Shift + P (पिछला) — Review टैब में बटन भी हैं। केवल Word डेस्कटॉप में काम करते हैं, Word Online में सीमित।

कार्ड 15
सामने: Mail Merge (मेल मर्ज) शुरू करने के चरण और मुख्य दस्तावेज़ प्रकार बताएँ।
पीछे: Mailings → Start Mail Merge → Letters/Emails/Envelopes/Labels/Directory → Select Recipients → Insert Merge Fields → Finish & Merge। डेटा स्रोत: Excel, CSV, Outlook Contacts, Access।

कार्ड 16
सामने: दस्तावेज़ के दृश्य (Views) बदलने के शॉर्टकट/तरीके क्या हैं? प्रत्येक दृश्य का उपयोग लिखें।
पीछे: View टैब या स्टेटस बार आइकन: Read Mode (पठन), Print Layout (डिफ़ॉल्ट, प्रिंट जैसा), Web Layout (वेब पेज), Outline (शीर्षक संरचना), Draft (तेज़ संपादन, कोई पेज ब्रेक नहीं)। शॉर्टकट: Alt → W दबाने के बाद की-टिप्स — R (Read Mode), P (Print Layout), W (Web Layout), O (Outline), D (Draft)।

कार्ड 17
सामने: स्टाइल्स (Styles) लागू करने, नया स्टाइल बनाने, स्टाइल पेन खोलने के शॉर्टकट बताएँ।
पीछे: Ctrl + Shift + S (Apply Styles डायलॉग), Alt + Ctrl + Shift + S (Styles पेन), Ctrl + Alt + 1/2/3 (Heading 1/2/3)। नया स्टाइल: Styles पेन → New Style बटन।

कार्ड 18
सामने: दस्तावेज़ सुरक्षा: "Restrict Editing" (संपादन प्रतिबंधित करें), पासवर्ड से खोलना/संशोधन रोकना कैसे सेट करें?
पीछे: File → Info → Protect Document → Encrypt with Password (खोलने के लिए) / Restrict Editing (संपादन सीमित करें: No changes/Track changes/Comments/Filling forms) → Yes, Start Enforcing Protection → पासवर्ड वैकल्पिक।
