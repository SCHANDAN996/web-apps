26. Which tab on the Ribbon contains the Font group for character formatting?
(a) Insert (b) Home (c) Layout (d) View
Answer: (b)
Solution: The Home tab holds the most frequently used formatting groups — Font, Paragraph, and Styles — while Insert handles objects, Layout manages page setup, and View controls document views; therefore the correct tab is Home.
Source: Microsoft Support – Word Ribbon overview

27. What is the keyboard shortcut to save a document in Microsoft Word on Windows?
(a) F12 (b) Ctrl+Shift+S (c) Alt+S (d) Ctrl+S
Answer: (d)
Solution: Ctrl+S saves the current document instantly; Ctrl+Shift+S opens Save As, Alt+S has no default save function, and F12 also opens Save As — so the direct save shortcut is Ctrl+S.
Source: Microsoft Learn – Word keyboard shortcuts

28. Which file extension is used by default for Word documents created in Word 2007 and later?
(a) .doc (b) .txt (c) .rtf (d) .docx
Answer: (d)
Solution: The Office Open XML format introduced in Word 2007 uses .docx; .doc is the legacy binary format, .rtf is Rich Text Format, and .txt is plain text — hence the default modern extension is .docx.
Source: Microsoft Support – File formats in Word

29. To apply a heading style that will appear in an automatic Table of Contents, you should use:
(a) Bold formatting (b) Underline (c) Font size 16 (d) Heading 1 style
Answer: (d)
Solution: Only built-in heading styles (Heading 1, Heading 2, etc.) are recognized by the Table of Contents feature; manual formatting like bold, font size, or underline does not create outline levels — so Heading 1 style is required.
Source: Microsoft Support – Create a table of contents

30. Which view shows the document as it will look when printed, including margins and page breaks?
(a) Draft (b) Web Layout (c) Print Layout (d) Outline
Answer: (c)
Solution: Print Layout displays pages with margins, headers, footers, and exact positioning; Draft hides some layout elements, Web Layout shows continuous flow, and Outline focuses on heading structure — therefore Print Layout is the correct view.
Source: Microsoft Support – Switch between views

31. The shortcut Ctrl+Z performs which action?
(a) Redo (b) Cut (c) Undo (d) Paste
Answer: (c)
Solution: Ctrl+Z reverses the last action (Undo); Ctrl+Y or Ctrl+Shift+Z performs Redo, Ctrl+X cuts, and Ctrl+V pastes — so the undo shortcut is Ctrl+Z.
Source: Microsoft Learn – Common shortcuts

32. To insert a page break at the current cursor position, which shortcut is used?
(a) Ctrl+Enter (b) Shift+Enter (c) Alt+Enter (d) Ctrl+Shift+Enter
Answer: (a)
Solution: Ctrl+Enter inserts a manual page break; Shift+Enter creates a line break, Alt+Enter has no standard break function, and Ctrl+Shift+Enter inserts a column break in multi-column layouts — thus the page break shortcut is Ctrl+Enter.
Source: Microsoft Support – Insert a page break

33. Which feature allows you to replace all occurrences of a word with another word in one operation?
(a) Find (b) Replace (c) Select All (d) Go To
Answer: (b)
Solution: The Replace dialog (Ctrl+H) finds each occurrence and substitutes it; Find only locates text, Select All highlights everything, and Go To navigates to a location — so Replace is the correct feature.
Source: Microsoft Support – Find and replace text

34. What does the "Track Changes" feature do?
(a) Marks insertions, deletions, and formatting changes (b) Saves versions automatically (c) Creates a backup copy (d) Locks the document
Answer: (a)
Solution: Track Changes records every edit — insertions, deletions, moves, and formatting — so reviewers can accept or reject them; it does not auto-save versions, create backups, or lock the document — hence it marks changes.
Source: Microsoft Support – Track changes

35. To create a bulleted list quickly, you can type an asterisk (*) followed by a space at the beginning of a line. This is an example of:
(a) AutoFormat As You Type (b) AutoCorrect (c) Quick Parts (d) Building Blocks
Answer: (a)
Solution: AutoFormat As You Type automatically converts typed characters like * or 1. into formatted lists; AutoCorrect fixes spelling, Quick Parts stores reusable content, and Building Blocks is the gallery for document parts — so this behavior is AutoFormat As You Type.
Source: Microsoft Support – AutoFormat options

36. Which tab contains the "Page Setup" group with Margins, Orientation, and Size commands?
(a) Home (b) Insert (c) Layout (d) References
Answer: (c)
Solution: The Layout tab (called Page Layout in older versions) groups all page-level settings — Margins, Orientation, Size, Columns, Breaks — while Home handles text, Insert adds objects, and References manages citations — therefore Layout is the correct tab.
Source: Microsoft Support – Page Layout tab

37. The shortcut Ctrl+A selects:
(a) Current word (b) Current paragraph (c) Current line (d) Entire document
Answer: (d)
Solution: Ctrl+A selects all content in the document; Ctrl+Shift+Right Arrow extends by word, Ctrl+Shift+Down Arrow by paragraph, and Home/End with Shift selects a line — so the whole document is selected by Ctrl+A.
Source: Microsoft Learn – Selection shortcuts

38. To insert a table, you go to the Insert tab and click:
(a) Shapes (b) Table (c) SmartArt (d) Chart
Answer: (b)
Solution: The Table button on the Insert tab opens the grid for creating tables; Shapes draws lines/boxes, SmartArt creates diagrams, and Chart inserts data-driven graphs — thus Table is the correct command.
Source: Microsoft Support – Insert a table

39. Which feature lets you send personalized letters to multiple recipients using a data source?
(a) Document Inspector (b) Quick Parts (c) Mail Merge (d) Compare
Answer: (c)
Solution: Mail Merge combines a main document with a recipient list to produce individualized output; Quick Parts stores reusable snippets, Document Inspector checks metadata, and Compare shows differences between documents — so Mail Merge is the feature.

40. The status bar at the bottom of the Word window shows all of the following EXCEPT:
(a) Ribbon tabs (b) Word count (c) Zoom slider (d) Page number
Answer: (a)
Solution: The status bar displays page number, word count, proofing status, view buttons, and zoom slider; Ribbon tabs are at the top of the window — therefore Ribbon tabs are not on the status bar.

41. To apply double line spacing to a paragraph, you can use the shortcut:
(a) Ctrl+1 (b) Ctrl+5 (c) Ctrl+2 (d) Ctrl+0
Answer: (c)
Solution: Ctrl+2 sets double spacing; Ctrl+1 is single, Ctrl+5 is 1.5 lines, and Ctrl+0 adds/removes 12 pt before paragraph — so double spacing is Ctrl+2.
Source: Microsoft Learn – Paragraph spacing shortcuts

42. Which command removes all formatting from selected text and returns it to the default style?
(a) Cut (b) Clear All Formatting (c) Copy (d) Format Painter
Answer: (b)
Solution: The Clear All Formatting button (eraser icon) strips manual formatting and restores the underlying style; Cut removes text, Copy duplicates it, and Format Painter copies formatting — thus Clear All Formatting is correct.
Source: Microsoft Support – Clear formatting

43. To insert a header that appears on every page, you double-click the top margin area or use the Insert tab → Header command. This area is called the:
(a) Footer (b) Header (c) Margin note (d) Watermark
Answer: (b)
Solution: The top margin area for repeating content is the Header; Footer is the bottom area, Margin note is not a standard term, and Watermark is a background image — so the area is the Header.
Source: Microsoft Support – Add a header

44. The "Format Painter" tool copies:
(a) Formatting only (b) Text content (c) Both text and formatting (d) Styles only
Answer: (a)
Solution: Format Painter copies character and paragraph formatting from one selection to another without copying the text itself; it does not copy content or style definitions — therefore it copies formatting only.
Source: Microsoft Support – Format Painter

45. Which file format preserves document formatting and is widely accepted for sharing final documents?
(a) .docx (b) .pdf (c) .rtf (d) .txt
Answer: (b)
Solution: PDF (Portable Document Format) locks layout and fonts for consistent viewing across devices; .docx is editable, .rtf has limited fidelity, and .txt loses all formatting — so PDF is best for final sharing.
Source: Microsoft Support – Save as PDF

46. In a mail merge, the "Edit Recipient List" button allows you to:
(a) Change the main document text (b) Insert merge fields (c) Filter, sort, or select specific recipients (d) Preview the merged letters
Answer: (c)
Solution: Edit Recipient List opens the data source view where you can filter, sort, check/uncheck recipients, and refine the list; it does not edit the main document, insert fields, or preview results — so it manages recipient selection.
Source: Microsoft Support – Mail merge recipients

47. To create a cross-reference to a heading in the same document, you use the References tab → Cross-reference. The reference type must be:
(a) Bookmark (b) Footnote (c) Numbered item (d) Heading
Answer: (d)
Solution: Cross-references to document headings require the "Heading" reference type; Bookmark links to bookmarked locations, Numbered item targets list entries, and Footnote references notes — thus Heading is the correct type.
Source: Microsoft Support – Cross-references

48. The "Document Inspector" checks for and removes hidden metadata such as:
(a) Comments, revisions, and document properties (b) Spelling errors (c) Broken links (d) Missing fonts
Answer: (a)
Solution: Document Inspector finds and removes personal information — comments, tracked changes, versions, custom properties, and hidden text; it does not check spelling, links, or fonts — so it targets metadata like comments and properties.
Source: Microsoft Support – Document Inspector

49. When you apply a "Style Set" from the Design tab, it changes:
(a) The entire document's theme fonts, colors, and heading styles (b) Only the font of the current paragraph (c) Page margins and orientation (d) The default template for new documents
Answer: (a)
Solution: A Style Set applies a coordinated collection of heading styles, body text, and theme colors/fonts across the whole document; it does not affect only one paragraph, page setup, or the global template — therefore it updates the document's theme styles.
Source: Microsoft Support – Style sets
