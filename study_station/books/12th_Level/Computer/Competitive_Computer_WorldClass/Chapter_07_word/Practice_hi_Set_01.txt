1. Microsoft Word 2007 और बाद के संस्करणों में बनाए गए दस्तावेज़ों का डिफ़ॉल्ट फ़ाइल एक्सटेंशन क्या है?
(a) .doc (b) .txt (c) .rtf (d) .docx
उत्तर: (d)
हल: .doc एक्सटेंशन Word 97–2003 में उपयोग होता था; .docx (Office Open XML) Word 2007 से डिफ़ॉल्ट है, इसलिए उत्तर .docx है।
स्रोत: Microsoft Support

2. Windows पर Microsoft Word में वर्तमान दस्तावेज़ को सहेजने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Ctrl+A (b) Ctrl+S (c) Ctrl+Shift+S (d) Alt+S
उत्तर: (b)
हल: Ctrl+A सभी टेक्स्ट का चयन करता है; Ctrl+S Windows Office ऐप्स में यूनिवर्सल Save शॉर्टकट है, इसलिए उत्तर Ctrl+S है।
स्रोत: Microsoft Learn

3. Word में चयनित टेक्स्ट या ऑब्जेक्ट को क्लिपबोर्ड पर कॉपी करने के लिए कौन सा शॉर्टकट है?
(a) Ctrl+V (b) Ctrl+C (c) Ctrl+X (d) Ctrl+P
उत्तर: (b)
हल: Ctrl+V पेस्ट करता है, Ctrl+X कट करता है; Ctrl+C चयन को क्लिपबोर्ड पर कॉपी करता है, इसलिए उत्तर Ctrl+C है।
स्रोत: Microsoft Learn

4. Word में क्लिपबोर्ड की सामग्री को इंसर्शन पॉइंट पर पेस्ट करने के लिए कौन सा शॉर्टकट है?
(a) Ctrl+V (b) Ctrl+C (c) Ctrl+X (d) Ctrl+Z
उत्तर: (a)
हल: Ctrl+C कॉपी करता है और Ctrl+X कट करता है; Ctrl+V पेस्ट ऑपरेशन करता है, इसलिए उत्तर Ctrl+V है।
स्रोत: Microsoft Learn

5. Word में चयनित सामग्री को काटकर क्लिपबोर्ड पर रखने के लिए कौन सा शॉर्टकट है?
(a) Ctrl+X (b) Ctrl+V (c) Ctrl+Z (d) Ctrl+C
उत्तर: (a)
हल: Ctrl+C बिना हटाए कॉपी करता है; Ctrl+X चयन को क्लिपबोर्ड पर ले जाता है, इसलिए उत्तर Ctrl+X है।
स्रोत: Microsoft Learn

6. Microsoft Word में अंतिम क्रिया को पूर्ववत करने के लिए कौन सा शॉर्टकट है?
(a) Ctrl+Z (b) Ctrl+Y (c) Ctrl+Shift+Z (d) Alt+Backspace
उत्तर: (a)
हल: Ctrl+Y पूर्ववत की गई क्रिया को दोहराता है; Ctrl+Z मानक Undo शॉर्टकट है, इसलिए उत्तर Ctrl+Z है।
स्रोत: Microsoft Learn

7. Word में पूर्ववत की गई क्रिया को फिर से करने (Redo) के लिए कौन सा शॉर्टकट है?
(a) Ctrl+Z (b) Ctrl+Shift+Z (c) Ctrl+Y (d) Ctrl+U
उत्तर: (c)
हल: Ctrl+Z पूर्ववत करता है; Ctrl+Y (या Ctrl+Shift+Z) अंतिम पूर्ववत क्रिया को फिर से करता है, इसलिए उत्तर Ctrl+Y है।
स्रोत: Microsoft Learn

8. Word में चयनित टेक्स्ट पर बोल्ड फ़ॉर्मेटिंग लागू करने के लिए कौन सा शॉर्टकट है?
(a) Ctrl+D (b) Ctrl+I (c) Ctrl+U (d) Ctrl+B
उत्तर: (d)
हल: Ctrl+I इटैलिक करता है और Ctrl+U अंडरलाइन करता है; Ctrl+B बोल्ड फ़ॉर्मेटिंग को टॉगल करता है, इसलिए उत्तर Ctrl+B है।
स्रोत: Microsoft Learn

9. Word में चयनित टेक्स्ट पर इटैलिक फ़ॉर्मेटिंग लागू करने के लिए कौन सा शॉर्टकट है?
(a) Ctrl+I (b) Ctrl+U (c) Ctrl+Shift+I (d) Ctrl+B
उत्तर: (a)
हल: Ctrl+B बोल्ड है और Ctrl+U अंडरलाइन; Ctrl+I इटैलिक को टॉगल करता है, इसलिए उत्तर Ctrl+I है।
स्रोत: Microsoft Learn

10. Word में चयनित टेक्स्ट पर अंडरलाइन फ़ॉर्मेटिंग लागू करने के लिए कौन सा शॉर्टकट है?
(a) Ctrl+B (b) Ctrl+I (c) Ctrl+U (d) Ctrl+Shift+U
उत्तर: (c)
हल: Ctrl+B और Ctrl+I बोल्ड और इटैलिक संभालते हैं; Ctrl+U अंडरलाइन को टॉगल करता है, इसलिए उत्तर Ctrl+U है।
स्रोत: Microsoft Learn

11. Word में कौन सा दृश्य दस्तावेज़ को वैसा दिखाता है जैसा वह प्रिंट होने पर दिखाई देगा, जिसमें मार्जिन और पेज ब्रेक शामिल हैं?
(a) Draft (b) Print Layout (c) Web Layout (d) Outline
उत्तर: (b)
हल: Draft दृश्य मार्जिन और पेज ब्रेक छुपाता है; Print Layout सटीक प्रिंटेड उपस्थिति प्रदर्शित करता है, इसलिए उत्तर Print Layout है।
स्रोत: Microsoft Support

12. कौन सी सुविधा टाइप करते समय स्वचालित रूप से वर्तनी और व्याकरण की जांच करती है, त्रुटियों को रंगीन लहरदार रेखाओं से चिह्नित करती है?
(a) Thesaurus (b) AutoCorrect (c) Spelling & Grammar (d) Word Count
उत्तर: (c)
हल: AutoCorrect टाइपो को स्वचालित रूप से ठीक करता है; रीयल-टाइम लहरदार-रेखा चेकर Spelling & Grammar सुविधा है, इसलिए उत्तर Spelling & Grammar है।
स्रोत: Microsoft Support

13. मेल मर्ज ऑपरेशन में, कौन सा घटक परिवर्तनीय डेटा (नाम, पते) को मुख्य दस्तावेज़ में मर्ज करने के लिए रखता है?
(a) Main Document (b) Template (c) Merge Field (d) Data Source
उत्तर: (d)
हल: मुख्य दस्तावेज़ निश्चित टेक्स्ट रखता है; Data Source (Excel शीट, Access तालिका, आदि) परिवर्तनीय रिकॉर्ड प्रदान करता है, इसलिए उत्तर Data Source है।
स्रोत: Microsoft Learn

14. डिफ़ॉल्ट रूप से Word दस्तावेज़ में हेडर और फुटर कहाँ दिखाई देते हैं?
(a) बाएँ और दाएँ मार्जिन (b) प्रत्येक पृष्ठ के ऊपरी और निचले मार्जिन (c) मुख्य टेक्स्ट क्षेत्र के ऊपर और नीचे (d) केवल पहले पृष्ठ पर
उत्तर: (b)
हल: हेडर ऊपरी मार्जिन में और फुटर निचले मार्जिन में प्रत्येक पृष्ठ पर प्रिंट होते हैं जब तक कि Different First Page सेट न हो, इसलिए उत्तर प्रत्येक पृष्ठ के ऊपरी और निचले मार्जिन है।
स्रोत: Microsoft Support

15. Word में मैन्युअल पेज ब्रेक डालने के लिए कौन सा शॉर्टकट है?

16. Word में Find पेन (Navigation पेन) खोलने के लिए कौन सा शॉर्टकट है?

18. Word में संपूर्ण दस्तावेज़ सामग्री का चयन करने के लिए कौन सा शॉर्टकट है?

21. Word में कौन सा सेक्शन ब्रेक नए सेक्शन को अगले पृष्ठ पर शुरू करता है?
(a) Next Page (b) Even Page (c) Continuous (d) Odd Page
उत्तर: (a)
हल: Continuous उसी पृष्ठ पर शुरू होता है; Even/Odd Page अगले सम/विषम पृष्ठ को बाध्य करते हैं; Next Page नए सेक्शन को तुरंत अगले पृष्ठ पर शुरू करता है, इसलिए उत्तर Next Page है।
स्रोत: Microsoft Support

22. जब Track Changes चालू होता है, तो दस्तावेज़ में डिलीशन आमतौर पर कैसे प्रदर्शित होते हैं?
(a) पीले रंग में हाइलाइटेड (b) स्ट्राइकथ्रू फ़ॉर्मेटिंग (c) मार्जिन में ले जाया गया (d) केवल लाल फ़ॉन्ट रंग
उत्तर: (b)
हल: इंसर्शन अंडरलाइन दिखाई देते हैं; डिलीशन स्ट्राइकथ्रू के साथ दिखाए जाते हैं (या बलून में), इसलिए उत्तर स्ट्राइकथ्रू फ़ॉर्मेटिंग है।
स्रोत: Microsoft Support

23. हेडिंग पर कौन सी सुविधा लागू की जानी चाहिए ताकि Word स्वचालित रूप से Table of Contents बना सके?
(a) बोल्ड फ़ॉर्मेटिंग (b) बुकमार्क (c) हेडिंग स्टाइल्स (d) आउटलाइन लेवल
उत्तर: (c)
हल: केवल बोल्ड या आउटलाइन लेवल TOC प्रविष्टियों को चिह्नित नहीं करता; अंतर्निहित हेडिंग स्टाइल्स (Heading 1, Heading 2, आदि) लागू करने से स्वचालित TOC निर्माण सक्षम होता है, इसलिए उत्तर हेडिंग स्टाइल्स है।
स्रोत: Microsoft Learn

24. Word के आधुनिक संस्करणों में डिफ़ॉल्ट मैक्रो सुरक्षा सेटिंग क्या है जो सुरक्षा और कार्यक्षमता को संतुलित करती है?
(a) सभी मैक्रो सक्षम करें (b) बिना सूचना के सभी मैक्रो अक्षम करें (c) सूचना के साथ सभी मैक्रो अक्षम करें (d) डिजिटली हस्ताक्षरित मैक्रो को छोड़कर सभी मैक्रो अक्षम करें
उत्तर: (c)
हल: "सभी सक्षम करें" असुरक्षित है; "बिना सूचना के अक्षम करें" वैध मैक्रो को ब्लॉक करता है; डिफ़ॉल्ट उपयोगकर्ता को चेतावनी देता है और प्रति फ़ाइल सक्षम करने की अनुमति देता है, इसलिए उत्तर सूचना के साथ सभी मैक्रो अक्षम करें है।
स्रोत: Microsoft Learn

25. Review टैब पर कौन सा कमांड आपको फ़ॉर्मेटिंग परिवर्तनों को सीमित करने और संपादन को दस्तावेज़ के विशिष्ट भागों तक प्रतिबंधित करने की अनुमति देता है?
(a) Restrict Editing (b) Compare (c) Protect Document (d) Block Authors
उत्तर: (a)
हल: Protect Document (विरासत) और Block Authors अलग परिदृश्यों के लिए हैं; Restrict Editing फ़ॉर्मेटिंग और संपादन प्रतिबंधों को लागू करने के लिए पेन खोलता है, इसलिए उत्तर Restrict Editing है।
स्रोत: Microsoft Support
