1. What is the default file extension for documents created in Microsoft Word 2007 and later versions?
(a) .doc (b) .txt (c) .rtf (d) .docx
Answer: (d)
Solution: The .doc extension was used in Word 97–2003; .docx (Office Open XML) has been the default since Word 2007, so the answer is .docx.
Source: Microsoft Support

2. Which keyboard shortcut saves the current document in Microsoft Word on Windows?
(a) Ctrl+A (b) Ctrl+S (c) Ctrl+Shift+S (d) Alt+S
Answer: (b)
Solution: Ctrl+A selects all text; Ctrl+S is the universal Save shortcut across Windows Office apps, so the answer is Ctrl+S.
Source: Microsoft Learn

3. Which shortcut copies the selected text or object to the Clipboard in Word?
(a) Ctrl+V (b) Ctrl+C (c) Ctrl+X (d) Ctrl+P
Answer: (b)
Solution: Ctrl+V pastes, Ctrl+X cuts; Ctrl+C copies the selection to the Clipboard, so the answer is Ctrl+C.
Source: Microsoft Learn

4. Which shortcut pastes the Clipboard contents at the insertion point in Word?
(a) Ctrl+V (b) Ctrl+C (c) Ctrl+X (d) Ctrl+Z
Answer: (a)
Solution: Ctrl+C copies and Ctrl+X cuts; Ctrl+V performs the paste operation, so the answer is Ctrl+V.
Source: Microsoft Learn

5. Which shortcut cuts the selected content and places it on the Clipboard in Word?
(a) Ctrl+X (b) Ctrl+V (c) Ctrl+Z (d) Ctrl+C
Answer: (a)
Solution: Ctrl+C copies without removing; Ctrl+X removes the selection to the Clipboard, so the answer is Ctrl+X.
Source: Microsoft Learn

6. Which shortcut reverses the last action in Microsoft Word?
(a) Ctrl+Z (b) Ctrl+Y (c) Ctrl+Shift+Z (d) Alt+Backspace
Answer: (a)
Solution: Ctrl+Y redoes an undone action; Ctrl+Z is the standard Undo shortcut, so the answer is Ctrl+Z.
Source: Microsoft Learn

7. Which shortcut redoes an action that was undone in Word?
(a) Ctrl+Z (b) Ctrl+Shift+Z (c) Ctrl+Y (d) Ctrl+U
Answer: (c)
Solution: Ctrl+Z undoes; Ctrl+Y (or Ctrl+Shift+Z) redoes the last undone action, so the answer is Ctrl+Y.
Source: Microsoft Learn

8. Which shortcut applies bold formatting to selected text in Word?
(a) Ctrl+D (b) Ctrl+I (c) Ctrl+U (d) Ctrl+B
Answer: (d)
Solution: Ctrl+I italicizes and Ctrl+U underlines; Ctrl+B toggles bold formatting, so the answer is Ctrl+B.
Source: Microsoft Learn

9. Which shortcut applies italic formatting to selected text in Word?
(a) Ctrl+I (b) Ctrl+U (c) Ctrl+Shift+I (d) Ctrl+B
Answer: (a)
Solution: Ctrl+B is bold and Ctrl+U is underline; Ctrl+I toggles italic, so the answer is Ctrl+I.
Source: Microsoft Learn

10. Which shortcut applies underline formatting to selected text in Word?
(a) Ctrl+B (b) Ctrl+I (c) Ctrl+U (d) Ctrl+Shift+U
Answer: (c)
Solution: Ctrl+B and Ctrl+I handle bold and italic; Ctrl+U toggles underline, so the answer is Ctrl+U.
Source: Microsoft Learn

11. Which view in Word shows the document as it will appear when printed, including margins and page breaks?
(a) Draft (b) Print Layout (c) Web Layout (d) Outline
Answer: (b)
Solution: Draft view hides margins and page breaks; Print Layout displays the exact printed appearance, so the answer is Print Layout.
Source: Microsoft Support

12. Which feature automatically checks spelling and grammar as you type, marking errors with coloured wavy lines?
(a) Thesaurus (b) AutoCorrect (c) Spelling & Grammar (d) Word Count
Answer: (c)
Solution: AutoCorrect fixes typos automatically; the real-time wavy-line checker is the Spelling & Grammar feature, so the answer is Spelling & Grammar.
Source: Microsoft Support

13. In a Mail Merge operation, which component contains the variable data (names, addresses) to be merged into the main document?
(a) Main Document (b) Template (c) Merge Field (d) Data Source
Answer: (d)
Solution: The main document holds the fixed text; the Data Source (Excel sheet, Access table, etc.) supplies the variable records, so the answer is Data Source.
Source: Microsoft Learn

14. Where do headers and footers appear in a Word document by default?
(a) Left and right margins (b) Top and bottom margins of each page (c) Above and below the main text area (d) Only on the first page
Answer: (b)
Solution: Headers print in the top margin and footers in the bottom margin of every page unless Different First Page is set, so the answer is top and bottom margins of each page.
Source: Microsoft Support

15. Which shortcut inserts a manual page break in Word?
(a) Shift+Enter (b) Ctrl+Enter (c) Ctrl+Shift+Enter (d) Alt+Enter
Answer: (b)
Solution: Shift+Enter inserts a line break; Ctrl+Enter forces a new page, so the answer is Ctrl+Enter.
Source: Microsoft Learn

16. Which shortcut opens the Find pane (Navigation pane) in Word?
(a) Ctrl+G (b) Ctrl+H (c) Ctrl+F (d) F3
Answer: (c)
Solution: Ctrl+H opens Replace; Ctrl+G opens Go To; Ctrl+F opens the Find/Navigation pane, so the answer is Ctrl+F.
Source: Microsoft Learn

17. Which shortcut opens the Find and Replace dialog box with the Replace tab active in Word?
(a) Ctrl+F (b) Ctrl+G (c) Ctrl+R (d) Ctrl+H
Answer: (d)
Solution: Ctrl+F opens Find; Ctrl+H opens directly to the Replace tab, so the answer is Ctrl+H.
Source: Microsoft Learn

18. Which shortcut selects the entire document content in Word?
(a) Ctrl+S (b) Ctrl+Shift+A (c) Ctrl+Space (d) Ctrl+A
Answer: (d)
Solution: Ctrl+S saves; Ctrl+A selects all text, objects, and tables in the document, so the answer is Ctrl+A.
Source: Microsoft Learn

19. Which shortcut creates a new blank document in Word?
(a) Alt+N (b) Ctrl+O (c) Ctrl+Shift+N (d) Ctrl+N
Answer: (d)
Solution: Ctrl+O opens an existing file; Ctrl+N starts a new blank document based on the Normal template, so the answer is Ctrl+N.
Source: Microsoft Learn

20. Which shortcut opens the Open dialog box to browse for an existing Word document?
(a) Ctrl+O (b) Ctrl+N (c) Ctrl+Shift+O (d) Ctrl+F12
Answer: (a)
Solution: Ctrl+N creates new; Ctrl+O (or Ctrl+F12) opens the Open dialog, so the answer is Ctrl+O.
Source: Microsoft Learn

21. Which type of section break starts the new section on the next page in Word?
(a) Next Page (b) Even Page (c) Continuous (d) Odd Page
Answer: (a)
Solution: Continuous starts on the same page; Even/Odd Page force the next even/odd page; Next Page starts the new section on the immediately following page, so the answer is Next Page.
Source: Microsoft Support

22. When Track Changes is turned on, how are deletions typically displayed in the document?
(a) Highlighted in yellow (b) Strikethrough formatting (c) Moved to the margin (d) Red font colour only
Answer: (b)
Solution: Insertions appear underlined; deletions are shown with strikethrough (or in balloons), so the answer is strikethrough formatting.
Source: Microsoft Support

23. Which feature must be applied to headings so that Word can automatically generate a Table of Contents?
(a) Bold formatting (b) Bookmarks (c) Heading Styles (d) Outline Level
Answer: (c)
Solution: Bold or outline level alone does not mark TOC entries; applying built-in Heading Styles (Heading 1, Heading 2, etc.) enables automatic TOC creation, so the answer is Heading Styles.
Source: Microsoft Learn

24. What is the default macro security setting in modern versions of Word that balances safety and functionality?
(a) Enable all macros (b) Disable all macros without notification (c) Disable all macros with notification (d) Disable all macros except digitally signed macros
Answer: (c)
Solution: "Enable all" is unsafe; "Disable without notification" blocks legitimate macros; the default warns the user and allows enabling per file, so the answer is Disable all macros with notification.
Source: Microsoft Learn

25. Which command on the Review tab allows you to limit formatting changes and restrict editing to specific parts of a document?
(a) Restrict Editing (b) Compare (c) Protect Document (d) Block Authors
Answer: (a)
Solution: Protect Document (legacy) and Block Authors are for different scenarios; Restrict Editing opens the pane to enforce formatting and editing restrictions, so the answer is Restrict Editing.
Source: Microsoft Support
