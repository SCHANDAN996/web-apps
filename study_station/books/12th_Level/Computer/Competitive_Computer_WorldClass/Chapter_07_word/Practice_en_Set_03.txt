51. Which file extension is used by default for documents created in Microsoft Word 2007 and later versions?
(a) .doc (b) .dotx (c) .docx (d) .rtf
Answer: (c)
Solution: The .doc extension was the default for Word 97–2003, while .dotx is for templates and .rtf is a cross-platform format; the modern default is .docx, so the answer is .docx.
