76. Which tab on the Ribbon contains the Font group for character formatting?
(a) Insert (b) Home (c) Layout (d) View
Answer: (b)
Solution: The Insert tab is for adding objects like tables and pictures, while Layout handles page setup; the Font group with options for font face, size, color, and effects is on the Home tab, so the answer is Home.
Source: Microsoft Support – Word Ribbon overview

77. What is the default file extension for documents created in Microsoft Word 2007 and later?
(a) .doc (b) .docx (c) .rtf (d) .txt
Answer: (b)
Solution: The older .doc format was used up to Word 2003; .rtf and .txt are interchangeable formats, but the XML-based default since Word 2007 is .docx, so the answer is .docx.
Source: Microsoft Learn – File formats in Word

78. Which keyboard shortcut opens the Save As dialog box in Word for Windows?
(a) Ctrl+S (b) F12 (c) Ctrl+Shift+S (d) Alt+F2
Answer: (b)
Solution: Ctrl+S saves the current file without prompting for a new name; F12 directly opens Save As, while Ctrl+Shift+S and Alt+F2 are not standard Word shortcuts for this action, so the answer is F12.
Source: Microsoft Support – Keyboard shortcuts in Word

79. To apply a heading style that appears in the Navigation Pane and can be used for a Table of Contents, you should use:
(a) Font formatting (b) Format Painter (c) Styles gallery (d) Themes
Answer: (c)
Solution: Font formatting changes appearance only; Format Painter copies formatting; Themes affect the whole document design. Only the Styles gallery applies built-in heading styles that outline levels recognize, so the answer is Styles gallery.
Source: Microsoft Support – Use styles in Word

80. Which view shows the document as it will look when printed, including margins, headers, and footers?
(a) Print Layout (b) Web Layout (c) Draft (d) Outline
Answer: (a)
Solution: Draft view hides margins and headers/footers; Web Layout optimizes for screen; Outline shows heading structure. Print Layout displays the full page representation, so the answer is Print Layout.
Source: Microsoft Support – Switch between views

81. The keyboard shortcut Ctrl+Enter inserts a:
(a) Column break (b) Section break (c) Line break (d) Page break
Answer: (d)
Solution: Shift+Enter inserts a line break; Ctrl+Shift+Enter inserts a column break; Section breaks are on the Layout tab. Ctrl+Enter is the standard shortcut for a manual page break, so the answer is Page break.
Source: Microsoft Support – Insert a page break

82. Which feature allows you to create personalized letters for multiple recipients using a data source?
(a) Building Blocks (b) Quick Parts (c) Mail Merge (d) AutoText
Answer: (c)
Solution: Quick Parts, Building Blocks, and AutoText store reusable content but do not merge with a data source. Mail Merge connects a main document to a recipient list, so the answer is Mail Merge.
Source: Microsoft Support – Mail merge in Word

83. To keep two specific words together on the same line (prevent a line break between them), you should insert a:
(a) Nonbreaking space (b) Normal space (c) Tab (d) Soft hyphen
Answer: (a)
Solution: A normal space allows a line break; a tab moves text; a soft hyphen indicates optional hyphenation. A nonbreaking space (Ctrl+Shift+Space) binds the words together, so the answer is Nonbreaking space.
Source: Microsoft Support – Insert a nonbreaking space

84. Which tab contains the Page Setup group where you can change margins, orientation, and paper size?
(a) Home (b) Insert (c) Layout (d) References
Answer: (c)
Solution: Home handles text formatting; Insert adds objects; References manages citations and tables. Page Setup options are on the Layout tab, so the answer is Layout.

85. The Format Painter tool copies:
(a) Formatting only (b) Text content (c) Both text and formatting (d) Styles only
Answer: (a)
Solution: Format Painter copies character and paragraph formatting (font, size, color, spacing) but not the actual text or style definitions, so the answer is Formatting only.

86. Which keyboard shortcut applies the Heading 1 style in Word for Windows?
(a) Ctrl+Alt+1 (b) Ctrl+Shift+1 (c) Alt+1 (d) Ctrl+1
Answer: (a)
Solution: Ctrl+1 sets single line spacing; Ctrl+Shift+1 and Alt+1 are not standard heading shortcuts. The built-in shortcut for Heading 1 is Ctrl+Alt+1, so the answer is Ctrl+Alt+1.

87. To insert a table of contents that updates automatically when headings change, you must first:
(a) Insert page numbers (b) Apply heading styles (c) Add bookmarks (d) Create footnotes
Answer: (b)
Solution: Page numbers, bookmarks, and footnotes are unrelated to TOC generation. Word builds a TOC from paragraphs formatted with heading styles, so the answer is Apply heading styles.

88. Which feature tracks insertions, deletions, and formatting changes made by collaborators?
(a) Comments (b) Track Changes (c) Compare (d) Protect Document
Answer: (b)
Solution: Comments are for notes; Compare shows differences between two documents; Protect Document restricts editing. Track Changes records each edit in the document, so the answer is Track Changes.

89. The shortcut Ctrl+Z performs which action?
(a) Undo (b) Redo (c) Cut (d) Paste
Answer: (a)
Solution: Ctrl+Y or Ctrl+Shift+Z redoes; Ctrl+X cuts; Ctrl+V pastes. Ctrl+Z is the universal Undo shortcut in Word, so the answer is Undo.

90. To start a new column before the current column is full, you insert a:
(a) Page break (b) Section break (c) Line break (d) Column break
Answer: (d)
Solution: A page break starts a new page; a section break starts a new section; a line break (Shift+Enter) starts a new line. A column break (Ctrl+Shift+Enter) forces text to the next column, so the answer is Column break.
Source: Microsoft Support – Insert a column break

91. Which file format preserves formatting and is widely used for sharing read-only documents?
(a) .docx (b) .txt (c) .rtf (d) .pdf
Answer: (d)
Solution: .docx is editable; .rtf and .txt may lose complex formatting. PDF (Portable Document Format) locks layout and is standard for read-only sharing, so the answer is .pdf.
Source: Microsoft Support – Save as PDF

92. The Navigation Pane helps you:
(a) Browse headings, pages, and search results (b) Manage macros (c) Insert citations (d) Record audio
Answer: (a)
Solution: Macros are on the View/Developer tabs; citations are on References; audio recording is not a Word feature. The Navigation Pane shows heading structure, page thumbnails, and find results, so the answer is Browse headings, pages, and search results.

93. To repeat a table header row on each printed page, you select the header row and choose:
(a) Split Cells (b) Merge Cells (c) Repeat Header Rows (d) Distribute Rows
Answer: (c)
Solution: Merge/Split Cells change cell structure; Distribute Rows equalizes row height. The Table Layout tab's "Repeat Header Rows" option makes the header appear on every page, so the answer is Repeat Header Rows.

94. Which shortcut opens the Find and Replace dialog box with the Replace tab active?

95. A watermark in Word is typically used to:
(a) Insert a page number (b) Add a background image to every page (c) Create a hyperlink (d) Format a paragraph
Answer: (b)
Solution: Page numbers are inserted via Header & Footer; hyperlinks link to locations; paragraph formatting changes text layout. A watermark places faint text or image behind page content, so the answer is Add a background image to every page.

96. To prevent a paragraph from being split across two pages, you set the paragraph option:
(a) Keep with next (b) Widow/Orphan control (c) Keep lines together (d) Page break before
Answer: (c)
Solution: "Keep with next" binds this paragraph to the following one; "Widow/Orphan control" prevents single lines at page top/bottom; "Page break before" forces a new page. "Keep lines together" keeps all lines of the paragraph on one page, so the answer is Keep lines together.
Source: Microsoft Support – Keep lines together
