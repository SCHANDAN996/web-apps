101. Which tab in the Microsoft Word ribbon contains the commands for changing font type, size, and color?
(a) Home (b) Layout (c) Insert (d) View
Answer: (a)
Solution: The Insert tab is for adding objects like tables and pictures, while Layout handles page setup; the Home tab groups all basic text formatting commands such as font, paragraph, and styles, so the answer is Home.
Source: Microsoft Support – Word ribbon overview

102. What is the default file extension for a document created in Microsoft Word 2007 or later?
(a) .doc (b) .txt (c) .docx (d) .rtf
Answer: (c)
Solution: The older .doc format was used up to Word 2003; .docx is the Office Open XML format introduced in Word 2007 and remains the default, so the answer is .docx.
Source: Microsoft Learn – File formats in Word

103. Which keyboard shortcut opens the Save As dialog box in Word for Windows?
(a) Ctrl + S (b) Alt + F2 (c) F12 (d) Ctrl + Shift + S
Answer: (c)
Solution: Ctrl + S saves the current file without prompting for a new name; F12 directly opens the Save As dialog, so the answer is F12.
Source: Microsoft Support – Keyboard shortcuts in Word

104. The ruler in Word is used primarily to:
(a) Measure the document length in centimeters (b) Zoom in and out of the page (c) Set tabs, indents, and margins visually (d) Count words and characters
Answer: (c)
Solution: The ruler provides a visual way to adjust paragraph indents, tab stops, and page margins; it does not measure total document length or count words, so the answer is Set tabs, indents, and margins visually.
Source: Microsoft Support – Use the ruler in Word

105. Which view shows the document as it will appear when printed, including margins, headers, and footers?
(a) Draft (b) Print Layout (c) Web Layout (d) Outline
Answer: (b)
Solution: Draft view hides margins and headers/footers for faster editing; Print Layout displays the full page representation, so the answer is Print Layout.
Source: Microsoft Support – Switch between views in Word

106. To apply double line spacing to a selected paragraph, the correct sequence is:
(a) Home → Line and Paragraph Spacing → 2.0 (b) Layout → Spacing → Double (c) Design → Paragraph Spacing → Double (d) Insert → Line Spacing → 2.0
Answer: (a)
Solution: Line spacing options reside in the Home tab under the Line and Paragraph Spacing button; Layout and Design tabs do not contain this control, so the answer is Home → Line and Paragraph Spacing → 2.0.
Source: Microsoft Support – Change line spacing in Word

107. The Format Painter tool copies:
(a) Text content only (b) Page layout settings only (c) Both text and formatting (d) Formatting only
Answer: (d)
Solution: Format Painter copies character and paragraph formatting (font, size, color, spacing) from one selection to another without copying the text itself, so the answer is Formatting only.
Source: Microsoft Support – Copy formatting with Format Painter

108. Which feature automatically moves text to the next line when it reaches the right margin?
(a) Text Wrapping (b) Word Wrap (c) Hyphenation (d) Justification
Answer: (b)
Solution: Word Wrap is the built-in behavior that breaks lines at the margin; Text Wrapping controls how objects interact with text, and Hyphenation splits words, so the answer is Word Wrap.
Source: Microsoft Support – Word wrap and text wrapping

109. To insert a page break at the current cursor position, press:
(a) Shift + Enter (b) Alt + Enter (c) Ctrl + Enter (d) Ctrl + Shift + Enter
Answer: (c)
Solution: Shift + Enter creates a line break without a new paragraph; Ctrl + Enter inserts a manual page break, so the answer is Ctrl + Enter.
Source: Microsoft Support – Insert a page break

110. The Find and Replace dialog box can be opened with which shortcut?
(a) Ctrl + F (b) Ctrl + H (c) Ctrl + R (d) F5
Answer: (b)
Solution: Ctrl + F opens the Navigation pane for simple find; Ctrl + H opens the full Find and Replace dialog with the Replace tab active, so the answer is Ctrl + H.
Source: Microsoft Support – Find and replace text

111. Which tab contains the command to insert a table?
(a) Home (b) References (c) Insert (d) Layout
Answer: (c)
Solution: The Insert tab groups all objects that can be added to a document, including tables, pictures, and shapes, so the answer is Insert.
Source: Microsoft Support – Insert a table

112. In a table, the Layout tab (under Table Tools) appears only when:
(a) The document is in Print Layout view (b) The cursor is inside a table (c) A table style is applied (d) The table has more than three rows
Answer: (b)
Solution: Contextual Table Tools tabs (Design and Layout) become visible only when the insertion point is within a table, so the answer is The cursor is inside a table.
Source: Microsoft Support – Work with table tools

113. Mail Merge is used to:
(a) Create personalized letters, labels, or emails from a data source (b) Combine multiple documents into one (c) Merge two tables into a single table (d) Track changes from multiple reviewers
Answer: (a)
Solution: Mail Merge generates individualized output by merging a main document with a recipient list; it does not combine separate documents or merge tables, so the answer is Create personalized letters, labels, or emails from a data source.
Source: Microsoft Support – Mail merge overview

114. The shortcut to open the Styles pane is:
(a) Ctrl + Shift + S (b) Ctrl + Alt + S (c) F11 (d) Alt + Ctrl + Shift + S
Answer: (d)
Solution: Ctrl + Shift + S opens the Apply Styles dialog; the full Styles pane requires Alt + Ctrl + Shift + S, so the answer is Alt + Ctrl + Shift + S.
Source: Microsoft Support – Keyboard shortcuts for styles

115. Which feature allows you to keep track of insertions, deletions, and formatting changes made by collaborators?
(a) Comments (b) Version History (c) Compare Documents (d) Track Changes
Answer: (d)
Solution: Track Changes records every edit with the author's name and timestamp; Comments are for notes only, and Compare Documents is a separate tool, so the answer is Track Changes.
Source: Microsoft Support – Track changes in Word

116. To protect a document so that only tracked changes can be made, use:
(a) Encrypt with Password (b) Add a Digital Signature (c) Mark as Final (d) Restrict Editing → Allow only this type of editing → Tracked changes
Answer: (d)
Solution: Restrict Editing with "Tracked changes" selected enforces that all edits are recorded; Encrypt with Password locks the file entirely, and Mark as Final is only a visual indicator, so the answer is Restrict Editing → Allow only this type of editing → Tracked changes.
Source: Microsoft Support – Protect a document

117. The default bottom margin in a new Word document (Normal template) is:
(a) 1.25 inches (b) 1.5 inches (c) 1 inch (d) 2 inches
Answer: (c)
Solution: The Normal template sets all four margins to 1 inch (2.54 cm) by default, so the answer is 1 inch.
Source: Microsoft Support – Change margins

118. Which command inserts the current date that updates automatically each time the document is opened?
(a) Insert → Field → Date (b) Type the date manually (c) Ctrl + Shift + D (d) Insert → Date & Time → check "Update automatically"
Answer: (d)
Solution: The Date & Time dialog with "Update automatically" inserts a DATE field that refreshes on open; Ctrl + Shift + D inserts a static date, so the answer is Insert → Date & Time → check "Update automatically".
Source: Microsoft Support – Insert the date and time

119. To apply a heading style that appears in the Navigation pane and can be used for a Table of Contents, use:
(a) Layout → Heading (b) Bold and increase font size manually (c) Insert → Heading (d) Styles gallery → Heading 1
Answer: (d)
Solution: Only built-in heading styles (Heading 1, Heading 2, etc.) are recognized by the Navigation pane and TOC generator; manual formatting does not create outline levels, so the answer is Styles gallery → Heading 1.
Source: Microsoft Support – Use heading styles

120. The keyboard shortcut to toggle the display of non-printing characters (¶, spaces, tabs) is:
(a) Ctrl + * (b) Ctrl + Shift + 8 (c) Ctrl + Shift + * (d) Alt + Ctrl + *
Answer: (b)
Solution: On standard keyboards, the asterisk is Shift + 8; therefore Ctrl + Shift + 8 (or Ctrl + *) toggles the Show/Hide ¶ button, so the answer is Ctrl + Shift + 8.
Source: Microsoft Support – Show or hide formatting marks

121. When using Find and Replace with wildcards, which character represents any single character?
(a) ? (b) # (c) * (d) @
Answer: (a)
Solution: In Word wildcards, the asterisk (*) stands for any number of characters, while the question mark (?) stands for exactly one character, so the answer is ?.
Source: Microsoft Support – Use wildcards in find and replace

122. A section break that starts the new section on the next odd-numbered page is:
(a) Odd Page (b) Continuous (c) Even Page (d) Next Page
Answer: (a)
Solution: Odd Page section break forces the following section to begin on the next odd page, inserting a blank even page if necessary; Even Page does the opposite, so the answer is Odd Page.
Source: Microsoft Support – Insert section breaks

123. In a mail merge, the "Edit Recipient List" button allows you to:
(a) Filter, sort, and select specific recipients (b) Change the output file format (c) Modify the merge field codes (d) Change the main document text
Answer: (a)
Solution: Edit Recipient List opens the Mail Merge Recipients dialog where you can filter, sort, and check/uncheck individual records; it does not edit the main document or field codes, so the answer is Filter, sort, and select specific recipients.
Source: Microsoft Support – Edit the recipient list

124. Which feature creates a hierarchical list of headings with page numbers for quick navigation?
(a) Index (b) Table of Contents (c) Bibliography (d) Cross-reference
Answer: (b)
Solution: A Table of Contents is built from heading styles and includes page numbers; an Index lists keywords, and a Bibliography lists citations, so the answer is Table of Contents.
Source: Microsoft Support – Create a table of contents

125. Which macro security setting in Word allows only digitally signed macros to run without prompting?
(a) Disable all macros except digitally signed macros (b) Disable all macros with notification (c) Disable all macros without notification (d) Enable all macros
Answer: (a)
Solution: The setting "Disable all macros except digitally signed macros" allows signed macros to run automatically while disabling unsigned ones; "Enable all macros" runs any macro, which is unsafe, so the answer is Disable all macros except digitally signed macros.
Source: Microsoft Support – Macro security settings
