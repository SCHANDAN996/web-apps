76. What is the default file extension for an Excel workbook in modern versions (Excel 2007 and later)?
(a) .xls (b) .xlsx (c) .xlsm (d) .csv
Answer: (b)
Solution: The .xls extension belongs to the legacy binary format (Excel 97–2003). The .xlsm extension is used only when the workbook contains macros, and .csv is a plain-text comma-separated format, not the native workbook format. The standard default for a macro-free workbook since Excel 2007 is .xlsx, so the answer is .xlsx.

78. In an Excel formula, what does the $ symbol before a column letter and row number (e.g., $A$1) indicate?
(a) The cell contains a currency value (b) The reference is absolute (c) The reference is relative (d) The cell is locked for editing
Answer: (b)
Solution: The $ symbol has nothing to do with currency formatting or cell protection; it fixes the reference so that it does not change when the formula is copied. A relative reference (A1) adjusts both column and row, while a mixed reference ($A1 or A$1) fixes only one part. Therefore, $A$1 is an absolute reference, so the answer is The reference is absolute.

97. What does the formula =INDEX(A1:C3, 2, 3) return?

Answer: (a)
