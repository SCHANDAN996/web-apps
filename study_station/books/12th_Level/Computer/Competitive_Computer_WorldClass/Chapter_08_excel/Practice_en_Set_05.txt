101. Which keyboard shortcut opens the Format Cells dialog box in Microsoft Excel for Windows?
(a) Ctrl + F1 (b) Ctrl + Shift + 1 (c) Alt + 1 (d) Ctrl + 1
Answer: (d)
Solution: Many users confuse Ctrl+1 with Ctrl+Shift+1 (which applies the Number format with two decimals) or Ctrl+F1 (which toggles the ribbon); the direct shortcut for Format Cells is Ctrl+1, so the answer is Ctrl + 1.
Source: Microsoft Support - Excel keyboard shortcuts

102. What does the formula =COUNTA(A1:A10) return if the range contains 3 numbers, 2 text entries, and 5 empty cells?
(a) 3 (b) 8 (c) 5 (d) 10
Answer: (c)
Solution: A common trap is to count only numbers (which COUNT does) or to include empty cells; COUNTA counts all non-empty cells regardless of type, so 3 numbers + 2 text = 5, so the answer is 5.
Source: Microsoft Support - COUNTA function

103. Which function returns the largest value in a range that meets a specified condition?
(a) MAXIFS (b) MAXIF (c) LARGEIF (d) MAX with IF
Answer: (a)
Solution: Candidates often guess MAXIF (which does not exist) or try array formulas with MAX and IF; the correct modern function is MAXIFS introduced in Excel 2019, so the answer is MAXIFS.
Source: Microsoft Support - MAXIFS function

104. In a structured reference, what does Table1[@Sales] refer to?
(a) The entire Sales column (b) The Sales value in the current row (c) The Sales header (d) The total row of Sales
Answer: (b)
Solution: The @ symbol in structured references means "this row"; beginners often think it means the whole column or the header, but it specifically returns the value from the current row, so the answer is The Sales value in the current row.
Source: Microsoft Support - Structured references

106. What is the result of =SUMPRODUCT({1,2,3},{4,5,6})?
(a) 32 (b) 21 (c) 26 (d) 15
Answer: (a)
Solution: Some multiply corresponding pairs and forget to sum (1×4=4, 2×5=10, 3×6=18, sum=32); others add the arrays first; SUMPRODUCT multiplies then sums, giving 4+10+18=32, so the answer is 32.
Source: Microsoft Support - SUMPRODUCT function

108. What does the formula =INDEX(A1:C3, 2, 3) return?
(a) Value in row 2, column C (b) Value in row 3, column B (c) Value in row 2, column 3 of the array (d) Value in row 3, column 2 of the array

118. What is the purpose of the $ sign in a cell reference like $A$1?
(a) Makes the reference absolute (b) Formats as currency (c) Indicates a named range (d) Locks the cell for editing
Answer: (a)
Solution: The $ fixes row and/or column so the reference does not change when copied; it has no effect on formatting or protection, so the answer is Makes the reference absolute.

120. What does the formula =TODAY() - DATE(2022,1,1) return on 15-Jan-2022?
(a) 0 (b) 15 (c) 16 (d) 14
Answer: (d)
Solution: TODAY() returns the serial for 15-Jan-2022; DATE(2022,1,1) is 1-Jan-2022; difference is 14 days (not 15 because both dates inclusive would be 15, but subtraction gives elapsed days), so the answer is 14.

125. What does the formula =OFFSET(A1, 2, 3, 1, 1) return?

Answer: (d)
Solution: OFFSET(reference, rows, cols, height, width); from A1, down 2 rows → row 3, right 3 cols → column D, height 1 width 1 → single cell D3, so the answer is Cell D3.
