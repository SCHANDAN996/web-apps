51. Microsoft Excel 2007 या बाद के संस्करण में बनी कार्यपुस्तिका का डिफ़ॉल्ट फ़ाइल एक्सटेंशन क्या है?
(a) .xls (b) .xlsm (c) .xlsx (d) .csv

हल: .xls एक्सटेंशन Excel 2003 तक उपयोग होता था; .xlsm मैक्रो-सक्षम कार्यपुस्तिकाओं के लिए है और .csv एक सादा-पाठ प्रारूप है, इसलिए उत्तर .xlsx है।
स्रोत: Microsoft Support – Excel file formats

52. कौन सा कुंजी संयोजन किसी सेल में वर्तमान तिथि दर्ज करता है?
(a) Ctrl + Shift + : (b) Ctrl + Shift + ; (c) Ctrl + : (d) Ctrl + ;
उत्तर: (d)
हल: Ctrl + Shift + ; वर्तमान समय दर्ज करता है, जबकि Ctrl + : और Ctrl + Shift + : मानक Excel शॉर्टकट नहीं हैं, इसलिए उत्तर Ctrl + ; है।

53. यदि सेल A1 में 10 और सेल A2 में 20 है, तो सूत्र =A1+A2*2 क्या लौटाएगा?
(a) 50 (b) 60 (c) 40 (d) 30
उत्तर: (a)
हल: गुणा की प्राथमिकता जोड़ से अधिक होती है, इसलिए A2*2 पहले परिकलित होता है (40) फिर A1 (10) में जुड़ता है, जिससे 50 प्राप्त होता है; एक सामान्य जाल है पहले जोड़कर 60 प्राप्त करना, इसलिए उत्तर 50 है।
स्रोत: NCERT कक्षा 10 कंप्यूटर अनुप्रयोग

54. कौन सा संदर्भ प्रकार किसी सूत्र को दूसरे सेल में कॉपी करने पर बदलता है?
(a) निरपेक्ष (b) मिश्रित (c) निश्चित (d) सापेक्ष
उत्तर: (d)
हल: निरपेक्ष ($A$1) और मिश्रित ($A1 या A$1) संदर्भ पंक्ति या स्तंभ को लॉक करते हैं; केवल सापेक्ष संदर्भ (A1) कॉपी करने पर पंक्ति और स्तंभ दोनों को समायोजित करते हैं, इसलिए उत्तर सापेक्ष है।
स्रोत: Microsoft Learn – Cell references

57. =IF(5>3,"Pass","Fail") का परिणाम क्या है?
(a) Pass (b) Fail (c) TRUE (d) FALSE
उत्तर: (a)
हल: तार्किक परीक्षण 5>3 TRUE का मूल्यांकन करता है, इसलिए value_if_true तर्क "Pass" लौटाया जाता है; जाल यह सोचना है कि फ़ंक्शन बूलियन TRUE लौटाता है, इसलिए उत्तर Pass है।
स्रोत: Microsoft Support – IF function

58. VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup]) में range_lookup = FALSE क्या निर्दिष्ट करता है?
(a) सन्निकट मिलान (b) वाइल्डकार्ड मिलान (c) सटीक मिलान (d) केस-संवेदी मिलान
उत्तर: (c)
हल: FALSE (या 0) सटीक मिलान बाध्य करता है; TRUE (या 1) सन्निकट मिलान की अनुमति देता है; VLOOKUP कभी केस-संवेदी नहीं होता और वाइल्डकार्ड केवल सन्निकट मोड में पाठ के साथ काम करते हैं, इसलिए उत्तर सटीक मिलान है।
स्रोत: Microsoft Support – VLOOKUP function

65. COUNT और COUNTA में क्या अंतर है?
(a) COUNT संख्याएँ गिनता है; COUNTA गैर-रिक्त सेल गिनता है (b) COUNT पाठ गिनता है; COUNTA संख्याएँ गिनता है (c) दोनों केवल संख्याएँ गिनते हैं (d) दोनों केवल पाठ गिनते हैं
उत्तर: (a)
हल: COUNT पाठ और रिक्त को अनदेखा करता है; COUNTA रिक्त को छोड़कर सब कुछ गिनता है; एक सामान्य जाल है यह सोचना कि COUNTA केवल पाठ गिनता है, इसलिए उत्तर COUNT संख्याएँ गिनता है; COUNTA गैर-रिक्त सेल गिनता है।
स्रोत: Microsoft Support – COUNT and COUNTA functions

66. =ROUND(3.14159, 2) क्या लौटाता है:
(a) 3 (b) 3.15 (c) 3.1 (d) 3.14
उत्तर: (d)
हल: ROUND निर्दिष्ट अंकों की संख्या तक पूर्णांकित करता है; तीसरा दशमलव 1 है (<5), इसलिए 3.14159, 3.14 बन जाता है; जाल है चौथे स्थान पर 5 के कारण ऊपर पूर्णांकित करना, इसलिए उत्तर 3.14 है।
स्रोत: Microsoft Support – ROUND function

71. जब A1 = 75 हो, तो =IF(A1>100,"High",IF(A1>50,"Medium","Low")) क्या लौटाता है?
(a) High (b) Medium (c) Low (d) Error
उत्तर: (b)
हल: 75, 100 से अधिक नहीं है, इसलिए पहला IF अपने value_if_false पर जाता है, जो एक और IF है; 75 > 50 TRUE है, इसलिए "Medium" लौटाया जाता है; जाल है पहली शर्त पर रुककर Low उत्तर देना, इसलिए उत्तर Medium है।
स्रोत: Microsoft Support – Nested IF functions

72. कौन सा फ़ंक्शन संयोजन किसी भी स्तंभ में मान खोज सकता है और दाईं ओर किसी भी स्तंभ से मान लौटा सकता है?

स्रोत: Microsoft Support – INDEX and MATCH functions
