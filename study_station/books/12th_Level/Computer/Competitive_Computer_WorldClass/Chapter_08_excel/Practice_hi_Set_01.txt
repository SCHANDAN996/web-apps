1. एक्सेल में एक पंक्ति और एक स्तंभ का प्रतिच्छेदन क्या कहलाता है?
(a) रेंज (b) सेल (c) शीट (d) वर्कबुक
उत्तर: (b)
हल: शुरुआती अक्सर कंटेनर (वर्कबुक) या ग्रिड लाइन (पंक्ति/स्तंभ) को उस एकल इकाई के साथ भ्रमित कर देते हैं जहाँ डेटा दर्ज किया जाता है; प्रतिच्छेदन को विशेष रूप से सेल नाम दिया गया है, इसलिए उत्तर सेल है।
स्रोत: Microsoft Support - Excel basics

2. प्रत्येक एक्सेल सूत्र किस प्रतीक से शुरू होना चाहिए?
(a) @ (b) = (c) # (d) +
उत्तर: (b)
हल: प्लस चिह्न अंकगणित के लिए काम करता है लेकिन केवल बराबर चिह्न एक्सेल को सूत्र का मूल्यांकन करने के लिए कहता है; इसके बिना प्रविष्टि टेक्स्ट रह जाती है, इसलिए उत्तर = है।
स्रोत: Microsoft Learn - Create a formula

3. एक्सेल 2007 और बाद के संस्करणों में वर्कबुक का डिफ़ॉल्ट फ़ाइल एक्सटेंशन क्या है?
(a) .xlsx (b) .xls (c) .xlsm (d) .csv
उत्तर: (a)
हल: पुराना .xls प्रारूप 65,536 पंक्तियों तक सीमित है; .xlsx मानक XML-आधारित डिफ़ॉल्ट है जब तक कि मैक्रोज़ उपयोग न किए जाएँ, इसलिए उत्तर .xlsx है।
स्रोत: Microsoft Support - File formats

4. विंडोज़ के लिए एक्सेल में फॉर्मेट सेल्स डायलॉग बॉक्स खोलने वाला कीबोर्ड शॉर्टकट कौन सा है?
(a) Alt+1 (b) Ctrl+Shift+1 (c) Ctrl+1 (d) F1
उत्तर: (c)
हल: Ctrl+Shift+1 सीधे नंबर फॉर्मेट लागू करता है, जबकि Ctrl+1 सभी टैब के साथ पूरा डायलॉग खोलता है; F1 सहायता खोलता है, इसलिए उत्तर Ctrl+1 है।
स्रोत: Microsoft Support - Keyboard shortcuts in Excel

5. फंक्शन =COUNTA(A1:A10) क्या गिनता है?
(a) केवल टेक्स्ट (b) गैर-खाली सेल (c) केवल संख्याएँ (d) खाली सेल
उत्तर: (b)
हल: COUNT केवल संख्याएँ गिनता है; COUNTA कोई भी सेल जो खाली नहीं है गिनता है जिसमें टेक्स्ट, त्रुटियाँ और तार्किक मान शामिल हैं, इसलिए उत्तर गैर-खाली सेल है।
स्रोत: Microsoft Learn - COUNTA function

6. कौन सी सुविधा फिल हैंडल को खींचने पर महीनों या सप्ताह के दिनों जैसी श्रृंखला को स्वचालित रूप से भरती है?
(a) ऑटोकंप्लीट (b) ऑटोफिल (c) फ्लैश फिल (d) ऑटोकरेक्ट
उत्तर: (b)
हल: फ्लैश फिल आसन्न कॉलम में पैटर्न का पता लगाता है; ऑटोफिल प्रारंभिक चयन से पहचानी गई श्रृंखला को बढ़ाता है, इसलिए उत्तर ऑटोफिल है।
स्रोत: Microsoft Support - Fill data automatically

7. आधुनिक एक्सेल वर्कशीट (2007 से आगे) में अधिकतम पंक्तियों की संख्या क्या है?
(a) 65,536 (b) 1,048,576 (c) 1,000,000 (d) असीमित
उत्तर: (b)
हल: पुरानी सीमा 65,536 .xls पर लागू होती है; वर्तमान ग्रिड 1,048,576 पंक्तियों और 16,384 स्तंभों का है, इसलिए उत्तर 1,048,576 है।
स्रोत: Microsoft Learn - Excel specifications

8. कौन सा फंक्शन एक रेंज में सबसे बड़ा मान लौटाता है?
(a) TOP (b) MIN (c) LARGE (d) MAX
उत्तर: (d)

स्रोत: Microsoft Learn - MAX function

9. $A$1 जैसे सेल संदर्भ में $ चिह्न क्या करता है?
(a) पंक्ति और स्तंभ दोनों को लॉक करता है (b) नामित रेंज को इंगित करता है (c) पिछली शीट को संदर्भित करता है (d) मुद्रा के रूप में फॉर्मेट करता है
उत्तर: (a)
हल: अक्षर या संख्या से पहले एकल $ केवल उस भाग को लॉक करता है; दो $ चिह्न संदर्भ को कॉपी करते समय पंक्ति और स्तंभ दोनों के लिए निरपेक्ष बनाते हैं, इसलिए उत्तर पंक्ति और स्तंभ दोनों को लॉक करता है।
स्रोत: Microsoft Support - Absolute references

10. रिबन पर कौन सा टैब पिवटटेबल कमांड रखता है?

11. =IF(5>3,"Pass","Fail") का परिणाम क्या है?
(a) FALSE (b) Fail (c) TRUE (d) Pass
उत्तर: (d)
हल: तार्किक परीक्षण 5>3 TRUE का मूल्यांकन करता है, इसलिए value_if_true तर्क "Pass" लौटाया जाता है; फंक्शन बूलियन शब्द TRUE नहीं लौटाता, इसलिए उत्तर Pass है।
स्रोत: Microsoft Learn - IF function

19. त्रुटि #REF! क्या इंगित करती है?

25. एक्सेल टेबल (Ctrl+T) के बारे में कौन सा कथन सही है?
(a) उनमें डुप्लीकेट हेडर हो सकते हैं (b) संरचित संदर्भ A1 जैसे सेल पते उपयोग करते हैं (c) वे डिफ़ॉल्ट रूप से फ़िल्टरिंग अक्षम करते हैं (d) जब नीचे नया डेटा जोड़ा जाता है तो वे स्वचालित रूप से विस्तारित होते हैं
