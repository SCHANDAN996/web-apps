101. Microsoft Excel for Windows में Format Cells डायलॉग बॉक्स खोलने के लिए कौन सा कीबोर्ड शॉर्टकट है?
(a) Ctrl + F1 (b) Ctrl + Shift + 1 (c) Alt + 1 (d) Ctrl + 1
उत्तर: (d)
हल: कई उपयोगकर्ता Ctrl+1 को Ctrl+Shift+1 (जो दो दशमलव के साथ Number फॉर्मेट लागू करता है) या Ctrl+F1 (जो रिबन को टॉगल करता है) से भ्रमित करते हैं; Format Cells के लिए सीधा शॉर्टकट Ctrl+1 है, इसलिए उत्तर Ctrl + 1 है।
स्रोत: Microsoft Support - Excel keyboard shortcuts

102. यदि रेंज में 3 संख्याएँ, 2 टेक्स्ट प्रविष्टियाँ और 5 खाली सेल हैं, तो सूत्र =COUNTA(A1:A10) क्या लौटाएगा?
(a) 3 (b) 8 (c) 5 (d) 10
उत्तर: (c)
हल: एक सामान्य जाल केवल संख्याओं को गिनना है (जो COUNT करता है) या खाली सेल शामिल करना; COUNTA प्रकार की परवाह किए बिना सभी गैर-खाली सेल गिनता है, इसलिए 3 संख्याएँ + 2 टेक्स्ट = 5, इसलिए उत्तर 5 है।
स्रोत: Microsoft Support - COUNTA function

103. कौन सा फ़ंक्शन एक रेंज में सबसे बड़ा मान लौटाता है जो एक निर्दिष्ट शर्त को पूरा करता है?
(a) MAXIFS (b) MAXIF (c) LARGEIF (d) MAX with IF
उत्तर: (a)
हल: उम्मीदवार अक्सर MAXIF का अनुमान लगाते हैं (जो मौजूद नहीं है) या MAX और IF के साथ सरणी सूत्र आज़माते हैं; सही आधुनिक फ़ंक्शन MAXIFS है जिसे Excel 2019 में पेश किया गया था, इसलिए उत्तर MAXIFS है।
स्रोत: Microsoft Support - MAXIFS function

104. एक संरचित संदर्भ में, Table1[@Sales] क्या संदर्भित करता है?
(a) संपूर्ण Sales कॉलम (b) वर्तमान पंक्ति में Sales मान (c) Sales हेडर (d) Sales की कुल पंक्ति
उत्तर: (b)
हल: संरचित संदर्भों में @ प्रतीक का अर्थ "यह पंक्ति" है; शुरुआती अक्सर सोचते हैं कि इसका अर्थ पूरा कॉलम या हेडर है, लेकिन यह विशेष रूप से वर्तमान पंक्ति से मान लौटाता है, इसलिए उत्तर वर्तमान पंक्ति में Sales मान है।
स्रोत: Microsoft Support - Structured references

105. कौन सा शॉर्टकट किसी सेल में वर्तमान तिथि डालता है (Windows Excel)?

उत्तर: (d)

स्रोत: Microsoft Support - Excel keyboard shortcuts

106. =SUMPRODUCT({1,2,3},{4,5,6}) का परिणाम क्या है?
(a) 32 (b) 21 (c) 26 (d) 15
उत्तर: (a)
हल: कुछ संगत जोड़े गुणा करते हैं और योग करना भूल जाते हैं (1×4=4, 2×5=10, 3×6=18, योग=32); अन्य पहले सरणियों को जोड़ते हैं; SUMPRODUCT पहले गुणा करता है फिर योग करता है, जिससे 4+10+18=32 मिलता है, इसलिए उत्तर 32 है।
स्रोत: Microsoft Support - SUMPRODUCT function

107. कौन सी सुविधा डेटा प्रविष्टि को पूर्वनिर्धारित सूची तक सीमित करती है?
(a) Data Validation (b) Conditional Formatting (c) Data Filter (d) Data Sort

स्रोत: Microsoft Support - Data Validation

108. सूत्र =INDEX(A1:C3, 2, 3) क्या लौटाता है?
(a) पंक्ति 2, कॉलम C में मान (b) पंक्ति 3, कॉलम B में मान (c) सरणी की पंक्ति 2, कॉलम 3 में मान (d) सरणी की पंक्ति 3, कॉलम 2 में मान
उत्तर: (c)
हल: INDEX दिए गए सरणी के भीतर row_num फिर column_num का उपयोग करता है; A1:C3 की पंक्ति 2 कॉलम 3 सेल C2 है, इसलिए उत्तर सरणी की पंक्ति 2, कॉलम 3 में मान है।
स्रोत: Microsoft Support - INDEX function

109. सूत्र संपादित करते समय निरपेक्ष/सापेक्ष संदर्भों को टॉगल करने वाला कौन सा शॉर्टकट है (Windows)?

112. यदि 44562, 15-Jan-2022 के लिए क्रमांक संख्या है, तो सूत्र =TEXT(44562, "mmmm") क्या लौटाता है?

116. सूत्र =IFERROR(VLOOKUP(E1, A:B, 2, FALSE), "Not Found") क्या करता है?
(a) केवल तभी "Not Found" लौटाता है जब VLOOKUP #N/A लौटाए (b) किसी भी त्रुटि के लिए "Not Found" लौटाता है (c) यदि E1 खाली है तो "Not Found" लौटाता है (d) यदि कॉलम B खाली है तो "Not Found" लौटाता है

120. 15-Jan-2022 को सूत्र =TODAY() - DATE(2022,1,1) क्या लौटाता है?
(a) 0 (b) 15 (c) 16 (d) 14
उत्तर: (d)

स्रोत: Microsoft Support - Date arithmetic
