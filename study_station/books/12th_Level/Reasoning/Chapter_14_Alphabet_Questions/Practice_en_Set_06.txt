126. If the letters of the word "CHAMPION" are arranged in alphabetical order, how many letters remain in the same position as in the original word?
(a) None (b) One (c) Three (d) Two
Answer: (b)
Solution: The trap is comparing with the reverse order or counting letters that merely stay in the same half of the word. Alphabetical order of C, H, A, M, P, I, O, N is A, C, H, I, M, N, O, P; comparing position by position with C-H-A-M-P-I-O-N, only O (7th position) stays in place. So the answer is One.

127. In the English alphabet, which letter is exactly midway between the 4th letter from the left and the 9th letter from the right?
(a) J (b) L (c) K (d) M
Answer: (c)
Solution: The trap is counting the 9th letter from the right as R's neighbour by counting from the left. The 9th letter from the right is 26 − 9 + 1 = 18th from the left (R), and the 4th from the left is D; midway between positions 4 and 18 is (4 + 18)/2 = 11, which is K. So the answer is K.

Solution: The trap is using the normal positions D = 4, O = 15, G = 7 (sum 26) instead of the reversed ones. Reverse code = 27 − normal position: D = 23, O = 12, G = 20, and 23 + 12 + 20 = 55. So the answer is 55.

136. In the word "SUBSTANTIAL", if all vowels are replaced by the next letter of the alphabet and all consonants by the previous letter, how many letters of the new string are vowels?

Answer: (a)
Solution: The trap is counting the original four vowels (U, A, I, A), but each vowel shifts to the next letter and becomes a consonant (V, B, J, B). Among the consonants shifting one step back (S→R, B→A, T→S, N→M, L→K), only B→A produces a vowel. So the answer is One.
