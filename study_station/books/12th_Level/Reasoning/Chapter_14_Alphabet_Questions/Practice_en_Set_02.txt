26. Which letter is exactly midway between the 10th letter from the left and the 16th letter from the left in the English alphabet?
(a) N (b) L (c) M (d) O
Answer: (c)
Solution: The tempting error is averaging the letter values of J and P directly instead of the positions. The midpoint position is (10 + 16)/2 = 13, and the 13th letter is M. So the answer is M.
Source: PYQ-style

27. How many pairs of letters in the word "CREATIVE" have as many letters between them in the word as there are in the English alphabet (in both directions)?
(a) 3 (b) 1 (c) 2 (d) 4
Answer: (a)
Solution: Many students count only the forward direction and stop at 2 pairs. Checking all pairs in both directions, the matching pairs are C–E (one letter between in both), A–E (three letters between in both) and T–V (one letter between in both). So the answer is 3.
Source: PYQ-style

28. If the letters of the word "DANGER" are arranged in alphabetical order, which letter will be third from the right?
(a) G (b) R (c) E (d) N
Answer: (a)
Solution: The trap is counting from the left after arranging instead of from the right. Alphabetical order of D, A, N, G, E, R is A, D, E, G, N, R; from the right the order is R (1st), N (2nd), G (3rd). So the answer is G.
Source: PYQ-style

29. In the English alphabet, which letter is 7th to the right of the 12th letter from the left?
(a) T (b) S (c) Q (d) R
Answer: (b)
Solution: A common slip is subtracting instead of adding when both references are from the left. The 12th letter from the left is L, and 7th to its right is 12 + 7 = 19th letter. So the answer is S.
Source: PYQ-style

30. Which letter is 5th to the left of the 9th letter from the right end of the English alphabet?
(a) L (b) M (c) N (d) O
Answer: (b)
Solution: The trap is mixing up the right and left references. The 9th letter from the right is the 26 − 9 + 1 = 18th from the left (R), and the 5th to its left is at position 18 − 5 = 13 from the left. So the answer is M.
Source: PYQ-style

31. If the alphabet is written in reverse order, which letter will be 8th to the right of the 10th letter from the left?
(a) H (b) G (c) J (d) I
Answer: (d)
Solution: Students often reverse the alphabet mentally for only one step and lose track. In the reversed alphabet the 10th letter from the left is Q (17th in normal order); moving 8 places right in the reversed series means moving 8 places towards A, i.e. 17 − 8 = 9th normal letter. So the answer is I.
Source: PYQ-style

32. How many meaningful English words can be formed with the letters E, A, R, T using each letter only once?
(a) 2 (b) 4 (c) 3 (d) 5
Answer: (c)
Solution: The trap is counting only the obvious words RATE and TEAR and stopping at 2, or counting three-letter words like EAR which do not use all four letters. The valid four-letter words are RATE, TEAR and TARE. So the answer is 3.
Source: PYQ-style

33. In the word "MACHINE", how many pairs of letters have as many letters between them in the word as in the alphabet?
(a) 3 (b) 0 (c) 1 (d) 2
Answer: (a)
Solution: The tempting mistake is checking only adjacent-looking pairs like H–I and stopping. Checking all pairs, the matches are M–I (three letters between in both), H–I (zero between in both) and H–E (two letters between in both). So the answer is 3.
Source: PYQ-style

34. If every alternate letter of the alphabet starting from A is removed (A, C, E, … removed), which letter will be the 7th in the remaining series?
(a) N (b) M (c) O (d) P
Answer: (a)
Solution: The trap is counting the removed letters instead of the remaining ones. The remaining series is B, D, F, H, J, L, N, P, … and its 7th term is N. So the answer is N.
Source: PYQ-style

35. Which of the following words will come third in a dictionary?
(a) Manage (b) Mango (c) Manner (d) Manual
Answer: (c)
Solution: The trap is comparing only the first three letters, which are identical (Man). Compare the 4th letter: Manage (b), Mango (g), Manner (n), Manual (u), giving the order Manage, Mango, Manner, Manual. So the answer is Manner.
Source: PYQ-style

36. Which of the following words will come second in a dictionary?
(a) Prize (b) Printer (c) Private (d) Prince
Answer: (b)
Solution: The trap is comparing only "Pri", which is common to all four. The 4th letters are n (Prince, Printer), v (Private), z (Prize); between Prince and Printer the 5th letter decides: c comes before t, so the order is Prince, Printer, Private, Prize. So the answer is Printer.
Source: PYQ-style

37. If A = 1, B = 2, … Z = 26, what is the sum of the letter values of the word "CAB"?
(a) 5 (b) 6 (c) 8 (d) 9
Answer: (b)
Solution: The trap is misreading B's value as 3 and getting 7 or more. C = 3, A = 1, B = 2, so the sum is 3 + 1 + 2 = 6. So the answer is 6.
Source: PYQ-style

38. In a certain code, the letters of the alphabet are numbered such that A = 26, B = 25, … Z = 1. What is the value of the letter H?
(a) 19 (b) 18 (c) 17 (d) 20
Answer: (a)
Solution: The tempting error is computing 26 − 8 = 18, forgetting the +1 in the reverse formula. Reverse value = 27 − normal position = 27 − 8 = 19. So the answer is 19.
Source: PYQ-style

39. How many letters in the word "EDUCATION" remain at the same position when the letters are arranged in alphabetical order?
(a) 2 (b) 0 (c) 3 (d) 1
Answer: (b)
Solution: The trap is assuming the starting vowel E will stay fixed without checking. The alphabetical arrangement is A, C, D, E, I, N, O, T, U, and comparing position by position with E, D, U, C, A, T, I, O, N, no letter stays in its original place. So the answer is 0.
Source: PYQ-style

40. Which letter is exactly in the middle of the 8th letter from the left and the 20th letter from the left in the English alphabet?
(a) M (b) L (c) O (d) N
Answer: (d)
Solution: The trap is averaging the letter values instead of the positions. The middle position is (8 + 20)/2 = 14, and the 14th letter is N. So the answer is N.
Source: PYQ-style

41. If the first half of the alphabet is written in reverse order, which letter will be 10th from the left?
(a) F (b) E (c) C (d) D
Answer: (d)
Solution: The trap is reversing the whole alphabet instead of only the first half. The new order begins M, L, K, J, I, H, G, F, E, D, … and the 10th letter is D. So the answer is D.
Source: PYQ-style

42. In the word "POLITICAL", which letter is 3rd to the right of the letter which is 4th from the left?
(a) I (b) T (c) L (d) C
Answer: (d)
Solution: The trap is counting the reference letter itself as the first step to the right. The 4th letter from the left is I (position 4); three places to its right is position 7, which is C. So the answer is C.
Source: PYQ-style

43. How many vowels in the word "BEAUTIFUL" are immediately preceded by a consonant?
(a) 1 (b) 2 (c) 4 (d) 3
Answer: (d)
Solution: The trap is counting all vowels instead of only those coming just after a consonant. In B-E-A-U-T-I-F-U-L, the vowels E (after B), I (after T) and U (after F) qualify, while A and the first U follow vowels. So the answer is 3.
Source: PYQ-style

44. If Z = 1, Y = 2, … A = 26, what is the sum of the values of the letters in "CAT"?
(a) 57 (b) 56 (c) 58 (d) 55
Answer: (a)
Solution: The trap is using normal values (3 + 1 + 20 = 24) instead of reversed ones. Reversed value = 27 − normal position: C = 24, A = 26, T = 7, and 24 + 26 + 7 = 57. So the answer is 57.
Source: PYQ-style

45. Which group of letters is different from the others?
(a) DFI (b) BDG (c) EHK (d) ACF
Answer: (c)
Solution: The trap is checking only the first gap and not the second. In ACF, BDG and DFI the gaps are +2 then +3, but in EHK the gaps are +3 then +3. So the answer is EHK.
Source: PYQ-style

46. Find the missing letter in the series: B, E, H, K, ?
(a) M (b) O (c) N (d) L
Answer: (c)
Solution: The trap is misreading the gap as +2 and picking a nearer letter. Each step adds 3: B(2), E(5), H(8), K(11), so the next is 11 + 3 = 14. So the answer is N.
Source: PYQ-style

47. Find the missing letter in the series: A, C, F, J, O, ?
(a) U (b) T (c) S (d) R
Answer: (a)
Solution: The trap is assuming equal gaps. The gaps are +2, +3, +4, +5, so the next gap is +6: O(15) + 6 = 21. So the answer is U.
Source: PYQ-style

48. In the series Z, X, V, T, ?, which letter comes next?
(a) Q (b) R (c) S (d) P
Answer: (b)
Solution: The trap is reading the series forward and adding 2. The series decreases by 2 each time: Z(26), X(24), V(22), T(20), so the next is 18. So the answer is R.
Source: PYQ-style

49. How many meaningful English words can be formed from the letters N, O, T, E using each letter only once?
(a) 4 (b) 1 (c) 3 (d) 2
Answer: (d)
Solution: The trap is counting three-letter words like NOT and TON, but all four letters must be used. The valid four-letter words are NOTE and TONE. So the answer is 2.
Source: PYQ-style

50. If the letters of the word "MASTER" are rearranged, which of the following arrangements would appear first in a dictionary?
(a) MASTER (b) MATERS (c) ARMETS (d) STREAM
Answer: (c)
Solution: The trap is picking MASTER because it is the familiar word, without comparing first letters. Dictionary order is decided by the first letter: ARMETS starts with A, MATERS and MASTER with M, and STREAM with S, and A comes earliest. So the answer is ARMETS.
Source: PYQ-style
