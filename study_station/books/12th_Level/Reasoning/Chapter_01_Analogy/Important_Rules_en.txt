# Important Rules & Approaches — Analogy

## Part 1: Key Rules / Approaches

| Rule Name | Description | Example |
|---|---|---|
| Identify the Relationship First | Before looking at options, state the exact relation between the given pair in one short sentence. | Doctor : Hospital → "A doctor works in a hospital." |
| Make a Bridge Sentence | Convert the pair into a sentence, then test each option in the same sentence. | Bird : Nest → "A bird lives in a nest" → Lion : Den ✓ |
| Match the Order of Terms | The relation must hold in the same direction (A→B), not reversed. | Tree : Fruit ≠ Fruit : Tree; Egg : Bird is wrong if the pair is Bird : Egg. |
| Match the Part of Speech | Noun : Noun pairs need noun : noun options; Verb : Verb needs verb : verb. | Run : Fast (verb : adverb) → Sing : Melodiously ✓ |
| Check the Degree/Intensity | For synonym-type analogies, match the intensity level of words. | Warm : Hot (increasing heat) → Cool : Cold ✓ |
| Classify the Analogy Type | Quickly tag the pair: synonym, antonym, part-whole, tool-work, worker-workplace, cause-effect, number/letter pattern. | Pen : Write → tool : function type |
| Letter-Shift Rule (Alphabet Analogy) | Convert letters to positions (A=1…Z=26) and find the shift/pattern; apply the same to the answer. | ABC : DEF (+3 each) → GHI : JKL ✓ |
| Number Operation Rule | Try +, −, ×, ÷, square, cube, or a combination on the first number to get the second. | 4 : 16 (square) → 5 : 25 ✓ |
| Eliminate Wrong Options | Remove options where the relation, order, or word class does not match; choose from what remains. | If pair is "part : whole", delete all "whole : part" options first. |
| Beware of Near-Correct Traps | Examiners place options with a similar but not identical relation; verify with your bridge sentence. | Doctor : Patient is a trap for Doctor : Hospital (person vs place). |
| Gender/Young-One Rule | Match the exact sub-type: male-female, adult-young, animal-sound, etc. | Dog : Puppy → Cat : Kitten ✓ (not Cat : Cub) |
| Country–Capital–Currency Precision | These are fixed facts; one wrong detail makes the option wrong. | India : New Delhi → Japan : Tokyo ✓ |

## Part 2: Time Management

| Rule | Description | Action |
|---|---|---|
| 15-Second Rule | If the relationship between the given pair is not clear within 15 seconds, do not force it. | Mark the question and move on; return in the second round. |
| 45-Second Rule | No analogy question should take more than 45 seconds in total, including checking options. | If still unsolved at 45 seconds, make your best elimination-based guess or skip. |
| Easy-First Pass | Solve direct types (synonym, antonym, capital, young-one) first; they take under 15 seconds each. | Secure quick marks before attempting letter/number patterns. |
| Option-Scan Shortcut | Read options before fully solving; sometimes only one option fits the obvious relation type. | Saves 10–15 seconds per question. |
| No-Overthinking Rule | The simplest, most direct relationship is usually correct; avoid inventing complex links. | Prefer "lives in" over rare or indirect connections. |
| Revision Slot | Reserve the last 2–3 minutes of the reasoning section for marked/skipped analogies. | Re-attempt with a fresh mind; often the pattern becomes visible. |

## Part 3: Logical / Mathematical Formulas

| Formula | Use | Example |
|---|---|---|
| Letter position: A=1, B=2, … Z=26 | Base for all alphabet analogies. | D = 4, so D + 3 = G |
| Reverse position: 27 − n | Position from the end of the alphabet. | Z = 27 − 26 = 1 from end |
| n² (square) | Number analogy where second term is the square. | 7 : 49 |
| n² ± k | Square plus/minus a constant. | 5 : 27 (5² + 2) |
| n³ (cube) | Number analogy using cubes. | 3 : 27 |
| n × k or n × k ± c | Multiplication-based patterns. | 6 : 38 (6 × 6 + 2) |
| Sum of digits / digit reversal | Used in tricky number analogies. | 36 : 63 (reversal) |
| Letter-pair sum constant | Two letters' positions add to a fixed number (often 27). | A : Z (1 + 26 = 27) → C : X (3 + 24 = 27) |
