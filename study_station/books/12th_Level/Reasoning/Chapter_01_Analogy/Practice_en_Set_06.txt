126. Doctor : Patient :: Lawyer : ?
(a) Customer (b) Accused (c) Client (d) Magistrate
Answer: (c)
Solution: The tempting option is Accused, but a lawyer serves all clients, not only the accused; an accused person is merely one type of client. A doctor gives professional service to a patient, and a lawyer gives professional service to a client, so the answer is Client.
Source: PYQ-style

127. Thermometer : Temperature :: Ammeter : ?
(a) Voltage (b) Power (c) Resistance (d) Current
Answer: (d)
Solution: The trap is Voltage, which is measured by a voltmeter, not an ammeter. A thermometer measures temperature, and an ammeter measures electric current, so the answer is Current.
Source: NCERT Class 10 Science

128. Moon : Satellite :: Earth : ?
(a) Planet (b) Star (c) Sun (d) Asteroid
Answer: (a)
Solution: The tempting option is Sun, but the Sun is what Earth revolves around, not what Earth is. The Moon is a satellite of Earth, and the Earth is a planet of the Sun — both pairs show object : category, so the answer is Planet.
Source: NCERT Class 6 Geography

129. Ornithology : Birds :: Entomology : ?

132. 8 : 72 :: 9 : ?
(a) 81 (b) 99 (c) 72 (d) 90
Answer: (d)
Solution: The tempting option is 81, which is simply 9 squared, but the rule is n : n × (n + 1), since 8 × 9 = 72. Applying the same rule, 9 × 10 = 90, so the answer is 90.

135. DF : UW :: GI : ?
(a) TR (b) XZ (c) QS (d) RT
Answer: (b)
Solution: The trap is TR, which comes from mixing reverse-alphabet pairing with the wrong order; the actual rule is that each letter moves 17 places forward: D(4) → U(21) and F(6) → W(23). Applying it, G(7) → X(24) and I(9) → Z(26), so the answer is XZ.

136. ABC : ZYX :: DEF : ?
(a) VUW (b) UVW (c) WUV (d) WVU
Answer: (d)
Solution: The tempting option is WUV, which scrambles the order; the rule is that each letter is replaced by its reverse-alphabet counterpart (A↔Z, B↔Y, C↔X). Thus D→W, E→V, F→U, so the answer is WVU.

146. ACE : GIK :: BDF : ?
(a) HJK (b) HJL (c) GIK (d) IKM
Answer: (b)
Solution: The tempting option is HJK, but the rule is that every letter moves 6 places forward: A→G, C→I, E→K. Applying it, B→H, D→J, F→L, so the answer is HJL.

147. 42 : 6 :: 56 : ?
(a) 7 (b) 6 (c) 8 (d) 9
Answer: (c)
Solution: The trap is 7, chosen by students who assume the answer must be a single-digit divisor of 56 without checking the first pair; the rule is n : n ÷ 7, since 42 ÷ 7 = 6. Applying it, 56 ÷ 7 = 8, so the answer is 8.
