# सादृश्यता (Analogy) — महत्वपूर्ण नियम एवं दृष्टिकोण

## 1️⃣ मुख्य नियम / दृष्टिकोण

| नियम का नाम | विवरण | उदाहरण |
|---|---|---|
| संबंध पहचानो नियम | पहले दिए गए युग्म (A : B) के बीच का संबंध ठीक-ठीक पहचानें, फिर वही संबंध दूसरे युग्म (C : ?) में लागू करें। | पुस्तक : पढ़ना :: चाकू : काटना (कार्य-संबंध) |
| क्रम स्थिरता नियम | संबंध की दिशा (क्रम) कभी न बदलें — A से B जैसा संबंध है, वैसा ही C से उत्तर होना चाहिए। | घोड़ा : घोड़ी :: राजा : रानी (स्त्रीलिंग); "रानी : राजा" गलत |
| समान श्रेणी नियम | उत्तर विकल्प उसी श्रेणी/वर्ग का होना चाहिए जिस श्रेणी का दिया गया पद है। | आम : फल :: गाजर : सब्ज़ी (फल नहीं) |
| सटीक संबंध नियम | "लगभग मिलता" संबंध नहीं, बिल्कुल वही विशिष्ट संबंध चुनें जो प्रश्न-युग्म में है। | डॉक्टर : रोगी :: वकील : मुवक्किल (सेवा-ग्राहक, मित्र नहीं) |
| शब्द-प्रकार नियम | संग्या का उत्तर संग्या, क्रिया का क्रिया, विशेषण का विशेषण होना चाहिए। | गर्म : ठंडा :: दिन : रात (विलोम) |
| वर्णमाला स्थिति नियम | अक्षरों की स्थिति-संख्या (A=1 … Z=26) याद रखें; अंतर, योग, विपरीत अक्षर (A↔Z) जाँचें। | ABC : ZYX :: DEF : WVU (विपरीत अक्षर) |
| संख्या-संक्रिया नियम | संख्या-सादृश्यता में वर्ग, घन, गुणन, जोड़, आधा-दुगुना जैसी संक्रियाएँ क्रम से जाँचें। | 4 : 16 :: 5 : 25 (वर्ग) |
| शब्द-निर्माण नियम | शब्दों में अक्षरों की संख्या, अक्षरों का पुनर्विन्यास, उपसर्ग/प्रत्यय का संबंध जाँचें। | LISTEN : SILENT :: EARTH : HEART (अक्षर-पुनर्विन्यास) |
| प्रमुख संबंध-प्रकार | कार्य, उपकरण-कार्यकर्ता, जीव-वासस्थान, जीव-बच्चा, देश-राजधानी/मुद्रा, अंश-संपूर्ण, पर्यायवाची, विलोम, लिंग, मात्रा-इकाई, अध्ययन-विषय — इन्हें क्रम से याद रखें। | कुत्ता : पिल्ला :: बिल्ली : बिलौटा (जीव-बच्चा) |
| विकल्प-विलोमन विधि | संबंध स्पष्ट न हो तो हर विकल्प को C के साथ जोड़कर देखें कि कौन-सा युग्म A : B जैसा संबंध बनाता है। | पेन : लिखना :: ? : सिलना → सुई |
| दोहरा संबंध सावधानी | कभी-कभी दो विकल्प एक ही प्रकार के संबंध दिखाते हैं; तब अधिक विशिष्ट/सटीक वाला चुनें। | पक्षी : घोंसला :: शेर : माँद (घर नहीं) |
| चित्र/आकृति सादृश्यता | आकृतियों में घूर्णन, दर्पण-प्रतिबिंब, भागों की संख्या, छायांकन का परिवर्तन जाँचें। | त्रिभुज घूमकर उल्टा हो → विकल्प में उल्टी आकृति |

## 2️⃣ समय प्रबंधन

| नियम | विवरण |
|---|---|
| 15-सेकंड नियम | यदि 15 सेकंड में A : B का संबंध स्पष्ट न हो, तो प्रश्न को चिह्नित कर आगे बढ़ें; अंत में समय बचे तो लौटें। |
| 45-सेकंड नियम | संबंध मिल जाने पर भी 45 सेकंड से अधिक न लगाएँ; विकल्प-विलोमन विधि से जल्दी उत्तर तय करें। |
| पहले आसान, फिर कठिन | शब्द-सादृश्यता (विलोम/पर्यायवाची) सबसे तेज़ होती है — पहले हल करें; संख्या/अक्षर-सादृश्यता बाद में। |
| अनुमान से बचें | संबंध न मिले तो तुक्का न लगाएँ (negative marking में) — छोड़ना बेहतर है। |
| अभ्यास लक्ष्य | अभ्यास में प्रति प्रश्न 30 सेकंड का लक्ष्य रखें, तभी परीक्षा में 15–45 सेकंड संभव होगा। |

## 3️⃣ गणितीय / तार्किक सूत्र

| सूत्र/संक्रिया | प्रयोग | उदाहरण |
|---|---|---|
| अक्षर स्थिति-संख्या | A=1, B=2 … Z=26; विपरीत अक्षर = 27 − स्थिति | C(3) का विपरीत X(24) |
| वर्ग संबंध | n : n² | 7 : 49 |
| घन संबंध | n : n³ | 3 : 27 |
| गुणन/भाग संबंध | n : n×k या n : n÷k | 6 : 18 (×3) |
| जोड़/घटाव संबंध | n : n+k | 9 : 14 (+5) |
| मिश्रित संक्रिया | n : n²+1, n : 2n+3 आदि — क्रम से जाँचें | 4 : 17 (वर्ग+1) |
| अंक-योग संबंध | n : अंकों का योग | 56 : 11 (5+6) |

**नोट:** शब्द-सादृश्यता में कोई सूत्र नहीं होता; सूत्र केवल संख्या एवं अक्षर-आधारित सादृश्यता में लागू होते हैं।
