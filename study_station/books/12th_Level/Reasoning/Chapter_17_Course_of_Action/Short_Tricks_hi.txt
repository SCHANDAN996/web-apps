# 🪄 शॉर्ट ट्रिक्स — कथन और कार्यवाही (Statement & Course of Action)

---

## 🎯 ट्रिक 1: "समस्या → समाधान" का सीधा रास्ता

```
┌─────────────────────────────────────────────┐
│  🧠 म्नेमोनिक: "दर्द है तो दवा दो"          │
│                                             │
│  कथन = दर्द (समस्या)                        │
│  कार्यवाही = दवा (समाधान)                   │
│                                             │
│  दवा दर्द से जुड़ी होनी चाहिए!              │
│  सिरदर्द में पेट की दवा = गलत कार्यवाही ❌  │
└─────────────────────────────────────────────┘
```
**नियम:** कार्यवाही कथन की समस्या से **सीधे और तार्किक रूप से** जुड़ी हो। अगर कथन "सड़क दुर्घटनाएँ बढ़ीं" है और कार्यवाही "स्कूलों में छुट्टी बढ़ाई जाए" — तो यह दवा दर्द से मेल नहीं खाती।

## 🎯 ट्रिक 2: "3-सी" फॉर्मूला

```
┌─────────────────────────────────────────────┐
│  🧠 म्नेमोनिक: "तीन सी की जाँच"             │
│                                             │
│  C1 = Connection (समस्या से जुड़ाव)         │
│  C2 = Correctness (व्यावहारिक/उचित)         │
│  C3 = Capability (करना संभव है?)            │
│                                             │
│  तीनों ✅ = कार्यवाही सही                   │
│  एक भी ❌ = कार्यवाही गलत                  │
└─────────────────────────────────────────────┘
```

## 🎯 ट्रिक 3: "अति हर जगह बुरी"

```
┌─────────────────────────────────────────────┐
│  🧠 म्नेमोनिक: "अति = आउट"                  │
│                                             │
│  कार्यवाही में ये शब्द दिखें तो सतर्क:      │
│  • "सभी को गिरफ्तार कर देना चाहिए"          │
│  • "पूरी तरह बंद कर देना चाहिए"             │
│  • "हमेशा के लिए प्रतिबंध"                  │
│  • "तुरंत गोली मार देनी चाहिए"              │
│                                             │
│  अतिवादी/चरमपंथी कार्यवाही = 99% गलत ❌     │
└─────────────────────────────────────────────┘
```

## 🎯 ट्रिक 4: "कल का काम आज नहीं"

```
┌─────────────────────────────────────────────┐
│  🧠 म्नेमोनिक: "पुरानी कार्यवाही = पुराना   │
│               जूता"                         │
│                                             │
│  अगर कार्यवाही ऐसी बात कहे जो पहले से       │
│  हो चुकी है या कथन में पहले से कही गई है,   │
│  तो वह कार्यवाही नहीं, दोहराव है।           │
│                                             │
│  दोहराव = गलत ❌                            │
└─────────────────────────────────────────────┘
```
**उदाहरण:** कथन: "सरकार ने बिजली दरें बढ़ा दी हैं।" कार्यवाही: "सरकार को बिजली दरें बढ़ानी चाहिए।" → यह तो हो चुका! ❌

## 🎯 ट्रिक 5: "सुझाव नहीं, कदम चाहिए"

```
┌─────────────────────────────────────────────┐

│                                             │

│  खाली सलाह/भाषण/जागरूकता-ही-जागरूकता        │

│                                             │
│  लेकिन ध्यान: "जागरूकता अभियान" तब सही है   │
│  जब समस्या ही अज्ञानता की हो!               │
└─────────────────────────────────────────────┘
```

## 🚫 Skip Strategy — कब प्रश्न छोड़ें

```
┌─────────────────────────────────────────────┐
│  🏳️ SKIP SIGNAL 1: "दोनों कार्यवाही लगभग    │
│  एक जैसी लग रही हैं और 45 सेकंड में फर्क    │
│  नहीं समझ आया" → छोड़ो, बाद में आओ।         │
│                                             │
│  🏳️ SKIP SIGNAL 2: "कथन में ऐसी जानकारी    │
│  है जिससे आप अपरिचित हो (जैसे कोई कानून     │
│  या योजना)" → अनुमान मत लगाओ, skip करो।     │
│                                             │
│  🏳️ SKIP SIGNAL 3: "दोनों कार्यवाहियाँ      │
│  सही लग रही हैं पर विकल्प में 'दोनों'       │
│  नहीं है" → प्रश्न में गड़बड़ी संभव,        │
│  समय बर्बाद मत करो।                         │
│                                             │
│  💡 याद रखो: Negative marking में एक        │
│  skipped प्रश्न > एक गलत प्रश्न!            │
└─────────────────────────────────────────────┘
```
