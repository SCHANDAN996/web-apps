# Important Rules & Approaches — Statement & Course of Action

## Part 1: Key Rules / Approaches

| Rule Name | Description | Example |
|---|---|---|
| Problem–Action Link | The course of action must directly address the problem stated in the statement. | Statement: "Road accidents are rising due to drunk driving." → Valid action: "Strict checking and heavy fines for drunk driving." |
| Practicality Test | The action must be practically possible and legally/constitutionally valid. | "Ban all vehicles" is impractical; "Enforce traffic rules strictly" is practical. |
| Positive Approach | Prefer constructive, solution-oriented actions over harsh, negative, or extreme ones. | "Improve facilities in government schools" ✓; "Close all government schools" ✗ |
| No Extreme Action | Actions involving violence, bans on everything, or punishment without inquiry are rejected. | "Dismiss all employees" / "Shoot the protesters" — always wrong. |
| No Assumption of Facts | Do not assume facts not given in the statement; judge only on what is stated. | If the statement says "water supply is irregular," do not assume corruption is the cause. |
| Authority Check | The action must be within the power of the authority mentioned (government, police, management). | Police cannot "pass a new law" — that is the legislature's job. |
| Long-Term vs Short-Term | Both immediate relief and long-term prevention can be valid; check if each logically follows. | Flood situation → "Provide relief material" (short-term) ✓ and "Build better drainage" (long-term) ✓ |
| "Only I / Only II / Both / Neither" Logic | Evaluate each course of action independently first, then combine. | If I follows and II does not → answer "Only I follows." |
| Reject Repetition of Problem | An action that merely restates the problem or expresses concern is not a course of action. | "The matter should be discussed" without any concrete step — usually rejected. |
| Inquiry Before Punishment | Punitive action is valid only after a proper inquiry is proposed. | "Suspend the official after an inquiry" ✓; "Punish the official immediately" ✗ |
| Universal Applicability | The action should be a general solution, not one that helps only a select few unfairly. | "Give free laptops to all rich students" — illogical and unfair. |
| Precedent / Standard Practice | Actions matching standard administrative practice (committees, awareness drives, enforcement) usually follow. | "Set up a committee to look into the matter" — often valid for policy-level problems. |

## Part 2: Time Management

| Rule | Description |
|---|---|
| 15-Second Rule | Read the statement and both courses of action once. If the problem–action link is not clear within 15 seconds, mark the question and move on. |
| 45-Second Rule | Spend a maximum of 45 seconds per question. Most Statement & Course of Action questions are solvable in 30–45 seconds; never cross 60 seconds. |
| Two-Pass Strategy | Pass 1: Solve all direct, obvious questions. Pass 2: Return to marked questions with a fresh read of the statement only. |
| Elimination First | Eliminate clearly extreme/impractical actions in the first 10 seconds — this often halves the options instantly. |
| Skip Signal | Skip if: (a) the statement is ambiguous even after two reads, or (b) both actions look equally valid/invalid and you cannot decide within 45 seconds. |
