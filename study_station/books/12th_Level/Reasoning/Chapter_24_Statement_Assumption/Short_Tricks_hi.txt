# 🪄 शॉर्ट ट्रिक्स — कथन और पूर्वधारणा

---

## 🎯 ट्रिक 1: "छुपा हुआ = पूर्वधारणा"

```
┌─────────────────────────────────────────┐
│  याद रखो: "जो बोला नहीं, पर सोचा ज़रूर"   │
│                                         │
│  पूर्वधारणा = वक्ता के मन की वह बात      │
│  जो कथन में लिखी नहीं, पर मानी गई है।    │
│                                         │
│  👉 कथन में जो साफ़ लिखा है, वो          │
│     पूर्वधारणा कभी नहीं हो सकती!         │
└─────────────────────────────────────────┘
```

│  ② इसका असर होगा                        │
│                                         │
│  👉 "नोटिस देखो, दो मानो" — याद रहेगा!   │

## 🎯 ट्रिक 5: "केवल-सर्व-हमेशा = लाल झंडा" 🚩

```
┌─────────────────────────────────────────┐
│  पूर्वधारणा में ये शब्द दिखें:          │
│  केवल | सभी | हमेशा | कभी नहीं | एकमात्र │
│                                         │
│  → 90% मामलों में वह पूर्वधारणा गलत!    │
│  (अतिवादी शब्द = परीक्षक का जाल)        │
│                                         │

└─────────────────────────────────────────┘

## 🎯 ट्रिक 8: "उल्टा परीक्षण" (Negation Test)

```
┌─────────────────────────────────────────┐
│  पूर्वधारणा को उल्टा करके देखो:         │
│  अगर उल्टा करने से कथन बेकार/           │
│  बेमतलब हो जाए → धारणा निहित है ✓       │
│  कथन पर कोई फर्क न पड़े → निहित नहीं ✗  │
│                                         │
│  👉 "उल्टा करो, कथन टूटे तो पकड़ो"      │
└─────────────────────────────────────────┘
```

## 🎯 ट्रिक 13: "I-II में संघर्ष? दोनों-निहित विकल्प देखो"

```

│  दोनों धारणाएँ अलग-अलग कोण से सही       │
│  लगें और एक-दूसरे को न काटें,           │
│  तो "दोनों निहित" चुनने से मत डरो।      │
│  पर दोनों एक ही बात कह रही हों          │
│  तो सिर्फ एक चुनो।                      │
│                                         │
│  👉 "अलग कोण = दोनों, एक कोण = एक"      │

## ⏭️ SKIP STRATEGY — कब प्रश्न छोड़ें

```
┌─────────────────────────────────────────┐
│  ⏱️ नियम 1: 20-सेकंड नियम               │
│  20 सेकंड में "क्यों बोला?" टेस्ट से    │
│  कोई धारणा कनेक्ट न हो → मार्क करके     │
│  आगे बढ़ो, अंत में लौटो।                │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  ⏱️ नियम 2: दोनों-लग-रहे जाल            │
│  दोनों धारणाएँ सही लगें और अंतर         │
│  समझ न आए → अंदाज़ा मत लगाओ।           │
│  नेगेटिव मार्किंग में यही प्रश्न        │
│  सबसे ज़्यादा नुकसान करते हैं।          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  ⏱️ नियम 3: लंबा कथन = पहले छोड़ो       │
│  3-4 पंक्तियों वाला घुमावदार कथन हो     │
│  तो पहले राउंड में skip करो —           │
│  छोटे-सीधे प्रश्नों से अंक बटोरो,       │
│  फिर समय बचे तो लौटकर हल करो।          │
└─────────────────────────────────────────┘
```
