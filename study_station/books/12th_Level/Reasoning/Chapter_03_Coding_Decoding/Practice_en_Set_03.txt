51. In a certain code language, "MOTHER" is written as "NPUIFS". How will "FATHER" be written in that code?
(a) GBUIFS (b) GAUIFS (c) GBUIFR (d) GBTIFS
Answer: (a)
Solution: Each letter is shifted one step forward: M→N, O→P, T→U, H→I, E→F, R→S. The tempting option GBTIFS wrongly keeps T unchanged, but every letter must move forward by one, so the answer is GBUIFS.
Source: PYQ-style

52. In a certain code, "DELHI" is written as "CDKGH". How is "MUMBAI" written in that code?

Solution: Each letter is shifted one step backward: D→C, E→D, L→K, H→G, I→H. The option NTLAZH wrongly shifts the first letter forward; the rule is uniformly minus one, so the answer is LTLAZH.

61. In a code language, "123" means "hot filtered coffee", "356" means "very hot day" and "589" means "day and night". Which digit stands for "very"?
(a) 6 (b) 5 (c) 3 (d) 9
Answer: (a)
Solution: Comparing the first two codes, "hot" is common and so is digit 3; comparing the last two, "day" is common and so is digit 5. Removing hot=3 and day=5 from "356" leaves very=6. The trap is picking 5, which actually stands for "day", so the answer is 6.
Source: PYQ-style

62. In a certain code, "pit na som" means "bring me water", "na jo tod" means "water is life", "tub od pit" means "give me toy" and "som tod" means "good life". Which word stands for "is"?
(a) na (b) jo (c) tod (d) od
Answer: (b)
Solution: "water" is common to the first two sentences and the common code is "na"; "life" is common to the second and fourth sentences and the common code is "tod". Removing na=water and tod=life from "na jo tod" leaves jo=is. The trap is choosing "tod", which actually means "life", so the answer is jo.
Source: PYQ-style

63. If A = 1, B = 2, C = 3, and so on, then what is the code for the word "CAB" if the code is the sum of letter values?
(a) 4 (b) 5 (c) 6 (d) 7
Answer: (c)
Solution: C = 3, A = 1, B = 2, so the sum is 3 + 1 + 2 = 6. The trap option 5 comes from miscounting C as 2; C is the third letter, so the answer is 6.
