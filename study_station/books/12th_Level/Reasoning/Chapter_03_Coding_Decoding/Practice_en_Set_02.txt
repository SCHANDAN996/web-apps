26. In a certain code language, "MANGO" is written as "NBOHP". How will "APPLE" be written in the same code?
(a) ZQQKD (b) BQOMF (c) BQQMF (d) ZOOKD
Answer: (c)
Solution: The tempting option BQOMF swaps the middle letters instead of shifting each one forward. Each letter is shifted +1: M→N, A→B, N→O, G→H, O→P. Applying +1 to APPLE gives B, Q, Q, M, F, so the answer is BQQMF.
Source: PYQ-style
