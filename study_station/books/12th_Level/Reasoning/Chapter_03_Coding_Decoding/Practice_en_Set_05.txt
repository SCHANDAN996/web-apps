101. In a certain code, "MOTHER" is written as "NPUIFS". How is "FATHER" written in that code?
(a) GAUIFS (b) GBTIFS (c) GBUIFR (d) GBUIFS
Answer: (d)
Solution: Each letter is shifted one step forward: M→N, O→P, T→U, H→I, E→F, R→S. Applying the same to FATHER gives G, B, U, I, F, S; the tempting wrong option swaps the third and fourth letters, a common slip. So the answer is GBUIFS.
Source: PYQ-style

105. In a certain code, "123" means "hot filtered coffee", "356" means "very hot day", and "589" means "day and night". Which digit stands for "very"?
(a) 5 (b) 6 (c) 3 (d) 9
Answer: (b)
Solution: "hot" is common to the first two codes, and 3 is the common digit, so hot = 3. "day" is common to the last two codes, and 5 is common, so day = 5. In "356" = "very hot day", removing 3 and 5 leaves 6 for "very". So the answer is 6.

115. In a code language, "pen is mightier than sword" is written as "ta na ka sa ma", "sword is powerful" is "ka na ra", and "pen and sword" is "ta pa ka". What is the code for "powerful"?
(a) ra (b) na (c) ka (d) pa
Answer: (a)
Solution: "sword" appears in all three sentences and the common code is "ka", so sword = ka; "is" is common to the first two sentences and the common code is "na", so is = na. In "sword is powerful" = "ka na ra", removing ka and na leaves "ra" for powerful; the tempting wrong option "na" actually stands for "is". So the answer is ra.

124. In a certain language, "she is reading books" is coded as "lo mi na po", "books are very good" as "po re ti su", and "she reads good stories" as "mi su ka le". What is the code for "good"?
(a) su (b) re (c) ti (d) po
Answer: (a)
Solution: "books" appears in sentences one and two, and the common code is "po", so books = po. "good" appears in sentences two and three; the common code between "po re ti su" and "mi su ka le" is "su", so good = su. The tempting wrong option "po" belongs to "books", not "good". So the answer is su.
Source: PYQ-style
