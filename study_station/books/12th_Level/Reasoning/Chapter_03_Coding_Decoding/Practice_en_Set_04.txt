Questions 76–100: Medium

76. In a certain code, "MASTER" is written as "OCUVGT". How is "PLANET" written in that code?
(a) QNCPGV (b) RNCQGV (c) RNCPGV (d) RNCPGU
Answer: (c)
Solution: Each letter moves +2: M→O, A→C, S→U, T→V, E→G, R→T. The tempting option RNCQGV wrongly shifts N to Q instead of P. Applying +2 to PLANET gives R, N, C, P, G, V, so the answer is RNCPGV.
Source: PYQ-style

77. If "FRIEND" is coded as "GQJDMC", how will "ENEMY" be coded?
(a) FMGMZ (b) EMFLZ (c) FMFLY (d) FMFLZ
Answer: (d)
Solution: The pattern alternates +1, −1: F+1=G, R−1=Q, I+1=J, E−1=D, N+1=M, D−1=C. The trap FMFLY forgets the final +1 on Y. For ENEMY: E+1=F, N−1=M, E+1=F, M−1=L, Y+1=Z, so the answer is FMFLZ.
Source: PYQ-style

78. In a code, "WATER" is written as "XBUFS". How is "MONEY" written?
(a) NOPFZ (b) NPOFY (c) NPOFZ (d) MPOFZ
Answer: (c)
Solution: Every letter shifts +1: W→X, A→B, T→U, E→F, R→S. The trap MPOFZ keeps the first letter unchanged, which breaks the uniform shift. MONEY becomes N, P, O, F, Z, so the answer is NPOFZ.

80. In a certain language, "pit na som" means "bring me water", "na jo tod" means "water is life", and "tub od pit" means "give me toy". Which word means "me"?
(a) na (b) som (c) pit (d) jo
Answer: (c)
Solution: "water" is common to the first two sentences, so "na" = water — this makes na the trap. "me" is common to the first and third sentences, and the common code word is "pit", so the answer is pit.

82. In a code, "TIGER" is written as "QDFHS". How is "LEOPARD" written?
(a) CQZONMD (b) DQZONMD (c) CQZNNMD (d) CQZONME
Answer: (a)
Solution: The word is reversed and each letter shifts −1: TIGER reversed is REGIT, then −1 gives QDFHS. The trap DQZONMD shifts the first letter by +1 instead of −1. LEOPARD reversed is DRAPOEL, shifted −1 gives C,Q,Z,O,N,M,D, so the answer is CQZONMD.

83. If A = 1, B = 2, … Z = 26, and "CAT" is coded as 24 (sum of letter values), what is the code for "DOG"?
(a) 24 (b) 26 (c) 28 (d) 30
Answer: (b)
Solution: CAT = 3+1+20 = 24 confirms the sum rule. The trap 24 comes from carelessly copying the example's value. DOG = 4+15+7 = 26, so the answer is 26.

86. In a code language, "she is good" is written as "ka ta ma", "he is bad" is written as "ta na sa", and "she and he" is written as "ka pa na". What is the code for "good"?
(a) pa (b) ma (c) ta (d) ka
Answer: (b)
Solution: "is" is common to sentences 1 and 2, so "ta" = is; "she" is common to 1 and 3, so "ka" = she. The trap ka is "she", not "good". The remaining word in sentence 1 is "good" = ma, so the answer is ma.
