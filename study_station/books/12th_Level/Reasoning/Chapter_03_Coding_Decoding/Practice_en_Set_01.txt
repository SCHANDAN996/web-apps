1. In a certain code, CAT is written as DBU. How is DOG written in that code?
(a) EPH (b) FPH (c) EPI (d) DPH
Answer: (a)
Solution: The trap is DPH, which shifts only the last two letters and leaves D unchanged. Each letter moves one step forward: C→D, A→B, T→U, so D→E, O→P, G→H, and the answer is EPH.
Source: PYQ-style

2. In a certain code, PEN is written as QFO. How is INK written in that code?
(a) JPM (b) JOL (c) KOL (d) JOK
Answer: (b)
Solution: The trap is JOK, which forgets to shift the last letter K. Each letter moves one step forward: P→Q, E→F, N→O, so I→J, N→O, K→L, and the answer is JOL.
Source: PYQ-style

3. If BOY is coded as YOB by writing the letters in reverse order, how is GIRL coded in the same way?
(a) LRIG (b) LIRG (c) RILG (d) GRLI
Answer: (a)
Solution: The trap is LIRG, which keeps the middle letters I and R in their original order. Reversing G-I-R-L completely gives L-R-I-G, so the answer is LRIG.

6. In a certain code, 123 means "hot filtered coffee", 356 means "very hot day" and 589 means "day and night". Which digit stands for "very"?
(a) 8 (b) 3 (c) 6 (d) 5
Answer: (c)
Solution: The trap is 3, but 3 is common to the first two codes which share "hot", so hot = 3. The last two codes share "day" and digit 5, so day = 5; in the second code the remaining digit 6 stands for "very", so the answer is 6.

11. In a certain code, "pit na som" means "bring me water", "na jo tod" means "water is life", "tub od pit" means "give me toy". Which word means "me"?
(a) jo (b) pit (c) som (d) na
Answer: (b)
Solution: The trap is "na", but na is common to the first two sentences which share "water", so water = na. "Me" appears in the first and third sentences and the common code word is "pit", so the answer is pit.
Source: PYQ-style

12. If A = 1, B = 2, … Z = 26, what is the sum of the letter values of the word CAB?
(a) 7 (b) 5 (c) 8 (d) 6
Answer: (d)
Solution: The trap is 7, which comes from miscounting C as 4. C = 3, A = 1, B = 2, and 3 + 1 + 2 = 6, so the answer is 6.
