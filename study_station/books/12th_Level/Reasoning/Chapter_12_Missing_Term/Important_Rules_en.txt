# Important Rules & Approaches — Missing Term

## Part 1: Key Rules/Approaches

| Rule Name | Description | Example |
|---|---|---|
| Identify the Series Type First | Check if the series is based on numbers, letters, or a mix (alpha-numeric) before solving. | A, C, F, J, ? → letter series with increasing gaps |
| Difference Method | Find the difference between consecutive terms; check if differences are constant, increasing, or form their own pattern. | 2, 5, 10, 17, ? → differences 3, 5, 7, 9 → answer 26 |
| Second-Level Difference | If first differences show no pattern, take differences of the differences. | 1, 4, 10, 19, ? → 1st diff: 3, 6, 9; 2nd diff: 3, 3 → answer 31 |
| Multiplication/Division Pattern | Check if each term is multiplied or divided by a fixed or changing number. | 3, 6, 18, 72, ? → ×2, ×3, ×4, ×5 → answer 360 |
| Mixed Operations | Pattern may combine operations like ×2 + 1, ×3 − 2, etc. | 2, 5, 11, 23, ? → ×2 + 1 each time → answer 47 |
| Square/Cube Pattern | Terms may be squares, cubes, or squares/cubes ± a number. | 2, 5, 10, 17, 26, ? → n² + 1 → answer 37 |
| Prime Number Check | Series may consist of consecutive prime numbers. | 2, 3, 5, 7, 11, ? → next prime → 13 |
| Alternate Series (Twin Series) | Odd-position and even-position terms follow two separate patterns. | 1, 2, 4, 4, 7, 8, ? → odd: 1,4,7,10; even: 2,4,8 → answer 10 |
| Letter Position Values | Convert letters to alphabet positions (A=1 … Z=26) and apply number rules. | C, F, I, L, ? → 3, 6, 9, 12, +3 → answer O |
| Opposite Letter Rule | Letters may pair with opposites (A↔Z, B↔Y … sum = 27). | A, Y, C, W, ? → alternate +2, −2 → answer E |
| Vowel/Consonant Pattern | Series may use only vowels or skip vowels. | A, E, I, O, ? → vowels → answer U |
| Group Pattern | Terms repeat in fixed groups or follow a cyclic order. | AB, DE, GH, JK, ? → skip one letter each time → answer MN |
| Fibonacci-Type Rule | Each term is the sum of the previous two terms. | 1, 1, 2, 3, 5, 8, ? → 5 + 8 → answer 13 |
| Digit-Based Pattern | Pattern may depend on sum of digits, reversed digits, or digit position. | 12, 21, 13, 31, 14, ? → reversed pairs → answer 41 |
| Check All Options | If two patterns seem possible, test which one matches an option exactly. | 4, 9, 16, 25, ? → squares → 36 (not 35) |

## Part 2: Time Management

| Rule | Description | Action |
|---|---|---|
| 15-Second Rule | If the pattern is not clear within 15 seconds, do not keep staring at the question. | Mark it and move to the next question immediately. |
| 45-Second Rule | If a pattern is found but calculation is long, give a maximum of 45 seconds total. | If still unsolved, make your best logical guess and skip. |
| First Pass Strategy | Solve all easy difference-based and letter-position questions first. | Secure quick marks before attempting mixed or twin series. |
| Second Pass Strategy | Return to marked questions with a fresh mind; try alternate-series or square/cube checks. | Often the pattern becomes visible on a second look. |
| No Blind Guessing | Missing Term questions have traps (near-correct options). | Guess only after eliminating at least two options. |
| Option Scanning | Glance at options before solving; they hint at the pattern type (big jumps = multiplication, small jumps = addition). | Saves 5–10 seconds per question. |

## Part 3: Logical/Mathematical Formulas

| Formula Name | Formula | Use / Example |
|---|---|---|
| Alphabet Position | A=1, B=2, … Z=26 | Convert letter series to numbers: D, G, J → 4, 7, 10 (+3) |
| Opposite Letter Sum | Letter + Opposite = 27 | A(1) ↔ Z(26); M(13) ↔ N(14) |
| nth Term of AP | aₙ = a + (n−1)d | Constant difference series: 5, 9, 13, … d=4 |
| Square Series | n² or n² ± k | 1, 4, 9, 16, 25 … or 2, 5, 10, 17 (n²+1) |
| Cube Series | n³ or n³ ± k | 1, 8, 27, 64 … or 0, 7, 26, 63 (n³−1) |
| Geometric Pattern | aₙ = a × rⁿ⁻¹ | Constant ratio: 3, 6, 12, 24 (r=2) |
| Triangular Numbers | n(n+1)/2 | 1, 3, 6, 10, 15, 21 … |
| Prime Numbers | 2, 3, 5, 7, 11, 13, 17, 19, 23 … | Memorise primes up to 50 for quick checks |
