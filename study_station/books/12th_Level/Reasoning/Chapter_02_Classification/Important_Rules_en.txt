# Important Rules & Approaches — Classification

## Part 1: Key Rules/Approaches

| Rule Name | Description | Example |
|---|---|---|
| Find the Common Property | First identify the property shared by all items, then find the one that lacks it. | Apple, Mango, Banana, Potato → Potato (vegetable, others are fruits) |
| Category-Based Grouping | Check if items belong to a category: animal/vegetable/mineral, living/non-living, profession, instrument, etc. | Doctor, Teacher, Lawyer, River → River (not a profession) |
| Number Property Check | For numbers, test: odd/even, prime/composite, perfect square/cube, divisibility, digit sum. | 3, 5, 7, 9 → 9 (composite, others are prime) |
| Letter Position Check | For letter groups, check alphabet positions: vowels, consecutive letters, gaps, sum of positions. | ACE, BDF, CEG, DFJ → DFJ (others have +2 gap) |
| Pair vs. Group Logic | Sometimes 3 items form a related trio (tool–work–worker); the odd one breaks the relation. | Pen–Write, Knife–Cut, Needle–Stitch, Book–Read → depends on relation asked |
| Word–Meaning Relation | Check synonym/antonym, part–whole, cause–effect, or degree relations among words. | Happy, Joyful, Glad, Angry → Angry (opposite emotion) |
| Gender/Class Distinction | One item may differ by gender, size, or sub-class within the same broad category. | Lion, Tiger, Leopard, Cow → Cow (herbivore/domestic, others wild carnivores) |
| Multiple Possible Answers | If two answers seem possible, choose the one based on the strongest/most specific common property. | Rose, Lotus, Marigold, Mango → Mango (tree fruit; others are flowers) |
| Elimination Method | When unsure, eliminate options that clearly share the group property; the leftover is the answer. | 8, 27, 64, 100 → 100 (not a perfect cube) |
| Check All Options First | Never lock an answer after checking only 2–3 options; the odd one may be revealed only after seeing all. | Always scan all four options before deciding. |

## Part 2: Time Management

| Rule | Description | Action |
|---|---|---|
| 15-Second Rule | If the common property/pattern is not clear within 15 seconds, do not keep staring. | Mark the question and move on; return later if time permits. |
| 45-Second Rule | No Classification question should take more than 45 seconds in total. | If still unsolved at 45 seconds, make your best elimination-based guess and move ahead. |
| Easy-First Pass | Classification questions are usually quick scorers; attempt them early in the reasoning section. | Solve all Classification questions in the first pass to secure fast marks. |
| No Overthinking | The simplest common property is usually the intended one; avoid rare or twisted logic. | Prefer the obvious category difference over complex patterns. |
| Skip Signal | If a question needs calculations beyond one step (e.g., multiple digit operations), it is a time trap. | Skip and revisit only after completing the section. |

## Part 3: Logical/Mathematical Formulas

| Formula/Tool | Use | Example |
|---|---|---|
| Alphabet Position (A=1 … Z=26) | To check letter gaps, sums, and patterns in letter classification. | C(3), F(6), I(9) → +3 pattern |
| Prime Numbers (2, 3, 5, 7, 11, 13…) | To spot the odd number that is prime/composite. | 2, 3, 5, 9 → 9 is composite |
| Perfect Squares (1, 4, 9, 16, 25…) | To classify numbers by square property. | 16, 25, 36, 50 → 50 is not a perfect square |
| Perfect Cubes (1, 8, 27, 64, 125…) | To classify numbers by cube property. | 8, 27, 64, 30 → 30 is not a perfect cube |
| Digit Sum Check | To test divisibility or hidden number patterns. | 12 (1+2=3), 21 (3), 30 (3), 25 (7) → 25 is odd one out |
| No other formulas | Classification is logic-based, not formula-based; the above checks are tools, not formulas. | — |
