101. Find the odd one out.
(a) Bat (b) Pigeon (c) Parrot (d) Sparrow
Answer: (a)
Solution: Bat is tempting because it flies like the others, but it is a mammal, not a bird. Sparrow, pigeon and parrot are all birds, so the answer is Bat.
Source: PYQ-style

102. Find the odd one out.
(a) Brass (b) Iron (c) Silver (d) Copper
Answer: (a)
Solution: Brass looks like a metal among metals, but it is an alloy of copper and zinc, while copper, iron and silver are pure elements, so the answer is Brass.
Source: NCERT Class 10 Science

103. Find the odd one out.
(a) 121 (b) 225 (c) 169 (d) 144
Answer: (b)
Solution: 121 = 11², 144 = 12², 169 = 13² are squares of consecutive numbers; 225 = 15² breaks the sequence since 14² = 196 is missing, so the answer is 225.
Source: PYQ-style

106. Find the odd one out.

Answer: (a)

121. Find the odd one out.
(a) 432 (b) 231 (c) 321 (d) 123
Answer: (a)
Solution: The trap is that all look like three-digit numbers with consecutive digits. In 123, 231 and 321 the digits are 1, 2 and 3 only, rearranged; 432 uses digits 4, 3, 2, a different set, so the answer is 432.
Source: PYQ-style

125. Find the odd one out.
