76. Which word will come first in a dictionary?
(a) Mango (b) Mandate (c) Manager (d) Manner
Answer: (c)
Solution: All four words begin with "Man", so compare the fourth letters: Manager has 'a', Mandate has 'd', Mango has 'g', Manner has 'n'. The trap is Mandate, picked by students who stop comparing too early; since 'a' is the smallest letter, the answer is Manager.
Source: PYQ-style

77. Arrange the words in dictionary order: 1. Select 2. Seldom 3. Selfish 4. Seller
(a) 4, 2, 1, 3 (b) 2, 4, 3, 1 (c) 2, 1, 4, 3 (d) 2, 1, 3, 4
Answer: (d)
Solution: All begin with "Sel"; the fourth letters are Select = 'e', Seldom = 'd', Selfish = 'f', Seller = 'l'. Since d < e < f < l, the order is Seldom, Select, Selfish, Seller. The trap is placing Seller before Select by misreading the fourth letters, so the answer is 2, 1, 3, 4.
