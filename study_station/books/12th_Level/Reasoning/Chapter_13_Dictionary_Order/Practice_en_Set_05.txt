101. Which word will come first in dictionary order?
(a) Capture (b) Captain (c) Capital (d) Capsule
Answer: (c)
Solution: All four words begin with "Cap", so compare the fourth letters: Capture 't', Capital 'i', Captain 't', Capsule 's'. The tempting trap is Capsule, because 's' looks early, but 'i' comes before 's' and 't', so the answer is Capital.
Source: PYQ-style

102. Arrange the following words in dictionary order: 1. Mango 2. Manage 3. Manner 4. Manual
(a) 2, 1, 3, 4 (b) 2, 3, 1, 4 (c) 1, 2, 3, 4 (d) 2, 1, 4, 3
Answer: (a)
Solution: All start with "Man", so compare the fourth letters: Mango 'g', Manage 'a', Manner 'n', Manual 'u'. The trap is assuming longer words come later, but only letter order matters; alphabetical order of a, g, n, u gives Manage, Mango, Manner, Manual, so the answer is 2, 1, 3, 4.
