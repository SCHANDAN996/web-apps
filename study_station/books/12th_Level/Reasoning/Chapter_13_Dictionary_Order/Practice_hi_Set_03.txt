51. निम्नलिखित शब्दों को शब्दकोश क्रम में व्यवस्थित कीजिए:

75. शब्दकोश क्रम में व्यवस्थित कीजिए:
1. Democracy 2. Demolish 3. Demonstrate 4. Demoralize
(a) 1, 2, 3, 4 (b) 1, 2, 4, 3 (c) 2, 1, 4, 3 (d) 1, 3, 2, 4
उत्तर: (a)
हल: सभी "Demo" से शुरू होते हैं। पाँचवें अक्षर की तुलना करें: Democracy में c है, Demolish में l है, Demonstrate में n है, Demoralize में r है। चूँकि c < l < n < r, शब्द पहले से शब्दकोश क्रम में हैं। जाल यह है कि अंतिम दो को उलट दिया जाए क्योंकि "moral", "monstrate" से पहले लगता है, पर निर्णायक अक्षर n और r हैं, इसलिए उत्तर 1, 2, 3, 4 है।
स्रोत: PYQ-style
