1. Which of the following words will come first in a dictionary?
(a) Magnet (b) Manage (c) Manner (d) Mango
Answer: (a)
Solution: All four words begin with "Man", so compare the fourth letters: g, a, g, n. "Manage" tempts many students because of the 'a', but the third letters of "Magnet" and "Manage" are 'g' and 'n', and 'g' comes before 'n', so Magnet precedes Manage. So the answer is Magnet.
Source: PYQ-style

2. Which word will come last in a dictionary?
(a) Chair (b) Chart (c) Chain (d) Charm
Answer: (b)
Solution: All begin with "Cha". The fourth letters are i, i, r, r, so the last word is among "Charm" and "Chart". Their fifth letters are 'm' and 't', and 't' comes later. So the answer is Chart.

3. Arrange in dictionary order: 1. Apple 2. Apply 3. Application 4. Appreciate
(a) 1, 2, 4, 3 (b) 3, 1, 2, 4 (c) 1, 2, 3, 4 (d) 1, 3, 2, 4
Answer: (d)
Solution: "Appreciate" has 'r' as its fourth letter while the others have 'l', so it comes last. Among Apple, Apply and Application, the fifth letters are e, y, i, giving Apple, Application, Apply. The trap is placing Apply before Application by ignoring the fifth letter. So the answer is 1, 3, 2, 4.

The full order is Pen, Pencil, Penny, Pension. The trap is ignoring "Pen" and counting only the longer words. So the answer is Penny.

21. In a dictionary, which word will appear between "Master" and "Matter"?
(a) Match (b) Mature (c) Mast (d) Mason
Answer: (a)
Solution: The third letter 's' comes before 't', so all "Mas" words (Mason, Mast, Master) precede all "Mat" words, which rules out Mason and Mast. Within the "Mat" group, "Match" has fourth letter 'c' and "Matter" has 't', so Match lies between Master and Matter, while "Mature" comes after "Matter" because its fifth letter 'u' follows 't'. So the answer is Match.
Source: PYQ-style

Answer: (c)
Solution: The trap is "Grant": compare the fourth letters of "Grammar" and "Grant" — 'm' comes before 'n', so all "Gram" words precede all "Gran" words, meaning Grant comes after Grammar, not before. The order is Grain, Gram, Grammar, Grand, Grant, and a prefix word like "Gram" comes immediately before its extension. So the answer is Gram.
