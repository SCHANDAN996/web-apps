# 🪄 SHORT TRICKS & MNEMONICS — Dictionary Order

---

## 🧠 MNEMONIC 1: "A-Z is the Boss"
```
┌─────────────────────────────────────────────┐
│  "In a dictionary, A is KING, Z is BEGGAR." │
│  Whatever comes first in A→Z comes first    │
│  in the list. No exceptions. Ever.          │
└─────────────────────────────────────────────┘
```
**Use:** The golden rule. Every dictionary-order question is just "who wins the alphabet race?"

---

## 🧠 MNEMONIC 2: "Same Start? Move Right!"
```
┌─────────────────────────────────────────────┐
│  "Letters match? Don't stop, don't fight —  │
│   just MOVE RIGHT to the next letter!"      │
└─────────────────────────────────────────────┘
```
**Use:** CAT vs CAR → C=C, A=A, then T vs R → R wins. Keep sliding right until letters differ.

---

## 🧠 MNEMONIC 3: "Short Word Wins the Tie"
```
┌─────────────────────────────────────────────┐
│  "When one word ENDS but letters still      │
│   match — the SHORT one stands first!"      │
│   PEN beats PENCIL. CAT beats CATCH.        │
└─────────────────────────────────────────────┘
```
**Use:** Trap questions! If word X is fully inside word Y (PEN inside PENCIL), X comes first.

---

## 🧠 MNEMONIC 4: "Number the Letters — 1 to 26"
```
┌─────────────────────────────────────────────┐
│  "A1 B2 C3 D4 E5 ... Z26 —                  │
│   turn letters into NUMBERS and compare     │
│   like money. Smaller number = earlier."    │
└─────────────────────────────────────────────┘
```
**Use:** For confusing pairs like M vs N (13 vs 14). EJOTY helps: E=5, J=10, O=15, T=20, Y=25.

---

## 🧠 MNEMONIC 5: "EJOTY — The Alphabet Checkpoints"
```
┌─────────────────────────────────────────────┐
│  E J O T Y                                  │
│  5 10 15 20 25                              │
│  "Every Jolly Officer Takes Yogurt"         │
│  Five checkpoints = instant letter numbers! │
└─────────────────────────────────────────────┘
```
**Use:** Never count from A again. Need R? O=15, so R=18. Done in 2 seconds.

---

## 🧠 MNEMONIC 6: "First Letter First — Group Them!"
```
┌─────────────────────────────────────────────┐
│  "Don't compare all words at once!          │
│   GROUP by first letter: all A-words,       │
│   then B-words, then C-words..."            │
└─────────────────────────────────────────────┘
```
**Use:** Arranging 5-6 words. First sort by letter 1, then sort inside each group. Cuts time by half.

---

## 🧠 MNEMONIC 7: "The Last-Letter Trap"
```
┌─────────────────────────────────────────────┐
│  "Never judge by the END of the word!       │
│   'APPLE' vs 'AXE' — APPLE wins because     │
│   P (16) beats X (24) at position 2.        │
│   The LAST letter is a decoy!"              │
└─────────────────────────────────────────────┘
```
**Use:** Examiner's favourite trap — words ending in early letters but starting late. AXE ends in E (early letter), yet APPLE still comes first because the decision happens at position 2: P before X.

---

## 🧠 MNEMONIC 8: "Which Comes 3rd? Build the Queue!"
```
┌─────────────────────────────────────────────┐
│  "Asked for the 3rd word? Don't guess!      │
│   Write the FULL order 1,2,3,4,5 —          │
│   then just point at number 3."             │
└─────────────────────────────────────────────┘
```
**Use:** "Which word comes third/fourth?" questions. Partial sorting causes silly errors — sort fully.

---

## 🧠 MNEMONIC 9: "Reverse Dictionary = Z to A"
```
┌─────────────────────────────────────────────┐
│  "Reverse order? Just flip the crown —      │
│   Z is KING now, A is beggar!"              │
└─────────────────────────────────────────────┘
```
**Use:** Rare but asked: "arrange in reverse dictionary order." Same method, opposite direction.

---

## 🧠 MNEMONIC 10: "Capitals Don't Matter"
```
┌─────────────────────────────────────────────┐
│  "DOG or dog — same rank in the book.       │
│   Capital letters get NO special seat!"     │
└─────────────────────────────────────────────┘
```
**Use:** Trap where options mix "Apple" and "apple" — treat them identically.

---

## 🧠 MNEMONIC 11: "The 15-Second Scan"
```
┌─────────────────────────────────────────────┐
│  "Look at ALL first letters first.          │
│   If all different → answer in 15 seconds.  │
│   If some match → only THOSE need round 2." │
└─────────────────────────────────────────────┘
```
**Use:** Triage! Very often the first letters alone decide the whole order — check them before doing any deeper comparison.

---

## 🧠 MNEMONIC 12: "Dictionary = Phone Contact List"
```
┌─────────────────────────────────────────────┐
│  "Your phone sorts names exactly like a     │
│   dictionary. 'Aarav' before 'Abhay' before │
│   'Zoya'. You've done this 1000 times!"     │
└─────────────────────────────────────────────┘
```
**Use:** Real-life anchor. If confused, imagine typing the words into your phone's search.

---

## 🧠 MNEMONIC 13: "One Letter Different? Slow Down!"
```
┌─────────────────────────────────────────────┐
│  "BALL vs BALD: B=B, A=A, L=L —             │
│   then position 4: L vs D.                  │
│   D (4) beats L (12), so BALD comes first!  │
│   Compare position by position, patiently." │
└─────────────────────────────────────────────┘
```
**Use:** Words differing by just one letter in the middle — the highest-error zone. Slow down here.

---

## ⏭️ SKIP STRATEGY — When to Skip

```
┌─────────────────────────────────────────────────────────┐
│  SKIP TIP 1: If after 15 seconds you haven't grouped    │
│  the words by first letter, MARK it and move on.        │
│  Dictionary questions are "bankers" — come back in the  │
│  last 10 minutes; they never need formulas, only care.  │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  SKIP TIP 2: 6+ words with 3+ sharing the same first    │
│  TWO letters (e.g., STRONG, STREAM, STREET, STRESS)?    │
│  High error risk under time pressure. Attempt only if   │
│  you have 40+ seconds; otherwise skip and return.       │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  SKIP TIP 3: Never skip because the question "looks     │
│  long" — word count doesn't equal difficulty. But DO    │
│  skip if options differ only in positions 3-4 of the    │
│  order (e.g., swapping the 3rd and 4th word) and you're │
│  rushing — one slip = negative marking. Accuracy first. │
└─────────────────────────────────────────────────────────┘
```

**⏱️ Time Rule:** Easy (all different first letters) → 15 sec. Medium (shared first letter) → 30 sec. Hard (shared first two letters) → 45 sec max, else mark & return.
