# Important Rules & Approaches — Statement & Argument

## Part 1: Key Rules / Approaches

| Rule Name | Description | Example |
|---|---|---|
| Strong vs Weak Argument | A strong argument is logical, relevant, and directly addresses the issue; a weak argument is emotional, vague, or irrelevant. | Statement: Should plastic bags be banned? — "Yes, because they pollute soil and water" (strong); "Yes, because I hate plastic" (weak). |
| Relevance Test | The argument must directly relate to the statement. If it talks about something else, it is weak. | Statement: Should exams be online? — "Paper costs are rising" is relevant; "Students like computers" is weak. |
| Ambiguity Test | If the argument is unclear or can be interpreted in many ways, it is weak. | "It may help somehow" — vague, hence weak. |
| Simplicity / Over-simplification Test | An argument that ignores the complexity of the issue ("just do it") is weak. | "Unemployment can end if everyone works hard" — over-simplified, weak. |
| Established Fact Test | Arguments based on proven facts, laws, or universal truths are strong. | "Smoking causes cancer, so tobacco ads should be banned" — strong. |
| Precedence / Experience Test | If a similar step has worked (or failed) elsewhere, citing that experience makes the argument strong. | "Country X reduced accidents after strict fines" — strong. |
| Desirability Test | An argument is strong if it shows the action is genuinely desirable or harmful for society at large. | "Free education benefits poor children" — strong. |
| "Only / All / None" Trap | Arguments using extreme words (only, all, never) are usually weak because they overgeneralise. | "Only privatisation can fix railways" — weak. |
| Personal Opinion Trap | Arguments based on personal likes/dislikes, not logic, are weak. | "I don't like travelling by bus" — weak. |
| Both-Strong Case | If both "Yes" and "No" arguments are logical and relevant, the answer is "either I or II is strong" / "both are strong" as per options. | Ban on strikes: "Yes, strikes harm the public" and "No, strikes are a democratic right" — both strong. |
| Neither-Strong Case | If both arguments are vague, emotional, or irrelevant, answer "neither is strong". | "Yes, because it feels right" / "No, because why not" — neither strong. |
| Read the Question Format | Check whether options say "only I strong", "only II strong", "either", "neither", or "both" before answering. | Marking "both" when the option says "either" is a common error. |

## Part 2: Time Management

| Rule | Description |
|---|---|
| 15-Second Rule | Read the statement and both arguments within 15 seconds. If the issue and both arguments are clear, proceed to judge. |
| 45-Second Rule | If after 45 seconds you cannot decide whether an argument is strong or weak, mark your best guess and move on — do not re-read repeatedly. |
| Skip Strategy | Skip questions where both arguments look equally strong/weak on first reading; return to them only if time remains. |
| No Overthinking | Do not bring outside knowledge or personal beliefs; judge only by the tests above. Personal bias wastes time and causes errors. |
| Average Target | Aim for 30–40 seconds per question; this chapter is scoring and should not consume extra time. |

## Part 3: Logical / Mathematical Formulas

No formulas for this chapter. Statement & Argument is purely judgement-based; apply the qualitative tests (relevance, ambiguity, established fact, precedence, desirability) instead of any formula.
