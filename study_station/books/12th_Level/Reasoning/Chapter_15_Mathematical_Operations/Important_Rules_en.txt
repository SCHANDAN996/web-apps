# Important Rules & Approaches — Mathematical Operations

## Part 1: Key Rules / Approaches

| Rule Name | Description | Example |
|---|---|---|
| BODMAS / PEMDAS | Solve in order: Brackets → Orders (powers/roots) → Division → Multiplication → Addition → Subtraction. | 12 + 6 ÷ 3 = 12 + 2 = 14 (not 18 ÷ 3) |
| Symbol Substitution | Replace given symbols with actual operations, then apply BODMAS. | If '×' means '+', then 4 × 3 = 4 + 3 = 7 |
| Symbol Interchange | Swap two signs/numbers in the equation, then check which option balances it. | Interchange + and −: test each option by rewriting the equation |
| Balancing the Equation | Insert the correct signs from options so LHS = RHS; verify with BODMAS. | 8 ? 4 ? 2 = 6 → 8 − 4 + 2 = 6 |
| Backward Calculation | When result is given, work from the answer side to find the missing number/sign. | 5 ? 3 = 8 → missing sign is '+' |
| Number Interchange | Two digits/numbers swap places; recompute the expression after swapping. | Interchange 2 and 5: 25 + 3 → 52 + 3 = 55 |
| Option Elimination | Test each option directly in the equation instead of solving from scratch. | Try (a), (b), (c), (d) one by one; stop when LHS = RHS |
| LHS–RHS Check | Always compute both sides separately; never assume equality. | If LHS = 20 and RHS = 18, the option is wrong |
| Sign Priority Trap | Division and multiplication are done before addition and subtraction, even if they appear later. | 10 − 2 × 3 = 10 − 6 = 4 (not 8 × 3 = 24) |
| Bracket First | Anything inside ( ), { }, [ ] is solved before everything outside. | (6 + 2) × 3 = 24, not 6 + 6 = 12 |

## Part 2: Time Management

| Rule | Guideline |
|---|---|
| 15-Second Rule | If the symbol code or pattern is not clear within 15 seconds, mark the question and move on. |
| 45-Second Rule | No single question should take more than 45 seconds; if it does, skip and return at the end. |
| Easy-First Scan | Attempt direct symbol-substitution questions first; they are the fastest. |
| Option-Testing Limit | While balancing equations, test a maximum of 2 options; if both fail, skip and revisit. |
| Rewrite Habit | Always rewrite the coded equation in normal symbols before calculating — saves re-reading time. |
| No Mental BODMAS | Do multi-step BODMAS on paper; mental slips cost more time than writing. |
| Last-Minute Rule | In the final minutes, only revisit marked questions that need one option check, not full re-solves. |

## Part 3: Logical / Mathematical Formulas

| Formula / Rule | Statement | Example |
|---|---|---|
| BODMAS Order | B → O → D → M → A → S | 2 + 3 × 4 = 14 |
| Division = Multiplication by Reciprocal | a ÷ b = a × (1/b) | 12 ÷ 4 = 12 × ¼ = 3 |
| Equality Condition | An equation is correct only if LHS = RHS after substitution. | 6 + 2 = 4 × 2 ✓ |
| Substitution Identity | If 'A means B', replace every A with B before solving. | '+' means '−': 9 + 4 = 9 − 4 = 5 |
| No other fixed formulas | This chapter is rule-based, not formula-based; BODMAS and substitution cover all question types. | — |
