Q101. (Hard) A loan of Rs 16,400 is to be paid back in two equal annual installments at 5% per annum compound interest. Find the value of each installment.
(A) Rs 8,820  (B) Rs 8,800  (C) Rs 8,900  (D) Rs 8,750

Answer: (A)

Solution:
Let each installment be x. Discounting both installments: P = x / (1 + 5/100) + x / (1 + 5/100)^2 = 20x / 21 + 400x / 441 = 820x / 441. Given P = 16400: 16400 = 820x / 441 => x = (16400 * 441) / 820 = 20 * 441 = Rs 8,820. Therefore, the correct value is Rs 8,820, corresponding to option (A).

Source: SSC CGL Pattern

Q102. (Hard) A man borrows Rs 25,500 to be repaid in two equal half-yearly installments at 8% per annum compound interest, compounded semi-annually. Find the value of each installment.
(A) Rs 13,500  (B) Rs 13,520  (C) Rs 13,600  (D) Rs 13,450

Answer: (B)

Solution:
Semi-annual rate = 8 / 2 = 4% = 1/25. P = x / (26/25) + x / (26/25)^2 = 25x / 26 + 625x / 676 = 1275x / 676. 25500 = 1275x / 676 => x = (25500 * 676) / 1275 = 20 * 676 = Rs 13,520. Therefore, the correct value is Rs 13,520, corresponding to option (B).

Q104. (Hard) A father divides Rs 26,020 between his two sons aged 15 years and 17 years such that each receives an equal amount when they reach 18 years of age at 4% per annum compound interest. Find the share of the younger son.
(A) Rs 13,520  (B) Rs 12,000  (C) Rs 13,000  (D) Rs 12,500

Answer: (D)

Solution:
Younger son's term = 18 - 15 = 3 years. Elder son's term = 18 - 17 = 1 year. Equal maturity amounts: P1 * (1 + 4/100)^3 = P2 * (1 + 4/100)^1 => P1 / P2 = 1 / (1 + 4/100)^2 = (25 / 26)^2 = 625 / 676. Total units = 625 + 676 = 1301 units = Rs 26,020 => 1 unit = Rs 20. Younger son's share = 625 * 20 = Rs 12,500. Therefore, the correct value is Rs 12,500, corresponding to option (D).

Source: SSC CGL Pattern
