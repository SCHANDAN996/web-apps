# अध्याय 10: चक्रवृद्धि ब्याज (स्नातक स्तर हेतु संपूर्ण आधारशिला)

## 1. चक्रवृद्धि ब्याज की मूल अवधारणा
चक्रवृद्धि ब्याज (Compound Interest - CI) वह ब्याज है जो प्रारंभिक मूलधन के साथ-साथ पूर्ववर्ती अवधियों के संचित ब्याज पर भी देय होता है। यह एक ज्यामितीय (गुणोत्तर) वृद्धि को दर्शाता है, जबकि साधारण ब्याज एक समांतर वृद्धि होती है।
- **मूलधन (P):** उधार ली गई अथवा निवेश की गई मूल राशि।
- **वार्षिक ब्याज दर (R):** प्रति वर्ष ब्याज की प्रतिशत दर।
- **समय या संयोजन चक्र (n अथवा T):** ब्याज संयोजन की कुल अवधियाँ।
- **मिश्रधन (A):**
  A = P * [ 1 + (R / 100) ]^n
- **चक्रवृद्धि ब्याज (CI):**
  CI = मिश्रधन - मूलधन = P * [ (1 + R/100)^n - 1 ]

## 2. ब्याज संयोजन आवृत्ति में रूपांतरण
जब ब्याज का संयोजन वार्षिक न होकर अन्य समयावधियों में किया जाता है:
- **अर्धवार्षिक (छमाही) संयोजन:**
  - प्रभावी दर = R / 2 % प्रति छमाही।
  - समय चक्र = 2 * T।
  - मिश्रधन A = P * [ 1 + R / (200) ]^(2T)
- **त्रैमासिक (तिमाही) संयोजन:**
  - प्रभावी दर = R / 4 % प्रति तिमाही।
  - समय चक्र = 4 * T।
  - मिश्रधन A = P * [ 1 + R / (400) ]^(4T)
- **प्रत्येक 'm' माह में संयोजन:**
  - प्रति चक्र दर = R * (m / 12) %।
  - चक्रों की संख्या = (T * 12) / m।

## 3. भिन्न रूपी समय अवधि एवं उत्तरोत्तर भिन्न दरें
- **समय भिन्न में होने पर (जैसे 2 वर्ष 4 माह = 2 1/3 वर्ष):**
  A = P * [ 1 + R / 100 ]^2 * [ 1 + (R * 1/3) / 100 ]
- **उत्तरोत्तर वर्षों में भिन्न-भिन्न दरें (R1, R2, R3):**
  A = P * [ 1 + R1 / 100 ] * [ 1 + R2 / 100 ] * [ 1 + R3 / 100 ]

## 4. चक्रवृद्धि ब्याज और साधारण ब्याज का अंतर (CI - SI)
- **2 वर्षों के लिए अंतर:**
  Diff_2 = P * (R / 100)^2 = (P * R^2) / 10000
- **3 वर्षों के लिए अंतर:**
  Diff_3 = P * (R / 100)^2 * [ 3 + R / 100 ] = [ P * R^2 * (300 + R) ] / 10^6
- **3 वर्ष एवं 2 वर्ष के अंतरों का अनुपात:**
  Diff_3 / Diff_2 = (300 + R) / 100 = 3 + R / 100

## 5. ट्री विधि एवं अनुपात विधि (पास्कल त्रिभुज)
- माना A_1 = 1 वर्ष का मूलधन पर ब्याज = (P * R) / 100
- माना B = ब्याज पर ब्याज = (A_1 * R) / 100
- माना C = B पर ब्याज = (B * R) / 100
- **2 वर्ष के लिए (अनुपात 2 : 1):**
  - कुल CI = 2 * A_1 + 1 * B
  - CI - SI = 1 * B
- **3 वर्ष के लिए (अनुपात 3 : 3 : 1):**
  - कुल CI = 3 * A_1 + 3 * B + 1 * C
  - CI - SI = 3 * B + 1 * C

## 6. गुने का घातांक नियम (Multiplicity Law)
यदि कोई धनराशि चक्रवृद्धि ब्याज पर T वर्षों में 'k' गुनी हो जाती है:
- 2T वर्षों में वह k^2 गुनी होगी।
- 3T वर्षों में वह k^3 गुनी होगी।
- m*T वर्षों में वह k^m गुनी हो जाएगी।

## 7. चक्रवृद्धि ब्याज की समान वार्षिक किश्तें (Installments)
यदि P रुपये का ऋण R% वार्षिक चक्रवृद्धि ब्याज पर 'n' समान वार्षिक किश्तों 'x' में चुकाया जाए:
- P = [ x / (1 + R/100) ] + [ x / (1 + R/100)^2 ] + ... + [ x / (1 + R/100)^n ]

## 8. जनसंख्या वृद्धि एवं अवमूल्यन (Depreciation)
- **जनसंख्या वृद्धि:** P_n = P_0 * [ 1 + R / 100 ]^n
- **मशीनरी का अवमूल्यन:** V_n = V_0 * [ 1 - R / 100 ]^n
