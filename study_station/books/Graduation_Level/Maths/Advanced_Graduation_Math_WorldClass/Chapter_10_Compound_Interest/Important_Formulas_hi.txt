# महत्वपूर्ण सूत्र: चक्रवृद्धि ब्याज (स्नातक स्तर)

## 1. मुख्य चक्रवृद्धि ब्याज सूत्र
- मिश्रधन: A = P * [ 1 + R / 100 ]^n
- चक्रवृद्धि ब्याज: CI = A - P = P * [ (1 + R / 100)^n - 1 ]
- मिश्रधन से मूलधन: P = A / [ 1 + R / 100 ]^n

## 2. गैर-वार्षिक संयोजन रूपांतरण
- **अर्धवार्षिक (छमाही):** A = P * [ 1 + R / 200 ]^(2T)
- **त्रैमासिक (तिमाही):** A = P * [ 1 + R / 400 ]^(4T)
- **m-मासिक चक्र:** दर = R * (m / 12) %, चक्र = (12 * T) / m

## 3. भिन्न समय अवधि हेतु
- समय T = a वर्ष और (b / c) वर्ष होने पर:
  A = P * [ 1 + R / 100 ]^a * [ 1 + (R * b/c) / 100 ]

## 4. CI और SI के अंतर के सूत्र
- 2 वर्षों के लिए:
  Diff_2 = P * (R / 100)^2 = (P * R^2) / 10000
- 3 वर्षों के लिए:
  Diff_3 = [ P * R^2 * (300 + R) ] / 1000000
- अंतरों का अनुपात:
  Diff_3 / Diff_2 = (300 + R) / 100

## 5. अनुपात / ट्री विधि
- A_1 = मूलधन पर 1 वर्ष का साधारण ब्याज
- B = A_1 पर 1 वर्ष का ब्याज
- C = B पर 1 वर्ष का ब्याज
- 2 वर्ष का CI = 2 * A_1 + 1 * B
- 3 वर्ष का CI = 3 * A_1 + 3 * B + 1 * C
- 4 वर्ष का CI = 4 * A_1 + 6 * B + 4 * C + 1 * D

## 6. गुने के घातांक नियम
- यदि राशि T वर्ष में k गुनी हो:
  - 2T वर्ष में: k^2 गुनी
  - 3T वर्ष में: k^3 गुनी
  - m*T वर्ष में: k^m गुनी

## 7. ऋण की समान वार्षिक किश्त (Installment)
- R% वार्षिक CI पर n समान किश्तों x में चुकाया गया ऋण P:
  P = [ x / (1 + R/100) ] + [ x / (1 + R/100)^2 ] + ... + [ x / (1 + R/100)^n ]
- 2 किश्तों हेतु:
  P = x * [ 100 / (100 + R) ] * [ (200 + R) / (100 + R) ]

## 8. वृद्धि एवं अवमूल्यन
- वृद्धि: P_n = P_0 * [ 1 + R / 100 ]^n
- अवमूल्यन: V_n = V_0 * [ 1 - R / 100 ]^n
