# 📋 चक्रवृद्धि ब्याज — महत्वपूर्ण सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| मिश्रधन (वार्षिक चक्रवृद्धि) | A = P(1 + R/100)ᵀ | ब्याज वर्ष में एक बार जुड़े तब |
| चक्रवृद्धि ब्याज | CI = P[(1 + R/100)ᵀ − 1] | CI = A − P से भी |
| अर्धवार्षिक चक्रवृद्धि | A = P(1 + R/200)²ᵀ | दर आधी, समय दोगुना |
| त्रैमासिक चक्रवृद्धि | A = P(1 + R/400)⁴ᵀ | दर एक-चौथाई, समय चार गुना |
| मासिक चक्रवृद्धि | A = P(1 + R/1200)¹²ᵀ | दर ÷12, समय ×12 |
| भिन्नात्मक समय (जैसे 2⅖ वर्ष) | A = P(1 + R/100)² × (1 + (2/5)R/100) | पूर्ण वर्षों पर CI, शेष भाग पर साधारण गुणन |
| अलग-अलग वर्षों की दरें | A = P(1 + R₁/100)(1 + R₂/100)(1 + R₃/100) | हर वर्ष की दर भिन्न हो तब |
| CI − SI अंतर (2 वर्ष) | CI − SI = P(R/100)² | केवल 2 वर्ष के लिए मान्य |
| CI − SI अंतर (3 वर्ष) | CI − SI = P(R/100)²(3 + R/100) | केवल 3 वर्ष के लिए मान्य |
| 2 वर्ष के CI से SI | SI = (2 × CI × 100) / (200 + R) | CI और R ज्ञात हों तब |
| दर ज्ञात करना (2 वर्ष, CI−SI दिया) | R = 2(CI − SI)/SI × 100 | 2 वर्ष का SI दिया हो तब |
| 2 वर्ष का CI (सीधा) | CI = P × [R(200 + R)] / 10000 | बिना घात लगाए |
| 2 वर्ष का प्रभावी ब्याज % | R + R + R²/100 = 2R + R²/100 | x + y + xy/100 नियम |
| 3 वर्ष का प्रभावी ब्याज % | 3R + 3R²/100 + R³/10000 | तीन वर्ष की कुल वृद्धि % |
| n गुना होने का समय | T = log(n) / log(1 + R/100) | धन दोगुना/तिगुना कब होगा |
| दोगुना होने का नियम (अनुमानित) | T ≈ 72 / R | 72 का नियम — त्वरित अनुमान |
| वार्षिक किस्त (ऋण चुकौती) | P = x/(1+R/100) + x/(1+R/100)² + … | समान किस्तों में ऋण वापसी |
| जनसंख्या वृद्धि | जनसंख्या = P(1 + R/100)ᵀ | वृद्धि दर धनात्मक हो तब |
| जनसंख्या/मूल्य ह्रास | मान = P(1 − R/100)ᵀ | मशीन का मूल्यह्रास, जनसंख्या कमी |
| T वर्ष पहले की जनसंख्या | P₀ = P / (1 + R/100)ᵀ | वर्तमान से पीछे जाना हो तब |
| साधारण ब्याज (तुलना हेतु) | SI = PRT/100 | CI बनाम SI प्रश्नों में |
| CI और SI का संबंध (1 वर्ष) | 1 वर्ष का CI = 1 वर्ष का SI | पहले वर्ष दोनों बराबर |
| वृद्धि गुणक विधि | A = P × (गुणक)ᵀ, गुणक = 1 + R/100 | जैसे R=10% ⇒ गुणक 1.1 |
| भिन्न विधि (R = 1/n के रूप में) | R = 25% ⇒ A = P(5/4)ᵀ | 20%→6/5, 25%→5/4, 50%→3/2 |
| किस्त-योजना (उधार लिया गया धन) | P(1+R/100)ᵀ = x[(1+R/100)ᵀ⁻¹ + … + 1] | EMI-प्रकार प्रश्नों में |
