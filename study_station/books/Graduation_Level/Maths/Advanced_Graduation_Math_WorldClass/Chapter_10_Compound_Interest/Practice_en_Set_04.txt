Q76. (Hard) A loan of Rs 25,500 is to be repaid in two equal annual installments at 4% per annum compound interest, compounded annually. Find the value of each installment.
(A) Rs 13,520  (B) Rs 13,000  (C) Rs 14,000  (D) Rs 13,250

Answer: (A)

Solution:
Let each annual installment be x. The present value equation is: P = [x / (1 + 4/100)] + [x / (1 + 4/100)^2] = [25x / 26] + [625x / 676] = (650x + 625x) / 676 = 1275x / 676. Given P = 25500: 25500 = 1275x / 676 => x = (25500 * 676) / 1275 = 20 * 676 = Rs 13,520. Psychological Trap: A common error is treating the loan under simple interest and dividing the principal by 2, yielding 12,750. Therefore, the correct value is Rs 13,520, corresponding to option (A).
