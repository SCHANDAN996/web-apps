# क्रमचय और संचय — महत्वपूर्ण सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| गुणन नियम (Fundamental Principle) | m × n | क्रमिक कार्य; "और" वाले प्रश्न |
| योग नियम | m + n | पारस्परिक अपवर्जी कार्य; "या" वाले प्रश्न |
| क्रमचय (Permutation) | ⁿPᵣ = n! / (n−r)! | क्रम मायने रखता है |
| संचय (Combination) | ⁿCᵣ = n! / [r!(n−r)!] | क्रम मायने नहीं रखता |
| संबंध | ⁿPᵣ = ⁿCᵣ × r! | क्रमचय = संचय × व्यवस्था |
| संचय की पूरकता | ⁿCᵣ = ⁿCₙ₋ᵣ | r बड़ा हो तो n−r लें |
| पास्कल नियम | ⁿCᵣ + ⁿCᵣ₋₁ = ⁿ⁺¹Cᵣ | संचयों का योग |
| कुल संचय (सभी चयन) | ⁿC₀ + ⁿC₁ + … + ⁿCₙ = 2ⁿ | कम-से-कम शून्य चयन |
| कम-से-कम एक चयन | 2ⁿ − 1 | "कम से कम एक" वाले प्रश्न |
| n भिन्न वस्तुओं की व्यवस्था | n! | सीधी पंक्ति में |
| पुनरावृत्ति सहित क्रमचय | nʳ | प्रत्येक स्थान पर n विकल्प |
| समान वस्तुओं सहित व्यवस्था | n! / (p! q! r! …) | p, q, r समान वस्तुएँ (जैसे शब्दों के अक्षर) |
| वृत्ताकार व्यवस्था (भिन्न) | (n−1)! | गोल मेज़, घड़ी-दिशा भिन्न |
| वृत्ताकार (घड़ी/विपरीत समान) | (n−1)! / 2 | माला, हार — पलटने पर समान |
| एकसाथ रहने की शर्त | (n−k+1)! × k! | k वस्तुएँ एक गुच्छा बनाकर |
| कभी एकसाथ न रहें | कुल − एकसाथ = n! − (n−k+1)!·k! | पूरक विधि |
| खाली स्थान विधि (Gap Method) | ⁿ⁺¹Pᵣ या ⁿ⁺¹Cᵣ × r! | कोई दो साथ न आएँ — पहले बाकी बैठाएँ |
| n में से r, जब p विशेष हमेशा शामिल | ⁿ⁻ᵖCᵣ₋ₚ | निश्चित सदस्य पहले से चुने |
| n में से r, जब p विशेष कभी न शामिल | ⁿ⁻ᵖCᵣ | अवांछित सदस्य बाहर |
| कम-से-कम एक शर्त वाला चयन | ⁿCᵣ − ⁿ⁻ᵖCᵣ | "कम से कम एक विशेष" |
| विभाजन — समान समूहों में | (mn)! / [(m!)ⁿ · n!] | mn वस्तुएँ, n समान समूह (प्रत्येक m) |
| विभाजन — असमान समूहों में | n! / (p! q! r!) | p+q+r = n, भिन्न आकार के समूह |
| वितरण — भिन्न वस्तुएँ, भिन्न व्यक्ति | rⁿ | n भिन्न वस्तुएँ r व्यक्तियों को |
| धनात्मक पूर्णांक हल | ⁿ⁻¹Cᵣ₋₁ | x₁+x₂+…+xᵣ = n, प्रत्येक ≥ 1 |
| अऋणात्मक पूर्णांक हल | ⁿ⁺ʳ⁻¹Cᵣ₋₁ | x₁+x₂+…+xᵣ = n, प्रत्येक ≥ 0 |
| समान वस्तुओं का वितरण | ⁿ⁺ʳ⁻¹Cᵣ₋₁ | n समान वस्तुएँ r व्यक्तियों में |
| बहुभुज के विकर्ण | n(n−3)/2 | n भुजाओं वाले बहुभुज |
| बिंदुओं से रेखाएँ | ⁿC₂ − ᵐC₂ + 1 | m बिंदु संरेख हों तो |
| बिंदुओं से त्रिभुज | ⁿC₃ − ᵐC₃ | m संरेख बिंदुओं को छोड़कर |
| शतरंज बोर्ड — वर्ग | 1²+2²+…+8² = 204 | 8×8 बोर्ड में कुल वर्ग |
| शतरंज बोर्ड — आयत | (1+2+…+8)² = 1296 | 8×8 बोर्ड में कुल आयत |
| m×n ग्रिड में आयत | ᵐ⁺¹C₂ × ⁿ⁺¹C₂ | क्षैतिज × ऊर्ध्वाधर रेखा-युग्म |
| अंकों से संख्याएँ (पुनरावृत्ति रहित) | ⁿPᵣ (शून्य की जाँच सहित) | शून्य पहले स्थान पर नहीं |
| ⁿCᵣ अधिकतम कब | r = n/2 (n सम) या (n±1)/2 (n विषम) | मध्य पद सबसे बड़ा |
| ⁿCᵣ = ⁿCₛ ⟹ | r = s या r + s = n | समान संचयों की पहचान |
| डिरेंजमेंट (Derangement) | Dₙ = n![1 − 1/1! + 1/2! − … + (−1)ⁿ/n!] | कोई वस्तु अपने स्थान पर न हो |
| Dₙ का पुनरावृत्ति रूप | Dₙ = (n−1)(Dₙ₋₁ + Dₙ₋₂) | D₁ = 0, D₂ = 1 |
