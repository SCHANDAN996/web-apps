# 🪄 क्रमचय और संचय — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 1: "क्रम में क्रम, संचय में चयन"** │
│                                             │
│ क्रमचय (Permutation) में **क्रम** (order)   │
│ मायने रखता है — जैसे "क्रमचय" शब्द में      │
│ "क्रम" छिपा है।                             │
│ संचय (Combination) में सिर्फ़ **चयन** —     │
│ "संचय" में "चय" छिपा है।                    │
│ 👉 सवाल में "व्यवस्था/क्रम/पद" दिखे → P     │
│ 👉 "चुनाव/समिति/समूह" दिखे → C              │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 2: "C = P ÷ r!" (भाई-भाई फॉर्मूला)**│
│                                             │
│ संचय, क्रमचय का छोटा भाई है — उसमें क्रम    │
│ की गिनती हटा दो:                            │
│ ⁿCᵣ = ⁿPᵣ ÷ r!                              │
│ याद रखें: **"चयन में क्रम का भाग"**         │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 3: "ऊपर से नीचे, r कदम"**           │
│                                             │
│ ⁿPᵣ सीधे मुंहज़बानी: n से शुरू करो और       │
│ r संख्याएँ घटाते हुए गुणा करो।              │
│ ⁷P₃ = 7×6×5 = 210 (बस 3 कदम!)               │
│ 👉 **"जितना r, उतने गुणनखंड"**              │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 4: "C का शॉर्टकट — ऊपर r कदम,**     │
│ **नीचे r!"**                                │
│                                             │
│ ⁸C₃ = (8×7×6)/(3×2×1) = 56                  │
│ ऊपर 8 से 3 कदम, नीचे 3! — काटते जाओ,        │
│ factorial कभी पूरा मत खोलो!                 │
│ 👉 **"पहले काटो, फिर गुणा करो"**            │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 5: "दर्पण नियम" — ⁿCᵣ = ⁿCₙ₋ᵣ**     │
│                                             │
│ 10 में से 8 चुनना = 10 में से 2 छोड़ना।     │
│ बड़ा r दिखे तो उसे n−r में बदल दो!          │
│ ¹⁰⁰C₉₈ = ¹⁰⁰C₂ = 4950 ✔                    │
│ 👉 **"बड़े को उल्टाओ, काम आसान बनाओ"**      │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 6: "AND = ×, OR = +" (गणित की**     │
│ **अंग्रेजी)**                               │
│                                             │
│ "और/AND" (दोनों काम साथ) → **गुणा**         │
│ "या/OR" (कोई एक काम) → **जोड़**             │
│ उदा.: 3 शर्ट **और** 2 पैंट → 3×2 = 6        │
│ 3 बस **या** 2 ट्रेन → 3+2 = 5               │
│ 👉 **"और गुणा करवाता है, या जोड़"**         │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 7: "गोल घेरा, एक कम" — वृत्तीय**    │
│ **क्रमचय = (n−1)!**                         │
│                                             │
│ गोल मेज़ पर घूमने से व्यवस्था एक जैसी —     │
│ इसलिए एक व्यक्ति को **बिठाकर ताला लगा दो**, │
│ बाकी (n−1) को सजाओ।                         │
│ 👉 **"गोल में एक को कुर्सी से बाँधो"**      │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 8: "माला में आधा" — हार/माला**      │
│ **= (n−1)!/2**                              │
│                                             │
│ माला/हार को **पलट** सकते हैं — clockwise    │
│ और anti-clockwise एक ही दिखते हैं,          │
│ इसलिए 2 से भाग।                             │
│ 👉 **"माला पलटी, आधा हुआ"**                 │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 9: "साथ रहने वालों को रस्सी से**    │
│ **बाँधो"**                                  │
│                                             │
│ "A और B हमेशा साथ बैठें" → दोनों को एक      │
│ **बंडल** मानो → (n−1)! × 2!                 │
│ (बंडल के अंदर भी 2! व्यवस्था मत भूलो!)      │
│ 👉 **"बाँधो, सजाओ, अंदर भी सजाओ"**          │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 10: "दूर रहने वालों को खाली**       │
│ **जगह में घुसाओ" (Gap Method)**             │
│                                             │
│ "A और B साथ न बैठें" → पहले बाकी लोगों को   │
│ बिठाओ, फिर बने **खाली स्थानों (gaps)** में  │
│ A, B को घुसाओ।                              │
│ 5 लोग बैठे → 6 gaps → ⁶P₂ में A, B।         │
│ 👉 **"पहले भिड़ाओ मत, बाद में घुसाओ"**      │
│ 👉 कुल − साथ वाले = अलग वाले (पूरक नियम)    │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 11: "रिपीट है तो भाग दो"**          │
│                                             │
│ दोहराए अक्षरों वाले शब्द:                   │
│ कुल = n! ÷ (p! q! r! …)                     │
│ ALLAHABAD → 9! ÷ (4! × 2!)                  │
│ (A चार बार, L दो बार)                       │
│ 👉 **"जो दोहराया, उसका factorial नीचे"**    │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 12: "स्वर-व्यंजन जोड़ी" (Vowel**    │
│ **Trick)**                                  │
│                                             │
│ "सभी स्वर साथ रहें" → स्वरों को एक बंडल,   │
│ फिर बंडल × बाकी, और बंडल के अंदर की         │
│ व्यवस्था अलग से गुणा।                       │
│ 👉 **"स्वर बंडल, तीन मंज़िल: बाहर, अंदर,**  │
│ **गुणा"**                                   │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 13: "तारे और छड़ें" (Stars &**      │
│ **Bars)**                                   │
│                                             │
│ n एक जैसी वस्तुएँ r लोगों में बाँटनी हों    │
│ (हर किसी को ≥1) → ⁿ⁻¹Cᵣ₋₁                   │
│ शून्य भी चले तो → ⁿ⁺ʳ⁻¹Cᵣ₋₁                 │
│ 👉 **"कम से कम एक = n−1; शून्य चले = n+r−1"**│
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 14: "0! = 1 का जादू"**              │
│                                             │
│ 0! = 1 (खाली चीज़ को सजाने का एक ही तरीका — │
│ न सजाना!)। ⁿC₀ = ⁿCₙ = 1, ⁿC₁ = n           │
│ 👉 **"कुछ न चुनना भी एक चुनाव है"**         │
└─────────────────────────────────────────────┘

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 15: "कम से कम एक = कुल − कोई**      │
│ **नहीं" (पूरक जादू)**                       │
│                                             │
│ "कम से कम एक" दिखते ही उल्टा सोचो:          │
│ कुल मामले − (एक भी नहीं) वाले मामले।        │
│ 2ⁿ − 1 = कम से कम एक चुनने के तरीके।        │
│ 👉 **"कम से कम का मतलब — घटाओ नियम"**       │
└─────────────────────────────────────────────┘
