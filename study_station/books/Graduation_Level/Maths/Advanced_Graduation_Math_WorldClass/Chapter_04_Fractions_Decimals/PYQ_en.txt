# Pattern Analysis: Fractions & Decimals (Graduation Level)

Recurring patterns in SSC CGL Tier-2, IBPS PO, and State PCS:
1. Converting mixed recurring decimals into lowest fractional terms and performing arithmetic.
2. Determining which fraction is largest / smallest using gap balancing or mediant methods.
3. Identifying terminating decimal conditions and counting number of digits after the decimal point.
4. Algebraic equations disguised with recurring decimals.

---

Q1. (Medium) Convert 0.4bar(7) into a simple fraction in lowest terms.
(A) 43/90  (B) 47/99  (C) 43/99  (D) 47/90
Answer: (A)
Solution: Formula: (47 - 4) / 90 = 43 / 90. Since gcd(43, 90) = 1, it is in lowest terms. Therefore, the correct value is 43/90, corresponding to option (A).
Psychological Trap: Treating it as pure recurring and writing 47/99.
Source: SSC CGL Pattern

Q2. (Medium) Find the value of 0.bar(3) + 0.bar(6) + 0.bar(7) + 0.bar(8).
(A) 2 2/3  (B) 2 5/9  (C) 2 7/9  (D) 2 1/3
Answer: (A)
Solution: 0.bar(3) + 0.bar(6) + 0.bar(7) + 0.bar(8) = (3 + 6 + 7 + 8) / 9 = 24 / 9 = 8 / 3 = 2 2/3. Therefore, the correct value is 2 2/3, corresponding to option (A).
Source: SSC CGL Pattern

Q3. (Medium) Which of the following fractions is the largest: 15/17, 19/21, 23/25, 27/29?
(A) 27/29  (B) 23/25  (C) 19/21  (D) 15/17
Answer: (A)
Solution: For each fraction, the difference between denominator and numerator is constant: 17 - 15 = 2, 21 - 19 = 2, 25 - 23 = 2, 29 - 27 = 2. When the difference is constant for proper fractions, the fraction with the greatest numerator is the largest: 27/29. Therefore, the correct value is 27/29, corresponding to option (A).
Source: State PCS Pattern

Q4. (Hard) Find the value of the cube root of 0.037bar(037).
(A) 1/3  (B) 1/9  (C) 1/27  (D) 3/10
Answer: (A)
Solution: The repeating block is '037' with period 3. 0.bar(037) = 37 / 999. Dividing 999 by 37 gives exactly 27. So 0.bar(037) = 1 / 27. Cube root is cbrt(1/27) = 1/3. Therefore, the correct value is 1/3, corresponding to option (A).
Source: SSC CGL Pattern

Q5. (Hard) How many decimal places will the decimal representation of 31 / (2^4 * 5^7) contain before terminating?
(A) 7  (B) 4  (C) 11  (D) 28
Answer: (A)
Solution: A fraction of the form p / (2^m * 5^n) terminates after exactly max(m, n) decimal places. Here m = 4 and n = 7, so max(4, 7) = 7 digits. Therefore, the correct value is 7, corresponding to option (A).
Source: IBPS PO Pattern

Q6. (Medium) Evaluate: (0.bar(142857)) / (0.bar(285714)).
(A) 1/2  (B) 2  (C) 1/3  (D) 1/4
Answer: (A)
Solution: Notice 0.bar(142857) = 1/7, and 0.bar(285714) = 2/7. Ratio = (1/7) / (2/7) = 1/2. Therefore, the correct value is 1/2, corresponding to option (A).
Source: SSC CGL Pattern

Q7. (Medium) Arrange in ascending order: 3/5, 7/9, 11/13.
(A) 3/5 < 7/9 < 11/13  (B) 11/13 < 7/9 < 3/5  (C) 7/9 < 3/5 < 11/13  (D) 3/5 < 11/13 < 7/9
Answer: (A)
Solution: Differences: 5 - 3 = 2, 9 - 7 = 2, 13 - 11 = 2. Since the difference is constant and all are proper fractions, ascending order of numerators gives 3/5 < 7/9 < 11/13. Therefore, the correct value is 3/5 < 7/9 < 11/13, corresponding to option (A).
Source: State PCS Pattern

Q8. (Hard) If 0.xbar(y) + 0.ybar(x) = 5/9, where x and y are digits from 1 to 9, find the value of (x + y).
(A) 5  (B) 6  (C) 4  (D) 9
Answer: (A)
Solution: 0.xbar(y) = (10x + y - x) / 90 = (9x + y) / 90. 0.ybar(x) = (9y + x) / 90. Sum = (10x + 10y) / 90 = (x + y) / 9. Given (x + y) / 9 = 5/9, hence x + y = 5. Therefore, the correct value is 5, corresponding to option (A).
Source: SSC CGL Pattern

Q9. (Medium) What fraction of 2 hours 20 minutes is 35 minutes?
(A) 1/4  (B) 1/3  (C) 1/5  (D) 1/6
Answer: (A)
Solution: 2 hours 20 minutes = 2 * 60 + 20 = 140 minutes. Fraction = 35 / 140 = 1/4. Therefore, the correct value is 1/4, corresponding to option (A).
Source: IBPS PO Pattern

Q10. (Hard) Find the difference: 5.bar(76) - 2.bar(34).
(A) 3.bar(42)  (B) 3.42  (C) 3.bar(41)  (D) 3.bar(44)
Answer: (A)
Solution: 5.bar(76) - 2.bar(34) = (5 + 76/99) - (2 + 34/99) = 3 + (76 - 34)/99 = 3 + 42/99 = 3.bar(42). Therefore, the correct value is 3.bar(42), corresponding to option (A).
Source: SSC CGL Pattern
