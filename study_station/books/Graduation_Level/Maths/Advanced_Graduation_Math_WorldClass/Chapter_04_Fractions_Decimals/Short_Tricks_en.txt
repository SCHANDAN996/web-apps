# 🪄 Short Tricks — Fractions & Decimals

---

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 1 — "KFC" for Dividing Fractions**                  │
│                                                             │
│ **Keep** the first fraction, **Flip** the second,           │
│ **Change** ÷ to ×.                                          │
│                                                             │
│ (3/4) ÷ (2/5) → Keep 3/4, Change to ×, Flip 2/5 → 5/2      │
│ = (3/4) × (5/2) = 15/8                                      │
│                                                             │
│ 🍗 "Kentucky Fried Chicken" — you never divide, you FLIP!  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 2 — "Bigger Bottom = Smaller Slice"**               │
│                                                             │
│ Comparing fractions with the SAME numerator?                │
│ The BIGGER denominator gives the SMALLER fraction.          │
│                                                             │
│ 5/9 vs 5/7 → 9 is bigger → 5/9 is SMALLER.                  │
│                                                             │
│ 🍕 Same pizza, more people = thinner slice for you!         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 3 — "Cross-Multiply Climb" for Comparison**         │
│                                                             │
│ To compare a/b vs c/d: cross-multiply.                      │
│ a×d vs c×b — the bigger product sits under the bigger       │
│ fraction.                                                   │
│                                                             │
│ 3/7 vs 4/9 → 3×9=27 vs 4×7=28 → 28 wins → 4/9 is bigger.   │
│                                                             │
│ 🧗 Climb diagonally upward — numerator × opposite bottom!   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 4 — "Ninths = Repeat the Digit"**                   │
│                                                             │
│ n/9 = 0.nnn… (single digit repeats forever)                 │
│                                                             │
│ 4/9 = 0.444…   7/9 = 0.777…                                 │
│                                                             │
│ And for 99: n/99 = 0.nnnn… (two digits repeat)              │
│ 23/99 = 0.232323…                                           │
│                                                             │
│ 🔁 "Nine makes the digit dance on repeat!"                  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 5 — "BAR Code" for Recurring Decimals → Fraction**  │
│                                                             │
│ 0.ababab… = ab/99        0.abcabc… = abc/999                │
│                                                             │
│ Rule: repeating block on top, that many 9s below.           │
│ 0.363636… = 36/99 = 4/11                                    │
│                                                             │
│ 📊 Count the digits under the BAR — that's your 9s count!   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 6 — "Mixed Repeat: Subtract the Sneaky Part"**      │
│                                                             │
│ 0.1666… → write as (16 − 1)/90 = 15/90 = 1/6                │
│                                                             │
<|sep|>│ Rule: (whole number formed − non-repeating part) /          │
│ (as many 9s as repeating digits, then as many 0s as         │
│ non-repeating digits).                                      │
│                                                             │
│ 🕵️ The non-repeater is a "sneaky" digit — subtract it out!  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 7 — "Denominator Detective: Only 2s and 5s"**       │
│                                                             │
│ A fraction terminates as a decimal ONLY IF the denominator  │
│ (in lowest terms) has no prime factors except 2 and 5.      │
│                                                             │
│ 3/40 → 40 = 2³×5 ✓ terminates (0.075)                       │
│ 5/12 → 12 = 2²×3 ✗ repeats (0.41666…)                       │
│                                                             │
│ 🕵️ "2 and 5 are the only VIP guests allowed at the          │
│ Termination Party!"                                         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 8 — "Half of Half" for ×0.25, ×0.5, ×0.75**         │
│                                                             │
│ ×0.5 = divide by 2                                          │
│ ×0.25 = divide by 4 (half of half)                          │
│ ×0.75 = divide by 4, then ×3                                │
│                                                             │
│ 84 × 0.75 → 84/4 = 21 → 21×3 = 63                           │
│                                                             │
│ 🪓 Chop, chop, chop — decimals are just fractions in a      │
│ trench coat!                                                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 9 — "Slide the Dot" for ×10, ÷10**                  │
│                                                             │
│ Multiply by 10 → decimal point slides RIGHT one place.      │
│ Divide by 10 → slides LEFT one place.                       │
│                                                             │
│ 4.567 × 100 = 456.7 (two hops right)                        │
│ 4.567 ÷ 100 = 0.04567 (two hops left)                       │
│                                                             │
│ 🛝 "Multiply = Money grows = move RIGHT toward riches!"     │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 10 — "Ladder of LCM" for Adding Unlike Fractions**  │
│                                                             │
│ 1/4 + 1/6 → LCM(4,6) = 12                                   │
│ = 3/12 + 2/12 = 5/12                                        │
│                                                             │
│ Never add tops and bottoms directly — that's the #1 trap!   │
│                                                             │
│ 🪜 "Climb both fractions up to the SAME floor (LCM)         │
│ before adding!"                                             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 11 — "0.1, 0.01, 0.001 = TENTH-HUNDREDTH-THOUSANDTH"**│
│                                                             │
│ Places after the decimal:                                   │
│ 1st = tenths (1/10), 2nd = hundredths (1/100),              │
│ 3rd = thousandths (1/1000)                                  │
│                                                             │
│ 0.375 = 3 tenths + 7 hundredths + 5 thousandths = 375/1000  │
│                                                             │
│ 🏠 "Each step right of the dot, the room gets 10× smaller!" │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 12 — "Reciprocal Rocket" for Unit Fractions**       │
│                                                             │
│ If x + 1/x = 5, then x² + 1/x² = 5² − 2 = 23                │
│ And x³ + 1/x³ = 5³ − 3×5 = 110                              │
│                                                             │
│ Formula: square the sum, subtract 2; cube the sum,          │
│ subtract 3× the sum.                                        │
│                                                             │
│ 🚀 "Square minus TWO, Cube minus THREE-times — 2-3 blast!"  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 13 — "Between Two Fractions: Add Tops, Add Bottoms"**│
│                                                             │
│ A fraction between a/b and c/d is (a+c)/(b+d).              │
│                                                             │
│ Between 1/2 and 2/3 → (1+2)/(2+3) = 3/5 ✓                   │
│                                                             │
│ 🥪 "The mediant sandwich — fillings on top, breads below!"  │
│ (Great for "which fraction lies between" questions.)        │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 14 — "Percent-Fraction Power Pairs"**               │
│                                                             │
│ 1/3 = 33.33%   1/6 = 16.66%   1/8 = 12.5%   1/12 = 8.33%    │
│ 1/7 = 14.28%   1/9 = 11.11%   1/11 = 9.09%                  │
│                                                             │
│ Memory hook: "7-14, 8-12.5, 9-11, 11-9" — notice the        │
│ mirror pairs: 1/9 = 11.11% and 1/11 = 9.09%!                │
│                                                             │
│ 🪞 "9 and 11 swap their percents like twins swapping        │
│ clothes!"                                                   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ **TRICK 15 — "Zero Hero" for Decimal Division**             │
│                                                             │
│ Dividing decimals? Make the divisor a whole number first:   │
│ 4.5 ÷ 0.15 → multiply both by 100 → 450 ÷ 15 = 30           │
│                                                             │
│ Whatever you do to the divisor, do to the dividend —        │
│ the answer never changes!                                   │
│                                                             │
│ 🦸 "Zero Hero: shift both dots together, villain divisor    │
│ becomes a friendly whole number!"                           │
└─────────────────────────────────────────────────────────────┘
