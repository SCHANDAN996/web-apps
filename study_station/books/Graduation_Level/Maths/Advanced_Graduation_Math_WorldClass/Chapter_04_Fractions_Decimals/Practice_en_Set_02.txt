26. What is the value of 3/7 + 5/14 − 1/2?
(a) 1/7 (b) 2/7 (c) 5/14 (d) 3/14
Answer: (b)
Solution: The tempting wrong choice 3/14 comes from forgetting to convert 1/2 into fourteenths. Take LCM 14: 3/7 = 6/14, 5/14 stays, 1/2 = 7/14. So 6/14 + 5/14 − 7/14 = 4/14 = 2/7, so the answer is 2/7.
Source: NCERT Class 7 Mathematics

27. A man spends 2/5 of his salary on rent and 1/4 of the remainder on food. What fraction of his salary is left?
(a) 9/20 (b) 3/10 (c) 7/20 (d) 11/20
Answer: (a)
Solution: The trap is to subtract 1/4 of the whole salary instead of the remainder, which gives 7/20. After rent, the remainder is 3/5. Food takes 1/4 of 3/5 = 3/20. Left = 3/5 − 3/20 = 12/20 − 3/20 = 9/20, so the answer is 9/20.
Source: PYQ-style

28. Which of the following fractions is the largest: 5/8, 7/12, 11/18, 3/5?
(a) 3/5 (b) 11/18 (c) 5/8 (d) 7/12
Answer: (c)
Solution: The trap is picking 11/18 because it has the biggest numerator. Convert to decimals: 5/8 = 0.625, 7/12 ≈ 0.583, 11/18 ≈ 0.611, 3/5 = 0.6. The largest is 0.625, so the answer is 5/8.
Source: NCERT Class 7 Mathematics

29. The value of 0.36 × 0.25 ÷ 0.09 is:
(a) 10 (b) 0.1 (c) 0.01 (d) 1
Answer: (d)
Solution: The tempting wrong answer 0.1 comes from misplacing the decimal point after division. First, 0.36 × 0.25 = 0.09. Then 0.09 ÷ 0.09 = 1, so the answer is 1.

30. If 3/4 of a number is 48 more than 1/4 of the same number, the number is:
(a) 108 (b) 72 (c) 84 (d) 96
Answer: (d)
Solution: The trap is setting 3/4 of the number equal to 48, which gives 64 and pushes guesswork. Here 3/4 x − 1/4 x = 48, so 1/2 x = 48 and x = 96, so the answer is 96.

31. Simplify: (2/3 of 5/6) ÷ (5/9)
(a) 5/6 (b) 2/3 (c) 1 (d) 3/2
Answer: (c)
Solution: The trap is dividing 5/6 by 5/9 directly and ignoring "2/3 of", which gives 3/2. First, 2/3 × 5/6 = 10/18 = 5/9. Then 5/9 ÷ 5/9 = 1, so the answer is 1.
Source: NCERT Class 7 Mathematics

32. The decimal 0.777… expressed as a fraction is:
(a) 7/11 (b) 7/10 (c) 77/100 (d) 7/9
Answer: (d)
Solution: The trap is 77/100, which treats the repeating decimal as terminating. Let x = 0.777…; then 10x = 7.777…, so 9x = 7 and x = 7/9, so the answer is 7/9.

34. A fraction becomes 2/3 when 1 is added to both numerator and denominator, and becomes 1/2 when 1 is subtracted from both. The fraction is:
(a) 5/7 (b) 4/7 (c) 3/5 (d) 2/3
Answer: (c)
Solution: The trap is testing only one condition; 5/7 satisfies the second condition since 4/6 = 2/3… no, check both conditions fully. For 3/5: adding 1 gives 4/6 = 2/3, and subtracting 1 gives 2/4 = 1/2, both satisfied, so the answer is 3/5.

35. The value of (0.5)² + (0.4)² − 2 × 0.5 × 0.4 is:
(a) 0.01 (b) 0.1 (c) 0.41 (d) 0.81
Answer: (a)
Solution: The trap 0.41 comes from adding the squares and forgetting the subtraction term. This is (a − b)² = (0.5 − 0.4)² = (0.1)² = 0.01, so the answer is 0.01.
Source: NCERT Class 8 Mathematics

36. If the numerator of a fraction is increased by 20% and the denominator is decreased by 20%, the fraction becomes 6/5. The original fraction is:
(a) 4/5 (b) 5/6 (c) 3/4 (d) 2/3
Answer: (a)
Solution: The trap 5/6 is just the reciprocal of 6/5, ignoring the percentage changes. New fraction = (1.2 N)/(0.8 D) = 1.5 × (N/D) = 6/5, so N/D = (6/5)/1.5 = 4/5, so the answer is 4/5.
Source: PYQ-style

37. What is 0.125 expressed as a fraction in lowest terms?
(a) 1/80 (b) 5/4 (c) 125/1000 (d) 1/8
Answer: (d)
Solution: The trap 125/1000 is a correct conversion but is not in lowest terms as required. 0.125 = 125/1000 = 1/8 after dividing numerator and denominator by 125, so the answer is 1/8.

38. The sum of the reciprocals of 3/4 and 4/5 is:
(a) 7/9 (b) 29/12 (c) 27/20 (d) 31/12
Answer: (d)
Solution: The trap 27/20 comes from adding the fractions first and then taking the reciprocal. The reciprocals are 4/3 and 5/4; with LCM 12, the sum is 16/12 + 15/12 = 31/12, so the answer is 31/12.

39. A student was asked to multiply a number by 3/5 but divided it by 3/5 instead. The result was 32 more than the correct answer. The number is:
(a) 40 (b) 25 (c) 35 (d) 30
Answer: (d)
Solution: The trap is taking the difference with the wrong sign, giving a negative equation. Wrong result = 5x/3, correct result = 3x/5; difference = (25x − 9x)/15 = 16x/15 = 32, so x = 30, so the answer is 30.
Source: PYQ-style

41. Which of the following is equal to 5/6 − 3/4 + 7/12?

42. The price of an article is reduced by 1/5. By what fraction must the new price be increased to restore the original price?
(a) 1/6 (b) 1/4 (c) 1/5 (d) 2/5
Answer: (b)
Solution: The trap 1/5 assumes the same fraction works both ways, but the base changes. New price = 4/5 of original. To restore, increase by 1/5 of original = (1/5)/(4/5) = 1/4 of the new price, so the answer is 1/4.
Source: PYQ-style

43. If 0.4 of a number exceeds 0.25 of it by 12, the number is:
(a) 80 (b) 90 (c) 75 (d) 60
Answer: (a)
Solution: The trap 60 comes from dividing 12 by 0.2 instead of 0.15. Here 0.4x − 0.25x = 0.15x = 12, so x = 12/0.15 = 80, so the answer is 80.

46. The difference between 4/7 of a number and 2/5 of the same number is 18. The number is:
(a) 95 (b) 105 (c) 115 (d) 125
Answer: (b)
Solution: The trap is subtracting numerators and denominators directly, treating the difference as 2/2 = 1. LCM 35: 4/7 = 20/35 and 2/5 = 14/35; difference = 6/35 of the number = 18, so the number = 18 × 35/6 = 105, so the answer is 105.
Source: PYQ-style

47. Which decimal is equivalent to 7/16?
(a) 0.4375 (b) 0.4435 (c) 0.4275 (d) 0.475
Answer: (a)
Solution: The trap 0.475 comes from dividing 7 by 16 carelessly and stopping early. 7/16 = 7 ÷ 16 = 0.4375 (since 1/16 = 0.0625 and 7 × 0.0625 = 0.4375), so the answer is 0.4375.
Source: NCERT Class 9 Mathematics

48. If 2/3 of A = 3/4 of B, then A : B is:
(a) 3 : 2 (b) 8 : 9 (c) 9 : 8 (d) 2 : 3
Answer: (c)
Solution: The trap 8 : 9 is the inverted ratio, a classic examiner trick. From 2A/3 = 3B/4, cross-multiply: 8A = 9B, so A/B = 9/8, so the answer is 9 : 8.
Source: PYQ-style

49. The value of 0.1 + 0.01 + 0.001 + 0.0001 is:
(a) 0.111 (b) 1.111 (c) 0.1111 (d) 0.11
Answer: (c)
Solution: The trap 0.111 comes from ignoring the last term's extra decimal place. Adding aligned decimals: 0.1000 + 0.0100 + 0.0010 + 0.0001 = 0.1111, so the answer is 0.1111.

50. A tank is 3/8 full. When 45 litres more is poured in, it becomes 3/4 full. The capacity of the tank is:
(a) 100 litres (b) 160 litres (c) 120 litres (d) 140 litres
Answer: (c)
Solution: The trap is dividing 45 by 3/4, which ignores that 45 litres is only the increase. The increase is 3/4 − 3/8 = 3/8 of capacity = 45 litres, so capacity = 45 × 8/3 = 120 litres, so the answer is 120 litres.
Source: PYQ-style
