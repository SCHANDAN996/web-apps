76. The value of 0.2̄ + 0.3̄ expressed as a single fraction is:
(a) 4/9 (b) 1/2 (c) 5/11 (d) 5/9
Answer: (d)
Solution: The trap is adding the repeating digits directly without converting each decimal properly. 0.2̄ = 2/9 and 0.3̄ = 3/9, so the sum is 2/9 + 3/9 = 5/9, so the answer is 5/9.
Source: NCERT Class 9 Mathematics (Number Systems)

77. Which of the following fractions is the largest: 7/12, 11/18, 13/20, 3/5?
(a) 7/12 (b) 11/18 (c) 13/20 (d) 3/5
Answer: (c)
Solution: The trap is picking 3/5 because it looks the "simplest" fraction. Convert to decimals: 7/12 ≈ 0.583, 11/18 ≈ 0.611, 13/20 = 0.65, 3/5 = 0.60. The greatest is 0.65, so the answer is 13/20.
Source: PYQ-style

78. If 3/7 of a number is 45 more than 1/4 of the same number, the number is:
(a) 126 (b) 140 (c) 84 (d) 252
Answer: (d)
Solution: The trap is making arithmetic slips while dividing 45 by the difference of fractions. 3/7 − 1/4 = (12 − 7)/28 = 5/28, so the number = 45 × 28/5 = 252, so the answer is 252.
Source: PYQ-style

79. The value of (0.75 × 0.75 − 0.25 × 0.25) / (0.75 − 0.25) is:
(a) 0.75 (b) 1 (c) 0.5 (d) 1.25
Answer: (b)
Solution: The trap is expanding the numerator fully and making decimal errors. Use a² − b² = (a−b)(a+b): numerator = (0.75 − 0.25)(0.75 + 0.25) = 0.5 × 1. Dividing by 0.5 gives 1, so the answer is 1.
Source: NCERT Class 8 Mathematics (Algebraic Identities applied to decimals)

80. A student was asked to multiply a number by 3/5 but divided it by 3/5 instead. The result was 64 more than the correct answer. The number is:
(a) 120 (b) 90 (c) 150 (d) 60
Answer: (d)
Solution: The trap is miscomputing the bracket 5/3 − 3/5. The difference is (25 − 9)/15 = 16/15, so x × 16/15 = 64, giving x = 64 × 15/16 = 60, so the answer is 60.
Source: PYQ-style

81. The fraction equivalent to 0.636363… is:
(a) 7/11 (b) 63/100 (c) 7/9 (d) 63/90
Answer: (a)
Solution: The trap is writing 63/100 by treating it as a terminating decimal. Let x = 0.6363…; then 100x = 63.6363…, so 99x = 63 and x = 63/99 = 7/11, so the answer is 7/11.
Source: NCERT Class 9 Mathematics (Number Systems)

82. What is the value of 1/(1×2) + 1/(2×3) + 1/(3×4) + … + 1/(9×10)?
(a) 9/10 (b) 1/10 (c) 10/11 (d) 8/9
Answer: (a)
Solution: The trap is adding all nine fractions directly. Each term 1/(n(n+1)) = 1/n − 1/(n+1), so the series telescopes to 1 − 1/10 = 9/10, so the answer is 9/10.
Source: PYQ-style

83. The denominator of a fraction exceeds its numerator by 5. If 3 is added to both the numerator and the denominator, the fraction becomes 2/3. The fraction is:
(a) 5/11 (b) 7/12 (c) 3/8 (d) 4/9
Answer: (b)
Solution: The trap is testing only whether the denominator exceeds the numerator by 5 and ignoring the second condition. Let the numerator be x; then (x+3)/(x+5+3) = 2/3 gives 3x + 9 = 2x + 16, so x = 7 and the fraction is 7/12, so the answer is 7/12.
Source: PYQ-style

84. The value of 2.5 × 0.04 ÷ 0.005 is:
(a) 2 (b) 0.2 (c) 20 (d) 200
Answer: (c)
Solution: The trap is misplacing the decimal point when dividing by 0.005. 2.5 × 0.04 = 0.1; then 0.1 ÷ 0.005 = 100/5 = 20, so the answer is 20.
Source: NCERT Class 7 Mathematics (Fractions and Decimals)

85. Which of the following is in ascending order?
(a) 3/5, 7/11, 5/8, 9/14 (b) 5/8, 3/5, 7/11, 9/14 (c) 3/5, 5/8, 7/11, 9/14 (d) 7/11, 3/5, 5/8, 9/14
Answer: (c)
Solution: The trap is assuming bigger numerators mean bigger fractions. Decimals: 3/5 = 0.600, 5/8 = 0.625, 7/11 ≈ 0.636, 9/14 ≈ 0.643. Ascending order is 3/5, 5/8, 7/11, 9/14, so the answer is 3/5, 5/8, 7/11, 9/14.
Source: PYQ-style

86. The sum of the reciprocals of two numbers is 1/3 and the difference of the reciprocals is 1/15. The smaller number is:
(a) 5/2 (b) 5 (c) 15/2 (d) 3
Answer: (b)
Solution: The trap is reporting the reciprocals instead of the numbers. Adding the two equations: 2/x = 1/3 + 1/15 = 6/15 = 2/5, so 1/x = 1/5 and x = 5. The other reciprocal is 1/3 − 1/5 = 2/15, giving 15/2 = 7.5. The smaller number is 5, so the answer is 5.
Source: PYQ-style

87. 0.1̄6̄ (i.e., 0.1666…) expressed as a fraction is:
(a) 1/7 (b) 16/99 (c) 1/6 (d) 16/90
Answer: (c)
Solution: The trap is writing 16/99 by treating both digits as repeating. Let x = 0.1666…; then 10x = 1.666… and 100x = 16.666…, so 90x = 15 and x = 15/90 = 1/6, so the answer is 1/6.
Source: NCERT Class 9 Mathematics (Number Systems)

88. A man spends 2/5 of his salary on rent, 1/4 of the remainder on food, and saves the rest. If he saves ₹9,900, his salary is:
(a) ₹18,000 (b) ₹20,000 (c) ₹24,000 (d) ₹22,000
Answer: (d)
Solution: The trap is taking 1/4 of the whole salary instead of the remainder. Remainder after rent = 3/5; food = 1/4 × 3/5 = 3/20; savings = 3/5 − 3/20 = 9/20. Salary = 9900 × 20/9 = ₹22,000, so the answer is ₹22,000.
Source: PYQ-style

89. The value of (0.6̄ + 0.7̄) × 9 is:
(a) 14 (b) 12 (c) 13 (d) 13.5
Answer: (c)
Solution: The trap is converting only one recurring decimal correctly. 0.6̄ = 6/9 and 0.7̄ = 7/9; sum = 13/9; multiplied by 9 gives 13, so the answer is 13.
Source: NCERT Class 9 Mathematics (Number Systems)

90. If 4/9 of 3/5 of a number is 240, then 5/6 of that number is:
(a) 720 (b) 750 (c) 600 (d) 900
Answer: (b)
Solution: The trap is stopping after finding the number and forgetting the final step. Number = 240 × 9/4 × 5/3 = 900. Then 5/6 × 900 = 750, so the answer is 750.
Source: PYQ-style

91. The decimal 0.125 is what fraction of 0.5?
(a) 3/8 (b) 1/8 (c) 1/2 (d) 1/4
Answer: (d)
Solution: The trap is answering 1/8, which is the value of 0.125 itself, not the ratio. Required fraction = 0.125/0.5 = 125/500 = 1/4, so the answer is 1/4.
Source: NCERT Class 7 Mathematics (Fractions and Decimals)

92. The difference between the largest and smallest of the fractions 2/3, 3/4, 5/6, 7/12 is:
(a) 1/6 (b) 1/4 (c) 1/3 (d) 5/12
Answer: (b)
Solution: The trap is comparing only numerators or only denominators. Using twelfths: 2/3 = 8/12, 3/4 = 9/12, 5/6 = 10/12, 7/12 = 7/12. Largest = 5/6, smallest = 7/12, and the difference is 10/12 − 7/12 = 3/12 = 1/4, so the answer is 1/4.
Source: PYQ-style

93. The sum of the numerator and denominator of a fraction is 11. If 2 is added to both the numerator and the denominator, the fraction becomes 2/3. The fraction is:
(a) 3/8 (b) 4/7 (c) 5/6 (d) 2/9
Answer: (b)
Solution: The trap is checking only that the numerator and denominator add to 11, which several options satisfy. Let the numerator be x; then (x+2)/(11−x+2) = 2/3 gives 3x + 6 = 26 − 2x, so x = 4 and the fraction is 4/7, so the answer is 4/7.
Source: PYQ-style

94. The value of 3.3̄ − 1.1̄ expressed as a single fraction is:
(a) 20/9 (b) 2 (c) 2.2̄ (d) 2.1̄
Answer: (a)
Solution: The trap is subtracting digit-wise and leaving the result as a recurring decimal instead of a single fraction. 3.3̄ = 10/3 and 1.1̄ = 10/9; difference = 30/9 − 10/9 = 20/9, so the answer is 20/9.
Source: NCERT Class 9 Mathematics (Number Systems)

95. In a class, 3/8 of the students play cricket, 1/4 play football, and the remaining 45 students play neither. The total number of students is:
(a) 144 (b) 96 (c) 120 (d) 108
Answer: (c)
Solution: The trap is adding 3/8 + 1/4 = 5/8 and then dividing 45 by 5/8 instead of the remaining fraction. Remaining fraction = 1 − 5/8 = 3/8. Total = 45 × 8/3 = 120, so the answer is 120.
Source: PYQ-style

96. The value of 0.04 × 0.04 × 0.04 + 0.06 × 0.06 × 0.06 is:
(a) 0.00028 (b) 0.0028 (c) 0.000216 (d) 0.000064
Answer: (a)
Solution: The trap is reporting only one cube, like 0.000064 or 0.000216. 0.04³ = 0.000064 and 0.06³ = 0.000216; sum = 0.00028, so the answer is 0.00028.
Source: NCERT Class 8 Mathematics (Cubes, applied to decimals)

97. If a/b = 2/3, b/c = 4/5 and c/d = 6/7, then a/d is:
(a) 16/45 (b) 24/35 (c) 2/7 (d) 16/35
Answer: (d)
Solution: The trap is multiplying only two of the three ratios. a/d = (a/b)(b/c)(c/d) = (2/3)(4/5)(6/7) = 48/105 = 16/35, so the answer is 16/35.
Source: PYQ-style

98. The expression 1.5̄ − 0.5̄ equals:
(a) 1 (b) 0.9̄ (c) 14/9 (d) 1.1̄
Answer: (a)
Solution: The trap is subtracting the repeating parts carelessly and writing 1.1̄. 1.5̄ = 14/9 and 0.5̄ = 5/9; difference = 9/9 = 1, so the answer is 1.
Source: NCERT Class 9 Mathematics (Number Systems)

99. A tank is 2/5 full. When 36 litres more is added, it becomes 7/10 full. The capacity of the tank is:
(a) 120 litres (b) 100 litres (c) 150 litres (d) 90 litres
Answer: (a)
Solution: The trap is dividing 36 by the numerator of the fraction difference instead of the whole difference. Difference = 7/10 − 2/5 = 7/10 − 4/10 = 3/10. Capacity = 36 × 10/3 = 120 litres, so the answer is 120 litres.
Source: PYQ-style

100. The value of (2.3)² + 2 × 2.3 × 1.7 + (1.7)² is:
(a) 16 (b) 15.6 (c) 14.4 (d) 16.4
Answer: (a)
Solution: The trap is squaring each decimal separately and adding, risking place-value errors. This is (a + b)² with a = 2.3, b = 1.7, so it equals (2.3 + 1.7)² = 4² = 16, so the answer is 16.
Source: NCERT Class 8 Mathematics (Algebraic Identities)
