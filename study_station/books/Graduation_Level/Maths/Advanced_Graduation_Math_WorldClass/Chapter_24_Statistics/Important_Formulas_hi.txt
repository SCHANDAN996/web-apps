# सांख्यिकी — महत्वपूर्ण सूत्र (Important Formulas)

## 1. केंद्रीय प्रवृत्ति के माप (Measures of Central Tendency)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| समांतर माध्य (अवर्गीकृत) | x̄ = Σx / n | सीधे आँकड़ों का औसत |
| समांतर माध्य (वर्गीकृत) | x̄ = Σfᵢxᵢ / Σfᵢ | बारंबारता सारणी में मध्य-बिंदु xᵢ लें |
| कल्पित माध्य विधि | x̄ = A + (Σfᵢdᵢ / Σfᵢ), dᵢ = xᵢ − A | बड़े मानों में गणना आसान करने हेतु |
| पद-विचलन विधि | x̄ = A + (Σfᵢuᵢ / Σfᵢ) × h, uᵢ = (xᵢ − A)/h | समान वर्ग-अंतराल h हो तो |
| भारित माध्य | x̄w = Σwᵢxᵢ / Σwᵢ | अंक-भार (credits/weights) वाले प्रश्न |
| संयुक्त माध्य | x̄ = (n₁x̄₁ + n₂x̄₂) / (n₁ + n₂) | दो समूहों का मिलाकर माध्य |
| माध्यिका (अवर्गीकृत) | n विषम: ((n+1)/2)वाँ पद; n सम: (n/2)वें व (n/2+1)वें पदों का माध्य | पहले आरोही क्रम में लिखें |
| माध्यिका (वर्गीकृत) | M = L + [(N/2 − C) / f] × h | L = माध्यिका वर्ग की निचली सीमा, C = पूर्व संचयी बारंबारता |
| बहुलक (वर्गीकृत) | Z = L + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × h | f₁ = बहुलक वर्ग, f₀ = पूर्व, f₂ = परवर्ती बारंबारता |
| अनुभवजन्य संबंध | Z = 3M − 2x̄ | माध्य-माध्यिका-बहुलक में से दो दिए हों तो |
| गुणोत्तर माध्य | GM = ⁿ√(x₁·x₂·…·xₙ) | वृद्धि दर, अनुपात, index-type प्रश्न |
| हरात्मक माध्य | HM = n / Σ(1/xᵢ) | चाल-समय, दर-आधारित औसत |
| AM ≥ GM ≥ HM | x̄ ≥ GM ≥ HM | समान धनात्मक आँकड़ों पर सदैव सत्य |

## 2. विचलन के माप (Measures of Dispersion)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| परिसर (Range) | R = L − S | अधिकतम − न्यूनतम मान |
| परिसर गुणांक | (L − S) / (L + S) | तुलना हेतु इकाई-रहित माप |
| चतुर्थक विचलन | QD = (Q₃ − Q₁) / 2 | अर्ध-अंतर-चतुर्थक परास |
| चतुर्थक विचलन गुणांक | (Q₃ − Q₁) / (Q₃ + Q₁) | दो श्रृंखलाओं की तुलना में |
| माध्य विचलन (माध्य से) | MD = Σfᵢ|xᵢ − x̄| / N | मॉड्यूलस (धनात्मक) लेना न भूलें |
| प्रसरण (Variance) | σ² = Σfᵢ(xᵢ − x̄)² / N | विचलन का मूल माप |
| प्रसरण (लघु रूप) | σ² = (Σx²/n) − x̄² | गणना में तेज़ तरीका |
| मानक विचलन | σ = √[Σfᵢ(xᵢ − x̄)² / N] | प्रसरण का धनात्मक वर्गमूल |
| मानक विचलन (पद-विचलन) | σ = h × √[Σfᵢuᵢ²/N − (Σfᵢuᵢ/N)²] | वर्गीकृत आँकड़े, uᵢ = (xᵢ − A)/h |
| विचरण गुणांक (CV) | CV = (σ / x̄) × 100 | स्थिरता/संगति की तुलना — कम CV = अधिक संगत |
| संयुक्त मानक विचलन | σ = √[(n₁(σ₁²+d₁²) + n₂(σ₂²+d₂²))/(n₁+n₂)], dᵢ = x̄ᵢ − x̄ | दो समूहों का मिलाकर σ |

## 3. स्थिति माप (Partition Values)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| kवाँ चतुर्थक (k = 1, 2, 3) | Qₖ = L + [(kN/4 − C)/f] × h | माध्यिका-सूत्र जैसा ही, N/4 के गुणज |
| kवाँ दशमक (k = 1…9) | Dₖ = L + [(kN/10 − C)/f] × h | N/10 के गुणज पर |
| kवाँ शतमक (k = 1…99) | Pₖ = L + [(kN/100 − C)/f] × h | CAT/CSAT में प्रतिशत-रैंक प्रश्न |
| विशेष संबंध | Q₂ = D₅ = P₅₀ = माध्यिका | एक ही बिंदु के चार नाम |

## 4. विषमता एवं कुब्दता (Skewness & Kurtosis)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| कार्ल पियरसन गुणांक | Sk = (x̄ − Z) / σ | बहुलक ज्ञात हो तो |
| संशोधित गुणांक | Sk = 3(x̄ − M) / σ | बहुलक अस्पष्ट हो तो |
| बाउली गुणांक | Sk = (Q₃ + Q₁ − 2Q₂) / (Q₃ − Q₁) | चतुर्थकों से विषमता |
| विषमता की दिशा | Sk > 0 धनात्मक (x̄ > M > Z); Sk < 0 ऋणात्मक (x̄ < M < Z) | पूँछ की दिशा देखें |
| कुब्दता | β₂ = μ₄ / μ₂² | β₂ = 3 मध्यम शिखर, > 3 अधिक शिखर, < 3 चपटा |

## 5. सहसंबंध एवं प्रतिगमन (Correlation & Regression)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| कार्ल पियरसन r | r = Σ(x−x̄)(y−ȳ) / √[Σ(x−x̄)²·Σ(y−ȳ)²] | −1 ≤ r ≤ +1 |
| r (लघु रूप) | r = [nΣxy − ΣxΣy] / √[(nΣx²−(Σx)²)(nΣy²−(Σy)²)] | कैलकुलेशन-अनुकूल रूप |
| स्पीयरमैन कोटि सहसंबंध | R = 1 − [6Σd² / n(n²−1)] | d = कोटियों का अंतर; रैंकिंग प्रश्न |
| प्रतिगमन रेखा (Y पर X) | y − ȳ = b_yx (x − x̄) | x दिया हो, y ज्ञात करना हो |
| प्रतिगमन रेखा (X पर Y) | x − x̄ = b_xy (y − ȳ) | y दिया हो, x ज्ञात करना हो |
| प्रतिगमन गुणांक | b_yx = r·(σ_y/σ_x); b_xy = r·(σ_x/σ_y) | r और σ से सीधे |
| r और b का संबंध | r = ±√(b_yx · b_xy) | r का चिह्न = b के चिह्न जैसा |
| कोण-संकेत | दोनों रेखाओं के बीच कोण छोटा ⇒ |r| बड़ा | रेखाएँ मिल जाएँ ⇒ r = ±1 |

## 6. प्रायिकता (Probability)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| क्लासिकल प्रायिकता | P(E) = अनुकूल परिणाम / कुल परिणाम | 0 ≤ P(E) ≤ 1 |
| पूरक घटना | P(E′) = 1 − P(E) | "कम से कम एक" वाले प्रश्नों में |
| योग नियम (सामान्य) | P(A∪B) = P(A) + P(B) − P(A∩B) | अतिव्यापी घटनाएँ |
| योग नियम (परस्पर अपवर्जी) | P(A∪B) = P(A) + P(B) | A∩B = ∅ हो तो |
| सप्रतिबंध प्रायिकता | P(A|B) = P(A∩B) / P(B) | "दिया गया कि…" वाले प्रश्न |
| गुणन नियम | P(A∩B) = P(A)·P(B|A) | क्रमिक घटनाएँ |
| स्वतंत्र घटनाएँ | P(A∩B) = P(A)·P(B) | स्वतंत्रता की जाँच का नियम |
| कुल प्रायिकता | P(A) = Σ P(Bᵢ)·P(A|Bᵢ) | विभाजन {Bᵢ} पर |
| बेज़ प्रमेय | P(Bᵢ|A) = P(Bᵢ)·P(A|Bᵢ) / Σ P(Bⱼ)·P(A|Bⱼ) | "घटना हो चुकी, कारण क्या?" |
| द्विपद बंटन | P(X = r) = ⁿCᵣ pʳ qⁿ⁻ʳ, q = 1−p | n स्वतंत्र परीक्षण, सफलता p |
| द्विपद माध्य/प्रसरण | माध्य = np; σ² = npq | सीधे परिणाम याद रखें |
| संचय/क्रमचय | ⁿPᵣ = n!/(n−r)!; ⁿCᵣ = n!/[r!(n−r)!] | क्रम मायने रखे ⇒ P, न रखे ⇒ C |

## 7. सूचकांक एवं अन्य (Index Numbers & Misc.)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| सरल सूचकांक | I = (p₁/p₀) × 100 | आधार वर्ष p₀, चालू वर्ष p₁ |
| लास्पेयर सूचकांक | I = [Σp₁q₀ / Σp₀q₀] × 100 | आधार-वर्ष मात्रा भारित |
| पाशे सूचकांक | I = [Σp₁q₁ / Σp₀q₁] × 100 | चालू-वर्ष मात्रा भारित |
| फिशर आदर्श सूचकांक | I = √(L × P) | लास्पेयर व पाशे का GM |
| माध्य में परिवर्तन का प्रभाव | प्रत्येक पद +k ⇒ माध्य +k; ×k ⇒ माध्य ×k | σ जोड़ने पर अपरिवर्तित, गुणा पर ×|k| |
| नया पद जुड़ने पर माध्य | नया माध्य = (n·x̄ + xₙ₊₁)/(n+1) | प्रवेश/निकासी वाले प्रश्न |
