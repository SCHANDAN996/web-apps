## Trick 1: The "FOIL" Army
```
┌─────────────────────────────────────────────┐
│ (a + b)(c + d) = ?                          │
│ FOIL: First, Outer, Inner, Last             │
│ First: a·c   Outer: a·d                     │
│ Inner: b·c   Last: b·d                      │
│ 🧠 Memory: A soldier marches F-O-I-L!       │
└─────────────────────────────────────────────┘
```

## Trick 2: "Same Sign Sum, Different Sign Difference"
```
┌─────────────────────────────────────────────┐
│ (a+b)² vs (a−b)² — which sign in middle?    │
│ 🧠 "The middle term MARRIES the sign"       │
│ (a+b)² = a² + 2ab + b²  → + marries +       │
│ (a−b)² = a² − 2ab + b²  → − marries −       │
│ Last term is ALWAYS positive (b² never lies)│
└─────────────────────────────────────────────┘
```

## Trick 3: SOAP for Cubes
```
┌─────────────────────────────────────────────┐
│ a³ + b³ = (a+b)(a² − ab + b²)               │
│ a³ − b³ = (a−b)(a² + ab + b²)               │
│ 🧠 SOAP: Same, Opposite, Always Positive    │
│ First bracket: SAME sign as the cube        │
│ Middle term: OPPOSITE sign                  │
│ Last term: ALWAYS POSITIVE                  │
└─────────────────────────────────────────────┘
```

## Trick 6: Vieta's "SUM-PRODUCT Switch"
```
┌─────────────────────────────────────────────┐
│ For ax² + bx + c = 0:                       │
│ Sum of roots = −b/a  (sign FLIPS!)          │
│ Product of roots = c/a (sign STAYS)         │
│ 🧠 "SUM is SHY — it hides its sign.         │
│     PRODUCT is PROUD — it shows its sign."  │
└─────────────────────────────────────────────┘
```

## Trick 8: Log Laws — "Logs Love to Downgrade"
```
┌─────────────────────────────────────────────┐
│ log(M·N) = log M + log N  (× becomes +)     │
│ log(M/N) = log M − log N  (÷ becomes −)     │
│ log(Mⁿ) = n·log M         (power falls down)│
│ 🧠 "Logs are LAZY — they downgrade every    │
│     operation: multiply→add, divide→minus,  │
│     power→just a multiplier on the floor!"  │
└─────────────────────────────────────────────┘
```

## Trick 9: AP-GP "Add vs Attack"
```
┌─────────────────────────────────────────────┐
│ AP: a, a+d, a+2d…  → nth term = a+(n−1)d    │
│ GP: a, ar, ar²…    → nth term = a·r^(n−1)   │
│ 🧠 "AP ADDS politely (d walks step by step).│
│     GP ATTACKS with power (r explodes!)."   │
│ Both use (n−1), never n — "start counts 0"  │
└─────────────────────────────────────────────┘
```

## Trick 10: Sum of First n Naturals — "Gauss's Pairing"
```

│     each pair = 101, and 50 pairs → 5050!   │

└─────────────────────────────────────────────┘
```

## Trick 12: Remainder Theorem — "Plug the Killer"
```

└─────────────────────────────────────────────┘
```

## Trick 14: Modulus |x| — "The Distance Bouncer"
```
┌─────────────────────────────────────────────┐
│ |x| < a  →  −a < x < a  (sandwich)          │
│ |x| > a  →  x < −a OR x > a (run away)      │
│ 🧠 "LESS than = LOCKED inside the sandwich. │
│     GREATER than = GET OUT, run both ways!" │
│ |x−3| < 2 means x stays within 2 of 3.      │
└─────────────────────────────────────────────┘
```
