26. If x + 1/x = 5, then the value of x² + 1/x² is
(a) 23 (b) 25 (c) 27 (d) 21
Answer: (a)
Solution: The tempting wrong option is 25, obtained by simply squaring 5 and forgetting the cross term. Squaring both sides: (x + 1/x)² = x² + 2 + 1/x² = 25, so x² + 1/x² = 25 − 2 = 23. So the answer is 23.
Source: NCERT Class 9 Mathematics (Polynomials)

27. If a + b = 10 and ab = 21, then the value of a² + b² is
(a) 79 (b) 100 (c) 58 (d) 42
Answer: (c)
Solution: The trap is 100, which is just (a + b)² written carelessly. Using (a + b)² = a² + 2ab + b², we get a² + b² = 100 − 2(21) = 100 − 42 = 58. So the answer is 58.
Source: NCERT Class 9 Mathematics (Polynomials)

28. If x − 1/x = 4, then the value of x² + 1/x² is
(a) 20 (b) 14 (c) 16 (d) 18
Answer: (d)
Solution: The tempting wrong option is 14, found by subtracting 2 as in the sum formula. For difference, (x − 1/x)² = x² − 2 + 1/x² = 16, so x² + 1/x² = 16 + 2 = 18. So the answer is 18.
Source: NCERT Class 9 Mathematics (Polynomials)

29. If x + 1/x = 3, then the value of x³ + 1/x³ is
(a) 21 (b) 27 (c) 18 (d) 9
Answer: (c)
Solution: The trap is 27, which is just 3³. Using the identity x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 27 − 9 = 18. So the answer is 18.
Source: NCERT Class 9 Mathematics (Polynomials)

30. The factors of x² − 7x + 12 are
(a) (x − 3)(x − 4) (b) (x + 3)(x + 4) (c) (x + 3)(x − 4) (d) (x − 2)(x − 6)
Answer: (a)
Solution: The tempting wrong option is the pair with both plus signs, which gives the right product 12 but the wrong middle sign. We need two numbers with product +12 and sum −7, which are −3 and −4, giving (x − 3)(x − 4). So the answer is (x − 3)(x − 4).
Source: NCERT Class 9 Mathematics (Polynomials)

31. If 2x + 3y = 12 and 3x + 2y = 13, then the value of x + y is
(a) 4 (b) 6 (c) 7 (d) 5
Answer: (d)
Solution: The trap is solving fully for x and y and then mis-adding. Instead add the two equations directly: 5x + 5y = 25, so x + y = 5 without finding x and y separately. So the answer is 5.
Source: NCERT Class 10 Mathematics (Pair of Linear Equations)

32. If x² − 5x + 6 = 0, then the sum of the roots is
(a) 6 (b) −5 (c) 5 (d) −6
Answer: (c)
Solution: The tempting wrong option is −5, taken straight from the coefficient with its sign. Sum of roots = −(coefficient of x)/(coefficient of x²) = −(−5)/1 = 5. So the answer is 5.
Source: NCERT Class 10 Mathematics (Quadratic Equations)

33. The product of the roots of 2x² − 7x + 3 = 0 is
(a) 7/2 (b) 3/2 (c) −3/2 (d) 2/3
Answer: (b)
Solution: The trap is answering 3, forgetting to divide by the leading coefficient. Product of roots = c/a = 3/2. So the answer is 3/2.
Source: NCERT Class 10 Mathematics (Quadratic Equations)

34. If a³ + b³ = 91 and a + b = 7, then the value of ab is
(a) 14 (b) 10 (c) 12 (d) 9
Answer: (c)
Solution: The trap is assuming a and b are small integers and guessing wrongly. Using a³ + b³ = (a + b)³ − 3ab(a + b): 91 = 343 − 21ab, so 21ab = 252 and ab = 12. So the answer is 12.
Source: NCERT Class 9 Mathematics (Polynomials)

35. If x = 3 + 2√2, then the value of √x − 1/√x is
(a) √2 (b) 2√2 (c) 4 (d) 2
Answer: (d)
Solution: The tempting wrong option is 2√2, from mishandling the surd. Note x = (√2 + 1)², so √x = √2 + 1 and 1/√x = √2 − 1; their difference is 2. So the answer is 2.
Source: NCERT Class 9 Mathematics (Number Systems)

36. If x + y = 8 and xy = 15, then the value of x³ + y³ is
(a) 152 (b) 242 (c) 512 (d) 362
Answer: (a)
Solution: The trap is 512, which is just 8³. Using x³ + y³ = (x + y)³ − 3xy(x + y) = 512 − 3(15)(8) = 512 − 360 = 152. So the answer is 152.
Source: NCERT Class 9 Mathematics (Polynomials)

37. The value of (x + 2)³ − (x − 2)³ when x = 1 is
(a) 30 (b) 28 (c) 24 (d) 26
Answer: (b)
Solution: The tempting wrong option is 26, from a sign slip while handling the negative cube. Substituting x = 1: (3)³ − (−1)³ = 27 − (−1) = 27 + 1 = 28. So the answer is 28.
Source: NCERT Class 9 Mathematics (Polynomials)

38. If x² + 1/x² = 7, then the value of x + 1/x (x > 0) is
(a) 5 (b) √7 (c) 9 (d) 3
Answer: (d)
Solution: The tempting wrong option is √7, taking the square root directly. Since (x + 1/x)² = x² + 1/x² + 2 = 9, we get x + 1/x = 3 (positive root as x > 0). So the answer is 3.
Source: NCERT Class 9 Mathematics (Polynomials)

39. The remainder when x³ + 2x² − 5x + 3 is divided by (x − 1) is
(a) 5 (b) 1 (c) −1 (d) 3
Answer: (b)
Solution: The trap is performing long division and making an arithmetic slip. By the Remainder Theorem, remainder = value at x = 1: 1 + 2 − 5 + 3 = 1. So the answer is 1.
Source: NCERT Class 9 Mathematics (Polynomials)

40. If (x − 2) is a factor of x³ − 3x² + kx − 4, then k equals
(a) 6 (b) 4 (c) −4 (d) 2
Answer: (b)
Solution: The trap is substituting x = −2 instead of x = 2, or making a sign slip in the constant terms. By the Factor Theorem, at x = 2: 8 − 12 + 2k − 4 = 0, so 2k − 8 = 0 and k = 4. So the answer is 4.
Source: NCERT Class 9 Mathematics (Polynomials)

41. If 3ˣ = 81, then the value of 3^(x−2) is
(a) 27 (b) 9 (c) 3 (d) 81
Answer: (b)
Solution: The tempting wrong option is 27, from faulty exponent subtraction. Since 3ˣ = 81 = 3⁴, x = 4, so 3^(x−2) = 3² = 9. So the answer is 9.
Source: NCERT Class 9 Mathematics (Number Systems)

42. The simplified form of (a² − b²)/(a − b), where a ≠ b, is
(a) a − b (b) a + b (c) a² + b² (d) 2ab
Answer: (b)
Solution: The trap is a − b, from cancelling wrongly. Since a² − b² = (a − b)(a + b), dividing by (a − b) leaves a + b. So the answer is a + b.
Source: NCERT Class 8 Mathematics (Algebraic Expressions)

43. If x/y = 3/4, then the value of (3x + 2y)/(3x − 2y) is
(a) 1/17 (b) 7 (c) 17 (d) 5
Answer: (c)
Solution: The trap is 1/17, from inverting the ratio by mistake. Let x = 3k, y = 4k: numerator = 9k + 8k = 17k, denominator = 9k − 8k = k, so the value is 17. So the answer is 17.
Source: NCERT Class 8 Mathematics (Comparing Quantities)

44. If x + 1/x = 2, then the value of x¹⁰⁰ + 1/x¹⁰⁰ is
(a) 2¹⁰⁰ (b) 100 (c) 0 (d) 2
Answer: (d)
Solution: The tempting wrong option is 2¹⁰⁰, from raising both sides to the 100th power wrongly. x + 1/x = 2 implies x = 1 (multiplying by x gives (x − 1)² = 0), so x¹⁰⁰ + 1/x¹⁰⁰ = 1 + 1 = 2. So the answer is 2.
Source: NCERT Class 9 Mathematics (Polynomials)

45. The roots of x² − 4x + 4 = 0 are
(a) −2 and −2 (b) 2 and −2 (c) 4 and 1 (d) 2 and 2
Answer: (d)
Solution: The trap is 2 and −2, confusing this with x² − 4 = 0. Here x² − 4x + 4 = (x − 2)² = 0, giving equal roots 2 and 2. So the answer is 2 and 2.
Source: NCERT Class 10 Mathematics (Quadratic Equations)

46. If a + b + c = 0, then the value of a³ + b³ + c³ is
(a) 3abc (b) (a + b + c)³ (c) abc (d) 0
Answer: (a)
Solution: The tempting wrong option is 0, assuming the cubes also cancel out. The identity a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) gives a³ + b³ + c³ = 3abc when a + b + c = 0. So the answer is 3abc.
Source: NCERT Class 9 Mathematics (Polynomials)

47. If 2x − 3y = 7 and 4x + y = 7, then the value of x is
(a) 2 (b) 1 (c) −1 (d) 3
Answer: (a)
Solution: The trap is an elimination sign error. Multiply the second equation by 3: 12x + 3y = 21; adding to the first: 14x = 28, so x = 2. So the answer is 2.
Source: NCERT Class 10 Mathematics (Pair of Linear Equations)

48. The value of (997)² using an algebraic identity is
(a) 993009 (b) 994090 (c) 994009 (d) 995009
Answer: (c)
Solution: The trap is a place-value slip in direct multiplication. Write 997 = 1000 − 3: (1000 − 3)² = 1000000 − 6000 + 9 = 994009. So the answer is 994009.
Source: NCERT Class 8 Mathematics (Algebraic Expressions)

49. If x² − 3x + 1 = 0, then the value of x² + 1/x² is
(a) 7 (b) 9 (c) 11 (d) 5
Answer: (a)
Solution: The tempting wrong option is 9, which is just 3². Dividing the equation by x: x − 3 + 1/x = 0, so x + 1/x = 3; then x² + 1/x² = 9 − 2 = 7. So the answer is 7.
Source: NCERT Class 10 Mathematics (Quadratic Equations)

50. If (x + a) is the HCF of x² + 5x + 6 and x² + 7x + 12, then a equals
(a) 3 (b) 2 (c) 4 (d) 6
Answer: (a)
Solution: The trap is picking a factor of only one polynomial. Factorising: x² + 5x + 6 = (x + 2)(x + 3) and x² + 7x + 12 = (x + 3)(x + 4); the common factor is (x + 3), so a = 3. So the answer is 3.
Source: NCERT Class 9 Mathematics (Polynomials)
