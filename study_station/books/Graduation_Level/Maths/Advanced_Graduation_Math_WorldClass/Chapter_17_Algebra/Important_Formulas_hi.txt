# 📋 बीजगणित — महत्वपूर्ण सूत्र (Important Formulas)

## 1. सर्वसमिकाएँ (Identities)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| वर्ग (योग) | (a + b)² = a² + 2ab + b² | द्विपद का वर्ग खोलने में |
| वर्ग (अंतर) | (a − b)² = a² − 2ab + b² | अंतर के वर्ग में |
| वर्गों का अंतर | a² − b² = (a + b)(a − b) | गुणनखंड और तेज़ गुणा (जैसे 99×101) |
| त्रिपद का वर्ग | (a + b + c)² = a² + b² + c² + 2(ab + bc + ca) | तीन पदों के वर्ग में |
| घन (योग) | (a + b)³ = a³ + b³ + 3ab(a + b) | घन खोलने में |
| घन (अंतर) | (a − b)³ = a³ − b³ − 3ab(a − b) | घन खोलने में |
| घनों का योग | a³ + b³ = (a + b)(a² − ab + b²) | गुणनखंड में |
| घनों का अंतर | a³ − b³ = (a − b)(a² + ab + b²) | गुणनखंड में |
| त्रिघन सर्वसमिका | a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) | a + b + c = 0 हो तो a³ + b³ + c³ = 3abc |
| विशेष स्थिति | यदि a + b + c = 0, तो a³ + b³ + c³ = 3abc | सीधे मान निकालने में |
| x + 1/x परिवार | x² + 1/x² = (x + 1/x)² − 2 | x + 1/x = k दिया हो तो |
| x − 1/x परिवार | x² + 1/x² = (x − 1/x)² + 2 | x − 1/x = k दिया हो तो |
| घन रूप | x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) | x + 1/x = k से घन निकालने में |
| घन रूप (ऋण) | x³ − 1/x³ = (x − 1/x)³ + 3(x − 1/x) | x − 1/x = k से घन निकालने में |

## 2. घातांक के नियम (Laws of Exponents)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| गुणन नियम | aᵐ × aⁿ = aᵐ⁺ⁿ | समान आधार के गुणन में |
| भाग नियम | aᵐ ÷ aⁿ = aᵐ⁻ⁿ | समान आधार के भाग में |
| घात की घात | (aᵐ)ⁿ = aᵐⁿ | शक्ति पर शक्ति |
| शून्य घात | a⁰ = 1 (a ≠ 0) | किसी भी संख्या की घात 0 |
| ऋणात्मक घात | a⁻ⁿ = 1/aⁿ | ऋण घात हटाने में |
| भिन्न घात | a^(m/n) = ⁿ√(aᵐ) | मूल (root) में बदलने में |
| गुणनफल की घात | (ab)ⁿ = aⁿbⁿ | कोष्ठक खोलने में |
| भिन्न की घात | (a/b)ⁿ = aⁿ/bⁿ | भिन्न की घात में |

## 3. द्विघात समीकरण (Quadratic Equations)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| मानक रूप | ax² + bx + c = 0 (a ≠ 0) | पहचान का आधार |
| मूलों का सूत्र | x = [−b ± √(b² − 4ac)] / 2a | मूल निकालने में |
| विविक्तकर (Discriminant) | D = b² − 4ac | मूलों की प्रकृति जाँचने में |
| वास्तविक व असमान मूल | D > 0 | दो अलग-अलग मूल |
| समान मूल | D = 0 | दोनों मूल बराबर |
| अवास्तविक मूल | D < 0 | कोई वास्तविक मूल नहीं |
| मूलों का योग | α + β = −b/a | बिना हल किए योग |
| मूलों का गुणनफल | αβ = c/a | बिना हल किए गुणनफल |
| समीकरण निर्माण | x² − (α + β)x + αβ = 0 | मूलों से समीकरण बनाने में |

## 4. समांतर श्रेढ़ी (AP)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| nवाँ पद | aₙ = a + (n − 1)d | कोई भी पद निकालने में |
| n पदों का योग | Sₙ = n/2 [2a + (n − 1)d] | योग निकालने में |
| योग (प्रथम-अंतिम) | Sₙ = n/2 (a + l) | अंतिम पद l ज्ञात हो तो |
| समांतर माध्य | b = (a + c)/2 | a, b, c समांतर श्रेढ़ी में हों तो |

## 5. गुणोत्तर श्रेढ़ी (GP)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| nवाँ पद | aₙ = a·rⁿ⁻¹ | कोई भी पद निकालने में |
| n पदों का योग (r ≠ 1) | Sₙ = a(rⁿ − 1)/(r − 1), r > 1 | योग निकालने में |
| n पदों का योग (r < 1) | Sₙ = a(1 − rⁿ)/(1 − r) | r भिन्न हो तो |
| अनंत श्रेढ़ी का योग | S∞ = a/(1 − r), \|r\| < 1 | अनंत तक योग |
| गुणोत्तर माध्य | b = √(ac) | a, b, c गुणोत्तर श्रेढ़ी में हों तो |

## 6. प्राकृत संख्याओं के योग

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| प्रथम n प्राकृत संख्याएँ | Σn = n(n + 1)/2 | 1 + 2 + … + n |
| वर्गों का योग | Σn² = n(n + 1)(2n + 1)/6 | 1² + 2² + … + n² |
| घनों का योग | Σn³ = [n(n + 1)/2]² | 1³ + 2³ + … + n³ |
| प्रथम n विषम संख्याएँ | 1 + 3 + 5 + … = n² | विषम संख्याओं का योग |
| प्रथम n सम संख्याएँ | 2 + 4 + 6 + … = n(n + 1) | सम संख्याओं का योग |

## 7. अवशेष व गुणनखंड प्रमेय (Remainder & Factor Theorem)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| अवशेष प्रमेय | p(x) को (x − a) से भाग देने पर शेषफल = p(a) | शेषफल सीधे निकालने में |
| गुणनखंड प्रमेय | यदि p(a) = 0, तो (x − a), p(x) का गुणनखंड है | गुणनखंड जाँचने में |

## 8. असमानिकाएँ (Inequalities)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| AM–GM | (a + b)/2 ≥ √(ab) (a, b > 0) | न्यूनतम/अधिकतम मान में |
| AM–GM (n पद) | (a₁ + a₂ + … + aₙ)/n ≥ (a₁a₂…aₙ)¹/ⁿ | सामान्य रूप |
| न्यूनतम योग | a + 1/a ≥ 2 (a > 0) | न्यूनतम मान 2, जब a = 1 |
| मापांक | \|x\| < a ⟺ −a < x < a | मापांक असमानिका खोलने में |

## 9. लघुगणक (Logarithms)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| परिभाषा | logₐb = x ⟺ aˣ = b | घात-लघुगणक परिवर्तन |
| गुणन नियम | log(mn) = log m + log n | गुणन को योग में |
| भाग नियम | log(m/n) = log m − log n | भाग को अंतर में |
| घात नियम | log(mⁿ) = n log m | घात को आगे लाने में |
| आधार परिवर्तन | logₐb = log b / log a | आधार बदलने में |
| व्युत्क्रम | logₐb × log_b a = 1 | परस्पर व्युत्क्रम |
