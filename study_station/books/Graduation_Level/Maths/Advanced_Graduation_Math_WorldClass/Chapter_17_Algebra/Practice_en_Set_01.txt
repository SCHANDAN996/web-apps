1. If x + 5 = 12, then the value of x is
(a) 7 (b) 6 (c) 5 (d) 8
Answer: (a)
Solution: The tempting wrong option is 17, obtained by adding 5 to 12 instead of subtracting. Subtracting 5 from both sides gives x = 12 − 5, so the answer is 7.
Source: NCERT Class 8 Mathematics

2. The value of (a + b)² is
(a) a² + 2ab + b² (b) a² + b² (c) a² − 2ab + b² (d) 2a² + 2b²
Answer: (a)
Solution: Many students wrongly pick a² + b² by forgetting the middle term. Expanding (a + b)(a + b) gives a² + ab + ab + b², so the answer is a² + 2ab + b².
Source: NCERT Class 8 Mathematics

3. If 3x = 27, then x equals
(a) 3 (b) 24 (c) 9 (d) 81
Answer: (c)
Solution: The trap is 24, found by subtracting 3 from 27 instead of dividing. Dividing both sides by 3 gives x = 27/3, so the answer is 9.
Source: NCERT Class 8 Mathematics

4. The value of a² − b² is equal to
(a) (a + b)(a − b) (b) (a − b)² (c) (a + b)² (d) a² + b²
Answer: (a)
Solution: The tempting wrong option is (a − b)², which actually equals a² − 2ab + b². The difference of squares factorises as (a + b)(a − b), so the answer is (a + b)(a − b).
Source: NCERT Class 8 Mathematics

5. If x = 2, the value of 3x² + 2x − 1 is
(a) 13 (b) 11 (c) 17 (d) 15
Answer: (d)
Solution: The trap is 13, obtained by computing 3x² as 6² = 36 wrongly or by arithmetic slips. Substituting x = 2: 3(4) + 2(2) − 1 = 12 + 4 − 1, so the answer is 15.
Source: NCERT Class 9 Mathematics

6. The sum of the roots of x² − 5x + 6 = 0 is
(a) −5 (b) −6 (c) 6 (d) 5
Answer: (d)
Solution: The tempting wrong option is −5, from forgetting the sign change in the formula. Sum of roots = −(coefficient of x)/(coefficient of x²) = −(−5)/1, so the answer is 5.
Source: NCERT Class 10 Mathematics

7. The product of the roots of x² − 7x + 12 = 0 is
(a) 7 (b) −7 (c) 12 (d) −12
Answer: (c)
Solution: The trap is 7, which is the sum of the roots, not the product. Product of roots = constant term/coefficient of x² = 12/1, so the answer is 12.

8. If 2x − 3 = 9, then x is
(a) 3 (b) 5 (c) 12 (d) 6
Answer: (d)
Solution: The tempting wrong option is 3, found by dividing 9 by 3 carelessly. Adding 3 to both sides gives 2x = 12, then dividing by 2, so the answer is 6.

9. The factors of x² + 5x + 6 are
(a) (x + 1)(x + 6) (b) (x − 2)(x − 3) (c) (x + 2)(x + 3) (d) (x + 5)(x + 1)
Answer: (c)
Solution: The trap is (x + 1)(x + 6), whose middle term is 7x, not 5x. We need two numbers with product 6 and sum 5, which are 2 and 3, so the answer is (x + 2)(x + 3).
Source: NCERT Class 9 Mathematics

10. If x + y = 10 and x − y = 4, then x is
(a) 3 (b) 6 (c) 14 (d) 7
Answer: (d)
Solution: The tempting wrong option is 3, which is actually the value of y. Adding the two equations gives 2x = 14, so the answer is 7.

11. The value of (x + 1/x)² when x + 1/x = 4 is
(a) 8 (b) 16 (c) 12 (d) 20
Answer: (b)
Solution: The trap is 8, from doubling instead of squaring. Squaring 4 directly gives 4², so the answer is 16.

12. If x² = 49, then the values of x are
(a) 7 only (b) 7 and −7 (c) −7 only (d) 49 and −49
Answer: (b)
Solution: The tempting wrong option is 7 only, but squaring −7 also gives 49. Taking square roots of both sides gives x = ±7, so the answer is 7 and −7.

13. The discriminant of 2x² + 3x + 1 = 0 is
(a) −7 (b) 5 (c) 17 (d) 1
Answer: (d)
Solution: The trap is 17, from computing b² + 4ac instead of b² − 4ac. Here b² − 4ac = 9 − 8, so the answer is 1.

17. If 5x + 3 = 2x + 12, then x is
(a) 3 (b) 2 (c) 5 (d) 9

Solution: The trap is 5, from adding 2x to 5x instead of subtracting. Subtracting 2x and 3 from both sides gives 3x = 9, so the answer is 3.

18. The value of (a − b)² is
(a) a² − 2ab + b² (b) a² + 2ab + b² (c) a² − b² (d) a² − 2ab − b²
Answer: (a)
Solution: The tempting wrong option is a² − b², which is a different identity altogether. Expanding (a − b)(a − b) gives a² − ab − ab + b², so the answer is a² − 2ab + b².
Source: NCERT Class 8 Mathematics

19. If x + 1/x = 2, then the value of x² + 1/x² is
(a) 2 (b) 4 (c) 0 (d) 6
Answer: (a)
Solution: The trap is 4, from simply squaring 2 without subtracting 2. Using x² + 1/x² = (x + 1/x)² − 2 = 4 − 2, so the answer is 2.
Source: NCERT Class 9 Mathematics

20. The linear equation 2x + 3y = 12 has which of the following as a solution?
(a) x = 2, y = 3 (b) x = 3, y = 2 (c) x = 1, y = 4 (d) x = 4, y = 1
Answer: (b)
Solution: The tempting wrong option is x = 2, y = 3, which gives 4 + 9 = 13, not 12. Checking x = 3, y = 2 gives 6 + 6 = 12, so the answer is x = 3, y = 2.
Source: NCERT Class 9 Mathematics

21. If x + 1/x = 5, then the value of x³ + 1/x³ is
(a) 115 (b) 110 (c) 120 (d) 125
Answer: (b)
Solution: The tempting wrong option is 125, from simply cubing 5. Using x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 125 − 15, so the answer is 110.
Source: PYQ-style

22. If the roots of x² − kx + 16 = 0 are equal, then the positive value of k is
(a) 8 (b) 4 (c) 16 (d) 32
Answer: (a)
Solution: The trap is 16, from setting k equal to the constant term. Equal roots require discriminant zero: k² − 64 = 0, so k = 8 (taking the positive value), so the answer is 8.
Source: NCERT Class 10 Mathematics

23. If x² − 3x + 2 = 0 and y² − 5y + 6 = 0, then the maximum value of x + y is
(a) 4 (b) 7 (c) 6 (d) 5
Answer: (d)
Solution: The tempting wrong option is 7, from adding the largest numbers visible without solving. The first equation gives x = 1 or 2; the second gives y = 2 or 3; maximum x + y = 2 + 3, so the answer is 5.
Source: PYQ-style

24. If a + b = 7 and ab = 12, then the value of a² + b² is
(a) 37 (b) 25 (c) 49 (d) 24
Answer: (b)
Solution: The trap is 49, from squaring 7 and forgetting to subtract 2ab. Using a² + b² = (a + b)² − 2ab = 49 − 24, so the answer is 25.
Source: NCERT Class 9 Mathematics

25. The quadratic equation whose roots are 3 and −4 is
(a) x² + x + 12 = 0 (b) x² − x − 12 = 0 (c) x² + x − 12 = 0 (d) x² − 7x + 12 = 0
Answer: (c)
Solution: The tempting wrong option is x² − x − 12 = 0, from a sign error in the sum of roots. Sum of roots = −1 and product = −12, giving x² − (sum)x + product = x² + x − 12, so the answer is x² + x − 12 = 0.
Source: NCERT Class 10 Mathematics
