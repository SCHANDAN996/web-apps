126. If x + 1/x = 5, then the value of x³ + 1/x³ is
(a) 100 (b) 125 (c) 110 (d) 115
Answer: (c)
Solution: The tempting wrong choice 125 comes from simply cubing 5, forgetting the correction term. Use the identity x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 125 − 15 = 110, so the answer is 110.

Answer: (b)
Solution: Many students pick 0 because a + b + c = 0, but that trap ignores the identity a³ + b³ + c³ = 3abc when the sum is zero. The expression equals (a³ + b³ + c³)/abc = 3abc/abc = 3, so the answer is 3.

129. The roots of the equation x² − 8x + 15 = 0 are
(a) −3 and 5 (b) −3 and −5 (c) 3 and −5 (d) 3 and 5
Answer: (d)
Solution: The trap options with negative signs arise from mishandling the middle term's sign. Factorising: (x − 3)(x − 5) = 0 gives x = 3 or x = 5, and indeed 3 + 5 = 8 and 3 × 5 = 15, so the answer is 3 and 5.
