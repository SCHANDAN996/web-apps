76. If x + 1/x = 5, then the value of x² + 1/x² is
(a) 25 (b) 21 (c) 27 (d) 23
Answer: (d)
Solution: The trap is squaring 5 directly to get 25, forgetting the cross term. Use (x + 1/x)² = x² + 1/x² + 2, so x² + 1/x² = 25 − 2 = 23, so the answer is 23.
Source: NCERT Class 9 Mathematics

77. If a + b = 10 and ab = 21, then the value of a³ + b³ is
(a) 370 (b) 400 (c) 330 (d) 430
Answer: (a)
Solution: Many students cube 10 to get 1000 and stop. Use a³ + b³ = (a + b)³ − 3ab(a + b) = 1000 − 3 × 21 × 10 = 1000 − 630 = 370, so the answer is 370.
Source: NCERT Class 9 Mathematics

78. If x − 1/x = 4, then the value of x² + 1/x² is
(a) 18 (b) 16 (c) 14 (d) 20
Answer: (a)
Solution: The trap is using the plus formula and subtracting 2, giving 14. For the minus form, (x − 1/x)² = x² + 1/x² − 2, so x² + 1/x² = 16 + 2 = 18, so the answer is 18.
Source: NCERT Class 9 Mathematics

79. If x² − 3x + 1 = 0, then the value of x³ + 1/x³ is
(a) 9 (b) 27 (c) 36 (d) 18
Answer: (d)
Solution: Dividing by x gives x + 1/x = 3. The trap is cubing 3 to get 27 directly. Use x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 27 − 9 = 18, so the answer is 18.
Source: NCERT Class 9 Mathematics

80. The factors of x² + 7x + 12 are
(a) (x − 3)(x − 4) (b) (x + 2)(x + 6) (c) (x + 3)(x + 4) (d) (x − 2)(x − 6)
Answer: (c)
Solution: The trap is choosing negative signs because factorisation is often practised with subtraction. We need two numbers with product 12 and sum 7, which are 3 and 4, both positive, so the answer is (x + 3)(x + 4).
Source: NCERT Class 8 Mathematics

81. If 2x + 3y = 12 and 3x + 2y = 13, then the value of x + y is
(a) 7 (b) 6 (c) 4 (d) 5
Answer: (d)
Solution: The trap is solving fully for x and y separately, wasting time. Adding the equations gives 5x + 5y = 25, so x + y = 5, so the answer is 5.
Source: NCERT Class 10 Mathematics

82. The sum of the roots of the equation 2x² − 8x + 6 = 0 is
(a) −4 (b) 3 (c) 4 (d) 8
Answer: (c)
Solution: The trap is reporting 8, the coefficient itself, ignoring the sign rule. Sum of roots = −(−8)/2 = 4, so the answer is 4.
Source: NCERT Class 10 Mathematics

83. The product of the roots of 3x² − 7x + 4 = 0 is
(a) 4/3 (b) 7/3 (c) −4/3 (d) 3/4
Answer: (a)
Solution: The trap is using 7/3, which is related to the sum, not the product. Product of roots = c/a = 4/3, so the answer is 4/3.
Source: NCERT Class 10 Mathematics

84. For what value of k does the equation x² + kx + 9 = 0 have equal roots?
(a) ±3 (b) ±6 (c) 6 only (d) 9
Answer: (b)
Solution: The trap is taking only +6 and forgetting the negative value. Equal roots need discriminant zero: k² − 36 = 0, so k = ±6, so the answer is ±6.
Source: NCERT Class 10 Mathematics

85. If a = 2 and b = 3, then the value of a³ − b³ is
(a) −19 (b) 19 (c) −1 (d) 1
Answer: (a)
Solution: The trap is computing 27 − 8 = 19 by swapping the order. Here a³ − b³ = 8 − 27 = −19, so the answer is −19.
Source: NCERT Class 9 Mathematics

86. If x + y = 7 and xy = 10, then the value of x² + y² is
(a) 39 (b) 49 (c) 29 (d) 59
Answer: (c)
Solution: The trap is squaring 7 to get 49 without subtracting 2xy. Use x² + y² = (x + y)² − 2xy = 49 − 20 = 29, so the answer is 29.
Source: NCERT Class 9 Mathematics

87. The remainder when x³ + 2x² − 5x + 3 is divided by (x − 1) is
(a) 1 (b) 3 (c) −1 (d) 0
Answer: (a)
Solution: The trap is assuming the remainder is zero because 1 is a "nice" number. By the Remainder Theorem, substitute x = 1: 1 + 2 − 5 + 3 = 1, so the answer is 1.
Source: NCERT Class 9 Mathematics

88. If (x − 2) is a factor of x³ − 4x² + kx − 4, then k equals
(a) 4 (b) −6 (c) 8 (d) 6
Answer: (d)
Solution: The trap is substituting x = −2 instead of x = 2. Substituting x = 2: 8 − 16 + 2k − 4 = 0 gives 2k = 12, so k = 6, so the answer is 6.
Source: NCERT Class 9 Mathematics

89. The value of (103)² using algebraic identity is
(a) 10690 (b) 10609 (c) 10069 (d) 10906
Answer: (b)
Solution: The trap is misplacing digits while adding. Use (100 + 3)² = 10000 + 600 + 9 = 10609, so the answer is 10609.
Source: NCERT Class 8 Mathematics

90. If x = 3 + 2√2, then the value of √x − 1/√x is
(a) √2 (b) 2 (c) 4 (d) 2√2
Answer: (b)
Solution: The trap is computing √x + 1/√x = 2√2, which is the plus version. Here x = (√2 + 1)², so √x = √2 + 1 and 1/√x = √2 − 1; their difference is 2, so the answer is 2.
Source: NCERT Class 9 Mathematics

91. The solution of 5x − 3 = 3x + 7 is
(a) −5 (b) 2 (c) 10 (d) 5
Answer: (d)
Solution: The trap is adding 3x to both sides by mistake, giving a wrong coefficient. Rearranging: 5x − 3x = 7 + 3, so 2x = 10 and x = 5, so the answer is 5.
Source: NCERT Class 8 Mathematics

92. If 2^(x+1) = 32, then x equals
(a) 6 (b) 5 (c) 4 (d) 3
Answer: (c)
Solution: The trap is answering 5, which is the power of 2 that gives 32, forgetting the +1 shift. Since 32 = 2⁵, x + 1 = 5, so x = 4, so the answer is 4.
Source: NCERT Class 9 Mathematics

93. The quadratic equation whose roots are 3 and −5 is
(a) x² − 2x − 15 = 0 (b) x² + 2x − 15 = 0 (c) x² + 2x + 15 = 0 (d) x² − 2x + 15 = 0
Answer: (b)
Solution: The trap is writing x² − 2x − 15 by miscomputing the sum. Sum of roots = −2 and product = −15, so the equation is x² − (sum)x + product = x² + 2x − 15 = 0, so the answer is x² + 2x − 15 = 0.
Source: NCERT Class 10 Mathematics

94. If a/b = 3/4, then the value of (4a + 3b)/(4a − 3b) is
(a) 4 (b) 2 (c) 3 (d) undefined
Answer: (d)
Solution: The trap is rushing to compute a finite ratio like 4. Since a/b = 3/4, we get 4a = 3b, so the denominator 4a − 3b = 0 and division by zero is not allowed, so the answer is undefined.
Source: NCERT Class 10 Mathematics

95. The value of (x + 2)(x − 2)(x² + 4) is
(a) x⁴ − 16 (b) x⁴ + 16 (c) x⁴ − 8x² + 16 (d) x² − 16
Answer: (a)
Solution: The trap is expanding fully and landing on x⁴ − 8x² + 16, which is (x² − 4)². Here (x + 2)(x − 2) = x² − 4, then (x² − 4)(x² + 4) = x⁴ − 16, so the answer is x⁴ − 16.
Source: NCERT Class 9 Mathematics

96. If x + 1/x = 2, then the value of x¹⁰⁰ + 1/x¹⁰⁰ is
(a) 2¹⁰⁰ (b) 100 (c) 2 (d) 0
Answer: (c)
Solution: The trap is trying to compute huge powers. From x + 1/x = 2 we get (x − 1)² = 0, so x = 1, and 1 + 1 = 2, so the answer is 2.
Source: NCERT Class 9 Mathematics

97. The HCF of x² − 9 and x² − 6x + 9 is
(a) (x + 3) (b) (x − 3)² (c) (x − 3) (d) (x² − 9)
Answer: (c)
Solution: The trap is picking (x − 3)², confusing HCF with LCM. Factorising: x² − 9 = (x − 3)(x + 3) and x² − 6x + 9 = (x − 3)²; the common factor is only (x − 3), so the answer is (x − 3).
Source: NCERT Class 10 Mathematics

98. If x + 2y = 7 and 3x − 2y = 5, then x equals
(a) 2 (b) 3 (c) 4 (d) 5
Answer: (b)
Solution: The trap is a sign slip while eliminating y, such as subtracting the equations and getting a wrong coefficient. Adding the two equations cancels 2y: 4x = 12, so x = 3 (and y = 2 satisfies both), so the answer is 3.
Source: NCERT Class 10 Mathematics

99. If a² + b² = 25 and ab = 12, then (a + b)² equals
(a) 25 (b) 49 (c) 37 (d) 61
Answer: (b)
Solution: The trap is answering 25, forgetting the 2ab term. (a + b)² = a² + b² + 2ab = 25 + 24 = 49, so the answer is 49.
Source: NCERT Class 9 Mathematics

100. The discriminant of 2x² − 4x + 3 = 0 is
(a) −8 (b) 8 (c) 40 (d) −40
Answer: (a)
Solution: The trap is computing 16 + 24 = 40 by adding instead of subtracting. Discriminant = b² − 4ac = 16 − 24 = −8, so the roots are not real, so the answer is −8.
Source: NCERT Class 10 Mathematics
