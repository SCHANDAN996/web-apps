# 🪄 प्रतिशत की शॉर्ट ट्रिक्स (Short Tricks)

---

┌─────────────────────────────────────────┐
│ **ट्रिक 1: "बटा सौ, गुणा सौ"**           │
│ भिन्न → प्रतिशत: ×100                     │
│ प्रतिशत → भिन्न: ÷100                     │
│ याद रखें: **"प्रतिशत आए तो सौ से भाग,     │
│ प्रतिशत बनाएँ तो सौ से गुणा"**             │
│ जैसे: 3/4 = 3/4 × 100 = 75%              │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 2: भिन्न-प्रतिशत की "पहाड़ा-टेबल"** │
│ 1/2=50%, 1/3=33.33%, 1/4=25%, 1/5=20%,   │
│ 1/6=16.66%, 1/8=12.5%, 1/10=10%,         │
│ 1/12=8.33%, 1/15=6.66%, 1/20=5%          │
│ म्नेमोनिक: **"आधा-तिहाई-चौथाई, पाँचवाँ-    │
│ छठा-आठवाँ — सौ में बाँटो, काम आसान"**      │
│ 1/7 = 14.28% और 1/14 = 7.14% (आधा-दुगुना)│
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 3: "ऊपर-नीचे उल्टा नियम"**        │
│ A, B से x% ज़्यादा है →                    │
│ B, A से कम है = x/(100+x) × 100%          │
│ A, B से x% कम है →                         │
│ B, A से ज़्यादा है = x/(100−x) × 100%      │
│ याद रखें: **"ज़्यादा में जोड़, कम में घटा —  │
│ हर में 100 के साथ वही खेल"**               │
│ जैसे: 25% ज़्यादा → 25/125 = 20% कम        │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 4: "a + b + ab/100" — चक्रवृद्धि  │
│ का भाई**                                   │
│ दो क्रमिक परिवर्तन a% और b% का कुल प्रभाव: │
│ **a + b + ab/100**                         │
│ म्नेमोनिक: **"जोड़ो, फिर गुणा-सौ जोड़ो"**  │
│ घटावट हो तो चिह्न ऋणात्मक लें।             │
│ जैसे: +20%, −10% → 20−10−2 = +8%          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 5: "वर्ग-घन की वृद्धि"**          │
│ भुजा x% बढ़े → क्षेत्रफल ≈ (2x + x²/100)% │
│ भुजा x% बढ़े → आयतन ≈ (3x + 3x²/100 +    │
│ x³/10000)%                                 │
│ छोटे x के लिए: **क्षेत्रफल ≈ 2x, आयतन ≈ 3x**│
│ म्नेमोनिक: **"दो-दूनी-तीन — विमा जितनी,    │
│ गुणक उतना"** (1D→x, 2D→2x, 3D→3x)         │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 6: "लाभ-हानि का CP-100 खेल"**     │
│ लाभ% = (SP−CP)/CP × 100                    │
│ हानि% = (CP−SP)/CP × 100                   │
│ म्नेमोनिक: **"नीचे हमेशा क्रय (CP),        │
│ ऊपर अंतर, गुणा सौ"**                       │
│ CP = "Cost Price = Comparison Point"      │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 7: "बराबर लाभ-हानि = हमेशा हानि"**│
│ दो वस्तुएँ एक ही SP पर — एक पर x% लाभ,     │
│ दूसरी पर x% हानि → कुल मिलाकर हमेशा हानि:  │
│ **हानि% = x²/100**                         │
│ म्नेमोनिक: **"समान प्रतिशत, समान विक्रय —  │
│ वर्ग बटा सौ, हानि निश्चय"**                │
│ जैसे: x=10 → हानि = 1%                    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 8: "छूट का सीधा घटाव नहीं"**      │
│ दो क्रमिक छूटें d₁% और d₂% →              │
│ समतुल्य छूट = d₁ + d₂ − d₁d₂/100           │
│ म्नेमोनिक: **"छूट जोड़ो, गुणनफल-सौ घटाओ"** │
│ (ट्रिक 4 का उल्टा रूप — चिह्न उलटे)        │
│ जैसे: 20% + 10% = 20+10−2 = 28%           │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 9: "जनसंख्या का घातांक"**         │
│ r% वार्षिक वृद्धि पर n वर्ष बाद:           │
│ P(1 + r/100)ⁿ                              │
│ n वर्ष पहले: P/(1 + r/100)ⁿ                │
│ म्नेमोनिक: **"आगे गुणा, पीछे भाग —         │
│ घात में वर्ष, कोष्टक में दर"**             │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 10: "खर्च स्थिर, कीमत बढ़ी"**     │
│ कीमत x% बढ़े और खर्च वही रखना हो →        │
│ खपत कम करें = x/(100+x) × 100%             │
│ म्नेमोनिक: **"महँगाई आए, हर में जोड़ जाए"** │
│ जैसे: 25% महँगाई → 25/125 = 20% कम खपत    │
│ (ट्रिक 3 की बहन — दोनों साथ याद करें)      │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 11: "10% = दशमलव एक कदम बाएँ"**   │
│ किसी संख्या का 10% → दशमलव एक स्थान बाएँ।  │
│ 5% = 10% का आधा; 1% = दो स्थान बाएँ;      │
│ 15% = 10% + 5%                             │
│ जैसे: 480 का 15% = 48 + 24 = 72            │
│ म्नेमोनिक: **"दस-पाँच-एक, जोड़-घटा ट्रिक"**│
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 12: "a% of b = b% of a"**         │
│ 8% of 25 = 25% of 8 = 2                    │
│ कठिन प्रतिशत को उलट दें — आसान बन जाएगा!   │
│ म्नेमोनिक: **"प्रतिशत का उलटफेर —          │
│ गुणा में कोई फेर नहीं"**                   │
│ जैसे: 36% of 50 = 50% of 36 = 18          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 13: "अंकित मूल्य का उल्टा खेल"**  │
│ छूट d% देकर भी लाभ p% चाहिए →              │
│ MP/CP = (100+p)/(100−d)                    │
│ म्नेमोनिक: **"लाभ ऊपर जुड़ा, छूट नीचे      │
│ घटी — अंकित-क्रय का अनुपात बनी"**          │
│ जैसे: 20% छूट, 25% लाभ → MP/CP = 125/80   │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 14: "मिश्रण में प्रतिशत —          │
│ कुल पर ही टिका"**                          │
│ मिश्रण में x% दूध → दूध = x/100 × कुल मिश्रण│
│ पानी मिलाएँ तो दूध की मात्रा अपरिवर्तित!    │
│ म्नेमोनिक: **"जो न मिले, वही अचल —         │
│ उसी को बराबर करो, बाकी हल"**               │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ **ट्रिक 15: "परीक्षा पास-फेल का अंतर      │
│ नियम"**                                    │
│ दो छात्रों के अंकों का अंतर ÷ पास% का अंतर │
│ = पूर्णांक (कुल अंक)                        │
│ म्नेमोनिक: **"अंक-अंतर बटा प्रतिशत-अंतर,   │
│ निकल आया पूरा पेपर"**                      │
│ जैसे: अंतर 30 अंक, प्रतिशत-अंतर 10% →     │
│ कुल = 30/10 × 100 = 300 अंक                │
└─────────────────────────────────────────┘
