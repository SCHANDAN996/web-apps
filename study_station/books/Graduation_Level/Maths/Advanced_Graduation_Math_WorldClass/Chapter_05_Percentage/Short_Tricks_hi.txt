# प्रतियोगी परीक्षा शॉर्ट ट्रिक्स: प्रतिशत

1. मानक भिन्न तालिका:
   - 1/6 = 16.67%, 1/7 = 14.28%, 1/8 = 12.5%, 1/9 = 11.11%
   - 1/11 = 9.09%, 1/12 = 8.33%, 1/14 = 7.14%, 1/16 = 6.25%

2. घटा हुआ मूल्य सीधा सूत्र:
   जब r% की कमी से T रुपये में k किग्रा अधिक वस्तु मिले:
   - घटा हुआ मूल्य = (T का r%) / k
   - प्रारंभिक मूल्य = घटा हुआ मूल्य / (1 - r/100)

3. आय-व्यय एलीगेशन शॉर्टकट:
   व्यय : बचत = (बचत वृद्धि - आय वृद्धि) : (आय वृद्धि - व्यय वृद्धि)

4. गुणनफल स्थिरता (AB नियम):
   मूल्य में +1/n वृद्धि => खपत में -1/(n + 1) कमी।
   मूल्य में -1/n कमी => खपत में +1/(n - 1) वृद्धि।
