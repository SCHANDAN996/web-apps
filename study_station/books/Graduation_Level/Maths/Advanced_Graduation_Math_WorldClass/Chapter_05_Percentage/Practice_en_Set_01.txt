Q1. (Easy) Convert the fraction 7/16 into its percentage equivalent.
(A) 43.75%  (B) 42.50%  (C) 44.25%  (D) 41.75%

Answer: (A)

Solution:
(7 / 16) * 100% = 700 / 16% = 43.75%. Therefore, the correct value is 43.75%, corresponding to option (A).

Q4. (Easy) If 25% of a number x is 75, what is 80% of the same number x?
(A) 200  (B) 260  (C) 220  (D) 240

Answer: (D)

Solution:
Since 25% of x is 75, the number x is 75 * 4 = 300. Thus 80% of 300 = 300 * 0.8 = 240. Therefore, the correct value is 240, corresponding to option (D).

Q5. (Easy) The salary of an employee is increased from Rs 24,000 to Rs 30,000. Find the percentage increase in salary.
(A) 25%  (B) 20%  (C) 30%  (D) 24%

Answer: (A)

Solution:
Increase = 30,000 - 24,000 = 6,000. Percentage increase = (6,000 / 24,000) * 100% = (1/4) * 100% = 25%. Psychological Trap: A common error is taking the increased salary Rs 30,000 as the denominator yielding 20% instead of the original base 24,000. Therefore, the correct value is 25%, corresponding to option (A).

Source: SSC CGL Pattern

Q15. (Easy) If 60% of (x - y) = 40% of (x + y), find the ratio of x to y.
(A) 3 : 2  (B) 5 : 2  (C) 5 : 1  (D) 4 : 1

Answer: (C)

Solution:
60*(x - y) = 40*(x + y) => 3(x - y) = 2(x + y) => 3x - 3y = 2x + 2y => x = 5y => x / y = 5 / 1. Therefore, the correct value is 5 : 1, corresponding to option (C).

Q23. (Easy) If x% of y is 100 and y% of z is 200, find the relation between x and z.
(A) x = 2z  (B) z = x  (C) z = 2x  (D) z = 4x

Answer: (C)

Solution:
(x * y) / 100 = 100 and (y * z) / 100 = 200. Dividing the second equation by the first: (y*z) / (x*y) = 200 / 100 => z / x = 2 => z = 2x. Therefore, the correct value is z = 2x, corresponding to option (C).

Source: SSC CGL Pattern

Q24. (Easy) A number is increased by 10% and then decreased by 10%. What is the net percentage change in the number?
(A) No change  (B) 1% increase  (C) 2% decrease  (D) 1% decrease

Answer: (D)

Solution:
Net change = a + b + (ab / 100) = 10 - 10 + (10 * (-10) / 100) = -1%. Hence, 1% decrease. Psychological Trap: Many students incorrectly believe that an equal percentage increase followed by a decrease results in zero change. Therefore, the correct value is 1% decrease, corresponding to option (D).

Source: SSC CGL Pattern
