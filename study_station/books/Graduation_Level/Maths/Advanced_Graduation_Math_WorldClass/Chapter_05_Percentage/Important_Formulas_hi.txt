# महत्वपूर्ण सूत्र: प्रतिशत

1. गुणक संबंध:
   - r% वृद्धि के बाद मान = प्रारंभिक * (1 + r/100)
   - r% कमी के बाद मान = प्रारंभिक * (1 - r/100)

2. क्रमिक प्रतिशत परिवर्तन:
   शुद्ध % परिवर्तन = a + b + (ab / 100) %

3. गुणनफल स्थिरता नियम:
   - मूल्य में +a/b वृद्धि => खपत में -a/(b + a) कमी
   - मूल्य में -a/b कमी => खपत में +a/(b - a) वृद्धि

4. समान प्रतिशत वृद्धि एवं कमी:
   पहले x% वृद्धि फिर x% कमी => सदैव कमी = (x^2 / 100)%

5. जनसंख्या वृद्धि / अवमूल्यन:
   - n वर्ष बाद जनसंख्या = P * (1 + r/100)^n
   - n वर्ष पूर्व जनसंख्या = P / (1 + r/100)^n

6. आय-व्यय-बचत प्रतिशत संबंध:
   आय में % वृद्धि * आय = (व्यय में % वृद्धि * व्यय) + (बचत में % वृद्धि * बचत)

7. चुनाव जीत अंतर:
   अंतर = (विजेता% - पराजित%) * वैध मत = (2 * विजेता% - 100)% * वैध मत
