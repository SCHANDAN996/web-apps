# महत्वपूर्ण सूत्र — द्विघात समीकरण एवं श्रेणी

## 1. द्विघात समीकरण (Quadratic Equations)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| मानक रूप | ax² + bx + c = 0 (a ≠ 0) | पहचान: a, b, c निकालना |
| मूलों का सूत्र (श्रीधराचार्य) | x = [−b ± √(b² − 4ac)] / 2a | सीधे मूल निकालने में |
| विविक्तकर (Discriminant) | D = b² − 4ac | मूलों की प्रकृति जाँचने में |
| वास्तविक व असमान मूल | D > 0 | दो अलग-अलग मूल |
| वास्तविक व समान मूल | D = 0 | x = −b/2a |
| काल्पनिक मूल | D < 0 | संयुग्मी सम्मिश्र युग्म |
| परिमेय मूलों की शर्त | D पूर्ण वर्ग संख्या हो (a, b, c परिमेय हों) | परिमेय मूलों की जाँच |
| मूलों का योग | α + β = −b/a | बिना हल किए योग |
| मूलों का गुणनफल | αβ = c/a | बिना हल किए गुणनफल |
| समीकरण बनाना | x² − (α+β)x + αβ = 0 | मूल दिए हों तो |
| मूलों का अंतर | \|α − β\| = √D / \|a\| | अंतर सीधे निकालने में |
| α² + β² | (α + β)² − 2αβ | वर्गों का योग |
| α³ + β³ | (α + β)³ − 3αβ(α + β) | घनों का योग |
| 1/α + 1/β | (α + β)/αβ | व्युत्क्रमों का योग |
| उभयनिष्ठ मूल (एक) | (a₁c₂ − a₂c₁)² = (b₁c₂ − b₂c₁)(a₁b₂ − a₂b₁) | दो समीकरणों में एक समान मूल |
| दोनों मूल उभयनिष्ठ | a₁/a₂ = b₁/b₂ = c₁/c₂ | अनुपात समान होने पर |
| चिह्न नियम: दोनों मूल धनात्मक | α+β > 0 और αβ > 0 | मूलों के चिह्न पहचानने में |
| चिह्न नियम: विपरीत चिह्न | αβ < 0 | एक धन, एक ऋण मूल |

## 2. समांतर श्रेणी (AP)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| nवाँ पद | aₙ = a + (n − 1)d | कोई भी पद निकालने में |
| सार्व अंतर | d = a₂ − a₁ | श्रेणी AP है या नहीं, जाँच |
| प्रथम n पदों का योग | Sₙ = n/2 [2a + (n − 1)d] | योग निकालने में |
| योग (प्रथम-अंतिम पद से) | Sₙ = n/2 (a + l) | अंतिम पद ज्ञात हो तो |
| nवाँ पद योग से | aₙ = Sₙ − Sₙ₋₁ | Sₙ दिया हो तो पद निकालना |
| समांतर माध्य | A = (a + b)/2 | दो संख्याओं के बीच |
| n पदों का योग (विषम n) | Sₙ = n × मध्य पद | त्वरित योग |
| AP में m, n पदों से | d = (aₘ − aₙ)/(m − n) | d सीधे निकालना |

## 3. गुणोत्तर श्रेणी (GP)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| nवाँ पद | aₙ = arⁿ⁻¹ | कोई भी पद निकालने में |
| सार्व अनुपात | r = a₂/a₁ | GP जाँच |
| प्रथम n पदों का योग (r ≠ 1) | Sₙ = a(rⁿ − 1)/(r − 1), r > 1 | योग, r > 1 |
| योग (r < 1) | Sₙ = a(1 − rⁿ)/(1 − r) | योग, r < 1 |
| अनंत GP का योग | S∞ = a/(1 − r), \|r\| < 1 | अनंत श्रेणी |
| गुणोत्तर माध्य | G = √(ab) | दो धन संख्याओं के बीच |
| तीन पद GP में | a/r, a, ar | तीन पद मानने की तरकीब |
| चार पद GP में | a/r³, a/r, ar, ar³ | चार पद मानने की तरकीब |

## 4. हरात्मक श्रेणी (HP)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| HP की परिभाषा | व्युत्क्रम AP में हों | HP → AP में बदलकर हल |
| हरात्मक माध्य | H = 2ab/(a + b) | दो संख्याओं के बीच |
| AM–GM–HM संबंध | AM ≥ GM ≥ HM और G² = A × H | असमिका-आधारित प्रश्न |

## 5. विशेष श्रेणियों के योग

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| प्रथम n प्राकृत संख्याओं का योग | Σn = n(n + 1)/2 | आधारभूत योग |
| वर्गों का योग | Σn² = n(n + 1)(2n + 1)/6 | वर्ग-श्रेणी |
| घनों का योग | Σn³ = [n(n + 1)/2]² | घन-श्रेणी |
| प्रथम n विषम संख्याओं का योग | n² | त्वरित योग |
| प्रथम n सम संख्याओं का योग | n(n + 1) | त्वरित योग |
| अंकगणितीय-गुणोत्तर श्रेणी (AGP) | S∞ = a/(1−r) + dr/(1−r)² | अनंत AGP, \|r\| < 1 |
