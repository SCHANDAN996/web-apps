1. x के सापेक्ष f(x) = x³ का अवकलज क्या है?
(a) 3x (b) x² (c) 3x² (d) x³/3
उत्तर: (c)
हल: घात नियम से, d/dx(xⁿ) = n·xⁿ⁻¹। यहाँ n = 3 है, इसलिए अवकलज 3x² है। विकल्प x³/3 जाल है — वह x² का समाकलन है, x³ का अवकलज नहीं, इसलिए उत्तर 3x² है।
स्रोत: NCERT कक्षा 11 गणित (सीमा और अवकलज)

2. अचर फलन f(x) = 7 का अवकलज क्या है?
(a) 7 (b) 1 (c) 0 (d) 7x
उत्तर: (c)
हल: अचर बदलता नहीं, इसलिए उसका परिवर्तन की दर शून्य है: d/dx(7) = 0। विकल्प 7 जाल है — विद्यार्थी फलन के मान को उसके अवकलज से भ्रमित करते हैं, इसलिए उत्तर 0 है।
स्रोत: NCERT कक्षा 11 गणित (सीमा और अवकलज)

3. ∫ 2x dx क्या है?
(a) 2x² + C (b) x² + C (c) 2 + C (d) x²/2 + C
उत्तर: (b)
हल: ∫ 2x dx = 2·(x²/2) + C = x² + C। विकल्प 2 जाल है — वह 2x का अवकलज है, समाकलन नहीं, इसलिए उत्तर x² + C है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

4. sin x का अवकलज क्या है?
(a) cos x (b) −cos x (c) −sin x (d) tan x
उत्तर: (a)
हल: d/dx(sin x) = cos x, यह एक मानक परिणाम है। विकल्प −cos x जाल है — वह cos x का अवकलज है जिसमें चिह्न की चूक है, इसलिए उत्तर cos x है।
स्रोत: NCERT कक्षा 11 गणित (सीमा और अवकलज)

5. cos x का अवकलज क्या है?
(a) sin x (b) −sin x (c) cos x (d) −cos x
उत्तर: (b)
हल: d/dx(cos x) = −sin x। विकल्प sin x जाल है — इसमें कोसाइन के अवकलन पर आने वाला ऋणात्मक चिह्न छूट जाता है, इसलिए उत्तर −sin x है।
स्रोत: NCERT कक्षा 11 गणित (सीमा और अवकलज)

6. eˣ का अवकलज क्या है?
(a) x·eˣ⁻¹ (b) eˣ/x (c) ln x (d) eˣ
उत्तर: (d)
हल: चरघातांकी फलन eˣ स्वयं का अवकलज होता है: d/dx(eˣ) = eˣ। विकल्प x·eˣ⁻¹ जाल है — इसमें चरघातांकी फलन पर घात नियम गलती से लगाया गया है, इसलिए उत्तर eˣ है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

7. ln x (x > 0) का अवकलज क्या है?
(a) 1/x (b) x (c) ln x (d) eˣ
उत्तर: (a)
हल: d/dx(ln x) = 1/x। विकल्प ln x जाल है — यह फलन को उसके अवकलज से भ्रमित करता है, इसलिए उत्तर 1/x है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

8. lim(x→0) (sin x)/x क्या है?
(a) 1 (b) 0 (c) ∞ (d) अस्तित्व में नहीं
उत्तर: (a)
हल: यह मानक सीमा lim(x→0) (sin x)/x = 1 है (x रेडियन में)। विकल्प 0 जाल है — यह अंश में x = 0 रखने से आता है और यह नज़रअंदाज़ करता है कि हर भी 0 की ओर जाता है, इसलिए उत्तर 1 है।
स्रोत: NCERT कक्षा 11 गणित (सीमा और अवकलज)

9. ∫ (1/x) dx (x > 0) क्या है?
(a) ln x + C (b) 1/x² + C (c) eˣ + C (d) x·ln x + C
उत्तर: (a)
हल: चूँकि d/dx(ln x) = 1/x, समाकलन से ∫ (1/x) dx = ln x + C मिलता है। विकल्प 1/x² + C जाल है — यह x⁻¹ पर घात नियम के गलत प्रयोग से आता है, इसलिए उत्तर ln x + C है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

10. x²·sin x का अवकलज क्या है?
(a) 2x·sin x + x²·cos x (b) 2x·cos x (c) x²·cos x (d) 2x·sin x
उत्तर: (a)
हल: गुणन नियम से, d/dx(uv) = u′v + uv′: अवकलज = 2x·sin x + x²·cos x। विकल्प 2x·cos x जाल है — इसमें दोनों गुणकों का अवकलन करके गुणा किया गया है, जो गुणन नियम नहीं है, इसलिए उत्तर 2x·sin x + x²·cos x है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

11. n ≠ −1 के लिए ∫ xⁿ dx क्या है?
(a) n·xⁿ⁻¹ + C (b) xⁿ⁺¹/(n+1) + C (c) xⁿ⁻¹ + C (d) (n+1)·xⁿ⁺¹ + C
उत्तर: (b)
हल: समाकलन का घात नियम: ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C, जो n ≠ −1 के लिए मान्य है। विकल्प n·xⁿ⁻¹ + C जाल है — वह अवकलन का नियम है, समाकलन का नहीं, इसलिए उत्तर xⁿ⁺¹/(n+1) + C है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

12. यदि f(x) = x², तो f′(3) क्या है?
(a) 9 (b) 12 (c) 3 (d) 6
उत्तर: (d)
हल: f′(x) = 2x, इसलिए f′(3) = 2 × 3 = 6। विकल्प 9 जाल है — वह f(3) है, अर्थात् फलन का मान, उसका अवकलज नहीं, इसलिए उत्तर 6 है।
स्रोत: NCERT कक्षा 11 गणित (सीमा और अवकलज)

13. tan x का अवकलज क्या है?
(a) cot x (b) sec x·tan x (c) cosec²x (d) sec²x
उत्तर: (d)
हल: d/dx(tan x) = sec²x। विकल्प sec x·tan x जाल है — वह sec x का अवकलज है, tan x का नहीं, इसलिए उत्तर sec²x है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

14. ∫ eˣ dx क्या है?
(a) x·eˣ⁻¹ + C (b) eˣ + C (c) eˣ/x + C (d) ln x + C
उत्तर: (b)
हल: चूँकि d/dx(eˣ) = eˣ, हमें ∫ eˣ dx = eˣ + C मिलता है। विकल्प x·eˣ⁻¹ + C जाल है — इसमें चरघातांकी पर घात नियम का गलत प्रयोग है, इसलिए उत्तर eˣ + C है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

15. lim(x→0) (eˣ − 1)/x क्या है?
(a) 1 (b) e (c) 0 (d) ∞
उत्तर: (a)
हल: यह मानक सीमा 1 के बराबर है, क्योंकि eˣ = 1 + x + x²/2! + …, इसलिए (eˣ − 1)/x → 1। विकल्प e जाल है — विद्यार्थी eˣ को संख्या e से जोड़कर बिना प्रसार किए उसे चुन लेते हैं, इसलिए उत्तर 1 है।
स्रोत: NCERT कक्षा 11 गणित (सीमा और अवकलज)

16. x⁵ का अवकलज क्या है?
(a) x⁴ (b) 4x⁵ (c) 5x⁴ (d) 5x⁵
उत्तर: (c)
हल: घात नियम से, d/dx(x⁵) = 5x⁴। विकल्प x⁴ जाल है — इसमें घात तो घटा दी गई पर घातांक 5 से गुणा करना भूल गए, इसलिए उत्तर 5x⁴ है।
स्रोत: NCERT कक्षा 11 गणित (सीमा और अवकलज)

17. ∫ cos x dx क्या है?
(a) −sin x + C (b) tan x + C (c) −cos x + C (d) sin x + C
उत्तर: (d)
हल: चूँकि d/dx(sin x) = cos x, हमें ∫ cos x dx = sin x + C मिलता है। विकल्प −sin x + C जाल है — यह इसे cos x के अवकलज से भ्रमित करता है, इसलिए उत्तर sin x + C है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

18. किसी बिंदु पर फलन का अवकलज बताता है:
(a) वक्र के नीचे का क्षेत्रफल (b) उस बिंदु पर स्पर्श रेखा की ढलान (c) फलन का अधिकतम मान (d) वक्र की लंबाई
उत्तर: (b)
हल: ज्यामितीय रूप से, f′(a) वक्र y = f(x) पर x = a बिंदु पर स्पर्श रेखा की ढलान है। विकल्प "वक्र के नीचे का क्षेत्रफल" जाल है — वह निश्चित समाकलन देता है, इसलिए उत्तर उस बिंदु पर स्पर्श रेखा की ढलान है।
स्रोत: NCERT कक्षा 12 गणित (अवकलज के अनुप्रयोग)

19. x ≠ 0 के लिए (x² + 1)/(x) का अवकलज क्या है?
(a) 2x (b) 1 + 1/x² (c) 1 − 1/x² (d) 1/x²
उत्तर: (c)
हल: पहले सरल करें: (x² + 1)/x = x + 1/x। फिर d/dx = 1 − 1/x²। विकल्प 1 + 1/x² जाल है — इसमें यह भूल गए कि d/dx(1/x) = −1/x² में ऋणात्मक चिह्न आता है, इसलिए उत्तर 1 − 1/x² है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

20. ∫₀¹ x dx क्या है?
(a) 1 (b) 1/4 (c) 2 (d) 1/2
उत्तर: (d)
हल: ∫₀¹ x dx = [x²/2]₀¹ = 1/2 − 0 = 1/2। विकल्प 1 जाल है — यह बिना समाकलन किए x = 1 पर x का मान रखने से आता है, इसलिए उत्तर 1/2 है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

21. sin(2x) का अवकलज क्या है?
(a) cos(2x) (b) 2sin(2x) (c) 2cos(2x) (d) −2cos(2x)
उत्तर: (c)
हल: शृंखला नियम से, d/dx(sin(2x)) = cos(2x) × d/dx(2x) = 2cos(2x)। विकल्प cos(2x) जाल है — इसमें आंतरिक फलन 2x के अवकलज से गुणा करना भूल गए, इसलिए उत्तर 2cos(2x) है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

22. ∫ x·eˣ dx क्या है?
(a) eˣ + C (b) eˣ(x + 1) + C (c) x·eˣ + C (d) eˣ(x − 1) + C
उत्तर: (d)
हल: खंडशः समाकलन से, u = x, dv = eˣdx लेने पर: ∫ x·eˣ dx = x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C = eˣ(x − 1) + C। विकल्प eˣ(x + 1) + C जाल है — इसमें दूसरे समाकलन की गलत हैंडलिंग से चिह्न गलत है, इसलिए उत्तर eˣ(x − 1) + C है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

23. f(x) = x³ − 3x के लिए स्थानीय उच्चिष्ठ (local maximum) किस पर होता है?
(a) x = −1 (b) x = 1 (c) x = 0 (d) x = 3
उत्तर: (a)
हल: f′(x) = 3x² − 3 = 0 से x = ±1 मिलता है। f″(x) = 6x: x = −1 पर, f″(−1) = −6 < 0, इसलिए x = −1 स्थानीय उच्चिष्ठ है; x = 1 पर, f″(1) = 6 > 0, यह निम्निष्ठ है। विकल्प x = 1 जाल है — वह स्थानीय निम्निष्ठ है, उच्चिष्ठ नहीं, इसलिए उत्तर x = −1 है।
स्रोत: NCERT कक्षा 12 गणित (अवकलज के अनुप्रयोग)

24. lim(x→0) (1 − cos x)/x² क्या है?
(a) 0 (b) 1/2 (c) 1 (d) 2
उत्तर: (b)
हल: 1 − cos x = 2sin²(x/2) का प्रयोग करने पर सीमा lim 2sin²(x/2)/x² = 2 × (1/2)² = 1/2 बनती है। विकल्प 0 जाल है — x = 0 रखने पर 0/0 आता है, और अंश के प्रभावी होने का अनुमान गलत उत्तर देता है, इसलिए उत्तर 1/2 है।
स्रोत: NCERT कक्षा 11 गणित (सीमा और अवकलज)

25. ∫₀^(π/2) sin x dx क्या है?
(a) 0 (b) π/2 (c) 1 (d) −1
उत्तर: (c)
हल: ∫ sin x dx = −cos x, इसलिए ∫₀^(π/2) sin x dx = [−cos x]₀^(π/2) = −cos(π/2) + cos(0) = 0 + 1 = 1। विकल्प 0 जाल है — यह केवल cos(π/2) का मान रखने और निचली सीमा भूल जाने से आता है, इसलिए उत्तर 1 है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)
