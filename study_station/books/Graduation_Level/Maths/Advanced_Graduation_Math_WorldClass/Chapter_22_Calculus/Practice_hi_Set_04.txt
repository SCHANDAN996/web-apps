76. f(x) = x³ − 6x² + 9x + 1 का x = 2 पर अवकलज है
(a) 3 (b) 0 (c) −3 (d) 9
उत्तर: (c)
हल: लुभाने वाला गलत विकल्प 0 है, जो f′(x) = 0 रखकर क्रांतिक बिंदु (critical points) निकालने से मिलता है, जबकि x = 2 पर मान निकालना था। अवकलन करें: f′(x) = 3x² − 12x + 9। x = 2 पर: f′(2) = 12 − 24 + 9 = −3, इसलिए उत्तर −3 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 6

77. यदि y = e^(2x) · sin x, तो dy/dx बराबर है
(a) e^(2x)(sin x + 2 cos x) (b) e^(2x)(2 sin x + cos x) (c) 2e^(2x) · cos x (d) e^(2x)(2 sin x − cos x)
उत्तर: (b)
हल: लुभाने वाला गलत विकल्प 2e^(2x) · cos x है, जो प्रत्येक गुणनखंड को अलग-अलग अवकलित करके गुणा करता है — गुणन नियम की एक क्लासिक गलती। गुणन नियम से: dy/dx = 2e^(2x) · sin x + e^(2x) · cos x = e^(2x)(2 sin x + cos x), इसलिए उत्तर e^(2x)(2 sin x + cos x) है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

78. फलन f(x) = x³ − 3x का स्थानीय उच्चतम (local maximum) है
(a) x = 1 (b) x = 0 (c) x = −1 (d) x = 3
उत्तर: (c)
हल: लुभाने वाला गलत विकल्प x = 1 है, जो एक क्रांतिक बिंदु तो है पर वास्तव में स्थानीय निम्नतम है। f′(x) = 3x² − 3 = 0 से x = ±1 मिलता है। f″(x) = 6x; x = −1 पर, f″(−1) = −6 < 0, इसलिए x = −1 स्थानीय उच्चतम है, अतः उत्तर x = −1 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 6

79. ∫ (2x + 3)² dx बराबर है
(a) (2x + 3)³/3 + C (b) (2x + 3)³/2 + C (c) 2(2x + 3)³/3 + C (d) (2x + 3)³/6 + C
उत्तर: (d)
हल: लुभाने वाला गलत विकल्प (2x + 3)³/3 + C है, जो आंतरिक अवकलज 2 से भाग देना भूल जाता है। प्रतिस्थापन u = 2x + 3, du = 2dx से: ∫ u² (du/2) = u³/6 + C = (2x + 3)³/6 + C, इसलिए उत्तर (2x + 3)³/6 + C है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 7

80. ∫₀^(π/2) sin²x dx का मान है
(a) π/4 (b) π/2 (c) 1 (d) π
उत्तर: (a)
हल: लुभाने वाला गलत विकल्प π/2 है, जो उसी अंतराल पर ∫ sin x dx का मान है, sin²x का नहीं। sin²x = (1 − cos 2x)/2 का प्रयोग करें: समाकलन [x/2 − sin 2x/4] 0 से π/2 तक = π/4 − 0 = π/4, इसलिए उत्तर π/4 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 7

81. यदि y = ln(sin x), तो dy/dx बराबर है
(a) cot x (b) tan x (c) sec x (d) cosec x
उत्तर: (a)
हल: लुभाने वाला गलत विकल्प tan x है, जो cos x और sin x के अनुपात को उलटने से बनता है। शृंखला नियम से: dy/dx = (1/sin x) · cos x = cot x, इसलिए उत्तर cot x है।

82. वक्र y = x² − 4x + 5 के उस बिंदु पर स्पर्श रेखा की ढलान जहाँ x = 3 है, है
(a) 4 (b) 2 (c) 6 (d) 0
उत्तर: (b)
हल: लुभाने वाला गलत विकल्प 0 है, जो शीर्ष (x = 2) पर ढलान है, x = 3 पर नहीं। dy/dx = 2x − 4; x = 3 पर, ढलान = 6 − 4 = 2, इसलिए उत्तर 2 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 6

83. ∫ x · e^x dx बराबर है
(a) e^x(x + 1) + C (b) e^x(x − 1) + C (c) x·e^x + C (d) e^x + C
उत्तर: (b)
हल: लुभाने वाला गलत विकल्प e^x(x + 1) + C है, जो खंडशः समाकलन में चिह्न की चूक से आता है। u = x, dv = e^x dx लेने पर: ∫ x·e^x dx = x·e^x − ∫ e^x dx = x·e^x − e^x + C = e^x(x − 1) + C, इसलिए उत्तर e^x(x − 1) + C है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 7

84. f(x) = x² + 4x + 7 का न्यूनतम मान है
(a) 7 (b) 4 (c) 3 (d) 11
उत्तर: (c)

85. यदि y = x^x, तो dy/dx बराबर है
(a) x^x · ln x (b) x · x^(x−1) (c) x^x(1 + ln x) (d) x^(x−1)
उत्तर: (c)
हल: लुभाने वाला गलत विकल्प x · x^(x−1) है, जो चर घातांक पर घात नियम को गलत तरीके से लागू करता है। लघुगणक लें: ln y = x ln x, अतः y′/y = 1 + ln x, जिससे dy/dx = x^x(1 + ln x), इसलिए उत्तर x^x(1 + ln x) है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

90. यदि x = a cos θ और y = b sin θ, तो dy/dx बराबर है

उत्तर: (a)
हल: लुभाने वाला गलत विकल्प (b/a) tan θ है, जो cos θ के अवकलन से आने वाले ऋण चिह्न और अनुपात के उलटने — दोनों को भूल जाता है। dy/dθ = b cos θ, dx/dθ = −a sin θ, अतः dy/dx = (b cos θ)/(−a sin θ) = −(b/a) cot θ, इसलिए उत्तर −(b/a) cot θ है।
