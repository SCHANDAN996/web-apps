51. यदि y = x³ − 3x² + 5, तो x = 2 पर dy/dx है
(a) 0 (b) 4 (c) 5 (d) 8
उत्तर: (a)
हल: पद-दर-पद अवकलन करने पर: dy/dx = 3x² − 6x। x = 2 पर यह 3(4) − 6(2) = 12 − 12 = 0 है। लुभाने वाला गलत विकल्प 8 इसलिए आता है क्योंकि x = 2 को केवल x³ में रख दिया जाता है और अवकलन का चरण छूट जाता है। अतः उत्तर 0 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

52. x के सापेक्ष sin x · cos x का अवकलज है
(a) sin²x − cos²x (b) cos²x − sin²x (c) 2 sin x cos x (d) cos²x + sin²x
उत्तर: (b)
हल: गुणन नियम से, d/dx(sin x cos x) = cos x·cos x + sin x·(−sin x) = cos²x − sin²x। लुभाने वाला गलत विकल्प 2 sin x cos x, sin²x का अवकलज है, sin x cos x का नहीं। अतः उत्तर cos²x − sin²x है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

53. ∫(2x + 3) dx बराबर है
(a) 2x² + 3x + C (b) x² + 3x + C (c) x² + 3 + C (d) 2x + C
उत्तर: (b)
हल: पद-दर-पद समाकलन करने पर: ∫2x dx = x² और ∫3 dx = 3x, इसलिए परिणाम x² + 3x + C है। लुभाने वाले गलत विकल्प 2x² + 3x + C में 2x का समाकलन करते समय नई घात से भाग देना भूल गए हैं। अतः उत्तर x² + 3x + C है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 7

54. f(x) = 4x − x² का अधिकतम मान है
(a) 2 (b) 16 (c) 8 (d) 4
उत्तर: (d)
हल: f′(x) = 4 − 2x = 0 से x = 2 मिलता है, और f″(x) = −2 < 0 अधिकतम की पुष्टि करता है। तब f(2) = 8 − 4 = 4। लुभाने वाला गलत विकल्प 8 इसलिए आता है क्योंकि x = 2 पर केवल 4x निकाला गया और x² घटाया नहीं गया। अतः उत्तर 4 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 6

55. d/dx (e^x · ln x) बराबर है
(a) e^x ln x (b) e^x / x (c) e^x (ln x + 1/x) (d) e^x (ln x − 1/x)
उत्तर: (c)
हल: गुणन नियम से: e^x · ln x + e^x · (1/x) = e^x (ln x + 1/x)। लुभाने वाले गलत विकल्प e^x / x में केवल ln x का अवकलज रखा गया है और वह पद छोड़ दिया गया है जिसमें e^x, ln x से यथावत गुणित होता है। अतः उत्तर e^x (ln x + 1/x) है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

56. ∫₀¹ x² dx बराबर है
(a) 1/3 (b) 1/2 (c) 1 (d) 2/3
उत्तर: (a)
हल: प्रतिअवकलज x³/3 है। 0 से 1 तक मान रखने पर 1/3 − 0 = 1/3 मिलता है। लुभाने वाला गलत विकल्प 1/2, x²/2 लेने से आता है, जो x² का नहीं बल्कि x का प्रतिअवकलज है। अतः उत्तर 1/3 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 7

57. यदि y = (2x + 1)⁵, तो dy/dx है
(a) 10(2x + 1)⁴ (b) 5(2x + 1)⁴ (c) 5(2x + 1)⁴ · 2x (d) 10(2x + 1)⁵
उत्तर: (a)
हल: शृंखला नियम से, dy/dx = 5(2x + 1)⁴ · d/dx(2x + 1) = 5(2x + 1)⁴ · 2 = 10(2x + 1)⁴। लुभाने वाले गलत विकल्प 5(2x + 1)⁴ में आंतरिक अवकलज 2 से गुणा करना भूल गए हैं। अतः उत्तर 10(2x + 1)⁴ है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

58. वक्र y = x² − 4x + 3 के उस बिंदु पर स्पर्श-रेखा की प्रवणता जहाँ x = 3 है, होगी
(a) 2 (b) 0 (c) 3 (d) 6
उत्तर: (a)
हल: dy/dx = 2x − 4, और x = 3 पर यह 6 − 4 = 2 है। लुभाने वाला गलत विकल्प 0 इसलिए आता है क्योंकि x = 3 को मूल वक्र में रखने पर y = 9 − 12 + 3 = 0 मिलता है, जो बिंदु की ऊँचाई है, प्रवणता नहीं। अतः उत्तर 2 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 6

59. x > 0 के लिए ∫(1/x) dx बराबर है
(a) −1/x² + C (b) x ln x + C (c) ln x + C (d) 1/x² + C
उत्तर: (c)
हल: 1/x का समाकलन प्राकृतिक लघुगणक ln x + C होता है। लुभाने वाला गलत विकल्प −1/x² + C, 1/x² का समाकलन है, जो x⁻¹ पर घात नियम गलत तरीके से लगाने से आता है। अतः उत्तर ln x + C है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 7

60. फलन f(x) = x³ − 3x का स्थानीय निम्निष्ठ (local minimum) है
(a) x = −1 (b) x = 0 (c) x = 3 (d) x = 1
उत्तर: (d)
हल: f′(x) = 3x² − 3 = 0 से x = ±1 मिलता है। चूँकि f″(x) = 6x, इसलिए f″(1) = 6 > 0, अतः x = 1 स्थानीय निम्निष्ठ है, जबकि f″(−1) = −6 < 0 होने से x = −1 स्थानीय उच्चिष्ठ है। लुभाने वाला गलत विकल्प x = −1 उच्चिष्ठ बिंदु है — यही चिह्न का क्लासिक जाल है। अतः उत्तर x = 1 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 6

61. d/dx (tan x) बराबर है
(a) cot x (b) sec x tan x (c) sec²x (d) −cosec²x
उत्तर: (c)
हल: tan x = sin x / cos x लिखकर भागफल नियम लगाने पर (cos²x + sin²x)/cos²x = 1/cos²x = sec²x मिलता है। लुभाने वाला गलत विकल्प sec x tan x, tan x का नहीं बल्कि sec x का अवकलज है। अतः उत्तर sec²x है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

62. ∫₀^(π/2) sin x dx बराबर है
(a) 0 (b) π/2 (c) 1 (d) −1
उत्तर: (c)
हल: प्रतिअवकलज −cos x है। मान रखने पर: −cos(π/2) − (−cos 0) = 0 + 1 = 1। लुभाने वाला गलत विकल्प −1, sin x के प्रतिअवकलज में ऋण चिह्न गिरा देने से आता है। अतः उत्तर 1 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 7

63. यदि y = x^x (x > 0), तो dy/dx बराबर है
(a) x · x^(x−1) (b) x^x / x (c) x^x ln x (d) x^x (1 + ln x)
उत्तर: (d)
हल: लघुगणक लेने पर: ln y = x ln x। अवकलन करने पर: y′/y = ln x + 1, अतः y′ = x^x (1 + ln x)। लुभाने वाले गलत विकल्प x · x^(x−1) में घात नियम गलत तरीके से लगाया गया है, जबकि उसके लिए घात का अचर होना ज़रूरी है। अतः उत्तर x^x (1 + ln x) है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

64. y = x, x-अक्ष, x = 0 और x = 4 से घिरा क्षेत्रफल है
(a) 4 (b) 16 (c) 12 (d) 8
उत्तर: (d)
हल: क्षेत्रफल = ∫₀⁴ x dx = [x²/2]₀⁴ = 16/2 = 8। लुभाने वाला गलत विकल्प 16, x = 4 पर x² का मान 2 से भाग दिए बिना लेने से आता है। अतः उत्तर 8 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 8

65. यदि f(x) = ln(sin x), तो f′(x) बराबर है
(a) 1/sin x (b) cot x (c) tan x (d) cos x
उत्तर: (b)
हल: शृंखला नियम से, f′(x) = (1/sin x) · cos x = cos x / sin x = cot x। लुभाने वाले गलत विकल्प 1/sin x में लघुगणक का अवकलन करके रुक गए हैं और आंतरिक अवकलज cos x भूल गए हैं। अतः उत्तर cot x है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

66. ∫ x e^x dx बराबर है
(a) (x − 1) e^x + C (b) x e^x + C (c) e^x + C (d) (x + 1) e^x + C
उत्तर: (a)
हल: खंडशः समाकलन से, u = x और dv = e^x dx लेने पर: ∫x e^x dx = x e^x − ∫e^x dx = x e^x − e^x + C = (x − 1)e^x + C। लुभाने वाले गलत विकल्प x e^x + C में वह दूसरा समाकलन छोड़ दिया गया है जो खंडशः विधि में सदैव आता है। अतः उत्तर (x − 1) e^x + C है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 7

67. f(x) = x² + 4x + 7 का न्यूनतम मान है
(a) 3 (b) 4 (c) 7 (d) 11
उत्तर: (a)
हल: f′(x) = 2x + 4 = 0 से x = −2 मिलता है, और f″(x) = 2 > 0 न्यूनतम की पुष्टि करता है। तब f(−2) = 4 − 8 + 7 = 3। लुभाने वाला गलत विकल्प 7 केवल अचर पद है, जो f(0) के बराबर है, न्यूनतम मान नहीं। अतः उत्तर 3 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 6

68. −1 < x < 1 के लिए d/dx [sin⁻¹x] बराबर है
(a) −1/√(1 − x²) (b) 1/√(1 − x²) (c) 1/(1 + x²) (d) √(1 − x²)
उत्तर: (b)
हल: यदि y = sin⁻¹x तो x = sin y, अतः dx/dy = cos y = √(1 − x²), जिससे dy/dx = 1/√(1 − x²)। लुभाने वाला गलत विकल्प 1/(1 + x²), tan⁻¹x का अवकलज है — प्रतिलोम फलनों के बीच यह आम भ्रम है। अतः उत्तर 1/√(1 − x²) है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

69. ∫₁^e (1/x) dx बराबर है

उत्तर: (a)

70. y = x⁴ − 2x³ + x का द्वितीय अवकलज है
(a) 4x³ − 6x² + 1 (b) 12x² − 12x (c) 12x² − 6x (d) 24x − 12
उत्तर: (b)
हल: प्रथम अवकलज: 4x³ − 6x² + 1। पुनः अवकलन करने पर: 12x² − 12x। लुभाने वाला गलत विकल्प 4x³ − 6x² + 1 केवल प्रथम अवकलज है — एक कदम पहले रुक जाने का परिणाम। अतः उत्तर 12x² − 12x है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 5

71. फलन f(x) = 2x³ − 9x² + 12x + 1 वर्धमान (increasing) है जब
(a) 1 < x < 2 (b) केवल x > 1 (c) x < 1 या x > 2 (d) केवल x < 2
उत्तर: (c)
हल: f′(x) = 6x² − 18x + 12 = 6(x − 1)(x − 2)। यह धनात्मक तब है जब दोनों गुणनखंडों का चिह्न समान हो, अर्थात् x < 1 या x > 2। लुभाने वाला गलत विकल्प 1 < x < 2 ठीक वह अंतराल है जहाँ f′(x) ऋणात्मक है, अर्थात् वहाँ फलन ह्रासमान है। अतः उत्तर x < 1 या x > 2 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 6

72. ∫ cos(3x) dx बराबर है
(a) 3 sin(3x) + C (b) (1/3) sin(3x) + C (c) −3 sin(3x) + C (d) −(1/3) sin(3x) + C

स्रोत: NCERT कक्षा 12 गणित, अध्याय 7

73. यदि किसी वृत्त की त्रिज्या 2 cm/s की दर से बढ़ रही है, तो r = 5 cm पर उसके क्षेत्रफल की वृद्धि दर है
(a) 10π cm²/s (b) 4π cm²/s (c) 25π cm²/s (d) 20π cm²/s
उत्तर: (d)

74. ∫₀² (3x² + 1) dx बराबर है

75. f(x) = x³ − 6x² + 9x + 1 का नति-परिवर्तन बिंदु (point of inflection) x के किस मान पर है
(a) 0 (b) 1 (c) 2 (d) 3
उत्तर: (c)
हल: f′(x) = 3x² − 12x + 9 और f″(x) = 6x − 12। f″(x) = 0 रखने पर x = 2 मिलता है, और वहाँ f″ चिह्न बदलता है, जो नति-परिवर्तन बिंदु की पुष्टि करता है। लुभाने वाले गलत विकल्प 1 और 3 वे स्थिर बिंदु हैं जहाँ f′(x) = 0 है, न कि जहाँ f″(x) = 0। अतः उत्तर 2 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 6
