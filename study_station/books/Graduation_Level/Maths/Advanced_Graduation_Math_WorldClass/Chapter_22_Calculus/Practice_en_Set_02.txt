Questions 26–50: Medium

26. The derivative of f(x) = x³ − 3x² + 2x at x = 2 is
(a) 0 (b) 6 (c) 4 (d) 2
Answer: (d)
Solution: Many students substitute x = 2 into f(x) first and get 0, which is the trap — we need the derivative, not the function value. f′(x) = 3x² − 6x + 2, so f′(2) = 12 − 12 + 2 = 2, so the answer is 2.
Source: NCERT Class 12 Mathematics (Differentiation)

27. If y = e^(2x) · sin x, then dy/dx equals
(a) 2e^(2x) sin x (b) e^(2x)(sin x + 2 cos x) (c) e^(2x)(2 sin x + cos x) (d) e^(2x) cos x
Answer: (c)
Solution: The trap is differentiating only one factor, which gives the wrong options. By the product rule, dy/dx = 2e^(2x) sin x + e^(2x) cos x = e^(2x)(2 sin x + cos x), so the answer is e^(2x)(2 sin x + cos x).
Source: NCERT Class 12 Mathematics (Product Rule)

28. ∫ (1/(x² + 4)) dx equals
(a) (1/4) tan⁻¹(x/4) + C (b) tan⁻¹(x/2) + C (c) (1/2) tan⁻¹(x/2) + C (d) 2 tan⁻¹(x/2) + C
Answer: (c)
Solution: The tempting wrong choice forgets the factor 1/a in the standard formula ∫ dx/(x² + a²) = (1/a) tan⁻¹(x/a). Here a = 2, so the integral is (1/2) tan⁻¹(x/2) + C, so the answer is (1/2) tan⁻¹(x/2) + C.
Source: NCERT Class 12 Mathematics (Integrals)

29. The maximum value of f(x) = 4x − x² on the real line is
(a) 4 (b) 2 (c) 8 (d) 16
Answer: (a)
Solution: Some students evaluate f at x = 4 and get 0, confusing the root with the vertex. f′(x) = 4 − 2x = 0 gives x = 2, and f″(x) = −2 < 0 confirms a maximum; f(2) = 8 − 4 = 4, so the answer is 4.
Source: NCERT Class 12 Mathematics (Maxima and Minima)

30. lim (x→0) (sin 5x)/x equals
(a) 0 (b) 5 (c) 1 (d) 1/5
Answer: (b)
Solution: The trap is quoting lim (sin x)/x = 1 directly and answering 1, ignoring the coefficient 5. Write (sin 5x)/x = 5 · (sin 5x)/(5x) → 5 · 1 = 5, so the answer is 5.
Source: NCERT Class 11 Mathematics (Limits)

31. If y = ln(cos x), then dy/dx equals
(a) tan x (b) −cot x (c) cot x (d) −tan x
Answer: (d)
Solution: The sign trap tempts students to pick tan x, forgetting that the derivative of cos x is −sin x. By the chain rule, dy/dx = (1/cos x)·(−sin x) = −tan x, so the answer is −tan x.
Source: NCERT Class 12 Mathematics (Chain Rule)

32. ∫₀^(π/2) sin²x dx equals
(a) π/4 (b) π/2 (c) 1 (d) π
Answer: (a)
Solution: A common slip is integrating sin²x as if it were sin x, giving 1. Using sin²x = (1 − cos 2x)/2, the integral is [x/2 − sin 2x/4] from 0 to π/2 = π/4, so the answer is π/4.
Source: NCERT Class 12 Mathematics (Definite Integrals)

33. The slope of the tangent to the curve y = x² − 4x + 5 at the point where x = 3 is
(a) 5 (b) 3 (c) 2 (d) 6
Answer: (c)
Solution: The trap is computing y(3) = 2 and reporting the function value instead of the slope — coincidentally the same number here, but the method matters: dy/dx = 2x − 4, and at x = 3 the slope is 6 − 4 = 2, so the answer is 2.
Source: NCERT Class 12 Mathematics (Applications of Derivatives)

34. d/dx (x^x) equals
(a) x·x^(x−1) (b) x^(x−1) (c) x^x ln x (d) x^x (1 + ln x)
Answer: (d)
Solution: The classic trap is treating x^x as a pure power and answering x·x^(x−1); that rule needs a constant exponent. Taking logarithms, ln y = x ln x, so y′/y = 1 + ln x and y′ = x^x(1 + ln x), so the answer is x^x(1 + ln x).
Source: NCERT Class 12 Mathematics (Logarithmic Differentiation)

35. ∫ x·e^x dx equals
(a) e^x(x − 1) + C (b) e^x(x + 1) + C (c) x·e^x + C (d) e^x + C
Answer: (a)
Solution: The sign trap gives e^x(x + 1) to those who misapply integration by parts. With u = x, dv = e^x dx: ∫ x e^x dx = x e^x − ∫ e^x dx = x e^x − e^x + C = e^x(x − 1) + C, so the answer is e^x(x − 1) + C.
Source: NCERT Class 12 Mathematics (Integration by Parts)

36. The function f(x) = x³ − 12x has a local minimum at x equal to
(a) −2 (b) 0 (c) 4 (d) 2
Answer: (d)
Solution: The trap is picking x = −2, which is a critical point but a local maximum. f′(x) = 3x² − 12 = 0 gives x = ±2; f″(x) = 6x is positive at x = 2, confirming a local minimum there, so the answer is 2.
Source: NCERT Class 12 Mathematics (Maxima and Minima)

37. lim (x→0) (e^x − 1)/x equals
(a) 0 (b) e (c) 1 (d) ∞
Answer: (c)
Solution: Substituting x = 0 gives 0/0, and the trap is declaring the limit 0 or undefined. This is the standard exponential limit (or use L'Hôpital: derivative ratio e^x/1 → 1), so the answer is 1.
Source: NCERT Class 11 Mathematics (Limits)

38. If x = a cos θ and y = a sin θ, then dy/dx equals
(a) −cot θ (b) −tan θ (c) cot θ (d) tan θ
Answer: (a)
Solution: The trap is dividing dy/dθ by dx/dθ but dropping the minus sign from the derivative of cos θ. dy/dθ = a cos θ and dx/dθ = −a sin θ, so dy/dx = −cot θ, so the answer is −cot θ.
Source: NCERT Class 12 Mathematics (Parametric Differentiation)

39. ∫₁^e (1/x) dx equals
(a) e − 1 (b) 1 (c) e (d) 0
Answer: (b)
Solution: The trap is computing e − 1 by treating the integrand as a constant 1. Since ∫ (1/x) dx = ln x, the value is ln e − ln 1 = 1 − 0 = 1, so the answer is 1.
Source: NCERT Class 12 Mathematics (Definite Integrals)

40. The second derivative of y = x⁴ − 6x² is zero at x equal to
(a) ±√3 (b) ±2 (c) 0 only (d) ±1
Answer: (d)
Solution: Some stop at the first derivative 4x³ − 12x = 0 and report ±√3, which are critical points, not inflection candidates. y″ = 12x² − 12 = 0 gives x² = 1, so the answer is ±1.
Source: NCERT Class 12 Mathematics (Higher Order Derivatives)

41. The area enclosed between y = x² and the x-axis from x = 0 to x = 3 is
(a) 3 (b) 9 (c) 6 (d) 27
Answer: (b)
Solution: The trap is evaluating x² at x = 3 and answering 9 by luck of method confusion — the correct method is integration: ∫₀³ x² dx = [x³/3]₀³ = 27/3 = 9, so the answer is 9.
Source: NCERT Class 12 Mathematics (Application of Integrals)

42. d/dx [tan⁻¹x] at x = 1 equals
(a) 1 (b) 1/2 (c) π/4 (d) 2
Answer: (b)
Solution: The trap is answering π/4, which is tan⁻¹(1), the function value, not the derivative. Since d/dx tan⁻¹x = 1/(1 + x²), at x = 1 we get 1/2, so the answer is 1/2.
Source: NCERT Class 12 Mathematics (Derivatives of Inverse Functions)

43. ∫ (cos x)/(1 + sin x) dx equals
(a) ln|1 + sin x| + C (b) −ln|1 + sin x| + C (c) tan⁻¹(sin x) + C (d) ln|cos x| + C
Answer: (a)
Solution: The sign trap suggests −ln|1 + sin x|, but the numerator is exactly the derivative of the denominator with a plus sign. With u = 1 + sin x, du = cos x dx, the integral is ln|u| + C = ln|1 + sin x| + C, so the answer is ln|1 + sin x| + C.
Source: NCERT Class 12 Mathematics (Substitution Method)

44. For f(x) = x + 1/x (x > 0), the minimum value of f is
(a) 1 (b) 3 (c) 2 (d) 4
Answer: (c)
Solution: The trap is assuming the minimum occurs at x = 2 or guessing 1. f′(x) = 1 − 1/x² = 0 gives x = 1 (since x > 0), f″(1) = 2 > 0, and f(1) = 1 + 1 = 2, matching AM ≥ GM, so the answer is 2.
Source: NCERT Class 12 Mathematics (Maxima and Minima)

45. lim (x→∞) (3x² + 2x)/(x² + 5) equals
(a) 3 (b) 1 (c) 0 (d) ∞
Answer: (a)
Solution: The trap is answering 1 by comparing only the x² terms' presence, ignoring coefficients. Dividing numerator and denominator by x² gives (3 + 2/x)/(1 + 5/x²) → 3/1 = 3, so the answer is 3.
Source: NCERT Class 11 Mathematics (Limits)

46. If y = sin⁻¹x + cos⁻¹x, then dy/dx equals
(a) 1 (b) 2/√(1 − x²) (c) 0 (d) π/2
Answer: (c)
Solution: The trap is adding the two derivatives and getting 2/√(1 − x²), forgetting that d/dx cos⁻¹x is negative. Since sin⁻¹x + cos⁻¹x = π/2 (a constant), its derivative is 0, so the answer is 0.
Source: NCERT Class 12 Mathematics (Inverse Trigonometric Functions)

47. ∫₀^1 x(1 − x) dx equals
(a) 1/6 (b) 1/3 (c) 1/2 (d) 1/4
Answer: (a)
Solution: The trap is averaging the bounds and guessing 1/4. Expand: ∫₀¹ (x − x²) dx = [x²/2 − x³/3]₀¹ = 1/2 − 1/3 = 1/6, so the answer is 1/6.
Source: NCERT Class 12 Mathematics (Definite Integrals)

48. The point of inflection of y = x³ − 3x² + 2 is at x equal to
(a) 0 (b) 1 (c) 2 (d) 3
Answer: (b)
Solution: The trap is solving y′ = 3x² − 6x = 0 and picking x = 0 or 2, which are stationary points, not inflection points. y″ = 6x − 6 = 0 gives x = 1, and y″ changes sign there, so the answer is 1.
Source: NCERT Class 12 Mathematics (Higher Order Derivatives)

49. d/dx [√(sin x)] equals
(a) −cos x / (2√(sin x)) (b) √(cos x) / 2 (c) 1 / (2√(sin x)) (d) cos x / (2√(sin x))
Answer: (d)
Solution: The trap is differentiating only the outer square root and omitting the chain-rule factor cos x. By the chain rule, d/dx (sin x)^(1/2) = (1/2)(sin x)^(−1/2)·cos x = cos x/(2√(sin x)), so the answer is cos x/(2√(sin x)).
Source: NCERT Class 12 Mathematics (Chain Rule)

50. ∫ (dx)/(x ln x) equals
(a) ln x + C (b) ln|ln x| + C (c) 1/(ln x) + C (d) (ln x)²/2 + C
Answer: (b)
Solution: The trap is answering ln x + C by pattern-matching ∫ dx/x. Substitute u = ln x, du = dx/x, giving ∫ du/u = ln|u| + C = ln|ln x| + C, so the answer is ln|ln x| + C.
Source: NCERT Class 12 Mathematics (Substitution Method)
