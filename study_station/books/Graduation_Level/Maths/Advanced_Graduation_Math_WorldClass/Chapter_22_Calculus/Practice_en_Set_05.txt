101. The derivative of x³ − 5x² + 7x − 3 with respect to x is
(a) x² − 10x + 7 (b) 3x² − 5x + 7 (c) 3x² − 10x + 7 (d) 3x² − 10x − 3
Answer: (c)
Solution: The trap option 3x² − 5x + 7 drops the coefficient 2 when differentiating 5x². Differentiating term by term gives 3x² − 10x + 7, with the constant −3 vanishing, so the answer is 3x² − 10x + 7.
Source: NCERT Class 11 Mathematics (Limits and Derivatives)

102. If y = x·sin x, then dy/dx equals
(a) cos x (b) sin x − x cos x (c) x cos x (d) sin x + x cos x
Answer: (d)
Solution: The trap option x cos x ignores the derivative of the first factor x, which contributes sin x. By the product rule, dy/dx = sin x + x cos x, so the answer is sin x + x cos x.
Source: NCERT Class 12 Mathematics (Continuity and Differentiability)

103. The derivative of e^(2x) with respect to x is
(a) e^(2x) (b) 2e^(2x) (c) 2x·e^(2x) (d) e^(2x)/2
Answer: (b)
Solution: The trap option e^(2x) forgets to multiply by the inner derivative of 2x, which is 2. By the chain rule the derivative is 2e^(2x), so the answer is 2e^(2x).
Source: NCERT Class 12 Mathematics (Continuity and Differentiability)

104. ∫(3x² + 4x + 5) dx equals
(a) 6x + 4 + C (b) x³ + 4x² + 5x + C (c) x³ + 2x² + 5x + C (d) 3x³ + 2x² + 5x + C
Answer: (c)
Solution: The trap option 6x + 4 + C is the derivative, not the integral — a classic direction confusion. Integrating term by term gives x³ + 2x² + 5x + C, so the answer is x³ + 2x² + 5x + C.
Source: NCERT Class 12 Mathematics (Integrals)

105. The value of ∫₀¹ x² dx is
(a) 1/2 (b) 2/3 (c) 1 (d) 1/3
Answer: (d)
Solution: The trap option 1/2 comes from mistakenly applying the power rule for x instead of x². Since ∫x²dx = x³/3, evaluating from 0 to 1 gives 1/3, so the answer is 1/3.
Source: NCERT Class 12 Mathematics (Integrals)

106. If y = ln(sin x), then dy/dx equals
(a) tan x (b) 1/sin x (c) cos x (d) cot x
Answer: (d)
Solution: The trap option 1/sin x stops after differentiating ln and forgets the inner derivative cos x. By the chain rule, dy/dx = cos x / sin x = cot x, so the answer is cot x.
Source: NCERT Class 12 Mathematics (Continuity and Differentiability)

107. The maximum value of f(x) = 12x − x³ for x > 0 occurs at x equal to
(a) 1 (b) 3 (c) 2 (d) 4
Answer: (c)
Solution: The trap option 4 comes from solving 12 − 3x = 0, forgetting that the derivative contains x². Setting f′(x) = 12 − 3x² = 0 gives x = 2, and f″(2) = −12 < 0 confirms a maximum, so the answer is 2.
Source: NCERT Class 12 Mathematics (Application of Derivatives)

108. ∫(1/x) dx equals
(a) −1/x² + C (b) x⁰ + C (c) ln|x| + C (d) 1/x² + C
Answer: (c)
Solution: The trap option −1/x² + C is actually the integral of 1/x², not of 1/x; the power rule fails at n = −1. The integral of 1/x is ln|x| + C, so the answer is ln|x| + C.
Source: NCERT Class 12 Mathematics (Integrals)

109. The derivative of x^x with respect to x is
(a) x^x (1 + ln x) (b) x^x (c) x^x · ln x (d) x·x^(x−1)
Answer: (a)
Solution: The trap option x·x^(x−1) wrongly applies the power rule to a variable exponent. Taking logarithms, ln y = x ln x, so y′/y = 1 + ln x and y′ = x^x(1 + ln x), so the answer is x^x (1 + ln x).
Source: NCERT Class 12 Mathematics (Continuity and Differentiability)

110. The slope of the tangent to the curve y = x² − 4x + 3 at the point where x = 3 is
(a) 2 (b) 3 (c) 0 (d) −1
Answer: (a)
Solution: The trap option 0 comes from setting the derivative to zero, which finds the turning point at x = 2, not the slope at x = 3. Since dy/dx = 2x − 4, at x = 3 the slope is 2, so the answer is 2.
Source: NCERT Class 12 Mathematics (Application of Derivatives)

111. ∫₀^(π/2) sin x dx equals
(a) 1 (b) 0 (c) π/2 (d) −1
Answer: (a)
Solution: The trap option −1 arises from a sign slip when substituting the lower limit. Since ∫sin x dx = −cos x, the value is (−cos(π/2)) − (−cos 0) = 0 + 1 = 1, so the answer is 1.
Source: NCERT Class 12 Mathematics (Integrals)

112. If y = (2x + 3)⁵, then dy/dx equals
(a) 10(2x + 3)⁴ (b) 5(2x + 3)⁴ · 2x (c) 5(2x + 3)⁴ (d) 10(2x + 3)⁵
Answer: (a)
Solution: The trap option 5(2x + 3)⁴ omits the inner derivative 2. By the chain rule, dy/dx = 5(2x + 3)⁴ · 2 = 10(2x + 3)⁴, so the answer is 10(2x + 3)⁴.
Source: NCERT Class 12 Mathematics (Continuity and Differentiability)

113. The function f(x) = x³ − 3x has local maxima and minima respectively at
(a) x = −1 and x = 1 (b) x = 1 and x = −1 (c) x = 0 and x = 3 (d) x = −3 and x = 3
Answer: (a)
Solution: The trap option x = 1 and x = −1 swaps the two by ignoring the sign of the second derivative. f′(x) = 3x² − 3 = 0 gives x = ±1; f″(−1) = −6 < 0 (maximum) and f″(1) = 6 > 0 (minimum), so the answer is x = −1 and x = 1.
Source: NCERT Class 12 Mathematics (Application of Derivatives)

114. ∫e^x (1 + x) dx equals
(a) x·e^x + e^x + C (b) e^x · x + C (c) e^x (1 + x) + C (d) e^x + C
Answer: (b)
Solution: The trap option e^x(1 + x) + C looks plausible but its derivative is e^x(2 + x), not e^x(1 + x). Splitting and using integration by parts: ∫e^x dx + ∫x e^x dx = e^x + x e^x − e^x + C = x e^x + C, so the answer is e^x · x + C.
Source: NCERT Class 12 Mathematics (Integrals)

115. The derivative of tan x with respect to x is
(a) −cosec²x (b) cot x (c) sec x tan x (d) sec²x
Answer: (d)
Solution: The trap option sec x tan x is the derivative of sec x, not of tan x. Writing tan x = sin x / cos x and applying the quotient rule gives (cos²x + sin²x)/cos²x = sec²x, so the answer is sec²x.
Source: NCERT Class 12 Mathematics (Continuity and Differentiability)

116. The area enclosed between the curve y = x, the x-axis, and the lines x = 0 and x = 4 is
(a) 4 (b) 16 (c) 8 (d) 12
Answer: (c)
Solution: The trap option 16 forgets the factor 1/2 in the antiderivative x²/2. Area = ∫₀⁴ x dx = [x²/2]₀⁴ = 8, so the answer is 8.
Source: NCERT Class 12 Mathematics (Application of Integrals)

117. If x = a cos θ and y = a sin θ, then dy/dx equals
(a) tan θ (b) −tan θ (c) cot θ (d) −cot θ
Answer: (d)
Solution: The trap option −tan θ results from inverting the ratio of the two derivatives. Since dy/dθ = a cos θ and dx/dθ = −a sin θ, dy/dx = −cot θ, so the answer is −cot θ.
Source: NCERT Class 12 Mathematics (Continuity and Differentiability)

118. ∫dx/(1 + x²) equals
(a) sin⁻¹x + C (b) ln(1 + x²) + C (c) 2x/(1 + x²)² + C (d) tan⁻¹x + C
Answer: (d)
Solution: The trap option ln(1 + x²) + C would be correct only if the numerator were 2x, matching the derivative of the denominator. The standard integral is tan⁻¹x + C, so the answer is tan⁻¹x + C.
Source: NCERT Class 12 Mathematics (Integrals)

119. The minimum value of f(x) = x² + 4x + 7 is
(a) 4 (b) 3 (c) 7 (d) −2
Answer: (b)
Solution: The trap option −2 is the x-value where the minimum occurs, not the minimum value itself. f′(x) = 2x + 4 = 0 gives x = −2, and f(−2) = 4 − 8 + 7 = 3, so the answer is 3.
Source: NCERT Class 12 Mathematics (Application of Derivatives)

120. The derivative of sin⁻¹x with respect to x is
(a) √(1 − x²) (b) 1/√(1 − x²) (c) 1/(1 + x²) (d) −1/√(1 − x²)
Answer: (b)
Solution: The trap option 1/(1 + x²) is the derivative of tan⁻¹x, a common mix-up. If y = sin⁻¹x then x = sin y, so dx/dy = cos y = √(1 − x²) and dy/dx = 1/√(1 − x²), so the answer is 1/√(1 − x²).
Source: NCERT Class 12 Mathematics (Continuity and Differentiability)

121. The value of ∫₀^(π/2) (sin x)/(sin x + cos x) dx is
(a) π (b) π/2 (c) π/4 (d) 1
Answer: (c)
Solution: The trap option π/2 is the value of 2I, forgetting the final halving. Using ∫₀^a f(x)dx = ∫₀^a f(a−x)dx and adding the two forms gives 2I = π/2, so I = π/4, so the answer is π/4.
Source: NCERT Class 12 Mathematics (Integrals — Properties of Definite Integrals)

122. If y = e^(x²), then d²y/dx² equals
(a) 2e^(x²) (b) 2e^(x²)(1 + 2x²) (c) 4x²e^(x²) (d) 2x·e^(x²)
Answer: (b)
Solution: The trap option 4x²e^(x²) drops the term obtained by differentiating the factor 2x in the first derivative. With y′ = 2x·e^(x²), the product rule gives y″ = 2e^(x²) + 4x²e^(x²) = 2e^(x²)(1 + 2x²), so the answer is 2e^(x²)(1 + 2x²).
Source: NCERT Class 12 Mathematics (Continuity and Differentiability)

123. The area of the region bounded by the parabola y = x² and the line y = x is
(a) 1/6 (b) 1/3 (c) 1/2 (d) 2/3
Answer: (a)
Solution: The trap option 1/3 comes from integrating only x² and ignoring the line. The curves meet at x = 0 and x = 1, where x ≥ x², so area = ∫₀¹ (x − x²) dx = 1/2 − 1/3 = 1/6, so the answer is 1/6.
Source: NCERT Class 12 Mathematics (Application of Integrals)

124. If y = x²·e^x, then dy/dx equals
(a) e^x(x² + 2x) (b) x²·e^x (c) 2x·e^x (d) e^x(x² − 2x)
Answer: (a)
Solution: The trap option 2x·e^x differentiates only x² and treats e^x as a constant. By the product rule, dy/dx = 2x·e^x + x²·e^x = e^x(x² + 2x), so the answer is e^x(x² + 2x).
Source: NCERT Class 12 Mathematics (Continuity and Differentiability)

125. The value of ∫₋₁¹ x³·sin²x dx is
(a) 2∫₀¹ x³ sin²x dx (b) 0 (c) 1/4 (d) π/4
Answer: (b)
Solution: The trap option 2∫₀¹ x³ sin²x dx wrongly applies the even-function doubling rule to an odd integrand. Since x³ is odd and sin²x is even, their product is odd, and the integral of an odd function over [−1, 1] is zero, so the answer is 0.
Source: NCERT Class 12 Mathematics (Integrals — Properties of Definite Integrals)
