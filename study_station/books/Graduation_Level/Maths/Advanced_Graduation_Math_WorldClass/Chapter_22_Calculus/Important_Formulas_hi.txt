# 📋 महत्वपूर्ण सूत्र — कलन (Calculus)

## 1. सीमा (Limits)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| मानक त्रिकोणमितीय सीमा | lim(x→0) sin x / x = 1 | sin, tan के प्रश्नों में सीधे लगाएँ |
| tan सीमा | lim(x→0) tan x / x = 1 | sin वाले के साथ मिलाकर |
| घातांकीय सीमा | lim(x→0) (eˣ − 1) / x = 1 | e वाले अनिर्णेय रूप में |
| लघुगणकीय सीमा | lim(x→0) log(1 + x) / x = 1 | log(1+x) दिखे तो तुरंत |
| बीजीय सीमा | lim(x→a) (xⁿ − aⁿ) / (x − a) = n·aⁿ⁻¹ | xⁿ − aⁿ के प्रश्नों में |
| (1 + 1/n)ⁿ सीमा | lim(n→∞) (1 + 1/n)ⁿ = e | e की परिभाषा |
| (1 + x)^(1/x) सीमा | lim(x→0) (1 + x)^(1/x) = e | 1^∞ रूप में |
| aˣ सीमा | lim(x→0) (aˣ − 1) / x = log a | आधार a वाले घातांक में |
| सैंडविच प्रमेय | g(x) ≤ f(x) ≤ h(x), lim g = lim h = L ⇒ lim f = L | दो फलनों के बीच दबा फलन |
| लॉपितल नियम | lim f/g (0/0 या ∞/∞) = lim f′/g′ | अनिर्णेय रूप में अवकलन करके |

## 2. अवकलन (Differentiation) — मूल सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| घात नियम | d/dx (xⁿ) = n·xⁿ⁻¹ | सबसे अधिक प्रयुक्त |
| अचर नियम | d/dx (c) = 0 | अचर का अवकलज शून्य |
| sin का अवकलज | d/dx (sin x) = cos x | — |
| cos का अवकलज | d/dx (cos x) = −sin x | ऋण चिह्न याद रखें |
| tan का अवकलज | d/dx (tan x) = sec²x | — |
| cot का अवकलज | d/dx (cot x) = −cosec²x | ऋण चिह्न |
| sec का अवकलज | d/dx (sec x) = sec x · tan x | — |
| cosec का अवकलज | d/dx (cosec x) = −cosec x · cot x | ऋण चिह्न |
| घातांक का अवकलज | d/dx (eˣ) = eˣ | अपरिवर्तित रहता है |
| aˣ का अवकलज | d/dx (aˣ) = aˣ · log a | आधार a में |
| log का अवकलज | d/dx (log x) = 1/x | x > 0 |
| logₐ का अवकलज | d/dx (logₐ x) = 1/(x · log a) | आधार a में |

## 3. अवकलन के नियम

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| योग नियम | (u ± v)′ = u′ ± v′ | पद-दर-पद अवकलन |
| गुणनफल नियम | (u·v)′ = u′v + uv′ | "पहले का अवकलज × दूसरा + पहला × दूसरे का अवकलज" |
| भागफल नियम | (u/v)′ = (u′v − uv′)/v² | ऊपर का अवकलज पहले |
| शृंखला नियम | dy/dx = (dy/du)·(du/dx) | संयुक्त फलन में |
| प्रतिलोम फलन | d/dx [f⁻¹(x)] = 1 / f′(f⁻¹(x)) | inverse फलन में |
| प्राचलिक अवकलन | dy/dx = (dy/dt)/(dx/dt) | x, y दोनों t के फलन हों तो |
| लघुगणकीय अवकलन | y = uᵛ ⇒ log y = v log u, फिर अवकलन | चर घात वाले फलन में |
| द्वितीय अवकलज | d²y/dx² = d/dx (dy/dx) | उच्चतम-न्यूनतम परीक्षण में |

## 4. प्रतिलोम त्रिकोणमितीय फलनों के अवकलज

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| sin⁻¹ | d/dx sin⁻¹x = 1/√(1 − x²) | \|x\| < 1 |
| cos⁻¹ | d/dx cos⁻¹x = −1/√(1 − x²) | sin⁻¹ का ऋणात्मक |
| tan⁻¹ | d/dx tan⁻¹x = 1/(1 + x²) | — |
| cot⁻¹ | d/dx cot⁻¹x = −1/(1 + x²) | tan⁻¹ का ऋणात्मक |
| sec⁻¹ | d/dx sec⁻¹x = 1/(\|x\|√(x² − 1)) | \|x\| > 1 |
| cosec⁻¹ | d/dx cosec⁻¹x = −1/(\|x\|√(x² − 1)) | sec⁻¹ का ऋणात्मक |

## 5. अवकलन के अनुप्रयोग

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| स्पर्श रेखा का ढाल | m = dy/dx \|(x₁,y₁) | बिंदु पर अवकलज |
| स्पर्श रेखा का समीकरण | y − y₁ = m(x − x₁) | बिंदु-ढाल रूप |
| अभिलंब का ढाल | −1/m | स्पर्श रेखा के लंबवत |
| वर्धमान फलन | f′(x) > 0 | अंतराल में जाँचें |
| ह्रासमान फलन | f′(x) < 0 | अंतराल में जाँचें |
| स्थिर बिंदु | f′(x) = 0 | क्रांतिक बिंदु खोजने में |
| उच्चतम परीक्षण | f′(a) = 0 और f″(a) < 0 ⇒ x = a पर उच्चतम | द्वितीय अवकलज परीक्षण |
| न्यूनतम परीक्षण | f′(a) = 0 और f″(a) > 0 ⇒ x = a पर न्यूनतम | द्वितीय अवकलज परीक्षण |
| परिवर्तन की दर | dy/dt = (dy/dx)·(dx/dt) | समय सापेक्ष दर |
| सन्निकटन | Δy ≈ f′(x)·Δx | छोटे परिवर्तन का अनुमान |

## 6. समाकलन (Integration) — मूल सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| घात नियम | ∫xⁿ dx = xⁿ⁺¹/(n+1) + C | n ≠ −1 |
| 1/x | ∫(1/x) dx = log\|x\| + C | n = −1 वाला विशेष रूप |
| घातांक | ∫eˣ dx = eˣ + C | — |
| aˣ | ∫aˣ dx = aˣ/ log a + C | आधार a में |
| sin | ∫sin x dx = −cos x + C | ऋण चिह्न |
| cos | ∫cos x dx = sin x + C | — |
| sec² | ∫sec²x dx = tan x + C | tan का अवकलज याद करें |
| cosec² | ∫cosec²x dx = −cot x + C | — |
| sec·tan | ∫sec x tan x dx = sec x + C | — |
| cosec·cot | ∫cosec x cot x dx = −cosec x + C | — |
| 1/(1+x²) | ∫dx/(1 + x²) = tan⁻¹x + C | — |
| 1/√(1−x²) | ∫dx/√(1 − x²) = sin⁻¹x + C | — |
| 1/(x²+a²) | ∫dx/(x² + a²) = (1/a) tan⁻¹(x/a) + C | — |
| 1/√(a²−x²) | ∫dx/√(a² − x²) = sin⁻¹(x/a) + C | — |
| 1/(x²−a²) | ∫dx/(x² − a²) = (1/2a) log\|(x−a)/(x+a)\| + C | — |
| 1/(a²−x²) | ∫dx/(a² − x²) = (1/2a) log\|(a+x)/(a−x)\| + C | — |
| 1/√(x²+a²) | ∫dx/√(x² + a²) = log\|x + √(x² + a²)\| + C | — |
| 1/√(x²−a²) | ∫dx/√(x² − a²) = log\|x + √(x² − a²)\| + C | — |
| √(a²−x²) | ∫√(a² − x²) dx = (x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a) + C | क्षेत्रफल प्रश्नों में |
| √(x²+a²) | ∫√(x² + a²) dx = (x/2)√(x²+a²) + (a²/2) log\|x + √(x²+a²)\| + C | — |
| √(x²−a²) | ∫√(x² − a²) dx = (x/2)√(x²−a²) − (a²/2) log\|x + √(x²−a²)\| + C | — |
| tan | ∫tan x dx = log\|sec x\| + C | — |
| cot | ∫cot x dx = log\|sin x\| + C | — |
| sec | ∫sec x dx = log\|sec x + tan x\| + C | — |
| cosec | ∫cosec x dx = log\|cosec x − cot x\| + C | — |

## 7. समाकलन की विधियाँ

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| प्रतिस्थापन | ∫f(g(x))·g′(x) dx = ∫f(u) du, u = g(x) | अंदर का फलन + उसका अवकलज दिखे तो |
| खंडशः समाकलन | ∫u·v dx = u∫v dx − ∫(u′∫v dx) dx | दो फलनों के गुणन में |
| ILATE क्रम | Inverse, Log, Algebraic, Trig, Exponential | पहला फलन चुनने का क्रम |
| आंशिक भिन्न | P(x)/Q(x) को सरल भिन्नों में तोड़ें | परिमेय फलन में |
| निश्चित समाकलन | ∫ₐᵇ f(x) dx = F(b) − F(a) | सीमा रखकर मान |
| सम फलन गुण | f सम हो तो ∫₋ₐᵃ f(x) dx = 2∫₀ᵃ f(x) dx | सममित सीमा में |
| विषम फलन गुण | f विषम हो तो ∫₋ₐᵃ f(x) dx = 0 | सममित सीमा में |
| राजा गुण (King) | ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a + b − x) dx | त्रिकोणमितीय निश्चित समाकलन में |
| 0 से 2a गुण | ∫₀²ᵃ f(x) dx = ∫₀ᵃ [f(x) + f(2a − x)] dx | सीमा 0 से 2a हो तो |

## 8. समाकलन के अनुप्रयोग

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| वक्र के नीचे क्षेत्रफल | A = ∫ₐᵇ y dx = ∫ₐᵇ f(x) dx | x-अक्ष के साथ |
| दो वक्रों के बीच क्षेत्रफल | A = ∫ₐᵇ [f(x) − g(x)] dx | ऊपरी वक्र − निचला वक्र |
| y-अक्ष के साथ क्षेत्रफल | A = ∫_c^d x dy | x को y के पदों में |
| घूर्णन आयतन (x-अक्ष) | V = π∫ₐᵇ y² dx | वक्र का x-अक्ष पर घूर्णन |
| वक्र की लंबाई | L = ∫ₐᵇ √(1 + (dy/dx)²) dx | — |

## 9. अवकल समीकरण (Differential Equations)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| चर-पृथक्करण | dy/dx = f(x)·g(y) ⇒ dy/g(y) = f(x) dx | चर अलग करके समाकलन |
| रैखिक अवकल समीकरण | dy/dx + Py = Q; समाकलन गुणक = e^∫P dx | हल: y·(I.F.) = ∫Q·(I.F.) dx |
| समघात समीकरण | y = vx रखें | dy/dx = f(y/x) रूप में |
| कोटि (Order) | समीकरण में उपस्थित उच्चतम अवकलज का क्रम (जैसे d²y/dx² हो तो कोटि 2) | परिभाषा-आधारित प्रश्न |
| घात (Degree) | उच्चतम अवकलज की शक्ति (परिमेय/मूल-मुक्त रूप में) | कोटि के साथ पूछा जाता है |
