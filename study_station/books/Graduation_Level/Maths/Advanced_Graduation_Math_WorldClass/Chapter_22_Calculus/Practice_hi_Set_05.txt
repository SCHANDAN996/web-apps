101. x के सापेक्ष x³ − 5x² + 7x − 3 का अवकलज है
(a) x² − 10x + 7 (b) 3x² − 5x + 7 (c) 3x² − 10x + 7 (d) 3x² − 10x − 3
उत्तर: (c)
हल: भ्रामक विकल्प 3x² − 5x + 7 में 5x² का अवकलन करते समय गुणांक 2 छूट जाता है। पद-दर-पद अवकलन करने पर 3x² − 10x + 7 मिलता है, और अचर −3 शून्य हो जाता है, इसलिए उत्तर 3x² − 10x + 7 है।
स्रोत: NCERT कक्षा 11 गणित (सीमा और अवकलज)

102. यदि y = x·sin x, तो dy/dx बराबर है
(a) cos x (b) sin x − x cos x (c) x cos x (d) sin x + x cos x
उत्तर: (d)
हल: भ्रामक विकल्प x cos x पहले गुणनखंड x के अवकलज को नज़रअंदाज़ करता है, जो sin x का योगदान देता है। गुणन नियम से, dy/dx = sin x + x cos x, इसलिए उत्तर sin x + x cos x है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

103. x के सापेक्ष e^(2x) का अवकलज है
(a) e^(2x) (b) 2e^(2x) (c) 2x·e^(2x) (d) e^(2x)/2
उत्तर: (b)
हल: भ्रामक विकल्प e^(2x) में 2x के आंतरिक अवकलज 2 से गुणा करना भूल जाता है। शृंखला नियम से अवकलज 2e^(2x) है, इसलिए उत्तर 2e^(2x) है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

104. ∫(3x² + 4x + 5) dx बराबर है
(a) 6x + 4 + C (b) x³ + 4x² + 5x + C (c) x³ + 2x² + 5x + C (d) 3x³ + 2x² + 5x + C
उत्तर: (c)
हल: भ्रामक विकल्प 6x + 4 + C समाकलन नहीं, बल्कि अवकलज है — यह दिशा की एक क्लासिक गलती है। पद-दर-पद समाकलन करने पर x³ + 2x² + 5x + C मिलता है, इसलिए उत्तर x³ + 2x² + 5x + C है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

105. ∫₀¹ x² dx का मान है
(a) 1/2 (b) 2/3 (c) 1 (d) 1/3
उत्तर: (d)
हल: भ्रामक विकल्प 1/2 x² के बजाय x के घात नियम को गलती से लागू करने से आता है। चूँकि ∫x²dx = x³/3, 0 से 1 तक मान रखने पर 1/3 मिलता है, इसलिए उत्तर 1/3 है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

106. यदि y = ln(sin x), तो dy/dx बराबर है
(a) tan x (b) 1/sin x (c) cos x (d) cot x
उत्तर: (d)
हल: भ्रामक विकल्प 1/sin x ln का अवकलन करने के बाद रुक जाता है और आंतरिक अवकलज cos x को भूल जाता है। शृंखला नियम से, dy/dx = cos x / sin x = cot x, इसलिए उत्तर cot x है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

107. x > 0 के लिए f(x) = 12x − x³ का अधिकतम मान x के किस मान पर होता है
(a) 1 (b) 3 (c) 2 (d) 4
उत्तर: (c)
हल: भ्रामक विकल्प 4, 12 − 3x = 0 हल करने से आता है, जबकि अवकलज में x² होता है। f′(x) = 12 − 3x² = 0 रखने पर x = 2 मिलता है, और f″(2) = −12 < 0 अधिकतम की पुष्टि करता है, इसलिए उत्तर 2 है।
स्रोत: NCERT कक्षा 12 गणित (अवकलज के अनुप्रयोग)

108. ∫(1/x) dx बराबर है
(a) −1/x² + C (b) x⁰ + C (c) ln|x| + C (d) 1/x² + C
उत्तर: (c)
हल: भ्रामक विकल्प −1/x² + C वास्तव में 1/x² का समाकलन है, 1/x का नहीं; घात नियम n = −1 पर विफल हो जाता है। 1/x का समाकलन ln|x| + C है, इसलिए उत्तर ln|x| + C है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

109. x के सापेक्ष x^x का अवकलज है
(a) x^x (1 + ln x) (b) x^x (c) x^x · ln x (d) x·x^(x−1)
उत्तर: (a)
हल: भ्रामक विकल्प x·x^(x−1) चर घातांक पर घात नियम को गलत तरीके से लागू करता है। लघुगणक लेने पर, ln y = x ln x, इसलिए y′/y = 1 + ln x और y′ = x^x(1 + ln x), इसलिए उत्तर x^x (1 + ln x) है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

110. वक्र y = x² − 4x + 3 के उस बिंदु पर स्पर्शरेखा की ढलान जहाँ x = 3 है, है
(a) 2 (b) 3 (c) 0 (d) −1
उत्तर: (a)
हल: भ्रामक विकल्प 0 अवकलज को शून्य के बराबर रखने से आता है, जो x = 2 पर मोड़ बिंदु बताता है, x = 3 पर ढलान नहीं। चूँकि dy/dx = 2x − 4, x = 3 पर ढलान 2 है, इसलिए उत्तर 2 है।
स्रोत: NCERT कक्षा 12 गणित (अवकलज के अनुप्रयोग)

111. ∫₀^(π/2) sin x dx बराबर है
(a) 1 (b) 0 (c) π/2 (d) −1
उत्तर: (a)
हल: भ्रामक विकल्प −1 निचली सीमा रखते समय चिह्न की चूक से आता है। चूँकि ∫sin x dx = −cos x, मान है (−cos(π/2)) − (−cos 0) = 0 + 1 = 1, इसलिए उत्तर 1 है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

112. यदि y = (2x + 3)⁵, तो dy/dx बराबर है
(a) 10(2x + 3)⁴ (b) 5(2x + 3)⁴ · 2x (c) 5(2x + 3)⁴ (d) 10(2x + 3)⁵
उत्तर: (a)
हल: भ्रामक विकल्प 5(2x + 3)⁴ में आंतरिक अवकलज 2 छूट जाता है। शृंखला नियम से, dy/dx = 5(2x + 3)⁴ · 2 = 10(2x + 3)⁴, इसलिए उत्तर 10(2x + 3)⁴ है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

113. फलन f(x) = x³ − 3x के स्थानीय उच्चिष्ठ और निम्निष्ठ क्रमशः कहाँ हैं
(a) x = −1 और x = 1 (b) x = 1 और x = −1 (c) x = 0 और x = 3 (d) x = −3 और x = 3
उत्तर: (a)
हल: भ्रामक विकल्प x = 1 और x = −1 द्वितीय अवकलज के चिह्न को न देखकर दोनों को उलट देता है। f′(x) = 3x² − 3 = 0 से x = ±1 मिलता है; f″(−1) = −6 < 0 (उच्चिष्ठ) और f″(1) = 6 > 0 (निम्निष्ठ), इसलिए उत्तर x = −1 और x = 1 है।
स्रोत: NCERT कक्षा 12 गणित (अवकलज के अनुप्रयोग)

114. ∫e^x (1 + x) dx बराबर है
(a) x·e^x + e^x + C (b) e^x · x + C (c) e^x (1 + x) + C (d) e^x + C
उत्तर: (b)
हल: भ्रामक विकल्प e^x(1 + x) + C दिखने में सही लगता है, परंतु इसका अवकलज e^x(2 + x) है, e^x(1 + x) नहीं। विभाजित करके और खंडशः समाकलन से: ∫e^x dx + ∫x e^x dx = e^x + x e^x − e^x + C = x e^x + C, इसलिए उत्तर e^x · x + C है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

115. x के सापेक्ष tan x का अवकलज है
(a) −cosec²x (b) cot x (c) sec x tan x (d) sec²x
उत्तर: (d)
हल: भ्रामक विकल्प sec x tan x, sec x का अवकलज है, tan x का नहीं। tan x = sin x / cos x लिखकर भागफल नियम लागू करने पर (cos²x + sin²x)/cos²x = sec²x मिलता है, इसलिए उत्तर sec²x है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

116. वक्र y = x, x-अक्ष और रेखाओं x = 0 तथा x = 4 के बीच घिरा क्षेत्रफल है
(a) 4 (b) 16 (c) 8 (d) 12
उत्तर: (c)
हल: भ्रामक विकल्प 16 प्रतिअवकलज x²/2 में 1/2 के गुणक को भूल जाता है। क्षेत्रफल = ∫₀⁴ x dx = [x²/2]₀⁴ = 8, इसलिए उत्तर 8 है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन के अनुप्रयोग)

117. यदि x = a cos θ और y = a sin θ, तो dy/dx बराबर है
(a) tan θ (b) −tan θ (c) cot θ (d) −cot θ
उत्तर: (d)
हल: भ्रामक विकल्प −tan θ दोनों अवकलजों के अनुपात को उलटने से आता है। चूँकि dy/dθ = a cos θ और dx/dθ = −a sin θ, dy/dx = −cot θ, इसलिए उत्तर −cot θ है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

118. ∫dx/(1 + x²) बराबर है
(a) sin⁻¹x + C (b) ln(1 + x²) + C (c) 2x/(1 + x²)² + C (d) tan⁻¹x + C
उत्तर: (d)
हल: भ्रामक विकल्प ln(1 + x²) + C तभी सही होता जब अंश में 2x होता, जो हर के अवकलज से मेल खाता। मानक समाकलन tan⁻¹x + C है, इसलिए उत्तर tan⁻¹x + C है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन)

119. f(x) = x² + 4x + 7 का न्यूनतम मान है
(a) 4 (b) 3 (c) 7 (d) −2
उत्तर: (b)
हल: भ्रामक विकल्प −2 वह x-मान है जहाँ न्यूनतम होता है, न्यूनतम मान स्वयं नहीं। f′(x) = 2x + 4 = 0 से x = −2 मिलता है, और f(−2) = 4 − 8 + 7 = 3, इसलिए उत्तर 3 है।
स्रोत: NCERT कक्षा 12 गणित (अवकलज के अनुप्रयोग)

120. x के सापेक्ष sin⁻¹x का अवकलज है
(a) √(1 − x²) (b) 1/√(1 − x²) (c) 1/(1 + x²) (d) −1/√(1 − x²)
उत्तर: (b)
हल: भ्रामक विकल्प 1/(1 + x²), tan⁻¹x का अवकलज है — यह एक सामान्य भ्रम है। यदि y = sin⁻¹x तो x = sin y, इसलिए dx/dy = cos y = √(1 − x²) और dy/dx = 1/√(1 − x²), इसलिए उत्तर 1/√(1 − x²) है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

121. ∫₀^(π/2) (sin x)/(sin x + cos x) dx का मान है
(a) π (b) π/2 (c) π/4 (d) 1
उत्तर: (c)
हल: भ्रामक विकल्प π/2, 2I का मान है, जिसमें अंतिम आधा करना भूल गए। ∫₀^a f(x)dx = ∫₀^a f(a−x)dx का उपयोग करके और दोनों रूपों को जोड़ने पर 2I = π/2 मिलता है, इसलिए I = π/4, इसलिए उत्तर π/4 है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन — निश्चित समाकलनों के गुण)

122. यदि y = e^(x²), तो d²y/dx² बराबर है
(a) 2e^(x²) (b) 2e^(x²)(1 + 2x²) (c) 4x²e^(x²) (d) 2x·e^(x²)
उत्तर: (b)
हल: भ्रामक विकल्प 4x²e^(x²) में प्रथम अवकलज के गुणक 2x का अवकलन करने से मिलने वाला पद छूट जाता है। y′ = 2x·e^(x²) के साथ, गुणन नियम से y″ = 2e^(x²) + 4x²e^(x²) = 2e^(x²)(1 + 2x²), इसलिए उत्तर 2e^(x²)(1 + 2x²) है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

123. परवलय y = x² और रेखा y = x से घिरे क्षेत्र का क्षेत्रफल है
(a) 1/6 (b) 1/3 (c) 1/2 (d) 2/3
उत्तर: (a)
हल: भ्रामक विकल्प 1/3 केवल x² का समाकलन करके रेखा को नज़रअंदाज़ करने से आता है। वक्र x = 0 और x = 1 पर मिलते हैं, जहाँ x ≥ x², इसलिए क्षेत्रफल = ∫₀¹ (x − x²) dx = 1/2 − 1/3 = 1/6, इसलिए उत्तर 1/6 है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन के अनुप्रयोग)

124. यदि y = x²·e^x, तो dy/dx बराबर है
(a) e^x(x² + 2x) (b) x²·e^x (c) 2x·e^x (d) e^x(x² − 2x)
उत्तर: (a)
हल: भ्रामक विकल्प 2x·e^x केवल x² का अवकलन करता है और e^x को अचर मान लेता है। गुणन नियम से, dy/dx = 2x·e^x + x²·e^x = e^x(x² + 2x), इसलिए उत्तर e^x(x² + 2x) है।
स्रोत: NCERT कक्षा 12 गणित (सांतत्य और अवकलनीयता)

125. ∫₋₁¹ x³·sin²x dx का मान है
(a) 2∫₀¹ x³ sin²x dx (b) 0 (c) 1/4 (d) π/4
उत्तर: (b)
हल: भ्रामक विकल्प 2∫₀¹ x³ sin²x dx विषम समाकल्य पर सम-फलन के दुगुने करने के नियम को गलत तरीके से लागू करता है। चूँकि x³ विषम है और sin²x सम है, उनका गुणनफल विषम है, और [−1, 1] पर विषम फलन का समाकलन शून्य होता है, इसलिए उत्तर 0 है।
स्रोत: NCERT कक्षा 12 गणित (समाकलन — निश्चित समाकलनों के गुण)
