# 🪄 मिश्रण और पृथ्थीकरण — शॉर्ट ट्रिक्स (Short Tricks)

---

## ट्रिक 1: "ऊपर-नीचे, बीच का राजा" — एलीगेशन क्रॉस

```
┌─────────────────────────────────────────────┐
│  एलीगेशन क्रॉस कभी मत भूलो:                 │
│                                             │
│   सस्ता (c) ──────┐                         │
│                    ╲                        │
│                     ╲── माध्य (m)           │
│                    ╱                        │
│   महँगा (d) ──────┘                         │
│                                             │
│   अनुपात = (d − m) : (m − c)                │
│                                             │
│  🧠 याद रखो: "ऊपर-नीचे, बीच का राजा"        │
│  राजा (माध्य) बीच में बैठता है,             │
│  और दोनों तरफ़ से दूरी नापता है!            │
└─────────────────────────────────────────────┘
```

## ट्रिक 2: "उल्टा खेल" — अनुपात की दिशा

```
┌─────────────────────────────────────────────┐
│  क्रॉस में अनुपात हमेशा उल्टा आता है:       │
│                                             │
│  सस्ते का हिस्सा = (महँगा − माध्य)          │
│  महँगे का हिस्सा = (माध्य − सस्ता)          │
│                                             │
│  🧠 म्नेमोनिक: "दूर वाला पास वाले का"       │
│  जो दाम दूर है, उसका अंतर                   │
│  पास वाले की मात्रा बताता है!               │
└─────────────────────────────────────────────┘
```

## ट्रिक 4: "निकालो-भरो" का जादुई सूत्र

```
┌─────────────────────────────────────────────┐
│  बार-बार निकालकर बदलने वाले प्रश्न:         │
│                                             │
│  शेष मात्रा = V × (1 − x/V)ⁿ                │
│                                             │
│  V = कुल मात्रा, x = हर बार निकाली गई       │
│  मात्रा, n = बार की संख्या                  │
│                                             │
│  🧠 म्नेमोनिक: "घटाओ, घात लगाओ"             │
│  (1 − x/V) पर n की घात — बस!               │
└─────────────────────────────────────────────┘
```

## ट्रिक 9: "अंतर का अनुपात" — सीधा शॉर्टकट

```
┌─────────────────────────────────────────────┐
│  दो मिश्रण A (a% सांद्रता) और B (b%)        │
│  मिलाकर m% बनाना हो:                        │
│                                             │
│  A : B = (m − b) : (a − m)                  │
│  (अंतरों का उल्टा अनुपात)                   │
│                                             │
│  🧠 म्नेमोनिक: "अंतर उल्टा,                 │
│  उत्तर सीधा"                                │
│  अंतर उल्टा लिखो, अनुपात सीधा मिलेगा!       │
└─────────────────────────────────────────────┘
```

## ट्रिक 10: "शुद्ध = 100%" — शुद्ध पदार्थ मिलाना

```
┌─────────────────────────────────────────────┐

│  पानी मिलाना हो तो = 0%।                    │
│                                             │
│  🧠 म्नेमोनिक: "शुद्ध सौ, पानी जीरो"        │
│  सौ और जीरो — क्रॉस के दो चिर-साथी!         │
└─────────────────────────────────────────────┘
```

## ट्रिक 11: "x की जगह 1" — अनुपात से मात्रा

```
┌─────────────────────────────────────────────┐
│  अनुपात a : b मिले और कुल मात्रा V हो:      │
│  पहला हिस्सा = V × a/(a+b)                  │
│  दूसरा हिस्सा = V × b/(a+b)                 │
│                                             │
│  🧠 म्नेमोनिक: "कुल बाँटो,                  │
│  अनुपात के हिसाब से"                        │
│  हर (a+b) में से a पहले को, b दूसरे को!     │
└─────────────────────────────────────────────┘
```

```
└─────────────────────────────────────────────┘
```

## ट्रिक 14: "मास्टर एक्रोनिम — M.I.L.K."

```
┌─────────────────────────────────────────────┐
│  पूरे अध्याय की एक ही चाबी:                 │
│                                             │
│  M — Mean (माध्य) बीच में रखो               │
│  I — Invert (उल्टा) अंतरों का अनुपात        │
│  L — Level (स्तर) जाँचो: उत्तर बीच में?     │
│  K — Keep total (कुल स्थिर) प्रतिस्थापन में │
│                                             │
│  🧠 "MILK याद रखो — मिश्रण का दूध           │
│  कभी नहीं फटेगा!" 🥛                        │
└─────────────────────────────────────────────┘
```
