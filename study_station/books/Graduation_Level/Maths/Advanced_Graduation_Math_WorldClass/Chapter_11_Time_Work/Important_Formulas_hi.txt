# 📋 समय और कार्य — महत्वपूर्ण सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| कार्य-समय मूल संबंध | कार्य = दर × समय | सभी प्रश्नों की नींव |
| कार्य की दर | दर = 1 / (कुल दिन) | A अकेला n दिन में करे तो 1 दिन का कार्य = 1/n |
| कुल समय | समय = 1 / (संयुक्त दर) | दरें जोड़ने के बाद उल्टा करें |
| दो व्यक्ति मिलकर | समय = xy / (x + y) | A: x दिन, B: y दिन हों तो |
| तीन व्यक्ति मिलकर | समय = xyz / (xy + yz + zx) | A: x, B: y, C: z दिन हों तो |
| LCM विधि | कुल कार्य = LCM(x, y, …); दर = LCM/दिन | भिन्नों से बचने की सबसे तेज़ विधि |
| कार्य बचा हुआ | शेष कार्य = 1 − (किए गए दिन × दर) | "कुछ दिन बाद छोड़ दिया" वाले प्रश्न |
| एक छोड़कर जाए | शेष समय = शेष कार्य / बचे लोगों की दर | पहले शेष कार्य निकालें |
| वैकल्पिक दिन (Alternate days) | 2 दिन का कार्य = A की दर + B की दर | जोड़े में गिनें, अंतिम दिन अलग जाँचें |
| क्षमता अनुपात | दर ∝ 1/समय; A:B की दर = (1/x):(1/y) | "A, B से दोगुना कुशल" वाले प्रश्न |
| M₁D₁H₁/W₁ = M₂D₂H₂/W₂ | (आदमी × दिन × घंटे) / कार्य = स्थिर | आदमी-दिन-घंटे वाले प्रश्न |
| कार्य ∝ आदमी | W₁/W₂ = M₁/M₂ (दिन, घंटे समान हों) | सीधा अनुपात |
| दिन ∝ 1/आदमी | D₁/D₂ = M₂/M₁ (कार्य समान हो) | व्युत्क्रम अनुपात |
| पाइप-टंकी (भरना) | भरने की दर = +1/x | धनात्मक दर |
| पाइप-टंकी (खाली करना) | खाली करने की दर = −1/y | ऋणात्मक दर, रिसाव वाले प्रश्न |
| भरने + रिसाव | शुद्ध दर = 1/x − 1/y | रिसाव वाली टंकी |
| दो पाइप मिलकर भरें | समय = xy / (x + y) | दोनों भरने वाली हों |
| एक भरे, एक खाली करे | समय = xy / (y − x), (y > x) | खाली करने वाली धीमी हो तभी टंकी भरेगी |
| तीन पाइपें | शुद्ध दर = 1/x + 1/y − 1/z | चिन्हों का ध्यान रखें |
| मजदूरी का बँटवारा | मजदूरी ∝ कार्य (दर × दिन) | कुल मजदूरी कार्य-अनुपात में बाँटें |
| समान समय में बँटवारा | मजदूरी का अनुपात = दरों का अनुपात | सबने बराबर दिन काम किया हो तो |
| कुशलता-समय संबंध | A, B से k गुना कुशल ⇒ समय = B का समय / k | कुशलता बढ़े तो समय घटता है |
| काम समय से पहले/बाद | अंतर = \|वास्तविक समय − निर्धारित समय\| | "n दिन पहले पूरा" वाले प्रश्न |
| श्रृंखला नियम (Chain Rule) | M₁D₁T₁E₁/W₁ = M₂D₂T₂E₂/W₂ | कुशलता (E) भी दी हो तो |
| आदमी-औरत-बच्चा | दरें अनुपात से: जैसे 1 आदमी = 2 औरत = 4 बच्चे | समतुल्यता दी हो तो एक ही इकाई में बदलें |
| x दिन काम, फिर अकेला | शेष = 1 − x(संयुक्त दर); समय = शेष/अकेले की दर | "मिलकर शुरू, फिर एक अकेला" पैटर्न |
| दोगुनी/आधी दर | नई दर = k × पुरानी दर ⇒ नया समय = पुराना समय / k | दर बदलने वाले प्रश्न |
