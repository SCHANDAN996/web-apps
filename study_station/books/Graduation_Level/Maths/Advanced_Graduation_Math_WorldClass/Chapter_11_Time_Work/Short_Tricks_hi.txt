# 🪄 समय और कार्य — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 1: "LCM = कुल काम" जादू**            │
│                                             │
│ 🗝️ कीवर्ड: **"काम को LCM बनाओ, मुश्किल भगाओ"**│
│                                             │
│ A = 12 दिन, B = 15 दिन → कुल काम = LCM(12,15)│
│ = 60 यूनिट। A की क्षमता = 5, B की = 4 यूनिट/दिन│
│                                             │
│ याद रखो: **"LCM लो, क्षमता पाओ, भाग दो, उत्तर │
│ आओ!"** — यही Time & Work की आत्मा है।       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 2: "दिन उल्टे, क्षमता सीधी"**         │
│                                             │
│ 🗝️ कीवर्ड: **"जितना ज़्यादा दिन, उतनी कम    │
│ ताकत"**                                     │
│                                             │
│ दिन और क्षमता (efficiency) हमेशा **व्युत्क्रम**│
│ में होते हैं। A : B के दिन = 3 : 4           │
│ ⇒ क्षमता = 4 : 3 (बस उलट दो!)               │
│                                             │
│ म्नेमोनिक: **"दिन-ताकत सीसा-पलटा"** — एक     │
│ बढ़े तो दूसरा घटे।                          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 3: "MDH फॉर्मूला — मज़दूर-दिन-घंटे"** │
│                                             │
│ 🗝️ सूत्र: **M₁D₁H₁/W₁ = M₂D₂H₂/W₂**         │
│                                             │
│ याद रखो: **"मुझे दही हँडी वाली"** —          │
│ M=मुझे(Men), D=दही(Days), H=हँडी(Hours),     │
│ W=वाली(Work)।                               │
│                                             │
│ काम ज़्यादा तो लोग भी ज़्यादा (सीधा), दिन    │
│ ज़्यादा तो लोग कम (उल्टा)।                   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 4: "पाइप-टंकी = भाई-बहन"**            │
│                                             │
│ 🗝️ कीवर्ड: **"भरने वाला भाई (+), खाली करने │
│ वाली बहन (−)"**                             │
│                                             │
│ भरने वाला पाइप = पॉजिटिव काम, निकास पाइप =   │
│ नेगेटिव काम। कुल क्षमता = (+) और (−) का जोड़।│
│                                             │
│ याद रखो: **"प्लस भरता, माइनस मिटाता"**।      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 5: "छोड़कर जाने वाला" ट्रिक**         │
│                                             │
│ 🗝️ कीवर्ड: **"जो भागे, उसका काम पूरा जोड़ो"**│
│                                             │
│ A काम छोड़कर भाग गया? तो मान लो A अंत तक     │
│ रहता — कुल काम में A के बचे दिनों का काम     │
│ **जोड़ दो**, फिर दोनों की क्षमता से भाग दो।  │
│                                             │
│ म्नेमोनिक: **"भगोड़े का बकाया, कुल में जुड़ाया"**│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 6: "बारी-बारी काम = जोड़ी-ब्लॉक"**    │
│                                             │
│ 🗝️ कीवर्ड: **"दो दिन = एक ब्लॉक"**          │
│                                             │
│ A और B एक-एक दिन बारी से काम करें तो 2 दिन  │
│ का काम = (A+B) की क्षमता। कुल काम ÷ ब्लॉक    │
│ काम = पूरे ब्लॉक, शेष को अलग से देखो।        │
│                                             │
│ याद रखो: **"बारी-बारी में ब्लॉक गिनो, शेष    │
│ दिन अलग पिनो"**।                            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 7: "क्षमता अनुपात से दिन"**           │
│                                             │
│ 🗝️ कीवर्ड: **"ताकत 3:2 तो दिन 2:3"**        │
│                                             │
│ A की क्षमता B से दोगुनी ⇒ A को आधे दिन।      │
│ सीधा उल्टा — कुछ नहीं सोचना!                │
│                                             │
│ म्नेमोनिक: **"ताकतवर जल्दी, कमज़ोर देर"**।   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 8: "मज़दूरी = क्षमता का हिस्सा"**     │
│                                             │
│ 🗝️ कीवर्ड: **"जितना काम, उतनी कमाई"**       │
│                                             │
│ ₹900 की मज़दूरी, क्षमता 2:3:4 ⇒ हिस्से भी    │
│ 2:3:4 में। दिनों में नहीं, **क्षमता में** बाँटो!│
│                                             │
│ ट्रैप अलर्ट: दिनों के अनुपात में बाँटना =    │
│ गलत! याद रखो: **"पैसा ताकत देखकर बँटता है"**।│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 9: "x दिन पहले छोड़ा" शॉर्टकट**       │
│                                             │
│ 🗝️ सूत्र: **साथ काम = (कुल काम + भागने वाले│
│ का x दिन का काम) ÷ कुल क्षमता**              │
│                                             │
│ A अंतिम 3 दिन पहले छोड़े, A की क्षमता 5 ⇒    │
│ कुल काम में 15 यूनिट जोड़ो, फिर (A+B) से भाग।│
│                                             │
│ म्नेमोनिक: **"जल्दी-भागी का कर्ज़ा जोड़ो"**। │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 10: "दो पाइप + एक निकास" तिकड़ी**     │
│                                             │
│ 🗝️ कीवर्ड: **"दो भरें, एक बहाए — नेट निकालो"**│
│                                             │
│ भरने वालों की क्षमता जोड़ो, निकास की घटाओ।   │
│ नेट क्षमता से कुल टंकी में भाग।              │
│                                             │
│ याद रखो: **"जोड़-घटा-भाग, तीन कदम सफलता"**।  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 11: "A और B मिलकर = गुणा बटा जोड़"**  │
│                                             │
│ 🗝️ सूत्र: **साथ में समय = (x × y)/(x + y)** │
│                                             │
│ A = 6 दिन, B = 12 दिन ⇒ (6×12)/(6+12) = 4 दिन│
│                                             │
│ म्नेमोनिक: **"ऊपर गुणा, नीचे जोड़ — मिलजुल   │
│ काम छोड़"** (यानी जल्दी खत्म!)।              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 12: "आधा काम = आधा समय नहीं!"**       │
│                                             │
│ 🗝️ ट्रैप अलर्ट: क्षमता बदल जाए तो काम के    │
│ हिस्से अलग-अलग दर से चलते हैं।               │
│                                             │
│ "आधा काम A ने, आधा B ने" ⇒ कुल समय =        │
│ (½ काम ÷ A) + (½ काम ÷ B)।                  │
│                                             │
│ याद रखो: **"हिस्सा-हिस्सा सोचो, एकसाथ मत     │
│ जोड़ो"**।                                    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 13: "आदमी-औरत-बच्चा" कन्वर्ज़न**      │
│                                             │
│ 🗝️ कीवर्ड: **"सबको एक सिक्के में बदलो"**    │
│                                             │
│ 2 आदमी = 3 औरतें ⇒ सबको औरतों (या बच्चों)   │
│ में बदल दो, फिर MDH लगाओ।                   │
│                                             │
│ म्नेमोनिक: **"परिवार एक जाति में, हिसाब     │
│ आसानी में"**।                               │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
