101. If sin θ = 3/5 and θ is acute, find the value of (tan θ + sec θ).
(a) 2 (b) 1 (c) 3/2 (d) 5/4
Answer: (a)
Solution: The tempting wrong option 3/2 comes from adding tan θ = 3/4 and sec θ = 5/4 incorrectly as 3/4 + 3/4. With sin θ = 3/5, cos θ = 4/5, so tan θ = 3/4 and sec θ = 5/4; their sum is 3/4 + 5/4 = 8/4 = 2, so the answer is 2.

102. Find the value of sin² 25° + sin² 65°.
(a) 1/2 (b) 2 (c) 1 (d) 3/4
Answer: (c)
Solution: The trap is to compute each term separately and guess 1/2. Since sin 65° = cos 25°, the expression becomes sin² 25° + cos² 25° = 1, so the answer is 1.

103. If tan θ + cot θ = 2, find the value of tanⁿ θ + cotⁿ θ for any positive integer n.
(a) 2 (b) 2ⁿ (c) n (d) 1
Answer: (a)
Solution: Many students pick 2ⁿ by wrongly raising the whole equation to power n. From tan θ + cot θ = 2 we get tan²θ − 2 tan θ + 1 = 0, so tan θ = 1 and cot θ = 1; hence 1ⁿ + 1ⁿ = 2, so the answer is 2.

104. The value of (1 + tan²θ)(1 − sin θ)(1 + sin θ) is:
(a) 1 (b) 0 (c) sin²θ (d) cos²θ
Answer: (a)
Solution: The tempting wrong option cos²θ comes from stopping after (1 − sin θ)(1 + sin θ) = cos²θ and forgetting the first factor. Since (1 + tan²θ) = sec²θ, the product is sec²θ · cos²θ = 1, so the answer is 1.

105. If 3 sin θ + 4 cos θ = 5, find the value of 4 sin θ − 3 cos θ.
(a) 5 (b) 1 (c) 0 (d) 3
Answer: (c)
Solution: The trap is to assume the second expression also equals 5 by symmetry. Squaring and adding: (3 sin θ + 4 cos θ)² + (4 sin θ − 3 cos θ)² = 9 + 16 = 25, so the second expression squared is 25 − 25 = 0, so the answer is 0.

125. If A + B = 45°, find the value of (1 + tan A)(1 + tan B).
(a) 1 (b) √2 (c) 2 (d) 1/2
Answer: (c)
Solution: The tempting wrong option 1 comes from assuming each factor equals 1. From tan(A + B) = 1 we get tan A + tan B = 1 − tan A tan B; expanding (1 + tan A)(1 + tan B) = 1 + tan A + tan B + tan A tan B = 1 + (1 − tan A tan B) + tan A tan B = 2, so the answer is 2.
