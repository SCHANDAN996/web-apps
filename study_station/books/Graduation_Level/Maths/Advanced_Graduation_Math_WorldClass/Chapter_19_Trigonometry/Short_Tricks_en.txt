## Trick 2: The "0, 1, 2, 3, 4" Table
```
┌─────────────────────────────────────────────┐
│  Angle:   0°    30°    45°    60°    90°    │
│  sin:     0     1/2    √2/2   √3/2   1      │
│                                             │
│  Method: write 0,1,2,3,4 → divide by 4 →    │
│  take square root:                          │
│  √0/2=0, √1/2=1/2, √2/2, √3/2, √4/2=1       │
│  cos = same row READ BACKWARDS              │
│  tan = sin ÷ cos                            │
└─────────────────────────────────────────────┘
```
**Use:** Rebuild the entire standard-angle table in 10 seconds — never memorise it again.

## Trick 9: sin(A+B) — "Sine is a Mixer, Cosine is a Matcher"
```
┌─────────────────────────────────────────────┐
│  sin(A+B) = sinA·cosB + cosA·sinB           │
│  cos(A+B) = cosA·cosB − sinA·sinB           │
│                                             │
│  Trick: "SINE MIXES (sin-cos, cos-sin),     │
│  COSINE MATCHES (cos-cos, sin-sin)          │
│  — and cosine is MINUS-GRUMPY!"             │
└─────────────────────────────────────────────┘
```
**Use:** Never flip the +/− sign in compound-angle formulas again.

## Trick 10: Double Angle — "cos2θ Has Three Faces"
```
┌─────────────────────────────────────────────┐
│  cos2θ = cos²θ − sin²θ                      │
│        = 2cos²θ − 1                         │
│        = 1 − 2sin²θ                         │
│                                             │
│  Trick: "One formula, THREE disguises —     │
│  pick the disguise that matches the data!"  │
│  Given sin? Use 1−2sin²θ. Given cos? 2cos²−1│
└─────────────────────────────────────────────┘
```
**Use:** Choose the fastest form for simplification questions.

└─────────────────────────────────────────────┘
