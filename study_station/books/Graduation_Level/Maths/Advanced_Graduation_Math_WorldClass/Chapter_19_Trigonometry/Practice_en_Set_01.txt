1. What is the value of sin 30°?
(a) 1 (b) √3/2 (c) 1/2 (d) √2/2
Answer: (c)
Solution: From the standard trigonometric table, sin 30° = 1/2. The tempting option √3/2 is the value of sin 60°, not sin 30°, so the answer is 1/2.
Source: NCERT Class 10 Mathematics

2. What is the value of cos 60°?
(a) √3/2 (b) 1/√2 (c) 1/2 (d) 1
Answer: (c)
Solution: cos 60° = 1/2 from the standard table. Note that cos 60° equals sin 30° because they are complementary angles; √3/2 is cos 30°, so the answer is 1/2.
Source: NCERT Class 10 Mathematics

3. What is the value of tan 45°?
(a) 0 (b) 1 (c) 1/√3 (d) √3
Answer: (b)
Solution: tan 45° = sin 45°/cos 45° = 1, since sine and cosine are equal at 45°. The value √3 belongs to tan 60°, so the answer is 1.
Source: NCERT Class 10 Mathematics

4. What is the value of sin²θ + cos²θ?
(a) 0 (b) 2 (c) 1 (d) tan²θ
Answer: (c)
Solution: This is the fundamental Pythagorean identity: sin²θ + cos²θ = 1 for every angle θ. It comes directly from the Pythagoras theorem applied to a right triangle, so the answer is 1.
Source: NCERT Class 10 Mathematics

5. What is the value of tan 60°?
(a) √3 (b) 1 (c) 1/√3 (d) 1/2
Answer: (a)
Solution: tan 60° = sin 60°/cos 60° = (√3/2)/(1/2) = √3. The reciprocal 1/√3 is tan 30°, a common confusion, so the answer is √3.
Source: NCERT Class 10 Mathematics

6. If sin θ = 1/2 and θ is acute, what is θ?
(a) 60° (b) 30° (c) 45° (d) 90°
Answer: (b)
Solution: sin 30° = 1/2, so θ = 30°. The trap is 60°, where cos (not sin) equals 1/2, so the answer is 30°.
Source: NCERT Class 10 Mathematics

7. What is the value of cos 0°?
(a) 1 (b) 1/2 (c) 0 (d) √3/2
Answer: (a)
Solution: cos 0° = 1, since at 0° the adjacent side coincides with the hypotenuse. The value 0 is sin 0°, so the answer is 1.
Source: NCERT Class 10 Mathematics

8. What is the value of sin 90°?
(a) 1 (b) 0 (c) 1/2 (d) √3/2
Answer: (a)
Solution: sin 90° = 1, the maximum value of sine. The value 0 is cos 90°, so the answer is 1.
Source: NCERT Class 10 Mathematics

9. What is sec θ in terms of cos θ?
(a) cos θ (b) sin θ/cos θ (c) 1/sin θ (d) 1/cos θ
Answer: (d)
Solution: secant is the reciprocal of cosine: sec θ = 1/cos θ. The reciprocal of sine is cosecant, not secant, so the answer is 1/cos θ.
Source: NCERT Class 10 Mathematics

10. What is the value of tan 30°?
(a) √3 (b) 1/√3 (c) 1 (d) √3/2
Answer: (b)
Solution: tan 30° = sin 30°/cos 30° = (1/2)/(√3/2) = 1/√3. The value √3 is tan 60°, so the answer is 1/√3.
Source: NCERT Class 10 Mathematics

11. If tan θ = 1 and θ is acute, then θ equals:
(a) 30° (b) 90° (c) 60° (d) 45°
Answer: (d)
Solution: tan 45° = 1, so θ = 45°. At 45° the two legs of the right triangle are equal, making the ratio 1, so the answer is 45°.
Source: NCERT Class 10 Mathematics

12. What is the value of 1 + tan²θ?
(a) sec²θ (b) cosec²θ (c) cot²θ (d) sin²θ
Answer: (a)
Solution: Dividing sin²θ + cos²θ = 1 by cos²θ gives tan²θ + 1 = sec²θ. The identity 1 + cot²θ = cosec²θ is the tempting confusion, so the answer is sec²θ.
Source: NCERT Class 10 Mathematics

13. What is the value of sin 45°?
(a) 1/√2 (b) √3/2 (c) 1/2 (d) 1
Answer: (a)
Solution: sin 45° = 1/√2 (equivalently √2/2). Both 1/2 and √3/2 belong to 30° and 60°, so the answer is 1/√2.
Source: NCERT Class 10 Mathematics

14. What is cot θ equal to?
(a) 1/tan θ (b) 1/sin θ (c) 1/cos θ (d) tan θ
Answer: (a)
Solution: cotangent is the reciprocal of tangent: cot θ = 1/tan θ = cos θ/sin θ. The reciprocal of sine is cosecant, so the answer is 1/tan θ.
Source: NCERT Class 10 Mathematics

15. In a right triangle, sin θ is defined as:
(a) Base/Hypotenuse (b) Hypotenuse/Perpendicular (c) Perpendicular/Base (d) Perpendicular/Hypotenuse
Answer: (d)
Solution: sin θ = Perpendicular (opposite side)/Hypotenuse. Base/Hypotenuse is cos θ and Perpendicular/Base is tan θ, so the answer is Perpendicular/Hypotenuse.
Source: NCERT Class 10 Mathematics

16. What is the value of cos 30°?
(a) 1/2 (b) √3/2 (c) 1/√2 (d) 1
Answer: (b)
Solution: cos 30° = √3/2. The value 1/2 is cos 60°, the complementary-angle trap, so the answer is √3/2.
Source: NCERT Class 10 Mathematics

17. What is the value of cosec 30°?
(a) 2 (b) 1 (c) √2 (d) 2/√3
Answer: (a)
Solution: cosec 30° = 1/sin 30° = 1/(1/2) = 2. The value 2/√3 is cosec 60°, so the answer is 2.
Source: NCERT Class 10 Mathematics

18. What is the value of sec 60°?
(a) √2 (b) 2 (c) 2/√3 (d) 1
Answer: (b)
Solution: sec 60° = 1/cos 60° = 1/(1/2) = 2. The value 2/√3 is sec 30°, so the answer is 2.
Source: NCERT Class 10 Mathematics

19. What is the value of sin 0°?
(a) 1 (b) √3/2 (c) 1/2 (d) 0
Answer: (d)
Solution: sin 0° = 0, since the perpendicular is zero at 0°. The value 1 is cos 0°, so the answer is 0.
Source: NCERT Class 10 Mathematics

20. What is the value of 1 + cot²θ?
(a) sec²θ (b) tan²θ (c) cosec²θ (d) cos²θ
Answer: (c)
Solution: Dividing sin²θ + cos²θ = 1 by sin²θ gives 1 + cot²θ = cosec²θ. The sec²θ identity pairs with tan²θ, not cot²θ, so the answer is cosec²θ.
Source: NCERT Class 10 Mathematics

21. If sin θ = 3/5 and θ is acute, what is the value of cos θ?
(a) 3/4 (b) 4/5 (c) 5/4 (d) 4/3
Answer: (b)
Solution: Using sin²θ + cos²θ = 1, cos²θ = 1 − 9/25 = 16/25, so cos θ = 4/5 (positive since θ is acute). The ratio 3/4 is tan θ, a common slip, so the answer is 4/5.
Source: NCERT Class 10 Mathematics

22. What is the value of sin 60° × cos 30° + cos 60° × sin 30°?
(a) 1/2 (b) √3/2 (c) 0 (d) 1
Answer: (d)
Solution: This is sin(60° + 30°) = sin 90° = 1 by the addition formula. Directly: (√3/2)(√3/2) + (1/2)(1/2) = 3/4 + 1/4 = 1, so the answer is 1.
Source: NCERT Class 11 Mathematics

23. If tan θ = 3/4 and θ is acute, what is the value of sin θ?
(a) 4/5 (b) 5/3 (c) 3/4 (d) 3/5
Answer: (d)
Solution: tan θ = 3/4 means perpendicular = 3k, base = 4k, so hypotenuse = 5k (3-4-5 triangle). Then sin θ = 3k/5k = 3/5. The value 4/5 is cos θ, so the answer is 3/5.
Source: NCERT Class 10 Mathematics

24. What is the value of (1 − sin²θ) × sec²θ?
(a) 0 (b) tan²θ (c) 1 (d) cos²θ
Answer: (c)
Solution: 1 − sin²θ = cos²θ, and sec²θ = 1/cos²θ, so the product is cos²θ × 1/cos²θ = 1. The trap is stopping at cos²θ and forgetting the sec²θ factor, so the answer is 1.
Source: NCERT Class 10 Mathematics

25. The angle of elevation of the top of a tower from a point 30 m away from its foot is 45°. What is the height of the tower?
(a) 30√3 m (b) 15 m (c) 30 m (d) 30/√3 m
Answer: (c)
Solution: tan 45° = height/30, and since tan 45° = 1, height = 30 m. The value 30√3 would result from wrongly using tan 60°, so the answer is 30 m.
Source: NCERT Class 10 Mathematics
