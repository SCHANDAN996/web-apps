# 🪄 त्रिकोणमिति — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 1: "पंडित बद्री प्रसाद, हर हर भोले" │
├─────────────────────────────────────────────┤
│ sin = लंब/कर्ण → **प**ंडित **ब**द्री **प्र**साद │
│ (P/H)                                        │
│ cos = आधार/कर्ण → **ह**र **ह**र **भो**ले     │
│ (B/H)                                        │
│ tan = लंब/आधार → **प**ंडित **ब**द्री **भ**क्त │
│ (P/B)                                        │
│ 💡 एक ही मंत्र में तीनों अनुपात याद!          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 2: "Some People Have Curly Brown   │
│ Hair Through Proper Brushing"               │
├─────────────────────────────────────────────┤
│ S = sin = P/H (Perpendicular/Hypotenuse)    │
│ C = cos = B/H (Base/Hypotenuse)             │
│ T = tan = P/B (Perpendicular/Base)          │
│ 💡 English medium वालों के लिए क्लासिक ट्रिक! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 3: "ALL SILVER TEA CUPS"           │
│ (चतुर्थांश में धनात्मक अनुपात)               │
├─────────────────────────────────────────────┤
│ I चतुर्थांश: **A**LL (सभी +)                 │
│ II चतुर्थांश: **S**ilver (केवल sin, cosec +) │
│ III चतुर्थांश: **T**ea (केवल tan, cot +)     │
│ IV चतुर्थांश: **C**ups (केवल cos, sec +)     │
│ 💡 घड़ी की विपरीत दिशा में A-S-T-C!          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 4: "0, 1, 2, 3, 4 की जड़ें"        │
│ (sin की मान-तालिका)                          │
├─────────────────────────────────────────────┤
│ sin 0° = √0/2 = 0                            │
│ sin 30° = √1/2 = 1/2                         │
│ sin 45° = √2/2 = 1/√2                        │
│ sin 60° = √3/2                               │
│ sin 90° = √4/2 = 1                           │
│ 💡 अंगुलियों पर 0,1,2,3,4 गिनो, वर्गमूल लो, │
│ 2 से भाग दो — sin तैयार! cos = उल्टा क्रम।  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 5: "हथेली की अंगुलियाँ" (Palm Trick)│
├─────────────────────────────────────────────┤
│ बाईं हथेली फैलाओ: कनिष्ठा = 0°, अनामिका = 30°,│
│ मध्यमा = 45°, तर्जनी = 60°, अंगूठा = 90°     │
│ sin θ = √(बाईं ओर की अंगुलियाँ)/2            │
│ cos θ = √(दाईं ओर की अंगुलियाँ)/2            │
│ 💡 परीक्षा हॉल में कैलकुलेटर आपकी हथेली है! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 6: "sin-cos जुड़वाँ, tan-cot उल्टवाँ"│
│ (पूरक कोण / Complementary)                   │
├─────────────────────────────────────────────┤
│ sin(90°−θ) = cos θ  |  cos(90°−θ) = sin θ    │
│ tan(90°−θ) = cot θ  |  sec(90°−θ) = cosec θ  │
│ 💡 "co" वाला बिना-"co" में बदल जाता है:      │
│ sin↔cos, tan↔cot, sec↔cosec — बस 90° घटाओ!  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 7: "तीन भाइयों का वर्ग-वाद"        │
│ (वर्ग सर्वसमिकाएँ)                           │
├─────────────────────────────────────────────┤
│ sin²θ + cos²θ = 1  (मूल भाई)                 │
│ 1 + tan²θ = sec²θ  (tan का भाई sec)          │
│ 1 + cot²θ = cosec²θ (cot का भाई cosec)       │
│ 💡 याद रखो: "t-s जोड़ी, c-c जोड़ी" —         │
│ tan→sec, cot→cosec। बाकी सब इन्हीं से निकलता │
│ है (1 से घटाकर)।                             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 8: "उल्टे का परिवार" (Reciprocal)  │
├─────────────────────────────────────────────┤
│ sin ↔ cosec (दोनों में 's' की आवाज़)         │
│ cos ↔ sec (दोनों में 'co' की शुरुआत)         │
│ tan ↔ cot (दोनों में 't' अक्षर)              │
│ 💡 जाल: cos का उल्टा cosec नहीं, sec है!     │
│ परीक्षक यहीं फँसाता है।                      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 9: "sinA+sinB = सुंदर जोड़ी"       │
│ (योग → गुणनफल सूत्र)                         │
├─────────────────────────────────────────────┤
│ sin C + sin D = 2 sin((C+D)/2)·cos((C−D)/2)  │
│ 💡 याद करने का मंत्र: "दो बार, आधा जोड़,     │
│ आधा घटाव" — पहले sin फिर cos।               │
│ cos C + cos D में दोनों cos; घटाने वालों में │
│ क्रम उल्टा (D−C) और sin में माइनस सावधान!    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 10: "sin 2θ = दोहरी शादी"          │
│ (द्विकोण सूत्र)                              │
├─────────────────────────────────────────────┤
│ sin 2θ = 2 sinθ cosθ (दोनों का मिलन)         │
│ cos 2θ = cos²θ − sin²θ = 2cos²θ−1 = 1−2sin²θ │
│ tan 2θ = 2tanθ/(1−tan²θ)                     │
│ 💡 cos 2θ के तीन रूप: "cos पहले, sin बाद में"│
│ — परीक्षा में वही रूप चुनो जो दिया गया है।  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 11: "ऊँचाई-दूरी का 1-√3 खेल"       │
│ (ऊँचाई और दूरी के प्रश्न)                    │
├─────────────────────────────────────────────┤
│ 30° → tan = 1/√3 (छोटा कोण, छोटा मान)        │
│ 45° → tan = 1 (बराबर का खेल)                 │
│ 60° → tan = √3 (बड़ा कोण, बड़ा मान)          │
│ 💡 "30-45-60 = 1/√3, 1, √3" — तीनों मान      │
│ गुणा 3 के खेल में: ×√3 करते जाओ!             │
│ ऊँचाई = दूरी × tanθ — बस इतना ही आधार।      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 12: "एक ही बिंदु, दो कोण"          │
│ (दो उन्नयन कोण वाली ऊँचाई)                   │
├─────────────────────────────────────────────┤
│ दो कोण 30° और 60° हों, दूरी अंतर d हो, तो:   │
│ ऊँचाई h = d·√3/2 ... (जब 30° दूर से हो)      │
│ सामान्य सूत्र: h = d/(cot α − cot β)         │
│ 💡 "cot बड़े कोण का घटाओ, भाग दो" —          │
│ cot छोटे कोण का बड़ा होता है, इसलिए α<β।    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 13: "π = 180° की पाई" (रेडियन)     │
├─────────────────────────────────────────────┤
│ π rad = 180° → 1° = π/180, 1 rad ≈ 57.3°     │
│ 💡 "पाई खाओ, 180 पाओ" — रेडियन से डिग्री:    │
│ ×180/π; डिग्री से रेडियन: ×π/180।            │
│ याद रखने योग्य: 30°=π/6, 45°=π/4, 60°=π/3,  │
│ 90°=π/2 — "6-4-3-2 घटता हर"                  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 14: "sin बढ़ता, cos घटता"          │
│ (0°–90° में प्रवृत्ति)                       │
├─────────────────────────────────────────────┤
│ 0°→90°: sin ↑ (0 से 1), cos ↓ (1 से 0),      │
│ tan ↑ (0 से ∞)                               │
│ 💡 "sin सीढ़ी चढ़ता है, cos उतरता है,        │
│ tan रॉकेट है" — इसलिए sin 1° < sin 2°,       │
│ पर cos 1° > cos 2°। तुलना वाले प्रश्नों में  │
│ सीधे लगाओ!                                   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🎯 ट्रिक 15: "tan 45° की आत्मा = 1"         │
│ (समान मान वाले कोण)                          │
├─────────────────────────────────────────────┤
│ sin θ = cos θ ⇒ θ = 45°                      │
│ tan θ = cot θ ⇒ θ = 45°                      │
│ sec θ = cosec θ ⇒ θ = 45°                    │
│ 💡 "जुड़वाँ बराबर हों तो 45°" — परीक्षा में  │
│ समीकरण दिखते ही सीधे उत्तर टिक करो!          │
└─────────────────────────────────────────────┘
