## 🎯 Trick 1: The "See-Saw Balance" Rule

```
┌─────────────────────────────────────────────────┐
│  ⚖️ MNEMONIC: "Average is the BALANCE POINT"    │
│                                                 │
│  Think of average as the fulcrum of a see-saw.  │
│  Total EXCESS above average = Total DEFICIT     │
│  below average.                                 │
│                                                 │
│  USE: If one number is 6 above average, the     │
│  others must collectively be 6 BELOW it.        │
│  Never compute the full sum — just balance!     │
└─────────────────────────────────────────────────┘
```

## 🎯 Trick 2: "New Guy Pays the Bill" (Person Joins/Leaves)

```
┌─────────────────────────────────────────────────┐
│  🚪 MNEMONIC: "NEW = OLD + (Change × New Count)"│
│                                                 │
│  When a person JOINS and the average rises:     │
│  New person's value = Old average +             │
│  (Change in average × New number of members)    │
│                                                 │
│  Equivalently: New person's value = New average │
│  + (Change in average × Old number of members)  │
│                                                 │
│  Example: 10 members, avg 20. One joins, avg    │
│  becomes 22. New person's value = 20 + 2×11     │
│  = 42.                                          │
│                                                 │
│  Memory hook: "The NEWCOMER settles EVERYONE's  │
│  account — including his own!"                  │
└─────────────────────────────────────────────────┘
```

