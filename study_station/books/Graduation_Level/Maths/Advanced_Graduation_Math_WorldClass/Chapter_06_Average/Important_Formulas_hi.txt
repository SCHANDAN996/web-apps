# महत्वपूर्ण सूत्र: औसत

## 1. आधारभूत सूत्र
- औसत = (प्रेक्षणों का योग) / n
- कुल योग = औसत * n

## 2. विचलन विधि
- वास्तविक औसत = कल्पित माध्य (A) + (विचलनों का योग) / n

## 3. प्रवेश, निष्कासन एवं प्रतिस्थापन
- नए सदस्य का मान = नया औसत + n * (नया औसत - पुराना औसत)
- निष्कासित सदस्य का मान = पुराना औसत - (n - 1) * (नया औसत - पुराना औसत)
- प्रतिस्थापित नए सदस्य का मान = पुराने सदस्य का मान + n * (नया औसत - पुराना औसत)

## 4. समांतर श्रेढ़ी और विशेष श्रेढ़ियाँ
- समांतर श्रेढ़ी का औसत = (प्रथम पद + अंतिम पद) / 2
- प्रथम n प्राकृतिक संख्याओं का औसत = (n + 1) / 2
- प्रथम n सम प्राकृतिक संख्याओं का औसत = n + 1
- प्रथम n विषम प्राकृतिक संख्याओं का औसत = n
- प्रथम n प्राकृतिक संख्याओं के वर्गों का औसत = (n + 1)(2n + 1) / 6
- प्रथम n प्राकृतिक संख्याओं के घनों का औसत = n(n + 1)^2 / 4

## 5. भारित औसत और मिश्रण
- संयुक्त औसत = (n_1 * A_1 + n_2 * A_2) / (n_1 + n_2)
- n_1 : n_2 = (A_2 - A_avg) : (A_avg - A_1)

## 6. औसत चाल
- दो समान दूरियों के लिए: 2uv / (u + v)
- तीन समान दूरियों के लिए: 3uvw / (uv + vw + wu)
