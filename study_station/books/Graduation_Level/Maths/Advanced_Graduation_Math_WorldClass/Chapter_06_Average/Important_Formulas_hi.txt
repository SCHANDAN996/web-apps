# 📋 औसत (Average) — महत्वपूर्ण सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| मूल औसत | औसत = योग ÷ संख्या | हर प्रश्न की नींव |
| योग | योग = औसत × संख्या | औसत और संख्या दी हो तो |
| प्रथम n प्राकृत संख्याओं का औसत | (n + 1) / 2 | 1 से n तक |
| प्रथम n सम संख्याओं का औसत | n + 1 | 2, 4, 6, … |
| प्रथम n विषम संख्याओं का औसत | n | 1, 3, 5, … |
| प्रथम n वर्गों का औसत | (n + 1)(2n + 1) / 6 | 1², 2², …, n² |
| प्रथम n घनों का औसत | n(n + 1)² / 4 | 1³, 2³, …, n³ |
| क्रमागत संख्याओं का औसत | (पहली + अंतिम) / 2 | समांतर श्रेणी (AP) में |
| n क्रमागत सम/विषम संख्याओं का औसत | बीच की संख्या (n विषम हो तो) | समान अंतर वाली श्रेणी |
| भारित औसत | (w₁x₁ + w₂x₂ + …) / (w₁ + w₂ + …) | समूहों के अलग-अलग औसत मिलाने पर |
| संयुक्त औसत | (n₁a₁ + n₂a₂) / (n₁ + n₂) | दो समूहों का मिश्रण |
| नया सदस्य आने पर | नया मान = नया औसत + (पुरानी संख्या × औसत में परिवर्तन) | शामिल होने/छोड़ने वाले प्रश्न |
| सदस्य छोड़ने पर | छोड़ने वाले का मान = पुराना औसत − (शेष संख्या × औसत में परिवर्तन) | बाहर जाने वाले प्रश्न |
| गलत-सही प्रतिस्थापन | सही योग = गलत योग − गलत मान + सही मान | एक संख्या गलत पढ़ी गई हो |
| औसत में परिवर्तन (प्रतिस्थापन) | Δऔसत = (नया मान − पुराना मान) / कुल संख्या | एक व्यक्ति बदलने पर |
| सभी मानों में k जोड़ने/घटाने पर | नया औसत = पुराना औसत ± k | अनुपातिक परिवर्तन |
| सभी मानों को k से गुणा/भाग करने पर | नया औसत = पुराना औसत × k (या ÷ k) | स्केलिंग प्रश्न |
| क्रिकेट — रन-रेट | नई पारियों का औसत = (कुल रन) / (कुल पारियाँ) | पारी जुड़ने पर औसत बदलना |
| औसत गति (समान दूरी) | 2xy / (x + y) | आना-जाना अलग गति से |
| औसत गति (समान समय) | (x + y) / 2 | समान समय अलग गति से |
| तीन बराबर दूरियों की औसत गति | 3xyz / (xy + yz + zx) | x, y, z गति से तीन चरण |
| आयु-प्रश्न (n वर्ष बाद) | नई औसत आयु = पुरानी औसत + n | सभी की आयु समान रूप से बढ़ती है |
| मिश्रण-औसत (एलीगेशन) | (सस्ता : महँगा) = (महँगा − औसत) : (औसत − सस्ता) | दो मूल्यों का मिश्रण |
| औसत से विचलन | विचलन = मान − औसत; सभी विचलनों का योग = 0 | जाँच/शॉर्टकट में |
| मध्य पद (2n+1 क्रमागत संख्याएँ) | औसत = (n + 1)वाँ पद | विषम संख्या में पद हों तो |
