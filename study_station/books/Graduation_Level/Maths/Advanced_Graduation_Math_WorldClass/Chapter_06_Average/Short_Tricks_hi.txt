# 🪄 औसत — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

**🎯 ट्रिक 1: "बंटवारा नियम" — औसत की असली पहचान**

```
┌─────────────────────────────────────────────┐
│  औसत = "सबको बराबर बाँटो"                    │
│  याद करो: माँ ने रोटियाँ बाँटीं —             │
│  कुल रोटियाँ ÷ लोग = हर एक का हिस्सा          │
│  ➤ औसत = योग ÷ संख्या  (यही जन्म-सूत्र है)   │
└─────────────────────────────────────────────┘
```
कीवर्ड: **"योग बटे गिनती"** — बस यही एक लाइन पूरे अध्याय की जड़ है।

---

**🎯 ट्रिक 2: "नया मेहमान" ट्रिक — नया व्यक्ति आने पर**

```
┌─────────────────────────────────────────────┐
│  नया औसत जानना हो तो सोचो:                  │
│  "मेहमान कितना लाया?"                        │
│  ➤ नया व्यक्ति का मान = पुराना औसत ±         │
│    (कुल लोगों पर बँटा असर)                   │
│  औसत बढ़े तो मेहमान "अमीर",                  │
│  घटे तो "गरीब" — पुराने औसत से तुलना करो।    │
└─────────────────────────────────────────────┘
```
सूत्र-याद: **नए का मान = पुराना औसत + (बदलाव × नई कुल संख्या)**

**🎯 ट्रिक 3: "बदली वाला खिलाड़ी" — एक व्यक्ति के बदलने पर**

```
┌─────────────────────────────────────────────┐
│  क्रिकेट टीम में खिलाड़ी बदला गया!            │
│  ➤ औसत में बदलाव = (नया − पुराना) ÷ कुल संख्या│
│  याद करो: "फर्क बटे टीम"                     │
│  नया खिलाड़ी भारी → औसत ऊपर                  │
│  नया खिलाड़ी हल्का → औसत नीचे                │
└─────────────────────────────────────────────┘
```

---

**🎯 ट्रिक 4: "सीढ़ी-बीच" ट्रिक — क्रमागत संख्याओं का औसत**

```
┌─────────────────────────────────────────────┐
│  क्रमागत (लगातार) संख्याएँ = सीढ़ी के डंडे     │
│  ➤ औसत = बीच वाला डंडा!                      │
│  विषम संख्या हो → ठीक बीच की संख्या           │
│  सम संख्या हो → बीच की दो का औसत             │
│  शॉर्टकट: (पहली + आखिरी) ÷ 2                │
│  याद करो: "अंत जोड़ो, आधा करो"               │
└─────────────────────────────────────────────┘
```

---

**🎯 ट्रिक 5: "1 से n तक" — प्राकृत संख्याओं का औसत**

```
┌─────────────────────────────────────────────┐
│  1, 2, 3 … n का औसत = (n+1)/2                │
│  याद करो: "n को एक बढ़ाओ, आधा पाओ"           │
│  जैसे 1 से 99 तक → (99+1)/2 = 50 ✔          │
└─────────────────────────────────────────────┘
```

---

**🎯 ट्रिक 6: "वर्ग-घन जोड़ी" — वर्गों और घनों के औसत**

```
┌─────────────────────────────────────────────┐
│  पहले n वर्गों का औसत = (n+1)(2n+1)/6        │
│  पहले n घनों का औसत  = n(n+1)²/4             │
│  म्नेमोनिक: "वर्ग में 6 नीचे, घन में 4 नीचे"  │
│  वर्ग = छः का खेल, घन = चार का खेल           │
└─────────────────────────────────────────────┘
```

---

**🎯 ट्रिक 7: "सम-विषम भाई" — सम/विषम संख्याओं का औसत**

```
┌─────────────────────────────────────────────┐
│  पहली n सम संख्याओं का औसत = n + 1           │
│  पहली n विषम संख्याओं का औसत = n             │
│  याद करो: "सम एक आगे, विषम वहीं खड़ा"        │
│  सम = n+1 (आगे बढ़ा), विषम = n (वहीं रुका)   │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 8: "तराजू संतुलन" — विचलन (Deviation) विधि**

```
┌─────────────────────────────────────────────┐
│  बड़ी संख्याओं का औसत? कोई भी "अनुमानित औसत" │
│  मान लो (जैसे 50), फिर हर संख्या का फर्क लो। │
│  ➤ असली औसत = अनुमानित + (कुल फर्क ÷ संख्या) │
│  याद करो: "पहले अंदाज़ा, फिर हिसाब"          │
│  परीक्षा में समय बचाने वाली ट्रिक!           │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 9: "उम्र-पार्टी" ट्रिक — आयु वाले प्रश्न**

```
┌─────────────────────────────────────────────┐
│  "x वर्ष बाद/पहले" वाले प्रश्नों में:        │
│  ➤ हर व्यक्ति की उम्र बदलती है,              │
│    इसलिए कुल योग में (±x × संख्या) जोड़ो।    │
│  याद करो: "जितने लोग, उतनी बार उम्र जोड़ो"   │
│  एक भूलोगे तो पूरा प्रश्न गलत!               │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 10: "मिश्रण-कटोरा" — भारित औसत (Weighted Average)**

```
┌─────────────────────────────────────────────┐
│  दो ग्रुप मिलें तो:                          │
│  ➤ संयुक्त औसत = (n₁a₁ + n₂a₂) ÷ (n₁ + n₂)   │
│  याद करो: "हर ग्रुप अपना वज़न लेकर आता है"    │
│  बड़ा ग्रुप औसत को अपनी ओर खींचता है!        │
│  (जैसे दूध-पानी: जो ज़्यादा, उसी का रंग)      │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 11: "रन-मशीन" — क्रिकेट औसत प्रश्न**

```
┌─────────────────────────────────────────────┐
│  बल्लेबाज़ का औसत बढ़ाने/घटाने वाले प्रश्न:  │
│  ➤ नई पारी के रन = नया औसत × कुल पारियाँ     │
│       − पुराना औसत × पुरानी पारियाँ          │
│  याद करो: "नया कुल − पुराना कुल = आज के रन"  │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 12: "गलती-सुधार" ट्रिक — गलत पढ़ी गई संख्या**

```
┌─────────────────────────────────────────────┐
│  कोई संख्या गलत लिखी गई हो तो:             │
│  ➤ सही योग = गलत योग − गलत संख्या + सही संख्या│
│  याद करो: "गलत हटाओ, सही जोड़ो"              │
│  फिर सही योग ÷ संख्या = सही औसत              │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 13: "गति-दोहराव" — समान दूरी की औसत गति**

```
┌─────────────────────────────────────────────┐
│  समान दूरी, दो गतियाँ a और b:               │
│  ➤ औसत गति = 2ab/(a+b)  (हरात्मक माध्य)      │
│  याद करो: "दोगुना गुणा, बटे जोड़"            │
│  ⚠️ ट्रैप: (a+b)/2 कभी नहीं!                 │
│  तीन गतियाँ हों तो: 3abc/(ab+bc+ca)          │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 14: "± गुणन" — औसत में बदलाव का त्वरित सूत्र**

```
┌─────────────────────────────────────────────┐
│  औसत में x की बढ़ोतरी = कुल योग में          │
│  x × (कुल संख्या) की बढ़ोतरी                 │
│  याद करो: "औसत का बदलाव × गिनती =            │
│            योग का बदलाव"                     │
│  यही एक लाइन अनेक प्रश्न सुलझा देती है!      │
└─────────────────────────────────────────────┘
```

**🎯 ट्रिक 15: "A-Z मास्टर की" — पूरे अध्याय का एक्रोनिम**

```
┌─────────────────────────────────────────────┐
│  "योग-गिनती-बदलाव-बीच"                       │
│  योग ÷ गिनती = औसत (मूल सूत्र)               │
│  बदलाव × गिनती = योग-बदलाव (नया/बदला व्यक्ति) │
│  बीच = क्रमागत संख्याओं का औसत               │
│  ये 4 शब्द = औसत अध्याय का मुख्य खेल!        │
└─────────────────────────────────────────────┘
```
