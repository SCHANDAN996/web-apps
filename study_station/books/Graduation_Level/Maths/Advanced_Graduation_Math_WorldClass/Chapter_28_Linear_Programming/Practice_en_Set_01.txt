1. In a linear programming problem, the objective function is always:
(a) Linear (b) Exponential (c) Quadratic (d) Logarithmic
Answer: (a)
Solution: By definition, a linear programming problem has a linear objective function and linear constraints. Quadratic or exponential objectives belong to non-linear programming, so the answer is Linear.
Source: NCERT Class 12 Mathematics (Linear Programming)

2. The region satisfying all the constraints of an LPP, including non-negativity restrictions, is called the:
(a) Feasible region (b) Convex hull (c) Bounded region (d) Optimal region
Answer: (a)
Solution: The common region determined by all constraints and x ≥ 0, y ≥ 0 is the feasible region. "Optimal region" is a tempting but wrong term — optimality refers to the best point, not the whole region. The answer is Feasible region.
Source: NCERT Class 12 Mathematics (Linear Programming)

3. The constraints x ≥ 0 and y ≥ 0 in an LPP are known as:
(a) Non-negativity constraints (b) Redundant constraints (c) Structural constraints (d) Boundary constraints
Answer: (a)
Solution: Since quantities like production units cannot be negative, x ≥ 0, y ≥ 0 are called non-negativity constraints. Structural constraints come from the actual problem conditions, so the answer is Non-negativity constraints.
Source: NCERT Class 12 Mathematics (Linear Programming)

4. The feasible region of an LPP is always:
(a) A circle (b) A convex polygon (c) A parabola (d) A hyperbola
Answer: (b)
Solution: Linear constraints produce half-planes, whose intersection is a convex polygon (or an unbounded convex region). Curved shapes like circles or parabolas cannot arise from linear inequalities, so the answer is A convex polygon.
Source: NCERT Class 12 Mathematics (Linear Programming)

5. The corner points of the feasible region are also called:
(a) Inflection points (b) Saddle points (c) Extreme points (d) Critical points
Answer: (c)
Solution: The vertices of the feasible polygon are called extreme points, and the optimal value of a bounded LPP occurs at one of them. Saddle points belong to game theory, so the answer is Extreme points.
Source: NCERT Class 12 Mathematics (Linear Programming)

6. The fundamental theorem of linear programming states that if an optimal solution exists for a bounded feasible region, it occurs at:
(a) The centre of the region (b) Any interior point (c) At least one corner point (d) The midpoint of an edge
Answer: (c)
Solution: The corner point theorem guarantees the optimum lies at a vertex of the feasible region. Interior points can never beat the best corner for a linear objective, so the answer is At least one corner point.
Source: NCERT Class 12 Mathematics (Linear Programming)

7. Which of the following is a valid objective function in an LPP?
(a) Z = x² + y (b) Z = x/y (c) Z = 3x + 5y (d) Z = xy
Answer: (c)
Solution: Only Z = 3x + 5y is linear in the decision variables. Terms like x², xy and x/y make the function non-linear, so the answer is Z = 3x + 5y.
Source: NCERT Class 12 Mathematics (Linear Programming)

8. The first step in solving an LPP graphically is to:
(a) Find the optimal value (b) Convert inequalities into equations and draw the lines (c) Evaluate the objective at the origin (d) Shade the unbounded region
Answer: (b)
Solution: Graphical solution begins by replacing each inequality with an equation, drawing the boundary lines, and then shading half-planes. Evaluating the objective comes later, so the answer is Convert inequalities into equations and draw the lines.

9. For the constraint 2x + 3y ≤ 6, the feasible half-plane contains:
(a) The origin side of the line (b) Only points above the line (c) Only points on the line (d) The side away from the origin
Answer: (a)
Solution: Testing the origin: 2(0) + 3(0) = 0 ≤ 6, which is true, so the origin side is shaded. Choosing the side away from the origin is the common trap, so the answer is The origin side of the line.

10. In a maximisation problem, if the feasible region is bounded, the maximum value of Z:
(a) Always occurs at the origin (b) Occurs at the midpoint of the longest side (c) Does not exist (d) Occurs at a corner point
Answer: (d)
Solution: For a bounded feasible region, both maximum and minimum of a linear objective occur at corner points. The origin gives the optimum only in special cases, so the answer is Occurs at a corner point.
Source: NCERT Class 12 Mathematics (Linear Programming)

11. Maximize Z = 3x + 4y subject to x + y ≤ 4, x ≥ 0, y ≥ 0. The maximum value of Z is:
(a) 12 (b) 16 (c) 14 (d) 10
Answer: (b)
Solution: Corner points are (0,0), (4,0), (0,4) with Z values 0, 12, 16. The tempting answer 12 comes from stopping at (4,0), but checking all corners gives the maximum 16 at (0,4), so the answer is 16.
Source: NCERT Class 12 Mathematics (Linear Programming)

12. Minimize Z = x + 2y subject to x + y ≥ 3, x ≥ 0, y ≥ 0. The minimum value of Z is:
(a) 4 (b) 6 (c) 2 (d) 3
Answer: (d)
Solution: Corner points of the feasible region are (3,0) and (0,3), with Z values 3 and 6. The trap is picking 6 by testing only one corner; the minimum is 3 at (3,0), so the answer is 3.
Source: NCERT Class 12 Mathematics (Linear Programming)

13. If the feasible region of an LPP is empty, the problem is said to be:
(a) Unbounded (b) Degenerate (c) Infeasible (d) Redundant
Answer: (c)
Solution: When no point satisfies all constraints simultaneously, the LPP is infeasible. Unbounded refers to an infinitely large feasible region, a different situation, so the answer is Infeasible.
Source: NCERT Class 12 Mathematics (Linear Programming)

14. The variables x and y in an LPP are called:
(a) Slack variables (b) Decision variables (c) Dummy variables (d) Surplus variables
Answer: (b)
Solution: The unknowns whose values we determine to optimise the objective are decision variables. Slack and surplus variables appear later in the simplex method, so the answer is Decision variables.
Source: NCERT Class 12 Mathematics (Linear Programming)

15. A diet problem in linear programming is usually a problem of:
(a) Both always (b) Maximisation (c) Minimisation (d) Neither
Answer: (c)
Solution: Diet problems seek the minimum cost of food meeting nutritional requirements, so they are minimisation problems. Assuming every LPP maximises profit is the trap, so the answer is Minimisation.

16. The graphical method of solving an LPP is practical only when the number of decision variables is:
(a) One (b) Two (c) Three (d) Any number
Answer: (b)
Solution: Graphing requires two axes, so the graphical method works for two decision variables. For more variables the simplex method is used, so the answer is Two.

17. Maximize Z = 5x + 3y subject to x ≤ 4, y ≤ 5, x ≥ 0, y ≥ 0. The maximum value of Z is:
(a) 35 (b) 15 (c) 20 (d) 32
Answer: (a)
Solution: Corner points are (0,0), (4,0), (4,5), (0,5) with Z values 0, 20, 35, 15. The trap is 20 from using only the x-limit; the maximum is 35 at (4,5), so the answer is 35.

18. Which of the following points lies in the feasible region of x + y ≤ 5, x ≥ 0, y ≥ 0?
(a) (3, 3) (b) (5, 1) (c) (4, 2) (d) (2, 2)
Answer: (d)
Solution: Check each point: (3,3) gives 6 > 5, (4,2) gives 6 > 5, (5,1) gives 6 > 5; only (2,2) gives 4 ≤ 5. The trap is checking non-negativity only and ignoring the main constraint, so the answer is (2, 2).
Source: NCERT Class 12 Mathematics (Linear Programming)

19. In an LPP, the line ax + by = c drawn for different values of c to find the optimum is called:
(a) A constraint line (b) An iso-profit (or iso-cost) line (c) A boundary line (d) A feasible line
Answer: (b)
Solution: Parallel lines of the objective function Z = ax + by for various Z values are iso-profit or iso-cost lines; the optimum is where the farthest such line last touches the feasible region. Constraint lines bound the region, so the answer is An iso-profit (or iso-cost) line.
Source: NCERT Class 12 Mathematics (Linear Programming)

20. If two corner points of the feasible region both give the same optimal value of Z, then:
(a) The problem has no solution (b) The region must be unbounded (c) The problem is infeasible (d) Every point on the segment joining them is optimal
Answer: (d)
Solution: A linear objective that is equal at two vertices is constant along the entire edge joining them, giving infinitely many optimal solutions. This is called alternative optima, not infeasibility, so the answer is Every point on the segment joining them is optimal.
Source: NCERT Class 12 Mathematics (Linear Programming)

21. Maximize Z = 4x + 6y subject to x + y ≤ 5, x + 2y ≤ 8, x ≥ 0, y ≥ 0. The maximum value of Z is:
(a) 20 (b) 24 (c) 26 (d) 28
Answer: (c)
Solution: Corner points are (0,0), (5,0), (0,4), and the intersection of x + y = 5 and x + 2y = 8, which is (2,3); Z values are 0, 20, 24, 26. The trap is 24 from testing only the axis intercepts; the maximum is 26 at (2,3), so the answer is 26.

Solution: Corner points are (6,0), (0,6), and the intersection of x + 2y = 6 and 2x + y = 6, which is (2,2); Z values are 18, 12, 10. The trap is 12 from testing only intercepts; the minimum is 10 at (2,2), so the answer is 10.

23. Maximize Z = 2x + 3y subject to x + y ≤ 4, x ≥ 0, y ≥ 0. If the constraint y ≤ 3 is added, the maximum value of Z:
(a) Decreases (b) Becomes unbounded (c) Increases (d) Remains the same
Answer: (a)
Solution: Originally the maximum is 12 at (0,4). Adding y ≤ 3 removes (0,4); the new corner points are (0,3), (1,3) and (4,0) with Z values 9, 11 and 8, so the best is now 11 at (1,3). The trap is assuming an extra constraint never changes anything; tightening the feasible region can only lower or keep the maximum, and here it falls from 12 to 11, so the answer is Decreases.
Source: NCERT Class 12 Mathematics (Linear Programming)

24. A manufacturer produces two items A and B. Profit is ₹40 per unit of A and ₹50 per unit of B. Machine time allows at most 100 units total, and at least 20 units of A must be made. If x = units of A and y = units of B, the correct model is:
(a) Max Z = 40x + 50y; x + y ≤ 100, x ≥ 20, y ≥ 0 (b) Max Z = 50x + 40y; x + y ≤ 100, x ≥ 20, y ≥ 0 (c) Max Z = 40x + 50y; x + y ≥ 100, x ≥ 20, y ≥ 0 (d) Min Z = 40x + 50y; x + y ≤ 100, x ≥ 20, y ≥ 0
Answer: (a)
Solution: Profit on A is ₹40 and on B is ₹50, so Z = 40x + 50y; "at most 100" gives x + y ≤ 100, and "at least 20 of A" gives x ≥ 20. The trap is swapping the profits, so the answer is Max Z = 40x + 50y; x + y ≤ 100, x ≥ 20, y ≥ 0.
Source: NCERT Class 12 Mathematics (Linear Programming)

25. Maximize Z = 3x + 3y subject to 2x + y ≤ 8, x + 2y ≤ 8, x ≥ 0, y ≥ 0. The number of optimal solutions is:
(a) Infinitely many (b) Exactly two (c) Zero (d) Exactly one
Answer: (d)
Solution: Corner points are (0,0), (4,0), (0,4), and the intersection of 2x + y = 8 and x + 2y = 8, which is (8/3, 8/3); Z values are 0, 12, 12, 16. The maximum 16 occurs only at (8/3, 8/3). The trap is assuming equal coefficients of x and y force multiple optima; here the answer is Exactly one.
Source: NCERT Class 12 Mathematics (Linear Programming)
