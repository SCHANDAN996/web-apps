126. Maximise Z = 6x + 2y subject to 2x + 3y ≤ 18, 3x + 3y ≤ 24, x ≥ 0, y ≥ 0. What is the maximum value of Z?
(a) 54 (b) 48 (c) 0 (d) 47
Answer: (b)
Solution: The feasible region is bounded; check Z at each corner point: (0, 0) → 0; (0, 6) → 12; (6, 2) → 40; (8, 0) → 48. The largest value is 48, at (8, 0). So the answer is 48.
