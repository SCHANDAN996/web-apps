हल: जाल यह है कि "अपरिबद्ध" को "असुसंगत" से भ्रमित करें — अपरिबद्ध क्षेत्र में भी सुसंगत बिंदु होते हैं। असुसंगतता का अर्थ है प्रतिबंध समुच्चय रिक्त है, जैसे x + y ≤ 2 के साथ x + y ≥ 5, इसलिए उत्तर एक-दूसरे का खंडन करने वाले प्रतिबंध है, जिनसे कोई बिंदु सभी को संतुष्ट नहीं करता।

44. 2x + y ≤ 6, x ≤ 2, x ≥ 0, y ≥ 0 के अधीन Z = 11x + 7y का अधिकतमीकरण करें। इष्टतम हल है:
(a) (2, 2) जहाँ Z = 36 (b) (3, 0) जहाँ Z = 33 (c) (0, 6) जहाँ Z = 42 (d) (2, 0) जहाँ Z = 22
उत्तर: (c)
हल: जाल (2, 2) है जहाँ Z = 36, क्योंकि यह दोनों प्रतिबंधों को पूर्णतः उपयोग करता है। सभी कोनों की जाँच: (0, 0) पर 0, (2, 0) पर 22, (2, 2) पर 36, और (0, 6) सुसंगत है क्योंकि 2(0) + 6 = 6 ≤ 6 और 0 ≤ 2, जहाँ Z = 42, इसलिए उत्तर (0, 6) जहाँ Z = 42 है।
स्रोत: NCERT कक्षा 12 गणित, अध्याय 12 (रैखिक प्रोग्रामन)

(a) 5000 − y (b) 6000 − x (c) 5000 − x (d) x + y − 6000
उत्तर: (c)
हल: जाल यह है कि P की माँग के बजाय A का स्टॉक 6000 उपयोग करें। दुकान P को ठीक 5000 किग्रा चाहिए, जिसमें से x A से आता है, इसलिए शेष B से आना चाहिए, और उत्तर 5000 − x है।

47. Z = 3x + 9y के लिए सुसंगत कोनीय बिंदु (0, 0), (5, 0), (3, 4), (0, 5) हैं। अधिकतम मान और इष्टतम हलों की संख्या है:
(a) 45, ठीक एक (b) 45, अनंत (c) 51, ठीक एक (d) 15, अनंत

48. एक खिलौना कंपनी प्रकार A और प्रकार B के खिलौने बनाती है। प्रत्येक A में 5 मिनट कटाई और 10 मिनट असेंबली लगती है; प्रत्येक B में 8 मिनट कटाई और 8 मिनट असेंबली लगती है। कटाई के लिए प्रतिदिन 3 घंटे 20 मिनट और असेंबली के लिए 4 घंटे उपलब्ध हैं। प्रतिबंध (x = A की संख्या, y = B की संख्या) हैं:
(a) 5x + 8y ≤ 200, 10x + 8y ≤ 240, x, y ≥ 0 (b) 5x + 8y ≤ 240, 10x + 8y ≤ 200, x, y ≥ 0 (c) 5x + 10y ≤ 200, 8x + 8y ≤ 240, x, y ≥ 0 (d) 10x + 5y ≤ 200, 8x + 8y ≤ 240, x, y ≥ 0
उत्तर: (a)
हल: जाल यह है कि समय सीमाएँ उलट दें: 3 घंटे 20 मिनट = 200 मिनट कटाई की सीमा है और 4 घंटे = 240 मिनट असेंबली की। कटाई से 5x + 8y ≤ 200 और असेंबली से 10x + 8y ≤ 240, इसलिए उत्तर 5x + 8y ≤ 200, 10x + 8y ≤ 240, x, y ≥ 0 है।
