# 📋 महत्वपूर्ण सूत्र — रैखिक प्रोग्रामन (Linear Programming)

| सूत्र का नाम | सूत्र | एक-पंक्ति उपयोग-संकेत |
|---|---|---|
| सामान्य LP रूप (General LP Form) | अधिकतम/न्यूनतम Z = c₁x₁ + c₂x₂, शर्तें: aᵢ₁x₁ + aᵢ₂x₂ (≤, =, ≥) bᵢ, x₁, x₂ ≥ 0 | हर LPP की मानक संरचना |
| उद्देश्य फलन (Objective Function) | Z = ax + by | वह राशि जिसे अधिकतम या न्यूनतम करना है |
| अऋणात्मकता शर्तें (Non-negativity Constraints) | x ≥ 0, y ≥ 0 | हल को प्रथम चतुर्थांश तक सीमित करती हैं |
| सुसंगत क्षेत्र (Feasible Region) | सभी शर्तों + अऋणात्मकता को संतुष्ट करने वाला उभयनिष्ठ क्षेत्र | हल इस क्षेत्र के अंदर/सीमा पर होना चाहिए |
| कोनीय बिंदु प्रमेय (Corner Point Theorem) | इष्टतम Z सुसंगत क्षेत्र के किसी शीर्ष (कोनीय बिंदु) पर प्राप्त होता है | Z का मान केवल कोनीय बिंदुओं पर निकालें |
| इष्टतम मान — परिबद्ध क्षेत्र (Optimal Value, Bounded Region) | Z_max या Z_min = सभी कोनीय बिंदुओं पर Z का अधिकतम/न्यूनतम | प्रत्येक शीर्ष पर Z-मानों की तुलना करें |
| अपरिबद्ध क्षेत्र परीक्षण (Unbounded Region Test) | यदि खुला अर्ध-तल ax + by > M (या < m) सुसंगत क्षेत्र से उभयनिष्ठ बिंदु रखता है, तो कोई अधिकतम (या न्यूनतम) नहीं | रेखा Z = M खींचकर ओवरलैप जाँचें |
| उद्देश्य रेखा की ढलान (Slope of Objective Line) | ढलान = −a/b (Z = ax + by के लिए) | इष्टतम शीर्ष खोजने के लिए शर्त-रेखाओं की ढलान से तुलना करें |
| शर्त की सीमा रेखा (Constraint Boundary Line) | aᵢ₁x₁ + aᵢ₂x₂ = bᵢ | सीमा रेखा खींचने के लिए असमिका को समीकरण में बदलें |
| परीक्षण-बिंदु विधि (Test-Point Method) | असमिका में (0,0) रखें; सत्य हो → मूल बिंदु वाला पक्ष छायांकित करें | सही अर्ध-तल छायांकित करने का त्वरित तरीका |
| रेखा का X-अंतःखंड (X-intercept) | x = b/a₁ (y = 0 रखकर) | शर्त-रेखाओं को शीघ्र आलेखित करने के लिए |
| रेखा का Y-अंतःखंड (Y-intercept) | y = b/a₂ (x = 0 रखकर) | शर्त-रेखाओं को शीघ्र आलेखित करने के लिए |
| विहित रूप (Canonical Form) | अधिकतम Z = cᵀX, AX ≤ b, X ≥ 0 (सभी शर्तें ≤, सभी चर ≥ 0) | स्लैक चर जोड़ने से पहले का रूप |
| मानक रूप — सिम्प्लेक्स (Standard Form, Simplex) | अधिकतम Z = cᵀX, AX = b, X ≥ 0 (सभी शर्तें समीकरण, b ≥ 0) | स्लैक/सरप्लस चर जोड़ने के बाद का रूप; सिम्प्लेक्स इसी पर चलता है |
| स्लैक चर (Slack Variable) | a₁x₁ + a₂x₂ + s = b, s ≥ 0 (≤ शर्त के लिए) | ≤ असमिका को समीकरण में बदलता है |
| सरप्लस चर (Surplus Variable) | a₁x₁ + a₂x₂ − s = b, s ≥ 0 (≥ शर्त के लिए) | ≥ असमिका को समीकरण में बदलता है |
| आधारी सुसंगत हल (Basic Feasible Solution) | अधिकतम m धनात्मक चरों वाला हल (m = शर्तों की संख्या) | किसी कोनीय बिंदु के तदनुरूप |
| सिम्प्लेक्स इष्टतमता शर्त (Simplex Optimality Condition) | सभी Cⱼ − Zⱼ ≤ 0 (अधिकतमीकरण में) | जब कोई धनात्मक Cⱼ − Zⱼ न रहे तो रुकें |
| प्रवेशी चर (Entering Variable) | सबसे अधिक धनात्मक Cⱼ − Zⱼ वाला स्तंभ | कौन-सा चर आधार में प्रवेश करेगा |
| बाहर जाने वाला चर — अनुपात परीक्षण (Leaving Variable, Ratio Test) | न्यूनतम अनुपात = min { bᵢ / aᵢₖ , aᵢₖ > 0 } | कौन-सा चर आधार से बाहर जाएगा |
| पिवट अवयव (Pivot Element) | प्रवेशी स्तंभ और बाहर जाने वाली पंक्ति का प्रतिच्छेदन | जिसके इर्द-गिर्द पंक्ति संक्रियाएँ होती हैं |
| प्राइमल की द्वैत (Dual of a Primal) | प्राइमल: अधिकतम cᵀX, AX ≤ b → द्वैत: न्यूनतम bᵀY, AᵀY ≥ c, Y ≥ 0 | हर LPP की एक युग्मित द्वैत समस्या होती है |
| द्वैत चरों की संख्या | = प्राइमल शर्तों की संख्या | m प्राइमल शर्तें → m द्वैत चर |
| दुर्बल द्वैतता (Weak Duality) | cᵀX ≤ bᵀY (प्राइमल अधिकतम, द्वैत न्यूनतम) | प्राइमल उद्देश्य मान द्वैत से कभी अधिक नहीं |
| प्रबल द्वैतता (Strong Duality) | इष्टतमता पर: Z_primal = Z_dual | दोनों इष्टतम मान बराबर होते हैं |
| पूरक शिथिलता (Complementary Slackness) | xⱼ·(j-वीं शर्त का द्वैत स्लैक) = 0; yᵢ·(i-वीं शर्त का प्राइमल स्लैक) = 0 | इष्टतम प्राइमल और द्वैत हलों को जोड़ता है |
| सम-लाभ / सम-लागत रेखा (Iso-profit / Iso-cost Line) | ax + by = k (k बदलने पर समांतर रेखाएँ) | इष्टतम खोजने के लिए रेखा को बाहर की ओर खिसकाएँ |
| निरर्थक शर्त (Redundant Constraint) | ऐसी शर्त जिसे हटाने से सुसंगत क्षेत्र नहीं बदलता | आलेखीय रूप से पहचानें; गणना में छोड़ दें |
| असंगतता शर्त (Infeasibility Condition) | सुसंगत क्षेत्र = ∅ (रिक्त) | शर्तें परस्पर विरोधी — कोई हल नहीं |
| अनेक इष्टतम हल (Multiple Optimal Solutions) | उद्देश्य रेखा किसी बंधी हुई शर्त के किनारे के समांतर हो | उस किनारे के सभी बिंदु इष्टतम होते हैं |
| अपभ्रष्टता (Degeneracy) | आधारी सुसंगत हल में कोई आधारी चर = 0 | सिम्प्लेक्स में चक्रीकरण (cycling) करा सकती है |
| बिग-M विधि का उद्देश्य फलन (Big-M Method Objective) | न्यूनतम Z = cᵀX + M·(कृत्रिम चरों का योग) | कृत्रिम चरों पर भारी दंड दें |
| आहार समस्या रूप (Diet Problem Form) | न्यूनतम Z = Σ cⱼxⱼ, Σ aᵢⱼxⱼ ≥ bᵢ, xⱼ ≥ 0 | न्यूनतम पोषण पूरा करते हुए लागत न्यूनतम करें |
| मिश्रण/उत्पादन रूप (Blending/Production Form) | अधिकतम Z = Σ pⱼxⱼ, Σ aᵢⱼxⱼ ≤ bᵢ, xⱼ ≥ 0 | संसाधन सीमाओं के अंतर्गत लाभ अधिकतम करें |
| परिवहन समस्या (Transportation Problem) | न्यूनतम Z = ΣΣ cᵢⱼxᵢⱼ, Σⱼ xᵢⱼ = aᵢ (आपूर्ति), Σᵢ xᵢⱼ = bⱼ (मांग) | संतुलित तब जब कुल आपूर्ति = कुल मांग |
| संतुलित परिवहन शर्त (Balanced Transportation Condition) | Σ aᵢ = Σ bⱼ | असंतुलित हो तो डमी पंक्ति/स्तंभ जोड़ें |
| परिवहन में आधारी सेल (Basic Cells in Transportation) | m + n − 1 आवंटन (अनपभ्रष्ट) | MODI/u-v विधि लगाने से पहले जाँचें |
