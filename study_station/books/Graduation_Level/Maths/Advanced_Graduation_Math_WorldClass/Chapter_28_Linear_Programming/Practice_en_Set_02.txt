26. A linear programming problem has the objective function Z = 3x + 4y. If the feasible region is bounded with corner points (0, 0), (4, 0), (2, 3) and (0, 5), the maximum value of Z is:
(a) 12 (b) 18 (c) 24 (d) 20
Answer: (d)
Solution: The trap is stopping at (2, 3), where Z = 6 + 12 = 18 looks like the biggest balanced value. Evaluating all corners: (0, 0) gives 0, (4, 0) gives 12, (2, 3) gives 18, and (0, 5) gives 4 × 5 = 20, so the answer is 20.
Source: NCERT Class 12 Mathematics, Chapter 12 (Linear Programming)

27. In an LPP, the feasible region is the set of points satisfying:
(a) Only the non-negativity restrictions (b) All the constraints including non-negativity restrictions (c) Only the objective function (d) Only the structural constraints
Answer: (b)
Solution: The trap is picking the option mentioning only structural constraints, forgetting that x ≥ 0 and y ≥ 0 are also constraints. The feasible region must satisfy every constraint together with the non-negativity restrictions, so the answer is all the constraints including non-negativity restrictions.

28. The corner points of a feasible region are A(0, 10), B(5, 5), C(15, 15) and D(0, 20). For Z = 3x − 4y + 24, the minimum value of Z is:
(a) −46 (b) −56 (c) 4 (d) 24
Answer: (b)
Solution: The trap is choosing the value at A, namely 0 − 40 + 24 = −16, as the smallest by stopping early. Computing all: B gives 15 − 20 + 24 = 19, C gives 45 − 60 + 24 = 9, and D gives 0 − 80 + 24 = −56, so the answer is −56.

29. If the feasible region of an LPP is unbounded and the objective is to maximise Z = ax + by, then a finite maximum exists only if:
(a) The open half-plane ax + by > M has no point in common with the feasible region, where M is the largest corner value (b) The region contains the origin (c) All constraints are equalities (d) The objective coefficients are negative
Answer: (a)
Solution: The trap is assuming an unbounded region always means no maximum, which is false. The standard test: find the largest corner value M, then check whether the half-plane ax + by > M shares any point with the feasible region; if it does not, M is the maximum, so the answer is the half-plane condition.

30. A firm makes tables and chairs. A table needs 2 hours of carpentry and 1 hour of polishing; a chair needs 1 hour of carpentry and 1 hour of polishing. At most 100 carpentry hours and 80 polishing hours are available. If x = tables and y = chairs, the correct constraint set is:
(a) 2x + y ≤ 80, x + y ≤ 100, x ≥ 0, y ≥ 0 (b) 2x + y ≤ 100, x + y ≤ 80, x ≥ 0, y ≥ 0 (c) 2x + y ≥ 100, x + y ≥ 80 (d) x + 2y ≤ 100, x + y ≤ 80, x ≥ 0, y ≥ 0
Answer: (b)
Solution: The trap is swapping the resource limits: carpentry (2x + y) must be capped at 100, not 80. Carpentry hours used give 2x + y ≤ 100 and polishing hours give x + y ≤ 80, with non-negativity, so the answer is 2x + y ≤ 100, x + y ≤ 80, x ≥ 0, y ≥ 0.

31. The feasible region determined by x + y ≤ 4, x ≥ 0, y ≥ 0 is:
(a) Unbounded (b) A square (c) A triangle with vertices (0,0), (4,0), (0,4) (d) Empty
Answer: (c)
Solution: The trap is calling the region unbounded because only one inequality is given; the non-negativity restrictions close it. The line x + y = 4 meets the axes at (4, 0) and (0, 4), and with the axes the region is a triangle, so the answer is a triangle with vertices (0,0), (4,0), (0,4).

32. For the constraints x + 2y ≥ 10, 3x + y ≥ 15, x ≥ 0, y ≥ 0, the minimum of Z = 2x + 3y occurs at:
(a) (0, 15) (b) (4, 3) (c) (10, 0) (d) (0, 5)

Solution: The trap is (10, 0) with Z = 20, which looks small but is not the least. The corner points are (10, 0), (0, 15) and the intersection of the two lines, x = 4, y = 3; Z values are 20, 45 and 8 + 9 = 17, so the answer is (4, 3).

33. Which of the following is NOT a requirement of a linear programming problem?
(a) Non-negative decision variables (b) Linear constraints (c) A quadratic objective function (d) A linear objective function
Answer: (c)
Solution: The trap is thinking any optimisation qualifies as LP. Linearity of both the objective and the constraints, plus non-negativity, defines LP; a quadratic objective makes it non-linear programming, so the answer is a quadratic objective function.

34. The maximum of Z = 5x + 3y subject to 3x + 5y ≤ 15, 5x + 2y ≤ 10, x ≥ 0, y ≥ 0 is:
(a) 235/19 (b) 12 (c) 15 (d) 10
Answer: (a)
Solution: The trap is picking an axis-intercept value like 10 at (2, 0) or 9 at (0, 3). Solving 3x + 5y = 15 and 5x + 2y = 10 gives x = 20/19, y = 45/19, and Z = (100 + 135)/19 = 235/19 ≈ 12.37, which exceeds all intercept values, so the answer is 235/19.

35. In a diet problem, food F1 costs ₹50/kg and gives 4 units of protein; food F2 costs ₹80/kg and gives 6 units. At least 24 units of protein are needed. If x, y are kg of F1, F2, the problem is:
(a) Maximise Z = 4x + 6y subject to 50x + 80y ≤ 24 (b) Maximise Z = 50x + 80y subject to 4x + 6y ≤ 24 (c) Minimise Z = 4x + 6y subject to 50x + 80y ≥ 24 (d) Minimise Z = 50x + 80y subject to 4x + 6y ≥ 24, x, y ≥ 0
Answer: (d)
Solution: The trap is reversing objective and constraint — cost is what we minimise, protein is the requirement. Cost Z = 50x + 80y is minimised subject to the protein requirement 4x + 6y ≥ 24 with x, y ≥ 0, so the answer is minimise Z = 50x + 80y subject to 4x + 6y ≥ 24, x, y ≥ 0.

36. The region common to x ≥ 0, y ≥ 0, x + y ≥ 1 is:

37. If an LPP has two optimal corner points, then:
(a) Every point on the segment joining them is also optimal (b) The feasible region is empty (c) The problem has no solution (d) The objective function is constant everywhere
Answer: (a)
Solution: The trap is concluding the problem is defective. When two adjacent corners give the same optimal value, the objective line is parallel to the joining edge, so every point of that segment is optimal — infinitely many solutions. The answer is every point on the segment joining them is also optimal.

39. The corner point theorem states that for a bounded feasible region, the optimal value of the objective function:
(a) Occurs at a corner point of the feasible region (b) Cannot be determined (c) Occurs at the midpoint of an edge (d) Always occurs at the origin
Answer: (a)
Solution: The trap is assuming the origin is always optimal because it is easy to test. The fundamental theorem of LP says an optimal value over a bounded feasible region is attained at a vertex, so the answer is that it occurs at a corner point of the feasible region.

Answer: (c)
Solution: The trap is calling it a constraint line because it looks similar. Lines of constant Z are called iso-profit (maximisation) or iso-cost (minimisation) lines, and moving them parallel locates the optimum, so the answer is an iso-profit or iso-cost line.

Solution: The trap is swapping the time limits: 3 hours 20 minutes = 200 minutes is the cutting limit and 4 hours = 240 minutes is assembly. Cutting gives 5x + 8y ≤ 200 and assembly gives 10x + 8y ≤ 240, so the answer is 5x + 8y ≤ 200, 10x + 8y ≤ 240, x, y ≥ 0.
