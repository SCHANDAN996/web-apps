# 🪄 संख्या श्रेणी एवं तर्क — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

## ट्रिक 1: "पहले अंतर, फिर अनुपात" (D-A नियम)

```
┌─────────────────────────────────────────────┐
│  🧠 "देखो अंतर, न बने तो भाग दो!"           │
│                                             │
│  कोई भी श्रेणी मिले — पहले अंतर (Difference)│
│  निकालो। अंतर से कुछ न बने तो अनुपात        │
│  (Ratio/गुणन) देखो।                         │
│                                             │
│  क्रम याद रखो: D → A → S → M                │
│  Difference → Anupat → Square → Mixed       │
│  "दादा आया स्कूल मिलने"                     │
└─────────────────────────────────────────────┘
```

## ट्रिक 2: "दोगुना-तिगुना पहचानो" (गुणक श्रेणी)

```
┌─────────────────────────────────────────────┐
│  🧠 "बड़ी छलाँग = गुणा का खेल"              │
│                                             │
│  अगर संख्याएँ तेज़ी से बढ़ रही हैं           │
│  (2, 6, 18, 54...) तो समझो ×3 चल रहा है।    │
│                                             │
│  अंगूठा-नियम: अगली संख्या पिछली से          │
│  2 गुना से ज़्यादा बड़ी हो → गुणन श्रेणी     │
│  की ओर पहले ध्यान दो।                       │
└─────────────────────────────────────────────┘
```

## ट्रिक 3: "वर्ग-घन पहचान सूची" (याद करने वाली संख्याएँ)

```
┌─────────────────────────────────────────────┐
│  🧠 "1-4-9-16-25, 36-49-64-81-100"          │
│     वर्गों की ट्रेन!                         │
│  🧠 "1-8-27-64-125, 216-343-512-729-1000"   │
│     घनों का ढेर!                            │
│                                             │
│  ट्रिक: श्रेणी में 26 दिखे → 25+1 (5²+1)    │
│  63 दिखे → 64−1 (4³−1)                      │
│  "पास-पड़ोस की संख्या = वर्ग/घन ± कुछ"      │
└─────────────────────────────────────────────┘
```

## ट्रिक 4: "±1, ±2 वाला पड़ोसी" (वर्ग/घन के आसपास)

```
┌─────────────────────────────────────────────┐
│  🧠 "वर्ग के पड़ोसी को पकड़ो!"              │
│                                             │
│  3, 8, 15, 24, 35, ?                        │
│  देखो: 4−1, 9−1, 16−1, 25−1, 36−1           │
│  → अगला 49−1 = 48                           │
│                                             │
│  मंत्र: "संख्या वर्ग के करीब? तो ± खोजो    │
│  भीतर में!"                                 │
└─────────────────────────────────────────────┘
```

## ट्रिक 5: "दोहरा अंतर" (Second Difference)

```
┌─────────────────────────────────────────────┐
│  🧠 "अंतर का अंतर = राज़ का राज़"           │
│                                             │
│  2, 5, 10, 17, 26, ?                        │
│  अंतर: 3, 5, 7, 9 → अंतर का अंतर: 2, 2, 2   │
│  → अगला अंतर 11 → उत्तर 37                  │
│                                             │
│  नियम: दोहरा अंतर समान = द्विघात श्रेणी     │
│  (n² वाली) — सीधे n²±k आज़माओ!              │
└─────────────────────────────────────────────┘
```

## ट्रिक 6: "बैठक-क्रम का घड़ी-नियम" (Seating Arrangement)

```
┌─────────────────────────────────────────────┐
│  🧠 "गोल मेज़ = घड़ी की दिशा पकड़ो"         │
│                                             │
│  Circular arrangement में पहले एक व्यक्ति    │
│  को बैठाओ, फिर "बाएँ/दाएँ" को घड़ी          │
│  (Clockwise) / उल्टी घड़ी (Anti-clockwise)  │
│  में बाँटो।                                 │
│                                             │
│  ट्रिक: "मुँह अंदर = बायाँ-दायाँ सामान्य,   │
│  मुँह बाहर = सब उल्टा!"                     │
│  (Facing centre: left-right normal;         │
│   facing outside: left-right उलट जाता है)   │
└─────────────────────────────────────────────┘
```

## ट्रिक 7: "Syllogism का VENN-कुंजी"

```
┌─────────────────────────────────────────────┐
│  🧠 "हर कथन का गोला बनाओ,                   │
│      निष्कर्ष गोले में घुसाओ!"              │
│                                             │
│  "All A are B" → A का गोला B के अंदर        │
│  "Some A are B" → गोले थोड़े टकराए          │
│  "No A is B" → गोले अलग-अलग                 │
│                                             │
│  मंत्र: "All = अंदर, Some = सटे,            │
│          No = दूर-दूर खड़े!"                │
└─────────────────────────────────────────────┘
```

## ट्रिक 8: "दो कथनों का मेल-नियम" (न्याय-नियम)

```
┌─────────────────────────────────────────────┐
│  🧠 "मज़बूत + मज़बूत = मज़बूत,              │
│      कमज़ोर घुसे तो कुछ निश्चित नहीं!"      │
│                                             │
│  All + All = All  ✓                         │
│  All + No  = No   ✓                         │
│  Some + Some = कोई निश्चित निष्कर्ष नहीं    │
│  All + Some = कोई निश्चित निष्कर्ष नहीं     │
│  (Some वाले मेल में केवल संभावना            │
│   (possibility) पूछी जाए तो जाँच अलग)       │
│                                             │
│  ट्रिक: "दो Some मिलें तो कुछ न मिले,       │
│  No आए तो No ही दिखे!"                      │
└─────────────────────────────────────────────┘
```

## ट्रिक 9: "कोडिंग का EJOTY खजाना"

```
┌─────────────────────────────────────────────┐
│  🧠 E-J-O-T-Y = 5-10-15-20-25               │
│                                             │
│  E=5, J=10, O=15, T=20, Y=25                │
│  इन 5 अक्षरों की position याद रखो,          │
│  बाकी ±1, ±2 से निकाल लो!                   │
│                                             │
│  उदा: R = ? → T=20, R दो पीछे → 18          │
│  मंत्र: "इजोटी याद है, तो ABCD आसान है!"    │
└─────────────────────────────────────────────┘
```

## ट्रिक 10: "उल्टा अक्षर जोड़ी" (Opposite Letter Trick)

```
┌─────────────────────────────────────────────┐
│  🧠 "AZad, BoY, CruX, Dew, EVen,            │
│      FuN, GT, HS, IR, JQ, KP, LO, MN"       │
│                                             │
│  A↔Z, B↔Y, C↔X ... M↔N                      │
│  जोड़ी का योग हमेशा 27!                     │
│                                             │
│  नियम: "उल्टे अक्षरों का जोड़ = 27 का कोड"  │
│  उदा: H का opposite = 27−8 = 19 = S         │
└─────────────────────────────────────────────┘
```

## ट्रिक 11: "रक्त-संबंध का पारिवारिक वृक्ष"

```
┌─────────────────────────────────────────────┐
│  🧠 "पुरुष □, महिला ○, शादी =,              │
│      पीढ़ी नीचे बढ़े!"                      │
│                                             │
│  Blood relation में हमेशा चित्र बनाओ:        │
│  □ = पुरुष, ○ = महिला,                      │
│  = = विवाह, ऊर्ध्वाधर रेखा = पीढ़ी          │
│                                             │
│  ट्रिक: "मेरे" से शुरू करो और उल्टा चलो —   │
│  "Pointing to" वाले प्रश्नों में वक्ता से    │
│  खुद को जोड़ो!                              │
└─────────────────────────────────────────────┘
```

## ट्रिक 12: "दिशा का NESW चक्र"

```
┌─────────────────────────────────────────────┐
│  🧠 "Never Eat Soggy Wafers"                │
│     = North→East→South→West (घड़ी-दिशा)     │
│                                             │
│  दायाँ मुड़ना = +90° (अगला दिशा-अक्षर)      │
│  बायाँ मुड़ना = −90° (पिछला दिशा-अक्षर)     │
│                                             │
│  ट्रिक: "Right = आगे बढ़ो NESW में,         │
│          Left = पीछे हटो!"                  │
│  दो बार Right = U-turn (उल्टी दिशा)         │
└─────────────────────────────────────────────┘
```

## ट्रिक 14: "×2±1 की लहर" (Mixed Series)

┌─────────────────────────────────────────────┐

│                                             │

│  मंत्र: "लहराती श्रेणी = दो श्रेणियों       │
