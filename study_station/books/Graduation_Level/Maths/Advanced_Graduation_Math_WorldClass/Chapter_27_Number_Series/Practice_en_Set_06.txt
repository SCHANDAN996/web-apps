126. Find the missing term: 3, 7, 16, 35, 74, ?
(a) 151 (b) 148 (c) 149 (d) 153
Answer: (d)
Solution: The tempting trap is to look for a constant difference, but the differences are 4, 9, 19, 39 — not constant. The pattern is ×2 + 1, ×2 + 2, ×2 + 3, ×2 + 4, so next is ×2 + 5: 74 × 2 + 5 = 153. So the answer is 153.
Source: PYQ-style

127. Find the next term: 2, 3, 10, 39, 172, ?
(a) 895 (b) 860 (c) 875 (d) 885
Answer: (d)
Solution: Many students try ×2 or ×3 with a constant addend and get stuck. The pattern is ×1 + 1, ×2 + 4, ×3 + 9, ×4 + 16 — the multiplier rises by 1 and the addend is a perfect square. Next: 172 × 5 + 25 = 885. So the answer is 885.
Source: PYQ-style

128. Find the wrong term in the series: 1, 2, 6, 15, 31, 57, 91
(a) 57 (b) 15 (c) 31 (d) 6
Answer: (a)
Solution: The trap is checking only the first differences 1, 4, 9, 16 and assuming the rest follow. The differences should be perfect squares 1, 4, 9, 16, 25, 36, giving 1, 2, 6, 15, 31, 56, 91 — so 57 should be 56. So the answer is 57.

129. Find the next term: 1, 4, 27, 256, ?

130. Find the missing term: 8, 15, 28, 53, 102, ?

144. Find the wrong term: 5, 8, 16, 19, 38, 42, 82
