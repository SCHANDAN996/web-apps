# 📋 महत्वपूर्ण सूत्र — संख्या श्रेणी एवं तर्क

## 1. समांतर श्रेणी (Arithmetic Progression)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| nवाँ पद | aₙ = a + (n − 1)d | समान अंतर वाली श्रेणी में कोई भी पद |
| पहले n पदों का योग | Sₙ = n/2 [2a + (n − 1)d] | जब पहला पद (a) और सार्व अंतर (d) दिया हो |
| योग (प्रथम-अंतिम रूप) | Sₙ = n/2 (a + l) | जब पहला और अंतिम पद ज्ञात हो |
| सार्व अंतर | d = a₂ − a₁ | लगातार दो पदों का अंतर |
| पदों की संख्या | n = [(l − a)/d] + 1 | पहले से अंतिम पद तक कुल पद |
| समांतर माध्य | A = (a + b)/2 | दो संख्याओं के बीच का पद |

## 2. गुणोत्तर श्रेणी (Geometric Progression)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| nवाँ पद | aₙ = a·rⁿ⁻¹ | समान अनुपात वाली श्रेणी में कोई भी पद |
| पहले n पदों का योग (r ≠ 1) | Sₙ = a(rⁿ − 1)/(r − 1), r > 1 | तेज़ी से बढ़ती गुणन श्रेणी |
| योग (r < 1) | Sₙ = a(1 − rⁿ)/(1 − r) | घटती गुणोत्तर श्रेणी |
| अनंत श्रेणी का योग (\|r\| < 1) | S∞ = a/(1 − r) | 1/2 + 1/4 + 1/8 + … जैसे प्रश्न |
| सार्व अनुपात | r = a₂/a₁ | लगातार दो पदों का भागफल |
| गुणोत्तर माध्य | G = √(ab) | दो संख्याओं के बीच गुणन-आधारित पद |

## 3. विशेष श्रेणियों के योग

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| प्रथम n प्राकृत संख्याओं का योग | Σn = n(n + 1)/2 | 1 + 2 + 3 + … + n |
| प्रथम n वर्गों का योग | Σn² = n(n + 1)(2n + 1)/6 | 1 + 4 + 9 + … + n² |
| प्रथम n घनों का योग | Σn³ = [n(n + 1)/2]² | 1 + 8 + 27 + … + n³ |
| प्रथम n सम संख्याओं का योग | n(n + 1) | 2 + 4 + 6 + … + 2n |
| प्रथम n विषम संख्याओं का योग | n² | 1 + 3 + 5 + … + (2n − 1) |
| nवाँ विषम पद | 2n − 1 | विषम श्रेणी का कोई पद |
| nवाँ सम पद | 2n | सम श्रेणी का कोई पद |

## 4. श्रेणी पहचान के नियम

| सूत्र का नाम | सूत्र / नियम | उपयोग-संकेत |
|---|---|---|
| प्रथम अंतर विधि | a₂ − a₁, a₃ − a₂, … | अंतर समान → AP; अंतर स्वयं AP → द्विघात श्रेणी |
| द्वितीय अंतर विधि | अंतरों का अंतर | द्वितीय अंतर स्थिर → n² आधारित श्रेणी |
| अनुपात विधि | a₂/a₁, a₃/a₂, … | अनुपात समान → GP |
| द्विघात श्रेणी का पद | aₙ = an² + bn + c | द्वितीय अंतर = 2a |
| मिश्र श्रेणी | aₙ = aₙ₋₁ × k ± m | गुणा और जोड़/घटाव दोनों हो तो |
| फिबोनाचि नियम | aₙ = aₙ₋₁ + aₙ₋₂ | हर पद पिछले दो का योग |
| वैकल्पिक श्रेणी | विषम स्थान व सम स्थान अलग-अलग | एक-एक पद छोड़कर दो श्रेणियाँ बनाएँ |

## 5. वर्ग, घन एवं मूल

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| वर्ग अंतर | (n + 1)² − n² = 2n + 1 | लगातार वर्गों का अंतर विषम संख्या |
| वर्ग योग/अंतर | a² − b² = (a + b)(a − b) | वर्ग-आधारित श्रेणी की जाँच |
| घन अंतर | (n + 1)³ − n³ = 3n² + 3n + 1 | घन श्रेणी में अंतर का स्वरूप |
| n² ± k पैटर्न | aₙ = n² ± k | 2, 5, 10, 17… (n² + 1) जैसी श्रेणी |
| n³ ± k पैटर्न | aₙ = n³ ± k | 0, 7, 26, 63… (n³ − 1) जैसी श्रेणी |
| n(n + 1) पैटर्न | aₙ = n(n + 1) | 2, 6, 12, 20, 30… जैसी श्रेणी |
| n(n + 1)(n + 2) पैटर्न | aₙ = n(n + 1)(n + 2) | 6, 24, 60, 120… जैसी श्रेणी |

## 6. अंक-आधारित तर्क (Digit Logic)

| सूत्र का नाम | सूत्र / नियम | उपयोग-संकेत |
|---|---|---|
| दो-अंकीय संख्या | 10x + y | अंक पलटने वाले प्रश्न |
| अंक पलटने पर संख्या | 10y + x | मूल और उलटी संख्या का संबंध |
| अंतर (पलटने पर) | 9(x − y) | हमेशा 9 का गुणज |
| योग (पलटने पर) | 11(x + y) | हमेशा 11 का गुणज |
| अंकों का योग नियम (9) | संख्या ≡ अंकों का योग (mod 9) | 9 की विभाज्यता जाँच |
| 11 की विभाज्यता | (विषम स्थानों का योग) − (सम स्थानों का योग) = 0 या 11 का गुणज | बड़ी संख्या की शीघ्र जाँच |

## 7. विभाज्यता नियम (Divisibility Rules)

| संख्या | नियम | उपयोग-संकेत |
|---|---|---|
| 2 | अंतिम अंक सम | त्वरित जाँच |
| 3 | अंकों का योग 3 से विभाज्य | श्रेणी-योग प्रश्नों में |
| 4 | अंतिम दो अंक 4 से विभाज्य | बड़ी संख्या |
| 5 | अंतिम अंक 0 या 5 | त्वरित जाँच |
| 6 | 2 और 3 दोनों से विभाज्य | संयुक्त नियम |
| 8 | अंतिम तीन अंक 8 से विभाज्य | बड़ी संख्या |
| 9 | अंकों का योग 9 से विभाज्य | डिजिटल रूट |
| 11 | स्थान-योगों का अंतर 0 या 11 का गुणज | पैलिंड्रोम-जैसे प्रश्न |

## 8. तर्क एवं क्रम (Logic & Arrangement)

| सूत्र का नाम | सूत्र / नियम | उपयोग-संकेत |
|---|---|---|
| क्रमचय (Permutation) | ⁿPᵣ = n!/(n − r)! | क्रम मायने रखे तो |
| संचय (Combination) | ⁿCᵣ = n!/[r!(n − r)!] | क्रम मायने न रखे तो |
| n वस्तुओं की व्यवस्था | n! | सभी भिन्न हों तो |
| समान वस्तुओं सहित | n!/(p! q! …) | p, q वस्तुएँ समान हों तो |
| वृत्तीय व्यवस्था | (n − 1)! | गोल मेज़ पर बैठना |
| कूट-भाषा स्थान मान | A = 1, B = 2, …, Z = 26 | अक्षर-संख्या श्रेणी |
| अक्षर का विपरीत स्थान | 27 − स्थान मान | A↔Z, B↔Y जोड़े |
| दिशा-दूरी (पाइथागोरस) | दूरी = √(x² + y²) | दिशा-परीक्षण प्रश्न |
