# 📋 महत्वपूर्ण सूत्र — साधारण ब्याज (Simple Interest)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| साधारण ब्याज | SI = (P × R × T) / 100 | मूल सूत्र; P = मूलधन, R = दर (% वार्षिक), T = समय (वर्ष) |
| मिश्रधन | A = P + SI = P(1 + RT/100) | कुल राशि = मूलधन + ब्याज |
| मूलधन ज्ञात करना | P = (SI × 100) / (R × T) | ब्याज, दर, समय दिए हों तो |
| दर ज्ञात करना | R = (SI × 100) / (P × T) | ब्याज, मूलधन, समय दिए हों तो |
| समय ज्ञात करना | T = (SI × 100) / (P × R) | ब्याज, मूलधन, दर दिए हों तो |
| समय माह में हो | T = महीने / 12 | समय हमेशा वर्ष में बदलें |
| समय दिनों में हो | T = दिन / 365 | साधारण वर्ष; लीप वर्ष में 366 |
| ब्याज = मूलधन का n गुना | T = (n × 100) / R | "कितने वर्षों में ब्याज मूलधन का n गुना" प्रश्नों में |
| राशि n गुनी होने का समय | T = ((n − 1) × 100) / R | मिश्रधन n गुना ⇒ ब्याज (n−1) गुना |
| दर बदलने पर ब्याज-अंतर | ΔSI = (P × ΔR × T) / 100 | दर ΔR बढ़ने/घटने पर ब्याज में अंतर |
| समय बदलने पर ब्याज-अंतर | ΔSI = (P × R × ΔT) / 100 | समय ΔT बदलने पर |
| दो दरों पर ब्याज-अंतर से मूलधन | P = (ΔSI × 100) / (ΔR × T) | "R₁ की जगह R₂ होता तो ₹X अधिक मिलता" |
| दो समयों पर ब्याज-अंतर से मूलधन | P = (ΔSI × 100) / (R × ΔT) | "T₁ की जगह T₂ वर्ष होता तो ₹X अधिक मिलता" |
| वार्षिक किस्त में ऋण चुकता (मूल सूत्र) | P = x/(1 + R·1/100) + x/(1 + R·2/100) + … + x/(1 + R·n/100) | बराबर वार्षिक किस्त x, कुल n किस्तें; kवीं किस्त का वर्तमान मूल्य = x/(1 + R·k/100) |
| किस्त ज्ञात करना | x = P / [ Σₖ 1/(1 + R·k/100) ], k = 1 से n | मूलधन P दिया हो और किस्त निकालनी हो; हर पद अलग से हल करके जोड़ें |
| भिन्न दरों पर विभाजित मूलधन | P₁ : P₂ = (R₂ × T₂) : (R₁ × T₁) | समान ब्याज पाने के लिए विभाजन-अनुपात |
| कुल ब्याज (विभाजित निवेश) | SI = (P₁R₁T₁ + P₂R₂T₂) / 100 | धन के भाग अलग-अलग दर/समय पर हों |
| औसत दर | R = (R₁T₁ + R₂T₂ + …) / (T₁ + T₂ + …) | एक ही मूलधन, अलग-अलग अवधि में अलग दर |
| ब्याज-दर प्रतिशत में (मिश्रधन से) | R = ((A − P) × 100) / (P × T) | मिश्रधन A दिया हो तो |
| n गुना होने में लगा समय (तुलना) | T₁/T₂ = (n₁ − 1)/(n₂ − 1) | समान दर पर दो अलग गुणक-प्रश्नों की तुलना |
| दर तथा समय समान हों तो | SI ∝ P | ब्याज मूलधन के समानुपाती |
| मूलधन तथा समय समान हों तो | SI ∝ R | ब्याज दर के समानुपाती |
| मूलधन तथा दर समान हों तो | SI ∝ T | ब्याज समय के समानुपाती |
| मासिक दर से वार्षिक दर | R(वार्षिक) = 12 × R(मासिक) | "प्रतिमाह दर" दी हो तो |
| त्रैमासिक/छमाही दर से वार्षिक | R(वार्षिक) = 4 × R(त्रैमासिक) = 2 × R(छमाही) | SI में दर सीधे गुणा होती है (CI जैसी घात नहीं) |
| उधार दी गई राशि (ब्याज सहित वापसी) | P = A × 100 / (100 + RT) | मिश्रधन से मूलधन निकालना |

**किस्त-प्रश्नों के लिए सुझाव:** कोई भी "संक्षिप्त सूत्र" अलग-अलग परिस्थितियों (पहली किस्त कब देय है) में अलग उत्तर दे सकता है, इसलिए परीक्षा में हमेशा वर्तमान-मूल्य योग (P = Σ x/(1 + R·k/100)) से ही हल करें — यही विधि हर स्थिति में सही है।
