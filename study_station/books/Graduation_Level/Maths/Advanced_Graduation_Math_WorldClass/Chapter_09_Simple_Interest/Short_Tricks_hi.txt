# 🪄 साधारण ब्याज — शॉर्ट ट्रिक्स (म्नेमोनिक्स)

---

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 1: "पी-आर-टी सौ" — मास्टर सूत्र      │
├─────────────────────────────────────────────┤
│ SI = (P × R × T) / 100                       │
│ याद करो: **"पार्टी सौ"** — पार्टी (PRT) में    │
│ सौ (100) लोग आए!                             │
│ P = मूलधन, R = दर, T = समय                   │
│ बस तीनों गुणा करो, 100 से भाग दो — ब्याज तैयार!│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 2: "ब्याज हमेशा मूलधन का बेटा"        │
├─────────────────────────────────────────────┤
│ साधारण ब्याज में हर साल ब्याज **सिर्फ़ मूलधन**  │
│ पर लगता है — ब्याज पर ब्याज नहीं!             │
│ याद करो: **"बेटा (ब्याज) पिता (मूलधन) से कमाया,│
│ पोते (ब्याज-पर-ब्याज) का नामोनिशान नहीं"**     │
│ → हर वर्ष ब्याज समान रहता है।                  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 3: "A = P + SI" — परिवार फॉर्मूला     │
├─────────────────────────────────────────────┤
│ मिश्रधन = मूलधन + ब्याज                       │
│ याद करो: **"अम्मी-पापा-सोनू इकट्ठे"**          │
│ A(अम्मी/Amount) = P(पापा/Principal) + SI(सोनू) │
│ तीनों में से कोई दो पता हों → तीसरा घटा/जोड़कर  │
│ निकाल लो।                                     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 4: "दर-समय गुणनफल" शॉर्टकट           │
├─────────────────────────────────────────────┤
│ SI = P × (R×T)/100 → यानी ब्याज = मूलधन का    │
│ **(R×T)%**                                     │
│ याद करो: **"रेट × टाइम = परसेंट क्राइम"**      │
│ जैसे: 5% × 4 साल = 20% → ₹5000 का 20% = ₹1000 │
│ सीधे प्रतिशत निकालो, कैलकुलेशन आधी!           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 5: "N गुना होने का फॉर्मूला"          │
├─────────────────────────────────────────────┤
│ धन N गुना हो जाए → ब्याज = (N−1) गुना          │
│ ∴ R × T = (N−1) × 100                         │
│ याद करो: **"गुना में से एक घटाओ, सौ से गुणाओ"**│
│ जैसे: धन 3 गुना → RT = 200; 5 गुना → RT = 400 │
│ ⚠️ जाल: "3 गुना" ≠ "3 गुना ब्याज"!             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 6: "दोगुना-तिगुना समय अनुपात"         │
├─────────────────────────────────────────────┤
│ समान दर पर: दोगुना होने का समय T₁, तिगुना का  │
│ T₂ हो, तो **T₂ = 2 × T₁**                     │
│ याद करो: **"हर अगला गुना, उतना ही समय फिर से"**│
│ क्यों? SI समान दर पर रेखीय (linear) बढ़ता है —  │
│ हर "एक गुना" ब्याज में उतना ही समय लगता है।    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 7: "महीने-दिन का धर्मांतरण"           │
├─────────────────────────────────────────────┤
│ महीने → वर्ष: 12 से भाग | दिन → वर्ष: 365 से  │
│ याद करो: **"बारह महीने, साढ़े-तीन-सौ दिन"**    │
│ (365 = "साढ़े तीन सौ" की धुन)                  │
│ जैसे: 8 महीने = 8/12 = 2/3 वर्ष;              │
│ 73 दिन = 73/365 = 1/5 वर्ष                    │
│ ⚠️ परीक्षा में 365 ही लें, जब तक 366 न कहा जाए।│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 8: "दर बदले तो अंतर बराबर"            │
├─────────────────────────────────────────────┤
│ दर R₁ से R₂ हो जाए और ब्याज में अंतर D हो:     │
│ **P × T = (D × 100)/(R₂ − R₁)**               │
│ याद करो: **"अंतर ऊपर, दर-अंतर नीचे"**          │
│ जैसे: दर 4%→6%, ब्याज ₹200 बढ़ा, T=2 साल →     │
│ P = (200×100)/(2×2) = ₹5000                   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 9: "समय बदले तो भी वही कहानी"         │
├─────────────────────────────────────────────┤
│ समय T₁ से T₂ हो जाए और ब्याज-अंतर D हो:        │
│ **P × R = (D × 100)/(T₂ − T₁)**               │
│ याद करो: ट्रिक 8 की **जुड़वाँ बहन** —           │
│ "जो बदला उसे नीचे, जो स्थिर उसे ऊपर"           │
│ दर बदली → R नीचे; समय बदला → T नीचे।          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 10: "भविष्य में देय ऋण की बराबर किस्तें"│
├─────────────────────────────────────────────┤
│ **भविष्य में देय** ₹P का ऋण, T वर्षों में       │
│ बराबर वार्षिक किस्त ₹x से चुकाना हो (R% साधारण │
│ ब्याज):                                        │
│ कुल ब्याज = (x × R/100) × (1+2+…+(T−1))        │
│          = (x × R/100) × T(T−1)/2              │
│ और P = T·x + कुल ब्याज                         │
│ याद करो: **"त्रिभुज संख्या"** T(T−1)/2         │
│ ⚠️ यह सूत्र **भविष्य में देय राशि** पर लगता है; │
│ आज उधार ली गई राशि (वर्तमान ऋण) के लिए        │
│ P = x/(1+R/100) + x/(1+2R/100) + … लगाओ।      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 11: "दो हिस्सों में बँटवारा"           │
├─────────────────────────────────────────────┤
│ ₹P को R₁% और R₂% पर लगाया, कुल ब्याज SI:       │
│ पहला हिस्सा = (SI×100 − P×R₂×T) / ((R₁−R₂)×T) │
│ याद करो: **"उल्टी दर से गुणा, अंतर से भाग"**   │
│ (जिस हिस्से की दर R₁, उसे निकालने के लिए       │
│ दूसरी दर R₂ से गुणा करो — क्रॉस-कनेक्शन!)      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 12: "SI : CI अंतर (2 वर्ष)"           │
├─────────────────────────────────────────────┤
│ 2 वर्ष के लिए CI − SI = P × (R/100)²           │
│ याद करो: **"चक्रवृद्धि का टैक्स = दर का वर्ग"**│
│ जैसे: R=10%, P=₹10000 → अंतर = 10000×(0.1)²   │
│ = ₹100। SI पर CI का "पेनल्टी" सिर्फ़ दर के     │
│ वर्ग जितनी! (3 वर्ष के लिए यह ट्रिक नहीं चलेगी)│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 13: "प्रतिशत-भिन्न रामबाण तालिका"     │
├─────────────────────────────────────────────┤
│ रट लो — SI के सवाल अक्सर इन्हीं भिन्नों पर     │
│ घूमते हैं:                                     │
│ 5% = 1/20 | 4% = 1/25 | 8% = 2/25 |           │
│ 10% = 1/10 | 12% = 3/25 | 6⅔% = 1/15 |        │
│ 16⅔% = 1/6 | 33⅓% = 1/3                       │
│ याद करो: **"भिन्न बनाओ, कैलकुलेटर भगाओ"**      │
│ 8% × 5 साल = 2/25 × 5 = 2/5 → सीधे 40%!       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 14: "उधार-लेने वाला उल्टा सवाल"       │
├─────────────────────────────────────────────┤
│ "कितने समय में धन N गुना?" → T = (N−1)×100/R  │
│ "किस दर से धन N गुना?" → R = (N−1)×100/T      │
│ याद करो: **"जो पूछे उसे छोड़ो, बाकी दोनों      │
│ लड़ाओ"** — T पूछा तो (N−1)×100 को R से भाग;    │
│ R पूछा तो T से भाग। त्रिकोण: ऊपर (N−1)×100,    │
│ नीचे R और T — ढककर निकालो!                    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🪄 ट्रिक 15: "एक लाइन में पूरा अध्याय"         │
├─────────────────────────────────────────────┤
│ **"मूल × दर × समय, बटा सौ — ब्याज हाजिर;      │
│  मूल में मिलाओ — मिश्रधन तैयार!"**             │
│ यह दोहा सुबह-शाम बोलो — SI का कोई सवाल        │
│ इन दो लाइनों से बाहर नहीं जाता।               │
│ 🧠 अंतिम सलाह: पहले R×T का प्रतिशत निकालो,     │
│ फिर मूलधन पर लगाओ — सवाल कुछ ही सेकंड में हल! │
└─────────────────────────────────────────────┘
