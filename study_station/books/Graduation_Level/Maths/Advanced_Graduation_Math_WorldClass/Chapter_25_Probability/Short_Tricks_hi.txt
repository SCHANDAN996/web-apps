# 🪄 प्रायिकता — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

**🎯 ट्रिक 1: "ऊपर चाहिए, नीचे सब"**

```
┌─────────────────────────────────────┐
│ P(E) = अनुकूल / कुल                  │
│ याद रखो: "ऊपर जो चाहिए,             │
│          नीचे जो भी हो सकता है"      │
│ अनुकूल ऊपर, कुल नीचे — कभी उल्टा नहीं!│
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 2: "0 से 1 की सड़क"**

```
┌─────────────────────────────────────┐
│ 0 ≤ P(E) ≤ 1                        │
│ "प्रायिकता 0 से 1 की सड़क पर चलती है,│
│  न तो पीछे (ऋणात्मक) जाती है,        │
│  न आगे (1 से ज़्यादा) भागती है।"     │
│ उत्तर 1.2 या −0.3 आए = गलती पक्की!  │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 3: "नहीं = 1 में से घटाओ" (पूरक नियम)**

```
┌─────────────────────────────────────┐
│ P(E नहीं) = 1 − P(E)                │
│ मंत्र: "नहीं सुनते ही 1 से काटो"     │
│ "कम से कम एक" वाले सवालों में        │
│ सीधा हिसाब मुश्किल → उल्टा करो:     │
│ P(कम से कम एक) = 1 − P(एक भी नहीं)  │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 4: "OR जोड़ता, AND गुणा करता"**

```
┌─────────────────────────────────────┐
│ OR (या) → + (जोड़)                   │
│ AND (और) → × (गुणा)                  │
│ याद रखो: "या-या जुड़वाँ, और-और गुणनखंड"│
│ P(A या B) = P(A) + P(B) − P(A∩B)    │
│ P(A और B) = P(A) × P(B) [स्वतंत्र हों तो]│
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 5: "परस्पर अपवर्जी = दुश्मन भाई"**

```
┌─────────────────────────────────────┐
│ परस्पर अपवर्जी (Mutually Exclusive): │
│ दो घटनाएँ साथ नहीं हो सकतीं।         │
│ "दुश्मन भाई — एक आए तो दूसरा भागे"  │
│ P(A∩B) = 0, इसलिए सीधे जोड़ दो:     │
│ P(A∪B) = P(A) + P(B)                │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 6: "स्वतंत्र = अपने रास्ते"**

```
┌─────────────────────────────────────┐
│ स्वतंत्र घटनाएँ: एक का दूसरे पर      │
│ कोई असर नहीं।                        │
│ "अपने-अपने रास्ते, गुणा करो बस"     │
│ P(A∩B) = P(A) × P(B)                │
│ सिक्का दो बार उछालो — पहले का       │
│ परिणाम दूसरे को याद ही नहीं!         │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 7: "साथ-बिना" ट्रिक (Replacement)**

```
┌─────────────────────────────────────┐
│ "साथ वापसी" = हर बार वही कुल        │
│ "बिना वापसी" = कुल एक-एक घटता       │
│ मंत्र: "वापसी है तो हर समान,         │
│        नहीं तो हर घटता जान"          │
│ 52 ताश: वापसी में 52, 52…           │
│ बिना वापसी: 52, 51, 50…             │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 8: "ताश का 52-13-4-2" मास्टर कोड**

```
┌─────────────────────────────────────┐
│ 52 = कुल पत्ते                       │
│ 13 = एक रंग (suit) के पत्ते          │
│ 4  = रंगों/बादशाहों/रानियों की संख्या │
│ 2  = रंग (लाल/काले)                  │
│ 12 = फेस कार्ड (4+4+4)               │
│ कोड: "बावन-तेरा-चार-दो,              │
│       ताश का राज़ खोल दो!"           │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 9: "पासे का वर्ग-जादू"**

```
┌─────────────────────────────────────┐
│ 1 पासा → 6 परिणाम                    │
│ 2 पासे → 36 परिणाम                   │
│ 3 पासे → 216 परिणाम                  │
│ ट्रिक: "पासा जितना, 6 की घात उतनी"  │
│ 6¹ = 6, 6² = 36, 6³ = 216           │
│ योग 7 की प्रायिकता सबसे ज़्यादा      │
│ (6/36) — "सात सबसे भाग्यशाली!"      │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 10: "कम से कम एक = उल्टा खेल"**

```
┌─────────────────────────────────────┐
│ "कम से कम एक" दिखते ही:              │
│ 1 − P(शून्य)                         │
│ उदा.: 3 सिक्कों में कम से कम एक Head │
│ = 1 − P(सब Tail) = 1 − 1/8 = 7/8    │
│ मंत्र: "कम से कम आए, उल्टा चल भाई!" │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 11: "सशर्त = छोटा संसार" (Conditional Probability)**

```
┌─────────────────────────────────────┐
│ P(A|B) = P(A∩B) / P(B)              │
│ "B हो चुका = संसार सिकुड़ गया"       │
│ अब कुल परिणाम = B के परिणाम,         │
│ अनुकूल = A∩B के परिणाम।              │
│ याद रखो: "जो दिया, वही नीचे"        │
│ (B दिया है → B हर में)               │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 12: "गेंद-बैग: पहले कुल, फिर मन"**

```
┌─────────────────────────────────────┐
│ बैग-गेंद सवालों का 2-कदम मंत्र:      │
│ कदम 1: कुल गेंदें गिनो (हर)          │
│ कदम 2: मनचाही गेंदें गिनो (अंश)      │
│ दो गेंदें निकालें (बिना वापसी):      │
│ अंश: C(मनचाही,2), हर: C(कुल,2)      │
│ "पहले कुल, फिर मन — कॉम्बिनेशन धन!" │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 13: "जन्मदिन विरोधाभास = उल्टी गिनती"**

```
┌─────────────────────────────────────┐
│ "कम से कम दो का जन्मदिन मिले"       │
│ = 1 − P(सबके अलग-अलग)               │
│ n लोग: 1 − (365×364×…×(365−n+1))/365ⁿ│
│ मंत्र: "मिलान पूछे, अलग-अलग घटाओ"   │
└─────────────────────────────────────┘
```

---

**🎯 ट्रिक 14: "बेज़ = पहले कारण, फिर परिणाम" (Bayes' Theorem)**

```
┌─────────────────────────────────────┐
│ P(Aᵢ|B) = P(Aᵢ)·P(B|Aᵢ) / ΣP(Aⱼ)·P(B|Aⱼ)│
│ कहानी: "परिणाम दिखा, अपराधी कौन?"   │
│ ऊपर: जिस कारण की प्रायिकता चाहिए     │
│ नीचे: सभी कारणों का कुल योग          │
│ मंत्र: "ऊपर एक कारण, नीचे सारे कारण"│
└─────────────────────────────────────┘
```

**🎯 ट्रिक 15: "nCr चुनाव, nPr सजावट"**

```
┌─────────────────────────────────────┐
│ क्रम मायने नहीं → nCr (चुनाव/Selection)│
│ क्रम मायने रखता है → nPr (सजावट/Arrangement)│
│ प्रायिकता में 90% बार चुनाव ही होता है│
│ (गेंदें, पत्ते — क्रम से फर्क नहीं)  │
│ मंत्र: "चुनाव में क्रम भुलाओ,        │
│        सजावट में क्रम निभाओ"         │
└─────────────────────────────────────┘
```
