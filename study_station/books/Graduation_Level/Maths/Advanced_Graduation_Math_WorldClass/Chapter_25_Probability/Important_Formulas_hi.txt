# प्रायिकता — महत्वपूर्ण सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| प्रायिकता की मूल परिभाषा | P(E) = अनुकूल परिणाम / कुल परिणाम | जब सभी परिणाम समसंभाव्य हों |
| प्रायिकता की सीमा | 0 ≤ P(E) ≤ 1 | उत्तर जाँचने के लिए |
| निश्चित घटना | P(S) = 1 | पूरा प्रतिदर्श समष्टि |
| असंभव घटना | P(∅) = 0 | कोई अनुकूल परिणाम नहीं |
| पूरक घटना | P(E′) = 1 − P(E) | "कम से कम एक" वाले प्रश्नों में |
| योग नियम (सामान्य) | P(A∪B) = P(A) + P(B) − P(A∩B) | "A या B" वाले प्रश्न |
| परस्पर अपवर्जी घटनाएँ | P(A∪B) = P(A) + P(B) | जब A∩B = ∅ |
| तीन घटनाओं का योग | P(A∪B∪C) = P(A)+P(B)+P(C) − P(A∩B) − P(B∩C) − P(C∩A) + P(A∩B∩C) | समावेशन-अपवर्जन सिद्धांत |
| सप्रतिबंध प्रायिकता | P(A\|B) = P(A∩B) / P(B), P(B) > 0 | "B हो चुका है, तब A" |
| गुणन नियम | P(A∩B) = P(A) × P(B\|A) = P(B) × P(A\|B) | क्रमिक घटनाएँ |
| स्वतंत्र घटनाएँ | P(A∩B) = P(A) × P(B) | सिक्का-पासा, प्रतिस्थापन सहित |
| स्वतंत्रता की जाँच | P(A\|B) = P(A) ⇔ A, B स्वतंत्र | कथन-आधारित प्रश्नों में |
| कुल प्रायिकता का प्रमेय | P(A) = Σ P(Bᵢ) × P(A\|Bᵢ) | जब Bᵢ विभाजन हों (कई थैले/मशीनें) |
| बेज़ प्रमेय | P(Bᵢ\|A) = P(Bᵢ) × P(A\|Bᵢ) / Σ P(Bⱼ) × P(A\|Bⱼ) | "घटना हो चुकी, स्रोत कौन?" |
| प्रतिस्थापन सहित चयन | P = (अनुकूल/कुल)ⁿ | हर बार समान प्रायिकता |
| बिना प्रतिस्थापन चयन (हाइपरज्यामितीय) | P = [C(N₁, k₁) × C(N₂, k₂) × …] / C(N, n) | N = कुल वस्तुएँ, Nᵢ = i-वें प्रकार की वस्तुएँ, kᵢ = i-वें प्रकार से निकाली गई, n = k₁ + k₂ + … (कुल निकाली गई) |
| कम से कम एक | P(कम से कम एक) = 1 − P(कोई नहीं) | "at least one" देखते ही |
| जन्मदिन समस्या | P(मेल) = 1 − 365! / [(365−n)! × 365ⁿ] | n लोगों में जन्मदिन मेल |
| द्विपद बंटन | P(X = r) = ⁿCᵣ pʳ (1−p)ⁿ⁻ʳ | n स्वतंत्र परीक्षण, r सफलताएँ |
| द्विपद का माध्य | μ = np | अपेक्षित सफलताएँ |
| द्विपद का प्रसरण | σ² = np(1−p) | विचरण |
| अपेक्षित मान (सामान्य) | E(X) = Σ xᵢ × P(xᵢ) | जुआ/लॉटरी/बीमा प्रश्न |
| प्रतिकूल अनुपात (Odds) | Odds in favour = P(E) : P(E′) | "पक्ष में अनुपात" |
| Odds से प्रायिकता | P(E) = a / (a+b), जब odds a : b | अनुपात → प्रायिकता |
| ज्यामितीय प्रायिकता | P = अनुकूल माप / कुल माप | लंबाई/क्षेत्रफल/समय आधारित |
| पासों का योग (दो पासे) | P(योग = s) = अनुकूल युग्म / 36 | योग 7 की प्रायिकता अधिकतम = 6/36 |
| कार्ड (52 पत्ते) | P(इक्का) = 4/52, P(हुकुम) = 13/52 | रंग 26, चित्र-पत्ते 12 |
| थैला (गेंदें) | P(लाल) = लाल गेंदें / कुल गेंदें | बिना प्रतिस्थापन में हर चरण अलग |

**बिना प्रतिस्थापन चयन — उदाहरण:** थैले में 5 लाल व 3 हरी गेंदें हैं; 4 गेंदें एक साथ निकाली गईं। 2 लाल व 2 हरी आने की प्रायिकता = C(5, 2) × C(3, 2) / C(8, 4) = 10 × 3 / 70 = 3/7। यहाँ N = 8, N₁ = 5, N₂ = 3, k₁ = 2, k₂ = 2, n = 4।
