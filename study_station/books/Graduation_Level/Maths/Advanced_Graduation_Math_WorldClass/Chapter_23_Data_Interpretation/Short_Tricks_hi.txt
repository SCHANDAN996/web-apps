# 🪄 डेटा व्याख्या — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 1: "प्रतिशत का पिता" — आधार याद रखो** │
│                                             │
│ % वृद्धि/कमी में हमेशा पूछो: "किसके          │
│ मुक़ाबले?" — हर जवाब **आधार (Base)** में     │
│ छिपा है।                                    │
│                                             │
│ 🗝️ कीवर्ड: **"से" = आधार**                  │
│ "A, B **से** 20% अधिक" → आधार B            │
│ "B, A **से** कितना % कम?" → आधार A         │
│                                             │
│ मंत्र: *"से के पहले नहीं, से के बाद आधार है"*│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 2: "ऊपर-नीचे नहीं बराबर" — 20% का खेल**│
│                                             │
│ 20% बढ़ा तो वापस आने के लिए 20% नहीं,        │
│ **16.67%** घटाना पड़ेगा!                    │
│                                             │
│ 🗝️ सूत्र-ट्रिक: x% बढ़े → घटाओ x/(100+x)×100 │
│                                             │
│ म्नेमोनिक: **"ऊपर सीढ़ी लंबी, नीचे सीढ़ी     │
│ छोटी"** — बढ़त हमेशा कमी से बड़ी दिखती है।   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 3: "भिन्न-प्रतिशत प्रेम-तालिका"**      │
│                                             │
│ रट लो — DI की आधी जंग यहीं जीत जाती है:      │
│ 1/2=50% | 1/3=33.33% | 1/4=25% | 1/5=20%   │
│ 1/6=16.67% | 1/7=14.28% | 1/8=12.5%        │
│ 1/9=11.11% | 1/11=9.09% | 1/12=8.33%       │
│                                             │
│ 🗝️ म्नेमोनिक: **"7-11 जुड़वाँ"** — 1/7=14.28 │
│ और 1/11=9.09, दोनों दोहरे अंकों वाले!        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 4: "औसत का तराज़ू" — विचलन विधि**     │
│                                             │
│ बड़ी संख्याओं का औसत? एक **अनुमानित औसत**    │
│ पकड़ो, फिर हर संख्या का +/− विचलन जोड़ो।     │
│                                             │
│ उदा: 198, 202, 205, 195 → आधार 200          │
│ विचलन: −2, +2, +5, −5 = 0 → औसत = 200       │
│                                             │
│ 🗝️ मंत्र: *"तराज़ू के दो पलड़े, विचलन में    │
│ सब समेटे"*                                   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 5: "CAGR = चुपचाप चढ़ने वाला"**       │
│                                             │
│ CAGR ≈ (कुल वृद्धि % ÷ वर्ष) से थोड़ा **कम** │
│ — चक्रवृद्धि हमेशा साधारण से पीछे रहती है।   │
│                                             │
│ 🗝️ म्नेमोनिक: **"चक्रवृद्धि चालू, साधारण     │
│ सीधा"** — सीधा भाग देकर उत्तर थोड़ा घटाओ।    │
│                                             │
│ 2 वर्ष के लिए: r ≈ √(अंतिम/प्रारंभ) − 1      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 6: "अनुपात का क्रॉस-चमत्कार"**        │
│                                             │
│ दो वर्षों के अनुपात दिए हों (जैसे 3:5 और      │
│ 4:7) और तुलना करनी हो → **क्रॉस गुणा** करो:  │
│ 3×7 = 21 बनाम 4×5 = 20 → पहला बड़ा।         │
│                                             │
│ 🗝️ मंत्र: *"तिरछा गुणा, सीधा फैसला"*        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 7: "पाई-चार्ट = 360° की पिज़्ज़ा पार्टी"**│
│                                             │
│ 1% = 3.6° (याद रखो: **"एक प्रतिशत, साढ़े     │
│ तीन डिग्री का टुकड़ा"**)                     │
│                                             │
│ कोण → प्रतिशत: कोण ÷ 3.6                    │
│ प्रतिशत → कोण: प्रतिशत × 3.6                 │
│                                             │
│ 🗝️ म्नेमोनिक: **"36 का चक्कर"** — 360, 3.6, │
│ 36% = 129.6°… सब 36 के खेल हैं।             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 8: "पहले विकल्प, फिर गणना"**          │
│                                             │
│ DI में पहले **विकल्पों का अंतर** देखो:        │
│ • विकल्प दूर-दूर (जैसे 12%, 25%, 40%) →     │
│   सिर्फ अनुमान/राउंडिंग काफी!               │
│ • विकल्प पास-पास (21.2%, 21.5%) → पूरी      │
│   गणना ज़रूरी।                               │
│                                             │
│ 🗝️ मंत्र: *"दूर विकल्प, आधा काम; पास विकल्प, │
│ पूरा काम"*                                   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 9: "लाभ-हानि का CP-सम्राट"**          │
│                                             │
│ लाभ% हमेशा **क्रय मूल्य (CP)** पर — कभी SP   │
│ पर नहीं!                                     │
│                                             │
│ 🗝️ म्नेमोनिक: **"Cost is King"** — राजा के   │
│ ऊपर ही हिसाब बैठता है।                       │
│                                             │
│ जाल-पहचान: "SP पर 20% लाभ" लिखा हो तो       │
│ वह CP पर 25% लाभ है (20/80 × 100)।          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 10: "वृद्धि दर का उल्टा चश्मा"**      │
│                                             │
│ A से B तक वृद्धि = (B−A)/A × 100             │
│ B से A तक कमी = (B−A)/**B** × 100            │
│                                             │
│ अंश समान, हर अलग — **हर हमेशा "से" वाला!**   │
│                                             │
│ 🗝️ म्नेमोनिक: **"ऊपर एक ही पहाड़, नीचे       │
│ बदलता आधार"**                                │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 11: "बार-ग्राफ की आँख-नाप"**          │
│                                             │
│ बार-ग्राफ में "लगभग कितना गुना?" पूछे तो     │
│ स्केल पर बार की **ऊँचाई की तुलना** से        │
│ अनुमान — पूरी गणना की ज़रूरत नहीं।           │
│                                             │
│ 🗝️ मंत्र: *"ग्राफ आँखों से पढ़ो, कलम बाद में  │
│ चलाओ"* — कई DI सवाल दृश्य-अनुमान से ही       │
│ हल हो जाते हैं!                              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 12: "दो वर्ष, दो बदलाव — सक्सेसिव सूत्र"**│
│                                             │
│ कुल परिवर्तन = a + b + (ab/100)              │
│ (घटने पर चिह्न ऋणात्मक)                      │
│                                             │
│ उदा: +10% फिर −10% → 10 − 10 − 1 = **−1%**  │
│ (बराबर नहीं, 1% की हानि!)                    │
│                                             │
│ 🗝️ म्नेमोनिक: **"जोड़-घटा के साथ, गुणा-सौदा  │
│ भी साथ"** — ab/100 भूलना = गलती पक्की।       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 13: "भारित औसत = हिस्सेदारी का खेल"** │
│                                             │
│ दो समूहों का मिश्रित औसत, अलग-अलग औसतों के   │
│ **बीच** होगा — और **बड़े समूह की ओर** झुकेगा।│
│                                             │
│ 🗝️ म्नेमोनिक: **"जिसकी संख्या ज़्यादा, औसत   │
│ उसी का साथी"**                               │
│                                             │
│ विकल्प-काटछाँट: दोनों औसतों से बाहर वाले     │
│ विकल्प तुरंत काट दो!                         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 14: "DI का तीन-कदम मंत्र"**           │
│                                             │
│ हर DI सेट में यह क्रम अपनाओ:                  │
│ **प**ढ़ो (शीर्षक + इकाइयाँ + टिप्पणी) →      │
│ **प**हचानो (क्या पूछा: %, अनुपात, औसत?) →    │
│ **प**ूरा करो (कम से कम गणना में)             │
│                                             │
│ 🗝️ एक्रोनिम: **"प-प-प" = पढ़ो, पहचानो, परफेक्ट│
│ करो**                                        │
│                                             │
│ सबसे बड़ा जाल: इकाई (लाख/करोड़, %/संख्या)    │
│ न देखना — पहले कदम में ही पकड़ लो!           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 15: "छोड़ना भी एक कला" — स्मार्ट स्किप**│
│                                             │
│ DI सेट के 5 प्रश्नों में से 1-2 हमेशा         │
│ "कथन I, II, III" वाले समय-खाऊ होते हैं।      │
│ पहले सीधे (डेटा-निकालो) प्रश्न करो, कथन-वाले │
│ अंत में।                                     │
│                                             │
│ 🗝️ मंत्र: *"पहले फल, फिर फांस"* — आसान अंक  │
│ पहले, जाली प्रश्न बाद में।                   │
└─────────────────────────────────────────────┘
