# Important Formulas — Data Interpretation

| Formula Name | Formula | One-line Use-Hint |
|---|---|---|
| Percentage | (Part / Whole) × 100 | Convert any share into % of total |
| Percentage Change | [(New − Old) / Old] × 100 | Growth or decline between two periods |
| Percentage Point Difference | %A − %B | Compare two percentages directly (not % change) |
| Average (Mean) | Sum of values / Number of values | Central value of a data set |
| Weighted Average | Σ(wᵢxᵢ) / Σwᵢ | When groups have different sizes/weights |
| Ratio | a : b = a/b | Compare two quantities; simplify by HCF |
| Comparing Ratios | a/b vs c/d → cross-multiply a×d vs b×c | Quick ratio comparison without decimals |
| Part from Ratio | Share = (ratio term / sum of terms) × Total | Split a total in a given ratio |
| Compound Growth | A = P(1 + r/100)ⁿ | Population/sales growing at constant rate |
| Compound Growth (decline) | A = P(1 − r/100)ⁿ | Depreciation or steady decrease |
| CAGR | [(Final / Initial)^(1/n) − 1] × 100 | Average yearly growth over n years |
| Successive % Change | a + b + (ab/100) | Net effect of two consecutive changes |
| % A is of B | (A / B) × 100 | "A is what percent of B?" |
| % More/Less | (Difference / Base) × 100 | Base = quantity after "than/of" in the question |
| Angle in Pie Chart | (Value / Total) × 360° | Convert data to pie-chart sector angle |
| Value from Pie Angle | (Angle / 360°) × Total | Reverse: angle → actual value |
| Pie % from Angle | (Angle / 360°) × 100 | Sector angle → percentage share |
| Median (odd n) | Value of [(n+1)/2]th term | Arrange data in order first |
| Median (even n) | Mean of (n/2)th and (n/2 + 1)th terms | Average the two middle values |
| Mode | Most frequent value | Highest bar / most repeated entry |
| Range | Maximum − Minimum | Spread of the data |
| Approximation Rule | Round to nearest 5–10% before computing | When options are far apart |
| Fraction ↔ % (key ones) | 1/2=50%, 1/3≈33.33%, 1/4=25%, 1/5=20%, 1/6≈16.67%, 1/7≈14.28%, 1/8=12.5%, 1/9≈11.11%, 1/11≈9.09%, 1/12≈8.33% | Instant % conversion in pie/ratio questions |
| Base × % shortcut | x% of Y = (x × Y)/100; 10% = shift decimal one place left | Build any % from 10%, 5%, 1% blocks |
| Index Number | (Current value / Base value) × 100 | Compare values against a base year = 100 |
| Growth from Index | Index − 100 = % growth over base | Read growth directly off index |
| Average of Ratios trap | Overall ratio ≠ average of individual ratios | Recompute from totals, never average the %s |
| Net Change after +a% then −a% | Net = −a²/100 % (always a decrease) | Equal rise & fall never returns to start |
| Two-Table Cross Data | Required value = (Row share % × Column total) / 100 | Combine % table with absolute-value table |
| Line Graph Slope | (y₂ − y₁)/(x₂ − x₁) | Steepest segment = fastest growth rate |
| Bar Comparison | Difference or Ratio of bar heights | Read scale carefully — check units & zero base |
| Missing Value (DI table) | Missing = Total − Σ(known values) | Use row/column totals to back-calculate |
| Percentage Share | (Category value / Category total) × 100 | Share of one item within its own group |
| Per-unit / Density | Total quantity / Number of units | Production per factory, runs per match, etc. |
