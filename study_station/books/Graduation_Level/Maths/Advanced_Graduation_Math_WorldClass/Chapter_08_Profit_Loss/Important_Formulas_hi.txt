# महत्वपूर्ण सूत्र: लाभ और हानि (स्नातक स्तर)

## 1. आधारभूत समीकरण
- लाभ = SP - CP (जब SP > CP)
- हानि = CP - SP (जब CP > SP)
- लाभ % = (लाभ / CP) * 100
- हानि % = (हानि / CP) * 100
- SP = CP * [(100 + P%) / 100] = CP * [(100 - L%) / 100]
- CP = SP * [100 / (100 + P%)] = SP * [100 / (100 - L%)]

## 2. मार्जिन रूपांतरण (क्रय मूल्य बनाम विक्रय मूल्य)
- CP पर लाभ (p) से SP पर मार्जिन (m): m = p / (1 + p)
- SP पर मार्जिन (m) से CP पर लाभ (p): p = m / (1 - m)

## 3. अंकित मूल्य एवं बट्टा (छूट) संबंध
- छूट = MP - SP
- छूट % = (छूट / MP) * 100
- SP = MP * [(100 - D%) / 100]
- MP = SP * [100 / (100 - D%)]
- स्वर्ण अनुपात सूत्र: MP / CP = (100 + P%) / (100 - D%)
- मूल्य वृद्धि (Markup) % = [(P% + D%) / (100 - D%)] * 100

## 4. क्रमिक बट्टा (Successive Discounts)
- दो क्रमिक छूटें: D_eq = d_1 + d_2 - (d_1 * d_2) / 100
- तीन क्रमिक छूटें: SP = MP * (1 - d_1/100) * (1 - d_2/100) * (1 - d_3/100)

## 5. मुफ्त वस्तु योजनाएँ ("X खरीदें, Y मुफ्त पाएं")
- प्रभावी छूट % = [Y / (X + Y)] * 100
- यदि अतिरिक्त d% की नकद छूट भी दी जाए:
  शुद्ध SP गुणक = [X / (X + Y)] * (1 - d/100)

## 6. बेईमान व्यापारी सूत्र
- केवल त्रुटिपूर्ण बाट (क्रय मूल्य पर बिक्री): लाभ % = [त्रुटि / (सत्य माप - त्रुटि)] * 100
- समग्र गुणक विधि: समग्र गुणक = (1 + मूल्य वृद्धि%) * (सत्य माप / असत्य माप) * (1 - छूट%)
- कुल लाभ % = (समग्र गुणक - 1) * 100

## 7. समान विक्रय मूल्य के सौदे (SP_1 = SP_2)
- समान प्रतिशत लाभ व हानि (p = l = x): कुल हानि % = (x / 10)^2 % = (x^2 / 100) %
- भिन्न प्रतिशत (p% लाभ, l% हानि):
  कुल % = [ 100(p - l) - 2pl ] / [ (100 + p) + (100 - l) ]

## 8. वस्तुओं की संख्या की समतुल्यता
- यदि x वस्तुओं का CP = y वस्तुओं का SP हो:
  SP / CP = x / y => लाभ % = [(x - y) / y] * 100 (यदि x > y हो तो लाभ, अन्यथा हानि)
