# 📋 महत्वपूर्ण सूत्र — लाभ और हानि (Profit & Loss)

## 1. आधारभूत सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| लाभ | लाभ = विक्रय मूल्य (SP) − क्रय मूल्य (CP) | SP > CP होने पर |
| हानि | हानि = क्रय मूल्य (CP) − विक्रय मूल्य (SP) | CP > SP होने पर |
| लाभ % | लाभ % = (लाभ / CP) × 100 | हमेशा CP पर गणना |
| हानि % | हानि % = (हानि / CP) × 100 | हमेशा CP पर गणना |
| SP (लाभ से) | SP = CP × (100 + लाभ%) / 100 | लाभ% ज्ञात हो तो |
| SP (हानि से) | SP = CP × (100 − हानि%) / 100 | हानि% ज्ञात हो तो |
| CP (लाभ से) | CP = SP × 100 / (100 + लाभ%) | SP और लाभ% दिया हो |
| CP (हानि से) | CP = SP × 100 / (100 − हानि%) | SP और हानि% दिया हो |
| गुणक विधि (लाभ) | SP = CP × (1 + लाभ%/100) | त्वरित गणना |
| गुणक विधि (हानि) | SP = CP × (1 − हानि%/100) | त्वरित गणना |

## 2. अंकित मूल्य और छूट (Marked Price & Discount)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| छूट | छूट = अंकित मूल्य (MP) − विक्रय मूल्य (SP) | छूट हमेशा MP पर |
| छूट % | छूट % = (छूट / MP) × 100 | MP आधार है, CP नहीं |
| SP (छूट से) | SP = MP × (100 − छूट%) / 100 | एकल छूट |
| MP (SP से) | MP = SP × 100 / (100 − छूट%) | SP ज्ञात हो तो |
| MP–CP संबंध | MP / CP = (100 + लाभ%) / (100 − छूट%) | लाभ% और छूट% दोनों दिए हों |
| क्रमिक छूट (समतुल्य) | समतुल्य छूट% = a + b − (ab/100) | दो क्रमिक छूटें a%, b% |
| तीन क्रमिक छूटें | SP = MP × (1−a/100)(1−b/100)(1−c/100) | गुणक विधि से |

## 3. विशेष स्थितियाँ

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| समान SP, एक पर लाभ x% व दूसरी पर हानि x% | हानि % = x²/100 | सदैव हानि होती है |
| समान SP वाली दो वस्तुओं का कुल CP | कुल CP = 2 × SP × 100² / (100² − x²) | ऊपर वाली स्थिति में |
| CP के x% लाभ पर बेचना = SP का कितना % | SP पर लाभ% = (x / (100+x)) × 100 | आधार बदलने पर |
| SP के x% लाभ = CP का कितना % | CP पर लाभ% = (x / (100−x)) × 100 | आधार बदलने पर |
| वस्तुओं की संख्या समान (CP-आधारित) | लाभ% = [(SP का योग − CP का योग) / CP का योग] × 100 | मिश्र सौदों में |
| x वस्तुओं का CP = y वस्तुओं का SP | लाभ% = ((x − y) / y) × 100 | x > y हो तो लाभ |
| a वस्तुएँ b रु. में खरीदीं, c वस्तुएँ d रु. में बेचीं | लाभ% = ((ad − bc) / bc) × 100 | अलग-अलग दरें हों तो |

## 4. बेईमानी / तौल में धोखा (Dishonest Dealer)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| कम तौलने पर लाभ% | लाभ% = (त्रुटि / सही तौल − त्रुटि) × 100 | त्रुटि = 1000 − वास्तविक तौल |
| कम तौल + छूट दोनों | कुल लाभ% = [(100 + तौल-लाभ%)(100 − छूट%)/100] − 100 | गुणक विधि से |
| खरीद में ज़्यादा तौल, बिक्री में कम तौल | लाभ% = [(खरीद-त्रुटि + बिक्री-त्रुटि + दोनों का गुणनफल/100)] | दोनों ओर धोखा |

## 5. मिश्रण और अन्य

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| दो वस्तुएँ अलग-अलग लाभ/हानि पर | कुल लाभ% = (कुल SP − कुल CP) / कुल CP × 100 | पहले कुल CP, कुल SP निकालें |
| लाभ का x% = हानि का y% (समान CP) | x% लाभ वाला SP : y% हानि वाला SP = (100+x) : (100−y) | अनुपात प्रश्नों में |
| मूल्य वृद्धि पर खपत समान | खपत में कमी% = (वृद्धि / (100 + वृद्धि)) × 100 | खर्च स्थिर रखने हेतु |
| SP समान, लाभ% = हानि% = x | सदैव हानि = x²/100 % | याद रखें: "बराबर-बराबर, हानि पक्की" |

## 6. त्वरित संकेत (Quick Keys)

| संकेत | अर्थ |
|---|---|
| लाभ/हानि % का आधार = **हमेशा CP** | SP पर कभी नहीं (जब तक प्रश्न न कहे) |
| छूट का आधार = **हमेशा MP** | CP पर कभी नहीं |
| क्रमिक परिवर्तन = **गुणकों का गुणन** | जोड़ना नहीं, गुणा करना |
| x% लाभ + x% हानि (समान SP) = **हानि x²/100 %** | शून्य नहीं! |
| CP → SP: ×(100±r)/100 | SP → CP: ÷(100±r)/100 |
