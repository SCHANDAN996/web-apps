# 🪄 ल.स.प. और म.स.प. — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 1: "बड़ा भाई LCM, छोटा भाई HCF"**      │
│                                             │
│ LCM हमेशा संख्याओं से **बड़ा या बराबर** होता है, │
│ HCF हमेशा **छोटा या बराबर**।                  │
│ याद रखें: **"L = Large, H = Half/छोटा"**       │
│ 👉 उत्तर जाँचने का सबसे तेज़ तरीका: अगर LCM    │
│ संख्या से छोटा आया — गणना गलत है!              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 2: "गुणनफल = L × H" (दो संख्याओं का जादू)**│
│                                             │
│ दो संख्याओं का गुणनफल = LCM × HCF             │
│ म्नेमोनिक: **"दो का मेल, LH खेल"**             │
│ ⚠️ ट्रैप: यह नियम सिर्फ **दो** संख्याओं पर लगता है,│
│ तीन पर नहीं! परीक्षक यहीं फँसाता है।            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 3: "HCF = Common का Minimum, LCM = सबका Maximum"**│
│                                             │
│ अभाज्य गुणनखंड विधि में:                      │
│ • HCF → केवल **उभयनिष्ठ** अभाज्य, **छोटी घात**   │
│ • LCM → **सभी** अभाज्य, **बड़ी घात**             │
│ म्नेमोनिक: **"H = Half (आधे/कम), L = Lot (सब/ज़्यादा)"**│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 4: "घंटी-बजना = LCM, बाँटना = HCF"**      │
│                                             │
│ • साथ-साथ बजना/मिलना/चमकना (घंटियाँ, बत्तियाँ,   │
│   ट्रैफिक लाइट) → **LCM**                     │
│ • बराबर बाँटना/काटना/टुकड़े करना (रस्सी, छड़,    │
│   टाइल, कमरा) → **HCF**                       │
│ म्नेमोनिक: **"मिलन में L, बँटवारे में H"**        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 5: शेषफल वाले LCM — "L − k" ट्रिक**       │
│                                             │
│ "वह छोटी संख्या जिसे a, b, c से भाग देने पर     │
│ हर बार शेष r बचे" → **LCM(a,b,c) + r**        │
│ "हर बार शेषफल भाजक से k कम" → **LCM(a,b,c) − k**│
│ म्नेमोनिक: **"बचा जोड़ो, कमी घटाओ"**             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 6: भिन्नों का LCM/HCF — "ऊपर-नीचे उल्टा"**│
│                                             │
│ • भिन्नों का LCM = **अंशों का LCM / हरों का HCF**│
│ • भिन्नों का HCF = **अंशों का HCF / हरों का LCM**│
│ म्नेमोनिक: **"L ऊपर L, H ऊपर H — नीचे उल्टा"**  │
│ (LCM में ऊपर LCM, HCF में ऊपर HCF; नीचे दूसरा)  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 7: सह-अभाज्य (Co-prime) पहचान — "1 ही साथी"**│
│                                             │
│ HCF = 1 हो तो संख्याएँ सह-अभाज्य, और            │
│ **LCM = सीधे दोनों का गुणनफल**।                │
│ म्नेमोनिक: **"कोई साझा नहीं, तो सीधा गुणा"**     │
│ उदा: 8 और 9 → LCM = 72 (बिना गुणनखंड किए!)     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 8: यूक्लिड विभाजन — "बड़े को छोटे से कुचलो"**│
│                                             │
│ बड़ी संख्याओं का HCF: बड़ी संख्या ÷ छोटी,       │
│ फिर भाजक ÷ शेषफल… जब तक शेष 0।                │
│ अंतिम भाजक = HCF।                             │
│ म्नेमोनिक: **"शेष शून्य, खेल ख़त्म"**            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 9: "N संख्याएँ H के गुणज" मॉडल**           │
│                                             │
│ HCF = H दिया हो तो संख्याएँ मानो: Ha, Hb        │
│ (जहाँ a, b सह-अभाज्य)। फिर LCM = H·a·b।        │
│ म्नेमोनिक: **"H बाहर, सह-अभाज्य अंदर"**          │
│ 👉 "LCM और HCF दिए हों, संख्याएँ निकालो" वाले     │
│ प्रश्नों में यही मॉडल 15 सेकंड में हल करता है।    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 10: LCM का LCM — "घातों का मुकाबला"**      │
│                                             │
│ 12 = 2²·3, 18 = 2·3², 30 = 2·3·5              │
│ LCM = हर अभाज्य की **सबसे बड़ी घात**:            │
│ 2²·3²·5 = 180                                 │
│ म्नेमोनिक: **"हर खिलाड़ी का बेस्ट स्कोर"**        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 11: "वर्गाकार टाइल = HCF, वर्ग बनाना = LCM"**│
│                                             │
│ • आयताकार हॉल में **सबसे बड़ी वर्गाकार टाइल**    │
│   → भुजा = HCF(लंबाई, चौड़ाई)                  │
│ • आयताकार टाइलों से **सबसे छोटा वर्ग** बनाना     │
│   → भुजा = LCM(लंबाई, चौड़ाई)                  │
│ म्नेमोनिक: **"बड़ी टाइल H, बड़ा निर्माण L"**      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 12: अनुपात से संख्या — "अनुपात × HCF"**    │
│                                             │
│ दो संख्याओं का अनुपात a:b (सरलतम) और HCF = H    │
│ हो, तो संख्याएँ = **Ha और Hb**, LCM = H·a·b।    │
│ म्नेमोनिक: **"अनुपात कंकाल, HCF मांस"**          │
│ (अनुपात ढाँचा है, HCF उसे असली आकार देता है)     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 13: "एक ही शेषफल" वाला HCF**              │
│                                             │
│ "वह बड़ी-से-बड़ी संख्या जिससे a, b, c को भाग      │
│ देने पर समान शेष बचे" →                       │
│ **HCF(a−b, b−c, c−a)**                        │
│ म्नेमोनिक: **"अंतर निकालो, HCF पाओ"**            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 14: परीक्षा-हॉल 10-सेकंड चेकलिस्ट**        │
│                                             │
│ प्रश्न पढ़ते ही पूछें:                         │
│ ① "साथ/फिर से/एकसाथ" दिखा? → **LCM**           │
│ ② "बड़ी-से-बड़ी/बराबर बाँटना" दिखा? → **HCF**    │
│ ③ "शेष बचे" दिखा? → **+r या −k ट्रिक**          │
│ ④ भिन्न दिखी? → **ऊपर-नीचे उल्टा नियम**          │
│ म्नेमोनिक: **"साथ-L, बाँट-H, शेष-जोड़, भिन्न-उल्टा"**│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 15: "LCM ÷ HCF = सह-अभाज्यों का गुणनफल"**  │
│                                             │
│ दो संख्याओं के लिए: LCM/HCF = a·b (जहाँ संख्याएँ │
│ Ha, Hb हैं)।                                   │
│ उदा: LCM = 84, HCF = 6 → a·b = 14 = 2×7       │
│ → संख्याएँ 12 और 42।                           │
│ म्नेमोनिक: **"भाग दो, जोड़ी खोलो"**              │
└─────────────────────────────────────────────┘
