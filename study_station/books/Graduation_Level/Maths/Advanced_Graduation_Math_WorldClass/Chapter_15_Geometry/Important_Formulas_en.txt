# Important Formulas — Quantitative Aptitude (Quick Revision)

*(All formulas are standard NCERT-level results used in SSC, Railway, Bank and State exams.)*

## 1. Number System

- Sum of first n natural numbers: **1 + 2 + … + n = n(n + 1)/2**
- Sum of first n even numbers: **2 + 4 + … + 2n = n(n + 1)**
- Sum of first n odd numbers: **1 + 3 + … + (2n − 1) = n²**
- Sum of squares: **1² + 2² + … + n² = n(n + 1)(2n + 1)/6**
- Sum of cubes: **1³ + 2³ + … + n³ = [n(n + 1)/2]²**
- Dividend = Divisor × Quotient + Remainder
- HCF × LCM = Product of the two numbers (for two numbers only)

## 2. Percentage

- x% of y = **(x/100) × y**
- Percentage change = **(Change / Original value) × 100**
- If a value increases by x% and then decreases by x%, net change = **−x²/100 %** (always a decrease)
- Successive changes of a% and b%: net change = **a + b + (ab/100) %**

## 3. Profit and Loss

- Profit = SP − CP; Loss = CP − SP
- Profit % = **(Profit / CP) × 100**; Loss % = **(Loss / CP) × 100**
- SP = CP × (100 + Profit%)/100; SP = CP × (100 − Loss%)/100
- Discount = Marked Price − Selling Price; Discount % = **(Discount / MP) × 100**
- When CP of x articles = SP of y articles, Profit % = **(x − y)/y × 100**

## 4. Simple and Compound Interest

- Simple Interest: **SI = (P × R × T)/100**
- Amount (SI) = P + SI
- Compound Interest (annual): **A = P(1 + R/100)ᵀ**; CI = A − P
- Compounded half-yearly: rate = R/2, time = 2T
- Compounded quarterly: rate = R/4, time = 4T
- Difference between CI and SI for 2 years = **P(R/100)²**

## 5. Ratio, Proportion and Average

- If a : b = c : d, then **ad = bc**
- Average = **Sum of all values / Number of values**
- Average of first n natural numbers = **(n + 1)/2**
- If a new person joins a group, change in total = (new average − old average) × new count

## 6. Time, Speed and Distance

- Speed = **Distance / Time**
- km/h to m/s: multiply by **5/18**; m/s to km/h: multiply by **18/5**
- Average speed (equal distances at speeds a and b) = **2ab/(a + b)**
- Train crossing a pole: time = length of train / speed
- Train crossing a platform: time = (train length + platform length) / speed
- Boat downstream speed = boat + stream; upstream speed = boat − stream
- Boat speed in still water = (downstream + upstream)/2; stream speed = (downstream − upstream)/2

## 7. Time and Work

- If A finishes a work in x days, A's 1-day work = **1/x**
- A and B together: 1-day work = **1/x + 1/y**; time = **xy/(x + y)**
- Work = Efficiency × Time (more efficiency ⇒ less time, inverse relation)
- If A is twice as efficient as B, A takes half the time B takes.

## 8. Pipes and Cisterns

- Pipe fills in x hours, drain empties in y hours (y > x): net 1-hour work = **1/x − 1/y**
- Tank filled in = **xy/(y − x)** hours

## 9. Mensuration (2D)

- Square: Area = **side²**; Perimeter = **4 × side**; Diagonal = **side × √2**
- Rectangle: Area = **l × b**; Perimeter = **2(l + b)**; Diagonal = **√(l² + b²)**
- Triangle: Area = **½ × base × height**
- Equilateral triangle: Area = **(√3/4) × side²**; Height = **(√3/2) × side**
- Right triangle: **Hypotenuse² = Base² + Perpendicular²** (Pythagoras)
- Circle: Area = **πr²**; Circumference = **2πr**
- Semi-circle: Area = **πr²/2**; Perimeter = **πr + 2r**
- Parallelogram: Area = **base × height**
- Trapezium: Area = **½ × (sum of parallel sides) × height**
- Rhombus: Area = **½ × d₁ × d₂** (d₁, d₂ are diagonals)

## 10. Mensuration (3D)

- Cube: Volume = **side³**; Surface area = **6 × side²**; Diagonal = **side × √3**
- Cuboid: Volume = **l × b × h**; Surface area = **2(lb + bh + hl)**; Diagonal = **√(l² + b² + h²)**
- Cylinder: Volume = **πr²h**; Curved surface area = **2πrh**; Total surface area = **2πr(r + h)**
- Cone: Volume = **(1/3)πr²h**; Curved surface area = **πrl**, where l = √(r² + h²)
- Sphere: Volume = **(4/3)πr³**; Surface area = **4πr²**
- Hemisphere: Volume = **(2/3)πr³**; Total surface area = **3πr²**

## 11. Algebra Identities

- (a + b)² = a² + 2ab + b²
- (a − b)² = a² − 2ab + b²
- a² − b² = (a + b)(a − b)
- (a + b)³ = a³ + b³ + 3ab(a + b)
- (a − b)³ = a³ − b³ − 3ab(a − b)
- a³ + b³ = (a + b)(a² − ab + b²)
- a³ − b³ = (a − b)(a² + ab + b²)

## 12. Surds, Indices and Logarithms

- aᵐ × aⁿ = aᵐ⁺ⁿ ; aᵐ ÷ aⁿ = aᵐ⁻ⁿ ; (aᵐ)ⁿ = aᵐⁿ
- a⁰ = 1 (a ≠ 0) ; a⁻ⁿ = 1/aⁿ
- log(ab) = log a + log b ; log(a/b) = log a − log b ; log(aⁿ) = n log a

## 13. Permutation, Combination and Probability

- n! = n × (n − 1) × … × 2 × 1 ; 0! = 1
- ⁿPᵣ = **n!/(n − r)!**
- ⁿCᵣ = **n! / [r!(n − r)!]**
- Probability of an event = **Favourable outcomes / Total outcomes** (always between 0 and 1)
- P(event) + P(not event) = 1

## 14. Geometry Facts

- Sum of angles of a triangle = **180°**
- Sum of angles of a quadrilateral = **360°**
- Sum of interior angles of an n-sided polygon = **(n − 2) × 180°**
- Exterior angle of a triangle = sum of the two opposite interior angles
- Angle in a semicircle = **90°**
- Angles in the same segment of a circle are equal
- Tangent is perpendicular to the radius at the point of contact

## 15. Trigonometry (Basic)

- sin²θ + cos²θ = 1
- 1 + tan²θ = sec²θ
- 1 + cot²θ = cosec²θ
- sin(90° − θ) = cos θ ; tan(90° − θ) = cot θ
- Standard values: sin 0° = 0, sin 30° = 1/2, sin 45° = 1/√2, sin 60° = √3/2, sin 90° = 1
- tan 0° = 0, tan 30° = 1/√3, tan 45° = 1, tan 60° = √3
