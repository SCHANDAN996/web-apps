# 🪄 क्षेत्रमिति — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 1: "आधा-आधा" वाला त्रिभुज**          │
│                                             │
│ त्रिभुज का क्षेत्रफल = ½ × आधार × ऊँचाई     │
│                                             │
│ 🧠 याद रखें: "त्रिभुज आयत का **आधा भाई**    │
│ है" — आयत = आधार × ऊँचाई, त्रिभुज = उसका    │
│ आधा। त्रि(3) भुजा वाला आधा (½) खाता है!     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 2: वृत्त — "पाई-आर-स्क्वायर पिज़्ज़ा"**│
│                                             │
│ क्षेत्रफल = πr² | परिधि = 2πr               │
│                                             │
│ 🧠 म्नेमोनिक: "**पिज़्ज़ा πr²**" — पिज़्ज़ा   │
│ (गोल) का क्षेत्रफल πr²। और किनारे की क्रस्ट │
│ (परिधि) = 2πr — "दो पाई आर की क्रस्ट"।      │
│                                             │
│ ⚡ परीक्षा ट्रैप: r² (क्षेत्रफल) vs 2r       │
│ (परिधि) — घात देखकर पहचानें!                │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 3: घन vs घनाभ — "सब बराबर"**         │
│                                             │
│ घन (Cube): सभी भुजाएँ बराबर (a)             │
│ आयतन = a³, पृष्ठ = 6a², विकर्ण = a√3        │
│                                             │
│ 🧠 याद रखें: घन = "**घर का डिब्बा**" —      │
│ 6 फलक (6a²), 3 आयाम (a³), विकर्ण में √3     │
│ (तीनों दिशाएँ मिलकर)।                        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 4: बेलन — "टिन का डिब्बा"**          │
│                                             │
│ वक्र पृष्ठ = 2πrh | कुल पृष्ठ = 2πr(r+h)    │
│ आयतन = πr²h                                 │
│                                             │
│ 🧠 ट्रिक: "**लेबल vs ढक्कन**" — टिन पर      │
│ चिपका लेबल = वक्र पृष्ठ (2πrh), ढक्कन-तली   │
│ जोड़ दो = कुल पृष्ठ। आयतन = "पिज़्ज़ा को     │
│ ऊँचा कर दो" (πr² × h)।                      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 5: शंकु — "एक-तिहाई जादू"**          │
│                                             │
│ आयतन = (1/3)πr²h                            │
│                                             │
│ 🧠 म्नेमोनिक: "**शंकु कंजूस है**" — उसी     │
│ आधार-ऊँचाई के बेलन का सिर्फ़ 1/3 भरता है।   │
│ आइसक्रीम कोन = बेलन-गिलास का तिहाई!         │
│                                             │
│ ⚡ तिरछी ऊँचाई: l = √(r² + h²) — "पाइथागोरस │
│ का कोन"                                     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 6: गोला — "4-4 का खेल"**             │
│                                             │
│ पृष्ठ = 4πr² | आयतन = (4/3)πr³              │
│                                             │
│ 🧠 याद रखें: "**चार-चार गोला**" — पृष्ठ में │
│ 4πr², आयतन में भी 4 (4/3 πr³)। आयतन में    │
│ घात 3 और भाजक 3 — "**घात = भाजक**"!         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 7: अर्धगोला — "आधा + एक"**           │
│                                             │
│ वक्र पृष्ठ = 2πr² | कुल पृष्ठ = 3πr²        │
│ आयतन = (2/3)πr³                             │
│                                             │
│ 🧠 ट्रिक: कटोरा उल्टा रखो — गोला भाग 2πr²,  │
│ सपाट तली πr² जोड़ो = **3πr²**। "2 गोल + 1   │
│ सपाट = 3"                                    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 8: समलंब चतुर्भुज — "औसत का रास्ता"**│
│                                             │
│ क्षेत्रफल = ½ × (समांतर भुजाओं का योग) ×    │
│ ऊँचाई                                       │
│                                             │
│ 🧠 म्नेमोनिक: "**दो सड़कें, एक औसत**" —     │
│ समांतर भुजाएँ a और b की औसत (a+b)/2 लो,     │
│ ऊँचाई से गुणा करो। औसत × ऊँचाई = क्षेत्रफल! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 9: समचतुर्भुज — "विकर्णों का आधा     │
│ खेल"**                                      │
│                                             │
│ क्षेत्रफल = ½ × d₁ × d₂                     │
│                                             │
│ 🧠 याद रखें: "**पतंग का क्षेत्रफल**" —      │
│ पतंग (काइट) के दोनों डंडे (विकर्ण) गुणा     │
│ करके आधा करो। पतंग = समचतुर्भुज परिवार!     │
└─────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ **ट्रिक 10: हीरोन का सूत्र — "सेमी की सेना"** │
│                                              │
│ s = (a+b+c)/2                                │
│ क्षेत्रफल = √[s(s−a)(s−b)(s−c)]              │
│                                              │
│ 🧠 म्नेमोनिक: "**पहले आधा घेरा, फिर सबसे    │
│ घटाओ**" — s = अर्ध-परिमाप (semi = आधा),     │
│ फिर s में से हर भुजा घटाकर गुणा, फिर         │
│ वर्गमूल। "सेमी (s) से शुरू, रूट पर खत्म"।   │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ **ट्रिक 11: पाइप/खोखला बेलन — "R² − r²"**     │
│                                              │
│ आयतन = πh(R² − r²)                           │
│                                              │
│ 🧠 ट्रिक: "**बड़े में से छोटा निकालो**" —    │
│ पाइप = बाहरी बेलन − भीतरी बेलन। R बड़ा,      │
│ r छोटा — हमेशा वर्गों का अंतर!               │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ **ट्रिक 12: प्रिज़्म/समान प्रवाह — "आयतन      │
│ अपरिवर्तित"**                                │
│                                              │
│ पिघलाकर ढलाई: आयतन₁ = आयतन₂                  │
│                                              │
│ 🧠 म्नेमोनिक: "**मिट्टी वही, आकार नया**" —  │
│ गेंद से घन बनाओ, तार से वृत्त बनाओ — आयतन   │
│ (या तार की लंबाई) कभी नहीं बदलता। ऐसे       │
│ प्रश्नों में सीधे आयतन बराबर रखो!            │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ **ट्रिक 13: भुजा × k का प्रभाव — "घात का     │
│ खेल"**                                       │
│                                              │
│ भुजा k गुना → परिमाप k गुना → क्षेत्रफल k²  │
│ गुना → आयतन k³ गुना                          │
│                                              │
│ 🧠 याद रखें: "**1-2-3 सीढ़ी**" — लंबाई (1D) │
│ में k, क्षेत्रफल (2D) में k², आयतन (3D) में │
│ k³। आयाम = घात!                              │
│                                              │
│ ⚡ उदाहरण: भुजा दोगुनी → क्षेत्रफल 4 गुना,  │
│ आयतन 8 गुना।                                 │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ **ट्रिक 14: वर्ग का विकर्ण — "√2 का रिश्ता"** │
│                                              │
│ विकर्ण = a√2 | क्षेत्रफल = d²/2              │
│                                              │
│ 🧠 ट्रिक: "**विकर्ण से क्षेत्रफल = आधा      │
│ वर्ग**" — d²/2 यानी विकर्ण के वर्ग का आधा।  │
│ "विकर्ण आया, वर्ग करो, आधा करो"।             │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ **ट्रिक 15: घनाभ का विकर्ण — "3D पाइथागोरस"** │
│                                              │
│ विकर्ण = √(l² + b² + h²)                     │
│                                              │
│ 🧠 म्नेमोनिक: "**तीनों माप, वर्ग, जोड़,     │
│ रूट**" — कमरे के कोने से कोने तक की दूरी।   │
│ 2D में दो माप, 3D में तीन — बस एक और जोड़   │
│ दो!                                          │
└──────────────────────────────────────────────┘

## ⚡ सुपर-फास्ट रिवीज़न टेबल (एक नज़र में)

| आकृति | कीवर्ड याद रखें | मुख्य सूत्र |
|---|---|---|
| त्रिभुज | आधा भाई | ½ × b × h |
| वृत्त | पिज़्ज़ा πr² | πr², 2πr |
| घन | घर का डिब्बा | a³, 6a², a√3 |
| बेलन | टिन का डिब्बा | πr²h, 2πrh |
| शंकु | कंजूस (1/3) | (1/3)πr²h |
| गोला | चार-चार | 4πr², (4/3)πr³ |
| अर्धगोला | 2 गोल + 1 सपाट | 3πr² |
| समलंब | औसत का रास्ता | ½(a+b)h |
| समचतुर्भुज | पतंग | ½d₁d₂ |
| स्केलिंग | 1-2-3 सीढ़ी | k, k², k³ |
