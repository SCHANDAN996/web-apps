# 🪄 Short Tricks — Mensuration (Memory Hacks)

---

**Trick 1 — "Pizza Pie" for Circle Area**
```
┌─────────────────────────────────────────────┐
│ 🍕 "Apple pies ARE square? NO — pies are    │
│ ROUND: πr²!"                                │
│ Area of circle = πr² (r is SQUARED —        │
│ two r's, like two slices).                  │
│ Circumference = 2πr (ONE r — just the rim). │
│ Count the r's: Area→2, Rim→1.               │
└─────────────────────────────────────────────┘
```

**Trick 2 — "LATE Night Cylinder"**
```
┌─────────────────────────────────────────────┐
│ 🥫 Curved Surface Area of cylinder = 2πrh   │
│ Remember: "Two Pies Roll Home"              │
│ 2-π-r-h → say it as a chant.                │
│ Total SA = 2πr(h + r) → "Two Pies, Height   │
│ plus Radius" — the lids (r) join the party. │
└─────────────────────────────────────────────┘
```

**Trick 3 — "Cone = One-Third Cousin"**
```
┌─────────────────────────────────────────────┐
│ 🍦 Volume of cone = (1/3)πr²h               │
│ A cone is a cylinder's skinny cousin who    │
│ eats only ONE-THIRD of the meal.            │
│ Same base, same height → cone holds 1/3.    │
│ (Works for pyramid too: 1/3 × base × h!)    │
└─────────────────────────────────────────────┘
```

**Trick 4 — "Slant Height Ladder"**
```
┌─────────────────────────────────────────────┐
│ 🪜 l² = r² + h²  (Pythagoras in disguise!)  │
│ The slant height is a LADDER leaning on a   │
│ cone: ground = r, wall = h, ladder = l.     │
│ See "slant" → think "right triangle".       │
└─────────────────────────────────────────────┘
```

**Trick 5 — "Hero Needs SSS"**
```
┌─────────────────────────────────────────────┐
│ 🦸 Heron's formula: Area = √[s(s−a)(s−b)(s−c)]│
│ where s = (a+b+c)/2                         │
│ "HERO saves Semi-perimeter, then subtracts  │
│ Each Side, multiplies All, takes Root."     │
│ S → Subtract → Square root.                 │
└─────────────────────────────────────────────┘
```

**Trick 6 — "Trapezium = Average Couple × Gap"**
```
┌─────────────────────────────────────────────┐
│ 🛤️ Area = ½ × (sum of parallel sides) × h   │
│ Two parallel rails are a COUPLE — take      │
│ their AVERAGE, multiply by the GAP (h).     │
│ "Average the pair, multiply the gap."       │
└─────────────────────────────────────────────┘
```

**Trick 7 — "Rhombus & Kite: Diagonal Deal"**
```
┌─────────────────────────────────────────────┐
│ 🪁 Area = ½ × d₁ × d₂                       │
│ Rhombus, kite — anything with crossing      │
│ diagonals: "HALF the Diagonal Deal."        │
│ Square too! (d₁ = d₂ → d²/2).               │
└─────────────────────────────────────────────┘
```

**Trick 9 — "Cuboid Diagonal = 3D Pythagoras"**
```
┌─────────────────────────────────────────────┐
│ 📦 Diagonal = √(l² + b² + h²)               │
│ "Add THREE squares, then root — the space   │
│ diagonal pokes through the box."            │
│ Just Pythagoras with one extra friend (h).  │
└─────────────────────────────────────────────┘
```

**Trick 10 — "Sphere: 4-3 Rule"**
```
┌─────────────────────────────────────────────┐
│ ⚽ Surface = 4πr²  |  Volume = (4/3)πr³     │
│ "FOUR on the skin, FOUR-THIRDS inside."     │
│ Surface has r² (flat-ish), Volume has r³    │
│ (full 3D). Power of r = dimension count!    │
└─────────────────────────────────────────────┘
```

**Trick 11 — "Hemisphere = Half + Lid"**
```
┌─────────────────────────────────────────────┐
│ 🍜 CSA = 2πr² (half of 4πr²)                │
│ TSA = 3πr² (half + the circular LID πr²)    │
│ Volume = (2/3)πr³                           │
│ "Half the ball, then add the lid — 2+1=3."  │
└─────────────────────────────────────────────┘
```

**Trick 12 — "Sector = Fraction of the Pie"**
```
┌─────────────────────────────────────────────┐
│ 🥧 Arc length = (θ/360) × 2πr               │
│ Sector area = (θ/360) × πr²                 │
│ "Whatever FRACTION θ is of 360°, that's     │
│ your fraction of the whole circle."         │
│ One fraction rules arcs AND areas.          │
└─────────────────────────────────────────────┘
```

**Trick 13 — "Path Around the Field"**
```
┌─────────────────────────────────────────────┐
│ 🚶 Path OUTSIDE rectangle:                  │
│ Area = (l+2w)(b+2w) − lb                    │
│ Path INSIDE: Area = lb − (l−2w)(b−2w)       │
│ "Path adds TWICE its width to each side —   │
│ because it walks on BOTH ends!"             │
└─────────────────────────────────────────────┘
```

**Trick 15 — "π = 22/7 vs 3.14 Signal"**
```
┌─────────────────────────────────────────────┐

│ (the 7 cancels beautifully).                │

└─────────────────────────────────────────────┘
```
