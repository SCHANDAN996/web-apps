# क्षेत्रमिति — महत्वपूर्ण सूत्र

## 1. द्विविमीय आकृतियाँ (2D)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| वर्ग का क्षेत्रफल | a² | भुजा a |
| वर्ग का विकर्ण | a√2 | विकर्ण से क्षेत्रफल = d²/2 |
| आयत का क्षेत्रफल | l × b | लंबाई × चौड़ाई |
| आयत का परिमाप | 2(l + b) | बाड़ लगाने वाले प्रश्न |
| त्रिभुज का क्षेत्रफल | ½ × आधार × ऊँचाई | मूल सूत्र |
| हीरोन का सूत्र | √[s(s−a)(s−b)(s−c)], s = (a+b+c)/2 | तीनों भुजाएँ दी हों |
| समबाहु त्रिभुज का क्षेत्रफल | (√3/4)a² | भुजा a |
| समबाहु त्रिभुज की ऊँचाई | (√3/2)a | ऊँचाई-आधारित प्रश्न |
| समद्विबाहु त्रिभुज का क्षेत्रफल | (b/4)√(4a² − b²) | a = समान भुजा, b = आधार |
| समकोण त्रिभुज | कर्ण² = लंब² + आधार² | पाइथागोरस |
| समांतर चतुर्भुज का क्षेत्रफल | आधार × ऊँचाई | तिरछी आकृति |
| समचतुर्भुज का क्षेत्रफल | ½ × d₁ × d₂ | विकर्णों से |
| समलंब चतुर्भुज का क्षेत्रफल | ½ × (समांतर भुजाओं का योग) × ऊँचाई | Trapezium |
| चक्रीय चतुर्भुज का क्षेत्रफल | √[(s−a)(s−b)(s−c)(s−d)] | चारों भुजाएँ दी हों |
| वृत्त का क्षेत्रफल | πr² | त्रिज्या r |
| वृत्त की परिधि | 2πr | चक्कर/पहिया प्रश्न |
| त्रिज्यखंड का क्षेत्रफल | (θ/360°) × πr² | कोण θ डिग्री में |
| चाप की लंबाई | (θ/360°) × 2πr | θ डिग्री में |
| वृत्तखंड का क्षेत्रफल | (θ/360°)πr² − ½r²sinθ | त्रिज्यखंड − त्रिभुज |
| वलय (Ring) का क्षेत्रफल | π(R² − r²) | R = बाह्य, r = आंतरिक त्रिज्या |
| अर्धवृत्त का क्षेत्रफल | ½πr² | आधा वृत्त |
| बहुभुज (n भुजा) का क्षेत्रफल | (na²/4)cot(π/n) | सम बहुभुज, भुजा a |
| सम षट्भुज का क्षेत्रफल | (3√3/2)a² | 6 समबाहु त्रिभुजों का योग |
| पथ (चारों ओर अंदर) का क्षेत्रफल | lb − (l − 2w)(b − 2w) | w = पथ की चौड़ाई; पूरे आयत में से आंतरिक आयत घटाएँ |
| पथ (चारों ओर बाहर) का क्षेत्रफल | (l + 2w)(b + 2w) − lb | बाहरी पथ; बड़े आयत में से मूल आयत घटाएँ |

## 2. त्रिविमीय आकृतियाँ (3D)

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| घन का आयतन | a³ | भुजा a |
| घन का पृष्ठीय क्षेत्रफल | 6a² | कुल सतह |
| घन का विकर्ण | a√3 | कमरे का विकर्ण |
| घनाभ का आयतन | l × b × h | टंकी/बक्सा |
| घनाभ का पृष्ठीय क्षेत्रफल | 2(lb + bh + hl) | कुल सतह |
| घनाभ का विकर्ण | √(l² + b² + h²) | सबसे लंबी छड़ |
| बेलन का आयतन | πr²h | पाइप/टंकी |
| बेलन का वक्र पृष्ठ | 2πrh | बिना ढक्कन-तल |
| बेलन का कुल पृष्ठ | 2πr(r + h) | बंद बेलन |
| शंकु का आयतन | (1/3)πr²h | बेलन का एक-तिहाई |
| शंकु का वक्र पृष्ठ | πrl | l = तिर्यक ऊँचाई |
| शंकु का कुल पृष्ठ | πr(l + r) | वक्र + आधार |
| शंकु की तिर्यक ऊँचाई | l = √(r² + h²) | पाइथागोरस से |
| गोले का आयतन | (4/3)πr³ | ठोस गोला |
| गोले का पृष्ठीय क्षेत्रफल | 4πr² | गेंद की सतह |
| अर्धगोले का आयतन | (2/3)πr³ | कटोरा |
| अर्धगोले का वक्र पृष्ठ | 2πr² | बिना तल |
| अर्धगोले का कुल पृष्ठ | 3πr² | तल सहित |
| शंकु-छिन्नक (Frustum) का आयतन | (1/3)πh(R² + r² + Rr) | R = बड़ी, r = छोटी त्रिज्या |
| छिन्नक का वक्र पृष्ठ | π(R + r)l | l = तिर्यक ऊँचाई |
| प्रिज्म का आयतन | आधार का क्षेत्रफल × ऊँचाई | सामान्य नियम |
| पिरामिड का आयतन | (1/3) × आधार क्षेत्रफल × ऊँचाई | सामान्य नियम |
| गोलीय कोशल (Shell) का आयतन | (4/3)π(R³ − r³) | खोखला गोला |

## 3. परिवर्तन और संबंध-नियम

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| भुजा k गुना → क्षेत्रफल | k² गुना | 2D स्केलिंग |
| भुजा k गुना → आयतन | k³ गुना | 3D स्केलिंग |
| पिघलाकर ढलाई | आयतन₁ = आयतन₂ | गोला → बेलन आदि |
| बेलन में डूबी वस्तु | उठा हुआ जल = वस्तु का आयतन | विस्थापन सिद्धांत |
| पहिये के चक्कर | दूरी = चक्करों की संख्या × 2πr | परिधि-आधारित |
| 1 घन मीटर | 1000 लीटर | आयतन-क्षमता रूपांतरण |
| 1 हेक्टेयर | 10,000 वर्ग मीटर | भूमि मापन |
| 1 एकड़ | 4046.86 वर्ग मीटर (लगभग) | भूमि मापन |
| वर्ग में बना सबसे बड़ा वृत्त | r = a/2 | अंतःवृत्त |
| वृत्त में बना सबसे बड़ा वर्ग | विकर्ण = 2r | परिवर्ग |
