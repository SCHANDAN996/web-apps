51. If z = 3 + 4i, then the value of z·z̄ is
(a) 24i (b) 7 (c) 5 (d) 25
Answer: (d)
Solution: The tempting wrong answer 5 comes from confusing z·z̄ with |z|; the modulus is 5, but the product of a number with its conjugate is the square of the modulus. z·z̄ = (3 + 4i)(3 − 4i) = 9 + 16 = 25, so the answer is 25.
Source: NCERT Class 11 Mathematics, Chapter 5

52. The modulus of (1 + i)/(1 − i) is
(a) 0 (b) 1 (c) √2 (d) 2
Answer: (b)
Solution: The tempting wrong answer √2 comes from taking the modulus of the numerator only and forgetting the denominator. Use |z₁/z₂| = |z₁|/|z₂| = √2/√2 = 1, so the answer is 1.
Source: NCERT Class 11 Mathematics, Chapter 5

53. If z = x + iy and |z − 2| = |z + 2|, then the locus of z is
(a) the y-axis (b) the x-axis (c) the line x = 2 (d) a circle of radius 2
Answer: (a)
Solution: The tempting wrong answer "a circle of radius 2" comes from confusing a perpendicular bisector with a circle. |z − 2| = |z + 2| means z is equidistant from (2, 0) and (−2, 0), so the locus is the perpendicular bisector of the segment joining them, which is the y-axis, so the answer is the y-axis.
Source: NCERT Class 11 Mathematics, Chapter 5

54. The value of i¹⁰³ + i¹⁰⁴ + i¹⁰⁵ is
(a) i (b) 1 (c) −1 (d) −i
Answer: (b)
Solution: The tempting wrong answer i comes from summing only the first and last terms and dropping the middle one. Reduce powers mod 4: i¹⁰³ = i³ = −i, i¹⁰⁴ = 1, i¹⁰⁵ = i, and the sum is −i + 1 + i = 1, so the answer is 1.
Source: NCERT Class 11 Mathematics, Chapter 5

55. If (a + ib)(c + id) = p + iq, then (a² + b²)(c² + d²) equals
(a) 2pq (b) p² − q² (c) p² + q² (d) p² + q² + 2pq
Answer: (c)
Solution: The tempting wrong answer p² − q² comes from mishandling the modulus-squared identity. Since |z₁z₂|² = |z₁|²|z₂|², we get (a² + b²)(c² + d²) = p² + q², so the answer is p² + q².
Source: NCERT Class 11 Mathematics, Chapter 5

56. The argument of z = −1 − i is
(a) π/4 (b) −π/4 (c) −3π/4 (d) 3π/4
Answer: (c)
Solution: The tempting wrong answer π/4 comes from ignoring the signs of both coordinates. The point (−1, −1) lies in the third quadrant, so arg z = −π + π/4 = −3π/4 (principal value), so the answer is −3π/4.
Source: NCERT Class 11 Mathematics, Chapter 5

57. If z₁ = 2 + 3i and z₂ = 1 − i, then z₁/z₂ equals
(a) (−1 + 5i)/2 (b) (5 + i)/2 (c) (−1 − 5i)/2 (d) (1 + 5i)/2
Answer: (a)
Solution: The tempting wrong answer (5 + i)/2 comes from a sign error while multiplying by the conjugate. Multiply numerator and denominator by 1 + i: (2 + 3i)(1 + i) = 2 + 2i + 3i + 3i² = −1 + 5i, and the denominator is 1 + 1 = 2, so the answer is (−1 + 5i)/2.
Source: NCERT Class 11 Mathematics, Chapter 5

58. The number of solutions of z² + |z|² = 0, where z is complex, is
(a) infinitely many (b) 2 (c) 4 (d) 1
Answer: (a)
Solution: The tempting wrong answer 2 comes from treating it like a real quadratic. Write z = x + iy: z² + |z|² = (x² − y² + x² + y²) + 2ixy = 2x² + 2ixy = 0, giving x = 0 with y arbitrary, so every purely imaginary number satisfies it and the answer is infinitely many.
Source: NCERT Exemplar Class 11 Mathematics

59. If ω is a complex cube root of unity, then (1 + ω)(1 + ω²) equals
(a) 0 (b) 1 (c) −1 (d) ω
Answer: (b)
Solution: The tempting wrong answer 0 comes from misusing 1 + ω + ω² = 0. Expand: 1 + ω + ω² + ω³ = 0 + 1 = 1, since ω³ = 1, so the answer is 1.
Source: NCERT Class 11 Mathematics, Chapter 5

60. If |z| = 1, then (z − 1)/(z + 1), z ≠ −1, is
(a) purely real (b) equal to 1 (c) purely imaginary (d) equal to −1
Answer: (c)
Solution: The tempting wrong answer "purely real" comes from assuming the quotient of unit-modulus numbers is real. Let w = (z − 1)/(z + 1); when |z| = 1 one finds w + w̄ = 0 (check with z = i: w = (i − 1)/(i + 1) = i), so Re(w) = 0 and the answer is purely imaginary.
Source: NCERT Exemplar Class 11 Mathematics

61. The value of (1 + i)⁸ is
(a) −16i (b) −16 (c) 16 (d) 16i
Answer: (c)
Solution: The tempting wrong answer 16i comes from stopping at (1 + i)² = 2i and mishandling the later squarings. (1 + i)⁸ = (2i)⁴ = 16i⁴ = 16, so the answer is 16.
Source: NCERT Class 11 Mathematics, Chapter 5

62. If z = cos θ + i sin θ, then zⁿ + 1/zⁿ equals
(a) 2i sin nθ (b) 2 sin nθ (c) cos nθ (d) 2 cos nθ
Answer: (d)
Solution: The tempting wrong answer 2i sin nθ belongs to zⁿ − 1/zⁿ, not the sum. By De Moivre's theorem, zⁿ = cos nθ + i sin nθ and 1/zⁿ = cos nθ − i sin nθ; adding gives 2 cos nθ, so the answer is 2 cos nθ.
Source: NCERT Class 11 Mathematics, Chapter 5

63. The conjugate of (2 + 3i)/(1 − 2i) is
(a) (4 − 7i)/5 (b) (−4 + 7i)/5 (c) (−4 − 7i)/5 (d) (4 + 7i)/5
Answer: (c)
Solution: The tempting wrong answer (−4 + 7i)/5 is the quotient itself, not its conjugate. First compute (2 + 3i)(1 + 2i)/(1 + 4) = (2 + 4i + 3i − 6)/5 = (−4 + 7i)/5; the conjugate flips the imaginary sign, so the answer is (−4 − 7i)/5.
Source: NCERT Class 11 Mathematics, Chapter 5

64. If |z − 3i| = 3, then the locus of z is
(a) a circle with centre (0, 3) and radius 3 (b) a circle with centre (3, 0) and radius 3 (c) a line through (0, 3) (d) a circle with centre (0, −3) and radius 3
Answer: (a)
Solution: The tempting wrong answer "centre (3, 0)" comes from reading 3i as the real number 3. |z − z₀| = r is a circle with centre z₀ and radius r; here z₀ = 3i = (0, 3), so the answer is a circle with centre (0, 3) and radius 3.
Source: NCERT Class 11 Mathematics, Chapter 5

65. The value of (1 − ω + ω²)(1 + ω − ω²), where ω is a complex cube root of unity, is
(a) 2 (b) 0 (c) −4 (d) 4
Answer: (d)
Solution: The tempting wrong answer 0 comes from wrongly setting each bracket to zero. Since 1 + ω + ω² = 0, we have 1 + ω² = −ω and 1 + ω = −ω², so the first bracket is −2ω and the second is −2ω²; the product is 4ω³ = 4, so the answer is 4.
Source: NCERT Class 11 Mathematics, Chapter 5

66. If z + 1/z = 1, then z³ equals
(a) −1 (b) 1 (c) i (d) −i
Answer: (a)
Solution: The tempting wrong answer 1 comes from assuming z is a cube root of unity. From z + 1/z = 1 we get z² − z + 1 = 0; multiplying by (z + 1) gives z³ + 1 = 0, so the answer is −1.

67. The modulus of (3 − 4i)(12 + 5i) is
(a) 25 (b) 13 (c) 5 (d) 65
Answer: (d)
Solution: The tempting wrong answer 13 comes from taking only |12 + 5i| and forgetting the product rule. |z₁z₂| = |z₁||z₂| = 5 × 13 = 65, so the answer is 65.

68. If z = (1 + i√3)², then arg z is
(a) π/3 (b) −2π/3 (c) π/6 (d) 2π/3
Answer: (d)
Solution: The tempting wrong answer π/3 is the argument of 1 + i√3 before squaring. Squaring doubles the argument: arg z = 2 × π/3 = 2π/3, which lies in (−π, π], so the answer is 2π/3.

69. The real part of (1 + i)¹⁰ is
(a) 1024 (b) 32 (c) −32 (d) 0
Answer: (d)
Solution: The tempting wrong answer 32 comes from computing the modulus instead of the real part. (1 + i)² = 2i, so (1 + i)¹⁰ = (2i)⁵ = 32i⁵ = 32i, whose real part is 0, so the answer is 0.
Source: NCERT Class 11 Mathematics, Chapter 5

70. If z₁ and z₂ are complex numbers such that |z₁ + z₂| = |z₁| + |z₂|, then
(a) arg z₁ = −arg z₂ (b) z₁ = z₂ (c) arg z₁ = arg z₂ (d) |z₁| = |z₂|
Answer: (c)
Solution: The tempting wrong answer z₁ = z₂ is sufficient but not necessary. Equality in the triangle inequality holds exactly when z₁ and z₂ point in the same direction, i.e., arg z₁ = arg z₂, so the answer is arg z₁ = arg z₂.
Source: NCERT Exemplar Class 11 Mathematics

71. The value of i + i² + i³ + … + i¹⁰⁰ is
(a) 0 (b) 1 (c) i (d) −1
Answer: (a)
Solution: The tempting wrong answer i comes from summing only the first few terms. Powers of i cycle in blocks of four summing to 0; 100 terms make exactly 25 complete blocks, so the answer is 0.

72. If z = x + iy satisfies arg(z − 1) = arg(z + 3), then the locus of z is
(a) a circle (b) the x-axis outside the segment [−3, 1] (c) the line segment joining (1, 0) and (−3, 0) excluding endpoints (d) the y-axis
Answer: (b)
Solution: The tempting wrong answer "a circle" confuses equal arguments with a constant angle difference. Equal arguments mean z lies on the same ray direction from both points, which happens on the x-axis outside the segment joining (−3, 0) and (1, 0), so the answer is the x-axis outside the segment [−3, 1].
Source: NCERT Exemplar Class 11 Mathematics

73. If (x + iy)¹ᐟ³ = a + ib, then x/a + y/b equals
(a) 4(a² − b²) (b) 4(a² + b²) (c) a² − b² (d) 2(a² + b²)
Answer: (a)
Solution: The tempting wrong answer 4(a² + b²) comes from a sign slip while cubing. Cubing: x = a³ − 3ab² and y = 3a²b − b³, so x/a = a² − 3b² and y/b = 3a² − b²; adding gives 4a² − 4b², so the answer is 4(a² − b²).

74. The least positive integer n for which ((1 + i)/(1 − i))ⁿ = 1 is
(a) 2 (b) 4 (c) 8 (d) 16
Answer: (b)
Solution: The tempting wrong answer 2 comes from computing ((1+i)/(1−i))² = i² = −1 and stopping too early. (1 + i)/(1 − i) = i, and the least n with iⁿ = 1 is n = 4, so the answer is 4.
Source: NCERT Class 11 Mathematics, Chapter 5

75. If z₁ = 1 + 2i and z₂ = 2 − i, then |z₁z₂| equals
(a) 25 (b) 5 (c) 7 (d) √7
Answer: (b)
Solution: The tempting wrong answer 25 is |z₁z₂|², not the modulus itself. |z₁z₂| = |z₁||z₂| = √5 × √5 = 5 (equivalently z₁z₂ = 4 + 3i, whose modulus is 5), so the answer is 5.
Source: NCERT Class 11 Mathematics, Chapter 5
