1. If z = 3 + 4i, then |z| equals
(a) 12 (b) 7 (c) 25 (d) 5
Answer: (d)
Solution: The tempting wrong option is 7, obtained by simply adding 3 and 4, but modulus is not a sum. |z| = √(3² + 4²) = √(9 + 16) = √25, so the answer is 5.
Source: NCERT Class 11 Mathematics, Chapter 5

2. The value of i²⁰²³ is
(a) i (b) −1 (c) 1 (d) −i
Answer: (d)
Solution: The trap is to stop at i²⁰²⁰ = 1 and forget the remainder. Since 2023 = 4 × 505 + 3, i²⁰²³ = i³ = −i, so the answer is −i.

3. The conjugate of the complex number 5 − 7i is
(a) −5 − 7i (b) 7 − 5i (c) −5 + 7i (d) 5 + 7i
Answer: (d)
Solution: The tempting wrong option is −5 − 7i, which changes both signs, but conjugation changes only the sign of the imaginary part. Conjugate of 5 − 7i is 5 + 7i, so the answer is 5 + 7i.

4. If z = 2 + 3i, then z + z̄ equals
(a) 4 (b) 6i (c) 13 (d) 4 + 6i
Answer: (a)
Solution: The trap is 4 + 6i, obtained by adding without changing the sign of the imaginary part. z + z̄ = (2 + 3i) + (2 − 3i) = 4, so the answer is 4.

5. The product (1 + i)(1 − i) equals
(a) 0 (b) 1 (c) 2i (d) 2
Answer: (d)
Solution: The tempting wrong option is 0, from wrongly treating it as a difference of squares with i² = 1. (1 + i)(1 − i) = 1 − i² = 1 − (−1) = 2, so the answer is 2.

6. The imaginary part of (3 + 2i)/(1 − i) is
(a) 5/2 (b) 1/2 (c) −1/2 (d) 5
Answer: (a)
Solution: Multiply numerator and denominator by 1 + i: numerator becomes (3 + 2i)(1 + i) = 3 + 3i + 2i + 2i² = 1 + 5i, and denominator becomes 2. So the quotient is 1/2 + (5/2)i. The trap is to report the real part 1/2 instead of the imaginary part, so the answer is 5/2.
Source: NCERT Class 11 Mathematics, Chapter 5

7. The value of (1 + i)² is
(a) 2 (b) 1 + 2i (c) 2i (d) 0
Answer: (c)
Solution: The tempting wrong option is 2, from forgetting that i² = −1. (1 + i)² = 1 + 2i + i² = 1 + 2i − 1 = 2i, so the answer is 2i.

8. If z = −1 + i√3, then |z| equals
(a) 2 (b) 4 (c) √2 (d) 1
Answer: (a)
Solution: The trap is 4, which is |z|² rather than |z|. |z| = √((−1)² + (√3)²) = √(1 + 3) = √4, so the answer is 2.

9. The multiplicative inverse of i is
(a) −i (b) i (c) 1 (d) −1
Answer: (a)
Solution: The tempting wrong option is i, but i × i = −1, not 1. Since i × (−i) = −i² = 1, the inverse of i is −i, so the answer is −i.

11. The value of i⁴ⁿ, where n is a positive integer, is
(a) −1 (b) i (c) 1 (d) −i
Answer: (c)
Solution: The trap is −1, which is i², not i⁴. Since i⁴ = 1, any power that is a multiple of 4 gives 1, so the answer is 1.

12. If z = 4 − 3i, then z·z̄ equals
(a) 7 (b) 1 (c) 25 (d) 16
Answer: (c)
Solution: The tempting wrong option is 7, from adding 4 and 3. z·z̄ = |z|² = 4² + (−3)² = 16 + 9, so the answer is 25.

13. The complex number 1/(3 + 4i) in the form a + ib is
(a) 3/25 + 4i/25 (b) 3/7 − 4i/7 (c) 3/25 − 4i/25 (d) −3/25 + 4i/25
Answer: (c)
Solution: Multiply numerator and denominator by the conjugate 3 − 4i: denominator becomes 9 + 16 = 25, numerator becomes 3 − 4i. The trap is 3/7 − 4i/7, using 3 + 4 = 7 as denominator, so the answer is 3/25 − 4i/25.

15. If x + iy = (2 + 3i)(2 − 3i), then the value of y is
(a) 0 (b) 13 (c) 12 (d) −9
Answer: (a)
Solution: (2 + 3i)(2 − 3i) = 4 − 9i² = 4 + 9 = 13, a purely real number. The trap is 13, which is the value of x, not y, so the answer is 0.

17. The argument (principal value) of the complex number 1 + i is

Answer: (a)

20. The polar form of the complex number −1 is

21. If (x + iy)(2 − 3i) = 4 + i, then the value of x is
(a) 5/13 (b) 1 (c) 11/13 (d) −1
Answer: (a)
Solution: Divide: x + iy = (4 + i)/(2 − 3i). Multiply by (2 + 3i)/(2 + 3i): numerator = 8 + 12i + 2i + 3i² = 5 + 14i, denominator = 13. So x + iy = 5/13 + (14/13)i. The trap is 11/13, from mishandling the i² term as +3 instead of −3, so the answer is 5/13.
Source: NCERT Class 11 Mathematics, Chapter 5

22. The modulus of (3 + 4i)(5 − 12i) is
(a) 5 (b) 25 (c) 13 (d) 65
Answer: (d)
Solution: The tempting wrong option is 25, which is |3 + 4i|². Using |z₁z₂| = |z₁||z₂| = √(9 + 16) × √(25 + 144) = 5 × 13, so the answer is 65.

23. If z = (1 + i√3)²/(1 − i), then |z| equals
(a) 2 (b) 2√2 (c) 4 (d) √2
Answer: (b)
Solution: |1 + i√3| = 2, so |(1 + i√3)²| = 4, and |1 − i| = √2. Hence |z| = 4/√2 = 2√2. The trap is 4, from forgetting to divide by the modulus of the denominator, so the answer is 2√2.
Source: NCERT Class 11 Mathematics, Chapter 5

24. The least positive integer n for which ((1 + i)/(1 − i))ⁿ = 1 is
(a) 2 (b) 8 (c) 4 (d) 6
Answer: (c)
Solution: (1 + i)/(1 − i) = ((1 + i)²)/2 = 2i/2 = i. So we need iⁿ = 1, whose least positive solution is n = 4. The trap is 2, but i² = −1 ≠ 1, so the answer is 4.
Source: NCERT Class 11 Mathematics, Chapter 5

25. If z₁ = 2 + 3i and z₂ = 1 − 2i, then the real part of z₁/z₂ is
(a) 7/5 (b) −4/5 (c) −4/3 (d) 4/5
Answer: (b)
Solution: z₁/z₂ = (2 + 3i)(1 + 2i)/((1 − 2i)(1 + 2i)) = (2 + 4i + 3i + 6i²)/5 = (−4 + 7i)/5. The trap is 7/5, which is the imaginary part, not the real part, so the answer is −4/5.
Source: NCERT Class 11 Mathematics, Chapter 5
