# 🪄 सम्मिश्र संख्याएँ — शॉर्ट ट्रिक्स (Short Tricks)

---

## ट्रिक 1: i की घातें — "चार का चक्कर"

```
┌─────────────────────────────────────────────┐
│  i¹ = i,  i² = −1,  i³ = −i,  i⁴ = 1        │
│                                             │
│  🧠 ट्रिक: "आई, माइनस वन, माइनस आई, वन"     │
│  — चार का चक्कर, फिर वही शुरू!              │
│                                             │
│  ⚡ बड़ी घात? घात को 4 से भाग दो,            │
│     शेषफल ही असली घात है।                   │
│     i⁵³ → 53 = 4×13 + 1 → i¹ = i            │
│     i²⁰²⁴ → शेष 0 → i⁴ = 1                  │
└─────────────────────────────────────────────┘
```

## ट्रिक 2: युग्मी (Conjugate) — "आईना ट्रिक"

```
┌─────────────────────────────────────────────┐
│  z = a + ib  →  z̄ = a − ib                  │
│                                             │
│  🧠 ट्रिक: "आईने में आई पलट जाता है"        │
│  — काल्पनिक भाग का चिह्न उल्टा,             │
│    वास्तविक भाग वैसा का वैसा।               │
│                                             │
│  ⚡ याद रखें: z·z̄ = |z|² (हमेशा वास्तविक!)  │
│     (3+4i)(3−4i) = 9+16 = 25 ✓              │
└─────────────────────────────────────────────┘
```

---

## ट्रिक 3: मापांक — "पाइथागोरस का चश्मा"

```
┌─────────────────────────────────────────────┐
│  |a + ib| = √(a² + b²)                      │
│                                             │
│  🧠 ट्रिक: "वर्ग करो, जोड़ो, रूट लो"        │
│  — 3-4-5 त्रिज्या याद रखो:                  │
│    |3+4i| = 5, |6+8i| = 10, |5+12i| = 13    │
│                                             │
│  ⚡ परीक्षा में 3-4-5 परिवार सबसे ज़्यादा    │
│     पूछा जाता है!                           │
└─────────────────────────────────────────────┘
```

---

## ट्रिक 4: भाग (Division) — "ऊपर-नीचे युग्मी"

```
┌─────────────────────────────────────────────┐
│  (a+ib)/(c+id) = ?                          │
│                                             │
│  🧠 ट्रिक: "हर का युग्मी, ऊपर-नीचे गुणा"    │
│  — हर में i दिखे तो तुरंत (c−id) से         │
│    अंश और हर दोनों को गुणा करो।             │
│    हर बन जाता है c²+d² (वास्तविक!)          │
│                                             │
│  ⚡ कभी भी हर में i मत छोड़ो —               │
│     यही परीक्षक का पसंदीदा जाल है।          │
└─────────────────────────────────────────────┘
```

## ट्रिक 5: ध्रुवीय रूप — "आर-सी-एस" (r-cis-θ)

```
┌─────────────────────────────────────────────┐
│  z = r(cos θ + i sin θ) = r·cis θ = re^{iθ} │
│                                             │
│  🧠 ट्रिक: "CIS = Cos + i·Sin"              │
│  — r = मापांक (दूरी), θ = कोण (दिशा)        │
│                                             │
│  ⚡ cos पहले, sin बाद में — क्रम मत बदलो!    │
│     "पहले कॉस, फिर आई-साइन"                 │
└─────────────────────────────────────────────┘
```

---

## ट्रिक 6: डी मोवर का प्रमेय — "घात अंदर, कोण गुणा"

```
┌─────────────────────────────────────────────┐
│  (cos θ + i sin θ)ⁿ = cos nθ + i sin nθ     │
│                                             │
│  🧠 ट्रिक: "बाहर की घात, अंदर जाकर           │
│     कोण से गुणा"                            │
│                                             │
│  ⚡ उदाहरण: (cos 30° + i sin 30°)⁶           │
│     = cos 180° + i sin 180° = −1            │
│  ⚡ यही nवें मूल निकालने की कुंजी है!        │
└─────────────────────────────────────────────┘
```

## ट्रिक 7: गुणन-भाग ध्रुवीय रूप में — "गुणा में जुड़ते, भाग में घटते"

```
┌─────────────────────────────────────────────┐
│  z₁·z₂: मापांक गुणा, कोण जुड़ते हैं         │
│  z₁/z₂: मापांक भाग, कोण घटते हैं            │
│                                             │
│  🧠 ट्रिक: "गुणा-जोड़, भाग-घटा"             │
│  — गुणा करो तो कोण जुड़ जाते हैं,           │
│    भाग करो तो घट जाते हैं।                 │
│                                             │
│  ⚡ |z₁z₂| = |z₁||z₂|,  arg(z₁z₂) = θ₁+θ₂   │
└─────────────────────────────────────────────┘
```

## ट्रिक 8: चतुर्थांश पहचानो — "सब पहले पॉजिटिव"

```
┌─────────────────────────────────────────────┐
│  a+ib किस चतुर्थांश में?                    │
│  (+,+)=I, (−,+)=II, (−,−)=III, (+,−)=IV     │
│                                             │
│  🧠 ट्रिक: घड़ी की उल्टी दिशा में गिनो —    │
│     "एक, दो, तीन, चार — दाएँ-ऊपर से शुरू"   │
│                                             │
│  ⚡ arg निकालते समय पहले चतुर्थांश देखो,     │
│     फिर tan⁻¹|b/a| — वरना कोण गलत!          │
└─────────────────────────────────────────────┘
```

## ट्रिक 9: 1 के घनमूल — "ओमेगा की तीन शक्तियाँ"

```
┌─────────────────────────────────────────────┐
│  1, ω, ω²  — जहाँ ω = (−1+i√3)/2            │
│                                             │
│  🧠 ट्रिक: "तीनों का योग शून्य,             │
│     तीनों का गुणन एक"                       │
│     1 + ω + ω² = 0   और   ω³ = 1            │
│                                             │
│  ⚡ ω² = ω̄ (युग्मी)                         │
│  ⚡ a³+b³ = (a+b)(a+bω)(a+bω²) —            │
│     यह पहचान सीधे पूछी जाती है!             │
└─────────────────────────────────────────────┘
```

## ट्रिक 10: ज्यामितीय अर्थ — "जोड़ = समांतर चतुर्भुज"

```
┌─────────────────────────────────────────────┐
│  z₁ + z₂ → समांतर चतुर्भुज का विकर्ण        │
│  |z₁ − z₂| → दो बिंदुओं के बीच की दूरी      │
│                                             │
│  🧠 ट्रिक: "घटाव यानी दूरी"                 │
│  — |z − z₀| = r दिखे तो समझो:               │
│    केंद्र z₀, त्रिज्या r का वृत्त!           │
│                                             │
│  ⚡ |z−z₁| = |z−z₂| → लंब-समद्विभाजक रेखा   │
└─────────────────────────────────────────────┘
```

---

## ट्रिक 11: त्रिभुज असमिका — "छोटा रास्ता सीधा"

```
┌─────────────────────────────────────────────┐
│  |z₁ + z₂| ≤ |z₁| + |z₂|                    │
│  |z₁ − z₂| ≥ ||z₁| − |z₂||                  │
│                                             │
│  🧠 ट्रिक: "सीधी दूरी, घूमकर से कम"         │
│  — दो शहरों के बीच सीधा रास्ता              │
│    घूमकर जाने से कभी लंबा नहीं!             │
│                                             │
│  ⚡ समानता कब? जब z₁, z₂ एक ही दिशा में हों │
│     (arg बराबर)।                            │
└─────────────────────────────────────────────┘
```

## ट्रिक 12: Re(z) और Im(z) — "आधा-जोड़, आधा-घटा"

```
┌─────────────────────────────────────────────┐
│  Re(z) = (z + z̄)/2                          │
│  Im(z) = (z − z̄)/2i                         │
│                                             │
│  🧠 ट्रिक: "वास्तविक में जोड़,               │
│     काल्पनिक में घटा — दोनों में आधा"       │
│                                             │
│  ⚡ z + z̄ = 2a (शुद्ध वास्तविक)             │
│     z − z̄ = 2ib (शुद्ध काल्पनिक)            │
│  ⚡ z = z̄ ⟺ z वास्तविक;  z = −z̄ ⟺ काल्पनिक │
└─────────────────────────────────────────────┘
```

## ट्रिक 13: nवें मूल — "वृत्त पर बराबर बँटे"

```
┌─────────────────────────────────────────────┐
│  zⁿ = 1 के n मूल, इकाई वृत्त पर             │
│  360°/n के अंतर पर बँटे होते हैं।           │
│                                             │
│  🧠 ट्रिक: "पिज़्ज़ा कटिंग रूल"              │
│  — n मूल = पिज़्ज़ा के n बराबर टुकड़े,      │
│    हर कोण 2π/n।                             │
│                                             │
│  ⚡ सभी n मूलों का योग = 0 (हमेशा!)         │
│  ⚡ मूलों का गुणनफल = (−1)ⁿ⁺¹               │
└─────────────────────────────────────────────┘
```

## ट्रिक 14: घूर्णन (Rotation) — "e^{iθ} से घुमाओ"

```
┌─────────────────────────────────────────────┐
│  z को θ कोण से घुमाना हो → z·e^{iθ}         │
│  90° घुमाना हो → z को i से गुणा करो!        │
│                                             │
│  🧠 ट्रिक: "आई से गुणा = 90° बायाँ मुड़ो"   │
│  — i·(1) = i (ऊपर), i·i = −1 (बायाँ)…       │
│    हर बार 90° वामावर्त!                     │
│                                             │
│  ⚡ −i से गुणा = 90° दक्षिणावर्त (दायाँ)     │
└─────────────────────────────────────────────┘
```

## ट्रिक 15: परीक्षा-जाल चेतावनी — "तीन सबसे बड़ी गलतियाँ"

```
┌─────────────────────────────────────────────┐
│  ❌ √(−1)·√(−1) = √(1) = 1  ← गलत!          │
│     सही: i·i = i² = −1                      │
│     (ऋण संख्याओं पर √a·√b = √ab नहीं चलता)  │
│                                             │
│  ❌ |z₁ + z₂| = |z₁| + |z₂|  ← हमेशा नहीं!  │
│                                             │
│  ❌ arg का चतुर्थांश भूलना ← सबसे आम जाल    │
│                                             │
│  🧠 ट्रिक: "रूट-माइनस में नियम रुकता है,    │
│     मापांक-जोड़ में बराबरी शर्त पर,          │
│     कोण में पहले चतुर्थांश!"                │
└─────────────────────────────────────────────┘
```
