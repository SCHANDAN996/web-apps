101. If z = 3 + 4i, then the value of |z|² is
(a) 5 (b) 25 (c) 49 (d) 7
Answer: (b)
Solution: Many students stop at |z| = √(9 + 16) = 5 and pick 5, forgetting the question asks for the square of the modulus. |z|² = 3² + 4² = 9 + 16 = 25, so the answer is 25.
Source: NCERT Class 11 Mathematics, Chapter 5

102. The multiplicative inverse of z = 2 − 3i is
(a) (2 − 3i)/5 (b) (2 + 3i)/5 (c) (2 + 3i)/13 (d) (2 − 3i)/13
Answer: (c)
Solution: The tempting wrong choice divides by |z| = √13 instead of |z|² = 13, but the real trap is the sign: the inverse uses the conjugate, so the imaginary part becomes positive. z⁻¹ = z̄/|z|² = (2 + 3i)/(4 + 9) = (2 + 3i)/13, so the answer is (2 + 3i)/13.
Source: NCERT Class 11 Mathematics, Chapter 5

103. If z = 1 + i, then z⁴ equals
(a) 4 (b) −4 (c) 4i (d) −4i
Answer: (b)
Solution: A common slip is computing (1 + i)² = 2i and then writing 2i again instead of squaring it. (1 + i)² = 2i, so z⁴ = (2i)² = 4i² = −4, so the answer is −4.
Source: NCERT Class 11 Mathematics, Chapter 5

104. The argument of z = −1 + i is
(a) π/4 (b) 5π/4 (c) −π/4 (d) 3π/4
Answer: (d)
Solution: The trap is taking tan⁻¹(1/−1) = −π/4, which places z in the fourth quadrant, but z = −1 + i lies in the second quadrant. arg z = π − π/4 = 3π/4, so the answer is 3π/4.
Source: NCERT Class 11 Mathematics, Chapter 5

105. If |z − 2| = |z + 2|, then the locus of z is
(a) a circle of radius 2 (b) the real axis (c) the imaginary axis (d) the line x = 2
Answer: (c)
Solution: Students often assume equal moduli give a circle, but this is the perpendicular bisector condition: z is equidistant from 2 and −2. The perpendicular bisector of the segment joining (2, 0) and (−2, 0) is the y-axis, i.e. the imaginary axis, so the answer is the imaginary axis.
Source: NCERT Class 11 Mathematics, Chapter 5

106. The value of i¹⁰³ is
(a) −i (b) i (c) 1 (d) −1
Answer: (a)
Solution: The trap is dividing 103 by 4 and misreading the remainder: 103 = 4 × 25 + 3, so i¹⁰³ = i³, not i¹. Since i³ = −i, the answer is −i.
Source: NCERT Class 11 Mathematics, Chapter 5

107. If z = 2(cos 30° + i sin 30°), then z³ equals
(a) 6i (b) −8i (c) 8 (d) 8i
Answer: (d)
Solution: By De Moivre's theorem, z³ = 8(cos 90° + i sin 90°). The tempting error is cubing the angle incorrectly or writing 6i by multiplying 2 × 3. cos 90° = 0 and sin 90° = 1, giving z³ = 8i, so the answer is 8i.
Source: NCERT Class 11 Mathematics, Chapter 5

108. The number of solutions of z² + |z| = 0, where z is complex, is
(a) 4 (b) 2 (c) 1 (d) 3
Answer: (d)
Solution: Let z = x + iy. Then x² − y² + 2ixy + √(x² + y²) = 0. The imaginary part gives xy = 0. If x = 0: −y² + |y| = 0 gives y = 0, ±1. If y = 0: x² + |x| = 0 gives only x = 0. So z = 0, i, −i — three solutions. The trap is missing z = 0 or discarding one of ±i, so the answer is 3.
Source: PYQ-style (JEE/Advanced algebra pattern)

109. If ω is a complex cube root of unity, then (1 + ω)(1 + ω²) equals
(a) 1 (b) 0 (c) −1 (d) ω
Answer: (a)
Solution: The trap is expanding and forgetting 1 + ω + ω² = 0. Expanding: 1 + ω + ω² + ω³ = 0 + 1 = 1, since ω³ = 1. So the answer is 1.
Source: NCERT Class 11 Mathematics, Chapter 5

110. If |z| = 1, then (z − 1)/(z + 1), z ≠ −1, is
(a) equal to 1 (b) purely real (c) equal to −1 (d) purely imaginary
Answer: (d)
Solution: The trap is assuming the quotient is real because |z| = 1. With z = cos θ + i sin θ, (z − 1)/(z + 1) = i tan(θ/2) after simplification using half-angle identities, which is purely imaginary, so the answer is purely imaginary.
Source: PYQ-style (JEE Main pattern)

111. The modulus of (1 + i)/(1 − i) is
(a) 0 (b) 1 (c) 2 (d) √2
Answer: (b)
Solution: The trap is adding the moduli to get √2 + √2 or reporting the quotient i as the modulus. |1 + i| = √2 and |1 − i| = √2, so the modulus of the quotient is √2/√2 = 1, so the answer is 1.
Source: NCERT Class 11 Mathematics, Chapter 5

112. If z₁ = 2 + 3i and z₂ = 1 − i, then z₁z₂ equals
(a) 5 + i (b) −1 + 5i (c) 5 + 5i (d) 2 − 3i
Answer: (a)
Solution: The trap is the sign of the real part: (2)(1) − (3)(−1) = 2 + 3 = 5, not 2 − 3 = −1. Imaginary part: 2(−1) + 3(1) = 1. So z₁z₂ = 5 + i, and the answer is 5 + i.
Source: NCERT Class 11 Mathematics, Chapter 5

113. The conjugate of (2 + i)² is
(a) 3 − 4i (b) 3 + 4i (c) −3 + 4i (d) 5 − 4i
Answer: (a)
Solution: First (2 + i)² = 4 + 4i + i² = 3 + 4i. The trap is forgetting i² = −1, which would give 5 + 4i and then 5 − 4i. The conjugate of 3 + 4i is 3 − 4i, so the answer is 3 − 4i.
Source: NCERT Class 11 Mathematics, Chapter 5

114. If z + z̄ = 8 and z − z̄ = 6i, then z equals
(a) 3 + 4i (b) 4 − 3i (c) 8 + 6i (d) 4 + 3i
Answer: (d)
Solution: Adding the equations: 2z = 8 + 6i, so z = 4 + 3i. The trap is halving only one part or mixing up which equation gives the real part, leading to 3 + 4i. So the answer is 4 + 3i.
Source: NCERT Class 11 Mathematics, Chapter 5

115. The value of (1 + i)¹⁰ + (1 − i)¹⁰ is
(a) 0 (b) 32i (c) −64 (d) 64
Answer: (a)
Solution: (1 + i)² = 2i, so (1 + i)¹⁰ = (2i)⁵ = 32i. Similarly (1 − i)¹⁰ = (−2i)⁵ = −32i. The trap is computing only one term or adding magnitudes to get 64. The sum is 32i − 32i = 0, so the answer is 0.
Source: PYQ-style (JEE Main pattern)

116. If |z − 3 − 4i| = 5, then the minimum value of |z| is
(a) 0 (b) 5 (c) 10 (d) 3
Answer: (a)
Solution: The locus is a circle centred at (3, 4) with radius 5, and the distance of the centre from the origin is √(9 + 16) = 5, equal to the radius, so the circle passes through the origin. The trap is answering 5 by confusing the radius with the minimum distance. Minimum |z| = 5 − 5 = 0, so the answer is 0.
Source: PYQ-style (JEE Main pattern)

117. The square roots of −5 + 12i are
(a) ±(3 − 2i) (b) ±(2 − 3i) (c) ±(2 + 3i) (d) ±(3 + 2i)
Answer: (c)
Solution: Let √(−5 + 12i) = a + bi. Then a² − b² = −5 and 2ab = 12. Trying a = 2, b = 3: a² − b² = 4 − 9 = −5 and 2ab = 12. The trap is swapping to 3 + 2i, which gives a² − b² = 5, the wrong sign. So the roots are ±(2 + 3i), and the answer is ±(2 + 3i).
Source: NCERT Class 11 Mathematics, Chapter 5

118. If arg(z) = π/3 and |z| = 6, then z equals
(a) 3 − 3√3 i (b) 3√3 + 3i (c) 6 + 6i (d) 3 + 3√3 i
Answer: (d)
Solution: z = 6(cos 60° + i sin 60°) = 6(1/2 + i√3/2) = 3 + 3√3 i. The trap is swapping the sine and cosine values, which yields 3√3 + 3i. So the answer is 3 + 3√3 i.
Source: NCERT Class 11 Mathematics, Chapter 5

119. If ω is a complex cube root of unity, then (1 + ω − ω²)² equals
(a) −4ω² (b) 4ω (c) −4ω (d) 4ω²
Answer: (b)
Solution: Since 1 + ω + ω² = 0, we have 1 + ω = −ω², so 1 + ω − ω² = −2ω². Squaring gives 4ω⁴ = 4ω, because ω³ = 1 makes ω⁴ = ω. The trap is writing −4ω² by forgetting to square the coefficient −2, so the answer is 4ω.
Source: PYQ-style (JEE Main pattern)

120. The equation |z + i| − |z − i| = 3 represents
(a) no locus (empty set) (b) an ellipse (c) a straight line (d) a hyperbola
Answer: (a)
Solution: By the triangle inequality, the difference of distances of z from (0, −1) and (0, 1) can never exceed the distance between those two points, which is 2, so a difference of 3 is impossible. The trap is choosing hyperbola by formula habit, forgetting that a hyperbola needs the constant difference to be strictly less than the interfocal distance, and here 3 > 2. So the answer is no locus (empty set).
Source: PYQ-style (JEE Advanced pattern)

121. If z₁, z₂, z₃ are vertices of an equilateral triangle inscribed in the circle |z| = 1, then z₁² + z₂² + z₃² equals
(a) z₁z₂z₃ (b) 3 (c) 0 (d) 1
Answer: (c)
Solution: The vertices can be taken as e^(iθ), e^(iθ)ω, e^(iθ)ω². Then z₁² + z₂² + z₃² = e^(2iθ)(1 + ω² + ω⁴) = e^(2iθ)(1 + ω² + ω) = 0. The trap is assuming the sum equals 3 because each |zₖ| = 1 — but squares of complex numbers are not moduli. So the answer is 0.
Source: PYQ-style (JEE Advanced pattern)

122. The number of complex numbers z satisfying z³ = z̄ is
(a) 3 (b) 5 (c) 4 (d) 6
Answer: (b)
Solution: Taking modulus: |z|³ = |z|, so |z| = 0 or |z| = 1. z = 0 is one solution. For |z| = 1, multiply both sides by z: z⁴ = z·z̄ = |z|² = 1, giving 4 fourth roots of unity. The trap is forgetting z = 0 or dividing by z carelessly. Total = 1 + 4 = 5, so the answer is 5.
Source: PYQ-style (JEE Advanced pattern)

123. If |z₁| = 2, |z₂| = 3 and |z₁ + z₂| = 4, then |z₁ − z₂| equals
(a) 5 (b) √14 (c) √10 (d) √6
Answer: (c)
Solution: Use the parallelogram identity: |z₁ + z₂|² + |z₁ − z₂|² = 2(|z₁|² + |z₂|²) = 2(4 + 9) = 26. So |z₁ − z₂|² = 26 − 16 = 10. The trap is treating moduli as scalars and answering 3 + 2 = 5 or 3 − 2 = 1. So |z₁ − z₂| = √10, and the answer is √10.
Source: PYQ-style (JEE Main pattern)

124. If z satisfies |z − 2 − 3i| ≤ 1, then the maximum value of |z| is
(a) 5 (b) √13 + 1 (c) √13 (d) √13 − 1
Answer: (b)
Solution: The region is the closed disk centred at 2 + 3i with radius 1, and the farthest point of the disk from the origin lies on the ray from the origin through the centre. Distance from the origin to the centre is √(4 + 9) = √13, so the maximum modulus is √13 + 1. The trap is answering √13 − 1, which is the minimum value, not the maximum, so the answer is √13 + 1.
Source: PYQ-style (JEE Main pattern)

125. If z = (3 + 4i)/(4 − 3i) + (4 − 3i)/(3 + 4i), then z equals
(a) 2 (b) 1 (c) 0 (d) 7/25
Answer: (c)
Solution: Note that −i(3 + 4i) = −3i − 4i² = 4 − 3i, so (3 + 4i)/(4 − 3i) = (3 + 4i)/(−i(3 + 4i)) = 1/(−i) = i, and the second fraction is its reciprocal 1/i = −i. The trap is rationalising both fractions fully and making an arithmetic slip that yields 7/25. The sum is i + (−i) = 0, so the answer is 0.
Source: PYQ-style (JEE Main pattern)
