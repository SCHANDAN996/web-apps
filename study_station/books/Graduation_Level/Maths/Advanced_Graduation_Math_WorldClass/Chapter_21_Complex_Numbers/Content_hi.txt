# सम्मिश्र संख्याएँ (Complex Numbers)

## अध्याय की रूपरेखा और सीखने के उद्देश्य

इस अध्याय को पढ़ने के बाद आप सक्षम होंगे:

1. काल्पनिक इकाई i और सम्मिश्र संख्या की संरचना समझना
2. सम्मिश्र संख्याओं पर बीजगणितीय संक्रियाएँ (जोड़, घटाव, गुणा, भाग) करना
3. संयुग्मी (Conjugate), मापांक (Modulus) और कोणांक (Argument) निकालना
4. ध्रुवीय रूप (Polar Form) और द-मोवर प्रमेय (De Moivre's Theorem) लागू करना
5. इकाई के मूल (Roots of Unity) और ज्यामितीय अनुप्रयोग (Locus, Rotation) हल करना
6. परीक्षा-स्तरीय ट्रैप पहचानना और समय बचाने वाली विधियाँ अपनाना

## आम समस्या: डर, अवधारणा से नहीं, नाम से

अधिकांश छात्र i देखते ही घबरा जाते हैं। सच्चाई यह है कि सम्मिश्र संख्या सिर्फ एक "जोड़ी" है — एक वास्तविक हिस्सा और एक काल्पनिक हिस्सा। जैसे आपका पता: गली नंबर (वास्तविक) + मकान नंबर (काल्पनिक)। दोनों मिलकर एक पूरा पता बनाते हैं। इस अध्याय में हम हर अवधारणा को इसी तरह तोड़-तोड़कर समझेंगे।

---

## खंड 1: काल्पनिक इकाई i

**परिभाषा:** i = √−1, अर्थात् i² = −1।

यहीं से एक सुंदर चक्र निकलता है:

- i¹ = i
- i² = −1
- i³ = −i
- i⁴ = 1
- i⁵ = i … और चक्र दोहराता है।

**नियम:** i की कोई भी घात n निकालने के लिए n को 4 से भाग दें; शेषफल ही घात बताता है। जैसे i⁵³ = i^(4×13+1) = i¹ = i।

**⚠️ ट्रैप:** √(−a)·√(−b) = √(ab) **नहीं** होता जब दोनों ऋणात्मक हों। सही: √(−a)·√(−b) = i√a · i√b = i²√(ab) = −√(ab)। परीक्षक यहीं फँसाता है — √(−4)·√(−9) = √36 = 6 लिखना **गलत** है; सही उत्तर −6 है।

🧠 **Active Recall:** बिना ऊपर देखे बताइए — i⁴⁰⁷ का मान क्या है? (संकेत: 407 को 4 से भाग दीजिए, शेष 3।)

---

## खंड 2: सम्मिश्र संख्या का मानक रूप

**z = a + ib**, जहाँ a, b वास्तविक संख्याएँ हैं।

- a = Re(z) → वास्तविक भाग
- b = Im(z) → काल्पनिक भाग (ध्यान दें: Im(z) = b, **ib नहीं** — यह क्लासिक ट्रैप है!)
- यदि a = 0 → विशुद्ध काल्पनिक (purely imaginary)
- यदि b = 0 → विशुद्ध वास्तविक (purely real)

**बराबरी का नियम:** a + ib = c + id ⟺ a = c और b = d। यानी दो सम्मिश्र संख्याएँ तभी बराबर हैं जब दोनों भाग अलग-अलग बराबर हों। यह छोटा-सा नियम समीकरण-आधारित प्रश्नों की कुंजी है।

**महत्वपूर्ण:** सम्मिश्र संख्याओं में "बड़ा-छोटा" (inequality) परिभाषित **नहीं** होता। "3 + 4i > 2 + 5i" जैसा कथन अर्थहीन है — परीक्षा में कथन-प्रश्नों में यही जाल बिछता है।

🧠 **Active Recall:** यदि (x + 3) + i(y − 2) = 5 + 4i, तो x और y क्या होंगे? खुद हल कीजिए, फिर आगे पढ़िए।

---

## खंड 3: बीजगणितीय संक्रियाएँ

**जोड़/घटाव:** भाग-दर-भाग। (a + ib) ± (c + id) = (a ± c) + i(b ± d)

**गुणा:** FOIL विधि से, और i² = −1 रख दें:
(a + ib)(c + id) = (ac − bd) + i(ad + bc)

**भाग:** हर का परिमेयीकरण — अंश और हर दोनों को हर के **संयुग्मी** से गुणा करें:
(a + ib)/(c + id) = [(a + ib)(c − id)] / (c² + d²)

**संयुग्मी (Conjugate):** z = a + ib का संयुग्मी z̄ = a − ib। बस i का चिह्न बदल दीजिए।

संयुग्मी के सुनहरे गुण (ये परीक्षा के सबसे पसंदीदा हैं):

- z + z̄ = 2Re(z) (पूर्णतः वास्तविक)
- z − z̄ = 2i·Im(z) (पूर्णतः काल्पनिक)
- z·z̄ = |z|² = a² + b²
- (z₁ ± z₂)̄ = z̄₁ ± z̄₂, (z₁z₂)̄ = z̄₁z̄₂, (z₁/z₂)̄ = z̄₁/z̄₂

🧠 **Active Recall:** (3 + 4i)(3 − 4i) का मान बिना पूरी गुणा किए बताइए। (संकेत: a² + b² सीधे!)

---

## खंड 4: मापांक (Modulus) और कोणांक (Argument)

**मापांक:** |z| = √(a² + b²) — मूलबिंदु से बिंदु (a, b) की दूरी।

मापांक के गुण:

- |z₁·z₂| = |z₁|·|z₂|
- |z₁/z₂| = |z₁|/|z₂|
- |zⁿ| = |z|ⁿ
- |z| = |z̄| = |−z|

**कोणांक:** θ = arg(z), जहाँ tan θ = b/a — लेकिन सावधान! θ बिंदु के **चतुर्थांश (quadrant)** पर निर्भर करता है:

- प्रथम चतुर्थांश (a>0, b>0): θ = tan⁻¹(b/a)
- द्वितीय (a<0, b>0): θ = π − tan⁻¹|b/a|
- तृतीय (a<0, b<0): θ = −π + tan⁻¹|b/a|
- चतुर्थ (a>0, b<0): θ = −tan⁻¹|b/a|

**मुख्य कोणांक (Principal Argument)** हमेशा (−π, π] में लिया जाता है। इसलिए तृतीय चतुर्थांश में मुख्य कोणांक केवल −π + tan⁻¹|b/a| लिखा जाता है — π + tan⁻¹(b/a) जैसा मान (−π, π] से बाहर चला जाता है, इसलिए वह मुख्य कोणांक नहीं होता।

**त्रिभुज असमिका:** |z₁ + z₂| ≤ |z₁| + |z₂| — और इसका विपरीत रूप: |z₁ − z₂| ≥ ||z₁| − |z₂||। ये दोनों CAT और CGL Tier-II के प्रिय हैं।

🧠 **Active Recall:** z = −1 + i√3 किस चतुर्थांश में है और इसका मुख्य कोणांक क्या है?

---

## खंड 5: ध्रुवीय रूप और द-मोवर प्रमेय

**ध्रुवीय रूप:** z = r(cos θ + i sin θ), जहाँ r = |z|, θ = arg(z)।
संक्षिप्त में: z = r·cis θ, या आयलर रूप में z = re^(iθ)।

**आयलर का जादुई सूत्र:** e^(iθ) = cos θ + i sin θ
और गणित का सबसे सुंदर समीकरण: **e^(iπ) + 1 = 0** — पाँच महत्वपूर्णतम स्थिरांक (e, i, π, 1, 0) एक पंक्ति में!

**द-मोवर प्रमेय (De Moivre's Theorem):**
[cos θ + i sin θ]ⁿ = cos(nθ) + i sin(nθ)

यह प्रमेय घात और मूल निकालने का हथियार है।

**सम्मिश्र संख्या का nवाँ मूल:** z^(1/n) के **ठीक n मूल** होते हैं:
z^(1/n) = r^(1/n) [cos((θ + 2kπ)/n) + i sin((θ + 2kπ)/n)], k = 0, 1, …, n−1

ये मूल सम्मिश्र तल पर एक समबहुभुज (regular polygon) के शीर्ष बनाते हैं — यह ज्यामितीय तथ्य प्रश्नों में सीधे पूछा जाता है।

🧠 **Active Recall:** (cos θ + i sin θ)⁶ का विस्तार द-मोवर से लिखिए। फिर सोचिए — 1 के घनमूल कितने होते हैं?

---

## खंड 6: इकाई के मूल (Roots of Unity)

**1 के nवें मूल:** zⁿ = 1 के हल: 1, ω, ω², …, ωⁿ⁻¹, जहाँ ω = cos(2π/n) + i sin(2π/n)।

**घनमूल (n = 3)** सबसे ज़्यादा पूछे जाते हैं: 1, ω, ω², जहाँ ω = (−1 + i√3)/2।

तीन जादुई गुण — इन्हें रट लीजिए, आधे प्रश्न यहीं से बनते हैं:

1. **1 + ω + ω² = 0**
2. **ω³ = 1**
3. **ω² = ω̄** (ω² ही ω का संयुग्मी है)

**उपयोगी परिणाम:** ωⁿ का मान n को 3 से भाग देकर; और 1 + ωⁿ + ω²ⁿ = 3 यदि n, 3 का गुणज है, अन्यथा 0।

🧠 **Active Recall:** (1 + ω)(1 + ω²) का मान क्या होगा? (संकेत: 1 + ω + ω² = 0 का उपयोग कीजिए।)

---

## खंड 7: ज्यामितीय अनुप्रयोग — सम्मिश्र तल पर ज्यामिति

सम्मिश्र तल (Argand Plane) में z = a + ib बिंदु (a, b) है। यहीं से परीक्षा के सुंदर प्रश्न निकलते हैं:

- **|z − z₀| = r** → केंद्र z₀, त्रिज्या r वाला **वृत्त**
- **|z − z₁| = |z − z₂|** → z₁ और z₂ को मिलाने वाले रेखाखंड का **लंब-समद्विभाजक** (सरल रेखा)
- **|z − z₁| + |z − z₂| = 2a (स्थिर)** → **दीर्घवृत्त** (ellipse), जब 2a > |z₁ − z₂|
- **|z − z₁| − |z − z₂| = ±2a** → **अतिपरवलय** (hyperbola)
- **arg((z − z₁)/(z − z₂)) = स्थिर** → वृत्त का **चाप** (arc)

**घूर्णन (Rotation):** z को मूलबिंदु के परितः कोण α से घुमाने पर नया बिंदु = z·e^(iα)। विशेष रूप से 90° घूर्णन = z को i से गुणा करना (i = e^(iπ/2))।

**🎯 Mnemonic — "i से इधर-उधर":**
"i से गुणा = इधर (बाईं ओर) 90° घूमो; −i से गुणा = उधर (दाईं ओर) 90° घूमो।"
याद रखिए: **i = इधर (anti-clockwise), −i = उधर (clockwise)**।

🧠 **Active Recall:** |z − 2| = |z + 2| किस आकृति को दर्शाता है? और |z − 3i| = 5 किसे?

---

## खंड 8: परीक्षक के पाँच पसंदीदा जाल (Traps)

1. **√(−a)·√(−b) = √(ab) की गलती** — सही उत्तर −√(ab) है।
2. **Im(z) को ib समझना** — Im(a + ib) = b (केवल गुणांक)।
3. **सम्मिश्र संख्याओं में तुलना** — "z₁ > z₂" अर्थहीन; केवल मापांकों की तुलना संभव है।
4. **arg(z) में चतुर्थांश भूलना** — tan⁻¹(b/a) सीधे लगाना द्वितीय/तृतीय चतुर्थांश में गलत उत्तर देता है; मुख्य कोणांक (−π, π] में ही रखें।
5. **ω के गुण उल्टे लिखना** — 1 + ω + ω² = 0 है, 1 नहीं; ω³ = 1 है, 0 नहीं।
