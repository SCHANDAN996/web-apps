Q101. (कठिन) यदि (x + y) : (x - y) = 7 : 3 है, तो अनुपात (x^3 + y^3) : (x^3 - y^3) ज्ञात कीजिए।
(A) 133 : 117  (B) 117 : 133  (C) 125 : 8  (D) 137 : 113

उत्तर: (A)

हल:
योगान्तरानुपात (Componendo and Dividendo) नियम से: 2x / 2y = (7 + 3) / (7 - 3) = 10 / 4 => x / y = 5 / 2 प्राप्त होता है। घन करने पर x^3 / y^3 = 125 / 8। पुनः योगान्तरानुपात लगाने पर: (x^3 + y^3) / (x^3 - y^3) = (125 + 8) / (125 - 8) = 133 / 117 है। अतः सही मान 133 : 117 है, जो विकल्प (A) के अनुरूप है।

स्रोत: SSC CGL पैटर्न

दोनों बर्तनों में कुल भाग समान हैं (3 + 4 = 7 और 5 + 2 = 7)। सीधे जोड़ने पर: कुल पानी = 3 + 5 = 8, कुल दूध = 4 + 2 = 6। नया अनुपात = 8 : 6 = 4 : 3 है। अतः सही मान 4 : 3 है, जो विकल्प (B) के अनुरूप है।

Q123. (कठिन) यदि x = (sqrt(m + 1) + sqrt(m - 1)) / (sqrt(m + 1) - sqrt(m - 1)) है, तो x^2 - 2mx + 1 का मान ज्ञात कीजिए।
(A) 1  (B) -1  (C) 0  (D) 2m

उत्तर: (C)

हल:
योगान्तरानुपात से: (x + 1) / (x - 1) = sqrt(m + 1) / sqrt(m - 1)। वर्ग करने पर: (x + 1)^2 / (x - 1)^2 = (m + 1) / (m - 1)। पुनः C&D लगाने पर: (x^2 + 1) / (2x) = m => x^2 - 2mx + 1 = 0 प्राप्त होता है। अतः सही मान 0 है, जो विकल्प (C) के अनुरूप है।

Q124. (कठिन) एक साझेदारी में, A कुल पूँजी का 1/3 भाग कुल समय के 1/4 भाग के लिए लगाता है, B कुल पूँजी का 1/4 भाग कुल समय के 1/2 भाग के लिए लगाता है, तथा C शेष पूँजी पूरे समय के लिए लगाता है। यदि कुल लाभ 1,140 रुपये है, तो A का हिस्सा ज्ञात कीजिए।
(A) 228 रुपये  (B) 760 रुपये  (C) 180 रुपये  (D) 152 रुपये

उत्तर: (D)

हल:
माना कुल पूँजी = 12 और समय = 4। A का गुणनफल = 4 * 1 = 4। B का = 3 * 2 = 6। C की शेष पूँजी = 5, गुणनफल = 5 * 4 = 20। लाभ का अनुपात = 2 : 3 : 10। कुल 15 भाग = 1140 => 1 भाग = 76 रु। A का हिस्सा = 2 * 76 = 152 रुपये है। अतः सही मान 152 रुपये है, जो विकल्प (D) के अनुरूप है।

Q125. (कठिन) यदि (P + Q) का 15% = (P - Q) का 25% है, तो Q का कितना प्रतिशत P के बराबर है?
(A) 25%  (B) 400%  (C) 250%  (D) 300%

उत्तर: (B)

हल:
15(P + Q) = 25(P - Q) => 3(P + Q) = 5(P - Q) => 3P + 3Q = 5P - 5Q => 2P = 8Q => P = 4Q। अभीष्ट प्रतिशत = (P / Q) * 100% = 4 * 100% = 400% है। अतः सही मान 400% है, जो विकल्प (B) के अनुरूप है।
