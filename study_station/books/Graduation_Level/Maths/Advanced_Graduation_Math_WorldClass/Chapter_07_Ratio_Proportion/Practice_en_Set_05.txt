Q101. (Hard) If (x + y) : (x - y) = 7 : 3, find the ratio (x^3 + y^3) : (x^3 - y^3).
(A) 133 : 117  (B) 117 : 133  (C) 125 : 8  (D) 137 : 113

Answer: (A)

Solution:
Applying Componendo and Dividendo: [(x + y) + (x - y)] / [(x + y) - (x - y)] = (7 + 3) / (7 - 3) => 2x / 2y = 10 / 4 => x / y = 5 / 2. Cubing gives x^3 / y^3 = 125 / 8. Applying Componendo and Dividendo once more: (x^3 + y^3) / (x^3 - y^3) = (125 + 8) / (125 - 8) = 133 / 117. Therefore, the correct value is 133 : 117, corresponding to option (A).

Q102. (Hard) If (a + b) / sqrt(ab) = 4 / 1, where a > b > 0, find the ratio a : b.
(A) (3 + sqrt(2)) : (3 - sqrt(2))  (B) (2 + sqrt(3)) : (2 - sqrt(3))  (C) (2 - sqrt(3)) : (2 + sqrt(3))  (D) (4 + sqrt(3)) : (4 - sqrt(3))

Answer: (B)

Solution:
Dividing by 2 gives (a + b) / (2 * sqrt(ab)) = 2 / 1. By Componendo & Dividendo: (a + b + 2*sqrt(ab)) / (a + b - 2*sqrt(ab)) = (2 + 1) / (2 - 1) => (sqrt(a) + sqrt(b))^2 / (sqrt(a) - sqrt(b))^2 = 3 / 1. Taking square root: (sqrt(a) + sqrt(b)) / (sqrt(a) - sqrt(b)) = sqrt(3) / 1. Applying C&D again: sqrt(a) / sqrt(b) = (sqrt(3) + 1) / (sqrt(3) - 1). Squaring both sides: a / b = (4 + 2*sqrt(3)) / (4 - 2*sqrt(3)) = (2 + sqrt(3)) / (2 - sqrt(3)). Therefore, the correct value is (2 + sqrt(3)) : (2 - sqrt(3)), corresponding to option (B).

Q105. (Hard) If x = (4ab) / (a + b), find the value of (x + 2a)/(x - 2a) + (x + 2b)/(x - 2b).
(A) 2  (B) 1  (C) 4  (D) 0

Answer: (A)

Solution:
Writing x / (2a) = (2b) / (a + b). By Componendo & Dividendo: (x + 2a) / (x - 2a) = (2b + a + b) / (2b - a - b) = (3b + a) / (b - a). Similarly, x / (2b) = (2a) / (a + b), so (x + 2b) / (x - 2b) = (3a + b) / (a - b) = -(3a + b) / (b - a). Adding both expressions gives [(3b + a) - (3a + b)] / (b - a) = (2b - 2a) / (b - a) = 2. Psychological Trap: Examinees often make sign errors when combining denominators (b - a) and (a - b), erroneously concluding that the terms cancel to 0. Therefore, the correct value is 2, corresponding to option (A).
