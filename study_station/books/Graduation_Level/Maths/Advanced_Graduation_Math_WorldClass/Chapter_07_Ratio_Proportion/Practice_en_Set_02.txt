Q26. (Medium) A bag contains Rs 1, 50 paise, and 25 paise coins in the ratio 5 : 6 : 8. If the total money in the bag is Rs 210, find the number of 50 paise coins.

Answer: (A)

Solution:

Number of 50 paise coins = 63 / 0.50 = 126 coins. Psychological Trap: A common error is confusing the monetary value in Rupees (Rs 63) with the number of coins (126). Therefore, the correct value is 126, corresponding to option (A).
