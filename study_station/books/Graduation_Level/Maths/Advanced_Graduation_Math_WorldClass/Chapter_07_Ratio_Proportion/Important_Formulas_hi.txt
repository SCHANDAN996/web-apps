# अनुपात और समानुपात — महत्वपूर्ण सूत्र

| सूत्र का नाम | सूत्र | उपयोग-संकेत |
|---|---|---|
| अनुपात (Ratio) | a : b = a/b | दो राशियों की तुलना; इकाइयाँ समान होनी चाहिए |
| अनुपात का सरलतम रूप | a : b = (a÷HCF) : (b÷HCF) | HCF से भाग देकर सरल करें |
| समानुपात (Proportion) | a : b :: c : d ⇒ a×d = b×c | बाह्य पदों का गुणनफल = मध्य पदों का गुणनफल |
| चतुर्थानुपाती (Fourth Proportional) | a : b :: c : x ⇒ x = bc/a | तीन पद दिए हों, चौथा निकालना हो |
| तृतीयानुपाती (Third Proportional) | a : b :: b : x ⇒ x = b²/a | दो पद दिए हों, तीसरा निकालना हो |
| मध्यानुपाती (Mean Proportional) | x = √(ab) | a और b के बीच का मध्य पद |
| अनुपात में वितरण | A का हिस्सा = (a/(a+b)) × कुल | कुल राशि को a : b में बाँटना |
| तीनों में वितरण | A = (a/(a+b+c)) × कुल | a : b : c में बँटवारा |
| अनुपातों का योग (Addendo) | a/b = c/d ⇒ (a+c)/(b+d) = a/b | अंश जोड़ें, हर जोड़ें — अनुपात वही |
| अनुपातों का अंतर (Subtrahendo) | a/b = c/d ⇒ (a−c)/(b−d) = a/b | अंश घटाएँ, हर घटाएँ — अनुपात वही |
| Componendo | a/b = c/d ⇒ (a+b)/b = (c+d)/d | अंश में हर जोड़ें |
| Dividendo | a/b = c/d ⇒ (a−b)/b = (c−d)/d | अंश से हर घटाएँ |
| Componendo-Dividendo | a/b = c/d ⇒ (a+b)/(a−b) = (c+d)/(c−d) | दोनों का मिश्रण — परीक्षा में बहुत उपयोगी |
| व्युत्क्रम अनुपात (Inverse Ratio) | a : b का व्युत्क्रम = b : a | क्रम उलट दें |
| मिश्र अनुपात (Compound Ratio) | a:b और c:d का मिश्र = ac : bd | अंश×अंश, हर×हर |
| द्वितीय अनुपात (Duplicate Ratio) | a : b का = a² : b² | वर्ग करें |
| उप-द्वितीय (Sub-duplicate) | a : b का = √a : √b | वर्गमूल लें |
| त्रितीय अनुपात (Triplicate) | a : b का = a³ : b³ | घन करें |
| आयु-अनुपात (वर्तमान) | वर्तमान आयु = अनुपात × x | x मानकर हल करें |
| आयु-अनुपात (n वर्ष बाद) | (a₁x + n) : (a₂x + n) = नया अनुपात | n वर्ष बाद/पहले का अनुपात |
| आय-व्यय अनुपात | बचत = आय − व्यय | आय : व्यय दिया हो, बचत से x निकालें |
| मिश्रण अनुपात | नया अनुपात = (मूल मात्रा ± परिवर्तन) का अनुपात | दूध-पानी, मिश्रधातु प्रश्नों में |
| सिक्कों की संख्या | संख्या = कुल राशि ÷ सिक्के का मूल्य | रुपये-अनुपात को सिक्कों में बदलना |
| लाभ-विभाजन | लाभ ∝ निवेश × समय | साझेदारी (Partnership) प्रश्नों में |
| अनुपात में प्रतिशत परिवर्तन | a : b ⇒ a का % = a/(a+b) × 100 | अनुपात से प्रतिशत |
| निरंतर अनुपात (Continued Proportion) | a : b = b : c ⇒ b² = ac | b, a और c का मध्यानुपाती |
| Invertendo | a/b = c/d ⇒ b/a = d/c | दोनों पक्ष उलटें |
| Alternendo | a/b = c/d ⇒ a/c = b/d | मध्य पदों की अदला-बदली |
| दो अनुपातों की तुलना | a/b ? c/d ⇒ ad ? bc | तिरछा गुणा करके तुलना |
| अनुपात में वृद्धि/कमी | नया पद = पुराना पद × (नया अनुपात/पुराना अनुपात) | वेतन, कीमत में अनुपातिक बदलाव |
| क्रमागत अनुपात (a:b, b:c मिलान) | यदि a : b = p : q और b : c = r : s, तो a : b : c = p·r : q·r : q·s | b के मान समान बनाकर जोड़ें |
| कार्य-समय अनुपात | कार्य ∝ 1/समय | व्युत्क्रम संबंध |
| गति-समय अनुपात | गति ∝ 1/समय (दूरी स्थिर) | व्युत्क्रम संबंध |
