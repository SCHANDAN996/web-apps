76. Two numbers are in the ratio 7 : 11. If 7 is added to each, the ratio becomes 2 : 3. Find the smaller number.
(a) 63 (b) 56 (c) 77 (d) 49
Answer: (d)
Solution: Let the numbers be 7x and 11x. Then (7x + 7)/(11x + 7) = 2/3, so 21x + 21 = 22x + 14, giving x = 7. The tempting error is solving 7x/11x = 2/3 directly, which is impossible; the shift of 7 must be included. Smaller number = 7 × 7 = 49, so the answer is 49.
Source: NCERT Class 8 Mathematics (Comparing Quantities)

77. The ratio of incomes of A and B is 5 : 4 and the ratio of their expenditures is 3 : 2. If each saves ₹1600, find A's income.
(a) ₹4000 (b) ₹5000 (c) ₹6000 (d) ₹8000
Answer: (a)
Solution: Let incomes be 5x, 4x and expenditures 3y, 2y. Then 5x − 3y = 1600 and 4x − 2y = 1600. From the second, y = 2x − 800; substituting in the first gives 5x − 6x + 2400 = 1600, so x = 800. A common trap is assuming savings are in the same ratio as incomes; they are not. A's income = 5 × 800 = ₹4000, so the answer is ₹4000.
Source: PYQ-style (SSC CGL pattern)

78. If a : b = 2 : 3, b : c = 4 : 5 and c : d = 6 : 7, find a : d.
(a) 4 : 7 (b) 12 : 35 (c) 8 : 21 (d) 16 : 35
Answer: (d)
Solution: a/d = (a/b)(b/c)(c/d) = (2/3)(4/5)(6/7) = 48/105 = 16/35. The trap is adding the ratios or stopping at a : c; all three links must be multiplied. So the answer is 16 : 35.
Source: NCERT Class 8 Mathematics

79. ₹7800 is divided among A, B and C in the ratio 1/2 : 1/3 : 1/4. Find B's share.
(a) ₹2000 (b) ₹1800 (c) ₹3600 (d) ₹2400
Answer: (d)
Solution: Multiply the fractional ratio by LCM 12 to get 6 : 4 : 3, total 13 parts. The trap is treating 1/2 : 1/3 : 1/4 as 2 : 3 : 4, which reverses the shares. B's share = (4/13) × 7800 = ₹2400, so the answer is ₹2400.
Source: PYQ-style (IBPS pattern)

80. The ratio of boys to girls in a school is 4 : 5. When 100 girls leave, the ratio becomes 6 : 7. Find the original number of boys.
(a) 1200 (b) 1500 (c) 1800 (d) 2000
Answer: (a)
Solution: Let boys = 4x, girls = 5x. Then 4x/(5x − 100) = 6/7, so 28x = 30x − 600, giving x = 300. The trap is applying the change to both groups; only girls leave. Boys = 4 × 300 = 1200, so the answer is 1200.
Source: PYQ-style (SSC pattern)

81. If (3a + 5b)/(3a − 5b) = 5, find a : b.
(a) 5 : 2 (b) 3 : 1 (c) 2 : 1 (d) 5 : 3
Answer: (a)
Solution: 3a + 5b = 15a − 25b, so 30b = 12a, giving a/b = 30/12 = 5/2. The trap is misplacing terms while cross-multiplying and getting the inverted ratio 2 : 5. So the answer is 5 : 2.
Source: NCERT Class 8 Mathematics

82. The ages of Ram and Shyam are in the ratio 5 : 7. Four years ago the ratio was 3 : 5. Find Ram's present age.
(a) 25 years (b) 15 years (c) 10 years (d) 20 years
Answer: (c)
Solution: Let ages be 5x and 7x. Then (5x − 4)/(7x − 4) = 3/5, so 25x − 20 = 21x − 12, giving x = 2. The trap is adding 4 instead of subtracting for "four years ago". Ram's age = 5 × 2 = 10 years, so the answer is 10 years.
Source: PYQ-style (SSC CGL pattern)

83. A mixture contains milk and water in the ratio 5 : 1. How much water must be added to 60 litres of the mixture so that the ratio becomes 5 : 3?
(a) 10 litres (b) 15 litres (c) 20 litres (d) 25 litres
Answer: (c)
Solution: Milk = 50 L, water = 10 L. Let x litres of water be added: 50/(10 + x) = 5/3, so 150 = 50 + 5x, giving x = 20. The trap is changing the milk quantity too; only water is added, milk stays 50 L. So the answer is 20 litres.
Source: PYQ-style (Bank PO pattern)

84. If x : y = 3 : 4, find (5x + 3y) : (7x − 2y).
(a) 27 : 11 (b) 27 : 13 (c) 21 : 13 (d) 13 : 27
Answer: (b)
Solution: Take x = 3k, y = 4k. Numerator = 15k + 12k = 27k; denominator = 21k − 8k = 13k. The trap is an arithmetic slip in 7x − 2y, computing it as 29k instead of 13k. Ratio = 27 : 13, so the answer is 27 : 13.
Source: NCERT Class 8 Mathematics

85. The third proportional to 12 and 18 is:
(a) 24 (b) 27 (c) 30 (d) 36
Answer: (b)
Solution: Third proportional x satisfies 12 : 18 = 18 : x, so x = 18²/12 = 324/12 = 27. The trap is computing the mean proportional √(12×18) or using 12²/18 = 8. So the answer is 27.
Source: NCERT Class 8 Mathematics

86. The mean proportional between 0.08 and 0.18 is:
(a) 0.12 (b) 0.13 (c) 0.14 (d) 0.16
Answer: (a)
Solution: Mean proportional = √(0.08 × 0.18) = √0.0144 = 0.12. The trap is taking the arithmetic mean 0.13, which is the wrong concept entirely. So the answer is 0.12.
Source: PYQ-style (SSC pattern)

87. If a/b = c/d = e/f = 2/3, find (3a + 2c + e)/(3b + 2d + f).
(a) 1/3 (b) 2/3 (c) 3/2 (d) 4/3
Answer: (b)
Solution: By the property of equal ratios, each ratio equals any same-weighted linear combination of numerators and denominators, so the required value is 2/3. The trap is adding numerators and denominators separately and simplifying wrongly; the property gives the ratio directly. So the answer is 2/3.
Source: NCERT Class 8 Mathematics

88. A sum of ₹1700 is divided among P, Q, R so that P gets 2/3 of what Q gets and Q gets 1/4 of what R gets. Find P's share.
(a) ₹600 (b) ₹300 (c) ₹200 (d) ₹400
Answer: (c)
Solution: P = (2/3)Q and Q = R/4, so taking Q = 3 gives P = 2 and R = 12; hence P : Q : R = 2 : 3 : 12, total 17 parts. The trap is writing the ratio as 2 : 3 : 4 by misreading "Q gets 1/4 of R". P's share = (2/17) × 1700 = ₹200, so the answer is ₹200.
Source: PYQ-style (Bank pattern)

89. The ratio of two numbers is 3 : 5. If each is increased by 10, the ratio becomes 5 : 7. Find the larger number.
(a) 25 (b) 20 (c) 30 (d) 35
Answer: (a)
Solution: Let the numbers be 3x and 5x. Then (3x + 10)/(5x + 10) = 5/7, so 21x + 70 = 25x + 50, giving x = 5. The trap is subtracting 10 instead of adding. Larger number = 5 × 5 = 25, so the answer is 25.
Source: NCERT Class 8 Mathematics

90. In a bag, 25-paise, 50-paise and ₹1 coins are in the ratio 8 : 4 : 1. If the total value is ₹105, find the number of 50-paise coins.
(a) 84 (b) 63 (c) 105 (d) 42
Answer: (a)
Solution: Let the coins be 8x, 4x, x. Value = 8x(0.25) + 4x(0.50) + x(1) = 2x + 2x + x = 5x = 105, so x = 21. The trap is using the coin ratio directly as the value ratio. 50-paise coins = 4 × 21 = 84, so the answer is 84.
Source: PYQ-style (SSC pattern)

91. If A : B = 3 : 4 and B : C = 8 : 9, find A : B : C.
(a) 3 : 4 : 9 (b) 6 : 8 : 9 (c) 3 : 8 : 9 (d) 6 : 4 : 9
Answer: (b)
Solution: Make B common: A : B = 3 : 4 = 6 : 8, and B : C = 8 : 9. So A : B : C = 6 : 8 : 9. The trap is writing 3 : 4 : 9 without equalising B's value in both ratios. So the answer is 6 : 8 : 9.
Source: NCERT Class 8 Mathematics

92. The ratio of the areas of two squares is 16 : 25. Find the ratio of their perimeters.
(a) 16 : 25 (b) 8 : 12 (c) 4 : 5 (d) 256 : 625
Answer: (c)
Solution: Sides are in the ratio √16 : √25 = 4 : 5, and perimeters share the same ratio as sides. The trap is keeping 16 : 25, the area ratio, for the perimeter. So the answer is 4 : 5.
Source: NCERT Class 10 Mathematics (Triangles — areas of similar figures)

93. A and B started a business with capitals in the ratio 4 : 5. After 6 months A withdrew half his capital. If the annual profit is ₹8000, find A's share.
(a) ₹4000 (b) ₹3200 (c) ₹3600 (d) ₹3000
Answer: (d)
Solution: A's effective capital-months = 4×6 + 2×6 = 36; B's = 5×12 = 60. Profit ratio = 36 : 60 = 3 : 5. The trap is ignoring the mid-year withdrawal and using 4 : 5. A's share = (3/8) × 8000 = ₹3000, so the answer is ₹3000.
Source: PYQ-style (Bank PO pattern)

94. If (a + b) : (b + c) : (c + a) = 6 : 7 : 8 and a + b + c = 14, find c.
(a) 4 (b) 6 (c) 5 (d) 7
Answer: (b)
Solution: Let a + b = 6k, b + c = 7k, c + a = 8k. Adding: 2(a + b + c) = 21k, so 28 = 21k, giving k = 4/3. Then c = (a + b + c) − (a + b) = 14 − 6 × (4/3) = 14 − 8 = 6. The trap is solving for a or b instead of c. So the answer is 6.
Source: PYQ-style (CAT pattern)

95. The ratio of copper to zinc in alloy A is 5 : 3 and in alloy B is 3 : 5. Equal weights of both alloys are melted together. Find the ratio of copper to zinc in the new alloy.
(a) 3 : 5 (b) 5 : 3 (c) 1 : 1 (d) 3 : 2
Answer: (c)
Solution: Take 8 kg of each alloy. Copper = 5 + 3 = 8 kg, zinc = 3 + 5 = 8 kg. The trap is averaging the ratios without checking that both alloys have equal total parts (8 each); here the equal weights make copper and zinc exactly balance. Ratio = 8 : 8 = 1 : 1, so the answer is 1 : 1.
Source: NCERT Class 8 Mathematics

96. What number must be subtracted from each of 14, 17, 34 and 42 so that the remainders are in proportion?
(a) 3 (b) 5 (c) 4 (d) 2
Answer: (d)
Solution: We need (14 − x)/(17 − x) = (34 − x)/(42 − x). Cross-multiplying: (14 − x)(42 − x) = (17 − x)(34 − x), so 588 − 56x + x² = 578 − 51x + x², giving 10 = 5x, so x = 2. The trap is adding the number instead of subtracting it. So the answer is 2.
Source: PYQ-style (SSC CGL pattern)

97. The ratio of the speeds of two trains is 4 : 5. If the first train covers 240 km in 3 hours, find the speed of the second train.
(a) 110 km/h (b) 90 km/h (c) 100 km/h (d) 120 km/h
Answer: (c)
Solution: Speed of the first train = 240/3 = 80 km/h. Since speeds are in the ratio 4 : 5, the second train's speed = 80 × 5/4 = 100 km/h. The trap is inverting the ratio and getting 64 km/h. So the answer is 100 km/h.
Source: NCERT Class 8 Mathematics

98. If 2A = 3B = 4C, find A : B : C.
(a) 6 : 4 : 3 (b) 4 : 3 : 2 (c) 3 : 4 : 6 (d) 2 : 3 : 4
Answer: (a)
Solution: Let 2A = 3B = 4C = k. Then A = k/2, B = k/3, C = k/4, and the ratio 1/2 : 1/3 : 1/4 becomes 6 : 4 : 3 on multiplying by 12. The classic trap is answering 2 : 3 : 4, which is exactly backwards. So the answer is 6 : 4 : 3.
Source: PYQ-style (SSC pattern)

99. A sum of ₹53 is divided among A, B, C such that A gets ₹7 more than B, and B gets ₹8 more than C. Find the ratio of their shares.
(a) 20 : 15 : 10 (b) 25 : 18 : 10 (c) 25 : 17 : 11 (d) 24 : 18 : 11
Answer: (b)
Solution: Let C = x. Then B = x + 8 and A = x + 15. Sum: 3x + 23 = 53, so x = 10, giving A = 25, B = 18, C = 10. The trap is setting A = x and misaligning the "more than" chain. Ratio = 25 : 18 : 10, so the answer is 25 : 18 : 10.
Source: PYQ-style (Bank Clerk pattern)

100. The ratio of the number of students in classes X, Y, Z is 3 : 4 : 5. If 20 students are added to each class, the ratio becomes 5 : 6 : 7. Find the original total number of students.
(a) 240 (b) 180 (c) 300 (d) 120
Answer: (d)
Solution: Let the students be 3k, 4k, 5k. Then (3k + 20)/(4k + 20) = 5/6, so 18k + 120 = 20k + 100, giving k = 10. Check with the next pair: (40 + 20)/(50 + 20) = 60/70 = 6/7, which matches. The trap is solving with one pair and not verifying; here both check out. Total = 12k = 120, so the answer is 120.
Source: PYQ-style (SSC CGL pattern)
