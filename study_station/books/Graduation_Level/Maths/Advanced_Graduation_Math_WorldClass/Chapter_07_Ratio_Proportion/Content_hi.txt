# अध्याय 07: अनुपात और समानुपात (विस्तृत स्नातक स्तरीय आधारभूत संकलन)

## 1. अनुपात की आधारभूत संकल्पना
दो सजातीय राशियों के बीच तुलनात्मक संबंध को अनुपात (a : b) कहा जाता है, जहाँ b != 0 होता है।
- **पूर्व पद और उत्तर पद:** अनुपात a : b में 'a' को पूर्व पद (antecedent) तथा 'b' को उत्तर पद (consequent) कहते हैं।
- **अपरिवर्तनीयता गुण:** अनुपात के दोनों पदों में समान अशून्य संख्या से गुणा या भाग करने पर अनुपात का मान अपरिवर्तित रहता है।

## 2. विशिष्ट एवं व्युत्पन्न अनुपात
- **वर्गानुपात (Duplicate Ratio):** a^2 : b^2
- **वर्गमूलानुपात (Sub-duplicate Ratio):** sqrt(a) : sqrt(b)
- **घनानुपात (Triplicate Ratio):** a^3 : b^3
- **घनमूलानुपात (Sub-triplicate Ratio):** a^(1/3) : b^(1/3)
- **विलोमानुपात (Inverse Ratio):** b : a
- **मिश्र अनुपात (Compound Ratio):** (a * c * e) : (b * d * f)

## 3. समानुपात के सिद्धांत
चार राशियाँ a, b, c, d समानुपात में होती हैं (a : b :: c : d) यदि a / b = c / d हो।
- **बाह्य पदों का गुणनफल = मध्य पदों का गुणनफल:** a * d = b * c।
- **चतुर्थानुपाती (Fourth Proportional):** x = (b * c) / a।
- **तृतीयानुपाती (Third Proportional):** x = b^2 / a।
- **मध्यानुपाती (Mean Proportional):** x = sqrt(a * b)।

## 4. योगानुपात एवं अंतरानुपात (Componendo & Dividendo)
यदि a / b = c / d हो, तो:
- **योगानुपात-अंतरानुपात नियम:** (a + b) / (a - b) = (c + d) / (c - d)।

## 5. अनुपातों का संयोजन (Merging Ratios)
यदि a : b = p : q तथा b : c = r : s:
उभयनिष्ठ पद b को समान करने पर:
a : b : c = (p * r) : (q * r) : (q * s)।

## 6. सिक्के एवं मूल्यवर्ग संबंधी प्रश्न
यदि किसी थैले में 1 रु, 50 पैसे और 25 पैसे के सिक्के c_1 : c_2 : c_3 के अनुपात में हों:
कुल मूल्य = (c_1 * 1 + c_2 * 0.50 + c_3 * 0.25) * x = कुल राशि।
सभी राशियों को एक ही इकाई (रुपये या पैसे) में बदलना अनिवार्य है।
