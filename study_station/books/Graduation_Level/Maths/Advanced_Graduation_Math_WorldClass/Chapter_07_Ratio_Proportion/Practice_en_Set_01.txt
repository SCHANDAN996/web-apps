Q1. (Easy) If x : y = 3 : 4 and y : z = 8 : 9, find the ratio x : z.
(A) 2 : 3  (B) 3 : 4  (C) 1 : 2  (D) 3 : 2

Answer: (A)

Solution:
Ratio x / z = (x / y) * (y / z) = (3 / 4) * (8 / 9) = 24 / 36 = 2 / 3. Therefore, the correct value is 2 : 3, corresponding to option (A).

Q10. (Easy) If 2a = 3b = 4c, find the ratio a : b : c.
(A) 2 : 3 : 4  (B) 6 : 4 : 3  (C) 4 : 3 : 2  (D) 3 : 4 : 6

Answer: (B)

Solution:
Let 2a = 3b = 4c = 12k (where 12 is LCM of 2, 3, 4). Then a = 6k, b = 4k, c = 3k. Hence, a : b : c = 6 : 4 : 3. Psychological Trap: A common error is taking the coefficients directly as the ratio 2 : 3 : 4 instead of taking their reciprocals. Therefore, the correct value is 6 : 4 : 3, corresponding to option (B).

Q11. (Easy) If a / 3 = b / 4 = c / 7, find the value of (a + b + c) / c.
(A) 3  (B) 7  (C) 2  (D) 1/2

Answer: (C)

Solution:
Let a / 3 = b / 4 = c / 7 = k. Then a = 3k, b = 4k, c = 7k. Thus, (a + b + c) / c = (3k + 4k + 7k) / (7k) = 14k / 7k = 2. Therefore, the correct value is 2, corresponding to option (C).

Q13. (Easy) Two numbers are in the ratio 3 : 5. If 9 is subtracted from each, the new ratio becomes 12 : 23. Find the smaller number.
(A) 33  (B) 30  (C) 36  (D) 27

Answer: (A)

Solution:
Let numbers be 3x and 5x. (3x - 9) / (5x - 9) = 12 / 23. Cross-multiplying: 23(3x - 9) = 12(5x - 9) => 69x - 207 = 60x - 108 => 9x = 99 => x = 11. Smaller number = 3x = 3 * 11 = 33. Therefore, the correct value is 33, corresponding to option (A).
