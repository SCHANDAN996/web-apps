51. Two numbers are in the ratio 7 : 11. If 7 is added to each, the ratio becomes 2 : 3. Find the smaller number.
(a) 77 (b) 56 (c) 49 (d) 42
Answer: (c)
Solution: Let the numbers be 7x and 11x. Then (7x + 7)/(11x + 7) = 2/3, so 21x + 21 = 22x + 14, giving x = 7. The tempting error is solving (7x + 7)/(11x + 7) = 3/2 by misreading the new ratio, which gives a negative x. The smaller number is 7 × 7 = 49, so the answer is 49.
Source: NCERT Class 8 Mathematics (Comparing Quantities)

52. If A : B = 3 : 4 and B : C = 5 : 6, then A : B : C is:
(a) 3 : 4 : 6 (b) 5 : 4 : 6 (c) 15 : 20 : 30 (d) 15 : 20 : 24
Answer: (d)
Solution: Make B common: LCM of 4 and 5 is 20. A : B = 15 : 20 and B : C = 20 : 24. The trap is writing 3 : 4 : 6 directly, ignoring that B has different values in the two ratios. Combining gives A : B : C = 15 : 20 : 24, so the answer is 15 : 20 : 24.
Source: NCERT Class 8 Mathematics

53. ₹6,200 is divided among A, B and C so that A gets half of what B gets, and B gets twice what C gets. B's share is:
(a) ₹3,100 (b) ₹1,550 (c) ₹2,067 (d) ₹1,240
Answer: (a)
Solution: Let C get x. Then B gets 2x and A gets x. Total = x + 2x + x = 4x = 6200, so x = 1550. The trap is taking A : B : C = 1 : 2 : 1 but then assigning B's share as x instead of 2x, giving 1550. B's share = 2 × 1550 = ₹3,100, so the answer is ₹3,100.
Source: PYQ-style

54. The ratio of incomes of A and B is 5 : 4 and the ratio of their expenditures is 3 : 2. If each saves ₹1,600, A's income is:
(a) ₹3,200 (b) ₹4,000 (c) ₹6,400 (d) ₹8,000
Answer: (b)
Solution: Let incomes be 5x, 4x and expenditures 3y, 2y. Then 5x − 3y = 1600 and 4x − 2y = 1600. From the second, 2x − y = 800, so y = 2x − 800; substituting gives 5x − 6x + 2400 = 1600, hence x = 800. The trap is doubling x to 1600 and then reporting 5 × 1600 = 8000, which comes from a sign slip in substitution. A's income = 5 × 800 = ₹4,000, so the answer is ₹4,000.
Source: PYQ-style (SSC CGL pattern)

55. If (3a + 5b) : (3a − 5b) = 5 : 1, then a : b equals:
(a) 3 : 5 (b) 2 : 5 (c) 5 : 2 (d) 5 : 3
Answer: (c)
Solution: Cross-multiplying, 3a + 5b = 5(3a − 5b), so 3a + 5b = 15a − 25b, giving 30b = 12a and a/b = 30/12 = 5/2. The trap is applying componendo-dividendo but forgetting the coefficients 3 and 5, which wrongly suggests a : b = 3 : 2 from the raw 6 : 4. So a : b = 5 : 2, and the answer is 5 : 2.
Source: NCERT Class 11 Mathematics (algebraic manipulation)

56. The third proportional to 12 and 18 is:
(a) 27 (b) 24 (c) 36 (d) 30
Answer: (a)
Solution: Third proportional x satisfies 12 : 18 = 18 : x, so x = 18²/12 = 324/12 = 27. The trap is computing the mean proportional √(12 × 18) ≈ 14.7 or using 12²/18 = 8. So the answer is 27.

58. If x : y = 2 : 3, then (5x + 2y) : (5x − 2y) is:
(a) 8 : 2 (b) 16 : 4 (c) 4 : 2 (d) 4 : 1
Answer: (d)
Solution: Put x = 2k, y = 3k. Then 5x + 2y = 10k + 6k = 16k and 5x − 2y = 10k − 6k = 4k. Ratio = 16k : 4k = 4 : 1. The trap is reporting 16 : 4 without reducing it to the lowest terms. So the answer is 4 : 1.

59. ₹1,170 is divided among P, Q, R in the ratio 1/2 : 1/3 : 1/4. Q's share is:
(a) ₹450 (b) ₹540 (c) ₹360 (d) ₹270
Answer: (c)
Solution: Multiply the fractions by 12: ratio = 6 : 4 : 3, sum = 13 parts. Each part = 1170/13 = ₹90. The trap is treating 1/2 : 1/3 : 1/4 as 1 : 1 : 1 or taking the largest fraction 1/2 as Q's share. Q's share = 4 × 90 = ₹360, so the answer is ₹360.

60. The ratio of boys to girls in a school is 3 : 4. If 10 boys join and 10 girls leave, the ratio becomes 4 : 5. The original number of girls is:
(a) 400 (b) 280 (c) 320 (d) 360
Answer: (d)
Solution: Let boys = 3x, girls = 4x. Then (3x + 10)/(4x − 10) = 4/5, so 15x + 50 = 16x − 40, giving x = 90. The trap is adding 10 to the girls instead of subtracting, which gives a negative x. Original girls = 4 × 90 = 360, so the answer is 360.
Source: PYQ-style

61. If a : b = 2 : 3, b : c = 4 : 5 and c : d = 6 : 7, then a : d is:
(a) 16 : 35 (b) 2 : 7 (c) 8 : 15 (d) 4 : 7
Answer: (a)
Solution: a/d = (a/b)(b/c)(c/d) = (2/3)(4/5)(6/7) = 48/105 = 16/35. The trap is multiplying only the extremes 2/3 × 6/7 = 4/7, skipping the middle ratio. So a : d = 16 : 35, and the answer is 16 : 35.

62. A sum of money is divided among A, B, C such that A's share : B's share = 3 : 2 and B's share : C's share = 4 : 5. If A gets ₹500 more than C, the total sum is:
(a) ₹6,000 (b) ₹7,500 (c) ₹4,500 (d) ₹9,000
Answer: (b)
Solution: A : B = 3 : 2 = 6 : 4 and B : C = 4 : 5, so A : B : C = 6 : 4 : 5. A − C = 6 − 5 = 1 part = ₹500. The trap is combining the ratios as 3 : 2 : 5 without making B common. Total = 15 parts = 15 × 500 = ₹7,500, so the answer is ₹7,500.
Source: PYQ-style

63. The prices of a scooter and a TV are in the ratio 7 : 2. If the scooter costs ₹35,000 more than the TV, the price of the TV is:
(a) ₹14,000 (b) ₹10,000 (c) ₹12,000 (d) ₹49,000
Answer: (a)
Solution: Difference = 7 − 2 = 5 parts = ₹35,000, so 1 part = ₹7,000. TV = 2 parts = ₹14,000. The trap is taking the scooter's price (7 parts = ₹49,000) as the answer when the TV is asked. So the answer is ₹14,000.

64. If 2A = 3B = 4C, then A : B : C is:

65. In a mixture of 60 litres, milk and water are in the ratio 2 : 1. How much water must be added to make the ratio 1 : 2?
(a) 45 litres (b) 60 litres (c) 50 litres (d) 40 litres
Answer: (b)
Solution: Milk = 40 L, water = 20 L. Milk stays 40 L. For milk : water = 1 : 2, water must be 80 L, so add 80 − 20 = 60 L. The trap is changing both quantities or assuming milk also increases. So the answer is 60 litres.

66. The ratio of two numbers is 3 : 5. If each is decreased by 10, the ratio becomes 1 : 2. The larger number is:
(a) 30 (b) 40 (c) 50 (d) 60
Answer: (c)
Solution: Let numbers be 3x, 5x. Then (3x − 10)/(5x − 10) = 1/2, so 6x − 20 = 5x − 10, giving x = 10. The trap is writing (3x − 10)/(5x − 10) = 2/1, inverting the new ratio. Larger number = 5 × 10 = 50, so the answer is 50.

68. If (a + b) : (b + c) : (c + a) = 6 : 7 : 8 and a + b + c = 14, then c equals:
(a) 6 (b) 7 (c) 8 (d) 5
Answer: (a)
Solution: Let a + b = 6k, b + c = 7k, c + a = 8k. Adding: 2(a + b + c) = 21k, so 28 = 21k, k = 4/3. Then c = (a + b + c) − (a + b) = 14 − 6 × (4/3) = 14 − 8 = 6. The trap is taking c = 8k directly, forgetting that 8k is c + a, not c. So the answer is 6.

71. If p/q = 3/4, then (6p − q)/(6p + q) equals:
(a) 7/13 (b) 5/11 (c) 7/11 (d) 9/13
Answer: (c)
Solution: Put p = 3k, q = 4k. Then 6p − q = 18k − 4k = 14k and 6p + q = 18k + 4k = 22k. Ratio = 14/22 = 7/11. The trap is substituting p = 3, q = 4 but forgetting to multiply p by 6, giving (3 − 4)/(3 + 4) = −1/7. So the answer is 7/11.

72. The ratio of the ages of a father and son is 7 : 2. After 10 years the ratio will be 9 : 4. The father's present age is:

Solution: Let ages be 7x and 2x. Then (7x + 10)/(2x + 10) = 9/4, so 28x + 40 = 18x + 90, giving x = 5. The trap is solving (7x + 10)/(2x + 10) = 4/9 by inverting, which yields a negative x. Father's age = 7 × 5 = 35 years, so the answer is 35 years.

75. The ratio of copper to zinc in alloy A is 5 : 3 and in alloy B is 3 : 2. Equal weights of both alloys are melted together. The ratio of copper to zinc in the new alloy is:
(a) 49 : 31 (b) 4 : 3 (c) 8 : 5 (d) 31 : 49
Answer: (a)
Solution: Take 40 g of each alloy (LCM of 8 and 5). Alloy A gives copper = 25 g, zinc = 15 g; alloy B gives copper = 24 g, zinc = 16 g. Total copper = 49 g, zinc = 31 g. The trap is simply adding the ratios as 5 + 3 : 3 + 2 = 8 : 5, ignoring that the two alloys have different part sizes. So the answer is 49 : 31.
Source: PYQ-style (CAT pattern)
