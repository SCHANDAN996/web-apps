# Important Formulas — Ratio & Proportion

| Formula Name | Formula | One-Line Use-Hint |
|---|---|---|
| Ratio | a : b = a/b | Compare two quantities of the same unit |
| Ratio in simplest form | a : b = (a÷HCF) : (b÷HCF) | Divide both terms by their HCF |
| Compound ratio | (a:b) × (c:d) = ac : bd | Multiply antecedents and consequents |
| Duplicate ratio | a² : b² | Square of the ratio a : b |
| Sub-duplicate ratio | √a : √b | Square root of the ratio a : b |
| Triplicate ratio | a³ : b³ | Cube of the ratio a : b |
| Sub-triplicate ratio | ∛a : ∛b | Cube root of the ratio a : b |
| Inverse (reciprocal) ratio | a : b → 1/a : 1/b = b : a | Flip when relation is inverse |
| Proportion | a : b :: c : d ⇒ a/b = c/d | Two equal ratios form a proportion |
| Product rule | a × d = b × c | Product of extremes = product of means |
| Fourth proportional | d = bc/a | When a : b :: c : d |
| Third proportional | c = b²/a | When a : b :: b : c |
| Mean proportional | b = √(ac) | When a : b :: b : c |
| Componendo | (a+b)/b = (c+d)/d | Add denominator to numerator on both sides |
| Dividendo | (a−b)/b = (c−d)/d | Subtract denominator from numerator |
| Componendo-Dividendo | (a+b)/(a−b) = (c+d)/(c−d) | Use when a/b = c/d and sums–differences appear |
| Invertendo | b/a = d/c | Invert both ratios of a proportion |
| Alternendo | a/c = b/d | Swap the means of a proportion |
| Addendo | a/b = c/d = (a+c)/(b+d) | Each ratio equals sum of numerators ÷ sum of denominators |
| Equal ratios chain | a/b = c/d = e/f = (a+c+e)/(b+d+f) | Combine several equal ratios into one |
| Dividing in a ratio | Share of 1st = a/(a+b) × Total | Split an amount in ratio a : b |
| Three-part division | Share = x/(x+y+z) × Total | Split an amount in ratio x : y : z |
| Ratio change (addition) | (a+k)/(b+k) = new ratio | Same number added to both terms |
| Income–expenditure | Savings = Income − Expenditure | Combine with income & expense ratios |
| Mixture ratio (alligation) | (Dearer − Mean) : (Mean − Cheaper) | Ratio of quantities mixed at two prices |
| Coins ratio | Value = (no. of coins) × (denomination) | Convert coin-count ratio to value ratio |
| Speed–time inverse | s₁ : s₂ = t₂ : t₁ | For same distance, speed ∝ 1/time |
| Work–time inverse | Men₁ : Men₂ = Time₂ : Time₁ | For same work, men ∝ 1/time |
| Direct proportion | x ∝ y ⇒ x = ky | Both increase or decrease together |
| Inverse proportion | x ∝ 1/y ⇒ xy = k | One rises as the other falls |
| Percentage to ratio | p% = p : 100 | Convert percentage into ratio form |
| Ratio to percentage | a : (a+b) → a/(a+b) × 100% | Convert a ratio share into percentage |
| Continued proportion | a : b = b : c ⇒ b² = ac | Middle term is mean proportional |
| Comparison of ratios | a/b vs c/d: compare ad vs bc | Cross-multiply to compare two ratios |
