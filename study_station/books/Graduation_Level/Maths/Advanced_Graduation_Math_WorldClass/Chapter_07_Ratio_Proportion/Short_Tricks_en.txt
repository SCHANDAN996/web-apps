# 🪄 Short Tricks — Ratio & Proportion

---

**Trick 1 — "RATIO = RAT-IO: Rats Always Take It Off (the common factor)"**

```
┌─────────────────────────────────────────────┐
│ A ratio is just a fraction in disguise.     │
│ Before ANY calculation, cancel the common   │
│ factor — the "rat" runs off with it!        │
│ 24 : 36 → ÷12 → 2 : 3. Never compute with   │
│ fat numbers when thin ones will do.         │
└─────────────────────────────────────────────┘
```

---

**Trick 2 — "A:B and B:C? Make B the Bridge!"**

```
┌─────────────────────────────────────────────┐
│ To combine A:B and B:C, force B to be the   │
│ SAME number in both (LCM of the two B's).   │
│ A:B = 2:3, B:C = 4:5 → B-bridge = 12        │
│ A:B = 8:12, B:C = 12:15 → A:B:C = 8:12:15   │
│ Memory hook: "Build the Bridge, then Cross."│
└─────────────────────────────────────────────┘
```

---

**Trick 3 — "Duplicate = Double the Drama (Square it!)"**

```
┌─────────────────────────────────────────────┐
│ Duplicate ratio of a:b     → a² : b²        │
│ Sub-duplicate              → √a : √b        │
│ Triplicate                 → a³ : b³        │
│ Sub-triplicate             → ∛a : ∛b        │
│ Mnemonic: "Du-Tri, Square-Cube —            │
│ Sub means Root out of the tube!"            │
└─────────────────────────────────────────────┘
```

---

**Trick 4 — "Componendo-Dividendo: The PLUS-MINUS Dance"**

```
┌─────────────────────────────────────────────┐
│ If a/b = c/d, then:                         │
│ (a+b)/(a−b) = (c+d)/(c−d)                   │
│ Numerator DANCES: plus on top, minus below. │
│ Use it the moment you see (x+y)/(x−y) = ?   │
│ Hook: "Same step, both sides — nobody       │
│ leaves the dance floor!"                    │
└─────────────────────────────────────────────┘
```

---

**Trick 5 — "Income-Expense-Savings: The IES Sandwich"**

```
┌─────────────────────────────────────────────┐
│ Income ratio a:b, Expense ratio c:d →       │
│ write incomes as ak, bk and expenses as     │
│ cm, dm. Savings = income − expense.         │
│ Each person's saving gives ONE equation:    │
│   ak − cm = S₁   and   bk − dm = S₂         │
│ Two equations, two unknowns (k, m) — solve  │
│ by elimination.                             │
│ If only ONE saving is given, you need one   │
│ more condition — never try to pull two      │
│ unknowns out of a single equation!          │
│ Mnemonic: "I Earn, I Spend, I Save —        │
│ two unknowns need two equations."           │
└─────────────────────────────────────────────┘
```

---

**Trick 6 — "The ₹1 Coin Test for 'Added to Both Terms'"**

```
┌─────────────────────────────────────────────┐
│ "x is added to both terms of a:b to make    │
│ c:d" → (a+x)/(b+x) = c/d → cross-multiply.  │
│ Shortcut: x = (ad − bc)/(c − d)             │
│ Check: 2:3, add x to get 3:4 →              │
│ x = (2·4 − 3·3)/(3 − 4) = (−1)/(−1) = 1 ✓   │
│ Hook: "Cross the coins, subtract, divide —  │
│ the added amount can't hide!"               │
└─────────────────────────────────────────────┘
```

**Trick 7 — "Proportion: Means × Means = Extremes × Extremes"**

```
┌─────────────────────────────────────────────┐
│ In a : b :: c : d → b × c = a × d           │
│ "The MIDDLE brothers multiply,              │
│  the OUTER brothers multiply —              │
│  and the family stays EQUAL."               │
│ M-M-E-E: "Mama Made Extra Eclairs."         │
└─────────────────────────────────────────────┘
```

---

**Trick 8 — "Mean Proportional = Geometric Middleman"**

```
┌─────────────────────────────────────────────┐
│ Mean proportional between a and b = √(ab)   │
│ Third proportional to a, b = b²/a           │
│ Fourth proportional to a, b, c = bc/a       │
│ Mnemonic: "Mean = Root of the product;      │
│ Third = Second SQUARED over First;          │
│ Fourth = Middle two multiply, First divides."│
└─────────────────────────────────────────────┘
```

---

**Trick 9 — "Divide ₹N in ratio a:b:c → The Pizza Slice Formula"**

```
┌─────────────────────────────────────────────┐
│ Share of first = N × a/(a+b+c)              │
│ Total parts = sum of ratio terms.           │
│ Hook: "Count ALL the slices BEFORE          │
│ serving anyone."                            │
│ Most ratio-division errors come from        │
│ forgetting to add the parts first!          │
└─────────────────────────────────────────────┘
```

---

**Trick 10 — "Inverse Proportion: The Seesaw Rule"**

```
┌─────────────────────────────────────────────┐
│ If A is inversely proportional to B:        │
│ A₁B₁ = A₂B₂ (products balance the seesaw).  │
│ More men → fewer days; more speed → less    │
│ time.                                       │
│ Hook: "One goes UP, the other must go DOWN  │
│ — the seesaw never lies."                   │
└─────────────────────────────────────────────┘
```

---

**Trick 11 — "Ages in Ratio: The Time-Travel Constant"**

```
┌─────────────────────────────────────────────┐
│ Ages are in ratio a:b NOW → write ak, bk.   │
│ After n years: (ak+n)/(bk+n) = new ratio.   │
│ The DIFFERENCE of ages never changes —      │
│ use it as a check!                          │
│ Mnemonic: "Time travels, difference stays." │
└─────────────────────────────────────────────┘
```

---

**Trick 12 — "Mixture Replacement: The Vanishing Fraction"**

```
┌─────────────────────────────────────────────┐
│ From V litres, x litres removed & replaced  │
│ n times → pure left = V(1 − x/V)ⁿ           │
│ Hook: "Every replacement, the pure stuff    │
│ keeps the SAME fraction of itself."         │
│ Remember: (1 − x/V) is the SURVIVAL factor. │
└─────────────────────────────────────────────┘
```

---

**Trick 13 — "Equal Ratios Chain: The Add-All Shortcut"**

```
┌─────────────────────────────────────────────┐
│ If a/b = c/d = e/f, then each equals        │
│ (a+c+e)/(b+d+f)                             │
│ Hook: "When ratios are equal, dump ALL      │
│ numerators on top, ALL denominators below — │
│ the ratio doesn't budge!"                   │
└─────────────────────────────────────────────┘
```

---

**Trick 14 — "Salary Increased THEN Decreased: The Net Trap"**

```
┌─────────────────────────────────────────────┐
│ +x% then −x% is NEVER zero change:          │
│ Net = −x²/100 % (always a LOSS).            │
│ Hook: "Up and down the same stairs,         │
│ you still end up one step lower."           │
│ 20% up then 20% down → 4% net loss.         │
└─────────────────────────────────────────────┘
```

**Trick 15 — "The 15-Second Sanity Check"**

```
┌─────────────────────────────────────────────┐
│ After solving, ask 3 questions:             │
│ ① Is my final ratio in lowest terms?        │
│ ② Do the parts sum to the total given?      │
│ ③ Bigger ratio term → bigger share?         │
│ Mnemonic: "LOW-SUM-LOGIC" — if any fails,   │
│ redo. 15 seconds now beats −1 mark later.   │
└─────────────────────────────────────────────┘
```
