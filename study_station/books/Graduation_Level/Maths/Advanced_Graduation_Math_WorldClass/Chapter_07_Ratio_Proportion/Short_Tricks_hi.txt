# 🪄 अनुपात और समानुपात — शॉर्ट ट्रिक्स (स्मृति-सहायक तकनीकें)

---

┌─────────────────────────────────────────────┐
│ **ट्रिक 1: "ऊपर पहला, नीचे दूसरा"** │
│ │
│ अनुपात a : b हमेशा a/b पढ़ा जाता है — │
│ पहला पद ऊपर (अंश), दूसरा नीचे (हर)। │
│ याद रखें: **"पहला राजा सिंहासन पर, दूसरा │
│ प्रजा नीचे"** — राजा हमेशा ऊपर बैठता है! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 2: "क्रॉस गुणा = समानुपात की जाँच"** │
│ │
│ a : b :: c : d सही है या नहीं? │
│ बस जाँचें: **a × d = b × c** │
│ याद रखें: **"बाहर-बाहर = अंदर-अंदर"** │
│ (बाहरी पदों का गुणनफल = मध्य पदों का गुणनफल) │
│ म्नेमोनिक: **"बीबीआईआई"** — बाहर-बाहर, │
│ अंदर-अंदर! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 3: "K मान लो, जीवन आसान हो"** │
│ │
│ a : b = 2 : 3 दिया हो, तो तुरंत लिखें │
│ a = 2k, b = 3k। │
│ याद रखें: **"अनुपात दिखे, K लगाओ"** — │
│ K वह जादुई चाबी है जो हर अनुपात-प्रश्न │
│ का ताला खोल देती है। │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 4: "जोड़-घटा नियम" (Componendo- │
│ Dividendo)** │
│ │
│ यदि a/b = c/d, तो (a+b)/(a−b) = (c+d)/(c−d) │
│ याद रखें: **"ऊपर जोड़, नीचे घटा — दोनों │
│ तरफ़ एक सा"** │
│ म्नेमोनिक: **"जोड़ ऊपर चढ़ा, घटा नीचे │
│ उतरा"** — सीढ़ी की तरह! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 5: "आयु-प्रश्नों की गोल्डन चेन"** │
│ │
│ आयु का अनुपात बदलता है, पर **अंतर कभी │
│ नहीं बदलता!** │
│ याद रखें: **"उम्र बढ़े, फासला वही"** — │
│ दो भाइयों की उम्र का फ़ासला जन्म से │
│ क़ब्र तक एक जैसा। अंतर से K निकालें, │
│ प्रश्न 10 सेकंड में हल! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 6: "मिश्रण में पानी मुफ़्त है"** │
│ │
│ दूध-पानी के मिश्रण में पानी मिलाने पर │
│ **दूध की मात्रा अपरिवर्तित** रहती है। │
│ याद रखें: **"पानी आए-जाए, दूध अडिग │
│ रहे"** — दूध को आधार बनाएँ, समीकरण │
│ उसी पर बनाएँ। │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 7: "a:b और b:c को जोड़ने की चेन │
│ ट्रिक"** │
│ │
│ a : b = 2 : 3 और b : c = 4 : 5 हो, तो │
│ b को समान करें (LCM 12): │
│ a : b : c = 8 : 12 : 15 │
│ याद रखें: **"बीच वाला पुल, दोनों तरफ़ │
│ बराबर"** — पुल (b) दोनों किनारों से │
│ जितना ऊँचा, उतना ही! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 8: "व्युत्क्रम = उल्टा खेल"** │
│ │
│ यदि a : b = 3 : 4, तो 1/a : 1/b = 4 : 3 │
│ याद रखें: **"उल्टा करो, अनुपात पलटो"** │
│ म्नेमोनिक: **"ULTA-PULTA"** — व्युत्क्रम │
│ मतलब अनुपात का पलटना! │
│ (पर ध्यान: तीन पदों में a:b:c का व्युत्क्रम │
│ bc : ca : ab होता है, सीधे उल्टा नहीं!) │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 9: "लाभ-बँटवारा = पूँजी × समय"** │
│ │
│ साझेदारी में लाभ का अनुपात = │
│ (पूँजी₁ × समय₁) : (पूँजी₂ × समय₂) │
│ याद रखें: **"पैसा भी, पैसे का पसीना भी"** │
│ — पैसा कितना लगा और कितने समय तक पसीना │
│ बहाया (रुका रहा), दोनों गिनते हैं! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 10: "प्रतिशत ↔ अनुपात पुल"** │
│ │
│ x, y से 25% अधिक = x : y = 125 : 100 = 5 : 4 │
│ याद रखें: **"प्रतिशत को 100 में जोड़ो, │
│ अनुपात बन गया"** │
│ 20% कम = 80 : 100 = 4 : 5। │
│ म्नेमोनिक: **"सौ का साथी"** — हर प्रतिशत │
│ 100 के साथ खेलता है! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 11: "मध्यानुपाती = ज्यामितीय │
│ माध्य"** │
│ │
│ a और b का मध्यानुपाती (mean proportional) │
│ = √(a × b) │
│ याद रखें: **"बीच वाला = गुणा का वर्गमूल"** │
│ म्नेमोनिक: **"गुणा करो, जड़ निकालो"** — │
│ पेड़ की जड़ (वर्गमूल) गुणा के फल से निकलती │
│ है! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 12: "तृतीयानुपाती = b²/a"** │
│ │
│ a और b का तृतीयानुपाती (third proportional) │
│ = b²/a │
│ याद रखें: **"दूसरे का वर्ग, पहले से भाग"** │
│ म्नेमोनिक: **"तीसरा मेहमान = दूसरे का │
│ स्क्वायर, पहले का हिस्सा"** │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 13: "आय-व्यय की डिफ़ॉल्ट सेटिंग"** │
│ │
│ आय का अनुपात a : b और व्यय का अनुपात │
│ c : d हो, तो बचत के लिए: │
│ आय = ak, व्यय = cm (अलग-अलग चर!) │
│ याद रखें: **"आय-व्यय अलग घर के, K और M │
│ अलग-अलग"** — एक ही K लगाना परीक्षक का │
│ सबसे बड़ा जाल है! │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 14: "सिक्कों की गिनती = मूल्य से │
│ भाग"** │
│ │
│ कुल राशि ÷ (सिक्कों के अनुपात × मूल्य) │
│ याद रखें: **"पहले रुपये बनाओ, फिर गिनती │
│ निकालो"** — 50 पैसे, 1 रु., 2 रु. के सिक्के │
│ 1:2:3 में हों, तो मूल्य-अनुपात │
│ 0.5 : 2 : 6 = 1 : 4 : 12 से कुल योग बाँटें। │
│ म्नेमोनिक: **"सिक्का नहीं, सिक्के की कीमत │
│ बँटती है"** │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ **ट्रिक 15: "मास्टर मंत्र — RATIO"** │
│ │
│ **R** — Reduce (अनुपात को सरलतम रूप दो) │
│ **A** — Assume K (K मानकर वास्तविक मान लो) │
│ **T** — Total से भाग (योग = अनुपातों का जोड़) │
│ **I** — Invert सावधानी से (व्युत्क्रम में पलटी) │
│ **O** — Outer×Outer = Inner×Inner (जाँच) │
│ │
│ याद रखें: **"RATIO शब्द ही अनुपात का │
│ पूरा खेल है!"** │
└─────────────────────────────────────────────┘
