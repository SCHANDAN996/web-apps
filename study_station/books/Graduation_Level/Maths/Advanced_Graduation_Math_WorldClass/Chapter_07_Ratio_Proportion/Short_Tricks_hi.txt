# शॉर्ट ट्रिक्स और मेंटल हैक्स: अनुपात और समानुपात

### ट्रिक 1: अनुपात संयोजन की 'N-विधि'
A : B = a : b तथा B : C = c : d को जोड़ने के लिए:
- प्रथम पद = a * c
- मध्य पद = b * c
- अंतिम पद = b * d
सीधे A : B : C प्राप्त होता है।

### ट्रिक 2: चार संख्याओं में जोड़ी जाने वाली संख्या
चार संख्याओं a, b, c, d को समानुपाती बनाने के लिए जोड़ी जाने वाली संख्या:
`x = (ad - bc) / [(b + c) - (a + d)]`

### ट्रिक 3: सिक्का मान हैक
सिक्कों के अनुपात को उनके रुपये मूल्य से सीधे गुणा करें:
कुल मूल्य इकाई = c_1 * d_1 + c_2 * d_2 + c_3 * d_3।
कुल राशि को इस योग से भाग देकर गुणक x तुरंत प्राप्त करें।

### ट्रिक 4: तीव्र योगानुपात-अंतरानुपात (C&D)
जब भी (A + B) / (A - B) = m / n दिखे:
तुरंत लिखें: `A / B = (m + n) / (m - n)`।
