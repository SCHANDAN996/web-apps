# 📋 महत्वपूर्ण सूत्र — संख्या प्रणाली (उन्नत)

|---|---|---|
| भाज्यता का मूल सूत्र | भाज्य = भाजक × भागफल + शेषफल (0 ≤ शेषफल < भाजक) | शेषफल वाले हर प्रश्न में |
| क्रमागत संख्याओं का योग | 1 + 2 + … + n = n(n+1)/2 | प्राकृत संख्याओं का योग |
| क्रमागत विषम संख्याओं का योग | 1 + 3 + 5 + … (n पद) = n² | पहली n विषम संख्याएँ |
| क्रमागत सम संख्याओं का योग | 2 + 4 + … + 2n = n(n+1) | पहली n सम संख्याएँ |
| वर्गों का योग | 1² + 2² + … + n² = n(n+1)(2n+1)/6 | वर्ग-श्रेणी के प्रश्न |
| घनों का योग | 1³ + 2³ + … + n³ = [n(n+1)/2]² | घन-श्रेणी के प्रश्न |
| म.स. × ल.स. नियम | दो संख्याओं का गुणनफल = म.स. × ल.स. | केवल दो संख्याओं पर लागू |
| ल.स. (भिन्नों का) | ल.स. = अंशों का ल.स. / हरों का म.स. | भिन्नों के ल.स./म.स. में |
| म.स. (भिन्नों का) | म.स. = अंशों का म.स. / हरों का ल.स. | भिन्नों के ल.स./म.स. में |
| गुणनखंडों की संख्या | N = aᵖ × bᵠ × cʳ ⇒ गुणनखंड = (p+1)(q+1)(r+1) | a, b, c अभाज्य हों |
| गुणनखंडों का योग | (a⁰+…+aᵖ)(b⁰+…+bᵠ)(c⁰+…+cʳ) | सभी गुणनखंडों का योग |
| विषम गुणनखंडों की संख्या | केवल विषम अभाज्य गुणनखंडों के घात +1 का गुणनफल | 2 के घात को छोड़ दें |
| पूर्ण वर्ग के गुणनखंड | पूर्ण वर्ग के गुणनखंडों की संख्या सदैव विषम | पहचानने की ट्रिक |
| शेषफल प्रमेय (विभाजन) | a = bq + r | यूक्लिड विभाजन |
| यूक्लिड की विधि | म.स.(a, b) = म.स.(b, a mod b) | बड़ी संख्याओं का म.स. |
| 3 से विभाज्यता | अंकों का योग 3 से विभाज्य | जाँच ट्रिक |
| 9 से विभाज्यता | अंकों का योग 9 से विभाज्य | जाँच ट्रिक |
| 4 से विभाज्यता | अंतिम दो अंक 4 से विभाज्य | जाँच ट्रिक |
| 8 से विभाज्यता | अंतिम तीन अंक 8 से विभाज्य | जाँच ट्रिक |
| 11 से विभाज्यता | (सम स्थानों के अंकों का योग − विषम स्थानों का योग) = 0 या 11 का गुणज | जाँच ट्रिक |
| 6 से विभाज्यता | 2 और 3 दोनों से विभाज्य | सह-अभाज्य विभाजक नियम |
| 12 से विभाज्यता | 3 और 4 दोनों से विभाज्य | सह-अभाज्य विभाजक नियम |
| इकाई अंक (घातांक) | इकाई अंक का चक्र: 2→4, 3→4, 7→4, 8→4, 9→2, 4→2; 0,1,5,6 स्थिर | घात को चक्र-लंबाई से भाग दें |
| शेषफल प्रमेय (घात) | (a × b) mod n = [(a mod n)(b mod n)] mod n | बड़े घातों का शेषफल |
| फर्मा का लघु प्रमेय | aᵖ⁻¹ ≡ 1 (mod p), p अभाज्य, p ∤ a | अभाज्य मॉडुलो में शेषफल |
| यूलर प्रमेय | a^φ(n) ≡ 1 (mod n), यदि म.स.(a,n)=1 | संयुक्त मॉडुलो में शेषफल |
| यूलर टोशेंट | φ(n) = n × ∏(1 − 1/p), जहाँ p, n के सभी भिन्न अभाज्य गुणनखंड हैं | n से छोटी सह-अभाज्य संख्याएँ; जैसे φ(12) = 12(1−1/2)(1−1/3) = 4 |
| विल्सन प्रमेय | (p−1)! ≡ −1 (mod p), p अभाज्य | फैक्टोरियल शेषफल |
| चीनी शेषफल प्रमेय | x ≡ r₁ (mod m₁), x ≡ r₂ (mod m₂); म.स.(m₁,m₂)=1 ⇒ अद्वितीय हल mod m₁m₂ | युग्मित शेषफल प्रश्न |
| aⁿ − bⁿ विभाज्यता | (a−b) से सदैव विभाज्य; (a+b) से यदि n सम | घात-अंतर प्रश्न |
| aⁿ + bⁿ विभाज्यता | (a+b) से विभाज्य यदि n विषम | घात-योग प्रश्न |
| अंकों की संख्या (n अंकीय) | 9 × 10ⁿ⁻¹ | अंक-गणना प्रश्न |
| 1 से n तक अंकों की कुल संख्या | 1–9: 9; 10–99: 180; 100–999: 2700 | पृष्ठ-संख्या प्रश्न |
| n! में शून्यों की संख्या | [n/5] + [n/25] + [n/125] + … | अंतिम शून्य गिनना |
| n! में अभाज्य p की घात | [n/p] + [n/p²] + [n/p³] + … | फैक्टोरियल में घात |
| दो अंकीय संख्या | 10a + b; अंक पलटने पर 10b + a | अंक-परिवर्तन प्रश्न |
| अंक पलटने का अंतर | 9(a − b) | अंतर सदैव 9 का गुणज |
| अंक पलटने का योग | 11(a + b) | योग सदैव 11 का गुणज |
| आधार परिवर्तन | (abc)ₖ = a·k² + b·k¹ + c·k⁰ (k = आधार) | द्विआधारी/अष्टाधारी से दशमलव |
| सम-विषम नियम | सम±सम=सम; विषम±विषम=सम; सम×कोई=सम | त्वरित जाँच |
| क्रमागत n संख्याओं का गुणनफल | n! से सदैव विभाज्य | विभाज्यता प्रमाण |
| अभाज्य संख्या जाँच | √n तक के अभाज्यों से भाग जाँचें | अभाज्यता परीक्षण |
| 100 तक अभाज्य संख्याएँ | कुल 25 | स्मरण तथ्य |
| पूर्ण वर्ग के गुण | इकाई अंक 0,1,4,5,6,9; अंकों का योग 1,4,7,9 | पूर्ण वर्ग पहचान |
| पूर्ण वर्ग का शेषफल | mod 3 → 0 या 1; mod 4 → 0 या 1 | असंभव विकल्प काटना |
