Q101. (Medium) Find the highest power of 3 that completely divides 100!.
(A) 48  (B) 33  (C) 44  (D) 47

Answer: (A)

Solution:
By Legendre's formula: E3(100!) = [100/3] + [100/9] + [100/27] + [100/81] = 33 + 11 + 3 + 1 = 48. Therefore, the correct value is 48, corresponding to option (A).

Q122. (Hard) How many natural numbers n exist such that n! terminates in exactly 5 trailing zeroes?

Solution:
Z(24!) = 4 zeroes. For 25!, Z(25!) = [25/5] + [25/25] = 5 + 1 = 6 zeroes. The count jumps from 4 to 6, so no such n exists. Psychological Trap: Assuming every integer number of zeroes can be formed by some factorial. Therefore, the correct value is 0, corresponding to option (B).

Q124. (Hard) What is the remainder when (1! + 2! + 3! + ... + 100!)^2 is divided by 5?

For all n >= 5, n! ≡ 0 (mod 5). 1! + 2! + 3! + 4! = 1 + 2 + 6 + 24 = 33 ≡ 3 (mod 5). (3)^2 = 9 ≡ 4 (mod 5). Therefore, the correct value is 4, corresponding to option (D).

Q125. (Hard) Find the number of trailing zeroes in the combination C(200, 100) = 200! / (100! * 100!).
(A) 0  (B) 1  (C) 2  (D) 3

Answer: (B)

Solution:
E5(200!) = 49. E5(100!) = 24, so denominator has 2 * 24 = 48 factors of 5. Net factors of 5 = 49 - 48 = 1. Powers of 2 are abundant. Hence, exactly 1 zero. Therefore, the correct value is 1, corresponding to option (B).
