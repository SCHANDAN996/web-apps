126. The point (2, 3) is reflected in the line x − y + 1 = 0. The image is:
(a) (2, 1) (b) (2, 3) (c) (3, 2) (d) (1, 2)
Answer: (b)
Solution: The tempting wrong option swaps the coordinates, which is the reflection rule only for the line y = x, not for x − y + 1 = 0. Check whether the point lies on the mirror line: 2 − 3 + 1 = 0, so the point lies on the line itself. A point on the mirror line reflects onto itself, so the answer is (2, 3).
Source: NCERT Class 11 Mathematics, Straight Lines

127. The distance between the parallel lines 3x + 4y + 5 = 0 and 6x + 8y − 15 = 0 is:
(a) 5/2 (b) 2 (c) 5 (d) 25/2
Answer: (a)
Solution: The trap is applying the formula |c1 − c2|/√(a² + b²) directly with 5 and −15, giving 20/5 = 4, without first making the coefficients of x and y identical. Rewrite the second line as 3x + 4y − 15/2 = 0. Distance = |5 − (−15/2)|/√(9 + 16) = (25/2)/5 = 5/2, so the answer is 5/2.
Source: NCERT Class 11 Mathematics, Straight Lines

128. The area of the triangle with vertices (1, 2), (3, 5) and (7, 11) is:
(a) 0 sq units (b) 4 sq units (c) 2 sq units (d) 6 sq units
Answer: (a)
Solution: The tempting wrong option comes from an arithmetic slip in the determinant that yields a small positive number. Compute: area = ½|1(5 − 11) + 3(11 − 2) + 7(2 − 5)| = ½|−6 + 27 − 21| = 0. The three points are collinear (each satisfies y = (3/2)x + 1/2), so the answer is 0 sq units.
Source: NCERT Class 11 Mathematics, Straight Lines

129. The equation of the circle passing through (0, 0), (4, 0) and (0, 3) is:
(a) x² + y² + 4x + 3y = 0 (b) x² + y² − 2x − 3y = 0 (c) x² + y² − 4x + 3y = 0 (d) x² + y² − 4x − 3y = 0
Answer: (d)
Solution: The trap is choosing signs of the linear terms without testing all three points. Let the circle be x² + y² + 2gx + 2fy = 0 (no constant term since it passes through the origin). Substituting (4, 0): 16 + 8g = 0, so g = −2. Substituting (0, 3): 9 + 6f = 0, so f = −3/2. The equation is x² + y² − 4x − 3y = 0, so the answer is x² + y² − 4x − 3y = 0.
Source: NCERT Class 11 Mathematics, Conic Sections

130. The length of the tangent drawn from the point (5, 1) to the circle x² + y² − 4x − 6y + 9 = 0 is:
(a) 6 (b) 9 (c) 3 (d) √7
Answer: (c)
Solution: The tempting wrong option 9 is the value of S1 left without taking the square root. Tangent length = √S1, where S1 = 5² + 1² − 4(5) − 6(1) + 9 = 25 + 1 − 20 − 6 + 9 = 9. Hence the length is √9 = 3, so the answer is 3.
Source: NCERT Class 11 Mathematics, Conic Sections

131. The eccentricity of the hyperbola 9x² − 16y² = 144 is:
(a) 4/5 (b) 5/3 (c) 5/4 (d) 3/5
Answer: (c)
Solution: The trap is using e = √(1 − b²/a²), the ellipse formula, which gives 3/5. For a hyperbola, e = √(1 + b²/a²). Standard form: x²/16 − y²/9 = 1, so a² = 16, b² = 9. Then e = √(1 + 9/16) = √(25/16) = 5/4, so the answer is 5/4.
Source: NCERT Class 11 Mathematics, Conic Sections

132. The focus of the parabola y² + 8x = 0 is:
(a) (−2, 0) (b) (−4, 0) (c) (0, −2) (d) (2, 0)
Answer: (a)
Solution: The tempting wrong option (2, 0) ignores the negative sign of the x-term. Write y² = −8x and compare with y² = −4ax: 4a = 8, so a = 2. Since the parabola opens left, the focus is (−a, 0) = (−2, 0), so the answer is (−2, 0).
Source: NCERT Class 11 Mathematics, Conic Sections

133. The locus of a point which moves so that its distance from (4, 0) is twice its distance from the line x = 1 is:
(a) an ellipse (b) a parabola (c) a hyperbola (d) a circle
Answer: (c)
Solution: The trap is assuming "distance from a fixed point over distance from a fixed line" always gives a parabola; that holds only when the ratio equals 1. Here the ratio (eccentricity) is 2 > 1, which by the focus–directrix definition gives a hyperbola, so the answer is a hyperbola.
Source: NCERT Class 11 Mathematics, Conic Sections

134. The angle between the lines represented by 2x² − 7xy + 3y² = 0 is:
(a) 60° (b) 90° (c) 30° (d) 45°
Answer: (d)
Solution: The tempting wrong option 90° comes from misapplying the perpendicularity condition a + b = 0, which here gives 2 + 3 = 5 ≠ 0, so the lines are not perpendicular. Use tan θ = |2√(h² − ab)/(a + b)| with a = 2, h = −7/2, b = 3: h² − ab = 49/4 − 6 = 25/4, so tan θ = 2·(5/2)/5 = 1, giving θ = 45°, so the answer is 45°.
Source: NCERT Class 11 Mathematics, Straight Lines

135. If the centroid of the triangle with vertices (a, 1), (3, b) and (5, 7) is (3, 4), then a + b equals:
(a) 5 (b) 4 (c) 6 (d) 3
Answer: (a)
Solution: The trap is solving only one coordinate equation and guessing the other. Centroid: (a + 3 + 5)/3 = 3 gives a = 1; (1 + b + 7)/3 = 4 gives b = 4. Hence a + b = 5, so the answer is 5.
Source: NCERT Class 10 Mathematics, Coordinate Geometry

136. The line 3x + 4y = 12 meets the axes at A and B. The length of the perpendicular from the origin to AB is:
(a) 7/12 (b) 5/12 (c) 12/5 (d) 12/7
Answer: (c)
Solution: The tempting wrong option inverts the correct fraction. The intercepts are A(4, 0) and B(0, 3), so AB = 5. Area of triangle OAB = ½·4·3 = 6 = ½·AB·p, giving p = 12/5. Equivalently, distance from (0, 0) to 3x + 4y − 12 = 0 is 12/√25 = 12/5, so the answer is 12/5.
Source: NCERT Class 11 Mathematics, Straight Lines

137. The point which divides the line segment joining (1, 2) and (4, 8) externally in the ratio 2 : 1 is:
(a) (5, 10) (b) (7, 14) (c) (7, 12) (d) (3, 6)
Answer: (b)
Solution: The tempting wrong option (3, 6) uses the internal section formula instead of external. External division: x = (2·4 − 1·1)/(2 − 1) = 7, y = (2·8 − 1·2)/(2 − 1) = 14. So the point is (7, 14), so the answer is (7, 14).
Source: NCERT Class 10 Mathematics, Coordinate Geometry

138. The equation of the line passing through (2, 3) and making an angle of 135° with the positive x-axis is:
(a) x + y = 5 (b) x − y = −1 (c) x + y = 1 (d) x − y = 5
Answer: (a)
Solution: The trap is taking slope = tan 135° = 1 instead of −1, which leads to x − y = −1. Actually tan 135° = −1, so the line is y − 3 = −1(x − 2), i.e. x + y = 5, so the answer is x + y = 5.
Source: NCERT Class 11 Mathematics, Straight Lines

139. The radius of the circle x² + y² − 6x + 8y = 0 is:
(a) 7 (b) 25 (c) 10 (d) 5
Answer: (d)
Solution: The tempting wrong option 25 is the squared radius left unrooted. Centre = (3, −4); radius = √(g² + f² − c) = √(9 + 16 − 0) = √25 = 5, so the answer is 5.

140. The vertices of a triangle are (0, 0), (6, 0) and (0, 8). The coordinates of its circumcentre are:
(a) (3, 3) (b) (4, 3) (c) (2, 8/3) (d) (3, 4)
Answer: (d)
Solution: The tempting wrong option (2, 8/3) is the centroid, not the circumcentre. The triangle is right-angled at the origin, so the circumcentre is the midpoint of the hypotenuse joining (6, 0) and (0, 8), which is (3, 4), so the answer is (3, 4).
Source: NCERT Class 10 Mathematics, Coordinate Geometry

141. The length of the latus rectum of the ellipse 25x² + 16y² = 400 is:
(a) 8/5 (b) 16/5 (c) 32/5 (d) 64/5
Answer: (c)
Solution: The trap is using 2a²/b instead of 2b²/a, or mixing up which denominator is larger. Standard form: x²/16 + y²/25 = 1, so a² = 25 (major axis vertical), b² = 16. Latus rectum = 2b²/a = 32/5, so the answer is 32/5.
Source: NCERT Class 11 Mathematics, Conic Sections

142. The distance of the point (1, 2, 3) from the origin in three-dimensional space is:
(a) √6 (b) √14 (c) 6 (d) 14
Answer: (b)
Solution: The tempting wrong option 6 comes from adding the coordinates instead of applying the distance formula. Distance = √(1² + 2² + 3²) = √(1 + 4 + 9) = √14, so the answer is √14.

143. The line joining (1, 1) and (3, 5) is perpendicular to the line joining (2, k) and (4, 2). The value of k is:
(a) 4 (b) 1 (c) −1 (d) 3
Answer: (d)
Solution: The trap is setting the product of slopes equal to +1 instead of −1. Slope of first line = (5 − 1)/(3 − 1) = 2. Slope of second = (2 − k)/(4 − 2) = (2 − k)/2. Perpendicularity: 2·(2 − k)/2 = −1, so 2 − k = −1, k = 3, so the answer is 3.
Source: NCERT Class 11 Mathematics, Straight Lines

144. The area of the quadrilateral with vertices (1, 1), (4, 1), (5, 4) and (2, 4) taken in order is:
(a) 9 sq units (b) 12 sq units (c) 6 sq units (d) 15 sq units
Answer: (a)
Solution: The tempting wrong option 12 comes from multiplying base 3 by height 3 and then adding the height once more by mistake. The quadrilateral is a parallelogram with horizontal sides of length 3 (from y = 1 and y = 4), so height = 3 and area = 3 × 3 = 9. The shoelace formula confirms: ½|1 + 16 + 20 + 2 − (4 + 5 + 8 + 4)| = ½|39 − 21| = 9, so the answer is 9 sq units.
Source: NCERT Class 11 Mathematics, Straight Lines

145. The equation of the directrix of the parabola x² = 12y is:
(a) y = 3 (b) y = −3 (c) x = −3 (d) x = 3
Answer: (b)
Solution: The tempting wrong option x = −3 treats the parabola as if it opened horizontally. Comparing x² = 12y with x² = 4ay gives a = 3; the parabola opens upward, so the directrix is y = −a = −3, so the answer is y = −3.

146. If the points (k, 2k), (3, 5) and (6, 8) are collinear, then k equals:
(a) 3/2 (b) 1 (c) 2 (d) 5/2
Answer: (c)
Solution: The trap is a sign slip in the determinant expansion. Collinearity gives k(5 − 8) + 3(8 − 2k) + 6(2k − 5) = 0, i.e. −3k + 24 − 6k + 12k − 30 = 0, so 3k = 6 and k = 2. Check: (2, 4) lies on y = x + 2, the line through (3, 5) and (6, 8), so the answer is 2.
Source: NCERT Class 11 Mathematics, Straight Lines

147. The foot of the perpendicular from (2, 3) to the line x + y − 5 = 0 is:
(a) (4, 1) (b) (3, 2) (c) (1, 4) (d) (2, 3)
Answer: (d)
Solution: The tempting wrong option (3, 2) is the reflection-style swap, which does not apply here. Since 2 + 3 − 5 = 0, the point (2, 3) already lies on the line, so the foot of the perpendicular is the point itself, so the answer is (2, 3).

148. The eccentricity of the ellipse 4x² + 9y² = 36 is:
(a) 5/9 (b) √5/3 (c) 2/3 (d) √5/2
Answer: (b)
Solution: The tempting wrong option √5/2 comes from swapping a and b, which would give e > 1 — impossible for an ellipse. Standard form: x²/9 + y²/4 = 1, so a² = 9, b² = 4. Then e = √(1 − 4/9) = √(5/9) = √5/3, so the answer is √5/3.
Source: NCERT Class 11 Mathematics, Conic Sections

149. The equation of the line whose x-intercept is twice its y-intercept and which passes through (4, 3) is:
(a) x + 2y = 10 (b) 2x + y = 11 (c) x + 2y = 8 (d) 2x − y = 5
Answer: (a)
Solution: The trap is writing the intercept form with the ratio inverted, giving 2x + y = 11. Let the y-intercept be b; then the x-intercept is 2b. Intercept form: x/(2b) + y/b = 1, i.e. x + 2y = 2b. Substituting (4, 3): 4 + 6 = 2b, so 2b = 10 and the line is x + 2y = 10, so the answer is x + 2y = 10.
Source: NCERT Class 11 Mathematics, Straight Lines

150. The area of the triangle formed by the line 3x + 4y = 24 with the coordinate axes is:
(a) 48 sq units (b) 24 sq units (c) 12 sq units (d) 96 sq units
Answer: (b)
Solution: The tempting wrong option 48 is the product of the intercepts without the factor ½. The x-intercept is 24/3 = 8 and the y-intercept is 24/4 = 6. Area = ½·8·6 = 24, so the answer is 24 sq units.
