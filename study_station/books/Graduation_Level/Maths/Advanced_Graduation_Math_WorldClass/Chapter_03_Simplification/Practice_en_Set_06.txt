126. Simplify: (0.6 × 0.6 × 0.6 + 0.4 × 0.4 × 0.4) ÷ (0.6 × 0.6 − 0.6 × 0.4 + 0.4 × 0.4)
(a) 0.2 (b) 0.4 (c) 0.6 (d) 1.0
Answer: (d)
Solution: The trap is to compute the cubes separately and divide, getting a messy decimal. The numerator is a³ + b³ and the denominator is a² − ab + b² with a = 0.6, b = 0.4; since a³ + b³ = (a + b)(a² − ab + b²), the expression equals a + b = 0.6 + 0.4, so the answer is 1.0.

127. If x = 3 + 2√2, find the value of √x + 1/√x.
(a) 2√2 (b) 2 (c) √2 (d) 4
Answer: (a)
Solution: The trap is to square first and get confused with the reciprocal. Note x = (√2 + 1)², so √x = √2 + 1 and 1/√x = √2 − 1 after rationalising; adding gives 2√2, so the answer is 2√2.

129. Find the value of √(12 + √(12 + √(12 + … ∞))).

Solution: The trap is to assume the answer is close to √12 ≈ 3.46 and pick 3. Let the value be x; then x = √(12 + x), so x² − x − 12 = 0, giving (x − 4)(x + 3) = 0; since x > 0, x = 4, so the answer is 4.
