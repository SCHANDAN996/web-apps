# Competitive Exam Short Tricks: Simplification & Approximation

1. The 'Product of Consecutive Factors' Surd Trick:
   For infinite radicals sqrt(N +- sqrt(N +- ...)):
   If N can be factored into two consecutive integers n * (n + 1):
   - For positive sign (+), the answer is the LARGER factor (n + 1).
   - For negative sign (-), the answer is the SMALLER factor (n).
   Example: sqrt(72 + sqrt(72 + ...)) -> 72 = 8 * 9 -> Answer is 9!
   Example: sqrt(42 - sqrt(42 - ...)) -> 42 = 6 * 7 -> Answer is 6!

2. Symmetric Difference Identity:
   When calculating a^2 + b^2 + c^2 - ab - bc - ca for numbers in Arithmetic Progression with common difference d:
   The result is ALWAYS 3 * d^2!
   Example: a = 997, b = 998, c = 999 (d = 1) -> 3 * (1)^2 = 3 instantly!

3. Rapid Ladder Fraction Vector Method:
   For 1 / (a + 1 / (b + 1 / c)):
   Work in reverse vector operations without drawing multiple fractions.
   Compute: numerator / denominator = continued fraction quotients using the Euclidean algorithm backwards.

4. Telescoping Partial Fraction Shortcut:
   Sum = (1 / Common Difference) * [(1 / First Factor) - (1 / Last Factor)].
   Example: 1/(2*5) + 1/(5*8) + ... + 1/(29*32) -> (1/3) * (1/2 - 1/32) = (1/3) * (15/32) = 5/32!
