प्रश्न: VBODMAS में विंकुलम (रेखा कोष्ठक) का वरीयता क्रम क्या होता है?
उत्तर: विंकुलम की वरीयता सभी कोष्ठकों और संक्रियाओं में सबसे ऊपर होती है; रेखा के अंतर्गत आने वाले व्यंजक को पहले हल किया जाता है।

प्रश्न: a ÷ b of c तथा (a ÷ b) × c के मानों में क्या अंतर है?
उत्तर: a ÷ b of c = a / (b × c) होता है, जबकि (a ÷ b) × c = (a × c) / b होता है।

प्रश्न: यदि a + b + c = 0 हो, तो (a^3 + b^3 + c^3) / (abc) का मान क्या होगा?
उत्तर: 3, क्योंकि a + b + c = 0 होने पर a^3 + b^3 + c^3 = 3abc होता है।

प्रश्न: रूप sqrt(a + 2*sqrt(b)) वाली द्विपद करणी का वर्गमूल कैसे ज्ञात किया जाता है?
उत्तर: ऐसी दो संख्याएं x और y ज्ञात कीजिए जहाँ x + y = a और x × y = b हो; तब वर्गमूल sqrt(x) + sqrt(y) होगा।

प्रश्न: श्रेणी 1/(1×2) + 1/(2×3) + ... + 1/(n×(n+1)) का कुल योग क्या होता है?
उत्तर: n / (n + 1).

प्रश्न: अनंत तक sqrt(a + sqrt(a + sqrt(a + ...))) का मान क्या होता है?
उत्तर: (1 + sqrt(4a + 1)) / 2.
