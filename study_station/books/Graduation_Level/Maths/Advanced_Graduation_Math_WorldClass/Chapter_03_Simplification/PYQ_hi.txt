# विगत वर्ष प्रश्न पैटर्न विश्लेषण: सरलीकरण एवं सन्निकटन (Graduation Level)

SSC CGL टियर-2, IBPS PO, तथा राज्य PCS परीक्षाओं के प्रमुख पैटर्न:
- प्रमुख प्रकार:
  1. रेखा कोष्ठक और 'का' (Of) संक्रियाओं पर आधारित जटिल VBODMAS व्यंजक।
  2. त्रिघात सर्वसमिकाओं पर आधारित दशमलव संख्याओं का सरलीकरण।
  3. अनंत करणी और सतत भिन्नों के मान।
  4. टेलीस्कोपिक आंशिक भिन्न श्रृंखलाएं।

---

Q1. (मध्यम) 1800 / [10 * {(12 - 6) + (24 - 12)}] का 2 का मान क्या होगा?
(A) 5  (B) 10  (C) 20  (D) 1
उत्तर: (A)
हल: कोष्ठक के अंदर: 6 + 12 = 18। मँझले कोष्ठक में: 10 * 18 = 180। व्यंजक 1800 / 180 का 2 बनता है। VBODMAS के अनुसार 'का' पहले होगा: 180 का 2 = 360। फिर 1800 / 360 = 5 प्राप्त होता है।
मनोवैज्ञानिक जाल: पहले 1800 / 180 = 10 निकालकर फिर 2 से गुणा करके 20 उत्तर देना।
स्रोत: SSC CGL Pattern

Q2. (मध्यम) (0.76 * 0.76 * 0.76 + 0.24 * 0.24 * 0.24) / (0.76 * 0.76 - 0.76 * 0.24 + 0.24 * 0.24) का मान ज्ञात कीजिए।
(A) 0.52  (B) 1.0  (C) 0.76  (D) 0.24
उत्तर: (B)
हल: यह (a^3 + b^3) / (a^2 - ab + b^2) का रूप है, जहाँ a = 0.76 और b = 0.24 है। इसका मान a + b = 0.76 + 0.24 = 1.0 होगा।
स्रोत: SSC CGL Pattern

Q3. (मध्यम) sqrt(7 + 2 * sqrt(10)) + sqrt(7 - 2 * sqrt(10)) का मान क्या होगा?
(A) 2*sqrt(2)  (B) 2*sqrt(5)  (C) sqrt(10)  (D) 7
उत्तर: (B)
हल: 5 और 2 का योग 7 तथा गुणनफल 10 है। अतः sqrt(5) + sqrt(2) और sqrt(5) - sqrt(2) प्राप्त होते हैं। जोड़ने पर 2*sqrt(5) मिलेगा।
स्रोत: State PCS Pattern

Q4. (कठिन) यदि x = 1 + 1 / (1 + 1 / (1 + 1/2)) हो, तो 2x + 4/5 का मान क्या होगा?
(A) 3  (B) 4  (C) 5  (D) 19/5
उत्तर: (B)
हल: नीचे से हल करने पर: 1 + 1/2 = 3/2। आगे 1 + 2/3 = 5/3। x = 1 + 3/5 = 8/5। अतः 2(8/5) + 4/5 = 20/5 = 4 प्राप्त होता है।
स्रोत: SSC CGL Pattern

Q5. (कठिन) श्रेणी 1/(1*4) + 1/(4*7) + 1/(7*10) + ... + 1/(16*19) का योग ज्ञात कीजिए।
(A) 5/19  (B) 6/19  (C) 18/19  (D) 1/19
उत्तर: (B)
हल: अंतर d = 3 है। टेलीस्कोपिक वियोजन से (1/3) * [1 - 1/19] = (1/3) * (18/19) = 6/19 प्राप्त होता है।
स्रोत: SSC CGL Pattern

Q6. (मध्यम) यदि a = 997, b = 998, c = 999 हो, तो a^2 + b^2 + c^2 - ab - bc - ca का मान क्या होगा?
(A) 1  (B) 3  (C) 6  (D) 0
उत्तर: (B)
हल: सर्वसमिका 0.5 * [(a - b)^2 + (b - c)^2 + (c - a)^2] से: 0.5 * [1 + 1 + 4] = 3 प्राप्त होता है।
स्रोत: SSC CGL Pattern

Q7. (कठिन) अनंत करणी x = sqrt(12 + sqrt(12 + sqrt(12 + ...))) का मान क्या होगा?
(A) 3  (B) 4  (C) 6  (D) 12
उत्तर: (B)
हल: x^2 - x - 12 = 0 से धनात्मक मूल x = 4 प्राप्त होता है।
स्रोत: IBPS PO Pattern

Q8. (कठिन) यदि a + b + c = 0 हो, तो (a + b)^3 + (b + c)^3 + (c + a)^3 का मान क्या होगा?
(A) 0  (B) -3abc  (C) 3abc  (D) 3(a^3 + b^3 + c^3)
उत्तर: (B)
हल: a + b = -c, b + c = -a, c + a = -b। अतः (-c)^3 + (-a)^3 + (-b)^3 = -(a^3 + b^3 + c^3) = -3abc प्राप्त होता है।
स्रोत: State PCS Pattern

Q9. (मध्यम) sqrt(49.08 * 16.02) + 12.01 * 5.98 का सन्निकट मान ज्ञात कीजिए।
(A) 92  (B) 100  (C) 84  (D) 110
उत्तर: (B)
हल: सन्निकटन: sqrt(49 * 16) + 12 * 6 = 28 + 72 = 100 प्राप्त होता है।
स्रोत: IBPS PO Pattern

Q10. (कठिन) 1 / (sqrt(9) - sqrt(8)) - 1 / (sqrt(8) - sqrt(7)) + ... + 1 / (sqrt(5) - sqrt(4)) का मान क्या होगा?
(A) 5  (B) 1  (C) 0  (D) 3
उत्तर: (A)
हल: परिमेयकरण करने पर बीच के सभी पद कट जाते हैं। शेष sqrt(9) + sqrt(4) = 3 + 2 = 5 बचता है।
स्रोत: SSC CGL Pattern
