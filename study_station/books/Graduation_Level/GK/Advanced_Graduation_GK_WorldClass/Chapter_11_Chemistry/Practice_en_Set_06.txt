126. Which of the following statements about the modern periodic table is correct?
(a) Elements are arranged in increasing order of atomic mass (b) Elements are arranged in increasing order of atomic radius (c) Elements are arranged in increasing order of atomic number (d) Elements are arranged in increasing order of density
Answer: (c)
Solution: The tempting wrong choice is atomic mass, which was Mendeleev's basis, but his table had anomalies like argon–potassium. Moseley's work established that atomic number, not atomic mass, is the fundamental property, so the answer is that elements are arranged in increasing order of atomic number.
Source: NCERT Class 11 Chemistry

127. The oxidation number of sulphur in H₂S₂O₇ (oleum) is:
(a) +4 (b) +7 (c) +5 (d) +6
Answer: (d)
Solution: Many students assume a peroxide or unusual structure and pick +7, but oleum has no peroxide linkage affecting sulphur. Solving 2(+1) + 2x + 7(−2) = 0 gives x = +6, so the answer is +6.
Source: NCERT Class 11 Chemistry

128. Which of the following has the highest first ionisation enthalpy?
(a) Si (b) Na (c) Al (d) Mg
Answer: (a)
Solution: The trap is Mg, chosen because of its fully filled 3s subshell, which only explains why Mg exceeds Al. Across the period the general rise in effective nuclear charge dominates, and silicon's first ionisation enthalpy (about 786 kJ/mol) is higher than that of Mg (about 738 kJ/mol), so the answer is Si.
Source: NCERT Class 11 Chemistry

129. In the reaction Zn + CuSO₄ → ZnSO₄ + Cu, the species that is oxidised is:
(a) Cu²⁺ (b) Cu (c) Zn (d) SO₄²⁻
Answer: (c)
Solution: The tempting wrong choice is Cu²⁺, but it gains electrons and is reduced to copper metal. Zinc loses two electrons, going from 0 to +2, so the species oxidised is Zn.

130. The pH of a 0.001 M HCl solution is:
(a) 1 (b) 2 (c) 3 (d) 11
Answer: (c)
Solution: The trap is 11, which comes from confusing pH with pOH. HCl is a strong acid and fully dissociates, giving [H⁺] = 10⁻³ M, so the answer is 3.

131. Which of the following is an amphoteric oxide?
(a) CaO (b) SO₃ (c) Na₂O (d) Al₂O₃
Answer: (d)

132. The number of moles in 11 g of CO₂ (molar mass 44 g/mol) is:
(a) 0.25 (b) 0.5 (c) 1.0 (d) 4.0
Answer: (a)
Solution: The trap is 4.0, which results from dividing the molar mass by the given mass instead of the reverse. Moles = 11/44 = 0.25, so the answer is 0.25.

133. Which gas is produced when dilute hydrochloric acid reacts with zinc metal?
(a) Carbon dioxide (b) Chlorine (c) Oxygen (d) Hydrogen
Answer: (d)
Solution: The tempting wrong choice is chlorine, since HCl contains chlorine, but chloride ions are not oxidised by zinc. Active metals displace hydrogen from dilute acids, so the gas evolved is hydrogen.

134. The electronic configuration of Fe²⁺ (atomic number of Fe = 26) is:
(a) [Ar] 3d⁵ 4s¹ (b) [Ar] 3d⁶ 4s² (c) [Ar] 3d⁴ 4s² (d) [Ar] 3d⁶ 4s⁰
Answer: (d)
Solution: The trap is [Ar] 3d⁶ 4s², which is the configuration of neutral iron, not its ion. When transition metals ionise, electrons are removed from the 4s orbital first, leaving [Ar] 3d⁶, so the answer is [Ar] 3d⁶ 4s⁰.

135. Which of the following statements about catalysts is correct?
(a) A catalyst lowers the activation energy of the reaction (b) A catalyst is consumed during the reaction (c) A catalyst increases the equilibrium yield of products (d) A catalyst changes the enthalpy of the reaction
Answer: (a)
Solution: The tempting wrong choice is that a catalyst increases equilibrium yield, but it only speeds up attainment of equilibrium without shifting it. A catalyst works by providing a path of lower activation energy, so the answer is that a catalyst lowers the activation energy of the reaction.

136. The IUPAC name of CH₃–CH(OH)–CH₃ is:
(a) Propan-2-ol (b) Propan-1-ol (c) Propanal (d) Propanone
Answer: (a)
Solution: The trap is propan-1-ol, chosen by numbering from the wrong end. The –OH group is on the middle carbon, and numbering must give it the lowest locant, so the answer is propan-2-ol.

137. Which of the following is the correct increasing order of acidic strength?
(a) HClO₂ < HClO < HClO₄ < HClO₃ (b) HClO₄ < HClO₃ < HClO₂ < HClO (c) HClO < HClO₂ < HClO₃ < HClO₄ (d) HClO₃ < HClO₄ < HClO < HClO₂
Answer: (c)
Solution: The tempting wrong choice reverses the series, assuming more oxygen means weaker acid. A greater number of oxygen atoms stabilises the conjugate base and raises the oxidation state of chlorine, so acidity rises from HClO to HClO₄, and the answer is HClO < HClO₂ < HClO₃ < HClO₄.
Source: NCERT Class 11 Chemistry

138. The bond order of O₂ molecule according to molecular orbital theory is:
(a) 1 (b) 2 (c) 1.5 (d) 3
Answer: (b)
Solution: The trap is 3, which is the bond order of N₂, a commonly confused pair. O₂ has 10 bonding and 6 antibonding electrons, giving bond order (10 − 6)/2 = 2, so the answer is 2.

140. The number of sigma and pi bonds in benzene (C₆H₆) respectively are:
(a) 6 sigma, 6 pi (b) 12 sigma, 3 pi (c) 6 sigma, 3 pi (d) 12 sigma, 6 pi
Answer: (b)

141. Which of the following quantum number sets is NOT possible for an electron in an atom?
(a) n = 2, l = 2, m = 1, s = +1/2 (b) n = 2, l = 1, m = 0, s = +1/2 (c) n = 3, l = 2, m = −2, s = −1/2 (d) n = 4, l = 0, m = 0, s = −1/2
Answer: (a)
Solution: The trap is to check only m and s values, which look valid in every set. The rule is that l can range only from 0 to n−1, so l = 2 is impossible when n = 2, and the answer is the set n = 2, l = 2, m = 1, s = +1/2.
Source: NCERT Class 11 Chemistry

142. The hybridisation of the central atom in SF₆ is:
(a) sp³ (b) sp³d (c) sp³d² (d) sp³d³
Answer: (c)
Solution: The tempting wrong choice is sp³d, which suits five electron pairs as in PCl₅. Sulphur in SF₆ has six bond pairs and no lone pairs, requiring six hybrid orbitals, so the answer is sp³d².

(a) Cadmium rods (b) Plutonium (c) Uranium-235 (d) Heavy water

144. The half-life of a first-order reaction is 20 minutes. The time required for 75% completion is:
(a) 60 minutes (b) 30 minutes (c) 20 minutes (d) 40 minutes
Answer: (d)
Solution: The tempting wrong choice is 30 minutes, from wrongly assuming linear decay. For a first-order reaction, 75% completion means two half-lives (50% then 75%), i.e. 2 × 20 = 40 minutes, so the answer is 40 minutes.

146. The standard electrode potential of Zn²⁺/Zn is −0.76 V and that of Cu²⁺/Cu is +0.34 V. The EMF of the Daniell cell is:
(a) −0.42 V (b) +1.10 V (c) +0.42 V (d) −1.10 V
Answer: (b)
Solution: The trap is +0.42 V, obtained by adding the potentials directly. EMF = E(cathode) − E(anode) = 0.34 − (−0.76) = 1.10 V, so the answer is +1.10 V.
Source: NCERT Class 12 Chemistry

147. Which of the following statements about the lanthanoid contraction is correct?
(a) It is caused by poor shielding of 4f electrons (b) It causes an increase in atomic size across the series (c) It makes the sizes of second and third transition series elements very different (d) It has no effect on the chemistry of transition elements
Answer: (a)
Solution: The tempting wrong choice claims the second and third transition series differ greatly in size, but lanthanoid contraction actually makes them almost identical (e.g., Zr and Hf). The contraction arises because 4f electrons shield the nuclear charge poorly, so the answer is that it is caused by poor shielding of 4f electrons.
Source: NCERT Class 12 Chemistry

148. The number of optical isomers possible for lactic acid (CH₃CHOHCOOH) is:
(a) 1 (b) 2 (c) 3 (d) 4
Answer: (b)
Solution: The trap is 4, from applying 2ⁿ with n = 2 by miscounting chiral centres. Lactic acid has only one chiral carbon, giving 2¹ = 2 optical isomers, so the answer is 2.

149. Which of the following is the correct order of increasing boiling point?
(a) SiH₄ < CH₄ < GeH₄ < SnH₄ (b) CH₄ < SiH₄ < GeH₄ < SnH₄ (c) SnH₄ < GeH₄ < SiH₄ < CH₄ (d) GeH₄ < SiH₄ < CH₄ < SnH₄
Answer: (b)
Solution: The tempting wrong choice reverses the order, assuming lighter molecules boil higher. For these non-polar hydrides, boiling point rises with molecular mass and van der Waals forces, so the answer is CH₄ < SiH₄ < GeH₄ < SnH₄.
Source: NCERT Class 12 Chemistry

150. In the extraction of aluminium by electrolysis of alumina, cryolite (Na₃AlF₆) is added to:
(a) Lower the melting point and increase conductivity of the mixture (b) Act as a reducing agent (c) Increase the melting point of alumina (d) Prevent oxidation of the cathode
Answer: (a)
Solution: The tempting wrong choice is that cryolite acts as a reducing agent, but aluminium is reduced electrolytically, not chemically. Cryolite lowers the working temperature and improves conductivity of the melt, so the answer is that it lowers the melting point and increases conductivity of the mixture.
Source: NCERT Class 12 Chemistry
