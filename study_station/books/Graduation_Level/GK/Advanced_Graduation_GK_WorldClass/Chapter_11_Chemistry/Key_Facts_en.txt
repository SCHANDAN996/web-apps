# Key Facts & Figures — General Chemistry

## Part 1: High-Yield Facts

| Fact | Description | Examiner's Trap | Trap Type |
|---|---|---|---|
| Atomic number = number of protons | Defines the element; isotopes differ in neutrons | Confusing atomic number with mass number | Similar-name confusion |
| Isotopes | Same protons, different neutrons (e.g., ¹H, ²H, ³H) | Swapping isotopes with isobars (same mass number) | Similar-name confusion |
| Isobars | Same mass number, different atomic number (e.g., ⁴⁰Ar, ⁴⁰Ca) | Marking isobars as isotopes | Similar-name confusion |
| Isotones | Same number of neutrons | Rarely asked; confused with isotopes/isobars | Similar-name confusion |
| Modern Periodic Table | Based on atomic number (Moseley), 18 groups, 7 periods | Mendeleev's table was based on atomic mass | Chronology confusion |
| Group 18 | Noble gases — inert, complete octet | Helium has 2 electrons, not 8 (duplet) | Near-correct statement |
| Alkali metals | Group 1; soft, low density, react violently with water | Hydrogen is placed in Group 1 but is NOT an alkali metal | Near-correct statement |
| Halogens | Group 17; most reactive non-metals; F is most reactive | Fluorine is most electronegative, not chlorine | Near-correct statement |
| Electronegativity | Increases left→right, decreases top→bottom; F highest | Reversing the trend | Trend reversal trap |
| Atomic radius | Decreases left→right, increases top→bottom | Reversing the trend | Trend reversal trap |
| Ionization energy | Increases left→right, decreases top→bottom | Reversing the trend | Trend reversal trap |
| Metals vs non-metals | Metals: left side, form basic oxides; non-metals: acidic oxides | Amphoteric oxides (Al₂O₃, ZnO) react with both | Exception trap |
| Acid | pH < 7, turns blue litmus red, releases H⁺ | Confusing litmus colour change direction | Direction confusion |
| Base | pH > 7, turns red litmus blue, releases OH⁻ | Confusing litmus colour change direction | Direction confusion |
| pH of pure water | 7 at 25°C | pH changes with temperature; 7 only at 25°C | Near-correct statement |
| Strong acids | HCl, H₂SO₄, HNO₃ | H₂CO₃ (carbonic) and CH₃COOH (acetic) are weak | Near-correct statement |
| Common salt | NaCl; brine electrolysis gives NaOH, Cl₂, H₂ | Confusing products of chlor-alkali process | Process confusion |
| Baking soda | NaHCO₃ (sodium hydrogen carbonate) | Confused with washing soda Na₂CO₃·10H₂O | Similar-name confusion |
| Washing soda | Na₂CO₃·10H₂O (sodium carbonate decahydrate) | Confused with baking soda | Similar-name confusion |
| Plaster of Paris | CaSO₄·½H₂O (calcium sulphate hemihydrate) | Confused with gypsum CaSO₄·2H₂O | Similar-name confusion |
| Bleaching powder | CaOCl₂ (calcium oxychloride) | Writing formula as Ca(OCl)₂ | Formula confusion |
| Rusting | Hydrated iron(III) oxide Fe₂O₃·xH₂O; needs O₂ + H₂O | Rust forms with oxygen alone — false | Near-correct statement |
| Galvanization | Coating iron with zinc to prevent rusting | Confused with electroplating or anodizing | Similar-process confusion |
| Corrosion of copper | Green coating of basic copper carbonate | Calling it rust (rust is only for iron) | Terminology trap |
| Alloy: Brass | Cu + Zn | Confused with bronze (Cu + Sn) | Similar-name confusion |
| Alloy: Bronze | Cu + Sn | Confused with brass | Similar-name confusion |
| Alloy: Stainless steel | Fe + Cr + Ni | Forgetting chromium as key anti-rust element | Composition trap |
| Alloy: Solder | Pb + Sn | Used for joining electrical wires | Composition trap |
| Amalgam | Alloy containing mercury (e.g., dental amalgam) | Any alloy is an amalgam — false | Definition trap |
| Oxidation | Loss of electrons / gain of oxygen | Confusing oxidation with reduction | Direction confusion |
| Reduction | Gain of electrons / loss of oxygen | Confusing with oxidation | Direction confusion |
| Oxidizing agent | Itself gets reduced | Agent does the opposite of its name | Name-behaviour trap |
| Catalyst | Speeds up reaction, unchanged at end | Catalyst changes equilibrium position — false | Near-correct statement |
| Hard water | Contains Ca²⁺/Mg²⁺ salts; no lather with soap | Permanent hardness removed by boiling — false (temporary is) | Near-correct statement |
| Temporary hardness | Due to bicarbonates; removed by boiling | Confused with permanent hardness (chlorides/sulphates) | Similar-name confusion |
| CNG main component | Methane (CH₄) | Confused with LPG (butane/propane) | Similar-name confusion |
| LPG main component | Butane (and propane) | Confused with CNG | Similar-name confusion |
| Gobar gas / Biogas | Mainly methane | Confused with producer gas (CO + N₂) | Similar-name confusion |
| Laughing gas | N₂O (nitrous oxide) | Confused with NO or NO₂ | Formula confusion |
| Dry ice | Solid CO₂ | Confused with ordinary ice; sublimes directly | State-change trap |
| Greenhouse gases | CO₂, CH₄, N₂O, water vapour, CFCs | O₂ or N₂ as greenhouse gases — false | Inclusion trap |
| Ozone layer | O₃; absorbs UV-B/UV-C in stratosphere | Ozone at ground level is a pollutant, not protective | Context trap |
| Acid rain | pH < 5.6; mainly H₂SO₄ and HNO₃ from SO₂, NOₓ | Attributing acid rain to CO₂ alone | Cause confusion |
| Diamond vs Graphite | Both carbon allotropes; diamond insulator, graphite conductor | "All carbon allotropes conduct" — false | Near-correct statement |
| Fullerene | C₆₀ buckyball, carbon allotrope | Confused with graphite structure | Structure confusion |
| Water gas | CO + H₂ | Confused with producer gas (CO + N₂) | Similar-name confusion |
| Heavy water | D₂O; used as moderator in nuclear reactors | Confused with hard water | Similar-name confusion |
| Common oxidation states | Fe: +2/+3; Cu: +1/+2 | Fe³⁺ is ferric, Fe²⁺ is ferrous | Terminology trap |
| Avogadro's number | 6.022 × 10²³ particles per mole | Confusing mole with molar mass | Definition trap |
| Atomic mass unit | 1 amu = 1/12 mass of C-12 atom | Based on C-12, not hydrogen | Standard confusion |
| Boyle's Law | P ∝ 1/V at constant T | Confusing with Charles's Law (V ∝ T) | Law confusion |
| Charles's Law | V ∝ T at constant P | Confusing with Boyle's Law | Law confusion |
| Absolute zero | 0 K = −273.15°C | Writing −273 K | Unit trap |
| Electrolysis of water | H₂ at cathode, O₂ at anode; ratio 2:1 | Swapping electrode-gas pairing | Direction confusion |
| Anode/Cathode | Oxidation at anode, reduction at cathode | Reversing the pairing | Direction confusion |
| Radioactivity | Discovered by Becquerel; Curies studied Ra, Po | Crediting discovery to Curie | Attribution trap |
| Nuclear fission | Heavy nucleus splits (reactors, atom bomb) | Confusing fission with fusion (Sun) | Process confusion |
| Nuclear fusion | Light nuclei join (Sun, hydrogen bomb) | Confusing with fission | Process confusion |
| Half-life | Time for half the nuclei to decay; constant per isotope | Half-life depends on temperature — false | Near-correct statement |
| Milk of magnesia | Mg(OH)₂ — antacid | Confused with lime water Ca(OH)₂ | Similar-name confusion |
| Quicklime / Slaked lime | CaO / Ca(OH)₂ | Swapping the two | Similar-name confusion |
| Blue vitriol | CuSO₄·5H₂O | Confused with green vitriol FeSO₄·7H₂O | Similar-name confusion |
| Green vitriol | FeSO₄·7H₂O | Confused with blue vitriol | Similar-name confusion |
| White vitriol | ZnSO₄·7H₂O | Confused with other vitriols | Similar-name confusion |
| Caustic soda | NaOH | Confused with caustic potash KOH | Similar-name confusion |
| Aqua regia | 3 HCl : 1 HNO₃; dissolves gold | Reversing the ratio | Ratio trap |
| Mohs scale | Talc = 1 (softest), Diamond = 10 (hardest) | Confusing order of corundum (9) and topaz (8) | Order confusion |
| Most abundant element in Earth's crust | Oxygen (~46.6%), then Silicon | Marking aluminium (most abundant metal) | Near-correct statement |
| Most abundant metal in crust | Aluminium | Marking iron | Near-correct statement |
| Most abundant gas in air | Nitrogen (~78%) | Marking oxygen (~21%) | Near-correct statement |
| Most abundant element in universe | Hydrogen | Marking oxygen | Near-correct statement |
| Liquid metal at room temp | Mercury (Hg); Gallium melts near 30°C | Bromine is liquid non-metal, not metal | Category trap |
| Liquid non-metal at room temp | Bromine | Marking mercury | Category trap |
| Lightest element | Hydrogen | Confused with helium (second lightest) | Rank confusion |
| Hardest natural substance | Diamond | Confused with graphite (soft, lubricant) | Contrast trap |
| Best conductor of electricity (metal) | Silver, then copper | Marking gold or copper first | Rank confusion |
| Non-metal conductor | Graphite | "Non-metals never conduct" — false | Exception trap |
| Iodine test | Starch + iodine → blue-black | Confusing with Benedict's test (sugar) | Test confusion |
| Flame test colours | Na: yellow, K: lilac, Ca: brick-red, Cu: blue-green | Swapping Na and K colours | Colour confusion |
| pH indicators | Litmus, phenolphthalein (pink in base), methyl orange | Phenolphthalein is colourless in acid, not pink | Direction confusion |
| Neutralization | Acid + base → salt + water | Forgetting water as a product | Product omission trap |
| Rancidity | Oxidation of fats/oils; prevented by antioxidants, N₂ flushing | Confusing with reduction | Process confusion |
| Photosynthesis | 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂ | Reversing reactants/products with respiration | Direction confusion |
| Respiration | C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + energy | Confusing with photosynthesis | Direction confusion |
| Soldering flux | Zinc chloride / ammonium chloride | Confusing flux with solder alloy | Terminology trap |
| Inert gas in bulbs | Argon (with nitrogen) | Marking oxygen | Inclusion trap |
| Gas in electric welding | Acetylene (C₂H₂) with oxygen — oxy-acetylene | Confused with LPG | Similar-use confusion |
| Dry cell | Zn anode, NH₄Cl paste electrolyte | Confused with lead-acid battery (H₂SO₄) | Battery confusion |
| Lead-acid battery | Pb electrodes, dilute H₂SO₄ electrolyte | Confused with dry cell | Battery confusion |
| Rust prevention methods | Painting, oiling, galvanization, alloying | Electroplating with copper prevents rust best — false | Near-correct statement |
| Marsh gas | Methane (CH₄) | Confused with coal gas | Similar-name confusion |
| Phosphorus forms | White P (reactive, stored in water), Red P (matchboxes) | White P stored in kerosene — false (that's sodium) | Storage trap |

| Chlorine use | Water disinfection, bleaching | Confused with fluorine (added to water for teeth) | Use confusion |
