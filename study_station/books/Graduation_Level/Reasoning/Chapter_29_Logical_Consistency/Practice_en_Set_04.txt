76. Three statements are given: "All engineers are graduates. Some graduates are artists. No artist is a doctor." Which of the following conclusions is definitely consistent with all three statements?
(a) Some graduates are not doctors (b) Some engineers are doctors (c) All doctors are engineers (d) No graduate is an artist
Answer: (a)
Solution: The tempting wrong choice claims some engineers are doctors, but nothing links engineers to doctors, so it is not definitely consistent. Since some graduates are artists and no artist is a doctor, those graduate-artists cannot be doctors, so the answer is "Some graduates are not doctors".

77. Which set of statements is logically consistent (all can be true together)?

Answer: (c)
Solution: The other three sets each contain a direct contradiction: the second makes some fish both flyers and non-flyers, the third makes Socrates both mortal and immortal, and the fourth makes cats both animals and non-animals. Red pens being blue follows smoothly with no clash, so the answer is "Some pens are red; All red things are blue; Some pens are blue".

Solution: From the premises, every A is a B and no B is a C, so no A can be a C. The claim that some A are C directly contradicts this, so the answer is "Some A are C".

79. A detective notes: "If the door was locked, the thief entered through the window. The door was locked." Which conclusion is consistent?
(a) The door was unlocked (b) The thief entered through the door (c) The thief entered through the window (d) The thief did not enter
Answer: (c)
Solution: This is a direct modus ponens: a locked door implies window entry, and the door was locked. The door-entry option contradicts the conditional chain, so the answer is "The thief entered through the window".

86. Statements: "If it rains, the match is cancelled. The match was not cancelled." What follows consistently?
(a) It did not rain (b) It rained (c) The match was played in rain (d) Rain is unrelated to the match
Answer: (a)
Solution: This is modus tollens: rain would have cancelled the match; the match was not cancelled; therefore it did not rain. The trap is affirming the consequent, so the answer is "It did not rain".
