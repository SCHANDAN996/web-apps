# Important Rules & Approaches — Analogy

## Part 1: Key Rules / Approaches

| Rule Name | Description | Example |
|---|---|---|
| Identify the Relationship First | Before looking at options, state the exact relation between the given pair in one clear sentence. | Doctor : Hospital → "A doctor works in a hospital." |
| Sentence Test | Frame a sentence connecting the first pair; the correct option must fit the same sentence in the same order. | Bird : Nest → "A bird lives in a nest" → Lion : Den |
| Order Matters | The relation must run in the same direction (A→B). Reversed pairs are wrong even if related. | Tree : Forest ≠ Forest : Tree; correct match keeps part→whole order. |
| Same Category Rule | Both pairs should belong to the same category of relation (tool–work, part–whole, cause–effect, etc.). | Pen : Write :: Knife : Cut (tool–function) |
| Degree/Intensity Rule | Words showing intensity must match in degree and direction (mild → extreme). | Warm : Hot :: Cool : Cold |
| Part–Whole Rule | Distinguish part→whole from whole→part; check which element is the component. | Wheel : Car :: Page : Book |
| Cause–Effect Rule | First word causes the second; effect cannot precede cause. | Disease : Pain :: Exercise : Fitness |
| Worker–Tool / Worker–Product | Person is linked to the tool used or the product made; do not mix the two. | Carpenter : Hammer (tool); Author : Book (product) |
| Animal–Young One / Dwelling | Standard pairs: animal with its young one or its shelter. | Dog : Puppy :: Cat : Kitten; Bee : Hive |
| Letter-Shift Rule (Alphabet Analogy) | Apply the same +/− positional shift to each letter; check letter-by-letter, not the whole word. | CAT +2 → ECV; so DOG +2 → FQI |
| Number Operation Rule | Try square, cube, ×n, +n, digit-sum, or reverse on the first number; the same operation must give the second. | 4 : 16 :: 5 : 25 (square) |
| Opposite / Synonym Rule | In word analogies, confirm whether the relation is synonym or antonym before matching. | Begin : End :: Arrive : Depart (antonyms) |
| Elimination Method | Reject options that reverse order, change category, or change degree; the last surviving option is the answer. | If relation is "tool : function", delete all "person : place" options. |
| Bridge-Word Precision | The bridge sentence must be specific, not vague ("related to" is never enough). | Weak: "Water is related to thirst." Strong: "Water removes thirst." |

## Part 2: Time Management

| Situation | Rule | Action |
|---|---|---|
| Pattern clear within 15 seconds | 15-Second Rule | Solve immediately and mark the answer. |
| Pattern not understood in 15 seconds | Skip Signal | Mark for review and move on; do not guess blindly. |
| Maximum time per question | 45-Second Rule | Never spend more than 45 seconds on one analogy; return only if time remains. |
| Two options look correct | Re-test Rule | Re-apply the sentence test with stricter wording; the more specific bridge wins. |
| Letter/number analogy | Direct-Compute Rule | Compute the shift/operation on the spot (10–20 sec); if no pattern in two attempts, skip. |
| Exam strategy | Easy-First Rule | Attempt word analogies first (fastest), then letter, then number analogies. |

## Part 3: Logical / Mathematical Formulas

| Formula | Use | Example |
|---|---|---|
| Letter position: A=1, B=2 … Z=26 | Base for all alphabet analogies | C(3) + 2 = E(5) |
| Shift: New letter = (Old position ± n), wrap around Z→A | Uniform letter shifting | Y(25) + 3 = B(2) |
| Reverse position: 27 − position | Opposite-end letter pairs | A(1) ↔ Z(26); D(4) ↔ W(23) |
| Number patterns: n², n³, n²±k, ×n±k, digit sum, digit reverse | Standard number analogy operations | 7 : 343 (n³); 36 : 9 (digit sum 3+6) |
| Ratio check: a : b = c : x ⇒ x = (b × c) / a | Proportion-type analogies | 2 : 6 :: 5 : 15 |

No other formulas are required for this chapter; success depends on vocabulary, relationship recognition, and disciplined elimination.
