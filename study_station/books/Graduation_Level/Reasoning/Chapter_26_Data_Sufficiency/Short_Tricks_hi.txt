# 🪄 शॉर्ट ट्रिक्स + Skip Strategy — आँकड़ों की पर्याप्तता

---

## 🎯 ट्रिक 1: "पहले अकेला, फिर अकेला, फिर साथ" — 3-कदम नियम

```
┌─────────────────────────────────────────────┐
│  कदम 1: कथन I अकेला → पर्याप्त?             │
│  कदम 2: कथन II अकेला → पर्याप्त?            │
│  कदम 3: दोनों मिलकर → पर्याप्त?             │
│                                             │
│  म्नेमोनिक: "अ-अ-स" (अकेला-अकेला-साथ)      │
└─────────────────────────────────────────────┘
```
कभी भी दोनों कथनों को पहले से मिलाकर मत पढ़ो। अक्सर गलतियाँ इसी से होती हैं।

---

## 🎯 ट्रिक 2: "उत्तर चाहिए, मान नहीं" — सबसे बड़ी ट्रिक

```
┌─────────────────────────────────────────────┐
│  प्रश्न: x का मान क्या है?                  │
│  कथन से x = 5 निकल आया? → पर्याप्त ✅       │
│  कथन से x = 5 या -5? → अपर्याप्त ❌         │
│                                             │
│  म्नेमोनिक: "एक जवाब = पर्याप्त,           │
│             दो जवाब = धोखा"                 │
└─────────────────────────────────────────────┘
```
**आपको मान निकालना नहीं है — केवल यह तय करना है कि निकाला जा सकता है या नहीं।** गणना में समय बर्बाद मत करो!

## 🎯 ट्रिक 3: "YES भी उत्तर है, NO भी उत्तर है"

```
┌─────────────────────────────────────────────┐
│  प्रश्न: क्या राम मोहन से लंबा है?          │
│  कथन से निश्चित "हाँ" → पर्याप्त ✅         │
│  कथन से निश्चित "नहीं" → भी पर्याप्त ✅     │
│  "पता नहीं" → अपर्याप्त ❌                  │
│                                             │
│  म्नेमोनिक: "हाँ-नहीं दोनों जीत,           │
│             शायद-शायद हार"                  │
└─────────────────────────────────────────────┘
```
परीक्षक का जाल: छात्र सोचते हैं "नहीं" आया तो कथन बेकार है — गलत! निश्चित "नहीं" भी पूर्ण उत्तर है।

## 🎯 ट्रिक 4: "विकल्प-पेड़" — 5 सेकंड में विकल्प चुनना

```
┌─────────────────────────────────────────────┐
│  I अकेला ✓, II अकेला ✗ → विकल्प (a)         │
│  I अकेला ✗, II अकेला ✓ → विकल्प (b)         │
│  दोनों अलग-अलग ✓ → विकल्प (d) [प्रत्येक]   │
│  अलग-अलग ✗, मिलकर ✓ → विकल्प (c) [दोनों]   │
│  मिलकर भी ✗ → विकल्प (e) [अपर्याप्त]        │
│                                             │
│  म्नेमोनिक: "पहला-दूसरा-साथ-कोई"            │
└─────────────────────────────────────────────┘
```
(विकल्प-क्रम परीक्षा के अनुसार बदल सकता है — पहले विकल्प पढ़ो, फिर पेड़ लगाओ।)

## 🎯 ट्रिक 5: "समीकरण गिनो, चर गिनो"

```
┌─────────────────────────────────────────────┐
│  n चर हल करने हैं → n स्वतंत्र समीकरण चाहिए│
│  2 चर + 1 समीकरण = अपर्याप्त ❌             │
│  2 चर + 2 समीकरण = पर्याप्त ✅              │
│                                             │
│  म्नेमोनिक: "जितने चर, उतने तार"            │
└─────────────────────────────────────────────┘
```
**जाल:** x + y = 10 और 2x + 2y = 20 — दिखने में 2 समीकरण, असल में एक ही है (स्वतंत्र नहीं) → अपर्याप्त!

## 🎯 ट्रिक 6: "रैंकिंग में खींचो रेखा"

```
┌─────────────────────────────────────────────┐
│  लंबाई/आयु/अंक वाले प्रश्न में:             │
│  कथन I: A > B     कथन II: B > C             │
│  अलग-अलग अधूरे, मिलकर A > B > C ✅          │
│                                             │
│  म्नेमोनिक: "टूटी जंजीर अकेली निकम्मी,      │
│             जुड़ी जंजीर काम की"             │
└─────────────────────────────────────────────┘
```
रैंकिंग प्रश्नों में अक्सर उत्तर "दोनों मिलकर" होता है — पर जाँच ज़रूर करो, अनुमान मत लगाओ।

## 🎯 ट्रिक 7: "संख्या-रेखा पर दो उल्टे पैर"

```
┌─────────────────────────────────────────────┐
│  x² = 25 → x = +5 या −5 (दो मान) ❌         │
│  |x| = 5 → दो मान ❌                        │
│  x³ = 125 → केवल x = 5 ✅                   │
│                                             │
│  म्नेमोनिक: "वर्ग दोमुँहा, घन एकमुँहा"      │
└─────────────────────────────────────────────┘
```
सम घात (even power) वाले कथन अक्सर अपर्याप्त निकलते हैं — यह परीक्षक का पसंदीदा जाल है।

## 🎯 ट्रिक 8: "कोड-भाषा में शब्द-ताला"

```
│  common मिला → कोड निश्चित ✅               │
│  common नहीं मिला → अपर्याप्त ❌            │
│                                             │
│  म्नेमोनिक: "मिलान नहीं तो मान नहीं"        │
└─────────────────────────────────────────────┘
```

## 🎯 ट्रिक 9: "रक्त-संबंध में पेड़ बिना मत बैठो"

```
┌─────────────────────────────────────────────┐
│  पहले मानसिक family tree बनाओ:              │
│  कथन I से पेड़ पूरा? कथन II से पूरा?        │
│  लिंग अज्ञात रह जाए → अक्सर अपर्याप्त ❌    │
│                                             │
│  म्नेमोनिक: "लिंग बिना, रिश्ता अधूरा"       │
└─────────────────────────────────────────────┘
```
**जाल:** "P, Q का भाई है" + "Q, R की बहन है" → P और R का संबंध? R का लिंग अज्ञात → अपर्याप्त!

## 🎯 ट्रिक 11: "कथन II को I से दूषित मत करो"

```
┌─────────────────────────────────────────────┐
│  कथन II जाँचते समय कथन I की जानकारी        │
│  भूल जाओ! II को बिल्कुल अकेला परखो।        │
│                                             │
│  म्नेमोनिक: "दूसरे की परीक्षा,             │
│             पहले की याद मिटा"               │

```
यही सबसे आम गलती है — II जाँचते वक्त I का डेटा मन में घुसा रहता है और "दोनों मिलकर" की जगह गलत विकल्प टिक हो जाता है।

## ⏭️ SKIP STRATEGY — कब प्रश्न छोड़ दें

### 🚫 नियम 1: "15-सेकंड अटकल नियम"
कथन I और II पढ़ने के बाद **15 सेकंड** में यह तय न हो कि किस दिशा में जाँचनी है (समीकरण? रैंकिंग? कोड?) — **तुरंत छोड़ें, mark करके आगे बढ़ें।** DS प्रश्न में उलझने से 3-4 आसान प्रश्नों का समय चला जाता है।

### 🚫 नियम 2: "तीन चर वाला जाल"
प्रश्न में **3 या अधिक चर** (जैसे a, b, c का मान) और कथनों में जटिल समीकरण दिखें — यह लंबी गणना का संकेत है। अगर 30 सेकंड में "समीकरण-गिनती" ट्रिक से फैसला न हो, तो **छोड़ दें** — ये प्रश्न जानबूझकर समय-भक्षक बनाए जाते हैं।

### 🚫 नियम 3: "दोनों-मिलकर लगे तो एक बार और जाँचें, फिर भी संदेह हो तो छोड़ें"
जब मन कहे "शायद दोनों मिलकर पर्याप्त हैं" पर आप पूरी तरह verify न कर पाएँ — **अनुमान पर टिक न करें।** DS में अनुमान = नकारात्मक अंकन का निमंत्रण। बेहतर है छोड़कर बाद में लौटें।

### 💡 बोनस सलाह
DS प्रश्नों को पेपर के **अंतिम दौर** में रखें — पहले सीधे प्रश्न (कोडिंग, श्रृंखला, रैंकिंग) निपटाएँ। DS में "लगभग-सही" विकल्प अक्सर मिलते हैं, इसलिए जल्दबाज़ी में टिक करने पर निगेटिव मार्किंग का जोखिम अधिक हो सकता है।
