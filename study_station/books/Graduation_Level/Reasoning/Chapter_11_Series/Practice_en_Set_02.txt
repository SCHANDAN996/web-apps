26. Find the next term: 3, 7, 16, 35, 74, ?
(a) 148 (b) 153 (c) 149 (d) 156
Answer: (b)
Solution: The tempting answer 148 comes from simply doubling 74, but the pattern is ×2 + 1, ×2 + 2, ×2 + 3, ×2 + 4, so next is ×2 + 5. Check: 3×2+1=7, 7×2+2=16, 16×2+3=35, 35×2+4=74, 74×2+5=153, so the answer is 153.
Source: PYQ-style

27. Find the missing term: 5, 11, 23, 47, ?, 191
(a) 95 (b) 97 (c) 96 (d) 94
Answer: (a)
Solution: Each term is double the previous plus 1: 5×2+1=11, 11×2+1=23, 23×2+1=47, 47×2+1=95, and 95×2+1=191 confirms it. The option 94 tempts those who only double 47, so the answer is 95.
Source: PYQ-style
