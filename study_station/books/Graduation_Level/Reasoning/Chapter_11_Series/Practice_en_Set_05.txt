101. Find the missing term: 3, 7, 15, 31, 63, ?
(a) 95 (b) 127 (c) 121 (d) 131
Answer: (b)
Solution: Each term is double the previous term plus 1: 3×2+1=7, 7×2+1=15, and so on up to 63, so 63×2+1=127. The tempting value 121 comes from adding a fixed number instead of doubling, so the answer is 127.
Source: PYQ-style

102. Find the missing term: 2, 6, 12, 20, 30, ?
(a) 40 (b) 36 (c) 42 (d) 44
Answer: (c)
Solution: Differences are 4, 6, 8, 10, so the next difference is 12, giving 30+12=42; equivalently the terms are n(n+1), and 6×7=42. The option 40 comes from wrongly assuming a constant difference of 10, so the answer is 42.
Source: PYQ-style

103. Find the missing term: 4, 9, 16, 25, 36, ?
(a) 42 (b) 49 (c) 48 (d) 45
Answer: (b)
Solution: These are squares of consecutive natural numbers starting from 2: 2², 3², 4², 5², 6², so the next is 7²=49. The option 48 tempts those who add 12 to 36 instead of the growing odd difference 13, so the answer is 49.

108. Find the missing term: 2, 3, 5, 9, 17, 33, ?

109. Find the missing term: 100, 50, 52, 26, 28, 14, ?
(a) 12 (b) 15 (c) 7 (d) 16
Answer: (d)
Solution: The pattern alternates ÷2, +2: 100÷2=50, 50+2=52, 52÷2=26, 26+2=28, 28÷2=14, so 14+2=16. The value 7 comes from applying ÷2 again and ignoring the alternating +2 step, so the answer is 16.
Source: PYQ-style

111. Find the missing term: 1, 1, 2, 3, 5, 8, 13, ?
(a) 19 (b) 20 (c) 18 (d) 21
Answer: (d)
Solution: This is the Fibonacci pattern: each term is the sum of the previous two, so 8+13=21. The value 20 comes from adding 7 instead of 8 to 13, so the answer is 21.

112. Find the missing term: 5, 10, 7, 14, 11, 22, ?
(a) 17 (b) 20 (c) 19 (d) 44
Answer: (c)
Solution: The pattern alternates ×2, −3: 5×2=10, 10−3=7, 7×2=14, 14−3=11, 11×2=22, so the next step is 22−3=19. The value 44 comes from applying ×2 again instead of the alternating −3 step, so the answer is 19.
Source: PYQ-style

114. Find the missing term: 0, 6, 24, 60, 120, ?

116. Find the missing term: 4, 18, 48, 100, 180, ?
(a) 288 (b) 280 (c) 300 (d) 294
Answer: (d)
Solution: Each term is (n+1)²×n: 2²×1=4, 3²×2=18, 4²×3=48, 5²×4=100, 6²×5=180, so 7²×6=294. The value 288 comes from miscomputing 49×6 as 48×6, so the answer is 294.

119. Find the missing term: 15, 31, 63, 127, 255, ?
(a) 509 (b) 510 (c) 511 (d) 512
Answer: (c)
Solution: Each term is double the previous plus 1, equivalently 2ⁿ−1: 2⁴−1=15 up to 2⁸−1=255, so 2⁹−1=511. The value 512 is 2⁹ without subtracting 1, a classic trap, so the answer is 511.
