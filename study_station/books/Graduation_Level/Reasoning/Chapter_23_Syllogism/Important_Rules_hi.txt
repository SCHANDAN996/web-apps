# न्याय-वाक्य (Syllogism) — महत्वपूर्ण नियम एवं दृष्टिकोण

## भाग 1: मुख्य नियम/दृष्टिकोण

| नियम का नाम | विवरण | उदाहरण |
|---|---|---|
| निश्चित निष्कर्ष का नियम | निष्कर्ष तभी सही जब वह **सभी संभव वेन आरेखों** में सत्य हो; एक भी आरेख में असत्य = गलत | कथन: सभी A, B हैं। निष्कर्ष "कुछ B, A हैं" — हर आरेख में सत्य, अतः सही |
| "सभी" (All) का रूपांतरण | "सभी A, B हैं" ⇒ "कुछ B, A हैं" सदैव सत्य; पर "सभी B, A हैं" कभी निश्चित नहीं | सभी बिल्लियाँ जानवर हैं ⇒ कुछ जानवर बिल्लियाँ हैं (सही) |
| "कोई नहीं" (No) का रूपांतरण | "कोई A, B नहीं" ⇒ "कोई B, A नहीं" दोनों दिशाओं में सत्य | कोई बिल्ली कुत्ता नहीं ⇒ कोई कुत्ता बिल्ली नहीं (सही) |
| "कुछ" (Some) का रूपांतरण | "कुछ A, B हैं" ⇒ "कुछ B, A हैं" सदैव सत्य | कुछ कलम लाल हैं ⇒ कुछ लाल कलम हैं (सही) |
| "कुछ नहीं" (Some Not) का नियम | "कुछ A, B नहीं" से "कुछ B, A नहीं" **नहीं** निकलता; यह रूपांतरण अमान्य | कुछ फल आम नहीं ⇏ कुछ आम फल नहीं |
| मध्य पद (Middle Term) का नियम | दोनों कथनों का उभयनिष्ठ पद कम-से-कम एक कथन में वितरित (distributed) होना चाहिए, वरना निष्कर्ष अनिश्चित। पद वितरित होता है: "सभी" के कर्ता में, "कोई नहीं" के कर्ता और विधेय दोनों में, तथा "कुछ नहीं" के विधेय में | सभी A, B हैं + सभी C, B हैं ⇒ A और C में कोई निश्चित संबंध नहीं (B कहीं वितरित नहीं) |
| दो ऋणात्मक कथनों का नियम | दोनों कथन "कोई नहीं/कुछ नहीं" हों तो कोई निश्चित निष्कर्ष नहीं निकलता | कोई A, B नहीं + कोई B, C नहीं ⇒ अनिश्चित |
| दो विशेष (Particular) कथनों का नियम | दोनों कथन "कुछ" वाले हों तो कोई निश्चित निष्कर्ष नहीं निकलता | कुछ A, B हैं + कुछ B, C हैं ⇒ अनिश्चित |
| सकारात्मक + सकारात्मक | दोनों कथन सकारात्मक हों तो निष्कर्ष भी सकारात्मक ही होगा; ऋणात्मक निष्कर्ष गलत | सभी A, B + सभी B, C ⇒ सभी A, C (सही); कोई A, C नहीं (गलत) |
| एक ऋणात्मक कथन का नियम | एक कथन ऋणात्मक हो तो निष्कर्ष भी ऋणात्मक ही होगा | सभी A, B हैं + कोई B, C नहीं ⇒ कोई A, C नहीं |
| संभावना (Possibility) का नियम | "संभावना है कि…" वाला निष्कर्ष तब सही जब कथनों से उसका खंडन न होता हो, अर्थात् ऐसी कोई स्थिति संभव हो जिसमें वह सत्य हो | कुछ A, B हैं ⇒ "सभी A, B होने की संभावना" सही (यदि कथन इसे रोकते न हों) |
| संभावना में ऋणात्मक रोक | कथन में "कोई A, B नहीं" हो तो "A का B होने की कोई संभावना" गलत | कोई पेन किताब नहीं ⇒ "कुछ पेन किताब होने की संभावना" गलत |
| निश्चित निष्कर्ष ≠ संभावना | जो निष्कर्ष निश्चित रूप से सही है, उसकी "संभावना" वाली घोषणा को उत्तर में नहीं मानते (परीक्षा परिपाटी) | सभी A, B सिद्ध हो तो "सभी A, B होने की संभावना" उत्तर नहीं |
| "कुछ A, B नहीं हैं" की जाँच | यह तभी सही जब A का कोई भाग B से पूर्णतः अलग हो | सभी A, B हैं ⇒ "कुछ A, B नहीं हैं" गलत |
| या (Either-Or) की शर्तें | (1) दोनों निष्कर्ष गलत हों, (2) दोनों एक ही पदों पर हों, (3) दोनों मिलकर सभी संभावनाएँ ढकें (पूरक जोड़ी हो)। मान्य जोड़ियाँ: "कुछ + कोई नहीं" और "सभी + कुछ नहीं" | निष्कर्ष I: कुछ A, C हैं; II: कोई A, C नहीं — दोनों गलत ⇒ या I या II |
| "कुछ + कुछ नहीं" या-जोड़ी नहीं | "कुछ A, B हैं" और "कुछ A, B नहीं हैं" दोनों एक साथ सत्य हो सकते हैं (उपविरोधी), इसलिए यह मान्य या-जोड़ी नहीं बनती | कुछ A, B हैं / कुछ A, B नहीं हैं ⇒ या-जोड़ी अमान्य |
| न्यूनतम आरेख विधि | पहले सबसे छोटा (न्यूनतम ओवरलैप) आरेख बनाएँ; निष्कर्ष उसमें गलत हो तो ही अधिकतम आरेख जाँचें | समय बचाने हेतु प्राथमिक विधि |
| ऋणात्मक कथन का आरेख | "कोई A, B नहीं" को क्रॉस (✗) या पृथक वृत्तों से दर्शाएँ; ओवरलैप कभी न बनाएँ | कोई कुत्ता बिल्ली नहीं ⇒ दो अलग वृत्त |
| "केवल/केवल कुछ" (Only/Only a few) | "केवल A, B हैं" = सभी B, A हैं; "केवल कुछ A, B हैं" = कुछ A, B हैं + कुछ A, B नहीं हैं | केवल कुछ छात्र विद्वान हैं ⇒ कुछ छात्र विद्वान + कुछ छात्र विद्वान नहीं |
| "प्रत्येक/हर" (Each/Every) | "प्रत्येक" और "हर" = "सभी" के समतुल्य | हर कलम लाल है = सभी कलमें लाल हैं |
| "कम-से-कम कुछ" (At least some) | "कम-से-कम कुछ" = "कुछ" के समतुल्य | कम-से-कम कुछ A, B हैं = कुछ A, B हैं |
| "अधिकांश/कई" (Most/Many) | "अधिकांश" और "कई" = "कुछ" के समतुल्य (इनसे "सभी" सिद्ध नहीं होता) | अधिकांश A, B हैं ⇒ केवल "कुछ A, B हैं" निश्चित |
| शब्द-भ्रम जाल | परीक्षक "सभी A, B हैं" से "सभी B, A हैं" लुभाता है — यह सबसे आम जाल है | सभी सेर पशु हैं ⇏ सभी पशु सेर हैं |
| निष्कर्ष-पूर्वाग्रह जाल | वास्तविक ज्ञान (real-world knowledge) लागू न करें; केवल कथनों को सत्य मानें | कथन: सभी कुत्ते बिल्लियाँ हैं ⇒ इसे ही सत्य मानकर हल करें |

## भाग 2: समय प्रबंधन

| नियम | विवरण |
|---|---|
| 15-सेकंड नियम | कथन पढ़कर 15 सेकंड में यह पहचान न हो कि कौन-सा नियम/आरेख लगेगा, तो प्रश्न को चिह्नित कर आगे बढ़ें; अंत में लौटें |
| 45-सेकंड नियम | एक Syllogism प्रश्न पर कुल 45 सेकंड से अधिक न दें; 2 कथन + 2 निष्कर्ष वाले सामान्य प्रश्न का लक्ष्य 30–40 सेकंड है |
| 3+ कथन वाले प्रश्न | 3 या अधिक कथन हों तो अधिकतम 60 सेकंड; उससे अधिक लगे तो छोड़ दें — गलत उत्तर से नकारात्मक अंकन का नुकसान बड़ा है |
| संभावना-प्रश्न अलर्ट | निष्कर्ष में "संभावना/possibility" दिखते ही पहले निश्चित निष्कर्ष जाँचें; निश्चित गलत हो तभी संभावना पर समय दें |
| या-जोड़ी शॉर्टकट | दोनों निष्कर्ष गलत + समान पद + पूरक जोड़ी (कुछ/कोई नहीं या सभी/कुछ नहीं) ⇒ सीधे "या I या II" टिक करें, पुनः आरेख न बनाएँ |
| पहले निष्कर्ष, बाद में आरेख | निष्कर्ष पढ़कर केवल उन्हीं पदों का संबंध जाँचें; पूरा आरेख बनाने में समय न गँवाएँ |
| अनुमान पर टिक न करें | 50-50 संदेह में उत्तर न दें (नकारात्मक अंकन); Syllogism में "लगता है सही है" वाला निष्कर्ष प्रायः गलत होता है |

## भाग 3: गणितीय/तार्किक सूत्र

| सूत्र/प्रतीक | अर्थ |
|---|---|
| सभी A, B हैं ⇒ कुछ B, A हैं | व्यापक से विशेष रूपांतरण (सदैव सत्य) |
| कोई A, B नहीं ⇔ कोई B, A नहीं | द्विदिश रूपांतरण (सदैव सत्य) |
| कुछ A, B हैं ⇔ कुछ B, A हैं | द्विदिश रूपांतरण (सदैव सत्य) |
| कुछ A, B नहीं ⇏ कुछ B, A नहीं | रूपांतरण अमान्य |
| सभी A, B + सभी B, C ⇒ सभी A, C | शृंखला नियम (Chain Rule) |
| सभी A, B + कोई B, C नहीं ⇒ कोई A, C नहीं | मिश्रित शृंखला (ऋणात्मक निष्कर्ष) |
| ऋणात्मक + ऋणात्मक ⇒ कोई निष्कर्ष नहीं | दो नकार से निष्कर्ष अमान्य |
| विशेष + विशेष ⇒ कोई निष्कर्ष नहीं | दो "कुछ" से निष्कर्ष अमान्य |
| केवल A, B हैं = सभी B, A हैं | "Only" का उलटा रूपांतरण |
| केवल कुछ A, B हैं = कुछ A, B हैं + कुछ A, B नहीं हैं | "Only a few" का द्वि-निष्कर्ष |
| या-जोड़ी: (कुछ A,B हैं) + (कोई A,B नहीं) या (सभी A,B हैं) + (कुछ A,B नहीं हैं) | मान्य Either-Or संयोजन |

**नोट:** इस अध्याय में कोई संख्यात्मक सूत्र नहीं; उपरोक्त तार्किक रूपांतरण ही इस अध्याय के "सूत्र" हैं।
