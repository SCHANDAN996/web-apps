101. In the expression P > Q ≥ R = S < T, which of the following conclusions is definitely true?
(a) T > Q (b) Q > T (c) P > T (d) P > R
Answer: (d)
Solution: The tempting option T > Q fails because the chain breaks at S < T — the sign reverses, so no relation between Q and T can be fixed. But P > Q ≥ R gives P > R directly through the common term Q, so the answer is P > R.

102. Statement: A ≥ B = C > D ≤ E. Which conclusion follows?
(a) E > B (b) A > D (c) A = C (d) C < E
Answer: (b)
Solution: E > B is tempting but the chain breaks at D ≤ E, so E and B cannot be compared. Since A ≥ B = C > D, we get A ≥ C > D, hence A > D is definite, so the answer is A > D.

103. Statement: M < N ≤ O = P > Q. Which of the following is definitely false?
(a) O > Q (b) N ≤ P (c) M > P (d) M < P
Answer: (c)
Solution: M < P follows from M < N ≤ O = P, and N ≤ P and O > Q also follow directly. The claim M > P contradicts the established M < P, so it is definitely false, so the answer is M > P.
