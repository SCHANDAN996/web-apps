# असमानता (Inequality) — महत्वपूर्ण नियम, दृष्टिकोण और समय प्रबंधन

## भाग 1: मुख्य नियम / दृष्टिकोण

### 1.1 चिह्नों का अर्थ

| चिह्न | अर्थ | उदाहरण |
|---|---|---|
| > | बड़ा | A > B → A, B से बड़ा |
| < | छोटा | A < B → A, B से छोटा |
| ≥ | बड़ा या बराबर | A ≥ B → A, B से छोटा नहीं |
| ≤ | छोटा या बराबर | A ≤ B → A, B से बड़ा नहीं |
| = | बराबर | A = B |
| ≠ | बराबर नहीं | A ≠ B |

### 1.2 संबंध स्थापित करने के नियम

| नियम | विवरण | उदाहरण |
|---|---|---|
| समान दिशा वाले चिह्न जुड़ते हैं | > के साथ > या ≥ जुड़ सकता है; < के साथ < या ≤ | A > B ≥ C ⇒ A > C |
| विपरीत दिशा वाले चिह्न नहीं जुड़ते | > और < मिल जाएँ तो निष्कर्ष नहीं निकलता | A > B < C ⇒ A और C में कोई निश्चित संबंध नहीं |
| सख्त चिह्न प्रबल होता है | श्रृंखला में > और ≥ दोनों हों तो परिणाम > होता है | A ≥ B > C ⇒ A > C |
| केवल ≥/≤ की श्रृंखला | सभी चिह्न ≥ हों तो परिणाम ≥ | A ≥ B ≥ C ⇒ A ≥ C |
| समानता का प्रसार | A = B और B > C ⇒ A > C | चर बदलकर जोड़ें |
| मध्य पद समान होना चाहिए | दो कथन तभी जुड़ेंगे जब उनमें उभयनिष्ठ चर हो | A > B, C > D → नहीं जुड़ते |

### 1.3 निष्कर्ष जाँचने के नियम (Coded/Direct Inequality)

| नियम | विवरण | उदाहरण |
|---|---|---|
| निश्चित निष्कर्ष | श्रृंखला से सीधे मिले तभी "सत्य" | A > B > C से A > C सत्य |
| ≥ निष्कर्ष की जाँच | A ≥ C तभी सत्य जब A > C निश्चित हो या A = C निश्चित हो (अर्थात् सभी संभावित स्थितियों में A ≥ C सत्य हो) | A ≥ B ≥ C ⇒ A ≥ C सत्य |
| संभावना (Possibility) | जो निश्चित असत्य न हो, वह संभावना सत्य | A > B < C से A > C की संभावना सत्य |
| नकारात्मक निष्कर्ष | "A < C असत्य" जाँचने के लिए A ≥ C देखें | श्रृंखला से विपरीत स्थिति परखें |

### 1.4 Either-Or (या तो / या) के नियम

| शर्त | विवरण | उदाहरण |
|---|---|---|
| दोनों निष्कर्ष अलग-अलग असत्य | पहली शर्त | निष्कर्ष I: A > C (असत्य), II: A ≤ C (असत्य) |
| दोनों में चर समान हों | तत्वों का युग्म एक ही हो | दोनों में A और C ही हों |
| दोनों मिलकर सभी संभावनाएँ ढकें | पूरक चिह्न-युग्म हैं: (>, ≤), (<, ≥), (=, ≠) | A > C और A ≤ C मिलकर पूर्ण |
| पूरक युग्म की जाँच | निष्कर्षों के चिह्न ऊपर के तीनों में से कोई एक युग्म बनाते हों, तभी Either-Or लागू होता है | A ≥ B < C में निष्कर्ष A > C / A ≤ C → Either-Or |

### 1.5 Coded Inequality के कोड-सारणी दृष्टिकोण

| नियम | विवरण | उदाहरण |
|---|---|---|
| पहले कोड तालिका बनाएँ | 'P @ Q' का अर्थ 'P > Q' — हर प्रतीक का अर्थ ऊपर लिखें | @ = >, # = <, $ = ≥, % = ≤, & = = |
| कथन को सामान्य चिह्नों में बदलें | फिर सामान्य नियम लगाएँ | A @ B $ C → A > B ≥ C |
| प्रतीक-भ्रम से बचें | ≥ और > के कोड अलग-अलग होते हैं; जल्दबाजी में गलती | $ को > मान लेना = गलत |

### 1.6 मात्रात्मक असमानता (Quantity I vs Quantity II)

| नियम | विवरण | उदाहरण |
|---|---|---|
| दोनों मात्राएँ अलग हल करें | Q1 और Q2 का मान निकालकर तुलना | Q1 = 12, Q2 = 15 ⇒ Q1 < Q2 |
| द्विघात में दोनों मूल लें | x² = 16 ⇒ x = ±4; दोनों मानों से तुलना | x = ±4, y = 3 ⇒ संबंध अनिश्चित हो सकता है |
| चिन्ह-विश्लेषण विधि | x² − 5x + 6 = 0 के मूल 2, 3; चिन्हों से सीधे तुलना | बड़े-छोटे मूलों का क्रम याद रखें |
| "संबंध स्थापित नहीं" विकल्प | मूलों के युग्म अलग-अलग क्रम दें तो CND | x = 2, 5; y = 3, 6 ⇒ CND |

## भाग 2: समय प्रबंधन

| नियम | विवरण | लागू करने का तरीका |
|---|---|---|
| 15-सेकंड नियम | सीधे चिह्न-आधारित प्रश्न (Direct Inequality) 15 सेकंड में हल होना चाहिए; पैटर्न 15 सेकंड में न समझ आए तो चिह्नित कर आगे बढ़ें | श्रृंखला एक ही दिशा में लिखें, तुरंत निष्कर्ष मिलाएँ |
| 45-सेकंड नियम | Coded या Either-Or वाला प्रश्न अधिकतम 45 सेकंड; इससे अधिक लगे तो छोड़ दें | कोड तालिका 10 सेकंड, रूपांतरण 15 सेकंड, निष्कर्ष 20 सेकंड |
| श्रृंखला एक दिशा में लिखें | सभी चिह्नों को > की दिशा में पलटकर लिखने से जाँच तेज़ होती है | A < B को B > A लिखें |
| Either-Or पहचान ट्रिक | दोनों निष्कर्ष असत्य + समान चर + पूरक चिह्न = तुरंत "या तो I या II" | 5 सेकंड में पहचान, पूरी गणना नहीं |
| Quantity प्रश्न में अनुमान | पूर्ण हल की जगह चिन्ह/मूल-क्रम से तुलना; 30 सेकंड की सीमा | द्विघात को पूरी तरह न हल करें, चिन्ह देखें |
| पहले आसान सेट | पेपर में पहले Direct, फिर Coded, अंत में Quantity-based | कठिन को अंत में चिह्नित करें |
| दोबारा जाँच का बजट | असमानता के 5 प्रश्नों के लिए कुल 3–4 मिनट; बचत का समय दुबारा जाँच में | Either-Or वाले प्रश्न अवश्य दुबारा देखें |

## भाग 3: गणितीय / तार्किक सूत्र

| सूत्र/प्रविधि | विवरण | उदाहरण |
|---|---|---|
| श्रृंखला संयोजन सूत्र | A (चिह्न₁) B (चिह्न₂) C में परिणाम = दोनों चिह्नों में सख्ततम; विपरीत दिशा ⇒ कोई संबंध नहीं | A ≥ B > C ⇒ A > C |
| पूरक चिह्न युग्म (Either-Or) | (>, ≤), (<, ≥), (=, ≠) | निष्कर्ष I: A > C, II: A ≤ C |
| द्विघात मूल-चिन्ह विधि | ax² + bx + c = 0 के मूलों के चिन्ह: c/a धनात्मक ⇒ समान चिन्ह; ऋणात्मक ⇒ विपरीत चिन्ह | x² − 5x + 6 = 0 ⇒ दोनों मूल धनात्मक |
| मूल-तुलना क्रम | x के मूल {x₁, x₂}, y के {y₁, y₂}; सभी x > सभी y ⇒ x > y; अन्यथा CND संभव | x ∈ {5, 6}, y ∈ {2, 3} ⇒ x > y |
| संभावना परीक्षण | निष्कर्ष निश्चित असत्य नहीं ⇒ संभावना सत्य | A > B < C से "A > C संभव है" सत्य |

**नोट:** इस अध्याय में कोई संख्यात्मक सूत्र (जैसे गति/कार्य के) नहीं होता; उपरोक्त तार्किक प्रविधियाँ ही इस अध्याय के "सूत्र" हैं।
