# Important Rules & Approaches — Classification (Odd One Out)

## Part 1: Key Rules/Approaches

| Rule Name | Description | Example |
|---|---|---|
| Identify the Group First | Find the common property shared by three (or more) items before judging the odd one. | Apple, Mango, Banana, Potato → three are fruits, Potato is a vegetable. |
| Check Multiple Criteria | Test each item against category, function, structure, origin, and properties — not just the first idea that comes to mind. | Rose, Lotus, Marigold, Lily → Lotus grows in water, others on land. |
| Category-Based Rule | Items belong to a class (animal, metal, planet, river); the odd one belongs to a different class. | Iron, Copper, Zinc, Wood → Wood is not a metal. |
| Function-Based Rule | Three items serve the same purpose; one serves a different purpose. | Pen, Pencil, Eraser, Marker → Eraser removes, others write. |
| Part–Whole Rule | Three are parts of the same whole; one is not. | Petal, Stem, Root, Brick → Brick is not a part of a plant. |
| Letter-Structure Rule (Word Classification) | Check vowel/consonant pattern, letter positions, or alphabetical gaps inside words. | ACE, GIK, MOQ, RTV → check gap patterns between letters. |
| Number-Property Rule | Test for prime, even/odd, perfect square/cube, divisibility, digit sum. | 121, 144, 169, 170 → 170 is not a perfect square. |
| Pair-Relationship Rule | In pair classification, three pairs share the same relation (synonym, tool–work, country–capital); one pair differs. | Doctor–Patient, Teacher–Student, Lawyer–Client, Pen–Paper → Pen–Paper has no service relation. |
| Degree/Intensity Rule | Three words show increasing or similar intensity; one breaks the scale. | Warm, Hot, Scorching, Cold → Cold is opposite in nature. |
| Gender/Opposite Rule | Three are masculine (or feminine); one is the opposite gender. | King, Prince, Queen, Duke → Queen is feminine. |
| Living/Non-living Rule | Three are living (or natural); one is non-living (or man-made). | Tree, River, Mountain, Car → Car is man-made. |
| Elimination Method | When unsure, eliminate options that clearly share a property; the leftover is the answer. | If three are clearly rivers, the fourth (a mountain) is odd. |
| Avoid Superficial Similarity | Do not classify by spelling, length, or first letter unless the chapter is word-based; meaning matters. | Bat (animal) vs Bat (sports) — classify by meaning in context. |
| Check All Options Before Answering | Sometimes two items look odd; pick the one where the other three share the strongest, most specific property. | Sparrow, Crow, Pigeon, Bat → Bat is a mammal (strongest rule: others are birds). |

## Part 2: Time Management

| Rule | Description | Action |
|---|---|---|
| 15-Second Rule | If the common property is not visible within 15 seconds, do not force it. | Mark the question and move on; return in the second pass. |
| 45-Second Rule | No classification question should take more than 45 seconds total, even on retry. | If still unsolved at 45 seconds, make an educated guess using elimination and skip. |
| First-Pass Strategy | Solve all direct category-based questions first (they take 10–15 sec each). | Builds speed and secures easy marks. |
| Second-Pass Strategy | Return to marked questions; try a different criterion (function instead of category). | A fresh angle often reveals the answer in seconds. |
| No-Overthinking Rule | Classification answers are usually based on one clear property, not rare GK. | If your answer needs obscure knowledge, re-check with a simpler rule. |

## Part 3: Logical/Mathematical Formulas

| Formula/Check | Description | Example |
|---|---|---|
| No fixed formulas for this chapter | Classification is rule-based, not formula-based. | — |
| Quick Number Checks (for number classification) | Prime test, perfect square (n²), perfect cube (n³), digit sum, divisibility by 3/9, even/odd. | 8, 27, 64, 100 → 100 is not a perfect cube. |
| Letter-Position Check (for letter/word classification) | Use alphabet positions (A=1 … Z=26) to check gaps or sums. | In "CFI": C=3, F=6, I=9 (gap of 3); a group breaking this gap is odd. |
