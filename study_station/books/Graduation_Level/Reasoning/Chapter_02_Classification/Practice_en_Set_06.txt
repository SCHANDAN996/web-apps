126. Four of the following five are alike in a certain way and form a group. Find the one that does not belong: 121, 144, 169, 225, 132
(a) 132 (b) 121 (c) 169 (d) 225
Answer: (a)
Solution: The tempting trap is to reject 121 because it is the smallest, but size is not the criterion. 121 = 11², 144 = 12², 169 = 13², 225 = 15² are all perfect squares, while 132 is not a perfect square, so the answer is 132.
Source: PYQ-style

127. Find the odd one out: 8, 27, 64, 100, 125
(a) 27 (b) 125 (c) 100 (d) 64
Answer: (c)
Solution: The trap is to pick 8 as the smallest number, but the real test is the cube property. 8 = 2³, 27 = 3³, 64 = 4³, 125 = 5³ are perfect cubes, whereas 100 is only a perfect square (10²), so the answer is 100.
Source: PYQ-style

128. Four letter-pairs follow the same rule; one does not. Find it: DF, HJ, LN, PR, UW
(a) LN (b) UW (c) PR (d) DF
Answer: (b)
Solution: The trap is that all five pairs look like "skip one letter" pairs, and indeed in each pair the second letter is 2 positions ahead of the first. The deeper rule is that DF, HJ, LN, PR start at positions 4, 8, 12, 16 (multiples of 4), while U starts at 21, which is not a multiple of 4, so the answer is UW.
Source: PYQ-style

129. Find the odd one out: 37, 41, 43, 47, 51
(a) 37 (b) 43 (c) 51 (d) 47
Answer: (c)
Solution: The trap is to choose 37 as the smallest or to assume all are primes. 37, 41, 43, 47 are all prime numbers, but 51 = 3 × 17 is composite, so the answer is 51.

133. Find the odd one out: 123, 234, 345, 456, 579

140. Find the odd one out: 63, 80, 99, 143, 168
(a) 99 (b) 168 (c) 143 (d) 63
Answer: (b)
Solution: The trap is to reject 143 as a three-digit number, but digit count is a decoy. 63 = 8²−1, 80 = 9²−1, 99 = 10²−1, 143 = 12²−1 are each one less than a perfect square, while 168 fits no such pattern, so the answer is 168.
Source: PYQ-style

142. Find the odd one out: 30, 42, 56, 72, 91

Source: PYQ-style
