┌─────────────────────────────────────────────┐
│ ट्रिक 1: "EJOTY" — पाँचों जादुई अंक          │
│ E=5, J=10, O=15, T=20, Y=25                  │
│ याद करें: "इज़्ज़त ओढ़ तन याद आए"            │
│ या English में: "Every Joker On TV Yells"    │
│ इन 5 अंकों से किसी भी अक्षर का स्थान ±1, ±2  │
│ करके तुरंत निकालें। जैसे R = T(20) − 2 = 18 │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 2: "CFILORUX" — पीछे से गिनती का जादू  │
│ इन अक्षरों का ऊपर से और नीचे से स्थान मिलकर  │
│ 27 बनाता है, और अंतर 3-3 का है:              │
│ C=3/24, F=6/21, I=9/18, L=12/15, O=15/12,   │
│ R=18/9, U=21/6, X=24/3                      │
│ याद करें: "सी फिल्मों रुक्स" — पीछे से पूछे  │
│ तो इन्हें सीधे उत्तर दें, बाकी 27−n से।      │
└─────────────────────────────────────────────┘

│ जोड़ा याद करें फ़िल्मी अंदाज़ में:            │
│ A-Z (आज़ाद), B-Y (बॉय), C-X (क्रिक्स),      │

│ H-S (एचएस), I-R (आईआर), J-Q (जेक्यू),      │
│ K-P (केपी), L-O (लो), M-N (मन)              │
│ याद करें: "AZad BoY, CriX, DeW, EV, FU, GT, │
│ HS, IR, JQ, KP, LO, MN"                     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 4: "बायाँ + बायाँ = जोड़ो" नियम        │
│ • बाएँ से nवाँ + बाएँ से mवाँ → n+m          │
│ • दाएँ से nवाँ + दाएँ से mवाँ → 27−(n+m)     │
│ • बाएँ n + दाएँ m → n + (27−m)               │
│ याद करें: "समान दिशा जुड़ती है, विपरीत 27    │
│ से उलटती है।"                                │
└─────────────────────────────────────────────┘

⏱️ समय नियम (Time Rules)

• सीधा स्थान/विपरीत अक्षर प्रश्न → 10–15 सेकंड में होना चाहिए।
• श्रृंखला प्रश्न → 20–30 सेकंड।
• शब्द-निर्माण / युग्म-गिनती प्रश्न → 45–60 सेकंड (ये समय खाते हैं)।

🚫 Skip Strategy — कब प्रश्न छोड़ें

1. **15 सेकंड में पैटर्न न दिखे तो छोड़ें।** श्रृंखला में अंतर लिखने के बाद भी नियम न बने, तो वह प्रश्न "दोहरी/तीसरी श्रृंखला" वाला है — इसमें 2 मिनट भी डूब सकते हैं। Mark करके आगे बढ़ें, अंत में लौटें।

2. **"कितने अर्थपूर्ण शब्द बन सकते हैं" वाला प्रश्न** अगर 30 सेकंड में 2 से ज़्यादा शब्द न मिलें, तो छोड़ दें — इसमें "2 से अधिक" विकल्प का जाल होता है और पक्का उत्तर बिना शब्दकोश के मुश्किल है। समय-कीमत सबसे खराब।

3. **युग्म-गिनती (letter pairs) प्रश्न में** अगर शब्द 10+ अक्षरों का हो, तो पहले बाकी पेपर निपटाएँ। गिनती में एक युग्म छूटने पर पूरा अंक जाता है — जोखिम ज़्यादा, लौटकर शांत मन से करें।
