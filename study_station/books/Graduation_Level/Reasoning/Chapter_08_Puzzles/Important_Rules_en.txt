IMPORTANT RULES & APPROACHES — PUZZLES (COMPLEX)

Part 1: Key Rules / Approaches

| Rule Name | Description | Example |
|---|---|---|
| Fix the Definite Clue First | Start with the clue that gives a fixed position or a direct fact; build the rest of the arrangement around it. | "A sits at the extreme left end" → place A first, then arrange the others relative to A. |
| Make a Table / Diagram | Convert every clue into a grid (person vs. attribute) or a seating sketch; never solve a complex puzzle in your head. | For 6 people × 3 attributes, draw a 6×3 grid and tick/cross the entries as each clue is used. |
| Negative Clues Are Gold | "X is not next to Y" or "P does not like red" eliminates possibilities — mark crosses immediately. | "B does not sit at any end" → B can only be in the non-end positions of the row. |
| Case-Based Approach | When a clue allows two possibilities, draw both cases separately; the case contradicted by a later clue is discarded. | In a circular puzzle where a person's facing is not yet fixed, "A is second to the left of B" gives two possible diagrams — draw both, then discard the one that breaks a later clue. |
| Link Clues Together | Combine two partial clues to make one strong deduction. | "The Engineer sits immediately to the right of the Teacher" (right as per the question's stated facing) fixes the pair Teacher–Engineer; "the Doctor sits to the left of the Engineer" then places the Doctor somewhere to the left of this pair. |
| Count Positions Carefully | In linear rows, fix the direction convention before placing anyone: left/right are taken from each person's own view when the question states a facing direction, and from the observer's view when the question says so. The question alone decides the convention — never assume it. | Question says "all persons are facing north" → "second to the left of B" is counted from B's own left. Question says "left/right as seen by the observer" → count from the observer's side. If the question defines neither, do not assume — let the complete set of clues and the options decide, or solve by cases. |
| Blood-Relation + Seating Hybrid | Decode the family tree first, then place the members in the arrangement. | Identify generations and genders from the relation clues before seating the members. |
| Floor/Box/Month Puzzles | Use a vertical stack (top to bottom) and fill the fixed floors/dates first. | "C lives on floor 3" → anchor C there, then place the others relative to this floor. |
| Elimination by Contradiction | Assume a possibility is true; if it violates any clue, reject it. | If placing P at position 2 forces Q into an impossible spot, P cannot be at position 2. |
| Verify the Final Arrangement | Re-read every clue once and check the final table against all of them. | One skipped clue is a very common cause of a wrong answer — the final check catches it. |

Part 2: Time Management

| Rule | Description |
|---|---|
| 15-Second Rule | Within 15 seconds of reading, decide the puzzle type (linear / circular / floor / box / comparison) and whether the first clue is definite. If the structure is not clear, mark the puzzle and move on. |
| 45-Second Rule | If no concrete placement is achieved within 45 seconds of starting the diagram, skip the puzzle and return after finishing the easier questions. |
| Set Selection | In many exams — especially bank exams — puzzle questions come in sets of 3–5 questions built on one arrangement. Attempt the set only if the master arrangement looks solvable; one correct table earns the marks of the whole set at once. |
| Attempt Order | Solve direct/standalone reasoning questions first; keep complex puzzle sets for the second round. |
| Time Cap | Spend at most about 3–4 minutes on one puzzle set; never let a single set consume the whole section. |
| Don't Guess Midway | An incomplete arrangement makes every linked answer risky — either complete the table or skip the whole set. |

Part 3: Logical / Mathematical Formulas

| Item | Detail |
|---|---|
| Formulas | No formulas for this chapter. Complex puzzles are solved purely by systematic tabulation, case elimination, and clue-linking — the diagram is the real tool. |
| Useful Counting Facts | Linear row of n persons: positions = n. Circular arrangement of n persons: (n−1)! distinct arrangements when rotations are treated as the same (for understanding only — exams need the diagram, not the count). |
