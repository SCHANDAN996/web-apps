IMPORTANT RULES & APPROACHES — PUZZLES (COMPLEX)

Part 1: Key Rules / Approaches

| Rule Name | Description | Example |
|---|---|---|
| Fix the Definite Clue First | Start with the clue that gives a fixed position or direct fact; build the rest around it. | "A sits at the extreme left end" → place A first, then arrange others. |
| Make a Table / Diagram | Convert every clue into a grid (person vs. attribute) or a seating sketch; never solve in your head. | For 6 people × 3 attributes, draw a 6×3 grid and tick/cross entries. |
| Negative Clues Are Gold | "X is not next to Y" or "P does not like red" eliminates options — mark crosses immediately. | "B does not sit at any end" → B can only be in middle positions. |
| Case-Based Approach | When a clue allows 2 possibilities, draw both cases; the case that contradicts a later clue is discarded. | Circular seating with unknown facing: try Case 1 and Case 2, eliminate one. |
| Link Clues Together | Combine two partial clues to make one strong deduction. | "Engineer is immediate right of Teacher" fixes the pair Teacher–Engineer; "Doctor is left of Engineer" then places Doctor somewhere to the left of this pair. |
| Count Positions Carefully | In linear rows, fix direction (left/right from viewer or from person) before placing anyone. | In a north-facing row, "left of A" means viewer's right. |
| Blood-Relation + Seating Hybrid | Decode the family tree first, then place members in the arrangement. | Identify who is male/female and generation before seating them. |
| Floor/Box/Month Puzzles | Use a vertical stack (top to bottom) and fill fixed floors/dates first. | "C lives on floor 3" → anchor; then place others relative to it. |
| Elimination by Contradiction | Assume an option is true; if it violates any clue, reject it. | If placing P at position 2 forces Q to an impossible spot, P ≠ 2. |
| Verify the Final Arrangement | Re-read every clue once and check the final table against all of them. | One unchecked clue is the most common cause of a wrong answer. |

Part 2: Time Management

| Rule | Description |
|---|---|
| 15-Second Rule | Within 15 seconds of reading, decide the puzzle type (linear / circular / floor / box / comparison) and whether the first clue is definite. If the structure is not clear, mark it and move on. |
| 45-Second Rule | If no concrete placement is achieved within 45 seconds of starting the diagram, skip the puzzle and return after finishing easier questions. |
| Set Selection | In exams, puzzles come in sets of 3–5 questions on one arrangement. Attempt the set only if the master arrangement is solvable; one correct table gives 3–5 marks at once. |
| Attempt Order | Solve direct/standalone reasoning questions first; keep complex puzzle sets for the second round. |
| Time Cap | Maximum 3–4 minutes per puzzle set (5 questions). Never let one puzzle consume the whole section. |
| Don't Guess Midway | An incomplete arrangement means all linked answers are risky — either complete the table or skip the whole set. |

Part 3: Logical / Mathematical Formulas

| Item | Detail |
|---|---|
| Formulas | No formulas for this chapter. Complex puzzles are solved purely by systematic tabulation, case elimination, and clue-linking. |
| Useful Counting Facts | Linear row of n persons: positions = n. Circular arrangement of n persons: relative arrangements = (n−1)! (for understanding only — exams need the diagram, not the count). |
