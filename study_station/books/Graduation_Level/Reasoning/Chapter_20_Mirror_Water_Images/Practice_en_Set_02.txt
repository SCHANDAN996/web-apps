Questions 26–50: Medium

26. A clock shows 4:30. What time will its image in a plane mirror show?
(a) 8:30 (b) 4:30 (c) 6:30 (d) 7:30
Answer: (d)
Solution: The trap is 8:30, obtained by subtracting 4:30 from 12:00 without borrowing. The correct rule is to subtract from 11:60: 11:60 − 4:30 = 7:30, so the answer is 7:30.
Source: PYQ-style

27. If the mirror image of a clock shows 3:45, what is the actual time?
(a) 9:15 (b) 8:15 (c) 8:45 (d) 3:15
Answer: (b)
Solution: The tempting wrong option is 8:45, which subtracts only the hour and keeps the minutes unchanged. Subtracting properly: 11:60 − 3:45 = 8:15, so the answer is 8:15.

Answer: (a)
Solution: The tempting wrong option is "to the left", which applies side-mirror logic to a water image. At 3:00 the minute hand points up to 12, and a water image flips the clock top-to-bottom, so the answer is straight down.

36. Which of the following capital letters looks the same in a mirror placed on its right?
(a) A (b) L (c) B (d) R
Answer: (a)
Solution: The trap is B, which is symmetric top-to-bottom, not left-to-right. Only letters with vertical symmetry, such as A, H, I, M, O, T, U, V, W, X, Y, survive a side mirror, so the answer is A.

38. Which of these words will read exactly the same in a mirror placed on its right?
(a) BIB (b) DAD (c) POP (d) TOT
Answer: (d)
Solution: The trap is DAD — it is a palindrome, but the letter D is not laterally symmetric, so it flips in a mirror. A word survives a side mirror only if it is a palindrome and every letter has vertical symmetry; T, O and T all qualify, so the answer is TOT.

39. The mirror image of the lowercase letter "b" in a side mirror is:

Answer: (c)

Answer: (b)
