# Important Rules & Approaches — Mirror & Water Images

## Part 1: Key Rules / Approaches

| Rule Name | Description | Example |
|---|---|---|
| Lateral Inversion (Mirror Rule) | In a mirror image, left and right sides interchange; top and bottom remain unchanged. | Letter **b** appears as **d** in a mirror. |
| Vertical Mirror (Right/Left side) | Mirror placed on the right or left of the object → image flips horizontally. | **P** facing right appears facing left. |
| Horizontal Mirror (Top/Bottom) | Mirror placed above or below the object → image flips vertically (behaves like a water image). | **M** becomes **W**-like shape. |
| Water Image Rule | In a water image, top and bottom interchange; left and right remain unchanged. | Letter **M** appears as **W** in water. |
| Symmetric Letters (Mirror) | Letters A, H, I, M, O, T, U, V, W, X, Y look the same in a vertical mirror. | **H** → **H** (unchanged). |
| Symmetric Letters (Water) | Letters B, C, D, E, H, I, K, O, X look the same in a water image (capital forms). | **C** → **C** (unchanged). |
| Numbers in Mirror | Digits 0, 1, 8 look the same in a vertical mirror; others reverse shape. | **3** appears as a reversed 3 (like Ɛ). |
| Numbers in Water | Digits 0, 3, 8 look the same in water image; others flip vertically. | **6** appears as an inverted 6. |
| Clock in Mirror | Mirror time = 11:60 − actual time (or 12:00 − time, adjusting minutes). | Actual 4:30 → Mirror 7:30. |
| Clock in Water | Water time = 18:30 − actual time; use 17:90 instead when actual minutes exceed 30 (to allow borrowing). | Actual 4:30 → Water 14:00 → 2:00. |
| Order Reversal Rule | In a mirror image of a word/number, the sequence of characters reverses (rightmost comes first). | **RAM** in mirror → reversed order with each letter laterally inverted. |
| Order Same Rule (Water) | In a water image, the sequence stays the same; only each character flips vertically. | **BOX** in water → same order, each letter flipped top-bottom. |
| Arrow Direction Rule | Mirror: arrow pointing right points left (up/down unchanged). Water: arrow pointing up points down (left/right unchanged). | → becomes ← in mirror; ↑ becomes ↓ in water. |
| Elimination Approach | Check one distinctive feature (a curve, dot, or slant) in options and eliminate mismatches first. | A dot on top-left must shift to top-right in mirror — reject options that don't. |
| Fold-and-Trace Approach | Mentally fold the page along the mirror line; the overlapping figure is the answer. | Mirror line on right → fold rightward. |

## Part 2: Time Management

| Situation | Rule | Action |
|---|---|---|
| Simple letter/number image | 15-second rule | If the correct flip is not clear within 15 seconds, mark and skip; return later. |
| Word/figure with 4+ elements | 45-second rule | Spend at most 45 seconds; check only 1–2 distinctive features, eliminate options, and pick. |
| Clock-based mirror/water question | Formula first | Apply 11:60 / 18:30 subtraction directly — do not draw the clock. |
| Confusing similar options | Feature check | Compare one unique detail (dot, tail, slant) instead of the whole figure. |
| Overall exam strategy | Priority rule | Attempt mirror/water questions early in the reasoning section — they are quick scorers if the rules are memorized. |

## Part 3: Logical / Mathematical Formulas

| Formula | Use | Example |
|---|---|---|
| Mirror time = 11:60 − Actual time | Clock mirror image | 11:60 − 4:30 = 7:30 |
| Mirror time = 12:00 − Actual time | When actual time has 00 minutes | 12:00 − 9:00 = 3:00 |
| Water time = 18:30 − Actual time | Clock water image | 18:30 − 4:30 = 14:00 → 2:00 |
| Water time = 17:90 − Actual time | When actual minutes > 30 (borrowing needed) | 17:90 − 4:45 = 13:45 → 1:45 |
| No other formulas for this chapter | All other questions are solved by visual flip rules (lateral/vertical inversion). | — |
