Questions 51–75: Medium

51. In a certain code, "MASTER" is written as "NZHUVI". How is "DOCTOR" written in that code?
(a) WKXGLI (b) WLXGRI (c) WLXHLI (d) WLXGLI
Answer: (d)
Solution: The trap is to shift letters by a fixed number; here each letter is replaced by its reverse-position letter (A↔Z, B↔Y, …). M→N, A→Z, S→H, T→G, E→V, R→I gives NZHUVI, and D→W, O→L, C→X, T→G, O→L, R→I, so the answer is WLXGLI.
Source: PYQ-style

52. In a code, "PENCIL" is written as "RGPENK". How will "ERASER" be written?
(a) GTCVGT (b) GTCUGT (c) FTCUGT (d) GTCUGS
Answer: (b)
Solution: Each letter is shifted +2: P→R, E→G, N→P, C→E, I→K, L→N. The trap is shifting only some letters or using +1. For ERASER: E→G, R→T, A→C, S→U, E→G, R→T, so the answer is GTCUGT.
Source: PYQ-style

53. If "DELHI" is coded as "73541" and "CALCUTTA" as "82589662", how will "CALICUT" be coded?
(a) 8251896 (b) 8251968 (c) 8258196 (d) 8521896
Answer: (a)
Solution: Map letters from CALCUTTA = 82589662: C=8, A=2, L=5, I=1, U=9, T=6. The trap is misreading the repeated C in the middle of CALICUT. CALICUT = C-A-L-I-C-U-T = 8-2-5-1-8-9-6, so the answer is 8251896.
Source: PYQ-style

56. If "ROSE" is coded as "6821", "CHAIR" as "73456" and "PREACH" as "961473", what is the code for "SEARCH"?
(a) 246173 (b) 216473 (c) 214763 (d) 214673
Answer: (d)
Solution: From ROSE: R=6, O=8, S=2, E=1; from CHAIR: C=7, H=3, A=4. The trap is swapping the digits of A and R. SEARCH = S-E-A-R-C-H = 2-1-4-6-7-3, so the answer is 214673.
Source: PYQ-style

57. In a certain code, "MONKEY" is written as "XDJMNL". How is "TIGER" written in that code?
(a) SHFDQ (b) QDFHS (c) QDHFS (d) QFDHS
Answer: (b)
Solution: The word is reversed and each letter shifted −1: MONKEY reversed is YEKNOM, and Y−1=X, E−1=D, K−1=J, N−1=M, O−1=N, M−1=L. The trap is shifting without reversing. For TIGER reversed = REGIT: R−1=Q, E−1=D, G−1=F, I−1=H, T−1=S, so the answer is QDFHS.
Source: PYQ-style

58. If A = 1, B = 2, …, Z = 26, and the code of a word is the sum of its letters' values, what is the code of "CAB"?
(a) 6 (b) 5 (c) 7 (d) 8
Answer: (a)
Solution: The trap is counting letters instead of adding values. C=3, A=1, B=2, and 3+1+2 = 6, so the answer is 6.

60. In a certain code, "123" means "hot filtered coffee", "356" means "very hot day" and "589" means "day and night". Which digit stands for "very"?
(a) 5 (b) 3 (c) 6 (d) 9
Answer: (c)
Solution: "hot" is common to the first two codes, so 3 = hot; "day" is common to the last two, so 5 = day. The trap is picking 5, which actually stands for "day". In "356" = "very hot day", removing 3 and 5 leaves 6, so the answer is 6.
Source: PYQ-style
