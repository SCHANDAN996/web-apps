101. In a certain code, "MASTER" is written as "NBTUFS". How is "PLANET" written in that code?
(a) QMAOFU (b) QMBNFU (c) QNBOFU (d) QMBOFU
Answer: (d)
Solution: The tempting option QMBNFU wrongly shifts N to B instead of O. Each letter moves one step forward: M→N, A→B, S→T, T→U, E→F, R→S, so PLANET becomes P→Q, L→M, A→B, N→O, E→F, T→U, so the answer is QMBOFU.
Source: PYQ-style

107. In a certain code, "MONKEY" is written as "XDJMNL". How is "TIGER" written?
(a) QDFHS (b) QDFHR (c) QDGHS (d) QEFHS
Answer: (a)
Solution: The tempting option QDFHR shifts the last letter by two steps instead of one. The rule is: reverse the word, then shift each letter one step back — MONKEY reversed is YEKNOM, and −1 each gives XDJMNL. For TIGER: reversed REGIT, then −1 each gives R→Q, E→D, G→F, I→H, T→S, so the answer is QDFHS.
Source: PYQ-style
