**ट्रिक 1: "EJOTY" — अक्षरों का रोल नंबर**
```
┌─────────────────────────────────────────────┐
│ E J O T Y                                   │
│ 5 10 15 20 25                               │
│ याद करो: "EJOTY" — पाँच अंक के पड़ाव!       │
│ बाकी अक्षर इनसे ±1, ±2 करके निकालो।         │
│ जैसे N = O(15) − 1 = 14 ✔                   │
└─────────────────────────────────────────────┘
```

**ट्रिक 2: "उल्टा जोड़ा 27" — Opposite Letters**
```
┌─────────────────────────────────────────────┐
│ A↔Z, B↔Y, C↔X … योग हमेशा 27!               │
│ याद करो: "AZad, BoY, CruX, DWarF, EVen,     │
│  GT, HS, IRon, JQ, KP, LOve, MN"            │
│ कोड में अक्षर दिखे और योग 27 बने →          │
│ समझो Opposite-letter coding है।             │
└─────────────────────────────────────────────┘
```

**ट्रिक 3: "पहले जोड़ो, फिर घटाओ" — Shift पहचान**
```
┌─────────────────────────────────────────────┐
│ CAT → FDW? C+3=F, A+3=D, T+3=W → uniform +3 │
│ CAT → FDY? C+3=F, A+3=D, T+5=Y → अलग-अलग!   │
│ नियम: पहले अक्षर का shift निकालो, दूसरे पर   │
│ लगाओ। मेल खाए → uniform; न खाए → pattern    │
│ बदलो (वर्णमाला क्रम / vowel-consonant अलग)। │
└─────────────────────────────────────────────┘
```

**ट्रिक 4: "Vowel की अलग पार्टी"**
```
┌─────────────────────────────────────────────┐
│ अगर uniform shift न बने, तो जाँचो:          │
│ क्या स्वर (A,E,I,O,U) अलग नियम से बदले हैं? │
│ जैसे: व्यंजन +2, स्वर −1                     │
│ मिश्र-कोडिंग में यही जाल अक्सर होता है!      │
└─────────────────────────────────────────────┘
```

**ट्रिक 5: "आधा-आधा पलट" — Reversal Coding**
```
┌─────────────────────────────────────────────┐
│ MASTER → RETSAM? पूरा उल्टा!                │
│ MASTER → SAMRET? आधा-आधा उल्टा (MAS|TER     │
│ → SAM|RET)।                                 │
│ कोड में वही अक्षर, नए नहीं → 100%           │
│ rearrangement है। Shift मत लगाना!           │
└─────────────────────────────────────────────┘
```

**ट्रिक 6: "गिनती = संख्या" — Number Coding**
```
┌─────────────────────────────────────────────┐
│ PEN → 35? P=16,E=5,N=14 → 16+5+14 = 35 ✔    │
│ PEN → 7? अक्षरों की गिनती × कुछ? 3 अक्षर…   │
│ संख्या-कोडिंग में पहले योग जोड़कर देखो,     │
│ फिर गुणा/वर्ग/अंकों का योग (digit sum)।     │
└─────────────────────────────────────────────┘
```

**ट्रिक 7: "Digit Sum — 9 का खेल"**
```
┌─────────────────────────────────────────────┐
│ बड़ी संख्या आए तो अंक जोड़ते जाओ:           │
│ 35 → 3+5 = 8। कई बार कोड = digit sum होता है│
│ 9 का भाग देकर शेषफल भी यही देता है!         │
└─────────────────────────────────────────────┘
```

**ट्रिक 8: "आमने-सामने वाला शब्द पकड़ो" — Sentence Coding**
```
┌─────────────────────────────────────────────┐
│ "ram is good" = "ta pa sa"                  │
│ "is very good" = "pa la sa"                 │
│ दोनों में common: "is good" ↔ "pa sa"       │
│ नियम: दो वाक्यों में जो शब्द common,        │
│ कोड में भी जो common — वही जोड़ी!           │
│ एक-एक करके हटाओ (elimination), बाकी अपने आप │
└─────────────────────────────────────────────┘
```

**ट्रिक 9: "नया शब्द = नया कोड"**
```
┌─────────────────────────────────────────────┐
│ Sentence coding में पूछा गया शब्द अगर       │
│ किसी वाक्य में नहीं दिखा → उसका कोड वही     │
│ होगा जो किसी से match नहीं हुआ।             │
│ "निर्धारित नहीं किया जा सकता" विकल्प भी     │
│ तभी चुनो जब 2+ कोड बचे हों!                 │
└─────────────────────────────────────────────┘
```

**ट्रिक 10: "घड़ी की दिशा में कुर्सी" — Symbol Coding**

## 🚦 Skip Strategy — कब प्रश्न छोड़ें

**⏱ 15-सेकंड नियम:**
पहले 15 सेकंड में केवल पैटर्न पहचानो — uniform shift? opposite? reversal? common-word? अगर इनमें से कोई न बने, तो प्रश्न को **mark करके आगे बढ़ो**। अंत में समय बचे तो लौटो। एक coding प्रश्न 1 अंक का है, उस पर 2 मिनट देना = 4 आसान प्रश्नों का नुकसान।

**🚫 कब तुरंत छोड़ें:**
- **3+ शर्तों वाली conditional coding** जिसमें हर अक्षर पर अलग नियम — गलती की संभावना बहुत ज़्यादा, negative marking में घाटा।
- **ऐसी sentence coding जहाँ 4+ वाक्य हों और common शब्द 1 भी न दिखे** — बिना anchor के केवल अनुमान है।
- **बढ़ते-shift (+1,+2,+3…) वाले प्रश्न** जहाँ 5+ अक्षर हों — गणना लंबी, विकल्प मिलते-जुलते; पहले बाकी पेपर निपटाओ।

**✅ कब ज़रूर करें:**
- Uniform shift, opposite-letter (योग 27), reversal, और 2-वाक्य वाली sentence coding — ये 30 सेकंड के अंदर पक्के अंक हैं। इन्हें कभी मत छोड़ो।
