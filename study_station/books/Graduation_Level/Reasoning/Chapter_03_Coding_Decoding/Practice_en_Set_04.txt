76. In a certain code, "MASTER" is written as "OCUVGT". How is "PLANET" written in that code?
(a) QMBMFU (b) RNCQGV (c) RNCPGV (d) RNCPGU
Answer: (c)
Solution: Each letter moves +2: M→O, A→C, S→U, T→V, E→G, R→T. The tempting option RNCQGV wrongly shifts the second letter by +3 instead of +2. Applying +2 to PLANET: P→R, L→N, A→C, N→P, E→G, T→V, so the answer is RNCPGV.
Source: PYQ-style

77. In a code, "TIGER" is written as "GRTVI". How is "LION" written in that code?
(a) ORLM (b) MROL (c) NROL (d) OMLR
Answer: (a)
Solution: Each letter is replaced by its reverse-position letter (A↔Z, B↔Y, …): T→G, I→R, G→T, E→V, R→I. The trap option MROL reverses the letter order of the correct code, which the rule does not do. For LION: L→O, I→R, O→L, N→M, so the answer is ORLM.
