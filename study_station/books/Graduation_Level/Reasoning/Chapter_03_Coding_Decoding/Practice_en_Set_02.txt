26. In a certain code language, "MANGO" is written as "OCPIQ". How will "APPLE" be written in the same code?
(a) CRRNG (b) DSSOH (c) ZOOKD (d) BQQMF
Answer: (a)
Solution: The tempting wrong option BQQMF comes from shifting every letter by only +1, but here each letter moves +2: M→O, A→C, N→P, G→I, O→Q. Applying +2 to APPLE: A→C, P→R, P→R, L→N, E→G, so the answer is CRRNG.
Source: PYQ-style (SSC CGL pattern)

27. If "TEACHER" is coded as "VGCEJGT", how is "STUDENT" coded?

Source: PYQ-style (Banking pattern)

28. In a code, "DOG" = 26 and "CAT" = 24. What is the code for "COW"?

Solution: The trap is to count letters or use reverse positions. The rule is sum of alphabetical positions: D(4)+O(15)+G(7)=26; C(3)+A(1)+T(20)=24. For COW: C(3)+O(15)+W(23)=41, so the answer is 41.
Source: PYQ-style (SSC CHSL pattern)
