# कोडिंग-डिकोडिंग (उन्नत) — महत्वपूर्ण नियम एवं दृष्टिकोण

## 1. मुख्य नियम / दृष्टिकोण

| नियम का नाम | विवरण | उदाहरण |
|---|---|---|
| स्थान-मान (Place Value) नियम | A=1, B=2 … Z=26; विपरीत क्रम Z=1, A=26 भी याद रखें | C = 3, X = 24 |
| विपरीत अक्षर (Opposite Letter) नियम | दो अक्षरों के स्थान-मानों का योग 27 हो तो वे विपरीत हैं (A↔Z, B↔Y, C↔X…) | M का विपरीत N (13+14=27) |
| Shift/अंतर नियम | प्रत्येक अक्षर में समान संख्या जोड़ी/घटाई जाती है (+1, −2 आदि) | CAT → DBU (प्रत्येक में +1) |
| बढ़ता/घटता अंतर नियम | अंतर क्रमशः बढ़ता या घटता है (+1, +2, +3…) | A→B (+1), B→D (+2), D→G (+3) |
| अक्षर-व्यवस्था (Rearrangement) नियम | अक्षरों का क्रम बदल दिया जाता है — उल्टा, आधा-आधा, जोड़ों में | TABLE → ELBAT (पूर्ण उलट) |
| अक्षर + अंक मिश्रित कोड | शब्द के अक्षरों के स्थान-मानों का योग/गुणन/अंतर अंक बनता है | DOG = 4+15+7 = 26 |
| स्वर-व्यंजन अलग नियम | स्वरों और व्यंजनों पर अलग-अलग ऑपरेशन लागू होते हैं | स्वर +1, व्यंजन −1 |
| वाक्य-कोडिंग (Sentence Coding) | कई वाक्यों की तुलना कर common शब्द ↔ common कोड मिलाएँ | "ram is good" = "ta pa sa" प्रकार |
| प्रतीक-कोडिंग (Symbol Coding) | अक्षरों के स्थान पर प्रतीक/अंक; शर्तें (conditions) दी होती हैं | अक्षर स्वर है तो @, वरना # |
| नई प्रतीक-परिभाषा (New Symbol) | @, #, $ आदि को +, −, ×, ÷ मानकर हल करें | A @ B = A + B |
| अंक-अक्षर प्रतिस्थापन | अंकों को अक्षरों से या अक्षरों को अंकों से बदलना | 1=A, 2=B… या कोड-तालिका दी हो |
| जोड़ी-विनिमय (Pair Swap) | पहला↔दूसरा, तीसरा↔चौथा अक्षर आपस में बदलते हैं | PART → APTR (P↔A, R↔T) |
| आधा-विभाजन नियम | शब्द को दो भागों में बाँटकर प्रत्येक भाग को उलटना/बदलना | MASTER → MAS\|TER → SAM\|RET → SAMRET |
| EJOTY त्वरित स्मरण | E=5, J=10, O=15, T=20, Y=25 — स्थान-मान शीघ्र निकालने हेतु | T के बाद U=21, V=22… |
| पहले-अंतिम अक्षर जाँच | विकल्पों में पहला/अंतिम अक्षर मिलाकर गलत विकल्प जल्दी काटें | कोड का पहला अक्षर D है → (a),(c) हटाएँ |
| नकारात्मक वाक्य सावधानी | "कौन-सा कोड नहीं हो सकता" जैसे प्रश्नों में उत्तर उल्टा चुनना होता है | NOT/EXCEPT वाले प्रश्न दो बार पढ़ें |

## 2. समय प्रबंधन

| नियम | विवरण |
|---|---|
| 15-सेकंड नियम | Shift/Rearrangement प्रश्न का पैटर्न 15 सेकंड में न दिखे तो चिह्नित कर आगे बढ़ें; अंत में लौटें |
| 45-सेकंड नियम | वाक्य-कोडिंग/शर्त-आधारित प्रतीक-कोडिंग जैसे लंबे प्रश्नों को अधिकतम 45 सेकंड दें; उससे अधिक लगे तो छोड़ दें |
| पहले स्थान-मान लिखें | प्रश्न देखते ही अक्षरों के स्थान-मान ऊपर लिख लें — पैटर्न तुरंत दिखता है |
| विकल्प-उन्मूलन | पूरा कोड बनाने से पहले 1–2 अक्षर से विकल्प काटें — समय बचता है |
| कठिन पहचान | 3+ शब्दों वाली वाक्य-कोडिंग या दोहरी शर्त वाली प्रतीक-कोडिंग को दूसरे चरण में रखें |

## 3. गणितीय / तार्किक सूत्र

| सूत्र | प्रयोग |
|---|---|
| विपरीत अक्षर का स्थान-मान = 27 − अक्षर का स्थान-मान | M (13) का विपरीत = 27−13 = 14 = N |
| शब्द का कोड-योग = Σ (अक्षरों के स्थान-मान) | CAB = 3+1+2 = 6 |
| n-वाँ अक्षर आगे = (स्थान-मान + n); 26 से अधिक हो तो 26 घटाएँ (चक्रीय) | Z(26) + 2 = 28 − 26 = 2 = B |
| n-वाँ अक्षर पीछे = (स्थान-मान − n); 1 से कम हो तो 26 जोड़ें | A(1) − 2 = −1 + 26 = 25 = Y |

इस अध्याय में उपरोक्त के अतिरिक्त कोई अन्य सूत्र प्रयोग नहीं होता।
