1. In a certain code language, "TIGER" is written as "UJHFS". How will "LION" be written in that code?
(a) MJPN (b) MJOP (c) NKPO (d) MJPO
Answer: (d)
Solution: Each letter is shifted one step forward: T→U, I→J, G→H, E→F, R→S. The tempting option MJOP swaps the last two letters, a common slip. Applying +1 to LION gives M, J, P, O, so the answer is MJPO.
Source: PYQ-style

2. If "CAT" is coded as "3120" (C=3, A=1, T=20), how is "DOG" coded?
(a) 5147 (b) 4156 (c) 4167 (d) 4157
Answer: (d)
Solution: Each letter is replaced by its position in the alphabet: D=4, O=15, G=7. The tempting option 4156 wrongly takes G as 6. So the code is 4157, and the answer is 4157.

4. If "ROSE" is coded as "6821" and "SORE" is coded as "2861", what is the code for "O"?
(a) 1 (b) 2 (c) 8 (d) 6
Answer: (c)
Solution: Comparing both words, R, S and E keep the same digits, so R=6, S=2, E=1, leaving O=8. The tempting option 6 is actually the code for R. Checking SORE: S=2, O=8, R=6, E=1 confirms it, so the answer is 8.

9. In a certain code, "5 3 7" means "sky is blue", "7 2 9" means "blue and green", and "3 9 4" means "is very green". What is the code for "green"?
(a) 9 (b) 3 (c) 7 (d) 2
Answer: (a)
Solution: "Blue" is common to the first two sentences, so blue = 7; "is" is common to the first and third, so is = 3. The tempting option 2 actually codes "and". "Green" is common to the second and third sentences, so the answer is 9.

23. If "MACHINE" is coded as "LBBIHOD", how is "ENGINE" coded? (Examiner's trap: mixed forward and backward shifts.)

Solution: Checking the given word: M→L (−1), A→B (+1), C→B (−1), H→I (+1), I→H (−1), N→O (+1), E→D (−1), so odd positions shift −1 and even positions shift +1. The tempting option FOHKPG comes from a uniform +1 shift. Applying the pattern to ENGINE gives D, O, F, J, M, F, so the answer is DOFJMF.
Source: PYQ-style

24. In a certain code, "PAPER" is written as "QZQFS". How will "RULER" be written? (Examiner's trap: one letter behaves differently.)

Answer: (b)
Solution: Checking the given word: P→Q (+1), A→Z (wrap-around backward), P→Q (+1), E→F (+1), R→S (+1); every letter moves +1 except A, which wraps backward to Z. The tempting option SVMFR forgets to shift the last letter. RULER has no A, so all letters move +1: S, V, M, F, S, so the answer is SVMFS.
Source: PYQ-style
