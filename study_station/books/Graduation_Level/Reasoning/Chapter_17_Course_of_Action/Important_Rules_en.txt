# Important Rules & Approaches — Statement & Course of Action

## Part 1: Key Rules / Approaches

| Rule Name | Description | Example |
|---|---|---|
| Problem–Solution Link | A course of action (COA) is valid only if it directly addresses the problem stated in the statement. | Statement: "Road accidents are rising due to drunk driving." → Valid COA: "Strict checking and heavy fines for drunk drivers." |
| Practicality Test | The COA must be practically and legally implementable; reject extreme, impossible, or unconstitutional actions. | "Ban all vehicles" for pollution → Invalid (impractical). |
| Positive Action Rule | Valid COAs are constructive and solution-oriented; reject actions based on revenge, panic, or blame. | "Punish all officials immediately" → Invalid; "Set up an inquiry committee" → Valid. |
| No Assumption Rule | Do not assume facts beyond the statement; judge the COA only on what is given. | Statement says "water shortage in city X" — do not assume corruption is the cause. |
| Authority–Responsibility Match | The COA must fall within the powers of the authority expected to act (government, court, police, etc.). | "Citizens should amend the law" → Invalid (only legislature can). |
| Root-Cause vs Symptom | Prefer COAs that tackle the root cause over those that only suppress symptoms. | For repeated flooding: "Improve drainage system" (root) > "Distribute relief" (symptom). |
| Both-Actions Rule | "Both follow" is correct only when each COA independently solves the problem; they must not contradict each other. | "Increase buses" and "Improve metro frequency" → Both can follow. |
| Either–Or Rule | "Either I or II follows" applies when both COAs target the same problem but are mutually exclusive. | "Shift the factory out of the city" vs "Install pollution filters in the factory" → Either–Or. |
| Extreme-Word Filter | COAs containing "all", "never", "immediately dismiss", "ban everything" are usually invalid. | "Ban all private hospitals" → Invalid. |
| Long-Term + Short-Term Check | A strong answer often combines immediate relief with a long-term preventive measure. | Flood: "Rescue operations" (short-term) + "Build embankments" (long-term). |
| Fact vs Opinion Check | If the statement is merely an opinion or suggestion, a COA does not follow; COAs follow from problems, not views. | "People should exercise daily" → No COA needed. |
| Precedent/Experience Rule | A COA that has worked in similar situations and is logically sound is acceptable even if not mentioned anywhere. | "Adopt rainwater harvesting, as done successfully in other states." |

## Part 2: Time Management

| Situation | Time Rule | Action |
|---|---|---|
| Statement read, problem clear, COAs obviously linked | 15-second rule | Mark the answer immediately; do not re-read. |
| Problem identified but COAs need practicality/legal check | 45-second rule | Invest up to 45 seconds; apply the filters (practicality, authority, extreme words). |
| Statement confusing or COAs look equally strong after 45 sec | Skip rule | Mark for review and move on; return only after finishing the section. |
| "Both follow" temptation | 10-second check | Verify each COA independently solves the problem before choosing "both". |
| Either–Or confusion | 10-second check | Confirm the two COAs are mutually exclusive; if both can coexist, "either–or" is wrong. |
