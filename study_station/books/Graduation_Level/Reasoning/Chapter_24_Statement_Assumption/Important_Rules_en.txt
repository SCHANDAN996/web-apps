# Important Rules & Approaches — Statement & Assumption

## Part 1: Key Rules / Approaches

| Rule Name | Description | Example |
|---|---|---|
| Implicit Test | An assumption is valid only if it is hidden (implied) in the statement, not directly stated. | Statement: "Buy X soap for glowing skin." → Assumption "X soap is available in the market" is implicit (valid). |
| Speaker's Intention Rule | Judge the assumption from the speaker's point of view, not from general truth or your own opinion. | Even if a belief is false in reality, if the speaker must believe it to say the statement, it is implicit. |
| Negative Word Caution | Words like "not", "never", "no" in an assumption usually make it invalid, unless the statement itself is negative. | Statement: "Join our coaching to pass." → Assumption "You cannot pass without coaching" is too extreme (invalid). |
| Extreme Word Rejection | Assumptions with "all", "only", "always", "none", "every" are generally invalid. | "Only Brand A can clean clothes" — rejected due to "only". |
| Restatement Trap | An assumption that merely repeats the statement in different words is NOT an assumption. | Statement: "Pollution is rising." → "Pollution is increasing day by day" is a restatement (invalid). |
| Advertisement/Notice Rule | For ads, appeals and notices, assumptions about (a) people reading it and (b) people responding to it are usually implicit. | Ad: "Enroll for yoga classes." → "People will read the ad" and "Some will enroll" are valid. |
| Suggestion/Advice Rule | When advice is given, it is assumed that (a) the problem exists and (b) the advice can be followed. | "Take medicine M for fever." → Assumes M is available and effective. |
| Cause–Effect Check | The assumption must be a root cause behind the statement, not a result or conclusion of it. | Do not confuse assumption (what the speaker believed before speaking) with conclusion (what follows after). |
| "Only I / Only II / Both / Neither" Format | Evaluate each assumption independently first, then match with the option. | Mark I: valid/invalid, II: valid/invalid → then choose (a)/(b)/(c)/(d). |
| Government/Policy Statement Rule | For official announcements, assumptions about feasibility and public acceptance are usually implicit. | "Government launches scheme S." → Assumes scheme can be implemented. |

## Part 2: Time Management

| Situation | Time Rule | Action |
|---|---|---|
| Simple statement (ad, notice, advice) | 15-second rule | If the implicit assumption is not clear within 15 seconds, mark the most likely option and move on. |
| Complex/abstract statement (philosophical, policy-based) | 45-second rule | Give maximum 45 seconds: read statement once, test each assumption with the implicit test, then decide. |
| Both assumptions seem valid | 45-second rule | Re-check for extreme words ("only", "all"); the milder assumption is usually correct. |
| Neither assumption seems valid | 15-second rule | Re-read once; if still unclear, choose "neither" and skip — do not overthink. |
| Full set strategy | — | Attempt direct ad/notice questions first; leave abstract statement questions for the end. |
