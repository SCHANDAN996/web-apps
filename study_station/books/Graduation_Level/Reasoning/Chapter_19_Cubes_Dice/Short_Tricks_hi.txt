🪄 शॉर्ट ट्रिक्स + Skip Strategy — घन-पासा (Cubes & Dice)

═══════════════════════════════════
🧠 म्नेमोनिक ट्रिक्स (Memory Tricks)
═══════════════════════════════════

┌─────────────────────────────────┐
│ ट्रिक 1: "सात का सच"              │
│ मानक पासे की अम्मुखी (opposite)   │
│ फलकों का योग हमेशा 7 होता है।     │
│ याद रखें: "सात सुर, सात समुद्र,   │
│ सात फलक-जोड़े!"                   │
│ 1↔6, 2↔5, 3↔4                     │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 2: "दो दिखे, तीसरा पक्का"   │
│ दो पासों में दो फलकें समान हों    │
│ और उनका क्रम भी समान हो, तो       │
│ बची हुई तीसरी फलकें आपस में       │
│ अम्मुखी होती हैं।                 │
│ याद रखें: "दो जुड़वा, तीसरा       │
│ दुश्मन!"                          │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 3: "एक कॉमन, घड़ी घुमाओ"    │
│ दो पासों में सिर्फ़ एक फलक        │
│ कॉमन हो, तो उस कॉमन फलक से        │
│ घड़ी की दिशा (clockwise) में      │
│ दोनों पासों की फलकें लिखो —       │
│ सामने-सामने वाली फलकें अम्मुखी।   │
│ याद रखें: "एक साथी, घड़ी की       │
│ सवारी!"                           │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 4: "घन काटो, तीन याद        │
│ रखो"                              │
│ n×n×n घन काटने पर:                │
│ • 3 फलकें रंगीन = कोने = 8        │
│ • 2 फलकें रंगीन = किनारे =        │
│   12(n−2)                         │
│ • 1 फलक रंगीन = 6(n−2)²           │
│ • 0 रंगीन = (n−2)³                │
│ याद रखें: "8 कोने, 12 किनारे,     │
│ 6 मुँह, अंदर सब बेजान!"           │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 5: "कोना कभी न बदले"        │
│ 3 रंगीन फलकों वाले छोटे घन        │
│ हमेशा 8 ही होते हैं — चाहे घन      │
│ कितना भी बड़ा हो।                 │
│ याद रखें: "कोने आठ, किस्मत        │
│ पक्की!"                           │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 6: "n−2 का खेल"             │
│ हर सूत्र में n−2 घुसा है —        │
│ क्योंकि बाहरी परत हटा दो तो       │
│ अंदर (n−2) बचता है।               │
│ याद रखें: "छिलका उतारो, n−2       │
│ पाओ!"                             │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 7: "जोड़ी बनाओ, अम्मुखी     │
│ पाओ"                              │
│ मानक पासे में: 1-6, 2-5, 3-4।     │
│ याद रखें: "एक-छह की जोड़ी,        │
│ दो-पाँच की साथी, तीन-चार          │
│ यारी!"                            │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 8: "दो कॉमन = सीधा जवाब"    │
│ दो पासों में दो फलकें कॉमन हों    │
│ (क्रम भले अलग हो), तो तीसरी       │
│ फलकें अम्मुखी — यह सबसे तेज़      │
│ केस है, 10 सेकंड में हल।          │
│ याद रखें: "दो मिले, बाकी          │
│ टकराए!"                           │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 9: "कॉमन फलक = कभी          │
│ अम्मुखी नहीं"                     │
│ जो फलक दोनों पासों में दिखे,      │
│ वह खुद अपनी अम्मुखी नहीं हो       │
│ सकती — विकल्पों से तुरंत काटो।    │
│ याद रखें: "जो दिखे, वह विरोधी     │
│ नहीं!"                            │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 10: "पड़ोसी से पहचान"       │
│ एक फलक के 4 पड़ोसी दिख जाएँ,      │
│ तो 5वाँ ही अम्मुखी है।            │
│ याद रखें: "चार पड़ोसी जानो,       │
│ पाँचवाँ दुश्मन मानो!"             │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 11: "कुल घन = घन का घन"     │
│ n×n×n घन में कुल छोटे घन = n³।    │
│ सभी श्रेणियों (3,2,1,0 रंगीन)     │
│ का योग n³ होना चाहिए —            │
│ जाँच का तरीका!                    │
│ याद रखें: "सब जोड़ो, n³           │
│ मिलो!"                            │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 12: "घनाभ का अलग हिसाब"     │
│ l×b×h घनाभ में कोने फिर 8,        │
│ पर किनारे वाले = 4[(l−2)+(b−2)+   │
│ (h−2)]। याद रखें: "घनाभ हो तो     │
│ तीनों भाई अलग-अलग गिनो!"          │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 13: "0 रंगीन = घन का        │
│ दिल"                              │
│ बिना रंगे घन = (n−2)³ —           │
│ बाहरी परत हटाओ, अंदर का घन        │
│ बचा। याद रखें: "दिल अंदर है,      │
│ रंग बाहर है!"                     │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 14: "मानक बनाम साधारण"      │
│ मानक पासा: अम्मुखी योग = 7।       │
│ साधारण पासा: योग 7 नहीं।          │
│ पहले यही जाँचो — आधे प्रश्न       │
│ यहीं छंट जाते हैं!                │
│ याद रखें: "पहले सात पूछो,         │
│ फिर आगे बढ़ो!"                    │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ ट्रिक 15: "एक कॉमन = घड़ी ही      │
│ रास्ता"                           │
│ दो पासों में सिर्फ़ एक फलक        │
│ कॉमन हो और बाकी सब अलग दिखें,     │
│ तो अम्मुखी फलकें सीधे नहीं        │
│ मिलतीं — कॉमन फलक से घड़ी की      │
│ दिशा में दोनों पासों की फलकें     │
│ लिखकर (ट्रिक 3) सामने-सामने       │
│ वाली फलकें अम्मुखी निकालो।        │
│ याद रखें: "एक कॉमन दिखे, घड़ी     │
│ घुमाकर निकालो!"                   │
└─────────────────────────────────┘

═══════════════════════════════════
⏭️ SKIP STRATEGY — कब प्रश्न छोड़ें
═══════════════════════════════════

🚩 नियम 1 — "15 सेकंड का कानून":
पासे के दो चित्र देखकर 15 सेकंड में यह न पता चले कि कॉमन फलक कौन सी है या कौन-सी ट्रिक लगेगी, तो प्रश्न को mark करके आगे बढ़ें। अंत में समय बचे तो लौटें।

🚩 नियम 2 — "तीन-चार पासों वाला जाल":
जिस प्रश्न में 3-4 पासों के चित्र देकर अम्मुखी फलक पूछी हो और कोई भी जोड़ी में कॉमन फलक न दिखे, तो यह प्रश्न 2-3 मिनट खा सकता है — पहले round में छोड़ें, बाद में elimination से करें।

🚩 नियम 3 — "घनाभ की लंबी कटिंग":
l×b×h घनाभ वाले प्रश्न में यदि तीनों विमाएँ अलग-अलग और बड़ी हों (जैसे 6×5×4) और "2 फलकें रंगीन" पूछा हो, तो सूत्र याद न आए तो अंदाज़ा न लगाएँ — गलत सूत्र = निगेटिव मार्किंग। पहले आसान n×n×n वाले निपटाएँ।

💡 बोनस टिप: पासे के प्रश्न में पहले विकल्प देखें — कई बार "कॉमन फलक अम्मुखी नहीं हो सकती" वाली ट्रिक से 2-3 विकल्प बिना हल किए कट जाते हैं!
