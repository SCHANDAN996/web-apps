51. Arrange the following words in dictionary order:

1. Plaster  2. Planet  3. Plastic  4. Plank  5. Plaque
(a) 2, 4, 5, 1, 3 (b) 2, 5, 4, 3, 1 (c) 4, 5, 2, 1, 3 (d) 4, 2, 5, 1, 3
Answer: (a)
Solution: All words start with "Pla". Fourth letters: n (Planet, Plank), q (Plaque), s (Plaster, Plastic). Planet vs Plank: fifth letters e < k, so Planet comes first. Plaster vs Plastic: fifth letters s < t, so Plaster comes first. The trap is placing Plank before Planet by ignoring the fifth letter, so the answer is 2, 4, 5, 1, 3.
