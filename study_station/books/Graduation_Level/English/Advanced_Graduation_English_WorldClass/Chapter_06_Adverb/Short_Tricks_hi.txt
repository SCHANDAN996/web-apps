🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — क्रियाविशेषण (Adverb)

---

## 🎯 15 म्नेमोनिक ट्रिक्स

┌─────────────────────────────────────────────┐
│ ट्रिक 1: "FAN-TIME" — Adverb के 7 प्रकार    │
│ F = Frequency (बारंबारता: always, often)    │
│ A = Affirmation/Negation (certainly, not)   │
│ N = Number/Degree (very, quite)             │
│ T = Time (now, yesterday)                   │
│ I = Interrogative (when, where, why)        │
│ M = Manner (slowly, bravely)                │
│ E = Place (here, there, everywhere)         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 2: "MPT" — वाक्य में कई Adverb हों तो │
│ क्रम: Manner → Place → Time                 │
│ ✅ He sang beautifully (M) at the hall (P)  │
│    yesterday (T).                           │
│ याद रखें: "मैं पहले तरीका, फिर ठिकाना,     │
│ फिर टाइम बताता हूँ"                         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 3: "हर Adjective + ly ≠ Adverb"       │
│ friendly, costly, lively, lonely, lovely,   │
│ orderly, scholarly — ये -ly लगकर भी         │
│ ADJECTIVE हैं!                               │
│ ❌ He behaved friendly.                     │
│ ✅ He behaved in a friendly manner.         │
│ म्नेमोनिक: "FCLLOOS — फ्रेंडली लोग -ly      │
│ पहनकर भी विशेषण हैं"                        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 4: "Sense-Verbs के साथ Adjective"     │
│ look, feel, smell, taste, sound (इंद्रिय    │
│ क्रियाएँ) + ADJECTIVE (Adverb नहीं)         │
│ ✅ The soup tastes good. (well ❌)          │
│ ✅ She looks beautiful. (beautifully ❌)    │
│ ट्रिक: "इंद्रियाँ बताती हैं कैसा है,        │
│ कैसे करता है नहीं"                          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 5: "Hard ≠ Hardly"                    │
│ hard = कड़ी मेहनत से (He works hard)        │
│ hardly = मुश्किल से/लगभग नहीं               │
│ (He hardly works = वह लगभग काम नहीं करता)   │
│ इसी जोड़ी में: late ≠ lately,               │
│ near ≠ nearly, high ≠ highly                │
│ ट्रिक: "-ly लगते ही मतलब पलट गया!"          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 6: "Enough की सीट"                    │
│ Adjective/Adverb के बाद: good enough,       │
│ fast enough                                 │
│ Noun के पहले: enough money, enough time     │
│ ट्रिक: "विशेषण के पीछे, संज्ञा के आगे —     │
│ Enough अपनी सीट बदलता है"                   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 7: "Too = गाली, Very = तारीफ़"        │
│ too = नकारात्मक अर्थ (अत्यधिक, बुरा)        │
│ ✅ It is too hot to drink. (पी नहीं सकते)   │
│ very = सकारात्मक अर्थ                       │
│ ✅ It is very hot. (बस ज़्यादा गर्म है)     │
│ ट्रिक: "Too आया तो तकलीफ़ आई"               │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 8: "Only की घूमती नौकरी"              │
│ Only जिस शब्द के पहले लगे, उसी पर ज़ोर:     │
│ • Only he gave me ₹100. (और किसी ने नहीं)   │
│ • He only gave me ₹100. (दिया, उधार नहीं)   │
│ • He gave me only ₹100. (बस ₹100)           │
│ ट्रिक: "Only जिसके कंधे पर बैठे, वही हीरो"  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 9: "Else + but"                       │
│ else के बाद हमेशा 'but' (than नहीं):        │
│ ✅ It was nothing else but pride.           │
│ ट्रिक: "Else का साथी सिर्फ़ But"            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 10: "Seldom, Hardly, Scarcely = NOT"  │
│ ये पहले से नकारात्मक हैं — इनके साथ         │
│ not/never/doesn't न लगाएँ:                  │
│ ❌ He does not hardly work.                 │
│ ✅ He hardly works.                         │
│ ट्रिक: "दो नकारात्मक = एक सकारात्मक,        │
│ परीक्षक यहीं फँसाता है"                     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 11: "Scarcely/Hardly…when,            │
│ No sooner…than"                             │
│ ✅ Hardly had I reached when it rained.     │
│ ✅ No sooner had I reached than it rained.  │
│ जोड़े कभी न बदलें!                          │
│ ट्रिक: "No sooner की शादी than से,          │
│ Hardly-Scarcely की when से"                 │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 12: "Much vs Very"                    │
│ very + Positive degree: very tall           │
│ much + Comparative degree: much taller      │
│ ✅ She is much wiser than her sister.       │
│ ✅ She is very wise.                        │
│ ट्रिक: "तुलना हो तो Much, सीधी बात तो Very" │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 13: "Ago vs Before"                   │
│ ago = अभी से पहले (Past Simple के साथ):     │
│ I met him two days ago.                     │
│ before = किसी पुराने बिंदु से पहले          │
│ (Past Perfect के साथ):                      │
│ I had met him two days before.              │
│ ट्रिक: "Ago आज गिनता है, Before कल से"      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 14: "Fast, Hard, Early, Late —        │
│ बदलते नहीं"                                 │
│ ये Adjective और Adverb दोनों रूप में एक     │
│ जैसे: He is a fast runner. / He runs fast.  │
│ ❌ He runs fastly. (fastly शब्द ही नहीं!)   │
│ ट्रिक: "Fastly जैसा शब्द अंग्रेज़ी में       │
│ मौजूद ही नहीं — दिखे तो काट दो"             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 15: "Adverb की पहचान — 3 सवाल"        │
│ किसी शब्द से पूछो: कब? कहाँ? कैसे? कितना?  │
│ जवाब दे तो वह Adverb है।                    │
│ परीक्षा में 5 सेकंड की जाँच:                │
│ "She sings sweetly" — कैसे गाती है?         │
│ sweetly → Adverb of Manner ✔                │
└─────────────────────────────────────────────┘

## ⏭️ स्किप रणनीति (कब प्रश्न छोड़ें)

**स्किप टिप 1 — दोनों विकल्प "सही लगने" वाले जाल:**
जब दो विकल्प कान को एक जैसे सही लगें (जैसे "He works hardly" vs "He hardly works"), तो तुरंत ट्रिक 5/10 लागू करें। 45 सेकंड में भी नियम याद न आए तो प्रश्न मार्क करके आगे बढ़ें — अनुमान पर टिक करने से नकारात्मक अंकन का जोखिम बढ़ता है।

**स्किप टिप 2 — लंबे वाक्य में छिपा Only/Enough:**
Only या Enough की स्थिति वाले प्रश्न में वाक्य लंबा हो और अर्थ-भेद सूक्ष्म हो, तो पहले आसान प्रश्न निपटाएँ। ये प्रश्न 'तार्किक' श्रेणी के हैं — इन्हें दूसरे दौर में 45 सेकंड दें, पहले दौर में नहीं।

**स्किप टिप 3 — अपरिचित शब्द वाला Error Spotting:**
अगर Error Spotting में कोई ऐसा शब्द हो जिसका अर्थ ही न पता हो (जैसे "scarcely" पहली बार देखा), तो उस विकल्प को तुरंत गलत मानने की बजाय बाकी तीन विकल्पों में ज्ञात नियम (Subject-Verb, Tense) जाँचें। तीनों सही निकलें तभी अपरिचित विकल्प चुनें; संदेह बना रहे तो छोड़ दें।
