# 🪄 Short Tricks + Skip Strategy — Adverb

---

## Trick 1 — The "HOW-WHEN-WHERE-HOW MUCH" Detector
```
┌─────────────────────────────────────────────┐
│ Ask the verb 4 questions:                   │
│ HOW? → manner (slowly, well)                │
│ WHEN? → time (yesterday, soon)              │
│ WHERE? → place (here, outside)              │
│ HOW MUCH / HOW OFTEN? → degree/frequency    │
│ (very, almost, always)                      │
│ The answer is ALWAYS an adverb.             │
└─────────────────────────────────────────────┘
```

## Trick 2 — "LY ≠ Always Adverb"
```
┌─────────────────────────────────────────────┐
│ FRIENDLY, LONELY, COSTLY, LOVELY, LIVELY,   │
│ ELDERLY, DEADLY, COWARDLY, SCHOLARLY        │
│ → All are ADJECTIVES despite ending in -ly! │
│ Memory hook: "Friendly Lonely Costly        │
│ Lovely Lively Elderly people can be         │
│ Deadly Cowardly Scholars."                  │
│ ❌ He behaved friendly.                     │
│ ✅ He behaved in a friendly manner.         │
└─────────────────────────────────────────────┘
```

## Trick 3 — "FAST-HARD-EARLY" (Same-Form Trio)
```
┌─────────────────────────────────────────────┐
│ FAST, HARD, EARLY, LATE, DAILY, STRAIGHT,   │
│ LONG, ENOUGH — same word as adj AND adverb. │
│ ⚠️ HARDLY ≠ hard + ly (hardly = almost not) │
│ ⚠️ LATELY ≠ late + ly (lately = recently)   │
│ He works hard. / He hardly works.           │
│ (opposite meanings!)                        │
└─────────────────────────────────────────────┘
```

## Trick 4 — "M-P-T" Order of Adverbs
```
┌─────────────────────────────────────────────┐
│ When many adverbs meet, order = M-P-T:      │
│ Manner → Place → Time                       │
│ "She sang beautifully (M) in the hall (P)   │
│  yesterday (T)."                            │
│ Hook: "My Pet Tiger" = Manner, Place, Time  │
└─────────────────────────────────────────────┘
```

## Trick 5 — "Enough Goes AFTER"
```
┌─────────────────────────────────────────────┐
│ ENOUGH as adverb comes AFTER adj/adverb:    │
│ ✅ tall enough, fast enough, well enough    │
│ ❌ enough tall, enough fast                 │
│ (But with nouns: enough money — BEFORE.)    │
└─────────────────────────────────────────────┘
```

## Trick 6 — "Only Moves, Meaning Moves"
```
┌─────────────────────────────────────────────┐
│ Place ONLY next to the word it limits:      │
│ Only he lent me ₹100. (nobody else)         │
│ He only lent me ₹100. (didn't gift)         │
│ He lent me only ₹100. (not more)            │
│ Exam trap: "only" misplaced = wrong answer. │
└─────────────────────────────────────────────┘
```

## Trick 7 — "Very vs Much"
```
┌─────────────────────────────────────────────┐
│ VERY + positive degree: very tall, very good│
│ MUCH + comparative: much taller, much better│
│ ✅ very interesting / much more interesting │
│ ❌ very better / much good                  │
│ Hook: "Very stays single, Much compares."   │
└─────────────────────────────────────────────┘
```

## Trick 8 — "Too = Negative Shade"
```
┌─────────────────────────────────────────────┐
│ TOO = more than desirable (bad sense):      │
│ "He is too weak to walk." (cannot walk)     │
│ Don't use too for happy meanings:           │
│ ❌ She is too beautiful. (in formal exams)  │
│ ✅ She is very beautiful.                   │
└─────────────────────────────────────────────┘
```

## Trick 9 — "Else + But"
```
┌─────────────────────────────────────────────┐
│ ELSE is followed by BUT, not THAN:          │
│ ✅ None else but Ram came.                  │
│ ❌ None else than Ram came.                 │
│ (But "other than", "rather than" use THAN.) │
└─────────────────────────────────────────────┘
```

## Trick 10 — "No Sooner… Than / Hardly… When"
```
┌─────────────────────────────────────────────┐
│ Fixed pairs — never mix:                    │
│ No sooner … THAN                            │
│ Hardly / Scarcely … WHEN (or before)        │
│ ❌ No sooner had he come when…              │
│ ✅ No sooner had he come than…              │
│ Hook: "Sooner-Than rhyme; Hardly-When chime"│
└─────────────────────────────────────────────┘
```

## Trick 11 — "Adverb After Verb, Not Between Verb & Object"
```
┌─────────────────────────────────────────────┐
│ ❌ He speaks fluently English.              │
│ ✅ He speaks English fluently.              │
│ Rule: Verb + Object + Adverb.               │
│ Never split verb and its object.            │
└─────────────────────────────────────────────┘
```

## Trick 12 — "Seldom, Never, Hardly = Already Negative"
```
┌─────────────────────────────────────────────┐
│ Negative adverbs need NO extra "not":       │
│ ❌ He does not hardly work.                 │
│ ✅ He hardly works.                         │
│ ❌ I never did not go.                      │
│ ✅ I never went.                            │
│ Double negative = instant error-spot answer.│
└─────────────────────────────────────────────┘
```

## Trick 13 — "Inversion Alarm"
```
┌─────────────────────────────────────────────┐
│ Sentence starts with Never, Seldom, Rarely, │
│ Hardly, Scarcely, No sooner, Not only →     │
│ INVERT: auxiliary BEFORE subject.           │
│ ❌ Never I have seen such a thing.          │
│ ✅ Never have I seen such a thing.          │
└─────────────────────────────────────────────┘
```

## Trick 14 — "Fairly vs Rather"
```
┌─────────────────────────────────────────────┐
│ FAIRLY → pleasant things: fairly good,      │
│ fairly wise.                                │
│ RATHER → unpleasant/surprising: rather dull,│
│ rather difficult.                           │
│ Hook: "Fairly = Fair (nice);                │
│ Rather = Rough."                            │
└─────────────────────────────────────────────┘
```

## Trick 15 — "Ago vs Before"
```
┌─────────────────────────────────────────────┐
│ AGO → simple past: "I met him two days ago."│
│ BEFORE → past perfect / no time reference:  │
│ "I had met him before."                     │
│ ❌ I had met him two days ago.              │
│ ✅ I had met him two days before.           │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy

**Tip 1 — Skip the "Sound-Right" trap question for 45 seconds.**
If two options both "sound correct" (e.g., *fast* vs *fastly*, *hard* vs *hardly*), don't guess instantly. Re-read the sentence, ask HOW/WHEN/WHERE, and check whether the word modifies a verb (adverb) or a noun (adjective). If still stuck after 45 seconds, mark and move on — these traps are designed to eat time.

**Tip 2 — Skip long "only/misplaced modifier" sentences on first pass.**
Questions where you must judge the position of *only, even, almost* in a long sentence need careful meaning analysis (45-sec category). Do the quick fact-based ones (very/much, hardly/when, inversion) first, then return.

**Tip 3 — Never skip double-negative and fixed-pair questions.**
*No sooner…than, hardly…when, else…but, seldom/not* — these are 15-second, near-guaranteed marks. Spot the pair, apply the rule, lock the answer. Skipping these is leaving free marks on the table.
