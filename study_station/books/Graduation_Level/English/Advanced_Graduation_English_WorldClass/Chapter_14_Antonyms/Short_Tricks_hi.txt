# 🪄 शॉर्ट ट्रिक्स + Skip Strategy

## 15 म्नेमोनिक ट्रिक्स

**ट्रिक 1 — "उल्टा सोचो" तरीका**
```
किसी शब्द का विलोम पूछा जाए, तो पहले शब्द का सामान्य अर्थ सोचें,
फिर उसका सटीक उल्टा चुनें।
उदा.: Abundant (प्रचुर) → Scanty (अपर्याप्त)
```

**ट्रिक 2 — "un- / in- / dis-" उपसर्ग पहचानो**
```
un-: happy–unhappy, able–unable
in-: active–inactive, visible–invisible
dis-: honest–dishonest, appear–disappear
परीक्षक का पहला कदम: उपसर्ग वाला विकल्प देखो।
```

**ट्रिक 3 — "im- / il- / ir-" का नियम याद रखो**
```
im-  P, B, M से पहले: polite–impolite, possible–impossible
il-  L से पहले: legal–illegal
ir-  R से पहले: regular–irregular
```

**ट्रिक 4 — "शुरुआत-अंत" जोड़ी**
```
शुरू और अंत से जुड़े शब्दों को जोड़ी में याद करो।
उदा.: Start ↔ End, Begin ↔ Finish, Arrive ↔ Depart
```

**ट्रिक 5 — "मीठा-कड़वा" भाव-युग्म**
```
शब्द का स्वाद सोचो, फिर उल्टा।
Sweet ↔ Bitter, Gentle ↔ Harsh, Soft ↔ Hard
```

**ट्रिक 6 — "अंधेरा-उजाला" चेन**
```
Light ↔ Dark, Dawn ↔ Dusk, Birth ↔ Death
चेन बनाओ: जन्म ↔ मृत्यु, उगना ↔ डूबना
```

**ट्रिक 7 — "दोस्त-दुश्मन" जोड़ी**
```
मित्र ↔ शत्रु, Friend ↔ Enemy, Ally ↔ Foe
रिश्ते वाले शब्दों को जोड़ी में याद करो।
```

**ट्रिक 8 — "ऊँचा-नीचा" सीढ़ी ट्रिक**
```
शब्द को सीढ़ी के ऊपर या नीचे रखो।
High ↔ Low, Rise ↔ Fall, Top ↔ Bottom
```

**ट्रिक 9 — "प्लस-माइनस" गणित ट्रिक**
```
शब्द को प्लस या माइनस सोचो।
Profit ↔ Loss, Gain ↔ Lose, Add ↔ Subtract
```

**ट्रिक 10 — "तेज़-धीमा" स्पीड ट्रिक**
```
तेज़ ↔ धीमा, Fast ↔ Slow, Quick ↔ Sluggish, Rapid ↔ Gradual
```

**ट्रिक 11 — "दिन-रात" समय ट्रिक**
```
दिन ↔ रात, Day ↔ Night, Morning ↔ Evening, Dawn ↔ Twilight
```

**ट्रिक 12 — "अंदर-बाहर" डिब्बा ट्रिक**
```
अंदर ↔ बाहर, Inner ↔ Outer, Enter ↔ Exit, Import ↔ Export
```

**ट्रिक 13 — "जल-आग" तत्व ट्रिक**
```
तत्वों के उल्टे जोड़े याद करो।
Fire ↔ Water, Hot ↔ Cold, Warm ↔ Cool
```

**ट्रिक 14 — "खुशी-दुखी" चेहरा ट्रिक**
```
खुशी ↔ दुखी, Joy ↔ Sorrow, Glad ↔ Sad, Cheerful ↔ Gloomy
```

**ट्रिक 15 — "सच-झूठ" आईना ट्रिक**
```
सच ↔ झूठ, True ↔ False, Truth ↔ Lie, Honest ↔ Dishonest
```

## Skip Strategy

**कब प्रश्न छोड़ें**

1. **दोनों विकल्प समान दिखें** — अगर दो विकल्प लगभग-सही लगें, तो 45 सेकंड से ज़्यादा न दें; पहले बाकी प्रश्न करो, फिर लौटकर आओ।
2. **बिल्कुल अनजाना शब्द** — अगर शब्द और सभी विकल्प नए हों, तो अनुमान के बजाय छोड़ दें; गलत उत्तर पर अंक-कटौती से बचो।
3. **लंबे कथन वाले प्रश्न** — अगर प्रश्न में जटिल वाक्यांश हो, तो पहले सरल प्रश्न करो; बाद में शांत मन से हल करो।
