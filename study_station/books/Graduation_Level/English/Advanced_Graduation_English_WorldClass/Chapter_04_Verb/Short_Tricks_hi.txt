# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — क्रिया (Verb)

## 🧠 म्नेमोनिक ट्रिक्स (बॉक्स में)

```
┌─────────────────────────────────────────────┐
│ ट्रिक 1: "S की सज़ा"                        │
│ He/She/It के साथ Verb को S की सज़ा मिलती है।│
│ बाकी सब (I, We, You, They) बच जाते हैं।    │
│ ✔ She plays. ✔ They play.                   │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 2: "दो राजा, एक ताज"                  │
│ And से जुड़े दो अलग व्यक्ति/वस्तु = Plural  │
│ लेकिन एक ही व्यक्ति/विचार = Singular        │
│ ✔ Ram and Shyam are friends.                │
│ ✔ The poet and philosopher is dead. (एक ही) │
│ पहचान: दूसरे noun से पहले 'the' न हो = एक।  │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 3: "Each-Every की अकड़"               │
│ Each, Every, Everyone, Everybody, Someone,  │
│ Nobody — सब अकड़बाज़ हैं, अकेले रहते हैं।   │
│ → हमेशा Singular Verb                       │
│ ✔ Each of the boys has a pen.               │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 4: "News अच्छी हो या बुरी, अकेली है"  │
│ -s लगा फिर भी Singular: News, Physics,      │
│ Mathematics, Politics, Measles, Billiards   │
│ ✔ The news is shocking.                     │
│ याद रखें: "बीमारी-खेल-विषय, सब Singular"    │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 5: "Police हमेशा बहुल"                │
│ Police, Cattle, People, Gentry, Peasantry — │
│ दिखने में एक, काम में बहुत। → Plural Verb   │
│ ✔ The police have arrested him.             │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 6: "Either-Neither = अकेला चुनाव"     │
│ Either…or / Neither…nor में Verb पास वाले   │
│ Subject के हिसाब से (Proximity Rule)।        │
│ ✔ Neither the boys nor Ram is here.         │
│ ✔ Neither Ram nor the boys are here.        │
│ याद: "Verb पड़ोसी की सुनता है"              │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 7: "There का झूठा सब्जेक्ट"           │
│ There से शुरू वाक्य में असली Subject Verb   │
│ के बाद छिपा होता है।                        │
│ ✔ There are many books on the table.        │
│ (books = असली subject, there = नकली)        │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 8: "Had + V3 = पहले वाला काम"         │
│ दो पुराने काम हों तो जो पहले हुआ → Past     │
│ Perfect (had + V3), बाद वाला → Simple Past। │
│ ✔ The train had left before I reached.      │
│ ट्रिक: "Before/After के पहले Had"           │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 9: "Since बिंदु, For दूरी"            │
│ Since = समय का बिंदु (Monday, 2010, 5 बजे)  │
│ For = समय की अवधि (two days, 5 years)       │
│ दोनों के साथ → Present Perfect/Perfect Cont.│
│ ✔ I have lived here since 2015 / for 9 yrs. │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 10: "Wish + Were = सपना"              │
│ कल्पना/इच्छा में I के साथ भी 'were'।        │
│ ✔ I wish I were a bird.                     │
│ ✔ If I were you… (If I was ❌)              │
│ ट्रिक: "सपने में सब were हो जाते हैं"       │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 11: "Modal के बाद नंगी क्रिया"        │
│ Can, Could, May, Might, Shall, Should,      │
│ Will, Would, Must के बाद हमेशा V1 (बिना to) │
│ ✔ He can swim. (can to swim ❌)             │
│ अपवाद याद: ought to, used to, have to       │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 12: "One of + बहुत, Verb एक"          │
│ One of the + Plural Noun + Singular Verb    │
│ ✔ One of my friends has gone.               │
│ ट्रिक: "भीड़ में से एक — Verb उसी एक का"    │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 13: "Scenery-Furniture-Information"   │
│ ये Uncountable हैं — कभी Plural नहीं,       │
│ Verb हमेशा Singular।                         │
│ ✔ The scenery is beautiful.                 │
│ ✔ The information is correct.               │
│ ट्रिक: "SFI — सिंगुलर फॉरएवर इंडिया"        │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 14: "It is time + Past"               │
│ It is time / It is high time के बाद Verb    │
│ Past Tense में (भले अर्थ वर्तमान का हो)।    │
│ ✔ It is high time you went home.            │
└─────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────┐
│ ट्रिक 15: "Intervening Phrase काट दो"       │
│ Subject और Verb के बीच का along with,       │
│ together with, as well as, with, like —     │
│ सब काट दो, Verb असली Subject से मिलाओ।      │
│ ✔ The captain, with his men, was killed.    │
│ (captain = singular → was)                  │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**1. दोहरे-जाल वाला Error Spotting (45 सेकंड से ज़्यादा लगे तो छोड़ें)**
जब वाक्य में Intervening Phrase + Collective Noun दोनों एक साथ हों और आप 45 सेकंड में असली Subject पकड़ न पाएँ, तो अंदाज़ा न लगाएँ। Negative marking में गलत अंदाज़ा −0.25 है, जबकि छोड़ना 0 है। पहले आसान 15-सेकंड वाले प्रश्न (Tense, Modal, Since/For) निपटाएँ, फिर समय बचे तो लौटें।

**2. "Sound-Right" जाल में फँसें तो रुकें, अंदाज़ा न लगाएँ**
जैसे "The news are…" या "One of my friend…" — कान को सही लगने वाला विकल्प अक्सर गलत होता है। अगर नियम याद न आए, तो प्रश्न छोड़ें; कान पर भरोसा करके टिक करना सबसे खतरनाक है।

**3. अपरिचित Subjunctive/Advanced Conditional**
"If I had been…" जैसे Third Conditional या Inversion (Had I known…) वाले प्रश्न में अगर structure पहचान में 30 सेकंड से ज़्यादा लगें, तो mark करके आगे बढ़ें। Verb के 80% अंक Subject-Verb Agreement, Tense और Modal से आते हैं — पहले वे सुरक्षित करें।
