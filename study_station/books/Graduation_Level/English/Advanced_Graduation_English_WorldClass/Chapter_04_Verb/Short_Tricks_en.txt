# 🪄 Short Tricks + Skip Strategy — Verb

## Memory Tricks (Mnemonics)

```
┌─────────────────────────────────────────────────────────────┐
│ TRICK 1: "FANBOYS never split the subject"                  │
│ Two subjects joined by AND = plural verb.                   │
│ But joined by or/nor/either...or/neither...nor = verb       │
│ agrees with the NEARER subject.                             │
│ "Neither the teacher nor the STUDENTS were present."        │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 2: "Each, Every, Everyone, Everybody = SINGULAR"      │
│ The 4 E's always take a singular verb.                      │
│ "Each of the boys HAS a pen." (NOT have)                    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 3: "Ignore the Sandwich"                              │
│ Phrases like along with, as well as, together with,         │
│ in addition to, accompanied by are a SANDWICH between       │
│ subject and verb — eat around them! Verb agrees with the    │
│ FIRST subject only.                                         │
│ "The captain, along with his men, WAS honoured."            │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 4: "News is SINGULAR news"                            │
│ Words ending in -s but singular: news, physics, economics,  │
│ mathematics, politics, measles, mumps, billiards.           │
│ "The news IS shocking."                                     │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 5: "Scissors come in PAIRS — always plural"           │
│ scissors, trousers, spectacles, goggles, pliers, tongs,     │
│ earnings, premises → plural verb.                           │
│ "My spectacles ARE broken."                                 │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 6: "A NUMBER of = many (plural)                       │
│           THE NUMBER of = the count (singular)"             │
│ "A number of students WERE absent."                         │
│ "The number of students WAS fifty."                         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 7: "Since + Point, For + Period"                      │
│ since = fixed point (Monday, 2010, childhood)               │
│ for = duration (two years, a long time)                     │
│ Both demand Perfect/Perfect Continuous tense.               │
│ "I have been waiting SINCE morning / FOR two hours."        │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 8: "Had + V3 comes FIRST in the past queue"           │
│ Two past actions → earlier one = Past Perfect,              │
│ later one = Simple Past.                                    │
│ "The train HAD LEFT before I REACHED the station."          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 9: "If I WERE a king..."                              │
│ Hypothetical/imaginary condition → use WERE for all         │
│ persons, even I/he/she/it.                                  │
│ "If I were you, I would apologise."                         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 10: "Hardly/Scarcely/No sooner — the negative trio"   │
│ Hardly...when | Scarcely...when | No sooner...than          │
│ First clause = Past Perfect (had + V3).                     │
│ "No sooner HAD she ENTERED than the phone rang."            │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 11: "One of the + plural noun + SINGULAR verb"        │
│ "One of my friends HAS gone abroad."                        │
│ Trap: the plural noun near the verb tempts you to use       │
│ a plural verb — the real subject is ONE.                    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 12: "Many a = singular, though it means many"         │
│ "Many a soldier HAS died for the country."                  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 13: "It is time + PAST tense"                         │
│ After "It is time / It is high time", use Simple Past       │
│ even though the meaning is present.                         │
│ "It is high time we LEFT." (NOT leave)                      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 14: "Collective noun: ONE team or MANY members?"      │
│ Acting as one unit → singular; members acting separately    │
│ → plural.                                                   │
│ "The jury HAS given its verdict." (united)                  │
│ "The jury ARE divided in their opinion." (divided)          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TRICK 15: "Lest...should"                                   │
│ After 'lest', always use SHOULD + V1; never use 'not'       │
│ (lest itself is negative).                                  │
│ "Walk fast lest you SHOULD miss the train."                 │
└─────────────────────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy

**1. Skip the "double-trap" sentence on first pass.**
If an error-spotting sentence has both an intervening phrase AND a collective noun, and you cannot isolate the subject within 20 seconds, mark it and move on. Return after finishing the easy fact-based questions — a fresh read usually exposes the real subject instantly.

**2. Don't fight the "sound-right" trap.**
Options like "The data shows..." vs "The data show..." are designed to make the wrong one *sound* natural. If you cannot recall the rule (data = plural in formal usage, though singular is now widely accepted — check what the exam's answer key convention is), skip rather than guess on instinct. Your ear is trained by spoken English, not exam English.

**3. Leave tense-sequence puzzles for the end.**
Questions mixing Past Perfect, reported speech, and conditionals in one sentence take 45+ seconds. Attempt all 15-second subject-verb agreement questions first, bank those marks, then return to the tense puzzles with leftover time.
