# 🪄 Short Tricks + Skip Strategy — Advanced Reading Comprehension

---

## Trick 1: The "S-P-Q-R" Reading Order
```
┌─────────────────────────────────────────────┐
│  S-P-Q-R                                    │
│  S = Scan the questions FIRST (30 sec)      │
│  P = Preview the passage (first + last      │
│      line of each paragraph)                │
│  Q = Question-attack (easy ones first)      │
│  R = Re-check only the flagged ones         │
└─────────────────────────────────────────────┘
```
Never read the full passage word-by-word first. Questions tell you *what* to hunt for.

---

## Trick 2: "FEEL" the Tone
```
┌─────────────────────────────────────────────┐
│  F-E-E-L for Tone Questions                 │
│  F = Feeling words (adjectives/adverbs)     │
│  E = Examples chosen (positive/negative?)   │
│  E = Ending line (author's final verdict)   │
│  L = Loaded words (alas, sadly, admirably)  │
└─────────────────────────────────────────────┘
```
Tone lives in adjectives, not in facts. "The policy, *regrettably*, failed" = critical tone.

---

## Trick 3: The "Goldilocks Rule" for Main Idea
```
┌─────────────────────────────────────────────┐
│  Correct main-idea answer is:               │
│  • Not TOO BROAD (covers more than passage) │
│  • Not TOO NARROW (only one paragraph)      │
│  • JUST RIGHT (covers whole passage)        │
└─────────────────────────────────────────────┘
```
Eliminate the two extremes first — you're left with two options, not four.

---

## Trick 4: "MAP" for Inference Questions
```
┌─────────────────────────────────────────────┐
│  M-A-P                                      │
│  M = Must be true (not "could be true")     │
│  A = Anchored in the text (find the line)   │
│  P = One small step only (no leaps)         │
└─────────────────────────────────────────────┘
```
Inference = fact + ONE logical step. If you need two steps, it's a trap option.

---

## Trick 5: The "Echo Trap" Detector
```
┌─────────────────────────────────────────────┐
│  If an option COPIES the passage's exact    │
│  words in an INFERENCE question → it's      │
│  probably WRONG.                            │
│  Inference answers PARAPHRASE; they don't   │
│  echo.                                      │
└─────────────────────────────────────────────┘
```

---

## Trick 6: "V-in-C" — Vocabulary in Context (3-Step)
```
┌─────────────────────────────────────────────┐
│  1. Cover the word. Read the sentence.      │
│  2. Insert YOUR OWN simple word that fits.  │
│  3. Match your word to the closest option.  │
└─────────────────────────────────────────────┘
```
Never pick the dictionary meaning you memorised — pick the meaning the *sentence* demands.

---

## Trick 7: The "But-After" Rule
```
┌─────────────────────────────────────────────┐
│  Author's real opinion comes AFTER:         │
│  however / but / yet / nevertheless /       │
│  although / despite                         │
│  Everything before the "but" is the view    │
│  the author is about to challenge.          │
└─────────────────────────────────────────────┘
```

---

## Trick 8: "DEEDS" — Passage Structure Spotter
```
┌─────────────────────────────────────────────┐
│  D = Definition (introduces a concept)      │
│  E = Explanation (how it works)             │
│  E = Evidence (data, studies, examples)     │
│  D = Debate (counter-arguments)             │
│  S = Stand (author's conclusion)            │
│  Label each paragraph → structure questions │
│  become 15-second questions.                │
└─────────────────────────────────────────────┘
```

---

## Trick 9: Extreme-Word Alarm
```
┌─────────────────────────────────────────────┐
│  RED-FLAG words in options:                 │
│  always, never, all, none, completely,      │
│  only, impossible, entirely                 │
│  Passages rarely claim absolutes → these    │
│  options are usually WRONG.                 │
│  SAFE words: may, might, often, some,       │
│  tends to, suggests                         │
└─────────────────────────────────────────────┘
```

---

## Trick 10: The "Two-Pass" Title Trick
```
┌─────────────────────────────────────────────┐
│  Pass 1: Delete options that mention only   │
│  ONE paragraph's content.                   │
│  Pass 2: Of the remaining two, pick the one │
│  that would still fit if the passage had    │
│  ONE MORE paragraph.                        │
└─────────────────────────────────────────────┘
```

---

## Trick 11: "EXCEPT" Question Shield
```
┌─────────────────────────────────────────────┐
│  In "All are true EXCEPT" questions:        │
│  Tick (✓) each option you FIND in the       │
│  passage. The one left unticked is the      │
│  answer. Never solve from memory — verify   │
│  all four.                                  │
└─────────────────────────────────────────────┘
```

---

## Trick 12: Pronoun Pointer
```
┌─────────────────────────────────────────────┐
│  "What does 'it/this/they' refer to?"       │
│  → Go BACKWARD, not forward. The nearest    │
│  matching noun BEFORE the pronoun (same     │
│  number/gender) is the answer.              │
└─────────────────────────────────────────────┘
```

---

## Trick 13: The 15/45-Second Sorter
```
┌─────────────────────────────────────────────┐
│  15-SEC (Fact): "According to the passage", │
│  vocab-in-context, pronoun reference,       │
│  "the author mentions..."                   │
│                                             │
│  45-SEC (Thinking): tone, main idea, title, │
│  inference, "author would agree with...",   │
│  structure/purpose questions                │
│                                             │
│  Do ALL 15-sec questions first, bank the    │
│  marks, then spend saved time on 45-sec.    │
└─────────────────────────────────────────────┘
```

---

## Trick 14: "Same-Side" Elimination
```
┌─────────────────────────────────────────────┐
│  If TWO options mean nearly the same thing, │
│  BOTH are wrong — a question can have only  │
│  one correct answer. Eliminate the pair     │
│  and choose between the other two.          │
└─────────────────────────────────────────────┘
```

---

## Trick 15: First-Line / Last-Line Anchor
```
┌─────────────────────────────────────────────┐
│  80% of the time:                           │
│  • Main idea hides in PARAGRAPH 1, lines    │
│    1–3, or the LAST paragraph.              │
│  • Read the middle paragraphs only for      │
│    detail questions.                        │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy

**Skip Tip 1 — The 90-Second Wall:**
If a question has consumed 90 seconds and you haven't eliminated even two options, mark it and move on. A hard inference question is worth the same 1 mark as a 15-second fact question. Return only if time remains.

**Skip Tip 2 — Skip the "Philosophy Trap" options:**
Options that sound deep, wise, or broadly true about life ("Technology has both good and bad sides") but are NOT discussed in the passage — skip them instantly. Truth outside the passage ≠ correct answer.

**Skip Tip 3 — Negative-marking discipline:**
If you cannot eliminate at least 2 options, DO NOT guess in exams with negative marking (SSC CGL, IBPS). A blind guess has a 25% success rate but a 75% chance of losing 0.25–0.5 marks. Attempt only when you're down to two options — then your expected value turns positive.
