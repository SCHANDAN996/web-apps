# 🪄 शॉर्ट ट्रिक्स + Skip Strategy — उन्नत पठन बोध

## 🔑 12 म्नेमोनिक ट्रिक्स (बॉक्स में)

```
┌─────────────────────────────────────────────────────────┐
│ ट्रिक 1: "पहले प्रश्न, फिर पैसेज" (Q→P नियम)              │
│ पैसेज पढ़ने से पहले प्रश्नों की एक झलक लें — दिमाग़ को     │
│ पता चल जाता है कि क्या खोजना है। समय बचता है, ध्यान        │
│ केंद्रित रहता है। (लेकिन पहले विकल्प न पढ़ें — भ्रम होगा!)   │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 2: "SKIM = सिर्फ़ किनारे"                            │
│ Skimming में पढ़ें: पहला पैरा + हर पैरा की पहली-आखिरी      │
│ पंक्ति + आखिरी पैरा। बीच का मसाला बाद में, जब प्रश्न माँगे। │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 3: "BUT के बाद सोना"                                 │
│ However, But, Yet, Nevertheless, Although — इन शब्दों के   │
│ बाद लेखक की असली राय छिपी होती है। Tone/Main Idea के       │
│ प्रश्नों में इन्हीं पर निशाना लगाओ।                          │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 4: "EXTREME = गलत"                                   │
│ विकल्पों में always, never, all, none, completely, only    │
│ दिखे तो 90% मामलों में वह विकल्प गलत है। लेखक सावधान        │
│ भाषा (may, often, tends to) पसंद करते हैं।                 │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 5: "पैसेज से बाहर = बाहर"                            │
│ Inference का उत्तर पैसेज में छिपे सुराग़ पर टिका होना        │
│ चाहिए। तुम्हारा अपना ज्ञान या राय कभी उत्तर नहीं हो सकती।    │
│ याद रखो: "जो पैसेज में नहीं, वो उत्तर में नहीं।"             │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 6: "शब्द-जाल पहचानो" (Synonym Trap)                  │
│ Vocabulary-in-context में विकल्प में शब्द का सबसे आम अर्थ    │
│ रखा होता है — वही जाल है। उस शब्द को वाक्य में वापस रखकर     │
│ पढ़ो; जो बैठ जाए, वही उत्तर।                                │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 7: "TONE का थर्मामीटर"                               │
│ पहले तय करो: लेखक + (प्रशंसा), − (आलोचना) या 0 (तटस्थ)?    │
│ फिर विकल्पों को इसी पैमाने पर रखो। आधे विकल्प तुरंत कट      │
│ जाएँगे। Critical ≠ हर बात पर नाराज़; Objective ≠ रायहीन।     │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 8: "15/45 सेकंड का घड़ी-नियम"                        │
│ Fact-based (सीधा उत्तर पैसेज में है) → 15 सेकंड में खत्म।   │
│ Inference/Tone (सोचना पड़े) → अधिकतम 45 सेकंड। इससे ज़्यादा │
│ लगे तो निशान लगाकर आगे बढ़ो।                               │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 9: "ROOT से रास्ता"                                  │
│ अनजाना शब्द? तोड़ो: जैसे BENE (अच्छा) + DICT (बोलना) =     │
│ Benediction (आशीर्वाद)। MAL (बुरा) + VOL (इच्छा) =          │
│ Malevolent (दुर्भावनापूर्ण)। मूल शब्द = आधा अर्थ।            │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 10: "दो बचे तो पैसेज वापस"                           │
│ दो विकल्पों में फँसो तो अंदाज़ा मत लगाओ — पैसेज की उस पंक्ति │
│ पर लौटो। जो विकल्प पैसेज के शब्दों से सबसे नज़दीक हो (बिना   │
│ Extreme भाषा के), वही उत्तर।                                │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 11: "Title = Main Idea का आईना"                      │
│ Title वाले प्रश्न में वह विकल्प चुनो जो पूरे पैसेज को ढके —  │
│ न सिर्फ़ एक पैरा को (बहुत संकरा), न पैसेज से बाहर की बात को  │
│ (बहुत चौड़ा)। "सोने जैसा" विकल्प: बिल्कुल सही चौड़ाई।       │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ ट्रिक 12: "EXCEPT/NOT में उल्टा चश्मा"                     │
│ नकारात्मक प्रश्न (EXCEPT, NOT TRUE, LEAST) में पहले तीन       │
│ सही कथन पैसेज में ढूँढो — जो न मिले, वही उत्तर। घबराकर      │
│ पहला सही कथन टिक मत कर देना!                               │
└─────────────────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

```
┌─────────────────────────────────────────────────────────┐
│ SKIP 1: "45 सेकंड की दीवार"                               │
│ कोई भी RC प्रश्न 45 सेकंड में हल न हो तो तुरंत निशान लगाकर  │
│ आगे बढ़ो। एक अटके प्रश्न पर 2 मिनट = बाकी 4 आसान प्रश्नों   │
│ की कुर्बानी। अंत में समय बचे तो लौट आओ।                    │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ SKIP 2: "लंबा पैसेज, कम समय"                              │
│ परीक्षा के आखिरी 5 मिनट बचे हों और एक पूरा लंबा पैसेज       │
│ (5 प्रश्न) बाकी हो, तो पहले उसके Fact-based प्रश्न करो —     │
│ वे पैसेज की एक पंक्ति से हल हो जाते हैं। Inference वाले      │
│ अंत में या छोड़ दो। आंशिक फ़सल भी फ़सल है।                  │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ SKIP 3: "दोनों-सही-लगें जाल"                              │
│ जब दो विकल्प बार-बार पढ़ने पर भी बराबर लगें और पैसेज में    │
│ सीधा सुराग़ न मिले, तो तुक्का लगाने के बजाय छोड़ दो          │
│ (negative marking में)। याद रखो: अनिश्चित Inference =       │
│ सबसे खतरनाक तुक्का। Fact-based पर कभी skip मत करो।         │
└─────────────────────────────────────────────────────────┘
```

## ⚡ अंतिम याद: "RC का पंचमंत्र"

**प**हले प्रश्न देखो → **स**्किम करो → **BUT** जैसे मोड़-शब्दों पर ध्यान → **E**xtreme विकल्प काटो → **पै**सेज से बाहर कभी मत जाओ।
