# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — आलोचनात्मक पठन (Critical Reading)

## 🎯 12 म्नेमोनिक ट्रिक्स (बॉक्स में)

```
┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 1: "पहले प्रश्न, फिर पैसेज" (Q-P नियम)                  │
│ पैसेज पढ़ने से पहले प्रश्नों की एक झलक लें। दिमाग़ को पता    │
│ चल जाता है कि क्या ढूँढना है — जैसे बाज़ार जाने से पहले      │
│ सूची पढ़ लेना।                                                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 2: "मुख्य विचार = पहली + आखिरी पंक्ति" (P-A नियम)      │
│ Main Idea प्रश्न में 80% बार उत्तर पहले या आखिरी पैराग्राफ़   │
│ में छिपा होता है। बीच के पैराग्राफ़ सिर्फ़ सबूत हैं।          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 3: "EXTREME मतलब EXTINCT"                               │
│ विकल्प में always, never, all, none, completely, only दिखे   │
│ तो 90% बार वह गलत है। परीक्षक चरम शब्दों से जाल बिछाता है।  │
│ सही उत्तर में आमतौर पर generally, often, may, likely होता है।│
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 4: "टोन पहचानो — P-C-N"                                 │
│ Positive (प्रशंसा: lauds, praises) | Critical (आलोचना:        │
│ warns, laments, questions) | Neutral (तटस्थ: states, reports)│
│ लेखक के भाव-शब्द पकड़ो, तथ्य-शब्द नहीं।                      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 5: "अनुमान = तथ्य + एक कदम" (T+1 नियम)                 │
│ Inference प्रश्न में सही उत्तर पैसेज से सिर्फ़ एक तार्किक     │
│ कदम आगे होता है। दो कदम आगे = Over-thinking जाल।            │
│ पैसेज में जो सीधे लिखा है, वह inference नहीं, fact है।      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 6: "शब्द-चोर पकड़ो" (Synonym Trap)                      │
│ Vocabulary-in-context में विकल्प में शब्द का सबसे आम अर्थ     │
│ रखा होता है — वही जाल है। उस पंक्ति में शब्द बदलकर पढ़ो;     │
│ जो विकल्प वाक्य का अर्थ न बिगाड़े, वही सही।                  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 7: "HOWEVER के बाद सोना"                                │
│ But, However, Yet, Nevertheless, Although — इनके बाद वाली    │
│ पंक्ति में लेखक की असली राय छिपी होती है। इनके पहले वाला     │
│ हिस्सा अक्सर दूसरों की राय होती है।                           │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 8: "EXCEPT = तीन सच, एक झूठ"                            │
│ EXCEPT/NOT प्रश्न में घबराओ मत। तीन विकल्प पैसेज में मिलेंगे, │
│ एक नहीं मिलेगा — वही उत्तर। नकारात्मक शब्द (NOT/EXCEPT) को   │
│ प्रश्न में घेर लो (underline) ताकि भूलो नहीं।                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 9: "15/45 सेकंड का घड़ी-कानून"                          │
│ Fact-based (सीधा तथ्य, शब्दार्थ, EXCEPT) = 15 सेकंड।         │
│ Inference/Tone/Main Idea = 45 सेकंड।                          │
│ 45 सेकंड में भी न बने तो निशान लगाकर आगे बढ़ो।               │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 10: "ROOT से रास्ता"                                    │
│ अनजाना शब्द दिखे तो तोड़ो: chron (समय) → chronic,            │
│ synchronous; cred (विश्वास) → credible, incredible;           │
│ dict (बोलना) → predict, contradict। मूल शब्द अर्थ का         │
│ 70% हिस्सा बता देता है।                                       │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 11: "दो विकल्प बचें तो पैसेज वापस"                      │
│ दो विकल्पों में फँसो तो अंदाज़ा मत लगाओ — पैसेज की उस पंक्ति  │
│ पर लौटो। जो विकल्प पैसेज के शब्दों से सबसे नज़दीक (लेकिन     │
│ नकल नहीं) हो, वही सही। परीक्षक सही उत्तर को परिभाषित         │
│ (paraphrase) करके देता है।                                    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 12: "लेखक बनो, पाठक नहीं" (Author's Hat)                │
│ हर पैराग्राफ़ के बाद खुद से पूछो: "लेखक यह क्यों लिख रहा     │
│ है?" — बताने के लिए? रोका-टोकी के लिए? चेतावनी के लिए?       │
│ Purpose प्रश्न का उत्तर इसी एक सवाल में छिपा है।             │
└─────────────────────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**🚩 स्किप संकेत 1: 45 सेकंड की दीवार**
Inference या Tone का प्रश्न 45 सेकंड में हल न हो तो तुरंत निशान (mark) लगाकर आगे बढ़ें। अंत में समय बचे तो लौटें। एक अटके प्रश्न पर 2 मिनट गँवाना = बाकी 4 आसान प्रश्नों का नुकसान।

**🚩 स्किप संकेत 2: "दोनों सही लग रहे हैं" स्थिति**
दो विकल्पों में 30 सेकंड से ज़्यादा फँसे रहना = Over-thinking जाल में फँसना। पहली बार जो विकल्प पैसेज-सबूत से जुड़ा लगा था, उसी पर टिकें और आगे बढ़ें। बार-बार उत्तर बदलना आमतौर पर सही को गलत बनाता है।

**🚩 स्किप संकेत 3: अपरिचित विषय का लंबा पैसेज**
अगर पैसेज का विषय (जैसे क्वांटम फिज़िक्स) बिल्कुल नया लगे, तो घबराकर पूरा पैसेज छोड़ें नहीं — बल्कि उसके Fact-based प्रश्न (शब्दार्थ, सीधा तथ्य) पहले करें, क्योंकि उनके उत्तर पैसेज में सीधे लिखे होते हैं। केवल उस पैसेज के कठिन Inference प्रश्न अंत के लिए छोड़ें।
