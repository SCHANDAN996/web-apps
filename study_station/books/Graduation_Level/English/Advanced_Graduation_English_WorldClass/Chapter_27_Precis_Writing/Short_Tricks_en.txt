# 🪄 Short Tricks + Skip Strategy — Precis Writing

---

## 🧠 Mnemonic 1: The Golden Formula — **"P-R-E-C-I-S"**

```
┌─────────────────────────────────────────────┐
│  P — Passage: Read it twice                 │
│  R — Retain: Only main ideas                │
│  E — Exclude: Examples, repetitions, quotes │
│  C — Compress: One-third the length         │
│  I — Indirect: Third person, reported form  │
│  S — Self-check: Title + own words          │
└─────────────────────────────────────────────┘
```
**Trick:** The word *PRECIS* itself is the checklist. If you forget the rules in the exam hall, spell the word!

---

## 🧠 Mnemonic 2: What to CUT — **"F-E-R-D"**

```
┌─────────────────────────────────────────────┐
│  F — Figures of speech (metaphors, similes) │
│  E — Examples & illustrations               │
│  R — Repetitions & quotations               │
│  D — Details (dates, minor names, numbers)  │
└─────────────────────────────────────────────┘
```
**Trick:** "The precis writer is a **FERD**-cutter — he cuts F-E-R-D without mercy."

---

## 🧠 Mnemonic 3: What to KEEP — **"M-A-I-N"**

```
┌─────────────────────────────────────────────┐
│  M — Main argument / thesis                 │
│  A — Author's tone & attitude               │
│  I — Important supporting reasons           │
│  N — Necessary conclusion                   │
└─────────────────────────────────────────────┘
```
**Trick:** Keep the **MAIN** dish, throw away the garnish.

---

## 🧠 Mnemonic 4: The One-Third Rule — **"3-2-1"**

```
┌─────────────────────────────────────────────┐
│  3 — Original passage = 3 parts             │
│  2 — You delete 2 parts                     │
│  1 — Your precis = 1 part (≈ one-third)     │
└─────────────────────────────────────────────┘
```
**Trick:** A 300-word passage → precis of ~100 words. Never exceed one-third; never fall below one-fourth.

---

## 🧠 Mnemonic 5: Reading Strategy — **"S-S-S"**

```
┌─────────────────────────────────────────────┐
│  1st S — SKIM: Read fast for the gist       │
│  2nd S — SCAN: Read slow, underline key     │
│          sentences                          │
│  3rd S — SUMMARIZE: Draft in your own words │
└─────────────────────────────────────────────┘
```
**Trick:** Three passes, three speeds — fast, slow, write.

---

## 🧠 Mnemonic 6: Title Selection — **"C-B-S"**

```
┌─────────────────────────────────────────────┐
│  C — Central idea only (not a side detail)  │
│  B — Brief (3–6 words, never a sentence)    │
│  S — Suitable to the WHOLE passage          │
└─────────────────────────────────────────────┘
```
**Trick:** If a title fits only one paragraph, reject it. The title must cover the passage like an umbrella covers the whole body — not just one hand.

---

## 🧠 Mnemonic 7: Language Rules — **"O-N-T"**

```
┌─────────────────────────────────────────────┐
│  O — Own words (no lifting sentences)       │
│  N — No personal opinion or comment         │
│  T — Third person, past tense, indirect     │
│      speech                                 │
└─────────────────────────────────────────────┘
```
**Trick:** You are a **reporter**, not a **debater**. Report the author; never argue with him.

---

## 🧠 Mnemonic 8: Direct → Indirect Speech — **"S-P-T"**

```
┌─────────────────────────────────────────────┐
│  S — Shift pronouns (I/we → he/they)        │
│  P — Push tense back (is → was, will →      │
│      would)                                 │
│  T — Throw away quotation marks             │
└─────────────────────────────────────────────┘
```
**Trick:** Dialogue in the passage? Convert: *He said, "I will fight"* → *He declared that he would fight.*

---

## 🧠 Mnemonic 9: Compression Weapons — **"O-P-C"**

```
┌─────────────────────────────────────────────┐
│  O — One word for a phrase                  │
│      ("at this point in time" → "now")      │
│  P — Phrase for a clause                    │
│      ("which was built in 1900" → "built    │
│      in 1900")                              │
│  C — Clause merger (join two short          │
│      sentences with and/but/because)        │
└─────────────────────────────────────────────┘
```
**Trick:** Shrink in three gears — word, phrase, clause.

---

## 🧠 Mnemonic 10: The Examiner's Checklist — **"T-L-F-U"**

```
┌─────────────────────────────────────────────┐
│  T — Title given?                           │
│  L — Length within one-third?               │
│  F — Faithful to the author's meaning?      │
│  U — Unified, fluent, own words?            │
└─────────────────────────────────────────────┘
```
**Trick:** Before submitting, ask "T-L-F-U?" — *"Tell Foo?"* — silly, but you will never forget it.

---

## 🧠 Mnemonic 11: Tone Detection — **"P-N-I"**

```
┌─────────────────────────────────────────────┐
│  P — Positive words (praise, hope, benefit) │
│      → Optimistic / Appreciative tone       │
│  N — Negative words (harm, failure, danger) │
│      → Critical / Pessimistic tone          │
│  I — Impartial facts, both sides            │
│      → Analytical / Objective tone          │
└─────────────────────────────────────────────┘
```
**Trick:** Count the emotional words. More praise = positive; more blame = critical; pure facts = objective.

---

## 🧠 Mnemonic 12: Paragraph Order — **"G-B-C"**

```
┌─────────────────────────────────────────────┐
│  G — Gist sentence (the core message)       │
│  B — Body: key arguments in passage order   │
│  C — Conclusion: author's final message     │
└─────────────────────────────────────────────┘
```
**Trick:** Never rearrange the author's logic. Follow the passage like a train follows its track.

---

## 🧠 Mnemonic 13: Word-Count Safety — **"±10 Rule"**

```
┌─────────────────────────────────────────────┐
│  If asked for ~100 words:                   │
│  Safe zone = 90–110 words                   │
│  Below 90  → you cut too much (lost ideas)  │
│  Above 110 → you kept too much (penalty)    │
└─────────────────────────────────────────────┘
```
**Trick:** Count words in your draft once. It takes 30 seconds and saves marks.

---

## 🧠 Mnemonic 14: Common Phrase Compressors — **"The Big Five"**

```
┌─────────────────────────────────────────────┐
│  "in spite of the fact that" → "although"   │
│  "due to the fact that"      → "because"    │
│  "in the event that"         → "if"         │
│  "at the present time"       → "now"        │
│  "a large number of"         → "many"       │
└─────────────────────────────────────────────┘
```
**Trick:** Memorize these five swaps — they appear in almost every precis passage and instantly cut 10–15 words.

---

## ⏭️ Skip Strategy

**1. Skip the decorative sentence, not the load-bearing one.**
If a sentence can be deleted and the passage still makes complete sense, it is decoration — cut it. If deleting it breaks the logic, it is load-bearing — keep it. Test every sentence with this one question: *"Does the argument survive without this?"*

**2. Skip examples, keep the rule they illustrate.**
When a passage says *"Perseverance leads to success. For instance, Thomas Edison failed a thousand times before…"* — write only *"Perseverance leads to success."* The example is the servant of the idea, not the idea itself.

**3. Skip your own opinion — even if you strongly disagree.**
The examiner tests whether you can reproduce the **author's** view, not yours. Adding "but this is wrong because…" or "in my opinion…" is the fastest way to lose marks. Stay invisible; let the author speak.

---

**Final Exam-Hall Sequence (memorize this order):**
**Read twice → Underline main ideas → Cut F-E-R-D → Draft with O-P-C → Check T-L-F-U → Write the title last.**
