# 🪄 Short Tricks + Skip Strategy — Sentence Arrangement

## Trick 1: The "Opener Hunter" Rule

```
┌─────────────────────────────────────────────┐
│  The FIRST sentence can NEVER contain:      │
│  • a pronoun with no noun before it (he, it,│
│    they, this, such)                        │
│  • a connector (but, however, therefore,    │
│    moreover, so, yet)                       │
│  • a conclusion word (thus, hence, finally) │
│  • "also", "too", "as well"                 │
└─────────────────────────────────────────────┘
```
Eliminate any option that starts with such a sentence. In most SSC/Bank questions, this alone kills 2 of 4 options.

## Trick 2: The "Closer Hunter" Rule

```
┌─────────────────────────────────────────────┐
│  The LAST sentence usually contains:        │
│  • thus, hence, therefore, finally,         │
│    in conclusion, as a result, ultimately   │
│  • a result, summary, or future outlook     │
│  • NEVER a fresh new topic                  │
└─────────────────────────────────────────────┘
```

## Trick 3: The Mandatory Pair (MP) Technique — The 80% Weapon

```
┌─────────────────────────────────────────────┐
│  Find ONE unbreakable pair → check options  │
│  → eliminate. One pair often solves all.    │
│                                             │
│  Strongest pairs (in order of reliability): │
│  1. Noun → Pronoun   (Ravi … he)            │
│  2. General → Specific (a man … the man)    │
│  3. Cause → Effect   (rain … flooded)       │
│  4. Question → Answer                       │
│  5. Time sequence    (first … then … later) │
└─────────────────────────────────────────────┘
```
**Mnemonic: "No General Can Question Time"** — **N**oun-pronoun, **G**eneral-specific, **C**ause-effect, **Q**uestion-answer, **T**ime sequence.

## Trick 4: The Article Clue (a/an → the)

```
┌─────────────────────────────────────────────┐
│  "a/an + noun" = FIRST mention              │
│  "the + same noun" = SECOND mention         │
│  So: "a farmer" must come BEFORE            │
│      "the farmer".                          │
└─────────────────────────────────────────────┘
```
This is the single most reliable mechanical clue — no meaning needed, pure pattern.

## Trick 5: The Pronoun Anchor

```
┌─────────────────────────────────────────────┐
│  Every "he/she/it/they/this/these/such"     │
│  must have its noun EARLIER in the passage. │
│  Find the noun → lock the pair.             │
│  "Such + noun" and "This + noun" are the    │
│  strongest backward-pointing arrows.        │
└─────────────────────────────────────────────┘
```

## Trick 6: The Connector Chain

```
┌─────────────────────────────────────────────┐
│  BUT / HOWEVER / YET  → contrast follows a  │
│      positive or opposite statement         │
│  BECAUSE / SINCE      → reason follows claim│
│  SO / THEREFORE       → result follows cause│
│  MOREOVER / ALSO      → addition follows a  │
│      similar point                          │
│  FOR EXAMPLE / FOR INSTANCE → example       │
│      follows a general statement            │
└─────────────────────────────────────────────┘
```
**Mnemonic: "BBS-ME"** — **B**ut contrasts, **B**ecause explains, **S**o concludes, **M**oreover adds, **E**xample illustrates.

## Trick 7: The Definition-First Rule

```
┌─────────────────────────────────────────────┐
│  If one sentence DEFINES a term and another │
│  DISCUSSES it, the definition comes first.  │
│  "Photosynthesis is the process by which…"  │
│  always precedes "This process requires…"   │
└─────────────────────────────────────────────┘
```

## Trick 8: The Chronology Snap

```
┌─────────────────────────────────────────────┐
│  Dates, ages, historical periods, or life   │
│  stages → arrange in time order instantly.  │
│  Born → educated → worked → retired.        │
│  1947 → 1950 → 1991. No thinking needed.    │
└─────────────────────────────────────────────┘
```

## Trick 9: The Option-Reverse Method (for 6-sentence PQRS with fixed 1 & 6)

```
┌─────────────────────────────────────────────┐
│  When S1 and S6 are fixed:                  │
│  1. Read S1 → ask "which of P/Q/R/S can     │
│     logically follow it?"                   │
│  2. Read S6 → ask "which sentence must      │
│     come just before it?"                   │
│  3. The middle two fall into place.         │
└─────────────────────────────────────────────┘
```
Attack from both ends, not from the middle.

## Trick 10: The "Read-Aloud-in-Your-Head" Test

```
┌─────────────────────────────────────────────┐
│  After picking an answer, mentally read the │
│  full sequence once. If any jump feels like │
│  a missing step, your pair is wrong.        │
│  10 seconds of verification saves 1 mark    │
│  of negative marking.                       │
└─────────────────────────────────────────────┘
```

## Trick 11: The Acronym/Full-Form Clue

```
┌─────────────────────────────────────────────┐
│  Full form first, short form later:         │
│  "The United Nations…" → "The UN…"          │
│  "Dr. A.P.J. Abdul Kalam" → "Kalam" / "he"  │
└─────────────────────────────────────────────┘
```

## Trick 12: The Idea-Unit Rule (for hard questions)

```
┌─────────────────────────────────────────────┐
│  When no pronoun/article clue exists, group │
│  sentences by TOPIC CLUSTERS:               │
│  problem-sentences together,                │
│  cause-sentences together,                  │
│  solution-sentences together.               │
│  Standard flow:                             │
│  Topic → Problem → Cause → Solution → Result│
│  Mnemonic: "To People, Caring Solves Rifts" │
└─────────────────────────────────────────────┘
```

## Trick 13: The 2×2 Elimination Grid

```
┌─────────────────────────────────────────────┐
│  Most options differ in only 1-2 positions. │
│  Don't solve the whole sequence — find the  │
│  ONE pair where options disagree, decide    │
│  that pair, and the answer reveals itself.  │
└─────────────────────────────────────────────┘
```

## Trick 14: The Negative-Word Anchor

```
┌─────────────────────────────────────────────┐
│  "Neither" needs "nor". "Not only" needs    │
│  "but also". "No sooner" needs "than".      │
│  In jumbled sentences, these correlative    │
│  halves form instant mandatory pairs.       │
└─────────────────────────────────────────────┘
```

## Trick 15: The 15/45-Second Triage

```
┌─────────────────────────────────────────────┐
│  15-SEC questions (do first):               │
│  • clear pronoun/article/chronology clues   │
│  • 4-sentence arrangements                  │
│  45-SEC questions (do second pass):         │
│  • 6-sentence abstract/philosophical topics │
│  • no mechanical clues, meaning-based only  │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy — When to Leave the Question

**Skip Signal 1 — The "No Anchor" Paragraph.**
After 30 seconds, if you have found **zero** mandatory pairs (no pronoun-noun, no article shift, no connector chain, no chronology), the question is purely meaning-based and can eat 2+ minutes. Mark it, move on, return in the last 5 minutes. One arrangement question is worth the same 1–2 marks as a 10-second vocabulary question.

**Skip Signal 2 — The "Two Options Both Work" Trap.**
If two options both seem logically smooth after one full read, do NOT keep re-reading — your accuracy on the third read barely improves. Pick the one where the **mandatory pair** (not just "flow") is satisfied, or skip. Over-thinking is the examiner's favourite trap in arrangement questions.

**Skip Signal 3 — The Abstract Opener.**
If all four sentences are philosophical/abstract (about "society", "values", "truth") with no concrete nouns, the opener is hard to identify and error risk is high. Attempt these only after all concrete-topic arrangements are done. In negative-marking exams, a skipped question costs 0; a guessed abstract arrangement costs 0.25–0.50.

**Golden Rule of Skipping:** Never skip *before* checking for the article clue (a → the) and the pronoun anchor. These two checks take under 15 seconds and solve roughly half of all arrangement questions. Skip only *after* these two checks fail.
