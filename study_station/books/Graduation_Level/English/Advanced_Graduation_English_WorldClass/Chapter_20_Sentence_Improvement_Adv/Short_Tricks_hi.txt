# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — वाक्य सुधार (उन्नत)

## ⚡ 12 म्नेमोनिक ट्रिक्स

┌─────────────────────────────────────────────┐
│ ट्रिक 1: **"SV-दूरी जाल"**                    │
│ कर्ता और क्रिया के बीच कितना भी लंबा वाक्यांश   │
│ आए — क्रिया हमेशा असली कर्ता के अनुसार।        │
│ "The quality of apples **was** good."         │
│ (apples नहीं, quality कर्ता है!)               │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 2: **"EACH-EVERY = एक"**                │
│ Each, Every, Everyone, Everybody, Either,     │
│ Neither → हमेशा एकवचन क्रिया।                  │
│ याद रखें: **"3E + EN = Singular"**            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 3: **"Nor-Or नज़दीकी नियम"**             │
│ Either…or / Neither…nor में क्रिया **पास वाले**  │
│ कर्ता के अनुसार।                               │
│ "Neither the teacher nor the students **were**│
│ present." (students पास है → were)            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 4: **"No sooner = Than"**               │
│ No sooner के साथ हमेशा **than**, कभी when नहीं।│
│ जोड़ी याद रखें: **Sooner–Than, Hardly–When,**  │
│ **Scarcely–When** (S-T, H-W, S-W)             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 5: **"Inversion की घंटी"**               │
│ वाक्य की शुरुआत No sooner / Hardly / Scarcely /│
│ Seldom / Never से हो → सहायक क्रिया कर्ता से    │
│ **पहले**: "No sooner **had he** entered…"     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 6: **"Prefer = To"**                    │
│ Prefer, Superior, Inferior, Senior, Junior,   │
│ Prior के साथ **than नहीं, to** लगता है।        │
│ याद रखें: **"PSISJP — सब To के दीवाने"**       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 7: **"One of the + बहुवचन + एकवचन"**     │
│ "One of the + बहुवचन संज्ञा + एकवचन क्रिया"     │
│ "One of my **friends has** come."             │
│ (friends बहुवचन, लेकिन क्रिया has — कर्ता One) │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 8: **"Since–For घड़ी"**                  │
│ **Since = बिंदु** (Monday, 2010, childhood)    │
│ **For = अवधि** (two years, a long time)       │
│ याद रखें: **"Since-Point, For-Period" (PP)**   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 9: **"If I were — कल्पना का were"**      │
│ काल्पनिक स्थिति (Subjunctive) में I/he/she/it  │
│ सबके साथ **were**: "If I **were** a bird…"    │
│ याद रखें: **"सपने में सब were"**               │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 10: **"Collective = टीम एक"**            │
│ Team, Committee, Jury, Government — जब एक      │
│ इकाई की तरह काम करें → एकवचन क्रिया।           │
│ "The committee **has** decided."              │
│ (बँटवारा दिखे तभी बहुवचन)                     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 11: **"Had + V3 = पहले वाला काम"**       │
│ दो भूतकालीन घटनाएँ हों तो **पहले हुई** घटना    │
│ Past Perfect (had + V3) में, बाद वाली Simple   │
│ Past में: "The train **had left** before I     │
│ **reached**." याद रखें: **"पहले Had, बाद में   │
│ Simple"**                                      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 12: **"Sound-Right जाल से सावधान"**      │
│ जो सुनने में सही लगे वही परीक्षक का हथियार है: │
│ ❌ "What you are doing?"                       │
│ ✅ "What **are you** doing?"                   │
│ प्रश्नवाचक वाक्य में सहायक क्रिया कर्ता से पहले। │
└─────────────────────────────────────────────┘

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**1. दो विकल्प लगभग एक जैसे हों और दोनों व्याकरणिक रूप से सही लगें**
ऐसे प्रश्न में अंतर अक्सर अत्यंत सूक्ष्म (idiom/register) होता है। 45 सेकंड में निश्चित न हों तो चिह्नित करके आगे बढ़ें — अंत में लौटें। अंदाज़े से negative marking का नुकसान संभव है।

**2. "No improvement required" विकल्प वाले प्रश्न में जल्दबाज़ी न करें**
परीक्षक जानबूझकर सही वाक्य देकर तीन "सुधार" विकल्प देता है। यदि मूल वाक्य सभी नियमों (S-V agreement, tense, preposition) पर खरा उतरे, तो "No improvement" ही उत्तर है — लेकिन यह जाँच 30 सेकंड से कम में पूरी न हो तो प्रश्न छोड़कर बाद में आएँ।

**3. लंबे वाक्य जिसमें underline हिस्सा बहुत छोटा हो**
पूरा वाक्य पढ़ने में समय न गँवाएँ — केवल underline हिस्से और उसके आसपास के 4–5 शब्द पढ़ें। फिर भी संदर्भ अस्पष्ट रहे तो उस प्रश्न को अंत के लिए छोड़ दें; पहले तथ्यात्मक (15-सेकंड) प्रश्न निपटाएँ।
