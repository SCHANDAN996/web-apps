🪄 Short Tricks + Skip Strategy — सर्वनाम (Pronoun)

═══════════════════════════════════
📦 म्नेमोनिक ट्रिक्स (Mnemonic Tricks)
═══════════════════════════════════

┌─────────────────────────────────────┐
│ ट्रिक 1: "B-E" — Objective Case     │
│ Between, Except — Preposition के    │
│ बाद हमेशा Objective Case: me, him,  │
│ her, us, them।                       │
│ ❌ between you and I                 │
│ ✅ between you and me                │
│ (ध्यान दें: 'and' conjunction है,    │
│ preposition नहीं — अकेले 'and' के    │
│ बाद case नहीं बदलता।)               │
│ ⚠️ than/as के बाद यह नियम लागू      │
│ नहीं — वहाँ case छिपे हुए verb पर   │
│ निर्भर करता है (ट्रिक 4 देखें)।      │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 2: "231 Rule" — क्रम याद रखें  │
│ अच्छे काम में क्रम: You(2) → He(3)  │
│ → I(1) = "231"                       │
│ बुरे काम/गलती में: I(1) → You(2) →  │
│ He(3) = "123"                        │
│ ✅ You, he and I passed.             │
│ ✅ I, you and he failed.             │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 3: "Each-Every-Either-Neither"│
│ = E-E-E-N → सब Singular!            │
│ "चार E-N की सेना, Verb हमेशा अकेली" │
│ ✅ Each of the boys has a pen.       │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 4: "Than Me या Than I?"       │
│ वाक्य पूरा करके देखो:               │
│ "He is taller than I (am)." ✅      │
│ Verb छिपा हो तो Subject Case लगाओ;  │
│ verb पूरा दिया हो और pronoun उसका   │
│ object हो तो Objective Case:        │
│ ✅ I know you better than (I know)   │
│ him.                                 │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 5: "One → One, Never He"      │
│ One से शुरू, One से खत्म:           │
│ ✅ One should do one's duty.         │
│ ❌ One should do his duty.           │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 6: "It is I, not It is me"    │
│ To-be verb (is/was) के बाद Subject  │
│ Case (परीक्षा-नियम):                │
│ ✅ It is I who called.               │
│ (बोलचाल में "It's me" चलता है,      │
│ परीक्षा में नहीं!)                   │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 7: "Who vs Whom — Him Test"   │
│ उत्तर He → Who लगाओ                  │
│ उत्तर Him → Whom लगाओ                │
│ "M वाले से M वाला" (Whom↔Him)        │
│ ✅ Whom did you meet? — I met him.   │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 8: "A-A-E-P-A" — Reflexive    │
│ Verbs की पाँच साथी                   │
│ Avail, Absent, Enjoy, Pride,        │
│ Acquit — इनके साथ Reflexive Pronoun │
│ (myself/himself/oneself) लगता है:   │
│ ✅ He availed himself of the offer.  │
│ ✅ She absented herself from class.  │
│ ✅ They enjoyed themselves.          │
│ ✅ He prides himself on his honesty. │
│ ✅ He acquitted himself well.        │
│ (ध्यान दें: हर verb के साथ Reflexive │
│ अनिवार्य नहीं — केवल यही चुनिंदा     │
│ verbs याद रखें।)                     │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 9: "Same…as / Such…as"        │
│ Same और Such के बाद conjunction     │
│ 'as' का प्रयोग होता है (who/which   │
│ नहीं):                               │
│ ✅ This is the same book as I lost.  │
│ ✅ He is not such a man as will      │
│ tell a lie.                          │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 10: "Superlative + That"      │
│ Superlative, All, Only, Any, None,  │
│ No के बाद 'that' (which नहीं):      │
│ ✅ This is the best book that I have.│
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 11: "Both-Few-Many-Several"   │
│ = Plural Verb की सेना                │
│ ✅ Both of them were present.        │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 12: "Let + Me"                 │
│ Let के बाद हमेशा Objective Case:    │
│ ✅ Let him and me go.                │
│ ❌ Let he and I go.                  │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 13: "None = Singular भी!"     │
│ None of + Plural Noun → Verb        │
│ Singular (परीक्षा-पसंद):            │
│ ✅ None of the students was absent.  │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 14: "Possessive के साथ        │
│ Apostrophe मना है"                   │
│ yours, hers, ours, theirs, its —    │
│ कभी ' नहीं। it's = it is!           │
│ ✅ The dog wagged its tail.          │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ ट्रिक 15: "Each Other ↔ One Another"│
│ दो के लिए Each Other,               │
│ दो से अधिक के लिए One Another:      │
│ ✅ Ram and Shyam help each other.    │
│ ✅ The players help one another.     │
└─────────────────────────────────────┘

═══════════════════════════════════
⏭️ Skip Strategy — कब प्रश्न छोड़ें
═══════════════════════════════════

🚩 रणनीति 1 — "दोनों लगते हैं सही" (Who/Whom, I/Me):
अगर 30 सेकंड में Him-Test या Verb-Completion ट्रिक से फैसला न हो, तो प्रश्न मार्क करके आगे बढ़ें। अनुमान पर टिक करने से Negative Marking का जोखिम — अंत में समय बचे तो लौटें।

🚩 रणनीति 2 — लंबा Intervening Phrase वाला Error Spotting:
"Each of the boys, along with his friends and teachers, ___" जैसे प्रश्न में Subject ढूँढने में समय लगे तो पहले बाकी प्रश्न निपटाएँ। ये 'तार्किक' प्रश्न हैं — इन्हें 45 सेकंड का बजट दें, 15 सेकंड में जबरन मत हल करें।

🚩 रणनीति 3 — अपरिचित Reflexive Verb:
अगर verb पहचान में न आए कि इसके साथ Reflexive Pronoun लगता है या नहीं, तो coin-flip मत करें। छोड़ दें — याद किया हुआ A-A-E-P-A समूह ही भरोसेमंद है, अनुमान नहीं।

═══════════════════════════════════
⚡ अंतिम सुझाव: पहले 15-सेकंड वाले तथ्यात्मक प्रश्न (Case, Number-Agreement) निपटाएँ, फिर 45-सेकंड वाले तार्किक प्रश्नों पर लौटें। Pronoun में गलती का सबसे बड़ा कारण जल्दबाज़ी है, अज्ञान नहीं।
