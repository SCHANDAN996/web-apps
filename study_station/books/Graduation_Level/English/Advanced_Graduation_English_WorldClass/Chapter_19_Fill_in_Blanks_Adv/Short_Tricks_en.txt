# 🪄 Short Tricks + Skip Strategy — Fill in the Blanks (Advanced)

## Trick 1 — The "Read the Whole Sentence First" Rule
Never look at the options before reading the complete sentence. The blank's answer is hidden in the sentence's own logic — a contrast word (*but, although, despite*), a cause word (*because, since*), or a parallel structure. Options are designed to seduce you; the sentence is designed to guide you.

## Trick 2 — The Contrast Flip
```
┌─────────────────────────────────────────────┐
│  See BUT / ALTHOUGH / DESPITE / YET /       │
│  WHEREAS → the blank must be the OPPOSITE   │
│  of the idea on the other side.             │
└─────────────────────────────────────────────┘
```
"Although he was wealthy, he lived a ______ life." → wealthy ↔ opposite → **frugal/simple**.

## Trick 3 — The Cause-Effect Mirror
```
┌─────────────────────────────────────────────┐
│  See BECAUSE / SINCE / THEREFORE / HENCE /  │
│  CONSEQUENTLY → the blank must MATCH the    │
│  direction (positive → positive,            │
│  negative → negative).                      │
└─────────────────────────────────────────────┘
```
"Because the evidence was ______, the court acquitted him." → acquittal is negative for prosecution → **insufficient/flimsy**.

## Trick 4 — Mnemonic: "PREP" for Preposition Blanks
```
┌─────────────────────────────────────────────┐
│  P — Phrase fixed? (abide BY, consist OF)   │
│  R — Rule of gerund (preposition + V-ing)   │
│  E — Examine the verb/adjective before it   │
│  P — Plug each option and read aloud        │
└─────────────────────────────────────────────┘
```
Fixed prepositions are memory items, not logic items: *accused **of**, devoid **of**, comply **with**, differ **from**, insist **on**, eligible **for***.

## Trick 5 — Mnemonic: "SVA-Check" (Subject–Verb Agreement)
```
┌─────────────────────────────────────────────┐
│  S — Strip the sentence: remove phrases     │
│      between subject and verb               │
│  V — Verify the REAL subject (not the       │
│      nearest noun!)                         │
│  A — Agree: singular subject → singular verb│
└─────────────────────────────────────────────┘
```
"The quality of the apples ______ good." → Strip "of the apples" → subject = *quality* → **is**, not *are*. (Trap: nearest noun *apples*.)

## Trick 6 — The Pair Test for Double Blanks
Don't solve blank 1 fully, then blank 2. Instead:
1. Eliminate options where **either** word fails.
2. Usually 2 options die on blank 1, 1 more dies on blank 2.
3. Read the surviving full pair into the sentence once.

Often the second blank alone eliminates three options — check the easier blank first!

## Trick 7 — Mnemonic: "TONE" for Vocabulary-in-Context
```
┌─────────────────────────────────────────────┐
│  T — Topic of the sentence (formal/casual?) │
│  O — Opinion: is the writer praising or     │
│      criticising?                           │
│  N — Negative or positive charge needed?    │
│  E — Exact degree: mild word or extreme?    │
└─────────────────────────────────────────────┘
```
*Frugal* (mild, positive) vs *miserly* (negative) vs *extravagant* (opposite) — same family, different charge. Examiners love this trap.

## Trick 8 — The Article Shortcut
- "______ university / European / one-rupee" → consonant **sound** → **a** (sound, not spelling!).
- "______ hour / honest / heir" → vowel sound → **an**.
- Unique things, superlatives, ordinals → **the** (*the Sun, the best, the first*).

## Trick 9 — Mnemonic: "FANBOYS vs. SPOONS" for Connectors
```
┌─────────────────────────────────────────────┐
│  FANBOYS (and, but, or, yet, so...) join    │
│  EQUALS — same grammar on both sides.       │
│  Subordinators (although, because, unless)  │
│  join UNEQUALS — one clause depends.        │
│  Never use BOTH: "Although...but" ❌        │
└─────────────────────────────────────────────┘
```

## Trick 10 — The Parallel Structure Scan
In lists and comparisons, the blank must match the grammatical form of its neighbours:
"He likes reading, swimming, and ______." → **jogging** (not *to jog*).
Spot the pattern in 5 seconds: find the word before the blank's partner items.

## Trick 11 — Mnemonic: "CUPS" for Tense Blanks
```
┌─────────────────────────────────────────────┐
│  C — Clue word? (since, ago, already, by    │
│      the time, yesterday)                   │
│  U — Universal truth? → simple present      │
│  P — Past + past? → earlier action takes    │
│      past perfect                           │
│  S — Sequence check: does the timeline      │
│      make sense?                            │
└─────────────────────────────────────────────┘
```
"Since 2010" → present perfect (*has lived*). "By the time we arrived, the train ______" → **had left**.

## Trick 12 — The "Sound-Right" Alarm
```
┌─────────────────────────────────────────────┐
│  ⚠️ If an option "sounds right" because     │
│  you've heard it in spoken English, be      │
│  suspicious. Exam English tests WRITTEN     │
│  standard: "different FROM" (not than),     │
│  "comprises" (not "comprises of"),          │
│  "despite" (not "despite of").              │
└─────────────────────────────────────────────┘
```

## Trick 13 — The Collocation Reflex
Some words marry specific partners: *make* a decision (not *do*), *do* homework (not *make*), *heavy* rain (not *strong*), *strong* coffee (not *powerful*), *commit* a crime, *pay* attention. When two options are both grammatically fine, the natural **collocation** wins.

## Trick 14 — The Elimination Order (45-second path)
1. Grammar kill: any option breaking agreement/tense/preposition? Out.
2. Meaning kill: any option opposite to the sentence's logic? Out.
3. Tone kill: wrong charge (positive vs negative)? Out.
4. Last two standing? Read both aloud in the full sentence — the collocation reveals itself.

## Trick 15 — Mnemonic: "BLANK" — the 5-Step Master Drill
```
┌─────────────────────────────────────────────┐
│  B — Bracket the blank's partner words      │
│  L — Look for signal words (but, because,   │
│      since, despite)                        │
│  A — Assess tone: positive or negative?     │
│  N — Narrow options by grammar first        │
│  K — Keep the collocation that sounds       │
│      natural in formal English              │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy

**Skip Tip 1 — The 20-Second Verdict.**
If after 20 seconds you cannot eliminate even one option, mark the question and move on. Fill-in-the-blank questions are independent — skipping one costs nothing on the next. Return only after finishing the section; a fresh read often cracks it instantly.

**Skip Tip 2 — Don't Fight Double-Blank Wars.**
If a double-blank question has all four options looking plausible on the first blank, jump straight to the second blank. If the second blank also fails to eliminate at least two options within 30 seconds, skip it. These are designed as time-traps for perfectionists.

**Skip Tip 3 — Never Guess Between "Sound-Alike" Pairs Under Negative Marking.**
When your choice narrows to two options that differ only in nuance (e.g., *elicit* vs *illicit*, *affect* vs *effect*, *principal* vs *principle*) and you genuinely don't know the distinction, leave it blank if the exam has negative marking. A 50-50 guess with a 0.25 penalty is a losing bet over time — bank your energy on questions where elimination has already done the work.
