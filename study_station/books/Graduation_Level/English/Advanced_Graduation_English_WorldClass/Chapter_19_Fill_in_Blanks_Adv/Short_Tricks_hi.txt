# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — रिक्त स्थान भरें (उन्नत)

## 🎯 12 म्नेमोनिक ट्रिक्स

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 1: "SV दूरियाँ मत देखो"**                    │
│ कर्ता और क्रिया के बीच आया वाक्यांश (Intervening      │
│ Phrase) को काट दो, फिर verb चुनो।                    │
│ The quality of apples **is** good. (quality → is)    │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 2: "Each-Every-Neither = हमेशा Singular"**    │
│ EEN (ईन) याद रखो — Each, Every, Neither, Either,    │
│ Everyone, Somebody → singular verb/pronoun.          │
│ Each of the boys **has** a pen.                      │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 3: "And जोड़े तो Plural, Or जोड़े तो पास वाला"** │
│ Ram and Shyam **are** friends.                       │
│ Neither Ram nor his friends **are** here.            │
│ (or/nor में verb पास वाले subject के अनुसार)          │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 4: "Since बिंदु, For अवधि"**                  │
│ Since = समय का बिंदु (since 2010, since Monday)      │
│ For = समय की अवधि (for ten years, for two hours)     │
│ याद रखो: **S = Spot, F = Full duration**             │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 5: "No sooner…than, Hardly…when"**            │
│ जोड़े हमेशा युगल में:                                  │
│ No sooner had he come **than** it rained.            │
│ Hardly had she slept **when** the phone rang.        │
│ ⚠️ than/when की अदला-बदली = परीक्षक का पसंदीदा जाल!   │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 6: "Had + V3 = Past का Past"**                │
│ दो पुरानी घटनाएँ हों तो पहले वाली Past Perfect में:    │
│ The train **had left** before I reached.             │
│ ट्रिक: "पहले हुई = had, बाद में हुई = simple past"     │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 7: "If I were — कल्पना में were"**             │
│ काल्पनिक वाक्यों (subjunctive) में I/he/she सबके साथ   │
│ **were**: If I **were** a bird… (was ❌)              │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 8: "Preposition के बाद -ing"**                 │
│ of, in, on, at, for, by, without, before, after के   │
│ बाद verb की ing form: He is good **at singing**.     │
│ (to-infinitive अपवाद: to + V1)                       │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 9: "Less चीज़, Fewer गिनती"**                  │
│ Less = अगणनीय (less water), Fewer = गणनीय            │
│ (fewer students)। याद रखो: **F = Fewer = Finger-     │
│ count** (उँगलियों पर गिन सकते हो)                     │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 10: "Between दो, Among भीड़"**                 │
│ Between = दो के बीच, Among = तीन या अधिक के बीच।      │
│ Between you **and me** (and I ❌ — preposition के बाद  │
│ object form!)                                        │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 11: "Root देखो, शब्द खुलो"**                   │
│ अनजाना शब्द आए तो root तोड़ो:                          │
│ bene = अच्छा → benefit, benevolent                   │
│ mal = बुरा → malnutrition, malicious                 │
│ dict = बोलना → predict, dictionary                   │
│ अर्थ का 70% अंदाज़ा root से ही लग जाता है!             │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **ट्रिक 12: "Tone पहले, शब्द बाद में"**                 │
│ Context-based blank में पहले वाक्य की भावना पकड़ो      │
│ (सकारात्मक/नकारात्मक), फिर विकल्प छाँटो। आधे विकल्प    │
│ सिर्फ़ tone से कट जाते हैं।                            │
│ "Despite the setback, she remained ___" → positive   │
│ शब्द चाहिए (optimistic ✓, miserable ❌)                │
└─────────────────────────────────────────────────────┘

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**1. दो विकल्प लगभग एक जैसे हों और समय 45 सेकंड पार कर जाए:**
जैसे "elicit / illicit" या "affect / effect" में अटक गए और root/collocation से भी फैसला न हो — प्रश्न चिह्नित करके आगे बढ़ो। अंत में वापस आओ; अक्सर दूसरी बार पढ़ने पर context साफ़ हो जाता है।

**2. अनजाना idiom/phrasal verb हो और कोई clue न मिले:**
Idiom याद है या नहीं — तर्क से नहीं निकाला जा सकता। 15 सेकंड में पहचान न आए तो अनुमान लगाकर आगे बढ़ो; negative marking में बिना सोचे टिक करने से बेहतर है छोड़ना।

**3. लंबा inference-based blank जिसमें पूरा पैरा पढ़ना पड़े:**
पेपर के अंत में ऐसे प्रश्न रखो। पहले सारे fact-based (grammar rule वाले) प्रश्न निपटाओ — वे 15 सेकंड में निश्चित अंक देते हैं; inference प्रश्न 45 सेकंड माँगते हैं और गलती की गुंजाइश भी ज़्यादा रखते हैं।

**याद रखने वाला मंत्र:** "पहले निश्चित, फिर संदिग्ध, अंत में अनुमान।"
