# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — उन्नत क्लोज़ टेस्ट

## 🎯 12 म्नेमोनिक ट्रिक्स

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 1: "पहले पढ़ो, बाद में भरो" (Read-Fill Rule)   │
│ पूरा पैरा एक बार बिना विकल्प देखे पढ़ें। पैसेज का    │
│ टोन (सकारात्मक/नकारात्मक/तटस्थ) पकड़ें — 60% ब्लैंक  │
│ सिर्फ़ टोन से हल हो जाते हैं।                        │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 2: "± टोन टेस्ट"                                │
│ ब्लैंक के आसपास but, however, although दिखे तो       │
│ टोन पलटता है: पहले (+) तो बाद (−), पहले (−) तो (+)। │
│ याद रखें: "BUT = U-TURN"                             │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 3: "जोड़ी पहचानो" (Collocation Catch)          │
│ अंग्रेज़ी में शब्द अकेले नहीं, जोड़ी में चलते हैं:     │
│ make a decision (do नहीं), heavy rain (strong नहीं), │
│ fast car (quick नहीं), pay attention (give नहीं)।    │
│ ब्लैंक से पहले/बाद का शब्द ही उत्तर बताता है।        │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 4: "PREP-LOCK" — प्रीपोज़िशन ताला               │
│ depend ON, consist OF, insist ON, succeed IN,        │
│ afraid OF, good AT, interested IN, married TO।       │
│ ब्लैंक के बाद प्रीपोज़िशन दिखे तो वही कुंजी है।      │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 5: "A-E-I-O-U लॉजिक" (Article Trick)           │
│ a/an/the में उलझें तो पूछें:                         │
│ (1) पहली बार ज़िक्र? → a/an                          │
│ (2) दोबारा ज़िक्र या खास चीज़? → the                 │
│ (3) ध्वनि देखें, अक्षर नहीं: an hour, a university।  │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 6: "S-V दूरी जाल" (Intervening Phrase Alert)   │
│ Subject और verb के बीच लंबा phrase आए तो verb        │
│ असली subject से मेल खाएगा, बीच के noun से नहीं:      │
│ "The quality of apples WAS good" (were नहीं)।        │
│ ट्रिक: बीच का phrase ढककर subject-verb जोड़ें।       │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 7: "Connector Compass" (संयोजक दिशासूचक)       │
│ जोड़ = and, also, moreover (एक ही दिशा)              │
│ विरोध = but, however, yet (उल्टी दिशा)               │
│ कारण = because, since, as (पीछे कारण)                │
│ परिणाम = so, therefore, thus (आगे नतीजा)             │
│ ब्लैंक के दोनों ओर की दिशा देखकर compass घुमाएँ।     │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 8: "ROOT-खोजी" (अर्थ अनुमान)                   │
│ अनजाना शब्द = Root + Prefix/Suffix तोड़ो:            │
│ bene = अच्छा (benefit, benevolent)                   │
│ mal = बुरा (malnutrition, malicious)                 │
│ chron = समय (chronology, chronic)                    │
│ dict = बोलना (predict, dictionary)                   │
│ spect = देखना (inspect, spectator)                   │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 9: "Pronoun Mirror" (सर्वनाम दर्पण)            │
│ it/they/this/these वाले ब्लैंक में पीछे मुड़कर देखें: │
│ सर्वनाम किस noun की ओर इशारा कर रहा है?             │
│ एकवचन noun → it/this; बहुवचन → they/these।          │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 10: "Tense Timeline" (काल रेखा)                │
│ पैसेज का मुख्य काल पकड़ें (past/present)।            │
│ सभी ब्लैंक उसी timeline पर रहेंगे, जब तक कोई         │
│ समय-संकेत (yesterday, by 2030, already) न बदले।      │
│ "Since + point of time → perfect tense" याद रखें।    │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 11: "Eliminate Twins" (जुड़वाँ विकल्प काटो)    │
│ दो विकल्पों का अर्थ लगभग एक हो तो दोनों गलत हैं —    │
│ परीक्षक एक ही सही उत्तर रखता है। बचे दो में          │
│ collocation और टोन से चुनें।                         │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ट्रिक 12: "Sound-Right चेतावनी"                      │
│ जो विकल्प "सुनने में सही" लगे, वही अक्सर जाल है:     │
│ ❌ "discuss about" → ✅ "discuss"                    │
│ ❌ "return back" → ✅ "return"                       │
│ ❌ "comprise of" → ✅ "comprise / consist of"        │
│ कान पर नहीं, नियम पर भरोसा करें।                     │
└─────────────────────────────────────────────────────┘
```

## ⏭️ स्किप रणनीति (कब प्रश्न छोड़ें)

```
┌─────────────────────────────────────────────────────┐
│ स्किप नियम 1: "दो बार पढ़ा, फिर भी धुंधला?"          │
│ किसी ब्लैंक पर 45 सेकंड से ज़्यादा न दें। पैसेज के    │
│ बाकी ब्लैंक भरने के बाद संदर्भ साफ़ होकर उत्तर        │
│ अक्सर खुद दिख जाता है — पहले आगे बढ़ें, बाद में लौटें।│
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ स्किप नियम 2: "50-50 पर तुक्का नहीं"                 │
│ दो विकल्पों में फँसे हों और negative marking हो,     │
│ तो प्रश्न छोड़ना बेहतर है। तुक्का तभी लगाएँ जब       │
│ कम से कम 2 विकल्प पक्के काट चुके हों।                │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ स्किप नियम 3: "Vocabulary ब्लैंक = तुरंत फैसला"      │
│ शब्दार्थ-आधारित ब्लैंक (अनजाना शब्द) में सोचने से    │
│ उत्तर नहीं आता — या तो जानते हैं या नहीं। 15 सेकंड    │
│ में न आए तो छोड़ें; उस समय में 2 grammar ब्लैंक      │
│ हल कर लेंगे। पहले आसान, फिर कठिन — क्रम बदलना        │
│ सबसे बड़ी ट्रिक है।                                  │
└─────────────────────────────────────────────────────┘
```

## 🏁 अंतिम मंत्र

**"पहले टोन, फिर जोड़ी, फिर नियम — और 45 सेकंड की लकीर।"**
हर ब्लैंक के लिए क्रम यही रखें: (1) पैसेज का टोन मेल खाता है? (2) कोई collocation/प्रीपोज़िशन जोड़ी है? (3) कोई व्याकरण नियम लगता है? तीनों में जो पहले जवाब दे, वही उत्तर।
