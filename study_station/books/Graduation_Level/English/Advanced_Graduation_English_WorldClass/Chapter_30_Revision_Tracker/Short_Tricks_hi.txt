# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति
## रिवीजन ट्रैकर / Revision Tracker

---

## 🎯 भाग 1: रिवीजन ट्रैकर की 12 म्नेमोनिक ट्रिक्स

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 1: "3-7-21" — रिवीजन का जादुई चक्र              │
│ नया टॉपिक पढ़ने के बाद: 3 दिन बाद → 7 दिन बाद →      │
│ 21 दिन बाद दोहराएँ। तीन बार रिवीजन = स्थायी स्मृति।   │
│ याद रखें: "तीन-सात-इक्कीस, भूलने की बात ख़त्म!"        │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 2: "RAG" — ट्रैफिक लाइट ट्रैकिंग                 │
│ हर टॉपिक को रंग दो:                                   │
│ 🔴 Red = कमज़ोर (फिर से पढ़ो)                         │
│ 🟡 Amber = ठीक-ठाक (1 रिवीजन बाकी)                    │
│ 🟢 Green = तैयार (सिर्फ़ टेस्ट से जाँचो)               │
│ नियम: हर हफ़्ते कम से कम 2 Red को Green बनाओ।          │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 3: "भूलो मत, ब्लर्ट करो" (Blurting)              │
│ किताब बंद करो → खाली कागज़ पर जो याद है लिखो →        │
│ खोलकर जाँचो। जो नहीं लिख पाए = वही कमज़ोर है।          │
│ याद रखें: "बिन देखे लिखो, फिर मिलाओ"                  │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 4: "80-20 रिवीजन नियम"                           │
│ 80% गलतियाँ 20% टॉपिक्स से आती हैं।                    │
│ अपनी गलतियों की डायरी बनाओ — वही 20% पकड़ो,           │
│ उसी पर बार-बार रिवीजन करो।                            │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 5: "ERROR" — गलती-डायरी का कोड                   │
│ E = Error (गलती क्या थी)                              │
│ R = Rule (कौन सा नियम टूटा)                           │
│ R = Right form (सही रूप क्या है)                       │
│ O = Once more (एक और उदाहरण लिखो)                     │
│ R = Revise date (कब दोहराओगे)                         │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 6: "पहले कमज़ोर, बाद में मज़बूत"                  │
│ रिवीजन हमेशा Red टॉपिक से शुरू करो।                    │
│ मज़बूत टॉपिक दोहराने में मज़ा आता है, पर फायदा          │
│ कमज़ोर टॉपिक दोहराने में है।                            │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 7: "एक पन्ना, एक टॉपिक" (One-Pager)              │
│ हर टॉपिक का सार एक पन्ने में — नियम, जाल, 2 उदाहरण।    │
│ परीक्षा से पहले सिर्फ़ यही one-pagers पलटो।            │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 8: "T-R-E-S-T" — रिवीजन शीट के 5 खाने            │
│ T = Topic (टॉपिक का नाम)                              │
│ R = Rule (मुख्य नियम)                                 │
│ E = Example (एक उदाहरण)                               │
│ S = Slip (मेरी आम गलती)                               │
│ T = Test date (अगली जाँच कब)                          │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 9: "24 घंटे का नियम"                             │
│ आज जो पढ़ा, उसे 24 घंटे के अंदर एक बार ज़रूर दोहराओ।   │
│ पहले दिन का रिवीजन सबसे सस्ता और सबसे असरदार है।      │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 10: "गलत = सोना" (Error = Gold)                  │
│ मॉक टेस्ट की हर गलती एक खज़ाना है।                     │
│ गलती छिपाओ मत — ट्रैकर में दर्ज करो, नियम लिखो,        │
│ 3 दिन बाद उसी टाइप का प्रश्न फिर हल करो।              │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 11: "स्पेस्ड रिपीटिशन की सीढ़ी"                   │
│ रिवीजन 1 → अगले दिन                                   │
│ रिवीजन 2 → 3 दिन बाद                                  │
│ रिवीजन 3 → 7 दिन बाद                                  │
│ रिवीजन 4 → 21 दिन बाद                                 │
│ हर सीढ़ी के बाद भूलने की गति आधी हो जाती है।           │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ ट्रिक 12: "Feynman टेस्ट"                              │
│ अगर तुम किसी नियम को 12 साल के बच्चे को नहीं समझा      │
│ सकते, तो वह टॉपिक अभी Green नहीं है — Amber रखो।      │
│ याद रखें: "समझाओगे तभी समझे कहलाओगे।"                  │
└─────────────────────────────────────────────────────┘
```

## ⏭️ भाग 2: Skip Strategy — कब प्रश्न छोड़ें

```
┌─────────────────────────────────────────────────────┐
│ स्किप टिप 1: "दो बार पढ़ा, फिर भी खाली?"               │
│ अगर प्रश्न दो बार पढ़ने के बाद भी समझ न आए या          │
│ कोई नियम याद न आए — तुरंत mark करके आगे बढ़ो।         │
│ अंत में समय बचे तो लौटो। एक प्रश्न पर अटककर            │
│ तीन आसान प्रश्न मत गंवाओ।                              │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ स्किप टिप 2: "50-50 का फँसाव"                          │
│ दो विकल्पों में फँसे हो और 30 सेकंड में फैसला न हो —    │
│ अंदाज़ा लगाने के बजाय छोड़ो (negative marking में       │
│ यही समझदारी है)। अपनी गलती-डायरी में इस टाइप को        │
│ दर्ज करो — यही तुम्हारा अगला रिवीजन टॉपिक है।          │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│ स्किप टिप 3: "लंबा RC, कम समय"                         │
│ अंतिम 10 मिनट में लंबा Reading Comprehension           │
│ passage मत शुरू करो। पहले Vocabulary और Grammar के     │
│ छोटे प्रश्न निपटाओ — कम समय में ज़्यादा निश्चित अंक।    │
└─────────────────────────────────────────────────────┘
```

## 📌 अंतिम मंत्र

> **"रिवीजन ट्रैकर = तुम्हारी कमज़ोरियों का नक्शा।
> जो मापता है, वही सुधारता है।"**

हर रविवार 30 मिनट: ट्रैकर खोलो → Red गिनो → अगले हफ़्ते की रिवीजन-सूची बनाओ। बस इतना ही खेल है।
