# 🪄 Short Tricks + Skip Strategy — Noun

---

## 🎯 Trick 1: The "SCU-MP" Rule for Uncountable Nouns

```
┌─────────────────────────────────────────────┐
│  S C U - M P                                │
│  S → Scenery      (never "sceneries")       │
│  C → Crockery     (never "crockeries")      │
│  U → Furniture... wait, U = Uncountables!   │
│  M → Machinery    (never "machineries")     │
│  P → Poetry       (never "poetries")        │
│  Add: Luggage, Baggage, Information,        │
│  Advice, News, Bread, Work, Evidence        │
│  → No plural, no "a/an", singular verb!     │
└─────────────────────────────────────────────┘
```
**Exam signal:** If you see *informations / advices / furnitures* in an error-spotting question — that's your error. 15-second kill.

## 🎯 Trick 2: The "PAINS" Trap — Plural-Looking but Singular

```
┌─────────────────────────────────────────────┐
│  Words ending in -s but SINGULAR:           │
│  News, Physics, Mathematics, Economics,     │
│  Politics, Ethics, Innings, Mumps, Measles, │
│  Billiards, Gymnastics                      │
│  Trick: "The NEWS IS good" ✓                │
│         "The news are good" ✗               │
└─────────────────────────────────────────────┘
```
**Memory hook:** *"Mathematics IS a subject, not subjects."* One discipline = one verb.

## 🎯 Trick 3: The "SCISSORS-PAIR" Family — Always Plural

```
┌─────────────────────────────────────────────┐
│  Two-part tools & clothes = ALWAYS plural:  │
│  Scissors, Trousers, Spectacles, Goggles,   │
│  Pliers, Tongs, Jeans, Shorts, Pajamas      │
│  Trick: Anything with TWO legs / TWO blades │
│  takes a plural verb.                       │
│  "My trousers ARE torn." ✓                  │
│  Count them with "a pair of" → singular:    │
│  "This pair of scissors IS sharp." ✓        │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 4: The "One of the + Plural Noun + Singular Verb" Formula

```
┌─────────────────────────────────────────────┐
│  One of the + PLURAL noun + SINGULAR verb   │
│  "One of my friends lives in Delhi." ✓      │
│  (friends = plural, lives = singular)       │
│  Trap: "One of my friend live..." ✗✗        │
│  Both parts wrong!                          │
└─────────────────────────────────────────────┘
```
**3-second check:** Cover "One of the" — the noun after it MUST be plural; the verb MUST be singular.

## 🎯 Trick 5: The Intervening Phrase Blindfold

```
┌─────────────────────────────────────────────┐
│  Subject + [long phrase] + verb             │
│  "The quality of the apples WAS good."      │
│  Blindfold everything between subject &     │
│  verb: "The quality ... WAS good."          │
│  Phrases to blindfold: of..., with...,      │
│  along with..., as well as..., together     │
│  with..., accompanied by..., in addition to │
└─────────────────────────────────────────────┘
```
**Golden line:** *"As well as / along with / together with" = grammatical zero. Ignore them for verb agreement.*

## 🎯 Trick 6: Collective Noun — "Team Test"

```
┌─────────────────────────────────────────────┐
│  Acting TOGETHER → singular verb            │
│  "The team HAS won the match."              │
│  Acting SEPARATELY → plural verb            │
│  "The team ARE arguing among themselves."   │
│  Test: Can you insert "members of" before   │
│  the noun? If yes → plural.                 │
└─────────────────────────────────────────────┘
```
**Exam favourites:** jury, committee, audience, family, government, class.

## 🎯 Trick 7: The "CATTLE-PEOPLE-POLICE" Trio — Always Plural

```
┌─────────────────────────────────────────────┐
│  Cattle, People, Police, Gentry, Peasantry, │
│  Poultry, Vermin → ALWAYS plural verb       │
│  "The police HAVE arrested him." ✓          │
│  "The police has arrested him." ✗           │
│  Mnemonic: "CPP — Cows, Persons, Police     │
│  never stand alone (singular)."             │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 8: Same Word, Two Numbers — "FISH-SHEEP-DEER" Club

```
┌─────────────────────────────────────────────┐
│  Singular = Plural (no change):             │
│  Sheep, Deer, Fish, Aircraft, Species,      │
│  Series, Swine, Dozen (after numbers)       │
│  "Two dozen eggs" ✓  "Two dozens eggs" ✗    │
│  BUT "dozens of eggs" ✓ (no number before)  │
└─────────────────────────────────────────────┘
```
**Trick:** Number + dozen/score/hundred/thousand → NO -s. No number + "of" → -s compulsory (*hundreds of people*).

## 🎯 Trick 9: Possessive — The "Apostrophe S" 3-Step Ladder

```
┌─────────────────────────────────────────────┐
│  Step 1: Singular noun → 's                 │
│          the boy's book                     │
│  Step 2: Plural ending in -s → only '       │
│          the boys' hostel                   │
│  Step 3: Plural NOT ending in -s → 's       │
│          children's toys, men's shoes       │
│  Bonus: Joint vs Separate ownership:        │
│  "Ram and Shyam's house" = ONE house        │
│  "Ram's and Shyam's houses" = TWO houses    │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 10: Double Possessive Red Flag

```
┌─────────────────────────────────────────────┐
│  "The leg of the table" ✓ (lifeless things  │
│  take 'of', not 's)                         │
│  "The table's leg" — avoid in formal exams  │
│  Living → 's  |  Non-living → of            │
│  "India's population" ✓ (country = living   │
│  entity, accepted)                          │
│  "The door of the room" ✓                   │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 11: "A Number of vs The Number of"

```
┌─────────────────────────────────────────────┐
│  A number of + plural verb (= many)         │
│  "A number of students WERE absent."        │
│  The number of + singular verb (= the count)│
│  "The number of students IS rising."        │
│  Trick: "A" = All plural; "The" = Think     │
│  of the number itself → singular.           │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 12: Hair / Bread / Paper — Context Switch

```
┌─────────────────────────────────────────────┐
│  "Her hair IS black." (all hair → singular) │
│  "Two grey hairs were found." (countable    │
│  individual strands → plural OK)            │
│  "Paper is costly." (material)              │
│  "Read the papers." (newspapers/documents)  │
│  Trick: Material = singular; Individual     │
│  items = plural allowed.                    │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 13: The "Sound-Right" Alarm

```
┌─────────────────────────────────────────────┐
│  If a sentence SOUNDS natural, be suspicious│
│  — examiners exploit spoken-English habits: │
│  ✗ "The news are shocking." (sounds fine    │
│     to many ears — still WRONG)             │
│  ✗ "He gave me many advices."               │
│  ✗ "Cattles are grazing."                   │
│  Rule: Grammar beats ear. Always.           │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy

**1. The 15/45-Second Filter:**
- **15-sec questions (DO FIRST):** Direct rule recall — uncountable noun errors (*informations*), plural-looking singulars (*news is*), fixed plurals (*police have*), apostrophe placement. If the rule flashes instantly, mark and move.
- **45-sec questions (SECOND PASS):** Collective noun context (*jury has/have*), intervening-phrase agreement, joint-vs-separate possession. These need sentence dissection — never rush them.

**2. The "Two-Error" Skip:** If a sentence improvement question has TWO suspicious spots and you can confirm only one, eliminate options containing the confirmed error first. If two options still survive, **skip and return** — guessing between two grammar-plausible options wastes 90 seconds for 1 mark.

**3. The "Over-thinking" Warning:** If you've spent 60+ seconds on a noun question and are now doubting a rule you knew cold (e.g., "news is"), **stop** — your first rule-based answer is almost always right. Over-thinking is the examiner's favourite trap. Mark your original answer, flag it, move on.

**4. Negative-Question Caution:** In "which sentence is CORRECT/INCORRECT" formats, underline the keyword (CORRECT vs INCORRECT) before reading options. Skipping this step is the #1 cause of silly losses — and it costs zero seconds to do.
