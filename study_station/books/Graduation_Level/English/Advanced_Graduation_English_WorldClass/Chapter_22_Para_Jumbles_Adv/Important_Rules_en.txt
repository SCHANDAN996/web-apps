# Important Rules & Tips — Advanced Para Jumbles

## (a) 12 High-Yield Rules

| Rule | Example | Examiner's Trap |
|------|---------|-----------------|
| 1. The opener introduces a full noun or the topic | "The Indian Space Research Organisation was founded in 1969." | A general-sounding line that starts with "This" |
| 2. A pronoun follows its noun | "Kalpana Chawla …" → "She …" | Two people in the passage — check whom "she" means |
| 3. "A/an" introduces; "the" refers back | "A survey was done." → "The survey found…" | "The" used for something everyone knows (the sun) is not a back-reference |
| 4. This / these / such point back | "Prices rose." → "This hurt families." | "These" needs a plural idea before it |
| 5. Contrast connectors follow the claim | "Solar power is clean. However, it is not available at night." | "However" can also open a later contrast in the same paragraph |
| 6. Cause comes before effect | "It rained for a week. As a result, the roads flooded." | "Because" can put the effect first in the same sentence |
| 7. Time markers set the order | first → then → later → finally | "Earlier" refers to a time before the current one |
| 8. Examples follow the general idea | "Many birds migrate. For example, Siberian cranes…" | An example placed as the opener |
| 9. "Also / too / moreover" add to a previous point | "Exercise improves health. It also lifts mood." | They never open the paragraph |
| 10. Questions are answered in the next line | "Why do leaves fall? They…" | A question in the middle starting a new turn |
| 11. The conclusion summarises | "Thus / Therefore / In short…" | A dramatic example posing as the conclusion |
| 12. Use the options | Sure that "SQ" is a pair → strike others | Two options share the pair — check one more link |

## (b) Time Management (15/45-second rule)

| Question type | Time rule | Why |
|---------------|-----------|-----|
| Find the first sentence | 15 seconds | Only needs the opener test |
| Find the last sentence | 15 seconds | Look for "thus/finally" or a summary |
| Arrange 4 sentences (P, Q, R, S) | 45 seconds | Find one pair, then use options |
| Fixed S1 and S6 | 45 seconds | Link S1 forward and S6 backward |
| Odd sentence out | 45 seconds | Identify the common theme first |
| Still unclear after 45 seconds | Skip and return | Long jumbles eat time meant for easier marks |

## (c) Morphology — words that act as clues

| Root / affix | Meaning | Example and how it helps |
|--------------|---------|--------------------------|
| re- | again, back | "re-emerged" — something existed before, so its first mention comes earlier |
| pre- | before | "previously" — refers to an earlier time |
| post- | after | "post-war" — follows a mention of the war |
| sub- | under, later | "subsequently" — comes after an event |
| -ward | direction/time | "afterwards" — follows an earlier action |
| con-/com- | together | "consequently" — joins a result to its cause |
