# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — त्रुटि लॉग टेम्पलेट

## 🧠 म्नेमोनिक ट्रिक्स (बॉक्स में)

**ट्रिक 1 — "LOG" फॉर्मूला (त्रुटि लॉग की 3 परतें)**
```
L = Locate (गलती कहाँ है — शब्द/नियम/विकल्प?)
O = Origin (गलती क्यों हुई — अज्ञान, जल्दबाज़ी, या जाल?)
G = Guard (अगली बार कैसे बचूँगा — एक पंक्ति का नियम)
```
हर गलत प्रश्न को इन तीन सवालों से गुज़ारें। बिना G के लॉग अधूरा है।

**ट्रिक 2 — "5W1H" त्रुटि-जाँच**
```
What (क्या गलत हुआ) | Why (क्यों) | When (किस टॉपिक में बार-बार)
Where (किस सेट/सेक्शन में) | Which rule (कौन-सा नियम) | How to fix (सुधार कैसे)
```

**ट्रिक 3 — "RED PEN" नियम (लॉग भरने का क्रम)**
```
R = Record (प्रश्न उतारो)      E = Error mark (गलत विकल्प पर निशान)
D = Diagnose (कारण लिखो)      P = Pattern (क्या यही गलती पहले भी?)
E = Edit rule (अपना नियम बनाओ) N = Next review date (दोहराने की तारीख़)
```

**ट्रिक 4 — "3-7-21" रिवीज़न चक्र**
```
गलती दर्ज करने के 3 दिन बाद → 7 दिन बाद → 21 दिन बाद दोहराएँ।
तीसरी बार भी गलत हो तो वह "Red Zone" टॉपिक है — उसे अलग पेज पर लिखें।
```

**ट्रिक 5 — "A-B-C" गलती वर्गीकरण**
```
A = Awareness gap (नियम ही नहीं पता था) → नोट्स में जोड़ो
B = Blunder (पता था, फिर भी चूक) → जल्दबाज़ी का निशान
C = Confusion (दो विकल्पों में उलझन) → दोनों का अंतर लिखो
```

**ट्रिक 6 — "One Line, One Rule"**
```
लॉग में पूरा प्रश्न नहीं, सिर्फ़ एक पंक्ति का नियम लिखें।
❌ लंबा: "प्रश्न 42 में Neither...nor के साथ verb..."
✅ छोटा: "Neither/nor → verb नज़दीक वाले subject के अनुसार।"
```

**ट्रिक 7 — "TAG" जाल-पहचान**
```
T = Trap word (जाल वाला शब्द पहचानो — जैसे 'along with', 'as well as')
A = Actual subject (असली कर्ता खोजो)
G = Grammar check (verb का मिलान असली कर्ता से)
```

**ट्रिक 8 — "STAR" रिव्यू (हफ़्ते के अंत में)**
```
S = Scan (पूरे लॉग को 10 मिनट में देखो)
T = Tally (किस टॉपिक की गलतियाँ सबसे ज़्यादा?)
A = Attack (उस टॉपिक के 10 नए प्रश्न लगाओ)
R = Retire (जो नियम अब 3 बार सही — उसे लॉग से हटाओ)
```

**ट्रिक 9 — "Duplicate = Danger"**
```
एक ही नियम की गलती दूसरी बार दर्ज हो → उसे ★ दो।
★ वाले नियम परीक्षा से पहले की आखिरी रिवीज़न लिस्ट हैं।
```

**ट्रिक 10 — "Q→R→T" कॉलम टेम्पलेट**
```
हर एंट्री के 3 कॉलम: Q (प्रश्न का सार) | R (Rule) | T (Trap)
T कॉलम खाली रहे तो सोचो — परीक्षक ने जाल कहाँ बिछाया था?
```

**ट्रिक 11 — "Sound-Right Alarm" 🔔**
```
जो विकल्प "सुनने में सही" लगे, उस पर ठहरो।
बोलचाल की भाषा (जैसे "He don't") कान को ठीक लगती है —
लॉग में ऐसी गलतियों के सामने 🔔 लगाओ।
```

**ट्रिक 12 — "Color Code"**
```
🔴 लाल = नियम नहीं पता था | 🟡 पीला = जल्दबाज़ी | 🔵 नीला = जाल में फँसा
एक नज़र में पता चलेगा कि समस्या ज्ञान की है या आदत की।
```

**ट्रिक 13 — "10-Minute Daily Log"**
```
रोज़ के अभ्यास के बाद सिर्फ़ 10 मिनट लॉग को।
लॉग भरने में प्रश्न हल करने से ज़्यादा समय लगे तो तरीका गलत है।
```

**ट्रिक 14 — "Exam-Eve Only ★"**
```
परीक्षा से एक दिन पहले पूरी किताब नहीं —
सिर्फ़ ★ और 🔔 वाली एंट्रियाँ पढ़ो। यही आपकी असली तैयारी है।
```

---

## ⏭️ Skip Strategy (कब प्रश्न छोड़ें)

**स्किप 1 — "दो बार पढ़ो, फिर छोड़ो" नियम**
किसी Error Spotting प्रश्न को दो बार पढ़ने के बाद भी गलती न दिखे, तो तुरंत आगे बढ़ें। तीसरी बार पढ़ना आमतौर पर "Over-thinking" का जाल है — दिमाग़ सही वाक्य में भी काल्पनिक गलती ढूँढने लगता है। पहले पूरा पेपर, फिर बचे समय में लौटें।

**स्किप 2 — "50-50 में दांव नहीं"**
दो विकल्पों में उलझन हो और दोनों का व्याकरणिक अंतर याद न आए, तो अनुमान न लगाएँ (negative marking में)। लॉग में इसे "C-Confusion" के रूप में दर्ज करें — यह गलती बाद में कमाई देगी, परीक्षा हॉल में नुकसान नहीं।

**स्किप 3 — "लंबे वाक्य = बाद में"**
जिस Error Spotting वाक्य में 3+ क्लॉज़ या लंबा intervening phrase हो, उसे पहले दौर में छोड़ दें। ऐसे प्रश्न 45-सेकंड वाले 'तार्किक' वर्ग में आते हैं — पहले 15-सेकंड वाले तथ्यात्मक प्रश्न (spelling, one-word, synonym) निपटाएँ, फिर इन पर लौटें।
