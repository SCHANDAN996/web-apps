# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — Articles (a, an, the)

## ⚡ 12 म्नेमोनिक ट्रिक्स

**ट्रिक 1 — "SEU" नियम (Sound, not Spelling)**
```
┌─────────────────────────────────────────────┐
│ Article हमेशा ध्वनि (Sound) देखकर लगाओ,      │
│ अक्षर देखकर नहीं!                            │
│ • a university (यू- की ध्वनि = व्यंजन)        │
│ • an hour (h मूक, स्वर ध्वनि)                │
│ • a European, a one-rupee note              │
│ • an honest man, an heir, an M.P.           │
└─────────────────────────────────────────────┘
```

**ट्रिक 2 — "खेल, भाषा, भोजन, विषय, रंग के पहले THE नहीं"**
```
┌─────────────────────────────────────────────┐
│ कुछ सामान्य बातों में No Article:            │
│ खेल (cricket), भाषा (Hindi), भोजन (dinner), │
│ विषय (history), रंग — इनसे पहले the नहीं।    │
│ याद रखो: "खेल-भाषा-भोजन-विषय = शून्य लेख"   │
└─────────────────────────────────────────────┘
```

**ट्रिक 3 — "पहली बार A, दूसरी बार THE"**
```
┌─────────────────────────────────────────────┐
│ I saw a dog. The dog was black.             │
│ पहली बार नया = a/an; दोबारा जिक्र = the      │
│ परीक्षा में sentence pair में यही घूमता है!   │
└─────────────────────────────────────────────┘
```

**ट्रिक 4 — "SUE" नियम (अद्वितीय चीज़ें)**
```
┌─────────────────────────────────────────────┐
│ S-Sun, U-Universe, E-Earth → इनसे पहले THE  │
│ the sun, the moon, the earth, the world     │
│ सावधानी: बाकी ग्रहों (Mars, Jupiter, Venus) │
│ से पहले the नहीं लगता!                      │
└─────────────────────────────────────────────┘
```

**ट्रिक 5 — "Superlative = THE, Comparative = THE…THE"**
```
┌─────────────────────────────────────────────┐
│ • the best, the tallest, the most honest    │
│ • The more, the merrier.                    │
│   The harder you work, the luckier you get. │
│ (दो comparative जुड़ें तो दोनों में the)      │
└─────────────────────────────────────────────┘
```

**ट्रिक 6 — "पर्वत-शृंखला THE, चोटी NO"**
```
┌─────────────────────────────────────────────┐
│ the Himalayas ✓  but  Mount Everest ✗ (no the)│
│ the Alps ✓       but  Mount Abu ✗            │
│ शृंखला = the | अकेली चोटी/पर्वत = शून्य      │
└─────────────────────────────────────────────┘
```

**ट्रिक 7 — "नदी-सागर-महासागर = THE की नदी बहती है"**
```
┌─────────────────────────────────────────────┐
│ the Ganga, the Yamuna, the Indian Ocean,    │
│ the Bay of Bengal, the Suez Canal           │
│ लेकिन झील: Lake Baikal (no the)             │
└─────────────────────────────────────────────┘
```

**ट्रिक 8 — "THE + विशेषण = पूरा वर्ग"**
```
┌─────────────────────────────────────────────┐
│ the rich = अमीर लोग, the poor = गरीब लोग,    │
│ the blind, the unemployed, the elderly      │
│ (ये plural हैं → verb plural: The poor are…) │
└─────────────────────────────────────────────┘
```

**ट्रिक 9 — "देश में THE कब?" — "RUP" नियम**
```
┌─────────────────────────────────────────────┐
│ R-Republic (the Czech Republic)             │
│ U-Union/United (the USA, the UAE, the UK)   │
│ P-Plural (the Netherlands, the Philippines) │
│ बाकी एकल देश: India, Japan, France = no the │
└─────────────────────────────────────────────┘
```

**ट्रिक 10 — "संगीत वाद्य = THE, खेल = NO"**
```
┌─────────────────────────────────────────────┐
│ play the flute, play the guitar ✓           │
│ play cricket, play chess ✗ (no the)         │
│ याद रखो: "बजाओ तो THE, खेलो तो खाली"        │
└─────────────────────────────────────────────┘
```

**ट्रिक 11 — "Same, Only, First, Next, Last = THE के दोस्त"**
```
┌─────────────────────────────────────────────┐
│ the same book, the only son, the first boy, │
│ the last chapter, the next day              │
│ इन शब्दों से पहले the लगभग अनिवार्य          │
└─────────────────────────────────────────────┘
```

**ट्रिक 12 — "School/Prison/Church — उद्देश्य देखो"**
```
┌─────────────────────────────────────────────┐
│ मूल उद्देश्य = no the: go to school (पढ़ने), │
│ go to prison (सज़ा), go to church (प्रार्थना) │
│ दूसरा उद्देश्य = the: I went to the school   │
│ to meet the principal. (बस मिलने गया)        │
└─────────────────────────────────────────────┘
```

## 🚫 Skip Strategy — कब प्रश्न छोड़ें

**1. दो नियम टकरा रहे हों और दोनों विकल्प "सही लग रहे हों"**
उदाहरण: "He is ___ best player in ___ team." — अगर आपको superlative rule और possessive rule में भ्रम हो रहा हो और 45 सेकंड बीत गए, तो अंधा अनुमान न लगाएँ। Negative marking में खाली छोड़ना +0 है, गलत = −0.25/−0.50। पहले mark करके आगे बढ़ें, अंत में लौटें।

**2. "No improvement / No error" विकल्प वाले प्रश्न में अतिविश्वास से बचें**
अगर वाक्य पढ़ने में बिल्कुल सही लग रहा है लेकिन आपको कोई नियम याद नहीं आ रहा — जल्दबाज़ी में (a)/(b) मत टिक करें। Sound-right जाल में फँसने की संभावना 50% से ज़्यादा है। नियम याद न आए तो skip करें।

**3. Idiom + Article मिश्रित प्रश्न (जैसे "in a fix" vs "in the fix")**
ये रटने वाले हैं, सोचने वाले नहीं। अगर phrase पहले कभी नहीं पढ़ा, तो तर्क लगाकर समय बर्बाद न करें — 15 सेकंड में निश्चित न हों तो छोड़ दें। ऐसे प्रश्न में अनुमान लगभग हमेशा गलत होता है क्योंकि परीक्षक जानबूझकर "तर्कसंगत लगने वाला" गलत विकल्प रखता है।

**⏱️ सुनहरा सूत्र:** Fact-based (a/an/the सीधा नियम) = 15 सेकंड। Context-based (उद्देश्य, दोहरा जिक्र, idiom) = अधिकतम 45 सेकंड। उससे ज़्यादा = skip, mark, move on।
