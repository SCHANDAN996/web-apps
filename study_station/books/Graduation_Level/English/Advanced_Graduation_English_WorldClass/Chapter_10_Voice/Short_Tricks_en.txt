# 🪄 Short Tricks + Skip Strategy — Active & Passive Voice

---

## Trick 1 — The "BY-TEST" (Is it really Passive?)

```
┌─────────────────────────────────────────────┐
│  If you can add "by someone" at the end     │
│  and the sentence still makes sense →       │
│  it is PASSIVE.                             │
│  "The window was broken (by someone)." ✓    │
└─────────────────────────────────────────────┘
```
Active: the subject **does** the action. Passive: the subject **receives** it. Ask: "Can I add *by…*?" If yes → Passive.

---

## Trick 2 — The "SOB" Formula (Object becomes Subject)

```
┌─────────────────────────────────────────────┐
│  S-O-B: Subject ↔ Object Swap + Be + V3     │
│  Active  : Ram (S) eats (V) mangoes (O).    │
│  Passive : Mangoes (S) are eaten (Be+V3)    │
│            by Ram (O).                      │
└─────────────────────────────────────────────┘
```
Every conversion is just three moves: **swap positions, add the right form of *be*, change the main verb to V3 (past participle).**

---

## Trick 3 — The "Tense Never Changes" Rule

```
┌─────────────────────────────────────────────┐
│  The TENSE lives in the helping verb.       │
│  Active tense = Passive tense. Only the     │
│  VERB FORM changes, never the time.         │
│  "is writing" → "is being written"          │
│  (both are Present Continuous!)             │
└─────────────────────────────────────────────┘
```
Examiners love options where the tense shifts ("is written" for "is writing"). Reject them instantly.

---

## Trick 4 — Mnemonic: **"BE + V3 = PASSIVE KEY"**

```
┌─────────────────────────────────────────────┐
│  No BE-family verb (is/am/are/was/were/     │
│  been/being) + V3 → NOT a passive.          │
│  Spot "has eaten" = Active.                 │
│  Spot "has been eaten" = Passive.           │
└─────────────────────────────────────────────┘
```

---

## Trick 5 — The 8-Tense Ladder (Memorize the Pattern)

```
┌─────────────────────────────────────────────┐
│  Present Simple   : is/am/are + V3          │
│  Present Cont.    : is/am/are being + V3    │
│  Present Perfect  : has/have been + V3      │
│  Past Simple      : was/were + V3           │
│  Past Continuous  : was/were being + V3     │
│  Past Perfect     : had been + V3           │
│  Future Simple    : will be + V3            │
│  Future Perfect   : will have been + V3     │
│  ⚠ Future Continuous & Perfect Continuous   │
│    → NO standard passive. Trap alert!       │
└─────────────────────────────────────────────┘
```
Mnemonic: **"Simple = BE, Continuous = BEING, Perfect = BEEN."**

---

## Trick 6 — Modal Magic: **"Modal + be + V3"**

```
┌─────────────────────────────────────────────┐
│  can/could/may/might/shall/should/          │
│  will/would/must/ought to →                 │
│  just insert "be + V3" after the modal.     │
│  "She can solve it." → "It can be solved    │
│  by her."                                   │
└─────────────────────────────────────────────┘
```
The modal itself **never changes** — a favourite examiner trap is changing "should" to "would".

---

## Trick 7 — Pronoun Swap Table (Instant Recall)

```
┌─────────────────────────────────────────────┐
│  I→me | we→us | he→him | she→her |          │
│  they→them | who→whom | it→it (no change)   │
│  Subject pronoun ↔ Object pronoun on swap.  │
└─────────────────────────────────────────────┘
```
Trap: "by he" / "by they" in options — always wrong. It must be "by him" / "by them".

---

## Trick 8 — Imperative Sentences: **"Let + object + be + V3"**

```
┌─────────────────────────────────────────────┐
│  "Open the door." →                         │
│  "Let the door be opened."                  │
│  Negative: "Do not touch it." →             │
│  "Let it not be touched."                   │
└─────────────────────────────────────────────┘
```
Advice/orders with "should": "Help the poor." → "The poor should be helped."

---

## Trick 9 — Interrogative Shortcut: **"Wh-word + helping verb FIRST"**

```
┌─────────────────────────────────────────────┐
│  "Why did he beat you?" →                   │
│  "Why were you beaten by him?"              │
│  Keep the question word, then the passive   │
│  helping verb, then the subject.            │
└─────────────────────────────────────────────┘
```
Yes/No questions: start with the helping verb — "Did she write it?" → "Was it written by her?"

---

## Trick 10 — Double-Object Verbs: **Two Passives Possible**

```
┌─────────────────────────────────────────────┐
│  "He gave me a book."                       │
│  → "I was given a book by him." (preferred) │
│  → "A book was given to me by him."         │
│  Verbs: give, teach, tell, send, offer,     │
│  promise, show, pay.                        │
└─────────────────────────────────────────────┘
```
If both options appear, the **person-first** passive ("I was given…") is usually the expected answer.

---

## Trick 11 — Quasi-Passive Trap: **No "by" agent needed**

```
┌─────────────────────────────────────────────┐
│  "Rice sells cheap." / "This book reads     │
│  well." / "The shop opens at 9."            │
│  These SOUND active but MEAN passive —      │
│  do NOT convert them.                       │
└─────────────────────────────────────────────┘
```

---

## Trick 12 — Verbs That Take "to/with" Instead of "by"

```
┌─────────────────────────────────────────────┐
│  known TO | surprised AT | amazed AT |      │
│  annoyed WITH | pleased WITH |              │
│  interested IN | satisfied WITH |           │
│  contained IN | obliged TO                  │
│  Mnemonic: "K-S-A-A-P-I-S-C-O" —            │
│  not every passive takes "by"!              │
└─────────────────────────────────────────────┘
```
Trap: "He is known by me" ❌ → "He is known to me" ✓

---

## Trick 13 — Infinitive Passive: **"to be + V3"**

```
┌─────────────────────────────────────────────┐
│  "I want someone to help me." →             │
│  "I want to be helped."                     │
│  "There is work to do." →                   │
│  "There is work to be done."                │
└─────────────────────────────────────────────┘
```

---

## Trick 14 — "It is said that…" Structures

```
┌─────────────────────────────────────────────┐
│  "People say that he is honest."            │
│  → "It is said that he is honest."          │
│  → "He is said to be honest."               │
│  Verbs: say, believe, think, report,        │
│  suppose, know, allege.                     │
└─────────────────────────────────────────────┘
```
Both forms are correct — pick whichever matches the options.

---

## Trick 15 — The 3-Second Elimination Scan

```
┌─────────────────────────────────────────────┐
│  In options, instantly REJECT any that:     │
│  ① change the tense                         │
│  ② keep V2 instead of V3 ("is wrote")       │
│  ③ use wrong pronoun case ("by he")         │
│  ④ drop/change the modal                    │
│  Usually 3 options die in 3 seconds.        │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy

**1. Skip Perfect-Continuous conversions (45+ sec).**
If the active sentence is in Present/Past/Future Perfect Continuous, there is **no standard passive form**. If an option forces one, the question is either flawed or the answer is "cannot be converted" — don't burn time reconstructing it. Mark, move on, return if time remains.

**2. Skip long double-object + negative + interrogative combos on first pass.**
A question like "Why did the manager not give him the files?" requires 4 simultaneous transformations (question + negative + double object + pronoun swap). These are 45-second questions. Attempt all 15-second Fact-based conversions (simple tense, modal, imperative) first, then return.

**3. Never guess between two passives that differ only in preposition (by/to/with) unless you know the collocation.**
"Known to" vs "known by" is pure memory — a blind guess has the same 25% odds but costs thinking time. If Trick 12's list doesn't ring a bell, flag it and invest those seconds in a solvable question instead.
