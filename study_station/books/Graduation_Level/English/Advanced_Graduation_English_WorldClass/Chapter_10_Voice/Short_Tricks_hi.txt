# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — वाच्य (Voice)

## 🎯 15 म्नेमोनिक ट्रिक्स

---

**ट्रिक 1 — "B.O.V." फॉर्मूला (Passive बनाने का मास्टर सूत्र)**

```
┌─────────────────────────────────────────────┐
│  Passive = Object + Be + V3 (+ by + Subject)│
│  याद रखें: "बोव" — B (Be) + O (Object पहले) │
│  + V (Verb की तीसरी form)                   │
│  Active:  Ram eats mangoes.                 │
│  Passive: Mangoes are eaten by Ram.         │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 2 — "Tense बदले, Be बदले, V3 कभी न बदले"**

```
┌─────────────────────────────────────────────┐
│  Passive में असली काम 'Be' करता है:         │
│  Present  → is/am/are + V3                  │
│  Past     → was/were + V3                   │
│  Future   → will be + V3                    │
│  Perfect  → has/have/had been + V3          │
│  Continuous → is being / was being + V3     │
│  V3 हर tense में वही रहती है!               │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 3 — "ING दिखे, BEING लगाओ"**

```
┌─────────────────────────────────────────────┐
│  Continuous tense का Passive बनाते ही       │
│  'being' अनिवार्य:                          │
│  She is writing a letter.                   │
│  → A letter is being written by her.        │
│  जाल: "is written" (गलत) — being भूलना     │
│  परीक्षक की पसंदीदा गलती है!                │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 4 — "Modal + be + V3 — तीनों का ट्रिबल"**

```
┌─────────────────────────────────────────────┐
│  can/could/may/might/shall/should/will/     │
│  would/must/ought to → सबके साथ:            │
│  Modal + be + V3                            │
│  He can solve it. → It can be solved.       │
│  याद: "मोदी बी वी-3" (Modal-Be-V3)          │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 5 — "Let का Passive — 'be' या 'allowed to'"**

```
┌─────────────────────────────────────────────┐
│  Let him do it.                             │
│  → Let it be done by him.                   │
│  Let me go. → I may be allowed to go.       │
│  याद: "Let के दो रूप — be done / allowed"   │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 6 — "Imperative = You are requested/ordered/advised"**

```
┌─────────────────────────────────────────────┐
│  Open the door.                             │
│  → You are requested to open the door.      │
│  Don't touch it.                            │
│  → You are forbidden to touch it.           │
│  याद: "आदेश सुनो, Requested बोलो"           │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 7 — "Double Object = दो Passive, Indirect पहले"**

```
┌─────────────────────────────────────────────┐
│  She gave me a book.                        │
│  → I was given a book by her. ✔ (बेहतर)     │
│  → A book was given to me by her. ✔         │
│  याद: "इंसान पहले, चीज़ बाद में"              │
│  (Indirect object वाला passive ज़्यादा स्वाभाविक)│
└─────────────────────────────────────────────┘
```

---

**ट्रिक 8 — "Preposition चिपकी रहती है"**

```
┌─────────────────────────────────────────────┐
│  Phrasal verb की preposition कभी न छोड़ें:  │
│  They laughed at him.                       │
│  → He was laughed at. (at ज़रूरी!)          │
│  She looks after the child.                 │
│  → The child is looked after.               │
│  याद: "Verb भागे, Preposition साथ भागे"     │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 9 — "Who से शुरू? By whom बोलो"**

```
┌─────────────────────────────────────────────┐
│  Who wrote this letter?                     │
│  → By whom was this letter written?         │
│  याद: "Who का Passive रूप = By whom"        │
│  (Whom...by भी सही, पर By whom शुरू में     │
│  ज़्यादा formal और परीक्षा-पसंद)            │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 10 — "It is said that... — Reporting Verbs"**

```
┌─────────────────────────────────────────────┐
│  People say that he is honest.              │
│  → It is said that he is honest.            │
│  → He is said to be honest.                 │
│  say/believe/think/know/report/suppose —    │
│  इनके दो passive रूप।                       │
│  याद: "It से शुरू या to से जोड़ो"            │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 11 — "By-agent गायब? तो Passive ही सही"**

```
┌─────────────────────────────────────────────┐
│  कर्ता अज्ञात/अनावश्यक हो तो by-phrase      │
│  हटा दें:                                   │
│  My watch has been stolen. (चोर कौन? अज्ञात)│
│  Rice is grown in India. (किसान स्पष्ट)     │
│  याद: "कर्ता न दिखे, by न लिखे"             │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 12 — "Quasi-Passive — Active दिखे, Passive माने"**

```
┌─────────────────────────────────────────────┐
│  कुछ verbs active form में passive अर्थ:    │
│  The book sells well. (बिकती है)            │
│  The cake tastes sweet. (चखी जाती है)       │
│  The door won't open.                       │
│  याद: "Sell, taste, read, open —            │
│  दिखें Active, मन में Passive"              │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 13 — "Get-Passive — आम बोलचाल का हथियार"**

```
┌─────────────────────────────────────────────┐
│  He got selected. / She got promoted.       │
│  get + V3 = be + V3 (informal passive)      │
│  याद: "Be न मिले तो Get से काम चलाओ"        │
│  (Formal लेखन में be ही प्राथमिक)           │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 14 — "Intransitive = No Passive (IN-P नियम)"**

```
┌─────────────────────────────────────────────┐
│  जिस verb का object न हो, उसका passive      │
│  असंभव: go, come, sleep, die, run, cry      │
│  He died. → ❌ कोई passive नहीं             │
│  याद: "INtransitive — Passive IN नहीं"      │
│  जाल: "was died", "was slept" — हमेशा गलत!  │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 15 — "Perfect में BEEN, Continuous में BEING"**

```
┌─────────────────────────────────────────────┐
│  has/have/had + been + V3  (Perfect)        │
│  is/was + being + V3       (Continuous)     │
│  याद: "Perfect-BEEN, Continuous-BEING —     │
│  N आए तो पूरा हुआ, ING आए तो चल रहा"       │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**स्किप 1 — दो विकल्प व्याकरणिक रूप से सही लगें (rare cases):**
कभी-कभी double object वाले प्रश्न में दोनों passive रूप सही होते हैं। अगर options में दोनों हैं और "बेहतर" तय न हो पा रहा, तो 45 सेकंड से ज़्यादा न दें — indirect object वाला चुनें, वरना छोड़ दें। अनुमान पर नकारात्मक अंकन का जोखिम न लें।

**स्किप 2 — Quasi-passive / Get-passive में संदेह हो:**
"The book sells well" जैसे प्रश्न में अगर आप नियम भूल गए हैं और दो विकल्पों ("is sold well" बनाम "sells well") में उलझ रहे हैं, तो तुरंत skip करें — यहाँ अधूरी जानकारी से गलती लगभग तय है। पहले नियम दोहराएँ, फिर अभ्यास में लौटें।

**स्किप 3 — लंबा वाक्य + कई tense बदलाव:**
अगर वाक्य में reported speech, modal और perfect tense तीनों मिले हुए हैं और समय कम है, तो उसे अंत में हल करने के लिए चिह्नित करें। पहले 15-सेकंड वाले fact-based प्रश्न (सीधा tense conversion, by-agent, V3 पहचान) निपटाएँ — वहीं से निश्चित अंक मिलते हैं।

**स्मरण-सूत्र:** *"पहले B.O.V. वाले, फिर जटिल वाले; संदेह हो तो skip, नकारात्मक अंकन से बचो।"*
