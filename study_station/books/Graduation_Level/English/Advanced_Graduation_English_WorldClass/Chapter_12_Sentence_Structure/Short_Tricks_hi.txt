# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — वाक्य संरचना (Sentence Structure)

## 🎯 15 म्नेमोनिक ट्रिक्स

```
┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 1: "SVA" — Subject-Verb Agreement                     │
│ "कर्ता पहले, क्रिया बाद में — दोनों का मेल ज़रूरी!"          │
│ ✗ The list of items ARE on the table.                       │
│ ✓ The list of items IS on the table.                        │
│ (कर्ता "list" है, "items" नहीं — बीच का phrase धोखा है!)    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 2: "FANBOYS" — समुच्चयबोधक (Coordinating Conjunctions)│
│ For, And, Nor, But, Or, Yet, So                             │
│ दो स्वतंत्र उपवाक्य (independent clauses) जोड़ने के लिए     │
│ इनसे पहले अल्पविराम (comma) लगाएँ:                          │
│ "He was tired, so he slept early."                          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 3: "AAAWWUBBIS" — अधीनस्थ संयोजक (Subordinators)      │
│ After, Although, As, When, While, Until, Because,           │
│ Before, If, Since                                           │
│ ये वाक्य की शुरुआत में आएँ तो comma लगेगा:                  │
│ "Because it rained, the match was cancelled."               │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 4: "Either-Or = नज़दीकी कर्ता जीतता है"                │
│ Either…or / Neither…nor में क्रिया नज़दीक वाले कर्ता के अनुसार:│
│ "Neither the teacher nor the STUDENTS WERE present."        │
│ "Neither the students nor the TEACHER WAS present."         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 5: "Each/Every = हमेशा Singular"                       │
│ Each boy, Every student, Either of them, Neither of them    │
│ → सबके साथ singular verb: "Each of the boys HAS a pen."     │
│ याद रखें: "Each-Every, एक-एक — क्रिया भी एकवचन!"            │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 6: "Inversion = प्रश्न का क्रम"                        │
│ Helping verb कर्ता से पहले:                                  │
│ ✗ What you are doing?  ✓ What ARE you doing?                │
│ हिंदी में "तुम क्या कर रहे हो?" — क्रिया बाद में;             │
│ अंग्रेज़ी में helping verb पहले!                              │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 7: "Negative शुरुआत = Inversion पक्का"                 │
│ Never, Seldom, Rarely, Hardly, No sooner, Not only          │
│ वाक्य की शुरुआत में → helping verb कर्ता से पहले:            │
│ "Never HAVE I seen such a sight."                           │
│ "No sooner HAD he arrived THAN it rained."                  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 8: "There = असली कर्ता बाद में"                        │
│ "There IS a book on the table." (book = singular)           │
│ "There ARE two books on the table." (books = plural)        │
│ There को कर्ता मत समझो — क्रिया के बाद वाला शब्द देखो!       │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 9: "Collective Noun = एक टीम, एक क्रिया"               │
│ Team, Committee, Jury, Family, Government                   │
│ एक इकाई की तरह काम करें → singular:                         │
│ "The committee HAS decided."                                │
│ (सदस्य अलग-अलग काम करें तभी plural — परीक्षा में दुर्लभ!)    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 10: "News, Physics, Economics — s लगा, पर Singular!"   │
│ News, Physics, Mathematics, Economics, Ethics, Measles      │
│ "The news IS shocking." "Physics IS difficult."             │
│ याद रखें: "दिखने में बहुवचन, काम में एकवचन!"                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 11: "Scissors-Trousers = जोड़ी वाले Plural"            │
│ Scissors, Trousers, Spectacles, Goggles, Pliers             │
│ हमेशा plural: "The scissors ARE on the desk."               │
│ Singular चाहिए तो: "A PAIR of scissors IS…"                 │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 12: "One of + Plural Noun + Singular Verb"             │
│ "One of my FRIENDS HAS come."                               │
│ संरचना याद रखें: One of + [बहुवचन संज्ञा] + [एकवचन क्रिया]   │
│ परीक्षक "friends have" लिखकर धोखा देता है!                  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 13: "Parallel Structure = समान रूप, समान सूत्र"        │
│ ✗ She likes reading, swimming, and TO DANCE.                │
│ ✓ She likes reading, swimming, and DANCING.                 │
│ सूची में सभी शब्द एक ही रूप में (सब -ing या सब to+V1)        │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 14: "Dangling Modifier = लटकता वाक्यांश पकड़ो"         │
│ ✗ Walking down the road, a snake bit him.                   │
│   (क्या साँप सड़क पर चल रहा था?!)                           │
│ ✓ Walking down the road, HE saw a snake.                    │
│ नियम: -ing वाक्यांश के बाद वही कर्ता आए जो काम कर रहा है।    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 15: "Run-on रोकथाम — 3 रास्ते: . ; ,+FANBOYS"          │
│ ✗ He was late, he missed the bus. (comma splice)            │
│ ✓ He was late. He missed the bus.                           │
│ ✓ He was late; he missed the bus.                           │
│ ✓ He was late, so he missed the bus.                        │
└─────────────────────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**🚩 छोड़ने का संकेत 1: दो विकल्प लगभग एक जैसे दिखें और 45 सेकंड बीत चुके हों।**
अगर (a) और (c) दोनों "सही लग रहे" हैं और आपने नियम लगाकर भी फैसला नहीं किया, तो अनुमान पर समय न बर्बाद करें — प्रश्न चिह्नित करके आगे बढ़ें, अंत में लौटें। Negative marking में अंधा अनुमान घाटा है।

**🚩 छोड़ने का संकेत 2: लंबा Complex Sentence जिसमें 3+ उपवाक्य हों और त्रुटि पहली बारी में न दिखे।**
ऐसे प्रश्न "Over-thinking Trap" होते हैं — जितना सोचोगे, उतना भ्रम बढ़ेगा। पहले आसान 15-सेकंड वाले प्रश्न (SVA, Tense, Article) निपटाओ, फिर समय बचे तो इन पर लौटो।

**🚩 छोड़ने का संकेत 3: अपरिचित Idiom/Structure जिसका नियम याद ही न हो।**
जिस संरचना का नियम आपने कभी नहीं पढ़ा, वहाँ "सही लगने" के आधार पर उत्तर देना जुआ है। बेहतर: छोड़ो, बाद में उस नियम को अपनी तैयारी सूची में जोड़ो।

**✅ सुनहरा क्रम:** पहले Fact-based (15 सेकंड) → फिर Inference-based (45 सेकंड) → अंत में चिह्नित प्रश्न। कभी भी एक प्रश्न पर 60 सेकंड से अधिक न दें।
