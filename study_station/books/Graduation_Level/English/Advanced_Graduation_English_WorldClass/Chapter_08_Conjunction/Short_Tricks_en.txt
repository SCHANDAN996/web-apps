# 🪄 Short Tricks + Skip Strategy — Conjunction

---

## 🎯 Trick 1: The FANBOYS Army (Coordinating Conjunctions)

```
┌─────────────────────────────────────────────┐
│  F – For      (reason)                      │
│  A – And      (addition)                    │
│  N – Nor      (negative alternative)        │
│  B – But      (contrast)                    │
│  O – Or       (choice)                      │
│  Y – Yet      (contrast, surprise)          │
│  S – So       (result)                      │
│                                             │
│  Memory hook: "FANBOYS never fight —       │
│  they JOIN two equal clauses."              │
└─────────────────────────────────────────────┘
```
**Exam use:** If two independent clauses are joined, the connector MUST be a FANBOYS word (with a comma before it). Anything else = error.

---

## 🎯 Trick 2: The "Pair-Marriage" Rule (Correlative Conjunctions)

```
┌─────────────────────────────────────────────┐
│  Either … OR      (never "either … nor")    │
│  Neither … NOR    (never "neither … or")    │
│  Not only … BUT ALSO                          │
│  Both … AND                                   │
│  Whether … OR                                 │
│  No sooner … THAN                             │
│  Hardly/Scarcely … WHEN                       │
│                                             │
│  Hook: "Married pairs — divorce = ERROR."   │
└─────────────────────────────────────────────┘
```
**Exam use:** Most correlative errors involve wrong partners. Scan the sentence for the first half; the second half is fixed. "No sooner… when" ❌ → "No sooner… than" ✅

## 🎯 Trick 3: The "No-Sooner THAN, Hardly WHEN" Split

```
┌─────────────────────────────────────────────┐
│  SOONER has a 'T' → takes THAN              │
│  HARDLY / SCARCELY → take WHEN              │
│                                             │
│  Hook: "Sooner-Than both have T;            │
│  Hardly-When both have W-sound."            │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 4: The "Double Negative Ban"

```
┌─────────────────────────────────────────────┐
│  Neither/Scarcely/Hardly already carry a    │
│  NEGATIVE meaning.                          │
│  ❌ He did not hardly work.                 │
│  ✅ He hardly worked.                       │
│                                             │
│  Hook: "One negative per sentence —         │
│  two negatives cancel the exam mark."       │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 5: The "Until vs Unless" Swap Test

```
┌─────────────────────────────────────────────┐
│  UNTIL = TIME (wait till the clock moves)   │
│  UNLESS = CONDITION (if… not)               │
│                                             │
│  Test: Replace with "if not".               │
│  If sentence still makes sense → UNLESS.    │
│  ❌ Wait here unless I return.              │
│  ✅ Wait here until I return.               │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 6: The "Reason-Because" Clash

```
┌─────────────────────────────────────────────┐
│  ❌ The reason is because he was late.      │
│  ✅ The reason is that he was late.         │
│                                             │
│  "Because" already means "for the reason    │
│  that" — using both = saying reason twice.  │
│  Hook: "Reason + Because = Double Dose."    │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 7: The "Though… Yet/But" Filter

```
┌─────────────────────────────────────────────┐
│  Although/Though pairs with YET (optional)  │
│  or a comma — NEVER with BUT.               │
│  ❌ Although he is rich, but he is honest.  │
│  ✅ Although he is rich, yet he is honest.  │
│  ✅ Although he is rich, he is honest.      │
│                                             │
│  Hook: "Though and But can't sit together." │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 8: The "Since-Because-As" Ladder (Reason Words)

```
┌─────────────────────────────────────────────┐
│  SINCE  → reason + also time (from a point) │
│  BECAUSE→ strongest, direct reason          │
│  AS     → mild, background reason           │
│  FOR    → formal, comes mid-sentence        │
│                                             │
│  Hook: "B-S-A-F: Because Shouts, As         │
│  whispers, Since times, For formalizes."    │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 9: The "Lest… Should" Formula

```
┌─────────────────────────────────────────────┐
│  LEST is always followed by SHOULD.         │
│  ✅ Work hard lest you should fail.         │
│  ❌ Work hard lest you will fail.           │
│  ❌ Work hard lest you should not fail.     │
│  (Lest is already negative — no "not"!)     │
│                                             │
│  Hook: "Lest = for fear that → Should       │
│  follows, Not stays out."                   │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 10: The "As If / As Though" Past Trap

```
┌─────────────────────────────────────────────┐
│  After "as if / as though" use PAST tense   │
│  for an unreal present:                     │
│  ✅ He talks as if he WERE a king.          │
│  ❌ He talks as if he is a king.            │
│                                             │
│  Hook: "As if = imagination → step back     │
│  one tense."                                │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 11: The "So… That / Such… That" Sorter

```
┌─────────────────────────────────────────────┐
│  SO   + adjective/adverb + that             │
│  SUCH + (a/an) + noun + that                │
│  ✅ He is so weak that he cannot walk.      │
│  ✅ It was such a hot day that we stayed in.│
│                                             │
│  Hook: "SO describes, SUCH names."          │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 12: The "Inversion Alarm" (Negative Adverbials First)

```
┌─────────────────────────────────────────────┐
│  No sooner / Hardly / Scarcely / Not only   │
│  at the START → invert subject & auxiliary: │
│  ✅ No sooner had he come than it rained.   │
│  ❌ No sooner he had come than it rained.   │
│                                             │
│  Hook: "Negative opener = question order."  │
└─────────────────────────────────────────────┘
```

## 🎯 Trick 13: The "That-After-Verbs" Checklist

```
┌─────────────────────────────────────────────┐
│  Said / told / believe / think / know       │
│  + THAT (optional in speech, keep in exam). │
│  But: "He said me that…" ❌                 │
│       "He told me that…" ✅                 │
│                                             │
│  Hook: "SAID never takes a person directly; │
│  TOLD always does."                         │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 14: The "While vs Whereas" Contrast Meter

```
┌─────────────────────────────────────────────┐
│  WHILE   = time OR mild contrast            │
│  WHEREAS = strong, formal contrast only     │
│  ✅ I like tea, whereas he likes coffee.    │
│  ❌ Whereas I was sleeping, phone rang.     │
│  (time → use WHILE)                         │
│                                             │
│  Hook: "Whereas = versus; While = meanwhile │
│  or mild versus."                           │
└─────────────────────────────────────────────┘
```

---

## 🎯 Trick 15: The "Provided/Providing That" Condition Tag

```
┌─────────────────────────────────────────────┐
│  Provided (that) / Providing (that) = IF    │
│  ✅ You can go provided that you return soon│
│  ❌ …provided that you will return soon.    │
│  (No future tense after condition words!)   │
│                                             │
│  Hook: "Condition clause = present tense    │
│  only; future lives in the main clause."    │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy

**Skip Tip 1 — The 10-Second Pair Scan:**
In error-spotting, first scan ONLY for correlative pairs (either/neither/not only/no sooner/hardly). If a pair is broken, you have your answer in under 10 seconds. If no pair exists, move to tense-after-conjunction checks. Don't re-read the whole sentence three times.

**Skip Tip 2 — The "Sound-Right" Trap Flag:**
If an option "sounds natural" in spoken English (e.g., "the reason is because", "although…but"), treat it as a SUSPECT, not a friend. Examiners deliberately plant spoken-English habits. Mark it, verify against the rule box, and if you can't confirm within 45 seconds, flag and move on — return after finishing the section.

**Skip Tip 3 — Long Sentence? Chop Before You Solve:**
If a sentence has 3+ clauses, don't solve it in one read. Break it at each conjunction, label each clause (main/subordinate), and check one junction at a time. If even after chopping the error isn't visible in 45 seconds, skip it — conjunction questions are rarely worth 2 minutes when 4 easier questions wait ahead.
