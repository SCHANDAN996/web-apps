🪄 SHORT TRICKS + SKIP STRATEGY — संयोजक (Conjunction)

═══════════════════════════════════
भाग 1: म्नेमोनिक ट्रिक्स (याद रखने की कुंजियाँ)
═══════════════════════════════════

┌─────────────────────────────────────────┐
│ ट्रिक 1: "FANBOYS" — 7 समन्वयी संयोजक      │
│ F-For, A-And, N-Nor, B-But, O-Or,        │
│ Y-Yet, S-So                               │
│ बस इतना याद रखो: "फैनबॉयज़" — ये 7 शब्द    │
│ दो स्वतंत्र उपवाक्यों (independent clauses)  │
│ को जोड़ते हैं, और इनसे पहले अल्पविराम (,)    │
│ लगता है।                                   │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 2: "AAAWWUBBIS" — आश्रित संयोजक       │
│ After, Although, As, When, While, Until,  │
│ Because, Before, If, Since                │
│ ये वाक्य की शुरुआत में आएँ तो बीच में        │
│ अल्पविराम ज़रूरी: "Because it rained, we    │
│ stayed home."                             │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 3: "जोड़ीदार जोड़े" — सहसंबंधी संयोजक   │
│ Either…Or | Neither…Nor | Not only…But    │
│ also | Both…And | Whether…Or | No sooner… │
│ Than | Hardly/Scarcely…When               │
│ नियम: जोड़ी कभी न बदलो! "Neither…or" ❌     │
│ "Neither…nor" ✅ — परीक्षक यही बदलकर जाल     │
│ बिछाता है।                                  │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 4: "No sooner ने Than पकड़ा"          │
│ No sooner → Than (कभी When नहीं!)          │
│ Hardly/Scarcely → When (कभी Than नहीं!)    │
│ याद करो: "No sooner का दोस्त Than,          │
│ Hardly का साथी When।"                      │
│ साथ ही: इनसे शुरू वाक्य में inversion —     │
│ "No sooner had he come than…"             │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 5: "Until vs Unless — UL का खेल"      │
│ Until = समय (तब तक) | Unless = शर्त (यदि  │
│ नहीं)। Unless के साथ not कभी नहीं:          │
│ "Unless you do not work hard" ❌            │
│ "Unless you work hard" ✅                   │
│ (Unless में ही 'नहीं' छिपा है — दोहरी नकारात्मकता │
│ गलत!)                                       │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 6: "Since-Because-As परिवार"          │
│ कारण बताने वाले तीनों के साथ therefore/     │
│ hence नहीं लगाते:                           │
│ "Because he was ill, therefore he was     │
│ absent" ❌ → therefore हटाओ ✅              │
│ याद करो: "एक वाक्य, एक कारण-संयोजक।"        │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 7: "Although के साथ But मना है"        │
│ Although/Though + yet (ठीक) ✅              │
│ Although/Though + but (गलत) ❌              │
│ हिंदी में "यद्यपि…फिर भी" दोनों चलते हैं,     │
│ अंग्रेज़ी में सिर्फ एक!                       │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 8: "Neither-Nor की निकटता नियम"        │
│ Neither…Nor / Either…Or / Not only…But    │
│ also में क्रिया (verb) नज़दीक वाले कर्ता के    │
│ अनुसार:                                     │
│ "Neither the teacher nor the students     │
│ WERE present." (students नज़दीक → were)     │
│ याद करो: "क्रिया पड़ोसी से मेल खाती है।"      │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 9: "Lest…Should" — डर का जोड़ा         │
│ Lest के बाद हमेशा should + V1, और lest के   │
│ साथ not कभी नहीं:                           │
│ "Walk fast lest you should not miss the   │
│ train" ❌ → not हटाओ ✅                     │
│ (Lest = "कहीं ऐसा न हो" — नकारात्मकता पहले   │
│ से मौजूद!)                                  │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 10: "So…That / Such…That"             │
│ So + adjective/adverb + that              │
│ Such + (a/an) + noun + that               │
│ "He is so weak that he cannot walk."      │
│ "It was such a hot day that we stayed in."│
│ याद करो: "So विशेषण को, Such संज्ञा को।"     │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 11: "The…The — तुलना की जुड़वाँ"        │
│ "The higher you go, the cooler it is."    │
│ दोनों तरफ comparative degree — एक तरफ        │
│ positive रखना गलत: "The high you go…" ❌    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 12: "As if / As though = अतीत का भ्रम" │
│ As if के बाद past tense (वर्तमान की कल्पना   │
│ के लिए): "He talks as if he WERE a king."  │
│ (were — सभी कर्ताओं के साथ, was नहीं!)       │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 13: "Reason…Because की लड़ाई"          │
│ "The reason is because…" ❌                 │
│ "The reason is that…" ✅                    │
│ Reason और because दोनों 'कारण' हैं — एक ही   │
│ काफ़ी है!                                   │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 14: "Rather than / Other than"        │
│ Rather than = की बजाय (वरीयता)              │
│ Other than = के अतिरिक्त/सिवाय              │
│ "I prefer tea rather than coffee."        │
│ "No one other than Ram came."             │
│ परीक्षक इन्हें आपस में बदलकर जाल बनाता है।     │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ट्रिक 15: "While = 3 चेहरे"                 │
│ ① समय (जब/के दौरान): "While I was         │
│ reading, the phone rang."                 │
│ ② विरोध (जबकि): "While Ram is rich,       │
│ Shyam is poor."                           │
│ ③ रियायत (यद्यपि = although): "While I    │
│ agree with you, I cannot support this     │
│ plan."                                    │
│ संदर्भ देखकर अर्थ चुनो — यही RC में काम आता  │
│ है। ध्यान: While का अर्थ "जब तक (until)"    │
│ नहीं होता — until के लिए until/till ही       │
│ प्रयोग होता है।                              │
└─────────────────────────────────────────┘

भाग 2: SKIP STRATEGY — कब प्रश्न छोड़ें
═══════════════════════════════════

⏭️ रणनीति 1: अपरिचित जोड़ी वाला Error-Spotting छोड़ दो
अगर वाक्य में ऐसा सहसंबंधी संयोजक है जिसे तुमने कभी नहीं पढ़ा (जैसे "Not merely…", "Such…as"), और 15 सेकंड में जोड़ी याद न आए — अंधा अनुमान मत लगाओ। नकारात्मक अंकन (negative marking) में गलत जोड़ी पकड़ने की संभावना ज़्यादा रहती है। पहले पास में छोड़ो, अंत में समय बचे तो वापस आओ।

⏭️ रणनीति 2: लंबे वाक्य में "Intervening Phrase" जाल पहचानो, घबराओ मत
"Neither the captain, along with his players, ___ present." — ऐसे प्रश्न में बीच का वाक्यांश (along with…) काटकर पढ़ो। अगर काटने के बाद भी उत्तर स्पष्ट न हो, तो यह 45-सेकंड वाला तार्किक प्रश्न है — पहले आसान 15-सेकंड वाले (सीधी जोड़ी: neither…nor, no sooner…than) निपटाओ, फिर इस पर लौटो।

⏭️ रणनीति 3: दो विकल्प लगभग-सही लगें तो "Sound-Right" जाल से बचो
"Hardly had he slept when/than…" — दोनों सही लगते हैं, पर नियम कहता है when। अगर नियम याद नहीं और दोनों विकल्प कान को सही लग रहे हों, तो यह परीक्षक का Sound-Right जाल है — अनुमान लगाने के बजाय छोड़ना बेहतर, क्योंकि कान की ध्वनि यहाँ धोखा देती है।
