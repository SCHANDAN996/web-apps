# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — एक शब्द प्रतिस्थापन

## म्नेमोनिक ट्रिक्स (याद रखने की चाबियाँ)

┌─────────────────────────────────────────────┐
│ ट्रिक 1: **"PHIL = प्यार"**                  │
│ Philanthropist = मानवता से प्यार करने वाला    │
│ Bibliophile = किताबों से प्यार करने वाला      │
│ Philatelist = डाक-टिकटों से प्यार करने वाला   │
│ 👉 Phil देखो तो "प्रेमी/शौकीन" समझो।         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 2: **"PHOBIA = डर"**                   │
│ Claustrophobia = बंद जगह का डर               │
│ Hydrophobia = पानी का डर                     │
│ Xenophobia = विदेशियों का डर                 │
│ 👉 Phobia देखो तो "डर" पर टिक करो।          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 3: **"CIDE = हत्या" (Caesar ने काटा)** │
│ Homicide = मनुष्य की हत्या                   │
│ Fratricide = भाई की हत्या (Frater = भाई)     │
│ Regicide = राजा की हत्या (Rex = राजा)        │
│ Infanticide = शिशु हत्या                     │
│ 👉 -cide वाला शब्द = किसी की हत्या।          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 4: **"MANIA = पागलपन/सनक"**            │
│ Kleptomania = चोरी की सनक                    │
│ Pyromania = आग लगाने की सनक (Pyro = आग)      │
│ Megalomania = बड़े बनने का पागलपन            │
│ 👉 Mania = बेख़याल जुनून।                    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 5: **"CRACY = शासन"**                  │
│ Democracy = जनता का शासन (Demos = जनता)      │
│ Autocracy = एकतंत्र (Auto = स्वयं)           │
│ Bureaucracy = नौकरशाही का शासन               │
│ Theocracy = धर्मगुरुओं का शासन (Theo = ईश्वर)│
│ 👉 -cracy = कौन राज करता है, वही पकड़ो।      │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 6: **"OMNI = सब कुछ"**                 │
│ Omnipotent = सर्वशक्तिमान (potent = शक्ति)   │
│ Omniscient = सर्वज्ञ (scient = ज्ञान)         │
│ Omnivorous = सर्वभक्षी (vore = खाना)         │
│ 👉 Omni = भगवान वाले गुण याद करो।            │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 7: **"VORE = खाना"**                   │
│ Carnivorous = मांसाहारी (Carn = मांस)        │
│ Herbivorous = शाकाहारी (Herb = पौधा)         │
│ Omnivorous = सर्वभक्षी                       │
│ 👉 गाय = Herbi, शेर = Carni, इंसान = Omni।   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 8: **"LOQU = बोलना"**                  │
│ Loquacious = बातूनी (बहुत बोलने वाला)        │
│ Eloquent = वाक्पटु (प्रभावशाली वक्ता)        │
│ Soliloquy = स्वगत कथन (अकेले में बोलना)      │
│ 👉 "लोक-वाच" — लोगों से वाचा (बात)।          │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 9: **"AMBUL = चलना" (Ambulance याद करो)│
│ Somnambulist = नींद में चलने वाला            │
│ (Somnus = नींद + Ambul = चलना)               │
│ Perambulator = बच्चों की गाड़ी (घुमाने वाली) │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 10: **"MORT = मृत्यु" (Mortuary)**     │
│ Post-mortem = मृत्यु के बाद की जाँच          │
│ Immortal = अमर (जो मरे नहीं)                 │
│ Mortician = शव-संस्कार करने वाला             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 11: **"GAMY = विवाह"**                 │
│ Monogamy = एक विवाह (Mono = एक)              │
│ Bigamy = दो विवाह (Bi = दो)                  │
│ Polygamy = बहु विवाह (Poly = अनेक)           │
│ 👉 Mono-Bi-Poly की संख्या-सीढ़ी याद रखो।     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 12: **"GRAPH = लिखना"**                │
│ Calligraphy = सुलेख (सुंदर लिखावट)           │
│ Biography = जीवनी (Bio = जीवन)               │
│ Autobiography = आत्मकथा (Auto = स्वयं)       │
│ Telegraph = दूर लिखना (Tele = दूर)           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 13: **"IST = करने वाला व्यक्ति"**      │
│ Optimist = आशावादी | Pessimist = निराशावादी  │
│ Sadist = दूसरों को दुख देकर खुश होने वाला    │
│ Masochist = खुद दुख पाकर खुश होने वाला       │
│ 👉 SadiST vs MasoCHIST — "देने वाला" बनाम    │
│ "लेने वाला" — परीक्षक यहीं उल्टा करता है!    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 14: **जोड़ी-ट्रिक: Amnesia vs Insomnia**│
│ Amnesia = याददाश्त जाना (A = नहीं + mnes =   │
│ स्मृति) — "अम्मा नहीं याद"                   │
│ Insomnia = नींद न आना (In = नहीं + somnus =  │
│ नींद) — "इन-सो-नहीं-आ"                       │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ ट्रिक 15: **"POT = पीना"**                   │
│ Potable = पीने योग्य (पानी)                  │
│ Potation = पेय पदार्थ                        │
│ 👉 "पोट (घड़ा) से पानी पियो" — घड़े का पानी  │
│ ही पीने योग्य होता है!                       │
└─────────────────────────────────────────────┘

## 🚫 Skip Strategy — कब प्रश्न छोड़ें

**टिप 1 — अपरिचित लैटिन/ग्रीक जोड़ी वाला प्रश्न:**
अगर प्रश्न में ऐसा शब्द है जिसका root आपने कभी नहीं पढ़ा (जैसे "Psephologist" या "Numismatist") और विकल्पों में भी कोई परिचित root नहीं दिखता, तो तुक्का न लगाएँ — **छोड़ दें**। Negative marking में अनजान शब्द पर दांव लगाना घाटे का सौदा है।

**टिप 2 — दो विकल्प लगभग एक जैसे हों:**
जैसे "Epitaph" (कब्र पर लिखा) बनाम "Epilogue" (किताब का अंतिम भाग) — अगर दोनों में उलझन हो और 30 सेकंड में फैसला न हो, तो प्रश्न को **अंतिम राउंड के लिए छोड़ें**। पहले बाकी पेपर खत्म करें, फिर ताज़े दिमाग से लौटें।

**टिप 3 — लंबा विवरण वाला प्रश्न:**
अगर प्रश्न का वाक्य 2-3 पंक्तियों का है और हर विकल्प अनजान लग रहा है, तो यह "टाइम-सिंक" है। पहले छोटे, सीधे प्रश्न निपटाएँ — OWS में ज़्यादातर प्रश्न 15 सेकंड वाले होते हैं, उन्हीं से अंक बटोरें।

**याद रखें:** OWS में स्किप करना कमज़ोरी नहीं, रणनीति है — 1 गलत उत्तर की negative marking, 1 छोड़े प्रश्न से ज़्यादा नुकसान करती है।
