# 📋 महत्वपूर्ण नियम एवं टिप्स — शब्द मूल (Roots) एवं Morphology

## (क) 12 हाई-यील्ड नियम

| # | नियम | उदाहरण | परीक्षक का जाल |
|---|---|---|---|
| 1 | एक ही root से बने शब्दों का अर्थ-सूत्र (thread) समान होता है | **dict** = बोलना → dictate, predict, verdict, contradict | "beneficial" में **dict** नहीं, **bene** (अच्छा) + **fic** (करना) है — दिखने वाले अक्षरों पर मत जाओ |
| 2 | Prefix अर्थ बदलता है, Suffix शब्द-वर्ग (part of speech) बदलता है | happy → **un**happy (अर्थ बदला); happy → happi**ness** (विशेषण → संज्ञा) | "unhappiness" में दोनों हैं — परीक्षक पूछता है कौन-सा prefix है |
| 3 | **a-/an-** = नहीं/बिना (Greek) | amoral, atheist, anaerobic | "amoral" (नैतिकता से परे) ≠ "immoral" (बुरी नैतिकता) — दोनों अलग शब्द हैं |
| 4 | **bene/bon** = अच्छा; **mal** = बुरा (Latin) | benefit, bonus vs. malice, malfunction | "malevolent" (बुरी इच्छा वाला) और "benevolent" (भली इच्छा वाला) — एक अक्षर का फर्क, उल्टा अर्थ |
| 5 | **-cide** = मारना; **-phobia** = डर; **-phile** = प्रेमी | homicide, claustrophobia, bibliophile | "philanthropist" (मानव-प्रेमी) vs "misanthropist" (मानव-द्वेषी) — mis = घृणा |
| 6 | **chron** = समय; **geo** = पृथ्वी; **bio** = जीवन | chronology, geography, biology | "chronicle" (इतिहास-लेखन) को "chronic" (पुरानी बीमारी) से भ्रमित न हों — दोनों समय से जुड़े पर अर्थ अलग |
| 7 | **-logy** = अध्ययन/विज्ञान; **-logist** = अध्ययन करने वाला | psychology → psychologist | "geology" (भूविज्ञान) vs "geography" (भूगोल) — graphy = लिखना/वर्णन |
| 8 | **auto** = स्वयं; **hetero** = भिन्न; **homo** = समान | autobiography, heterogeneous, homogeneous | "homonym" (समान नाम/ध्वनि) vs "homogeneous" (समान प्रकार) — root समान, अर्थ भिन्न |
| 9 | **pre-** = पहले; **post-** = बाद में; **ante-** = पूर्व | predict, postpone, antecedent | "antebellum" (युद्ध-पूर्व) में ante = पहले, anti (विरुद्ध) नहीं |
| 10 | **-able/-ible** = योग्य; **-ous** = से युक्त; **-less** = रहित | readable, famous, hopeless | "-ible" वाले शब्द सीमित हैं (visible, audible) — "-able" default है |
| 11 | **port** = ले जाना; **ject** = फेंकना; **spect** = देखना | transport, reject, inspect | "respect" = फिर से (re-) देखना = सम्मान; "inspect" = अंदर देखना — prefix से अर्थ स्पष्ट |
| 12 | अपरिचित शब्द = prefix + root + suffix तोड़कर अर्थ निकालो | **in** + **cred** (विश्वास) + **ible** = जिस पर विश्वास न हो | "incredible" का शाब्दिक अर्थ "अविश्वसनीय" है, "बहुत अच्छा" नहीं — परीक्षक literal meaning पूछता है |

## (ख) समय प्रबंधन: 15/45 सेकंड नियम

**15 सेकंड — तथ्यात्मक (Fact-based) प्रश्न:**
- सीधा root/prefix/suffix का अर्थ पूछा गया हो ("'chron' का अर्थ क्या है?")
- एक शब्द का synonym/antonym जो root से तुरंत पहचाना जा सके
- शब्द-वर्ग पहचान (suffix देखकर: -tion = संज्ञा, -ous = विशेषण)
- ⏱️ अगर 15 सेकंड में root याद न आए → अनुमान लगाकर आगे बढ़ो, अटको मत

**45 सेकंड — तार्किक (Inference-based) प्रश्न:**
- अपरिचित शब्द का अर्थ वाक्य के संदर्भ (context) से निकालना
- कई root वाले जटिल शब्द (जैसे "antidisestablishmentarianism" जैसी संरचना तोड़नी हो)
- RC पैसेज में शब्द का टोन/भाव बताना
- ⏱️ रणनीति: पहले prefix तोड़ो → फिर root → फिर suffix → फिर विकल्पों से मिलाओ

## (ग) रूपात्मक सूत्र (Morphology Formulas)

| सूत्र | मूल शब्द + प्रत्यय | बना शब्द | अर्थ |
|---|---|---|---|
| Root + Suffix | dict (बोलना) + -ate | dictate | आदेश देना |
| Prefix + Root | pre (पहले) + dict | predict | भविष्यवाणी करना |
| Prefix + Root + Suffix | contra (विरुद्ध) + dict + -ion | contradiction | विरोधाभास |
| Root + Suffix | bio (जीवन) + -logy | biology | जीवविज्ञान |
| Prefix + Root + Suffix | a (बिना) + theo (ईश्वर) + -ist | atheist | नास्तिक |
| Root + Suffix | chron (समय) + -ic | chronic | पुराना/दीर्घकालिक |
| Prefix + Root + Suffix | mal (बुरा) + vol (इच्छा) + -ent | malevolent | दुर्भावनापूर्ण |
| Prefix + Root + Suffix | bene (अच्छा) + fac (करना) + -tor | benefactor | उपकार करने वाला |
| Root + Suffix | spect (देखना) + -or | spectator | दर्शक |
| Prefix + Root + Suffix | retro (पीछे) + spect + -ive | retrospective | पूर्ववलोकन करने वाला |

**याद रखने का सूत्र:** *Prefix दिशा बताता है, Root अर्थ देता है, Suffix पहचान (शब्द-वर्ग) बताता है।*
