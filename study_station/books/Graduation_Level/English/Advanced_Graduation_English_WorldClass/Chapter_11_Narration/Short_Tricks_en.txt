# 🪄 Short Tricks + Skip Strategy — Direct & Indirect Speech

---

## Trick 1 — The "S-T-P" Backbone

```
┌─────────────────────────────────────────────┐
│  S — SAYING verb changes (said → told)      │
│  T — TENSE steps one step back              │
│  P — PRONOUNS follow S-O-N                  │
│  If you fix S, T, P — 90% of the job is done│
└─────────────────────────────────────────────┘
```

---

## Trick 2 — "SON" for Pronouns

```
┌─────────────────────────────────────────────┐
│  S = Subject of reporting verb → 1st person │
│  O = Object of reporting verb  → 2nd person │
│  N = No change                 → 3rd person │
│                                             │
│  He said to me, "I will help you."          │
│  I → He (S) | you → me (O)                  │
│  → He told me that he would help me.        │
└─────────────────────────────────────────────┘
```

---

## Trick 3 — The Tense Ladder ("One Step Down")

```
┌─────────────────────────────────────────────┐
│  Present Simple    → Past Simple            │
│  Present Cont.     → Past Cont.             │
│  Present Perfect   → Past Perfect           │
│  Past Simple       → Past Perfect           │
│  will/shall        → would/should           │
│  can/may           → could/might            │
│  ⚠ Past Perfect & would/could/might/ought   │
│    NEVER step down — they stay frozen!      │
└─────────────────────────────────────────────┘
```

## Trick 4 — "HERE → THERE, NOW → THEN"

```
┌─────────────────────────────────────────────┐
│  now → then          today → that day       │
│  here → there        tonight → that night   │
│  this → that         yesterday → day before │
│  these → those       tomorrow → next day    │
│  ago → before        last night → night bef.│
│  Memory hook: "Near words go FAR away."     │
└─────────────────────────────────────────────┘
```

## Trick 5 — Question Type Detector

```
┌─────────────────────────────────────────────┐
│  Yes/No question?  → use IF / WHETHER       │
│  Wh- question?     → keep the Wh- word      │
│  BOTH: drop do/does/did, make it a          │
│  STATEMENT order (subject before verb).     │
│  "Where do you live?" → where I lived ✔     │
│  (never "where did I live")                 │
└─────────────────────────────────────────────┘
```

---

## Trick 6 — Imperative = "Verb in a Box"

```
┌─────────────────────────────────────────────┐
│  Order/Request/Advice → to + V1             │
│  Negative command     → not to + V1         │
│  "Open the door."  → ordered me to open     │
│  "Don't go there." → forbade me to go there │
│  Reporting verb upgrades: said → ordered /  │
│  requested / advised / warned / forbade     │
└─────────────────────────────────────────────┘
```

---

## Trick 7 — Exclamations: "What a → Great"

```
┌─────────────────────────────────────────────┐
│  "What a / How" → exclaimed with joy/sorrow │
│  + "great/very" + statement order           │
│  "What a beautiful day!" →                  │
│  She exclaimed with joy that it was a       │
│  very beautiful day.                        │
│  Hurrah! → joy | Alas! → sorrow/grief       │
└─────────────────────────────────────────────┘
```

---

## Trick 8 — Universal Truth Freeze

```
┌─────────────────────────────────────────────┐
│  Universal truths, proverbs, habits =       │
│  TENSE DOES NOT CHANGE.                     │
│  He said, "The sun rises in the east."      │
│  → He said that the sun rises in the east.  │
│  (NOT "rose" — the sun doesn't care about   │
│  your reporting verb!)                      │
└─────────────────────────────────────────────┘
```

---

## Trick 9 — "Said To = Told" Switch

```
┌─────────────────────────────────────────────┐
│  said + to + object  → told + object (no to)│
│  said (no object)    → said stays           │
│  ✗ "told to me"  ✗ "said me"               │
│  ✔ told me | ✔ said to me                   │
└─────────────────────────────────────────────┘
```

---

## Trick 10 — "Let" Decoder

```
┌─────────────────────────────────────────────┐
│  "Let us play" (suggestion) → proposed/     │
│    suggested that they should play          │
│  "Let him go" (permission)  → requested/    │
│    ordered that he (should) be allowed to go│
│  Ask: SUGGESTION or PERMISSION? Then pick.  │
└─────────────────────────────────────────────┘
```

---

## Trick 11 — Optative (Wishes)

```
┌─────────────────────────────────────────────┐
│  "May you live long!" → wished/prayed that  │
│  + might + V1                               │
│  He said, "May God bless you!" →            │
│  He prayed that God might bless me.         │
└─────────────────────────────────────────────┘
```

---

## Trick 12 — The 3-Second Eliminator

```
┌─────────────────────────────────────────────┐
│  In options, instantly REJECT any that:     │
│  1. Keeps "that" + question mark together   │
│  2. Keeps do/does/did in indirect speech    │
│  3. Uses "told to" or "said me"             │
│  4. Changes tense of a universal truth      │
│  Usually 2 options die here — 50% chance    │
│  before you even read the sentence fully.   │
└─────────────────────────────────────────────┘
```

---

## Trick 13 — Reporting Verb in Present/Future

```
┌─────────────────────────────────────────────┐
│  "He says…" / "He will say…" →              │
│  NO tense change inside the quote!          │
│  Only pronouns + time words may shift.      │
│  He says, "I am busy." → He says that he    │
│  is busy. (am stays is — no backshift)      │
└─────────────────────────────────────────────┘
```

---

## ⏭️ Skip Strategy

**1. Skip the "double-transformation" trap question (temporarily).**
If a question mixes an exclamation + question + tense shift in one long sentence, mark it and return. These take 60+ seconds; solve the three 15-second fact questions around it first.

**2. Skip when two options differ only in pronoun.**
Don't re-read the whole sentence — just apply S-O-N to the one pronoun that differs. If you can't decide in 20 seconds, pick the one matching the reporting verb's object and move on.

**3. Never skip a "said/says + universal truth" question.**
These are free marks with a single rule (Trick 8). If you see "sun," "earth," "honesty is the best policy," or a scientific fact — answer instantly; the tense never changes.

**4. Skip over-thinking on "would/could/might."**
If the direct speech already has would/could/might/should/ought, the correct option keeps them unchanged. Any option that "steps them down" is a trap — eliminate and answer in 15 seconds.
