# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति (Short Tricks + Skip Strategy)

## भाग 1: म्नेमोनिक ट्रिक्स (Mnemonic Tricks)

---

**ट्रिक 1 — FANBOYS (संयोजक / Conjunctions)**

```
┌─────────────────────────────────────────────┐
│  F = For      A = And      N = Nor          │
│  B = But      O = Or       Y = Yet   S = So │
│  जब ये 7 coordinating conjunctions दो       │
│  independent clauses (पूर्ण वाक्य) को       │
│  जोड़ें, तो उनके पहले comma लगाएँ।          │
└─────────────────────────────────────────────┘
```
उदाहरण: *He was tired, **yet** he kept working.*
ध्यान दें: *He was tired **but** happy.* — यहाँ comma नहीं, क्योंकि "happy" कोई independent clause नहीं है।

---

**ट्रिक 2 — "Each/Every = एकल" (Subject-Verb Agreement)**

```
┌─────────────────────────────────────────────┐
│  Each, Every, Everyone, Everybody,          │
│  Someone, Nobody, Either, Neither           │
│  → हमेशा SINGULAR verb                      │
│  याद रखें: "E-S-N गैंग अकेला खेलता है"      │
└─────────────────────────────────────────────┘
```
जाल: *Each of the boys **have**…* ❌ → *Each of the boys **has**…* ✅
("of the boys" सिर्फ़ Intervening Phrase है — कर्ता "Each" है।)

---

**ट्रिक 3 — "A-N-A" नियम (Neither/Either के साथ)**

```
┌─────────────────────────────────────────────┐
│  Neither…nor / Either…or में verb           │
│  नज़दीक वाले कर्ता (Nearest subject) के      │
│  अनुसार: "Aakhri Niyamit Adhikaar"          │
└─────────────────────────────────────────────┘
```
*Neither the teacher nor the students **were** present.* ✅ (students नज़दीक है)

---

**ट्रिक 4 — "SVOC" वाक्य-कंकाल**

```
┌─────────────────────────────────────────────┐
│  S = Subject, V = Verb, O = Object,         │
│  C = Complement                             │
│  कोई भी लंबा वाक्य हो — पहले S और V खोजो,   │
│  बीच का सारा "कचरा" (phrases) हटा दो।       │
└─────────────────────────────────────────────┘
```
*The box of chocolates **is** (not are) on the table.*

---

**ट्रिक 5 — "MRS. VANDERTRAMP" जैसी युक्ति — Uncountable Nouns**

```
┌─────────────────────────────────────────────┐
│  "F-L-I-A-N-B" गैंग को कभी 's' नहीं:        │
│  Furniture, Luggage, Information,           │
│  Advice, News, Bread                        │
│  → इनके साथ 'much/little', कभी 'many' नहीं  │
└─────────────────────────────────────────────┘
```
*He gave me many informations* ❌ → *much information* ✅

---

**ट्रिक 6 — "2-2-2" Tense पहचान**

```
┌─────────────────────────────────────────────┐
│  Since + point of time → Perfect/Perfect    │
│  Continuous (has been, have been)           │
│  For + duration → Perfect tense             │
│  Ago + Past Simple (never present perfect!) │
└─────────────────────────────────────────────┘
```
*I have met him two years ago* ❌ → *I met him two years ago* ✅

---

**ट्रिक 7 — "If-Were" कल्पना नियम (Subjunctive)**

```
┌─────────────────────────────────────────────┐
│  काल्पनिक इच्छा/शर्त में 'I/he/she' के साथ  │
│  भी 'were' ही आता है:                       │
│  "If I WERE a bird…" (was नहीं)             │
│  याद: "कल्पना में सब WERE हो जाते हैं"      │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 8 — "Less vs Fewer" — गिनती परख**

```
┌─────────────────────────────────────────────┐
│  गिन सकते हो? → FEWER (fewer students)      │
│  गिन नहीं सकते? → LESS (less water)         │
│  याद: "Fewer = Finger से गिनो"              │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 9 — "Between-Among" नियम**

```
┌─────────────────────────────────────────────┐
│  दो के बीच → Between                        │
│  तीन या अधिक → Among                        │
│  याद: "Bee (मधुमक्खी) दो फूलों के बीच"      │
└─────────────────────────────────────────────┘
```
*The secret is between you and me.* (me, न कि I — preposition के बाद objective case!)

---

**ट्रिक 10 — "Preposition के बाद -ING"**

```
┌─────────────────────────────────────────────┐
│  of, in, on, at, for, with, without,        │
│  before, after, by — इनके बाद verb आए तो    │
│  हमेशा V+ing (Gerund)                       │
│  "Prepo के बाद ING, यह नियम है पक्का"       │
└─────────────────────────────────────────────┘
```
*He is good at **swimming**.* / *Without **saying** a word…*

---

**ट्रिक 11 — "Hardly/Scarcely = When, No sooner = Than"**

```
┌─────────────────────────────────────────────┐
│  Hardly/Scarcely … WHEN                     │
│  No sooner … THAN                           │
│  जोड़े कभी मत बदलो! परीक्षक यहीं जाल बिछाता │
│  है: "No sooner…when" ❌                    │
└─────────────────────────────────────────────┘
```
*No sooner had she left **than** the phone rang.* ✅

---

**ट्रिक 12 — "One of the + Plural Noun + Singular Verb"**

```
┌─────────────────────────────────────────────┐
│  One of the + बहुवचन संज्ञा + एकवचन क्रिया  │
│  One of my friends **is** (not are) a doctor│
│  याद: "One ही असली राजा है"                 │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 13 — Vocabulary Root-बम (एक जड़, दस शब्द)**

```
┌─────────────────────────────────────────────┐
│  SPECT (देखना) → inspect, respect,          │
│  spectator, spectacle, prospect             │
│  PORT (ले जाना) → transport, export,        │
│  import, portable, support                  │
│  DICT (बोलना) → predict, dictate, verdict,  │
│  contradict, dictionary                     │
│  याद: "जड़ पकड़ो, पेड़ अपने आप याद"         │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 14 — RC में "पहली-आखिरी पंक्ति" चाल**

```
┌─────────────────────────────────────────────┐
│  Main Idea पूछे तो: पहले पैरा की पहली       │
│  पंक्ति + आखिरी पैरा की आखिरी पंक्ति पढ़ो।  │
│  अक्सर उत्तर वहीं छिपा होता है।             │
│  Tone पूछे तो: adjectives/adverbs गिनो —    │
│  positive शब्द ज़्यादा = optimistic tone    │
└─────────────────────────────────────────────┘
```

---

**ट्रिक 15 — "Sound-Right जाल" पहचानो**

```
┌─────────────────────────────────────────────┐
│  जो विकल्प "सुनने में सही" लगे, उस पर       │
│  दोगुना शक करो:                             │
│  • "He is more superior" ❌ (superior to)   │
│  • "return back" ❌ (return ही काफी)        │
│  • "revert back" ❌ / "repeat again" ❌     │
│  याद: "कान नहीं, नियम सुनो"                 │
└─────────────────────────────────────────────┘
```

## भाग 2: स्किप रणनीति (Skip Strategy) — कब प्रश्न छोड़ें

**⏭️ स्किप नियम 1 — "45 सेकंड की दीवार"**
कोई भी प्रश्न 45 सेकंड में हल न हो तो तुरंत चिह्नित (mark) करके आगे बढ़ो। तथ्यात्मक प्रश्न (Error Spotting, Fill in the Blanks, Synonym/Antonym) 15 सेकंड में होना चाहिए — अगर नहीं हो रहा, तो आपको वह तथ्य नहीं आता; अटके रहने से अगले 3 आसान प्रश्न छूट जाएँगे। अंत में समय बचे तो लौटो।

**⏭️ स्किप नियम 2 — "अधूरा शब्दावली प्रश्न"**
Synonym/Antonym में अगर मुख्य शब्द (stem word) ही अनजाना है और विकल्पों से अंदाज़ा नहीं लग रहा, तो छोड़ दो — negative marking में अंधा अनुमान (blind guess) घाटा कराता है। लेकिन अगर 4 में से 2 विकल्प काट सको (elimination), तब सोचा-समझा अनुमान लगाना फ़ायदेमंद है।

**⏭️ स्किप नियम 3 — "लंबा RC पैरा, कम समय"**
अंतिम 5 मिनट बचे हों और एक लंबा Reading Comprehension गद्यांश बाकी हो, तो पूरा गद्यांश पढ़ने के बजाय पहले प्रश्न पढ़ो — जो प्रश्न सीधे तथ्य पूछते हैं ("According to the passage…"), उन्हें keyword खोजकर (scanning) हल करो; Tone/Inference वाले प्रश्न छोड़ दो, क्योंकि उनके लिए पूरा संदर्भ चाहिए।

**⏭️ स्किप नियम 4 — "दो बार पढ़ो, फिर भी दुविधा = छोड़ो"**
Error Spotting में वाक्य दो बार पढ़ने के बाद भी त्रुटि न दिखे, तो "No error" चुनने से पहले एक बार हर underlined हिस्से पर अलग-अलग नियम लगाकर देखो। फिर भी संदेह हो तो प्रश्न छोड़ो — "No error" विकल्प परीक्षक का पसंदीदा जाल है, और अनिश्चित उत्तर negative marking का निमंत्रण है।
