# 🪄 Short Tricks + Skip Strategy — Tense

---

## Trick 1 — The "SINCE-FOR" Switch

```
┌─────────────────────────────────────────────┐
│  SINCE = Point of time (a dot on the line)  │
│  FOR   = Period of time (a stretch)         │
│                                             │
│  since Monday, since 2010, since childhood  │
│  for two days, for a decade, for ages       │
│                                             │
│  Both demand → Perfect / Perfect Continuous │
└─────────────────────────────────────────────┘
```
**Exam signal:** The moment you see *since/for* with a blank verb, eliminate Simple Past instantly.

---

## Trick 2 — "BY THE TIME" = Past Perfect Alarm

```
┌─────────────────────────────────────────────┐
│  "By the time + Simple Past"                │
│        → main clause takes PAST PERFECT     │
│                                             │
│  By the time we reached, the train HAD LEFT.│
│  (Earlier action = had + V3)                │
└─────────────────────────────────────────────┘
```

---

## Trick 3 — The "HAD Twins" Rule

Two past actions in one sentence? The **earlier** one wears *had*.

```
┌─────────────────────────────────────────────┐
│  First action  → had + V3 (Past Perfect)    │
│  Second action → V2 (Simple Past)           │
│                                             │
│  The patient HAD DIED before the doctor CAME│
│  Mnemonic: "Before/After ke saath,          │
│  pehle wala HAD pakadta hai."               │
└─────────────────────────────────────────────┘
```

## Trick 4 — Universal Truth Never Ages

```
┌─────────────────────────────────────────────┐
│  Facts, truths, habits → SIMPLE PRESENT     │
│  even inside past reporting!                │
│                                             │
│  The teacher said that the sun RISES        │
│  in the east.  (NOT "rose")                 │
│                                             │
│  Mnemonic: "Truth doesn't retire."          │
└─────────────────────────────────────────────┘
```

---

## Trick 5 — The "WILL-WILL" Ban

```
┌─────────────────────────────────────────────┐
│  Time/condition clause (if, when, unless,   │
│  until, as soon as) → NO "will" allowed!    │
│  Use Simple Present for future meaning.     │
│                                             │
│  ✗ If it WILL rain, I will stay home.       │
│  ✓ If it RAINS, I will stay home.           │
│                                             │
│  Mnemonic: "One WILL per sentence —         │
│  the main clause keeps it."                 │
└─────────────────────────────────────────────┘
```

---

## Trick 6 — "IT IS TIME" Goes Backwards

```
┌─────────────────────────────────────────────┐
│  "It is time / It is high time" + subject   │
│        → verb in SIMPLE PAST (V2)           │
│  (meaning: the action is overdue)           │
│                                             │
│  It is high time you STARTED working.       │
└─────────────────────────────────────────────┘
```

## Trick 7 — The -ING Companions

```
┌─────────────────────────────────────────────┐
│  These words drag a Continuous tense along: │
│  now, at this moment, currently, look!,     │
│  listen!, at present, these days            │
│                                             │
│  Look! The children ARE PLAYING outside.    │
└─────────────────────────────────────────────┘
```

---

## Trick 8 — Stative Verbs Refuse -ING

```
┌─────────────────────────────────────────────┐
│  Mnemonic: "S-L-K-P-B-U"                    │
│  Sense (see, hear, smell)                   │
│  Love/hate/like                             │
│  Know/believe/understand                    │
│  Possess (own, belong, have)                │
│  Be/seem/appear                             │
│  Understand/remember/suppose                │
│                                             │
│  ✗ I am knowing him.  ✓ I know him.         │
│  ✗ This is belonging to me. ✓ This belongs… │
└─────────────────────────────────────────────┘
```

## Trick 9 — "HARDLY/SCARCELY… WHEN" & "NO SOONER… THAN"

```
┌─────────────────────────────────────────────┐
│  Hardly/Scarcely + HAD + V3 … WHEN + V2     │
│  No sooner    + HAD + V3 … THAN + V2        │
│                                             │
│  Hardly HAD I REACHED home WHEN it rained.  │
│  No sooner HAD she SEEN me THAN she smiled. │
│                                             │
│  Trap: examiners swap when ↔ than!          │
└─────────────────────────────────────────────┘
```

---

## Trick 10 — The 3-Second Tense Detector

```
┌─────────────────────────────────────────────┐
│  Scan the sentence for a TIME MARKER first: │
│  yesterday/ago        → Simple Past         │
│  just/already/yet     → Present Perfect     │
│  since/for            → Perfect (Cont.)     │
│  tomorrow/next week   → Future              │
│  always/every day     → Simple Present      │
│  while/when + past    → Past Continuous     │
│                                             │
│  Marker first, verb second — never reverse! │
└─────────────────────────────────────────────┘
```

---

## Trick 11 — "WISH / IF ONLY" = One Step Back

```
┌─────────────────────────────────────────────┐
│  Wish about present → Past tense            │
│  Wish about past    → Past Perfect          │
│                                             │
│  I wish I WERE a bird.        (present)     │
│  I wish I HAD STUDIED harder. (past regret) │
│                                             │
│  Mnemonic: "Wishes live one tense behind    │
│  reality."                                  │
└─────────────────────────────────────────────┘
```

---

## Trick 12 — Future in Disguise

```
┌─────────────────────────────────────────────┐
│  Fixed schedule/timetable → Simple Present  │
│  Personal plan            → Present Cont.   │
│  Decision made now        → will            │
│  Prior plan/intention     → going to        │
│                                             │
│  The train LEAVES at 6. (schedule)          │
│  I AM MEETING her tonight. (arranged)       │
└─────────────────────────────────────────────┘
```

---

## Trick 13 — "AS IF / AS THOUGH" Mirror Rule

```
┌─────────────────────────────────────────────┐
│  Unreal comparison → one tense back         │
│  He talks as if he WERE a king. (he isn't)  │
│  She behaved as though she HAD SEEN a ghost.│
└─────────────────────────────────────────────┘
```

---

## Trick 14 — Perfect Continuous Formula Lock

```
┌─────────────────────────────────────────────┐
│  have/has/had + BEEN + V-ing + since/for    │
│  Missing "been" = the #1 printed error.     │
│                                             │
│  ✗ He has working here since 2015.          │
│  ✓ He has BEEN working here since 2015.     │
│                                             │
│  Mnemonic: "No BEEN, no Continuous."        │
└─────────────────────────────────────────────┘
```

## 🚫 Skip Strategy

**1. The 20-Second Exit:** If a tense question has two long clauses and you cannot spot the time marker within 20 seconds, mark it and move on. Tense questions are Fact-based (15-sec category) — if it isn't clicking fast, it's consuming time meant for Inference questions. Return in the second pass with fresh eyes; the marker usually jumps out.

**2. Skip the "Both-Look-Right" Trap:** When two options differ only by *had + V3* vs *V2* (e.g., "left" vs "had left"), don't guess immediately — find the sequence of events first. If you genuinely cannot establish which action came first, skip rather than gamble; this is the examiner's favourite 50-50 trap.

**3. Don't Over-Think Stative Verbs:** If your ear says "I am knowing" sounds odd but an option offers it confidently, trust the rule, not the sound — but if you can't recall whether a verb is stative, flag and skip. A wrong guess here costs negative marking; the rule list (Trick 8) takes 30 seconds to re-memorise before the exam.
