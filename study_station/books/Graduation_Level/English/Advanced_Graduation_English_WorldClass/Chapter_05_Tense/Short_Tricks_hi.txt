# 🪄 शॉर्ट ट्रिक्स + स्किप रणनीति — काल (Tense)

## 🎯 15 म्नेमोनिक ट्रिक्स

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 1: "VIB" — Present Indefinite की पहचान                  │
│ V = Verb की पहली form, I = s/es (he/she/it के साथ),          │
│ B = Base form ही रहती है।                                     │
│ ✔ He goes. ✔ They go. ✘ He go.                              │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 2: "Since = Point, For = Period"                        │
│ Since → समय का बिंदु (Monday, 2010, 5 o'clock, childhood)    │
│ For → समय की अवधि (two days, five years, a long time)        │
│ ✔ since 2015 ✔ for ten years                                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 3: "ING चल रहा, V3 हो चुका"                             │
│ is/am/are + V-ing → काम अभी चल रहा (Continuous)              │
│ has/have/had + V3 → काम पूरा हो चुका (Perfect)               │
│ has/have been + V-ing → पूरा नहीं, चलता आ रहा (Perfect Cont.)│
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 4: "By the time = Had + V3"                             │
│ "By the time / Before + Past" आए तो पहले हुआ काम             │
│ Past Perfect में:                                              │
│ ✔ The train had left before I reached the station.          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 5: "No sooner… than / Hardly… when / Scarcely… when"    │
│ तीनों जोड़े याद रखो — than/when की अदला-बदली = गलत।           │
│ ✔ No sooner had he come than it rained.                     │
│ ✘ No sooner had he come when it rained.                     │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 6: "If + Past, Would + V1" (Unreal Present)             │
│ काल्पनिक शर्त: If + Past Simple → would + V1                  │
│ ✔ If I were a bird, I would fly.                            │
│ (were सभी subjects के साथ — I/he/she के साथ भी!)              │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 7: "If + Had V3, Would have V3" (Unreal Past)           │
│ बीते समय का पछतावा:                                           │
│ ✔ If he had worked hard, he would have passed.              │
│ याद रखो: "Had-Have जोड़ी" — दोनों तरफ़ Perfect।                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 8: "Wish = एक कदम पीछे"                                 │
│ wish के बाद tense एक स्तर पीछे जाता है:                        │
│ Present की wish → Past: I wish I knew.                       │
│ Past की wish → Past Perfect: I wish I had known.             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 9: "It is time + Past"                                  │
│ "It is time / It is high time" के बाद Past Simple आता है,     │
│ भले अर्थ वर्तमान का हो:                                        │
│ ✔ It is high time we left. (हमें चलना चाहिए)                  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 10: "Universal Truth = हमेशा Present"                   │
│ Reporting verb Past हो तो भी सार्वभौमिक सत्य Present में:      │
│ ✔ The teacher said that the earth revolves around the sun.  │
│ ✘ …the earth revolved around the sun.                       │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 11: "Tomorrow के साथ Will नहीं (Time Clause में)"        │
│ when, as soon as, if, until, before के बाद Future नहीं,       │
│ Present आता है:                                                │
│ ✔ When he comes, I will tell him.                           │
│ ✘ When he will come, I will tell him.                       │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 12: "This morning/evening = Past की ओर झुकाव"           │
│ "this morning, this evening" बीते हुए हिस्से के लिए Past:     │
│ ✔ I met him this morning. (सुबह बीत चुकी)                    │
│ लेकिन "today, this week" अभी चल रहे हैं → Perfect संभव:      │
│ ✔ I have written two letters today.                         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 13: "Just/Already/Yet/Recently = Present Perfect"       │
│ ये शब्द दिखते ही has/have + V3 लगाओ:                          │
│ ✔ He has just arrived. ✔ I have already finished.           │
│ ✔ Have you done it yet?                                     │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 14: "Ago = Past Simple"                                 │
│ ago हमेशा Past Simple के साथ: ✔ He came two days ago.        │
│ ✘ He has come two days ago.                                 │
│ (Present Perfect के साथ निश्चित बीता समय कभी नहीं!)           │
│ ध्यान दें: "before" किसी एक tense से बंधा नहीं है —           │
│ यह Past Simple और Past Perfect दोनों के साथ आ सकता है:       │
│ ✔ He left before I arrived.                                 │
│ ✔ He had left before I arrived.                             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ट्रिक 15: "While + Continuous, When + Simple"                 │
│ लंबा काम (background) → Past Continuous;                      │
│ छोटा काम (interrupt) → Past Simple:                           │
│ ✔ While I was walking, I saw a snake.                       │
│ याद रखो: "While लंबा, When झटका"।                             │
└─────────────────────────────────────────────────────────────┘

## ⏭️ Skip Strategy — कब प्रश्न छोड़ें

**1. दोनों विकल्प "लगभग सही" लगें और नियम याद न आए — छोड़ दो।**
Tense के प्रश्नों में परीक्षक जानबूझकर "sound-right" विकल्प रखता है (जैसे "I am knowing" सुनने में ठीक लगता है)। अगर 45 सेकंड में नियम याद न आए, अंधा अनुमान न लगाओ — नेगेटिव मार्किंग में यही बचाव है।

**2. लंबा वाक्य + 3-4 verbs वाला Error Spotting — अंत में करो।**
जिस वाक्य में कई clauses हों (जैसे "No sooner had he… when…"), पहले छोटे Fact-based प्रश्न (since/for, has/have) निपटाओ। लंबे वाक्य को दूसरे चक्कर में clause-by-clause तोड़कर हल करो।

**3. Conditional (If-clause) में Mixed Conditional दिखे — सावधानी, समय लगेगा।**
"If he had studied, he would be a doctor now" जैसे Mixed Conditional में दोनों clauses अलग-अलग समय के होते हैं। अगर concept स्पष्ट नहीं है, तो इसे skip करके बाद में आओ — जल्दबाज़ी में would/would have की अदला-बदली हो जाती है।

## ⚡ अंतिम सलाह

- **15 सेकंड वाले प्रश्न:** since/for, has/have/had, s/es, ago, just/already — सीधे नियम लगाओ, सोचो मत।
- **45 सेकंड वाले प्रश्न:** Sequence of Tenses, Conditional, Reported Speech — पहले समय-रेखा (timeline) दिमाग़ में बनाओ, फिर उत्तर दो।
- परीक्षा से एक दिन पहले इन 15 ट्रिक्स को एक बार ज़ोर से बोलकर दोहराओ — यही तुम्हारी "अंतिम झलक" शीट है।
