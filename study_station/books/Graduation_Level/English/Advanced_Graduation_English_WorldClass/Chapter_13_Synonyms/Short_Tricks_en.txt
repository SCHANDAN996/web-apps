# 🪄 Short Tricks + Skip Strategy — Synonyms

## Trick 1: The "Replace & Read" Test
```
┌─────────────────────────────────────────────┐
│ Don't match the word to the option directly.│
│ REPLACE the word in a sentence you invent,  │
│ then read it aloud. If the sentence still   │
│ makes sense, the synonym is right.          │
│ "He was CANDID" → "He was FRANK" ✔          │
└─────────────────────────────────────────────┘
```

## Trick 2: The Positive–Negative Filter
```
┌─────────────────────────────────────────────┐
│ First decide: is the word POSITIVE,         │
│ NEGATIVE, or NEUTRAL? Eliminate options of  │
│ the wrong charge instantly.                 │
│ "Frugal" = positive/neutral → cut "wasteful"│
│ "Candid" = positive → cut "rude", "harsh"   │
└─────────────────────────────────────────────┘
```

## Trick 3: Root Power (One Root = Ten Words)
```
┌─────────────────────────────────────────────┐
│ BENE = good → benefit, benevolent, benign   │
│ MAL  = bad  → malice, malignant, malady     │
│ CRED = believe → credible, credulous        │
│ LOQU = speak → eloquent, loquacious         │
│ Learn the root, guess the stranger.         │
└─────────────────────────────────────────────┘
```

## Trick 4: The "Degree Ladder"
```
┌─────────────────────────────────────────────┐
│ Synonyms differ in INTENSITY. Pick the one  │
│ at the same step of the ladder.             │
│ annoy < irritate < enrage < infuriate       │
│ "Irate" ≈ "angry", NOT "furious" (too high) │
└─────────────────────────────────────────────┘
```

## Trick 5: Mnemonic — "CANDID Camera"
```
┌─────────────────────────────────────────────┐
│ CANDID = frank, honest.                     │
│ A candid camera catches people being        │
│ HONEST and natural — no acting!             │
└─────────────────────────────────────────────┘
```

## Trick 6: Mnemonic — "GREG the Party Animal"
```
┌─────────────────────────────────────────────┐
│ GREG = flock/group (Latin grex).            │
│ GREGARIOUS = sociable — Greg loves the herd!│
│ Also: congregate, segregate, aggregate.     │
└─────────────────────────────────────────────┘
```

## Trick 7: Mnemonic — "AMBI = Both Hands"
```
┌─────────────────────────────────────────────┐
│ AMBI = both. Ambidextrous = both hands work.│
│ AMBIGUOUS = meaning goes BOTH ways = unclear│
│ AMBIVALENT = feelings on BOTH sides.        │
└─────────────────────────────────────────────┘
```

## Trick 8: The "Word Family" Cluster
```
┌─────────────────────────────────────────────┐
│ Never learn one word — learn the cluster:   │
│ BRAVE: courageous, valiant, gallant, intrepid│
│ Examiners rotate within the same family.    │
└─────────────────────────────────────────────┘
```

## Trick 9: The False-Friend Alarm
```
┌─────────────────────────────────────────────┐
│ Similar SOUND ≠ similar MEANING.            │
│ "Enervate" ≠ energize — it means WEAKEN.    │
│ "Restive" ≠ restful — it means RESTLESS.    │
│ "Inflammable" = flammable (both burn!).     │
└─────────────────────────────────────────────┘
```

## Trick 10: The Part-of-Speech Check
```
┌─────────────────────────────────────────────┐
│ The synonym must match the word's ROLE.     │
│ If the word is a verb, reject noun options. │
│ "Abdicate" (verb) → "renounce" ✔,           │
│ not "abdication" ✘ (noun trap).             │
└─────────────────────────────────────────────┘
```

## Trick 11: The Connotation Compass
```
┌─────────────────────────────────────────────┐
│ Same meaning, different flavour:            │
│ "Slim" (compliment) vs "Skinny" (insult).   │
│ Match the TONE of the given word, not just  │
│ the dictionary meaning.                     │
└─────────────────────────────────────────────┘
```

## Trick 12: The Elimination-First Rule
```
┌─────────────────────────────────────────────┐
│ Don't hunt the right answer — kill 3 wrong  │
│ ones. In synonym MCQs, two options are      │
│ usually antonyms or unrelated; one is a     │
│ near-miss trap. What survives is correct.   │
└─────────────────────────────────────────────┘
```

## Trick 13: Mnemonic — "LOQUACIOUS Lata"
```
┌─────────────────────────────────────────────┐
│ LOQU = speak. LOQUACIOUS = talkative.       │
│ Picture "Lata who never stops LOQU-ing" —   │
│ she talks, talks, talks!                    │
└─────────────────────────────────────────────┘
```

## Trick 14: The 15/45-Second Split
```
┌─────────────────────────────────────────────┐
│ Direct word (candid, abandon, keen) → 15 s. │
│ Word inside a sentence needing context or   │
│ tone judgement → 45 s. Never spend 45 s on  │
│ a pure recall word — answer or skip.        │
└─────────────────────────────────────────────┘
```

## Trick 15: The "One-Word-a-Day Root Diary"
```
┌─────────────────────────────────────────────┐
│ Each day, write ONE root + 5 derived words. │
│ In 60 days you own 300+ words — far more    │
│ than any synonym list you could cram.       │
└─────────────────────────────────────────────┘
```

## ⏭️ Skip Strategy

**Skip Tip 1 — The Total Stranger:**
If you have never seen the word AND cannot break it into a known root/prefix/suffix within 10 seconds, mark it and move on. A blind guess between 4 unknown options has a 75% chance of costing you negative marks. Return only if time remains.

**Skip Tip 2 — The Two-Temptation Deadlock:**
When two options both look correct (e.g., "candid" → "honest" vs "frank"), do NOT freeze. Apply the Connotation Compass (Trick 11): which one matches the exact tone/usage? If still tied after 20 seconds, pick the one closer in *register* (formal/informal) to the given word — and never leave it blank if there is no negative marking.

**Skip Tip 3 — Don't Over-Think Easy Words:**
If the word is common (happy, begin, brave) and the obvious synonym is sitting in the options, take it and go. Examiners plant "sophisticated-looking" distractors to make you doubt a simple correct answer. Over-thinking a 15-second question is the costliest trap in the vocabulary section.
