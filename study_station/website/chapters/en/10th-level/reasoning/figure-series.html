Chapter Notes

Figure Series

🧠
An arrow points up, then right, then down — which way next? Left! Because the arrow turns 90° each time. Figure-series questions test catching this visual pattern — not numbers, but figures.

Definition: In a figure series, a sequence of figures is given that changes by some rule (rotation, adding/removing, changing direction); we must identify the next or the missing figure.

🧠 Recall: In a figure series, is the pattern about numbers or about visuals (shape/direction)?

Main Rules (What Can Change)

1. Rotation

The figure turns by a fixed angle (45°, 90°) each time — clockwise or anticlockwise.

2. Addition/Removal

A line, dot, or side is added or removed at each step.

3. Change of Direction/Position

An element moves corner to corner, or shifts left-right.

4. Flip (Mirror)

The figure flips like a mirror each time.

The Golden Rule

🧠
First pick one element (like the arrow or the shaded part) and see how it changes at each step — did it rotate, grow, or shift? Then apply the same rule to the next figure.
🧠 Recall: If the arrow turns 90° each time and now points left, which way did it point in the previous figure?

The Examiner's Trap

⚠️ Trap 1 — two changes together: Sometimes rotation and addition happen together — check each element separately.

⚠️ Trap 2 — direction of rotation: Watch carefully the difference between clockwise and anticlockwise.

⚠️ Trap 3 — missing a small change: A single dot or line being added is easily overlooked.

Review this after 2 days.

In Simple Words

Feynman Technique: Figure Series in Simple Words

Tell your younger brother: "Think of a clock hand — it turns a little every hour. A figure series is just like that — a figure turns a bit each time, or a line keeps getting added. You just have to see 'what is changing', and then the next figure reveals itself."

🧠
Pick one element, see how it changes each time — did it rotate, grow, or shift? Then apply the same rule forward.

The Biggest Trick: Track Each Element Separately

If the figure has several things (arrow + shaded part + dots), track each one separately:

  • Does the arrow turn 90° each time?
  • Does the shaded part move to the next corner each time?
  • Does the number of dots increase by 1 each time?

Catch each element's own rule, then combine them to build the next figure.

Short Tricks

Short Tricks: Figure Series

🪄
Trick: First pick one element (arrow/shaded part/dot) and track its change — the rest later.
🪄
Trick: Identify the rotation angle — a full turn in 4 steps = 90°, in 8 steps = 45°.
🪄
Trick: Note the count of countable elements (sides, dots, lines) — often it increases/decreases by 1 each time.
🪄
Trick: Clockwise is the clock direction; anticlockwise is the reverse — fix the direction before moving on.
🪄
Trick: Match options element by element — cut any where even one element breaks the rule.
🪄
Trick: If two changes happen together (rotation + addition), apply each element's rule and combine.

Skip Strategy: Skip very tangled multi-element figures; do the direct rotation/count ones first.

💡Mnemonic: "One element, one rule" — then combine them all.

D left
