असमानता (Inequality)

🧠
अगर राम, श्याम से लंबा है और श्याम, मोहन से लंबा है — तो क्या राम, मोहन से लंबा है? हाँ! क्योंकि > का रिश्ता आगे बढ़ता है। असमानता के प्रश्न इन्हीं >, <, = चिह्नों से रिश्ते जोड़ने की परीक्षा हैं।

परिभाषा: इन प्रश्नों में कुछ राशियों के बीच असमानता के चिह्न (>, <, =, ≥, ≤) दिए जाते हैं, और हमें दिए गए कथन से कौन-सा निष्कर्ष निश्चित रूप से निकलता है, यह तय करना होता है।

🧠 Recall: यदि A > B और B > C, तो A और C में क्या संबंध है?

आधार: चिह्नों का अर्थ

  • A > B : A, B से बड़ा
  • A < B : A, B से छोटा
  • A = B : दोनों बराबर
  • A ≥ B : A, B से बड़ा या बराबर
  • A ≤ B : A, B से छोटा या बराबर

हल का सुनहरा नियम: शृंखला जोड़ो

1. समान दिशा जुड़ती है: A > B > C → A > C (सही)।

2. बराबर बीच में हो तो भी चले: A > B = C → A > C (सही)।

3. दिशा बदले तो रिश्ता टूटता है: A > B < C → A और C में कोई निश्चित संबंध नहीं।

Either-Or (या तो-या) नियम

जब दो निष्कर्षों में एक ही जोड़ी पर > और = (या < और =) हों, और अकेले कोई सही न हो, तो वे "या तो यह या वह" के रूप में सही होते हैं। जैसे A ≥ C से "A > C या A = C" — दोनों मिलकर सही।

🧠 Recall: A > B < C में A और C का संबंध निश्चित है या नहीं?

परीक्षक का जाल (Examiner's Trap)

⚠️ जाल 1 — दिशा बदलना: > और < मिल जाएँ तो सीधा निष्कर्ष नहीं निकलता। दिशा एक जैसी होनी चाहिए।

⚠️ जाल 2 — ≥ बनाम >: "≥" में बराबरी भी शामिल है; निष्कर्ष निकालते समय यह याद रखो।

⚠️ जाल 3 — Either-Or भूलना: कभी दोनों निष्कर्ष अकेले ग़लत, पर "या तो-या" के रूप में सही होते हैं।

इसे 2 दिन बाद दोहराएँ।

Inequality

🧠
If Ram is taller than Shyam and Shyam is taller than Mohan — is Ram taller than Mohan? Yes! Because the > relation carries forward. Inequality questions test joining relations using these >, <, = signs.

Definition: In these questions, inequality signs (>, <, =, ≥, ≤) are given between some quantities, and we must decide which conclusion definitely follows from the statement.

🧠 Recall: If A > B and B > C, what is the relation between A and C?

The Basics: Meaning of the Signs

  • A > B : A is greater than B
  • A < B : A is less than B
  • A = B : both are equal
  • A ≥ B : A is greater than or equal to B
  • A ≤ B : A is less than or equal to B

The Golden Rule: Join the Chain

1. Same direction joins: A > B > C → A > C (correct).

2. Equality in between still works: A > B = C → A > C (correct).

3. If the direction changes, the relation breaks: A > B < C → no definite relation between A and C.

The Either-Or Rule

When two conclusions have > and = (or < and =) on the same pair, and neither is correct alone, they are correct as "either this or that". For example, A ≥ C gives "A > C or A = C" — together they are correct.

🧠 Recall: In A > B < C, is the relation between A and C definite or not?

The Examiner's Trap

⚠️ Trap 1 — direction change: If > and < meet, no direct conclusion follows. The direction must be the same.

⚠️ Trap 2 — ≥ vs >: "≥" includes equality; remember this when drawing a conclusion.

⚠️ Trap 3 — forgetting Either-Or: Sometimes both conclusions are wrong alone, but correct as "either-or".

Feynman Technique: Inequality in Simple Words

🧠
Tell your younger brother: "Think, three friends by height — Ram > Shyam, Shyam > Mohan. So who is tallest? Ram! Shortest? Mohan! When all the arrows point the same way (>), the ends join directly. That is all inequality is."

If all signs are in the same direction, the chain joins; the moment the direction changes, the relation breaks.

The Biggest Trick: Watch the Arrow Direction

A > B > C — all arrows point 'greater to smaller' → A > C is certain.

But A > B < C — here B is smaller than both, so we don't know which of A and C is greater → no definite relation.

Whenever the direction is not the same, immediately conclude — "no definite relation".
