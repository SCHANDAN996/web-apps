# 🏫 JSPS Chandauli - School Portal Web Application

A full-stack **School Management & CBSE Parent Portal** web platform built using **Flask**, **SQLAlchemy**, and modern responsive design.

---

## 🌟 Key Features
* 👨‍👩‍👧 **Parent & Student Portal:** Check student attendance, notices, and fee records.
* 💳 **Fee Management:** Track admission fee structures, dues, and payment histories.
* 📢 **Announcements & Circulars:** CBSE compliance document viewer and circular board.
* 🛡️ **Role-Based Authentication:** Secure access control for Admin, Teachers, and Parents.
* 📱 **Mobile Responsive:** Seamless experience across smartphones, tablets, and desktops.

---

## 🛠️ Tech Stack
* **Backend:** Python / Flask, Flask-SQLAlchemy, Flask-Login, Flask-WTF
* **Frontend:** HTML5, Jinja2, CSS3, JavaScript
* **Database:** SQLite / PostgreSQL

---

## 🚀 Setup & Installation

```bash
# 1. Clone repository
git clone https://github.com/SCHANDAN996/school-portal-jsps.git
cd school-portal-jsps

# 2. Install requirements
pip install -r requirements.txt

# 3. Initialize Database & Run
python app.py
```
