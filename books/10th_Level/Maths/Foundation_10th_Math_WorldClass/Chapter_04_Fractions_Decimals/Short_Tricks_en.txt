4. The “Denominator is the Name” Rule (Addition/Subtraction)

text
Copy
Download
┌─────────────────────────────────────────────┐
│   🏷️  "Change the Name Before You Play"       │
│                                               │
│   Fractions are like teams. You can't play a  │
│   match if both teams wear the same name      │
│   (denominator). First, give them a common    │
│   uniform (LCM). Then add the players         │
│   (numerators).                                │
│                                               │
│   ⅓ + ¼ → change names to 4/12 and 3/12,      │
│   then play: 4 + 3 = 7 → 7/12.                │
│                                               │
│   Never add denominators directly – that's    │
│   like mixing two teams' jersey numbers!      │
└─────────────────────────────────────────────┘

6. Mixed Recurring Decimal – “Subtract the Non-Repeater”

text
Copy
Download
┌─────────────────────────────────────────────┐
│    🤹‍♂️  "All Minus Non-Repeater"               │
│                                               │
│   For mixed recurring (e.g., 0.8\overline{3}): │
│   Numerator = [all digits after decimal up to  │
│   first repeat] minus [non-repeating part].    │
│   Denominator = as many 9s as repeating digits │
│   followed by as many 0s as non-repeating.     │
│                                               │
│   0.8\overline{3} → (83 - 8) = 75, denom = 90 │
│   = 75/90 = 5/6.                              │
│                                               │
│   Story: "All guests (83) except the non-     │
│   repeater (8) are invited to the 9-0 party." │
└─────────────────────────────────────────────┘

│   the skyscraper; the other is the bungalow." │

10. Decimal Multiplication – “Count the Steps”

text
Copy
Download
┌─────────────────────────────────────────────┐
│       👣  "Multiply, Then Walk Back"           │
│                                               │
│   To multiply decimals: ignore the points,    │
│   multiply as whole numbers. Then count the   │
│   total decimal places in both numbers and    │
│   walk the decimal point back that many steps.│
│                                               │
│   0.4 × 0.02 → 4 × 2 = 8, total 3 decimal    │
│   places → 0.008.                             │
│                                               │
│   "The point went for a walk. Count its       │
│   steps forward, then trace back."            │
└─────────────────────────────────────────────┘

│                                               │
│   To find LCM of decimals:                    │
│   1. Remove decimal points by multiplying all │

│   LCM(12,18)=36 → divide by 10 → 3.6.         │
│                                               │
│   "The decimal point goes on vacation, LCM    │
│   visits the integers, then the point returns │
│   to claim its share."                        │
└─────────────────────────────────────────────┘

13. Terminating vs Recurring – “Check the Basement”

text
Copy
Download
┌─────────────────────────────────────────────┐
│       🏠  "Basement Rule"                      │
│                                               │
│   A fraction in simplest form terminates if   │
│   its denominator has only 2 and 5 as prime   │
│   factors. Otherwise, it recurs.              │
│                                               │
│   1/4 = 0.25 (denominator 4=2², terminates).  │
│   1/3 = 0.333... (3 is not 2 or 5, recurs).   │
│                                               │
│   "If the basement (denominator) is built     │
│   only with 2s and 5s, the decimal stops      │
│   politely. Any other prime and it chatters   │
│   forever."                                   │
└─────────────────────────────────────────────┘
