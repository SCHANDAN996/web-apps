Front: The core idea of classification in one sentence?
Back: Identify the "odd one out" — the item that differs from the shared property of the majority.

Front: The golden rule for solving classification?
Back: First identify the shared property of the majority, then see which one falls outside it.

Front: Rose, Lotus, Jasmine, Mango — which is odd?
Back: Mango. The other three are flowers; mango is a fruit.

Front: 3, 5, 7, 9, 11 — which is odd and why?
Back: 9. The rest are prime; 9 = 3×3 is composite.

Front: 4, 9, 16, 20, 25 — which is odd?
Back: 20. The rest are perfect squares (2²,3²,4²,5²); 20 is not.

Front: 8, 27, 64, 100, 125 — which is odd?
Back: 100. The rest are perfect cubes (2³,3³,4³,5³); 100 is not.

Front: In letter classification, what do we look at?
Back: The gap between letters. The pair whose pattern differs from the rest is the odd one.

Front: Dog, Cat, Cow, Tiger — which is odd?
Back: Tiger. The rest are domestic; the tiger is wild.

Front: India, Nepal, Tokyo, China — which is odd?
Back: Tokyo. The rest are countries; Tokyo is a city.

Front: Which properties to check first in number classification?
Back: Prime, perfect square, perfect cube, even/odd — "P-S-C-E".

Front: What is the most common trap?
Back: More than one basis existing — then choose the strongest, clearest basis.

Front: Copper, Iron, Gold, Rubber — which is odd?
Back: Rubber. The rest are metals; rubber is a non-metal.

Front: Triangle, Square, Circle, Rectangle — which is odd?
Back: Circle. The rest have straight sides/corners; a circle does not.

Front: 11, 13, 17, 19, 21 — which is odd?
Back: 21. The rest are prime; 21 = 3×7 is composite.

Front: If you cannot find a number's property within 30 seconds?
Back: Skip the question and return later (Skip Strategy).
