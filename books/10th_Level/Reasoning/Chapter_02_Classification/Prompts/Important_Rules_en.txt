📋 Important Rules & Approaches

1. Key Rules/Approaches
Rule Name	Description	Example
Four-Yes, One-No Test	A correct classification base must apply to exactly 4 options and fail on exactly 1. If it fits all 5 or only 3, it is not the right base.	Apple, Mango, Banana, Carrot, Grape → Base “Fruit?” → 4 Yes, 1 No (Carrot). Carrot is odd.
Primary Base First	Always check the most obvious, direct category (meaning, number type, letter position) before looking for hidden or structural patterns.	Numbers: 2,3,5,7,9 — first check Prime/Composite, not sum of digits.
Position-Writing Rule (Letters)	Immediately write the positional value (A=1, B=2... Z=26) beneath each letter to reveal gap patterns.	JMP → J(10), M(13)+3, P(16)+3. Break in gap signals odd one.
Opposite Letter Formula	Opposite letter position = 27 – given letter’s position.	Opposite of D(4) = 27-4 = 23 → W.
Meaning vs. Structure (Words)	If word meaning provides no clear category, switch to structure: count letters, vowels, or check dictionary order.	Happiness, Sadness, Anger, Joy, Fear — all emotions (meaning works). If confused, count letters.
GK Hot-Spot Check	For GK-based, first verify geography (country/capital), science (SI units, vitamins), sports (players), or calendar.	Metre, Kilogram, Second, Litre, Kelvin — Litre is not an SI unit.
Mixed Group Rule	In mixed classification, treat letters and numbers separately. First find relationship between letter position and number, then with next letter.	D4G — D(4), number 4, G(7) = D+3. If middle number ≠ first letter’s position, it’s odd.
Prime Number Trap	1 is neither prime nor composite. It often appears as a distractor in number classification.	1, 2, 3, 5, 7 — 1 is odd because it’s not prime.
2. Time Management
Strategy	Description	Action
15-Second Rule	If the pattern or common base is not identified within 15 seconds, mark the question and move on.	Don’t get stuck; attempt later if time permits.
45-Second Attempt Limit	Even if you spot the base, do not spend more than 45 seconds on a single classification question.	Re-evaluate the base quickly; if still unsure, take an educated guess and flag for review.
Skip and Cluster	Skip lengthy mixed or GK questions on first pass. Cluster similar easy types (letter-based, direct word) and solve them in a batch.	First 5 min: solve all direct Letter/Number/Word classifications; later tackle GK and Mixed.
Accuracy over Speed in GK	GK-based questions rely on knowledge. If unsure, do not waste time; a 50/50 guess is better than 2 minutes.	If you don’t know the capital or vitamin, skip immediately.
3. Logical/Mathematical Formulas
Formula / Constant	When to Use	Explanation
Opposite Letter	Letter-based, when pairs look reversed (e.g., A-Z, B-Y).	Position_opposite = 27 – Position_original
No other fixed formulas	Classification is based on pattern recognition, not calculation. Rules like “Sum of digits,” “Difference between positions,” “Product of digits” are question-specific, not universal formulas.	Use them as tests, not as memorized formulas.
