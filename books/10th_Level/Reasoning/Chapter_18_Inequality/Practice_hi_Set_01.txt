सेट 1: असमानता MCQs (हिंदी)
प्रश्न 1–16: आसान | प्रश्न 17–20: मध्यम

प्रश्न 1. यदि X > Y > Z, तो कौन-सा सही है?
(a) X > Z (b) Z > X (c) X = Z (d) नहीं कह सकते
उत्तर: (a) X > Z
हल: समान दिशा: X > Y > Z से X > Z।
स्रोत: NCERT रीज़निंग

प्रश्न 2. यदि X < Y < Z, तो सबसे बड़ा कौन है?
(a) X (b) Y (c) Z (d) नहीं कह सकते
उत्तर: (c) Z
हल: X < Y < Z, अतः Z सबसे बड़ा।
स्रोत: SSC MTS

प्रश्न 3. यदि A > B < C, तो A और C में क्या संबंध है?
(a) A > C (b) A < C (c) A = C (d) नहीं कह सकते
उत्तर: (d) नहीं कह सकते
हल: दिशा बदल गई, अतः कोई निश्चित संबंध नहीं।
स्रोत: SSC CHSL

प्रश्न 4. यदि A = B = C, तो A और C में क्या संबंध है?
(a) A > C (b) A < C (c) A = C (d) नहीं कह सकते
उत्तर: (c) A = C
हल: सब बराबर हैं, अतः A = C।
स्रोत: RRB NTPC

प्रश्न 5. यदि P > Q = R, तो कौन-सा सही है?
(a) P > R (b) P < R (c) P = R (d) नहीं कह सकते
उत्तर: (a) P > R
हल: P > Q और Q = R, अतः P > R।
स्रोत: NCERT रीज़निंग

प्रश्न 6. '≤' का अर्थ क्या है?
(a) बड़ा (b) छोटा या बराबर (c) बराबर (d) बड़ा या बराबर
उत्तर: (b) छोटा या बराबर
हल: ≤ का अर्थ छोटा या बराबर।
स्रोत: NCERT रीज़निंग

प्रश्न 7. यदि A > B > C > D, तो क्या A > D?
(a) सही (b) ग़लत (c) नहीं कह सकते (d) A = D
उत्तर: (a) सही
हल: पूरी शृंखला समान दिशा: A > D।
स्रोत: SSC MTS

प्रश्न 8. यदि A < B > C, तो A और C में क्या संबंध है?
(a) A > C (b) A < C (c) A = C (d) नहीं कह सकते
उत्तर: (d) नहीं कह सकते
हल: दिशा बदल गई, अतः कोई निश्चित संबंध नहीं।
स्रोत: SSC CGL

प्रश्न 9. यदि M ≥ N > O, तो कौन-सा सही है?
(a) M > O (b) M < O (c) M = O (d) नहीं कह सकते
उत्तर: (a) M > O
हल: M ≥ N और N > O, अतः M > O।
स्रोत: बैंक क्लर्क

प्रश्न 10. यदि A > B = C > D, तो क्या A > D?
(a) सही (b) ग़लत (c) नहीं कह सकते (d) A = D
उत्तर: (a) सही
हल: A > B = C > D, सब आगे की ओर, अतः A > D।
स्रोत: SSC CGL

प्रश्न 11. '>' चिह्न का अर्थ क्या है?
(a) छोटा (b) बड़ा (c) बराबर (d) असमान
उत्तर: (b) बड़ा
हल: > का अर्थ बड़ा।
स्रोत: NCERT रीज़निंग

प्रश्न 12. यदि A < B = C, तो क्या A < C?
(a) सही (b) ग़लत (c) नहीं कह सकते (d) A = C
उत्तर: (a) सही
हल: A < B और B = C, अतः A < C।
स्रोत: SSC MTS

प्रश्न 13. यदि A > B, B > C और C > D, तो क्या A > D?
(a) सही (b) ग़लत (c) नहीं कह सकते (d) A = D
उत्तर: (a) सही
हल: पूरी शृंखला समान दिशा: A > D।
स्रोत: RRB Group D

प्रश्न 14. यदि X = Y और Y > Z, तो क्या X > Z?
(a) सही (b) ग़लत (c) नहीं कह सकते (d) X = Z
उत्तर: (a) सही
हल: X = Y और Y > Z, अतः X > Z।
स्रोत: SSC CHSL

प्रश्न 15. यदि A ≤ B ≤ C, तो A और C में क्या संबंध है?
(a) A ≥ C (b) A ≤ C (c) A = C (d) नहीं कह सकते
उत्तर: (b) A ≤ C
हल: समान दिशा: A ≤ B ≤ C से A ≤ C।
स्रोत: NCERT रीज़निंग

प्रश्न 16. "या तो A > C या A = C" किसके बराबर है?
(a) A < C (b) A ≥ C (c) A ≤ C (d) A ≠ C
उत्तर: (b) A ≥ C
हल: "> या =" मिलकर ≥ होता है।
स्रोत: SSC CGL

प्रश्न 17. (मध्यम) यदि P < Q < R < S, तो सबसे छोटा कौन है?
(a) P (b) Q (c) R (d) S
उत्तर: (a) P
हल: P < Q < R < S, अतः P सबसे छोटा।
स्रोत: SSC CGL

प्रश्न 19. (मध्यम) यदि A = B, B = C और C = D, तो A और D में क्या संबंध है?
