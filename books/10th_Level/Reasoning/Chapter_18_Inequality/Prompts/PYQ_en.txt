4. Top 10 High-Yield PYQs with Solutions & Psychological Traps

Q1. IBPS PO Prelims 2017

Question: Statements: A > B ≥ C = D < E. Conclusions: I. A > C, II. A = C.

Solution: From A > B ≥ C, A > C is definite. Conclusion I is true, II is false. Answer: Only I follows.

🧠 Trap: “Double possibility confusion” — The statement A > B ≥ C makes A > C definite, yet the examiner offers A = C as a conclusion, tempting you to think it might also be true because ≥ includes =.

Q2. SBI PO Prelims 2018

Question: Statements: M ≥ N > O; P ≤ O > Q. Conclusions: I. M > Q, II. N ≥ P.

Solution: Combine: M ≥ N > O > Q. M > Q (True). N > O and P ≤ O gives no definite N ≥ P (False). Answer: Only I follows.

🧠 Trap: “Partial chain illusion” — N > O and P ≤ O do not guarantee N ≥ P; students incorrectly combine opposite directions.

Q3. SSC CGL Tier-1 2024 (Memory-Based)

Question: Statements: P < Q < R; A = B > C > D; R = I < M < N < A. Conclusions: I. R < A, II. I < B.

Solution: Combine: P < Q < R = I < M < N < A = B > C > D. R < A (True), I < B (True). Answer: Both follow.

🧠 Trap: “Complex chain management” — Multiple chains with equalities require careful combination; missing one link breaks the conclusion.

Q4. IBPS Clerk 2019

Question: Statements: G < D ≤ T < Y = O; V < R > K ≥ F > O. Conclusions: I. D < R, II. Y ≥ K.

Solution: From D ≤ T < Y = O and O < F ≤ K < R, D < R is definite (True). Y = O and O < F ≤ K gives Y < K, so Y ≥ K is false. Answer: Only I follows.

🧠 Trap: “Opposite arrow blind spot” — The second chain uses > which reverses direction; students miss the reversal.

Q5. RRB PO 2020

Question: Statements: S > N ≥ W = J ≤ T; Y ≥ U > N ≥ P. Conclusions: I. P ≤ S, II. T > Y.

Solution: S > N ≥ P ⇒ S > P, so P ≤ S is true. Y ≥ U > N ≥ W = J ≤ T gives no relation between T and Y (False). Answer: Only I follows.

🧠 Trap: “Missing link assumption” — T and Y are not connected; students fabricate a relation.

Q7. SBI PO 2021

Question: Statements: A < B = C ≤ D; C > E ≥ F; F > G < H. Conclusions: I. A < D, II. G < B.

Solution: A < B = C ≤ D ⇒ A < D (True). B = C > E ≥ F > G ⇒ B > G (True). Answer: Both follow.

🧠 Trap: “Chain splitting error” — Students fail to split the combined chain into two valid sub-chains.

Q8. IBPS PO 2023

Question: Statements: I > J ≥ K < L; M > N > L; O = P > M. Conclusions: I. K < O, II. M > K.

Solution: K < L < N < M < P = O ⇒ K < O (True). M > N > L > K ⇒ M > K (True). Answer: Both follow.

🧠 Trap: “Multiple intermediate variables” — The chain has many variables; students lose track and skip the question unnecessarily.

Q9. SSC CGL 2020

Question: Which symbols should be placed in blanks: P _ R _ D _ U _ E so that ‘U ≤ P’ and ‘P ≥ D’ definitely hold? Options include ≥, =, <, etc.

Solution: Option D: P ≥ R = D ≥ U < E satisfies both. Answer: D.

🧠 Trap: “Trial-and-error time sink” — Students test each option, consuming time beyond 45 seconds. Skip if not solved in 45 seconds.

Q10. Bank PO 2022

Question: Statements: P ≤ Q < R > K; R < S > T; T < U < V. Conclusions: I. P < S, II. P ≥ S.

Solution: P ≤ Q < R < S ⇒ P < S. So I is true, II is false. Answer: Only I follows.

🧠 Trap: “Either-or mirage” — I and II look complementary, but because I is true, Either-Or cannot apply. Students waste time checking Either-Or conditions.

5. Questions to Skip Based on 15/45-Second Rule

Skip according to 15-second rule: Q6 (Coded Inequality with five symbols) — If decoding the symbols takes more than 15 seconds, mark it for review and move on to avoid early time loss.

Skip according to 45-second rule: Q9 (Missing Symbol) — If the trial-and-error process extends beyond 45 seconds, skip it. Such questions can consume disproportionate time relative to their 1-mark value.
