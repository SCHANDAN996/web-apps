# Short Tricks: Inequality

Trick: If all signs point the same way, the ends join — A > B > C → A > C.

Trick: Equality (=) in between still lets the chain run — A > B = C → A > C.

Trick: If the direction changes (> then <), no definite relation between the ends — immediately "Can't say".

Trick: Think of ≥ as "> or =" and ≤ as "< or ="; don't forget the equality part in the conclusion.

Trick: Either-Or applies only when one conclusion has > and the other = on the same pair, and neither is correct alone.

Trick: Draw a number line or arrows — all arrows one way means joined, else broken.

Skip Strategy: In a long chain (5+ quantities), just check the path between the two ends asked; skip the rest.

💡 Mnemonic: "Same direction joins, changed direction breaks" — the heart of inequality.
