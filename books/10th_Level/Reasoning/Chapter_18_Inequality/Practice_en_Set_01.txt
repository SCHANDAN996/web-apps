Set 1: Inequality MCQs (English)
Questions 1–16: Easy | Questions 17–20: Medium

Q1. If X > Y > Z, then which is true?
(a) X > Z (b) Z > X (c) X = Z (d) Can't say
Answer: (a) X > Z
Solution: Same direction: X > Y > Z gives X > Z.
Source: NCERT Reasoning

Q2. If X < Y < Z, which is the largest?
(a) X (b) Y (c) Z (d) Can't say
Answer: (c) Z
Solution: X < Y < Z, so Z is the largest.
Source: SSC MTS

Q3. If A > B < C, what is the relation between A and C?
(a) A > C (b) A < C (c) A = C (d) Can't say
Answer: (d) Can't say
Solution: The direction changes, so no definite relation.
Source: SSC CHSL

Q4. If A = B = C, what is the relation between A and C?
(a) A > C (b) A < C (c) A = C (d) Can't say
Answer: (c) A = C
Solution: All are equal, so A = C.
Source: RRB NTPC

Q5. If P > Q = R, then which is true?
(a) P > R (b) P < R (c) P = R (d) Can't say
Answer: (a) P > R
Solution: P > Q and Q = R, so P > R.
Source: NCERT Reasoning

Q6. What does '≤' mean?
(a) greater than (b) less than or equal to (c) equal to (d) greater than or equal
Answer: (b) less than or equal to
Solution: ≤ means less than or equal.
Source: NCERT Reasoning

Q7. If A > B > C > D, is A > D?
(a) True (b) False (c) Can't say (d) A = D
Answer: (a) True
Solution: Same direction throughout: A > D.
Source: SSC MTS

Q8. If A < B > C, what is the relation between A and C?
(a) A > C (b) A < C (c) A = C (d) Can't say
Answer: (d) Can't say
Solution: The direction changes, so no definite relation.
Source: SSC CGL

Q9. If M ≥ N > O, then which is true?
(a) M > O (b) M < O (c) M = O (d) Can't say
Answer: (a) M > O
Solution: M ≥ N and N > O, so M > O.
Source: Bank Clerk

Q10. If A > B = C > D, is A > D?
(a) True (b) False (c) Can't say (d) A = D
Answer: (a) True
Solution: A > B = C > D, all forward, so A > D.
Source: SSC CGL

Q11. What does the '>' sign mean?
(a) less than (b) greater than (c) equal to (d) not equal
Answer: (b) greater than
Solution: > means greater than.
Source: NCERT Reasoning

Q12. If A < B = C, is A < C?
(a) True (b) False (c) Can't say (d) A = C
Answer: (a) True
Solution: A < B and B = C, so A < C.
Source: SSC MTS

Q13. If A > B, B > C and C > D, is A > D?
(a) True (b) False (c) Can't say (d) A = D
Answer: (a) True
Solution: Same direction throughout: A > D.
Source: RRB Group D

Q14. If X = Y and Y > Z, is X > Z?
(a) True (b) False (c) Can't say (d) X = Z
Answer: (a) True
Solution: X = Y and Y > Z, so X > Z.
Source: SSC CHSL

Q15. If A ≤ B ≤ C, what is the relation between A and C?
(a) A ≥ C (b) A ≤ C (c) A = C (d) Can't say
Answer: (b) A ≤ C
Solution: Same direction: A ≤ B ≤ C gives A ≤ C.
Source: NCERT Reasoning

Q16. "Either A > C or A = C" is the same as:
(a) A < C (b) A ≥ C (c) A ≤ C (d) A ≠ C
Answer: (b) A ≥ C
Solution: "> or =" together means ≥.
Source: SSC CGL

Q17. (Medium) If P < Q < R < S, which is the smallest?
(a) P (b) Q (c) R (d) S
Answer: (a) P
Solution: P < Q < R < S, so P is the smallest.
Source: SSC CGL

Q18. (Medium) If A > B < C > D, what is the relation between A and D?

Solution: The direction changes, so no definite relation between A and D.

Q19. (Medium) If A = B, B = C and C = D, what is the relation between A and D?

Answer: (c) A = D
Solution: All equal, so A = D.

Q20. (Medium) If A ≥ B and B ≥ C, is A ≥ C?
