## 📋 महत्वपूर्ण नियम और दृष्टिकोण

| **भाग** | **नियम का नाम** | **विवरण** | **उदाहरण** |
|----------|------------------|------------|-------------|
| **मुख्य नियम/दृष्टिकोण** | मिनट की सुई की चाल | 6° प्रति मिनट | 15 मिनट में मिनट की सुई 90° घूमेगी |
| | घंटे की सुई की चाल | 0.5° प्रति मिनट | 15 मिनट में घंटे की सुई 7.5° खिसकेगी |
| | सापेक्ष लाभ चाल | 5.5° प्रति मिनट (6° – 0.5°) | सुइयाँ दोबारा मिलने में 360/5.5 = 65⁵⁄₁₁ मिनट |
| | सुइयों के बीच कोण (न्यून) | θ = |30H – 5.5M|; यदि >180 तो 360–θ | 7:25 पर कोण = |210 – 137.5| = 72.5° |
| | सुइयों का मिलन (एक साथ) | 12 घंटे में 11 बार; सूत्र: M = 60H/11 | 3 और 4 के बीच: 3 बजकर 16⁴⁄₁₁ मिनट पर |
| | सुइयाँ विपरीत (180°) | 12 घंटे में 11 बार; M = (60H ± 180)/11 | 5 और 6 के बीच: 5 बजकर 43⁷⁄₁₁ मिनट पर (60×5+180)/11 |
| | सुइयाँ समकोण (90°) | 12 घंटे में 22 बार; M = (60H ± 90)/11 | 2 और 3 के बीच: 2 बजकर 19¹⁄₁₁ मिनट पर (120+90)/11 |
| | दर्पण समय | दर्पण समय = 11:60 – दिया गया समय (12 घंटे प्रारूप में) | 3:25 → 11:60 – 3:25 = 8:35 |
| | जल प्रतिबिम्ब समय | जल प्रतिबिम्ब = 18:30 – दिया गया समय | 10:10 → 18:30 – 10:10 = 8:20 |
| | खराब घड़ी (लाभ/हानि) | सही समय दिखाने के लिए दिन = 720 ÷ (प्रतिदिन लाभ मिनटों में) | 5 मिनट/दिन तेज़ → 720/5 = 144 दिन |
| | विषम दिन (साधारण/लीप) | साधारण वर्ष: 1 विषम दिन; लीप वर्ष: 2 विषम दिन | 2023 (साधारण) → 1 विषम दिन |
| | लीप वर्ष की जाँच | 4 से विभाज्य; शताब्दी वर्ष 400 से विभाज्य होने पर ही लीप | 2000 लीप; 1900 लीप नहीं |
| | महीना कोड (साधारण) | जन=0, फर=3, मार्च=3, अप्रैल=6, मई=1, जून=4, जुला=6, अग=2, सित=5, अक्टू=0, नव=3, दिस=5 | 15 अगस्त → मास कोड = 2 |
| | महीना कोड (लीप वर्ष) | जन=6, फर=2, शेष साधारण वर्ष के समान | 29 फरवरी 2024 → कोड 2 |
| | शताब्दी कोड | 1600s:6, 1700s:4, 1800s:2, 1900s:0, 2000s:6 | 1947 → शताब्दी कोड = 0 |
| | किसी तारीख का दिन | (तारीख + मास कोड + वर्ष कोड + शताब्दी कोड) mod 7 | 15 अगस्त 1947 → (15+2+2+0)=19 mod7=5 → शुक्रवार |
| | वर्ष कोड | (YY + ⌊YY/4⌋) mod 7 | 47 के लिए → (47+11)=58 mod7=2 |
| | समान कैलेंडर वर्ष | साधारण: 6 या 11 वर्ष बाद (विषम दिन जाँचें); लीप: 28 वर्ष बाद | 2025 (साधारण) → 2031 (यदि विषम दिन मिलान हो) |
| | **परीक्षक के जाल की सावधानी** | न्यून कोण और बड़ा कोण; जब तक न कहा जाए, छोटा कोण दें | 12:15 पर सूत्र से 277.5° → न्यून कोण 82.5° |
| | **परीक्षक के जाल की सावधानी** | दर्पण और जल प्रतिबिम्ब में घटाने का आधार भिन्न | प्रश्न में "दर्पण" (11:60 से) और "जल" (18:30 से) रेखांकित करें |
| | **परीक्षक के जाल की सावधानी** | लीप वर्ष में जनवरी/फरवरी के कोड मार्च से पहले बदलना | 15 फरवरी 2024 (लीप) → मास कोड 2, न कि 3 |
| **समय प्रबंधन** | 15-सेकंड नियम | यदि प्रश्न का प्रकार 15 सेकंड में पहचान में न आए (जैसे जटिल खराब घड़ी, अपरिचित भाषा), तो निशान लगाकर तुरंत छोड़ दें। | पुरानी तारीख और ग्रेगोरियन बदलाव से जुड़ा कैलेंडर प्रश्न |
| | 45-सेकंड नियम | यदि विधि पता हो फिर भी गणना 45 सेकंड से अधिक ले रही हो (जैसे 1900 से पहले का विस्तृत विषम दिन हिसाब), तो छोड़ें और बाद में लौटें। | 31 दिसंबर 1752 जैसा दुर्लभ प्रश्न |
| | प्राथमिकता क्रम | दर्पण/जल और सरल कोण के प्रश्न पहले हल करें; बहु-चरणीय खराब घड़ी और लीप-शताब्दी वाले कैलेंडर प्रश्न बाद में करें। | |
