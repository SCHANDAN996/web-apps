# 🔧 Mechanic Core Return Tracker

A modern **PWA & Hybrid Mobile Application** to track auto parts, core returns, mechanic credits, and refund lifecycles built with **Vite**, **JavaScript / Web Components**, and **Capacitor**.

---

## 🌟 Key Features
* 📦 **Core Return Logging:** Log parts by serial number, receipt, vehicle type, and mechanic ID.
* 💵 **Credit & Refund Tracking:** Track pending refunds from auto-part distributors and suppliers.
* 📱 **PWA & Android Support:** Installable as a Progressive Web App (PWA) or runnable as a native Android app via Capacitor.
* ⚡ **Offline First:** Fast client-side storage and responsive mobile-first UI.

---

## 🛠️ Tech Stack
* **Frontend:** Vite, HTML5, CSS3, Modern ES6+ JavaScript
* **Mobile Wrapper:** Capacitor / Android
* **Tooling:** Node.js, npm

---

## 🚀 Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server
npm run dev

# 3. Build for production
npm run build
```
