## 📌 Project Architecture & Capabilities

### 1️⃣ 🏥 [`hospital_management/`](hospital_management/)
* **Architecture:** Enterprise-grade NestJS backend with modular services, PostgreSQL / TypeORM, Nuxt frontend, and Docker Compose orchestration.
* **Modules:** Doctor/Staff scheduling, Outpatient (OPD) & Inpatient (IPD) records, appointment booking queues, and pharmacy billing invoices.

### 2️⃣ 🏫 [`school_portal_jsps/`](school_portal_jsps/)
* **Architecture:** Full-featured Python Flask portal with student admissions, fee tracking, role-based dashboards (Parent/Teacher/Admin), and CBSE compliance report viewers.

### 3️⃣ 🔧 [`mechanic_tracker/`](mechanic_tracker/)
* **Architecture:** Vite-powered Progressive Web App (PWA) with camera barcode/OCR scanning, Supabase sync, and Capacitor Android wrapper for automotive parts core return management.

### 4️⃣ 📄 [`pdf_compressor/`](pdf_compressor/)
* **Architecture:** Zero-leakage local PDF optimizer and DPI scaling tool running on `localhost`.

### 5️⃣ 🤖 [`whatsapp_automation/`](whatsapp_automation/)
* **Architecture:** Automated messaging and file broadcast scheduling dashboard with transaction history logging.
