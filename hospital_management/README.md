# 🏥 Enterprise Hospital Management System

A robust, full-stack **Hospital & Healthcare Management Platform** designed with a microservices/modular architecture using **NestJS**, modern frontend interfaces, **PostgreSQL / TypeORM**, and **Docker**.

---

## 🌟 Key Modules
* 🩺 **Doctor & Staff Management:** Doctor schedules, specialization records, and department allocations.
* 📋 **Patient Management:** Outpatient (OPD) & Inpatient (IPD) registration, medical records, and history tracking.
* 📅 **Appointments & Scheduling:** Automated appointment booking and doctor availability queues.
* 💳 **Billing & Pharmacy:** Invoices, prescription management, and billing records.
* 🐳 **Dockerized Setup:** Single-command container deployment for database and services.

---

## 🛠️ Tech Stack
* **Backend:** Node.js, NestJS, TypeScript, TypeORM, PostgreSQL
* **Frontend:** Nuxt.js / Vue.js / Modern Web UI
* **DevOps:** Docker, Docker Compose

---

## 🚀 Getting Started

### Using Docker Compose:
```bash
docker-compose up -d
```

### Local Development:
```bash
# 1. Install dependencies
npm install

# 2. Run Backend
cd backend && npm install && npm run start:dev

# 3. Run Frontend
cd frontend && npm install && npm run dev
```
