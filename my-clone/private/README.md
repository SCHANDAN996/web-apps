# निजी जानकारी का स्थान
अभी यह फ़ोल्डर केवल private classification के लिए है। Password/API key/token/private key यहाँ भी न रखें; dedicated सुरक्षित credential storage इस्तेमाल हो।
Detailed financial records, sensitive personal memories और तीसरे व्यक्तियों की निजी बातें उपयोगकर्ता की इच्छा से अलग records में रखें। परिवार export में इन्हें न मिलाएँ। फ़ोल्डर का नाम access-control नहीं बनाता; अभी सारी main memory private है।
