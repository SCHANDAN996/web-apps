# मेरी डिजिटल स्मृति — शुरुआत

यह साझा करने योग्य ढाँचा है। अपनी निजी जानकारी भरने से पहले `python tools/init_memory.py` चलाएँ। इससे स्थानीय निजी memory files बनेंगी; पुरानी files नहीं बदलेंगी।

काम का क्रम: `protocols/CHAT-RECORD.md` → `protocols/UPDATE.md` → जरूरत पर `agents/ROUTING.md`।
