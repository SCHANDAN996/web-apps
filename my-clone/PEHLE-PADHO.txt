MY CLONE - kaise use karein
===========================

1. Ye poora "my-clone" folder apne "my project" folder ke andar rakh do.
   Agar tumhare repos (android-apps, ebook, web-apps) bhi "my project" mein hain,
   toh CLAUDE.md aur .claude folder ko seedha "my project" folder mein rakhna
   behtar hai, taaki agent saare repos dekh sake.

2. Claude Code (desktop app ya terminal) mein wahi folder kholo.

3. Likho:  /chandan-assistant
   ya bolo: "briefing do"

Agent tumhare saare projects dekh ke batayega kya hua, kya baaki hai,
aur puchhega aaj kya karna hai.

Dhyan do: ".claude" folder Windows mein chhupa (hidden) ho sakta hai.
File Explorer mein View > Show > Hidden items on kar lo.

Kuch badalna ho (goal, naya product, band project), toh bas CLAUDE.md
file Notepad mein khol ke badal do.
