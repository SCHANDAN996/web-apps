# इस चैट की मेमोरी बनाने का प्रॉम्प्ट

मेरे memory project के START-HERE.md, protocols/CHAT-RECORD.md और protocols/UPDATE.md पढ़ो। इस चैट के उपलब्ध इतिहास से देवनागरी हिंदी में source-linked record बनाओ: उद्देश्य, पसंद, विचार, निर्णय, सुधार, अस्वीकृति, वास्तविक काम, वापसी, अधूरे काम और उपयोगी आगे के कदम।

हर महत्वपूर्ण निष्कर्ष के साथ छोटा असली quote और उपलब्ध तारीख/source दो। मेरे कथन, AI सलाह और अनुमान अलग रखो। दूसरों के लिए pasted/drafted सामग्री को मेरी जीवनी मत मानो। चुप्पी से abandonment न निकालो।

provider/chat ID के stable filename से chats/records में अलग file बनाओ; पहले से हो तो उसी में update जोड़ो। ID उपलब्ध न हो तो local UUID और source सीमा रखो। जरूरी specialists से प्रस्ताव और evidence review लेकर एक coordinator ही मुख्य memory में reviewed deltas जोड़े। सूची और portable summary refresh करो।

अंत में record का पूरा पथ, बदलाव, पढ़े इतिहास की सीमा और अज्ञात बातें बताओ। स्थानीय write access न हो तो named Markdown file लौटाओ; save होने का दावा न करो।
